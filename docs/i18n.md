# i18n — Sistema de internacionalização

**Status: FROZEN desde 2026-08-06.** O frontend converge para **PT-BR apenas**. Manter
lições MDX sincronizadas em várias línguas contra uma fonte PT-BR que segue evoluindo
exige uma nova rodada de tradução via LLM a cada revisão — custo real e recorrente de
tokens que o projeto não sustenta agora. Nada foi apagado: o dicionário de UI, as
strings de áudio e as lições traduzidas continuam no repositório, só não estão mais
roteadas no site publicado.

Este documento estava desatualizado mesmo antes do freeze (falava em 16 idiomas,
`content/translations/`, e scripts `translate-ui.ts`/`translate-content.ts` que nunca
existiram no pipeline real). Para a arquitetura de fato usada, o histórico do que foi
construído, e o que exatamente foi congelado, veja **`CLAUDE.md` §4** — é a fonte de
verdade, mantida em sincronia com o código.

Resumo rápido do que existe hoje (tudo pausado, não roteado):

- `src/lib/i18n/translations.ts` — dicionário de UI, 11 locales.
- `src/content/audio-translations.generated.ts` — strings de TTS, 11 locales.
- `content/i18n/<locale>/aulas/...` — lições MDX traduzidas (en-US 120/120; as demais
  parciais, defasadas contra a fonte PT-BR de 2026-05-31).
- Pipeline de tradução: agentes Claude Code (Haiku para volume, Sonnet para arquivos
  grandes, Opus para casos raros) — ver CLAUDE.md §4/§5.

Para retomar, siga o "playbook de re-sync" em `CLAUDE.md` §9.
