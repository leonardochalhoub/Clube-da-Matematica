### Definição fundamental

<Definicao titulo="Matriz diagonalizavel">

Seja $A \in \mathcal{M}_n(\mathbb{K})$. Dizemos que $A$ é **diagonalizável** (sobre $\mathbb{K}$) se existe uma matriz $P$ inversível tal que

<Equation explicacao="Decomposição espectral: P tem os autovetores como colunas, D é diagonal com os autovalores." latex="A = PDP^{-1}, \qquad D = \operatorname{diag}(\lambda_1, \lambda_2, \ldots, \lambda_n)" />

Equivalentemente, $AP = PD$ — cada coluna $p_i$ de $P$ satisfaz $Ap_i = \lambda_i p_i$, ou seja, é autovetor de $A$ com autovalor $\lambda_i$.

</Definicao>

> "A matrix $A$ is diagonalizable if it is similar to a diagonal matrix — there exists an invertible $P$ such that $P^{-1}AP$ is diagonal." — [Beezer, A First Course in Linear Algebra, §SD](http://linear.ups.edu/html/section-SD.html)

### Condições equivalentes

<Teorema titulo="Criterio de diagonalizabilidade">

As seguintes afirmações são equivalentes para $A \in \mathcal{M}_n(\mathbb{K})$:

1. $A$ é diagonalizável.
2. $A$ possui $n$ autovetores linearmente independentes.
3. A soma das dimensões dos autoespaços é igual a $n$: $\sum_\lambda \dim E_\lambda = n$.
4. Para cada autovalor $\lambda$, a multiplicidade geométrica iguala a multiplicidade algébrica: $m_g(\lambda) = m_a(\lambda)$.
5. $\mathbb{K}^n = \bigoplus_\lambda E_\lambda$ — o espaço é soma direta dos autoespaços.

**Prova da equivalência 2 $\Leftrightarrow$ 1.** Se $\{v_1, \ldots, v_n\}$ são $n$ autovetores LI com autovalores $\lambda_1, \ldots, \lambda_n$, forme $P = [v_1 \mid \cdots \mid v_n]$. Como as colunas são LI, $P$ é inversível. Calcule:

$$AP = A[v_1 \mid \cdots \mid v_n] = [\lambda_1 v_1 \mid \cdots \mid \lambda_n v_n] = [v_1 \mid \cdots \mid v_n]\operatorname{diag}(\lambda_i) = PD$$

Logo $P^{-1}AP = D$. A recíproca é imediata: se $A = PDP^{-1}$, as colunas de $P$ são autovetores LI. $\square$

</Teorema>

> "An $n \times n$ matrix $A$ is diagonalizable if and only if $A$ has $n$ linearly independent eigenvectors." — [Beezer, A First Course in Linear Algebra, §SD Theorem DED](http://linear.ups.edu/html/section-SD.html)

### Algoritmo de diagonalização

1. Calcule o polinômio característico $p_A(\lambda) = \det(A - \lambda I)$ e encontre as raízes $\lambda_1, \ldots, \lambda_k$ com multiplicidades algébricas $m_a(\lambda_i)$.
2. Para cada $\lambda_i$, resolva $(A - \lambda_i I)v = 0$ e encontre uma base de $E_{\lambda_i} = \ker(A - \lambda_i I)$. Verifique $m_g(\lambda_i) = \dim E_{\lambda_i}$.
3. Se $\sum m_g(\lambda_i) = n$: monte $P$ com os autovetores como colunas e $D = \operatorname{diag}(\lambda_1, \ldots, \lambda_n)$ (respeitando a ordem das colunas).
4. Se $\sum m_g(\lambda_i) < n$: $A$ não é diagonalizável — recorra à forma de Jordan.

### Aplicações imediatas

<Insight>

**$A^k$ em uma multiplicação.** Se $A = PDP^{-1}$, então $A^k = PD^kP^{-1}$ porque $(PDP^{-1})^k = PD(P^{-1}P)D\cdots DP^{-1} = PD^kP^{-1}$. E $D^k = \operatorname{diag}(\lambda_1^k, \ldots, \lambda_n^k)$ é trivial. Isso reduz $k$ multiplicações matriciais $O(n^3)$ a **uma única** composição.

</Insight>

<Equation explicacao="Potência matricial via diagonalização: D^k tem os autovalores elevados a k na diagonal." latex="A^k = P D^k P^{-1}, \quad D^k = \operatorname{diag}(\lambda_1^k, \ldots, \lambda_n^k)" />

<Equation explicacao="Exponencial de matriz: cada autovalor lambda_i gera e^{lambda_i t} na diagonal." latex="e^{At} = P e^{Dt} P^{-1}, \quad e^{Dt} = \operatorname{diag}(e^{\lambda_1 t}, \ldots, e^{\lambda_n t})" />

Para qualquer função analítica $f$: $f(A) = Pf(D)P^{-1}$ com $f(D) = \operatorname{diag}(f(\lambda_i))$.

</Porta>

<Porta nivel="5" titulo="Pra criança de 5 anos">

Imagina uma **caixa bagunçada** com brinquedos todos misturados. Se você separa por cor — vermelhos numa pilha, azuis em outra — fica muito mais fácil contar e brincar.

**Diagonalizar** uma matriz é exatamente isso: organizar os objetos matemáticos em **pilhas separadas** chamadas autovetores. Cada pilha tem um número especial (o autovalor) que diz "quanto cada coisa dessa cor cresce".

Depois de organizado, fazer muitas operações de uma vez vira conta simples: em vez de mexer em tudo junto, você só multiplica cada pilha pelo número dela — independente das outras.

</Porta>

<Porta nivel="10" titulo="Pra criança de 10 anos">

Diagonalizar uma matriz é como **trocar de óculos** pra ver melhor.

Sem óculos, $A$ parece complicada — números por todo lado, tudo misturado. Com os óculos certos (a mudança de base para autovetores), você enxerga $D$: uma matriz só com números na diagonal e zeros em todo o resto.

**Por que é útil?** Imagina que você quer calcular $A^{100}$ — multiplicar $A$ por ela mesma 100 vezes. Sem os óculos: trabalhíssimo. Com os óculos:

$$A^{100} = P D^{100} P^{-1}$$

E $D^{100}$ é fácil — só eleva cada número da diagonal à potência 100. Pronto.

$P$ é o "troca de óculos" e $P^{-1}$ é o "volta pros óculos normais".

</Porta>

<Porta nivel="15" titulo="Pra adolescente de 15 anos">

Diagonalização é a **transformação que revela** o que a matriz realmente faz. Em vez de ver números misturados, você enxerga direções independentes de esticamento.

### Por que isso é poderoso?

Qualquer iteração linear $x_{k+1} = Ax_k$ tem solução fechada via diagonalização. Escreva $x_0 = \sum c_i v_i$ (combinação dos autovetores de $A$). Então:

$$x_k = A^k x_0 = \sum_{i=1}^n c_i \lambda_i^k v_i$$

Cada componente cresce ou decai de forma independente, com taxa $\lambda_i$. São os **modos próprios** do sistema.

### Aplicação clássica: fórmula de Binet

A recorrência de Fibonacci $F_{n+1} = F_n + F_{n-1}$ em forma matricial:

$$\begin{pmatrix} F_{n+1} \\ F_n \end{pmatrix} = \begin{pmatrix} 1 & 1 \\ 1 & 0 \end{pmatrix}^n \begin{pmatrix} 1 \\ 0 \end{pmatrix}$$

Diagonalizando a matriz (autovalores $\phi = (1+\sqrt{5})/2$ e $\psi = (1-\sqrt{5})/2$):

$$F_n = \frac{\phi^n - \psi^n}{\sqrt{5}}$$

— a **fórmula fechada de Binet** — sem calcular $F_1, F_2, \ldots, F_{n-1}$.

### Quando NÃO diagonaliza?

Quando $m_g(\lambda) < m_a(\lambda)$ para algum $\lambda$. Exemplo clássico:

$$\begin{pmatrix} 2 & 1 \\ 0 & 2 \end{pmatrix}$$

Autovalor 2 com $m_a = 2$, mas $m_g = 1$ (só um autovetor independente). Não diagonaliza sobre $\mathbb{R}$ nem $\mathbb{C}$. Nesse caso, usa-se a **forma de Jordan** (próxima grande fronteira de álgebra linear).

</Porta>

<Porta nivel="25" titulo="Pra estudante de engenharia">

Diagonalização transforma **álgebra acoplada em álgebra desacoplada**. É a operação base de toda análise modal em engenharia estrutural, controle e processamento de sinais.

### Aplicação 1: sistemas LTI — equações diferenciais vetoriais

$\dot{x} = Ax$, $x(0) = x_0$. Se $A = PDP^{-1}$, mude variável $y = P^{-1}x$:

$$\dot{y} = P^{-1}\dot{x} = P^{-1}AP y = Dy$$

Sistema **desacoplado**: $\dot{y}_i = \lambda_i y_i$ para cada $i$. Solução: $y_i(t) = y_i(0)e^{\lambda_i t}$.

Voltando à variável original: $x(t) = Pe^{Dt}P^{-1}x_0 = \sum_{i=1}^n (P^{-1}x_0)_i e^{\lambda_i t} v_i$.

Estabilidade: $x(t) \to 0$ quando $t \to \infty$ se e somente se $\operatorname{Re}(\lambda_i) < 0$ para todo $i$ (**critério espectral de estabilidade**).

### Aplicação 2: análise modal em estruturas

Sistema massa-mola acoplado: $M\ddot{q} + Kq = 0$. Reduzindo a autoproblema generalizado $Kv = \lambda Mv$, os **modos normais** (autovetores) são as formas de vibração e as **frequências naturais** são $\omega_i = \sqrt{\lambda_i}$. A diagonalização desacopla as equações — cada modo vibra independente. Isso é a base do método de superposição modal (FEM, SAP2000, ANSYS).

### Aplicação 3: cadeias de Markov

Distribuição $\pi_{t+1} = P^T \pi_t$. Se $P$ é estocástica irredutível e aperiódica, diagonalizando: $\pi_t = P^T{}^t \pi_0$. A taxa de convergência à distribuição estacionária é governada pelo **segundo maior autovalor** $|\lambda_2|$ (gap espectral).

### Custo computacional e limites práticos

- Decomposição completa de autovalores: $O(n^3)$ via algoritmo QR iterativo.
- $A^k$ via diagonalização: $O(n^3)$ uma vez + $O(n^2)$ por passo — vantagem enorme para $k \gg n$.
- **Cuidado:** se $\kappa(P)$ (número de condicionamento de $P$) é alto, a decomposição é numericamente instável. Para matrizes simétricas, $P$ é ortogonal ($\kappa(P) = 1$) — estabilidade perfeita.
- Para matrizes esparsas, preferir Lanczos (busca alguns autovalores, não todos).

</Porta>

### Forma de Jordan: quando a diagonalização falha

Quando $A$ não é diagonalizável, a decomposição canônica é $A = PJP^{-1}$ com $J$ bloco-diagonal de blocos de Jordan:

$$J_{n_i}(\lambda_i) = \lambda_i I_{n_i} + N_{n_i}, \quad N_{n_i} = \begin{pmatrix} 0 & 1 & & \\ & 0 & \ddots & \\ & & \ddots & 1 \\ & & & 0 \end{pmatrix}$$

onde $N_{n_i}^{n_i} = 0$ (nilpotente). Aplicações de funções analíticas: $f(J_n(\lambda)) = \sum_{k=0}^{n-1} \frac{f^{(k)}(\lambda)}{k!} N^k$ — série truncada por nilpotência.

Em prática numérica, Jordan é **mal-condicionada** — a base $P$ pode ter $\kappa(P)$ altíssimo. Usa-se em vez disso a **decomposição de Schur** $A = QTQ^*$ com $Q$ unitária e $T$ triangular superior: numericamente estável, com $\kappa(Q) = 1$.

### Diagonalização simultânea

$\{A_i\}$ são simultaneamente diagonalizáveis $\iff$ comutam: $A_iA_j = A_jA_i$ para todo par. Em mecânica quântica, **observáveis compatíveis** ↔ operadores hermitianos que comutam ↔ podem ser medidos simultaneamente (base comum de autovetores). O princípio da incerteza de Heisenberg nasce da não-comutatividade de $\hat{x}$ e $\hat{p}$.

### Pseudoespectro e matrizes não-normais

Para matrizes não-normais, autovalores podem ser **enganosos**: pequena perturbação pode mudar muito a localização espectral. O $\epsilon$-pseudoespectro é:

$$\sigma_\epsilon(A) = \{z \in \mathbb{C} : \|(zI - A)^{-1}\|_2 > 1/\epsilon\}$$

Trefethen mostrou que o pseudoespectro explica fenômenos de *transient growth* em fluxos shear (turbulência subcrítica em Couette-Poiseuille) e instabilidade em redes neurais recorrentes.

### Conexão com Black-Scholes (L119)

A matriz Hessiana das sensibilidades $\Gamma_{ij} = \partial^2 V/\partial S_i \partial S_j$ em carteiras multi-ativo é simétrica positiva semidefinida. Diagonalizá-la revela as **direções de risco principais** — base da atribuição de risco em portfólios (Litterman, RiskMetrics 1994). Os autovalores são as variâncias nas direções não-correlacionadas; os autovetores são os **fatores de risco** ortogonais.

### Extensões modernas

- **Operador de Koopman**: levanta dinâmica não-linear para espaço de observáveis infinito-dimensional e lineariza — a diagonalização do operador (via DMD, Dynamic Mode Decomposition) identifica padrões coerentes em dados de fluidos e climate (Schmid 2010).
- **Análise espectral em deep learning**: skip connections em ResNets mantêm autovalores dos jacobianos próximos de 1, evitando explosion/vanishing gradients (He et al. 2016).

</Porta>

### Receita passo a passo

1. Calcule os autovalores: resolva $\det(A - \lambda I) = 0$.
2. Para cada autovalor $\lambda_i$, encontre base de $\ker(A - \lambda_i I)$.
3. Verifique: $\sum \dim E_{\lambda_i} = n$? Se sim, é diagonalizável.
4. Monte $P = [v_1 \mid v_2 \mid \cdots \mid v_n]$ e $D = \operatorname{diag}(\lambda_1, \ldots, \lambda_n)$.
5. Confira: $AP = PD$ (mais simples que calcular $PDP^{-1}$ explicitamente).

### Aplicação prática: crescimento populacional (IBGE)

Modelo Leslie de 2 faixas etárias — jovens ($J$) e adultos ($A$) — com taxas de fertilidade e sobrevivência típicas para um município brasileiro de porte médio:

$$M = \begin{pmatrix} 0{,}6 & 1{,}2 \\ 0{,}4 & 0{,}0 \end{pmatrix}$$

Para projetar 10 ciclos: $v_{10} = M^{10} v_0$. Via diagonalização, calcula-se uma vez e aplica-se diretamente — sem iterar 10 multiplicações de matrizes.

### Estabilidade de sistemas de controle

Um sistema de controle $\dot{x} = Ax$ é estável se $\operatorname{Re}(\lambda_i) < 0$ para todo $i$. Para checar estabilidade, você não precisa resolver a EDO — basta diagonalizar (ou calcular o espectro) de $A$ e verificar onde os autovalores caem no plano complexo.

### Quando NÃO usar diagonalização diretamente

- **$A$ próxima de defectiva**: $\kappa(P)$ alto → erros amplificados. Use Schur.
- **$A$ grande e esparsa, querendo poucos modos**: use Lanczos/Arnoldi (MATLAB `eigs`, SciPy `eigsh`).
- **$A$ simétrica real**: use sempre `np.linalg.eigh` (mais rápido, estável, garante $P$ ortogonal).

</Porta>

## Exemplos resolvidos

<Exemplo titulo="Diagonalizando uma matriz 2×2 (basico)" numero="1">

**Problema:** Diagonalize $A = \begin{pmatrix} 4 & 1 \\ 2 & 3 \end{pmatrix}$.

**Estratégia:** Encontrar autovalores e autovetores, montar $P$ e $D$, verificar $AP = PD$.

**Resolução:**

1. **Polinômio característico:**
$$p_A(\lambda) = \det(A - \lambda I) = (4-\lambda)(3-\lambda) - 2 = \lambda^2 - 7\lambda + 10 = (\lambda - 5)(\lambda - 2)$$
Autovalores: $\lambda_1 = 5$, $\lambda_2 = 2$.

2. **Autovetores:**

Para $\lambda_1 = 5$: $(A - 5I)v = 0 \Rightarrow \begin{pmatrix} -1 & 1 \\ 2 & -2 \end{pmatrix}v = 0$. Base: $v_1 = \begin{pmatrix} 1 \\ 1 \end{pmatrix}$.

Para $\lambda_2 = 2$: $(A - 2I)v = 0 \Rightarrow \begin{pmatrix} 2 & 1 \\ 2 & 1 \end{pmatrix}v = 0$. Base: $v_2 = \begin{pmatrix} 1 \\ -2 \end{pmatrix}$.

3. **Montagem:**
$$P = \begin{pmatrix} 1 & 1 \\ 1 & -2 \end{pmatrix}, \quad D = \begin{pmatrix} 5 & 0 \\ 0 & 2 \end{pmatrix}$$

**Verificação:** $AP = \begin{pmatrix} 5 & 2 \\ 5 & -4 \end{pmatrix}$ e $PD = \begin{pmatrix} 5 & 2 \\ 5 & -4 \end{pmatrix}$. Iguais. $\checkmark$

**Fonte.** [Beezer, A First Course in Linear Algebra §SD, Exemplo DMS22](http://linear.ups.edu/html/section-SD.html) — licença GNU FDL.
</Exemplo>

<Exemplo titulo="Matriz nao-diagonalizavel (compreensao)" numero="2">

**Problema:** Determine se $A = \begin{pmatrix} 3 & 1 \\ 0 & 3 \end{pmatrix}$ é diagonalizável. Justifique.

**Estratégia:** Calcular multiplicidades algébrica e geométrica do único autovalor.

**Resolução:**

1. **Autovalores:** $p_A(\lambda) = (3-\lambda)^2 = 0$, logo $\lambda = 3$ com $m_a = 2$.

2. **Autoespaço:** $(A - 3I) = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$. O sistema $(A - 3I)v = 0$ exige $v_2 = 0$, com $v_1$ livre. Base: $\left\{\begin{pmatrix} 1 \\ 0 \end{pmatrix}\right\}$. Portanto $m_g(3) = 1$.

3. **Conclusão:** $m_g(3) = 1 < 2 = m_a(3)$. Não há dois autovetores LI. **$A$ não é diagonalizável.**

**Verificação:** Se existisse $P$ com $P^{-1}AP = \begin{pmatrix} 3 & 0 \\ 0 & 3 \end{pmatrix} = 3I$, teríamos $A = P(3I)P^{-1} = 3I$. Mas $A \neq 3I$. Contradição. $\checkmark$

**Fonte.** [Beezer, A First Course in Linear Algebra §SD, Exemplo NDMS3](http://linear.ups.edu/html/section-SD.html) — licença GNU FDL.
</Exemplo>

<Exemplo titulo="Potencia matricial via diagonalizacao (intermediario)" numero="3">

**Problema:** Calcule $A^{10}$ para $A = \begin{pmatrix} 2 & 1 \\ 0 & 1 \end{pmatrix}$.

**Estratégia:** Diagonalizar $A$, elevar $D$ à potência 10 (trivial), compor.

**Resolução:**

1. **Autovalores:** $p_A(\lambda) = (2-\lambda)(1-\lambda) = 0$, logo $\lambda_1 = 2$, $\lambda_2 = 1$.

2. **Autovetores:**

$\lambda_1 = 2$: $(A - 2I)v = 0 \Rightarrow \begin{pmatrix} 0 & 1 \\ 0 & -1 \end{pmatrix}v = 0$. $v_1 = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$.

$\lambda_2 = 1$: $(A - I)v = 0 \Rightarrow \begin{pmatrix} 1 & 1 \\ 0 & 0 \end{pmatrix}v = 0$. $v_2 = \begin{pmatrix} 1 \\ -1 \end{pmatrix}$.

3. **Decomposição:** $P = \begin{pmatrix} 1 & 1 \\ 0 & -1 \end{pmatrix}$, $D = \begin{pmatrix} 2 & 0 \\ 0 & 1 \end{pmatrix}$.

$P^{-1} = \begin{pmatrix} 1 & 1 \\ 0 & -1 \end{pmatrix}$ (verificar: $\det P = -1$, logo $P^{-1} = \frac{1}{-1}\begin{pmatrix} -1 & -1 \\ 0 & 1 \end{pmatrix} = \begin{pmatrix} 1 & 1 \\ 0 & -1 \end{pmatrix}$).

4. **Potência:** $D^{10} = \begin{pmatrix} 2^{10} & 0 \\ 0 & 1^{10} \end{pmatrix} = \begin{pmatrix} 1024 & 0 \\ 0 & 1 \end{pmatrix}$.

$$A^{10} = PD^{10}P^{-1} = \begin{pmatrix} 1 & 1 \\ 0 & -1 \end{pmatrix}\begin{pmatrix} 1024 & 0 \\ 0 & 1 \end{pmatrix}\begin{pmatrix} 1 & 1 \\ 0 & -1 \end{pmatrix} = \begin{pmatrix} 1024 & 1023 \\ 0 & 1 \end{pmatrix}$$

**Verificação:** $A^2 = \begin{pmatrix} 4 & 3 \\ 0 & 1 \end{pmatrix}$. Pela fórmula: $A^2 = \begin{pmatrix} 2^2 & 2^2-1 \\ 0 & 1 \end{pmatrix} = \begin{pmatrix} 4 & 3 \\ 0 & 1 \end{pmatrix}$. $\checkmark$

**Fonte.** [Hefferon, Linear Algebra, cap. 5 §II](https://hefferon.net/linearalgebra/) — licença CC-BY-SA.
</Exemplo>

<Exemplo titulo="Formula de Binet para Fibonacci (avancado)" numero="4">

**Problema:** Derive a fórmula fechada de Binet $F_n = \dfrac{\phi^n - \psi^n}{\sqrt{5}}$, onde $\phi = \frac{1+\sqrt{5}}{2}$ e $\psi = \frac{1-\sqrt{5}}{2}$.

**Estratégia:** Reescrever a recorrência como iteração matricial, diagonalizar a matriz de transição.

**Resolução:**

1. **Forma matricial:** $\begin{pmatrix} F_{n+1} \\ F_n \end{pmatrix} = \begin{pmatrix} 1 & 1 \\ 1 & 0 \end{pmatrix}\begin{pmatrix} F_n \\ F_{n-1} \end{pmatrix}$. Seja $M = \begin{pmatrix} 1 & 1 \\ 1 & 0 \end{pmatrix}$.

2. **Autovalores de $M$:** $\lambda^2 - \lambda - 1 = 0 \Rightarrow \lambda = \frac{1 \pm \sqrt{5}}{2}$, logo $\lambda_1 = \phi$, $\lambda_2 = \psi$.

3. **Autovetores:** $v_1 = \begin{pmatrix} \phi \\ 1 \end{pmatrix}$, $v_2 = \begin{pmatrix} \psi \\ 1 \end{pmatrix}$.

4. **Decomposição:** $\begin{pmatrix} F_{n+1} \\ F_n \end{pmatrix} = M^n \begin{pmatrix} 1 \\ 0 \end{pmatrix} = PD^nP^{-1}\begin{pmatrix} 1 \\ 0 \end{pmatrix}$.

$P = \begin{pmatrix} \phi & \psi \\ 1 & 1 \end{pmatrix}$, $\det P = \phi - \psi = \sqrt{5}$. $P^{-1} = \frac{1}{\sqrt{5}}\begin{pmatrix} 1 & -\psi \\ -1 & \phi \end{pmatrix}$.

5. **Segunda componente:** $F_n = \frac{\phi^n(\phi - \psi + \psi \cdot \text{...}) - \psi^n(\ldots)}{\sqrt{5}}$. Calculando explicitamente a segunda linha de $PD^nP^{-1}\begin{pmatrix}1\\0\end{pmatrix}$:

$$F_n = \frac{1}{\sqrt{5}}\left(\phi^n \cdot 1 \cdot \frac{1}{\sqrt{5}}\sqrt{5} - \psi^n \cdot 1 \cdot \frac{1}{\sqrt{5}}\sqrt{5}\right) = \frac{\phi^n - \psi^n}{\sqrt{5}}$$

**Verificação:** $F_1 = \frac{\phi - \psi}{\sqrt{5}} = \frac{\sqrt{5}}{\sqrt{5}} = 1$. $F_2 = \frac{\phi^2 - \psi^2}{\sqrt{5}} = \frac{(\phi-\psi)(\phi+\psi)}{\sqrt{5}} = \frac{\sqrt{5} \cdot 1}{\sqrt{5}} = 1$. $\checkmark$

**Fonte.** [Beezer, A First Course in Linear Algebra §SD](http://linear.ups.edu/html/section-SD.html) — licença GNU FDL.
</Exemplo>

<Exemplo titulo="Estabilidade de sistema dinamico (modelagem)" numero="5">

**Problema:** O sistema $\dot{x} = Ax$ com $A = \begin{pmatrix} -3 & 1 \\ 1 & -3 \end{pmatrix}$ e $x(0) = \begin{pmatrix} 2 \\ 0 \end{pmatrix}$. Determine $x(t)$ e classifique a estabilidade.

**Estratégia:** Diagonalizar $A$, resolver o sistema desacoplado, compor a solução.

**Resolução:**

1. **Autovalores:** $p_A(\lambda) = (-3-\lambda)^2 - 1 = \lambda^2 + 6\lambda + 8 = (\lambda+4)(\lambda+2) = 0$. $\lambda_1 = -4$, $\lambda_2 = -2$.

2. **Autovetores:**

$\lambda_1 = -4$: $(A + 4I) = \begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}$. $v_1 = \begin{pmatrix} 1 \\ -1 \end{pmatrix}$.

$\lambda_2 = -2$: $(A + 2I) = \begin{pmatrix} -1 & 1 \\ 1 & -1 \end{pmatrix}$. $v_2 = \begin{pmatrix} 1 \\ 1 \end{pmatrix}$.

3. **Solução geral:** $x(t) = c_1 e^{-4t}\begin{pmatrix} 1 \\ -1 \end{pmatrix} + c_2 e^{-2t}\begin{pmatrix} 1 \\ 1 \end{pmatrix}$.

4. **Condição inicial:** $x(0) = \begin{pmatrix} 2 \\ 0 \end{pmatrix} \Rightarrow c_1 + c_2 = 2$ e $-c_1 + c_2 = 0$, logo $c_1 = c_2 = 1$.

$$x(t) = e^{-4t}\begin{pmatrix} 1 \\ -1 \end{pmatrix} + e^{-2t}\begin{pmatrix} 1 \\ 1 \end{pmatrix}$$

5. **Estabilidade:** Ambos autovalores são negativos ($-4 < 0$, $-2 < 0$), logo $x(t) \to 0$ quando $t \to \infty$. O sistema é **assintoticamente estável**.

**Verificação:** $x(0) = \begin{pmatrix} 1 \\ -1 \end{pmatrix} + \begin{pmatrix} 1 \\ 1 \end{pmatrix} = \begin{pmatrix} 2 \\ 0 \end{pmatrix}$. $\checkmark$

**Fonte.** [Hefferon, Linear Algebra, cap. 5 §II](https://hefferon.net/linearalgebra/) — licença CC-BY-SA.
</Exemplo>
