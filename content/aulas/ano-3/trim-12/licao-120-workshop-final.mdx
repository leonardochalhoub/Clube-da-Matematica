### Estrutura do programa concluído

<Definicao titulo="Os quatro pilares do programa">

O programa de 120 lições divide-se em quatro pilares:

- **Cálculo Diferencial e Integral** (Trimestres 5–8): limites, derivadas, integrais, séries, EDOs. Base: regras de diferenciação, TFC, séries de Taylor, equações lineares de 2ª ordem.
- **Álgebra Linear** (Trimestres 9–10): matrizes, sistemas, determinantes, espaços vetoriais, autovalores, SVD. Base: eliminação gaussiana, teorema espectral, decomposições.
- **Probabilidade e Estatística** (Trimestres 10–11): distribuições, TCL, IC, testes de hipótese, regressão. Base: normal, qui-quadrado, valor esperado, variância.
- **Modelagem Aplicada** (Trimestres 11–12): EDO aplicada, finanças quantitativas (Black-Scholes), ML básico. Base: EDO separável e linear, lema de Itô, gradiente descendente.

</Definicao>

> "A mathematical theory is not to be considered complete until you have made it só clear that you can explain it to the first man whom you meet on the street." — David Hilbert, citado em [Active Calculus §1.1](https://activecalculus.org/single/sec-1-1-vel.html)

<Teorema titulo="Teorema Fundamental do Cálculo (síntese)">

Seja $f$ contínua em $[a, b]$ e $F$ qualquer antiderivada de $f$. Então:

<Equation explicacao="Parte 1: a função definida pela integral acumulada é derivável e sua derivada é o integrando." latex="\frac{d}{dx}\int_a^x f(t)\,dt = f(x), \quad x \in [a, b]" />

<Equation explicacao="Parte 2: a integral definida calcula-se por qualquer antiderivada avaliada nos extremos." latex="\int_a^b f(x)\,dx = F(b) - F(a)" />

O TFC é a ponte entre as duas metades do cálculo — o diferencial e o integral. Aparece diretamente em 6 dos 40 problemas do workshop.

</Teorema>

### O que é síntese?

Síntese é o oposto de lista de ferramentas isoladas. Exemplo concreto:

> *"Uma empresa vende $q$ unidades por dia a preço $p(q) = 120 - 2q$ reais. O custo de produção é $C(q) = 200 + 40q + q^2$. Encontre a quantidade que maximiza o lucro."*

Para resolver:
1. **Lição 03** (função afim) — identificar receita $R(q) = q \cdot p(q)$.
2. **Lição 04** (quadrática) — $L(q) = R(q) - C(q)$ é quadrática.
3. **Lição 51-52** (derivada) — resolver $L'(q) = 0$.
4. **Lição 53** (segunda derivada) — confirmar que é máximo.

Você não recebe esses passos prontos. Você os **reconstrói** a partir do conhecimento.

### Por que isso importa?

- **Vestibular**: questão ITA/IME pede 3-4 técnicas de áreas diferentes.
- **Engenharia**: problemas reais nunca vêm rotulados.
- **Dados/IA**: redes neurais misturam álgebra linear + cálculo + estatística.

</Porta>

6. Compare com a solução. Se errou, refaça.
7. Interprete: o que o resultado significa no contexto?

## Exemplos resolvidos

<Exemplo titulo="Otimização com derivada — maximização de lucro" numero="1">

**Problema:** Uma empresa tem receita $R(q) = 120q - 2q^2$ e custo $C(q) = 200 + 40q + q^2$ (em reais, $q$ unidades/dia). Encontre a quantidade $q^*$ que maximiza o lucro $L(q) = R(q) - C(q)$.

**Estratégia:** Montar $L(q)$, calcular $L'(q)$, igualar a zero, verificar com segunda derivada que é máximo.

**Resolução:**

1. $L(q) = (120q - 2q^2) - (200 + 40q + q^2) = -3q^2 + 80q - 200$.
2. $L'(q) = -6q + 80$. Igualando a zero: $q^* = 80/6 = 40/3 \approx 13,3$ unidades/dia.
3. $L''(q) = -6 < 0$, confirmando máximo.
4. $L(40/3) = -3(40/3)^2 + 80(40/3) - 200 = -\frac{4800}{9} + \frac{3200}{3} - 200 = \frac{1400}{9} \approx 155,6$ reais/dia.

**Verificação:** $L'(13) = -78 + 80 = 2 > 0$ e $L'(14) = -84 + 80 = -4 < 0$, confirmando que o máximo está entre $q = 13$ e $q = 14$.

**Fonte.** [Active Calculus §3.3, Exercício 3.3.3](https://activecalculus.org/single/sec-3-5-optimization.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Integral definida por substituição — área sob curva" numero="2">

**Problema:** Calcule $\displaystyle\int_0^{\pi/2} \sin^2 x \cos^3 x \; dx$.

**Estratégia:** Separar $\cos^3 x = \cos^2 x \cdot \cos x = (1 - \sin^2 x)\cos x$ e usar substituição $u = \sin x$.

**Resolução:**

1. Escreva $\cos^3 x = (1 - \sin^2 x)\cos x$.
2. Seja $u = \sin x$, logo $du = \cos x\,dx$. Limites: $x=0 \Rightarrow u=0$; $x=\pi/2 \Rightarrow u=1$.
3. $\displaystyle\int_0^1 u^2(1 - u^2)\,du = \int_0^1 (u^2 - u^4)\,du = \left[\frac{u^3}{3} - \frac{u^5}{5}\right]_0^1 = \frac{1}{3} - \frac{1}{5} = \frac{2}{15}$.

**Verificação:** $0 < 2/15 \approx 0,133$. O integrando $\sin^2 x \cos^3 x \geq 0$ em $[0, \pi/2]$ com valor máximo em torno de $x \approx 0,63$ rad onde $\sin x \approx 0,59$, $\cos x \approx 0,81$; valor máximo $\approx 0,21$. Área $\approx 0,21 \times 1,57/2 \approx 0,16$. Ordem de grandeza consistente com $2/15$.

**Fonte.** [Active Calculus §5.3, Exercício 5.3.5](https://activecalculus.org/single/sec-5-3-substitution.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Diagonalização de matriz 2x2 — autovalores e autovetores" numero="3">

**Problema:** Diagonalize <Eq>{`A = \\begin{pmatrix} 3 & 1 \\\\ 0 & 2 \\end{pmatrix}`}</Eq>.

**Estratégia:** Calcular $\det(A - \lambda I) = 0$, encontrar autovalores, depois autovetores. Montar $P$ com colunas de autovetores e verificar $P^{-1}AP = D$.

**Resolução:**

1. $\det(A - \lambda I) = (3-\lambda)(2-\lambda) - 0 = (3-\lambda)(2-\lambda)$. Autovalores: $\lambda_1 = 3$, $\lambda_2 = 2$.
2. Para $\lambda_1 = 3$: <Eq>{`(A - 3I)\\mathbf{v} = 0 \\Rightarrow \\begin{pmatrix}0 & 1\\\\ 0 & -1\\end{pmatrix}\\mathbf{v} = 0 \\Rightarrow v_2 = 0`}</Eq>. Autovetor: $\mathbf{v}_1 = (1, 0)^T$.
3. Para $\lambda_2 = 2$: <Eq>{`(A - 2I)\\mathbf{v} = 0 \\Rightarrow \\begin{pmatrix}1 & 1\\\\ 0 & 0\\end{pmatrix}\\mathbf{v} = 0 \\Rightarrow v_1 = -v_2`}</Eq>. Autovetor: $\mathbf{v}_2 = (1, -1)^T$.
4. <Eq>{`P = \\begin{pmatrix}1 & 1 \\\\ 0 & -1\\end{pmatrix}`}</Eq>, <Eq>{`D = \\begin{pmatrix}3 & 0 \\\\ 0 & 2\\end{pmatrix}`}</Eq>.

**Verificação:** <Eq>{`AP = P \\begin{pmatrix}3&0\\\\0&2\\end{pmatrix}`}</Eq>. Coluna 1: $A(1,0)^T = (3,0)^T = 3(1,0)^T$. Coluna 2: $A(1,-1)^T = (2,-2)^T = 2(1,-1)^T$. Correto.

**Fonte.** [Linear Algebra Done Right, 4ª ed., §5C Exercício 5](https://linear.axler.net/) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="EDO de 2ª ordem — oscilador harmônico simples" numero="4">

**Problema:** Resolva $y'' + 4y = 0$ com $y(0) = 1$, $y'(0) = 0$.

**Estratégia:** Equação linear homogênea de 2ª ordem com coeficientes constantes. Equação característica $r^2 + 4 = 0$ tem raízes complexas conjugadas.

**Resolução:**

1. Equação característica: $r^2 + 4 = 0 \Rightarrow r = \pm 2i$.
2. Solução geral: $y(x) = C_1 \cos(2x) + C_2 \sin(2x)$.
3. Condição inicial $y(0) = 1$: $C_1 \cdot 1 + C_2 \cdot 0 = 1 \Rightarrow C_1 = 1$.
4. $y'(x) = -2C_1 \sin(2x) + 2C_2 \cos(2x)$. Condição $y'(0) = 0$: $2C_2 = 0 \Rightarrow C_2 = 0$.
5. Solução: $y(x) = \cos(2x)$.

**Verificação:** $y'' = -4\cos(2x)$. Logo $y'' + 4y = -4\cos(2x) + 4\cos(2x) = 0$. Condições: $y(0) = 1$, $y'(0) = -2\sin(0) = 0$. Correto.

**Fonte.** [Notes on Diffy Qs §2.2, Exercício 2.2.1](https://www.jirka.org/diffyqs/) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="Regressão linear simples — estimativa de coeficientes" numero="5">

**Problema:** Com os pontos $(1,2)$, $(2,3)$, $(3,5)$, $(4,4)$, $(5,6)$, encontre a reta de regressão $\hat y = \hat\beta_0 + \hat\beta_1 x$ pelo método de mínimos quadrados.

**Estratégia:** Usar as fórmulas $\hat\beta_1 = \frac{\sum(x_i - \bar x)(y_i - \bar y)}{\sum(x_i - \bar x)^2}$ e $\hat\beta_0 = \bar y - \hat\beta_1 \bar x$.

**Resolução:**

1. $n = 5$. $\bar x = (1+2+3+4+5)/5 = 3$. $\bar y = (2+3+5+4+6)/5 = 4$.
2. $\sum(x_i - \bar x)^2 = (-2)^2 + (-1)^2 + 0^2 + 1^2 + 2^2 = 4+1+0+1+4 = 10$.
3. $\sum(x_i - \bar x)(y_i - \bar y) = (-2)(-2)+(-1)(-1)+(0)(1)+(1)(0)+(2)(2) = 4+1+0+0+4 = 9$.
4. $\hat\beta_1 = 9/10 = 0,9$. $\hat\beta_0 = 4 - 0,9 \times 3 = 4 - 2,7 = 1,3$.
5. Reta: $\hat y = 1,3 + 0,9x$.

**Verificação:** Para $x = 3$: $\hat y = 1,3 + 2,7 = 4,0 = \bar y$. A reta de regressão sempre passa pelo ponto $(\bar x, \bar y)$. Correto.
