### Lei de Kirchhoff das tensões

Em um circuito $RLC$ série com fonte $V(t)$, a soma das quedas de tensão iguala a fonte:

$$V_L + V_R + V_C = V(t)$$

Usando $V_L = L\,\dot I$, $V_R = RI$, $V_C = Q/C$ e $I = \dot Q$:

<Equation explicacao="Equação diferencial do circuito RLC série — EDO linear de 2ª ordem com coeficientes constantes." latex="L\,\ddot{Q} + R\,\dot{Q} + \frac{Q}{C} = V(t)" />

<Definicao titulo="Parâmetros canônicos do circuito RLC">

Dividindo por $L$:

$$\ddot{Q} + 2\zeta\omega_0\,\dot{Q} + \omega_0^2\,Q = \frac{V(t)}{L}$$

- **Frequência natural não amortecida:** $\omega_0 = \dfrac{1}{\sqrt{LC}}$ [rad/s]
- **Coeficiente de amortecimento:** $\zeta = \dfrac{R}{2}\sqrt{\dfrac{C}{L}} = \dfrac{R}{2L}\cdot\dfrac{1}{\omega_0}$
- **Fator de qualidade:** $Q_f = \dfrac{1}{2\zeta} = \dfrac{1}{R}\sqrt{\dfrac{L}{C}}$
- **Frequência amortecida:** $\omega_d = \omega_0\sqrt{1-\zeta^2}$ (válido para $\zeta < 1$)

</Definicao>

> "The equation $LQ'' + RQ' + Q/C = V(t)$ is the standard form of the RLC circuit equation and has exactly the same mathematical form as the damped mass-spring system $mx'' + cx' + kx = F(t)$, with $L$ playing the role of mass, $R$ the damping constant, and $1/C$ the spring constant." — [Lebl, Notes on Diffy Qs §2.6](https://www.jirka.org/diffyqs/html/sec_rlc.html)

### Classificação pela equação característica

Equação homogênea ($V = 0$): $L\lambda^2 + R\lambda + 1/C = 0$.

$\Delta = R^2 - 4L/C$

<Definicao titulo="Três regimes de resposta livre">

- **Superamortecido** ($\zeta > 1$, $\Delta > 0$): dois $\lambda$ reais negativos. Retorno exponencial lento ao equilíbrio.
  $$Q_h(t) = C_1 e^{\lambda_1 t} + C_2 e^{\lambda_2 t}$$
- **Criticamente amortecido** ($\zeta = 1$, $\Delta = 0$): $\lambda$ duplo $\lambda = -R/(2L)$. Retorno mais rápido sem oscilação.
  $$Q_h(t) = (C_1 + C_2 t)\,e^{\lambda t}$$
- **Subamortecido** ($\zeta < 1$, $\Delta < 0$): $\lambda = -\zeta\omega_0 \pm i\omega_d$. Oscilação amortecida.
  $$Q_h(t) = e^{-\zeta\omega_0 t}\bigl(C_1\cos\omega_d t + C_2\sin\omega_d t\bigr)$$

</Definicao>

### Resposta em regime permanente (forçada)

Para $V(t) = V_0\cos(\omega t)$, solução particular:

$$Q_p(t) = \frac{V_0/L}{\sqrt{(\omega_0^2-\omega^2)^2 + (2\zeta\omega_0\omega)^2}}\cos(\omega t - \phi)$$

com $\tan\phi = \dfrac{2\zeta\omega_0\omega}{\omega_0^2-\omega^2}$.

<Teorema titulo="Ressonância no circuito RLC">

A amplitude de corrente $|I| = \omega|Q_p|$ é máxima quando $\omega = \omega_0$ (ressonância em série). Na ressonância, a impedância é puramente resistiva: $Z = R$. A corrente de pico é $I_{\max} = V_0/R$.

O fator de qualidade $Q_f = \omega_0 L/R$ mede o quanto o circuito amplifica na ressonância: largura de banda $\Delta\omega = \omega_0/Q_f$.

</Teorema>

<Insight>
Um rádio AM sintoniza uma estação ajustando $C$ (capacitor variável) até que $\omega_0 = 2\pi f_{\text{estação}}$. A largura de banda $\Delta\omega$ determina a seletividade: $Q_f$ alto — canal estreito e seletivo; $Q_f$ baixo — passa várias estações ao mesmo tempo.
</Insight>

</Porta>

<Porta nivel="5" titulo="Pra criança de 5 anos">

Imagina um **balanço de playground**. Tem três partes que mandam nele:

- A **corrente** que você dá no balanço (para ele ir) — isso é o **indutor**, que guarda energia de movimento.
- A **mola invisível** que quer trazer de volta ao centro — isso é o **capacitor**, que guarda energia elétrica.
- O **atrito do ar** que faz parar — isso é o **resistor**.

Quando você empurra no ritmo certo do balanço, ele vai cada vez mais alto. Isso chama **ressonância**. O rádio do seu carro usa exatamente isso para pegar só uma estação de cada vez.

</Porta>

<Porta nivel="10" titulo="Pra criança de 10 anos">

Um **circuito RLC** tem três componentes ligados em série:

- **R (resistor)**: transforma eletricidade em calor. Freia.
- **L (indutor)**: bobina de fio. Resiste à mudança de corrente, como uma massa pesada.
- **C (capacitor)**: guarda carga elétrica, como uma mola.

A **lei de Kirchhoff** diz que a soma das tensões é zero. Isso vira uma equação com derivadas:

$$L\,\ddot{Q} + R\,\dot{Q} + \frac{Q}{C} = V(t)$$

É *matematicamente idêntica* ao oscilador massa-mola que você já viu! Toda solução que funciona para molas funciona para circuitos elétricos.

Se não tiver resistor ($R = 0$), a corrente oscila para sempre — como um pêndulo ideal. Com resistor, vai amortecendo.

</Porta>

<Porta nivel="15" titulo="Para o estudante de ensino médio">

A equação do RLC é um caso especial de **EDO linear de 2ª ordem com coeficientes constantes**:

$$L\,\ddot{Q} + R\,\dot{Q} + \frac{Q}{C} = V(t)$$

**Passo 1 — Solução homogênea.** Faça $V = 0$ e teste $Q = e^{\lambda t}$:

$$L\lambda^2 + R\lambda + \frac{1}{C} = 0$$

$\Delta = R^2 - 4L/C$. Há três casos (superamortecido, crítico, subamortecido).

**Passo 2 — Solução particular.** Para $V(t) = V_0\cos(\omega t)$, chute $Q_p = A\cos\omega t + B\sin\omega t$ e determine $A, B$ substituindo.

**Passo 3 — Solução geral** = homogênea + particular. Aplique condições iniciais $Q(0) = Q_0$, $I(0) = \dot Q(0) = I_0$ para achar $C_1$ e $C_2$.

**Grandezas importantes:**
- $\omega_0 = 1/\sqrt{LC}$: frequência natural.
- $\zeta = R/(2\sqrt{L/C})$: fator de amortecimento.
- Ressonância: $\omega = \omega_0$ maximiza corrente.

</Porta>

<Porta nivel="25" titulo="Para o estudante de engenharia">

O circuito RLC série é descrito por:

$$L\,\ddot{Q} + R\,\dot{Q} + \frac{Q}{C} = V(t), \quad Q(0) = Q_0,\ \dot{Q}(0) = I_0$$

**Análise no domínio da frequência.** Transformada de Laplace ($V$ geral):

$$\left(Ls^2 + Rs + \frac{1}{C}\right)\hat{Q}(s) = \hat{V}(s) + LsQ_0 + LI_0 + RQ_0$$

Função de transferência (corrente/tensão, condições iniciais nulas):

$$H_I(s) = \frac{s\hat{Q}(s)}{\hat{V}(s)} = \frac{s}{Ls^2 + Rs + 1/C}$$

**Impedância:** $Z(j\omega) = R + j\omega L + \frac{1}{j\omega C}$. Ressonância em série: $\Im(Z) = 0 \Rightarrow \omega_r = \omega_0$.

**Fator de qualidade:** $Q_f = \omega_0 L/R = \frac{1}{\omega_0 RC}$. Mede seletividade — largura de banda $BW = \omega_0/Q_f$ [rad/s].

**Energia:** $E(t) = \frac{1}{2}LI^2 + \frac{Q^2}{2C}$. Potência dissipada: $P_R = RI^2$. Potência reativa: $Q_{reativa} = I^2(\omega L - 1/(\omega C))$.

**Resposta em regime permanente:** $\omega = \omega_0 \Rightarrow I_{\max} = V_0/R$ (limitado apenas pelo resistor). Para $Q_f \gg 1$, tensão no capacitor pode superar a fonte por fator $Q_f$ — chamada *ganho de tensão na ressonância*.

</Porta>

<Porta nivel="40" titulo="Para o profissional sênior">

O circuito RLC série foi analisado formalmente por Lord Kelvin e Arthur Kennelly no fim do século XIX, consolidando a teoria dos circuitos AC. A analogia eletromecânica sistemática foi explorada por James Clerk Maxwell em *Treatise on Electricity and Magnetism* (1873) e depois formalizada por Gabriel Kron na teoria das máquinas elétricas (1939).

**Perspectiva dos sistemas:** o RLC série é um oscilador harmônico de segunda ordem com dois graus de liberdade (estado $[Q, I]^T$). Em espaço de estados:

$$\frac{d}{dt}\begin{pmatrix}Q\\I\end{pmatrix} = \begin{pmatrix}0 & 1\\-\omega_0^2 & -2\zeta\omega_0\end{pmatrix}\begin{pmatrix}Q\\I\end{pmatrix} + \begin{pmatrix}0\\1/L\end{pmatrix}V(t)$$

Os autovalores da matriz do sistema são os polos $s = -\zeta\omega_0 \pm j\omega_d$. No plano-$s$ complexo, a distância à origem é $\omega_0$, o ângulo com o eixo negativo real é $\arccos\zeta$.

**Aplicações modernas:** filtros LC em RF (rádio AM 535–1605 kHz, FM 88–108 MHz), circuitos tanque em osciladores VCO, supressão de EMI em conversores DC-DC, análise de tolerâncias de componentes (Monte Carlo em SPICE), ressonância em redes de transmissão elétrica (problema do subamortecimento de linhas de 735 kV no Brasil após grandes distúrbios de carga). O fator de qualidade $Q_f$ reaparece em óptica (cavidades Fabry-Pérot), mecânica quântica (estados ressonantes) e cosmologia (oscilações de bárions antes do desacoplamento).

</Porta>

<Porta nivel="pratica" titulo="Aplicações com dados brasileiros">

**Rádio AM Brasil.** A estação CBN São Paulo transmite em 1350 kHz. Com $L = 0{,}5$ mH, qual $C$ sintoniza o receptor?

$\omega_0 = 2\pi \times 1350 \times 10^3 \approx 8{,}48 \times 10^6$ rad/s.

$C = 1/(L\omega_0^2) = 1/(0{,}5 \times 10^{-3} \times (8{,}48 \times 10^6)^2) \approx 27{,}7$ pF.

Capacitor ajustável de 10–50 pF cobre toda a faixa AM (535–1605 kHz).

**INMETRO e normas de EMI.** A ABNT NBR 15601 exige que dispositivos domésticos não emitam acima de certos limites em 150 kHz a 30 MHz. Filtros RLC de modo comum nas fontes de notebooks atenuam interferências eletromagnéticas — o fator de qualidade do filtro deve ser suficientemente baixo ($\zeta \approx 0{,}7$) para evitar picos de ressonância que violem os limites.

**Rede elétrica.** Compensadores de reativos (bancos de capacitores + indutores em subestações da CTEEP e Eletrobras) formam circuitos LC ajustados perto de 60 Hz para correção de fator de potência, mas com $\zeta$ alto o suficiente para evitar ressonância descontrolada.

</Porta>

## Exemplos resolvidos

<Exemplo numero="97.1" titulo="Classificação do regime — dados de componentes">

**Problema.** Circuito RLC série: $L = 1$ H, $R = 6$ $\Omega$, $C = 1/8$ F. Classifique o regime e escreva a solução homogênea geral.

**Estratégia.** Calcule $\Delta = R^2 - 4L/C$; identifique o regime; escreva $Q_h$.

**Resolução.**

$\Delta = 36 - 4(1)(8) = 36 - 32 = 4 > 0$ — **superamortecido**.

Equação característica: $\lambda^2 + 6\lambda + 8 = 0 \Rightarrow \lambda = (-6 \pm 2)/2$, logo $\lambda_1 = -2$, $\lambda_2 = -4$.

$$Q_h(t) = C_1 e^{-2t} + C_2 e^{-4t}$$

**Verificação.** $Q_h' = -2C_1 e^{-2t} - 4C_2 e^{-4t}$, $Q_h'' = 4C_1 e^{-2t} + 16C_2 e^{-4t}$. Substituindo em $Q'' + 6Q' + 8Q$: coletando $e^{-2t}$: $4C_1 - 12C_1 + 8C_1 = 0$ $\checkmark$. Coletando $e^{-4t}$: $16C_2 - 24C_2 + 8C_2 = 0$ $\checkmark$.

**Fonte.** [Lebl, Notes on Diffy Qs §2.6, Example 2.6.1](https://www.jirka.org/diffyqs/html/sec_rlc.html) — CC-BY-SA

</Exemplo>

<Exemplo numero="97.2" titulo="Regime subamortecido com condições iniciais">

**Problema.** $L = 1$ H, $R = 2$ $\Omega$, $C = 1/2$ F, $V = 0$. Condições: $Q(0) = 1$ C, $I(0) = 0$ A. Ache $Q(t)$.

**Estratégia.** Calcule $\Delta$, identifique regime subamortecido, aplique CI para determinar $C_1, C_2$.

**Resolução.**

$\Delta = 4 - 4(1)(2) = 4 - 8 = -4 < 0$ — **subamortecido**.

$\lambda = -1 \pm i$, logo $\alpha = 1$, $\omega_d = 1$.

$$Q_h(t) = e^{-t}(C_1 \cos t + C_2 \sin t)$$

CI: $Q(0) = C_1 = 1$.

$\dot Q = e^{-t}[(-C_1 + C_2\omega_d)\cos t + (-C_2 - C_1\omega_d)\sin t]$... com $\omega_d = 1$:

$\dot Q(0) = -C_1 + C_2 = 0 \Rightarrow C_2 = 1$.

$$Q(t) = e^{-t}(\cos t + \sin t) = \sqrt{2}\,e^{-t}\cos\!\left(t - \frac{\pi}{4}\right)$$

**Verificação.** $Q(0) = 1$ $\checkmark$; $\dot Q(0) = -1 + 1 = 0$ $\checkmark$. Amplitude decai como $\sqrt{2}e^{-t}$ $\checkmark$.

**Fonte.** [Lebl, Notes on Diffy Qs §2.6, Exercise 2.6.2](https://www.jirka.org/diffyqs/html/sec_rlc.html) — CC-BY-SA

</Exemplo>

<Exemplo numero="97.3" titulo="Resposta forçada — regime permanente">

**Problema.** $L = 0{,}1$ H, $R = 10$ $\Omega$, $C = 10^{-3}$ F, $V(t) = 50\cos(100t)$ V. Ache a corrente em regime permanente $I_p(t) = \dot Q_p$.

**Estratégia.** Calcule $Z(j\omega)$ e use $\hat I = \hat V/Z$.

**Resolução.**

$\omega = 100$ rad/s. $\omega_0 = 1/\sqrt{0{,}1 \times 10^{-3}} = 100$ rad/s — **ressonância!**

$Z(j100) = 10 + j(100 \times 0{,}1 - 1/(100 \times 10^{-3})) = 10 + j(10 - 10) = 10$ $\Omega$.

$I_p(t) = \frac{50}{10}\cos(100t) = 5\cos(100t)$ A.

Na ressonância, a impedância é puramente resistiva e a corrente atinge o valor máximo.

**Verificação.** $|Z|_{\omega=100} = 10$ $\Omega$ $\checkmark$; $I_{\max} = V_0/R = 50/10 = 5$ A $\checkmark$.

**Fonte.** [OpenStax University Physics Vol. 2, §14.5 Example 14.5](https://openstax.org/books/university-physics-volume-2/pages/14-5-resonance-in-an-ac-circuit) — CC-BY

</Exemplo>

<Exemplo numero="97.4" titulo="Fator de qualidade e largura de banda">

**Problema.** Receptor de rádio AM: $L = 0{,}5$ mH, $C = 25$ pF, $R = 5$ $\Omega$. Calcule $f_0$, $Q_f$ e $\Delta f$ (largura de banda).

**Estratégia.** Aplique as fórmulas de $f_0$, $Q_f$ e $BW$ diretamente.

**Resolução.**

$\omega_0 = 1/\sqrt{0{,}5 \times 10^{-3} \times 25 \times 10^{-12}} = 1/\sqrt{1{,}25 \times 10^{-14}} \approx 8{,}94 \times 10^6$ rad/s.

$f_0 = \omega_0/(2\pi) \approx 1{,}42$ MHz (faixa AM).

$Q_f = \omega_0 L/R = (8{,}94 \times 10^6 \times 0{,}5 \times 10^{-3})/5 = 4470/5 = 894$.

$\Delta f = f_0/Q_f = 1{,}42 \times 10^6/894 \approx 1{,}59$ kHz.

Canal AM tem 10 kHz de largura — $Q_f = 894$ é seletivo demais para AM, mas adequado para FM estéreo.

**Verificação.** $\zeta = 1/(2Q_f) = 1/1788 \approx 5{,}6 \times 10^{-4} \ll 1$ — fortemente subamortecido $\checkmark$.

**Fonte.** [OpenStax University Physics Vol. 2, §14.6](https://openstax.org/books/university-physics-volume-2/pages/14-6-rlc-series-circuits-with-ac) — CC-BY

</Exemplo>

<Exemplo numero="97.5" titulo="Circuito LC sem resistência — oscilação pura">

**Problema.** $L = 4$ H, $C = 1/16$ F, $R = 0$, $V = 0$. $Q(0) = 0$, $I(0) = 2$ A. Ache $Q(t)$ e a energia total.

**Estratégia.** Caso não amortecido: $\ddot Q + \omega_0^2 Q = 0$, solução geral seno/cosseno.

**Resolução.**

$\omega_0 = 1/\sqrt{4 \times 1/16} = 1/\sqrt{1/4} = 2$ rad/s.

$Q(t) = A\cos(2t) + B\sin(2t)$.

$Q(0) = A = 0 \Rightarrow Q(t) = B\sin(2t)$.

$\dot Q(0) = 2B = 2 \Rightarrow B = 1$.

$$Q(t) = \sin(2t), \quad I(t) = 2\cos(2t)$$

Energia: $E = \frac{1}{2}L I^2 + \frac{Q^2}{2C} = \frac{1}{2}(4)(4\cos^2 2t) + \frac{\sin^2 2t}{2(1/16)} = 8\cos^2 2t + 8\sin^2 2t = 8$ J (constante $\checkmark$).

**Fonte.** [Trench, Elementary Differential Equations §6.2, Exercise 6.2.3](https://digitalcommons.trinity.edu/mono/9/) — aberto

</Exemplo>
