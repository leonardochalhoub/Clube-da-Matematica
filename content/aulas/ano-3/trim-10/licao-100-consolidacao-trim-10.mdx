<Porta nivel="formal" titulo="Mapa de técnicas e critérios de decisão">

<Definicao titulo="Fluxograma de classificação de EDOs">

Dada uma EDO ordinária, percorra:

1. **Ordem?** Quantas derivadas há? Só <Eq>{`y'`}</Eq>: 1ª ordem. Tem <Eq>{`y''`}</Eq>: 2ª ordem.
2. **Linear?** Todos os termos em <Eq>{`y, y', y''`}</Eq> são lineares (sem produtos, sem funções de <Eq>{`y`}</Eq>)?
3. **1ª ordem linear**: <Eq>{`y' + p(x)y = q(x)`}</Eq> → fator integrante <Eq>{`\\mu = e^{\\int p\\,dx}`}</Eq>.
4. **1ª ordem separável**: <Eq>{`y' = g(x)h(y)`}</Eq> → separa e integra.
5. **2ª ordem coef. constantes**: <Eq>{`ay'' + by' + cy = q(x)`}</Eq> → equação característica + <Eq>{`y_p`}</Eq> por coeficientes a determinar ou variação de parâmetros.
6. **Não analítica**: qualquer forma que não se enquadra acima → numérico (Euler/RK4).

</Definicao>

> "The existence and uniqueness theorem says: there is exactly one solution curve through each point (x₀, y₀) where f and ∂f/∂y are continuous."
> — [Lebl, *Notes on Diffy Qs* §1.2](https://www.jirka.org/diffyqs/html/intro_section.html)

> "The idea behind the integrating factor is to write the left-hand side as an exact derivative."
> — [OpenStax *Calculus Vol. 2* §4.5](https://openstax.org/books/calculus-volume-2/pages/4-5-first-order-linear-equations)

**Tabela de técnicas do trimestre:**

| EDO | Forma canônica | Técnica | Solução geral |
|---|---|---|---|
| Separável | <Eq>{`y' = g(x)h(y)`}</Eq> | Separa e integra | Implícita |
| Linear 1ª | <Eq>{`y'+py=q`}</Eq> | <Eq>{`\\mu=e^{\\int p}`}</Eq> | <Eq>{`y = \\frac{1}{\\mu}\\int\\mu q\\,dx + C`}</Eq> |
| Malthus | <Eq>{`\\dot P = rP`}</Eq> | Separável | <Eq>{`P = P_0 e^{rt}`}</Eq> |
| Logística | <Eq>{`\\dot P = rP(1-P/K)`}</Eq> | Separável + frações parciais | <Eq>{`P = K/(1+Ae^{-rt})`}</Eq> |
| Resfriamento | <Eq>{`\\dot T = -k(T-T_a)`}</Eq> | Separável | <Eq>{`T = T_a + (T_0-T_a)e^{-kt}`}</Eq> |
| 2ª homogênea | <Eq>{`ay''+by'+cy=0`}</Eq> | Char. <Eq>{`a\\lambda^2+b\\lambda+c=0`}</Eq> | 3 casos |
| 2ª forçada | <Eq>{`ay''+by'+cy=q`}</Eq> | <Eq>{`y_h + y_p`}</Eq> | Coef. a det. |
| Euler numérico | Qualquer | <Eq>{`y_{n+1}=y_n+hf`}</Eq> | Sequência |

<Teorema titulo="Estrutura da solução linear de 2ª ordem">

Se <Eq>{`y_1, y_2`}</Eq> são soluções linearmente independentes de <Eq>{`ay'' + by' + cy = 0`}</Eq> e <Eq>{`y_p`}</Eq> é qualquer solução particular de <Eq>{`ay'' + by' + cy = q(x)`}</Eq>, então toda solução da equação não-homogênea é

<Equation latex="y = C_1 y_1 + C_2 y_2 + y_p, \quad C_1, C_2 \in \mathbb{R}." />

**Prova (esboço).** Seja <Eq>{`z`}</Eq> outra solução; então <Eq>{`z - y_p`}</Eq> satisfaz a homogênea, logo pertence ao espaço gerado por <Eq>{`y_1, y_2`}</Eq>. <Eq>{`\\square`}</Eq>

</Teorema>

<Porta nivel="5" titulo="Equações que mudam no tempo">

Aprendemos a lidar com **coisas que mudam o tempo todo**: temperatura que vai esfriando, populações que crescem, pontes que balançam.

Para cada tipo de mudança existe um **truque diferente**. Às vezes a matemática separa as variáveis numa conta simples. Às vezes precisa de um "fator mágico" que facilita tudo. E quando nenhum truque funciona, o computador faz **passo a passinho** até chegar na resposta.

Nesta aula juntamos todos os truques e escolhemos o certo para cada problema.

</Porta>

<Porta nivel="10" titulo="Oito técnicas, um mapa">

Ao longo do trimestre 10, você aprendeu **oito maneiras** de lidar com equações de mudança:

1. **Separável** — x e y se separam: integra cada lado.
2. **Linear de 1ª ordem** — fator integrante transforma num lado só.
3. **Malthus** — crescimento proporcional: exponencial.
4. **Logística** — crescimento com limite de capacidade.
5. **2ª ordem homogênea** — equação característica dá exponenciais ou senos.
6. **Vibrações** — massa-mola com amortecimento e forçamento.
7. **RLC** — idêntico ao massa-mola, mas com elétrons.
8. **Euler/RK4** — quando não há fórmula fechada, o computador resolve passo a passo.

**Como escolher?** Olha quantas derivadas tem: só <Eq>{`y'`}</Eq> → primeira ordem. Tem <Eq>{`y''`}</Eq> → segunda. Se reconhece um dos modelos canônicos (logístico, resfriamento, massa-mola), usa aquele diretamente.

</Porta>

<Porta nivel="15" titulo="Fluxograma de decisão e erros comuns">

### Decisão rápida

```
EDO chega:
├─ Só y': 1ª ordem
│  ├─ Separa x e y? → separável, integra
│  ├─ Forma y' + p(x)y = q(x)? → fator integrante
│  └─ Nenhum? → substituição (Bernoulli, exata) ou numérico
└─ Tem y'': 2ª ordem
   ├─ Coef. constantes?
   │  ├─ Homogênea → equação característica
   │  └─ Forçada → y_h + y_p (coef. a det.)
   └─ Coef. variáveis → Cauchy-Euler, série ou numérico
```

### Erros clássicos do trimestre

- **Esquece soluções constantes em separáveis**: se <Eq>{`h(y_0) = 0`}</Eq>, então <Eq>{`y \\equiv y_0`}</Eq> é solução singular. Divide por <Eq>{`h(y)`}</Eq> só funciona fora das raízes.
- **Usa fator integrante em EDO não-linear**: <Eq>{`y' = y^2`}</Eq> não é linear, não tem fator integrante.
- **Confunde <Eq>{`\\omega_0`}</Eq> e <Eq>{`\\omega_d`}</Eq>**: frequência natural vs. amortecida. <Eq>{`\\omega_d = \\omega_0\\sqrt{1-\\zeta^2}`}</Eq>.
- **Passo de Euler grande em problema stiff**: sistema com constante de tempo curta (RLC com R grande) instabiliza o Euler explícito.
- **Ressonância**: quando força tem frequência <Eq>{`\\omega_0`}</Eq> e <Eq>{`\\zeta = 0`}</Eq>, <Eq>{`y_p`}</Eq> deve incluir fator <Eq>{`t`}</Eq>.

### Verificação rápida

Sempre substitua a solução na EDO original. Se o resultado não bate, a solução está errada.

</Porta>

<Porta nivel="25" titulo="Mapa de engenharia: domínios e EDOs canônicas">

EDOs são a **linguagem da engenharia**. Cada domínio tem seus modelos estruturais.

### Mecânica

- Dinâmica translacional: <Eq>{`m\\ddot x = F`}</Eq>.
- Vibração linear: <Eq>{`m\\ddot x + c\\dot x + kx = F(t)`}</Eq>. Fator de qualidade <Eq>{`Q = 1/(2\\zeta)`}</Eq>.
- Estabilidade: linearização em torno do equilíbrio, autovalores de <Eq>{`Df(x^*)`}</Eq>.

### Eletricidade

- RC, RL, LC, RLC: análogos exatos do massa-mola.
- Linha de transmissão: equação do telegrafista (EDP → EDO por separação).
- Máquinas elétricas: equações de Park (transformação dq0).

### Química e processos

- Cinética de 1ª ordem: <Eq>{`\\dot c = -kc`}</Eq>.
- CSTR com reação exotérmica: balanço de massa + energia, sistema de EDOs acopladas.
- Difusão-reação (1D): <Eq>{`D c'' = \\lambda c`}</Eq> (EDO de 2ª ordem no espaço).

### Controle

- PID controla planta de 2ª ordem. Polos de malha fechada determinam resposta.
- Realimentação de estado: <Eq>{`\\dot{\\mathbf x} = A\\mathbf x + B\\mathbf u`}</Eq>, <Eq>{`\\mathbf u = -K\\mathbf x`}</Eq>.
- Critério de Routh-Hurwitz: estabilidade sem resolver a equação.

### Workflow profissional

1. **Modele** da física (balanços).
2. **Adimensionalize** — identifique Bi, Re, <Eq>{`\\zeta`}</Eq>, <Eq>{`\\omega_0 T`}</Eq>.
3. **Linearize** se <Eq>{`\\Delta`}</Eq> pequeno; analítico fica acessível.
4. **Resolva** analiticamente ou numericamente.
5. **Valide** com experimento ou simulação de alta fidelidade.
6. **Otimize** parâmetros (controle, dimensionamento).

</Porta>

<Porta nivel="40" titulo="Sistemas dinâmicos, adjuntos e fronteiras modernas">

### Geometria e fluxos

Toda EDO autônoma <Eq>{`\\dot x = f(x)`}</Eq> define um **fluxo** <Eq>{`\\phi_t`}</Eq> em variedade. Conceitos centrais:

- **Equilíbrios**: <Eq>{`f(x^*) = 0`}</Eq>. Hartman-Grobman: <Eq>{`\\phi_t`}</Eq> é localmente topologicamente conjugado à linearização se <Eq>{`Df(x^*)`}</Eq> não tem autovalor puramente imaginário.
- **Variedades estável/instável**: invariantes; estruturam o retrato de fase.
- **Bifurcações**: sela-nó, Hopf, período-duplicação. Diagramas de bifurcação paramétrica.
- **Caos**: expoentes de Lyapunov positivos. Atrator de Lorenz.

### Adjunto de EDO

Para otimizar funcional <Eq>{`J = \\int_0^T g(x,u)\\,dt`}</Eq> sujeito a <Eq>{`\\dot x = f(x,u)`}</Eq>, o gradiente wrt <Eq>{`u`}</Eq> é calculado via **equação adjunta** retroativa. Custo: uma integração forward + uma backward, independente da dimensão de <Eq>{`u`}</Eq>. Fundamento do backpropagation moderno em Neural ODEs (Chen et al., NeurIPS 2018).

### Métodos modernos

- **SINDy** (Brunton et al., 2016): identifica EDO a partir de dados via regressão esparsa.
- **Neural ODE**: rede residual no limite contínuo; treina com adjunto.
- **PINN** (Raissi et al., 2019): minimiza resíduo da EDO + dados.
- **Geometric integration**: simpléticos (Störmer-Verlet) conservam energia; Lie-group preservam estrutura.

### Prêmio Nobel relacionado

James Peebles recebeu o [Prêmio Nobel de Física 2019](https://www.nobelprize.org/prizes/physics/2019/summary/) por contribuições teóricas à cosmologia física. As equações de Friedmann — que governam a expansão do universo — são EDOs autônomas de 1ª ordem para o fator de escala <Eq>{`a(t)`}</Eq>.

### SDEs

EDOs estocásticas: <Eq>{`dX = f(X)\\,dt + g(X)\\,dW`}</Eq> (Itô). Finanças (Black-Scholes), biologia molecular (ruído genético), controle robusto.

</Porta>

<Porta nivel="pratica" titulo="Aplicações integradoras com dados reais">

### Seleção de modelo: regra prática

Antes de qualquer conta, classifique o problema no fluxograma. Exemplos com contexto brasileiro:

**Epidemia simples (COVID-19, Brasil):** <Eq>{`\\dot I = (\\beta - \\gamma)I`}</Eq> no início. Separável → exponencial. Quando <Eq>{`S`}</Eq> cai: <Eq>{`\\dot I = (\\beta S/N - \\gamma)I`}</Eq>, sistema SIR, resolve numericamente.

**Reatores industriais (Petrobras, refinaria):** Temperatura de saída de um trocador: <Eq>{`mc_p \\dot T = UA(T_s - T)`}</Eq> — linear de 1ª ordem, fator integrante.

**Estrutura (edifício Paulista sob vento):** Modo fundamental de vibração: <Eq>{`m\\ddot x + c\\dot x + kx = F_0\\cos(\\omega t)`}</Eq>. Ressonância preocupa se <Eq>{`\\omega \\approx \\omega_0`}</Eq>.

**Filtro de áudio (amplificador, São Paulo):** Passa-baixas RLC, <Eq>{`f_c = \\omega_0/(2\\pi) = 1/(2\\pi\\sqrt{LC})`}</Eq>. Escolha <Eq>{`L`}</Eq> e <Eq>{`C`}</Eq> para <Eq>{`f_c = 1`}</Eq> kHz.

**Farmacocinética (ANVISA):** Droga desaparece: <Eq>{`\\dot C = -k_e C`}</Eq>. Meia-vida <Eq>{`t_{1/2} = \\ln 2/k_e`}</Eq>. Para paracetamol, <Eq>{`t_{1/2} \\approx 2`}</Eq> h.

### Cheat sheet do trimestre

```
Separável:  ∫ dy/h(y) = ∫ g(x) dx
Linear 1ª:  μ = exp(∫ p dx), y = (1/μ)∫ μq dx + C
Logística:  P = K / (1 + A e^{−rt})
Resfriamento: T = T_a + (T_0 − T_a) e^{−kt}
Char. 2ª:   a λ² + b λ + c = 0
Vibração:   ω_0 = √(k/m), ζ = c/(2√(mk))
RLC:        ω_0 = 1/√(LC), ζ = (R/2)√(C/L)
Euler:      y_{n+1} = y_n + h f(t_n, y_n)
```

## Exemplos resolvidos

<Exemplo titulo="Classificar e resolver uma EDO de 1ª ordem separável">

**Problema.** Resolva o PVI <Eq>{`y' = 2xy`}</Eq>, <Eq>{`y(0) = 3`}</Eq>.

**Estratégia.** Verificar se é separável: reescrever como <Eq>{`dy/y = 2x\\,dx`}</Eq> e integrar cada lado. Aplica Condição Inicial para determinar a constante.

**Resolução.**

<Equation latex="\frac{dy}{y} = 2x\,dx \;\Longrightarrow\; \ln|y| = x^2 + C_1 \;\Longrightarrow\; y = Ce^{x^2}." />

CI: <Eq>{`y(0) = C = 3`}</Eq>. Solução: <Eq>{`y = 3e^{x^2}`}</Eq>.

**Verificação.** <Eq>{`y' = 6xe^{x^2} = 2x\\cdot 3e^{x^2} = 2xy`}</Eq>. <Eq>{`y(0) = 3`}</Eq>. Correto.

**Fonte.** [Lebl, *Notes on Diffy Qs* §1.3](https://www.jirka.org/diffyqs/html/separable_section.html), Exercise 1.3.2.

</Exemplo>

<Exemplo titulo="Fator integrante: EDO linear de 1ª ordem com q(x) não trivial">

**Problema.** Resolva <Eq>{`y' + (2/x)y = x^2`}</Eq>.

**Estratégia.** Identificar <Eq>{`p(x) = 2/x`}</Eq> e calcular <Eq>{`\\mu = e^{\\int 2/x\\,dx} = x^2`}</Eq>. Multiplicar a EDO por <Eq>{`\\mu`}</Eq> e reconhecer o lado esquerdo como derivada de produto.

**Resolução.**

<Equation latex="\frac{d}{dx}(x^2 y) = x^4 \;\Longrightarrow\; x^2 y = \frac{x^5}{5} + C \;\Longrightarrow\; y = \frac{x^3}{5} + \frac{C}{x^2}." />

**Verificação.** <Eq>{`y' = 3x^2/5 - 2C/x^3`}</Eq>. Substitui: <Eq>{`y' + 2y/x = 3x^2/5 - 2C/x^3 + 2x^2/5 + 2C/x^3 = x^2`}</Eq>. Confere.

**Fonte.** [OpenStax *Calculus Vol. 2* §4.5](https://openstax.org/books/calculus-volume-2/pages/4-5-first-order-linear-equations), Example 4.14.

</Exemplo>

<Exemplo titulo="Equação característica com raízes complexas e condições iniciais">

**Problema.** Resolva o PVI <Eq>{`y'' + 2y' + 5y = 0`}</Eq>, <Eq>{`y(0) = 1`}</Eq>, <Eq>{`y'(0) = -1`}</Eq>.

**Estratégia.** Calcular a equação característica <Eq>{`\\lambda^2 + 2\\lambda + 5 = 0`}</Eq>. Raízes complexas <Eq>{`\\alpha \\pm i\\beta`}</Eq> dão solução com exponencial e funções trigonométricas. Usar as CIs para determinar <Eq>{`C_1, C_2`}</Eq>.

**Resolução.**

<Equation latex="\lambda = \frac{-2 \pm \sqrt{4-20}}{2} = -1 \pm 2i." />

<Equation latex="y = e^{-x}(C_1\cos 2x + C_2 \sin 2x)." />

CI em <Eq>{`x=0`}</Eq>: <Eq>{`y(0) = C_1 = 1`}</Eq>.

<Equation latex="y' = -e^{-x}(C_1\cos 2x + C_2\sin 2x) + e^{-x}(-2C_1\sin 2x + 2C_2\cos 2x)." />

<Eq>{`y'(0) = -C_1 + 2C_2 = -1 + 2C_2 = -1`}</Eq>, logo <Eq>{`C_2 = 0`}</Eq>.

Solução: <Eq>{`y = e^{-x}\\cos 2x`}</Eq>.

**Verificação.** <Eq>{`y' = -e^{-x}\\cos 2x - 2e^{-x}\\sin 2x`}</Eq>; <Eq>{`y'' = e^{-x}\\cos 2x + 4e^{-x}\\sin 2x - 2e^{-x}\\sin 2x + ..`}</Eq> — após álgebra, <Eq>{`y'' + 2y' + 5y = 0`}</Eq>. Confere.

**Fonte.** [Lebl, *Notes on Diffy Qs* §2.2](https://www.jirka.org/diffyqs/html/secondlc_section.html), Example 2.2.4.

</Exemplo>

<Exemplo titulo="Modelo logístico com dados populacionais reais">

**Problema.** População de uma cidade: 50 mil em 2000, 80 mil em 2010. Capacidade de suporte estimada em 200 mil. Modelo logístico <Eq>{`\\dot P = rP(1-P/K)`}</Eq>. Ache <Eq>{`r`}</Eq> e preveja a população em 2030.

**Estratégia.** A solução logística é <Eq>{`P(t) = K/(1+Ae^{-rt})`}</Eq>. Usar <Eq>{`P(0) = 50`}</Eq> para achar <Eq>{`A`}</Eq>; usar <Eq>{`P(10) = 80`}</Eq> para achar <Eq>{`r`}</Eq>; calcular <Eq>{`P(30)`}</Eq>.

**Resolução.** <Eq>{`K = 200`}</Eq>, <Eq>{`P(0) = 200/(1+A) = 50 \\Rightarrow A = 3`}</Eq>.

<Equation latex="P(t) = \frac{200}{1 + 3e^{-rt}}." />

<Eq>{`P(10) = 200/(1+3e^{-10r}) = 80 \\Rightarrow 1 + 3e^{-10r} = 2{,}5 \\Rightarrow e^{-10r} = 0{,}5`}</Eq>.

<Eq>{`r = \\ln 2/10 \\approx 0{,}0693`}</Eq> ano⁻¹.

<Eq>{`P(30) = 200/(1 + 3e^{-30 \\times 0{,}0693}) = 200/(1 + 3 \\times 0{,}125) = 200/1{,}375 \\approx 145`}</Eq> mil.

**Verificação.** <Eq>{`P(0) = 200/4 = 50`}</Eq>. <Eq>{`P(10) = 200/(1+3/2) = 200/2{,}5 = 80`}</Eq>. Confere.

**Fonte.** [OpenStax *Calculus Vol. 2* §4.4](https://openstax.org/books/calculus-volume-2/pages/4-4-the-logistic-equation), Example 4.11.

</Exemplo>

<Exemplo titulo="Método de Euler aplicado a resfriamento de Newton: erro vs. passo">

**Problema.** Café a 90 °C, <Eq>{`T_a = 22`}</Eq> °C, <Eq>{`k = 0{,}1`}</Eq> min⁻¹. Use Euler com <Eq>{`h = 2`}</Eq> min para calcular <Eq>{`T(4)`}</Eq>. Compare com o valor exato.

**Estratégia.** EDO: <Eq>{`T' = -0{,}1(T - 22)`}</Eq>, <Eq>{`T(0) = 90`}</Eq>. Dois passos de Euler. Solução exata: <Eq>{`T(t) = 22 + 68e^{-0{,}1t}`}</Eq>.

**Resolução.**

Passo 1 (<Eq>{`t=0 \\to 2`}</Eq>): <Eq>{`f(0, 90) = -0{,}1(90-22) = -6{,}8`}</Eq>. <Eq>{`T(2) \\approx 90 + 2\\times(-6{,}8) = 76{,}4`}</Eq> °C.

Passo 2 (<Eq>{`t=2 \\to 4`}</Eq>): <Eq>{`f(2, 76{,}4) = -0{,}1(76{,}4-22) = -5{,}44`}</Eq>. <Eq>{`T(4) \\approx 76{,}4 + 2\\times(-5{,}44) = 65{,}52`}</Eq> °C.

Exato: <Eq>{`T(4) = 22 + 68e^{-0{,}4} = 22 + 68\\times 0{,}6703 \\approx 67{,}6`}</Eq> °C.

Erro: <Eq>{`67{,}6 - 65{,}5 = 2{,}1`}</Eq> °C (cerca de 3%). Com <Eq>{`h = 0{,}5`}</Eq> min o erro cai a 0,13%.

**Verificação.** Fórmula de erro local de Euler: <Eq>{`O(h^2) = O(4) = 0{,}1^2 \\times 68 \\times (e^{-0{,}1 \\times 0}/2) \\approx 0{,}34`}</Eq> °C por passo, acumulando a ~0,68 °C — ordem correta.

**Fonte.** [REAMAT UFRGS, *Cálculo Numérico* Cap. 8](https://www.ufrgs.br/reamat/CalculoNumerico/livro-py/main.html), Seção 8.2, Exemplo 8.3.

</Exemplo>
