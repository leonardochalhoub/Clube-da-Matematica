### Problema geral

<Definicao titulo="EDO linear homogenea de 2a ordem com coeficientes constantes">

$$ay'' + by' + cy = 0, \quad a, b, c \in \mathbb{R},\ a \neq 0$$

**Espaço de soluções:** pelo teorema de existência-unicidade, o conjunto de soluções é um espaço vetorial de **dimensão 2** — duas soluções linearmente independentes geram toda a família.

</Definicao>

### Ansatz e equação característica

Substitua $y = e^{\lambda x}$: $y' = \lambda e^{\lambda x}$, $y'' = \lambda^2 e^{\lambda x}$.

$$a\lambda^2 e^{\lambda x} + b\lambda e^{\lambda x} + c e^{\lambda x} = 0 \;\Rightarrow\; a\lambda^2 + b\lambda + c = 0$$

Como $e^{\lambda x} \neq 0$, tudo se reduz à equação algébrica quadrática.

<Teorema titulo="Tres casos pela discriminante">

Seja $\Delta = b^2 - 4ac$.

**Caso 1 — $\Delta > 0$:** raízes reais distintas $\lambda_1 \neq \lambda_2$.
$$y = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$$

**Caso 2 — $\Delta = 0$:** raiz dupla $\lambda = -b/(2a)$.
$$y = (C_1 + C_2 x)\,e^{\lambda x}$$

**Caso 3 — $\Delta < 0$:** raízes complexas conjugadas $\lambda = \alpha \pm i\beta$, onde $\alpha = -b/(2a)$, $\beta = \sqrt{4ac-b^2}/(2a)$.
$$y = e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$$

</Teorema>

> "If $b^2 - 4ac > 0$, the characteristic equation has two distinct real roots $r_1, r_2$, and the general solution of [the ODE] is $y = c_1 e^{r_1 x} + c_2 e^{r_2 x}$." — [Lebl, Notes on Diffy Qs, §2.2](https://www.jirka.org/diffyqs/html/socc_section.html)

### O caso da raiz dupla

<Insight>

Por que surge o fator $x$? Com raiz dupla $\lambda$, $e^{\lambda x}$ é uma solução, mas precisamos de outra. A redução de ordem mostra que $x e^{\lambda x}$ é a segunda solução independente. Verifique: $(xe^{\lambda x})'' + b/a\,(xe^{\lambda x})' + c/a\,(xe^{\lambda x}) = e^{\lambda x}(a\lambda^2 + b\lambda + c)/a + e^{\lambda x}(2\lambda + b/a) = 0$ quando $\Delta = 0$.

</Insight>

### Equações não-homogêneas

Para $ay'' + by' + cy = q(x)$: solução geral $y = y_h + y_p$.

$y_h$: solução da equação homogênea (dois parâmetros livres).

$y_p$: qualquer solução particular — obtida por **coeficientes a determinar** (quando $q$ é combinação de polinômio, exponencial, seno/cosseno) ou **variação de parâmetros** (geral).

</Porta>

<Porta nivel="5" titulo="Pra criança de 5 anos">

Pensa num balanço. Você o empurra e ele fica oscilando. A questão é: como ele se move com o passar do tempo?

Matemáticos descobriram que o movimento do balanço obedece a uma equação com $y''$ (como a posição está acelerando). Se não tiver atrito: oscila para sempre. Com atrito fraco: oscila e vai parando aos poucos. Com muito atrito: vai direto pra posição de repouso sem oscilar.

Cada um desses casos corresponde a um dos três tipos de solução da nossa equação.

</Porta>

<Porta nivel="10" titulo="Pra criança de 10 anos">

Na aula passada resolvemos EDOs de 1ª ordem (só $y'$). Agora temos $y''$ — aceleração — também.

O truque: testar $y = e^{\lambda x}$. Se isso funcionar, você acha $\lambda$ resolvendo uma **equação do 2º grau** — a equação característica.

Podem acontecer três coisas:
1. Duas raízes reais diferentes → soma de dois exponenciais.
2. Raiz dupla → exponencial multiplicado por $(C_1 + C_2 x)$.
3. Raízes complexas → exponencial com senos e cossenos (oscilação!).

O caso 3 é o mais bonito: aparece em qualquer sistema que oscila — pêndulo, mola, circuito LC.

</Porta>

<Porta nivel="15" titulo="Pra adolescente de 15 anos">

$ay'' + by' + cy = 0$ com $a, b, c$ constantes reais. A solução geral tem **sempre dois parâmetros livres** $C_1$ e $C_2$ (condições iniciais $y(0)$ e $y'(0)$ determinam ambos).

### Algoritmo completo

1. Escreva a equação característica: $a\lambda^2 + b\lambda + c = 0$.
2. Calcule $\Delta = b^2 - 4ac$.
3. Se $\Delta > 0$: $\lambda_{1,2} = (-b \pm \sqrt{\Delta})/(2a)$. Solução: $C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$.
4. Se $\Delta = 0$: $\lambda = -b/(2a)$. Solução: $(C_1 + C_2 x)e^{\lambda x}$.
5. Se $\Delta < 0$: $\lambda = \alpha \pm i\beta$, com $\alpha = -b/(2a)$, $\beta = \sqrt{-\Delta}/(2a)$. Solução: $e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$.

### Por que usar $e^{\alpha x}(\cos\beta x + \sin\beta x)$ e não complexo?

Pela fórmula de Euler: $e^{(\alpha+i\beta)x} = e^{\alpha x}(\cos\beta x + i\sin\beta x)$. Partes real e imaginária são ambas soluções reais. Uma combinação real delas dá a solução real geral.

### Exemplo: $y'' + 4y = 0$

$\lambda^2 + 4 = 0 \Rightarrow \lambda = \pm 2i$. Aqui $\alpha = 0$, $\beta = 2$.

$y = C_1\cos 2x + C_2\sin 2x$ — oscilação pura.

Com $y(0) = 1$, $y'(0) = 0$: $C_1 = 1$, $C_2 = 0$. $y = \cos 2x$.

</Porta>

<Porta nivel="25" titulo="Pra estudante de engenharia">

### Classificacao dos sistemas de segunda ordem

Todo sistema linear de 2ª ordem com coeficientes constantes se enquadra em um dos três regimes:

| Caso | $\Delta$ | Raízes | Comportamento |
|---|---|---|---|
| Superamortecido | $> 0$ | $\lambda_1, \lambda_2 < 0$ | Decaimento sem oscilação |
| Criticamente amortecido | $= 0$ | $\lambda$ duplo, real negativo | Decaimento mais rápido sem oscilação |
| Subamortecido | $< 0$ | $\alpha \pm i\beta$, $\alpha < 0$ | Oscilação com decaimento |
| Não-amortecido | $= 0$, sem dissipação | $\pm i\beta$ (puramente imaginário) | Oscilação eterna |
| Instável | qualquer | $\text{Re}(\lambda) > 0$ | Crescimento exponencial |

### Solucao nao-homogenea — coeficientes a determinar

Para $q(x) = $ polinômio, exponencial, seno/cosseno: chute uma forma para $y_p$ e determine os coeficientes.

| $q(x)$ | Forma tentativa para $y_p$ (se $\lambda_p$ não é raiz caraterística) |
|---|---|
| $x^n$ | $A_n x^n + \ldots + A_0$ |
| $e^{kx}$ | $Ae^{kx}$ |
| $\cos\omega x$ ou $\sin\omega x$ | $A\cos\omega x + B\sin\omega x$ |
| $x^n e^{kx}$ | $(A_n x^n + \ldots + A_0)e^{kx}$ |

**Regra de modificação**: se $\lambda_p$ é raiz característica de multiplicidade $m$, multiplique a tentativa por $x^m$.

### Variacao de parametros

Geral: $y_p = -y_1 \int \frac{y_2 q}{W}\,dx + y_2 \int \frac{y_1 q}{W}\,dx$, onde $W = y_1 y_2' - y_2 y_1'$ é o Wronskiano.

### Transformada de Laplace

$a(s^2 Y - sy_0 - y_0') + b(sY - y_0) + cY = Q(s)$. Resolve CI diretamente, sem separar $y_h$ e $y_p$.

</Porta>

<Porta nivel="40" titulo="Pra profissional sênior">

### Fundamento: espaco de solucoes

Por Picard-Lindelöf, o PVI $ay'' + by' + cy = 0$, $y(x_0) = y_0$, $y'(x_0) = y_1$ tem solução única global (para coeficientes constantes, em todo $\mathbb{R}$). O espaço de soluções é isomorfo a $\mathbb{R}^2$ via $(y_0, y_1) \mapsto y$.

O **Wronskiano** $W[y_1, y_2](x) = y_1 y_2' - y_2 y_1'$ é constante ou identicamente zero (Abel). $W \neq 0$ iff $\{y_1, y_2\}$ é base do espaço de soluções.

### Teoria espectral

Para $\mathcal{L} = a\,d^2/dx^2 + b\,d/dx + c$, os autovalores de $-\mathcal{L}$ no espaço $L^2([0,\pi])$ com condições de Dirichlet formam um espectro discreto $\{\lambda_n\}_{n \geq 1}$ — problema de Sturm-Liouville. As autofunções $\{\sin n\pi x\}$ formam base ortonormal: série de Fourier.

### Green e convoluções

A função de Green $G(x,s)$ de $\mathcal{L}$ satisfaz $\mathcal{L}G = \delta(x-s)$. A solução particular da não-homogênea é $y_p(x) = \int G(x,s)q(s)\,ds$. Para $ay'' + by' + cy = q$:

$$G(x,s) = \frac{y_1(s) y_2(x) - y_1(x) y_2(s)}{a\,W(s)}\, H(x-s)$$

onde $H$ é Heaviside (causalidade).

### Estabilidade de Lyapunov

Para $\ddot y + 2\zeta\omega_0\dot y + \omega_0^2 y = 0$: energia total $E = \frac{1}{2}\dot y^2 + \frac{1}{2}\omega_0^2 y^2$. $\dot E = -2\zeta\omega_0 \dot y^2 \leq 0$ (para $\zeta \geq 0$). Criticamente amortecido ($\zeta = 1$) é o mais rápido sem oscilação — ótimo para suspensão automotiva.

### Premio Nobel e osciladores

O modelo de oscilador linear de 2ª ordem fundamenta toda a teoria de detecção de ondas gravitacionais: os interferômetros LIGO usam ressonadores de 2ª ordem com frequência de 150 Hz. Kip Thorne, Barry Barish e Rainer Weiss receberam o [Prêmio Nobel de Física de 2017](https://www.nobelprize.org/prizes/physics/2017/summary/) pela detecção direta de ondas gravitacionais — dependente desta teoria.

</Porta>

<Porta nivel="pratica" titulo="Aplicacao pratica">

### Algoritmo de bolso

Para $ay'' + by' + cy = 0$:

1. $\Delta = b^2 - 4ac$.
2. Se $\Delta > 0$: $\lambda = (-b \pm \sqrt{\Delta})/(2a)$ — dois reais. $y = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$.
3. Se $\Delta = 0$: $\lambda = -b/(2a)$. $y = (C_1 + C_2 x)e^{\lambda x}$.
4. Se $\Delta < 0$: $\alpha = -b/(2a)$, $\beta = \sqrt{-\Delta}/(2a)$. $y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$.

### Erros classicos

- Esquecer que $\Delta < 0$ exige a **parte real** na exponencial: é $e^{\alpha x}\cos\beta x$, não $\cos\beta x$.
- Com raiz dupla: lembrar do fator $x$ na segunda solução.
- Ao impor CIs: usar $y'(0)$ corretamente — derivar $y$ antes de substituir $x = 0$.

### Modelo: oscilador eletrico LC

Circuito LC: $L\ddot q + q/C = 0$, $q(0) = Q_0$, $\dot q(0) = 0$.

$\lambda^2 + 1/(LC) = 0 \Rightarrow \lambda = \pm i/\sqrt{LC} = \pm i\omega_0$.

$q(t) = Q_0\cos(\omega_0 t)$, $i(t) = \dot q = -Q_0\omega_0\sin(\omega_0 t)$.

Frequência de ressonância: $\omega_0 = 1/\sqrt{LC}$ [rad/s] — base dos filtros de rádio.

### Sintese

| EDO | Carac. | Solução |
|---|---|---|
| $y'' - 5y' + 6y = 0$ | $\lambda^2-5\lambda+6 = (\lambda-2)(\lambda-3) = 0$ | $C_1 e^{2x} + C_2 e^{3x}$ |
| $y'' - 4y' + 4y = 0$ | $(\lambda-2)^2 = 0$ | $(C_1+C_2 x)e^{2x}$ |
| $y'' + 4y = 0$ | $\lambda = \pm 2i$ | $C_1\cos 2x + C_2\sin 2x$ |
| $y'' + 2y' + 5y = 0$ | $\lambda = -1 \pm 2i$ | $e^{-x}(C_1\cos 2x + C_2\sin 2x)$ |

</Porta>

## Exemplos resolvidos

<Exemplo titulo="Caso 1 — raizes reais distintas" numero="1">

**Problema.** Resolva $y'' - 5y' + 6y = 0$, $y(0) = 2$, $y'(0) = 3$.

**Estratégia.** $\Delta = 25 - 24 = 1 > 0$: dois reais distintos.

**Resolução.**

Equação característica: $\lambda^2 - 5\lambda + 6 = (\lambda-2)(\lambda-3) = 0$.

$\lambda_1 = 2$, $\lambda_2 = 3$. Solução geral: $y = C_1 e^{2x} + C_2 e^{3x}$.

$y(0) = C_1 + C_2 = 2$.

$y'(0) = 2C_1 + 3C_2 = 3$.

Sistema: $C_1 = 3$, $C_2 = -1$.

$$y = 3e^{2x} - e^{3x}$$

**Verificação.** $y'' - 5y' + 6y = (12-15+6\cdot 3)e^{2x} + (-9+15-6)e^{3x} = 12e^{2x} \cdot 0 + 0 = 0$. $y(0) = 3 - 1 = 2$, $y'(0) = 6 - 3 = 3$. Correto.

**Fonte.** [Lebl, Notes on Diffy Qs, §2.2, Example 2.2.1](https://www.jirka.org/diffyqs/html/socc_section.html) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="Caso 2 — raiz dupla" numero="2">

**Problema.** Resolva $y'' - 4y' + 4y = 0$, $y(0) = 1$, $y'(0) = 0$.

**Estratégia.** $\Delta = 16 - 16 = 0$: raiz dupla.

**Resolução.**

$\lambda^2 - 4\lambda + 4 = (\lambda-2)^2 = 0$. Raiz dupla $\lambda = 2$.

$y = (C_1 + C_2 x)e^{2x}$.

$y(0) = C_1 = 1$.

$y'(x) = C_2 e^{2x} + 2(C_1 + C_2 x)e^{2x}$.

$y'(0) = C_2 + 2C_1 = 0 \Rightarrow C_2 = -2$.

$$y = (1 - 2x)e^{2x}$$

**Verificação.** $y' = -2e^{2x} + 2(1-2x)e^{2x} = (2-4x-2)e^{2x} = -4xe^{2x}$. $y'' = -4e^{2x} - 8xe^{2x}$. $y''-4y'+4y = (-4-8x)e^{2x} - 4(-4x)e^{2x} + 4(1-2x)e^{2x} = (-4-8x+16x+4-8x)e^{2x} = 0$. Correto.

**Fonte.** [Lebl, Notes on Diffy Qs, §2.2, Example 2.2.2](https://www.jirka.org/diffyqs/html/socc_section.html) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="Caso 3 — complexas conjugadas (oscilacao amortecida)" numero="3">

**Problema.** Resolva $y'' + 2y' + 5y = 0$, $y(0) = 1$, $y'(0) = 2$.

**Estratégia.** $\Delta = 4 - 20 = -16 < 0$: complexas. $\alpha = -1$, $\beta = 2$.

**Resolução.**

$\lambda = (-2 \pm \sqrt{-16})/2 = -1 \pm 2i$.

$y = e^{-x}(C_1\cos 2x + C_2\sin 2x)$.

$y(0) = C_1 = 1$.

$y'(x) = -e^{-x}(C_1\cos 2x + C_2\sin 2x) + e^{-x}(-2C_1\sin 2x + 2C_2\cos 2x)$.

$y'(0) = -C_1 + 2C_2 = 2 \Rightarrow 2C_2 = 3 \Rightarrow C_2 = 3/2$.

$$y = e^{-x}\!\left(\cos 2x + \frac{3}{2}\sin 2x\right)$$

**Verificação.** A equação característica tem raízes $-1 \pm 2i$, ambas com parte real $-1 < 0$: solução decai exponencialmente. $y(0) = 1$, $y'(0) = -1 + 3 = 2$. Correto.

**Fonte.** [Lebl, Notes on Diffy Qs, §2.2, Example 2.2.3](https://www.jirka.org/diffyqs/html/socc_section.html) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="Nao-homogenea por coeficientes a determinar" numero="4">

**Problema.** Resolva $y'' - y' - 2y = e^{3x}$.

**Estratégia.** $y = y_h + y_p$. Para $q = e^{3x}$ e $3$ não é raiz da característica: tentativa $y_p = Ae^{3x}$.

**Resolução.**

$\lambda^2 - \lambda - 2 = (\lambda-2)(\lambda+1) = 0$. $y_h = C_1 e^{2x} + C_2 e^{-x}$.

Tentativa: $y_p = Ae^{3x}$. Substitua:

$9Ae^{3x} - 3Ae^{3x} - 2Ae^{3x} = e^{3x} \Rightarrow 4A = 1 \Rightarrow A = 1/4$.

$$y = C_1 e^{2x} + C_2 e^{-x} + \frac{1}{4}e^{3x}$$

**Verificação.** $y_p'' - y_p' - 2y_p = (9/4 - 3/4 - 2/4)e^{3x} = (9-3-2)/4\,e^{3x} = e^{3x}$. Correto.

**Fonte.** [Lebl, Notes on Diffy Qs, §2.3, Example 2.3.1](https://www.jirka.org/diffyqs/html/uc_section.html) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="Nao-homogenea com ressonancia (regra de modificacao)" numero="5">

**Problema.** Resolva $y'' - 3y' + 2y = e^{2x}$.

**Estratégia.** Tente $y_p = Ae^{2x}$ — mas $\lambda = 2$ é raiz característica! Regra de modificação: multiplique por $x$.

**Resolução.**

$\lambda^2 - 3\lambda + 2 = (\lambda-1)(\lambda-2) = 0$. $y_h = C_1 e^x + C_2 e^{2x}$.

$\lambda = 2$ é raiz simples: tente $y_p = Axe^{2x}$.

$y_p' = Ae^{2x} + 2Axe^{2x}$, $y_p'' = 4Ae^{2x} + 4Axe^{2x}$.

$y_p'' - 3y_p' + 2y_p = (4A + 4Ax)e^{2x} - (3A + 6Ax)e^{2x} + 2Axe^{2x} = Ae^{2x}$.

$A = 1$. Logo $y_p = xe^{2x}$.

$$y = C_1 e^x + C_2 e^{2x} + xe^{2x}$$

**Verificação.** $y_p = xe^{2x}$: $y_p'' - 3y_p' + 2y_p = (4+4x)e^{2x} - 3(1+2x)e^{2x} + 2xe^{2x} = (4+4x-3-6x+2x)e^{2x} = e^{2x}$. Correto.

**Fonte.** [Lebl, Notes on Diffy Qs, §2.3, Example 2.3.2](https://www.jirka.org/diffyqs/html/uc_section.html) — CC-BY-SA.

</Exemplo>
