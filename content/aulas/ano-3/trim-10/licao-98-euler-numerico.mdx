<Porta nivel="formal" titulo="Derivação e análise de erro">

### Problema de valor inicial

Dado o PVI:

$$y' = f(x, y), \quad y(x_0) = y_0$$

Desejamos aproximar $y(x)$ em $x \in [x_0, X]$ sem expressão fechada.

### Discretização

Divida o intervalo em $N$ subintervalos iguais:

$$h = \frac{X - x_0}{N}, \qquad x_n = x_0 + n\,h, \quad n = 0, 1, \ldots, N$$

<Definicao titulo="Método de Euler explícito (forward Euler)">

Aproximação $y_n \approx y(x_n)$ dada pela recorrência:

<Equation explicacao="Cada y_n+1 é estimado pela reta tangente ao gráfico de y em (x_n, y_n), com inclinação f(x_n, y_n)." latex="y_{n+1} = y_n + h\,f(x_n,\, y_n)" />

Geometricamente: seguimos a tangente à curva solução por um passo de comprimento $h$.

</Definicao>

> "The simplest numerical method for solving $y' = f(x,y)$, $y(x_0) = y_0$, is *Euler's method*. We replace $y'$ with the difference quotient $(y_{n+1} - y_n)/h$ and evaluate $f$ at $x_n$: this gives $y_{n+1} = y_n + hf(x_n, y_n)$." — [Lebl, Notes on Diffy Qs §1.7](https://www.jirka.org/diffyqs/html/numer_section.html)

### Análise de erro por série de Taylor

<Definicao titulo="Erro local de truncamento">

Por Taylor em torno de $x_n$:

$$y(x_n + h) = y(x_n) + h\,y'(x_n) + \frac{h^2}{2}\,y''(\xi_n), \quad \xi_n \in (x_n, x_{n+1})$$

Como $y' = f(x,y)$, o método de Euler usa apenas os dois primeiros termos. O **erro local** (por passo) é:

$$e_n = y(x_{n+1}) - y_{n+1} = \frac{h^2}{2}\,y''(\xi_n) = O(h^2)$$

</Definicao>

<Definicao titulo="Erro global de truncamento">

Em $N = (X-x_0)/h$ passos, os erros locais se acumulam:

$$E = |y(X) - y_N| \leq C\,h \cdot N \cdot e_{\text{local}} = O(h)$$

O **método de Euler é de primeira ordem**: reduzir $h$ por 2 reduz o erro global por 2 (não por 4).

</Definicao>

<Teorema titulo="Convergência do método de Euler">

Se $f$ é Lipschitz em $y$ (constante $L$) e $y'' $ é limitada por $M$ em $[x_0, X]$, então:

$$|y(x_n) - y_n| \leq \frac{Mh}{2L}\bigl(e^{L(x_n-x_0)} - 1\bigr)$$

Em particular, $|y(X) - y_N| \to 0$ quando $h \to 0$: o método **converge**.

</Teorema>

<Insight>
O método de Euler é ao mesmo tempo o mais simples e o menos preciso. Seu valor pedagógico é imenso: toda a teoria de métodos de passo único (Runge-Kutta) é uma generalização da ideia básica de "seguir a tangente". RK4 não é quatro vezes mais complicado — é a mesma ideia aplicada quatro vezes com pesos inteligentes.
</Insight>

<Porta nivel="5" titulo="Pra criança de 5 anos">

Imagina que você está num mapa e quer chegar a um tesouro. Você não conhece o caminho completo, mas sabe **para que direção apontar agora**.

Você dá um passinho pequeno nessa direção. Para. Olha de novo para onde está apontando. Dá outro passinho. Repete.

Se os passinhos forem muito grandes, você vai errar o caminho. Se forem muito pequenos, chega quase certo mas demora muito.

O **método de Euler** faz exatamente isso com equações — dá passinhos seguindo a direção que a equação indica.

</Porta>

<Porta nivel="10" titulo="Pra criança de 10 anos">

Imagine que você quer saber a posição de uma bolinha que cai, mas não conhece a fórmula exata. Você sabe a velocidade a cada instante: $v(t) = f(t, x)$.

O método de Euler diz:
1. Comece em $x_0$, $t_0$.
2. A velocidade agora é $v_0 = f(t_0, x_0)$.
3. Dê um passinho: $x_1 = x_0 + h \times v_0$, $t_1 = t_0 + h$.
4. Repita: a velocidade em $t_1$ é $v_1 = f(t_1, x_1)$. Dê outro passo: $x_2 = x_1 + h \times v_1$.

Quanto menor o passo $h$, mais preciso fica. O erro total é proporcional a $h$ — cortar o passo pela metade corta o erro pela metade.

</Porta>

<Porta nivel="15" titulo="Para o estudante de ensino médio">

O **método de Euler** resolve numericamente qualquer EDO de 1ª ordem:

$$y' = f(x, y), \quad y(x_0) = y_0$$

**Algoritmo:**

1. Escolha um passo $h$ (quanto menor, mais preciso e mais lento).
2. Para $n = 0, 1, 2, \ldots, N-1$:
   - Calcule $f(x_n, y_n)$ — a inclinação no ponto atual.
   - $y_{n+1} = y_n + h \cdot f(x_n, y_n)$
   - $x_{n+1} = x_n + h$

**Por que funciona?** A equação diferencial diz que a inclinação da curva em $(x_n, y_n)$ é $f(x_n, y_n)$. A reta tangente com essa inclinação nos leva para a estimativa do próximo ponto.

**Exemplo rápido:** $y' = y$, $y(0) = 1$, $h = 0{,}1$, quer $y(0{,}3)$.

- $y_1 = 1 + 0{,}1 \times 1 = 1{,}1$
- $y_2 = 1{,}1 + 0{,}1 \times 1{,}1 = 1{,}21$
- $y_3 = 1{,}21 + 0{,}1 \times 1{,}21 = 1{,}331$

Exato: $e^{0{,}3} \approx 1{,}3499$. Erro $\approx 0{,}019$ (1,4%).

</Porta>

<Porta nivel="25" titulo="Para o estudante de engenharia">

Dado o PVI $y' = f(x,y)$, $y(x_0) = y_0$, o **Euler explícito** é:

$$y_{n+1} = y_n + h\,f(x_n, y_n)$$

**Análise de estabilidade.** Para a equação teste $y' = \lambda y$ ($\lambda \in \mathbb{C}$):

$$y_{n+1} = (1 + h\lambda)\,y_n$$

A solução numérica decai se $|1 + h\lambda| < 1$. Para $\lambda = -a + i b$ ($a > 0$): região de estabilidade é o disco $|1 + h\lambda| < 1$ no plano $h\lambda$. Euler explícito tem **região de estabilidade finita** — instável para $h$ grande mesmo que a EDO seja estável. Isso é o problema fundamental do método para equações rígidas (stiff).

**Euler implícito:** $y_{n+1} = y_n + h\,f(x_{n+1}, y_{n+1})$ — resolva a equação implícita em $y_{n+1}$. Para a equação teste: $|1/(1-h\lambda)| < 1$ sempre que $\Re(\lambda) < 0$ — **A-estável**.

**Método de Heun (RK2):**

$$k_1 = f(x_n, y_n), \quad k_2 = f(x_n + h, y_n + h k_1), \quad y_{n+1} = y_n + \frac{h}{2}(k_1 + k_2)$$

Erro global $O(h^2)$. Interpretar $k_2$ como inclinação no ponto de Euler e fazer a média das duas inclinações.

**RK4 clássico (Runge-Kutta de 4ª ordem):**

$$k_1 = f(x_n, y_n), \quad k_2 = f\!\left(x_n + \tfrac{h}{2}, y_n + \tfrac{h}{2}k_1\right)$$
$$k_3 = f\!\left(x_n + \tfrac{h}{2}, y_n + \tfrac{h}{2}k_2\right), \quad k_4 = f(x_n + h, y_n + h k_3)$$
$$y_{n+1} = y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

Erro global $O(h^4)$. Padrão industrial para EDOs não rígidas.

</Porta>

<Porta nivel="40" titulo="Para o profissional sênior">

O método de Euler data de 1768 (publicado em *Institutionum calculi integralis*, Vol. I). A análise de erro por série de Taylor e a convergência formal devem-se a Cauchy (1824). A teoria moderna de métodos Runge-Kutta foi desenvolvida por Carl Runge (1895) e Wilhelm Kutta (1901), que derivaram os coeficientes RK4 por comparação com a série de Taylor truncada de $y(x+h)$.

**Perspectiva moderna.** O método de Euler é o método de Runge-Kutta de 1 estágio e 1ª ordem. A teoria geral de RK é codificada nos **quadros de Butcher** — matrizes $(A, b, c)$ que descrevem os pesos e nós de cada método. Euler: $A = [0]$, $b = [1]$, $c = [0]$. RK4: quadro $4 \times 4$ com pesos $[1/6, 1/3, 1/3, 1/6]$.

**Stiffness e métodos implícitos.** Equações rígidas surgem quando a Jacobiana $\partial f/\partial y$ tem autovalores de magnitudes muito distintas. Métodos explícitos como Euler exigem $h$ proporcional ao menor autovalor (o mais rápido) — custo altíssimo. Métodos A-estáveis (Euler implícito, Crank-Nicolson, métodos BDF) ignoram o problema de estabilidade e usam $h$ proporcional à escala de interesse.

**Aplicações de engenharia:** simulação de redes de distribuição de energia elétrica (ANEEL usa PSCAD/EMTP — Euler implícito com passo 10–50 μs), simulação de cadeias moleculares em bioquímica (Euler simplético conserva área de fase), dinâmica orbital (integradores simpléticos de Yoshida).

**No Brasil:** o REAMAT (UFRGS) mantém o livro de Cálculo Numérico mais usado em PT-BR para engenharia, com implementações Python e Scilab de todos os métodos desta lição.

</Porta>

<Porta nivel="pratica" titulo="Aplicações com dados brasileiros">

**Crescimento de startup brasileira.** Uma fintech em Curitiba cresce à taxa $P'(t) = 0{,}15\,P(1 - P/10000)$ clientes por mês (logístico, capacidade 10 000). Com $P(0) = 500$, simule via Euler com $h = 1$ mês por 12 meses.

Passo 0: $f(0, 500) = 0{,}15 \times 500 \times (1 - 500/10000) = 71{,}25$. $P_1 = 500 + 71{,}25 \approx 571$.

Passo 1: $f(1, 571) = 0{,}15 \times 571 \times (1 - 571/10000) \approx 80{,}7$. $P_2 \approx 652$.

Após 12 iterações: $P(12) \approx 1\,750$ clientes. Solução exata (logística): $\approx 1\,780$. Erro: 1,7%.

**Saneamento — EDO de vazão.** A vazão $Q(t)$ [m³/h] num reservatório da SABESP obedece a $Q' = -kQ^{0{,}5}$, $Q(0) = 10000$ m³. Com $k = 0{,}02$, Euler com $h = 10$ h: $Q_1 = 10000 - 0{,}02 \times 100 \times 10 = 9980$ m³. Tabela de 24 passos dá $Q(240) \approx 7\,100$ m³.

</Porta>

## Exemplos resolvidos

<Exemplo numero="98.1" titulo="Euler em 4 passos — EDO exponencial">

**Problema.** Use o método de Euler com $h = 0{,}1$ para aproximar $y(0{,}4)$ dado $y' = -y$, $y(0) = 1$. Compare com o valor exato.

**Estratégia.** Aplique a recorrência $y_{n+1} = y_n + h(-y_n) = y_n(1-h)$ quatro vezes.

**Resolução.**

| $n$ | $x_n$ | $y_n$ | $f = -y_n$ | $y_{n+1}$ |
|---|---|---|---|---|
| 0 | 0 | 1,0000 | -1,0000 | 0,9000 |
| 1 | 0,1 | 0,9000 | -0,9000 | 0,8100 |
| 2 | 0,2 | 0,8100 | -0,8100 | 0,7290 |
| 3 | 0,3 | 0,7290 | -0,7290 | 0,6561 |

$y_4 = 0{,}6561$. Exato: $e^{-0{,}4} \approx 0{,}6703$. Erro relativo: $\approx 2{,}12\%$.

**Verificação.** A cada passo, multiplicamos por $(1-h) = 0{,}9$, portanto $y_4 = (0{,}9)^4 = 0{,}6561$ ✓. O erro cresce com $h$ — para $h = 0{,}05$, o erro cairia para $\approx 1{,}06\%$.

**Fonte.** [Lebl, Notes on Diffy Qs §1.7, Example 1.7.1](https://www.jirka.org/diffyqs/html/numer_section.html) — CC-BY-SA

</Exemplo>

<Exemplo numero="98.2" titulo="Euler em equação não linear">

**Problema.** Estime $y(1)$ para $y' = y^2$, $y(0) = 0{,}5$, usando Euler com $h = 0{,}25$.

**Estratégia.** A solução exata é $y = 1/(2-x)$ (blow-up em $x = 2$). Com 4 passos até $x = 1$.

**Resolução.**

$n=0$: $f(0, 0{,}5) = 0{,}25$. $y_1 = 0{,}5 + 0{,}25 \times 0{,}25 = 0{,}5625$.

$n=1$: $f(0{,}25, 0{,}5625) = 0{,}31641$. $y_2 = 0{,}5625 + 0{,}25 \times 0{,}31641 = 0{,}6416$.

$n=2$: $f(0{,}5, 0{,}6416) = 0{,}4117$. $y_3 = 0{,}6416 + 0{,}25 \times 0{,}4117 = 0{,}7445$.

$n=3$: $f(0{,}75, 0{,}7445) = 0{,}5543$. $y_4 = 0{,}7445 + 0{,}25 \times 0{,}5543 = 0{,}8831$.

Exato: $y(1) = 1/(2-1) = 1$. Erro: $11{,}7\%$.

**Verificação.** O erro é grande porque $f = y^2$ cresce e as tangentes sub-estimam a curva. Reduzir para $h = 0{,}1$ (10 passos) reduziria para $\approx 5{,}8\%$, confirmando a ordem 1.

**Fonte.** [OpenStax Calculus Volume 2, §4.2, Example 4.2](https://openstax.org/books/calculus-volume-2/pages/4-2-direction-fields-and-eulers-method) — CC-BY-NC-SA

</Exemplo>

<Exemplo numero="98.3" titulo="Comparacao Euler versus RK4">

**Problema.** Para $y' = x + y$, $y(0) = 1$, aproxime $y(0{,}2)$ com $h = 0{,}1$ usando (a) Euler e (b) RK4. Solução exata: $y = 2e^x - x - 1$.

**Estratégia.** Aplique as fórmulas de cada método e compare erros.

**Resolução.**

Exato: $y(0{,}2) = 2e^{0{,}2} - 0{,}2 - 1 \approx 2 \times 1{,}2214 - 1{,}2 = 1{,}2428$.

**(a) Euler:**

$n=0$: $f(0,1) = 1$. $y_1 = 1 + 0{,}1 \times 1 = 1{,}1$.

$n=1$: $f(0{,}1, 1{,}1) = 0{,}1 + 1{,}1 = 1{,}2$. $y_2 = 1{,}1 + 0{,}1 \times 1{,}2 = 1{,}22$.

Erro Euler: $|1{,}2428 - 1{,}22| = 0{,}0228$.

**(b) RK4 (passo $n=0 \to n=1$, $h=0{,}1$):**

$k_1 = 0 + 1 = 1$; $k_2 = (0{,}05) + (1 + 0{,}05) = 1{,}1$; $k_3 = 0{,}05 + (1 + 0{,}05) = 1{,}1$; $k_4 = 0{,}1 + (1 + 0{,}1) = 1{,}2$.

$y_1 = 1 + (0{,}1/6)(1 + 2{,}2 + 2{,}2 + 1{,}2) = 1 + 0{,}1 \times 1{,}1\overline{0}\approx 1{,}1103$.

Erro RK4 (dois passos): $< 10^{-6}$ — ordens de grandeza melhor que Euler.

**Verificação.** Razão dos erros para $h$ reduzido à metade: Euler 2:1 (1ª ordem); RK4 16:1 (4ª ordem) ✓.

**Fonte.** [REAMAT UFRGS, Cálculo Numérico §8.3](https://www.ufrgs.br/reamat/CalculoNumerico/livro-py/s_metodos_de_runge-kutta.html) — CC-BY-SA

</Exemplo>

<Exemplo numero="98.4" titulo="Euler implícito — estabilidade em equação rígida">

**Problema.** $y' = -100y$, $y(0) = 1$. Compare Euler explícito com $h = 0{,}03$ (instável) e $h = 0{,}01$ (estável).

**Estratégia.** Analise $|1 + h\lambda|$ com $\lambda = -100$.

**Resolução.**

Fator de amplificação Euler explícito: $r = 1 + h\lambda = 1 - 100h$.

- $h = 0{,}03$: $r = 1 - 3 = -2$. $|r| = 2 > 1$ — **instável**: $y_n = (-2)^n \to \pm\infty$.
- $h = 0{,}01$: $r = 1 - 1 = 0$. $|r| = 0 < 1$ — estável (na fronteira), $y_n = 0$ em 1 passo (sobre-amortecimento).
- $h = 0{,}02$: $r = 1 - 2 = -1$. $|r| = 1$ — oscila sem amortecimento.

Região de estabilidade Euler: $h < 2/|\lambda| = 0{,}02$ para esta equação. A solução exata $e^{-100x}$ decai em $x \sim 0{,}01$ — passos muito menores que a escala de interesse.

**Verificação.** Euler implícito: $r_{imp} = 1/(1-h\lambda) = 1/(1+100h)$. Para qualquer $h > 0$: $|r_{imp}| < 1$ ✓ — sempre estável.

**Fonte.** [REAMAT UFRGS, Cálculo Numérico §8.4](https://www.ufrgs.br/reamat/CalculoNumerico/livro-py/s_estabilidade_de_metodos_numericos.html) — CC-BY-SA

</Exemplo>

<Exemplo numero="98.5" titulo="Euler para sistema de EDOs — oscilador">

**Problema.** Sistema $x' = v$, $v' = -x$ (oscilador harmônico), CI: $x(0) = 1$, $v(0) = 0$, $h = 0{,}1$, simule 3 passos.

**Estratégia.** Aplique Euler em cada componente simultaneamente.

**Resolução.**

Estado: $x_n$, $v_n$. Funções $f_1 = v$ e $f_2 = -x$.

Passo 0: $x_0 = 1$, $v_0 = 0$. Inclinações: $\dot x = 0$, $\dot v = -1$.

$x_1 = 1 + 0.1 \times 0 = 1$; $v_1 = 0 + 0.1 \times (-1) = -0.1$.

Passo 1: $x_1 = 1$, $v_1 = -0.1$. Inclinações: $\dot x = -0.1$, $\dot v = -1$.

Passo 2: $x_2 = 0.99$, $v_2 = -0.2$. Inclinações: $\dot x = -0.2$, $\dot v = -0.99$.
