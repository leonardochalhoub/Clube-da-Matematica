### Derivação da fórmula

<Definicao titulo="Integração por partes">

Sejam $u(x)$ e $v(x)$ funções deriváveis em $[a, b]$, com $u'$ e $v'$ contínuas. A regra do produto afirma:

$$\frac{d}{dx}[u(x)v(x)] = u'(x)v(x) + u(x)v'(x).$$

Integrando ambos os lados de $a$ a $b$ e aplicando o Teorema Fundamental do Cálculo:

$$[u(x)v(x)]_a^b = \int_a^b u'(x)v(x)\, dx + \int_a^b u(x)v'(x)\, dx.$$

Reorganizando:

$$\int_a^b u(x)v'(x)\, dx = [u(x)v(x)]_a^b - \int_a^b v(x)u'(x)\, dx.$$

Em notação diferencial ($dv = v'(x)\, dx$, $du = u'(x)\, dx$):

<Equation explicacao="Fórmula de integração por partes — forma indefinida." latex="\int u\, dv = uv - \int v\, du." />

</Definicao>

> "The formula for integration by parts comes from the product rule for differentiation: if $u$ and $v$ are both functions of $x$, then $(uv)' = u'v + uv'$. Integrating both sides and rearranging gives $\int u\, dv = uv - \int v\, du$." — [Active Calculus §5.4](https://activecalculus.org/single/sec-5-4-parts.html)

### Heurística LIATE

<Definicao titulo="Ordem de preferência para u (LIATE)">

Para escolher $u$ (a função que será derivada), prefira na ordem:

1. **L**ogarítmica: $\ln x$, $\log_a x$
2. **I**nversa trigonométrica: $\arctan x$, $\arcsin x$, $\arccos x$
3. **A**lgébrica: $x^n$, polinômios
4. **T**rigonométrica: $\sin x$, $\cos x$, $\tan x$
5. **E**xponencial: $e^x$, $a^x$

A primeira categoria que aparece no integrando vira $u$. O resto é $dv$.

**Lógica:** logarítmicas e inversas trigonométricas têm derivadas que simplificam (de transcendente para algébrica); exponenciais e trig reproduzem-se ao derivar. Logo $u$ deve ser o fator que "melhora" ao derivar.

</Definicao>

> "A useful heuristic for deciding which function to call $u$ in integration by parts is the acronym LIATE, which stands for Logarithmic, Inverse trigonometric, Algebraic, Trigonometric, and Exponential functions." — [OpenStax Calculus Vol. 2, §3.1](https://openstax.org/books/calculus-volume-2/pages/3-1-integration-by-parts)

<Teorema titulo="Truque: integral que volta a si mesma">

Para $I = \int e^x \cos x\, dx$:

Aplica partes com $u = \cos x$, $dv = e^x dx$: $I = e^x \cos x + \int e^x \sin x\, dx$.

Aplica partes novamente com $u = \sin x$: $I = e^x \cos x + e^x \sin x - I$.

Portanto $2I = e^x(\cos x + \sin x)$, e:

<Equation explicacao="Resultado do truque quando a integral original reaparece após duas aplicações." latex="I = \frac{e^x(\sin x + \cos x)}{2} + C." />

**Condição:** o truque funciona quando a segunda aplicação reproduz a integral original com o mesmo sinal (e não com sinal invertido, que daria identidade nula).

</Teorema>

<Insight>

**Partes é transferência de derivada.** A identidade $\int u\, dv = uv - \int v\, du$ move a operação de diferenciação de um fator para o outro. Em espaços funcionais com condições de fronteira nulas, isso torna $d/dx$ antissimétrico em $L^2$ — base da formulação fraca de EDPs.

</Insight>

Imagina dois amigos carregando uma mochila pesada. Um carrega por um trecho, depois passa pro outro.

Integração por partes é assim: você tem um cálculo difícil. Você "passa" parte dele pro outro lado e a conta fica mais fácil. Depois que o outro lado carrega um trecho, você consegue terminar.

<Porta nivel="10" titulo="Pra criança de 10 anos">

Lembra que a derivada de um produto tem dois termos? Se $f = u \cdot v$, então $f' = u'v + uv'$.

Agora imagine que você integra os dois lados:

$uv = \int u'v\, dx + \int uv'\, dx$

Reorganizando: $\int uv'\, dx = uv - \int u'v\, dx$.

**Tradução prática:** quando você tem um produto pra integrar, você pode trocar por $uv$ menos uma **outra integral**. Se a nova integral for mais simples, você ganhou.

**Exemplo**: $\int x \sin x\, dx$. $x$ é algébrico (simplifica ao derivar: vira $1$). $\sin x$ tem antiderivada $-\cos x$.

Então $u = x$, $dv = \sin x\, dx$. Após a fórmula: $-x\cos x + \int \cos x\, dx = -x\cos x + \sin x + C$.

**Truque LIATE**: de Log, Inv-trig, Algébrico, Trig, Exp — a primeira que aparece vira $u$.

</Porta>

<Porta nivel="15" titulo="Pra adolescente de 15 anos">

A fórmula é $\int u\, dv = uv - \int v\, du$.

**Receita em 5 passos:**

1. Identifique produto no integrando.
2. Use **LIATE** para escolher $u$ (Log > Inv-trig > Algébrico > Trig > Exp).
3. O resto é $dv$. Calcule $du = u'\, dx$ e $v = \int dv$.
4. Aplique a fórmula.
5. Resolva $\int v\, du$ — deve ser mais simples.

**Três padrões fundamentais:**

**1.** $\int x e^x\, dx$: $u = x$ (Algébrico), $dv = e^x dx$. Resultado: $xe^x - e^x + C$.

**2.** $\int \ln x\, dx$: $u = \ln x$ (Log), $dv = dx$. Então $du = dx/x$, $v = x$. Resultado: $x \ln x - x + C$.

**3.** $\int e^x \cos x\, dx$: aplique duas vezes — a integral volta. Isole: resultado $e^x(\sin x + \cos x)/2 + C$.

**Quando NÃO usar partes**: se vê $\int x e^{x^2}\, dx$, é substituição (cadeia disfarçada), não partes.

</Porta>

<Porta nivel="25" titulo="Pra estudante de engenharia">

Partes resolve sistematicamente a classe **produto polinômio × (exp, trig, log, inv-trig)**.

### Tabela de padrões

| Integral | $u$ | Observação |
|---|---|---|
| $\int x^n e^{ax}\, dx$ | $x^n$ | Aplica $n$ vezes; método tabular acelera |
| $\int x^n \sin(ax)\, dx$ | $x^n$ | Idem |
| $\int x^n \ln x\, dx$ | $\ln x$ | Uma aplicação; resultado limpo |
| $\int e^{ax}\cos(bx)\, dx$ | qualquer | Duas aplicações + isola $I$ |
| $\int \arctan x\, dx$ | $\arctan x$ | $dv = dx$; $v = x$; depois sub |
| $\int \arcsin x\, dx$ | $\arcsin x$ | $dv = dx$; $v = x$; depois sub |

### Conexões fundamentais

- **Laplace**: $\mathcal{L}\{t\} = \int_0^\infty t e^{-st}\, dt = 1/s^2$ — calculado por partes.
- **Função Gama**: $\Gamma(n+1) = n \Gamma(n)$ — demonstrado via partes + $\Gamma(1) = 1$.
- **Coeficientes de Fourier**: $a_n = (1/\pi)\int_{-\pi}^\pi f(x)\cos(nx)\, dx$ — partes reduz quando $f$ é polinomial.
- **Transformada de Laplace de $t^n$**: $n!/(s^{n+1})$ — partes iterada.

### Método tabular detalhado

Para $\int x^3 e^x\, dx$:

| D | I | Sinal |
|---|---|---|
| $x^3$ | $e^x$ | + |
| $3x^2$ | $e^x$ | − |
| $6x$ | $e^x$ | + |
| $6$ | $e^x$ | − |
| $0$ | — | — |

Resultado: $x^3 e^x - 3x^2 e^x + 6x e^x - 6e^x + C = e^x(x^3 - 3x^2 + 6x - 6) + C$.

### Fórmulas de redução

Via partes: $\int \sin^n x\, dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n-1}{n}\int \sin^{n-2}x\, dx$.

Idem para $\cos^n$, $\sec^n$, $\csc^n$.

</Porta>

### Generalização: identidade de Green

Em dimensão $n$, integração por partes é:

$$\int_\Omega u\, \nabla \cdot \mathbf{F}\, dV = \int_{\partial\Omega} u\, \mathbf{F} \cdot \mathbf{n}\, dS - \int_\Omega \nabla u \cdot \mathbf{F}\, dV.$$

Para $\mathbf{F} = \nabla v$: primeira identidade de Green $\int u\, \Delta v = \oint u\, \partial_n v - \int \nabla u \cdot \nabla v$.

### Formulação fraca em FEM

A equação de Poisson $-\Delta u = f$ em $\Omega$ com $u|_{\partial\Omega} = 0$ — partes move a derivada pra função teste $v \in H^1_0$:

$$\int_\Omega \nabla u \cdot \nabla v\, dV = \int_\Omega f v\, dV \quad \forall v \in H^1_0(\Omega).$$

Sem essa transferência via partes, não existiria formulação variacional. FEniCS, Firedrake, deal.II implementam isso simbolicamente.

### Adjunto de operador diferencial

Em $L^2$ com condições de fronteira nulas: $\langle Du, v\rangle = -\langle u, Dv\rangle$ — $D = d/dx$ é antissimétrico. Generalizando, o adjunto formal de $L = \sum a_k \partial^k$ é $L^* = \sum (-1)^k \partial^k (a_k \cdot)$. Partes prova isso.

### Análise de Fourier e suavidade

Partes iterada prova: $|\hat{f}(n)| = O(n^{-k})$ se e somente se $f \in C^{k-1}$ com $f^{(k)} \in L^1$. Conexão entre suavidade no espaço físico e decaimento na frequência — central em teoria de wavelets e compressão.

### Mecânica quântica

Hermiticidade do momento $\hat{p} = -i\hbar\, \partial_x$ exige $\langle \psi_1 | \hat{p} \psi_2 \rangle = \langle \hat{p}\psi_1 | \psi_2 \rangle$, demonstrado via partes + condição de fronteira (função de onda decai a zero no infinito).

</Porta>

<Porta nivel="pratica" titulo="Aplicação prática">

**Receita completa:**

1. O integrando tem produto? Se sim, partes. Se não, considere substituição.
2. Aplique **LIATE** para $u$.
3. $du = u'\, dx$, $v = \int dv$.
4. $uv - \int v\, du$.
5. Se $\int v\, du$ ainda é produto: itera (ou usa tabela DI).
6. Se a integral voltou: isola $I$.
7. Confira: derive o resultado — deve reproduzir o integrando.

### Aplicações brasileiras

**Valor presente de fluxo crescente:** uma renda $C(t) = t$ mil reais por ano, taxa $r = 10\%$, por $T = 5$ anos:

$$VP = \int_0^5 t \cdot e^{-0{,}1 t}\, dt.$$

Por partes: $u = t$, $dv = e^{-0{,}1t}\, dt$. Resultado: aproximadamente 9,48 mil reais.

**Esperança de variável exponencial:** $E[X] = \int_0^\infty x \lambda e^{-\lambda x}\, dx = 1/\lambda$ — partes com $u = x$.

**Fórmula de Laplace para EDOs de circuitos:** $\mathcal{L}\{t^n\} = n!/s^{n+1}$ — partes iterada.

### Erros clássicos

- Esquecer o sinal negativo em $-\int v\, du$.
- Escolher $u$ que complica (contra-LIATE).
- Não iterar quando polinômio tem grau > 1.
- Esquecer $+ C$ na integral indefinida.

## Exemplos resolvidos

<Exemplo titulo="Integral canônica xeˣ (básico)" numero="1">

**Problema.** Calcule $\int x e^x\, dx$.

**Estratégia.** LIATE: $x$ é Algébrico, $e^x$ é Exponencial. $u = x$ (simplifica ao derivar), $dv = e^x\, dx$.

**Resolução.**

$du = dx$, $v = e^x$.

$$\int x e^x\, dx = x e^x - \int e^x\, dx = x e^x - e^x + C = e^x(x - 1) + C.$$

**Verificação.** Derive $e^x(x-1) + C$: regra do produto dá $e^x(x-1) + e^x = xe^x$. Correto.

**Fonte.** [Active Calculus §5.4, Activity 5.4.2](https://activecalculus.org/single/sec-5-4-parts.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Integral de ln x (truque dv = dx)" numero="2">

**Problema.** Calcule $\int \ln x\, dx$.

**Estratégia.** Logarítmico sozinho: $u = \ln x$, $dv = dx$ (escolha não óbvia mas correta).

**Resolução.**

$du = dx/x$, $v = x$.

$$\int \ln x\, dx = x \ln x - \int x \cdot \frac{1}{x}\, dx = x \ln x - \int 1\, dx = x \ln x - x + C.$$

**Verificação.** Derive $x \ln x - x$: $\ln x + x \cdot (1/x) - 1 = \ln x + 1 - 1 = \ln x$. Correto.

**Fonte.** [APEX Calculus §6.2, Example 6.2.2](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Polinômio x² com tabela DI (intermediário)" numero="3">

**Problema.** Calcule $\int x^2 e^x\, dx$ pelo método tabular.

**Estratégia.** Polinômio de grau 2 × exponencial: método DI (derivar $x^2$ até zero, integrar $e^x$ repetidamente).

**Resolução.**

| D | I | Sinal |
|---|---|---|
| $x^2$ | $e^x$ | + |
| $2x$ | $e^x$ | − |
| $2$ | $e^x$ | + |
| $0$ | — | — |

Somando produtos diagonais com sinais alternados:

$$\int x^2 e^x\, dx = x^2 e^x - 2x e^x + 2e^x + C = e^x(x^2 - 2x + 2) + C.$$

**Verificação.** Derivando $e^x(x^2 - 2x + 2)$: $e^x(x^2 - 2x + 2) + e^x(2x - 2) = e^x x^2$. Correto.

**Fonte.** [APEX Calculus §6.2, Example 6.2.4](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Truque: integral que volta (eˣ cos x)" numero="4">

**Problema.** Calcule $I = \int e^x \cos x\, dx$.

**Estratégia.** Duas aplicações de partes — a integral reaparecerá. Isolar $I$.

**Resolução.**

1.ª aplicação: $u = \cos x$, $dv = e^x\, dx$, $du = -\sin x\, dx$, $v = e^x$.

$$I = e^x \cos x + \int e^x \sin x\, dx.$$

2.ª aplicação: $u = \sin x$, $dv = e^x\, dx$, $du = \cos x\, dx$, $v = e^x$.

$$I = e^x \cos x + e^x \sin x - \int e^x \cos x\, dx = e^x \cos x + e^x \sin x - I.$$

Portanto $2I = e^x(\cos x + \sin x)$:

$$I = \frac{e^x(\sin x + \cos x)}{2} + C.$$

**Verificação.** Derivando: $\frac{e^x(\sin x + \cos x) + e^x(\cos x - \sin x)}{2} = \frac{2e^x \cos x}{2} = e^x \cos x$. Correto.

**Fonte.** [OpenStax Calculus Vol. 2, §3.1, Example 3.3](https://openstax.org/books/calculus-volume-2/pages/3-1-integration-by-parts) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Integral definida com partes (desafio)" numero="5">

**Problema.** Calcule $\int_0^\pi x \sin x\, dx$.

**Estratégia.** LIATE: $u = x$, $dv = \sin x\, dx$. Aplicar partes e avaliar nos limites.

**Resolução.**

$du = dx$, $v = -\cos x$.

$$\int_0^\pi x \sin x\, dx = [-x \cos x]_0^\pi + \int_0^\pi \cos x\, dx.$$

$[-x \cos x]_0^\pi = -\pi\cos\pi - 0 = -\pi(-1) = \pi$.

$\int_0^\pi \cos x\, dx = [\sin x]_0^\pi = 0 - 0 = 0$.

Portanto $\int_0^\pi x \sin x\, dx = \pi + 0 = \pi$.

**Verificação.** O resultado $\pi$ é clássico — confirma-se numericamente ($\approx 3{,}1416$). A assimetria do sinal de $x\sin x$ em $[0, \pi]$ (sempre positiva) garante resultado positivo.

**Fonte.** [Active Calculus §5.4, Exercise 5.4.3](https://activecalculus.org/single/sec-5-4-parts.html) — CC-BY-NC-SA.

</Exemplo>
