### Identidades fundamentais

<Definicao titulo="Identidades usadas em integrais trigonométricas">

As seguintes identidades são as ferramentas centrais:

- **Pitágoras:** $\sin^2 x + \cos^2 x = 1$; $1 + \tan^2 x = \sec^2 x$; $1 + \cot^2 x = \csc^2 x$.
- **Potência par (half-angle):**

<Equation explicacao="Reduz sin² e cos² a funções de ângulo duplo — indispensável para expoentes pares." latex="\sin^2 x = \frac{1 - \cos 2x}{2}, \qquad \cos^2 x = \frac{1 + \cos 2x}{2}." />

- **Produto para soma:** $\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$.

</Definicao>

### Padrões para $\int \sin^n x \cos^m x\, dx$

<Definicao titulo="Estratégia segundo paridade dos expoentes">

| Situação | Estratégia |
|---|---|
| $n$ ímpar | Reserve $\sin x\, dx$; converta $\sin^{n-1}$ via $\sin^2 = 1 - \cos^2$; substitua $u = \cos x$ |
| $m$ ímpar | Reserve $\cos x\, dx$; converta $\cos^{m-1}$ via $\cos^2 = 1 - \sin^2$; substitua $u = \sin x$ |
| Ambos pares | Use half-angle repetidamente |

Para $\int \tan^n x \sec^m x\, dx$:

| Situação | Estratégia |
|---|---|
| $m$ par | Reserve $\sec^2 x\, dx$; converta via $\sec^2 = 1 + \tan^2$; sub $u = \tan x$ |
| $n$ ímpar | Reserve $\sec x \tan x\, dx$; converta via $\tan^2 = \sec^2 - 1$; sub $u = \sec x$ |

</Definicao>

> "The strategy for integrating a product of powers of sine and cosine depends on the parities of the exponents involved. When one of the exponents is odd, we 'peel off' one factor and use the Pythagorean identity to convert the remaining even power." — [OpenStax Calculus Vol. 2, §3.2](https://openstax.org/books/calculus-volume-2/pages/3-2-trigonometric-integrals)

> "The idea behind trigonometric substitution is to replace an expression involving a square root with a trigonometric expression, which is easier to integrate." — [APEX Calculus §6.4](https://www.apexcalculus.com/apex-calculus-v5.pdf)

### Fórmulas de redução

<Teorema titulo="Fórmula de redução para sinⁿ">

$$\int \sin^n x\, dx = -\frac{\sin^{n-1}x \cos x}{n} + \frac{n-1}{n}\int \sin^{n-2}x\, dx.$$

Análogas existem para $\cos^n$, $\tan^n$, $\sec^n$, $\csc^n$.

**Demonstração:** partes com $u = \sin^{n-1}x$, $dv = \sin x\, dx$, mais identidade $\sin^2 = 1 - \cos^2$.

</Teorema>

<Insight>

**Substituição de Weierstrass** (universal): $t = \tan(x/2)$ converte qualquer integral racional em $\sin x$, $\cos x$ em uma integral racional em $t$. Via frações parciais, tudo fica elementar — mas o resultado pode ser complicado. Use quando as outras estratégias falham.

</Insight>

<Porta nivel="5" titulo="Pra criança de 5 anos">

Sabe quando você usa um figurino de fantasma pra ninguém reconhecer você, e depois tira? Substituição trig é assim.

Você tem $\sqrt{1 - x^2}$ — difícil de trabalhar. Troca $x$ por $\sin\theta$ — disfarça! O radical desaparece e fica $\cos\theta$. Depois de calcular com $\theta$, tira o disfarce e volta pra $x$.

</Porta>

<Porta nivel="10" titulo="Pra criança de 10 anos">

Tem uma identidade que você conhece: $\sin^2\theta + \cos^2\theta = 1$.

Isso significa que $\sqrt{1 - \sin^2\theta} = \cos\theta$ (assumindo que $\cos\theta \geq 0$).

Então se você tem $\sqrt{1 - x^2}$ e faz $x = \sin\theta$, o radical desaparece e vira $\cos\theta$.

Depois de integrar com $\theta$, você usa um triângulo: se $\sin\theta = x$ e a hipotenusa é 1, o cateto adjacente é $\sqrt{1 - x^2}$. Isso te dá $\cos\theta$, $\tan\theta$, etc. em termos de $x$ — e você "desfaz" a substituição.

</Porta>

<Porta nivel="15" titulo="Pra adolescente de 15 anos">

### Potências de seno e cosseno

**Caso 1 (expoente ímpar):** $\int \sin^3 x\, dx$.

Reserve um $\sin x\, dx$, converta o resto: $\sin^2 x = 1 - \cos^2 x$.

$\int (1 - \cos^2 x)\sin x\, dx$. Sub $u = \cos x$: $-\int(1 - u^2)\, du = -u + u^3/3 + C = -\cos x + \cos^3 x/3 + C$.

**Caso 2 (expoentes pares):** $\int \sin^2 x\, dx$.

Use half-angle: $\int \frac{1 - \cos 2x}{2}\, dx = \frac{x}{2} - \frac{\sin 2x}{4} + C$.

### Substituição trigonométrica

**Exemplo:** $\int \sqrt{1 - x^2}\, dx$.

Sub $x = \sin\theta$, $dx = \cos\theta\, d\theta$, $\sqrt{1-x^2} = \cos\theta$.

Integral vira $\int \cos^2\theta\, d\theta = \theta/2 + \sin(2\theta)/4 + C$.

Volte: $\theta = \arcsin x$, $\sin(2\theta) = 2\sin\theta\cos\theta = 2x\sqrt{1-x^2}$.

Resultado: $\dfrac{\arcsin x}{2} + \dfrac{x\sqrt{1-x^2}}{2} + C$.

**Triângulo de referência:** sempre desenhe — é a chave para converter as funções trig de $\theta$ de volta para $x$.

</Porta>

<Porta nivel="25" titulo="Pra estudante de engenharia">

### Tabela mental de integrais básicas

- $\int \sin^2 x\, dx = (x - \sin x\cos x)/2 + C$.
- $\int \cos^2 x\, dx = (x + \sin x\cos x)/2 + C$.
- $\int \tan x\, dx = -\ln\lvert\cos x\rvert + C = \ln\lvert\sec x\rvert + C$.
- $\int \cot x\, dx = \ln\lvert\sin x\rvert + C$.
- $\int \sec x\, dx = \ln\lvert\sec x + \tan x\rvert + C$.
- $\int \csc x\, dx = -\ln\lvert\csc x + \cot x\rvert + C$.
- $\int \sec^2 x\, dx = \tan x + C$; $\int \csc^2 x\, dx = -\cot x + C$.
- $\int \sec x\tan x\, dx = \sec x + C$.

### Conexões de engenharia

- **RMS de senóide:** $V_{rms} = V_0/\sqrt{2}$ — via $\int_0^T \sin^2(\omega t)\, dt = T/2$.
- **Distribuição de Cauchy:** $\int_{-\infty}^\infty 1/(\pi(1+x^2))\, dx = 1$ — sub $x = \tan\theta$.
- **Comprimento de arco de elipse:** $\int \sqrt{1 - k^2\sin^2\theta}\, d\theta$ — integral elíptica, sem fórmula fechada.
- **Coeficientes de Fourier:** $a_n = (1/\pi)\int_{-\pi}^\pi f(x)\cos(nx)\, dx$ — para $f$ trig, cálculo direto por identidades.

### Euler e identidade complexa

Potências de $\sin x$ e $\cos x$ são computáveis via Euler: $\sin x = (e^{ix} - e^{-ix})/(2i)$, $\cos x = (e^{ix} + e^{-ix})/2$. Expansão binomial + integração de exponenciais complexas, depois parte real/imaginária.

</Porta>

<Porta nivel="40" titulo="Pra profissional sênior">

### Substituição de Weierstrass (universal)

$t = \tan(x/2)$ transforma qualquer função racional em $\sin x$ e $\cos x$ em racional em $t$:

$$\sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2\,dt}{1+t^2}.$$

A integral resultante resolve-se por frações parciais. Porém o resultado pode ser mais complicado do que métodos diretos — use quando outras estratégias falham ou em CAS.

### Integrais elípticas

$\int \sqrt{1 - k^2\sin^2\theta}\, d\theta = E(k)$ e $\int d\theta/\sqrt{1 - k^2\sin^2\theta} = K(k)$ — integrais elípticas de Legendre. Não são elementares para $k \neq 0$. Surgem em comprimento de elipse, pêndulo exato, gravitação.

### Análise de Fourier

Os coeficientes $a_n, b_n$ de uma série de Fourier generalizada computam-se via integrais trig. A suavidade de $f$ controla o decaimento de $|a_n|$, $|b_n|$ — análise de Fourier conecta integrais trig a teoria de aproximação.

### Geometria diferencial

Comprimento de arco $L = \int \sqrt{1 + (f')^2}\, dx$ envolve sub trig quando $f' = \tan\theta$. Curvatura $\kappa = |f''|/(1 + (f')^2)^{3/2}$ aparece integrada ao computar o comprimento de arco em coordenadas naturais. Sub trig em múltiplas variáveis: coordenadas esféricas e cilíndricas são Jacobianas trig.

</Porta>

<Porta nivel="pratica" titulo="Aplicação prática">

**Receita para integrais trig:**

1. Veja os expoentes de $\sin$ e $\cos$.
2. Algum ímpar? Reserve uma cópia desse fator com seu $dx$, converta o resto.
3. Ambos pares? Use $\sin^2 = (1 - \cos 2x)/2$ e $\cos^2 = (1 + \cos 2x)/2$.
4. Radical $\sqrt{a^2 \pm x^2}$ ou $\sqrt{x^2 - a^2}$? Aplique sub trig da tabela.
5. Após sub trig, desenhe o triângulo de referência para voltar a $x$.
6. Confira derivando.

### Área do círculo — validação canônica

$A = 4\int_0^r \sqrt{r^2 - x^2}\, dx$. Sub $x = r\sin\theta$: integral vira $4r^2\int_0^{\pi/2}\cos^2\theta\, d\theta = 4r^2\cdot\pi/4 = \pi r^2$.

### RMS de senóide — circuitos

Tensão $v(t) = V_0\sin(\omega t)$ em um período $T = 2\pi/\omega$:

$$V_{rms} = \sqrt{\frac{1}{T}\int_0^T V_0^2\sin^2(\omega t)\, dt} = V_0\sqrt{\frac{1}{2}} = \frac{V_0}{\sqrt{2}} \approx 0{,}707\, V_0.$$

### Erros comuns

- Esquecer a Jacobiana $dx \to a\cos\theta\, d\theta$ (ou $a\sec^2\theta\, d\theta$) — causa fator $a$ faltando.
- Não voltar de $\theta$ para $x$ com triângulo.
- Confundir $\sin^2 x$ (potência) com $\sin(2x)$ (ângulo dobrado).
- Em $x = a\sec\theta$, esquecer o ramo correto de $\theta$.

</Porta>

## Exemplos resolvidos

<Exemplo titulo="Potência ímpar de seno (básico)" numero="1">

**Problema.** Calcule $\int \sin^3 x\, dx$.

**Estratégia.** Expoente ímpar: reserve $\sin x\, dx$, converta $\sin^2 = 1 - \cos^2$, substitua $u = \cos x$.

**Resolução.**

$\int \sin^3 x\, dx = \int \sin^2 x \cdot \sin x\, dx = \int (1 - \cos^2 x)\sin x\, dx$.

Sub $u = \cos x$, $du = -\sin x\, dx$:

$-\int (1 - u^2)\, du = -u + u^3/3 + C = -\cos x + \frac{\cos^3 x}{3} + C$.

**Verificação.** Derivando: $\sin x - \cos^2 x\sin x = \sin x(1 - \cos^2 x) = \sin^3 x$. Correto.

**Fonte.** [APEX Calculus §6.3, Example 6.3.1](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Expoentes pares — half-angle (básico)" numero="2">

**Problema.** Calcule $\int \sin^2 x \cos^2 x\, dx$.

**Estratégia.** Ambos pares: use $\sin x\cos x = \sin(2x)/2$ e depois half-angle.

**Resolução.**

$\sin^2 x\cos^2 x = (\sin x\cos x)^2 = \frac{\sin^2(2x)}{4} = \frac{1}{4}\cdot\frac{1 - \cos 4x}{2} = \frac{1 - \cos 4x}{8}$.

$$\int \sin^2 x\cos^2 x\, dx = \frac{x}{8} - \frac{\sin 4x}{32} + C.$$

**Verificação.** Derivando: $1/8 - \cos(4x)/8 = (1 - \cos 4x)/8 = \sin^2(2x)/4 = \sin^2 x\cos^2 x$. Correto.

**Fonte.** [OpenStax Calculus Vol. 2, §3.2, Example 3.12](https://openstax.org/books/calculus-volume-2/pages/3-2-trigonometric-integrals) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Substituição x = a sin θ para √(a² − x²) (intermediário)" numero="3">

**Problema.** Calcule $\int \sqrt{4 - x^2}\, dx$.

**Estratégia.** Radical $\sqrt{a^2 - x^2}$ com $a = 2$: sub $x = 2\sin\theta$.

**Resolução.**

$dx = 2\cos\theta\, d\theta$; $\sqrt{4 - x^2} = \sqrt{4 - 4\sin^2\theta} = 2\cos\theta$ (com $\theta \in [-\pi/2, \pi/2]$).

$\int 2\cos\theta \cdot 2\cos\theta\, d\theta = 4\int\cos^2\theta\, d\theta = 4\cdot\frac{\theta + \sin\theta\cos\theta}{2} = 2\theta + 2\sin\theta\cos\theta + C$.

Triângulo de referência ($\sin\theta = x/2$, hipotenusa 2, cateto adjacente $\sqrt{4-x^2}$):

$\theta = \arcsin(x/2)$; $\cos\theta = \sqrt{4-x^2}/2$.

Resultado: $2\arcsin(x/2) + 2\cdot\frac{x}{2}\cdot\frac{\sqrt{4-x^2}}{2} + C = 2\arcsin(x/2) + \frac{x\sqrt{4-x^2}}{2} + C$.

**Verificação.** Derivando (regra da cadeia): $\frac{2}{\sqrt{4-x^2}} + \frac{\sqrt{4-x^2} - x^2/\sqrt{4-x^2}}{2} = \frac{2}{\sqrt{4-x^2}} + \frac{4 - 2x^2}{2\sqrt{4-x^2}} = \sqrt{4-x^2}$. Correto.

**Fonte.** [APEX Calculus §6.4, Example 6.4.2](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Substituição x = a tan θ para √(a² + x²) (intermediário)" numero="4">

**Problema.** Calcule $\int \dfrac{1}{\sqrt{1 + x^2}}\, dx$.

**Estratégia.** Radical $\sqrt{a^2 + x^2}$ com $a = 1$: sub $x = \tan\theta$.

**Resolução.**

$dx = \sec^2\theta\, d\theta$; $\sqrt{1+x^2} = \sec\theta$.

$\int \frac{\sec^2\theta}{\sec\theta}\, d\theta = \int \sec\theta\, d\theta = \ln\lvert\sec\theta + \tan\theta\rvert + C$.

Triângulo ($\tan\theta = x$, hipotenusa $\sqrt{1+x^2}$): $\sec\theta = \sqrt{1+x^2}$, $\tan\theta = x$.

Resultado: $\ln\lvert x + \sqrt{1+x^2}\rvert + C$ (equivalente a $\text{arcsinh}(x) + C$).

**Verificação.** Derivando $\ln(x + \sqrt{1+x^2})$: $\frac{1 + x/\sqrt{1+x^2}}{x + \sqrt{1+x^2}} = \frac{(\sqrt{1+x^2}+x)/\sqrt{1+x^2}}{x+\sqrt{1+x^2}} = \frac{1}{\sqrt{1+x^2}}$. Correto.

**Fonte.** [OpenStax Calculus Vol. 2, §3.3, Example 3.15](https://openstax.org/books/calculus-volume-2/pages/3-3-trigonometric-substitution) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Fórmula de redução e aplicação (desafio)" numero="5">

**Problema.** Derive a fórmula de redução $\int \sin^n x\, dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n-1}{n}\int\sin^{n-2}x\, dx$ e use-a para calcular $\int_0^{\pi/2}\sin^4 x\, dx$.

**Estratégia.** Derivar por partes; aplicar para $n = 4$ e $n = 2$.

**Resolução.**

**Derivação:** $u = \sin^{n-1}x$, $dv = \sin x\, dx$. $du = (n-1)\sin^{n-2}x\cos x\, dx$, $v = -\cos x$.

$\int\sin^n x\, dx = -\sin^{n-1}x\cos x + (n-1)\int\cos^2 x\sin^{n-2}x\, dx$.

Substitua $\cos^2 x = 1 - \sin^2 x$:

$(n-1)\int(1 - \sin^2 x)\sin^{n-2}x\, dx = (n-1)\int\sin^{n-2}x\, dx - (n-1)\int\sin^n x\, dx$.

Reorganize: $n\int\sin^n x\, dx = -\sin^{n-1}x\cos x + (n-1)\int\sin^{n-2}x\, dx$. Divida por $n$.

**Aplicação:** $n = 4$: $\int\sin^4 x\, dx = -\frac{\sin^3 x\cos x}{4} + \frac{3}{4}\int\sin^2 x\, dx$.

$\int\sin^2 x\, dx = x/2 - \sin(2x)/4$.

Avaliando em $[0, \pi/2]$: $\int_0^{\pi/2}\sin^4 x\, dx = 0 + \frac{3}{4}\left[\frac{\pi}{4} - 0\right] = \frac{3\pi}{16}$.

**Verificação.** Fórmula de Wallis: $\int_0^{\pi/2}\sin^4 x\, dx = \frac{3\cdot 1}{4\cdot 2}\cdot\frac{\pi}{2} = \frac{3\pi}{16}$. Confirma.

**Fonte.** [APEX Calculus §6.3, Theorem 6.3.1](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>
