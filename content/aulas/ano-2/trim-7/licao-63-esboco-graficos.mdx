<Porta nivel="formal" titulo="Pipeline de análise gráfica">

### Os oito passos formais

<Definicao titulo="Pipeline de esboço via cálculo">

1. **Domínio** <Eq>{`D \\subseteq \\mathbb{R}`}</Eq>: onde <Eq>{`f`}</Eq> está definida. Identifique zeros do denominador, radicandos negativos, logaritmos de não-positivos.

2. **Interceptos:** <Eq>{`f(0)`}</Eq> (intercepto vertical); raízes de <Eq>{`f(x) = 0`}</Eq> (interceptos horizontais, quando acessíveis).

3. **Simetrias:** <Eq>{`f(-x) = f(x)`}</Eq> → par (gráfico simétrico em relação ao eixo <Eq>{`y`}</Eq>); <Eq>{`f(-x) = -f(x)`}</Eq> → ímpar (simétrico em relação à origem); periodicidade.

4. **Assíntotas:**
   - **Vertical** em <Eq>{`x = a`}</Eq>: <Eq>{`\\lim_{x \\to a^\\pm} f(x) = \\pm\\infty`}</Eq>.
   - **Horizontal** <Eq>{`y = L`}</Eq>: <Eq>{`\\lim_{x \\to \\pm\\infty} f(x) = L`}</Eq>.
   - **Oblíqua** <Eq>{`y = mx + b`}</Eq>: <Eq>{`m = \\lim_{x \\to \\infty} f(x)/x`}</Eq> e <Eq>{`b = \\lim_{x \\to \\infty}(f(x) - mx)`}</Eq>.

5. **Primeira derivada** <Eq>{`f'`}</Eq>: encontre pontos críticos. Tabela de sinais → intervalos de crescimento (<Eq>{`f' > 0`}</Eq>) e decrescimento (<Eq>{`f' < 0`}</Eq>), extremos locais.

6. **Segunda derivada** <Eq>{`f''`}</Eq>: encontre pontos candidatos a inflexão (<Eq>{`f'' = 0`}</Eq> ou inexistente). Tabela de sinais → concavidade para cima (<Eq>{`f'' > 0`}</Eq>) ou para baixo (<Eq>{`f'' < 0`}</Eq>).

7. **Ponto de inflexão:** ponto <Eq>{`c`}</Eq> onde <Eq>{`f''`}</Eq> **muda de sinal** (a concavidade troca).

8. **Esboço:** marque interceptos, assíntotas (linhas tracejadas), extremos e inflexões; desenhe a curva respeitando crescimento e concavidade em cada intervalo.

</Definicao>

> "If f'(x) > 0 on an interval, then f is increasing on that interval. If f''(x) > 0, then f is concave up. These two pieces of information, combined with critical and inflection points, give a complete picture of the graph." — [OpenStax Calculus Vol. 1, §4.5](https://openstax.org/books/calculus-volume-1/pages/4-5-derivatives-and-the-shape-of-a-graph)

### Tabela de comportamento combinado

| <Eq>{`f'`}</Eq> | <Eq>{`f''`}</Eq> | Comportamento |
|---|---|---|
| <Eq>{`> 0`}</Eq> | <Eq>{`> 0`}</Eq> | crescente, côncava para cima |
| <Eq>{`> 0`}</Eq> | <Eq>{`< 0`}</Eq> | crescente, côncava para baixo |
| <Eq>{`< 0`}</Eq> | <Eq>{`> 0`}</Eq> | decrescente, côncava para cima |
| <Eq>{`< 0`}</Eq> | <Eq>{`< 0`}</Eq> | decrescente, côncava para baixo |

### Definição de concavidade e inflexão

<Definicao titulo="Concavidade">

<Eq>{`f`}</Eq> é **côncava para cima** em <Eq>{`I`}</Eq> se <Eq>{`f''(x) > 0`}</Eq> para todo <Eq>{`x \\in I`}</Eq> — a curva fica acima de qualquer tangente. <Eq>{`f`}</Eq> é **côncava para baixo** em <Eq>{`I`}</Eq> se <Eq>{`f''(x) < 0`}</Eq>.

</Definicao>

<Definicao titulo="Ponto de inflexão">

<Eq>{`c`}</Eq> é **ponto de inflexão** de <Eq>{`f`}</Eq> se <Eq>{`f`}</Eq> é contínua em <Eq>{`c`}</Eq> e <Eq>{`f''`}</Eq> muda de sinal em <Eq>{`c`}</Eq>.

</Definicao>

<Insight>

<Eq>{`f''(c) = 0`}</Eq> é necessário mas não suficiente para ponto de inflexão. Exemplo: <Eq>{`f(x) = x^4`}</Eq> tem <Eq>{`f''(0) = 0`}</Eq>, mas a concavidade não muda em <Eq>{`0`}</Eq> — não é inflexão.

</Insight>

<Porta nivel="5" titulo="Para uma criança de 5 anos">

Imagina que você está desenhando uma estrada montanhosa. A estrada às vezes sobe, às vezes desce.

Quando sobe, a derivada é positiva. Quando desce, é negativa. No topo da montanha ela para um instante antes de descer — esse é o ponto especial.

Agora olhe a curvatura da estrada. Às vezes a estrada **curve para cima** (como uma tigela) e às vezes **curve para baixo** (como uma cúpula). O lugar onde a curva troca é um ponto de inflexão.

Antes de desenhar qualquer coisa, é inteligente descobrir esses lugares especiais. Depois é só conectar os pontos!

</Porta>

<Porta nivel="10" titulo="Para uma criança de 10 anos">

Para fazer um bom esboço de <Eq>{`f(x)`}</Eq>, siga essa lista:

1. Onde a função existe? (Domínio)
2. Onde ela cruza os eixos? (<Eq>{`f(0)`}</Eq> e onde <Eq>{`f(x) = 0`}</Eq>)
3. Ela vai para o infinito em algum lugar? (Assíntotas)
4. Onde ela **sobe** (<Eq>{`f' > 0`}</Eq>) ou **desce** (<Eq>{`f' < 0`}</Eq>)?
5. Onde ela **curva pra cima** (<Eq>{`f'' > 0`}</Eq>) ou **pra baixo** (<Eq>{`f'' < 0`}</Eq>)?

Com esses 5 itens respondidos, o desenho praticamente se faz sozinho!

</Porta>

<Porta nivel="15" titulo="Para o estudante do ensino médio">

**O pipeline de esboço** tem 8 passos. Você pode memorizá-los com a sigla **DISSECF** (Domínio, Interceptos, Simetria, Sinal de <Eq>{`f'`}</Eq>, Extremos, Concavidade, Inflexões, Figura).

**Passo crítico — a tabela de sinais:** divida a reta real nos pontos críticos e inflexão. Em cada intervalo, determine se <Eq>{`f' > 0`}</Eq> ou <Eq>{`< 0`}</Eq> e se <Eq>{`f'' > 0`}</Eq> ou <Eq>{`< 0`}</Eq>. Isso determina completamente o comportamento da curva em cada trecho.

**Assíntota oblíqua:** ocorre quando grau do numerador = grau do denominador + 1 em funções racionais. Faça divisão polinomial para achar <Eq>{`y = mx + b`}</Eq>.

**Inflexão ≠ ponto crítico:** extremos locais têm <Eq>{`f' = 0`}</Eq>; inflexões têm <Eq>{`f'' = 0`}</Eq> (com mudança de sinal). Um ponto pode ser ambos (raro).

</Porta>

<Porta nivel="25" titulo="Para o estudante de engenharia">

O esboço via cálculo é a **análise qualitativa completa** de uma função, combinando:

**Teorema do Valor Médio (TVM):** fundamenta que <Eq>{`f' > 0`}</Eq> implica crescimento estrito. Sem o TVM, apenas saber que <Eq>{`f'(c) > 0`}</Eq> num ponto não garante crescimento em intervalo.

**Concavidade e f'':** se <Eq>{`f''`}</Eq> existe e é positiva em <Eq>{`I`}</Eq>, então <Eq>{`f'`}</Eq> é crescente em <Eq>{`I`}</Eq> — a função está "acelerando". Em análise numérica, a concavidade afeta a precisão de métodos de integração (regra do trapézio superestima quando <Eq>{`f'' < 0`}</Eq>).

**Assíntotas oblíquas:** <Eq>{`f(x) = P(x)/Q(x)`}</Eq> com <Eq>{`\\deg P = \\deg Q + 1`}</Eq>: faça divisão euclidiana. O quociente é a assíntota oblíqua; o resto <Eq>{`\\to 0`}</Eq> quando <Eq>{`x \\to \\infty`}</Eq>.

**Curva em engenharia:** análise de sinais (diagramas de Bode), curvas de carga-deslocamento em estruturas, e curvas P-V em termodinâmica são aplicações diretas desta análise qualitativa — substitui cálculo numérico pesado quando o comportamento qualitativo basta.

</Porta>

<Porta nivel="40" titulo="Para o profissional sênior">

A **Kurvendiskussion** (discussão de curva) alemã, obrigatória no Abitur, é exatamente este pipeline — um dos raros temas onde curricula alemão, japonês e singaporiano convergem em detalhe. Representa a síntese operacional do cálculo diferencial de uma variável.

Historicamente, Leibniz e Johann Bernoulli já usavam a segunda derivada para classificar extremos no século XVII. A formalização moderna — incluindo concavidade como propriedade global (não pontual) — veio com Cauchy e Weierstrass no século XIX, quando a análise substituiu o argumento geométrico intuitivo pelo argumento analítico rigoroso.

Em finanças quantitativas, a **convexidade** de um portfólio de bonds é exatamente a segunda derivada do preço em relação à taxa de juros. Gestores de risco usam convexidade (positiva ou negativa) para precificar a curvatura de payoffs — diretamente análoga à análise de <Eq>{`f''`}</Eq> nesta lição.

Em machine learning, a análise de perda (loss surface) via gradiente (<Eq>{`f'`}</Eq>) e Hessiana (<Eq>{`f''`}</Eq> em dimensão alta) é a extensão direta. Pontos de sela (onde o gradiente some mas não é mínimo) são o pesadelo dos otimizadores — análogo exato ao <Eq>{`f'(c) = 0`}</Eq> sem extremo, já visto em L61.

</Porta>

<Porta nivel="pratica" titulo="Aplicação prática brasileira">

**Análise de curva de produção agrícola.** A produção de soja por hectare, em função da quantidade de fertilizante aplicado, tem comportamento típico:

<Eq display>{`P(x) = -0{,}01x^3 + 0{,}6x^2 - 2x + 10, \quad x \in [0, 40]`}</Eq>

onde <Eq>{`x`}</Eq> é kg de fertilizante por hectare e <Eq>{`P`}</Eq> são sacas por hectare.

<Eq display>{`P'(x) = -0{,}03x^2 + 1{,}2x - 2`}</Eq>

Zeros de <Eq>{`P'`}</Eq>: discriminante <Eq>{`1{,}44 - 0{,}24 = 1{,}20`}</Eq>. Raízes: <Eq>{`x \\approx 1{,}84`}</Eq> e <Eq>{`x \\approx 38{,}16`}</Eq>. No intervalo <Eq>{`[0, 40]`}</Eq>: produção cresce de <Eq>{`x \\approx 1{,}84`}</Eq> até <Eq>{`x \\approx 38{,}16`}</Eq>.

<Eq>{`P''(x) = -0{,}06x + 1{,}2 = 0 \\Rightarrow x = 20`}</Eq> — ponto de inflexão onde a taxa de crescimento começa a cair (produtividade marginal decrescente, princípio fundamental da microeconomia agrária).

**Leitura prática:** aplicar até 38 kg/hectare aumenta a produção; além disso, excesso de fertilizante começa a prejudicar. O ponto de inflexão em 20 kg indica onde a produtividade marginal é máxima.

</Porta>

## Exemplos resolvidos

<Exemplo titulo="Esboço completo de polinômio cúbico">

**Problema.** Faça o esboço completo de <Eq>{`f(x) = x^3 - 3x`}</Eq>.

**Estratégia.** Aplicar os 8 passos do pipeline.

**Resolução.**

1. **Domínio:** <Eq>{`\\mathbb{R}`}</Eq>.
2. **Interceptos:** <Eq>{`f(0) = 0`}</Eq>. Raízes: <Eq>{`x(x^2-3) = 0 \\Rightarrow x = 0, \\pm\\sqrt{3}`}</Eq>.
3. **Simetria:** <Eq>{`f(-x) = -x^3 + 3x = -f(x)`}</Eq> → ímpar.
4. **Assíntotas:** nenhuma (polinômio).
5. **<Eq>{`f'(x) = 3x^2 - 3 = 3(x-1)(x+1)`}</Eq>**. Pontos críticos: <Eq>{`x = \\pm 1`}</Eq>. Crescente em <Eq>{`(-\\infty,-1)`}</Eq> e <Eq>{`(1,\\infty)`}</Eq>; decrescente em <Eq>{`(-1,1)`}</Eq>. Máx local <Eq>{`f(-1) = 2`}</Eq>; mín local <Eq>{`f(1) = -2`}</Eq>.
6. **<Eq>{`f''(x) = 6x`}</Eq>**. Zero em <Eq>{`x = 0`}</Eq>. Côncava para baixo em <Eq>{`x < 0`}</Eq>; para cima em <Eq>{`x > 0`}</Eq>.
7. **Inflexão:** <Eq>{`x = 0`}</Eq> (mudança de sinal de <Eq>{`f''`}</Eq>). Ponto: <Eq>{`(0, 0)`}</Eq>.
8. **Esboço:** curva em "S" passando pela origem, máximo em <Eq>{`(-1, 2)`}</Eq>, mínimo em <Eq>{`(1, -2)`}</Eq>.

**Verificação.** Pela simetria ímpar, o gráfico é simétrico em relação à origem — os valores conferem.

**Fonte.** [OpenStax Calculus Vol. 1, §4.5, Example 4.20](https://openstax.org/books/calculus-volume-1/pages/4-5-derivatives-and-the-shape-of-a-graph) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="Função racional com assíntota horizontal">

**Problema.** Esboce <Eq>{`f(x) = \\dfrac{x^2}{x^2 + 1}`}</Eq>.

**Estratégia.** Identificar assíntotas, usar <Eq>{`f'`}</Eq> e <Eq>{`f''`}</Eq>.

**Resolução.**

1. **Domínio:** <Eq>{`\\mathbb{R}`}</Eq> (denominador nunca nulo).
2. **Intercepto:** <Eq>{`f(0) = 0`}</Eq>. Única raiz: <Eq>{`x = 0`}</Eq>.
3. **Simetria:** <Eq>{`f(-x) = f(x)`}</Eq> → par.
4. **Assíntota horizontal:** <Eq>{`\\lim_{x \\to \\pm\\infty} x^2/(x^2+1) = 1`}</Eq>. Reta <Eq>{`y = 1`}</Eq>.
5. **<Eq>{`f'(x) = 2x/(x^2+1)^2`}</Eq>**. Positivo para <Eq>{`x > 0`}</Eq>, negativo para <Eq>{`x < 0`}</Eq>. Mínimo local em <Eq>{`x = 0`}</Eq> (por sinal: <Eq>{`f'`}</Eq> muda de <Eq>{`-`}</Eq> para <Eq>{`+`}</Eq>).
6. **<Eq>{`f''(x) = (2(x^2+1)^2 - 2x \\cdot 2(x^2+1)\\cdot 2x)/(x^2+1)^4 = 2(1-3x^2)/(x^2+1)^3`}</Eq>**. Zero: <Eq>{`x = \\pm 1/\\sqrt{3}`}</Eq>.
7. **Inflexões em** <Eq>{`x = \\pm 1/\\sqrt{3}`}</Eq>. <Eq>{`f'' > 0`}</Eq> em <Eq>{`|x| < 1/\\sqrt{3}`}</Eq>; <Eq>{`f'' < 0`}</Eq> em <Eq>{`|x| > 1/\\sqrt{3}`}</Eq>.
8. Curva simétrica, parte de 0, cresce assintoticamente para 1.

**Verificação.** <Eq>{`0 \\leq f(x) < 1`}</Eq> para todo <Eq>{`x`}</Eq> — consistente com assíntota horizontal em 1.

**Fonte.** [APEX Calculus §3.5, Example 3.5.2](https://www.apexcalculus.com/) · CC-BY-NC

</Exemplo>

<Exemplo titulo="Função com assíntota vertical e horizontal">

**Problema.** Esboce <Eq>{`f(x) = \\dfrac{2x}{x - 1}`}</Eq>.

**Estratégia.** Identificar assíntota vertical (<Eq>{`x = 1`}</Eq>) e horizontal, depois analisar <Eq>{`f'`}</Eq>.

**Resolução.**

1. **Domínio:** <Eq>{`\\mathbb{R} \\setminus \\{1\\}`}</Eq>.
2. **Interceptos:** <Eq>{`f(0) = 0`}</Eq>; raiz: <Eq>{`x = 0`}</Eq>.
3. **Assíntota vertical:** <Eq>{`x = 1`}</Eq> (<Eq>{`f \\to \\pm\\infty`}</Eq>).
4. **Assíntota horizontal:** <Eq>{`\\lim_{x \\to \\pm\\infty} 2x/(x-1) = 2`}</Eq>. Reta <Eq>{`y = 2`}</Eq>.
5. **<Eq>{`f'(x) = (2(x-1) - 2x)/(x-1)^2 = -2/(x-1)^2 < 0`}</Eq>** para todo <Eq>{`x \\neq 1`}</Eq>. Função estritamente decrescente em cada ramo.
6. **<Eq>{`f''(x) = 4/(x-1)^3`}</Eq>**. Positivo para <Eq>{`x > 1`}</Eq> (côncava para cima); negativo para <Eq>{`x < 1`}</Eq> (côncava para baixo).
7. **Sem inflexões** (denominador nunca nulo fora de <Eq>{`x = 1`}</Eq>).
8. Dois ramos: <Eq>{`x < 1`}</Eq> (decrescente, côncava para baixo) e <Eq>{`x > 1`}</Eq> (decrescente, côncava para cima).

**Verificação.** <Eq>{`f`}</Eq> nunca cruza a assíntota <Eq>{`y = 2`}</Eq> (verificar: <Eq>{`2x/(x-1) = 2 \\Rightarrow 2x = 2x - 2`}</Eq>, impossível).

**Fonte.** [Active Calculus §3.2, Activity 3.2.3](https://activecalculus.org/single/sec-3-4-families.html) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="Ponto de inflexão e concavidade">

**Problema.** Determine os pontos de inflexão e os intervalos de concavidade de <Eq>{`f(x) = x^4 - 6x^2`}</Eq>.

**Estratégia.** Calcular <Eq>{`f''`}</Eq>, encontrar zeros, verificar mudança de sinal.

**Resolução.**

<Eq display>{`f'(x) = 4x^3 - 12x, \quad f''(x) = 12x^2 - 12 = 12(x-1)(x+1)`}</Eq>

Zeros de <Eq>{`f''`}</Eq>: <Eq>{`x = \\pm 1`}</Eq>.

- <Eq>{`x < -1`}</Eq>: <Eq>{`f'' > 0`}</Eq> → côncava para cima.
- <Eq>{`-1 < x < 1`}</Eq>: <Eq>{`f'' < 0`}</Eq> → côncava para baixo.
- <Eq>{`x > 1`}</Eq>: <Eq>{`f'' > 0`}</Eq> → côncava para cima.

Inflexões em <Eq>{`x = -1`}</Eq> e <Eq>{`x = 1`}</Eq>: <Eq>{`f(-1) = 1 - 6 = -5`}</Eq>, <Eq>{`f(1) = -5`}</Eq>.

**Verificação.** Teste de mudança de sinal de <Eq>{`f''`}</Eq> confirmado. Nota: <Eq>{`f(x) = x^4 - 6x^2`}</Eq> tem <Eq>{`f''(0) = -12 < 0`}</Eq> e <Eq>{`f''(2) = 36 > 0`}</Eq>, consistente.

**Fonte.** [OpenStax Calculus Vol. 1, §4.5, Example 4.22](https://openstax.org/books/calculus-volume-1/pages/4-5-derivatives-and-the-shape-of-a-graph) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="Função racional com assíntota oblíqua">

**Problema.** Esboce <Eq>{`f(x) = \\dfrac{x^2 + 1}{x}`}</Eq>.

**Estratégia.** Divisão polinomial para obter assíntota oblíqua; analisar <Eq>{`f'`}</Eq> e <Eq>{`f''`}</Eq>.

**Resolução.**

1. **Domínio:** <Eq>{`\\mathbb{R} \\setminus \\{0\\}`}</Eq>.
2. **Interceptos:** <Eq>{`f(x) = 0 \\Rightarrow x^2 + 1 = 0`}</Eq> — sem raízes reais. Sem intercepto em <Eq>{`x = 0`}</Eq> (fora do domínio).
3. **Simetria:** <Eq>{`f(-x) = (-x^2 - 1)/(-x) = (x^2+1)/x = f(x)`}</Eq>... aguarde: <Eq>{`f(-x) = (x^2+1)/(-x) = -f(x)`}</Eq> → ímpar.
4. **Assíntota vertical:** <Eq>{`x = 0`}</Eq>. Divisão: <Eq>{`f(x) = x + 1/x`}</Eq> → assíntota oblíqua <Eq>{`y = x`}</Eq>.
5. **<Eq>{`f'(x) = 1 - 1/x^2`}</Eq>**. Zero: <Eq>{`x = \\pm 1`}</Eq>. Mínimo local em <Eq>{`x = 1`}</Eq> (valor 2); máximo local em <Eq>{`x = -1`}</Eq> (valor −2).
6. **<Eq>{`f''(x) = 2/x^3`}</Eq>**. Positivo para <Eq>{`x > 0`}</Eq>, negativo para <Eq>{`x < 0`}</Eq>. Sem inflexões (descontinuidade em 0).
7. **Esboço:** dois ramos hiperbólicos, cada um aproximando-se de <Eq>{`y = x`}</Eq> e de <Eq>{`x = 0`}</Eq>.

**Verificação.** <Eq>{`f(x) - x = 1/x \\to 0`}</Eq> quando <Eq>{`x \\to \\pm\\infty`}</Eq> — assíntota oblíqua confirmada.

**Fonte.** [APEX Calculus §3.5, Example 3.5.4](https://www.apexcalculus.com/) · CC-BY-NC

</Exemplo>
