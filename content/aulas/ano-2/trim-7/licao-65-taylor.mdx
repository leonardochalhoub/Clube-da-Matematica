<Porta nivel="formal" titulo="Definição rigorosa e propriedades">

### Polinômio de Taylor

<Definicao titulo="Polinômio de Taylor de ordem n">
Seja $f: I \to \mathbb{R}$ com $n$ derivadas em $a \in I$. O **polinômio de Taylor** de ordem $n$ em torno de $a$ é
$$P_n(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!} (x - a)^k = f(a) + f'(a)(x-a) + \frac{f''(a)}{2!}(x-a)^2 + \cdots + \frac{f^{(n)}(a)}{n!}(x-a)^n.$$

Quando $a = 0$, $P_n$ chama-se **polinômio de Maclaurin** de $f$.
</Definicao>

> "If $f$ has $n$ derivatives at $x = a$, then the $n$th-order Taylor polynomial of $f$ centered at $a$ is $p_n(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x-a)^k$." — [APEX Calculus §8.6](https://www.apexcalculus.com/downloads)

<Teorema titulo="Unicidade do polinômio de Taylor">
$P_n$ é o único polinômio de grau $\leq n$ tal que $P_n^{(k)}(a) = f^{(k)}(a)$ para $k = 0, 1, \ldots, n$.
</Teorema>

### Resíduo de Lagrange

<Definicao titulo="Resto de Taylor (forma de Lagrange)">
Se $f$ tem $n+1$ derivadas contínuas numa vizinhança de $a$, o **resíduo** $R_n(x) = f(x) - P_n(x)$ satisfaz
$$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}$$
para algum $\xi$ estritamente entre $a$ e $x$.
</Definicao>

> "Let $f$ have $n + 1$ derivatives on an open interval $I$ and let $a \in I$. For each $x \in I$ there exists a value $c$ between $a$ and $x$ such that $R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}$." — [OpenStax Calculus Vol. 2 §6.3](https://openstax.org/books/calculus-volume-2/pages/6-3-taylor-and-maclaurin-series)

<Insight titulo="Identidade de Euler via Taylor">
Substituindo $x \to ix$ na série de $e^x$:
$$e^{ix} = \sum_{k=0}^{\infty} \frac{(ix)^k}{k!} = \underbrace{\sum_{k=0}^{\infty} \frac{(-1)^k x^{2k}}{(2k)!}}_{\cos x} + i\underbrace{\sum_{k=0}^{\infty} \frac{(-1)^k x^{2k+1}}{(2k+1)!}}_{\sin x}.$$
Logo $e^{ix} = \cos x + i\sin x$. Em $x = \pi$: $e^{i\pi} + 1 = 0$ — a identidade de Euler.
</Insight>

<Porta nivel="5" titulo="Pra criança de 5 anos">

Imagina uma curva **toda torta**. Você quer **copiar** ela perto de um ponto, mas só pode usar uma regra e um lápis.

Você coloca a regra igual à inclinação da curva naquele ponto. Já ficou parecido!

Se você usar também um **arco de círculo** para ajustar a curvatura, fica ainda mais igual.

Cada **coisa a mais** que você adiciona (inclinação, curvatura, próxima coisa...) deixa a cópia mais fiel. O polinômio de Taylor é a **receita de cópia perfeita** — quanto mais termos, melhor.

</Porta>

<Porta nivel="10" titulo="Pra criança de 10 anos">

A ideia é simples: qualquer função "boazinha" pode ser **imitada por um polinômio** perto de um ponto.

A fórmula de Maclaurin (quando o ponto é $0$) é:

$$f(x) \approx f(0) + f'(0)\cdot x + \frac{f''(0)}{2}\cdot x^2 + \frac{f'''(0)}{6}\cdot x^3 + \cdots$$

Cada novo termo usa uma derivada mais. Mais termos = melhor imitação.

**Exemplo com seno:** Em $x = 0$: $\sin 0 = 0$, $\cos 0 = 1$, $-\sin 0 = 0$, $-\cos 0 = -1$, ...

Então $\sin x \approx x - x^3/6 + x^5/120 - \cdots$

Para $x$ pequeno, $\sin x \approx x$ já funciona — erro menor que $0{,}2\%$ para $x < 0{,}1$ rad!

</Porta>

<Porta nivel="15" titulo="Pra adolescente de 15 anos">

Taylor é a **ponte entre funções arbitrárias e polinômios** — os mais fáceis de calcular.

**Receita:**
1. Escolha um ponto $a$ (quase sempre $a = 0$ — série de Maclaurin).
2. Calcule $f(a),\, f'(a),\, f''(a),\, \ldots,\, f^{(n)}(a)$.
3. Monte $P_n(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x-a)^k$.

**Séries que todo estudante deve memorizar:**

- $e^x = 1 + x + x^2/2 + x^3/6 + \cdots$
- $\sin x = x - x^3/6 + x^5/120 - \cdots$
- $\cos x = 1 - x^2/2 + x^4/24 - \cdots$
- $\ln(1+x) = x - x^2/2 + x^3/3 - \cdots$ para $|x| < 1$

**Três aplicações imediatas:**

- **Aproximar valores:** $\sin(0{,}1) \approx 0{,}1 - 0{,}001/6 \approx 0{,}09983$.
- **Resolver limites:** $\lim_{x\to 0}\frac{e^x - 1 - x}{x^2} = \lim_{x\to 0}\frac{x^2/2 + O(x^3)}{x^2} = \frac{1}{2}$.
- **Engenharia:** $\sin\theta \approx \theta$ para pêndulo de ângulo pequeno — simplifica a equação diferencial.

</Porta>

<Porta nivel="25" titulo="Pra estudante de engenharia">

Taylor é o **instrumento cirúrgico do engenheiro**: sem ele, não há linearização, não há análise de pequenos sinais, não há Newton-Raphson, não há Runge-Kutta.

### Formas do resíduo

$$f(x) = P_n(x) + R_n(x)$$

**Lagrange:** $R_n = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}$, algum $\xi$ entre $a$ e $x$.

**Integral:** $R_n = \int_a^x \frac{(x-t)^n}{n!} f^{(n+1)}(t)\, dt$.

**Big-O:** $R_n = O((x-a)^{n+1})$ — leitura rápida de ordem de erro.

### Aplicações práticas

- **Linearização:** $f(x) \approx f(x_0) + f'(x_0)(x - x_0)$ — base de análise de pequenos sinais em eletrônica e controle.
- **Newton-Raphson:** usa Taylor de ordem 1: $f(x) \approx f(x_n) + f'(x_n)(x - x_n) = 0$ dá $x_{n+1} = x_n - f(x_n)/f'(x_n)$.
- **Runge-Kutta:** deduzido via Taylor multivariado em $t$ e $y$; RK4 tem erro global $O(h^4)$.
- **Relações de dispersão:** $\omega(k) \approx \omega_0 + v_g(k - k_0) + \cdots$ — velocidade de grupo como coeficiente de Taylor.

### Taylor multivariado (ordem 2)

$$f(\vec x) \approx f(\vec a) + \nabla f(\vec a)^T (\vec x - \vec a) + \tfrac{1}{2}(\vec x - \vec a)^T H(\vec a)(\vec x - \vec a)$$

onde $H$ é a **hessiana**. Crítico para otimização numérica.

### Convergência: nem sempre garantida

$f(x) = e^{-1/x^2}$ (com $f(0) = 0$) tem todas as derivadas nulas em $0$, portanto $P_n = 0$ para todo $n$. Mas $f \neq 0$ — função suave mas **não-analítica**. Taylor converge, mas NÃO converge a $f$.

</Porta>

<Porta nivel="40" titulo="Pra profissional sênior">

Taylor é o embrião de análise complexa, teoria de perturbação, física matemática e otimização de segunda ordem.

### Análise complexa: funções holomorfas são analíticas

Toda função **holomorfa** $f: \Omega \to \mathbb{C}$ é igual à sua série de Taylor em qualquer disco aberto onde é definida (Cauchy, 1820s). Isso é radicalmente mais forte que em $\mathbb{R}$: suavidade real ($C^{\infty}$) não garante analiticidade; holomorfismo garante. A beleza está nessa rigidez.

### Perturbação quântica

$H = H_0 + \lambda V$: autoenergia expandida em série de Taylor em $\lambda$: $E_n(\lambda) = E_n^{(0)} + \lambda E_n^{(1)} + \lambda^2 E_n^{(2)} + \cdots$ Coeficientes via Rayleigh-Schrödinger. É Taylor aplicado em espaço de operadores.

### Séries assintóticas vs. convergentes

Stirling: $\ln(n!) \sim n\ln n - n + \tfrac{1}{2}\ln(2\pi n) + \sum_k B_{2k}/(2k(2k-1)n^{2k-1})$. Esta série **diverge** para todo $n$ fixo, mas truncada dá excelente aproximação numérica. Diferença filosófica: uma série pode ser útil mesmo divergente — o erro decresce antes de explodir.

### Aproximantes de Padé

Aproximação racional $f(x) \approx P_m(x)/Q_n(x)$ supera Taylor em raio efetivo para funções com singularidades. Usados em mecânica quântica (método de Padé-Borel) e aceleração de convergência de séries.

### Contexto histórico

Brook Taylor (1715) publica *Methodus Incrementorum* sem prova de convergência. Maclaurin (1742) populariza $a = 0$. Lagrange (1797) formaliza o resíduo. Cauchy (1820s) prova rigorosamente via integral de contorno. Toda essa máquina chegou pronta para Maxwell construir eletromagnetismo e para Einstein linearizar a geodésica em torno de métrica plana.

</Porta>

<Porta nivel="pratica" titulo="Aplicação prática">

**Receita em 4 passos:**

1. **Identifique o ponto** de expansão $a$ (geralmente $0$).
2. **Calcule derivadas** $f(a), f'(a), f''(a), \ldots$ até a ordem desejada.
3. **Monte** $P_n(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x-a)^k$.
4. **Estime o erro**: para série alternada decrescente, $|R_n| < $ valor absoluto do primeiro termo omitido.

### Truques operacionais

- **Substitua:** $\sin(x^2) = x^2 - (x^2)^3/6 + \cdots = x^2 - x^6/6 + \cdots$ — direto da série de sin.
- **Multiplique:** $e^x \sin x = (1 + x + x^2/2 + \cdots)(x - x^3/6 + \cdots)$, expanda até a ordem.
- **Integre/derive:** $\arctan x = \int_0^x \frac{1}{1+t^2}\, dt = \int_0^x (1 - t^2 + t^4 - \cdots)\, dt = x - x^3/3 + x^5/5 - \cdots$

### Contexto brasileiro — taxa de juros

Em finanças, $(1 + r)^n \approx 1 + nr$ para taxa $r$ pequena (Taylor de ordem 1). Erro relativo: aproximadamente $\binom{n}{2} r^2$. Para $r = 1\%$ ao mês e $n = 12$ meses: erro $\approx 66 \times 0{,}0001 = 0{,}66\%$ — desprezível para estimativa rápida de retorno anual.

## Exemplos resolvidos

<Exemplo titulo="Maclaurin de e^x até ordem 4 (aplicação direta)" numero="1">

**Problema.** Encontre o polinômio de Maclaurin de $f(x) = e^x$ de ordem 4 e estime o erro em $x = 0{,}5$.

**Estratégia.** Como $\frac{d^k}{dx^k}e^x = e^x$, todas as derivadas em $a = 0$ valem $1$. Montar $P_4$ diretamente. Usar resíduo de Lagrange com $f^{(5)} = e^x$.

**Resolução.**

1. **Derivadas em $0$:** $f^{(k)}(0) = e^0 = 1$ para todo $k$.
2. **Polinômio:** $P_4(x) = 1 + x + \dfrac{x^2}{2} + \dfrac{x^3}{6} + \dfrac{x^4}{24}$.
3. **Erro em $x = 0{,}5$:** $|R_4(0{,}5)| \leq \dfrac{e^\xi}{5!}(0{,}5)^5 \leq \dfrac{e^{0{,}5}}{120}\cdot\dfrac{1}{32} \approx \dfrac{1{,}649}{120 \cdot 32} \approx 0{,}000430$.
4. **Valor aproximado:** $P_4(0{,}5) = 1 + 0{,}5 + 0{,}125 + 0{,}02083 + 0{,}002604 \approx 1{,}6484$. Valor exato: $e^{0{,}5} \approx 1{,}6487$ — erro menor que $3 \times 10^{-4}$. ✓

**Verificação.** O erro estimado $4{,}3 \times 10^{-4}$ é maior que o erro real $3 \times 10^{-4}$: o resíduo de Lagrange é um majorante. ✓

**Fonte.** [OpenStax Calculus Vol. 2, §6.3, Example 6.17](https://openstax.org/books/calculus-volume-2/pages/6-3-taylor-and-maclaurin-series) — CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="Taylor de ln x em torno de a = 1 (intermediário)" numero="2">

**Problema.** Obtenha o polinômio de Taylor de ordem 3 de $f(x) = \ln x$ centrado em $a = 1$.

**Estratégia.** Calcular $f, f', f'', f'''$ em $x = 1$. Montar $P_3$ com $(x - 1)$ como variável.

**Resolução.**

1. **Derivadas:** $f(x) = \ln x$, $f'(x) = 1/x$, $f''(x) = -1/x^2$, $f'''(x) = 2/x^3$.
2. **Em $a = 1$:** $f(1) = 0$, $f'(1) = 1$, $f''(1) = -1$, $f'''(1) = 2$.
3. **Polinômio:**
$$P_3(x) = 0 + 1\cdot(x-1) + \frac{-1}{2!}(x-1)^2 + \frac{2}{3!}(x-1)^3 = (x-1) - \frac{(x-1)^2}{2} + \frac{(x-1)^3}{3}.$$
4. **Teste em $x = 1{,}1$:** $P_3(1{,}1) = 0{,}1 - 0{,}005 + 0{,}000333 \approx 0{,}09533$. Valor exato: $\ln(1{,}1) \approx 0{,}09531$. ✓

**Verificação.** A série de $\ln(1+u) = u - u^2/2 + u^3/3 - \cdots$ com $u = x - 1$ coincide com $P_3$. ✓

**Fonte.** [Active Calculus §8.5, Activity 8.5.3](https://activecalculus.org/single/sec-8-4-taylor-series.html) — CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="Limite via Taylor: lim (sin x - x)/x^3 (intermediário)" numero="3">

**Problema.** Calcule $\displaystyle\lim_{x \to 0} \frac{\sin x - x}{x^3}$.

**Estratégia.** Substituir a série de Maclaurin de $\sin x$ no numerador e simplificar. Evita regras de L'Hôpital iteradas.

**Resolução.**

1. **Série:** $\sin x = x - \dfrac{x^3}{6} + \dfrac{x^5}{120} - \cdots$
2. **Numerador:** $\sin x - x = -\dfrac{x^3}{6} + \dfrac{x^5}{120} - \cdots$
3. **Divisão por $x^3$:** $\dfrac{\sin x - x}{x^3} = -\dfrac{1}{6} + \dfrac{x^2}{120} - \cdots$
4. **Limite:** ao tomar $x \to 0$, todos os termos com $x$ vão a zero. O limite é $\mathbf{-1/6}$.

**Verificação.** Aplicando L'Hôpital três vezes também daria $-1/6$, mas o método de Taylor é mais rápido. ✓

**Fonte.** [OpenStax Calculus Vol. 2, §6.3, Example 6.20](https://openstax.org/books/calculus-volume-2/pages/6-3-taylor-and-maclaurin-series) — CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="Erro de aproximação sin x ≈ x para pendulo (modelagem)" numero="4">

**Problema.** Um pêndulo usa a aproximação $\sin\theta \approx \theta$. Para $\theta = 15° = \pi/12$ rad, qual é o erro relativo percentual?

**Estratégia.** Calcular $\sin(\pi/12)$ exatamente e comparar com $\pi/12$. Estimar o erro via o próximo termo da série: $-\theta^3/6$.

**Resolução.**

1. **Ângulo em radianos:** $\theta = \pi/12 \approx 0{,}2618$ rad.
2. **Valor exato:** $\sin(\pi/12) = \sin(15°) = (\sqrt{6} - \sqrt{2})/4 \approx 0{,}2588$.
3. **Aproximação:** $\theta = 0{,}2618$.
4. **Erro absoluto:** $|0{,}2618 - 0{,}2588| = 0{,}0030$.
5. **Erro relativo:** $0{,}0030 / 0{,}2588 \approx 1{,}16\%$.
6. **Via Taylor:** erro $\approx \theta^3/6 = (0{,}2618)^3/6 \approx 0{,}00298$ — muito próximo do erro calculado. ✓

**Verificação.** Para $\theta < 0{,}1$ rad ($\approx 5{,}7°$), o erro cai abaixo de $0{,}017\%$ — justificando o uso em engenharia. ✓

**Fonte.** [APEX Calculus §8.6, Exercise 8.6.13](https://www.apexcalculus.com/downloads) — CC-BY-NC.
</Exemplo>

<Exemplo titulo="Maclaurin por composicao: e^(sin x) ate ordem 3 (avancado)" numero="5">

**Problema.** Obtenha o polinômio de Maclaurin de $f(x) = e^{\sin x}$ até ordem 3.

**Estratégia.** Substituir a série de $\sin x$ na série de $e^u$, agrupando termos até $x^3$.

**Resolução.**

1. **Série de sin:** $\sin x = x - x^3/6 + O(x^5)$.
2. **$u = \sin x$:** então $e^u = 1 + u + u^2/2 + u^3/6 + O(u^4)$.
3. **Substituindo:** $u = x - x^3/6 + \cdots$, logo:
   - $u = x - x^3/6$
   - $u^2 = x^2 - 2x\cdot x^3/6 + \cdots = x^2 + O(x^4)$
   - $u^3 = x^3 + O(x^5)$
4. **Montagem:**
$$e^{\sin x} = 1 + \left(x - \tfrac{x^3}{6}\right) + \frac{x^2}{2} + \frac{x^3}{6} + O(x^4) = 1 + x + \frac{x^2}{2} + 0 \cdot x^3 + O(x^4).$$
5. **Resultado:** $P_3(x) = 1 + x + \dfrac{x^2}{2}$.

**Verificação.** Em $x = 0$: $f(0) = e^0 = 1$ ✓. $f'(0) = e^{\sin 0}\cos 0 = 1$ ✓. $f''(0) = e^{\sin 0}(\cos^2 0 - \sin 0) = 1$ ✓.

</Exemplo>
