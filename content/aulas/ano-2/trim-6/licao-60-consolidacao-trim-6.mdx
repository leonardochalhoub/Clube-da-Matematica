### Hierarquia das ferramentas de derivação

| Lição | Conceito | Fórmula chave |
|---|---|---|
| 51 | Definição via limite | $f'(a) = \lim_{h \to 0}\dfrac{f(a+h) - f(a)}{h}$ |
| 52 | Regras operatórias | $(fg)' = f'g + fg'$,\ $\bigl(\tfrac{f}{g}\bigr)' = \tfrac{f'g - fg'}{g^2}$ |
| 53 | Regra da cadeia | $(f \circ g)'(x) = f'(g(x)) \cdot g'(x)$ |
| 54 | Derivada implícita | Diferencia $F(x,y) = 0$ em $x$; isola $y'$ |
| 55 | Derivadas superiores | $f^{(n)}(x) = (f^{(n-1)})'(x)$ |
| 56 | Derivadas de inversas | $(\arctan x)' = \tfrac{1}{1+x^2}$,\ $(\ln x)' = \tfrac{1}{x}$ |
| 57 | Linearização | $L(x) = f(a) + f'(a)(x - a)$ |
| 58 | Taxas relacionadas | Deriva equação em $t$; usa cadeia |
| 59 | Diferenciabilidade $C^k$ | $f$ diferenciável em $a \Rightarrow f$ contínua em $a$ |

### Reconhecimento de padrão

| Sinal no enunciado | Técnica a usar |
|---|---|
| Compute $f'(a)$ diretamente | Regras + tabela |
| $y = f(\text{expressão composta})$ | Regra da cadeia |
| $F(x, y) = 0$, ache $y'$ | Derivada implícita |
| $f''$, concavidade, inflexão | Derivadas superiores |
| Derivada de $\arcsin$, $\arctan$, $\ln$, $e^x$, $a^x$ | Tabela de inversas |
| Aproxime $f(x)$ perto de $a$ | Linearização |
| "Quão rápido $X$ muda com o tempo?" | Taxas relacionadas |
| "$f$ é diferenciável em $a$?" | Verificar continuidade + limite bilateral |

### Tabela de derivadas fundamentais

| $f(x)$ | $f'(x)$ |
|---|---|
| $x^n$ | $n x^{n-1}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $1/x$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x$ |
| $\arcsin x$ | $1/\sqrt{1-x^2}$ |
| $\arctan x$ | $1/(1+x^2)$ |

**Trimestre 6 em uma frase:** aprender a derivar qualquer função, de qualquer jeito, usando as ferramentas certas.

As ferramentas são:

1. **Definição** (limite) — sempre funciona, mas é lenta.
2. **Regras** (potência, produto, quociente) — rápidas para funções simples.
3. **Cadeia** — para funções "dentro de outras funções".
4. **Implícita** — para curvas que não são gráficos de função.
5. **Inversas** — para $\arctan$, $\ln$, etc.
6. **Linearização** — para aproximar valores difíceis.
7. **Taxas relacionadas** — para problemas de "quão rápido muda?".

O cálculo diferencial escalar que você dominou neste trimestre é o caso $n=1$, $d=1$ de uma teoria muito mais rica.

### Direções de generalização

1. **Cálculo multivariado**: Jacobiano $Df: \mathbb{R}^n \to \mathbb{R}^m$, Hessian $\nabla^2 f$, gradiente, divergência, rotacional.
2. **Cálculo funcional**: derivadas de Fréchet e Gâteaux em espaços de Banach — base para variação de funcionais (cálculo variacional, controle ótimo).
3. **Geometria diferencial**: derivada covariante, conexão de Levi-Civita, curvatura — usado em relatividade geral e geometria de variedades.
4. **Diferenciação automática**: forward mode (números duais) e reverse mode (backpropagation) — implementações eficientes da cadeia em grafos computacionais.
5. **Análise não-suave**: subgradiente de Rockafellar, derivada de Clarke para funções Lipschitz não diferenciáveis — usado em otimização convexa e controle.
6. **Cálculo estocástico**: lema de Itô generaliza a regra da cadeia para processos de Wiener: $df = f_t dt + f_x dW_t + \tfrac{1}{2}f_{xx}dt$.

### Mnemônica para profissionais

Toda teoria de derivada é uma resposta à pergunta: "Como $f$ muda linearmente quando o argumento muda um pouco?" A resposta muda de domínio, mas o princípio é sempre o mesmo.

### Verificação rápida com SymPy

```python
import sympy as sp
x, y, t = sp.symbols('x y t')

# Derivada simples
sp.diff(x**3 * sp.sin(x), x)

# Regra da cadeia
sp.diff(sp.atan(sp.exp(x**2)), x)

# Derivada implícita: x^2 + y^2 = 25
y_f = sp.Function('y')(x)
expr = x**2 + y_f**2 - 25
sp.solve(sp.diff(expr, x), sp.diff(y_f, x))[0]

# Linearização de sqrt(x) em a=9
f = sp.sqrt(x)
a = 9
L = f.subs(x, a) + sp.diff(f, x).subs(x, a) * (x - a)
sp.simplify(L)

# Taxa relacionada: V = (4/3)pi r^3
r = sp.Function('r')(t)
V = sp.Rational(4,3) * sp.pi * r**3
sp.diff(V, t)   # = 4 pi r^2 * r'(t)
```

## Exemplos resolvidos

<Exemplo titulo="Definição via limite — cálculo direto" numero="1">

**Problema.** Use a definição de derivada para calcular $f'(2)$ onde $f(x) = x^2 - 3x + 1$.

**Estratégia.** Aplicar diretamente $f'(2) = \lim_{h \to 0} \dfrac{f(2+h) - f(2)}{h}$, expandir o numerador e cancelar o $h$.

**Resolução.**

$$f(2+h) = (2+h)^2 - 3(2+h) + 1 = 4 + 4h + h^2 - 6 - 3h + 1 = -1 + h + h^2$$

$$f(2) = 4 - 6 + 1 = -1$$

$$\frac{f(2+h) - f(2)}{h} = \frac{(-1 + h + h^2) - (-1)}{h} = \frac{h + h^2}{h} = 1 + h$$

$$f'(2) = \lim_{h \to 0}(1 + h) = 1$$

**Verificação.** Por regras: $f'(x) = 2x - 3$, então $f'(2) = 4 - 3 = 1$. Consistente.

**Fonte.** [Active Calculus — Boelkins, §1.3, Preview Activity 1.3.1](https://activecalculus.org/single/sec-1-3-derivative-pt.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Regra da cadeia com composição dupla" numero="2">

**Problema.** Calcule $f'(x)$ para $f(x) = \sin^3(2x + 1)$.

**Estratégia.** Identificar a estrutura de composição: $f = u^3$ onde $u = \sin(v)$ e $v = 2x+1$. Aplicar cadeia duas vezes.

**Resolução.**

$$f(x) = [\sin(2x+1)]^3$$

Seja $u = \sin(2x+1)$, então $f = u^3$ e $f' = 3u^2 \cdot u'$.

Agora $u' = \cos(2x+1) \cdot (2x+1)' = 2\cos(2x+1)$.

Portanto:

$$f'(x) = 3\sin^2(2x+1) \cdot 2\cos(2x+1) = 6\sin^2(2x+1)\cos(2x+1)$$

Usando identidade duplo-ângulo: $2\sin\theta\cos\theta = \sin(2\theta)$,

$$f'(x) = 3\sin^2(2x+1)\cos(2x+1)$$

**Verificação.** Em $x = 0$: $f(0) = \sin^3(1) \approx (0{,}841)^3 \approx 0{,}595$. $f'(0) = 6\sin^2(1)\cos(1) \approx 6(0{,}708)(0{,}540) \approx 2{,}296$. Confirme numericamente: $\dfrac{f(0{,}001) - f(0)}{0{,}001} \approx 2{,}296$.

**Fonte.** [Active Calculus — Boelkins, §2.5, Example 2.5.3](https://activecalculus.org/single/sec-2-5-chain.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Derivada implícita — tangente a uma curva" numero="3">

**Problema.** Encontre a equação da reta tangente à curva $x^3 + y^3 = 9$ no ponto $(1, 2)$.

**Estratégia.** Diferenciar ambos os lados em relação a $x$ (tratando $y$ como função de $x$), isolar $y'$, avaliar em $(1,2)$ e escrever a equação da reta.

**Resolução.**

Diferenciando $x^3 + y^3 = 9$:

$$3x^2 + 3y^2 \cdot y' = 0$$

$$y' = -\frac{x^2}{y^2}$$

Em $(1, 2)$:

$$y'\big|_{(1,2)} = -\frac{1^2}{2^2} = -\frac{1}{4}$$

Equação da tangente:

$$y - 2 = -\frac{1}{4}(x - 1) \implies y = -\frac{x}{4} + \frac{9}{4}$$

**Verificação.** O ponto $(1,2)$ pertence à curva: $1 + 8 = 9$. Correto. A reta passa por $(1, 2)$: $-\tfrac{1}{4} + \tfrac{9}{4} = \tfrac{8}{4} = 2$. Correto.

**Fonte.** [OpenStax Calculus Vol. 1 — §3.8, Example 3.71](https://openstax.org/books/calculus-volume-1/pages/3-8-implicit-differentiation) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Linearização — aproximação de raiz cúbica" numero="4">

**Problema.** Use a linearização de $f(x) = \sqrt[3]{x}$ em $a = 8$ para aproximar $\sqrt[3]{8{,}1}$.

**Estratégia.** Calcular $L(x) = f(a) + f'(a)(x - a)$ e avaliar em $x = 8{,}1$.

**Resolução.**

$f(x) = x^{1/3}$, portanto $f'(x) = \dfrac{1}{3}x^{-2/3}$.

Em $a = 8$:

$$f(8) = 2, \qquad f'(8) = \frac{1}{3} \cdot 8^{-2/3} = \frac{1}{3} \cdot \frac{1}{4} = \frac{1}{12}$$

$$L(x) = 2 + \frac{1}{12}(x - 8)$$

$$\sqrt[3]{8{,}1} \approx L(8{,}1) = 2 + \frac{0{,}1}{12} \approx 2{,}00833$$

**Verificação.** Valor exato: $8{,}1^{1/3} \approx 2{,}00832$. Erro $< 0{,}001\%$.

**Fonte.** [OpenStax Calculus Vol. 1 — §4.2, Example 4.11](https://openstax.org/books/calculus-volume-1/pages/4-2-linear-approximations-and-differentials) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Taxa relacionada — balão esférico" numero="5">

**Problema.** O raio de um balão esférico aumenta à taxa de $3$ cm/s. Qual é a taxa de variação do volume quando o raio é $10$ cm?

**Estratégia.** Escrever $V = \tfrac{4}{3}\pi r^3$, derivar em relação a $t$ usando a cadeia, substituir $r = 10$ e $\dfrac{dr}{dt} = 3$.

**Resolução.**

$$V = \frac{4}{3}\pi r^3$$

Derivando em $t$:

$$\frac{dV}{dt} = 4\pi r^2 \cdot \frac{dr}{dt}$$

Substituindo $r = 10$ e $\dfrac{dr}{dt} = 3$:

$$\frac{dV}{dt} = 4\pi (10)^2 \cdot 3 = 1200\pi \approx 3\,769{,}9 \text{ cm}^3/\text{s}$$

**Verificação.** As unidades: $[\text{cm}^2] \cdot [\text{cm/s}] = [\text{cm}^3/\text{s}]$. Consistente. O volume cresce muito rápido porque a área da superfície é grande.

**Fonte.** [Active Calculus — Boelkins, §3.5, Example 3.5.1](https://activecalculus.org/single/sec-3-5-related-rates.html) — CC-BY-NC-SA.

</Exemplo>
