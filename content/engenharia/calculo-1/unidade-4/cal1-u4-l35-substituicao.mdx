## Regra da Substituição

<Teorema titulo="Teorema da Substituição (integral indefinida)">
Seja <Eq>{`g`}</Eq> diferenciável e <Eq>{`f`}</Eq> contínua no intervalo imagem de <Eq>{`g`}</Eq>. Então:

<Eq>{`\\int f(g(x))\\,g'(x)\\,dx = \\int f(u)\\,du \\bigg|_{u=g(x)} = F(g(x)) + C,`}</Eq>

onde <Eq>{`F`}</Eq> é antiderivada de <Eq>{`f`}</Eq>.

**Justificativa.** Pela regra da cadeia: <Eq>{`\\frac{d}{dx}[F(g(x))] = F'(g(x))\\,g'(x) = f(g(x))\\,g'(x)`}</Eq>.
</Teorema>

<Teorema titulo="Substituição em integrais definidas">
Se <Eq>{`g'`}</Eq> é contínua em <Eq>{`[a,b]`}</Eq> e <Eq>{`f`}</Eq> é contínua em <Eq>{`g([a,b])`}</Eq>:

<Eq>{`\\int_a^b f(g(x))\\,g'(x)\\,dx = \\int_{g(a)}^{g(b)} f(u)\\,du.`}</Eq>

**Atenção aos limites:** os limites de integração mudam de <Eq>{`x`}</Eq> para <Eq>{`u = g(x)`}</Eq>. Quando <Eq>{`x=a`}</Eq>, <Eq>{`u=g(a)`}</Eq>; quando <Eq>{`x=b`}</Eq>, <Eq>{`u=g(b)`}</Eq>.
</Teorema>

**Estratégia para escolher <Eq>{`u`}</Eq>:**
1. Identifique a "função interna" <Eq>{`g(x)`}</Eq> de uma composição.
2. Verifique se <Eq>{`g'(x)`}</Eq> (ou múltiplo dela) aparece no integrando.
3. Faça <Eq>{`u = g(x)`}</Eq>, <Eq>{`du = g'(x)\\,dx`}</Eq>.

<Cuidado>
Ao mudar limites em integrais definidas, não reverta para <Eq>{`x`}</Eq>. Calcule diretamente com os limites em <Eq>{`u`}</Eq>. Ou, alternativamente, calcule a primitiva em <Eq>{`u`}</Eq>, reverta para <Eq>{`x`}</Eq> e então substitua os limites originais.
</Cuidado>

</Porta>

## Trocar de Roupa para Calcular Mais Fácil

Às vezes, uma conta com números difíceis fica simples quando você **troca de nome**. Se você tem que calcular <Eq>{`2 \\times 13 + 2 \\times 7`}</Eq>, pode chamar <Eq>{`u = 2`}</Eq> e calcular <Eq>{`u \\times (13+7) = 2 \\times 20 = 40`}</Eq>.

A substituição de variável faz o mesmo na integral: troca o problema difícil por um mais simples. Você "fantasia" a integral com uma nova roupa (a variável <Eq>{`u`}</Eq>), calcula, e depois volta à roupa original.

</Porta>

## A Regra u-Substitution

**Regra prática:** Procure uma "parte dentro" cujos derivada está multiplicando.

**Exemplo.** <Eq>{`\\int 2x\\,(x^2+1)^5\\,dx`}</Eq>. Observe que <Eq>{`(x^2+1)' = 2x`}</Eq>. Faça:

<Eq>{`u = x^2+1,\\quad du = 2x\\,dx.`}</Eq>

<Eq>{`\\int u^5\\,du = \\frac{u^6}{6} + C = \\frac{(x^2+1)^6}{6} + C.`}</Eq>

**Verificação:** deriva e obtém <Eq>{`\\frac{6(x^2+1)^5 \\cdot 2x}{6} = 2x(x^2+1)^5`}</Eq>. $\checkmark$

**Exemplo com constante.** <Eq>{`\\int x\\,e^{x^2}\\,dx`}</Eq>: <Eq>{`u = x^2`}</Eq>, <Eq>{`du = 2x\\,dx \\Rightarrow x\\,dx = du/2`}</Eq>:

<Eq>{`\\int e^u \\frac{du}{2} = \\frac{e^u}{2} + C = \\frac{e^{x^2}}{2} + C.`}</Eq>

</Porta>

## Substituição em Integrais Definidas

Há dois métodos equivalentes:

**Método 1 — mudar os limites:**

<Eq>{`\\int_0^2 x\\,(1+x^2)^3\\,dx. \\quad u = 1+x^2,\\; du = 2x\\,dx.`}</Eq>

<Eq>{`x=0 \\Rightarrow u=1;\\quad x=2 \\Rightarrow u=5.`}</Eq>

<Eq>{`\\int_1^5 \\frac{u^3}{2}\\,du = \\frac{1}{2}\\cdot\\frac{u^4}{4}\\bigg|_1^5 = \\frac{625-1}{8} = \\frac{624}{8} = 78.`}</Eq>

**Método 2 — calcular primitiva em <Eq>{`x`}</Eq>:**

Primitiva: <Eq>{`F(x) = (1+x^2)^4/8`}</Eq>. Logo <Eq>{`F(2) - F(0) = 625/8 - 1/8 = 78`}</Eq>. $\checkmark$

**Substituições específicas para classes:**
- <Eq>{`\\sqrt{a^2-x^2}`}</Eq>: use <Eq>{`x = a\\sin\\theta`}</Eq>
- <Eq>{`\\sqrt{a^2+x^2}`}</Eq>: use <Eq>{`x = a\\tan\\theta`}</Eq>
- <Eq>{`\\sqrt{x^2-a^2}`}</Eq>: use <Eq>{`x = a\\sec\\theta`}</Eq>

</Porta>

## Substituição e o Teorema de Mudança de Variáveis

A substituição de variável é o caso unidimensional do **Teorema de Mudança de Variáveis** em integrais múltiplas:

<Eq>{`\\int_{g(a)}^{g(b)} f(u)\\,du = \\int_a^b f(g(x))\\,|g'(x)|\\,dx`}</Eq>

(com módulo quando <Eq>{`g'`}</Eq> pode mudar de sinal). Em <Eq>{`\\mathbb{R}^n`}</Eq>:

<Eq>{`\\int_{g(D)} f(\\mathbf{u})\\,d\\mathbf{u} = \\int_D f(g(\\mathbf{x}))\\,|\\det J_g(\\mathbf{x})|\\,d\\mathbf{x},`}</Eq>

onde <Eq>{`J_g`}</Eq> é a **Jacobiana** de <Eq>{`g`}</Eq>. O fator <Eq>{`|\\det J_g|`}</Eq> é o análogo multidimensional de <Eq>{`|g'(x)|`}</Eq>.

**Substituições polares, cilíndricas e esféricas** são aplicações deste teorema com Jacobianos específicos:
- Polares: <Eq>{`|J| = r`}</Eq>
- Cilíndricas: <Eq>{`|J| = r`}</Eq>
- Esféricas: <Eq>{`|J| = \\rho^2\\sin\\varphi`}</Eq>

</Porta>

<Porta tipo="40anos">

## Substituição em Processamento de Sinais

**Mudança de variável em integrais de convolução.** A resposta de um sistema linear a uma entrada <Eq>{`x(t)`}</Eq> é:

<Eq>{`y(t) = \\int_{-\\infty}^{\\infty} h(\\tau)\\,x(t-\\tau)\\,d\\tau.`}</Eq>

A substituição <Eq>{`u = t - \\tau`}</Eq> troca <Eq>{`y(t) = \\int_{-\\infty}^\\infty h(t-u)\\,x(u)\\,du`}</Eq>, mostrando que a convolução é comutativa.

**Análise de Fourier.** A mudança de variável <Eq>{`\\omega = 2\\pi f`}</Eq> converte entre as convenções de frequência angular e linear. Substituições de escala <Eq>{`t \\mapsto t/T`}</Eq> normalizam sinais para análise adimensional.

**Integração numérica por substituição.** Para integrar funções com singularidades como <Eq>{`\\int_0^1 f(x)/\\sqrt{x}\\,dx`}</Eq>, a substituição <Eq>{`x = u^2`}</Eq> (logo <Eq>{`dx = 2u\\,du`}</Eq>) elimina a singularidade:

<Eq>{`\\int_0^1 \\frac{f(u^2)}{u}\\cdot 2u\\,du = 2\\int_0^1 f(u^2)\\,du,`}</Eq>

que pode ser calculada com quadratura de Gauss padrão.

</Porta>

<Porta tipo="pratica">

## Identificando a Substituição Certa

**Passo 1:** Veja se há composição <Eq>{`f(g(x))`}</Eq> com <Eq>{`g'(x)`}</Eq> disponível.

**Passo 2:** Faça <Eq>{`u = g(x)`}</Eq>, compute <Eq>{`du`}</Eq>, substitua tudo (incluindo o <Eq>{`dx`}</Eq>).

**Passo 3:** Resolva em <Eq>{`u`}</Eq>, reverta para <Eq>{`x`}</Eq>.

| Integrando | Escolha de <Eq>{`u`}</Eq> |
|---|---|
| <Eq>{`\\sin^3 x \\cos x`}</Eq> | <Eq>{`u = \\sin x`}</Eq> |
| <Eq>{`\\frac{\\ln x}{x}`}</Eq> | <Eq>{`u = \\ln x`}</Eq> |
| <Eq>{`x e^{x^2}`}</Eq> | <Eq>{`u = x^2`}</Eq> |
| <Eq>{`\\frac{x}{\\sqrt{1-x^2}}`}</Eq> | <Eq>{`u = 1-x^2`}</Eq> |
| <Eq>{`\\tan x`}</Eq> | <Eq>{`u = \\cos x`}</Eq> |

</Porta>

## Exemplos

<Exemplo titulo="Substituição com ajuste de constante">
<Eq>{`\\int \\frac{x}{(1+x^2)^3}\\,dx.`}</Eq>

Faça <Eq>{`u = 1+x^2`}</Eq>, <Eq>{`du = 2x\\,dx`}</Eq>, logo <Eq>{`x\\,dx = du/2`}</Eq>:

<Eq>{`\\int \\frac{1}{u^3}\\cdot\\frac{du}{2} = \\frac{1}{2}\\int u^{-3}\\,du = \\frac{1}{2}\\cdot\\frac{u^{-2}}{-2} + C = -\\frac{1}{4(1+x^2)^2} + C.`}</Eq>

*Fonte: Stewart §4.5, Exemplo 3; Demidovich §5, Ex. 1210*
</Exemplo>

<Exemplo titulo="Substituição definida com troca de limites">
<Eq>{`\\int_0^{\\pi/2} \\sin^5 x \\cos x\\,dx.`}</Eq>

<Eq>{`u = \\sin x,\\; du = \\cos x\\,dx.\\quad x=0\\Rightarrow u=0;\\quad x=\\pi/2\\Rightarrow u=1.`}</Eq>

<Eq>{`\\int_0^1 u^5\\,du = \\frac{u^6}{6}\\bigg|_0^1 = \\frac{1}{6}.`}</Eq>

*Fonte: Stewart §4.5, Exemplo 7; Apostol §5.7*
</Exemplo>

<Exemplo titulo="Substituição para funções compostas com log e exp">
**(a)** <Eq>{`\\int \\frac{(\\ln x)^2}{x}\\,dx:`}</Eq> faça <Eq>{`u = \\ln x`}</Eq>, <Eq>{`du = dx/x`}</Eq>: <Eq>{`\\int u^2\\,du = u^3/3 + C = (\\ln x)^3/3 + C.`}</Eq>

**(b)** <Eq>{`\\int e^{\\sin x}\\cos x\\,dx:`}</Eq> faça <Eq>{`u = \\sin x`}</Eq>, <Eq>{`du = \\cos x\\,dx`}</Eq>: <Eq>{`\\int e^u\\,du = e^u + C = e^{\\sin x} + C.`}</Eq>

*Fonte: Demidovich §5, Ex. 1230–1240; OpenStax Calc I §5.5*
</Exemplo>

<Exemplo titulo="Substituição trigonométrica básica">
<Eq>{`\\int \\frac{x}{\\sqrt{4-x^2}}\\,dx.`}</Eq>

Faça <Eq>{`u = 4-x^2`}</Eq>, <Eq>{`du = -2x\\,dx`}</Eq>:

<Eq>{`\\int \\frac{1}{\\sqrt{u}}\\cdot\\left(-\\frac{du}{2}\\right) = -\\frac{1}{2}\\cdot 2\\sqrt{u} + C = -\\sqrt{4-x^2} + C.`}</Eq>

*Fonte: Guidorizzi §5.4; Active Calculus §5.3*
</Exemplo>

<Exemplo titulo="Integral definida com g' negativa">
<Eq>{`\\int_0^{\\pi/2} \\frac{\\cos x}{1 + \\sin^2 x}\\,dx.`}</Eq>

<Eq>{`u = \\sin x,\\; du = \\cos x\\,dx.\\quad u(0)=0,\\; u(\\pi/2)=1.`}</Eq>

<Eq>{`\\int_0^1 \\frac{du}{1+u^2} = [\\arctan u]_0^1 = \\frac{\\pi}{4}.`}</Eq>

*Fonte: Stewart §4.5, Exemplo 8; Apostol §5.7*
</Exemplo>
