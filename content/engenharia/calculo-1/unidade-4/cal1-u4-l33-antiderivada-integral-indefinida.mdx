## Antiderivada e Primitivas

<Definicao titulo="Antiderivada">
Uma função <Eq>{`F`}</Eq> é uma **antiderivada** (ou **primitiva**) de <Eq>{`f`}</Eq> em <Eq>{`I`}</Eq> se <Eq>{`F'(x) = f(x)`}</Eq> para todo <Eq>{`x \\in I`}</Eq>.
</Definicao>

<Teorema titulo="Unicidade a menos de constante">
Se <Eq>{`F`}</Eq> e <Eq>{`G`}</Eq> são antiderivadas de <Eq>{`f`}</Eq> em um intervalo <Eq>{`I`}</Eq>, então <Eq>{`G(x) - F(x) = C`}</Eq> (constante) em <Eq>{`I`}</Eq>.

**Demonstração.** <Eq>{`(G-F)' = G' - F' = f - f = 0`}</Eq> em <Eq>{`I`}</Eq>. Pelo Corolário 1 do TVM, <Eq>{`G - F`}</Eq> é constante.
</Teorema>

<Definicao titulo="Integral indefinida">
A **integral indefinida** de <Eq>{`f`}</Eq> é a família de todas as antiderivadas:

<Eq>{`\\int f(x)\\,dx = F(x) + C,`}</Eq>

onde <Eq>{`C \\in \\mathbb{R}`}</Eq> é a **constante de integração** e <Eq>{`F`}</Eq> é qualquer antiderivada de <Eq>{`f`}</Eq>.
</Definicao>

### Tabela de Primitivas Imediatas

| <Eq>{`f(x)`}</Eq> | <Eq>{`\\int f(x)\\,dx`}</Eq> |
|---|---|
| <Eq>{`x^n\\,(n\\ne -1)`}</Eq> | <Eq>{`\\dfrac{x^{n+1}}{n+1} + C`}</Eq> |
| <Eq>{`\\dfrac{1}{x}`}</Eq> | <Eq>{`\\ln\\lvert x\\rvert + C`}</Eq> |
| <Eq>{`e^x`}</Eq> | <Eq>{`e^x + C`}</Eq> |
| <Eq>{`a^x`}</Eq> | <Eq>{`\\dfrac{a^x}{\\ln a} + C`}</Eq> |
| <Eq>{`\\sin x`}</Eq> | <Eq>{`-\\cos x + C`}</Eq> |
| <Eq>{`\\cos x`}</Eq> | <Eq>{`\\sin x + C`}</Eq> |
| <Eq>{`\\sec^2 x`}</Eq> | <Eq>{`\\tan x + C`}</Eq> |
| <Eq>{`\\dfrac{1}{\\sqrt{1-x^2}}`}</Eq> | <Eq>{`\\arcsin x + C`}</Eq> |
| <Eq>{`\\dfrac{1}{1+x^2}`}</Eq> | <Eq>{`\\arctan x + C`}</Eq> |
| <Eq>{`\\cosh x`}</Eq> | <Eq>{`\\sinh x + C`}</Eq> |

### Propriedades da Integral Indefinida

<Eq>{`\\int [\\alpha f(x) + \\beta g(x)]\\,dx = \\alpha\\int f(x)\\,dx + \\beta\\int g(x)\\,dx.`}</Eq>

<Cuidado>
A constante <Eq>{`C`}</Eq> é **obrigatória**. Esquecer o <Eq>{`+ C`}</Eq> significa não representar todas as antiderivadas. Em equações diferenciais, <Eq>{`C`}</Eq> é determinada pela condição inicial.
</Cuidado>

</Porta>

## Desfazendo a Derivada

A derivada é como apertar um suco: pega a laranja e transforma em suco. A **antiderivada** é o processo contrário: pega o suco e tenta achar de volta qual era a laranja.

Se a derivada de <Eq>{`x^2`}</Eq> é <Eq>{`2x`}</Eq>, então a antiderivada de <Eq>{`2x`}</Eq> é <Eq>{`x^2`}</Eq>. Mas também pode ser <Eq>{`x^2 + 5`}</Eq> ou <Eq>{`x^2 - 3`}</Eq>, porque a derivada de qualquer constante é zero!

Por isso sempre escrevemos <Eq>{`+ C`}</Eq> — há infinitas laranjas que poderiam ter dado aquele suco.

</Porta>

## Regras de Integração Básicas

**Potência:** <Eq>{`\\int x^n\\,dx = \\frac{x^{n+1}}{n+1} + C`}</Eq> (para <Eq>{`n \\ne -1`}</Eq>).

Verifique derivando: <Eq>{`\\left(\\frac{x^{n+1}}{n+1}\\right)' = \\frac{(n+1)x^n}{n+1} = x^n.`}</Eq> $\checkmark$

**Exemplos:**

<Eq>{`\\int x^3\\,dx = \\frac{x^4}{4} + C, \\quad \\int \\frac{1}{x^2}\\,dx = \\int x^{-2}\\,dx = -\\frac{1}{x} + C.`}</Eq>

**Trigonométricas:**

<Eq>{`\\int \\cos x\\,dx = \\sin x + C, \\quad \\int \\sin x\\,dx = -\\cos x + C.`}</Eq>

**Exponencial:**

<Eq>{`\\int e^x\\,dx = e^x + C.`}</Eq>

</Porta>

<Porta tipo="15anos">

## Existência de Antiderivadas

**Nem toda função contínua tem antiderivada em forma fechada.** Por exemplo, <Eq>{`e^{-x^2}`}</Eq>, <Eq>{`\\sin(x^2)`}</Eq> e <Eq>{`\\ln(\\ln x)`}</Eq> são contínuas mas suas integrais não se expressam com funções elementares (Teorema de Liouville-Risch).

**Mas:** o Teorema Fundamental do Cálculo (próxima lição) garante que toda função contínua **tem** uma antiderivada, dada por <Eq>{`F(x) = \\int_a^x f(t)\\,dt`}</Eq>, mesmo que não haja fórmula fechada.

**Estratégia de verificação.** Para verificar <Eq>{`\\int f(x)\\,dx = F(x) + C`}</Eq>, **derive**: se <Eq>{`F'(x) = f(x)`}</Eq>, está correto. Isso é mais confiável do que memorizar fórmulas.

</Porta>

<Porta tipo="25anos">

## Antiderivadas e EDOs de Primeira Ordem

A equação <Eq>{`y' = f(x)`}</Eq> é a EDO mais simples: sua solução geral é a antiderivada <Eq>{`y = F(x) + C`}</Eq>, com <Eq>{`C`}</Eq> determinado pela condição inicial <Eq>{`y(x_0) = y_0`}</Eq>.

**Conexão com o espaço de soluções.** O conjunto de soluções de <Eq>{`y' = f(x)`}</Eq> é um **espaço afim** de dimensão 1: todas as soluções diferem por uma constante. Para EDOs de ordem <Eq>{`n`}</Eq>, o espaço tem dimensão <Eq>{`n`}</Eq>.

**Antiderivadas e distribuições.** No contexto das distribuições de Schwartz, toda distribuição tem antiderivada no sentido distribucional — inclusive a função de Heaviside (cuja derivada é a delta de Dirac): <Eq>{`H'(x) = \\delta(x)`}</Eq>.

</Porta>

<Porta tipo="40anos">

## Integração em Sistemas de Controle e Simulação

Em controle e simulação numérica, a antiderivada resolve a EDO <Eq>{`\\dot{x} = u(t)`}</Eq> (integrador puro):

<Eq>{`x(t) = x_0 + \\int_0^t u(\\tau)\\,d\\tau.`}</Eq>

**Integradores em Simulink/Modelica.** Um bloco integrador implementa exatamente isso: dado o sinal de entrada <Eq>{`u(t)`}</Eq>, produz <Eq>{`x(t)`}</Eq> pela antiderivada numérica (método de Euler, RK4, etc.).

**Drift e erro de integração.** Em sistemas inerciais (IMU), a velocidade é obtida por integração numérica da aceleração medida. Erros constantes no sensor (bias) crescem linearmente com o tempo: <Eq>{`\\int_0^t b\\,d\\tau = bt`}</Eq>. Por isso, sistemas de navegação precisam de fusão sensorial (GPS + IMU).

**Anti-integrador windup.** Em controladores PID, o termo integral acumula erro. Se a saída satura, o integrador continua integrando ("windup") — causa instabilidade. Técnicas anti-windup limitam essa acumulação.

</Porta>

<Porta tipo="pratica">

## Calculando Antiderivadas Passo a Passo

**Regra da potência com coeficientes:**

<Eq>{`\\int (4x^3 - 6x + 5)\\,dx = x^4 - 3x^2 + 5x + C.`}</Eq>

**Verificação:** deriva e confere. <Eq>{`(x^4 - 3x^2 + 5x + C)' = 4x^3 - 6x + 5.`}</Eq> $\checkmark$

**Condição inicial:** a partícula começa em repouso na posição 2. Dada aceleração <Eq>{`a(t) = 6t`}</Eq>:

<Eq>{`v(t) = \\int 6t\\,dt = 3t^2 + C_1. \\quad v(0) = 0 \\Rightarrow C_1 = 0.`}</Eq>

<Eq>{`x(t) = \\int 3t^2\\,dt = t^3 + C_2. \\quad x(0) = 2 \\Rightarrow C_2 = 2.`}</Eq>

Logo <Eq>{`x(t) = t^3 + 2`}</Eq>.

**Caso especial <Eq>{`n = -1`}</Eq>:** <Eq>{`\\int \\frac{1}{x}\\,dx = \\ln|x| + C`}</Eq> (o <Eq>{`|\\cdot|`}</Eq> é necessário para <Eq>{`x < 0`}</Eq>).

</Porta>

## Exemplos

<Exemplo titulo="Antiderivada de um polinômio com condição inicial">
Resolva <Eq>{`y' = 3x^2 - 4x + 1`}</Eq>, <Eq>{`y(1) = 2`}</Eq>.

<Eq>{`y = \\int (3x^2 - 4x + 1)\\,dx = x^3 - 2x^2 + x + C.`}</Eq>

<Eq>{`y(1) = 1 - 2 + 1 + C = C = 2 \\Rightarrow C = 2.`}</Eq>

Solução: <Eq>{`y = x^3 - 2x^2 + x + 2`}</Eq>.

*Fonte: Stewart §4.4, Exemplo 3; Active Calculus §4.4*
</Exemplo>

<Exemplo titulo="Primitiva envolvendo raízes e potências negativas">
<Eq>{`\\int \\left(\\sqrt{x} + \\frac{1}{\\sqrt{x}} - \\frac{2}{x^3}\\right)dx = \\int \\left(x^{1/2} + x^{-1/2} - 2x^{-3}\\right)dx`}</Eq>

<Eq>{`= \\frac{x^{3/2}}{3/2} + \\frac{x^{1/2}}{1/2} + x^{-2} + C = \\frac{2}{3}x\\sqrt{x} + 2\\sqrt{x} + \\frac{1}{x^2} + C.`}</Eq>

*Fonte: Demidovich §5, Ex. 1018; Guidorizzi §5.2*
</Exemplo>

<Exemplo titulo="Antiderivada de funções trigonométricas">
<Eq>{`\\int (3\\sin x - 4\\cos x + \\sec^2 x)\\,dx = -3\\cos x - 4\\sin x + \\tan x + C.`}</Eq>

Verificação: deriva cada termo e confere. $\checkmark$

*Fonte: Stewart §4.4, Exemplo 4; OpenStax Calc I §4.10*
</Exemplo>

<Exemplo titulo="Velocidade e posição a partir da aceleração">
Um objeto tem aceleração <Eq>{`a(t) = \\cos t`}</Eq>, com <Eq>{`v(0) = 1`}</Eq> e <Eq>{`s(0) = -2`}</Eq>.

<Eq>{`v(t) = \\int \\cos t\\,dt = \\sin t + C_1. \\quad v(0) = C_1 = 1.`}</Eq>

<Eq>{`s(t) = \\int (\\sin t + 1)\\,dt = -\\cos t + t + C_2. \\quad s(0) = -1 + C_2 = -2 \\Rightarrow C_2 = -1.`}</Eq>

Solução: <Eq>{`s(t) = -\\cos t + t - 1`}</Eq>.

*Fonte: Apostol §5.3, Exemplo 2*
</Exemplo>

<Exemplo titulo="Antiderivada com identidade trigonométrica">
<Eq>{`\\int \\sin^2 x\\,dx`}</Eq>: use <Eq>{`\\sin^2 x = (1 - \\cos 2x)/2`}</Eq>:

<Eq>{`\\int \\frac{1 - \\cos 2x}{2}\\,dx = \\frac{x}{2} - \\frac{\\sin 2x}{4} + C.`}</Eq>

Verificação: deriva e obtém <Eq>{`1/2 - \\cos(2x)/2 = \\sin^2 x`}</Eq>. $\checkmark$

*Fonte: Demidovich §5, Ex. 1050; Stewart §4.4*
</Exemplo>
