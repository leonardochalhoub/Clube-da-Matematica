<Porta nivel="formal" titulo="Definição rigorosa">

### Derivadas de ordem superior

<Definicao titulo="Derivada de ordem n">

Dada $f$ diferenciável, definimos recursivamente:

$$f^{(0)} = f, \quad f^{(n)} = \frac{d}{dx}\left[f^{(n-1)}\right], \quad n = 1, 2, 3, \ldots$$

**Notações equivalentes:**

$$f'',\; f^{(2)},\; \frac{d^2f}{dx^2},\; D^2 f \quad\text{(segunda derivada)}.$$

$$f^{(n)},\; \frac{d^n f}{dx^n},\; D^n f \quad\text{(}n\text{-ésima derivada)}.$$

</Definicao>

<Teorema titulo="Derivadas de ordem n para funções elementares">

| Função | $n$-ésima derivada |
|--------|-------------------|
| $x^m$ ($m \geq n$) | $\dfrac{m!}{(m-n)!}x^{m-n}$ |
| $x^m$ ($m < n$) | $0$ |
| $e^x$ | $e^x$ |
| $e^{ax}$ | $a^n e^{ax}$ |
| $\sin x$ | $\sin\!\left(x + \dfrac{n\pi}{2}\right)$ |
| $\cos x$ | $\cos\!\left(x + \dfrac{n\pi}{2}\right)$ |
| $\ln x$ | $(-1)^{n-1}\dfrac{(n-1)!}{x^n}$ ($n\geq 1$) |

</Teorema>

<Teorema titulo="Fórmula de Leibniz para o produto">

$(fg)^{(n)} = \displaystyle\sum_{k=0}^n \binom{n}{k} f^{(k)} g^{(n-k)}.$

Análoga ao binômio de Newton, com derivadas no lugar de potências.

</Teorema>

<Cuidado>

A segunda derivada da composição **não** é $(f\circ g)'' = f''(g)\cdot g''$. O correto é:

$$(f(g(x)))'' = f''(g(x))\cdot(g'(x))^2 + f'(g(x))\cdot g''(x).$$

</Cuidado>

</Porta>

<Porta nivel="5anos" titulo="Pra criança de 5 anos">

Você já andou de carro e sentiu quando ele acelera? Quando o carro acelera rápido e depois para de repente, você sente um "solavanco". Isso é a **terceira derivada**!

- Posição: onde você está.
- Velocidade (1ª derivada): como rápido você se move.
- Aceleração (2ª derivada): como rápido a velocidade muda.
- Jerk (3ª derivada): como rápido a aceleração muda — os solavancos!

Cada derivada olha para uma "velocidade" do nível anterior.

</Porta>

<Porta nivel="10anos" titulo="Pra quem tem 10 anos">

A segunda derivada de uma função diz se o gráfico está "curvando para cima" (como uma colina) ou "curvando para baixo" (como um vale).

- Se $f'' > 0$: curva para cima (convexa) — como $y = x^2$.
- Se $f'' < 0$: curva para baixo (côncava) — como $y = -x^2$.

Em física: se $x(t)$ é posição, $x''(t)$ é aceleração. A lei de Newton é $F = m\cdot x''(t)$ — a força é proporcional à segunda derivada da posição!

</Porta>

### Calculando derivadas de ordem superior

**Para polinômios:** Derive repetidamente.

$f(x) = x^5 - 3x^3 + 2x$:
- $f'(x) = 5x^4 - 9x^2 + 2$
- $f''(x) = 20x^3 - 18x$
- $f'''(x) = 60x^2 - 18$
- $f^{(4)}(x) = 120x$
- $f^{(5)}(x) = 120$
- $f^{(n)}(x) = 0$ para $n \geq 6$.

**Para exponencial:** $(e^{ax})^{(n)} = a^n e^{ax}$.

$(e^{3x})'' = 9e^{3x}$, $(e^{3x})''' = 27e^{3x}$.

**Para seno/cosseno:** O padrão se repete com período 4:

$(\sin x)' = \cos x$, $(\sin x)'' = -\sin x$, $(\sin x)''' = -\cos x$, $(\sin x)^{(4)} = \sin x$.

**Para logaritmo:** $(\ln x)^{(n)} = (-1)^{n-1}(n-1)!/x^n$.

$(\ln x)' = 1/x$, $(\ln x)'' = -1/x^2$, $(\ln x)''' = 2/x^3$.

</Porta>

<Porta nivel="25anos" titulo="Pra quem tem 25 anos">

### Importância das derivadas de ordem superior

**Fórmula de Taylor:** A $n$-ésima derivada aparece no coeficiente da série de Taylor:

$$f(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x-a)^k + R_n(x).$$

Quanto mais derivadas conhecemos, melhor a aproximação local de $f$.

**Equações diferenciais:** Muitas EDOs têm soluções envolvendo derivadas de alta ordem. Por exemplo, a equação de vibração de uma viga $EI y^{(4)} = q(x)$ (equação de Euler-Bernoulli) envolve a quarta derivada.

**Caráter de extremo:** Se $f'(a)=0$ e $f''(a)>0$, então $a$ é mínimo local. Se $f''(a)=0$, analisa-se $f'''(a)$ — se não-nulo, é inflexão; se zero, analisa-se $f^{(4)}(a)$ etc. *(Teste da derivada de ordem superior.)*

**Fórmula de Leibniz** — generaliza o produto:

$(x^m e^x)^{(n)} = \displaystyle\sum_{k=0}^n\binom{n}{k}\frac{m!}{(m-k)!}x^{m-k}e^x$ para $m \geq k$.

</Porta>

<Porta nivel="40anos" titulo="Pra quem tem 40 anos (engenharia)">

### Derivadas de ordem superior em engenharia

**Cinemática — jerk e conforto:** Na engenharia ferroviária, o jerk $j = d^3x/dt^3$ (terceira derivada da posição) determina o conforto do passageiro. Normas ISO limitam o jerk máximo admissível. Curvas de transição (espiradas de Euler) são projetadas para ter jerk limitado.

**Viga de Euler-Bernoulli:** A deflexão $y(x)$ de uma viga satisfaz $EIy'''' = q(x)$, onde $E$ é o módulo de elasticidade, $I$ o momento de inércia, e $q$ a carga distribuída. A resolução exige quatro condições de contorno (duas em cada extremidade).

**Análise espectral:** O erro de truncamento de métodos de diferenças finitas de ordem $p$ depende da $(p+1)$-ésima derivada da solução. Métodos de alta ordem são usados quando a solução é suave (muitas derivadas existem e são pequenas).

**Estabilidade de Lyapunov:** Para sistemas de controle $\dot{x} = f(x)$, a estabilidade assintótica é analisada via funções de Lyapunov cujas derivadas de ordem superior fornecem condições suficientes. O critério de Chetaev usa derivadas para provar instabilidade.

</Porta>

<Porta nivel="pratica" titulo="Prática guiada">

### Calculando $f^{(n)}$ de forma geral

**Estratégia:** Calcule $f'$, $f''$, $f'''$ e identifique o padrão.

**Exemplo:** Encontre $f^{(n)}(x)$ para $f(x) = \dfrac{1}{1-x}$.

$f' = (1-x)^{-2}$, $f'' = 2(1-x)^{-3}$, $f''' = 6(1-x)^{-4}$.

Padrão: $f^{(n)}(x) = \dfrac{n!}{(1-x)^{n+1}}$.

**Verificação:** $f^{(n+1)} = (n+1)!(1-x)^{-(n+2)}$, que bate com $n+1$ no lugar de $n$. $\checkmark$

**Equação diferencial:** $f'' + \omega^2 f = 0$ tem soluções $f = A\sin(\omega x) + B\cos(\omega x)$.

Verifique: $(\sin\omega x)'' = -\omega^2\sin\omega x$, logo $(\sin\omega x)'' + \omega^2\sin\omega x = 0$. $\checkmark$

</Porta>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — Segunda derivada de polinômio" numero={1} fonte="Stewart §2.7, Ex. 1–20; Guidorizzi §3.2">

Calcule $f''(x)$ e $f'''(x)$ para $f(x) = 2x^4 - x^3 + 5x^2 - 3$.

$f'(x) = 8x^3 - 3x^2 + 10x$.

$f''(x) = 24x^2 - 6x + 10$.

$f'''(x) = 48x - 6$.

</Exemplo>

<Exemplo titulo="Ex. 2 — n-ésima derivada por padrão" numero={2} fonte="Guidorizzi §3.2, Ex. 5; Apostol I §4.8">

Encontre $f^{(n)}(x)$ para $f(x) = \dfrac{1}{x}$.

$f' = -x^{-2}$, $f'' = 2x^{-3}$, $f''' = -6x^{-4}$, $f^{(4)} = 24x^{-5}$.

Padrão: $f^{(n)}(x) = (-1)^n\dfrac{n!}{x^{n+1}}$.

**Verificação:** $f^{(n+1)} = (-1)^{n+1}\dfrac{(n+1)!}{x^{n+2}}$ — confirma a fórmula com $n+1$. $\checkmark$

</Exemplo>

<Exemplo titulo="Ex. 3 — Segunda derivada de composição" numero={3} fonte="Stewart §2.7, Ex. 25–30; OpenStax Calc I §3.5">

Calcule $g''(x)$ para $g(x) = \sin(x^2)$.

$g'(x) = \cos(x^2)\cdot 2x = 2x\cos(x^2)$.

$g''(x) = 2\cos(x^2) + 2x\cdot(-\sin(x^2))\cdot 2x = 2\cos(x^2) - 4x^2\sin(x^2)$.

*(Note: a fórmula $(f(g(x)))'' = f''(g)g'^2 + f'(g)g''$ daria o mesmo: $-\sin(x^2)\cdot 4x^2 + \cos(x^2)\cdot 2$.)*

</Exemplo>

<Exemplo titulo="Ex. 4 — Fórmula de Leibniz" numero={4} fonte="Apostol I §4.8; Guidorizzi §3.2">

Calcule $(x^2 e^x)^{(4)}$ usando a fórmula de Leibniz com $f=x^2$, $g=e^x$.

$(e^x)^{(k)} = e^x$ para todo $k$.

$(x^2)^{(0)} = x^2$, $(x^2)^{(1)} = 2x$, $(x^2)^{(2)} = 2$, $(x^2)^{(k)} = 0$ para $k\geq 3$.

$(x^2 e^x)^{(4)} = \binom{4}{0}x^2 e^x + \binom{4}{1}2x e^x + \binom{4}{2}2 e^x + 0 + 0$

$= x^2 e^x + 8xe^x + 12e^x = e^x(x^2+8x+12).$

</Exemplo>

<Exemplo titulo="Ex. 5 — Aceleração e jerk" numero={5} fonte="Stewart §2.7, Ex. 31; Active Calculus §1.3; REAMAT cap. 3">

A posição de um veículo (em metros) é $s(t) = t^3 - 6t^2 + 9t + 2$ para $t\geq 0$ (segundos).

$v(t) = s'(t) = 3t^2 - 12t + 9$ (velocidade, m/s).

$a(t) = v'(t) = 6t - 12$ (aceleração, m/s²).

$j(t) = a'(t) = 6$ (jerk, m/s³) — constante!

**(a)** Em $t=2$: $v=0$ (parado momentaneamente), $a=-12$ (desacelerando), $j=6$ (aceleração crescendo).

**(b)** A aceleração é zero em $t=2$ — a velocidade muda de decrescente para crescente: mínimo de $v$.

**(c)** $v=0$ em $t=1$ e $t=3$ — o veículo está momentaneamente parado nessas instâncias.

</Exemplo>
