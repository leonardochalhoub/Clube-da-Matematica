## Roteiro Completo de Análise de Funções

### Sete Etapas Sistemáticas

**1. Domínio** <Eq>{`D_f`}</Eq> — Identifique onde <Eq>{`f`}</Eq> está definida. Exclua zeros de denominador, argumentos negativos de logaritmo/raiz de índice par.

**2. Simetria e periodicidade**
- Ímpar: <Eq>{`f(-x) = -f(x)`}</Eq> (simétrico à origem)
- Par: <Eq>{`f(-x) = f(x)`}</Eq> (simétrico ao eixo <Eq>{`y`}</Eq>)
- Periódica: <Eq>{`f(x+T) = f(x)`}</Eq>

**3. Assíntotas**
- **Vertical** <Eq>{`x = a`}</Eq>: quando <Eq>{`\lim_{x\to a^\pm} f(x) = \pm\infty`}</Eq>
- **Horizontal** <Eq>{`y = L`}</Eq>: quando <Eq>{`\lim_{x\to\pm\infty} f(x) = L`}</Eq>
- **Oblíqua** <Eq>{`y = mx + b`}</Eq>: quando <Eq>{`m = \lim_{x\to\infty} f(x)/x`}</Eq> e <Eq>{`b = \lim_{x\to\infty}[f(x)-mx]`}</Eq>

**4. Monotonia** — Sinais de <Eq>{`f'`}</Eq> e classificação dos pontos críticos.

**5. Extremos locais** — Valor de <Eq>{`f`}</Eq> nos pontos críticos.

**6. Concavidade e inflexões** — Sinais de <Eq>{`f''`}</Eq> e pontos onde muda de sinal.

**7. Pontos notáveis** — Interceptações com eixos (<Eq>{`f(0)`}</Eq>, zeros de <Eq>{`f`}</Eq>).

<Cuidado>
A assíntota oblíqua <Eq>{`y = mx+b`}</Eq> existe **se e somente se** os dois limites que definem <Eq>{`m`}</Eq> e <Eq>{`b`}</Eq> existem (finitos). Uma assíntota horizontal é caso especial com <Eq>{`m = 0`}</Eq>.
</Cuidado>

</Porta>

<Porta tipo="5anos">

## O Mapa do Tesouro da Função

Para desenhar o gráfico de uma função, você é como um detetive que coleta pistas:

1. **Onde ela existe?** (domínio)
2. **Tem simetria?** (espelho)
3. **O que acontece quando vai para muito longe?** (assíntotas)
4. **Onde sobe e desce?** (1ª derivada)
5. **Onde curva para cima ou baixo?** (2ª derivada)

Com essas pistas, você consegue esboçar o gráfico sem precisar calcular centenas de pontos!

</Porta>

<Porta tipo="10anos">

## Esboçando com Informação Estratégica

Em vez de calcular pontos aleatórios, vamos coletar as **informações-chave**:

**Para <Eq>{`f(x) = x/(x-1)`}</Eq>:**

1. **Domínio:** <Eq>{`x \ne 1`}</Eq> (denominador zero em <Eq>{`x=1`}</Eq>)
2. **Sem simetria**
3. **Assíntotas:**
   - Vertical: <Eq>{`x = 1`}</Eq> (denominador zero)
   - Horizontal: <Eq>{`\lim_{x\to\pm\infty} x/(x-1) = 1`}</Eq>, então <Eq>{`y = 1`}</Eq>
4. **<Eq>{`f(0) = 0`}</Eq>** (intercepta eixo <Eq>{`y`}</Eq> na origem)
5. **<Eq>{`f'(x) = -1/(x-1)^2 < 0`}</Eq>** — decrescente em todo domínio

Com isso, o gráfico já é claro: dois ramos que se aproximam das assíntotas.

</Porta>

<Porta tipo="15anos">

## Análise de Assíntota Oblíqua

Uma **assíntota oblíqua** <Eq>{`y = mx + b`}</Eq> existe quando o grau do numerador excede o do denominador em exatamente 1 (em funções racionais), ou em outros casos onde o crescimento é "linear".

**Método:** Para <Eq>{`x \to +\infty`}</Eq>:

<Eq>{`m = \lim_{x\to\infty} \frac{f(x)}{x}, \qquad b = \lim_{x\to\infty} [f(x) - mx].`}</Eq>

**Exemplo:** <Eq>{`f(x) = \frac{x^2+1}{x-1}`}</Eq>

Divisão polinomial: <Eq>{`f(x) = x + 1 + \frac{2}{x-1}.`}</Eq>

Como <Eq>{`2/(x-1) \to 0`}</Eq> quando <Eq>{`x \to \infty`}</Eq>, a assíntota oblíqua é <Eq>{`y = x + 1`}</Eq>.

**Exemplo com raiz:** <Eq>{`f(x) = \sqrt{x^2 + x}`}</Eq>. Para <Eq>{`x \to +\infty`}</Eq>:

<Eq>{`f(x) = x\sqrt{1+1/x} \approx x\left(1 + \frac{1}{2x}\right) = x + \frac{1}{2}.`}</Eq>

Assíntota oblíqua: <Eq>{`y = x + 1/2`}</Eq>.

</Porta>

<Porta tipo="25anos">

## Análise Qualitativa Completa

A análise completa de uma função revela sua **anatomia global**. Os elementos-chave são:

**Comportamento nos extremos:** <Eq>{`\lim_{x\to\pm\infty} f(x)`}</Eq> e <Eq>{`\lim_{x\to a^\pm} f(x)`}</Eq> nos pontos de descontinuidade.

**Estrutura topológica:** O número de ramos (componentes conexas do gráfico), seus limites de cada lado e como se conectam — é o "esqueleto" do gráfico.

**Hierarquia das ordens de crescimento:**
<Eq>{`\ln x \ll x^\alpha \ll e^x \ll e^{x^2} \quad (x \to +\infty),`}</Eq>

onde <Eq>{`f \ll g`}</Eq> significa <Eq>{`f(x)/g(x) \to 0`}</Eq>. Isso determina assíntotas de qualquer combinação dessas funções.

**Simetria e invariâncias:** Reduzem o trabalho pela metade. Uma função par só precisa ser analisada em <Eq>{`[0, +\infty)`}</Eq>.

**Pontos de não diferenciabilidade:** Cantos, cúspides e tangentes verticais são tão importantes quanto os extremos "clássicos" — compõem a análise completa.

</Porta>

<Porta tipo="40anos">

## Análise de Funções em Engenharia

**Resposta em frequência.** Em eletrônica, a função de módulo de uma impedância <Eq>{`|Z(j\omega)| = \sqrt{R^2 + (\omega L - 1/\omega C)^2}`}</Eq> tem um mínimo em <Eq>{`\omega_0 = 1/\sqrt{LC}`}</Eq> (frequência de ressonância). A análise de mínimos/máximos dessa função determina o projeto do filtro.

**Curvas de nível e topografia.** Em problemas bidimensionais, o esboço de <Eq>{`f(x)`}</Eq> é a "seção" de uma superfície — fundamental para entender funções de potencial elétrico, temperatura e pressão.

**Análise de bifurcações.** Em sistemas dinâmicos <Eq>{`\dot{x} = f(x, \mu)`}</Eq>, a análise gráfica de <Eq>{`f(\cdot, \mu)`}</Eq> para diferentes valores do parâmetro <Eq>{`\mu`}</Eq> revela quando equilíbrios surgem, desaparecem ou se tornam instáveis (bifurcações sela-nó, forquilha, Hopf).

**Curvas de custo e demanda.** Em economia de engenharia (engenharia econômica), a análise gráfica de funções de custo total, marginal e médio é o ponto de partida para decisões de projeto e planejamento de produção.

</Porta>

<Porta tipo="pratica">

## Esboço Passo a Passo

**Problema:** Esboce <Eq>{`f(x) = \frac{x^2}{x^2 - 4}`}</Eq>.

**Passo 1 — Domínio:** <Eq>{`x \ne \pm 2`}</Eq>.

**Passo 2 — Simetria:** <Eq>{`f(-x) = f(x)`}</Eq> → função **par** (simétrica ao eixo <Eq>{`y`}</Eq>).

**Passo 3 — Assíntotas:**
- Verticais: <Eq>{`x = 2`}</Eq> e <Eq>{`x = -2`}</Eq>.
- Horizontal: <Eq>{`\lim_{x\to\pm\infty} x^2/(x^2-4) = 1`}</Eq> → <Eq>{`y = 1`}</Eq>.

**Passo 4 — Monotonia:** <Eq>{`f'(x) = -8x/(x^2-4)^2`}</Eq>.
- <Eq>{`f' > 0`}</Eq> para <Eq>{`x < 0`}</Eq> (e <Eq>{`x \ne -2`}</Eq>); <Eq>{`f' < 0`}</Eq> para <Eq>{`x > 0`}</Eq> (e <Eq>{`x \ne 2`}</Eq>).
- Máximo local em <Eq>{`x = 0`}</Eq>: <Eq>{`f(0) = 0`}</Eq>.

**Passo 5 — Concavidade:** (calcule <Eq>{`f''`}</Eq>) — convexa em <Eq>{`(-\infty,-2) \cup (2,+\infty)`}</Eq>, côncava em <Eq>{`(-2,2)`}</Eq>.

**Passo 6 — Pontos notáveis:** <Eq>{`f(0) = 0`}</Eq>; sem zeros reais além de <Eq>{`x = 0`}</Eq>.

</Porta>

## Exemplos

<Exemplo titulo="Análise completa de função racional com assíntota oblíqua">
<Eq>{`f(x) = \frac{x^3}{x^2 - 1} = x + \frac{x}{x^2-1}.`}</Eq>

**Domínio:** <Eq>{`x \ne \pm 1`}</Eq>. **Função ímpar** (<Eq>{`f(-x) = -f(x)`}</Eq>).

**Assíntotas verticais:** <Eq>{`x = 1`}</Eq> e <Eq>{`x = -1`}</Eq>. **Oblíqua:** <Eq>{`y = x`}</Eq>.

**Derivada:** <Eq>{`f'(x) = \frac{x^4-3x^2}{(x^2-1)^2} = \frac{x^2(x^2-3)}{(x^2-1)^2}.`}</Eq>

Pontos críticos: <Eq>{`x = 0`}</Eq> e <Eq>{`x = \pm\sqrt{3}`}</Eq>. Em <Eq>{`x = 0`}</Eq>: <Eq>{`f(0) = 0`}</Eq>, ponto de sela (pela simetria e análise). Em <Eq>{`x = \pm\sqrt{3}`}</Eq>: extremos locais.

*Fonte: Stewart §3.5, Exemplo 5*
</Exemplo>

<Exemplo titulo="Função com assíntota oblíqua via raiz">
<Eq>{`f(x) = x - \sqrt{x^2 + 1}.`}</Eq>

Para <Eq>{`x \to +\infty`}</Eq>: <Eq>{`f(x) = x - x\sqrt{1+1/x^2} \approx x - x(1+1/(2x^2)) = -1/(2x) \to 0`}</Eq>. Assíntota horizontal <Eq>{`y = 0`}</Eq>.

Para <Eq>{`x \to -\infty`}</Eq>: <Eq>{`\sqrt{x^2+1} \approx |x| = -x`}</Eq>, então <Eq>{`f(x) \approx x - (-x) = 2x \to -\infty`}</Eq>. Assíntota oblíqua <Eq>{`y = 2x`}</Eq>.

*Fonte: Demidovich §4, Problema 425*
</Exemplo>

<Exemplo titulo="Função com ponto cúspide: f(x) = x^{2/3}(x − 3)">
**Domínio:** <Eq>{`\mathbb{R}`}</Eq>. **Zeros:** <Eq>{`x = 0`}</Eq> e <Eq>{`x = 3`}</Eq>.

<Eq>{`f'(x) = \frac{2}{3}x^{-1/3}(x-3) + x^{2/3} = \frac{5x-6}{3x^{1/3}}.`}</Eq>

Pontos críticos: <Eq>{`x = 0`}</Eq> (<Eq>{`f'`}</Eq> não existe — cúspide) e <Eq>{`x = 6/5`}</Eq> (<Eq>{`f' = 0`}</Eq>).

Em <Eq>{`x = 6/5`}</Eq>: mínimo local (<Eq>{`f'`}</Eq> muda de <Eq>{`-`}</Eq> para <Eq>{`+`}</Eq>). Em <Eq>{`x = 0`}</Eq>: máximo local (<Eq>{`f'`}</Eq> muda de <Eq>{`+`}</Eq> para <Eq>{`-`}</Eq> passando pelo ponto não-diferenciável).

*Fonte: Stewart §3.6, Exemplo 6; Guidorizzi §4.3*
</Exemplo>

<Exemplo titulo="Análise de função trigonométrica">
<Eq>{`f(x) = 2\sin x - \sin(2x), \quad x \in [0, 2\pi].`}</Eq>

<Eq>{`f'(x) = 2\cos x - 2\cos(2x) = 2\cos x - 2(2\cos^2 x - 1) = -4\cos^2 x + 2\cos x + 2.`}</Eq>

Seja <Eq>{`u = \cos x`}</Eq>: <Eq>{`f' = 0 \iff 4u^2 - 2u - 2 = 0 \iff u = 1`}</Eq> ou <Eq>{`u = -1/2`}</Eq>.

- <Eq>{`\cos x = 1 \Rightarrow x = 0`}</Eq> (borda)
- <Eq>{`\cos x = -1/2 \Rightarrow x = 2\pi/3`}</Eq> ou <Eq>{`x = 4\pi/3`}</Eq>

Máximo em <Eq>{`x = 2\pi/3`}</Eq>: <Eq>{`f(2\pi/3) = 3\sqrt{3}/2`}</Eq>. Mínimo em <Eq>{`x = 4\pi/3`}</Eq>: <Eq>{`f(4\pi/3) = -3\sqrt{3}/2`}</Eq>.

*Fonte: Courant & John §5.3; Active Calculus §3.3*
</Exemplo>

<Exemplo titulo="Esboço de função com dois parâmetros">
Para que valores de <Eq>{`a`}</Eq> a função <Eq>{`f(x) = x^3 - ax`}</Eq> tem dois extremos locais?

<Eq>{`f'(x) = 3x^2 - a.`}</Eq>

Para dois zeros de <Eq>{`f'`}</Eq> (dois pontos críticos): precisamos <Eq>{`a > 0`}</Eq> e <Eq>{`x = \pm\sqrt{a/3}`}</Eq>.

Para <Eq>{`a > 0`}</Eq>: <Eq>{`f(\sqrt{a/3}) = -(2a/3)\sqrt{a/3}`}</Eq> (mínimo) e <Eq>{`f(-\sqrt{a/3}) = (2a/3)\sqrt{a/3}`}</Eq> (máximo). Para <Eq>{`a \le 0`}</Eq>: <Eq>{`f' \ge 0`}</Eq> — sem extremos locais.

*Fonte: Demidovich §4, Problema 438*
</Exemplo>
