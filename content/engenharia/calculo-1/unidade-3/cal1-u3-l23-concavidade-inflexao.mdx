## Concavidade e Pontos de Inflexão

<Definicao titulo="Função convexa e côncava">
Uma função <Eq>{`f`}</Eq> é **convexa** (côncava para cima) num intervalo <Eq>{`I`}</Eq> se, para quaisquer <Eq>{`x_1, x_2 \in I`}</Eq> e <Eq>{`t \in [0,1]`}</Eq>:

<Eq>{`f(tx_1 + (1-t)x_2) \le tf(x_1) + (1-t)f(x_2).`}</Eq>

É **côncava** (côncava para baixo) se a desigualdade é invertida.
</Definicao>

<Teorema titulo="Critério da 2ª derivada para concavidade">
Seja <Eq>{`f`}</Eq> duas vezes diferenciável em <Eq>{`(a,b)`}</Eq>:
- Se <Eq>{`f''(x) > 0`}</Eq> para todo <Eq>{`x \in (a,b)`}</Eq>, então <Eq>{`f`}</Eq> é convexa em <Eq>{`(a,b)`}</Eq>.
- Se <Eq>{`f''(x) < 0`}</Eq> para todo <Eq>{`x \in (a,b)`}</Eq>, então <Eq>{`f`}</Eq> é côncava em <Eq>{`(a,b)`}</Eq>.
</Teorema>

<Definicao titulo="Ponto de inflexão">
O ponto <Eq>{`(x_0, f(x_0))`}</Eq> é **ponto de inflexão** se <Eq>{`f`}</Eq> muda de convexidade em <Eq>{`x_0`}</Eq>, ou seja, <Eq>{`f''`}</Eq> muda de sinal em <Eq>{`x_0`}</Eq>.

**Condição necessária:** Se <Eq>{`f`}</Eq> tem ponto de inflexão em <Eq>{`x_0`}</Eq> e <Eq>{`f''(x_0)`}</Eq> existe, então <Eq>{`f''(x_0) = 0`}</Eq>.
</Definicao>

### Teste da 2ª Derivada para Extremos Locais

Seja <Eq>{`f'(x_0) = 0`}</Eq> (ponto crítico):
- Se <Eq>{`f''(x_0) > 0`}</Eq> → <Eq>{`x_0`}</Eq> é **mínimo local**.
- Se <Eq>{`f''(x_0) < 0`}</Eq> → <Eq>{`x_0`}</Eq> é **máximo local**.
- Se <Eq>{`f''(x_0) = 0`}</Eq> → **inconclusivo** (use o Teste da 1ª Derivada).

**Intuição:** Se a função "abre para cima" (<Eq>{`f'' > 0`}</Eq>) num ponto crítico, ele é um mínimo. Se "abre para baixo" (<Eq>{`f'' < 0`}</Eq>), é um máximo.

<Cuidado>
<Eq>{`f''(x_0) = 0`}</Eq> **não** implica que <Eq>{`x_0`}</Eq> é ponto de inflexão — é necessário que <Eq>{`f''`}</Eq> mude de sinal. Para <Eq>{`f(x) = x^4`}</Eq>: <Eq>{`f''(0) = 0`}</Eq> mas <Eq>{`f''`}</Eq> não muda de sinal — não é inflexão.
</Cuidado>

## A Tigela e a Montanha

Pensa numa tigela. Ela é côncava para cima — se você jogar água, ela fica. Isso é uma função **convexa**: curva que "abre para cima".

Agora pensa numa montanha. Ela é côncava para baixo — a água escorre. Isso é uma função **côncava**: curva que "abre para baixo".

O ponto de inflexão é onde a curva **muda de tigela para montanha** (ou vice-versa) — é onde ela muda de curvatura.

</Porta>

<Porta tipo="10anos">

## Quando a Curva "Abre" para Cima ou para Baixo

A **2ª derivada** <Eq>{`f''(x)`}</Eq> mede como a inclinação está mudando:

- <Eq>{`f''(x) > 0`}</Eq>: a inclinação está aumentando → curva em forma de tigela (convexa)
- <Eq>{`f''(x) < 0`}</Eq>: a inclinação está diminuindo → curva em forma de morro (côncava)

**Exemplo:** <Eq>{`f(x) = x^2`}</Eq>. Como <Eq>{`f''(x) = 2 > 0`}</Eq> em todo ponto, a parábola é sempre convexa — é uma tigela.

**Exemplo:** <Eq>{`f(x) = -x^2`}</Eq>. Como <Eq>{`f''(x) = -2 < 0`}</Eq>, é sempre côncava — é uma montanha.

**Ponto de inflexão:** onde a função troca de tigela para montanha. Para <Eq>{`f(x) = x^3`}</Eq>: <Eq>{`f''(x) = 6x`}</Eq>, que muda de sinal em <Eq>{`x = 0`}</Eq> → ponto de inflexão em <Eq>{`(0, 0)`}</Eq>.

</Porta>

## Análise Combinada: 1ª e 2ª Derivada

Combinando o teste das duas derivadas, obtemos um quadro completo do comportamento local de <Eq>{`f`}</Eq>:

| <Eq>{`f'`}</Eq> | <Eq>{`f''`}</Eq> | Comportamento |
|------|------|--------------|
| <Eq>{`+`}</Eq> | <Eq>{`+`}</Eq> | crescente, curvando para cima |
| <Eq>{`+`}</Eq> | <Eq>{`-`}</Eq> | crescente, curvando para baixo |
| <Eq>{`-`}</Eq> | <Eq>{`+`}</Eq> | decrescente, curvando para cima |
| <Eq>{`-`}</Eq> | <Eq>{`-`}</Eq> | decrescente, curvando para baixo |

**Exemplo completo:** <Eq>{`f(x) = x^4 - 4x^3`}</Eq>

<Eq>{`f'(x) = 4x^3 - 12x^2 = 4x^2(x-3) \quad \Rightarrow \quad \text{pontos críticos: } x = 0, x = 3.`}</Eq>

<Eq>{`f''(x) = 12x^2 - 24x = 12x(x-2) \quad \Rightarrow \quad f''= 0 \text{ em } x = 0 \text{ e } x = 2.`}</Eq>

- Inflexões: <Eq>{`x = 0`}</Eq> (<Eq>{`f''`}</Eq> muda <Eq>{`+ \to -`}</Eq>) e <Eq>{`x = 2`}</Eq> (<Eq>{`f''`}</Eq> muda <Eq>{`- \to +`}</Eq>).
- <Eq>{`x = 0`}</Eq>: <Eq>{`f'(0) = 0`}</Eq> e <Eq>{`f''(0) = 0`}</Eq> → **inconclusivo pelo teste da 2ª derivada** → use 1ª: <Eq>{`f'`}</Eq> não muda de sinal → **não é extremo** (ponto de sela).
- <Eq>{`x = 3`}</Eq>: <Eq>{`f''(3) = 12(3)(1) = 36 > 0`}</Eq> → **mínimo local**.

</Porta>

## Convexidade: Fundamentos e Caracterizações

**Três caracterizações equivalentes de convexidade** (quando <Eq>{`f \in C^2`}</Eq>):

1. **Geométrica:** a corda entre quaisquer dois pontos fica acima do gráfico.
2. **Via tangente:** o gráfico fica acima de qualquer tangente: <Eq>{`f(x) \ge f(x_0) + f'(x_0)(x-x_0)`}</Eq>.
3. **Via 2ª derivada:** <Eq>{`f''(x) \ge 0`}</Eq> para todo <Eq>{`x`}</Eq>.

**Desigualdade de Jensen.** Se <Eq>{`f`}</Eq> é convexa e <Eq>{`p_i \ge 0`}</Eq> com <Eq>{`\sum p_i = 1`}</Eq>:
<Eq>{`f\left(\sum p_i x_i\right) \le \sum p_i f(x_i).`}</Eq>

Isso generaliza "a média do valor é menor ou igual ao valor da média" para convexas.

**Aplicação: desigualdade AM-GM.** Usando <Eq>{`f(x) = -\ln x`}</Eq> (convexa) com pesos iguais:
<Eq>{`-\ln\!\left(\frac{x_1+\cdots+x_n}{n}\right) \le \frac{-\ln x_1 - \cdots - \ln x_n}{n}`}</Eq>

<Eq>{`\Rightarrow \quad \frac{x_1+\cdots+x_n}{n} \ge (x_1 \cdots x_n)^{1/n}.`}</Eq>

</Porta>

<Porta tipo="40anos">

## Convexidade em Otimização e Engenharia

**Otimização convexa.** Todo mínimo local de uma função convexa é global. Isso é o fundamento de toda a otimização convexa moderna (programação linear, quadrática, semidefinida). Algoritmos como gradiente descendente convergem globalmente para funções convexas com Lipschitz-derivada.

**Análise de estabilidade de Lyapunov.** Se <Eq>{`V(x)`}</Eq> é convexa em torno de um equilíbrio <Eq>{`x^*`}</Eq>, então o sistema <Eq>{`\dot{x} = -\nabla V(x)`}</Eq> converge a <Eq>{`x^*`}</Eq> monotonicamente — sem oscilações.

**Resposta de sistemas ao degrau.** A concavidade da resposta temporal indica se o sistema está acelerando (<Eq>{`y'' > 0`}</Eq>) ou desacelerando (<Eq>{`y'' < 0`}</Eq>) sua aproximação ao valor final. O ponto de inflexão da resposta é o instante de máxima taxa de variação.

**Curvas S e crescimento logístico.** A equação logística <Eq>{`P(t) = K/(1+Ae^{-rt})`}</Eq> tem exatamente um ponto de inflexão em <Eq>{`t^* = \ln(A)/r`}</Eq>, correspondendo ao instante de máxima taxa de crescimento — fundamental em epidemiologia (curva da pandemia) e adoção de tecnologia.

</Porta>

<Porta tipo="pratica">

## Encontrando Inflexões na Prática

**Roteiro:** Calcule <Eq>{`f''`}</Eq>, encontre zeros e onde não existe, verifique mudança de sinal.

**Exemplo prático:** Curva de aprendizado <Eq>{`f(t) = 100 \cdot \frac{t^2}{t^2 + 100}`}</Eq> (eficiência em percentual após <Eq>{`t`}</Eq> horas de prática).

<Eq>{`f'(t) = \frac{20000t}{(t^2+100)^2} > 0 \quad \forall t > 0.`}</Eq>

<Eq>{`f''(t) = \frac{20000(100-3t^2)}{(t^2+100)^3}.`}</Eq>

<Eq>{`f''(t) = 0 \iff t = 10/\sqrt{3} \approx 5{,}77 \text{ horas}.`}</Eq>

Antes de 5,77h: <Eq>{`f'' > 0`}</Eq> (aprendizado acelerando). Após 5,77h: <Eq>{`f'' < 0`}</Eq> (aprendizado desacelerando).

**Interpretação:** O ponto de inflexão é o momento de **máxima velocidade de aprendizado** — após esse ponto, continua crescendo, mas cada hora adicional traz menos ganho.

</Porta>

## Exemplos

<Exemplo titulo="Análise completa de concavidade: f(x) = x⁴ − 6x²">
<Eq>{`f'(x) = 4x^3 - 12x = 4x(x^2-3).`}</Eq>

<Eq>{`f''(x) = 12x^2 - 12 = 12(x-1)(x+1).`}</Eq>

**Concavidade:** <Eq>{`f'' > 0`}</Eq> em <Eq>{`(-\infty,-1) \cup (1,+\infty)`}</Eq> (convexa). <Eq>{`f'' < 0`}</Eq> em <Eq>{`(-1,1)`}</Eq> (côncava).

**Inflexões:** <Eq>{`x = -1`}</Eq> (<Eq>{`f(-1) = -5`}</Eq>) e <Eq>{`x = 1`}</Eq> (<Eq>{`f(1) = -5`}</Eq>).

**Extremos:** <Eq>{`x = 0`}</Eq>: <Eq>{`f''(0) = -12 < 0`}</Eq> → máximo local <Eq>{`f(0) = 0`}</Eq>. <Eq>{`x = \pm\sqrt{3}`}</Eq>: <Eq>{`f''(\pm\sqrt{3}) = 12(3-1) > 0`}</Eq> → mínimos locais <Eq>{`f(\pm\sqrt{3}) = -9`}</Eq>.

*Fonte: Stewart §3.4, Exemplo 4*
</Exemplo>

<Exemplo titulo="Inflexão sem f'' = 0: função com derivada não existente">
Para <Eq>{`f(x) = x^{1/3}`}</Eq>:

<Eq>{`f'(x) = \frac{1}{3}x^{-2/3}, \quad f''(x) = -\frac{2}{9}x^{-5/3}.`}</Eq>

Em <Eq>{`x = 0`}</Eq>: <Eq>{`f''`}</Eq> não existe. Para <Eq>{`x < 0`}</Eq>: <Eq>{`f'' > 0`}</Eq> (convexa). Para <Eq>{`x > 0`}</Eq>: <Eq>{`f'' < 0`}</Eq> (côncava).

Logo <Eq>{`(0, 0)`}</Eq> é **ponto de inflexão**, mesmo sem <Eq>{`f''(0) = 0`}</Eq>.

*Fonte: Stewart §3.4; Apostol §4.7*
</Exemplo>

<Exemplo titulo="Teste da 2ª derivada inconclusivo: f(x) = x⁴">
<Eq>{`f'(x) = 4x^3, \quad f'(0) = 0. \quad f''(x) = 12x^2, \quad f''(0) = 0.`}</Eq>

O teste da 2ª derivada é **inconclusivo**. Mas <Eq>{`f''(x) = 12x^2 \ge 0`}</Eq> e não muda de sinal em <Eq>{`0`}</Eq> — não é inflexão. Pelo Teste da 1ª: <Eq>{`f' = 4x^3`}</Eq> muda de <Eq>{`-`}</Eq> para <Eq>{`+`}</Eq> em <Eq>{`x = 0`}</Eq> → **mínimo local** (<Eq>{`f(0) = 0`}</Eq>).

*Fonte: Guidorizzi §4.2; Spivak §11*
</Exemplo>

<Exemplo titulo="Desigualdade de Jensen aplicada">
Seja <Eq>{`f(x) = e^x`}</Eq> (convexa, pois <Eq>{`f'' = e^x > 0`}</Eq>). Pelo caráter convexo (gráfico acima das tangentes):

<Eq>{`e^x \ge 1 + x \quad \forall x.`}</Eq>

Pela desigualdade de Jensen com pesos <Eq>{`1/n`}</Eq>:

<Eq>{`e^{(x_1+\cdots+x_n)/n} \le \frac{e^{x_1}+\cdots+e^{x_n}}{n}.`}</Eq>

Substituindo <Eq>{`x_i = \ln a_i`}</Eq>: média geométrica ≤ média aritmética.

*Fonte: Courant & John §5.2; Apostol §4.7*
</Exemplo>

<Exemplo titulo="Análise de curva logística (pandemia/adoção de tecnologia)">
<Eq>{`P(t) = \frac{1000}{1 + 99e^{-0{,}2t}}.`}</Eq>

<Eq>{`P'(t) = \frac{1000 \cdot 99 \cdot 0{,}2 \cdot e^{-0{,}2t}}{(1+99e^{-0{,}2t})^2} > 0.`}</Eq>

Para encontrar o ponto de inflexão: <Eq>{`P'' = 0`}</Eq> quando <Eq>{`P(t) = K/2 = 500`}</Eq>.

<Eq>{`500 = \frac{1000}{1+99e^{-0{,}2t}} \implies e^{-0{,}2t} = \frac{1}{99} \implies t = \frac{\ln 99}{0{,}2} \approx 23 \text{ dias}.`}</Eq>

**Interpretação:** O número de casos cresce mais rapidamente até o dia 23, depois a taxa de crescimento diminui — é o "achatamento da curva".

*Fonte: Active Calculus §3.1, Atividade de modelagem*
</Exemplo>
