## Conexões Profundas

**TVM → Taylor.** O TVM é o caso <Eq>{`n = 0`}</Eq> do Teorema de Taylor: <Eq>{`f(b) - f(a) = f'(c)(b-a)`}</Eq>. Taylor generaliza para qualquer ordem.

**Taylor → Newton-Raphson.** A derivação da convergência quadrática de Newton é exatamente aplicar Taylor de grau 2 ao redor da raiz.

**Convexidade → Desigualdades.** A interpretação geométrica de função convexa (gráfico abaixo da corda) produz Jensen, AM-GM, Young, Hölder — todas as grandes desigualdades clássicas.

**L'Hôpital → Análise assintótica.** A hierarquia de crescimento <Eq>{`\ln x \ll x^a \ll e^x`}</Eq> determina as assíntotas de qualquer combinação dessas funções.

**Otimização → Equações.** Todo problema de otimização gera uma equação <Eq>{`f'(x) = 0`}</Eq> que pode não ter solução analítica — Newton-Raphson entra para resolvê-la numericamente.

</Porta>

## Perspectiva de Engenharia

As aplicações desta unidade são o núcleo da análise de sistemas:

**Análise de estabilidade** usa TVM e monotonicidade para verificar quando sistemas se estabilizam.

**Projeto ótimo** usa otimização com restrições — a ferramenta diária de engenheiros de projeto, econometria e pesquisa operacional.

**Controle PID** usa a integral + derivada do erro — análise de extremos e taxas de variação.

**Algoritmos de otimização** em machine learning (Adam, RMSProp, L-BFGS) são variações de Newton-Raphson e gradiente descendente.

**Aproximações em tempo real** em sistemas embarcados usam Taylor truncado — menos custos computacionais que funções trigonométricas ou exponenciais exatas.

</Porta>

## Gabarito Selecionado

<Exemplo titulo="Gabarito — Ex. 9(a): Ponto fixo único">
Defina <Eq>{`h(x) = f(x) - x`}</Eq>. Como <Eq>{`f: [0,1] \to [0,1]`}</Eq>: <Eq>{`h(0) = f(0) \ge 0`}</Eq> e <Eq>{`h(1) = f(1) - 1 \le 0`}</Eq>. Pelo TVI, existe <Eq>{`x^*`}</Eq> com <Eq>{`h(x^*) = 0`}</Eq>, i.e., <Eq>{`f(x^*) = x^*`}</Eq>.

**Unicidade:** Se <Eq>{`f(a) = a`}</Eq> e <Eq>{`f(b) = b`}</Eq> com <Eq>{`a \ne b`}</Eq>, pelo TVM:

<Eq>{`|a - b| = |f(a) - f(b)| = |f'(c)||a-b| \le k|a-b| < |a-b|.`}</Eq>

Contradição. Logo o ponto fixo é único. <Eq>{`\square`}</Eq>
</Exemplo>

<Exemplo titulo="Gabarito — Ex. 20(b): Taylor alterna em torno de sin x">
Para <Eq>{`n = 0`}</Eq>: <Eq>{`P_0(x) = x`}</Eq>. Precisamos <Eq>{`\sin x < x`}</Eq> para <Eq>{`x > 0`}</Eq>.

Seja <Eq>{`f(x) = x - \sin x`}</Eq>. <Eq>{`f(0) = 0`}</Eq>, <Eq>{`f'(x) = 1 - \cos x \ge 0`}</Eq> com igualdade apenas em <Eq>{`x = 2k\pi`}</Eq>. Logo <Eq>{`f`}</Eq> é crescente, <Eq>{`f(x) > 0`}</Eq> para <Eq>{`x > 0`}</Eq>: <Eq>{`\sin x < x`}</Eq>. $\checkmark$

Para <Eq>{`n = 1`}</Eq>: <Eq>{`P_1(x) = x - x^3/6`}</Eq>. Precisamos <Eq>{`x - x^3/6 < \sin x`}</Eq>. 

Seja <Eq>{`g(x) = \sin x - x + x^3/6`}</Eq>. <Eq>{`g(0) = 0`}</Eq>, <Eq>{`g'(x) = \cos x - 1 + x^2/2`}</Eq>, <Eq>{`g'(0) = 0`}</Eq>, <Eq>{`g''(x) = -\sin x + x \ge 0`}</Eq> para <Eq>{`x \ge 0`}</Eq> (pela primeira parte). Logo <Eq>{`g'`}</Eq> cresce, <Eq>{`g' \ge 0`}</Eq>, <Eq>{`g`}</Eq> cresce: <Eq>{`g(x) > 0`}</Eq> para <Eq>{`x > 0`}</Eq>. $\checkmark$
</Exemplo>
