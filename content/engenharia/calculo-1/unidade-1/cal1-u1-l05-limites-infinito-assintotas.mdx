<Porta nivel="formal" titulo="Definição rigorosa">

### Limites no infinito — definições formais

<Definicao titulo="Limite quando x → +∞">

Seja $f: D \to \mathbb{R}$ com $D$ não limitado superiormente. Dizemos que

$$\lim_{x \to +\infty} f(x) = L$$

se para todo $\varepsilon > 0$ existe $M > 0$ tal que

$$x > M \implies |f(x) - L| < \varepsilon.$$

Analogamente, $\lim_{x \to -\infty} f(x) = L$ se $\forall\varepsilon > 0, \exists M: x < -M \Rightarrow |f(x)-L| < \varepsilon$.

</Definicao>

<Definicao titulo="Limite infinito em ponto finito">

Dizemos que $\lim_{x \to a^+} f(x) = +\infty$ se

$$\forall\, K > 0,\; \exists\, \delta > 0 : 0 < x - a < \delta \implies f(x) > K.$$

Casos análogos: $x \to a^-$, $f(x) \to -\infty$.

</Definicao>

<Definicao titulo="Assíntotas">

- **Horizontal:** $y = L$ é assíntota horizontal de $f$ se $\lim_{x\to\pm\infty} f(x) = L$.
- **Vertical:** $x = a$ é assíntota vertical se $\lim_{x \to a} f(x) = \pm\infty$ (de pelo menos um lado).
- **Oblíqua:** $y = mx + b$ ($m \neq 0$) é assíntota oblíqua se $\lim_{x\to\pm\infty}[f(x) - (mx+b)] = 0$.

</Definicao>

<Teorema titulo="Limites de funções racionais no infinito">

Seja $r(x) = p(x)/q(x)$ com $\deg p = m$, $\deg q = n$, coeficientes líderes $a_m$ e $b_n$.

- Se $m < n$: $\lim_{x\to\pm\infty} r(x) = 0$ (assíntota $y=0$).
- Se $m = n$: $\lim_{x\to\pm\infty} r(x) = a_m/b_n$ (assíntota $y = a_m/b_n$).
- Se $m = n+1$: divisão polinomial fornece assíntota oblíqua.
- Se $m > n+1$: $|r(x)| \to \infty$ sem assíntota.

</Teorema>

<Cuidado>

Para radicais com $x \to -\infty$: $\sqrt{x^2} = |x| = -x$ (pois $x < 0$). Esquecer esse sinal é o erro mais comum nessa seção.

</Cuidado>

</Porta>

<Porta nivel="5" titulo="5 anos — Cada vez mais longe">

Imagina que você está numa estrada reta, andando para frente cada vez mais longe. O horizonte sempre parece estar a uma certa distância de você — digamos, parece estar sempre a 10 km. Não importa quanto você ande, o horizonte não chega a zero nem a 100 km: ele "tende a" 10 km.

Isso é um **limite no infinito**: conforme você anda mais e mais ($x$ fica grande), a distância até o horizonte ($f(x)$) se aproxima de um número fixo ($L = 10$).

A linha que o horizonte "promete" mas nunca atinge é a **assíntota**. Ela é como uma promessa que o gráfico faz mas nunca cumpre completamente.

</Porta>

<Porta nivel="10" titulo="10 anos — O que acontece quando x cresce muito?">

Pensa em $f(x) = 1/x$. Quando $x$ fica grande:

| $x$ | $1/x$ |
|---|---|
| 10 | 0,1 |
| 100 | 0,01 |
| 1000 | 0,001 |
| 1 000 000 | 0,000001 |

A função vai ficando cada vez mais próxima de **zero**, mas nunca chega a zero. Escrevemos $\lim_{x\to\infty} 1/x = 0$.

O eixo $x$ (a reta $y = 0$) é a **assíntota horizontal**. O eixo $y$ (a reta $x = 0$) é a **assíntota vertical**, porque quando $x \to 0$, $1/x$ vai para infinito.

</Porta>

<Porta nivel="15" titulo="15 anos — A técnica do grau dominante">

Para calcular $\displaystyle\lim_{x\to\infty}\frac{3x^2 - 5x + 1}{2x^2 + x - 3}$, o truque é **dividir tudo pelo maior grau**:

$$\frac{3x^2 - 5x + 1}{2x^2 + x - 3} = \frac{3 - 5/x + 1/x^2}{2 + 1/x - 3/x^2}$$

Quando $x \to \infty$, todos os termos com $1/x$ ou $1/x^2$ vão a zero. Sobra $\dfrac{3}{2}$.

**Regra prática:** em funções racionais, só os coeficientes dos termos de maior grau importam no infinito.

**Radicais:** $\sqrt{9x^2 + 1} \approx 3x$ para $x$ grande (e $\approx -3x$ para $x < 0$ muito negativo).

**Assíntota oblíqua:** quando $\deg(\text{num}) = \deg(\text{den}) + 1$, divida o polinômio: o quociente linear é a assíntota.

</Porta>

<Porta nivel="25" titulo="25 anos — Casos e armadilhas">

**Três casos para racionais** $p(x)/q(x)$:

1. $\deg p < \deg q$: limite 0, assíntota $y = 0$.
2. $\deg p = \deg q$: limite = razão dos coeficientes líderes.
3. $\deg p = \deg q + 1$: divida para obter assíntota oblíqua.

**Radicais e sinal:** $\lim_{x\to-\infty} \sqrt{4x^2+1}/(2x+1)$. Use $\sqrt{4x^2+1} = |x|\sqrt{4+1/x^2} = -x\sqrt{4+1/x^2}$ pois $x < 0$. Resultado: $-2x/(2x+1) \to -1$.

**Limite usando soma conjugada:**
$$\lim_{x\to\infty}\left[x - \sqrt{x^2 - x}\right] = \lim_{x\to\infty}\frac{x^2 - (x^2 - x)}{x + \sqrt{x^2-x}} = \lim_{x\to\infty}\frac{x}{x + x\sqrt{1-1/x}} = \frac{1}{2}$$

**Definição ε-M na prática:** para provar $\lim_{x\to\infty} 1/x = 0$, dado $\varepsilon > 0$, tome $M = 1/\varepsilon$: se $x > M$, então $|1/x - 0| = 1/x < 1/M = \varepsilon$. $\square$

</Porta>

<Porta nivel="40" titulo="40 anos — Análise assintótica em engenharia">

**Circuitos RC:** a resposta ao degrau é $V(t) = V_0(1 - e^{-t/\tau})$. O engenheiro sabe que $\lim_{t\to\infty} V(t) = V_0$ — isso determina o ponto de operação em regime permanente. A constante $\tau = RC$ é o "tempo para 63% do degrau", e $5\tau$ é "praticamente no infinito" para efeitos práticos.

**Diagramas de Bode:** a função de transferência $H(j\omega)$ de um filtro passa-baixa tem $|H(j\omega)| \to 0$ quando $\omega \to \infty$ (atenua frequências altas). Assíntotas de Bode são aproximações lineares (em dB/décade) exatamente do comportamento assintótico.

**Mecânica:** a velocidade terminal de queda $v(t) = v_t(1 - e^{-gt/v_t})$ satisfaz $\lim_{t\to\infty} v(t) = v_t$. Modelar a assíntota é modelar o comportamento de longo prazo.

**Estabilidade:** um sistema dinâmico $\dot{x} = Ax$ é estável se $\lim_{t\to\infty} x(t) = 0$. A questão de estabilidade é uma questão de limite no infinito.

</Porta>

<Porta nivel="pratica" titulo="Prática — Assíntotas e comportamento assintótico">

### Função de transferência de filtro

Um filtro Butterworth de 1ª ordem tem ganho $H(\omega) = \dfrac{1}{\sqrt{1 + (\omega/\omega_0)^2}}$.

**Passo 1 — assíntota em $\omega \to 0$:**
$$\lim_{\omega\to 0} H(\omega) = \frac{1}{\sqrt{1+0}} = 1 \quad (0\,\text{dB})$$

**Passo 2 — assíntota em $\omega \to \infty$:**
$$H(\omega) = \frac{1}{\sqrt{1+(\omega/\omega_0)^2}} \approx \frac{\omega_0}{\omega} \quad (\omega \gg \omega_0)$$

Logo $H(\omega) \to 0$ e a reta $H = \omega_0/\omega$ é a assíntota oblíqua em escala log-log (inclinação $-20\,\text{dB/década}$).

**Passo 3 — frequência de corte:** $H(\omega_0) = 1/\sqrt{2} \approx -3\,\text{dB}$, ponto onde as duas assíntotas se cruzam.

</Porta>

<Exemplo titulo="Limite racional no infinito — grau dominante" numero="1">

**Problema:** $\displaystyle\lim_{x \to \infty} \frac{3x^2 - x + 5}{2x^2 + 7x - 3}$

**Estratégia:** dividir numerador e denominador por $x^2$ (maior grau).

$$\frac{3x^2 - x + 5}{2x^2 + 7x - 3} = \frac{3 - 1/x + 5/x^2}{2 + 7/x - 3/x^2}$$

Quando $x \to \infty$: todos os termos $1/x^k \to 0$.

$$\lim_{x\to\infty}\frac{3x^2 - x + 5}{2x^2 + 7x - 3} = \frac{3 - 0 + 0}{2 + 0 - 0} = \frac{3}{2}$$

A reta $y = 3/2$ é assíntota horizontal.

**Fonte.** Stewart — Cálculo, §2.6, Exemplo 1. Cengage, 8ª ed.

</Exemplo>

<Exemplo titulo="Limite com radical — cuidado com o sinal" numero="2">

**Problema:** $\displaystyle\lim_{x \to \pm\infty} \frac{\sqrt{4x^2 + 1}}{2x + 1}$

**Para $x \to +\infty$:** $\sqrt{4x^2+1} = x\sqrt{4 + 1/x^2}$ (pois $x > 0$).

$$\frac{x\sqrt{4+1/x^2}}{2x+1} = \frac{\sqrt{4+1/x^2}}{2+1/x} \xrightarrow{x\to+\infty} \frac{2}{2} = 1$$

**Para $x \to -\infty$:** $\sqrt{4x^2+1} = |x|\sqrt{4+1/x^2} = -x\sqrt{4+1/x^2}$ (pois $x < 0$).

$$\frac{-x\sqrt{4+1/x^2}}{2x+1} = \frac{-\sqrt{4+1/x^2}}{2+1/x} \xrightarrow{x\to-\infty} \frac{-2}{2} = -1$$

Duas assíntotas horizontais: $y = 1$ (para $x \to +\infty$) e $y = -1$ (para $x \to -\infty$).

**Fonte.** Stewart — Cálculo, §2.6, Exemplos 3–4. Cengage, 8ª ed.

</Exemplo>

<Exemplo titulo="Assíntota oblíqua via divisão polinomial" numero="3">

**Problema:** Encontre as assíntotas de $f(x) = \dfrac{x^2 + 1}{x - 1}$.

**Passo 1 — vertical:** $\lim_{x\to 1} \dfrac{x^2+1}{x-1}$. Numerador $= 2 \neq 0$, denominador $\to 0$. Logo $x = 1$ é assíntota vertical.

**Passo 2 — oblíqua:** como $\deg(\text{num}) = \deg(\text{den}) + 1$, divida:

$$x^2 + 1 = (x-1)(x+1) + 2 \implies f(x) = x + 1 + \frac{2}{x-1}$$

Como $2/(x-1) \to 0$ quando $x \to \pm\infty$:

$$\lim_{x\to\pm\infty}\left[f(x) - (x+1)\right] = 0$$

A reta $y = x + 1$ é assíntota oblíqua.

**Fonte.** Guidorizzi — Um Curso de Cálculo, vol. 1, §2.5. LTC, 5ª ed.

</Exemplo>

<Exemplo titulo="Limite por conjugado — diferença de radicais" numero="4">

**Problema:** $\displaystyle\lim_{x \to \infty} \left[x - \sqrt{x^2 - x}\right]$

**Estratégia:** multiplicar por $\dfrac{x + \sqrt{x^2-x}}{x + \sqrt{x^2-x}}$.

$$x - \sqrt{x^2-x} = \frac{x^2 - (x^2 - x)}{x + \sqrt{x^2 - x}} = \frac{x}{x + \sqrt{x^2-x}}$$

Dividindo numerador e denominador por $x$ ($x > 0$):

$$\frac{x}{x + x\sqrt{1-1/x}} = \frac{1}{1 + \sqrt{1 - 1/x}} \xrightarrow{x\to\infty} \frac{1}{1 + 1} = \frac{1}{2}$$

**Fonte.** Stewart — Cálculo, §2.6, Exercício 65. Cengage, 8ª ed.

</Exemplo>

<Exemplo titulo="Prova pela definição ε-M" numero="5">

**Afirmação:** $\displaystyle\lim_{x \to +\infty} \frac{1}{x} = 0$.

**Prova:** dado $\varepsilon > 0$, queremos $|1/x - 0| < \varepsilon$, i.e., $1/x < \varepsilon$, i.e., $x > 1/\varepsilon$.

Tome $M = 1/\varepsilon$. Se $x > M$, então $x > 1/\varepsilon$, logo $1/x < \varepsilon = \varepsilon$. $\square$

**Variante:** prove $\lim_{x\to\infty}(2x+3)/(x-1) = 2$. Escrevemos:
$$\left|\frac{2x+3}{x-1} - 2\right| = \left|\frac{5}{x-1}\right| = \frac{5}{x-1} \quad (x > 1)$$

Para que isso seja $< \varepsilon$: $x - 1 > 5/\varepsilon$, i.e., $x > 1 + 5/\varepsilon$. Tome $M = 1 + 5/\varepsilon$. $\square$

**Fonte.** Apostol — Calculus, vol. I, §3.1. Wiley, 2ª ed.

</Exemplo>
