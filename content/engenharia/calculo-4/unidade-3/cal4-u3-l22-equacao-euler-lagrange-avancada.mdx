# Euler-Lagrange Para Sistemas Mais Gerais

A equação de Euler-Lagrange pode ser estendida para: (1) sistemas de várias funções incógnitas <Eq>{"y_1, \\ldots, y_n"}</Eq>; (2) funcionais com derivadas de ordem superior; (3) condições de contorno "naturais" (livres). O **Teorema de Noether** é um dos mais profundos do cálculo variacional: toda simetria do funcional gera uma quantidade conservada.

</Porta>
<Porta nivel="10anos">

# Extensões da Equação de Euler-Lagrange

**Múltiplas funções:** para <Eq>{"J[y_1,\\ldots,y_n] = \\int L(x, y_i, y_i')dx"}</Eq>, uma equação E-L por cada <Eq>{"y_k"}</Eq>:

<Eq>{"\\frac{\\partial L}{\\partial y_k} - \\frac{d}{dx}\\frac{\\partial L}{\\partial y_k'} = 0, \\quad k = 1,\\ldots,n"}</Eq>

**Derivadas de ordem superior:** <Eq>{"J[y] = \\int L(x,y,y',y'')dx"}</Eq>:

<EquacaoCanonica
  formula="\frac{\partial L}{\partial y} - \frac{d}{dx}\frac{\partial L}{\partial y'} + \frac{d^2}{dx^2}\frac{\partial L}{\partial y''} = 0"
  legenda="Equação de Euler-Lagrange de 4ª ordem — aparece em vigas elásticas"
  audioTexto="Derivada parcial de L com respeito a y menos d dx de L sub y linha mais d2 dx2 de L sub y linha linha é zero."
/>

**Condições naturais de contorno:** quando <Eq>{"y(a)"}</Eq> ou <Eq>{"y(b)"}</Eq> são livres, a variação dá adicionalmente: <Eq>{"L_{y'}\\big|_{x=a} = 0"}</Eq> ou <Eq>{"L_{y'}\\big|_{x=b} = 0"}</Eq>.

</Porta>

# Condições Naturais de Contorno e Múltiplas Variáveis

## Problema com Extremos Livres

Quando <Eq>{"y(a)"}</Eq> não é prescrito, a variação <Eq>{"\\eta(a)"}</Eq> é livre. Da integração por partes:

<Eq>{"\\delta J = \\int_a^b\\left(L_y - \\frac{d}{dx}L_{y'}\\right)\\eta\\,dx + \\left[L_{y'}\\eta\\right]_a^b"}</Eq>

Para que <Eq>{"\\delta J = 0"}</Eq> para toda <Eq>{"\\eta"}</Eq>:
- **Equação de E-L** no interior (como antes)
- **Condição natural:** <Eq>{"L_{y'}(a) = 0"}</Eq> e/ou <Eq>{"L_{y'}(b) = 0"}</Eq>

## Euler-Lagrange em Múltiplas Variáveis (Equações de Campo)

Para <Eq>{"J[u] = \\int_\\Omega L(x, u, \\nabla u)\\,dx"}</Eq> (com <Eq>{"x \\in \\mathbb{R}^n"}</Eq>):

<EquacaoCanonica
  formula="\frac{\partial L}{\partial u} - \sum_{i=1}^n \frac{\partial}{\partial x_i}\frac{\partial L}{\partial u_{x_i}} = 0"
  legenda="E-L para funcionais de campo — generaliza para n variáveis independentes"
  audioTexto="Derivada parcial de L com respeito a u menos a soma das derivadas parciais em x i de L sub u xi é zero."
/>

**Exemplo:** <Eq>{"L = \\frac{1}{2}|\\nabla u|^2 - fu"}</Eq> dá E-L: <Eq>{"-\\Delta u = f"}</Eq> (equação de Poisson).

**Exemplo:** <Eq>{"L = \\frac{1}{2}(u_t^2 - c^2|\\nabla u|^2)"}</Eq> dá E-L: <Eq>{"u_{tt} - c^2\\Delta u = 0"}</Eq> (equação de onda).

## Condição de Transversalidade

Se a curva pode variar na fronteira ao longo de uma curva dada <Eq>{"C"}</Eq>, a condição de transversalidade é:

<Eq>{"[L - y'L_{y'}]_{x=b}(x_b' - 1) + L_{y'}|_{x=b}\\,y_b' = 0"}</Eq>

(onde primas indicam derivadas ao longo de <Eq>{"C"}</Eq>).

# Teorema de Noether e Leis de Conservação

## Teorema de Noether (1918)

**Simetria contínua:** uma família de transformações <Eq>{"(x,y) \\to (\\bar{x}(s,x,y), \\bar{y}(s,x,y))"}</Eq> paramétrica em <Eq>{"s"}</Eq> com <Eq>{"s=0"}</Eq> = identidade, que preserva o funcional <Eq>{"J"}</Eq>.

<EquacaoCanonica
  formula="\frac{d}{dx}\left[L\xi + L_{y'}(\eta - y'\xi)\right] = 0"
  legenda="Lei de conservação de Noether — ξ e η são geradores infinitesimais da simetria"
  audioTexto="A derivada em x de L vezes xi mais L sub y linha vezes eta menos y linha xi é zero — uma quantidade conservada."
/>

onde <Eq>{"\\xi = d\\bar{x}/ds|_{s=0}"}</Eq> e <Eq>{"\\eta = d\\bar{y}/ds|_{s=0}"}</Eq>.

**Exemplos:**

| Simetria | Geradores | Conservada |
|---|---|---|
| Translação em <Eq>{"x"}</Eq>: <Eq>{"\\bar{x}=x+s"}</Eq> | <Eq>{"\\xi=1, \\eta=0"}</Eq> | <Eq>{"L - y'L_{y'}"}</Eq> (energia) |
| Translação em <Eq>{"y"}</Eq>: <Eq>{"\\bar{y}=y+s"}</Eq> | <Eq>{"\\xi=0, \\eta=1"}</Eq> | <Eq>{"L_{y'}"}</Eq> (momento) |
| Rotação: <Eq>{"\\bar{x}=x\\cos s - y\\sin s"}</Eq> | <Eq>{"\\xi=-y, \\eta=x"}</Eq> | Momento angular |

**Noether em física:** a lei de conservação de energia (translação temporal invariância) e de momento (translação espacial) são exemplos diretos.

## Teorema de Noether para Campos

Para <Eq>{"J[u] = \\int_{\\Omega} L(x,u,\\partial u)dx"}</Eq> e simetria <Eq>{"\\bar{x}^\\mu = x^\\mu + \\xi^\\mu"}</Eq>, <Eq>{"\\bar{u} = u + \\eta"}</Eq>:

<Eq>{"\\partial_\\mu J^\\mu = 0, \\quad J^\\mu = L\\xi^\\mu + L_{u_{x^\\mu}}(\\eta - u_{x_\\nu}\\xi^\\nu)"}</Eq>

**Corrente de Noether conservada** — base da teoria quântica de campos e teoria de calibre.

# Problemas com Restrições e Lagrangiano Generalizado

## Multiplicadores de Lagrange Variacionais

Para minimizar <Eq>{"J[y] = \\int L\\,dx"}</Eq> sujeito a <Eq>{"K[y] = \\int M\\,dx = C"}</Eq>:

**Lagrangiano aumentado:** <Eq>{"\\Phi[y,\\lambda] = J[y] - \\lambda(K[y] - C)"}</Eq>.

**Equação de E-L aumentada:**

<EquacaoCanonica
  formula="\frac{\partial}{\partial y}(L - \lambda M) - \frac{d}{dx}\frac{\partial}{\partial y'}(L - \lambda M) = 0"
  legenda="E-L com multiplicador — λ é determinado pela restrição K[y] = C"
  audioTexto="Equação de Euler-Lagrange com lagrangiana L menos lambda M, onde lambda é o multiplicador da restrição."
/>

## Restrições Holonômicas em Sistemas de EDOs

Para sistema de funções <Eq>{"y_k(x)"}</Eq> com restrição holonômica <Eq>{"g(x, y_1,\\ldots,y_n) = 0"}</Eq>:

<Eq>{"\\frac{\\partial L}{\\partial y_k} - \\frac{d}{dx}\\frac{\\partial L}{\\partial y_k'} = \\lambda\\frac{\\partial g}{\\partial y_k}, \\quad k=1,\\ldots,n"}</Eq>

## Extensão a Campos de Derivadas de Ordem Maior

Para funcionais da elasticidade <Eq>{"J = \\int_\\Omega L(x, u, \\nabla u, \\nabla^2 u)dx"}</Eq>:

<Eq>{"L_u - \\sum_i \\partial_i L_{u_{x_i}} + \\sum_{i,j}\\partial_i\\partial_j L_{u_{x_ix_j}} = 0"}</Eq>

**Exemplo:** placa de Kirchhoff-Love: <Eq>{"L = \\frac{D}{2}(\\Delta u)^2 - fu"}</Eq> → E-L: <Eq>{"D\\Delta^2 u = f"}</Eq> (biharmonico).

# Euler-Lagrange em Engenharia Estrutural e Óptica

## Principio de Fermat (Óptica)

O caminho da luz minimiza o tempo óptico <Eq>{"T = \\int \\frac{n(x,y)}{c}\\,ds"}</Eq>. A E-L da forma integralda dá a equação eikonal:

<Eq>{"\\frac{d}{ds}(n\\hat{t}) = \\nabla n"}</Eq>

onde <Eq>{"\\hat{t}"}</Eq> é o vetor tangente unitário ao raio. Para índice constante: raios retos.

## Deflexão de Placa Delgada

```python
import numpy as np
from scipy.sparse import diags, kron, eye
from scipy.sparse.linalg import spsolve

def biharmonic_2d(Nx, Ny, D=1.0):
    """
    Resolve D*Δ²u = f em (0,1)×(0,1) com u=∂u/∂n=0 na fronteira.
    Equação de Euler-Lagrange do funcional de placa de Kirchhoff.
    """
    hx = 1.0/(Nx+1)
    hy = 1.0/(Ny+1)
    
    # Laplaciano 1D em cada direção
    e = np.ones(Nx)
    Lx = diags([-e, 2*e, -e], [-1, 0, 1]) / hx**2
    e = np.ones(Ny)
    Ly = diags([-e, 2*e, -e], [-1, 0, 1]) / hy**2
    
    Ix, Iy = eye(Nx), eye(Ny)
    # Laplaciano 2D
    L2 = kron(Lx, Iy) + kron(Ix, Ly)
    # Bilaplaciano
    A = D * L2 @ L2
    
    x = np.linspace(hx, 1-hx, Nx)
    y = np.linspace(hy, 1-hy, Ny)
    X, Y = np.meshgrid(x, y)
    
    f = np.ones(Nx*Ny)  # carga uniforme
    u = spsolve(A.tocsr(), f)
    return u.reshape(Ny, Nx), X, Y

u, X, Y = biharmonic_2d(30, 30)
print(f"Deflexão máxima (centro): {u[15,15]:.6f}")
print(f"Valor exato (série): ≈ 0.001265")  # em unidades de q*L^4/(D)
```

**Referência:** Gelfand & Fomin, *Calculus of Variations*, §4; Timoshenko & Woinowsky-Krieger, *Theory of Plates and Shells*, Cap. 4.

## Exemplo 1 — E-L para Viga de Euler-Bernoulli

**Funcional:** <Eq>{"J[y] = \\int_0^L \\left[\\frac{EI}{2}(y'')^2 - fy\\right]dx"}</Eq>, <Eq>{"y(0)=y(L)=y'(0)=y'(L)=0"}</Eq>.

**Lagrangiana:** <Eq>{"L = \\frac{EI}{2}(y'')^2 - fy"}</Eq>, depende de <Eq>{"y"}</Eq> e <Eq>{"y''"}</Eq>.

**E-L de 4ª ordem:**

<Eq>{"L_y - \\frac{d}{dx}L_{y'} + \\frac{d^2}{dx^2}L_{y''} = -f + 0 + \\frac{d^2}{dx^2}(EIy'') = (EIy'')'' - f = 0"}</Eq>

**Equação:** <Eq>{"(EIy'')'' = f"}</Eq> (equação de deflexão de viga com carga distribuída <Eq>{"f"}</Eq>).

**Para <Eq>{"EI"}</Eq> constante e <Eq>{"f = f_0"}</Eq>:** <Eq>{"EIy'''' = f_0"}</Eq>, solução: <Eq>{"y = \\frac{f_0}{24EI}x^2(L-x)^2"}</Eq>.

**Referência:** Gelfand & Fomin, §4.1; Lanczos, *Variational Principles*, §V.

</Exemplo>

## Exemplo 2 — Noether: Conservação de Energia

**Sistema:** pêndulo, <Eq>{"L(t,\\theta,\\dot{\\theta}) = \\frac{ml^2\\dot{\\theta}^2}{2} - mgl(1-\\cos\\theta)"}</Eq>.

**Simetria temporal:** <Eq>{"\\bar{t} = t+s"}</Eq>, <Eq>{"\\bar{\\theta} = \\theta"}</Eq>, logo <Eq>{"\\xi = 1"}</Eq>, <Eq>{"\\eta = 0"}</Eq>.

**Quantidade conservada de Noether:**

<Eq>{"L\\xi + L_{\\dot{\\theta}}(\\eta - \\dot{\\theta}\\xi) = L - \\dot{\\theta}L_{\\dot{\\theta}} = \\frac{ml^2\\dot{\\theta}^2}{2} + mgl(1-\\cos\\theta) - \\dot{\\theta}\\cdot ml^2\\dot{\\theta}"}</Eq>

<Eq>{"= -\\frac{ml^2\\dot{\\theta}^2}{2} + mgl(1-\\cos\\theta) = -(T-V) = -L"}</Eq>

Equivalentemente, <Eq>{"E = T + V = \\frac{ml^2\\dot{\\theta}^2}{2} + mgl(1-\\cos\\theta) = \\text{const}"}</Eq> (energia mecânica total).

**Referência:** Gelfand & Fomin, §3.3; Lanczos, §III.5.

</Exemplo>
