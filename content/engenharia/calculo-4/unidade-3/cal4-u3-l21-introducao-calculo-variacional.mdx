# Otimizar Funções de Funções

O cálculo variacional estuda extremos de **funcionais** — regras que a cada função <Eq>{"y(x)"}</Eq> associam um número real. Por exemplo: o comprimento de uma curva, o tempo de descida por um escorregador, a área de uma superfície. A pergunta é: qual a curva que minimiza esse funcional? A resposta é dada pela **equação de Euler-Lagrange**.

# Cálculo Variacional: O Problema Fundamental

**Funcional:** <Eq>{"J[y] = \\int_a^b L(x, y, y')\\,dx"}</Eq>, onde <Eq>{"L"}</Eq> é dado e <Eq>{"y"}</Eq> satisfaz <Eq>{"y(a) = y_a"}</Eq>, <Eq>{"y(b) = y_b"}</Eq>.

**Variação primeira:** perturbar <Eq>{"y \\to y + \\varepsilon\\eta"}</Eq> (com <Eq>{"\\eta(a)=\\eta(b)=0"}</Eq>):

<Eq>{"\\delta J = \\frac{dJ[y+\\varepsilon\\eta]}{d\\varepsilon}\\bigg|_{\\varepsilon=0} = \\int_a^b \\left(L_y - \\frac{d}{dx}L_{y'}\\right)\\eta\\,dx = 0"}</Eq>

**Equação de Euler-Lagrange:**

<EquacaoCanonica
  formula="\frac{\partial L}{\partial y} - \frac{d}{dx}\frac{\partial L}{\partial y'} = 0"
  legenda="Condição necessária para extremo de J[y] — análogo a ∇f = 0 para funções"
  audioTexto="Derivada parcial de L com respeito a y menos a derivada total em x de L sub y linha é zero."
/>

**Problemas clássicos:**
- **Braquistócrona:** menor tempo de descida = cicloide
- **Geodésica:** menor comprimento entre dois pontos
- **Superfície mínima:** mínimo de <Eq>{"\\int\\sqrt{1+y'^2}\\,dx"}</Eq> = reta

</Porta>

# Derivação da Equação de Euler-Lagrange

## Variação Primeira e Lema Fundamental

**Variação de J:**

<Eq>{"J[y+\\varepsilon\\eta] = \\int_a^b L(x, y+\\varepsilon\\eta, y'+\\varepsilon\\eta')\\,dx"}</Eq>

<Eq>{"\\frac{dJ}{d\\varepsilon}\\bigg|_0 = \\int_a^b \\left(\\frac{\\partial L}{\\partial y}\\eta + \\frac{\\partial L}{\\partial y'}\\eta'\\right)dx"}</Eq>

Integrando por partes o segundo termo (com <Eq>{"\\eta(a)=\\eta(b)=0"}</Eq>):

<Eq>{"\\int_a^b \\frac{\\partial L}{\\partial y'}\\eta'\\,dx = -\\int_a^b \\frac{d}{dx}\\left(\\frac{\\partial L}{\\partial y'}\\right)\\eta\\,dx"}</Eq>

Logo:

<EquacaoCanonica
  formula="\delta J = \int_a^b \left(L_y - \frac{d}{dx}L_{y'}\right)\eta\,dx = 0 \quad \forall\, \eta \in C^1_0[a,b]"
  legenda="Para que isso valha para toda variação η, o integrando deve ser zero — Lema de du Bois-Reymond"
  audioTexto="A variação de J é a integral de L sub y menos d dx de L sub y linha vezes eta d x, igual a zero para toda eta."
/>

**Lema Fundamental (du Bois-Reymond):** Se <Eq>{"\\int_a^b g(x)\\eta(x)\\,dx = 0"}</Eq> para toda <Eq>{"\\eta \\in C^1_0"}</Eq>, então <Eq>{"g \\equiv 0"}</Eq>.

**Conclusão:** <Eq>{"L_y - \\frac{d}{dx}L_{y'} = 0"}</Eq>, ou seja <Eq>{"L_y - L_{y'x} - L_{y'y}y' - L_{y'y'}y'' = 0"}</Eq>.

## Casos Especiais e Integrais Primeiras

**L independente de y** (<Eq>{"L_y = 0"}</Eq>): <Eq>{"L_{y'} = \\text{const}"}</Eq> (integral primeira de momento).

**L independente de x:** identidade de Beltrami:

<EquacaoCanonica
  formula="L - y' L_{y'} = C \quad (\text{constante})"
  legenda="Integral primeira de Beltrami quando L não depende explicitamente de x"
  audioTexto="L menos y linha vezes L sub y linha é igual a uma constante C."
/>

**L independente de y':** <Eq>{"L_y = 0"}</Eq> (equação algébrica, não diferencial).

</Porta>

# Problemas Clássicos do Cálculo Variacional

## Braquistócrona (Bernoulli, 1696)

**Problema:** encontrar a curva de descida mais rápida entre dois pontos, sob gravidade, sem atrito.

**Funcional:** tempo de descida <Eq>{"T[y] = \\int_0^{x_1} \\frac{\\sqrt{1+y'^2}}{\\sqrt{2g(y_0-y)}}\\,dx"}</Eq>.

**Lagrangiana:** <Eq>{"L(y,y') = \\sqrt{\\frac{1+y'^2}{2g(y_0-y)}}"}</Eq> independente de <Eq>{"x"}</Eq>.

**Integral de Beltrami:** <Eq>{"L - y'L_{y'} = C"}</Eq>, ou seja <Eq>{"\\frac{1}{\\sqrt{(1+y'^2)(y_0-y)}} = \\text{const}"}</Eq>.

**Solução — cicloide:** <Eq>{"x = r(\\theta - \\sin\\theta)"}</Eq>, <Eq>{"y = y_0 - r(1-\\cos\\theta)"}</Eq>.

## Catenária (Leibniz, 1691)

**Problema:** encontrar a forma de equilíbrio de uma corrente de comprimento fixo, suspensa pelos extremos. Minimiza a energia potencial:

<Eq>{"V[y] = \\int_{x_0}^{x_1} y\\sqrt{1+y'^2}\\,dx"}</Eq>

**Equação de Euler-Lagrange** (L independente de x, Beltrami):

<Eq>{"y\\sqrt{1+y'^2} - y \\cdot \\frac{y'^2}{\\sqrt{1+y'^2}} = \\frac{y}{\\sqrt{1+y'^2}} = C"}</Eq>

**Solução:** <Eq>{"y = C\\cosh\\left(\\frac{x-x_0}{C}\\right)"}</Eq> (catenária).

## Superfície Mínima de Revolução

**Funcional:** área de superfície de revolução <Eq>{"A[y] = 2\\pi\\int_{x_0}^{x_1} y\\sqrt{1+y'^2}\\,dx"}</Eq>.

**Euler-Lagrange** (idêntico à catenária): solução = **catenoid** <Eq>{"y = C\\cosh(x/C)"}</Eq>.

## Isoperimétrico — Problema Clássico

**Problema:** entre todas as curvas fechadas de comprimento fixo <Eq>{"l"}</Eq>, qual encerra a maior área? Resposta: o círculo.

**Formulação:** maximizar <Eq>{"A = \\frac{1}{2}\\int(x\\dot{y}-y\\dot{x})dt"}</Eq> sujeito a <Eq>{"\\int\\sqrt{\\dot{x}^2+\\dot{y}^2}dt = l"}</Eq>.

**Método dos multiplicadores de Lagrange variacionais:** maximizar <Eq>{"J = A - \\mu P"}</Eq> para algum <Eq>{"\\mu"}</Eq> (curvatura = constante = <Eq>{"1/(2\\mu)"}</Eq> → círculo).

# Teoria Moderna: Espaços de Sobolev e Coercividade

## Formulação em Espaços de Sobolev

O problema variacional clássico pode ser formulado como: minimizar <Eq>{"J[u]"}</Eq> sobre <Eq>{"W^{1,p}(a,b)"}</Eq> (ou <Eq>{"H^1_0"}</Eq> para condições de Dirichlet).

**Teorema de Tonelli:** Se <Eq>{"L(x,y,p)"}</Eq> é convexo em <Eq>{"p"}</Eq> e satisfaz a condição de crescimento <Eq>{"L \\geq c_1|p|^q - c_2"}</Eq> (q>1), então <Eq>{"J"}</Eq> tem minimizante em <Eq>{"W^{1,q}(a,b)"}</Eq>.

**Coercividade:** <Eq>{"J[y] \\to +\\infty"}</Eq> quando <Eq>{"\\|y\\|_{W^{1,q}} \\to \\infty"}</Eq> — garante que mínimos não "escapam para infinito".

## Condições Necessárias de 2ª Ordem

**Condição de Legendre:** para mínimo, a **condição de Jacobi** (segunda variação não-negativa) requer <Eq>{"L_{y'y'} \\geq 0"}</Eq>.

**Segunda variação:**

<EquacaoCanonica
  formula="\delta^2 J = \int_a^b \left(L_{yy}\eta^2 + 2L_{yy'}\eta\eta' + L_{y'y'}\eta'^2\right)dx \geq 0"
  legenda="Segunda variação — análogo à Hessiana positiva semidefinida para mínimo"
  audioTexto="A segunda variação de J é a integral de L sub yy eta ao quadrado mais dois L sub yy linha eta eta linha mais L sub y linha y linha eta linha ao quadrado d x, que deve ser não-negativa para mínimo."
/>

**Pontos conjugados:** zeros das soluções da equação de Jacobi <Eq>{"(L_{y'y'}v')' - (L_{yy} - (d/dx)L_{yy'})v = 0"}</Eq> — determinam se o extremo é de fato mínimo.

## Teoria do Campo de Extremais

A solução da equação de Euler-Lagrange pode não ser global mínima se há pontos conjugados no intervalo. A **teoria de Jacobi** estuda isso sistematicamente, fornecendo condições necessárias e suficientes de segunda ordem.

# Cálculo Variacional em Engenharia

## Otimização de Trajetórias

A braquistócrona é o protótipo de problemas de **otimização de trajetórias** em robótica e aeronáutica: encontrar o caminho de tempo mínimo de A a B.

**Forma geral:** minimizar <Eq>{"T = \\int_{t_0}^{t_f} L(x, \\dot{x}, t)\\,dt"}</Eq> sobre trajetórias com velocidade limitada, sujeito a equações de movimento.

## Deflexão de Viga (Energia de Elasticidade)

A deflexão <Eq>{"u(x)"}</Eq> de uma viga de Euler-Bernoulli minimiza a energia total:

<Eq>{"J[u] = \\frac{1}{2}\\int_0^L EI(u'')^2\\,dx - \\int_0^L f\\,u\\,dx"}</Eq>

A equação de Euler-Lagrange de 4ª ordem é: <Eq>{"(EIu'')'' = f"}</Eq>.

## Código Python — Solução Numérica da Braquistócrona

```python
import numpy as np
from scipy.optimize import fsolve
import matplotlib.pyplot as plt

def brachistochrone(x1, y1, N=200):
    """
    Braquistócrona parametrizada pela cicloide:
    x(θ) = r(θ - sinθ), y(θ) = r(1 - cosθ)
    Encontra r tal que (x(θ₁), y(θ₁)) = (x1, y1).
    """
    def equations(r_theta):
        r, theta = r_theta
        return [r*(theta - np.sin(theta)) - x1,
                r*(1 - np.cos(theta)) - y1]
    
    r, theta_end = fsolve(equations, [1.0, 1.0])
    theta = np.linspace(0, theta_end, N)
    x = r * (theta - np.sin(theta))
    y = r * (1 - np.cos(theta))
    return x, y, r

# Ponto final: (1, 0.5)
x_end, y_end = 1.0, 0.5
x_brac, y_brac, r = brachistochrone(x_end, y_end)

# Tempo de descida na cicloide vs. reta
g = 9.81
# Reta: y = (y_end/x_end)*x
N = 1000
x_line = np.linspace(0, x_end, N)
y_line = (y_end/x_end)*x_line

def descent_time(x_path, y_path, g=9.81):
    """Calcular tempo de descida por integração numérica."""
    dx = np.diff(x_path)
    dy = np.diff(y_path)
    ds = np.sqrt(dx**2 + dy**2)
    y_mid = (y_path[:-1] + y_path[1:]) / 2
    v = np.sqrt(2*g*np.maximum(y_mid, 1e-10))  # velocidade
    return np.sum(ds/v)

T_brac = descent_time(x_brac, y_brac)
T_line = descent_time(x_line, y_line)
print(f"Tempo na cicloide: {T_brac:.4f} s")
print(f"Tempo na reta:     {T_line:.4f} s")
print(f"Redução:           {(1-T_brac/T_line)*100:.1f}%")
```

**Referência:** Gelfand & Fomin, *Calculus of Variations*, Cap. 1–2; Lanczos, *The Variational Principles of Mechanics*, Cap. II.

## Exemplo 1 — Geodésica no Plano

**Problema:** encontrar a curva mais curta entre <Eq>{"(x_0,y_0)"}</Eq> e <Eq>{"(x_1,y_1)"}</Eq> no plano.

**Funcional:** <Eq>{"J[y] = \\int_{x_0}^{x_1}\\sqrt{1+y'^2}\\,dx"}</Eq>.

**Lagrangiana:** <Eq>{"L(y') = \\sqrt{1+y'^2}"}</Eq> (independente de <Eq>{"x"}</Eq> e <Eq>{"y"}</Eq>).

**Equação de Euler-Lagrange:** <Eq>{"L_y = 0"}</Eq> e <Eq>{"\\frac{d}{dx}L_{y'} = 0"}</Eq>, logo <Eq>{"L_{y'} = \\frac{y'}{\\sqrt{1+y'^2}} = C"}</Eq>.

**Solução:** <Eq>{"y' = \\text{const}"}</Eq> → <Eq>{"y = ax + b"}</Eq> (reta). $\checkmark$

**Referência:** Gelfand & Fomin, *Calculus of Variations*, §2.

</Exemplo>

## Exemplo 2 — Catenária

**Problema:** minimizar <Eq>{"J[y] = \\int_{-1}^1 y\\sqrt{1+y'^2}\\,dx"}</Eq> com <Eq>{"y(-1) = y(1) = 1"}</Eq>.

**Beltrami (L independente de x):**

<Eq>{"y\\sqrt{1+y'^2} - y\\cdot\\frac{y'^2}{\\sqrt{1+y'^2}} = \\frac{y}{\\sqrt{1+y'^2}} = C"}</Eq>

**Separando variáveis:**

<Eq>{"\\frac{dy}{\\sqrt{(y/C)^2 - 1}} = \\pm\\,dx \\Rightarrow C\\cosh^{-1}(y/C) = x - x_0"}</Eq>

**Solução:** <Eq>{"y = C\\cosh((x-x_0)/C)"}</Eq>. Pela simetria <Eq>{"x_0 = 0"}</Eq>; das condições <Eq>{"y(\\pm 1) = 1"}</Eq>: <Eq>{"C\\cosh(1/C) = 1"}</Eq>.

**Numericamente:** <Eq>{"C \\approx 0{,}6627"}</Eq>, verificado como ponto crítico de <Eq>{"C\\cosh(1/C) - 1 = 0"}</Eq>.

**Referência:** Gelfand & Fomin, §3.1; Lanczos, §II.5.

</Exemplo>
