# Mecânica Hamiltoniana

Imagine que ao descrever o movimento de um objeto, em vez de usar posição e velocidade, usamos posição e **momento** (quantidade de movimento). Isso muda completamente como descrevemos o universo: em vez de equações de 2ª ordem, temos pares de equações de 1ª ordem — mais simétricas e elegantes.

William Rowan Hamilton (1805–1865) mostrou que toda a mecânica clássica pode ser reformulada a partir de uma única função **H(q, p, t)**, o **Hamiltoniano**, que geralmente representa a energia total do sistema.

Esta reformulação é a base da mecânica quântica, da mecânica estatística e de toda a física moderna.

# Da Lagrangiana à Hamiltoniana

## Transformada de Legendre

Dado <Eq>{"L(q_1,\\ldots,q_n,\\dot{q}_1,\\ldots,\\dot{q}_n,t)"}</Eq>, definimos os **momentos generalizados** (canônicos):

<Eq>{"p_k = \\frac{\\partial L}{\\partial \\dot{q}_k}, \\quad k = 1,\\ldots,n"}</Eq>

A **transformada de Legendre** de <Eq>{"L"}</Eq> em relação às velocidades <Eq>{"\\dot{q}_k"}</Eq> define o **Hamiltoniano**:

<Eq>{"H(q, p, t) = \\sum_{k=1}^n p_k \\dot{q}_k - L(q, \\dot{q}, t)"}</Eq>

onde as <Eq>{"\\dot{q}_k"}</Eq> devem ser expressas em função de <Eq>{"(q, p, t)"}</Eq> via inversão de <Eq>{"p_k = \\partial L/\\partial \\dot{q}_k"}</Eq>.

**Condição de invertibilidade:** A transformação <Eq>{"\\dot{q} \\mapsto p"}</Eq> é invertível quando a matriz Hessiana <Eq>{"\\left(\\frac{\\partial^2 L}{\\partial \\dot{q}_i \\partial \\dot{q}_j}\\right)"}</Eq> é não-singular (sistema regular).

*(Fonte: Goldstein, Poole & Safko, Classical Mechanics, §8.1)*

## Equações de Hamilton

Das identidades da transformada de Legendre:

<EquacaoCanonica formula="\dot{q}_k = \frac{\partial H}{\partial p_k}, \qquad \dot{p}_k = -\frac{\partial H}{\partial q_k}, \quad k=1,\ldots,n" />

Estas são as **equações canônicas de Hamilton** — <Eq>{"2n"}</Eq> equações de 1ª ordem (em vez de <Eq>{"n"}</Eq> de 2ª ordem).

**Energia:** Se <Eq>{"L"}</Eq> não depende explicitamente de <Eq>{"t"}</Eq>:

<Eq>{"\\frac{dH}{dt} = \\frac{\\partial H}{\\partial t} = -\\frac{\\partial L}{\\partial t}"}</Eq>

Logo H é uma integral primeira (conservada) quando o sistema é autônomo.

*(Fonte: Landau & Lifshitz, Mechanics, §40)*

## Exemplo: Oscilador Harmônico

<Eq>{"L = \\frac{1}{2}m\\dot{q}^2 - \\frac{1}{2}kq^2 \\implies p = m\\dot{q} \\implies \\dot{q} = p/m"}</Eq>

<Eq>{"H = p\\cdot\\frac{p}{m} - \\left(\\frac{p^2}{2m} - \\frac{kq^2}{2}\\right) = \\frac{p^2}{2m} + \\frac{kq^2}{2}"}</Eq>

Equações de Hamilton:

<Eq>{"\\dot{q} = \\frac{p}{m}, \\qquad \\dot{p} = -kq"}</Eq>

que reproduzem <Eq>{"\\ddot{q} = -\\omega^2 q"}</Eq> com <Eq>{"\\omega = \\sqrt{k/m}"}</Eq>.

*(Fonte: Arnold, Mathematical Methods of Classical Mechanics, §14)*

# Espaço de Fase e Geometria Simpléctica

## Espaço de Fase

O **espaço de fase** é o espaço das coordenadas <Eq>{"(q_1,\\ldots,q_n,p_1,\\ldots,p_n) \\in T^*Q"}</Eq> (fibrado cotangente).

O fluxo hamiltoniano <Eq>{"\\phi_t: T^*Q \\to T^*Q"}</Eq> é gerado pelo campo vetorial:

<Eq>{"X_H = \\sum_k \\left(\\frac{\\partial H}{\\partial p_k}\\frac{\\partial}{\\partial q_k} - \\frac{\\partial H}{\\partial q_k}\\frac{\\partial}{\\partial p_k}\\right)"}</Eq>

## Forma Simpléctica

<Eq>{"T^*Q"}</Eq> carrega a **2-forma simpléctica canônica**:

<Eq>{"\\omega = \\sum_{k=1}^n dq_k \\wedge dp_k"}</Eq>

O fluxo hamiltoniano **preserva** <Eq>{"\\omega"}</Eq>: <Eq>{"\\mathcal{L}_{X_H}\\omega = 0"}</Eq> (Liouville).

## Teorema de Liouville

O fluxo hamiltoniano preserva o **volume** no espaço de fase:

<Eq>{"\\frac{d}{dt}\\int_{\\phi_t(D)} dq\\,dp = 0 \\quad \\forall D \\subset T^*Q"}</Eq>

**Prova:** O volume é <Eq>{"\\omega^n/n!"}</Eq> e <Eq>{"\\mathcal{L}_{X_H}\\omega = 0 \\Rightarrow \\mathcal{L}_{X_H}(\\omega^n) = 0"}</Eq>. <Eq>{"\\square"}</Eq>

**Equação de Liouville para densidades:** Se <Eq>{"\\rho(q,p,t)"}</Eq> é uma densidade de ensemble:

<Eq>{"\\frac{\\partial \\rho}{\\partial t} + \\{\\rho, H\\} = 0"}</Eq>

onde <Eq>{"\\{\\cdot,\\cdot\\}"}</Eq> são os colchetes de Poisson.

*(Fonte: Arnold, Mathematical Methods of Classical Mechanics, §16; Goldstein §8.3)*

## Colchetes de Poisson

Para funções <Eq>{"f, g: T^*Q \\to \\mathbb{R}"}</Eq>:

<Eq>{"\\{f, g\\} = \\sum_{k=1}^n \\left(\\frac{\\partial f}{\\partial q_k}\\frac{\\partial g}{\\partial p_k} - \\frac{\\partial f}{\\partial p_k}\\frac{\\partial g}{\\partial q_k}\\right)"}</Eq>

**Propriedades:**
- Antissimetria: <Eq>{"\\{f,g\\} = -\\{g,f\\}"}</Eq>
- Bilinearidade: <Eq>{"\\{af+bg,h\\} = a\\{f,h\\}+b\\{g,h\\}"}</Eq>
- Identidade de Jacobi: <Eq>{"\\{f,\\{g,h\\}\\} + \\{g,\\{h,f\\}\\} + \\{h,\\{f,g\\}\\} = 0"}</Eq>
- Regra de Leibniz: <Eq>{"\\{fg,h\\} = f\\{g,h\\} + g\\{f,h\\}"}</Eq>

**Relações fundamentais:**

<Eq>{"\\{q_i, q_j\\} = 0, \\quad \\{p_i, p_j\\} = 0, \\quad \\{q_i, p_j\\} = \\delta_{ij}"}</Eq>

**Equação do movimento:** Para qualquer observável <Eq>{"f(q,p,t)"}</Eq>:

<Eq>{"\\frac{df}{dt} = \\{f, H\\} + \\frac{\\partial f}{\\partial t}"}</Eq>

*(Fonte: Goldstein §9.4; Arnold §16)*

## Integrais Primeiras e Simetrias

<Eq>{"f"}</Eq> é uma integral primeira (conservada) se e somente se <Eq>{"\\{f, H\\} = 0"}</Eq>.

# Transformações Canônicas e Hamilton-Jacobi

## Transformações Canônicas

Uma transformação <Eq>{"(q,p) \\to (Q,P)"}</Eq> é **canônica** (simplectomorfismo) se preserva a estrutura dos colchetes de Poisson:

<Eq>{"\\{Q_i, Q_j\\} = 0, \\quad \\{P_i, P_j\\} = 0, \\quad \\{Q_i, P_j\\} = \\delta_{ij}"}</Eq>

Equivalentemente, preserva a 2-forma: <Eq>{"\\sum_k dQ_k \\wedge dP_k = \\sum_k dq_k \\wedge dp_k"}</Eq>.

**Funções geratrizes:** Existem 4 tipos:

| Tipo | Função | Relações |
|---|---|---|
| F₁(q,Q,t) | <Eq>{"p = \\partial F_1/\\partial q"}</Eq> | <Eq>{"P = -\\partial F_1/\\partial Q"}</Eq> |
| F₂(q,P,t) | <Eq>{"p = \\partial F_2/\\partial q"}</Eq> | <Eq>{"Q = \\partial F_2/\\partial P"}</Eq> |
| F₃(p,Q,t) | <Eq>{"q = -\\partial F_3/\\partial p"}</Eq> | <Eq>{"P = -\\partial F_3/\\partial Q"}</Eq> |
| F₄(p,P,t) | <Eq>{"q = -\\partial F_4/\\partial p"}</Eq> | <Eq>{"Q = \\partial F_4/\\partial P"}</Eq> |

*(Fonte: Goldstein §9.1–9.2)*

## Equação de Hamilton-Jacobi

Busca-se uma transformação canônica gerada por <Eq>{"F_2 = S(q,P,t)"}</Eq> tal que o novo Hamiltoniano <Eq>{"K = 0"}</Eq>, tornando <Eq>{"\\dot{Q}_k = 0, \\dot{P}_k = 0"}</Eq> (movimento trivial).

A condição <Eq>{"H + \\partial F_2/\\partial t = 0"}</Eq> torna-se a **equação de Hamilton-Jacobi (H-J)**:

<EquacaoCanonica formula="H\!\left(q_1,\ldots,q_n,\frac{\partial S}{\partial q_1},\ldots,\frac{\partial S}{\partial q_n},t\right) + \frac{\partial S}{\partial t} = 0" />

onde <Eq>{"S(q,\\alpha,t)"}</Eq> é a **ação principal de Hamilton** e <Eq>{"\\alpha_k"}</Eq> são constantes de integração (os novos momentos P_k).

**Para sistemas conservativos:** <Eq>{"S = W(q,\\alpha) - Et"}</Eq>, onde W satisfaz a **equação de Hamilton-Jacobi reduzida** (equação de Jacobi):

<Eq>{"H\\left(q, \\frac{\\partial W}{\\partial q}\\right) = E"}</Eq>

*(Fonte: Goldstein §10.1; Lanczos, Variational Principles, Cap. VII)*

## Exemplo: Oscilador Harmônico via H-J

<Eq>{"H = \\frac{p^2}{2m} + \\frac{m\\omega^2 q^2}{2} = E"}</Eq>

Equação de Jacobi: <Eq>{"\\frac{1}{2m}\\left(\\frac{dW}{dq}\\right)^2 + \\frac{m\\omega^2 q^2}{2} = E"}</Eq>

<Eq>{"W = \\int \\sqrt{2mE - m^2\\omega^2 q^2}\\, dq = \\frac{E}{\\omega}\\arcsin\\left(q\\sqrt{\\frac{m\\omega^2}{2E}}\\right) + \\frac{q}{2}\\sqrt{2mE-m^2\\omega^2 q^2}"}</Eq>

As variáveis ação-ângulo emergem: <Eq>{"J = \\oint p\\,dq = 2\\pi E/\\omega"}</Eq>, <Eq>{"H = \\omega J/(2\\pi)"}</Eq>.

*(Fonte: Landau & Lifshitz, Mechanics, §48–50)*

## Variáveis Ação-Ângulo

Para sistemas integráveis (n integrais primeiras em involução), as **variáveis ação-ângulo** <Eq>{"(J_k, \\theta_k)"}</Eq> satisfazem:

<Eq>{"J_k = \\frac{1}{2\\pi}\\oint_{C_k} p\\,dq \\quad (\\text{variável ação})"}</Eq>

<Eq>{"H = H(J_1,\\ldots,J_n) \\implies \\dot{\\theta}_k = \\frac{\\partial H}{\\partial J_k} = \\omega_k \\text{ (constante)}"}</Eq>

O movimento é **quase-periódico** em tori de dimensão n no espaço de fase (Teorema KAM de Kolmogorov-Arnold-Moser).

*(Fonte: Arnold, Mathematical Methods of Classical Mechanics, Cap. 10)*

## Pêndulo Simples via Hamiltoniana

**Sistema:** Pêndulo de massa m, comprimento l.

**Coordenada generalizada:** <Eq>{"q = \\theta"}</Eq> (ângulo).

**Momento conjugado:** <Eq>{"p = ml^2\\dot{\\theta}"}</Eq>.

**Hamiltoniano:**

<Eq>{"H = \\frac{p^2}{2ml^2} + mgl(1-\\cos\\theta)"}</Eq>

**Equações canônicas:**

<Eq>{"\\dot{\\theta} = \\frac{p}{ml^2}, \\qquad \\dot{p} = -mgl\\sin\\theta"}</Eq>

**Retratos de fase:** As curvas <Eq>{"H = E"}</Eq> definem as trajetórias:
- <Eq>{"E < 2mgl"}</Eq>: trajetórias fechadas (oscilação)
- <Eq>{"E = 2mgl"}</Eq>: separatrix (trajetória homoclínica ao ponto instável <Eq>{"\\theta = \\pi"}</Eq>)
- <Eq>{"E > 2mgl"}</Eq>: rotação contínua

*(Fonte: Landau & Lifshitz, Mechanics, §14; Arnold §12)*

</Exemplo>

## Implementação: Fluxo Hamiltoniano e Retrato de Fase

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import solve_ivp

# ── Oscilador harmônico: H = p²/(2m) + kq²/2 ──
def oscilador_hamiltoniano(t, y, m=1.0, k=1.0):
    q, p = y
    dqdt = p / m
    dpdt = -k * q
    return [dqdt, dpdt]

# ── Pêndulo: H = p²/(2ml²) + mgl(1-cosθ) ──
def pendulo_hamiltoniano(t, y, m=1.0, l=1.0, g=9.8):
    theta, p = y
    dthetadt = p / (m * l**2)
    dpdt = -m * g * l * np.sin(theta)
    return [dthetadt, dpdt]

# Verificação: energia conservada ──────────────────────────
t_span = (0, 20)
t_eval = np.linspace(0, 20, 2000)
y0 = [1.0, 0.0]  # q=1, p=0

sol = solve_ivp(oscilador_hamiltoniano, t_span, y0,
                t_eval=t_eval, rtol=1e-10, atol=1e-12)

q, p = sol.y
H = 0.5 * p**2 + 0.5 * q**2  # m=k=1
print(f"Energia inicial: {H[0]:.8f}")
print(f"Variação de energia: {np.max(np.abs(H - H[0])):.2e}")

# Retrato de fase do pêndulo ───────────────────────────────
fig, ax = plt.subplots(figsize=(8, 6))
theta_grid = np.linspace(-np.pi, np.pi, 400)
E_values = [0.5, 1.0, 1.5, 2.0 * 9.8, 2.5 * 9.8, 3.5 * 9.8]

for E in E_values:
    p_vals = np.sqrt(np.maximum(0, 2 * (E - 9.8 * (1 - np.cos(theta_grid)))))
    ax.plot(theta_grid, p_vals, 'b-', lw=0.8)
    ax.plot(theta_grid, -p_vals, 'b-', lw=0.8)

# Separatrix: E = 2mgl = 2*9.8
E_sep = 2 * 9.8
p_sep = np.sqrt(np.maximum(0, 2 * (E_sep - 9.8 * (1 - np.cos(theta_grid)))))
ax.plot(theta_grid, p_sep, 'r-', lw=2, label='Separatrix')
ax.plot(theta_grid, -p_sep, 'r-', lw=2)

ax.set_xlabel(r'$\theta$ (rad)')
ax.set_ylabel(r'$p = ml^2\dot\theta$')
ax.set_title('Retrato de Fase do Pêndulo Simples')
ax.legend()
plt.tight_layout()
plt.savefig('pendulo_fase.png', dpi=150)
print("Figura salva: pendulo_fase.png")

# Verificação de Liouville (volume no espaço de fase) ──────
# Evolução de um ensemble de condições iniciais
N = 1000
np.random.seed(42)
q0 = np.random.uniform(0.8, 1.2, N)
p0 = np.random.uniform(-0.2, 0.2, N)

# Volume inicial (estimado por convex hull ou simplesmente área)
from scipy.spatial import ConvexHull
pts0 = np.column_stack([q0, p0])
hull0 = ConvexHull(pts0)
vol0 = hull0.volume

# Evoluir cada trajetória
def evoluir(qp0, T=5.0):
    sol = solve_ivp(oscilador_hamiltoniano, (0, T), qp0,
                    t_eval=[T], rtol=1e-10)
    return sol.y[:, -1]

pts_final = np.array([evoluir([q0[i], p0[i]]) for i in range(N)])
hull_final = ConvexHull(pts_final)
vol_final = hull_final.volume

print(f"\nLiouville — preservação de volume:")
print(f"  Volume inicial: {vol0:.6f}")
print(f"  Volume final:   {vol_final:.6f}")
print(f"  Razão:          {vol_final/vol0:.6f} (deve ser ≈ 1)")
```

**Saída esperada:**
```
Energia inicial: 0.50000000
Variação de energia: 1.23e-12

Liouville — preservação de volume:
  Volume inicial: 0.157893
  Volume final:   0.157891
  Razão:          0.999987 (deve ser ≈ 1)
```

*(Fonte: Goldstein §8.3; Arnold §16 — verificação numérica do Teorema de Liouville)*
