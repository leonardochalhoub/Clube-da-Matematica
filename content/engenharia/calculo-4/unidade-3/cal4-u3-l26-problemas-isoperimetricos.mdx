# Problemas Isoperimétricos

O problema mais antigo do cálculo variacional com restrições é o **problema de Dido** (Virgílio, Eneida): dada uma corda de comprimento fixo L, qual curva fechada encerra a maior área possível?

A resposta, intuitivamente óbvia mas rigorosamente difícil, é o **círculo**. Esta é a **Desigualdade Isoperimétrica**: entre todas as curvas fechadas de mesmo perímetro, o círculo maximiza a área.

A técnica matemática para resolver esses problemas é o uso de **multiplicadores de Lagrange**, generalizando para funcionais o que já fazemos com funções no cálculo multivariável.

# Problemas Isoperimétricos: Formulação

## Problema Isoperimétrico Clássico

**Problema:** Maximizar (ou minimizar) o funcional:

<Eq>{"J[y] = \\int_a^b F(x, y, y')\\, dx"}</Eq>

sujeito à restrição integral (isoperimétrica):

<Eq>{"G[y] = \\int_a^b g(x, y, y')\\, dx = C \\quad (\\text{constante prescrita})"}</Eq>

e condições de fronteira <Eq>{"y(a) = \\alpha"}</Eq>, <Eq>{"y(b) = \\beta"}</Eq>.

## Método dos Multiplicadores de Lagrange

Seguindo Lagrange, formamos o **funcional aumentado**:

<Eq>{"\\tilde{J}[y] = J[y] - \\lambda G[y] = \\int_a^b [F(x,y,y') - \\lambda g(x,y,y')]\\, dx"}</Eq>

**Teorema (Lagrange):** Se <Eq>{"y^*"}</Eq> é extremizante de J com restrição G = C, e se a restrição é normal (não-degenerada), então existe <Eq>{"\\lambda \\in \\mathbb{R}"}</Eq> tal que <Eq>{"y^*"}</Eq> satisfaz a equação de Euler-Lagrange do funcional aumentado:

<EquacaoCanonica formula="\frac{\partial}{\partial y}(F - \lambda g) - \frac{d}{dx}\frac{\partial}{\partial y'}(F - \lambda g) = 0" />

O valor de λ é determinado pela condição de restrição G[y] = C.

*(Fonte: Gelfand & Fomin, Calculus of Variations, §12; Courant & Hilbert, Methods of Mathematical Physics, §4.5)*

## Exemplo: Catenária Isoperimétrica

**Problema:** Entre todas as curvas <Eq>{"y(x)"}</Eq> de comprimento L unindo <Eq>{"(-a, 0)"}</Eq> a <Eq>{"(a, 0)"}</Eq>, encontrar a que minimiza o centro de gravidade (equivalente a maximizar a área sob a curva dividida pelo comprimento).

Minimizar <Eq>{"J = \\int_{-a}^a y\\sqrt{1+y'^2}\\,dx"}</Eq> s.a. <Eq>{"\\int_{-a}^a \\sqrt{1+y'^2}\\,dx = L"}</Eq>.

Funcional aumentado: <Eq>{"\\int_{-a}^a (y-\\lambda)\\sqrt{1+y'^2}\\,dx"}</Eq>.

E-L: a solução é uma **catenária** <Eq>{"y = \\lambda + c\\cosh\\left(\\frac{x-x_0}{c}\\right)"}</Eq>.

*(Fonte: Gelfand & Fomin §12; Lanczos, Variational Principles, §5.7)*

# Desigualdade Isoperimétrica

## Enunciado

Para qualquer curva fechada simples <Eq>{"\\Gamma"}</Eq> de comprimento L e área interior A:

<EquacaoCanonica formula="L^2 \geq 4\pi A" />

com igualdade se e somente se <Eq>{"\\Gamma"}</Eq> é um círculo.

## Prova via Fourier (Hurwitz, 1902)

Parametrize <Eq>{"\\Gamma"}</Eq> por comprimento de arco: <Eq>{"\\mathbf{r}(s) = (x(s), y(s))"}</Eq>, <Eq>{"s \\in [0, L]"}</Eq>.

**Expansão de Fourier** (período L):

<Eq>{"x(s) = \\sum_{n=-\\infty}^\\infty a_n e^{2\\pi i n s/L}, \\quad y(s) = \\sum_{n=-\\infty}^\\infty b_n e^{2\\pi i n s/L}"}</Eq>

**Comprimento** (via Parseval):

<Eq>{"L = \\int_0^L (x'^2 + y'^2)\\,ds = L^2 \\cdot \\frac{4\\pi^2}{L^2}\\sum_n n^2(|a_n|^2 + |b_n|^2) = 4\\pi^2\\sum_n n^2(|a_n|^2+|b_n|^2)"}</Eq>

Portanto: <Eq>{"1 = \\frac{4\\pi^2}{L^2}\\sum_n n^2(|a_n|^2+|b_n|^2)"}</Eq>.

**Área** (fórmula de Green):

<Eq>{"A = \\frac{1}{2}\\oint (x\\,dy - y\\,dx) = \\pi \\sum_n n(a_n \\bar{b}_n - \\bar{a}_n b_n) \\cdot i"}</Eq>

Pela desigualdade de Cauchy-Schwarz:

<Eq>{"\\frac{4\\pi A}{L^2} \\leq \\sum_n n^2(|a_n|^2+|b_n|^2) = \\frac{L^2}{4\\pi^2} \\cdot \\frac{4\\pi^2}{L^2} = 1"}</Eq>

Logo <Eq>{"4\\pi A \\leq L^2"}</Eq>, com igualdade apenas para <Eq>{"n = \\pm 1"}</Eq> (círculo). <Eq>{"\\square"}</Eq>

*(Fonte: Stein & Shakarchi, Fourier Analysis, §4; Osserman, Bulletin AMS, 1978)*

## Múltiplas Restrições Isoperimetricas

Maximizar J[y] sujeito a <Eq>{"G_k[y] = C_k"}</Eq>, <Eq>{"k = 1,\\ldots,m"}</Eq>:

<Eq>{"\\frac{\\partial F}{\\partial y} - \\frac{d}{dx}\\frac{\\partial F}{\\partial y'} = \\sum_{k=1}^m \\lambda_k \\left(\\frac{\\partial g_k}{\\partial y} - \\frac{d}{dx}\\frac{\\partial g_k}{\\partial y'}\\right)"}</Eq>

com m multiplicadores de Lagrange <Eq>{"\\lambda_1, \\ldots, \\lambda_m"}</Eq> determinados pelas m restrições.

*(Fonte: Gelfand & Fomin §12; Dacorogna, Introduction to the Calculus of Variations, §5)*

## Problema de Sturm

**Problema de Sturm:** Entre todas as curvas de comprimento L com extremos fixos, encontrar a de curvatura mínima quadrática.

Minimizar <Eq>{"J = \\int_0^L \\kappa^2\\,ds"}</Eq> s.a. <Eq>{"\\int_0^L ds = L"}</Eq>.

A solução são **elasticas** de Euler, arcos circulares e linhas retas (casos degenerados).

*(Fonte: Langer & Singer, J. Diff. Geom., 1984; Love, A Treatise on the Mathematical Theory of Elasticity)*

# Teoria: Regularidade e Existência

## Condição de Regularidade (Não-Degenerescência)

O Teorema de Lagrange falha quando a restrição é **degenerada**. A condição de regularidade exige:

<Eq>{"G'[y^*] \\neq 0 \\quad \\text{(o funcional restrição tem derivada não-nula no ótimo)}"}</Eq>

Mais precisamente, o funcional linear <Eq>{"G'[y^*]: h \\mapsto \\int_a^b \\left(g_y h + g_{y'} h'\\right)dx"}</Eq> não deve ser identicamente nulo.

*(Fonte: Giaquinta & Hildebrandt, Calculus of Variations I, §4.3)*

## Problema Isoperimétrico em <Eq>{"H^1"}</Eq>

**Espaço de admissíveis:** <Eq>{"\\mathcal{A} = \\{y \\in H^1(a,b) : y(a) = \\alpha, y(b) = \\beta, G[y] = C\\}"}</Eq>.

**Teorema de Existência (Tonelli):** Se <Eq>{"F(x,y,p)"}</Eq> é convexa em p, crescimento <Eq>{"F \\geq c|p|^2 - d"}</Eq>, e <Eq>{"\\mathcal{A} \\neq \\emptyset"}</Eq>, então J attinge seu mínimo em <Eq>{"\\mathcal{A}"}</Eq>.

*(Fonte: Dacorogna §5; Evans §8.2)*

## Segundo Teorema de Poincaré (Inequação Poincaré-Wirtinger)

Para <Eq>{"u \\in H^1(0,L)"}</Eq> com <Eq>{"\\int_0^L u\\,dx = 0"}</Eq>:

<Eq>{"\\int_0^L u^2\\,dx \\leq \\frac{L^2}{\\pi^2}\\int_0^L (u')^2\\,dx"}</Eq>

A constante <Eq>{"L^2/\\pi^2"}</Eq> é ótima, atingida por <Eq>{"u = \\sin(\\pi x/L)"}</Eq>.

**Prova:** Expansão de Fourier: os modos <Eq>{"n \\geq 1"}</Eq> contribuem com coeficientes <Eq>{"a_n"}</Eq> satisfazendo <Eq>{"\\sum a_n^2 \\leq (L/\\pi)^2 \\sum n^2 a_n^2"}</Eq>.

*(Fonte: Evans, PDE, §5.8.1; Brezis, Functional Analysis, §8)*

## Desigualdade Isoperimétrica via Análise Funcional

**Abordagem via Sobolev:** A desigualdade isoperimétrica em <Eq>{"\\mathbb{R}^n"}</Eq>:

<Eq>{"|\\partial\\Omega|^n \\geq n^n \\omega_n |\\Omega|^{n-1}"}</Eq>

é equivalente à desigualdade de Sobolev:

<Eq>{"\\|u\\|_{L^{n/(n-1)}(\\mathbb{R}^n)} \\leq C\\|\\nabla u\\|_{L^1(\\mathbb{R}^n)}"}</Eq>

via a função indicadora <Eq>{"u = \\mathbf{1}_\\Omega"}</Eq>.

*(Fonte: Evans §5.6; Osserman, Bulletin AMS, 1978; Federer, Geometric Measure Theory)*

## Problema de Dido: Solução Detalhada

**Problema:** Maximizar a área A = <Eq>{"\\int_0^L y\\,dx"}</Eq> entre uma curva <Eq>{"y(x) \\geq 0"}</Eq> e o eixo x, com comprimento de arco fixo <Eq>{"\\int_0^L \\sqrt{1+y'^2}\\,dx = \\ell"}</Eq> e <Eq>{"y(0) = y(L) = 0"}</Eq>.

**Funcional aumentado:**

<Eq>{"\\tilde{J} = \\int_0^L \\left[y - \\lambda\\sqrt{1+y'^2}\\right]dx"}</Eq>

**Equação de Euler-Lagrange:**

<Eq>{"1 + \\lambda\\frac{d}{dx}\\left(\\frac{y'}{\\sqrt{1+y'^2}}\\right) = 0 \\implies \\frac{d}{dx}\\left(\\frac{y'}{\\sqrt{1+y'^2}}\\right) = -\\frac{1}{\\lambda}"}</Eq>

A expressão <Eq>{"y'/\\sqrt{1+y'^2} = \\sin\\theta"}</Eq> é o seno do ângulo de inclinação, então:

<Eq>{"\\frac{d\\theta}{ds} = \\kappa = \\frac{1}{|\\lambda|} = \\text{constante}"}</Eq>

**Conclusão:** A curvatura é constante, logo a curva é um **arco circular** de raio <Eq>{"|\\lambda|"}</Eq>.

O raio é determinado por: comprimento do arco <Eq>{"= \\ell"}</Eq> e condições de fronteira.

*(Fonte: Gelfand & Fomin §12.1; Courant & Hilbert §4.5)*

</Exemplo>

## Implementação: Problema Isoperimétrico Numérico

```python
import numpy as np
from scipy.optimize import minimize
import matplotlib.pyplot as plt

# ── Discretização do problema isoperimétrico ───────────────
# Maximizar área sob curva y(x) de comprimento fixo ell
# Discretização com N pontos interiores em x = [0, 1]

N = 50
x = np.linspace(0, 1, N+2)
h = x[1] - x[0]
ell_target = 1.5  # comprimento desejado (> 1 = comprimento mínimo entre y=0)

def area(y_interior):
    y = np.concatenate([[0], y_interior, [0]])
    return np.trapz(y, x)

def comprimento(y_interior):
    y = np.concatenate([[0], y_interior, [0]])
    dy = np.diff(y)
    dx_arr = np.diff(x)
    return np.sum(np.sqrt(dx_arr**2 + dy**2))

# Função objetivo: negativar área (minimizar = maximizar área)
def neg_area(y_int):
    return -area(y_int)

# Restrição: comprimento = ell_target
constraints = {
    'type': 'eq',
    'fun': lambda y: comprimento(y) - ell_target
}

# Solução inicial: parábola normalizada
y0 = np.sin(np.pi * x[1:-1]) * 0.3

result = minimize(neg_area, y0,
                  method='SLSQP',
                  constraints=constraints,
                  options={'ftol': 1e-10, 'maxiter': 1000})

y_opt = np.concatenate([[0], result.x, [0]])

print(f"Área máxima: {area(result.x):.6f}")
print(f"Comprimento: {comprimento(result.x):.6f} (alvo: {ell_target})")
print(f"Convergiu: {result.success}")

# Solução analítica: arco circular
# Para comprimento ell e span 1:
# Raio R: 2R * arcsin(1/(2R)) = ell/2 → resolver numericamente
from scipy.optimize import brentq
def eq_raio(R):
    return 2*R*np.arcsin(1/(2*R)) - ell_target

R = brentq(eq_raio, 0.51, 10)
# Centro em x=0.5, y = -sqrt(R² - 0.25) + R (acima)
xc, yc_center = 0.5, -(R**2 - 0.25)**0.5
y_circ = np.maximum(0, np.sqrt(np.maximum(0, R**2 - (x - xc)**2)) + yc_center)

A_circ = np.trapz(y_circ, x)
print(f"\nSolução analítica (arco circular):")
print(f"  Raio: R = {R:.4f}")
print(f"  Área: {A_circ:.6f}")
print(f"  Diferença numérico vs. analítico: {abs(area(result.x) - A_circ):.2e}")

# Visualização
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

axes[0].plot(x, y_opt, 'b-', lw=2, label='Solução numérica')
axes[0].plot(x, y_circ, 'r--', lw=2, label=f'Arco circular (R={R:.3f})')
axes[0].set_xlabel('x')
axes[0].set_ylabel('y')
axes[0].set_title(f'Problema Isoperimétrico (ℓ = {ell_target})')
axes[0].legend()
axes[0].set_ylim(bottom=0)
axes[0].grid(True, alpha=0.3)

# Desigualdade isoperimétrica: L² ≥ 4πA
ells = np.linspace(1.0, 3.0, 200)
A_bound = ells**2 / (4*np.pi)
axes[1].plot(ells, A_bound, 'k-', lw=2, label='$L^2/(4\\pi)$ (limite superior)')
axes[1].axvline(ell_target, color='r', ls='--', label=f'ℓ = {ell_target}')
axes[1].axhline(A_circ, color='b', ls='--', label=f'A máx = {A_circ:.4f}')
axes[1].set_xlabel('Comprimento L')
axes[1].set_ylabel('Área')
axes[1].set_title('Desigualdade Isoperimétrica: $A \\leq L^2/(4\\pi)$')
axes[1].legend()
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('isoperimetrico.png', dpi=150)
print("\nFigura salva: isoperimetrico.png")

# Verificação: L² ≥ 4π A
print(f"\nVerificação: L² = {ell_target**2:.4f}, 4πA = {4*np.pi*A_circ:.4f}")
print(f"  L² ≥ 4πA: {ell_target**2 >= 4*np.pi*A_circ - 1e-10}")
print(f"  Igualdade (círculo completo): {abs(ell_target**2 - 4*np.pi*A_circ):.4f}")
```
