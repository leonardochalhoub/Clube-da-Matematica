# Por Que Espaços de Sobolev?

O Cálculo Variacional clássico trabalha com funções que possuem duas derivadas contínuas. Mas muitos problemas físicos — como o perfil de temperatura numa barra com fontes descontínuas, ou a deflexão de uma membrana — possuem soluções que **não são diferenciáveis** no sentido clássico.

Os **Espaços de Sobolev**, introduzidos por Sergei Sobolev (1908–1989), fornecem o ambiente correto para garantir a **existência** de soluções — mesmo para problemas onde a solução clássica não existe.

A ideia: ampliar a noção de derivada (derivadas fracas) e trabalhar em espaços de Hilbert completos, onde a otimização funciona bem.

# Espaços de Sobolev: Revisão Rápida

## Derivadas Fracas

Uma função <Eq>{"u \\in L^2(\\Omega)"}</Eq> possui **derivada fraca** <Eq>{"v = D^\\alpha u"}</Eq> se:

<Eq>{"\\int_\\Omega u D^\\alpha \\phi\\, dx = (-1)^{|\\alpha|} \\int_\\Omega v \\phi\\, dx \\quad \\forall \\phi \\in C_c^\\infty(\\Omega)"}</Eq>

## Espaço <Eq>{"H^1(\\Omega)"}</Eq>

<Eq>{"H^1(\\Omega) = W^{1,2}(\\Omega) = \\{u \\in L^2(\\Omega) : Du \\in L^2(\\Omega)\\}"}</Eq>

com produto interno:

<Eq>{"(u,v)_{H^1} = \\int_\\Omega (uv + \\nabla u \\cdot \\nabla v)\\, dx"}</Eq>

**Espaço <Eq>{"H_0^1(\\Omega)"}</Eq>:** fechamento de <Eq>{"C_c^\\infty(\\Omega)"}</Eq> em <Eq>{"H^1"}</Eq> — funções que "se anulam na fronteira" no sentido fraco.

*(Fonte: Evans, PDE, §5.2; Brezis, Functional Analysis, Sobolev Spaces and PDEs, §8)*

## Formulação Variacional do Problema de Poisson

Problema clássico: encontrar <Eq>{"u"}</Eq> tal que:

<Eq>{"-\\Delta u = f \\text{ em } \\Omega, \\quad u = 0 \\text{ em } \\partial\\Omega"}</Eq>

**Formulação fraca:** Multiplique por <Eq>{"v \\in H_0^1(\\Omega)"}</Eq> e integre por partes:

<Eq>{"\\int_\\Omega \\nabla u \\cdot \\nabla v\\, dx = \\int_\\Omega fv\\, dx \\quad \\forall v \\in H_0^1(\\Omega)"}</Eq>

Ou em notação abstrata: encontrar <Eq>{"u \\in H_0^1"}</Eq> tal que <Eq>{"a(u,v) = F(v)"}</Eq> para todo <Eq>{"v \\in H_0^1"}</Eq>, onde:

<Eq>{"a(u,v) = \\int_\\Omega \\nabla u \\cdot \\nabla v\\,dx, \\qquad F(v) = \\int_\\Omega fv\\,dx"}</Eq>

*(Fonte: Evans §6.1; Brezis §9)*

# Teorema de Lax-Milgram e Existência

## Forma Bilinear e Funcional Linear

Seja V um espaço de Hilbert. Uma **forma bilinear** <Eq>{"a: V \\times V \\to \\mathbb{R}"}</Eq> é:
- **Contínua:** <Eq>{"|a(u,v)| \\leq M\\|u\\|_V \\|v\\|_V"}</Eq>
- **Coerciva:** <Eq>{"a(u,u) \\geq \\alpha\\|u\\|_V^2"}</Eq> para algum <Eq>{"\\alpha > 0"}</Eq>

Um **funcional linear** <Eq>{"F: V \\to \\mathbb{R}"}</Eq> é contínuo se <Eq>{"|F(v)| \\leq C\\|v\\|_V"}</Eq>.

## Teorema de Lax-Milgram

**Enunciado:** Se <Eq>{"a"}</Eq> é bilinear, contínua e coerciva em V, e F é linear e contínuo em V, então existe **único** <Eq>{"u \\in V"}</Eq> tal que:

<EquacaoCanonica formula="a(u, v) = F(v) \quad \forall v \in V" />

Além disso, <Eq>{"\\|u\\|_V \\leq \\frac{1}{\\alpha}\\|F\\|_{V'}"}</Eq>.

*(Fonte: Evans §6.2.1; Brezis §6.2; Lax & Milgram, 1954)*

## Aplicação ao Problema de Poisson

**Verificação da coercividade** (usa Desigualdade de Poincaré em <Eq>{"H_0^1"}</Eq>):

<Eq>{"\\|u\\|_{L^2}^2 \\leq C_{\\Omega}\\|\\nabla u\\|_{L^2}^2 \\quad \\forall u \\in H_0^1(\\Omega)"}</Eq>

Logo:

<Eq>{"a(u,u) = \\|\\nabla u\\|_{L^2}^2 \\geq \\frac{1}{1+C_\\Omega}\\|u\\|_{H^1}^2"}</Eq>

**Conclusão:** Para todo <Eq>{"f \\in L^2(\\Omega)"}</Eq>, existe **única solução fraca** <Eq>{"u \\in H_0^1(\\Omega)"}</Eq> do problema de Poisson.

*(Fonte: Evans §6.2; Brezis §9.2)*

## Conexão com Minimização

O problema <Eq>{"a(u,v) = F(v)"}</Eq> é equivalente a minimizar:

<Eq>{"I[u] = \\frac{1}{2}a(u,u) - F(u) = \\frac{1}{2}\\int_\\Omega |\\nabla u|^2\\,dx - \\int_\\Omega fu\\,dx"}</Eq>

sobre <Eq>{"H_0^1(\\Omega)"}</Eq>, quando a é simétrica. A equivalência é pela identidade:

<Eq>{"I[u+v] = I[u] + a(u,v) - F(v) + \\frac{1}{2}a(v,v) \\geq I[u]"}</Eq>

quando <Eq>{"a(u,v) = F(v)"}</Eq> para todo v.

*(Fonte: Evans §6.1; Dacorogna §1)*

# Método Direto e Convexidade

## Método Direto do Cálculo das Variações (Tonelli)

**Estratégia:** Para minimizar <Eq>{"I[u] = \\int_\\Omega F(x, u, \\nabla u)\\,dx"}</Eq> sobre <Eq>{"\\mathcal{A} \\subset W^{1,p}"}</Eq>:

1. Tome uma sequência minimizante: <Eq>{"u_k \\in \\mathcal{A}"}</Eq> com <Eq>{"I[u_k] \\to \\inf I"}</Eq>.
2. Prove que <Eq>{"(u_k)"}</Eq> é limitada em <Eq>{"W^{1,p}"}</Eq> (via coercividade).
3. Extraia uma subsequência convergindo **fracamente**: <Eq>{"u_{k_j} \\rightharpoonup u^*"}</Eq>.
4. Prove semicontinuidade inferior fraca: <Eq>{"I[u^*] \\leq \\liminf I[u_{k_j}]"}</Eq>.
5. Verifique <Eq>{"u^* \\in \\mathcal{A}"}</Eq> (fechamento da classe admissível).

**Resultado:** <Eq>{"I[u^*] = \\min_{u \\in \\mathcal{A}} I[u]"}</Eq>.

*(Fonte: Evans §8.2; Dacorogna §3; Giusti)*

## Convexidade e Semicontinuidade Inferior

**Teorema:** Se <Eq>{"p \\mapsto F(x, s, p)"}</Eq> é **convexa** para q.t.p. x e todo s, então I é fracamente s.c.i. em <Eq>{"W^{1,p}"}</Eq>.

**Prova:** Para <Eq>{"u_k \\rightharpoonup u"}</Eq> em <Eq>{"W^{1,p}"}</Eq>, use a desigualdade de Jensen:

<Eq>{"F(x, u, \\nabla u) \\leq \\liminf_k F(x, u_k, \\nabla u_k) \\quad \\text{(por convexidade + convergência fraca)}"}</Eq>

*(Fonte: Evans §8.2.2; Dacorogna §3.4)*

## Quasiconvexidade (Morrey, 1952)

Para sistemas vetoriais (<Eq>{"u: \\Omega \\to \\mathbb{R}^m"}</Eq>, <Eq>{"m > 1"}</Eq>), a convexidade em <Eq>{"p"}</Eq> é **suficiente** mas não **necessária** para s.c.i.

A condição necessária e suficiente é a **quasiconvexidade** de Morrey:

<Eq>{"F(P) \\leq \\frac{1}{|D|}\\int_D F(P + \\nabla\\phi)\\,dx \\quad \\forall \\phi \\in W_0^{1,\\infty}(D), \\, \\forall P \\in \\mathbb{R}^{m\\times n}"}</Eq>

*(Fonte: Dacorogna §5.1; Evans §8.3; Morrey, Pacific J. Math., 1952)*

## Condição de Coercividade p-Crescimento

Para existência via método direto, basta crescimento p-coercivo:

<Eq>{"F(x, s, p) \\geq c_1|p|^p - c_2 \\quad (c_1 > 0, c_2 \\geq 0, p > 1)"}</Eq>

**Ejemplo:** Funcional p-Laplaciano <Eq>{"I_p[u] = \\int_\\Omega |\\nabla u|^p\\,dx"}</Eq> com condições de Dirichlet tem minimizante único em <Eq>{"W_0^{1,p}(\\Omega)"}</Eq>.

*(Fonte: Evans §8.1; Dacorogna §3)*

## Equação de Laplace: Solução Fraca vs. Clássica

**Problema:** <Eq>{"-\\Delta u = f"}</Eq> em <Eq>{"\\Omega = (0,1)^2"}</Eq>, <Eq>{"u = 0"}</Eq> na fronteira, com:

<Eq>{"f(x,y) = \\mathbf{1}_{[0.25, 0.75]^2}(x,y) \\quad (\\text{função descontínua})"}</Eq>

**Solução clássica:** Não existe (f é descontínua).

**Solução fraca:** Existe única <Eq>{"u \\in H_0^1(\\Omega)"}</Eq> por Lax-Milgram (F = integração contra f ∈ L²).

**Expansão espectral:**

<Eq>{"u(x,y) = \\sum_{m,n=1}^\\infty \\frac{\\hat{f}_{mn}}{\\pi^2(m^2+n^2)}\\sin(m\\pi x)\\sin(n\\pi y)"}</Eq>

onde <Eq>{"\\hat{f}_{mn} = 4\\int_0^1\\int_0^1 f\\sin(m\\pi x)\\sin(n\\pi y)\\,dx\\,dy"}</Eq>.

A solução fraca u é de classe <Eq>{"H^2(\\Omega)"}</Eq> pelo **Teorema de Regularidade Elíptica** (mesmo com f ∈ L²), mas não é <Eq>{"C^2"}</Eq> clássica.

*(Fonte: Evans §6.3 — regularidade interior; Brezis §9.5)*

## Implementação: Método de Elementos Finitos (FEM)

```python
import numpy as np
from scipy.sparse import lil_matrix, csr_matrix
from scipy.sparse.linalg import spsolve
import matplotlib.pyplot as plt

# ── Elemento Finito 1D: -u'' = f, u(0) = u(1) = 0 ─────────
def fem_1d_poisson(N, f_func):
    """
    Resolve -u'' = f em [0,1] com u(0)=u(1)=0
    usando elementos finitos lineares (P1) com N elementos.
    """
    h = 1.0 / N
    x_nodes = np.linspace(0, 1, N+1)
    
    # Montagem da matriz de rigidez K e vetor de carga F
    # Para P1: K_local = (1/h)*[[1,-1],[-1,1]], F_local = h/2*[f(x_i), f(x_{i+1})]
    K = lil_matrix((N+1, N+1))
    F_vec = np.zeros(N+1)
    
    for i in range(N):
        x_left, x_right = x_nodes[i], x_nodes[i+1]
        # Matriz de rigidez local
        K[i, i]     += 1.0/h
        K[i, i+1]   -= 1.0/h
        K[i+1, i]   -= 1.0/h
        K[i+1, i+1] += 1.0/h
        # Vetor de carga local (quadratura de ponto médio)
        x_mid = (x_left + x_right) / 2
        F_vec[i]   += h/2 * f_func(x_left)
        F_vec[i+1] += h/2 * f_func(x_right)
    
    # Aplicar condições de Dirichlet (u(0) = u(1) = 0)
    K = K.tocsr()
    K = K.tolil()
    K[0, :] = 0; K[0, 0] = 1; F_vec[0] = 0
    K[N, :] = 0; K[N, N] = 1; F_vec[N] = 0
    
    K = csr_matrix(K)
    u = spsolve(K, F_vec)
    return x_nodes, u

# ── Teste 1: f = π² sin(πx), solução exata u = sin(πx) ───
f1 = lambda x: np.pi**2 * np.sin(np.pi * x)
u_exata = lambda x: np.sin(np.pi * x)

erros = []
Ns = [10, 20, 40, 80, 160]
for N in Ns:
    x, u_h = fem_1d_poisson(N, f1)
    erro = np.max(np.abs(u_h - u_exata(x)))
    erros.append(erro)
    print(f"N = {N:4d}: erro_inf = {erro:.2e}")

# Taxa de convergência
import numpy as np
taxas = [np.log(erros[i-1]/erros[i])/np.log(2) for i in range(1, len(erros))]
print(f"Taxas de convergência: {[f'{t:.2f}' for t in taxas]}")
print("(Esperado: ≈ 2 para P1, problema suave)")

# ── Teste 2: f descontínua (solução fraca) ────────────────
f2 = lambda x: 1.0 if 0.25 <= x <= 0.75 else 0.0
x_fine, u_fraca = fem_1d_poisson(200, f2)

# Solução analítica para f = 1_{[1/4, 3/4]}
def u_analitica(x):
    if x <= 0.25:
        return x * (0.75 - 0.5*x - 0.5) / 1  # ajuste
    # Por integração direta: -u'' = f → u linear por partes
    # Região x ≤ 1/4: u'' = 0 → u = ax
    # Região 1/4 ≤ x ≤ 3/4: u'' = -1 → u = -x²/2 + bx + c
    # Região x ≥ 3/4: u'' = 0 → u = dx + e
    # Com u(0) = u(1) = 0 e continuidade de u e u' nos pontos de descontinuidade:
    if x <= 0.25:
        return 3*x/32
    elif x <= 0.75:
        return -x**2/2 + x/2 - 1/32
    else:
        return 3*(1-x)/32

u_anal = np.array([u_analitica(xi) for xi in x_fine])

print(f"\nSolução fraca (f descontínua):")
print(f"  u(0.5) numérico: {u_fraca[100]:.6f}")
print(f"  u(0.5) analítico: {u_analitica(0.5):.6f}")

# Visualização
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

x_test, u_h = fem_1d_poisson(40, f1)
axes[0].plot(x_test, u_h, 'b.-', ms=4, label='FEM (N=40)')
axes[0].plot(x_test, u_exata(x_test), 'r-', label='Exata')
axes[0].set_title('Problema de Poisson: $f = \\pi^2\\sin(\\pi x)$')
axes[0].legend(); axes[0].grid(True, alpha=0.3)

axes[1].plot(x_fine, u_fraca, 'b-', label='Solução fraca (FEM, N=200)')
axes[1].plot(x_fine, u_anal, 'r--', label='Analítica')
axes[1].axvspan(0.25, 0.75, alpha=0.2, color='gray', label='suporte de f')
axes[1].set_title('Solução Fraca: f descontínua')
axes[1].legend(); axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('fem_sobolev.png', dpi=150)
print("\nFigura salva: fem_sobolev.png")

# Verificação: energia mínima (coercividade)
print("\nVerificação de coercividade (energia):")
for N in [20, 40, 80]:
    x, u = fem_1d_poisson(N, f1)
    h = x[1] - x[0]
    energia = np.sum(np.diff(u)**2) / h  # ≈ ∫|u'|² dx
    norma_H1 = np.sqrt(np.sum(u**2)*h + energia)
    norma_L2_f = np.sqrt(np.sum(f1(x)**2)*h)
    print(f"  N={N}: ||u||_H1 = {norma_H1:.4f}, ||f||_L2 = {norma_L2_f:.4f}")
```
