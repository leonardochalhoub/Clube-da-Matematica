# Controle Ótimo

Imagine que você precisa levar um foguete da Terra até a Lua gastando o mínimo de combustível possível, ou frear um carro na distância mínima. Esses são problemas de **controle ótimo**: dado um sistema dinâmico, escolher as entradas (controles) de modo a minimizar um custo enquanto o sistema evolui de um estado a outro.

Lev Pontryagin (1908–1988) e sua equipe desenvolveram o **Princípio do Mínimo** que fornece as condições necessárias para o controle ótimo — uma generalização do Cálculo Variacional para problemas com restrições nas variáveis de controle.

# Formulação do Problema de Controle Ótimo

## Problema Geral

**Sistema dinâmico:**

<Eq>{"\\dot{x}(t) = f(x(t), u(t), t), \\quad x(t_0) = x_0"}</Eq>

onde <Eq>{"x(t) \\in \\mathbb{R}^n"}</Eq> é o **estado**, <Eq>{"u(t) \\in U \\subseteq \\mathbb{R}^m"}</Eq> é o **controle** (com restrições <Eq>{"u(t) \\in U"}</Eq>).

**Funcional de custo (Bolza):**

<Eq>{"J[u] = \\Phi(x(t_f), t_f) + \\int_{t_0}^{t_f} L(x(t), u(t), t)\\, dt"}</Eq>

onde <Eq>{"\\Phi"}</Eq> é o custo terminal e <Eq>{"L"}</Eq> é o custo corrente (integrando de Lagrange).

**Problema:** Minimizar <Eq>{"J[u]"}</Eq> sujeito à dinâmica e às restrições <Eq>{"u \\in U"}</Eq>.

**Casos especiais:**

| Forma | Definição |
|---|---|
| Lagrange | <Eq>{"\\Phi = 0"}</Eq> |
| Mayer | <Eq>{"L = 0"}</Eq> |
| Bolza | Caso geral |
| Tempo mínimo | <Eq>{"L = 1"}</Eq> (minimiza <Eq>{"t_f - t_0"}</Eq>) |

*(Fonte: Kirk, Optimal Control Theory, §2.1; Pontryagin et al., Mathematical Theory of Optimal Processes, §1)*

## Hamiltoniano de Pontryagin

Introduzindo o **vetor de co-estado** (adjunto) <Eq>{"\\lambda(t) \\in \\mathbb{R}^n"}</Eq>, define-se o **Hamiltoniano de Pontryagin**:

<Eq>{"\\mathcal{H}(x, u, \\lambda, t) = L(x, u, t) + \\lambda^T f(x, u, t)"}</Eq>

*(Fonte: Kirk §4.2; Pontryagin et al. §2)*

# Princípio do Mínimo de Pontryagin

## Enunciado

Se <Eq>{"u^*(t)"}</Eq> é o controle ótimo e <Eq>{"x^*(t)"}</Eq> a trajetória ótima correspondente, então existe um vetor adjunto <Eq>{"\\lambda^*(t) \\neq 0"}</Eq> tal que:

**1. Equação de estado (forward):**

<Eq>{"\\dot{x}^* = \\frac{\\partial \\mathcal{H}}{\\partial \\lambda} = f(x^*, u^*, t)"}</Eq>

**2. Equação adjunta (backward):**

<Eq>{"\\dot{\\lambda}^* = -\\frac{\\partial \\mathcal{H}}{\\partial x}\\bigg|_{(x^*,u^*,\\lambda^*)}"}</Eq>

**3. Condição de mínimo:**

<EquacaoCanonica formula="\mathcal{H}(x^*, u^*, \lambda^*, t) = \min_{u \in U}\, \mathcal{H}(x^*, u, \lambda^*, t) \quad \forall t \in [t_0, t_f]" />

**4. Condições de transversalidade** (para <Eq>{"t_f"}</Eq> livre):

<Eq>{"\\lambda^*(t_f) = \\frac{\\partial \\Phi}{\\partial x}\\bigg|_{t_f}, \\qquad \\mathcal{H}(t_f) = -\\frac{\\partial \\Phi}{\\partial t}\\bigg|_{t_f}"}</Eq>

*(Fonte: Pontryagin, Boltyansky, Gamkrelidze & Mishchenko, Mathematical Theory of Optimal Processes, Cap. 3; Kirk §4.2)*

## Controle Bang-Bang

Quando <Eq>{"U = [u_{\\min}, u_{\\max}]"}</Eq> e <Eq>{"\\mathcal{H}"}</Eq> é **linear** em u:

<Eq>{"\\mathcal{H} = \\phi(t) u + \\text{termos sem } u"}</Eq>

O mínimo é atingido nos extremos (controle **bang-bang**):

<Eq>{"u^*(t) = \\begin{cases} u_{\\max} & \\phi(t) < 0 \\\\ u_{\\min} & \\phi(t) > 0 \\\\ \\text{indeterminado} & \\phi(t) = 0 \\end{cases}"}</Eq>

A função <Eq>{"\\phi(t) = \\lambda^T(t) B"}</Eq> é chamada **função de comutação** (switching function).

*(Fonte: Kirk §4.5; Pontryagin et al. §2.7)*

## Exemplo: Problema do Tempo Mínimo (Duplo Integrador)

**Sistema:** <Eq>{"\\ddot{x} = u"}</Eq>, ou seja <Eq>{"\\dot{x}_1 = x_2"}</Eq>, <Eq>{"\\dot{x}_2 = u"}</Eq>, com <Eq>{"|u| \\leq 1"}</Eq>.

**Custo:** Minimizar <Eq>{"t_f"}</Eq> (tempo para ir de <Eq>{"(x_1^0, x_2^0)"}</Eq> para a origem).

**Hamiltoniano:** <Eq>{"\\mathcal{H} = 1 + \\lambda_1 x_2 + \\lambda_2 u"}</Eq>.

**Equações adjuntas:** <Eq>{"\\dot{\\lambda}_1 = 0"}</Eq>, <Eq>{"\\dot{\\lambda}_2 = -\\lambda_1"}</Eq>.

Logo: <Eq>{"\\lambda_1 = c_1"}</Eq>, <Eq>{"\\lambda_2 = -c_1 t + c_2"}</Eq> (linear em t).

**Controle bang-bang:** <Eq>{"u^*(t) = -\\text{sgn}(\\lambda_2(t)) = -\\text{sgn}(-c_1 t + c_2)"}</Eq>.

Como <Eq>{"\\lambda_2"}</Eq> é linear, troca de sinal **no máximo uma vez**: o controle ótimo tem **no máximo uma comutação** (resultado do Teorema de Pontryagin para sistemas lineares).

*(Fonte: Kirk §4.5; Athans & Falb, Optimal Control, §7)*

# Equação de Hamilton-Jacobi-Bellman

## Princípio da Otimalidade de Bellman

**Enunciado (Bellman, 1957):** Uma política ótima tem a propriedade de que, qualquer que seja o estado e a decisão iniciais, as decisões restantes devem constituir uma política ótima em relação ao estado resultante do primeiro instante.

**Função valor (cost-to-go):**

<Eq>{"V(x, t) = \\min_{u(\\cdot)} \\left[\\Phi(x(t_f)) + \\int_t^{t_f} L(x,u,\\tau)\\,d\\tau\\right]"}</Eq>

## Equação HJB

Se <Eq>{"V"}</Eq> é diferenciável (solução clássica), satisfaz a **equação de Hamilton-Jacobi-Bellman**:

<EquacaoCanonica formula="-\frac{\partial V}{\partial t} = \min_{u \in U}\left[L(x,u,t) + \left(\frac{\partial V}{\partial x}\right)^T f(x,u,t)\right]" />

com condição terminal <Eq>{"V(x, t_f) = \\Phi(x)"}</Eq>.

**Conexão com Pontryagin:** O co-estado ótimo é o gradiente da função valor:

<Eq>{"\\lambda^*(t) = \\frac{\\partial V}{\\partial x}(x^*(t), t)"}</Eq>

*(Fonte: Bellman, Dynamic Programming, 1957; Kirk §3.3; Lewis, Vrabie & Syrmos, Optimal Control, §2.5)*

## Regulador Linear-Quadrático (LQR)

**Sistema linear:** <Eq>{"\\dot{x} = Ax + Bu"}</Eq>, controle irrestrito <Eq>{"U = \\mathbb{R}^m"}</Eq>.

**Custo quadrático:**

<Eq>{"J = \\frac{1}{2}x^T(t_f)S_f x(t_f) + \\frac{1}{2}\\int_0^{t_f}(x^TQx + u^TRu)\\,dt"}</Eq>

onde <Eq>{"Q \\geq 0"}</Eq>, <Eq>{"R > 0"}</Eq>, <Eq>{"S_f \\geq 0"}</Eq> matrizes simétricas.

**A HJB torna-se linear:** Fazendo <Eq>{"V(x,t) = \\frac{1}{2}x^T P(t) x"}</Eq>, obtém-se a **equação de Riccati**:

<EquacaoCanonica formula="-\dot{P} = PA + A^TP - PBR^{-1}B^TP + Q, \quad P(t_f) = S_f" />

**Controle ótimo (feedback):**

<Eq>{"u^*(t) = -R^{-1}B^T P(t) x(t) = -K(t)x(t)"}</Eq>

**Caso estacionário** (<Eq>{"t_f \\to \\infty"}</Eq>): P resolve a equação algébrica de Riccati (ARE):

<Eq>{"PA + A^TP - PBR^{-1}B^TP + Q = 0"}</Eq>

e o ganho ótimo é <Eq>{"K = R^{-1}B^TP"}</Eq>.

*(Fonte: Kirk §5.1–5.2; Lewis, Vrabie & Syrmos, §3; Anderson & Moore, Optimal Control)*

## Solução Viscosa da HJB

Quando V não é diferenciável (controle bang-bang, restrições ativas), a HJB deve ser interpretada no sentido de **solução viscosa** (Crandall-Lions):

V é solução viscosa se, para qualquer <Eq>{"\\phi \\in C^1"}</Eq>:
- Se V−φ tem máximo local em <Eq>{"(x_0,t_0)"}</Eq>: <Eq>{"-\\phi_t \\leq \\min_u H(x_0,\\nabla\\phi,u)"}</Eq> (sub-solução)
- Se V−φ tem mínimo local em <Eq>{"(x_0,t_0)"}</Eq>: <Eq>{"-\\phi_t \\geq \\min_u H(x_0,\\nabla\\phi,u)"}</Eq> (super-solução)

*(Fonte: Evans, PDE, §10.3; Crandall & Lions, Trans. AMS, 1983)*

## LQR para Controle de Pêndulo Invertido

**Linearização em torno do equilíbrio instável** <Eq>{"\\theta = \\pi"}</Eq>, <Eq>{"\\dot{\\theta} = 0"}</Eq>:

Fazendo <Eq>{"\\theta = \\pi + \\phi"}</Eq> (φ pequeno):

<Eq>{"A = \\begin{pmatrix} 0 & 1 \\\\ g/l & 0 \\end{pmatrix}, \\quad B = \\begin{pmatrix} 0 \\\\ 1/(ml^2) \\end{pmatrix}"}</Eq>

**Parâmetros LQR** (pesos de projeto):

<Eq>{"Q = \\begin{pmatrix} 10 & 0 \\\\ 0 & 1 \\end{pmatrix}, \\quad R = 0{,}01"}</Eq>

**Solução ARE e ganho ótimo:**

<Eq>{"K = R^{-1}B^T P = [k_1 \\quad k_2]"}</Eq>

O controlador <Eq>{"u = -K\\mathbf{x}"}</Eq> estabiliza o pêndulo com desempenho ótimo.

*(Fonte: Kirk §5.2; Stengel, Optimal Control and Estimation, §4)*

</Exemplo>

## Implementação: LQR e Solução de Riccati

```python
import numpy as np
from scipy.linalg import solve_continuous_are, solve_continuous_lyapunov
import matplotlib.pyplot as plt
from scipy.integrate import solve_ivp

# ── Pêndulo invertido linearizado ──────────────────────────
m, l, g = 1.0, 1.0, 9.8
A = np.array([[0, 1],
              [g/l, 0]])
B = np.array([[0],
              [1/(m*l**2)]])

# Matrizes de custo LQR
Q = np.diag([10.0, 1.0])
R = np.array([[0.01]])

# ── Resolver equação algébrica de Riccati (ARE) ─────────────
P = solve_continuous_are(A, B, Q, R)
K = np.linalg.solve(R, B.T @ P)  # K = R⁻¹ B^T P

print("Matriz P (solução ARE):")
print(P)
print(f"\nGanho K = {K.flatten()}")

# Verificar ARE: P*A + A'*P - P*B*R⁻¹*B'*P + Q = 0
residuo = P @ A + A.T @ P - P @ B @ np.linalg.solve(R, B.T @ P) + Q
print(f"Resíduo ARE (deve ser ≈ 0): max|resíduo| = {np.max(np.abs(residuo)):.2e}")

# Autovalores do sistema em malha fechada
Acl = A - B @ K
eigenvalues = np.linalg.eigvals(Acl)
print(f"\nAutovalores em malha fechada: {eigenvalues}")
print(f"  Todos com parte real negativa: {np.all(np.real(eigenvalues) < 0)}")

# ── Simulação do sistema controlado ────────────────────────
def pendulo_lqr(t, x):
    u = -K @ x
    # Saturar controle em ±10 N·m (realístico)
    u = np.clip(u, -10, 10)
    return (A @ x + B @ u).flatten()

x0 = [0.1, 0.0]  # Perturbação inicial de 0.1 rad
sol = solve_ivp(pendulo_lqr, (0, 5), x0,
                t_eval=np.linspace(0, 5, 500), rtol=1e-9)

fig, axes = plt.subplots(3, 1, figsize=(8, 8))

axes[0].plot(sol.t, sol.y[0] * 180/np.pi, 'b-')
axes[0].set_ylabel('φ (graus)')
axes[0].set_title('Controle LQR — Pêndulo Invertido')
axes[0].axhline(0, color='k', lw=0.5)

axes[1].plot(sol.t, sol.y[1], 'g-')
axes[1].set_ylabel('φ̇ (rad/s)')
axes[1].axhline(0, color='k', lw=0.5)

u_history = np.array([-K @ sol.y[:, i] for i in range(sol.y.shape[1])])
axes[2].plot(sol.t, np.clip(u_history, -10, 10), 'r-')
axes[2].set_ylabel('u (N·m)')
axes[2].set_xlabel('t (s)')

for ax in axes:
    ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('lqr_pendulo.png', dpi=150)
print("\nFigura salva: lqr_pendulo.png")

# ── Cálculo do custo ótimo ─────────────────────────────────
# Custo infinito-horizonte: J* = x0^T P x0
J_otimo = np.array(x0) @ P @ np.array(x0)
print(f"\nCusto ótimo J* = x₀ᵀ P x₀ = {J_otimo:.4f}")

# ── Problema de tempo mínimo (duplo integrador) ────────────
print("\n── Duplo integrador — Controle Bang-Bang ──")
def duplo_integrador(t, x, u_sign):
    x1, x2 = x
    u = u_sign * 1.0  # |u| ≤ 1
    return [x2, u]

# Trajetória: x(0) = [3, 0] → origem com u = -1 depois u = +1
# A comutação ocorre na curva de comutação: x2 = -sgn(x2)|x2|²/2 + x1 = 0
# Para x0 = (3, 0): primeiro u = -1 até curva, depois u = +1
t_switch = np.sqrt(3)  # tempo de comutação aproximado

sol1 = solve_ivp(lambda t, x: duplo_integrador(t, x, -1),
                 (0, t_switch), [3, 0],
                 t_eval=np.linspace(0, t_switch, 100))
x_switch = sol1.y[:, -1]
t_final = t_switch + np.abs(x_switch[1])

sol2 = solve_ivp(lambda t, x: duplo_integrador(t, x, +1),
                 (0, t_final), x_switch.tolist(),
                 t_eval=np.linspace(0, t_final, 100))

print(f"Comutação em t = {t_switch:.3f} s, estado = {x_switch}")
print(f"Estado final: {sol2.y[:, -1]}")
print(f"Tempo total (≈ mínimo): {t_switch + t_final:.3f} s")
```
