# Wavelets: O Microscópio Matemático

A Transformada de Fourier decompõe um sinal em frequências, mas perde a informação de *quando* cada frequência ocorre. A wavelet resolve isso: é um "pequeno onda" localizada tanto no tempo quanto na frequência, como um microscópio matemático que muda de escala para ver estruturas pequenas (alta frequência) ou grandes (baixa frequência) do sinal.

# Wavelets: Fourier com Localização Temporal

**Ideia:** ao contrário da Fourier (base de exponenciais infinitas), as wavelets são localizadas:

<EquacaoCanonica
  formula="\psi_{a,b}(x) = \frac{1}{\sqrt{|a|}}\psi\!\left(\frac{x-b}{a}\right), \quad a \neq 0, \; b \in \mathbb{R}"
  legenda="Família wavelet: ψ dilatada por a e transladada por b"
  audioTexto="Psi de a e b de x é 1 sobre raiz de a absoluto vezes psi de x menos b sobre a."
/>

**Transformada Wavelet Contínua (CWT):**

<Eq>{"(Wf)(a,b) = \\langle f, \\psi_{a,b}\\rangle = \\frac{1}{\\sqrt{|a|}}\\int f(x)\\overline{\\psi\\left(\\frac{x-b}{a}\\right)}\\,dx"}</Eq>

**Condição de admissibilidade:** <Eq>{"C_\\psi = \\int_0^\\infty \\frac{|\\hat{\\psi}(\\xi)|^2}{\\xi}\\,d\\xi < \\infty"}</Eq> (implica <Eq>{"\\hat{\\psi}(0) = 0"}</Eq>, ou seja, <Eq>{"\\int\\psi = 0"}</Eq>).

**Fórmula de reconstrução:** <Eq>{"f(x) = \\frac{1}{C_\\psi}\\int_0^\\infty\\int_{-\\infty}^\\infty (Wf)(a,b)\\psi_{a,b}(x)\\,\\frac{db\\,da}{a^2}"}</Eq>.

</Porta>

# Wavelet de Haar e Análise Multirresolução

## Wavelet de Haar

A mais simples de todas as wavelets:

<EquacaoCanonica
  formula="\psi^H(x) = \begin{cases} 1 & 0 \leq x < 1/2 \\ -1 & 1/2 \leq x < 1 \\ 0 & \text{caso contrário} \end{cases}"
  legenda="Wavelet de Haar — base ortonormal de L²(ℝ), mas não é contínua"
  audioTexto="Psi de Haar é 1 para x entre 0 e 1 meio, menos 1 para x entre 1 meio e 1, e zero fora."
/>

A família <Eq>{"\\{\\psi^H_{j,k}(x) = 2^{j/2}\\psi^H(2^j x - k)\\}_{j,k \\in \\mathbb{Z}}"}</Eq> é base ortonormal de <Eq>{"L^2(\\mathbb{R})"}</Eq>.

**Função escala (scaling function):** <Eq>{"\\phi^H = \\mathbf{1}_{[0,1)}"}</Eq>, satisfaz a equação de refinamento <Eq>{"\\phi(x) = \\phi(2x) + \\phi(2x-1)"}</Eq>.

## Análise Multirresolução (MRA)

**Definição (Mallat):** Uma MRA é uma sequência de subespaços fechados <Eq>{"\\{V_j\\}_{j \\in \\mathbb{Z}}"}</Eq> de <Eq>{"L^2(\\mathbb{R})"}</Eq> satisfazendo:

1. <Eq>{"\\cdots \\subset V_{-1} \\subset V_0 \\subset V_1 \\subset \\cdots"}</Eq>
2. <Eq>{"\\overline{\\bigcup_j V_j} = L^2(\\mathbb{R})"}</Eq> e <Eq>{"\\bigcap_j V_j = \\{0\\}"}</Eq>
3. <Eq>{"f \\in V_j \\Leftrightarrow f(2\\cdot) \\in V_{j+1}"}</Eq> (invariância por dilatação)
4. <Eq>{"f \\in V_0 \\Rightarrow f(\\cdot - k) \\in V_0"}</Eq> para todo <Eq>{"k \\in \\mathbb{Z}"}</Eq>
5. Existe <Eq>{"\\phi \\in V_0"}</Eq> tal que <Eq>{"\\{\\phi(\\cdot - k)\\}_{k \\in \\mathbb{Z}}"}</Eq> é base ortonormal de <Eq>{"V_0"}</Eq>

**Wavelet mãe:** define-se <Eq>{"W_j = V_{j+1} \\ominus V_j"}</Eq> (complemento ortogonal). Existe <Eq>{"\\psi \\in W_0"}</Eq> tal que <Eq>{"\\{\\psi_{j,k}\\}"}</Eq> é base ortonormal de <Eq>{"W_j"}</Eq>, e:

<EquacaoCanonica
  formula="L^2(\mathbb{R}) = \bigoplus_{j \in \mathbb{Z}} W_j = V_0 \oplus \bigoplus_{j \geq 0} W_j"
  legenda="Decomposição ortogonal de L² em subespaços de detalhes de diferentes escalas"
  audioTexto="L dois de R é a soma direta ortogonal de todos os W j, ou equivalentemente V zero mais a soma dos W j para j positivo."
/>

</Porta>

# Wavelets de Daubechies e Transformada Wavelet Discreta

## Construção de Daubechies

**Objetivo:** construir wavelet <Eq>{"\\psi_N"}</Eq> com <Eq>{"N"}</Eq> momentos nulos (<Eq>{"\\int x^k \\psi_N(x) dx = 0"}</Eq> para <Eq>{"k = 0,\\ldots,N-1"}</Eq>), suporte compacto e derivadas contínuas.

**Equação de refinamento:** <Eq>{"\\phi(x) = \\sqrt{2}\\sum_k h_k \\phi(2x-k)"}</Eq>.

Os **coeficientes de filtro** <Eq>{"h_k"}</Eq> são determinados por:
1. Condição de normalização: <Eq>{"\\sum_k h_k = \\sqrt{2}"}</Eq>
2. Ortogonalidade: <Eq>{"\\sum_k h_k h_{k-2l} = \\delta_{l,0}"}</Eq>
3. <Eq>{"N"}</Eq> momentos nulos: <Eq>{"\\sum_k (-1)^k k^m h_k = 0"}</Eq> para <Eq>{"m = 0,\\ldots,N-1"}</Eq>

**Db2 (=db1 = Haar):** <Eq>{"h_0 = h_1 = 1/\\sqrt{2}"}</Eq>.

**Db4:** coeficientes de comprimento 4 que dão 2 momentos nulos e wavelet contínua.

## Transformada Wavelet Discreta (DWT) via Banco de Filtros

A DWT implementa-se com banco de filtros em pirâmide:

<EquacaoCanonica
  formula="c^{j-1}[k] = \sum_n h[n-2k] c^j[n], \quad d^{j-1}[k] = \sum_n g[n-2k] c^j[n]"
  legenda="Filtro passa-baixas h → coeficientes de escala; passa-altas g → coeficientes wavelet"
  audioTexto="c j menos 1 de k é a convolução com h decimada por 2; d j menos 1 de k é a convolução com g decimada por 2."
/>

onde <Eq>{"g_k = (-1)^k h_{N-1-k}"}</Eq> (filtro de quadratura em espelho).

**Complexidade:** <Eq>{"O(N)"}</Eq> (linear!) ao contrário da FFT <Eq>{"O(N\\log N)"}</Eq>.

**Reconstrução (IDWT):**

<Eq>{"c^j[n] = \\sum_k h[n-2k]c^{j-1}[k] + \\sum_k g[n-2k]d^{j-1}[k]"}</Eq>

(upsampling + convolução).

# Teoria de Wavelets e Análise Funcional

## Frame de Wavelets e Reconstrução Estável

Um **frame** de wavelets é uma família <Eq>{"\\{\\psi_{j,k}\\}"}</Eq> (não necessariamente ortonormal) satisfazendo:

<EquacaoCanonica
  formula="A\|f\|^2 \leq \sum_{j,k} |\langle f, \psi_{j,k}\rangle|^2 \leq B\|f\|^2"
  legenda="Condição de frame — A,B > 0 garantem reconstrução estável"
  audioTexto="A vezes norma de f ao quadrado é menor ou igual à soma dos quadrados dos produtos internos com psi j k, que é menor ou igual a B vezes norma de f ao quadrado."
/>

Para frame tight (<Eq>{"A = B"}</Eq>): <Eq>{"f = \\frac{1}{A}\\sum_{j,k}\\langle f, \\psi_{j,k}\\rangle \\psi_{j,k}"}</Eq> (inversão simples).

## Caracterização via Transformada de Fourier

Uma função <Eq>{"\\phi"}</Eq> gera MRA se e somente se:
- <Eq>{"\\sum_k |\\hat{\\phi}(\\xi + k)|^2 = 1"}</Eq> para q.t.p. <Eq>{"\\xi"}</Eq>
- <Eq>{"\\hat{\\phi}(\\xi) = m_0(\\xi/2)\\hat{\\phi}(\\xi/2)"}</Eq> com <Eq>{"m_0"}</Eq> <Eq>{"2\\pi"}</Eq>-periódica

onde <Eq>{"m_0(\\xi) = \\frac{1}{\\sqrt{2}}\\sum_k h_k e^{-ik\\xi}"}</Eq> é o **filtro em escala** (<Eq>{"\\text{CQF}"}</Eq>).

**Regularidade de Sobolev:** a wavelet <Eq>{"\\psi_N"}</Eq> de Daubechies pertence a <Eq>{"H^s(\\mathbb{R})"}</Eq> com <Eq>{"s \\approx 0{,}2075 N"}</Eq> (regularidade cresce com o número de momentos nulos).

## Ondas de Velocidade e Curvelets

Wavelets clássicas (1D, isotrópicas) são limitadas para capturar contornos e bordas em 2D. Extensões:

- **Ridgelet:** <Eq>{"\\rho_{a,b,\\theta}(x,y) = a^{-1/2}\\psi((x\\cos\\theta + y\\sin\\theta - b)/a)"}</Eq> — deteta linhas.
- **Curvelet:** capta bordas curvas com anisotropia dependente de escala (<Eq>{"\\text{largura} \\sim \\text{comprimento}^2"}</Eq>).

**Teorema (Candès-Donoho):** Curvelets representam funções com descontinuidades curvas em <Eq>{"n"}</Eq> termos com erro de melhor <Eq>{"n"}</Eq>-termo <Eq>{"O(n^{-2})"}</Eq>, enquanto wavelets dão apenas <Eq>{"O(n^{-1})"}</Eq>.

# Wavelets em Compressão e Denoising

## Compressão de Imagem (JPEG 2000)

JPEG 2000 usa a wavelet biortogonal CDF 9/7 (Cohen-Daubechies-Feauveau) para compressão com e sem perda. Vantagens sobre JPEG:

- Sem artefatos de bloco em taxas baixas
- Escalabilidade: resolução progressiva
- Melhor qualidade visual para mesma taxa de compressão

## Denoising por Limiarização de Coeficientes

O **denoising wavelet** de Donoho-Johnstone:
1. Calcular DWT de <Eq>{"y = f + \\sigma\\varepsilon"}</Eq>
2. Limiarizar: <Eq>{"\\tilde{d}_{j,k} = S_\\lambda(d_{j,k})"}</Eq>
3. Reconstruir via IDWT

onde <Eq>{"S_\\lambda"}</Eq> é soft-thresholding e o **limiar universal** é <Eq>{"\\lambda = \\sigma\\sqrt{2\\ln N}"}</Eq>.

**Optimalidade:** O estimador é ótimo (minimax) sobre classes de funções Lipschitz e Sobolev.

## Código Python — DWT com PyWavelets

```python
import numpy as np
import pywt  # pip install PyWavelets

# Sinal de teste: seno + ruído
np.random.seed(42)
N = 1024
t = np.linspace(0, 1, N)
sigma = 0.3
f_true = np.sin(2*np.pi*5*t) + 0.5*np.sin(2*np.pi*20*t)
y = f_true + sigma * np.random.randn(N)

# DWT multinível (Daubechies 4)
wavelet = pywt.Wavelet('db4')
coeffs = pywt.wavedec(y, wavelet, level=6)

# Denoising: limiar universal
threshold = sigma * np.sqrt(2 * np.log(N))
denoised_coeffs = [coeffs[0]] + [
    pywt.threshold(c, threshold, mode='soft') for c in coeffs[1:]
]

# Reconstrução
f_est = pywt.waverec(denoised_coeffs, wavelet)[:N]

snr_before = 10*np.log10(np.var(f_true)/np.var(y - f_true))
snr_after  = 10*np.log10(np.var(f_true)/np.var(f_est - f_true))
print(f"SNR antes:  {snr_before:.1f} dB")
print(f"SNR depois: {snr_after:.1f} dB")

# Comparar energia dos coeficientes (compressão)
d_all = np.concatenate([c.ravel() for c in coeffs[1:]])
idx_sorted = np.argsort(np.abs(d_all))[::-1]
for pct in [10, 5, 1]:
    k = int(pct/100 * len(d_all))
    energy_kept = np.sum(d_all[idx_sorted[:k]]**2) / np.sum(d_all**2) * 100
    print(f"Top {pct}% coef. → {energy_kept:.1f}% da energia de detalhe")
```

**Referência:** Daubechies, *Ten Lectures on Wavelets* (1992), Cap. 1–5; Mallat, *A Wavelet Tour of Signal Processing*, Cap. 6–7.

## Exemplo 1 — DWT de Haar para N=4

**Sinal:** <Eq>{"f = [4, 6, 2, 8]"}</Eq>.

**Nível 1** (filtros <Eq>{"h = [1/\\sqrt{2}, 1/\\sqrt{2}]"}</Eq> e <Eq>{"g = [1/\\sqrt{2}, -1/\\sqrt{2}]"}</Eq>):

- Coeficientes de aproximação: <Eq>{"a_1 = [(4+6)/\\sqrt{2}, (2+8)/\\sqrt{2}] = [5\\sqrt{2}, 5\\sqrt{2}]"}</Eq>
- Coeficientes de detalhe: <Eq>{"d_1 = [(4-6)/\\sqrt{2}, (2-8)/\\sqrt{2}] = [-\\sqrt{2}, -3\\sqrt{2}]"}</Eq>

**Nível 2:**

- <Eq>{"a_2 = [(5\\sqrt{2}+5\\sqrt{2})/\\sqrt{2}] = [10]"}</Eq>
- <Eq>{"d_2 = [(5\\sqrt{2}-5\\sqrt{2})/\\sqrt{2}] = [0]"}</Eq>

**Coeficientes:** <Eq>{"[a_2; d_2; d_1] = [10, 0, -\\sqrt{2}, -3\\sqrt{2}]"}</Eq>.

**Energia:** <Eq>{"4^2+6^2+2^2+8^2 = 120 = 10^2+0^2+(\\sqrt{2})^2+(3\\sqrt{2})^2 = 100+0+2+18 = 120 \\checkmark"}</Eq>.

**Referência:** Mallat, *A Wavelet Tour of Signal Processing*, §7.3; Daubechies, *Ten Lectures on Wavelets*, Cap. 1.

## Exemplo 2 — Coeficientes de Daubechies Db4

**Objetivo:** coeficientes de filtro de Daubechies de comprimento 4 (<Eq>{"N=2"}</Eq> momentos nulos).

As condições são: <Eq>{"h_0+h_1+h_2+h_3 = \\sqrt{2}"}</Eq>, <Eq>{"h_0^2+h_1^2+h_2^2+h_3^2 = 1"}</Eq>, <Eq>{"h_0h_2+h_1h_3 = 0"}</Eq>, e momento nulo: <Eq>{"h_0-h_1+h_2-h_3 = 0"}</Eq>.

**Solução:**

<Eq>{"h_0 = \\frac{1+\\sqrt{3}}{4\\sqrt{2}}, \\quad h_1 = \\frac{3+\\sqrt{3}}{4\\sqrt{2}}, \\quad h_2 = \\frac{3-\\sqrt{3}}{4\\sqrt{2}}, \\quad h_3 = \\frac{1-\\sqrt{3}}{4\\sqrt{2}}"}</Eq>

Numericamente: <Eq>{"h \\approx [0{,}4830, 0{,}8365, 0{,}2241, -0{,}1294]"}</Eq>.

**Referência:** Daubechies, *Ten Lectures on Wavelets*, Cap. 6.
