# Expandir a Solução em Modos Naturais do Sistema

Todo sistema físico (uma corda, uma membrana, um fio condutor de calor) tem "modos naturais" de vibração ou difusão — suas autofunções. A solução de qualquer problema com esse sistema é uma combinação linear (infinita) desses modos. Basta calcular os coeficientes de cada modo, e a física resolve todo o resto.

# Expansão Espectral para EDPs

**Estratégia:** Para <Eq>{"Lu = f"}</Eq> com <Eq>{"L"}</Eq> operador diferencial e condições de contorno:

1. Resolver o problema de Sturm-Liouville: <Eq>{"L\\phi_n = \\lambda_n w\\phi_n"}</Eq>
2. Expandir <Eq>{"u = \\sum_n c_n(t)\\phi_n(x)"}</Eq> e <Eq>{"f = \\sum_n f_n\\phi_n"}</Eq>
3. Substituir na EDP: cada <Eq>{"c_n(t)"}</Eq> satisfaz uma EDO simples
4. Resolver as EDOs e reconstruir <Eq>{"u"}</Eq>

**Equação do calor** <Eq>{"u_t = Lu"}</Eq>: <Eq>{"c_n'(t) = -\\lambda_n c_n(t) \\Rightarrow c_n(t) = c_n(0)e^{-\\lambda_n t}"}</Eq>

**Equação da onda** <Eq>{"u_{tt} = -Lu"}</Eq>: <Eq>{"c_n''(t) = -\\lambda_n c_n(t) \\Rightarrow c_n(t) = A_n\\cos(\\sqrt{\\lambda_n}t) + B_n\\sin(\\sqrt{\\lambda_n}t)"}</Eq>

# Separação de Variáveis em Coordenadas Gerais

## Equação do Calor com Condutividade Variável

Problema: <Eq>{"\\rho c u_t = (ku_x)_x"}</Eq>, <Eq>{"x \\in (a,b)"}</Eq>, Dirichlet, <Eq>{"u(x,0) = f(x)"}</Eq>.

**Passo 1 — SL:** O operador espacial é <Eq>{"L = -(k\\phi')'/\\rho c"}</Eq>, com autofunções <Eq>{"\\{\\phi_n\\}"}</Eq> ortogonais com peso <Eq>{"w = \\rho c"}</Eq>.

**Passo 2 — Expansão:** <Eq>{"u(x,t) = \\sum_n T_n(t)\\phi_n(x)"}</Eq>.

**Passo 3 — EDOs:** <Eq>{"T_n' + \\lambda_n T_n = 0 \\Rightarrow T_n(t) = e^{-\\lambda_n t}"}</Eq>.

**Passo 4 — Coeficientes iniciais:**

<EquacaoCanonica
  formula="c_n = \langle f, \phi_n\rangle_w = \int_a^b f(x)\phi_n(x)\rho c\,dx / \|\phi_n\|_w^2"
  legenda="Coeficiente de Fourier-SL da condição inicial"
  audioTexto="c n é o produto interno de f com phi n com peso rho c, dividido pela norma ao quadrado de phi n."
/>

**Solução:**

<EquacaoCanonica
  formula="u(x,t) = \sum_{n=1}^\infty c_n e^{-\lambda_n t}\phi_n(x)"
  legenda="Série espectral — cada modo decai exponencialmente com taxa λₙ"
  audioTexto="u de x t é a soma de c n vezes e elevado a menos lambda n t vezes phi n de x."
/>

## Equação da Onda em Domínio Arbitrário

Para <Eq>{"u_{tt} + Lu = 0"}</Eq> (vibração livre), <Eq>{"u(x,0) = f"}</Eq>, <Eq>{"u_t(x,0) = g"}</Eq>:

<Eq>{"u(x,t) = \\sum_n \\left[A_n\\cos(\\omega_n t) + B_n\\sin(\\omega_n t)\\right]\\phi_n(x)"}</Eq>

onde <Eq>{"\\omega_n = \\sqrt{\\lambda_n}"}</Eq> são as **frequências naturais** e:

<Eq>{"A_n = \\langle f, \\phi_n\\rangle_w/\\|\\phi_n\\|_w^2, \\quad B_n = \\langle g, \\phi_n\\rangle_w/(\\omega_n\\|\\phi_n\\|_w^2)"}</Eq>

# Expansão em Múltiplas Dimensões

## Problema em Retângulo

Para <Eq>{"u_t = \\Delta u"}</Eq> em <Eq>{"(0,L_x)\\times(0,L_y)"}</Eq> com Dirichlet, as autofunções do Laplaciano são produtos tensoriais:

<EquacaoCanonica
  formula="\phi_{mn}(x,y) = \sin\!\left(\frac{m\pi x}{L_x}\right)\sin\!\left(\frac{n\pi y}{L_y}\right), \quad \lambda_{mn} = \left(\frac{m\pi}{L_x}\right)^2 + \left(\frac{n\pi}{L_y}\right)^2"
  legenda="Autofunções bidimensionais do Laplaciano-Dirichlet no retângulo"
  audioTexto="phi m n de x y é o produto dos senos nas duas direções; lambda m n é a soma dos quadrados dos números de onda."
/>

**Solução:**

<Eq>{"u(x,y,t) = \\sum_{m=1}^\\infty\\sum_{n=1}^\\infty c_{mn}e^{-\\lambda_{mn}t}\\phi_{mn}(x,y)"}</Eq>

com <Eq>{"c_{mn} = \\frac{4}{L_x L_y}\\int_0^{L_x}\\int_0^{L_y}f(x,y)\\phi_{mn}(x,y)\\,dx\\,dy"}</Eq>.

## Problema em Disco (Coordenadas Polares)

Para <Eq>{"u_t = \\Delta u"}</Eq> em <Eq>{"B(0,R)"}</Eq> com Dirichlet, a separação <Eq>{"u = R(r)\\Theta(\\theta)T(t)"}</Eq> leva a:

- **Angular:** <Eq>{"\\Theta'' + m^2\\Theta = 0"}</Eq> → <Eq>{"\\cos(m\\theta)"}</Eq>, <Eq>{"\\sin(m\\theta)"}</Eq>
- **Radial (Bessel):** <Eq>{"r^2R'' + rR' + (\\lambda r^2 - m^2)R = 0"}</Eq> → <Eq>{"R(r) = J_m(\\sqrt{\\lambda}r)"}</Eq>
- **Condição:** <Eq>{"J_m(\\sqrt{\\lambda}R) = 0"}</Eq> → <Eq>{"\\sqrt{\\lambda} = j_{m,k}/R"}</Eq>

**Solução:**

<Eq>{"u(r,\\theta,t) = \\sum_{m=0}^\\infty\\sum_{k=1}^\\infty e^{-\\lambda_{mk}t}J_m(j_{mk}r/R)[A_{mk}\\cos(m\\theta) + B_{mk}\\sin(m\\theta)]"}</Eq>

## Convergência das Séries Espectrais

**Teorema:** Para <Eq>{"f \\in L^2_w(\\Omega)"}</Eq>, a série converge em norma <Eq>{"L^2_w"}</Eq>. Para <Eq>{"t > 0"}</Eq>, <Eq>{"u(\\cdot,t)"}</Eq> é analítica em <Eq>{"x"}</Eq> (os termos da série decaem super-exponencialmente).

**Regularidade para <Eq>{"t > 0"}</Eq>:** se <Eq>{"f \\in L^2"}</Eq> e <Eq>{"\\lambda_n \\sim n^{2/d}"}</Eq> (Weyl), então:

<Eq>{"\\|u(\\cdot,t)\\|_{H^k}^2 = \\sum_n \\lambda_n^k |c_n|^2 e^{-2\\lambda_n t} < \\infty"}</Eq>

(a gaussiana <Eq>{"e^{-\\lambda_n t}"}</Eq> vence qualquer potência de <Eq>{"\\lambda_n"}</Eq> — **regularização instantânea**).

# Teoria Espectral Abstrata e Fórmula de Trace

## Espectro do Laplaciano e Lei de Weyl

Para <Eq>{"\\Omega \\subset \\mathbb{R}^d"}</Eq> limitado (com fronteira suave), os autovalores de <Eq>{"-\\Delta"}</Eq> com Dirichlet satisfazem:

<EquacaoCanonica
  formula="N(\lambda) = \#\{n : \lambda_n \leq \lambda\} \sim \frac{\omega_d}{(2\pi)^d}|\Omega|\lambda^{d/2} \quad (\lambda \to \infty)"
  legenda="Lei de Weyl — contagem assintótica de autovalores"
  audioTexto="N de lambda é o número de autovalores menores que lambda, assintótico a uma constante vezes o volume de Omega vezes lambda elevado a d sobre 2."
/>

Em particular, <Eq>{"\\lambda_n \\sim C(d,\\Omega) n^{2/d}"}</Eq> (os autovalores crescem polinomialmente).

## Fórmula do Traço do Calor

O traço do semigrupo do calor <Eq>{"Z(t) = \\text{tr}(e^{t\\Delta}) = \\sum_n e^{-\\lambda_n t}"}</Eq> tem a expansão assintótica:

<Eq>{"Z(t) \\sim (4\\pi t)^{-d/2}\\left[|\\Omega| - \\frac{\\sqrt{\\pi t}}{2}|\\partial\\Omega| + c_2 t + \\cdots\\right] \\quad (t \\to 0^+)"}</Eq>

**Teorema de Kac (1966):** "Can one hear the shape of a drum?" — os autovalores de <Eq>{"-\\Delta"}</Eq> determinam <Eq>{"|\\Omega|"}</Eq> e <Eq>{"|\\partial\\Omega|"}</Eq> (e a característica de Euler se <Eq>{"d = 2"}</Eq>), mas não necessariamente a forma de <Eq>{"\\Omega"}</Eq> (contraexemplo: Gordon-Webb-Wolpert, 1992).

## Função Zeta Espectral

A **função zeta espectral** <Eq>{"\\zeta_L(s) = \\sum_n \\lambda_n^{-s}"}</Eq> (análogo da função zeta de Riemann) converge para <Eq>{"\\text{Re}(s) > d/2"}</Eq> e se estende meromorficamente a <Eq>{"\\mathbb{C}"}</Eq>.

Os **resíduos** de <Eq>{"\\zeta_L"}</Eq> fornecem invariantes geométricos de <Eq>{"\\Omega"}</Eq> (volume, área da fronteira, curvatura). Base do **determinante espectral** <Eq>{"\\det(L) = e^{-\\zeta_L'(0)}"}</Eq> em teoria quântica de campos.

# Expansão Espectral em Engenharia

## Análise Modal de Estruturas

A equação de vibração de uma membrana <Eq>{"u_{tt} = c^2\\Delta u"}</Eq> tem modos normais <Eq>{"\\{\\phi_{mn}, \\omega_{mn}\\}"}</Eq>. A resposta a excitação periódica <Eq>{"f(x,y,t) = F(x,y)\\cos(\\Omega t)"}</Eq> é:

<Eq>{"u = \\sum_{mn} \\frac{F_{mn}}{\\omega_{mn}^2 - \\Omega^2}\\phi_{mn}(x,y)\\cos(\\Omega t)"}</Eq>

**Ressonância:** quando <Eq>{"\\Omega \\approx \\omega_{mn}"}</Eq>, a resposta explode → projeto deve evitar que a frequência de excitação coincida com frequência natural.

## Simulação Numérica por Expansão Modal

```python
import numpy as np
from scipy.linalg import eigh

def laplacian_2d_fd(Nx, Ny):
    """Laplaciano discreto 2D (Dirichlet) por diferenças finitas."""
    N = Nx * Ny
    hx, hy = 1.0/(Nx+1), 1.0/(Ny+1)
    
    # Laplaciano 1D em cada direção
    Lx = (np.diag(2*np.ones(Nx)) - np.diag(np.ones(Nx-1),1) - np.diag(np.ones(Nx-1),-1)) / hx**2
    Ly = (np.diag(2*np.ones(Ny)) - np.diag(np.ones(Ny-1),1) - np.diag(np.ones(Ny-1),-1)) / hy**2
    
    # Produto de Kronecker: L2D = Lx⊗Iy + Ix⊗Ly
    Ix = np.eye(Nx)
    Iy = np.eye(Ny)
    return np.kron(Lx, Iy) + np.kron(Ix, Ly)

# Resolver problema de autovalores em (0,1)×(0,1)
Nx, Ny = 20, 20
L = laplacian_2d_fd(Nx, Ny)
eigvals, eigvecs = eigh(L, subset_by_index=range(min(10, Nx*Ny)))

print("10 menores autovalores (numérico vs. exato (m²+n²)π²):")
exact = sorted([(m**2 + n**2)*np.pi**2 for m in range(1,6) for n in range(1,6)])[:10]
for i, (num, ex) in enumerate(zip(eigvals[:10], exact)):
    print(f"  λ_{i+1}: {num:.4f} vs {ex:.4f} (erro {abs(num-ex)/ex*100:.2f}%)")

# Resolver equação do calor u_t = Δu, u(x,y,0) = sin(πx)sin(πy)
hx = 1.0/(Nx+1)
x = np.linspace(hx, 1-hx, Nx)
y = np.linspace(1/(Ny+1), 1-1/(Ny+1), Ny)
X, Y = np.meshgrid(x, y)
f0 = np.sin(np.pi*X)*np.sin(np.pi*Y)  # CI

# Coeficientes: c_n = <f, φ_n>
cn = eigvecs.T @ f0.ravel()

# Solução em t=0.1
t = 0.1
u = (eigvecs * np.exp(-eigvals * t)[np.newaxis, :]) @ cn

# Comparar com solução exata: e^{-2π²t}sin(πx)sin(πy)
u_exact = np.exp(-2*np.pi**2*t)*np.sin(np.pi*X)*np.sin(np.pi*Y)
err = np.max(np.abs(u.reshape(Ny, Nx) - u_exact))
print(f"\nErro máximo em t={t}: {err:.4e}")
```

**Referência:** Haberman, *Applied PDE*, §5.7–5.9; Strauss, *PDE*, §10.3.

## Exemplo 1 — Calor em Barra com Condutividade Variável

**Problema:** <Eq>{"u_t = (xu_x)_x"}</Eq>, <Eq>{"x \\in (1,e)"}</Eq>, <Eq>{"u(1,t)=u(e,t)=0"}</Eq>, <Eq>{"u(x,0)=\\ln x"}</Eq>.

**Mudança de variável:** <Eq>{"y = \\ln x \\in (0,1)"}</Eq>, <Eq>{"v(y,t) = u(e^y,t)"}</Eq>.

**Transformação:** <Eq>{"v_t = v_{yy}"}</Eq>, <Eq>{"v(0,t)=v(1,t)=0"}</Eq>, <Eq>{"v(y,0)=y"}</Eq>.

**Autofunções:** <Eq>{"\\phi_n(y) = \\sin(n\\pi y)"}</Eq>, <Eq>{"\\lambda_n = n^2\\pi^2"}</Eq>.

**Coeficientes:** <Eq>{"c_n = 2\\int_0^1 y\\sin(n\\pi y)\\,dy = \\frac{2(-1)^{n+1}}{n\\pi}"}</Eq>.

**Solução:**

<Eq>{"v(y,t) = \\frac{2}{\\pi}\\sum_{n=1}^\\infty \\frac{(-1)^{n+1}}{n}e^{-n^2\\pi^2 t}\\sin(n\\pi y)"}</Eq>

**Em variáveis originais:** <Eq>{"u(x,t) = \\frac{2}{\\pi}\\sum_{n=1}^\\infty \\frac{(-1)^{n+1}}{n}e^{-n^2\\pi^2 t}\\sin(n\\pi\\ln x)"}</Eq>.

**Referência:** Haberman, *Applied PDE*, §5.3; Strauss, §5.4.

</Exemplo>

## Exemplo 2 — Onda em Membrana Circular

**Problema:** <Eq>{"u_{tt} = c^2\\Delta u"}</Eq> em <Eq>{"B(0,1)"}</Eq>, <Eq>{"u|_{r=1}=0"}</Eq>, <Eq>{"u(r,0)=f(r)"}</Eq>, <Eq>{"u_t(r,0)=0"}</Eq> (caso radialmente simétrico: <Eq>{"m=0"}</Eq>).

**Autofunções radiais:** <Eq>{"\\phi_k(r) = J_0(j_{0,k}r)"}</Eq>, onde <Eq>{"j_{0,k}"}</Eq> é o <Eq>{"k"}</Eq>-ésimo zero positivo de <Eq>{"J_0"}</Eq>. Frequências: <Eq>{"\\omega_k = cj_{0,k}"}</Eq>.

**Coeficientes:**

<Eq>{"A_k = \\frac{\\int_0^1 f(r)J_0(j_{0,k}r)r\\,dr}{\\|J_0(j_{0,k}\\cdot)\\|^2_w} = \\frac{2\\int_0^1 f(r)J_0(j_{0,k}r)r\\,dr}{J_1(j_{0,k})^2}"}</Eq>

(usando <Eq>{"\\|J_0(j_{0,k}\\cdot)\\|_w^2 = J_1(j_{0,k})^2/2"}</Eq>).

**Solução:**

<Eq>{"u(r,t) = \\sum_{k=1}^\\infty A_k\\cos(cj_{0,k}t)J_0(j_{0,k}r)"}</Eq>

Zeros relevantes: <Eq>{"j_{0,1} \\approx 2{,}405"}</Eq>, <Eq>{"j_{0,2} \\approx 5{,}520"}</Eq>, <Eq>{"j_{0,3} \\approx 8{,}654"}</Eq>.

**Referência:** Haberman, *Applied PDE*, §7.7; Strauss, §10.4.

</Exemplo>
