# Fibrados: Espaços que "Pendem" Sobre Outros

Um **fibrado** é um espaço que, localmente, parece o produto de dois espaços — mas pode ser globalmente "torcido". O exemplo mais simples: um cilindro (S¹ × ℝ) é trivial, mas a **faixa de Möbius** (S¹ com ℝ torcido) é não-trivial.

Os **fibrados vetoriais** generalizam o fibrado tangente TM: em cada ponto da variedade M, há um espaço vetorial. A estrutura global pode ser torcida de maneiras que capturam informações topológicas profundas.

Em física, os **fibrados de gauge** (Yang-Mills) descrevem as interações fundamentais: o eletromagnetismo é um fibrado U(1), a força fraca é SU(2), a forte é SU(3).

# Fibrados Vetoriais

## Definição

Um **fibrado vetorial** de rank r sobre M é um espaço total E com projeção <Eq>{"\\pi: E \\to M"}</Eq> tal que:

- Cada fibra <Eq>{"E_p = \\pi^{-1}(p)"}</Eq> é um espaço vetorial de dimensão r.
- Localmente trivial: sobre cada aberto <Eq>{"U \\subset M"}</Eq> existe um **trivialização** <Eq>{"\\phi: \\pi^{-1}(U) \\to U \\times \\mathbb{R}^r"}</Eq> (homeomorfismo compatível).
- As **funções de transição** <Eq>{"g_{\\alpha\\beta}: U_\\alpha \\cap U_\\beta \\to GL(r, \\mathbb{R})"}</Eq> são suaves.

*(Fonte: Lee, Introduction to Smooth Manifolds, §10; Milnor & Stasheff, Characteristic Classes, §2)*

## Exemplos Fundamentais

**Fibrado tangente TM:** Fibra = T_pM, rank = dim M.

**Fibrado cotangente T*M:** Dual de TM; seções = 1-formas diferenciais.

**Fibrado normal:** Para M ⊂ N, fibra = espaço normal T_pM^⊥.

**Fibrado trivial:** E = M × ℝ^r (produto direto).

**Pull-back:** Para f: N → M e E → M, o fibrado pull-back <Eq>{"f^*E"}</Eq> tem fibra <Eq>{"(f^*E)_q = E_{f(q)}"}</Eq>.

*(Fonte: Lee §10; Hatcher, Vector Bundles and K-Theory)*

## Seções

Uma **seção** de E → M é um mapa suave <Eq>{"s: M \\to E"}</Eq> com <Eq>{"\\pi\\circ s = \\text{id}_M"}</Eq>.

**Espaço de seções:** <Eq>{"\\Gamma(E)"}</Eq> é um <Eq>{"C^\\infty(M)"}</Eq>-módulo.

- Seções de TM = campos vetoriais
- Seções de T*M = 1-formas diferenciais
- Seções de <Eq>{"\\bigwedge^k T^*M"}</Eq> = k-formas

*(Fonte: Lee §10)*

# Conexões em Fibrados Vetoriais

## Conexão (Derivada Covariante)

Uma **conexão** em E → M é um operador <Eq>{"\\nabla: \\Gamma(TM) \\times \\Gamma(E) \\to \\Gamma(E)"}</Eq>:

<Eq>{"(X, s) \\mapsto \\nabla_X s"}</Eq>

satisfazendo:
- <Eq>{"\\nabla_X(s+t) = \\nabla_X s + \\nabla_X t"}</Eq>
- <Eq>{"\\nabla_{fX}s = f\\nabla_X s"}</Eq>
- <Eq>{"\\nabla_X(fs) = (Xf)s + f\\nabla_X s"}</Eq> (Leibniz)

*(Fonte: Lee §12; Bott & Tu §6)*

## Curvatura de uma Conexão

A **curvatura** mede a não-comutatividade de ∇:

<Eq>{"F_\\nabla(X,Y)s = \\nabla_X\\nabla_Y s - \\nabla_Y\\nabla_X s - \\nabla_{[X,Y]}s"}</Eq>

F_∇ é uma 2-forma com valores em End(E): <Eq>{"F_\\nabla \\in \\Omega^2(M; \\text{End}(E))"}</Eq>.

**Em coordenadas locais** (base de seções <Eq>{"\\{e_1,\\ldots,e_r\\}"}</Eq>):

<Eq>{"\\nabla_X e_j = A^i_{\\;j}(X) e_i \\quad (\\text{forma de conexão})"}</Eq>

<Eq>{"F = dA + A \\wedge A \\quad (\\text{curvatura em forma matricial})"}</Eq>

*(Fonte: Bott & Tu §7; Milnor & Stasheff §1)*

## Transporte Paralelo e Holonomia

Para uma curva <Eq>{"\\gamma: [a,b] \\to M"}</Eq>, o **transporte paralelo** de s₀ ∈ <Eq>{"E_{\\gamma(a)}"}</Eq> é a solução de:

<Eq>{"\\nabla_{\\dot\\gamma} s = 0, \\quad s(a) = s_0"}</Eq>

O **grupo de holonomia** em p ∈ M:

<Eq>{"\\text{Hol}_p(\\nabla) = \\{P_\\gamma : E_p \\to E_p \\mid \\gamma \\text{ loop em } p\\} \\subset GL(E_p)"}</Eq>

*(Fonte: Lee §12; Kobayashi & Nomizu, Foundations of Differential Geometry)*

# Classes Características e Teoria de Gauge

## Construção de Chern-Weil

Dado um polinômio invariante P em GL(r), define-se a **classe característica**:

<Eq>{"P(F_\\nabla) \\in \\Omega^{2k}(M)"}</Eq>

É fechada e a classe de cohomologia é independente da conexão escolhida.

**Exemplos:**

- **1ª classe de Chern:** <Eq>{"c_1(E) = \\left[\\frac{i}{2\\pi}\\text{tr}(F)\\right] \\in H^2(M; \\mathbb{Z})"}</Eq>

- **Classe de Pontryagin:** <Eq>{"p_k(E) = \\left[\\frac{-1}{(2\\pi)^{2k}(2k)!}\\text{tr}(F^{2k})\\right]"}</Eq>

- **Caráter de Chern:** <Eq>{"\\text{ch}(E) = \\text{tr}(e^{F/2\\pi i})"}</Eq>

*(Fonte: Bott & Tu §§16–17; Chern, Complex Manifolds)*

## Fibrados de Gauge em Física

A física fundamental usa **fibrados principais** G → P → M onde G é o grupo de gauge:

| Interação | Grupo | Representação |
|---|---|---|
| Eletromagnetismo | U(1) | Fibrado de linha complexo |
| Força fraca | SU(2) | Fibrado rank 2 |
| Força forte (QCD) | SU(3) | Fibrado rank 3 |
| Gravitação | SO(3,1) | Fibrado de frames |

A **ação de Yang-Mills**:

<Eq>{"S_{YM} = \\frac{1}{2g^2}\\int_M \\text{tr}(F \\wedge \\star F)"}</Eq>

As equações de Euler-Lagrange são as **equações de Yang-Mills**:

<Eq>{"D_\\nabla \\star F = J \\quad (\\text{análogo de Maxwell})"}</Eq>

*(Fonte: Bleecker, Gauge Theory and Variational Principles; Nash & Sen, Topology and Geometry for Physicists)*

## K-Teoria

A **K-teoria** <Eq>{"K(M)"}</Eq> é o grupo de Grothendieck de fibrados vetoriais sobre M:

<Eq>{"K(M) = \\text{Vect}(M)^+ \\quad (\\text{completamento de Grothendieck de fibrados sob}\\oplus)"}</Eq>

**Teorema de Atiyah-Hirzebruch:** <Eq>{"K(M) \\otimes \\mathbb{Q} \\cong H^{\\text{par}}(M; \\mathbb{Q})"}</Eq>.

*(Fonte: Atiyah, K-Theory; Hatcher, Vector Bundles and K-Theory)*

## Fibrado de Hopf: S³ → S² com Fibra S¹

O **fibrado de Hopf** é o fibrado principal mais famoso:

<Eq>{"S^1 \\hookrightarrow S^3 \\xrightarrow{\\pi} S^2"}</Eq>

**Construção:** Identifique <Eq>{"S^3 \\subset \\mathbb{C}^2"}</Eq> com pares <Eq>{"(z_1, z_2)"}</Eq>, <Eq>{"|z_1|^2 + |z_2|^2 = 1"}</Eq>.

A projeção <Eq>{"\\pi: S^3 \\to \\mathbb{CP}^1 \\cong S^2"}</Eq>:

<Eq>{"\\pi(z_1, z_2) = [z_1 : z_2] \\in \\mathbb{CP}^1"}</Eq>

**Propriedades:**
- É um fibrado U(1) com 1ª classe de Chern c₁ = 1 (não-trivial).
- É topologicamente não-trivializável.
- Em física: descreve o monopolo magnético de Dirac.

**Número de Hopf:** <Eq>{"\\pi_3(S^2) \\ni [\\pi] = 1"}</Eq> — o fibrado de Hopf gera o 3º grupo de homotopia de S².

*(Fonte: Nakahara §9.3; Nash & Sen §5; Milnor & Stasheff §3)*

</Exemplo>

## Implementação: Curvatura de Conexão e Holonomia

```python
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

# ── Conexão de Levi-Civita em S² e holonomia ──────────────
# Transporte paralelo em S² ao longo de um triângulo geodésico

def christoffel_S2(theta, phi):
    """Symbols for S² with metric ds² = dθ² + sin²θ dφ²"""
    Gamma = np.zeros((2, 2, 2))
    # Γ^θ_φφ = -sin(θ)cos(θ)
    Gamma[0, 1, 1] = -np.sin(theta) * np.cos(theta)
    # Γ^φ_θφ = Γ^φ_φθ = cot(θ)
    if abs(np.sin(theta)) > 1e-12:
        cot_t = np.cos(theta) / np.sin(theta)
        Gamma[1, 0, 1] = cot_t
        Gamma[1, 1, 0] = cot_t
    return Gamma

def transporte_paralelo_S2(gamma_func, gamma_dot_func, V0, t_span, N=1000):
    """
    Transporta vetor V0 ao longo de gamma.
    Equação: dV^k/dt + Γ^k_ij γ̇^i V^j = 0
    """
    def eq_transporte(t, V):
        theta, phi = gamma_func(t)
        dtheta, dphi = gamma_dot_func(t)
        Gamma = christoffel_S2(theta, phi)
        dV = np.zeros(2)
        for k in range(2):
            for i in range(2):
                for j in range(2):
                    gdot = [dtheta, dphi][i]
                    dV[k] -= Gamma[k, i, j] * gdot * V[j]
        return dV
    
    t_eval = np.linspace(*t_span, N)
    sol = solve_ivp(eq_transporte, t_span, V0,
                    t_eval=t_eval, rtol=1e-10, atol=1e-12)
    return sol.t, sol.y.T

# ── Triângulo geodésico no equador e meridionais ──────────
# Percurso: Equador de φ=0 a φ=π/2, depois meridiano de θ=π/2 a θ=π/4,
# depois volta ao ponto inicial

# Segmento 1: Equador θ=π/2, φ: 0→π/2
alpha = np.pi / 2  # ângulo no equador

def gamma1(t):  # t ∈ [0, alpha]
    return np.array([np.pi/2, t])

def gamma1_dot(t):
    return np.array([0.0, 1.0])

t1, V1_traj = transporte_paralelo_S2(gamma1, gamma1_dot, [0.0, 1.0], (0, alpha))
V_apos_seg1 = V1_traj[-1]

# Após o transporte ao longo do equador, qual a rotação do vetor?
angle_rotacao = alpha * np.sin(np.pi/2)  # = alpha (ângulo sólido)
V_inicial = np.array([0.0, 1.0])
V_esperado = np.array([-np.sin(angle_rotacao), np.cos(angle_rotacao)])

print("Transporte paralelo em S²:")
print(f"  Vetor inicial: {V_inicial}")
print(f"  Após transporte de α={np.degrees(alpha):.1f}° no equador:")
print(f"  Vetor numérico: ({V_apos_seg1[0]:.4f}, {V_apos_seg1[1]:.4f})")
print(f"  Vetor analítico (rotação de α sin θ₀ = α): ({V_esperado[0]:.4f}, {V_esperado[1]:.4f})")

# ── Holonomia = rotação total (excesso angular) ────────────
print("\n── Holonomia e Excesso Angular ──")
# Para triângulo geodésico com ângulos A, B, C em S²:
# Holonomia = A + B + C - π = área do triângulo (curvatura integrada)
A = np.pi/2; B = np.pi/2; C = np.pi/2  # triângulo com 3 ângulos retos
excesso_angular = A + B + C - np.pi
area_triangulo = excesso_angular  # = π/2 para S² unitária
print(f"Triângulo com ângulos (π/2, π/2, π/2):")
print(f"  Excesso angular = {excesso_angular:.4f} rad = π/2")
print(f"  Área do triângulo = {area_triangulo:.4f} (= 1/8 da área total 4π)")
print(f"  Rotação do vetor = {np.degrees(excesso_angular):.1f}°")

# ── Fibrado de Hopf: visualização de fibras ────────────────
print("\n── Fibrado de Hopf ──")
# Projeção de Hopf: S³ → S²
# π(z₁, z₂) = (2 Re(z₁z̄₂), 2 Im(z₁z̄₂), |z₁|²-|z₂|²) ∈ S²

def hopf_projection(z1, z2):
    """Projeta ponto de S³ ⊂ C² para S² ⊂ R³."""
    return np.array([2*np.real(z1*np.conj(z2)),
                     2*np.imag(z1*np.conj(z2)),
                     np.abs(z1)**2 - np.abs(z2)**2])

# Fibra sobre o polo norte (0,0,1): {(e^{iθ}, 0) : θ ∈ [0,2π]}
theta_vals = np.linspace(0, 2*np.pi, 100)
fibra_norte = np.array([hopf_projection(np.exp(1j*t), 0) for t in theta_vals])
print("Fibra sobre polo norte: z₂=0, z₁=e^{iθ}")
print(f"  Todos os pontos projetam em: {hopf_projection(np.exp(0j), 0)}")

# Fibra sobre o polo sul (0,0,-1): {(0, e^{iθ})}
fibra_sul = np.array([hopf_projection(0, np.exp(1j*t)) for t in theta_vals])
print(f"  Todos os pontos do polo sul: {hopf_projection(0, np.exp(0j))}")

# Classe de Chern c₁ = 1: verificar via curvatura
# Para o fibrado de linha associado, F = c₁ é a forma de área de S²
# ∫_{S²} F = ∫_{S²} dA/4π × 2π = (1/4π)×4π×2π? Não — c₁ = 1 significa
# que ∫ c₁ = 1 (na normalização inteira)
print("\nClasse de Chern c₁(Hopf) = 1:")
print(f"  ∫_{{S²}} c₁ = 1 (fibrado não-trivial)")
print(f"  Monopolo de Dirac: carga magnética g = 1/(2e)")
```

```
  Excesso angular = 1.5708 rad = π/2
  Rotação do vetor = 90.0°

```
