# Formas Diferenciais: Uma Nova Linguagem

O Teorema de Stokes (em 3D), o Teorema de Green e o Teorema de Gauss-Ostrogradsky são, na verdade, **casos particulares de um único teorema** sobre formas diferenciais.

Uma **k-forma** é um objeto que pode ser integrado sobre variedades de dimensão k. Em vez de integrar funções sobre regiões, integramos formas sobre curvas (1-formas), superfícies (2-formas) e volumes (3-formas).

Esta linguagem unifica o cálculo vetorial clássico, é fundamental na física moderna (eletromagnetismo, mecânica hamiltoniana, relatividade geral) e é o alicerce da **cohomologia** — que detecta "buracos" topológicos no espaço.

# Álgebra Exterior e k-Formas

## Formas em <Eq>{"\\mathbb{R}^n"}</Eq>

Uma **k-forma diferencial** é uma expressão:

<Eq>{"\\omega = \\sum_{i_1 < i_2 < \\cdots < i_k} f_{i_1\\cdots i_k}\\, dx^{i_1} \\wedge dx^{i_2} \\wedge \\cdots \\wedge dx^{i_k}"}</Eq>

onde <Eq>{"\\wedge"}</Eq> é o **produto exterior** (produto wedge), antissimétrico:

<Eq>{"dx^i \\wedge dx^j = -dx^j \\wedge dx^i, \\quad dx^i \\wedge dx^i = 0"}</Eq>

**Exemplos em <Eq>{"\\mathbb{R}^3"}</Eq>:**

- 0-forma: função <Eq>{"f"}</Eq>
- 1-forma: <Eq>{"\\omega = P\\,dx + Q\\,dy + R\\,dz"}</Eq>
- 2-forma: <Eq>{"\\omega = F\\,dy\\wedge dz + G\\,dz\\wedge dx + H\\,dx\\wedge dy"}</Eq>
- 3-forma: <Eq>{"\\omega = f\\,dx\\wedge dy\\wedge dz"}</Eq>

*(Fonte: Spivak, Calculus on Manifolds, §4; Cartan, Differential Forms)*

## Derivada Exterior

A **derivada exterior** <Eq>{"d: \\Omega^k \\to \\Omega^{k+1}"}</Eq> é o operador:

<Eq>{"d\\omega = \\sum_{i_1 < \\cdots < i_k} \\sum_j \\frac{\\partial f_{i_1\\cdots i_k}}{\\partial x^j}\\, dx^j \\wedge dx^{i_1} \\wedge \\cdots \\wedge dx^{i_k}"}</Eq>

**Propriedades:**
- Linearidade: <Eq>{"d(\\alpha\\omega + \\beta\\eta) = \\alpha\\,d\\omega + \\beta\\,d\\eta"}</Eq>
- Regra de Leibniz: <Eq>{"d(\\omega \\wedge \\eta) = d\\omega \\wedge \\eta + (-1)^k\\omega \\wedge d\\eta"}</Eq> (ω é k-forma)
- **Nilpotência:** <Eq>{"d^2 = 0"}</Eq> (propriedade fundamental!)

*(Fonte: Spivak §4; do Carmo, Differential Forms and Applications)*

## Correspondência com Cálculo Vetorial em <Eq>{"\\mathbb{R}^3"}</Eq>

| Operação | Forma | Resultado |
|---|---|---|
| Gradiente | <Eq>{"d f"}</Eq> (0-forma) | 1-forma: <Eq>{"\\nabla f \\cdot d\\mathbf{r}"}</Eq> |
| Rotacional | <Eq>{"d \\omega"}</Eq> (1-forma) | 2-forma: corresponde a <Eq>{"\\nabla\\times\\mathbf{F}"}</Eq> |
| Divergente | <Eq>{"d \\omega"}</Eq> (2-forma) | 3-forma: corresponde a <Eq>{"\\nabla\\cdot\\mathbf{F}"}</Eq> |

**Propriedade <Eq>{"d^2 = 0"}</Eq> implica:**
- <Eq>{"\\text{rot}(\\text{grad}\\,f) = \\nabla\\times(\\nabla f) = 0"}</Eq>
- <Eq>{"\\text{div}(\\text{rot}\\,\\mathbf{F}) = \\nabla\\cdot(\\nabla\\times\\mathbf{F}) = 0"}</Eq>

*(Fonte: Spivak §4; Flanders, Differential Forms with Applications)*

# Teorema de Stokes Generalizado

## Enunciado

Seja <Eq>{"M"}</Eq> uma variedade orientada de dimensão n com fronteira <Eq>{"\\partial M"}</Eq> (orientada canonicamente), e <Eq>{"\\omega"}</Eq> uma (n-1)-forma com suporte compacto. Então:

<EquacaoCanonica formula="\int_M d\omega = \int_{\partial M} \omega" />

*(Fonte: Spivak, Calculus on Manifolds, §5; Rudin, Principles of Mathematical Analysis, §10)*

## Casos Especiais

**Teorema Fundamental do Cálculo** (n=1, M=[a,b]):

<Eq>{"\\int_a^b f'(x)\\,dx = f(b) - f(a)"}</Eq>

**Teorema de Green** (n=2, M⊂ℝ², ω = P dx + Q dy):

<Eq>{"\\iint_M \\left(\\frac{\\partial Q}{\\partial x} - \\frac{\\partial P}{\\partial y}\\right)dx\\,dy = \\oint_{\\partial M} P\\,dx + Q\\,dy"}</Eq>

**Teorema de Stokes Clássico** (n=2, M = superfície em ℝ³):

<Eq>{"\\iint_M (\\nabla\\times\\mathbf{F})\\cdot d\\mathbf{S} = \\oint_{\\partial M} \\mathbf{F}\\cdot d\\mathbf{r}"}</Eq>

**Teorema de Gauss-Ostrogradsky** (n=3, M⊂ℝ³, ω = 2-forma):

<Eq>{"\\iiint_M \\nabla\\cdot\\mathbf{F}\\,dV = \\oiint_{\\partial M} \\mathbf{F}\\cdot d\\mathbf{S}"}</Eq>

*(Fonte: Spivak §5; Apostol, Mathematical Analysis, §12)*

## Formas Fechadas e Exatas

Uma k-forma ω é:
- **Fechada:** <Eq>{"d\\omega = 0"}</Eq>
- **Exata:** <Eq>{"\\omega = d\\eta"}</Eq> para alguma (k-1)-forma η

Toda forma exata é fechada (<Eq>{"d^2 = 0"}</Eq>). A recíproca é o **Lema de Poincaré**:

**Lema de Poincaré:** Em <Eq>{"\\mathbb{R}^n"}</Eq> (ou qualquer domínio estrelar), toda forma fechada é exata.

*(Fonte: Spivak §4.2; Bott & Tu, Differential Forms in Algebraic Topology, §1)*

# Cohomologia de de Rham

## Grupos de Cohomologia

O fato de que nem toda forma fechada é exata em domínios topologicamente não-triviais é capturado pela **cohomologia de de Rham**:

<Eq>{"H^k_{\\text{dR}}(M) = \\frac{\\ker(d: \\Omega^k \\to \\Omega^{k+1})}{\\text{im}(d: \\Omega^{k-1} \\to \\Omega^k)} = \\frac{\\text{formas fechadas}}{\\text{formas exatas}}"}</Eq>

**Exemplos:**

| Espaço M | <Eq>{"H^0"}</Eq> | <Eq>{"H^1"}</Eq> | <Eq>{"H^2"}</Eq> |
|---|---|---|---|
| <Eq>{"\\mathbb{R}^n"}</Eq> | <Eq>{"\\mathbb{R}"}</Eq> | 0 | 0 |
| <Eq>{"S^1"}</Eq> | <Eq>{"\\mathbb{R}"}</Eq> | <Eq>{"\\mathbb{R}"}</Eq> | 0 |
| <Eq>{"S^2"}</Eq> | <Eq>{"\\mathbb{R}"}</Eq> | 0 | <Eq>{"\\mathbb{R}"}</Eq> |
| Toro <Eq>{"T^2"}</Eq> | <Eq>{"\\mathbb{R}"}</Eq> | <Eq>{"\\mathbb{R}^2"}</Eq> | <Eq>{"\\mathbb{R}"}</Eq> |

*(Fonte: Bott & Tu §1; Warner, Foundations of Differentiable Manifolds)*

## Teorema de de Rham

**Enunciado:** A cohomologia de de Rham é isomorfa à cohomologia singular com coeficientes reais:

<Eq>{"H^k_{\\text{dR}}(M) \\cong H^k(M; \\mathbb{R})"}</Eq>

**Consequência:** O número de Betti <Eq>{"b_k = \\dim H^k_{\\text{dR}}"}</Eq> conta "buracos k-dimensionais" no espaço.

*(Fonte: Bott & Tu §1; Warner §5)*

## Operador de Hodge e Laplaciano

Em uma variedade Riemanniana orientada de dimensão n, o **operador de Hodge** <Eq>{"\\star: \\Omega^k \\to \\Omega^{n-k}"}</Eq>:

<Eq>{"\\star(dx^{i_1}\\wedge\\cdots\\wedge dx^{i_k}) = \\frac{\\sqrt{|g|}}{(n-k)!}g^{i_1 j_1}\\cdots g^{i_k j_k}\\varepsilon_{j_1\\cdots j_k j_{k+1}\\cdots j_n}dx^{j_{k+1}}\\wedge\\cdots\\wedge dx^{j_n}"}</Eq>

**Coderivatada:** <Eq>{"\\delta = (-1)^{n(k+1)+1}\\star d\\star: \\Omega^k \\to \\Omega^{k-1}"}</Eq>

**Laplaciano de Hodge-de Rham:**

<Eq>{"\\Delta_{\\text{dR}} = d\\delta + \\delta d = (d + \\delta)^2: \\Omega^k \\to \\Omega^k"}</Eq>

**Teorema de Hodge:** Em variedade Riemanniana compacta, todo <Eq>{"[\\omega] \\in H^k_{\\text{dR}}"}</Eq> tem único representante harmônico <Eq>{"\\Delta_{\\text{dR}}\\omega = 0"}</Eq>.

*(Fonte: Warner §6; Jost, Riemannian Geometry and Geometric Analysis, §2.2)*

## Eletromagnetismo como 2-Forma

O tensor eletromagnético <Eq>{"F_{\\mu\\nu}"}</Eq> é uma 2-forma:

<Eq>{"F = \\frac{1}{2}F_{\\mu\\nu}dx^\\mu\\wedge dx^\\nu = \\mathbf{E}\\wedge dt + \\mathbf{B}"}</Eq>

**Equações de Maxwell:**
- <Eq>{"dF = 0"}</Eq> (equações homogêneas de Maxwell — Faraday e Gauss magnético)
- <Eq>{"d\\star F = \\star J"}</Eq> (equações inomogêneas — Gauss elétrico e Ampère-Maxwell)

*(Fonte: Misner, Thorne & Wheeler §4; Carroll §2.8)*

## Verificação de <Eq>{"d^2 = 0"}</Eq>: Caso Concreto

Seja <Eq>{"\\omega = x^2 y\\,dx + xyz\\,dy"}</Eq> em <Eq>{"\\mathbb{R}^3"}</Eq>.

**Primeira derivada exterior:**

<Eq>{"d\\omega = d(x^2y)\\wedge dx + d(xyz)\\wedge dy"}</Eq>

<Eq>{"= (2xy\\,dx + x^2\\,dy + 0\\,dz)\\wedge dx + (yz\\,dx + xz\\,dy + xy\\,dz)\\wedge dy"}</Eq>

<Eq>{"= x^2\\,dy\\wedge dx + yz\\,dx\\wedge dy + xy\\,dz\\wedge dy"}</Eq>

<Eq>{"= (yz - x^2)\\,dx\\wedge dy - xy\\,dy\\wedge dz"}</Eq>

**Segunda derivada:** <Eq>{"d(d\\omega)"}</Eq>

<Eq>{"d[(yz-x^2)\\,dx\\wedge dy - xy\\,dy\\wedge dz]"}</Eq>

<Eq>{"= (z\\,dy + y\\,dz - 2x\\,dx)\\wedge dx\\wedge dy - (y\\,dx + x\\,dy)\\wedge dy\\wedge dz"}</Eq>

<Eq>{"= y\\,dz\\wedge dx\\wedge dy - y\\,dx\\wedge dy\\wedge dz = y\\,dz\\wedge dx\\wedge dy - y\\,dx\\wedge dy\\wedge dz"}</Eq>

<Eq>{"= y\\,dx\\wedge dy\\wedge dz - y\\,dx\\wedge dy\\wedge dz = 0 \\quad \\checkmark"}</Eq>

*(Fonte: Spivak §4 — nilpotência da derivada exterior verificada diretamente)*

</Exemplo>

## Implementação: Formas Diferenciais com SymPy

```python
from sympy import *

# ── Variáveis e 1-formas básicas ───────────────────────────
x, y, z, t = symbols('x y z t')

# Em SymPy, usamos differentialgeometry para formas
# Aqui simulamos com manipulação simbólica direta

def wedge(df1, df2):
    """
    Produto wedge de 1-formas (representadas como dicts de coeficientes).
    df = {(i,): coef} para 1-forma, {(i,j): coef} para 2-forma, etc.
    """
    result = {}
    for (k1, v1), (k2, v2) in [(i, j) for i in df1.items() for j in df2.items()]:
        if isinstance(k1, int): k1 = (k1,)
        if isinstance(k2, int): k2 = (k2,)
        # Verificar índices distintos (antissimetria)
        if any(i in k2 for i in k1):
            continue
        key = k1 + k2
        coef = v1 * v2
        # Normalizar (ordenar e contar transposições)
        result[key] = result.get(key, S.Zero) + coef
    return result

# ── Verificação: Teorema de Stokes em R² ──────────────────
# Área do círculo unidade via Green: ∮(x dy - y dx)/2 = π
print("Verificação do Teorema de Green:")
print("∮_C (x dy - y dx)/2 = Área do disco unitário\n")

from sympy import cos, sin, pi, integrate, simplify

# Parametrização do círculo: x = cos t, y = sin t, t ∈ [0, 2π]
t_sym = symbols('t')
x_c = cos(t_sym)
y_c = sin(t_sym)
dx_c = diff(x_c, t_sym)
dy_c = diff(y_c, t_sym)

# Integral de linha: ∮ (x dy - y dx) / 2
integrando = (x_c * dy_c - y_c * dx_c) / 2
area_linha = integrate(integrando, (t_sym, 0, 2*pi))
print(f"Via Teorema de Green (linha): {area_linha} = π ≈ {float(pi):.4f}")
print(f"Área do disco (πr²=π): {float(pi):.4f}")

# ── Derivada exterior ─────────────────────────────────────
print("\n── Derivada Exterior ──")

# 1-forma ω = x²y dx + xyz dy
P = x**2 * y
Q = x * y * z
R_coef = S.Zero

# dω = (∂Q/∂x - ∂P/∂y) dx∧dy + (∂R/∂y - ∂Q/∂z) dy∧dz + (∂P/∂z - ∂R/∂x) dz∧dx
dPdx = diff(P, x); dPdy = diff(P, y); dPdz = diff(P, z)
dQdx = diff(Q, x); dQdy = diff(Q, y); dQdz = diff(Q, z)
dRdx = diff(R_coef, x); dRdy = diff(R_coef, y); dRdz = diff(R_coef, z)

coef_dxdy = dQdx - dPdy
coef_dydz = dRdy - dQdz
coef_dzdx = dPdz - dRdx

print(f"ω = x²y dx + xyz dy")
print(f"dω = ({coef_dxdy}) dx∧dy + ({coef_dydz}) dy∧dz + ({coef_dzdx}) dz∧dx")

# Verificar d²ω = 0: calcular d(dω)
# dω é 2-forma: A dx∧dy + B dy∧dz + C dz∧dx
A_coef = coef_dxdy  # coef de dx∧dy
B_coef = coef_dydz  # coef de dy∧dz
C_coef = coef_dzdx  # coef de dz∧dx

# d(A dx∧dy) = (∂A/∂z) dz∧dx∧dy = (∂A/∂z) dx∧dy∧dz
# d(B dy∧dz) = (∂B/∂x) dx∧dy∧dz
# d(C dz∧dx) = (∂C/∂y) dy∧dz∧dx = (∂C/∂y) dx∧dy∧dz  [com orientação]
coef_3forma = diff(A_coef, z) + diff(B_coef, x) + diff(C_coef, y)
print(f"\nd²ω = ({simplify(coef_3forma)}) dx∧dy∧dz = 0 $\checkmark$")

# ── Forma de Maxwell: dF = 0 ────────────────────────────────
print("\n── Eletromagnetismo com formas diferenciais ──")
# Em (3+1)D, com coordenadas (t, x, y, z)
# F = E_x dx∧dt + E_y dy∧dt + E_z dz∧dt + B_x dy∧dz + B_y dz∧dx + B_z dx∧dy
# dF = 0 ↔ equações de Maxwell homogêneas

# Para campo estático: E = (1, 0, 0), B = 0
# Verificar dF = 0 para campo uniforme
Ex, Ey, Ez = symbols('Ex Ey Ez')
Bx, By, Bz = symbols('Bx By Bz')

# dF = 0 implica equações de Faraday e Gauss B
# Para campos constantes (derivadas = 0): trivialmente dF = 0
print("Para campos eletromagnéticos uniformes (derivadas = 0):")
print("dF = 0 trivialmente — as equações homogêneas de Maxwell são satisfeitas.")
print("(Eq. de Faraday: ∇×E + ∂B/∂t = 0, Gauss B: ∇·B = 0)")

# Verificar que d(d(f)) = 0 para função arbitrária
f_func = x**2 * sin(y) * exp(z)
grad_f = Matrix([diff(f_func, v) for v in [x, y, z]])
# Divergência do gradiente = Laplaciano (não é zero em geral)
laplaciano = sum(diff(diff(f_func, v), v) for v in [x, y, z])
print(f"\nLaplaciano de x²sin(y)e^z = {simplify(laplaciano)}")
# Mas d²f = d(df) = 0 como 2-forma (pois df é 1-forma exata)
# ∂²f/∂x∂y - ∂²f/∂y∂x = 0 (Schwarz)
print("d²f = 0: verificado pela simetria das derivadas parciais (Schwarz) $\checkmark$")
```

**Saída esperada:**
```
Via Teorema de Green (linha): π = π ≈ 3.1416
Área do disco (πr²=π): 3.1416

dω = (yz - x²) dx∧dy + (-x) dy∧dz + (0) dz∧dx
d²ω = (0) dx∧dy∧dz = 0 $\checkmark$
```

*(Fonte: Spivak §4–5 — verificação simbólica das identidades do cálculo exterior)*
