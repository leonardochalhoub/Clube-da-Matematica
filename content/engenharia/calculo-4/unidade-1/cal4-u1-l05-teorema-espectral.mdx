# Matrizes Simétricas São Especiais

Matrizes simétricas (<Eq>{"A = A^T"}</Eq>) têm uma propriedade extraordinária: seus autovetores são sempre **perpendiculares entre si**, e seus autovalores são sempre **números reais** — mesmo que a matriz pareça "complicada"!

Isso torna matrizes simétricas as mais fáceis de trabalhar em muitas aplicações de engenharia, como vibrações de estruturas e análise de forças.

</Porta>
<Porta nivel="10anos">

# Teorema Espectral

**Teorema Espectral (matrizes simétricas):** Se <Eq>{"A = A^T"}</Eq> (<Eq>{"A \\in M_{n\\times n}(\\mathbb{R})"}</Eq>), então:
1. Todos os autovalores de <Eq>{"A"}</Eq> são **reais**
2. Autovetores de autovalores diferentes são **ortogonais**
3. Existe base ortonormal de autovetores: <Eq>{"A = Q\\Lambda Q^T"}</Eq> com <Eq>{"Q"}</Eq> ortogonal

**Formas quadráticas:** <Eq>{"q(x) = x^TAx = \\sum_{i,j}a_{ij}x_ix_j"}</Eq>. Com <Eq>{"x = Qy"}</Eq>:
<Eq>{"q(x) = y^T\\Lambda y = \\lambda_1 y_1^2 + \\cdots + \\lambda_n y_n^2"}</Eq>

**Definida positiva:** <Eq>{"q(x) > 0"}</Eq> para todo <Eq>{"x \\neq 0"}</Eq> <Eq>{"\\iff"}</Eq> todos <Eq>{"\\lambda_i > 0"}</Eq>.

</Porta>

# Teorema Espectral e Formas Quadráticas

## Teorema Espectral Real

**Teorema.** Seja <Eq>{"A \\in M_{n\\times n}(\\mathbb{R})"}</Eq> simétrica (<Eq>{"A = A^T"}</Eq>). Então:
1. Todos os autovalores de <Eq>{"A"}</Eq> são reais
2. Para autovalores distintos <Eq>{"\\lambda_i \\neq \\lambda_j"}</Eq>, os autoespaços são ortogonais: <Eq>{"E_{\\lambda_i} \\perp E_{\\lambda_j}"}</Eq>
3. Existe matriz ortogonal <Eq>{"Q"}</Eq> (<Eq>{"Q^TQ = I"}</Eq>) e diagonal real <Eq>{"\\Lambda"}</Eq> com:

<EquacaoCanonica
  formula="A = Q\Lambda Q^T = \sum_{i=1}^n \lambda_i q_i q_i^T"
  legenda={<>Decomposição espectral: <Eq>{"q_i"}</Eq> são autovetores ortonormais, <Eq>{"\\lambda_i"}</Eq> autovalores</>}
  audioTexto="A é igual a Q Lambda Q transposta, que é a soma de lambda i vezes q i vezes q i transposta."
/>

**Prova (autovalores reais):** Se <Eq>{"Av = \\lambda v"}</Eq> com <Eq>{"v \\neq 0"}</Eq>, tome o conjugado: <Eq>{"\\bar{\\lambda}\\|v\\|^2 = v^* Av = (Av)^* v = \\lambda^* \\|v\\|^2"}</Eq>. Logo <Eq>{"\\lambda = \\bar{\\lambda} \\in \\mathbb{R}"}</Eq>.

## Teorema Espectral Complexo (Hermitianas)

Para <Eq>{"A \\in M_{n\\times n}(\\mathbb{C})"}</Eq> **hermitiana** (<Eq>{"A = A^* = \\bar{A}^T"}</Eq>), o mesmo resultado vale com matrizes **unitárias** <Eq>{"U"}</Eq> (<Eq>{"U^*U = I"}</Eq>).

## Classificação de Formas Quadráticas

**Forma quadrática:** <Eq>{"q(x) = x^TAx"}</Eq> com <Eq>{"A"}</Eq> simétrica.

| Classificação | Condição nos autovalores | Critério de Sylvester |
|--------------|------------------------|----------------------|
| Definida positiva | Todos <Eq>{"\\lambda_i > 0"}</Eq> | Todos menores principais > 0 |
| Semidefinida positiva | Todos <Eq>{"\\lambda_i \\geq 0"}</Eq> | Menores principais <Eq>{"\\geq 0"}</Eq> |
| Indefinida | Autovalores de ambos sinais | — |
| Definida negativa | Todos <Eq>{"\\lambda_i < 0"}</Eq> | Sinais alternados |

**Critério de Sylvester:** <Eq>{"A"}</Eq> é DP <Eq>{"\\iff"}</Eq> todos os menores principais líderes <Eq>{"\\Delta_k = \\det(A_{k\\times k}) > 0"}</Eq>.

## Variacional — Autovalores como Extremos

**Teorema de Min-Max de Courant-Fischer:**
<Eq>{"\\lambda_k = \\min_{\\dim S = n-k+1}\\max_{x\\in S,\\,\\|x\\|=1}x^TAx = \\max_{\\dim S = k}\\min_{x\\in S,\\,\\|x\\|=1}x^TAx"}</Eq>

**Caso especial:** <Eq>{"\\lambda_{\\max} = \\max_{\\|x\\|=1}x^TAx"}</Eq>, <Eq>{"\\lambda_{\\min} = \\min_{\\|x\\|=1}x^TAx"}</Eq>.

</Porta>

# Espectro de Operadores Simétricos

## Operadores Auto-Adjuntos em Espaço de Hilbert

**Definição.** <Eq>{"T: H \\to H"}</Eq> é **auto-adjunto** se <Eq>{"\\langle Tu,v\\rangle = \\langle u,Tv\\rangle"}</Eq> para todos <Eq>{"u,v \\in H"}</Eq>.

**Teorema Espectral (dimensão infinita).** Se <Eq>{"T"}</Eq> é operador compacto auto-adjunto em <Eq>{"H"}</Eq> separável, então:
- <Eq>{"T"}</Eq> tem espectro discreto <Eq>{"\\{\\lambda_n\\} \\to 0"}</Eq>
- Existe base ortonormal de autovetores <Eq>{"\\{e_n\\}"}</Eq>
- <Eq>{"Tv = \\sum_n \\lambda_n \\langle v,e_n\\rangle e_n"}</Eq>

## Conexão com Problemas de Sturm-Liouville

O operador diferencial <Eq>{"Lf = -(pf')' + qf"}</Eq> (com CCs adequadas) é auto-adjunto em <Eq>{"L^2[a,b]"}</Eq> com produto interno ponderado, compacto (via resolvente). O espectro espectral dá a base para expansão de funções em séries de autofunções.

## Exemplos Resolvidos

<Exemplo
  numero={1}
  titulo="Diagonalização Ortogonal Completa"
  fonte="Strang, G. Linear Algebra and Its Applications, Cengage, 4ª ed., §6.4, Exemplo 3"
>
**Diagonalize ortogonalmente** <Eq>{"A = \\begin{pmatrix}3&1\\\\1&3\\end{pmatrix}"}</Eq>.

**Resolução:**

Autovalores: <Eq>{"p_A(\\lambda) = (3-\\lambda)^2-1 = 0 \\Rightarrow \\lambda_{1,2} = 3\\pm 1"}</Eq>, ou seja <Eq>{"\\lambda_1=2"}</Eq>, <Eq>{"\\lambda_2=4"}</Eq>.

Autovetores (já ortogonais por Teorema Espectral):
- <Eq>{"\\lambda_1=2"}</Eq>: <Eq>{"(A-2I)v=0 \\Rightarrow v_1=(1,-1)^T/\\sqrt{2}"}</Eq>
- <Eq>{"\\lambda_2=4"}</Eq>: <Eq>{"(A-4I)v=0 \\Rightarrow v_2=(1,1)^T/\\sqrt{2}"}</Eq>

Verificação: <Eq>{"v_1\\cdot v_2 = (1\\cdot1+(-1)\\cdot1)/2 = 0"}</Eq> $\checkmark$

<Eq>{"Q = \\frac{1}{\\sqrt{2}}\\begin{pmatrix}1&1\\\\-1&1\\end{pmatrix}, \\quad \\Lambda = \\begin{pmatrix}2&0\\\\0&4\\end{pmatrix}"}</Eq>

**Decomposição espectral:** <Eq>{"A = 2v_1v_1^T + 4v_2v_2^T"}</Eq>.
</Exemplo>

<Exemplo
  numero={2}
  titulo="Classificação de Forma Quadrática"
  fonte="Lay, D.C. Álgebra Linear e suas Aplicações, LTC, 5ª ed., §7.2, Exemplo 3"
>
**Classifique** <Eq>{"q(x,y,z) = 2x^2+2y^2+2z^2+2xy+2xz+2yz"}</Eq>.

**Resolução:**

Matriz associada: <Eq>{"A = \\begin{pmatrix}2&1&1\\\\1&2&1\\\\1&1&2\\end{pmatrix}"}</Eq>.

Critério de Sylvester:
- <Eq>{"\\Delta_1 = 2 > 0"}</Eq>
- <Eq>{"\\Delta_2 = \\det\\begin{pmatrix}2&1\\\\1&2\\end{pmatrix} = 3 > 0"}</Eq>
- <Eq>{"\\Delta_3 = \\det A = 2(4-1)-1(2-1)+1(1-2) = 6-1-1 = 4 > 0"}</Eq>

**Conclusão:** <Eq>{"q"}</Eq> é **definida positiva**. Autovalores: <Eq>{"\\lambda_1 = \\lambda_2 = 1"}</Eq>, <Eq>{"\\lambda_3 = 4"}</Eq> (verificar: traço = 6, det = 4 $\checkmark$).
</Exemplo>

<Exemplo
  numero={3}
  titulo="Extremos em Formas Quadráticas — Frequências de Vibração"
  fonte="Strang, G. Linear Algebra and Its Applications, Cengage, 4ª ed., §6.5, Exemplo 2"
>
**Um sistema de massas acopladas tem matriz de rigidez** <Eq>{"K = \\begin{pmatrix}2&-1\\\\-1&2\\end{pmatrix}"}</Eq> **e massa** <Eq>{"M = I"}</Eq>**. Encontre as frequências naturais.**

**Resolução:**

As frequências naturais satisfazem <Eq>{"Kv = \\omega^2 v"}</Eq> (problema de autovalores).

Autovalores de <Eq>{"K"}</Eq>: <Eq>{"\\lambda_1 = 1, \\lambda_2 = 3"}</Eq>, com autovetores <Eq>{"v_1 = (1,1)^T/\\sqrt{2}"}</Eq> e <Eq>{"v_2 = (1,-1)^T/\\sqrt{2}"}</Eq>.

**Frequências:** <Eq>{"\\omega_1 = 1"}</Eq>, <Eq>{"\\omega_2 = \\sqrt{3}"}</Eq> rad/s.

**Modos normais:**
- <Eq>{"\\omega_1 = 1"}</Eq>: as duas massas vibram **em fase** (mesmo sentido)
- <Eq>{"\\omega_2 = \\sqrt{3}"}</Eq>: as duas massas vibram **em contrafase** (sentidos opostos)

Solução geral: <Eq>{"x(t) = c_1\\cos(t+\\phi_1)v_1 + c_2\\cos(\\sqrt{3}t+\\phi_2)v_2"}</Eq>.
</Exemplo>

# Teorema Espectral: Versão Funcional

## Teorema Espectral para Operadores Compactos

**Teorema.** Seja <Eq>{"T: H \\to H"}</Eq> operador compacto auto-adjunto em espaço de Hilbert separável. Então existe sequência de autovalores reais <Eq>{"\\{\\lambda_n\\}"}</Eq> com <Eq>{"|\\lambda_n| \\to 0"}</Eq> e base ortonormal <Eq>{"\\{e_n\\}"}</Eq> tal que <Eq>{"Te_n = \\lambda_n e_n"}</Eq> e:
<Eq>{"T = \\sum_n \\lambda_n \\langle\\cdot, e_n\\rangle e_n"}</Eq>

**Nota:** "compacto" significa que <Eq>{"T"}</Eq> mapeia conjuntos limitados em relativamente compactos — generalização de dimensão finita.

## Álgebra <Eq>{"C^*"}</Eq>

A teoria espectral moderna vive em **álgebras** <Eq>{"C^*"}</Eq>: álgebras de Banach completas com involução <Eq>{"(^*)"}</Eq> satisfazendo <Eq>{"\\|a^*a\\| = \\|a\\|^2"}</Eq>. O **Teorema Espectral de Gelfand-Naimark** generaliza a diagonalização a operadores normais em qualquer álgebra <Eq>{"C^*"}</Eq>.
