# Direções Especiais de uma Transformação

Quando uma transformação linear age sobre um vetor especial, ela apenas **escala** esse vetor — não muda sua direção. Esses vetores especiais são os **autovetores**, e os fatores de escala são os **autovalores**.

Por exemplo, a matriz que dobra tudo no eixo <Eq>{"x"}</Eq> e não muda o eixo <Eq>{"y"}</Eq>: o eixo <Eq>{"x"}</Eq> tem autovalor 2 e o eixo <Eq>{"y"}</Eq> tem autovalor 1.

</Porta>
<Porta nivel="10anos">

# Autovalores e Autovetores

Um **autovetor** de <Eq>{"T: V \\to V"}</Eq> é um vetor não-nulo <Eq>{"v"}</Eq> com <Eq>{"T(v) = \\lambda v"}</Eq> para algum escalar <Eq>{"\\lambda"}</Eq> (**autovalor**).

**Cálculo:** <Eq>{"\\lambda"}</Eq> é autovalor <Eq>{"\\iff \\det(A - \\lambda I) = 0"}</Eq> (**polinômio característico**).

**Diagonalização:** <Eq>{"A = PDP^{-1}"}</Eq> com <Eq>{"D"}</Eq> diagonal <Eq>{"\\iff"}</Eq> existem <Eq>{"n"}</Eq> autovetores LI.

**Aplicação principal:** resolver <Eq>{"u' = Au"}</Eq>, calcular <Eq>{"A^k"}</Eq>, analisar estabilidade de sistemas.

</Porta>

# Autovalores, Autovetores e Diagonalização

## Definição e Cálculo

**Definição.** Seja <Eq>{"A \\in M_{n\\times n}(\\mathbb{F})"}</Eq>. Um escalar <Eq>{"\\lambda \\in \\mathbb{F}"}</Eq> é **autovalor** de <Eq>{"A"}</Eq> se existe <Eq>{"v \\neq 0"}</Eq> com <Eq>{"Av = \\lambda v"}</Eq>. <Eq>{"v"}</Eq> é **autovetor** associado a <Eq>{"\\lambda"}</Eq>.

**Polinômio característico:**

<EquacaoCanonica
  formula="p_A(\lambda) = \det(A - \lambda I) = (-1)^n\lambda^n + \cdots + (-1)^{n-1}\mathrm{tr}(A)\lambda^{n-1} + \cdots + \det(A)"
  legenda={<>Polinômio característico de <Eq>{"A"}</Eq>: <Eq>{"p_A(\\lambda) = \\det(A-\\lambda I)"}</Eq></>}
  audioTexto="O polinômio característico de A é o determinante de A menos lambda vezes I."
/>

Os autovalores são as raízes de <Eq>{"p_A(\\lambda)"}</Eq>.

**Autoespaço:** <Eq>{"E_\\lambda = \\ker(A-\\lambda I)"}</Eq> é subespaço de <Eq>{"\\mathbb{F}^n"}</Eq>.

**Multiplicidades:**
- **Algébrica** <Eq>{"m_a(\\lambda)"}</Eq>: multiplicidade de <Eq>{"\\lambda"}</Eq> como raiz de <Eq>{"p_A"}</Eq>
- **Geométrica** <Eq>{"m_g(\\lambda)"}</Eq>: <Eq>{"\\dim(E_\\lambda)"}</Eq>

**Desigualdade:** <Eq>{"1 \\leq m_g(\\lambda) \\leq m_a(\\lambda)"}</Eq> sempre.

## Condição de Diagonalização

**Teorema.** <Eq>{"A \\in M_{n\\times n}"}</Eq> é diagonalizável (sobre <Eq>{"\\mathbb{F}"}</Eq>) <Eq>{"\\iff"}</Eq> <Eq>{"m_g(\\lambda) = m_a(\\lambda)"}</Eq> para todo autovalor <Eq>{"\\lambda"}</Eq>.

**Corolário.** Se <Eq>{"A"}</Eq> tem <Eq>{"n"}</Eq> autovalores distintos, então <Eq>{"A"}</Eq> é diagonalizável.

**Corolário.** Matrizes simétricas reais (<Eq>{"A = A^T"}</Eq>) são sempre diagonalizáveis sobre <Eq>{"\\mathbb{R}"}</Eq> com autovetores ortogonais (Teorema Espectral — próxima lição).

## Aplicação: Potências de Matrizes e Sistemas de EDOs

Se <Eq>{"A = PDP^{-1}"}</Eq>, então <Eq>{"A^k = PD^kP^{-1}"}</Eq> — cálculo trivial!

**Sistema de EDOs** <Eq>{"\\mathbf{u}' = A\\mathbf{u}"}</Eq> com condição inicial <Eq>{"\\mathbf{u}(0) = \\mathbf{u}_0"}</Eq>:

Fazendo <Eq>{"\\mathbf{u} = P\\mathbf{w}"}</Eq>, o sistema desacopla: <Eq>{"\\mathbf{w}' = D\\mathbf{w}"}</Eq>. Solução:
<Eq>{"w_k(t) = c_k e^{\\lambda_k t}, \\quad \\mathbf{u}(t) = Pe^{Dt}P^{-1}\\mathbf{u}_0 = e^{At}\\mathbf{u}_0"}</Eq>

onde a **exponencial de matriz** é <Eq>{"e^{At} = \\sum_{k=0}^\\infty \\frac{(At)^k}{k!}"}</Eq>.

## Localização de Autovalores — Gershgorin

**Teorema de Gershgorin.** Todo autovalor de <Eq>{"A"}</Eq> está em pelo menos um disco de Gershgorin:
<Eq>{"D_i = \\left\\{\\lambda \\in \\mathbb{C}: |\\lambda - a_{ii}| \\leq \\sum_{j\\neq i}|a_{ij}|\\right\\}"}</Eq>

# Autovalores — Teoria Avançada

## Polinômio Minimal e Teorema de Cayley-Hamilton

**Teorema de Cayley-Hamilton.** <Eq>{"p_A(A) = 0"}</Eq>: toda matriz anula seu próprio polinômio característico.

**Polinômio minimal** <Eq>{"m_A(\\lambda)"}</Eq>: menor grau polinômio mônico que anula <Eq>{"A"}</Eq>. Divide <Eq>{"p_A"}</Eq> e tem as mesmas raízes (mas possivelmente menor multiplicidade).

**Diagonalização:** <Eq>{"A"}</Eq> é diagonalizável <Eq>{"\\iff m_A"}</Eq> não tem raízes repetidas.

## Decomposição de Jordan (detalhada)

Sobre <Eq>{"\\mathbb{C}"}</Eq>, todo <Eq>{"A"}</Eq> satisfaz <Eq>{"A = S + N"}</Eq> (**decomposição de Jordan-Chevalley**) onde <Eq>{"S"}</Eq> é diagonalizável, <Eq>{"N"}</Eq> é nilpotente e <Eq>{"SN = NS"}</Eq>. Esta decomposição é única.

## Autovalores e Estabilidade

Para o sistema <Eq>{"\\mathbf{u}' = A\\mathbf{u}"}</Eq>:
- **Estável** (soluções limitadas) <Eq>{"\\iff \\text{Re}(\\lambda) \\leq 0"}</Eq> para todos os autovalores
- **Assintoticamente estável** <Eq>{"\\iff \\text{Re}(\\lambda) < 0"}</Eq> para todos
- **Instável** <Eq>{"\\iff"}</Eq> existe <Eq>{"\\lambda"}</Eq> com <Eq>{"\\text{Re}(\\lambda) > 0"}</Eq>

## Exemplos Resolvidos

<Exemplo
  numero={1}
  titulo="Diagonalização Completa"
  fonte="Strang, G. Linear Algebra and Its Applications, Cengage, 4ª ed., §5.2, Exemplo 3"
>
**Diagonalize** <Eq>{"A = \\begin{pmatrix}2&1\\\\1&2\\end{pmatrix}"}</Eq>.

**Resolução:**

Polinômio característico: <Eq>{"p_A(\\lambda) = (2-\\lambda)^2 - 1 = \\lambda^2 - 4\\lambda + 3 = (\\lambda-1)(\\lambda-3)"}</Eq>.

Autovalores: <Eq>{"\\lambda_1 = 1"}</Eq>, <Eq>{"\\lambda_2 = 3"}</Eq>.

Autovetores:
- <Eq>{"\\lambda_1 = 1"}</Eq>: <Eq>{"(A-I)v = 0"}</Eq> → <Eq>{"v_1 = (1,-1)^T"}</Eq>
- <Eq>{"\\lambda_2 = 3"}</Eq>: <Eq>{"(A-3I)v = 0"}</Eq> → <Eq>{"v_2 = (1,1)^T"}</Eq>

<Eq>{"P = \\begin{pmatrix}1&1\\\\-1&1\\end{pmatrix}, \\quad D = \\begin{pmatrix}1&0\\\\0&3\\end{pmatrix}, \\quad A = PDP^{-1}"}</Eq>

**Cálculo de** <Eq>{"A^{10}"}</Eq>:
<Eq>{"A^{10} = PD^{10}P^{-1} = \\frac{1}{2}\\begin{pmatrix}1&1\\\\-1&1\\end{pmatrix}\\begin{pmatrix}1&0\\\\0&3^{10}\\end{pmatrix}\\begin{pmatrix}1&-1\\\\1&1\\end{pmatrix}"}</Eq>

<Eq>{"= \\frac{1}{2}\\begin{pmatrix}1+3^{10}&-1+3^{10}\\\\-1+3^{10}&1+3^{10}\\end{pmatrix}"}</Eq>

Como <Eq>{"3^{10} = 59049"}</Eq>: <Eq>{"A^{10} = \\begin{pmatrix}29525&29524\\\\29524&29525\\end{pmatrix}"}</Eq>.
</Exemplo>

<Exemplo
  numero={2}
  titulo="Sistema de EDOs via Autovalores"
  fonte="Strang, G. Linear Algebra and Its Applications, Cengage, 4ª ed., §5.4, Exemplo 1"
>
**Resolva o sistema** <Eq>{"\\begin{cases}u_1' = 4u_1 + u_2\\\\u_2' = 2u_1 + 3u_2\\end{cases}"}</Eq> **com** <Eq>{"u_1(0) = 1"}</Eq>, <Eq>{"u_2(0) = 0"}</Eq>.

**Resolução:**

<Eq>{"A = \\begin{pmatrix}4&1\\\\2&3\\end{pmatrix}"}</Eq>. Autovalores: <Eq>{"p_A(\\lambda) = \\lambda^2 - 7\\lambda + 10 = (\\lambda-2)(\\lambda-5)"}</Eq>.

- <Eq>{"\\lambda_1 = 2"}</Eq>: <Eq>{"v_1 = (1,-2)^T"}</Eq>
- <Eq>{"\\lambda_2 = 5"}</Eq>: <Eq>{"v_2 = (1,1)^T"}</Eq>

Solução geral: <Eq>{"\\mathbf{u}(t) = c_1 e^{2t}(1,-2)^T + c_2 e^{5t}(1,1)^T"}</Eq>

Condição inicial <Eq>{"\\mathbf{u}(0) = (1,0)^T"}</Eq>:
<Eq>{"c_1 + c_2 = 1, \\quad -2c_1 + c_2 = 0 \\Rightarrow c_1 = 1/3, \\; c_2 = 2/3"}</Eq>

<Eq>{"\\mathbf{u}(t) = \\frac{1}{3}e^{2t}\\begin{pmatrix}1\\\\-2\\end{pmatrix} + \\frac{2}{3}e^{5t}\\begin{pmatrix}1\\\\1\\end{pmatrix}"}</Eq>
</Exemplo>

<Exemplo
  numero={3}
  titulo="Autovalores e Estabilidade"
  fonte="Strang, G. Linear Algebra and Its Applications, Cengage, 4ª ed., §5.4; Lay, D.C. Álgebra Linear, LTC, §5.7"
>
**Classifique a estabilidade do sistema** <Eq>{"\\mathbf{x}' = A\\mathbf{x}"}</Eq> **onde** <Eq>{"A = \\begin{pmatrix}-2&1\\\\-5&-1\\end{pmatrix}"}</Eq>.

**Resolução:**

Polinômio característico: <Eq>{"p_A(\\lambda) = \\lambda^2 + 3\\lambda + 7"}</Eq>.

Discriminante: <Eq>{"\\Delta = 9 - 28 = -19 < 0"}</Eq>. Raízes complexas:
<Eq>{"\\lambda = \\frac{-3 \\pm i\\sqrt{19}}{2}"}</Eq>

Parte real: <Eq>{"\\text{Re}(\\lambda) = -3/2 < 0"}</Eq>.

**Conclusão:** o sistema é **assintoticamente estável** — todas as soluções tendem a 0 quando <Eq>{"t \\to \\infty"}</Eq>. As soluções oscilam (parte imaginária) e decaem exponencialmente (parte real negativa).
</Exemplo>

# Autovalores: Teoria Espectral

## Espectro e Resolução

**Definição.** O **espectro** de <Eq>{"A \\in M_{n\\times n}(\\mathbb{C})"}</Eq> é <Eq>{"\\sigma(A) = \\{\\lambda \\in \\mathbb{C}: \\det(A-\\lambda I) = 0\\}"}</Eq>.

O **resolvente** é a função <Eq>{"R_A(\\lambda) = (A-\\lambda I)^{-1}"}</Eq>, definida para <Eq>{"\\lambda \\notin \\sigma(A)"}</Eq>. É holomorfa em <Eq>{"\\mathbb{C}\\setminus\\sigma(A)"}</Eq> com polos nos autovalores (de ordem = multiplicidade).

**Integral espectral (Dunford):** <Eq>{"f(A) = \\frac{1}{2\\pi i}\\oint_C f(\\lambda)R_A(\\lambda)\\,d\\lambda"}</Eq> para <Eq>{"C"}</Eq> envolvendo <Eq>{"\\sigma(A)"}</Eq>. Isso define o **cálculo funcional** — como <Eq>{"e^A"}</Eq>, <Eq>{"\\ln A"}</Eq>, <Eq>{"A^{1/2}"}</Eq>.

## Conexão com Análise Complexa

Os autovalores de <Eq>{"A"}</Eq> são exatamente os polos de <Eq>{"\\text{tr}(R_A(\\lambda)) = \\sum_k(\\lambda_k - \\lambda)^{-1}"}</Eq>. A soma dos resíduos em todos os polos = <Eq>{"n"}</Eq> (dimensão do espaço).

O **polinômio característico** é <Eq>{"p_A(\\lambda) = \\det(A-\\lambda I)"}</Eq>, e a identidade de Liouville diz que <Eq>{"\\det(A-\\lambda I)"}</Eq> é um polinômio de grau exato <Eq>{"n"}</Eq> em <Eq>{"\\lambda"}</Eq>.
