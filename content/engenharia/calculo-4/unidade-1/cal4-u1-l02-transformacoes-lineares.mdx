# Funções que Respeitam a Estrutura Vetorial

Uma **transformação linear** é uma função entre espaços vetoriais que respeita as operações: a imagem da soma é a soma das imagens, e a imagem do escalar é o escalar da imagem.

Toda matriz <Eq>{"A"}</Eq> de dimensão <Eq>{"m \\times n"}</Eq> define uma transformação linear <Eq>{"T(x) = Ax"}</Eq> de <Eq>{"\\mathbb{R}^n"}</Eq> para <Eq>{"\\mathbb{R}^m"}</Eq>. E toda transformação linear entre espaços de dimensão finita pode ser representada por uma matriz!

</Porta>

# Transformações Lineares

Uma função <Eq>{"T: V \\to W"}</Eq> é **linear** se:
- <Eq>{"T(u+v) = T(u)+T(v)"}</Eq> para todos <Eq>{"u,v \\in V"}</Eq>
- <Eq>{"T(\\alpha v) = \\alpha T(v)"}</Eq> para todo <Eq>{"\\alpha \\in \\mathbb{F}"}</Eq>, <Eq>{"v \\in V"}</Eq>

**Equivalentemente:** <Eq>{"T(\\alpha u + \\beta v) = \\alpha T(u) + \\beta T(v)"}</Eq>.

**Consequência:** <Eq>{"T(0) = 0"}</Eq> sempre.

**Núcleo:** <Eq>{"\\ker T = \\{v \\in V: T(v) = 0\\}"}</Eq> — subespaço de <Eq>{"V"}</Eq>

**Imagem:** <Eq>{"\\text{Im}\\,T = \\{T(v): v \\in V\\}"}</Eq> — subespaço de <Eq>{"W"}</Eq>

**Teorema do Posto-Nulidade:** <Eq>{"\\dim(\\ker T) + \\dim(\\text{Im}\\,T) = \\dim V"}</Eq>

</Porta>

# Transformações Lineares e Representação Matricial

## Caracterização e Propriedades

Uma transformação linear é completamente determinada pelos valores em uma base:

**Teorema.** Dado uma base <Eq>{"\\{b_1,\\ldots,b_n\\}"}</Eq> de <Eq>{"V"}</Eq> e vetores quaisquer <Eq>{"w_1,\\ldots,w_n \\in W"}</Eq>, existe única <Eq>{"T: V \\to W"}</Eq> linear com <Eq>{"T(b_i) = w_i"}</Eq>.

**Composição de lineares é linear.** O conjunto de todas as transformações lineares <Eq>{"T: V \\to W"}</Eq> forma um espaço vetorial <Eq>{"\\mathcal{L}(V,W)"}</Eq> com <Eq>{"\\dim \\mathcal{L}(V,W) = \\dim V \\cdot \\dim W"}</Eq>.

## Representação Matricial

Dadas bases <Eq>{"\\mathcal{B} = \\{b_1,\\ldots,b_n\\}"}</Eq> de <Eq>{"V"}</Eq> e <Eq>{"\\mathcal{C} = \\{c_1,\\ldots,c_m\\}"}</Eq> de <Eq>{"W"}</Eq>, a **matriz de** <Eq>{"T"}</Eq> **em relação a** <Eq>{"\\mathcal{B}"}</Eq> **e** <Eq>{"\\mathcal{C}"}</Eq> é <Eq>{"[T]_{\\mathcal{B}}^{\\mathcal{C}} = M \\in M_{m\\times n}"}</Eq> cujas colunas são as coordenadas de <Eq>{"T(b_j)"}</Eq> na base <Eq>{"\\mathcal{C}"}</Eq>:

<EquacaoCanonica
  formula="[T]_\mathcal{B}^\mathcal{C} = \bigl[[T(b_1)]_\mathcal{C} \;\big|\; [T(b_2)]_\mathcal{C} \;\big|\; \cdots \;\big|\; [T(b_n)]_\mathcal{C}\bigr]"
  legenda={<>Matriz da transformação: colunas = coordenadas das imagens dos vetores da base</>}
  audioTexto="A matriz da transformação T tem como colunas as coordenadas de T de b1, T de b2, ..., T de bn na base C."
/>

**Composição:** <Eq>{"[S \\circ T]_\\mathcal{B}^\\mathcal{E} = [S]_\\mathcal{C}^\\mathcal{E}\\cdot[T]_\\mathcal{B}^\\mathcal{C}"}</Eq>.

## Mudança de Base

A **matriz de mudança de base** de <Eq>{"\\mathcal{B}"}</Eq> para <Eq>{"\\mathcal{C}"}</Eq> é <Eq>{"P = [I]_\\mathcal{B}^\\mathcal{C}"}</Eq> (colunas = coordenadas de <Eq>{"b_i"}</Eq> na base <Eq>{"\\mathcal{C}"}</Eq>).

Se <Eq>{"M = [T]_\\mathcal{B}^\\mathcal{B}"}</Eq> e <Eq>{"M' = [T]_\\mathcal{C}^\\mathcal{C}"}</Eq>, então:
<Eq>{"M' = P^{-1}MP"}</Eq>

Matrizes relacionadas por similaridade (<Eq>{"M' = P^{-1}MP"}</Eq>) representam a **mesma** transformação linear em bases diferentes.

## Tipos Especiais de Transformações

| Tipo | Condição | Consequência |
|------|----------|-------------|
| Injetora (1-1) | <Eq>{"\\ker T = \\{0\\}"}</Eq> | posto = <Eq>{"n"}</Eq> |
| Sobrejetora (onto) | <Eq>{"\\text{Im}\\,T = W"}</Eq> | nulidade = 0 (se <Eq>{"\\dim V = \\dim W"}</Eq>) |
| Isomorfismo | injetora + sobrejetora | <Eq>{"\\dim V = \\dim W"}</Eq> |
| Endomorfismo | <Eq>{"V = W"}</Eq> | matriz quadrada |
| Automorphismo | isomorfismo + <Eq>{"V=W"}</Eq> | matriz invertível |

# Transformações Lineares — Teoria Avançada

## Teorema do Posto-Nulidade: Prova

**Prova.** Seja <Eq>{"\\{u_1,\\ldots,u_k\\}"}</Eq> base de <Eq>{"\\ker T"}</Eq> e estenda a uma base <Eq>{"\\{u_1,\\ldots,u_k,v_1,\\ldots,v_r\\}"}</Eq> de <Eq>{"V"}</Eq> (<Eq>{"k+r = n"}</Eq>). Afirmamos que <Eq>{"\\{T(v_1),\\ldots,T(v_r)\\}"}</Eq> é base de <Eq>{"\\text{Im}\\,T"}</Eq>.

*Geração:* dado <Eq>{"T(v) \\in \\text{Im}\\,T"}</Eq>, escreva <Eq>{"v = \\sum\\alpha_i u_i + \\sum\\beta_j v_j"}</Eq>, logo <Eq>{"T(v) = \\sum\\beta_j T(v_j)"}</Eq>.

*LI:* se <Eq>{"\\sum\\beta_j T(v_j) = 0"}</Eq>, então <Eq>{"T(\\sum\\beta_j v_j) = 0"}</Eq>, logo <Eq>{"\\sum\\beta_j v_j \\in \\ker T"}</Eq>, portanto <Eq>{"\\sum\\beta_j v_j = \\sum\\gamma_i u_i"}</Eq>. Como a coleção toda é LI, <Eq>{"\\beta_j = 0"}</Eq> para todo <Eq>{"j"}</Eq>. <Eq>{"\\square"}</Eq>

## Álgebra de Endomorfismos

<Eq>{"\\mathcal{L}(V,V) = \\text{End}(V)"}</Eq> é uma **álgebra associativa** (com multiplicação = composição). O grupo dos automorfismos <Eq>{"\\text{Aut}(V) = \\text{GL}(V)"}</Eq> é o grupo de todas as transformações invertíveis.

Para <Eq>{"\\dim V = n"}</Eq>: <Eq>{"\\text{End}(V) \\cong M_{n\\times n}(\\mathbb{F})"}</Eq> e <Eq>{"\\text{GL}(V) \\cong \\text{GL}(n,\\mathbb{F})"}</Eq>.

## Exemplos Resolvidos

<Exemplo
  numero={1}
  titulo="Transformação Diferenciação e sua Matriz"
  fonte="Lay, D.C. Álgebra Linear e suas Aplicações, LTC, 5ª ed., §4.7, Exemplo 3"
>
**Seja** <Eq>{"D: \\mathcal{P}_3 \\to \\mathcal{P}_2"}</Eq> **a derivação** <Eq>{"D(p) = p'"}</Eq>**. Encontre a matriz de** <Eq>{"D"}</Eq> **nas bases canônicas** <Eq>{"\\{1,t,t^2,t^3\\}"}</Eq> **e** <Eq>{"\\{1,t,t^2\\}"}</Eq>.

**Resolução:**

Calcule as imagens da base de domínio:
- <Eq>{"D(1) = 0 = 0\\cdot 1 + 0\\cdot t + 0\\cdot t^2"}</Eq>
- <Eq>{"D(t) = 1 = 1\\cdot 1 + 0\\cdot t + 0\\cdot t^2"}</Eq>
- <Eq>{"D(t^2) = 2t = 0\\cdot 1 + 2\\cdot t + 0\\cdot t^2"}</Eq>
- <Eq>{"D(t^3) = 3t^2 = 0\\cdot 1 + 0\\cdot t + 3\\cdot t^2"}</Eq>

Matriz (colunas = coordenadas das imagens):
<Eq>{"[D] = \\begin{pmatrix}0&1&0&0\\\\0&0&2&0\\\\0&0&0&3\\end{pmatrix}"}</Eq>

**Aplicação:** <Eq>{"D(2+3t-t^3)"}</Eq>. Coordenadas de <Eq>{"2+3t-t^3"}</Eq> na base de <Eq>{"\\mathcal{P}_3"}</Eq>: <Eq>{"(2,3,0,-1)^T"}</Eq>.

<Eq>{"[D](2,3,0,-1)^T = (3,0,-3)^T"}</Eq>, portanto <Eq>{"D(2+3t-t^3) = 3-3t^2"}</Eq> $\checkmark$
</Exemplo>

<Exemplo
  numero={2}
  titulo="Mudança de Base"
  fonte="Strang, G. Linear Algebra and Its Applications, Cengage, 4ª ed., §5.3, Exemplo 2"
>
**Seja** <Eq>{"T: \\mathbb{R}^2 \\to \\mathbb{R}^2"}</Eq> **a reflexão em relação ao eixo** <Eq>{"x"}</Eq>**. Sua matriz na base canônica é** <Eq>{"M = \\begin{pmatrix}1&0\\\\0&-1\\end{pmatrix}"}</Eq>**. Encontre a matriz de** <Eq>{"T"}</Eq> **na base** <Eq>{"\\mathcal{B} = \\{(1,1)^T, (1,-1)^T\\}"}</Eq>.

**Resolução:**

Matriz de mudança de base: <Eq>{"P = \\begin{pmatrix}1&1\\\\1&-1\\end{pmatrix}"}</Eq>, <Eq>{"P^{-1} = \\frac{1}{2}\\begin{pmatrix}1&1\\\\1&-1\\end{pmatrix}"}</Eq>.

<Eq>{"[T]_\\mathcal{B}^\\mathcal{B} = P^{-1}MP = \\frac{1}{2}\\begin{pmatrix}1&1\\\\1&-1\\end{pmatrix}\\begin{pmatrix}1&0\\\\0&-1\\end{pmatrix}\\begin{pmatrix}1&1\\\\1&-1\\end{pmatrix}"}</Eq>

<Eq>{"= \\frac{1}{2}\\begin{pmatrix}1&-1\\\\1&1\\end{pmatrix}\\begin{pmatrix}1&1\\\\1&-1\\end{pmatrix} = \\begin{pmatrix}0&1\\\\1&0\\end{pmatrix}"}</Eq>

**Interpretação:** na base <Eq>{"\\mathcal{B}"}</Eq>, a reflexão troca os dois vetores da base — matrix é a permutação <Eq>{"\\begin{pmatrix}0&1\\\\1&0\\end{pmatrix}"}</Eq>, muito mais simples!
</Exemplo>

<Exemplo
  numero={3}
  titulo="Forma de Jordan (Introdução)"
  fonte="Lay, D.C. Álgebra Linear e suas Aplicações, LTC, 5ª ed., §5.4, Exemplo 5; Axler, S. Linear Algebra Done Right, Springer, §8.A"
>
**Seja** <Eq>{"T: \\mathbb{R}^3 \\to \\mathbb{R}^3"}</Eq> **com matriz** <Eq>{"A = \\begin{pmatrix}2&1&0\\\\0&2&1\\\\0&0&2\\end{pmatrix}"}</Eq>**. Mostre que** <Eq>{"A"}</Eq> **não é diagonalizável e encontre uma base de Jordan.**

**Resolução:**

O único autovalor é <Eq>{"\\lambda = 2"}</Eq> (multiplicidade algébrica 3). <Eq>{"\\ker(A-2I) = \\text{span}\\{e_1\\}"}</Eq> (multiplicidade geométrica 1).

Como a multiplicidade geométrica < algébrica, <Eq>{"A"}</Eq> não é diagonalizável.

Para a forma de Jordan, use **vetores generalizados**:
- <Eq>{"v_1 = e_1 = (1,0,0)^T"}</Eq>: <Eq>{"(A-2I)v_1 = 0"}</Eq>
- <Eq>{"v_2"}</Eq> tal que <Eq>{"(A-2I)v_2 = v_1"}</Eq>: <Eq>{"v_2 = e_2 = (0,1,0)^T"}</Eq>
- <Eq>{"v_3"}</Eq> tal que <Eq>{"(A-2I)v_3 = v_2"}</Eq>: <Eq>{"v_3 = e_3 = (0,0,1)^T"}</Eq>

Na base <Eq>{"\\{v_1,v_2,v_3\\}"}</Eq> (que é a base canônica aqui), a forma de Jordan é a própria <Eq>{"A"}</Eq>.
</Exemplo>

# Transformações Lineares: Teoria Formal

## Categoria dos Espaços Vetoriais

Os espaços vetoriais sobre <Eq>{"\\mathbb{F}"}</Eq> e as transformações lineares entre eles formam uma **categoria** <Eq>{"\\mathbf{Vect}_\\mathbb{F}"}</Eq>, com composição de morfismos dada pela composição de funções.

Esta categoria é **abeliana**: todo morfismo tem núcleo e conúcleo, a sequência exata curta <Eq>{"0 \\to \\ker T \\to V \\to \\text{Im}\\,T \\to 0"}</Eq> divide.

## Dualidade e Funtor Contravariante

O funtor dual <Eq>{"(-)^*: \\mathbf{Vect}_\\mathbb{F}^{op} \\to \\mathbf{Vect}_\\mathbb{F}"}</Eq> associa a <Eq>{"T: V \\to W"}</Eq> o **transposto** <Eq>{"T^*: W^* \\to V^*"}</Eq>, <Eq>{"T^*(\\varphi) = \\varphi \\circ T"}</Eq>.

**Propriedades:** <Eq>{"\\ker T^* = (\\text{Im}\\,T)^\\perp"}</Eq>, <Eq>{"\\text{Im}\\,T^* = (\\ker T)^\\perp"}</Eq> (em dimensão finita, com dualidade natural).

## Teorema de Estrutura para Endomorfismos

**Teorema (Decomposição de Jordan).** Sobre <Eq>{"\\mathbb{C}"}</Eq>, todo endomorfismo <Eq>{"T \\in \\text{End}(V)"}</Eq> de dimensão finita é similar (na mesma base complexa) a uma matriz em forma normal de Jordan:
<Eq>{"J = \\text{diag}(J_{n_1}(\\lambda_1), J_{n_2}(\\lambda_2), \\ldots)"}</Eq>
onde <Eq>{"J_n(\\lambda)"}</Eq> é o bloco de Jordan <Eq>{"n \\times n"}</Eq> com autovalor <Eq>{"\\lambda"}</Eq>. A forma de Jordan é única a menos de ordem dos blocos.
