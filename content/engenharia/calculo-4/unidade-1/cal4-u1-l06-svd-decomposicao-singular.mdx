# A Decomposição que Revela a Estrutura de Qualquer Matriz

Qualquer matriz — mesmo retangular, mesmo de posto baixo — pode ser fatorada como <Eq>{"A = U\\Sigma V^T"}</Eq>: uma rotação, seguida de uma escala, seguida de outra rotação.

Os valores de escala (<Eq>{"\\sigma_i"}</Eq>) revelam a "força" de cada direção transformada. Essa é a decomposição mais poderosa da álgebra linear!

</Porta>

# SVD — Decomposição em Valores Singulares

**Teorema SVD:** Para qualquer <Eq>{"A \\in M_{m\\times n}(\\mathbb{R})"}</Eq>, existem matrizes ortogonais <Eq>{"U \\in M_{m\\times m}"}</Eq>, <Eq>{"V \\in M_{n\\times n}"}</Eq> e <Eq>{"\\Sigma \\in M_{m\\times n}"}</Eq> (diagonal não-negativa) tais que:

<Eq>{"A = U\\Sigma V^T"}</Eq>

**Valores singulares:** <Eq>{"\\sigma_1 \\geq \\sigma_2 \\geq \\cdots \\geq \\sigma_r > 0 = \\sigma_{r+1} = \\cdots"}</Eq> onde <Eq>{"r = \\text{posto}(A)"}</Eq>.

**Relação com autovalores:** <Eq>{"\\sigma_i = \\sqrt{\\lambda_i(A^TA)}"}</Eq>.

**Aplicações:** compressão de imagens, PCA, mínimos quadrados, pseudoinversa.

</Porta>
<Porta nivel="15anos">

# Decomposição em Valores Singulares (SVD)

## Existência e Construção

**Teorema (SVD):** Para <Eq>{"A \\in M_{m\\times n}(\\mathbb{R})"}</Eq> com posto <Eq>{"r"}</Eq>:

<EquacaoCanonica
  formula="A = U\Sigma V^T = \sigma_1 u_1 v_1^T + \sigma_2 u_2 v_2^T + \cdots + \sigma_r u_r v_r^T"
  legenda={<><Eq>{"U"}</Eq>, <Eq>{"V"}</Eq> ortogonais; <Eq>{"\\Sigma = \\text{diag}(\\sigma_1,\\ldots,\\sigma_r,0,\\ldots,0)"}</Eq></>}
  audioTexto="A é igual a U sigma V transposto, que é a soma de sigma i vezes u i vezes v i transposto."
/>

**Construção:**
1. Calcule os autovalores <Eq>{"\\lambda_1 \\geq \\cdots \\geq \\lambda_n \\geq 0"}</Eq> de <Eq>{"A^TA"}</Eq>
2. <Eq>{"\\sigma_i = \\sqrt{\\lambda_i}"}</Eq>; colunas de <Eq>{"V"}</Eq> = autovetores ortonormais de <Eq>{"A^TA"}</Eq>
3. Para <Eq>{"i \\leq r"}</Eq>: <Eq>{"u_i = Av_i/\\sigma_i"}</Eq>; complete <Eq>{"U"}</Eq> com base ortonormal de <Eq>{"\\ker A^T"}</Eq>

## Interpretação Geométrica

<Eq>{"A"}</Eq> mapeia a esfera unitária em <Eq>{"\\mathbb{R}^n"}</Eq> num **elipsoide** em <Eq>{"\\mathbb{R}^m"}</Eq>:
- Os semi-eixos têm comprimentos <Eq>{"\\sigma_1,\\ldots,\\sigma_r"}</Eq>
- As direções dos semi-eixos são <Eq>{"u_1,\\ldots,u_r"}</Eq>
- As direções "pré-imagem" são <Eq>{"v_1,\\ldots,v_r"}</Eq>

## Normas Matriciais via SVD

- **Norma espectral (2):** <Eq>{"\\|A\\|_2 = \\sigma_1"}</Eq>
- **Norma de Frobenius:** <Eq>{"\\|A\\|_F = \\sqrt{\\sum_{i,j}a_{ij}^2} = \\sqrt{\\sigma_1^2+\\cdots+\\sigma_r^2}"}</Eq>
- **Norma nuclear:** <Eq>{"\\|A\\|_* = \\sigma_1+\\cdots+\\sigma_r"}</Eq>

## Pseudoinversa de Moore-Penrose

A **pseudoinversa** <Eq>{"A^+"}</Eq> é definida por:
<Eq>{"A^+ = V\\Sigma^+U^T"}</Eq>
onde <Eq>{"\\Sigma^+ = \\text{diag}(1/\\sigma_1,\\ldots,1/\\sigma_r,0,\\ldots,0)"}</Eq>.

**Propriedades:** <Eq>{"AA^+A = A"}</Eq>, <Eq>{"A^+AA^+ = A^+"}</Eq>, <Eq>{"(AA^+)^T = AA^+"}</Eq>, <Eq>{"(A^+A)^T = A^+A"}</Eq> (4 equações de Moore-Penrose).

**Solução de mínimos quadrados:** a solução de norma mínima de <Eq>{"\\min\\|Ax-b\\|"}</Eq> é <Eq>{"x^+ = A^+b"}</Eq>.

## SVD Truncada — Compressão

A **melhor aproximação de posto** <Eq>{"k"}</Eq> de <Eq>{"A"}</Eq> (em norma Frobenius ou espectral) é:
<Eq>{"A_k = \\sum_{i=1}^k \\sigma_i u_i v_i^T"}</Eq>

**Teorema de Eckart-Young:** <Eq>{"\\min_{\\text{posto}(B)\\leq k}\\|A-B\\|_2 = \\sigma_{k+1}"}</Eq> e a solução é exatamente <Eq>{"A_k"}</Eq>.

# SVD — Análise Avançada

## SVD Generalizada (GSVD)

Para duas matrizes <Eq>{"A \\in M_{m\\times n}"}</Eq>, <Eq>{"B \\in M_{p\\times n}"}</Eq>, a GSVD decompõe simultaneamente:
<Eq>{"A = U\\Sigma_A X^{-T}, \\quad B = V\\Sigma_B X^{-T}"}</Eq>
com <Eq>{"\\Sigma_A^T\\Sigma_A + \\Sigma_B^T\\Sigma_B = I"}</Eq> Útil em problemas de regularização (Tikhonov).

## PCA e SVD

**Análise de Componentes Principais (PCA):** dada matriz de dados <Eq>{"X \\in M_{m\\times n}"}</Eq> (centrada), as **componentes principais** são os vetores singulares à direita <Eq>{"v_i"}</Eq> de <Eq>{"X"}</Eq>, e a variância explicada pela <Eq>{"i"}</Eq>-ésima componente é <Eq>{"\\sigma_i^2/(m-1)"}</Eq>.

**Redução de dimensionalidade:** projetar em <Eq>{"\\{v_1,\\ldots,v_k\\}"}</Eq> captura <Eq>{"\\frac{\\sigma_1^2+\\cdots+\\sigma_k^2}{\\sigma_1^2+\\cdots+\\sigma_r^2}"}</Eq> da variância total.

## Exemplos Resolvidos

<Exemplo
  numero={1}
  titulo="SVD de Matriz 2×2"
  fonte="Strang, G. Linear Algebra and Its Applications, Cengage, 4ª ed., §6.7, Exemplo 3"
>
**Calcule a SVD de** <Eq>{"A = \\begin{pmatrix}3&1\\\\1&3\\end{pmatrix}"}</Eq>.

**Resolução:**

<Eq>{"A^TA = A^2 = \\begin{pmatrix}10&6\\\\6&10\\end{pmatrix}"}</Eq> (pois <Eq>{"A"}</Eq> é simétrica, <Eq>{"A^TA = A^2"}</Eq>).

Autovalores de <Eq>{"A^TA"}</Eq>: <Eq>{"\\lambda_1 = 16, \\lambda_2 = 4"}</Eq>. Valores singulares: <Eq>{"\\sigma_1 = 4, \\sigma_2 = 2"}</Eq>.

Autovetores de <Eq>{"A^TA"}</Eq>: <Eq>{"v_1 = (1,1)^T/\\sqrt{2}"}</Eq>, <Eq>{"v_2 = (1,-1)^T/\\sqrt{2}"}</Eq>.

Vetores singulares esquerdos: <Eq>{"u_i = Av_i/\\sigma_i"}</Eq>:
<Eq>{"u_1 = \frac{1}{4}\\begin{pmatrix}3&1\\\\1&3\\end{pmatrix}\\frac{1}{\\sqrt{2}}\\begin{pmatrix}1\\\\1\\end{pmatrix} = \\frac{1}{\\sqrt{2}}\\begin{pmatrix}1\\\\1\\end{pmatrix}"}</Eq>

<Eq>{"u_2 = \\frac{1}{2}\\begin{pmatrix}3&1\\\\1&3\\end{pmatrix}\\frac{1}{\\sqrt{2}}\\begin{pmatrix}1\\\\-1\\end{pmatrix} = \\frac{1}{\\sqrt{2}}\\begin{pmatrix}1\\\\-1\\end{pmatrix}"}</Eq>

Neste caso <Eq>{"U = V"}</Eq> (pois <Eq>{"A"}</Eq> é simétrica positiva definida). Resultado: <Eq>{"A = U\\text{diag}(4,2)U^T"}</Eq> = diagonalização ortogonal!
</Exemplo>

<Exemplo
  numero={2}
  titulo="Pseudoinversa e Mínimos Quadrados"
  fonte="Strang, G. Linear Algebra and Its Applications, Cengage, 4ª ed., §4.4 e §6.7"
>
**Use a SVD para resolver o sistema de mínimos quadrados** <Eq>{"Ax = b"}</Eq> **com** <Eq>{"A = \\begin{pmatrix}1&1\\\\1&0\\\\0&1\\end{pmatrix}"}</Eq>, <Eq>{"b = (1,2,1)^T"}</Eq>.

**Resolução:**

<Eq>{"A^TA = \\begin{pmatrix}2&1\\\\1&2\\end{pmatrix}"}</Eq>, autovalores <Eq>{"\\lambda_1=3, \\lambda_2=1"}</Eq>, <Eq>{"\\sigma_1=\\sqrt{3}, \\sigma_2=1"}</Eq>.

Autovetores: <Eq>{"v_1=(1,1)^T/\\sqrt{2}"}</Eq>, <Eq>{"v_2=(1,-1)^T/\\sqrt{2}"}</Eq>.

<Eq>{"u_1 = Av_1/\\sigma_1 = \\frac{1}{\\sqrt{6}}(2,1,1)^T"}</Eq>, <Eq>{"u_2 = Av_2/\\sigma_2 = \\frac{1}{\\sqrt{2}}(0,1,-1)^T"}</Eq>.

Complete <Eq>{"U"}</Eq> com <Eq>{"u_3 = (1,-2,-1)^T/\\sqrt{6}"}</Eq> (ortogonal a <Eq>{"u_1,u_2"}</Eq>).

Pseudoinversa: <Eq>{"x^+ = A^+b = V\\Sigma^+U^Tb"}</Eq>

<Eq>{"U^Tb = (\\langle b,u_1\\rangle, \\langle b,u_2\\rangle, \\langle b,u_3\\rangle)^T = (4/\\sqrt{6}, -1/\\sqrt{2}, -4/\\sqrt{6})^T"}</Eq>

<Eq>{"\\Sigma^+U^Tb = (4/(\\sqrt{6}\\sqrt{3}), -1/\\sqrt{2}, 0)^T = (4/\\sqrt{18}, -1/\\sqrt{2}, 0)^T"}</Eq>

<Eq>{"x^+ = V\\Sigma^+U^Tb = \\frac{1}{3}(3,1)^T = (1,1/3)^T"}</Eq> aproximadamente — a solução de mínimos quadrados de norma mínima.
</Exemplo>

<Exemplo
  numero={3}
  titulo="Compressão de Imagem via SVD Truncada"
  fonte="Horn & Johnson. Matrix Analysis, Cambridge, 2ª ed., §2.6; Strang, G. Linear Algebra, §6.7"
>
**Uma imagem em tons de cinza** <Eq>{"100\\times100"}</Eq> **é representada por** <Eq>{"A \\in M_{100\\times 100}"}</Eq>**. Se os 10 maiores valores singulares somam 90% do total** <Eq>{"\\|A\\|_F^2"}</Eq>**, qual a taxa de compressão da SVD truncada de posto 10?**

**Resolução:**

**Dados armazenados originalmente:** <Eq>{"100 \\times 100 = 10000"}</Eq> valores.

**SVD truncada de posto 10:** armazenar <Eq>{"U_k"}</Eq> (<Eq>{"100\\times 10"}</Eq>), <Eq>{"\\Sigma_k"}</Eq> (<Eq>{"10"}</Eq> valores), <Eq>{"V_k"}</Eq> (<Eq>{"100\\times 10"}</Eq>).

**Total armazenado:** <Eq>{"100\\cdot10 + 10 + 100\\cdot10 = 2010"}</Eq> valores.

**Taxa de compressão:** <Eq>{"10000/2010 \\approx 4.98"}</Eq>: menos de 1/5 dos dados!

**Erro:** pelo Eckart-Young, <Eq>{"\\|A-A_{10}\\|_F^2 = \\sum_{i=11}^{100}\\sigma_i^2 = 10\\% \\cdot \\|A\\|_F^2"}</Eq>.

**Interpretação:** com apenas 20% dos dados, reconstruímos 90% da "energia" da imagem.
</Exemplo>

# SVD: Teoria e Aplicações Avançadas

## Existência da SVD

**Teorema.** Para qualquer <Eq>{"A \\in M_{m\\times n}(\\mathbb{R})"}</Eq>, existem matrizes <Eq>{"U \\in M_{m\\times m}"}</Eq> ortogonal, <Eq>{"V \\in M_{n\\times n}"}</Eq> ortogonal, e <Eq>{"\\Sigma \\in M_{m\\times n}"}</Eq> com entradas não-negativas somente na diagonal principal (<Eq>{"\\sigma_1 \\geq \\cdots \\geq \\sigma_{\\min(m,n)} \\geq 0"}</Eq>) tais que <Eq>{"A = U\\Sigma V^T"}</Eq>.

**Prova:** <Eq>{"A^TA"}</Eq> é simétrica semi-definida positiva; pelo Teorema Espectral, <Eq>{"A^TA = V\\Lambda V^T"}</Eq> com <Eq>{"\\lambda_i \\geq 0"}</Eq>. Defina <Eq>{"\\sigma_i = \\sqrt{\\lambda_i}"}</Eq> e <Eq>{"u_i = Av_i/\\sigma_i"}</Eq> para <Eq>{"\\sigma_i > 0"}</Eq>; então <Eq>{"\\langle u_i,u_j\\rangle = v_i^TA^TAv_j/\\sigma_i\\sigma_j = \\lambda_j\\delta_{ij}/\\sigma_i\\sigma_j = \\delta_{ij}"}</Eq>. Complete <Eq>{"U"}</Eq> com base de <Eq>{"\\ker A^T"}</Eq>.

## Desigualdade de Von Neumann

Para <Eq>{"A,B \\in M_{n\\times n}"}</Eq>:
<Eq>{"|\\text{tr}(A^TB)| \\leq \\sum_{i=1}^n \\sigma_i(A)\\sigma_i(B)"}</Eq>

com igualdade <Eq>{"\\iff A = UBV"}</Eq> para <Eq>{"U,V"}</Eq> ortogonais. Este é o **Lema de von Neumann** (1937), fundamental em teoria de otimização matricial.
