# Espaços Completos — Onde Toda Sequência que Parece Convergir, Converge

Um espaço métrico é **completo** se toda sequência de Cauchy (pontos que ficam cada vez mais próximos entre si) converge para um ponto dentro do espaço. Um **espaço de Hilbert** é um espaço com produto interno que é completo nessa norma.

Os exemplos mais importantes: o espaço <Eq>{"L^2[a,b]"}</Eq> de funções de quadrado integrável, e o espaço <Eq>{"\\ell^2"}</Eq> de sequências com soma de quadrados finita.

# Espaços de Hilbert

**Definição:** Um **espaço de Hilbert** <Eq>{"H"}</Eq> é um espaço vetorial com produto interno <Eq>{"\\langle \\cdot, \\cdot \\rangle"}</Eq> que é **completo** em relação à norma <Eq>{"\\|x\\| = \\sqrt{\\langle x, x \\rangle}"}</Eq>.

**Exemplos:**
- <Eq>{"\\mathbb{R}^n"}</Eq> com produto interno euclidiano
- <Eq>{"\\ell^2 = \\{(a_n) : \\sum |a_n|^2 < \\infty\\}"}</Eq> com <Eq>{"\\langle a, b \\rangle = \\sum a_n \\overline{b_n}"}</Eq>
- <Eq>{"L^2[a,b] = \\{f : \\int_a^b |f|^2 < \\infty\\}"}</Eq> com <Eq>{"\\langle f, g \\rangle = \\int_a^b f\\bar{g}"}</Eq>

**Base ortonormal:** sistema <Eq>{"\\{e_k\\}"}</Eq> com <Eq>{"\\langle e_j, e_k \\rangle = \\delta_{jk}"}</Eq> e <Eq>{"\\overline{\\text{span}}\\{e_k\\} = H"}</Eq>.

**Teorema de Riesz-Fischer:** todo espaço de Hilbert separável admite base ortonormal contável, e a série <Eq>{"\\sum c_k e_k"}</Eq> converge se e somente se <Eq>{"\\sum |c_k|^2 < \\infty"}</Eq>.

# Completude e Espaços de Hilbert

## Sequências de Cauchy e Completude

**Definição:** Em um espaço métrico <Eq>{"(X, d)"}</Eq>, uma sequência <Eq>{"(x_n)"}</Eq> é de **Cauchy** se:

<EquacaoCanonica
  formula="\forall \varepsilon > 0,\; \exists N \in \mathbb{N} : m,n > N \implies d(x_m, x_n) < \varepsilon"
  legenda="Critério de Cauchy — convergência sem conhecer o limite a priori"
  audioTexto="Para todo epsilon maior que zero, existe N tal que m e n maiores que N implicam distância menor que epsilon."
/>

**Completude:** X é completo se toda sequência de Cauchy converge em X. Exemplo: <Eq>{"\\mathbb{R}"}</Eq> é completo; <Eq>{"\\mathbb{Q}"}</Eq> não é (<Eq>{"\\sqrt{2}"}</Eq> é limite de Cauchys racionais).

## Espaços de Hilbert

**Definição (Hilbert):** <Eq>{"H"}</Eq> é um espaço de Hilbert se é um espaço com produto interno <Eq>{"\\langle \\cdot, \\cdot \\rangle : H \\times H \\to \\mathbb{K}"}</Eq> completo na norma induzida.

**Identidade do paralelogramo** (caracteriza espaços com produto interno):

<EquacaoCanonica
  formula="\|x + y\|^2 + \|x - y\|^2 = 2(\|x\|^2 + \|y\|^2)"
  legenda="Um espaço normado é de Hilbert sse satisfaz a identidade do paralelogramo"
  audioTexto="Norma de x mais y ao quadrado mais norma de x menos y ao quadrado igual a dois vezes norma de x ao quadrado mais norma de y ao quadrado."
/>

## O Espaço L²[a,b]

**Construção:** Tome as funções mensuráveis <Eq>{"f : [a,b] \\to \\mathbb{C}"}</Eq> com <Eq>{"\\int_a^b |f|^2 \\, dx < \\infty"}</Eq>, identificando funções iguais q.t.p.

<EquacaoCanonica
  formula="L^2[a,b] = \left\{[f] : \int_a^b |f(x)|^2\,dx < \infty\right\}, \quad \langle f,g\rangle = \int_a^b f(x)\overline{g(x)}\,dx"
  legenda="[f] denota a classe de equivalência de funções iguais quase em toda parte"
  audioTexto="L dois de a a b é o espaço de funções com integral do quadrado finita, com produto interno dado pela integral de f g barra."
/>

**Teorema de Riesz-Fischer:** <Eq>{"L^2[a,b]"}</Eq> é completo. (Prova usa o critério: série de funções com somas parciais de norma limitada converge q.t.p. e em <Eq>{"L^2"}</Eq>.)

</Porta>

# Bases Ortonormais em Espaços de Hilbert

## Sistemas Ortonormais e Projeções

**Definição:** Um sistema <Eq>{"\\{e_k\\}_{k \\in J}"}</Eq> em <Eq>{"H"}</Eq> é **ortonormal** se <Eq>{"\\langle e_j, e_k \\rangle = \\delta_{jk}"}</Eq>.

**Desigualdade de Bessel:** Para qualquer <Eq>{"x \\in H"}</Eq> e sistema ortonormal finito ou contável <Eq>{"\\{e_k\\}"}</Eq>:

<EquacaoCanonica
  formula="\sum_{k=1}^{\infty} |\langle x, e_k\rangle|^2 \leq \|x\|^2"
  legenda="Os coeficientes de Fourier generalizados de x satisfazem esta desigualdade"
  audioTexto="Soma dos quadrados dos coeficientes de Fourier é menor ou igual ao quadrado da norma de x."
/>

**Prova:** Seja <Eq>{"S_n = \\sum_{k=1}^n \\langle x, e_k \\rangle e_k"}</Eq>. Então:

<Eq>{"0 \\leq \\|x - S_n\\|^2 = \\|x\\|^2 - \\sum_{k=1}^n |\\langle x, e_k \\rangle|^2"}</Eq>

Logo <Eq>{"\\sum_{k=1}^n |\\langle x, e_k \\rangle|^2 \\leq \\|x\\|^2"}</Eq> para todo <Eq>{"n"}</Eq>, e passa-se ao limite.

## Base Ortonormal e Isomorfismo com ℓ²

**Definição (base):** <Eq>{"\\{e_k\\}"}</Eq> é **base ortonormal** (= sistema ortonormal completo) se:
1. <Eq>{"\\langle e_j, e_k \\rangle = \\delta_{jk}"}</Eq> (ortonormalidade)
2. <Eq>{"\\langle x, e_k \\rangle = 0 \\; \\forall k \\implies x = 0"}</Eq> (completude)

**Equivalências:** As seguintes condições são equivalentes:
- <Eq>{"\\{e_k\\}"}</Eq> é base ortonormal
- <Eq>{"\\overline{\\text{span}}\\{e_k\\} = H"}</Eq>
- <Eq>{"x = \\sum_{k} \\langle x, e_k \\rangle e_k"}</Eq> (série convergente em <Eq>{"H"}</Eq>) para todo <Eq>{"x"}</Eq>
- **Identidade de Parseval:** <Eq>{"\\|x\\|^2 = \\sum_k |\\langle x, e_k \\rangle|^2"}</Eq>

<EquacaoCanonica
  formula="\|x\|^2 = \sum_{k=1}^{\infty} |\langle x, e_k \rangle|^2"
  legenda="Parseval — a norma é preservada ao passar para coordenadas de Fourier"
  audioTexto="Norma de x ao quadrado igual à soma dos quadrados dos coeficientes de Fourier."
/>

**Teorema de Riesz-Fischer (versão geral):** O mapa <Eq>{"U : H \\to \\ell^2"}</Eq> dado por <Eq>{"Ux = (\\langle x, e_k \\rangle)_{k \\geq 1}"}</Eq> é uma **isometria bijetiva** (isomorfismo de espaços de Hilbert). Portanto todo espaço de Hilbert separável é isometricamente isomorfo a <Eq>{"\\ell^2"}</Eq>.

## Base de Fourier em L²[-π,π]

O sistema <Eq>{"\\{\\frac{1}{\\sqrt{2\\pi}} e^{inx}\\}_{n \\in \\mathbb{Z}}"}</Eq> é base ortonormal de <Eq>{"L^2[-\\pi, \\pi]"}</Eq>.

Para <Eq>{"f \\in L^2[-\\pi, \\pi]"}</Eq>, os **coeficientes de Fourier** são:

<EquacaoCanonica
  formula="c_n = \langle f, e^{in\cdot}\rangle_{L^2} = \frac{1}{2\pi}\int_{-\pi}^{\pi} f(x)e^{-inx}\,dx"
  legenda="Coeficiente de Fourier complexo — projeção sobre e^{inx}/√(2π)"
  audioTexto="c n é o produto interno de f com e elevado a in x, dado pela integral de f vezes e elevado a menos inx dividido por dois pi."
/>

e <Eq>{"\\|f\\|_{L^2}^2 = 2\\pi \\sum_{n=-\\infty}^{\\infty} |c_n|^2"}</Eq> (Parseval para Fourier).

# Teoria Geral de Espaços de Hilbert

## Projeções Ortogonais e Subespaços Fechados

**Teorema da Projeção:** Seja <Eq>{"M"}</Eq> subespaço fechado de <Eq>{"H"}</Eq>. Para cada <Eq>{"x \\in H"}</Eq>, existe único <Eq>{"m^* \\in M"}</Eq> tal que <Eq>{"\\|x - m^*\\| = \\inf_{m \\in M}\\|x - m\\|"}</Eq>. Além disso, <Eq>{"m^* = P_M x"}</Eq> é linear em <Eq>{"x"}</Eq> e:

<EquacaoCanonica
  formula="H = M \oplus M^\perp, \quad x = P_M x + P_{M^\perp} x"
  legenda="Decomposição ortogonal direta — qualquer Hilbert se decompõe em M e seu complemento"
  audioTexto="H é soma direta de M e M perp, e x se decompõe como projeção em M mais projeção em M perp."
/>

**Corolário:** <Eq>{"M^{\\perp\\perp} = M"}</Eq> para subespaços fechados; e <Eq>{"(M^\\perp)^\\perp = \\overline{M}"}</Eq> em geral.

## Teorema de Representação de Riesz

**Teorema (Riesz-Fréchet):** Para cada funcional linear contínuo <Eq>{"\\phi : H \\to \\mathbb{K}"}</Eq>, existe único <Eq>{"y \\in H"}</Eq> tal que:

<EquacaoCanonica
  formula="\phi(x) = \langle x, y \rangle \quad \forall x \in H, \quad \|\phi\| = \|y\|"
  legenda="Todo funcional contínuo em H é da forma 'produto interno com y'"
  audioTexto="phi de x igual ao produto interno de x com y, para todo x em H."
/>

**Consequência:** <Eq>{"H^* \\cong H"}</Eq> (auto-dual). Isso falha para espaços <Eq>{"L^p"}</Eq> com <Eq>{"p \\neq 2"}</Eq>: <Eq>{"(L^p)^* \\cong L^q"}</Eq> onde <Eq>{"1/p + 1/q = 1"}</Eq>.

## Operadores em Espaços de Hilbert

**Operador Adjunto:** Dado <Eq>{"T : H_1 \\to H_2"}</Eq> linear contínuo, existe único <Eq>{"T^* : H_2 \\to H_1"}</Eq> tal que <Eq>{"\\langle Tx, y\\rangle_{H_2} = \\langle x, T^*y\\rangle_{H_1}"}</Eq>.

**Auto-adjunto:** <Eq>{"T = T^*"}</Eq> (generalização de "matriz simétrica").

**Operador compacto:** <Eq>{"T"}</Eq> é compacto se mapeia bolas limitadas em conjuntos pré-compactos (toda sequência limitada tem subsequência com imagem convergente).

**Teorema Espectral (operadores compactos auto-adjuntos):** Se <Eq>{"T"}</Eq> é compacto e auto-adjunto em <Eq>{"H"}</Eq> separável, então:
- Autovalores <Eq>{"\\{\\lambda_k\\}"}</Eq> são reais e <Eq>{"\\lambda_k \\to 0"}</Eq>
- Autovetores <Eq>{"\\{e_k\\}"}</Eq> formam base ortonormal de <Eq>{"\\overline{\\text{Im}(T)}"}</Eq>
- <Eq>{"T = \\sum_k \\lambda_k \\langle \\cdot, e_k \\rangle e_k"}</Eq> (série convergente em norma operatorial)

**Referência:** Kreyszig, *Introductory Functional Analysis with Applications*, §9.

## Espaços de Sobolev H^k

Para aplicações em EDPs, os **espaços de Sobolev** são subconjuntos de <Eq>{"L^2"}</Eq>:

<EquacaoCanonica
  formula="H^k(\Omega) = \{u \in L^2(\Omega) : D^\alpha u \in L^2(\Omega),\; |\alpha| \leq k\}"
  legenda="Funções com k derivadas fracas em L² — espaço de Hilbert com produto interno natural"
  audioTexto="H k de Omega é o conjunto de funções u em L dois tal que todas as derivadas fracas de ordem até k são também em L dois."
/>

com produto interno <Eq>{"\\langle u, v \\rangle_{H^k} = \\sum_{|\\alpha| \\leq k} \\int_\\Omega D^\\alpha u \\cdot \\overline{D^\\alpha v} \\, dx"}</Eq>.

**Teorema de Sobolev (embedding):** <Eq>{"H^k(\\Omega) \\hookrightarrow C^m(\\Omega)"}</Eq> se <Eq>{"k > m + n/2"}</Eq> (onde <Eq>{"n = \\dim \\Omega"}</Eq>).

# Espaços de Hilbert em Engenharia

## Sinal de Energia Finita — L²

Todo sinal físico de energia finita pertence a <Eq>{"L^2(\\mathbb{R})"}</Eq>: <Eq>{"E = \\int_{-\\infty}^{\\infty} |x(t)|^2 \\, dt < \\infty"}</Eq>.

A **Identidade de Parseval** na forma de Fourier afirma que a energia é preservada:

<Eq>{"\\int_{-\\infty}^{\\infty} |x(t)|^2 \\, dt = \\int_{-\\infty}^{\\infty} |X(f)|^2 \\, df"}</Eq>

Isso justifica a análise espectral de energia e o conceito de **densidade espectral de potência**.

## Decomposição de Fourier e Codificação

**Séries de Fourier em L²[-π,π]:** Todo sinal periódico de energia finita tem expansão:

<Eq>{"f(x) = \\sum_{n=-\\infty}^{\\infty} c_n e^{inx}"}</Eq>

com convergência em norma <Eq>{"L^2"}</Eq> (não necessariamente pontual!). Os coeficientes <Eq>{"c_n"}</Eq> minimizam o erro quadrático médio — isso é compressão ótima em <Eq>{"L^2"}</Eq>.

**Código Python — verificar Parseval discreto:**
```python
import numpy as np

N = 64
x = np.random.randn(N)  # sinal aleatório
X = np.fft.fft(x)       # DFT

energia_tempo = np.sum(np.abs(x)**2)
energia_freq  = np.sum(np.abs(X)**2) / N  # fator 1/N da DFT

print(f"Energia (tempo): {energia_tempo:.6f}")
print(f"Energia (freq):  {energia_freq:.6f}")
print(f"Diferença relativa: {abs(energia_tempo - energia_freq)/energia_tempo:.2e}")
```

## Filtros Lineares como Operadores em L²

Um filtro linear invariante no tempo com resposta ao impulso <Eq>{"h \\in L^2"}</Eq> define operador:

<Eq>{"(Tx)(t) = (h * x)(t) = \\int_{-\\infty}^{\\infty} h(t-\\tau)x(\\tau)\\,d\\tau"}</Eq>

que é um operador compacto auto-adjunto (se <Eq>{"h"}</Eq> par e real) em <Eq>{"L^2"}</Eq>. As autofunções são exatamente os exponenciais complexos <Eq>{"e^{i\\omega t}"}</Eq> com autovalores <Eq>{"H(\\omega) = \\hat{h}(\\omega)"}</Eq> (função de transferência).

**Referência:** Kreyszig, *Introductory Functional Analysis with Applications*, §3.1-3.6; Debnath & Mikusinski, *Introduction to Hilbert Spaces*, Cap. 2.

## Exemplo 1 — L²[0,1] e Bessel/Parseval para Fourier Seno

**Base:** <Eq>{"\\{\\sqrt{2}\\sin(n\\pi x)\\}_{n=1}^\\infty"}</Eq> é base ortonormal de <Eq>{"L^2[0,1]"}</Eq>.

**Verificação de ortonormalidade:**

<Eq>{"\\langle \\sqrt{2}\\sin(m\\pi x), \\sqrt{2}\\sin(n\\pi x) \\rangle = 2\\int_0^1 \\sin(m\\pi x)\\sin(n\\pi x)\\,dx = \\delta_{mn}"}</Eq>

(usando <Eq>{"\\int_0^1 \\sin(m\\pi x)\\sin(n\\pi x)\\,dx = \\frac{1}{2}\\delta_{mn}"}</Eq>).

**Coeficientes de <Eq>{"f(x) = x"}</Eq>:**

<Eq>{"c_n = \\langle x, \\sqrt{2}\\sin(n\\pi x) \\rangle = \\sqrt{2}\\int_0^1 x\\sin(n\\pi x)\\,dx = \\sqrt{2} \\cdot \\frac{(-1)^{n+1}}{n\\pi}"}</Eq>

**Parseval:**

<Eq>{"\\|x\\|_{L^2}^2 = \\int_0^1 x^2\\,dx = \\frac{1}{3} = \\sum_{n=1}^\\infty |c_n|^2 = \\sum_{n=1}^\\infty \\frac{2}{n^2\\pi^2} = \\frac{2}{\\pi^2}\\cdot\\frac{\\pi^2}{6} = \\frac{1}{3} \\checkmark"}</Eq>

(usando <Eq>{"\\sum_{n=1}^\\infty \\frac{1}{n^2} = \\frac{\\pi^2}{6}"}</Eq>).

**Referência:** Kreyszig, *Introductory Functional Analysis*, §3.4; Debnath & Mikusinski, *Introduction to Hilbert Spaces*, §3.3.

</Exemplo>

## Exemplo 2 — Completude de ℓ² e Limite de Sequência de Cauchy

**Claim:** A sequência <Eq>{"x^{(n)} = (1, 1/2, \\ldots, 1/n, 0, 0, \\ldots) \\in \\ell^2"}</Eq> é de Cauchy e converge para <Eq>{"x = (1/k)_{k \\geq 1}"}</Eq>.

**Verificação de Cauchy:** Para <Eq>{"m > n"}</Eq>:

<Eq>{"\\|x^{(m)} - x^{(n)}\\|_{\\ell^2}^2 = \\sum_{k=n+1}^m \\frac{1}{k^2} \\leq \\sum_{k=n+1}^\\infty \\frac{1}{k^2} \\to 0 \\text{ quando } n \\to \\infty"}</Eq>

**Limite:** <Eq>{"x = (1, 1/2, 1/3, \\ldots) \\in \\ell^2"}</Eq> pois <Eq>{"\\sum_{k=1}^\\infty 1/k^2 = \\pi^2/6 < \\infty"}</Eq>.

**Contraste:** Em <Eq>{"\\ell^2"}</Eq> a sequência converge; em <Eq>{"c_{00}"}</Eq> (sequências de suporte finito), o limite <Eq>{"(1/k)"}</Eq> não pertence ao espaço — demonstrando que <Eq>{"c_{00}"}</Eq> não é completo.

**Referência:** Kreyszig, *Introductory Functional Analysis*, §3.1; Axler, *Linear Algebra Done Right*, 3ª ed., §6C.

</Exemplo>

## Exemplo 3 — Projeção Ortogonal em L²

**Problema:** Projetar <Eq>{"f(x) = x^2"}</Eq> sobre <Eq>{"M = \\text{span}\\{1, x\\} \\subset L^2[-1,1]"}</Eq>.

**Base ortonormal de M** (Gram-Schmidt aplicado a <Eq>{"\\{1, x\\}"}</Eq> em <Eq>{"L^2[-1,1]"}</Eq>):

<Eq>{"e_0 = \\frac{1}{\\sqrt{2}}, \\quad e_1 = \\sqrt{\\frac{3}{2}}\\,x"}</Eq>

**Projeção:**

<Eq>{"P_M(x^2) = \\langle x^2, e_0\\rangle e_0 + \\langle x^2, e_1\\rangle e_1"}</Eq>

<Eq>{"\\langle x^2, e_0 \\rangle = \\frac{1}{\\sqrt{2}}\\int_{-1}^1 x^2\\,dx = \\frac{1}{\\sqrt{2}}\\cdot\\frac{2}{3} = \\frac{\\sqrt{2}}{3}"}</Eq>

<Eq>{"\\langle x^2, e_1 \\rangle = \\sqrt{\\frac{3}{2}}\\int_{-1}^1 x^3\\,dx = 0 \\quad (\\text{integrand ímpar})"}</Eq>

Logo <Eq>{"P_M(x^2) = \\frac{\\sqrt{2}}{3} \\cdot \\frac{1}{\\sqrt{2}} = \\frac{1}{3}"}</Eq>.

**Erro:** <Eq>{"\\|x^2 - 1/3\\|_{L^2}^2 = \\int_{-1}^1 (x^2 - 1/3)^2\\,dx = \\frac{8}{45}"}</Eq>.

Esta projeção é o **melhor ajuste quadrático** de <Eq>{"x^2"}</Eq> no espaço das funções afins em <Eq>{"L^2[-1,1]"}</Eq>.

**Referência:** Axler, *Linear Algebra Done Right*, §6C; Debnath & Mikusinski, *Introduction to Hilbert Spaces*, §4.1.

</Exemplo>
