# O Problema que Unifica Séries de Fourier e Muito Mais

A teoria de Sturm-Liouville generaliza as séries de Fourier: em vez de senos e cossenos, usamos autofunções de um operador diferencial com condições de contorno. As autofunções são ortogonais entre si (como senos e cossenos!) e formam uma base completa no espaço <Eq>{"L^2"}</Eq>. Isso permite resolver equações diferenciais parciais expandindo a solução nessa base.

# Problema de Sturm-Liouville

**Forma padrão:** Encontrar <Eq>{"\\lambda"}</Eq> e <Eq>{"y \\neq 0"}</Eq> tais que:

<Eq>{"-(py')' + qy = \\lambda w y \\quad \\text{em } (a,b)"}</Eq>

com condições de contorno separadas: <Eq>{"\\alpha_1 y(a) + \\alpha_2 y'(a) = 0"}</Eq>, <Eq>{"\\beta_1 y(b) + \\beta_2 y'(b) = 0"}</Eq>.

**Hipóteses (problema regular):** <Eq>{"p, p', q, w"}</Eq> contínuos em <Eq>{"[a,b]"}</Eq>; <Eq>{"p > 0"}</Eq>, <Eq>{"w > 0"}</Eq> em <Eq>{"[a,b]"}</Eq>.

**Principais resultados:**
1. Autovalores <Eq>{"\\lambda_1 < \\lambda_2 < \\cdots \\to +\\infty"}</Eq> (todos reais)
2. Autofunções <Eq>{"y_n"}</Eq> são ortogonais com peso: <Eq>{"\\int_a^b y_m y_n w \\, dx = 0"}</Eq> se <Eq>{"m \\neq n"}</Eq>
3. <Eq>{"\\{y_n\\}"}</Eq> é completa em <Eq>{"L^2_w(a,b)"}</Eq>

# Teoria de Sturm-Liouville: Auto-adjunticidade

## Operador de Sturm-Liouville

Dado o **operador diferencial** <Eq>{"L = -\\frac{1}{w}\\left[\\frac{d}{dx}\\left(p\\frac{d}{dx}\\right) - q\\right]"}</Eq>, o problema de Sturm-Liouville (SL) é:

<EquacaoCanonica
  formula="Ly = \lambda y, \quad y \text{ satisfaz as condições de contorno}"
  legenda="L é auto-adjunto em L²_w(a,b) com as condições de contorno de SL"
  audioTexto="L de y igual a lambda y, onde y satisfaz as condições de contorno."
/>

## Identidade de Lagrange Verde

Para <Eq>{"u, v"}</Eq> satisfazendo as condições de contorno:

<EquacaoCanonica
  formula="\int_a^b (uLv - vLu)\,w\,dx = \big[p(u'v - uv')\big]_a^b = 0"
  legenda="Identidade de Green (ou de Lagrange) — L é simétrico/auto-adjunto em L²_w"
  audioTexto="A integral de u L v menos v L u vezes w de a a b é igual ao termo de borda p vezes u linha v menos u v linha, que se anula nas condições de contorno."
/>

**Consequência:** <Eq>{"\\langle Lu, v \\rangle_w = \\langle u, Lv \\rangle_w"}</Eq> onde <Eq>{"\\langle f, g \\rangle_w = \\int_a^b fg \\cdot w\\,dx"}</Eq>.

## Teorema Principal (Problema Regular)

Para o problema SL regular (p, w > 0, q ≥ 0):

**T1 (Autovalores reais):** Todos os autovalores são reais. *Prova:* <Eq>{"\\lambda\\langle y, y \\rangle_w = \\langle Ly, y \\rangle_w = \\langle y, Ly \\rangle_w = \\bar{\\lambda}\\langle y, y \\rangle_w"}</Eq>, logo <Eq>{"\\lambda = \\bar{\\lambda}"}</Eq>.

**T2 (Ortogonalidade):** Autofunções de autovalores distintos são ortogonais com peso <Eq>{"w"}</Eq>. *Prova:* Se <Eq>{"Ly_m = \\lambda_m y_m"}</Eq> e <Eq>{"Ly_n = \\lambda_n y_n"}</Eq> com <Eq>{"\\lambda_m \\neq \\lambda_n"}</Eq>:

<Eq>{"(\\lambda_m - \\lambda_n)\\langle y_m, y_n \\rangle_w = \\langle Ly_m, y_n \\rangle_w - \\langle y_m, Ly_n \\rangle_w = 0"}</Eq>

**T3 (Não-degenerescência):** Cada autovalor tem multiplicidade geométrica 1 (a EDO de segunda ordem tem solução geral 2D; as condições de contorno reduzem a 1D).

**T4 (Sequência infinita):** <Eq>{"\\lambda_1 < \\lambda_2 < \\cdots < \\lambda_n < \\cdots \\to +\\infty"}</Eq>.

**T5 (Completude):** As autofunções <Eq>{"\\{y_n\\}"}</Eq>, normalizadas como <Eq>{"\\phi_n = y_n/\\|y_n\\|_w"}</Eq>, formam base ortonormal completa de <Eq>{"L^2_w(a,b)"}</Eq>.

**Consequência:** Para <Eq>{"f \\in L^2_w(a,b)"}</Eq>:

<EquacaoCanonica
  formula="f = \sum_{n=1}^{\infty} c_n \phi_n, \quad c_n = \langle f, \phi_n\rangle_w = \int_a^b f\,\phi_n\,w\,dx"
  legenda="Expansão generalizada de Fourier-SL, convergente em L²_w"
  audioTexto="f é igual à soma de c n vezes phi n, onde c n é o produto interno de f com phi n com peso w."
/>

</Porta>

# Exemplos Canônicos e Fórmula de Rayleigh

## Problema de Fourier como Caso Especial

O problema <Eq>{"y'' + \\lambda y = 0"}</Eq>, <Eq>{"y(0) = y(L) = 0"}</Eq> é SL com <Eq>{"p = 1, q = 0, w = 1"}</Eq>. Os autovalores e autofunções são:

<EquacaoCanonica
  formula="\lambda_n = \left(\frac{n\pi}{L}\right)^2, \quad y_n(x) = \sin\left(\frac{n\pi x}{L}\right), \quad n = 1, 2, 3, \ldots"
  legenda="Caso mais simples de SL — origina as séries de Fourier de seno"
  audioTexto="Lambda n igual a n pi sobre L ao quadrado, y n de x igual a seno de n pi x sobre L."
/>

## Equação de Bessel — Problema SL Singular

Para <Eq>{"x \\in (0, 1)"}</Eq>, <Eq>{"\\nu > 0"}</Eq> fixo, o problema:

<Eq>{"-(xy')' + \\frac{\\nu^2}{x}y = \\lambda x y, \\quad y(0) \\text{ limitado}, \\quad y(1) = 0"}</Eq>

é **SL singular** (p(0) = 0). Os autovalores são <Eq>{"\\lambda_n = j_{\\nu,n}^2"}</Eq> (zeros de <Eq>{"J_\\nu"}</Eq>) e as autofunções são <Eq>{"y_n(x) = J_\\nu(j_{\\nu,n} x)"}</Eq>, ortogonais com peso <Eq>{"w(x) = x"}</Eq>:

<Eq>{"\\int_0^1 J_\\nu(j_{\\nu,m}x)\\,J_\\nu(j_{\\nu,n}x)\\,x\\,dx = \\frac{1}{2}[J_{\\nu+1}(j_{\\nu,n})]^2 \\delta_{mn}"}</Eq>

## Equação de Legendre — Problema SL Singular

Para <Eq>{"x \\in (-1,1)"}</Eq>:

<Eq>{"-(1-x^2)y'' + 2xy' = \\lambda y \\Leftrightarrow -[(1-x^2)y']' = \\lambda y"}</Eq>

SL com <Eq>{"p = 1-x^2, q = 0, w = 1"}</Eq> (singular nos extremos). Autovalores: <Eq>{"\\lambda_n = n(n+1)"}</Eq>; autofunções: Polinômios de Legendre <Eq>{"P_n(x)"}</Eq>.

## Quociente de Rayleigh

Para <Eq>{"y"}</Eq> satisfazendo as condições de contorno SL:

<EquacaoCanonica
  formula="\lambda = R[y] = \frac{\langle Ly, y\rangle_w}{\langle y, y\rangle_w} = \frac{\int_a^b (p|y'|^2 + q|y|^2)\,dx}{\int_a^b |y|^2\,w\,dx}"
  legenda="Quociente de Rayleigh — caracterização variacional dos autovalores"
  audioTexto="Lambda é igual ao quociente de Rayleigh R de y, dado pela integral de p módulo de y linha ao quadrado mais q módulo de y ao quadrado, dividido pela integral de y ao quadrado vezes w."
/>

**Propriedade min-max:** <Eq>{"\\lambda_1 = \\min_{y \\neq 0} R[y]"}</Eq>, e <Eq>{"\\lambda_n = \\min_{y \\perp y_1,\\ldots,y_{n-1}} R[y]"}</Eq> (Courant-Fischer).

# Teoria Espectral de Operadores Diferenciais

## Problema SL como Operador Compacto

Considere o operador inverso <Eq>{"G : L^2_w \\to L^2_w"}</Eq> dado por <Eq>{"Gf = u"}</Eq>, onde <Eq>{"u"}</Eq> é a solução do problema:

<Eq>{"Lu = f, \\quad u \\text{ satisfaz as condições de contorno SL}"}</Eq>

Esse operador é expresso via **Função de Green** <Eq>{"G(x,\\xi)"}</Eq> de L:

<EquacaoCanonica
  formula="(Gf)(x) = \int_a^b G(x,\xi)\,f(\xi)\,w(\xi)\,d\xi"
  legenda="G é operador integral de Hilbert-Schmidt, portanto compacto em L²_w"
  audioTexto="G f de x é igual à integral de a a b da função de Green G de x vírgula xi vezes f de xi vezes w de xi d xi."
/>

**Construção de G(x,ξ):** Seja <Eq>{"u_1, u_2"}</Eq> soluções de <Eq>{"Ly = 0"}</Eq> satisfazendo as condições em <Eq>{"a"}</Eq> e em <Eq>{"b"}</Eq> respectivamente:

<Eq>{"G(x, \\xi) = \\frac{1}{p(\\xi)W(\\xi)} \\begin{cases} u_1(x)u_2(\\xi) & x < \\xi \\\\ u_1(\\xi)u_2(x) & x > \\xi \\end{cases}"}</Eq>

onde <Eq>{"W = u_1 u_2' - u_1' u_2"}</Eq> é o wronskiano.

**Teorema:** O operador <Eq>{"G"}</Eq> assim definido é auto-adjunto e compacto em <Eq>{"L^2_w(a,b)"}</Eq>. Pelo teorema espectral para operadores compactos auto-adjuntos, seus autovalores <Eq>{"\\mu_n = 1/\\lambda_n \\to 0"}</Eq> e suas autofunções formam base ortonormal de <Eq>{"L^2_w"}</Eq>.

## Problema SL Singular e Espectro Contínuo

Quando <Eq>{"p(a) = 0"}</Eq> ou <Eq>{"p(b) = 0"}</Eq> (problema SL singular), o operador pode ter **espectro contínuo** além do discreto. Exemplo: <Eq>{"-(e^x y')' = \\lambda e^x y"}</Eq> em <Eq>{"(0,\\infty)"}</Eq> tem espectro <Eq>{"[0, \\infty)"}</Eq>.

**Condição de limite (Weyl):** No ponto singular, a condição de contorno é substituída por um critério de comportamento: **limit point** (uma solução em <Eq>{"L^2_w"}</Eq>) ou **limit circle** (ambas em <Eq>{"L^2_w"}</Eq>). A teoria de Weyl-Kodaira classifica todos os casos.

## Fórmula de Expansão e Convergência

**Convergência em L²:** Para <Eq>{"f \\in L^2_w"}</Eq>, a série <Eq>{"\\sum c_n \\phi_n"}</Eq> converge em norma.

**Convergência pontual (Dirichlet-Jordan):** Se <Eq>{"f"}</Eq> é de variação limitada numa vizinhança de <Eq>{"x_0"}</Eq>, então:

<Eq>{"\\sum_{n=1}^N c_n \\phi_n(x_0) \\to \\frac{f(x_0^+) + f(x_0^-)}{2} \\quad (N \\to \\infty)"}</Eq>

**Completude e unicidade:** Se <Eq>{"\\langle f, \\phi_n \\rangle_w = 0"}</Eq> para todo <Eq>{"n"}</Eq> então <Eq>{"f = 0"}</Eq> q.t.p. em <Eq>{"L^2_w"}</Eq>.

# Sturm-Liouville em Engenharia

## Vibração de Viga Não-Uniforme

Uma viga com rigidez variável <Eq>{"EI(x)"}</Eq> e densidade linear <Eq>{"\\rho(x)"}</Eq> tem modos de vibração governados por:

<Eq>{"\\frac{d^2}{dx^2}\\left(EI(x)\\frac{d^2 y}{dx^2}\\right) = \\omega^2 \\rho(x) y"}</Eq>

Para viga simplesmente apoiada (quarta ordem) ou viga com apenas flexão simples (ordem 2), o problema reduz-se a um SL. As frequências naturais <Eq>{"\\omega_n = \\sqrt{\\lambda_n}"}</Eq> são os autovalores, e os modos <Eq>{"y_n(x)"}</Eq> são as autofunções.

## Difusão com Condutividade Variável

A equação de difusão <Eq>{"u_t = \\frac{1}{\\rho c}(ku_x)_x"}</Eq> com <Eq>{"k(x), \\rho(x), c(x) > 0"}</Eq> variáveis se separa como:

<Eq>{"u(x,t) = \\sum_n a_n e^{-\\lambda_n t} \\phi_n(x)"}</Eq>

onde <Eq>{"\\{\\phi_n, \\lambda_n\\}"}</Eq> são autofunções/autovalores de <Eq>{"-(k\\phi_n')' = \\lambda_n \\rho c \\phi_n"}</Eq> — exatamente um problema SL com <Eq>{"p = k"}</Eq>, <Eq>{"w = \\rho c"}</Eq>.

## Cálculo Numérico de Autovalores

```python
import numpy as np
from scipy.linalg import eigh

def sturm_liouville_fd(p_func, q_func, w_func, a, b, N):
    """
    Discretiza -( p y' )' + q y = lambda w y por diferenças finitas.
    Retorna (eigenvalues, eigenvectors) os N primeiros.
    """
    h = (b - a) / (N + 1)
    x = np.linspace(a + h, b - h, N)
    xh = np.linspace(a + h/2, b - h/2, N + 1)  # pontos médios
    
    p = p_func(xh)
    q_vals = q_func(x)
    w = w_func(x)
    
    # Matriz rigidez (tridiagonal)
    diag_main  = (p[:-1] + p[1:]) / h**2 + q_vals
    diag_upper = -p[1:-1] / h**2
    
    K = np.diag(diag_main) + np.diag(diag_upper, 1) + np.diag(diag_upper, -1)
    W = np.diag(w)
    
    return eigh(K, W, subset_by_index=[0, min(9, N-1)])

# Exemplo: -y'' = λ y em [0, π], y(0) = y(π) = 0 → λ_n = n²
vals, vecs = sturm_liouville_fd(
    p_func=lambda x: np.ones_like(x),
    q_func=lambda x: np.zeros_like(x),
    w_func=lambda x: np.ones_like(x),
    a=0, b=np.pi, N=200
)
print("Autovalores numéricos:", np.round(vals, 4))
print("Autovalores exatos:   ", [n**2 for n in range(1, len(vals)+1)])
```

**Referência:** Stakgold & Holst, *Green's Functions and Boundary Value Problems*, §7; Birkhoff & Rota, *Ordinary Differential Equations*, 4ª ed., Cap. X.

## Exemplo 1 — Autofunções do Problema de Fourier

**Problema:** <Eq>{"y'' + \\lambda y = 0"}</Eq>, <Eq>{"y(0) = 0"}</Eq>, <Eq>{"y'(L) = 0"}</Eq> (condição mista).

**Identificação SL:** <Eq>{"p = 1, q = 0, w = 1"}</Eq>, <Eq>{"\\alpha_1 = 1, \\alpha_2 = 0"}</Eq>, <Eq>{"\\beta_1 = 0, \\beta_2 = 1"}</Eq>.

**Solução geral** (para <Eq>{"\\lambda > 0"}</Eq>): <Eq>{"y = A\\cos(\\sqrt{\\lambda}x) + B\\sin(\\sqrt{\\lambda}x)"}</Eq>.

**Condição em <Eq>{"x=0"}</Eq>:** <Eq>{"y(0) = A = 0"}</Eq>, logo <Eq>{"y = B\\sin(\\sqrt{\\lambda}x)"}</Eq>.

**Condição em <Eq>{"x=L"}</Eq>:** <Eq>{"y'(L) = B\\sqrt{\\lambda}\\cos(\\sqrt{\\lambda}L) = 0"}</Eq>.

Para <Eq>{"B \\neq 0"}</Eq>: <Eq>{"\\cos(\\sqrt{\\lambda}L) = 0 \\implies \\sqrt{\\lambda_n}L = \\frac{(2n-1)\\pi}{2}"}</Eq>, <Eq>{"n = 1,2,3,\\ldots"}</Eq>

**Autovalores e autofunções:**

<Eq>{"\\lambda_n = \\left(\\frac{(2n-1)\\pi}{2L}\\right)^2, \\quad y_n(x) = \\sin\\left(\\frac{(2n-1)\\pi x}{2L}\\right)"}</Eq>

**Verificação de ortogonalidade:**

<Eq>{"\\int_0^L \\sin\\left(\\frac{(2m-1)\\pi x}{2L}\\right)\\sin\\left(\\frac{(2n-1)\\pi x}{2L}\\right)dx = \\frac{L}{2}\\delta_{mn}"}</Eq>

**Referência:** Strauss, *Partial Differential Equations: An Introduction*, 2ª ed., §5.1; Stakgold & Holst, §7.1.

## Exemplo 2 — Quociente de Rayleigh e Estimativa do Primeiro Autovalor

**Problema:** Estimar <Eq>{"\\lambda_1"}</Eq> de <Eq>{"-(e^x y')' = \\lambda e^x y"}</Eq>, <Eq>{"y(0) = y(1) = 0"}</Eq>.

**Identificação:** <Eq>{"p = e^x, q = 0, w = e^x"}</Eq>.

**Quociente de Rayleigh:**

<Eq>{"R[y] = \\frac{\\int_0^1 e^x |y'|^2\\,dx}{\\int_0^1 e^x |y|^2\\,dx}"}</Eq>

**Função teste:** <Eq>{"y = x(1-x)"}</Eq> (satisfaz as condições de contorno).

**Numerador:** <Eq>{"\\int_0^1 e^x(1-2x)^2\\,dx = e - 3 \\approx 0{,}718"}</Eq>.

**Denominador:** <Eq>{"\\int_0^1 e^x x^2(1-x)^2\\,dx \\approx 0{,}0699"}</Eq>.

**Estimativa:** <Eq>{"\\lambda_1 \\leq R[y] \\approx 10{,}27"}</Eq>.

**Valor exato** (por comparação com Fourier, <Eq>{"e^x \\approx e^{1/2}"}</Eq>): <Eq>{"\\lambda_1 \\approx \\pi^2 + 1/4 \\approx 10{,}12"}</Eq> — a estimativa está dentro de 1,5%.

**Referência:** Stakgold & Holst, *Green's Functions and Boundary Value Problems*, §7.4; Birkhoff & Rota, §10.2.

</Exemplo>

## Exemplo 3 — Expansão em Autofunções e Solução de EDP

**Problema:** Calor em barra com condutividade variável:

<Eq>{"u_t = (xu_x)_x, \\quad x \\in (1, e), \\quad u(1,t) = u(e,t) = 0"}</Eq>

**Separação de variáveis:** <Eq>{"u = X(x)T(t)"}</Eq> leva a:

<Eq>{"T' = -\\lambda T, \\quad -(xX')' = \\lambda X"}</Eq>

**Problema SL:** <Eq>{"p = x, q = 0, w = 1"}</Eq>. Fazendo <Eq>{"x = e^s"}</Eq> (<Eq>{"s = \\ln x \\in (0,1)"}</Eq>) transforma em <Eq>{"-Y'' = \\lambda Y"}</Eq>, logo:

<Eq>{"\\lambda_n = (n\\pi)^2, \\quad X_n(x) = \\sin(n\\pi \\ln x)"}</Eq>

**Expansão da solução:**

<Eq>{"u(x,t) = \\sum_{n=1}^\\infty a_n e^{-n^2\\pi^2 t}\\sin(n\\pi\\ln x)"}</Eq>

com <Eq>{"a_n = \\frac{2}{\\|X_n\\|^2}\\int_1^e f(x)\\sin(n\\pi\\ln x)\\,dx"}</Eq> (onde <Eq>{"f = u(x,0)"}</Eq>).

**Referência:** Haberman, *Applied Partial Differential Equations*, 5ª ed., §5.3; Stakgold & Holst, §7.3.
