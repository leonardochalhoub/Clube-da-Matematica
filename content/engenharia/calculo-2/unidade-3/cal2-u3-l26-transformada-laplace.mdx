<Porta nivel="formal" titulo="Definição e tabela de pares principais">

### Definição

$$\mathcal{L}\{f(t)\}(s) = F(s) = \int_0^\infty e^{-st}f(t)\,dt, \quad s > \sigma_0$$

Existe para funções de crescimento exponencial: $|f(t)| \leq Me^{at}$ para $t$ grande.

### Tabela de pares essenciais

| $f(t)$ | $F(s) = \mathcal{L}\{f\}$ | Válido para |
|--------|--------------------------|------------|
| $1$ | $1/s$ | $s > 0$ |
| $e^{at}$ | $1/(s-a)$ | $s > a$ |
| $t^n$ | $n!/s^{n+1}$ | $s > 0$ |
| $\sin(bt)$ | $b/(s^2+b^2)$ | $s > 0$ |
| $\cos(bt)$ | $s/(s^2+b^2)$ | $s > 0$ |
| $e^{at}\sin(bt)$ | $b/((s-a)^2+b^2)$ | $s > a$ |
| $e^{at}\cos(bt)$ | $(s-a)/((s-a)^2+b^2)$ | $s > a$ |
| $t^n e^{at}$ | $n!/(s-a)^{n+1}$ | $s > a$ |
| $\delta(t-a)$ | $e^{-as}$ | $s > 0$ |
| $u(t-a)f(t-a)$ | $e^{-as}F(s)$ | (deslocamento $t$) |

### Propriedades chave

$$\mathcal{L}\{af+bg\} = aF+bG \quad\text{(linearidade)}$$
$$\mathcal{L}\{e^{at}f(t)\} = F(s-a) \quad\text{(deslocamento em }s\text{)}$$
$$\mathcal{L}\{f'\} = sF(s)-f(0), \quad \mathcal{L}\{f''\} = s^2F(s)-sf(0)-f'(0)$$
$$\mathcal{L}\{(f*g)(t)\} = F(s)\cdot G(s) \quad\text{(convolução)}$$

### Estratégia de solução

1. Aplique $\mathcal{L}$ à EDO → equação algébrica em $F(s)$.
2. Resolva para $F(s)$ (frações parciais se necessário).
3. Aplique $\mathcal{L}^{-1}$ via tabela ou frações parciais.

</Porta>

<Porta nivel="5anos" titulo="Trocar o domínio para simplificar">

Resolver $y'' + y' + y = e^t$ é difícil no "domínio do tempo". Mas se trocarmos para o "domínio da frequência" (domínio $s$), viramos:

$s^2 Y - \text{cond. iniciais} + sY - y(0) + Y = 1/(s-1)$.

Agora é só álgebra: resolve-se para $Y(s)$ e depois "traduz de volta" para $y(t)$ usando a tabela.

É como resolver equações em logaritmos: trocamos de domínio para simplificar, depois voltamos.

</Porta>

<Porta nivel="10anos" titulo="Derivada vira multiplicação por s">

$\mathcal{L}\{f'(t)\} = sF(s) - f(0)$.

Isso é o pulo do gato: **derivar no tempo** vira **multiplicar por $s$** no domínio de Laplace.

Então uma EDO de 2ª ordem — que envolve $y''$, $y'$ e $y$ — vira uma equação algébrica em $s^2 Y$, $sY$ e $Y$. Álgebra é mais fácil que cálculo!

</Porta>

<Porta nivel="15anos" titulo="Frações parciais + tabela">

Após resolver para $Y(s) = \dfrac{2s+3}{(s+1)(s^2+4)}$, decomponha:

$\dfrac{2s+3}{(s+1)(s^2+4)} = \dfrac{A}{s+1}+\dfrac{Bs+C}{s^2+4}$.

$A = 1/5$, $B = -1/5$, $C = 7/5$.

$y(t) = \dfrac{1}{5}e^{-t} - \dfrac{1}{5}\cos 2t + \dfrac{7}{10}\sin 2t$.

Cada fração vira uma entrada da tabela!

</Porta>

<Porta nivel="25anos" titulo="Função de transferência e análise de sistemas">

Para $ay''+by'+cy = g(t)$ com condições iniciais nulas:

$\mathcal{L}$: $(as^2+bs+c)Y(s) = G(s)$.

$$H(s) = \frac{Y(s)}{G(s)} = \frac{1}{as^2+bs+c}$$

é a **função de transferência** do sistema. Seus polos (raízes do denominador) determinam a estabilidade:
- Polos no semiplano esquerdo ($\text{Re}(s) < 0$): sistema estável.
- Polos no eixo imaginário: marginalmente estável.
- Polos no semiplano direito: instável.

**Resposta em frequência:** $H(j\omega) = H(s)|_{s=j\omega}$ — diagrama de Bode.

</Porta>

<Porta nivel="40anos" titulo="Aplicações em engenharia">

**Controle automático:** a transformada de Laplace é a base do projeto de controladores PID, análise de estabilidade pelo critério de Routh-Hurwitz, e diagramas de Nyquist.

**Análise de circuitos:** impedâncias generalizadas $Z_L = sL$, $Z_C = 1/(sC)$ permitem analisar circuitos transientes como circuitos resistivos em $s$.

**Processamento de sinais:** filtros analógicos (Butterworth, Chebyshev, Bessel) são especificados por $H(s)$; a transformada $Z$ é o análogo discreto.

**Equação de difusão:** a transformada de Laplace em $t$ converte $u_t = \kappa u_{xx}$ em EDO ordinária em $x$: $(s - \kappa\partial^2/\partial x^2)U = u_0$ — solucionável em termos de $\sqrt{s}$.

</Porta>

<Porta nivel="pratica" titulo="Passo a passo">

1. **Aplique** $\mathcal{L}$ à EDO usando $\mathcal{L}\{y''\} = s^2Y - sy(0) - y'(0)$.
2. **Colete** os termos em $Y(s)$ e incorpore as condições iniciais.
3. **Resolva** $Y(s) = [\ldots]/(as^2+bs+c)$.
4. **Decomponha** em frações parciais (se necessário).
5. **Aplique** $\mathcal{L}^{-1}$ usando a tabela.
6. **Verifique** substituindo na EDO original.

</Porta>

</DuasPortas>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — Tabela de pares" numero={1} fonte="Boyce-DiPrima §6.1, Ex. 1; Zill §7.1, Ex. 1">

Calcule $\mathcal{L}\{t^2 e^{-3t}\}$.

$\mathcal{L}\{t^n e^{at}\} = \dfrac{n!}{(s-a)^{n+1}}$, $n=2$, $a=-3$:

$\mathcal{L}\{t^2 e^{-3t}\} = \dfrac{2!}{(s+3)^3} = \dfrac{2}{(s+3)^3}$.

</Exemplo>

<Exemplo titulo="Ex. 2 — Solução de PVI por Laplace" numero={2} fonte="Boyce-DiPrima §6.2, Ex. 3; Zill §7.2, Ex. 5">

Resolva $y'' - y' - 2y = 0$, $y(0) = 1$, $y'(0) = 0$.

$\mathcal{L}$: $s^2Y - s - 0 - (sY-1) - 2Y = 0$.

$(s^2-s-2)Y = s-1$.

$Y = \dfrac{s-1}{(s-2)(s+1)} = \dfrac{1/3}{s-2}+\dfrac{2/3}{s+1}$.

$y = \frac{1}{3}e^{2t}+\frac{2}{3}e^{-t}$.

</Exemplo>

<Exemplo titulo="Ex. 3 — Com forçamento" numero={3} fonte="Boyce-DiPrima §6.2, Ex. 9; Zill §7.2, Ex. 15">

Resolva $y'' + 4y = \sin t$, $y(0) = 0$, $y'(0) = 0$.

$\mathcal{L}$: $s^2Y + 4Y = 1/(s^2+1)$.

$Y = \dfrac{1}{(s^2+4)(s^2+1)} = \dfrac{1/3}{s^2+1} - \dfrac{1/3}{s^2+4}$.

$y = \dfrac{1}{3}\sin t - \dfrac{1}{6}\sin 2t$.

</Exemplo>

<Exemplo titulo="Ex. 4 — Função degrau (Heaviside)" numero={4} fonte="Boyce-DiPrima §6.3, Ex. 5; Zill §7.3, Ex. 10">

Resolva $y'' + y = u(t-\pi)$, $y(0) = 0$, $y'(0) = 0$.

$\mathcal{L}$: $s^2Y+Y = e^{-\pi s}/s$.

$Y = \dfrac{e^{-\pi s}}{s(s^2+1)} = e^{-\pi s}\left[\dfrac{1}{s}-\dfrac{s}{s^2+1}\right]$.

$\mathcal{L}^{-1}$: $y = u(t-\pi)[1-\cos(t-\pi)] = u(t-\pi)[1+\cos t]$.

</Exemplo>

**(a)** $f(t) = 3t^4 - 2t^2 + 5$

**(b)** $f(t) = e^{-2t}\cos(3t)$

**(a)** $y'' - 4y = 0$, $y(0) = 1$, $y'(0) = 0$
