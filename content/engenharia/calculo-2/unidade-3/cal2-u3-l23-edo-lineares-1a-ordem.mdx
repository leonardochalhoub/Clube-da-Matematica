<DuasPortas>

<Porta nivel="formal" titulo="Método do fator integrante">

### Forma padrão

$y' + p(x)y = q(x)$

**Solução homogênea** ($q = 0$): separável, $y_h = Ce^{-\int p\,dx}$.

### Fator integrante

Multiplique ambos os lados por $\mu(x) = e^{\int p(x)\,dx}$:
$$\mu y' + \mu p y = \mu q \quad\Longrightarrow\quad (\mu y)' = \mu q$$

Integrando:
$$\mu(x)y = \int\mu(x)q(x)\,dx + C$$
$$y = \frac{1}{\mu(x)}\left[\int\mu(x)q(x)\,dx + C\right]$$

### Estrutura da solução

$$y = y_h + y_p = Ce^{-\int p\,dx} + y_p$$

onde $y_p$ é uma solução particular (qualquer valor de $C$ fixo, e.g., $C=0$).

### Princípio da superposição (linear)

Se $y_1$ e $y_2$ são soluções de $y'+py=q_1$ e $y'+py=q_2$ respectivamente, então $y_1+y_2$ é solução de $y'+py=q_1+q_2$.

### Existência e unicidade para PVI linear

Se $p$ e $q$ são contínuas em $(a,b)$ e $x_0 \in (a,b)$, o PVI tem solução única em $(a,b)$ — sem restrição de tamanho do intervalo.

</Porta>

<Porta nivel="5anos" titulo="O truque do fator integrante">

Queremos resolver $y' + y = e^x$. Não é separável. Mas se multiplicarmos por $\mu = e^x$:

$e^x y' + e^x y = e^{2x}$, que é $(e^x y)' = e^{2x}$.

Integramos: $e^x y = e^{2x}/2 + C$, logo $y = e^x/2 + Ce^{-x}$.

O fator integrante "transforma" a EDO em uma derivada de produto!

</Porta>

<Porta nivel="10anos" titulo="Solução homogênea e particular">

A solução geral $y = Ce^{-x} + e^x/2$ tem dois pedaços:

- $Ce^{-x}$: solução da equação homogênea $y' + y = 0$ (decai para 0).
- $e^x/2$: solução particular da equação completa (cresce com o forçamento $e^x$).

O comportamento assintótico é dominado pela particular se a homogênea decai.

</Porta>

<Porta nivel="15anos" titulo="Resposta transitória e estacionária">

Para $y' + y = A\sin(\omega t)$ (forçamento senoidal):

$y_h = Ce^{-t}$ → decai (transitório).

$y_p = \dfrac{A(\sin\omega t - \omega\cos\omega t)}{1+\omega^2}$ → persiste (estacionário).

Para $t$ grande, $y \approx y_p$: o sistema "esquece" a condição inicial e segue o forçamento. Isso é a **resposta em regime estacionário** em controle e circuitos.

</Porta>

<Porta nivel="25anos" titulo="Variação de parâmetros para 1ª ordem">

Método alternativo: assuma $y_p = v(x)e^{-\int p\,dx}$ (substituição $C \to v(x)$).

Substituindo: $v'e^{-\int p\,dx} = q(x)$, logo $v' = q(x)e^{\int p\,dx}$, $v = \int q e^{\int p\,dx}\,dx$.

Isso generaliza para ordem superior (lição 29) e é equivalente ao fator integrante em 1ª ordem.

**Fórmula de Cauchy (variação de parâmetros):**
$$y(x) = e^{-\int_{x_0}^x p(t)\,dt}y_0 + \int_{x_0}^x e^{-\int_s^x p(t)\,dt}q(s)\,ds$$

</Porta>

<Porta nivel="40anos" titulo="Aplicações em engenharia">

**Circuito RL:** $L\,di/dt + Ri = V(t)$ → $i' + (R/L)i = V/L$. Fator integrante: $\mu = e^{Rt/L}$.

**Circuito RC:** $C\,dV/dt + V/R = I_s(t)/R$ (corrente de fonte) — análogo ao RL.

**Controle proporcional:** $\tau\dot{e}+e = r$ onde $e$ = erro, $r$ = referência; solução exponencial com constante de tempo $\tau$.

**Mistura:** tanque com volume $V$, entrada de concentração $c_0$ e fluxo $Q$. $V\,dc/dt = Q(c_0-c)$, linear de 1ª ordem. Solução: $c(t) = c_0 + (c_1-c_0)e^{-Qt/V}$.

</Porta>

<Porta nivel="pratica" titulo="Passo a passo">

1. **Coloque** na forma padrão: $y' + p(x)y = q(x)$.
2. **Calcule** $\mu(x) = e^{\int p(x)\,dx}$ (não precisa de constante de integração).
3. **Multiplique** ambos os lados por $\mu$: $(\mu y)' = \mu q$.
4. **Integre:** $\mu y = \int\mu q\,dx + C$.
5. **Divida** por $\mu$: $y = (\int\mu q\,dx + C)/\mu$.
6. **Aplique** a condição inicial para determinar $C$.

</Porta>

</DuasPortas>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — Fator integrante básico" numero={1} fonte="Stewart §9.5, Ex. 1; Boyce-DiPrima §2.1, Ex. 1">

Resolva $y' - 2y = e^{3x}$.

$p = -2$, $\mu = e^{-2x}$.

$(e^{-2x}y)' = e^{-2x}\cdot e^{3x} = e^x$.

$e^{-2x}y = e^x + C$, logo $y = e^{3x} + Ce^{2x}$.

</Exemplo>

<Exemplo titulo="Ex. 2 — Coeficiente variável" numero={2} fonte="Stewart §9.5, Ex. 5; Boyce-DiPrima §2.1, Ex. 7">

Resolva $y' + \dfrac{2}{x}y = \cos x/x^2$, $x > 0$.

$p = 2/x$, $\mu = e^{2\ln x} = x^2$.

$(x^2 y)' = \cos x$. Integrando: $x^2 y = \sin x + C$.

$y = \dfrac{\sin x + C}{x^2}$.

</Exemplo>

<Exemplo titulo="Ex. 3 — Circuito RL" numero={3} fonte="Boyce-DiPrima §2.1, Ex. 20; Zill §3.4">

No circuito RL com $R = 4\,\Omega$, $L = 1\,H$ e $V(t) = 12\sin(3t)$ V, $i(0) = 0$:

$i' + 4i = 12\sin 3t$. $\mu = e^{4t}$.

$(e^{4t}i)' = 12e^{4t}\sin 3t$.

$e^{4t}i = \displaystyle\int 12e^{4t}\sin 3t\,dt = \frac{12e^{4t}(4\sin 3t - 3\cos 3t)}{25} + C$.

$i = \frac{12(4\sin 3t - 3\cos 3t)}{25} + Ce^{-4t}$.

$i(0) = 0$: $-36/25 + C = 0$, $C = 36/25$.

$i(t) = \frac{48\sin 3t - 36\cos 3t}{25} + \frac{36}{25}e^{-4t}$.

</Exemplo>

<Exemplo titulo="Ex. 4 — Problema de mistura" numero={4} fonte="Boyce-DiPrima §2.3, Ex. 12; Zill §3.3, Ex. 16">

Um tanque tem 100 L de água pura. Entra solução com 0,5 kg/L a 5 L/min; sai 5 L/min. Concentração em $t = 20$ min?

$Q$ = quantidade de sal (kg): $\dfrac{dQ}{dt} = 0{,}5\times 5 - \dfrac{Q}{100}\times 5 = 2{,}5 - Q/20$.

$Q' + Q/20 = 2{,}5$. $\mu = e^{t/20}$. $(e^{t/20}Q)' = 2{,}5e^{t/20}$.

$e^{t/20}Q = 50e^{t/20} + C$. $Q(0)=0$: $C = -50$.

$Q(20) = 50(1-e^{-1}) \approx 31{,}6$ kg. Concentração: $31{,}6/100 = 0{,}316$ kg/L.

</Exemplo>
