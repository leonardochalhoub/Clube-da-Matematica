<Porta nivel="formal" titulo="Teoria geral e equação característica">

### Equação característica

Para $ay'' + by' + cy = 0$, tente $y = e^{rx}$:
$$ar^2 + br + c = 0 \quad \Rightarrow \quad r = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$$

### Três casos

**Caso 1: $\Delta = b^2-4ac > 0$** — duas raízes reais distintas $r_1, r_2$:
$$y = c_1 e^{r_1 x} + c_2 e^{r_2 x}$$

**Caso 2: $\Delta = 0$** — raiz real repetida $r = -b/(2a)$:
$$y = (c_1 + c_2 x)e^{rx}$$

**Caso 3: $\Delta < 0$** — raízes complexas $r = \alpha \pm i\beta$ ($\alpha = -b/(2a)$, $\beta = \sqrt{4ac-b^2}/(2a)$):
$$y = e^{\alpha x}(c_1\cos\beta x + c_2\sin\beta x)$$

### Wronskiano e independência linear

O **Wronskiano** de $y_1, y_2$ é $W = \begin{vmatrix}y_1 & y_2 \\ y_1' & y_2'\end{vmatrix} = y_1 y_2' - y_2 y_1'$.

$y_1$ e $y_2$ são **linearmente independentes** iff $W \neq 0$ (em algum ponto).

**Solução geral:** se $y_1, y_2$ são l.i., então $y = c_1 y_1 + c_2 y_2$ é a solução geral.

### Oscilação amortecida

Para $my'' + by' + ky = 0$ (oscilador massa-mola):
- $b^2 - 4mk > 0$: sobreamortecido (sem oscilação).
- $b^2 - 4mk = 0$: criticamente amortecido.
- $b^2 - 4mk < 0$: subamortecido ($y = e^{-bt/(2m)}(c_1\cos\omega_d t + c_2\sin\omega_d t)$, frequência amortecida $\omega_d = \sqrt{4mk-b^2}/(2m)$).

</Porta>

<Porta nivel="5anos" titulo="A equação do oscilador">

Pense numa mola: $y'' + y = 0$. A equação característica é $r^2 + 1 = 0$, logo $r = \pm i$.

A solução é $y = c_1\cos x + c_2\sin x$ — oscila para sempre!

Se há atrito: $y'' + 2y' + y = 0$. Raiz repetida $r = -1$. Solução: $y = (c_1 + c_2 x)e^{-x}$ — decai sem oscilar.

</Porta>

<Porta nivel="10anos" titulo="Os três casos — intuitivamente">

**Real distinto ($\Delta > 0$):** dois modos exponenciais independentes. Se ambas as raízes são negativas, o sistema decai monotonamente.

**Raiz repetida ($\Delta = 0$):** o caso especial "criticamente amortecido" — decai o mais rápido possível sem oscilar. Importante em design de amortecedores de automóvel.

**Complexo ($\Delta < 0$):** a parte real $\alpha$ determina o envelope (cresce/decai); a parte imaginária $\beta$ determina a frequência de oscilação.

</Porta>

<Porta nivel="15anos" titulo="Wronskiano e verificação de independência">

Para $y_1 = e^{2x}$ e $y_2 = e^{3x}$:

$W = \begin{vmatrix}e^{2x} & e^{3x} \\ 2e^{2x} & 3e^{3x}\end{vmatrix} = 3e^{5x} - 2e^{5x} = e^{5x} \neq 0$.

Independentes! A solução geral de $y'' - 5y' + 6y = 0$ é $y = c_1 e^{2x} + c_2 e^{3x}$.

**Fórmula de Abel:** $W(x) = W(x_0)\exp\!\left(-\displaystyle\int_{x_0}^x p(t)\,dt\right)$ — o Wronskiano é ou sempre zero ou nunca zero.

</Porta>

<Porta nivel="25anos" titulo="Equação de Euler e reduções de ordem">

**Equação de Cauchy-Euler:** $ax^2y'' + bxy' + cy = 0$. Tente $y = x^r$:
$r(r-1)a + rb + c = 0$ — equação de índices.

Três casos análogos (real distinto, repetido, complexo em $\ln x$).

**Redução de ordem:** se $y_1$ é solução conhecida, procure $y_2 = v(x)y_1$. Substituindo:
$$y_1 v'' + (2y_1' + py_1)v' = 0$$
EDO linear de 1ª ordem em $w = v'$: $w'/w = -(2y_1'/y_1 + p)$, solucionável por separação.

</Porta>

<Porta nivel="40anos" titulo="Aplicações em engenharia">

**Sistema massa-mola-amortecedor:** $m\ddot{x} + c\dot{x} + kx = 0$. Os três casos determinam a resposta livre:
- Subamortecido ($c < 2\sqrt{mk}$): oscila com decaimento exponencial.
- Criticamente amortecido ($c = 2\sqrt{mk}$): retorno mais rápido ao equilíbrio.
- Sobreamortecido ($c > 2\sqrt{mk}$): retorno sem oscilação, mas mais lento.

**Fator de amortecimento:** $\zeta = c/(2\sqrt{mk})$. Especificação de projeto: $\zeta = 0{,}7$ (ótimo para resposta a degrau em controle).

**Beams (viga de Euler-Bernoulli):** $EI\,d^4w/dx^4 = q(x)$. A solução homogênea tem exponenciais e trigonométricas — análogo à equação de 4ª ordem.

**Equação de Schrödinger (1D, potencial constante):** $-\hbar^2/(2m)\psi'' + V\psi = E\psi$. Raízes reais ($E < V$: decaimento) ou imaginárias ($E > V$: propagação).

</Porta>

<Porta nivel="pratica" titulo="Passo a passo">

1. **Escreva** a equação característica $ar^2 + br + c = 0$.
2. **Calcule** $\Delta = b^2 - 4ac$.
3. **Escreva** $y_1, y_2$ conforme o caso.
4. **Solução geral:** $y = c_1 y_1 + c_2 y_2$.
5. **Para PVI:** aplique $y(x_0) = y_0$ e $y'(x_0) = y_1$ para encontrar $c_1, c_2$.
6. **Verifique** calculando $y'$ e $y''$ e substituindo na EDO.

</Porta>

</DuasPortas>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — Raízes reais distintas" numero={1} fonte="Boyce-DiPrima §3.1, Ex. 1; Zill §4.3, Ex. 1">

Resolva $y'' - y' - 6y = 0$, $y(0) = 2$, $y'(0) = -1$.

$r^2 - r - 6 = 0 \Rightarrow (r-3)(r+2) = 0 \Rightarrow r_1 = 3, r_2 = -2$.

$y = c_1 e^{3x} + c_2 e^{-2x}$.

$y(0) = c_1 + c_2 = 2$; $y'(0) = 3c_1 - 2c_2 = -1$.

$c_1 = 3/5$, $c_2 = 7/5$. $y = \frac{3}{5}e^{3x}+\frac{7}{5}e^{-2x}$.

</Exemplo>

<Exemplo titulo="Ex. 2 — Raiz repetida" numero={2} fonte="Boyce-DiPrima §3.4, Ex. 1; Zill §4.3, Ex. 7">

Resolva $y'' + 4y' + 4y = 0$, $y(0) = 1$, $y'(0) = 0$.

$r^2+4r+4 = (r+2)^2 = 0 \Rightarrow r = -2$ (repetida).

$y = (c_1 + c_2 x)e^{-2x}$.

$y(0) = c_1 = 1$; $y'(0) = -2c_1 + c_2 = 0 \Rightarrow c_2 = 2$.

$y = (1+2x)e^{-2x}$.

</Exemplo>

<Exemplo titulo="Ex. 3 — Raízes complexas" numero={3} fonte="Boyce-DiPrima §3.3, Ex. 1; Zill §4.3, Ex. 12">

Resolva $y'' + 2y' + 5y = 0$, $y(0) = 0$, $y'(0) = 1$.

$r^2+2r+5=0 \Rightarrow r = -1 \pm 2i$. $\alpha = -1$, $\beta = 2$.

$y = e^{-x}(c_1\cos 2x + c_2\sin 2x)$.

$y(0) = c_1 = 0$; $y'(0) = -c_1 + 2c_2 = 1 \Rightarrow c_2 = 1/2$.

$y = \frac{1}{2}e^{-x}\sin 2x$.

</Exemplo>

<Exemplo titulo="Ex. 4 — Oscilador subamortecido" numero={4} fonte="Boyce-DiPrima §3.7, Ex. 5; Zill §5.1, Ex. 12">

Massa $m=2$ kg, mola $k=8$ N/m, amortecedor $c=4$ N$\cdot$s/m. PVI: $x(0)=1$, $\dot{x}(0)=0$.

$2\ddot{x}+4\dot{x}+8x=0 \Rightarrow \ddot{x}+2\dot{x}+4x=0$.

$r^2+2r+4=0 \Rightarrow r = -1\pm i\sqrt{3}$.

$x = e^{-t}(c_1\cos\sqrt{3}t+c_2\sin\sqrt{3}t)$.

$x(0) = c_1 = 1$; $\dot{x}(0) = -c_1+\sqrt{3}c_2 = 0 \Rightarrow c_2 = 1/\sqrt{3}$.

$x = e^{-t}\left(\cos\sqrt{3}t + \frac{\sin\sqrt{3}t}{\sqrt{3}}\right)$.

</Exemplo>

### Bloco A — Equação característica

<Exercicio numero={1} fonte="Boyce-DiPrima §3.1–3.4, Ex. 1–20; Zill §4.3, Ex. 1–20">
Resolva:

**(a)** $y'' - 3y' + 2y = 0$, $y(0) = 1$, $y'(0) = 0$

**(b)** $y'' + 6y' + 9y = 0$, $y(0) = 2$, $y'(0) = -3$

**(c)** $y'' + 4y = 0$, $y(0) = 0$, $y'(0) = 3$

**(d)** $4y'' - 4y' - 3y = 0$
</Exercicio>

<Exercicio numero={2} fonte="Zill §4.3, Ex. 25–36; Boyce-DiPrima §3.3–3.4, Ex. 15–25">
Determine a EDO de 2ª ordem com as soluções dadas:

**(a)** $y_1 = e^{-2x}$, $y_2 = e^{5x}$

**(b)** $y_1 = e^{x}\cos(3x)$, $y_2 = e^{x}\sin(3x)$

**(c)** $y_1 = 1$, $y_2 = e^{-2x}$
</Exercicio>

### Bloco B — Wronskiano e independência

<Exercicio numero={3} fonte="Boyce-DiPrima §3.2; Zill §4.1, Ex. 1–12">
Calcule o Wronskiano e determine independência linear:

**(a)** $y_1 = e^{2x}$, $y_2 = xe^{2x}$

**(b)** $y_1 = \sin^2 x$, $y_2 = 1-\cos 2x$

**(c)** $y_1 = x^2$, $y_2 = x^3$ em $(-\infty,\infty)$
</Exercicio>

<Exercicio numero={4} fonte="Boyce-DiPrima §3.6; Zill §4.2">

</Exercicio>

**(b)** Para $m=1$, $k=9$, $x(0)=2$, $\dot{x}(0)=3$, escreva a solução na forma $A\cos(\omega t+\phi)$.

</Exercicio>

<Exercicio numero={6} fonte="USP MAT0112; Boyce-DiPrima §5.4 (Euler)">

**(a)** Use $y = x^r$ para encontrar os expoentes.

**(b)** Mostre que os expoentes são iguais e encontre $y_2 = x^r\ln x$.

**(c)** Resolva com $y(1) = 0$, $y'(1) = 1$.
</Exercicio>

<Exercicio numero={7} fonte="ITA 2021; Zill §6.1">

</Exercicio>
