<Porta nivel="formal" titulo="Dois métodos para a solução particular">

### Método dos coeficientes indeterminados

Funciona quando $g(x)$ é combinação linear de: $e^{ax}P_n(x)$, $e^{ax}P_n(x)\cos\beta x$, $e^{ax}P_n(x)\sin\beta x$.

**Forma da particular:** use o mesmo "tipo" que $g$, mas multiplique por $x^s$ onde $s$ é a multiplicidade da raiz correspondente na equação característica.

| Forma de $g(x)$ | Forma de $y_p$ (se raiz não coincide) |
|----------------|--------------------------------------|
| $P_n(x)$ | $Q_n(x)$ (polinômio grau $n$) |
| $e^{ax}P_n(x)$ | $e^{ax}Q_n(x)$ |
| $\cos\beta x$ ou $\sin\beta x$ | $A\cos\beta x + B\sin\beta x$ |
| $e^{ax}\cos\beta x$ | $e^{ax}(A\cos\beta x + B\sin\beta x)$ |

**Regra de modificação:** se $g$ coincidir com solução homogênea, multiplique $y_p$ por $x$ (ou $x^2$ se raiz dupla).

### Variação de parâmetros

Para $y'' + p(x)y' + q(x)y = g(x)$ com $y_h = c_1 y_1 + c_2 y_2$:

$$y_p = -y_1\int\frac{y_2(x)g(x)}{W(x)}\,dx + y_2\int\frac{y_1(x)g(x)}{W(x)}\,dx$$

onde $W = y_1 y_2' - y_2 y_1'$ é o Wronskiano.

**Vantagem:** funciona para qualquer $g(x)$ contínua, inclusive com coeficientes variáveis.

</Porta>

<Porta nivel="5anos" titulo="Adicionando o forçamento">

A EDO homogênea descreve o sistema sozinho ($g=0$): uma mola livre oscila por conta própria.

A particular $y_p$ descreve como o sistema responde ao forçamento $g(x)$.

A solução geral $y = y_h + y_p$ combina: o comportamento livre + a resposta ao forçamento.

Com o tempo (se $y_h$ decai), o sistema "esquece" a condição inicial e fica apenas com $y_p$.

</Porta>

<Porta nivel="10anos" titulo="Coeficientes indeterminados — a ideia">

Se $g(x) = e^{2x}$, tentamos $y_p = Ae^{2x}$. Substituindo: $y_p'' = 4Ae^{2x}$, $y_p' = 2Ae^{2x}$.

Na EDO $y'' - y = e^{2x}$: $(4-1)Ae^{2x} = e^{2x}$, logo $A = 1/3$.

O truque é que derivar não muda o "tipo" das funções (exponencial continua exponencial, cosseno vira seno + cosseno). Então basta determinar os coeficientes.

</Porta>

<Porta nivel="15anos" titulo="Ressonância pura">

Para $y'' + \omega_0^2 y = \cos\omega_0 t$ (forçamento na frequência natural):

Tentativa $y_p = A\cos\omega_0 t$ falha (coincide com a homogênea). Use $y_p = t(A\cos\omega_0 t + B\sin\omega_0 t)$.

Substituindo: $B = 0$, $A = 1/(2\omega_0)$.

$y_p = \dfrac{t\sin\omega_0 t}{2\omega_0}$.

**A amplitude cresce sem limite com $t$!** Isso é ressonância: o forçamento e o sistema estão em fase — é como empurrar um balanço sempre no momento certo.

</Porta>

<Porta nivel="25anos" titulo="Função de Green e resposta ao impulso">

A variação de parâmetros fornece a **função de Green** $G(x,s)$ tal que:
$$y_p(x) = \int_{x_0}^x G(x,s)g(s)\,ds, \quad G(x,s) = \frac{y_1(s)y_2(x)-y_2(s)y_1(x)}{W(s)}$$

Esta representa a resposta do sistema ao impulso $\delta(x-s)$.

**Resposta ao impulso em controle:** $h(t) = \mathcal{L}^{-1}\{H(s)\}$ onde $H(s) = 1/(ms^2+cs+k)$ é a função de transferência. A convolução $y = h * f$ (resposta ao forçamento geral).

</Porta>

<Porta nivel="40anos" titulo="Aplicações em engenharia">

**Vibração forçada:** $m\ddot{x}+c\dot{x}+kx = F_0\cos\omega t$.

Resposta estacionária: $x_p = \frac{F_0/k}{\sqrt{(1-r^2)^2+(2\zeta r)^2}}\cos(\omega t-\phi)$, onde $r = \omega/\omega_n$.

**Fator de amplificação dinâmica (DAF):** razão entre amplitude dinâmica e estática, pico em $r = \sqrt{1-2\zeta^2}$ (próximo à ressonância).

**Circuito RLC forçado:** $L\ddot{q}+R\dot{q}+q/C = E(t)$ — análogo elétrico do oscilador mecânico.

**Método da rigidez complexa:** $x = \text{Re}\{Xe^{i\omega t}\}$ transforma a EDO em sistema algébrico $(-\omega^2 M+i\omega C+K)X = F$ — base do método de análise modal.

</Porta>

<Porta nivel="pratica" titulo="Passo a passo">

1. **Resolva** a homogênea: encontre $y_h = c_1 y_1 + c_2 y_2$.
2. **Escolha o método:**
   - $g(x)$ do tipo exponencial-polinômio-trig → coeficientes indeterminados.
   - $g(x)$ geral, coeficientes variáveis → variação de parâmetros.
3. **Coeficientes indeterminados:** identifique a forma de $y_p$, substitua, determine os coeficientes.
4. **Variação de parâmetros:** calcule $W$, depois as integrais, combine.
5. **Solução geral:** $y = y_h + y_p$.
6. **PVI:** aplique condições iniciais para $c_1, c_2$.

</Porta>

</DuasPortas>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — Coeficientes indeterminados com polinômio" numero={1} fonte="Boyce-DiPrima §3.5, Ex. 1; Zill §4.4, Ex. 1">

Resolva $y'' - 3y' + 2y = 3x^2$.

$y_h$: $r^2-3r+2=0$, $r=1,2$. $y_h = c_1 e^x + c_2 e^{2x}$.

$y_p = Ax^2+Bx+C$: $y_p'' = 2A$, $y_p' = 2Ax+B$.

$2A - 3(2Ax+B) + 2(Ax^2+Bx+C) = 3x^2$.

$2Ax^2 + (-6A+2B)x + (2A-3B+2C) = 3x^2$.

$A = 3/2$, $B = 9/2$, $C = 21/4$. $y_p = \frac{3x^2}{2}+\frac{9x}{2}+\frac{21}{4}$.

</Exemplo>

<Exemplo titulo="Ex. 2 — Regra de modificação (ressonância)" numero={2} fonte="Boyce-DiPrima §3.5, Ex. 7; Zill §4.4, Ex. 13">

Resolva $y'' - 2y' + y = e^x$.

$y_h$: $r^2-2r+1=(r-1)^2=0$, $r=1$ (dupla). $y_h = (c_1+c_2 x)e^x$.

$e^x$ coincide com $y_h$ (raiz dupla). Use $y_p = Ax^2 e^x$.

$y_p' = (2Ax+Ax^2)e^x$, $y_p'' = (2A+4Ax+Ax^2)e^x$.

$y_p''-2y_p'+y_p = 2Ae^x = e^x \Rightarrow A = 1/2$.

$y = (c_1+c_2 x)e^x + \frac{x^2}{2}e^x$.

</Exemplo>

<Exemplo titulo="Ex. 3 — Variação de parâmetros" numero={3} fonte="Boyce-DiPrima §3.6, Ex. 3; Zill §4.6, Ex. 5">

Resolva $y'' + y = \sec x$.

$y_h = c_1\cos x + c_2\sin x$. $W = 1$.

$y_p = -\cos x\displaystyle\int\frac{\sin x\sec x}{1}\,dx + \sin x\int\frac{\cos x\sec x}{1}\,dx$.

$= -\cos x\int\tan x\,dx + \sin x\int 1\,dx = \cos x\ln|\cos x| + x\sin x$.

$y = c_1\cos x + c_2\sin x + \cos x\ln|\cos x| + x\sin x$.

</Exemplo>

<Exemplo titulo="Ex. 4 — Oscilação forçada sem amortecimento" numero={4} fonte="Boyce-DiPrima §3.8, Ex. 3; Zill §5.1, Ex. 22">

Resolva $y'' + 4y = 3\cos 2t$ (forçamento em frequência natural $\omega_0 = 2$).

$y_h = c_1\cos 2t + c_2\sin 2t$. Regra de modificação: $y_p = t(A\cos 2t + B\sin 2t)$.

$y_p'' = (-4At+4B)\cos 2t + (-4Bt-4A)\sin 2t + \cdots$

Substituindo: $4B\cos 2t - 4A\sin 2t = 3\cos 2t \Rightarrow B = 3/4$, $A = 0$.

$y = c_1\cos 2t + c_2\sin 2t + \frac{3t}{4}\sin 2t$.

A amplitude $3t/4$ cresce sem limite — **ressonância**.

</Exemplo>

## Exercícios

### Bloco A — Coeficientes indeterminados

<Exercicio numero={1} fonte="Boyce-DiPrima §3.5, Ex. 1–16; Zill §4.4, Ex. 1–18">
Resolva pelo método dos coeficientes indeterminados:

**(a)** $y'' + 3y' + 2y = 6e^x$

**(b)** $y'' - 4y = 4x^2 - 2x + 1$

**(c)** $y'' + y = 4\sin t$, $y(0) = 0$, $y'(0) = 0$

**(d)** $y'' - 2y' + 5y = e^x\cos 2x$
</Exercicio>

### Bloco B — Variação de parâmetros

<Exercicio numero={2} fonte="Boyce-DiPrima §3.6, Ex. 1–14; Zill §4.6, Ex. 1–15">
Use variação de parâmetros:

**(a)** $y'' + 4y' + 4y = e^{-2x}/x^2$, $x > 0$

**(b)** $y'' - y = \cosh x$

**(c)** $x^2y'' - 2xy' + 2y = x\ln x$, $x > 0$ *(equação de Euler — dica: solução homogênea $x, x^2$)*
</Exercicio>

### Bloco C — Ressonância e aplicações

<Exercicio numero={3} fonte="Boyce-DiPrima §3.8; Zill §5.1, Ex. 20–35">
**Oscilador forçado:**

**(a)** $m\ddot{x}+kx = F_0\cos\omega t$, $\omega\neq\omega_0 = \sqrt{k/m}$. Mostre que $x_p = \dfrac{F_0/m}{\omega_0^2-\omega^2}\cos\omega t$ e esboce a amplitude em função de $\omega$.

**(b)** Para $\omega = \omega_0$ (ressonância), encontre $x_p$ e descreva o comportamento.

**(c)** Com amortecimento $c = 2$ N$\cdot$s/m, $m=1$ kg, $k=5$ N/m, $F_0=3$ N, $\omega=2$ rad/s: encontre a amplitude da resposta estacionária.
</Exercicio>

<Exercicio numero={4} fonte="ITA MA-012; Boyce-DiPrima §3.8, Ex. 20">
Mostre que a solução de $m\ddot{x}+kx=F_0\cos\omega t$, $x(0)=0$, $\dot{x}(0)=0$ pode ser escrita como $x(t) = \dfrac{F_0/m}{\omega_0^2-\omega^2}(\cos\omega t - \cos\omega_0 t)$ e use a fórmula de soma-para-produto para mostrar que, quando $\omega\to\omega_0$, $x(t) \to \dfrac{F_0}{2m\omega_0}t\sin\omega_0 t$ (limite de ressonância via L'Hôpital).
</Exercicio>

<Exercicio numero={5} fonte="USP MAT0112; Zill §5.2, Ex. 25">
**Circuito RLC:** $L=1$ H, $R=100\,\Omega$, $C=10^{-4}$ F, $E(t) = 100\sin(60t)$ V.

**(a)** Escreva a EDO para a carga $q$.

**(b)** Encontre a resposta estacionária e calcule amplitude e fase.

**(c)** Calcule a frequência de ressonância e compare com 60 rad/s.
</Exercicio>
