<Porta nivel="formal" titulo="Séries de Taylor e resto">

### Série de Taylor

Se $f$ tem derivadas de todas as ordens em $x = a$:
$$f(x) = \sum_{n=0}^\infty\frac{f^{(n)}(a)}{n!}(x-a)^n$$

Quando $a = 0$: **série de Maclaurin**.

### Resto de Taylor (forma de Lagrange)

O polinômio de Taylor de grau $N$ é $T_N(x) = \displaystyle\sum_{n=0}^N\frac{f^{(n)}(a)}{n!}(x-a)^n$.

O erro é $R_N(x) = f(x) - T_N(x)$. **Forma de Lagrange:**
$$R_N(x) = \frac{f^{(N+1)}(c)}{(N+1)!}(x-a)^{N+1}$$
para algum $c$ entre $a$ e $x$.

**Estimativa:** $|R_N(x)| \leq \dfrac{M}{(N+1)!}|x-a|^{N+1}$ onde $M = \max|f^{(N+1)}|$ no intervalo.

### Séries de Maclaurin fundamentais

$$e^x = \sum_{n=0}^\infty\frac{x^n}{n!}, \quad \text{todo }x$$
$$\sin x = \sum_{n=0}^\infty\frac{(-1)^n x^{2n+1}}{(2n+1)!}, \quad \text{todo }x$$
$$\cos x = \sum_{n=0}^\infty\frac{(-1)^n x^{2n}}{(2n)!}, \quad \text{todo }x$$
$$\ln(1+x) = \sum_{n=1}^\infty\frac{(-1)^{n-1}x^n}{n}, \quad -1 < x \leq 1$$
$$(1+x)^\alpha = \sum_{n=0}^\infty\binom{\alpha}{n}x^n, \quad |x| < 1$$

</Porta>

<Porta nivel="5anos" titulo="Aproximar com polinômios">

$e^x \approx 1 + x + x^2/2 + x^3/6$ — um polinômio de grau 3.

Para $x = 0{,}1$: $e^{0.1} \approx 1 + 0{,}1 + 0{,}005 + 0{,}00017 = 1{,}10517$. O valor real é $1{,}10517$. Muito próximo!

As séries de Taylor são a maneira de calcular funções complicadas usando apenas somas, subtrações e multiplicações.

</Porta>

<Porta nivel="10anos" titulo="Como construir a série">

Queremos $f(x) = c_0 + c_1 x + c_2 x^2 + c_3 x^3 + \cdots$.

- Em $x=0$: $f(0) = c_0$, logo $c_0 = f(0)$.
- Derive: $f'(x) = c_1 + 2c_2 x + \cdots$, em $x=0$: $c_1 = f'(0)$.
- Derive de novo: $f''(x) = 2c_2 + \cdots$, em $x=0$: $c_2 = f''(0)/2$.
- Em geral: $c_n = f^{(n)}(0)/n!$.

</Porta>

<Porta nivel="15anos" titulo="Estimando o erro">

Quantos termos de $e^x$ precisamos para aproximar $e$ com erro $< 10^{-6}$?

$|R_N(1)| \leq \dfrac{3}{(N+1)!}$ (pois $|e^c| \leq e < 3$ para $c \in [0,1]$).

Queremos $3/(N+1)! < 10^{-6}$, i.e., $(N+1)! > 3\times 10^6$.

$9! = 362880 < 3\times 10^6$, $10! = 3628800 > 3\times 10^6$. Logo $N = 9$.

</Porta>

<Porta nivel="25anos" titulo="Fórmula de Euler e séries complexas">

Estendendo a série de Maclaurin para $x = i\theta$ ($\theta$ real):
$$e^{i\theta} = \sum_{n=0}^\infty\frac{(i\theta)^n}{n!} = \sum_{n=0}^\infty\frac{(-1)^n\theta^{2n}}{(2n)!} + i\sum_{n=0}^\infty\frac{(-1)^n\theta^{2n+1}}{(2n+1)!} = \cos\theta + i\sin\theta.$$

**Fórmula de Euler:** $e^{i\pi} + 1 = 0$ (relação entre $e$, $i$, $\pi$, $0$ e $1$).

**Convergência:** o Teorema de Taylor com resto garante convergência se $|f^{(n)}(c)| \leq M\cdot n!$ não cresce mais rápido que $n!$ — condição satisfeita por funções analíticas.

</Porta>

<Porta nivel="40anos" titulo="Aplicações em engenharia">

**Linearização de sistemas:** $f(x) \approx f(x_0) + f'(x_0)(x-x_0)$ é a base do controle linear ao redor de um ponto de operação.

**Método de elementos finitos:** a série de Taylor em 2D ($f(x+h,y+k) \approx f + f_x h + f_y k + \frac{1}{2}(f_{xx}h^2 + 2f_{xy}hk + f_{yy}k^2)$) é a base das fórmulas de diferenças finitas.

**Análise de erros numéricos:** a consistência de métodos como Euler e Runge-Kutta é provada mostrando que o erro de truncamento local é $O(h^p)$ via expansão de Taylor.

**Propagação de incertezas:** $\sigma_f^2 \approx \displaystyle\sum_i\left(\frac{\partial f}{\partial x_i}\right)^2\sigma_i^2$ usa Taylor de primeira ordem.

</Porta>

<Porta nivel="pratica" titulo="Passo a passo">

1. **Calcule** $f(a), f'(a), f''(a), \ldots, f^{(N)}(a)$.
2. **Escreva** $T_N(x) = \displaystyle\sum_{n=0}^N\frac{f^{(n)}(a)}{n!}(x-a)^n$.
3. **Estime o erro:** $|R_N| \leq M|x-a|^{N+1}/(N+1)!$ onde $M$ limita $|f^{(N+1)}|$.
4. **Escolha $N$** para satisfazer a precisão desejada.
5. **Manipulação:** para encontrar a série de $g$, parta de uma série conhecida (substituição, derivação, integração).

</Porta>

</DuasPortas>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — Série de Maclaurin de seno" numero={1} fonte="Stewart §11.10, Ex. 1; Guidorizzi §9.8, Ex. 1">

Construa a série de Maclaurin de $\sin x$.

$f(x) = \sin x$: $f(0) = 0$, $f'(0) = 1$, $f''(0) = 0$, $f'''(0) = -1$, $f^{(4)}(0) = 0$, $\ldots$

Padrão: termos pares nulos, termos ímpares $(-1)^n$:
$$\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots = \sum_{n=0}^\infty\frac{(-1)^n x^{2n+1}}{(2n+1)!}.$$

</Exemplo>

<Exemplo titulo="Ex. 2 — Estimativa de erro" numero={2} fonte="Stewart §11.10, Ex. 11; OpenStax Calc II §6.3">

Aproxime $\cos(0{,}3)$ com erro $< 10^{-5}$.

$\cos x \approx 1 - x^2/2 + x^4/24 - x^6/720 + \cdots$

$|R_N(0{,}3)| \leq (0{,}3)^{N+1}/(N+1)!$.

Para $N=5$: $(0{,}3)^6/720 \approx 1{,}01\times 10^{-6} < 10^{-5}$. Suficiente com 5 termos:
$$\cos(0{,}3) \approx 1 - 0{,}045 + 0{,}0003375 - \frac{(0{,}3)^6}{720} \approx 0{,}955336.$$

</Exemplo>

<Exemplo titulo="Ex. 3 — Série por manipulação" numero={3} fonte="Stewart §11.10, Ex. 15; Guidorizzi §9.8, Ex. 7">

Encontre a série de Maclaurin de $xe^{-x^2}$.

De $e^t = \displaystyle\sum_{n=0}^\infty\frac{t^n}{n!}$, substitua $t = -x^2$:
$$e^{-x^2} = \sum_{n=0}^\infty\frac{(-1)^n x^{2n}}{n!}.$$
Multiplique por $x$:
$$xe^{-x^2} = \sum_{n=0}^\infty\frac{(-1)^n x^{2n+1}}{n!} = x - x^3 + \frac{x^5}{2} - \frac{x^7}{6}+\cdots$$

</Exemplo>

<Exemplo titulo="Ex. 4 — Limite via Taylor" numero={4} fonte="Stewart §11.10, Ex. 37; Apostol §10.23">

Calcule $\displaystyle\lim_{x\to 0}\frac{e^x - 1 - x}{x^2}$.

$e^x = 1 + x + x^2/2 + O(x^3)$. Logo $e^x - 1 - x = x^2/2 + O(x^3)$.
$$\lim_{x\to 0}\frac{x^2/2 + O(x^3)}{x^2} = \frac{1}{2}.$$

</Exemplo>

## Exercícios

### Bloco A — Construção e estimativa

<Exercicio numero={1} fonte="Stewart §11.10, Ex. 1–14; Guidorizzi §9.8, Ex. 1–8">
Encontre a série de Taylor centrada em $a$ e o raio de convergência:

**(a)** $f(x) = e^{2x}$, $a = 0$

**(b)** $f(x) = \cos x$, $a = \pi/2$

**(c)** $f(x) = \ln x$, $a = 1$

**(d)** $f(x) = \dfrac{1}{1+2x}$, $a = 0$
</Exercicio>

<Exercicio numero={2} fonte="Stewart §11.10, Ex. 15–28; OpenStax Calc II §6.3, Ex. 1–20">
Use manipulação de séries conhecidas:

**(a)** $f(x) = x^2\sin(x^3)$

**(b)** $f(x) = \dfrac{1}{\sqrt{1+x}}$ *(série binomial com $\alpha = -1/2$)*

**(c)** $f(x) = e^x\cos x$

**(d)** $\displaystyle\int_0^1\frac{1-e^{-x}}{x}\,dx$ com erro $< 10^{-4}$
</Exercicio>

### Bloco B — Resto e precisão

<Exercicio numero={3} fonte="Stewart §11.10, Ex. 35–46; Apostol §10.24">
**(a)** Quantos termos de $\cos x$ (série de Maclaurin) são necessários para calcular $\cos(0{,}5)$ com erro $< 10^{-8}$?

**(b)** Mostre que $|R_N(x)| \leq |x|^{N+1}/(N+1)!$ para $e^x$ e qualquer $x \in [0,1]$.

**(c)** Estime $\displaystyle\int_0^{0.5} e^{-x^2}\,dx$ com erro $< 10^{-6}$.
</Exercicio>

<Exercicio numero={4} fonte="Apostol §10.23; Demidovich §5.7, Ex. 40–60">
Use séries de Taylor para calcular os limites:

**(a)** $\displaystyle\lim_{x\to 0}\frac{\sin x - x + x^3/6}{x^5}$

**(b)** $\displaystyle\lim_{x\to 0}\frac{(1-\cos x)^2}{x^2-\ln(1+x^2)}$

**(c)** $\displaystyle\lim_{x\to 0}\frac{e^x - e^{\sin x}}{x^3}$
</Exercicio>

### Bloco C — Nível ITA/USP

<Exercicio numero={5} fonte="ITA MA-012; Stewart §11.10, Ex. 63–70">
Mostre que $\pi = 4\arctan(1/5) - \arctan(1/239)$ (fórmula de Machin) e use a série de $\arctan$ para calcular $\pi$ com 10 casas decimais, estimando o número de termos necessário.
</Exercicio>

<Exercicio numero={6} fonte="USP MAT0112 — 2021; Apostol §10.24">
Prove que $e$ é irracional: assuma $e = p/q$ e mostre que $q! \cdot (e - T_q(1))$ seria um inteiro positivo menor que 1, contradição. *(Dica: use o resto de Lagrange.)*
</Exercicio>

<Exercicio numero={7} fonte="ITA 2022; Apostol §10.25">
A **série de Bernoulli:** mostre que $\dfrac{x}{e^x-1} = \displaystyle\sum_{n=0}^\infty\frac{B_n x^n}{n!}$ define os números de Bernoulli e calcule $B_0, B_1, B_2, B_4$ multiplicando ambos os lados por $e^x - 1$ e igualando coeficientes.
</Exercicio>
