<Porta nivel="formal" titulo="Tabela de testes e condições de uso">

| Teste | Condição de aplicação | Conclusão | Quando preferir |
|-------|----------------------|-----------|-----------------|
| Termo geral | Sempre | $a_n\not\to 0 \Rightarrow$ div. | Primeiro passo |
| Geométrica | $a_n = ar^n$ | $\lvert r\rvert<1$: conv.; $\lvert r\rvert\geq 1$: div. | Série geométrica pura |
| Telescópica | $a_n = b_n - b_{n+1}$ | Soma $= b_1 - \lim b_n$ | Decomposição em parciais |
| Integral | $a_n = f(n)$ decrescente | Mesmo que $\int_1^\infty f$ | $f$ integr. facilmente |
| Comparação direta | $0\leq a_n\leq b_n$ | $\sum b_n<\infty\Rightarrow\sum a_n<\infty$ | Desigualdade explícita |
| LCT | $a_n/b_n\to L\in(0,\infty)$ | Mesmo comportamento | Comportamento dominante |
| Razão | $\lvert a_{n+1}/a_n\rvert\to L$ | $L<1$: c.a.; $L>1$: div. | Fatoriais, $n^n$, $x^n$ |
| Raiz | $\sqrt[n]{\lvert a_n\rvert}\to L$ | $L<1$: c.a.; $L>1$: div. | Potências da forma $(b_n)^n$ |
| Leibniz | $(-1)^n b_n$, $b_n\searrow 0$ | Converge | Série alternada |

### Soma de séries numéricas por séries de potências

Se $S = \displaystyle\sum_{n=0}^\infty a_n$ e $a_n = f^{(n)}(0)/n!$ para alguma $f$ conhecida, então $S = f(1)$.

**Exemplo:** $\displaystyle\sum_{n=0}^\infty\frac{(-1)^n}{2n+1} = \arctan(1) = \pi/4$.

**Derivação de série:** $\displaystyle\sum_{n=1}^\infty\frac{n}{2^n} = \left.\frac{d}{dx}\sum nx^{n-1}\right|_{x=1/2}$ (com cuidado no ponto de convergência).

</Porta>

```
Analisar ∑ aₙ
│
├─ aₙ → 0? NÃO → DIVERGE
│
└─ SIM → continua...
    │
    ├─ aₙ = arⁿ? → Geométrica
    │
    ├─ aₙ = bₙ − bₙ₊₁? → Telescópica
    │
    ├─ aₙ tem (−1)ⁿ? → Leibniz (verifique bₙ ↘ 0)
    │
    ├─ aₙ tem n! ou nⁿ? → Teste da Razão
    │
    ├─ aₙ = (bₙ)ⁿ? → Teste da Raiz
    │
    ├─ aₙ = f(n), f ↘? → Teste da Integral
    │
    └─ aₙ ~ 1/nᵖ (comportamento dominante)? → LCT
```

## Exemplos resolvidos — Reconhecimento de padrão

<Exemplo titulo="Ex. 1 — Combinando razão e reconhecimento" numero={1} fonte="Stewart §11.7, Ex. 1; Guidorizzi §9.6, Ex. 15">

Determine a convergência de $\displaystyle\sum_{n=1}^\infty\frac{(2n)!}{(n!)^2 4^n}$.

Razão: $\dfrac{(2n+2)!}{((n+1)!)^2 4^{n+1}}\cdot\dfrac{(n!)^2 4^n}{(2n)!} = \dfrac{(2n+2)(2n+1)}{4(n+1)^2} = \dfrac{(2n+1)}{2(n+1)} \to 1$.

Razão inconclusiva. Use LCT com $b_n = 1/\sqrt{n}$ (estimativa de Stirling: $\binom{2n}{n} \sim 4^n/\sqrt{\pi n}$):

$a_n = \binom{2n}{n}/4^n \sim 1/\sqrt{\pi n}$. LCT com $b_n = 1/\sqrt{n}$: $L = 1/\sqrt{\pi}$. Como $\sum 1/\sqrt{n}$ diverge, a série **diverge**.

</Exemplo>

<Exemplo titulo="Ex. 2 — Série de potências para soma numérica" numero={2} fonte="Stewart §11.9, Ex. 19; Apostol §10.23">

Calcule $\displaystyle\sum_{n=0}^\infty\frac{(-1)^n}{(2n+1)3^{2n+1}}$.

Reconheça: $\arctan x = \displaystyle\sum_{n=0}^\infty\frac{(-1)^n x^{2n+1}}{2n+1}$.

Dividindo por $x$: $\dfrac{\arctan x}{x} = \displaystyle\sum_{n=0}^\infty\frac{(-1)^n x^{2n}}{2n+1}$.

Em $x = 1/3$: $\displaystyle\sum_{n=0}^\infty\frac{(-1)^n}{(2n+1)3^{2n+1}} = \frac{1}{3}\cdot\frac{\arctan(1/3)}{1/3} = \arctan\frac{1}{3}$.

</Exemplo>

<Exemplo titulo="Ex. 3 — Derivação para somar" numero={3} fonte="Stewart §11.9, Ex. 21; Guidorizzi §9.8, Ex. 14">

Calcule $\displaystyle\sum_{n=1}^\infty\frac{n(-1)^{n-1}}{2^n}$.

De $\displaystyle\sum_{n=0}^\infty(-x)^n = \frac{1}{1+x}$, derive:
$\displaystyle\sum_{n=1}^\infty n(-1)^{n-1}x^{n-1} = \frac{1}{(1+x)^2}$.

Em $x = 1/2$: $\displaystyle\sum_{n=1}^\infty\frac{n(-1)^{n-1}}{2^{n-1}} = \frac{1}{(3/2)^2} = \frac{4}{9}$.

Multiplique por $1/2$: $\displaystyle\sum_{n=1}^\infty\frac{n(-1)^{n-1}}{2^n} = \dfrac{2}{9}$.

</Exemplo>

<Exemplo titulo="Ex. 4 — Série mista: comparação e Leibniz" numero={4} fonte="Guidorizzi §9.6, Ex. 20; OpenStax Calc II §5.6">

Classifique $\displaystyle\sum_{n=1}^\infty\frac{(-1)^n\ln n}{n}$.

$b_n = \ln n/n$. $b_n' = (1-\ln n)/n^2 < 0$ para $n \geq 3$ → decrescente para $n$ grande. $b_n \to 0$. Leibniz: **converge**.

$\sum |a_n| = \sum \ln n/n$. LCT com $1/n$: $L = \lim \ln n = \infty$. Como $\sum 1/n$ diverge, $\sum \ln n/n$ **diverge**.

**Conclusão:** converge **condicionalmente**.

</Exemplo>

## Exercícios do workshop de estratégias

### Série A — Reconhecimento rápido

<Exercicio numero={1} fonte="Stewart §11.7, Ex. 1–28; OpenStax Calc II §5.6, Ex. 271–300">
Determine convergência (identifique o teste mais eficiente):

**(a)** $\displaystyle\sum_{n=1}^\infty\frac{n^2 5^n}{n!}$

**(b)** $\displaystyle\sum_{n=2}^\infty\frac{1}{n\ln n(\ln\ln n)^2}$

**(c)** $\displaystyle\sum_{n=1}^\infty\frac{(-1)^n n^2}{n^3+1}$

**(d)** $\displaystyle\sum_{n=1}^\infty\left(\frac{n}{n+2}\right)^n$

**(e)** $\displaystyle\sum_{n=1}^\infty\frac{\sin(1/n^2)}{n}$
</Exercicio>

### Série B — Soma por séries de potências

<Exercicio numero={2} fonte="Stewart §11.9, Ex. 15–30; Apostol §10.23">
Calcule as somas usando séries de potências:

**(a)** $\displaystyle\sum_{n=1}^\infty\frac{n}{3^n}$

**(b)** $\displaystyle\sum_{n=0}^\infty\frac{(-1)^n\pi^{2n+1}}{4^{2n+1}(2n+1)!}$

**(c)** $\displaystyle\sum_{n=1}^\infty\frac{n^2}{2^n}$

**(d)** $\displaystyle\sum_{n=0}^\infty\frac{(-1)^n}{6^{2n}(2n)!}$
</Exercicio>

### Série C — Nível ITA/USP

<Exercicio numero={3} fonte="ITA MA-012; Stewart §11.7, Ex. 35–40">
Para quais $x$ a série $\displaystyle\sum_{n=1}^\infty\frac{(-1)^n}{\sqrt{n}}(x-3)^n$ converge? Classifique (absoluta, condicional ou divergência) em cada ponto do intervalo, incluindo as extremidades.
</Exercicio>

<Exercicio numero={4} fonte="USP MAT0112 — lista 2021; Apostol §10.25">
Use a série de Taylor de $\ln(1-x) = -\displaystyle\sum_{n=1}^\infty x^n/n$ e a fórmula de Parseval para provar que $\displaystyle\sum_{n=1}^\infty\frac{1}{n^2} = \frac{\pi^2}{6}$, integrando $\ln(1-x)^2$ e usando a fórmula de $\arcsin$.

*(Alternativa: use a série de $\ln(1+x)$ e $\ln(1-x)$ para obter $\text{Li}_2(1)$ e $\text{Li}_2(-1)$, onde $\text{Li}_2$ é o dilogatmo.)*
</Exercicio>

<Exercicio numero={5} fonte="ITA 2020; Demidovich §5.7, Ex. 80–100">
Prove que $e$ não é raiz de nenhum polinômio com coeficientes racionais (irracionalidade de $e$): use a série $e = \sum 1/n!$ e o resto de Taylor para mostrar que $\sum_{k=0}^N c_k e^k \neq 0$ para qualquer escolha de inteiros $c_k$ não todos nulos.

*(Este é um resultado clássico de Hermite (1873); o problema pede a versão simplificada para $N=1$.)*
</Exercicio>
