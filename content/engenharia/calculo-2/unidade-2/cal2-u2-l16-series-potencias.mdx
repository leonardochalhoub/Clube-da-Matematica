<Porta nivel="formal" titulo="Definições e teoremas centrais">

### Definição

Uma **série de potências** centrada em $a$ é:
$$\sum_{n=0}^\infty c_n(x-a)^n = c_0 + c_1(x-a) + c_2(x-a)^2 + \cdots$$

### Raio de convergência

**Fórmula de Hadamard:** $R = \dfrac{1}{\limsup_{n\to\infty}\sqrt[n]{|c_n|}}$ (convencione $R=0$ se $\limsup=\infty$; $R=\infty$ se $\limsup=0$).

**Fórmula da razão (quando o limite existe):** $R = \displaystyle\lim_{n\to\infty}\frac{|c_n|}{|c_{n+1}|}$.

**Teorema:** a série converge absolutamente para $|x-a| < R$ e diverge para $|x-a| > R$. Nas extremidades $x = a \pm R$, o comportamento deve ser testado individualmente.

### Operações com séries de potências

**Derivação term-a-term** (para $|x-a| < R$):
$$f'(x) = \sum_{n=1}^\infty nc_n(x-a)^{n-1}$$

**Integração term-a-term** (para $|x-a| < R$):
$$\int f(x)\,dx = C + \sum_{n=0}^\infty\frac{c_n}{n+1}(x-a)^{n+1}$$

O raio de convergência é preservado em ambas as operações.

### Séries de potências conhecidas

$$\frac{1}{1-x} = \sum_{n=0}^\infty x^n, \quad |x| < 1$$
$$e^x = \sum_{n=0}^\infty\frac{x^n}{n!}, \quad |x| < \infty$$
$$\sin x = \sum_{n=0}^\infty\frac{(-1)^n x^{2n+1}}{(2n+1)!}, \quad \cos x = \sum_{n=0}^\infty\frac{(-1)^n x^{2n}}{(2n)!}$$
$$\ln(1+x) = \sum_{n=1}^\infty\frac{(-1)^{n-1}x^n}{n}, \quad -1 < x \leq 1$$
$$\arctan x = \sum_{n=0}^\infty\frac{(-1)^n x^{2n+1}}{2n+1}, \quad |x| \leq 1$$

</Porta>

<Porta nivel="5anos" titulo="Funções como somas infinitas">

$e^x = 1 + x + x^2/2 + x^3/6 + \cdots$

Para $x = 1$: $e = 1 + 1 + 1/2 + 1/6 + 1/24 + \cdots \approx 2{,}718$.

Cada nova parcela melhora a aproximação. Uma série de potências é como um "calculador infinito" para a função!

</Porta>

<Porta nivel="10anos" titulo="Raio de convergência — zona de validade">

A série $\sum x^n = 1/(1-x)$ só vale para $|x| < 1$.

Para $x = 2$: $1 + 2 + 4 + 8 + \cdots$ diverge (claramente não é $1/(1-2) = -1$!).

O raio de convergência delimita a "zona de validade" da série. Fora dela, a aproximação polinomial não funciona.

</Porta>

<Porta nivel="15anos" titulo="Derivação e integração term-a-term">

De $\dfrac{1}{1-x} = \displaystyle\sum_{n=0}^\infty x^n$ para $|x| < 1$:

**Derivando:** $\dfrac{1}{(1-x)^2} = \displaystyle\sum_{n=1}^\infty nx^{n-1}$.

**Substituindo $x \to -x$:** $\dfrac{1}{1+x} = \displaystyle\sum_{n=0}^\infty(-1)^n x^n$.

**Integrando:** $\ln(1+x) = \displaystyle\sum_{n=1}^\infty\dfrac{(-1)^{n-1}x^n}{n}$, válido para $-1 < x \leq 1$.

</Porta>

<Porta nivel="25anos" titulo="Análise complexa e singularidades">

O raio de convergência de $\sum c_n(x-a)^n$ na reta real é determinado pela **singularidade complexa mais próxima de $a$**.

**Exemplo:** $f(x) = 1/(1+x^2)$ tem singularidades em $x = \pm i$ (complexas). A série de Maclaurin $\sum(-1)^n x^{2n}$ tem $R = 1 = |i - 0|$.

**Fórmula integral de Cauchy:** os coeficientes são $c_n = \dfrac{1}{2\pi i}\displaystyle\oint_{|z-a|=r}\frac{f(z)}{(z-a)^{n+1}}\,dz$.

**Função analítica:** $f$ é analítica em $a$ iff tem série de potências convergente em uma vizinhança de $a$.

</Porta>

<Porta nivel="40anos" titulo="Aplicações em engenharia">

**Análise de circuitos (séries de Laurent):** impedâncias são funções da frequência complexa $s$; expansão em série de Laurent ao redor de polos fornece resíduos para resposta transitória.

**Cálculo de integrais sem forma fechada:** $\displaystyle\int_0^1 e^{-x^2}\,dx \approx \displaystyle\int_0^1\sum_{n=0}^N\frac{(-1)^n x^{2n}}{n!}\,dx = \sum_{n=0}^N\frac{(-1)^n}{(2n+1)n!}$.

**Solução em série de EDO (método de Frobenius):** EDOs lineares com coeficientes polinomiais admitem soluções $y = \sum a_n x^n$ com raio dado pela singularidade mais próxima do ponto inicial.

**Transformada Z:** $H(z) = \sum_{n=0}^\infty h[n]z^{-n}$ é série de potências em $z^{-1}$ — análogo discreto da transformada de Laplace; $R$ determina a região de estabilidade do filtro.

</Porta>

<Porta nivel="pratica" titulo="Passo a passo">

1. **Encontre $R$** via razão: $R = \lim|c_n/c_{n+1}|$, ou raiz: $R = 1/\limsup\sqrt[n]{|c_n|}$.
2. **Intervalo de convergência:** $(a-R, a+R)$ e teste as extremidades $x = a \pm R$ individualmente.
3. **Para derivar/integrar:** opere term-a-term — o novo raio é o mesmo $R$.
4. **Para representar $f$:** manipule uma série conhecida por substituição, derivação ou integração.
5. **Verificação:** compare com os valores conhecidos da função nos primeiros termos.

</Porta>

</DuasPortas>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — Raio de convergência via razão" numero={1} fonte="Stewart §11.8, Ex. 1; Guidorizzi §9.7, Ex. 2">

Encontre o intervalo de convergência de $\displaystyle\sum_{n=0}^\infty\frac{(-1)^n x^n}{n+1}$.

Razão: $\displaystyle\lim\frac{|x|^{n+1}/(n+2)}{|x|^n/(n+1)} = |x|\lim\frac{n+1}{n+2} = |x|$.

$R = 1$: converge absolutamente para $|x| < 1$.

- $x = 1$: $\sum(-1)^n/(n+1)$ — alternada com $b_n \to 0$, **converge**.
- $x = -1$: $\sum 1/(n+1)$ — série harmônica, **diverge**.

Intervalo de convergência: $[-1, 1)$.

</Exemplo>

<Exemplo titulo="Ex. 2 — Derivação de série conhecida" numero={2} fonte="Stewart §11.9, Ex. 3; Guidorizzi §9.8, Ex. 3">

Represente $\dfrac{1}{(1-x)^2}$ como série de potências.

De $\dfrac{1}{1-x} = \displaystyle\sum_{n=0}^\infty x^n$, derive term-a-term:
$$\frac{d}{dx}\frac{1}{1-x} = \frac{1}{(1-x)^2} = \sum_{n=1}^\infty nx^{n-1} = \sum_{n=0}^\infty(n+1)x^n, \quad |x| < 1.$$

</Exemplo>

<Exemplo titulo="Ex. 3 — Integração para arctan" numero={3} fonte="Stewart §11.9, Ex. 5; Apostol §10.23">

Represente $\arctan x$ como série de potências.

De $\dfrac{1}{1+t^2} = \displaystyle\sum_{n=0}^\infty(-1)^n t^{2n}$ para $|t| < 1$:
$$\arctan x = \int_0^x\frac{dt}{1+t^2} = \sum_{n=0}^\infty\frac{(-1)^n x^{2n+1}}{2n+1}, \quad |x| \leq 1.$$

</Exemplo>

<Exemplo titulo="Ex. 4 — Série de potências com raio infinito" numero={4} fonte="Stewart §11.9, Ex. 1; Guidorizzi §9.7, Ex. 1">

Mostre que $\displaystyle\sum_{n=0}^\infty\frac{x^n}{n!} = e^x$ para todo $x$.

Razão: $\displaystyle\lim\frac{|x|^{n+1}/(n+1)!}{|x|^n/n!} = \lim\frac{|x|}{n+1} = 0 < 1$.

$R = \infty$: converge para todo $x \in \mathbb{R}$.

</Exemplo>

## Exercícios

### Bloco A — Raio e intervalo de convergência

<Exercicio numero={1} fonte="Stewart §11.8, Ex. 1–18; Guidorizzi §9.7, Ex. 1–10">
Encontre o raio e o intervalo de convergência:

**(a)** $\displaystyle\sum_{n=1}^\infty\frac{n}{3^n}x^n$

**(b)** $\displaystyle\sum_{n=0}^\infty\frac{(x-2)^n}{n^2+1}$

**(c)** $\displaystyle\sum_{n=0}^\infty\frac{(-1)^n x^{2n+1}}{(2n+1)!}$

**(d)** $\displaystyle\sum_{n=1}^\infty\frac{n!}{n^n}(x-1)^n$
</Exercicio>

### Bloco B — Operações com séries

<Exercicio numero={2} fonte="Stewart §11.9, Ex. 1–20; OpenStax Calc II §6.1, Ex. 1–20">
Represente as funções como séries de potências e determine o intervalo de convergência:

**(a)** $f(x) = \dfrac{x}{1+4x^2}$

**(b)** $f(x) = \ln(1-x^2)$

**(c)** $f(x) = \displaystyle\int_0^x\frac{\sin t}{t}\,dt$ *(Útil para o seno integral Si$(x)$.)*

**(d)** $f(x) = \arctan(x^2)$
</Exercicio>

<Exercicio numero={3} fonte="Apostol §10.23; Demidovich §5.7, Ex. 1–20">
Use séries de potências para calcular com erro $< 0{,}001$:

**(a)** $\displaystyle\int_0^{0.5}\frac{e^{-x^2}-1}{x}\,dx$

**(b)** $\displaystyle\int_0^{0.3}\sqrt{1+x^3}\,dx$
</Exercicio>

### Bloco C — Nível ITA/USP

<Exercicio numero={4} fonte="ITA MA-012; Stewart §11.9, Ex. 35–40">
Derive a **série binomial:** $(1+x)^\alpha = \displaystyle\sum_{n=0}^\infty\binom{\alpha}{n}x^n$ para $|x| < 1$, onde $\binom{\alpha}{n} = \dfrac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!}$.

Aplique para $\alpha = -1/2$ e obtenha $\dfrac{1}{\sqrt{1-x^2}} = \displaystyle\sum_{n=0}^\infty\dfrac{(2n)!}{4^n(n!)^2}x^{2n}$.

</Exercicio>

<Exercicio numero={5} fonte="USP MAT0112 — 2022; Apostol §10.23">
Mostre que $\displaystyle\sum_{n=1}^\infty\frac{x^n}{n} = -\ln(1-x)$ para $|x| < 1$, e use isso para calcular $\displaystyle\sum_{n=1}^\infty\frac{1}{n2^n}$ e $\displaystyle\sum_{n=1}^\infty\frac{1}{n3^n}$.
</Exercicio>

<Exercicio numero={6} fonte="ITA 2016; Apostol §10.25">
A **série de Bessel** de ordem 0 é $J_0(x) = \displaystyle\sum_{n=0}^\infty\frac{(-1)^n x^{2n}}{4^n(n!)^2}$.

**(a)** Verifique que $R = \infty$.

**(b)** Mostre que $J_0$ satisfaz a EDO de Bessel: $xJ_0''(x) + J_0'(x) + xJ_0(x) = 0$.
</Exercicio>
