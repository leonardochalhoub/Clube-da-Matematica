<Porta nivel="formal" titulo="Definições e séries canônicas">

### Definição de convergência

A série $\displaystyle\sum_{n=1}^\infty a_n$ **converge** para $S$ se $\displaystyle\lim_{N\to\infty}S_N = S$ onde $S_N = \displaystyle\sum_{n=1}^N a_n$.

Se o limite não existe ou é $\pm\infty$, a série **diverge**.

### Série geométrica

$$\sum_{n=0}^\infty ar^n = \frac{a}{1-r}, \quad |r| < 1. \qquad \text{Diverge se } |r| \geq 1.$$

**Prova:** $S_N = a(1-r^{N+1})/(1-r) \xrightarrow{N\to\infty} a/(1-r)$ quando $|r| < 1$.

### Série telescópica

Se $a_n = b_n - b_{n+1}$:
$$\sum_{n=1}^\infty a_n = \sum_{n=1}^\infty(b_n-b_{n+1}) = b_1 - \lim_{n\to\infty}b_n.$$

### Série harmônica

$$\sum_{n=1}^\infty\frac{1}{n} \text{ diverge.}$$

**Prova por agrupamento (Oresme):** $\frac{1}{3}+\frac{1}{4} > \frac{1}{2}$; $\frac{1}{5}+\cdots+\frac{1}{8} > \frac{1}{2}$; etc.

### Teste do termo geral (condição necessária)

Se $\displaystyle\sum a_n$ converge, então $a_n \to 0$.

**Contrapositivo:** se $a_n \not\to 0$, a série diverge.

**Cuidado:** $a_n \to 0$ é **necessário mas não suficiente** (série harmônica: $1/n \to 0$ mas diverge).

### Propriedades lineares

Se $\displaystyle\sum a_n = A$ e $\displaystyle\sum b_n = B$:
$$\sum(ca_n + db_n) = cA + dB.$$

</Porta>

<Porta nivel="5anos" titulo="Somas infinitas podem ser finitas">

$\frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \frac{1}{16} + \cdots = 1$

Imagina: você percorre metade do caminho, depois metade do que sobrou, depois metade de novo. Nunca chega ao final, mas fica cada vez mais próximo de 1. A soma total é exatamente 1.

</Porta>

<Porta nivel="10anos" titulo="Série geométrica — visualização">

$S = 1 + r + r^2 + r^3 + \cdots$ para $|r| < 1$.

Multiplique por $r$: $rS = r + r^2 + r^3 + \cdots$

Subtraia: $S - rS = 1$, logo $S(1-r) = 1$, $S = 1/(1-r)$.

Para $r = 1/2$: $S = 1/(1-1/2) = 2$.
Para $r = -1/2$: $S = 1/(1+1/2) = 2/3$.

</Porta>

<Porta nivel="15anos" titulo="Série telescópica">

$\displaystyle\sum_{n=1}^\infty\frac{1}{n(n+1)} = \sum_{n=1}^\infty\left(\frac{1}{n}-\frac{1}{n+1}\right)$.

$S_N = \left(\frac{1}{1}-\frac{1}{2}\right)+\left(\frac{1}{2}-\frac{1}{3}\right)+\cdots+\left(\frac{1}{N}-\frac{1}{N+1}\right) = 1 - \frac{1}{N+1} \to 1$.

A maioria dos termos "cancela" como um telescópio que fecha!

</Porta>

<Porta nivel="25anos" titulo="Soma de séries clássicas">

**Séries de Basel (Euler):**
$$\sum_{n=1}^\infty\frac{1}{n^2} = \frac{\pi^2}{6}, \qquad \sum_{n=1}^\infty\frac{1}{n^4} = \frac{\pi^4}{90}$$

**Série de Leibniz:**
$$\sum_{n=0}^\infty\frac{(-1)^n}{2n+1} = 1-\frac{1}{3}+\frac{1}{5}-\cdots = \frac{\pi}{4}$$

**Série de Mercator:**
$$\sum_{n=1}^\infty\frac{(-1)^{n+1}}{n} = 1-\frac{1}{2}+\frac{1}{3}-\cdots = \ln 2$$

**Função Zeta de Riemann:**
$$\zeta(s) = \sum_{n=1}^\infty\frac{1}{n^s}, \quad s > 1.$$
A hipótese de Riemann ($\zeta(s) = 0 \Rightarrow \text{Re}(s) = 1/2$) permanece um dos maiores problemas em aberto da matemática.

</Porta>

<Porta nivel="40anos" titulo="Aplicações em engenharia">

**Análise de Fourier:** a série de Fourier de um sinal periódico $f(t)$ é $\sum (a_n\cos n\omega t + b_n\sin n\omega t)$. Convergência garante reconstrução do sinal a partir de harmônicas.

**Controle digital:** a resposta de um filtro digital a impulso unitário é uma sequência $h[n]$; o sistema é estável se $\sum |h[n]| < \infty$.

**Cálculo numérico:** série de Taylor de $e^x$ é usada para implementar funções matemáticas em hardware (CORDIC, FPU).

**Teoria de filas:** a probabilidade de $n$ clientes em fila M/M/1 é $p_n = (1-\rho)\rho^n$ — série geométrica que soma 1.

</Porta>

<Porta nivel="pratica" titulo="Passo a passo">

1. **Verifique** se $a_n \to 0$; se não, a série diverge (teste do termo geral).
2. **Reconheça** se é geométrica ($ar^n$) ou telescópica ($b_n - b_{n+1}$).
3. **Para geométrica:** calcule $|r|$; se $< 1$, soma $= a/(1-r)$; se $\geq 1$, diverge.
4. **Para telescópica:** calcule $S_N$ e tome o limite.
5. **Caso contrário:** use testes de convergência (lições 13–16).

</Porta>

</DuasPortas>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — Série geométrica" numero={1} fonte="Stewart §11.2, Ex. 3; Guidorizzi §9.2, Ex. 2">

Calcule $\displaystyle\sum_{n=0}^\infty\left(\frac{2}{3}\right)^n$.

$r = 2/3$, $|r| < 1$, $a = 1$. Logo $S = \dfrac{1}{1-2/3} = 3$.

</Exemplo>

<Exemplo titulo="Ex. 2 — Série telescópica" numero={2} fonte="Stewart §11.2, Ex. 7; OpenStax Calc II §5.2">

Calcule $\displaystyle\sum_{n=1}^\infty\ln\frac{n}{n+1}$.

$a_n = \ln n - \ln(n+1)$. Telescópica: $S_N = \ln 1 - \ln(N+1) = -\ln(N+1) \to -\infty$.

A série **diverge**.

</Exemplo>

<Exemplo titulo="Ex. 3 — Teste do termo geral" numero={3} fonte="Stewart §11.2, Ex. 11; Guidorizzi §9.2, Ex. 7">

Mostre que $\displaystyle\sum_{n=1}^\infty\frac{n}{2n+1}$ diverge.

$a_n = n/(2n+1) \to 1/2 \neq 0$. Pelo teste do termo geral, a série diverge.

</Exemplo>

<Exemplo titulo="Ex. 4 — Decomposição em frações parciais + telescópio" numero={4} fonte="Stewart §11.2, Ex. 17; Apostol §10.14">

Calcule $\displaystyle\sum_{n=1}^\infty\frac{1}{n(n+2)}$.

$\dfrac{1}{n(n+2)} = \dfrac{1/2}{n} - \dfrac{1/2}{n+2}$.

$S_N = \dfrac{1}{2}\left[\left(1-\dfrac{1}{3}\right)+\left(\dfrac{1}{2}-\dfrac{1}{4}\right)+\cdots+\left(\dfrac{1}{N}-\dfrac{1}{N+2}\right)\right] = \dfrac{1}{2}\left[1+\dfrac{1}{2}-\dfrac{1}{N+1}-\dfrac{1}{N+2}\right] \to \dfrac{3}{4}$.

</Exemplo>

**(a)** $\displaystyle\sum_{n=1}^\infty\frac{3}{(-2)^n}$

**(c)** $\displaystyle\sum_{n=1}^\infty\frac{1}{\sqrt{n}+\sqrt{n+1}}$

**(d)** $\displaystyle\sum_{n=1}^\infty\left(\sin\frac{1}{n}-\sin\frac{1}{n+1}\right)$

### Bloco B — Soma de séries clássicas

<Exercicio numero={3} fonte="Apostol §10.14; Demidovich §5.2, Ex. 1–20">

**(a)** $\displaystyle\sum_{n=1}^\infty\frac{1}{n(n+1)(n+2)} = \frac{1}{4}$ (decomposição em frações parciais + telescópio).

**(b)** $\displaystyle\sum_{n=0}^\infty\frac{(-1)^n}{4^n} = \frac{4}{5}$.

**(c)** $\displaystyle\sum_{n=1}^\infty\frac{1}{4n^2-1} = \frac{1}{2}$ *(dica: frações parciais)*.
</Exercicio>
