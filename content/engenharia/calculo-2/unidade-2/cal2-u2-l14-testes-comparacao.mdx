<Porta nivel="formal" titulo="Testes de comparação">

### Teste da comparação direta

Sejam $0 \leq a_n \leq b_n$ para todo $n$ suficientemente grande.

- Se $\displaystyle\sum b_n$ **converge**, então $\displaystyle\sum a_n$ **converge**.
- Se $\displaystyle\sum a_n$ **diverge**, então $\displaystyle\sum b_n$ **diverge**.

**Prova:** as somas parciais de $\sum a_n$ são limitadas acima pelas de $\sum b_n$ (caso convergente).

### Teste da comparação no limite (LCT)

Sejam $a_n, b_n > 0$. Se $\displaystyle\lim_{n\to\infty}\frac{a_n}{b_n} = L$ com $0 < L < \infty$, então:
$$\sum a_n \text{ converge} \iff \sum b_n \text{ converge.}$$

**Casos degenerados:**
- $L = 0$: se $\sum b_n$ converge, então $\sum a_n$ converge.
- $L = \infty$: se $\sum b_n$ diverge, então $\sum a_n$ diverge.

### Estratégia de escolha da série de referência

1. Identifique o **comportamento dominante** de $a_n$ para $n$ grande.
2. Escolha $b_n$ da mesma ordem: se $a_n \sim c/n^p$, compare com $\sum 1/n^p$.
3. Use LCT para confirmar.

**Exemplos de comportamentos dominantes:**
- $a_n = \frac{n^2+1}{n^3+5} \sim \frac{1}{n}$ → compare com $\sum 1/n$ (diverge).
- $a_n = \frac{1}{\sqrt{n^2+1}} \sim \frac{1}{n}$ → compare com $\sum 1/n$ (diverge).
- $a_n = \frac{1}{n^2+n} \sim \frac{1}{n^2}$ → compare com $\sum 1/n^2$ (converge).

</Porta>

<Porta nivel="5anos" titulo="Comparar para concluir">

Se você sabe que uma mochila pesa menos de 5 kg, e outra mochila pesa menos que a primeira, então a segunda pesa menos de 5 kg também.

Com séries: se $a_n \leq b_n$ e a soma de $b_n$ é finita, então a soma de $a_n$ também é finita — ela fica "embaixo" de algo finito.

</Porta>

<Porta nivel="10anos" titulo="Comportamento dominante">

Para $n$ grande, $\dfrac{n^2+3n+1}{n^3+5} \approx \dfrac{n^2}{n^3} = \dfrac{1}{n}$.

O numerador e denominador são dominados pelos termos de maior grau! Então o comportamento de $a_n$ é o mesmo que $1/n$, e como $\sum 1/n$ diverge, nossa série também diverge.

O teste do limite formaliza essa intuição.

</Porta>

<Porta nivel="15anos" titulo="LCT em ação">

Determine se $\displaystyle\sum_{n=1}^\infty\frac{1}{\sqrt{n^2+n+1}}$ converge.

$a_n = 1/\sqrt{n^2+n+1}$. Comportamento dominante: $\sim 1/n$. Compare com $b_n = 1/n$.

$$L = \lim_{n\to\infty}\frac{a_n}{b_n} = \lim_{n\to\infty}\frac{n}{\sqrt{n^2+n+1}} = \lim_{n\to\infty}\frac{1}{\sqrt{1+1/n+1/n^2}} = 1.$$

Como $L = 1 \in (0,\infty)$ e $\sum 1/n$ diverge, a série dada **diverge**.

</Porta>

<Porta nivel="25anos" titulo="Testes para séries de termos positivos — panorama">

| Teste | Quando usar | Conclusão |
|-------|-------------|-----------|
| Comparação direta | Desigualdade explícita disponível | Uma domina a outra |
| Comparação no limite | Comportamento assintótico identificável | Mesmo comportamento |
| Integral | $a_n = f(n)$ com $f$ decrescente | Mesmo comportamento que $\int f$ |
| Razão (L15) | Termos com fatoriais ou exponenciais | $L < 1$: conv.; $L > 1$: div. |
| Raiz (L15) | Termos da forma $(b_n)^n$ | $L < 1$: conv.; $L > 1$: div. |

**Refinamento:** para comparar $\sum a_n$ com $\sum b_n$, o LCT garante que $a_n \leq Cb_n$ para $n$ grande, pois $L$ finito implica $|a_n/b_n - L| < \varepsilon$ logo $a_n < (L+\varepsilon)b_n$.

</Porta>

<Porta nivel="40anos" titulo="Aplicações em análise numérica e engenharia">

**Séries de Laurent e convergência de resíduos:** em análise complexa, a comparação com séries geométricas prova a convergência de expansões em séries de Laurent ao redor de singularidades.

**Análise de algoritmos:** a complexidade média de algoritmos de divisão e conquista satisfaz recorrências cujas somas são comparadas com séries-p para determinar a ordem de crescimento (master theorem).

**Estimativa de soma de erros:** em simulação numérica, os erros de truncamento são $a_n = O(n^{-p})$; a comparação confirma quando a soma cumulativa de erros é limitada.

**Convergência de produtos infinitos:** $\prod(1+a_n)$ converge absolutamente iff $\sum|a_n| < \infty$, testado por comparação.

</Porta>

<Porta nivel="pratica" titulo="Passo a passo">

1. **Identifique** o comportamento dominante de $a_n$ para $n\to\infty$.
2. **Escolha** $b_n$ com o mesmo comportamento (série-p ou geométrica).
3. **Aplique** o LCT: calcule $L = \lim a_n/b_n$.
   - Se $0 < L < \infty$: mesma convergência que $\sum b_n$.
   - Se $L = 0$: $\sum a_n$ converge se $\sum b_n$ converge.
   - Se $L = \infty$: $\sum a_n$ diverge se $\sum b_n$ diverge.
4. **Alternativa** (comparação direta): encontre uma desigualdade explícita $a_n \leq b_n$ ou $a_n \geq b_n$.

</Porta>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — LCT com série-p" numero={1} fonte="Stewart §11.4, Ex. 1; Guidorizzi §9.4, Ex. 2">

Determine se $\displaystyle\sum_{n=1}^\infty\frac{n^2+1}{n^4+n^2+1}$ converge.

$a_n \sim n^2/n^4 = 1/n^2$. LCT com $b_n = 1/n^2$:
$$L = \lim\frac{n^4+n^2}{n^4+n^2+1} = 1.$$
Como $\sum 1/n^2$ converge ($p=2>1$), a série **converge**.

</Exemplo>

<Exemplo titulo="Ex. 2 — Comparação direta" numero={2} fonte="Stewart §11.4, Ex. 3; OpenStax Calc II §5.4">

Mostre que $\displaystyle\sum_{n=1}^\infty\frac{\sin^2 n}{n^2}$ converge.

$0 \leq \sin^2 n \leq 1$, logo $0 \leq \dfrac{\sin^2 n}{n^2} \leq \dfrac{1}{n^2}$.

Como $\sum 1/n^2$ converge, pela comparação direta, a série **converge**.

</Exemplo>

<Exemplo titulo="Ex. 3 — LCT com divergência" numero={3} fonte="Stewart §11.4, Ex. 9; Guidorizzi §9.4, Ex. 5">

Determine se $\displaystyle\sum_{n=1}^\infty\frac{1+n\ln n}{n^2+5}$ converge.

$a_n \sim n\ln n/n^2 = \ln n/n$. LCT com $b_n = \ln n/n$:
$$L = \lim\frac{(1+n\ln n)n}{(n^2+5)\ln n} = \lim\frac{n^2\ln n + n}{n^2\ln n + 5\ln n} = 1.$$
Como $\sum \ln n/n \geq \sum 1/n$ diverge (para $n \geq 3$, $\ln n \geq 1$), a série **diverge**.

</Exemplo>

<Exemplo titulo="Ex. 4 — Série com seno" numero={4} fonte="Guidorizzi §9.4, Ex. 8; Apostol §10.16">

Determine se $\displaystyle\sum_{n=1}^\infty\sin\frac{1}{n}$ converge.

$\sin(1/n) \sim 1/n$ para $n$ grande. LCT com $b_n = 1/n$:
$$L = \lim n\sin\frac{1}{n} = \lim\frac{\sin(1/n)}{1/n} = 1.$$
Como $\sum 1/n$ diverge, a série **diverge**.

</Exemplo>
