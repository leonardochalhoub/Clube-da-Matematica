<Porta nivel="formal" titulo="Teorema de mudança de variáveis">

### Caso 2D

Seja $T: S\to D$ com $T(u,v) = (x(u,v), y(u,v))$, $C^1$, injetiva no interior.

**Jacobiano:** $J_T(u,v) = \dfrac{\partial(x,y)}{\partial(u,v)} = \begin{vmatrix}x_u & x_v\\y_u & y_v\end{vmatrix} = x_u y_v - x_v y_u$

$$\iint_D f(x,y)\,dA = \iint_S f(T(u,v))\,|J_T(u,v)|\,du\,dv$$

### Caso 3D

$$\iiint_E f(x,y,z)\,dV = \iiint_S f(T(\mathbf{u}))\,|\det J_T(\mathbf{u})|\,d\mathbf{u}$$

### Transformações úteis

| Transformação | Jacobiano |
|--------------|-----------|
| Polares $(r,\theta)\to(x,y)$ | $r$ |
| Cilíndricas $(r,\theta,z)\to(x,y,z)$ | $r$ |
| Esféricas $(\rho,\phi,\theta)\to(x,y,z)$ | $\rho^2\sin\phi$ |
| Linear $x=au$, $y=bv$ | $\lvert ab\rvert$ |
| Elíptica $x=ar\cos\theta$, $y=br\sin\theta$ | $abr$ |
| Elipsoidal $x=a\rho\sin\phi\cos\theta$, etc. | $abc\rho^2\sin\phi$ |

### Propriedade de composição

Se $T = T_2\circ T_1$: $|J_T| = |J_{T_2}|\cdot|J_{T_1}|$ — o jacobiano composto é produto dos jacobianos.

</Porta>

<Porta nivel="5anos" titulo="O que o jacobiano mede?">

Pense no jacobiano como um "fator de ampliação": se um quadradinho de área $\Delta u\,\Delta v$ no plano $(u,v)$ é mapeado para uma região no plano $(x,y)$, o jacobiano diz quantas vezes a área foi multiplicada.

Polares: um quadradinho $\Delta r\,\Delta\theta$ longe da origem vira uma célula de área $r\,\Delta r\,\Delta\theta$ — o fator $r$ é exatamente o jacobiano!

</Porta>

<Porta nivel="10anos" titulo="Como escolher a transformação">

**Objetivo:** simplificar a região $D$ ou o integrando $f$.

**Estratégia 1 — simplificar a região:** se $D$ é um paralelogramo ou elipse, use uma transformação linear que o leve ao quadrado unitário ou disco unitário.

**Estratégia 2 — simplificar o integrando:** se $f$ contém $x/a + y/b$, defina $u = x/a + y/b$; se contém $x-y$, defina $u = x-y$.

**Exemplo:** para $D$ = paralelogramo com lados $\{ax+by = c_1\}$ e $\{cx+dy = c_2\}$, defina $u = ax+by$, $v = cx+dy$.

</Porta>

<Porta nivel="15anos" titulo="Jacobiano inverso e a relação dual">

Se $T: S\to D$ tem jacobiano $J_T$, então $T^{-1}: D\to S$ tem jacobiano $J_{T^{-1}} = 1/J_T$.

Na prática, às vezes é mais fácil calcular $\partial(u,v)/\partial(x,y)$ e tomar o recíproco:

$$\frac{\partial(x,y)}{\partial(u,v)} = \frac{1}{\partial(u,v)/\partial(x,y)}$$

**Exemplo:** para polares, $\partial(r,\theta)/\partial(x,y) = 1/r$, confirmando que $\partial(x,y)/\partial(r,\theta) = r$.

</Porta>

<Porta nivel="25anos" titulo="Jacobiano e orientação">

$J_T > 0$: a transformação preserva orientação (não vira o espaço).
$J_T < 0$: a transformação inverte orientação.
$J_T = 0$: a transformação colapsa área (singular — não use como mudança de variáveis).

Na fórmula de mudança de variáveis, usa-se $|J_T|$ para integrar a função sem considerar orientação. Para integrais de formas diferenciais (cálculo exterior), o sinal importa.

**Transformação linear:** $T(u,v) = A\begin{pmatrix}u\\v\end{pmatrix}$; o jacobiano é $\det A$. Se $A$ é uma rotação, $|\det A| = 1$ — rotações preservam área, como esperado.

</Porta>

<Porta nivel="40anos" titulo="Aplicações em engenharia">

**FEA — mapeamento isoparamétrico:** em elementos finitos, o elemento de referência (quadrado unitário) é mapeado para o elemento real por uma transformação $T$; a rigidez é integrada no elemento de referência usando $|J_T|$ para compensar a deformação.

**CFD — malhas estruturadas:** as equações de Navier-Stokes são reescritas em coordenadas curvilíneas do domínio computacional usando o tensor métrico $g_{ij}$ (relacionado ao jacobiano): $\sqrt{|g|} = |J_T|$.

**Processamento de imagens:** transformações afins (rotação, escala, cisalhamento) de imagens usam jacobianos para preservar (ou controlar) a área no mapeamento de pixels.

</Porta>

<Porta nivel="pratica" titulo="Passo a passo">

1. **Identifique** o que simplificar: região ou integrando.
2. **Defina** a transformação $T$: escreva $(x,y)$ em função de $(u,v)$.
3. **Calcule** o jacobiano $J = x_u y_v - x_v y_u$.
4. **Encontre** a região $S = T^{-1}(D)$ nos novos parâmetros.
5. **Substitua**: $f(x(u,v), y(u,v))\cdot|J|\,du\,dv$.
6. **Calcule** a integral sobre $S$ (que deve ser mais simples).

</Porta>

</DuasPortas>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — Paralelogramo via transformação linear" numero={1} fonte="Stewart §15.10, Ex. 5; Apostol vol. 2 §11.8, Ex. 3">

Calcule $\iint_D (x-y)^2\,dA$ onde $D$ é o quadrado com vértices $(0,0)$, $(1,1)$, $(2,0)$, $(1,-1)$.

Defina $u = x-y$, $v = x+y$. Então $x = (u+v)/2$, $y = (v-u)/2$.

$J = \begin{vmatrix}1/2&1/2\\-1/2&1/2\end{vmatrix} = 1/2$.

$D$ em $(u,v)$: $S = [-1,1]\times[0,2]$.

$$\iint_S u^2\cdot\frac{1}{2}\,du\,dv = \frac{1}{2}\int_0^2\!\int_{-1}^1 u^2\,du\,dv = \frac{1}{2}\cdot 2\cdot\frac{2}{3} = \frac{2}{3}.$$

</Exemplo>

<Exemplo titulo="Ex. 2 — Elipse via escalonamento" numero={2} fonte="Stewart §15.10, Ex. 9; Guidorizzi vol. 3 §3.1, Ex. 5">

Área da elipse $\frac{x^2}{a^2}+\frac{y^2}{b^2}\leq 1$.

Defina $x = ar\cos\theta$, $y = br\sin\theta$. Jacobiano: $abr$.

$D$ = disco $r\leq 1$, $0\leq\theta\leq 2\pi$.

$$A = \int_0^{2\pi}\!\int_0^1 abr\,dr\,d\theta = ab\pi.$$

</Exemplo>

<Exemplo titulo="Ex. 3 — Integrando simplificado" numero={3} fonte="Apostol vol. 2 §11.8, Ex. 8; Guidorizzi vol. 3 §3.1, Ex. 10">

Calcule $\iint_D e^{(x+y)/(x-y)}\,dA$ onde $D = \{x-y\geq 1, x+y\geq 0, x\leq 2\}$.

Defina $u = x+y$, $v = x-y$. Jacobiano: $|J| = 1/2$ (calculado como acima).

$S$: $v\geq 1$, $u\geq 0$, $(u+v)/2\leq 2 \Rightarrow u+v\leq 4$.

$$\frac{1}{2}\int_1^{\infty}\!\int_0^{4-v} e^{u/v}\,du\,dv \quad \text{(cuidado: limites ficam } v\in[1,4]\text{)}.$$

Para $v\in[1,4]$: $\frac{1}{2}\int_1^4 v(e^{(4-v)/v}-1)\,dv$ — resolvível mas trabalhoso.

</Exemplo>

## Exercícios

### Bloco A — Transformações lineares

<Exercicio numero={1} fonte="Stewart §15.10, Ex. 1–10; Apostol vol. 2 §11.8, Ex. 1–10">
**(a)** Use $u = x+y$, $v = x-y$ para calcular $\iint_D \cos\!\left(\frac{x-y}{x+y}\right)\!dA$ onde $D$ é o triângulo $(0,0)$, $(2,0)$, $(0,2)$.

**(b)** Encontre a área delimitada por $xy = 1$, $xy = 2$, $y = x$, $y = 2x$ usando $u = xy$, $v = y/x$.

**(c)** Use uma transformação adequada para calcular $\iint_D (x^2-y^2)\,dA$ onde $D$ é o retângulo de lados $x+y = 0$, $x+y = 2$, $x-y = 0$, $x-y = 1$.
</Exercicio>

### Bloco B — Regiões gerais

<Exercicio numero={2} fonte="Stewart §15.10, Ex. 11–20; Guidorizzi vol. 3 §3.1, Ex. 1–10">
**(a)** Calcule $\iint_D e^{x+y}\,dA$ onde $D$ é o quadrilátero com vértices $(0,0)$, $(1,0)$, $(2,1)$, $(1,1)$ usando $u=x$, $v=y-x$.

**(b)** Re-derive o volume do elipsoide $x^2/a^2+y^2/b^2+z^2/c^2\leq 1$ usando a transformação elipsoidal.
</Exercicio>

### Bloco C — Nível ITA/USP

<Exercicio numero={3} fonte="ITA MA-012; Apostol vol. 2 §11.8, Ex. 15–20">
**(a)** Use a transformação $u = x^2-y^2$, $v = 2xy$ para calcular $\iint_D (x^2-y^2)\,dA$ onde $D = \{x^2-y^2\leq 1, 2xy\leq 1, x\geq 0, y\geq 0\}$.

**(b)** Mostre que o jacobiano de $T(r,\theta) = (r^n\cos(n\theta), r^n\sin(n\theta))$ é $nr^{2n-1}$ e use isso para calcular $\iint_{r\leq 1} (x^2+y^2)^{n-1}dA$ de forma simples.
</Exercicio>
