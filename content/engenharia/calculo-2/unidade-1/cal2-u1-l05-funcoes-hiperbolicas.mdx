<Porta nivel="formal" titulo="Definições e identidades completas">

### Definições

$$\sinh x = \frac{e^x-e^{-x}}{2}, \quad \cosh x = \frac{e^x+e^{-x}}{2}$$
$$\tanh x = \frac{\sinh x}{\cosh x}, \quad \coth x = \frac{\cosh x}{\sinh x}, \quad \text{sech}\,x = \frac{1}{\cosh x}, \quad \text{csch}\,x = \frac{1}{\sinh x}$$

### Identidades fundamentais

| Identidade | Análogo circular |
|-----------|-----------------|
| $\cosh^2 x - \sinh^2 x = 1$ | $\cos^2\theta + \sin^2\theta = 1$ |
| $1 - \tanh^2 x = \text{sech}^2 x$ | $1 + \tan^2\theta = \sec^2\theta$ |
| $\sinh(x\pm y) = \sinh x\cosh y \pm \cosh x\sinh y$ | $\sin(\alpha\pm\beta)$ |
| $\cosh(x\pm y) = \cosh x\cosh y \pm \sinh x\sinh y$ | $\cos(\alpha\pm\beta)$ |
| $\sinh(2x) = 2\sinh x\cosh x$ | $\sin 2\theta = 2\sin\theta\cos\theta$ |
| $\cosh(2x) = \cosh^2 x + \sinh^2 x = 2\cosh^2 x - 1$ | $\cos 2\theta$ |

### Derivadas e integrais

| Função | Derivada | Integral |
|--------|---------|---------|
| $\sinh x$ | $\cosh x$ | $\cosh x + C$ |
| $\cosh x$ | $\sinh x$ | $\sinh x + C$ |
| $\tanh x$ | $\text{sech}^2 x$ | $\ln\cosh x + C$ |
| $\text{sech}\,x$ | $-\text{sech}\,x\tanh x$ | $\arctan(\sinh x)+C$ |
| $\text{csch}\,x$ | $-\text{csch}\,x\coth x$ | $\ln\lvert \tanh(x/2)\rvert+C$ |

### Inversas hiperbólicas

$$\sinh^{-1}x = \ln(x+\sqrt{x^2+1}), \quad \cosh^{-1}x = \ln(x+\sqrt{x^2-1}), \; x\geq 1$$
$$\tanh^{-1}x = \frac{1}{2}\ln\frac{1+x}{1-x}, \; |x|<1$$

### Derivadas das inversas

$$\frac{d}{dx}\sinh^{-1}x = \frac{1}{\sqrt{x^2+1}}, \quad \frac{d}{dx}\cosh^{-1}x = \frac{1}{\sqrt{x^2-1}}, \quad \frac{d}{dx}\tanh^{-1}x = \frac{1}{1-x^2}$$

</Porta>

<Porta nivel="5anos" titulo="A hipérbole e o círculo">

No círculo: $\cos\theta$ e $\sin\theta$ são as coordenadas de um ponto, e $\cos^2\theta + \sin^2\theta = 1$.

Na hipérbole: $\cosh t$ e $\sinh t$ são as coordenadas, e $\cosh^2 t - \sinh^2 t = 1$.

A diferença é um sinal de menos! As funções hiperbólicas são as "irmãs" das trigonométricas, mas vivem na hipérbole em vez do círculo.

</Porta>

<Porta nivel="10anos" titulo="Por que a catenary é um cosh">

Um cabo pendurado entre dois postes tem formato de catenária:
$$y = a\cosh\frac{x}{a}.$$

Isso aparece porque a equação de equilíbrio do cabo envolve a razão entre tensão horizontal e peso, que satisfaz exatamente a equação diferencial $y'' = \sqrt{1+(y')^2}/a$, cuja solução é o cosseno hiperbólico.

</Porta>

<Porta nivel="15anos" titulo="Substituições hiperbólicas para radicais">

Assim como há substituições trigonométricas circulares, há substituições hiperbólicas:

- Para $\sqrt{x^2+a^2}$: use $x = a\sinh t$, pois $\sqrt{a^2\sinh^2 t+a^2} = a\cosh t$.
- Para $\sqrt{x^2-a^2}$: use $x = a\cosh t$, pois $\sqrt{a^2\cosh^2 t-a^2} = a\sinh t$.

**Exemplo:** $\displaystyle\int\frac{dx}{\sqrt{x^2+1}}$. Com $x = \sinh t$, $dx = \cosh t\,dt$:
$$\int\frac{\cosh t\,dt}{\cosh t} = t + C = \sinh^{-1}x + C = \ln(x+\sqrt{x^2+1})+C.$$

</Porta>

<Porta nivel="25anos" titulo="Conexão com funções circulares complexas">

As funções hiperbólicas são funções circulares de argumento imaginário:
$$\cosh x = \cos(ix), \quad \sinh x = -i\sin(ix).$$

Isso explica por que as identidades hiperbólicas diferem das circulares apenas em sinais: as identidades de Euler $e^{i\theta} = \cos\theta + i\sin\theta$ e $e^x = \cosh x + \sinh x$ são formalmente análogas.

**Fórmula de Osborn:** para converter identidades circulares em hiperbólicas, substitua $\sin\theta \to \sinh$, $\cos\theta \to \cosh$, e mude o sinal de qualquer produto de dois $\sinh$.

**Integrais canônicas resultantes:**
$$\int\frac{dx}{\sqrt{x^2\pm a^2}} = \ln\left|x+\sqrt{x^2\pm a^2}\right|+C$$

</Porta>

<Porta nivel="40anos" titulo="Aplicações em engenharia">

**Catenária e pontes pênseis:** o cabo do Golden Gate segue $y = a\cosh(x/a)$. O comprimento de arco $L = \int_0^d\sqrt{1+\sinh^2(x/a)}\,dx = a\sinh(d/a)$.

**Equação do calor em estado estacionário:** em coordenadas cilíndricas, soluções radialmente simétricas envolvem funções de Bessel modificadas $I_0$ e $K_0$, que para grandes argumentos se comportam como $e^x/\sqrt{x}$, análogo às hiperbólicas.

**Teoria da relatividade especial:** o parâmetro de rapidez $\phi$ satisfaz $v = c\tanh\phi$, e a transformação de Lorentz é formalmente uma rotação hiperbólica.

**Linha de transmissão (telegrafia):** a equação de telegrafista admite soluções $\cosh(\gamma x)$ e $\sinh(\gamma x)$ para ondas estacionárias em linha terminada.

</Porta>

<Porta nivel="pratica" titulo="Passo a passo">

1. **Reconheça** o radical ou a expressão que sugere substituição hiperbólica ($\sqrt{x^2+a^2}$ ou $\sqrt{x^2-a^2}$).
2. **Substitua** $x = a\sinh t$ ou $x = a\cosh t$ conforme o caso.
3. **Use** a identidade $\cosh^2 t - \sinh^2 t = 1$ para simplificar o radical.
4. **Calcule** a integral em $t$.
5. **Retorne** a $x$ usando $\sinh^{-1}(x/a) = \ln(x/a + \sqrt{x^2/a^2+1})$.

</Porta>

</DuasPortas>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — Derivada de sinh e cosh" numero={1} fonte="Stewart §6.7, Ex. 1–4; Guidorizzi §6.5, Ex. 1">

Verifique que $\dfrac{d}{dx}\sinh x = \cosh x$ e $\dfrac{d}{dx}\cosh x = \sinh x$.

Por definição: $\dfrac{d}{dx}\sinh x = \dfrac{d}{dx}\dfrac{e^x-e^{-x}}{2} = \dfrac{e^x+e^{-x}}{2} = \cosh x$. $\checkmark$

$\dfrac{d}{dx}\cosh x = \dfrac{d}{dx}\dfrac{e^x+e^{-x}}{2} = \dfrac{e^x-e^{-x}}{2} = \sinh x$. $\checkmark$

</Exemplo>

<Exemplo titulo="Ex. 2 — Integral com substituição hiperbólica" numero={2} fonte="Stewart §6.7, Ex. 35; Guidorizzi §6.5, Ex. 8">

Calcule $\displaystyle\int\sqrt{x^2+4}\,dx$.

Com $x = 2\sinh t$, $dx = 2\cosh t\,dt$, $\sqrt{x^2+4} = 2\cosh t$:
$$\int 2\cosh t \cdot 2\cosh t\,dt = 4\int\cosh^2 t\,dt = 4\int\frac{1+\cosh 2t}{2}\,dt = 2t + \sinh 2t + C.$$

Como $\sinh 2t = 2\sinh t\cosh t$ e $t = \sinh^{-1}(x/2) = \ln(x/2+\sqrt{x^2/4+1})$, $\cosh t = \sqrt{x^2/4+1}$:
$$= 2\sinh^{-1}\frac{x}{2} + \frac{x\sqrt{x^2+4}}{2}+C = x\frac{\sqrt{x^2+4}}{2}+2\ln\left(x+\sqrt{x^2+4}\right)+C.$$

</Exemplo>

<Exemplo titulo="Ex. 3 — Comprimento da catenária" numero={3} fonte="Stewart §6.7, Ex. 45; Apostol §6.19">

Calcule o comprimento de arco de $y = \cosh x$ de $x = 0$ a $x = a$.

$L = \displaystyle\int_0^a\sqrt{1+\sinh^2 x}\,dx = \int_0^a\cosh x\,dx = \sinh a$.

Para $a = 1$: $L = \sinh 1 = (e-e^{-1})/2 \approx 1{,}175$.

</Exemplo>

<Exemplo titulo="Ex. 4 — Derivada de arcsinh" numero={4} fonte="Stewart §6.7, Ex. 25; Guidorizzi §6.5, Ex. 12">

Calcule $\dfrac{d}{dx}\sinh^{-1}x$ e verifique que $\displaystyle\int\frac{dx}{\sqrt{x^2+1}} = \sinh^{-1}x+C$.

Se $y = \sinh^{-1}x$, então $\sinh y = x$, logo $\cosh y\,\dfrac{dy}{dx} = 1$, e $\dfrac{dy}{dx} = \dfrac{1}{\cosh y} = \dfrac{1}{\sqrt{\sinh^2 y+1}} = \dfrac{1}{\sqrt{x^2+1}}$. $\checkmark$

</Exemplo>
