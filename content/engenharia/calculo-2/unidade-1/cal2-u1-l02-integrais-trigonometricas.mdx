<Porta nivel="formal" titulo="Estratégias sistemáticas">

### Caso 1: $m$ ou $n$ ímpar

Se $n = 2k+1$ (ímpar), separe $\cos^{2k+1}x = \cos^{2k}x\cdot\cos x = (1-\sin^2 x)^k\cos x$ e substitua $u = \sin x$.

Se $m = 2k+1$ (ímpar), separe $\sin^{2k+1}x = (1-\cos^2 x)^k\sin x$ e substitua $u = \cos x$.

### Caso 2: $m$ e $n$ ambos pares

Use as **identidades de ângulo duplo**:
$$\sin^2 x = \frac{1-\cos 2x}{2}, \qquad \cos^2 x = \frac{1+\cos 2x}{2}, \qquad \sin x\cos x = \frac{\sin 2x}{2}.$$

### Integrais de $\tan^n x$ e $\sec^m x$

Identidade fundamental: $\tan^2 x = \sec^2 x - 1$.

- **$\sec^m x \tan^n x$ com $m$ par:** $u = \tan x$, $du = \sec^2 x\,dx$.
- **$\sec^m x \tan^n x$ com $n$ ímpar:** $u = \sec x$, $du = \sec x\tan x\,dx$.
- **$\int \tan^n x\,dx$:** use $\tan^n x = \tan^{n-2}x(\sec^2 x - 1)$ (fórmula de redução).
- **$\int \sec x\,dx = \ln|\sec x + \tan x| + C$** (resultado especial).

### Identidades produto-soma

$$\sin A\cos B = \frac{1}{2}[\sin(A+B)+\sin(A-B)], \quad \cos A\cos B = \frac{1}{2}[\cos(A-B)+\cos(A+B)].$$

Úteis para $\int \sin(mx)\cos(nx)\,dx$.

</Porta>

<Porta nivel="5anos" titulo="Ideia intuitiva">

Imagina que $\sin x$ e $\cos x$ são como peças de Lego. Para calcular a integral, você precisa "desmontar" as peças em formas que sabe integrar.

A regra é simples: se você tem uma potência ímpar de $\sin$ ou $\cos$, separa um deles para ser o "motor" da substituição. Se os dois são pares, usa um truque para reduzir a potência.

</Porta>

<Porta nivel="10anos" titulo="As três identidades-chave">

Para resolver integrais trigonométricas, você precisa de três ferramentas:

1. **Pitágoras:** $\sin^2 x + \cos^2 x = 1$ (e as versões $\tan^2 x = \sec^2 x - 1$, $\cot^2 x = \csc^2 x - 1$)

2. **Ângulo duplo:** $\sin^2 x = \frac{1 - \cos 2x}{2}$, $\cos^2 x = \frac{1 + \cos 2x}{2}$

3. **Produto-soma:** $\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$

Com essas três, você resolve qualquer integral trigonométrica de potências.

</Porta>

<Porta nivel="15anos" titulo="Exemplos dos dois casos">

**Caso ímpar — $\int \sin^3 x\,dx$:**

Separe: $\sin^3 x = \sin^2 x \cdot \sin x = (1 - \cos^2 x)\sin x$.

Substitua $u = \cos x$, $du = -\sin x\,dx$:
$$\int(1-u^2)(-du) = -u + \frac{u^3}{3} + C = -\cos x + \frac{\cos^3 x}{3} + C.$$

**Caso par — $\int \sin^2 x\,dx$:**

Use $\sin^2 x = \frac{1-\cos 2x}{2}$:
$$\int \frac{1-\cos 2x}{2}\,dx = \frac{x}{2} - \frac{\sin 2x}{4} + C.$$

**Tangente — $\int \tan^2 x\,dx$:**

$\tan^2 x = \sec^2 x - 1$, então $\int\tan^2 x\,dx = \tan x - x + C$.

</Porta>

<Porta nivel="25anos" titulo="Fórmulas de redução gerais">

**Fórmulas de Wallis:**
$$\int_0^{\pi/2}\sin^n x\,dx = \int_0^{\pi/2}\cos^n x\,dx = \begin{cases} \dfrac{(n-1)!!}{n!!}\cdot\dfrac{\pi}{2} & n \text{ par} \\[6pt] \dfrac{(n-1)!!}{n!!} & n \text{ ímpar} \end{cases}$$

onde $n!! = n\cdot(n-2)\cdot(n-4)\cdots$ é o duplo fatorial.

**Produto de Wallis:** $\dfrac{\pi}{2} = \dfrac{2\cdot2\cdot4\cdot4\cdot6\cdot6\cdots}{1\cdot3\cdot3\cdot5\cdot5\cdot7\cdots}$

**Fórmulas de redução gerais:**
$$\int\sin^n x\,dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n-1}{n}\int\sin^{n-2}x\,dx$$
$$\int\sec^n x\,dx = \frac{\sec^{n-2}x\tan x}{n-1} + \frac{n-2}{n-1}\int\sec^{n-2}x\,dx$$

</Porta>

<Porta nivel="40anos" titulo="Aplicações em engenharia">

**Análise de Fourier:** As integrais $\int_{-\pi}^{\pi}\sin(mx)\sin(nx)\,dx$ e $\int_{-\pi}^{\pi}\cos(mx)\cos(nx)\,dx$ são a base da ortogonalidade das funções trigonométricas — fundamental para séries de Fourier e processamento de sinais.

**Potência média em circuitos AC:** A potência instantânea é $p(t) = V_m I_m \cos\omega t \cdot \cos(\omega t + \phi)$. A potência média é $P = \frac{1}{T}\int_0^T p(t)\,dt$, calculada exatamente com as integrais deste tópico.

**Mecânica dos sólidos:** Momentos de inércia de seções circulares envolvem $\int \sin^2\theta\,d\theta$ e $\int\cos^2\theta\,d\theta$.

**Óptica — difração:** A integral de Fraunhofer para uma abertura circular envolve $\int_0^\pi \sin^2\theta \cdot J_0(k\sin\theta)\,d\theta$.

</Porta>

<Porta nivel="pratica" titulo="Fluxograma de decisão">

**Para $\int \sin^m x \cos^n x\,dx$:**

```
m ímpar?
  Sim → u = cos x, separe sin x
  Não → n ímpar?
    Sim → u = sin x, separe cos x
    Não → ambos pares: use cos²x = (1+cos2x)/2, sin²x = (1-cos2x)/2
```

**Para $\int \sec^m x \tan^n x\,dx$:**

```
m par?
  Sim → u = tan x, reserve sec²x
  Não → n ímpar?
    Sim → u = sec x, reserve sec x tan x
    Não → use tan² = sec²-1 para reduzir
```

</Porta>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — sin³x (expoente ímpar)" numero={1} fonte="Stewart §7.2, Ex. 1; Guidorizzi §6.2, Ex. 1">

Calcule $\displaystyle\int \sin^3 x\,dx$.

$\sin^3 x = (1 - \cos^2 x)\sin x$. Com $u = \cos x$, $du = -\sin x\,dx$:
$$\int(1-u^2)(-du) = -\cos x + \frac{\cos^3 x}{3} + C.$$

</Exemplo>

<Exemplo titulo="Ex. 2 — sin²x cos²x (ambos pares)" numero={2} fonte="Stewart §7.2, Ex. 9; OpenStax Calc II §3.2">

Calcule $\displaystyle\int \sin^2 x \cos^2 x\,dx$.

Use $\sin^2 x \cos^2 x = \frac{1}{4}\sin^2(2x) = \frac{1}{4}\cdot\frac{1-\cos 4x}{2} = \frac{1-\cos 4x}{8}$:
$$\int\frac{1-\cos 4x}{8}\,dx = \frac{x}{8} - \frac{\sin 4x}{32} + C.$$

</Exemplo>

<Exemplo titulo="Ex. 3 — tan³x sec x" numero={3} fonte="Guidorizzi §6.2, Ex. 8; Stewart §7.2, Ex. 23">

Calcule $\displaystyle\int \tan^3 x \sec x\,dx$.

$\tan^3 x\sec x = \tan^2 x \cdot (\sec x \tan x) = (\sec^2 x - 1)(\sec x \tan x)$. Com $u = \sec x$:
$$\int(u^2-1)\,du = \frac{\sec^3 x}{3} - \sec x + C.$$

</Exemplo>

<Exemplo titulo="Ex. 4 — Produto-soma sin(3x)cos(5x)" numero={4} fonte="Stewart §7.2, Ex. 37; Apostol §2.5">

Calcule $\displaystyle\int \sin(3x)\cos(5x)\,dx$.

Use $\sin A\cos B = \frac{1}{2}[\sin(A+B)+\sin(A-B)]$:
$$\int\frac{1}{2}[\sin 8x + \sin(-2x)]\,dx = \int\frac{1}{2}[\sin 8x - \sin 2x]\,dx = -\frac{\cos 8x}{16} + \frac{\cos 2x}{4} + C.$$

</Exemplo>
