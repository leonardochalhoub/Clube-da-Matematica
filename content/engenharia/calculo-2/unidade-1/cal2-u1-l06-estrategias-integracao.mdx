### Fluxograma de escolha de técnica

```
Integrar ∫f(x)dx
│
├─ f(x) tem forma f(g(x))·g'(x)?
│   └─ SIM → Substituição u = g(x)
│
├─ f(x) = produto de dois tipos distintos?
│   └─ SIM → Integração por partes (LIATE)
│
├─ f(x) tem √(a²−x²), √(a²+x²) ou √(x²−a²)?
│   └─ SIM → Substituição trigonométrica
│
├─ f(x) = P(x)/Q(x) racional?
│   └─ SIM → Frações parciais
│
├─ f(x) = sin^m·cos^n ou tan^m·sec^n?
│   └─ SIM → Integrais trigonométricas (L02)
│
└─ Nenhum dos acima → tabela, substituição criativa ou combinação
```

### Regra LIATE para integração por partes

Escolha $u$ na ordem: **L**ogarítmica, **I**nversa trig., **A**lgebraica, **T**rigonométrica, **E**xponencial.

### Reconhecimento de formas padrão

| Integrando | Técnica | Resultado |
|-----------|---------|-----------|
| $\dfrac{f'(x)}{f(x)}$ | Subst. $u=f(x)$ | $\ln\lvert f(x)\rvert+C$ |
| $\dfrac{1}{x^2+a^2}$ | Fórmula direta | $\dfrac{1}{a}\arctan\dfrac{x}{a}+C$ |
| $\dfrac{1}{\sqrt{a^2-x^2}}$ | Fórmula direta | $\arcsin\dfrac{x}{a}+C$ |
| $e^{ax}\cos bx$ | Partes (2×) | fórmula de redução |
| $\ln x$ | Partes: $u=\ln x$ | $x\ln x - x + C$ |

</Porta>

<Porta nivel="5anos" titulo="Como escolher a técnica">

É como reconhecer o tipo de problema numa prova:

- Se você vê "raiz quadrada de algo com $x^2$", pensa em triângulo → sub. trig.
- Se você vê fração com polinômio em cima e embaixo, pensa em pedaços → frações parciais.
- Se você vê duas funções multiplicadas (como $x\cdot e^x$), pensa em partes.
- Se parece que tem algo dentro de algo (como $\sin(x^2)$), tenta substituição.

</Porta>

<Porta nivel="10anos" titulo="Quando combinar técnicas">

Muitas integrais precisam de mais de uma técnica:

**Exemplo:** $\displaystyle\int x\sqrt{x^2+1}\,dx$.

Parece sub. trig., mas é mais fácil com $u = x^2+1$: $du = 2x\,dx$, logo $\dfrac{1}{2}\int\sqrt{u}\,du = \dfrac{u^{3/2}}{3}+C = \dfrac{(x^2+1)^{3/2}}{3}+C$.

**Exemplo:** $\displaystyle\int\ln x\,dx$. Não é produto óbvio, mas escreva como $1\cdot\ln x$ e aplique partes com $u = \ln x$, $dv = dx$.

</Porta>

<Porta nivel="15anos" titulo="Técnicas combinadas — casos clássicos">

**Circular:** $\displaystyle\int e^x\sin x\,dx$.

Partes (2×) e reagrupe: $I = e^x\sin x - e^x\cos x - I \Rightarrow 2I = e^x(\sin x - \cos x) \Rightarrow I = \dfrac{e^x(\sin x-\cos x)}{2}+C$.

**Sub. trig. + frações parciais:** $\displaystyle\int\frac{dx}{x\sqrt{x^2-1}}$. Com $x = \sec\theta$: $\displaystyle\int\frac{\sec\theta\tan\theta\,d\theta}{\sec\theta\tan\theta} = \theta+C = \text{arcsec}(x)+C$.

**Partes + sub.:** $\displaystyle\int x^2 e^{-x^2}\,dx$ não tem forma fechada em elementares, mas $\displaystyle\int_0^\infty x^2 e^{-x^2}\,dx = \dfrac{\sqrt{\pi}}{4}$ (Gaussiana).

</Porta>

<Porta nivel="25anos" titulo="Integrais sem forma fechada e integrais de Risch">

**Algoritmo de Risch (1969):** determina algoritmicamente se uma função elementar tem antiderivada elementar e, se sim, calcula-a. Implementado em sistemas CAS (Maple, Mathematica, SageMath).

**Funções sem antiderivada elementar:**
$$\int e^{-x^2}\,dx, \quad \int\frac{\sin x}{x}\,dx, \quad \int\frac{e^x}{x}\,dx, \quad \int\sqrt{1-k^2\sin^2\theta}\,d\theta$$

Estas são integrais de funções especiais: $\text{erf}(x)$, $\text{Si}(x)$, $\text{Ei}(x)$, $E(\theta,k)$.

**Critério prático:** se a substituição, partes e frações parciais falharem após 2-3 tentativas, verifique se a integral pode não ter forma fechada.

</Porta>

<Porta nivel="40anos" titulo="Integração numérica e simbólica em engenharia">

**Quadratura de Gauss:** $\displaystyle\int_{-1}^1 f(x)\,dx \approx \sum_{i=1}^n w_i f(x_i)$. Os nós $x_i$ e pesos $w_i$ são selecionados para maximizar o grau de precisão (integra exatamente polinômios de grau $\leq 2n-1$).

**Regra de Simpson adaptativa:** subdivide o intervalo onde $f$ é irregular. Base de integradores numéricos (MATLAB `integral`, Python `scipy.integrate.quad`).

**Tabela de Bromwich:** usada em engenharia de controle para calcular transformadas de Laplace inversas por integração no plano complexo.

**Interpolação + integração:** dados discretos $\{(x_i, y_i)\}$ são interpolados por splines antes de integrar numericamente — prática padrão em análise de dados de sensores.

</Porta>

<Porta nivel="pratica" titulo="Passo a passo">

1. **Simplifique** a expressão algébrica (expanda, fatore, use identidades trig/hip.).
2. **Tente substituição simples** $u = g(x)$ — funciona quando a derivada de $g$ aparece no integrando.
3. **Reconheça** padrões: LIATE → partes; radicais quadráticos → sub. trig.; racional → frações parciais.
4. **Tente partes** se o integrando é produto de dois tipos diferentes.
5. **Combine** técnicas quando necessário.
6. **Verifique** o resultado diferenciando.
7. **Se tudo falhar**, consulte tabela ou use integrador simbólico.

</Porta>

</DuasPortas>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — Reconhecimento de padrão" numero={1} fonte="Stewart §7.5, Ex. 1; OpenStax Calc II §3.5, Ex. 1">

Calcule $\displaystyle\int\frac{x+2}{x^2+4x+5}\,dx$.

Note que $\dfrac{d}{dx}(x^2+4x+5) = 2x+4 = 2(x+2)$. Então $x+2 = \dfrac{1}{2}(2x+4)$, logo:
$$\int\frac{x+2}{x^2+4x+5}\,dx = \frac{1}{2}\int\frac{2x+4}{x^2+4x+5}\,dx = \frac{1}{2}\ln(x^2+4x+5)+C.$$

</Exemplo>

<Exemplo titulo="Ex. 2 — Combinando sub. trig. e sub. algébrica" numero={2} fonte="Stewart §7.5, Ex. 13; Guidorizzi §6.4, Obs.">

Calcule $\displaystyle\int\frac{dx}{\sqrt{x}(1+x)}$.

Substitua $u = \sqrt{x}$, $du = \frac{1}{2\sqrt{x}}\,dx$, logo $dx = 2\sqrt{x}\,du = 2u\,du$:
$$\int\frac{2u\,du}{u(1+u^2)} = 2\int\frac{du}{1+u^2} = 2\arctan\sqrt{x}+C.$$

</Exemplo>

<Exemplo titulo="Ex. 3 — Partes + sub. circular" numero={3} fonte="Stewart §7.5, Ex. 25; Active Calculus §5.6">

Calcule $\displaystyle\int e^{\sqrt{x}}\,dx$.

Subst. $u = \sqrt{x}$, $x = u^2$, $dx = 2u\,du$:
$$\int e^u\cdot 2u\,du.$$
Agora partes: $v = u$, $dw = e^u\,du$, $w = e^u$:
$$2\left[ue^u - \int e^u\,du\right] = 2(ue^u - e^u) + C = 2e^{\sqrt{x}}(\sqrt{x}-1)+C.$$

</Exemplo>

<Exemplo titulo="Ex. 4 — Integral trigonométrica via identidade" numero={4} fonte="Stewart §7.5, Ex. 31; OpenStax Calc II §3.5, Ex. 25">

Calcule $\displaystyle\int\frac{\cos x}{\sin^2 x + \sin x - 6}\,dx$.

Subst. $u = \sin x$, $du = \cos x\,dx$:
$$\int\frac{du}{u^2+u-6} = \int\frac{du}{(u+3)(u-2)}.$$
Frações parciais: $\dfrac{1}{(u+3)(u-2)} = \dfrac{1/5}{u-2} - \dfrac{1/5}{u+3}$.
$$= \frac{1}{5}\ln|\sin x - 2| - \frac{1}{5}\ln|\sin x + 3|+C.$$

</Exemplo>
