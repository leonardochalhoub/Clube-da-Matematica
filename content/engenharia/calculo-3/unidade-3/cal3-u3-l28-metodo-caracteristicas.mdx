<Porta nivel="formal" titulo="Método das características — teoria completa">

### EDP linear de 1ª ordem

$a(x,t)u_x + b(x,t)u_t = c(x,t)u + d(x,t)$

**Curvas características:** $\dfrac{dx}{a} = \dfrac{dt}{b} = \dfrac{du}{cu+d}$.

Ao longo das características, a EDP se torna um **sistema de EDOs ordinário**.

### Equação de advecção linear: $u_t + cu_x = 0$

Características: $dx/dt = c$ (retas no plano $xt$), $du/dt = 0$.

**Solução:** $u(x,t) = u(x-ct, 0) = f(x-ct)$ — translação da condição inicial.

### Equação de Burgers invíscida: $u_t + uu_x = 0$

Características: $dx/dt = u$ (velocidade = valor de $u$!).

Ao longo de $x(t) = x_0 + f(x_0)t$: $u = f(x_0)$ (constante).

**Formação de choque:** se $f'(x_0) < 0$ para algum $x_0$, características se cruzam em:

$$t_{\text{choque}} = -\frac{1}{\min_x f'(x)}$$

Depois de $t_{\text{choque}}$, a solução clássica não existe; a **solução fraca** tem uma descontinuidade (choque).

### Condição de Rankine-Hugoniot

Para lei de conservação $u_t + (F(u))_x = 0$, a velocidade $s$ do choque satisfaz:

$$s = \frac{F(u_R)-F(u_L)}{u_R-u_L}$$

onde $u_L$, $u_R$ são os valores à esquerda e direita do choque.

### Condição de entropia (Lax)

A solução física satisfaz $F'(u_L) > s > F'(u_R)$: as características entram no choque de ambos os lados.

</Porta>

<Porta nivel="5anos" titulo="Características — caminhos onde a informação viaja">

Imagine um fluido num cano. As características são as **trajetórias das partículas de fluido**: ao longo de cada trajetória, a velocidade do fluido permanece constante (no caso invíscido).

Se dois "sinais" (dois valores de velocidade) viajam e se encontram, ocorre um **choque**: uma descontinuidade abrupta, como a onda de choque de um avião supersônico.

</Porta>

<Porta nivel="10anos" titulo="Equação de transporte — exemplo passo a passo">

$u_t + 3u_x = 0$, $u(x,0) = e^{-x^2}$.

Características: $x(t) = x_0 + 3t$, $u = f(x_0) = e^{-x_0^2}$.

Da relação $x = x_0+3t$: $x_0 = x-3t$.

$u(x,t) = e^{-(x-3t)^2}$ — gaussiana viajando para a direita com velocidade $3$.

**Para $u_t - 2u_x = 0$:** $x(t) = x_0 - 2t$, $u(x,t) = f(x+2t)$ — viajando para a **esquerda**.

</Porta>

<Porta nivel="15anos" titulo="Burgers invíscido — formação de choque">

$u_t+uu_x = 0$, $u(x,0) = \begin{cases}1 & x\leq 0\\1-x & 0<x<1\\0 & x\geq 1\end{cases}$.

**Características:**
- $x_0\leq 0$: $x = x_0+t$, $u = 1$.
- $0<x_0<1$: $x = x_0+(1-x_0)t$, $u = 1-x_0$.
- $x_0\geq 1$: $x = x_0$, $u = 0$.

**Cruzamento:** para $x_0\in(0,1)$, $dx/dt = 1-x_0 \in (0,1)$, e para $x_0=0$, $dx/dt=1$. A característica de $x_0=0$ (velocidade 1) alcança a de $x_0=1$ (velocidade 0) em tempo finito.

Choque em $t_{\text{choque}} = -1/\min(f') = -1/(-1) = 1$ no ponto $x = 1$.

Para $t > 1$: solução de choque com $u_L=1$, $u_R=0$, velocidade de choque $s=(F(1)-F(0))/(1-0) = (1/2-0)/1 = 1/2$.

Posição do choque: $x_s(t) = 1 + (t-1)/2 = (t+1)/2$.

</Porta>

<Porta nivel="25anos" titulo="Soluções fracas e ondas de rarefação">

Para $u_t+(u^2/2)_x = 0$ (Burgers) com dado inicial do tipo degrau expandindo ($u_L < u_R$):

Não há choque — as características se afastam, criando um **fácio de expansão** (rarefaction fan). A solução de **onda de rarefação** é:

$$u(x,t) = \begin{cases}u_L & x < u_L t\\x/t & u_L t\leq x\leq u_R t\\u_R & x > u_R t\end{cases}$$

Esta é uma solução contínua, não-diferenciável, que satisfaz a EDP fora das retas $x = u_Lt$ e $x = u_Rt$.

**Método de vanishing viscosity:** a solução física de $u_t+(F(u))_x=0$ é o limite $\varepsilon\to 0$ de $u_t+(F(u))_x=\varepsilon u_{xx}$. A viscosidade artificial seleciona a solução entrópica (Lax, Oleinik, Kružkov).

**Teoria $L^1$:** Kružkov (1970) provou existência e unicidade de soluções de entropia em $L^1\cap L^\infty$ para leis de conservação escalares via condição de entropia $|u-k|_t + (F(u)\text{sgn}(u-k)-F(k)\text{sgn}(u-k))_x\leq 0$.

</Porta>

<Porta nivel="40anos" titulo="Aplicações em engenharia">

**Dinâmica de tráfego (Lighthill-Whitham-Richards):** o modelo de tráfego $\rho_t+(v(\rho)\rho)_x = 0$ com $v(\rho) = v_{\max}(1-\rho/\rho_{\max})$ é uma lei de conservação não-linear. Os choques modelam a formação de congestionamentos espontâneos; as ondas de rarefação modelam o fluxo após a remoção de um bloqueio.

**Escoamento compressível — ondas de choque:** as equações de Euler $\rho_t+(\rho u)_x=0$, $(\rho u)_t+(\rho u^2+p)_x=0$ formam um sistema hiperbólico. Choques são descontinuidades de $\rho$, $u$ e $p$; as condições de Rankine-Hugoniot fornecem as relações de Rankine (saltos de densidade/pressão/velocidade). O número de Mach $M = u/c_s$ determina se o choque é forte ou fraco.

**Modelagem de reservatórios (fluxo de Buckley-Leverett):** $S_t + (f(S))_x = 0$ com $f$ não-convexa (saturação de água $S$ em meio poroso). Choques aparecem na frente de avanço da água; ondas de rarefação formam-se onde $f''<0$ para $f''>0$. O método das características + condição de Rankine-Hugoniot é a base dos simuladores de reservatório.

</Porta>

<Porta nivel="pratica" titulo="Passo a passo — método das características">

**EDP linear $u_t + c(x)u_x = 0$, $u(x,0) = f(x)$:**

1. **Trace** as características: $dx/dt = c(x)$, $du/dt = 0$ — resolve a EDO $dx/dt = c(x)$ com $x(0) = x_0$.
2. **Ao longo de cada característica:** $u = f(x_0)$ (constante).
3. **Inverta** $x = x(x_0,t)$ para obter $x_0 = x_0(x,t)$.
4. **Solução:** $u(x,t) = f(x_0(x,t))$.

**EDP de Burgers $u_t + uu_x = 0$, $u(x,0) = f(x)$:**

1. Características: $x = x_0 + f(x_0)t$.
2. Verifique choque: $t_{\text{choque}} = -1/\min(f')$ se $\min(f') < 0$.
3. Para $t < t_{\text{choque}}$: inverta $x = x_0+f(x_0)t$ para $x_0 = x_0(x,t)$; $u = f(x_0)$.
4. Para $t > t_{\text{choque}}$: use Rankine-Hugoniot para localizar o choque.

</Porta>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — Advecção com velocidade variável" numero={1} fonte="Strauss — PDE §2.4, Ex. 3; Evans — PDE §3.2, Ex. 3">

$u_t + xu_x = 0$, $u(x,0) = f(x)$.

Características: $dx/dt = x \Rightarrow x(t) = x_0 e^t$.

$u = f(x_0) = f(xe^{-t})$ (ao longo de $x = x_0 e^t$, $x_0 = xe^{-t}$).

**Verificação:** $u_t = f'(xe^{-t})\cdot(-xe^{-t})$; $u_x = f'(xe^{-t})\cdot e^{-t}$.

$u_t + xu_x = f'(-xe^{-t}+xe^{-t}) = 0$. $\checkmark$

</Exemplo>

<Exemplo titulo="Ex. 2 — EDP de 1ª ordem quasilinear" numero={2} fonte="Strauss — PDE §2.4, Ex. 7; Evans — PDE §3.2, Ex. 5">

$u_t + u^2 u_x = 0$ (Burgers cúbica), $u(x,0) = x$.

Características: $dx/dt = u^2$; $du/dt = 0 \Rightarrow u = x_0$ (constante).

Então $x = x_0 + x_0^2 t$.

Invertendo: $x_0 = x_0(x,t)$ da equação $x = x_0+x_0^2 t$ — equação quadrática em $x_0$.

$x_0 t x_0^2 + x_0 - x = 0$: $x_0 = \dfrac{-1\pm\sqrt{1+4tx}}{2t}$ (para $t>0$ pequeno).

Choque: $dx_0/dx = 0$ não ocorre para $f'(x_0) = 1 > 0$ (dado crescente) — as características se afastam (onda de rarefação, não choque).

</Exemplo>

<Exemplo titulo="Ex. 3 — Lei de conservação com choque" numero={3} fonte="Strauss — PDE §2.4, Ex. 10; Evans — PDE §3.4, Ex. 6">

$u_t+(u^2/2)_x = 0$, $u(x,0) = \begin{cases}2 & x<0\\0 & x>0\end{cases}$ (degrau com $u_L > u_R$: choque imediato).

Características: velocidade $dx/dt = u$: para $x_0<0$: velocidade 2; para $x_0>0$: velocidade 0.

As características de $x_0<0$ alcançam imediatamente $x_0>0$: **choque desde $t=0$**.

Rankine-Hugoniot: $s = (F(2)-F(0))/(2-0) = (2-0)/2 = 1$.

**Solução:** $u(x,t) = \begin{cases}2 & x < t\\0 & x > t\end{cases}$ — choque se move com velocidade $s=1$.

</Exemplo>

## Exercícios

### Bloco A — Método das características

<Exercicio numero={1} fonte="Strauss — PDE §2.4, Ex. 1–10; Evans — PDE §3.2, Ex. 1–6">
**(a)** Resolva $u_t + 2xu_x = 0$, $u(x,0) = \sin x$. Encontre as curvas características.

**(b)** Resolva $u_t + u_x = u$, $u(x,0) = f(x)$. *(Dica: ao longo das características, $du/dt = u$.)*

**(c)** Resolva a EDP linear de 1ª ordem $u_x + u_y = 1$ com $u(x,0) = e^{-x^2}$.
</Exercicio>

### Bloco B — Formação de choques

<Exercicio numero={2} fonte="Strauss — PDE §2.4, Ex. 11–18; Evans — PDE §3.4, Ex. 1–6">
**(a)** Para $u_t+uu_x=0$ com $u(x,0)=1/(1+x^2)$: existe choque? Se sim, encontre $t_{\text{choque}}$ e a posição do choque.

**(b)** Resolva $u_t+(u^2/2)_x=0$ com o dado inicial: $u(x,0) = 0$ para $x<0$, $u(x,0) = 1$ para $x>0$ (degrau expansivo — onda de rarefação).

**(c)** Para a lei de conservação $u_t+(u^3/3)_x=0$, $u_L=1$, $u_R=-1$: calcule a velocidade do choque e verifique a condição de entropia de Lax.
</Exercicio>

### Bloco C — Nível ITA/USP

<Exercicio numero={3} fonte="ITA MA-013; Evans — PDE §3.4, Ex. 5–12">
**(a)** Prove que a solução da equação de Burgers $u_t+uu_x=0$ com dado suave $f$ perde regularidade em tempo finito se e somente se $f$ tem algum ponto de declive negativo ($f'(x_0)<0$ para algum $x_0$). *(Mostre que $u_x$ satisfaz $v_t+uv_x+v^2=0$ e aplique o lema de comparação.)*

**(b)** Derive as condições de Rankine-Hugoniot para uma lei de conservação escalar $u_t+(F(u))_x=0$ a partir da formulação fraca: $\int\int(\phi_t u+\phi_x F(u))\,dx\,dt=0$ para toda $\phi\in C_c^\infty$.

**(c)** Use o método das características para resolver o **problema de Riemann** da lei de conservação $u_t+(u^2/2)_x=0$ com dado inicial geral de dois estados constantes $u_L$ e $u_R$, distinguindo os casos $u_L>u_R$ (choque) e $u_L<u_R$ (rarefação).
</Exercicio>
