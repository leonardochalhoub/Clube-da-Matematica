<Porta nivel="formal" titulo="Derivação e fórmula de d'Alembert">

### Mudança de variáveis características

Com $\xi = x+ct$, $\eta = x-ct$ (L21, Ex.):

$u_{\xi\eta} = 0 \Rightarrow u = F(\xi)+G(\eta) = F(x+ct)+G(x-ct)$

**Solução geral:** toda solução suave de $u_{tt} = c^2 u_{xx}$ escreve-se como superposição de **onda direita** e **onda esquerda**.

### Problema de Cauchy no domínio infinito

$$u_{tt} = c^2 u_{xx},\quad x\in\mathbb{R},\;t>0$$
$$u(x,0) = f(x),\quad u_t(x,0) = g(x)$$

**Fórmula de d'Alembert:**
$$u(x,t) = \frac{f(x+ct)+f(x-ct)}{2}+\frac{1}{2c}\int_{x-ct}^{x+ct}g(s)\,ds$$

**Derivação:** de $u = F(\xi)+G(\eta)$:

$u(x,0) = F(x)+G(x) = f(x)$;

$u_t(x,0) = cF'(x)-cG'(x) = g(x) \Rightarrow F(x)-G(x) = \frac{1}{c}\int_{x_0}^x g(s)\,ds+C$.

Resolvendo: $F(x) = \frac{f(x)}{2}+\frac{1}{2c}\int_{x_0}^x g$, $G(x) = \frac{f(x)}{2}-\frac{1}{2c}\int_{x_0}^x g$. Substituindo: fórmula de d'Alembert.

### Cone de dependência

$u(x_0, t_0)$ depende apenas de $f$ e $g$ no intervalo $[x_0-ct_0, x_0+ct_0]$ — o **cone de dependência** da onda no ponto $(x_0,t_0)$.

**Velocidade de propagação finita:** perturbações viajam com velocidade exatamente $c$.

### Energia conservada

$$E(t) = \frac{1}{2}\int_{-\infty}^{+\infty}(u_t^2 + c^2u_x^2)\,dx = E(0)\quad\text{(conservação)}$$

</Porta>

<Porta nivel="5anos" titulo="Duas ondas viajando em sentidos opostos">

A solução $u(x,t) = F(x+ct)+G(x-ct)$ é a soma de:

- **$F(x+ct)$:** formato $F$ viajando para a **esquerda** com velocidade $c$.
- **$G(x-ct)$:** formato $G$ viajando para a **direita** com velocidade $c$.

Imagine jogar uma pedra numa piscina: as ondas se propagam para fora em todas as direções. Na versão 1D (corda), duas frentes de onda idênticas vão para a esquerda e para a direita simultaneamente.

</Porta>

<Porta nivel="10anos" titulo="Exemplo com velocidade inicial zero">

Corda com deslocamento inicial $f(x) = e^{-x^2}$, velocidade inicial $g(x) = 0$.

$u(x,t) = \frac{e^{-(x+ct)^2}+e^{-(x-ct)^2}}{2}$.

**Interpretação:** o "pacote gaussiano" se divide em dois pacotes metade menores, um viajando para a esquerda e outro para a direita, cada um com velocidade $c$.

Para $t = 0$: $u = e^{-x^2}$ (gaussiana centrada). Para $t > 0$: dois meios picos afastando-se.

</Porta>

<Porta nivel="15anos" titulo="Domínio semi-infinito — reflexão de ondas">

Para a corda semi-infinita $x\geq 0$, $t>0$ com condição de Dirichlet $u(0,t) = 0$ (extremidade fixa):

**Método das imagens:** estenda $f$ e $g$ como funções **ímpares** em $\mathbb{R}$:

$\tilde{f}(x) = \begin{cases}f(x) & x\geq 0\\-f(-x) & x<0\end{cases}$, e analogamente $\tilde{g}$.

Aplique d'Alembert com $\tilde{f}$ e $\tilde{g}$. A solução se anula automaticamente em $x=0$:

$$u(x,t) = \frac{\tilde{f}(x+ct)+\tilde{f}(x-ct)}{2}+\frac{1}{2c}\int_{x-ct}^{x+ct}\tilde{g}(s)\,ds$$

Para $x > ct$ (onda ainda não atingiu a parede): $u = [f(x+ct)+f(x-ct)]/2+\ldots$ (como no caso infinito).

Para $x < ct$ (após reflexão): a onda refletida tem sinal invertido — reflexão com inversão de fase.

Para extremidade livre ($u_x(0,t) = 0$): estender como função **par** — reflexão sem inversão de fase.

</Porta>

<Porta nivel="25anos" titulo="Solução de Riemann e equações hiperbólicas">

Para o sistema hiperbólico $\mathbf{u}_t + A\mathbf{u}_x = 0$ (com $A$ diagonalizável, autovalores reais $c_1,\ldots,c_n$):

A diagonalização $A = PDP^{-1}$ e mudança $\mathbf{v} = P^{-1}\mathbf{u}$ decompõe em $n$ equações escalares desacopladas $v_i^t + c_i v_i^x = 0$, cada uma com solução $v_i(x,t) = v_i(x-c_it,0)$.

**Equação de Euler linearizada:** perturbações acústicas num gás compressível satisfazem $\rho_t + \rho_0 u_x = 0$, $u_t + c_s^2\rho_x/\rho_0 = 0$ — sistema hiperbólico com velocidade do som $c_s = \sqrt{\gamma P_0/\rho_0}$.

**Problema de Riemann:** solução com dado inicial em degrau ($\mathbf{u}$ constante para $x < 0$ e $x > 0$, distintos). As soluções são ondas simples, choques e ondas de rarefação — base de esquemas numéricos (Godunov, Roe, MUSCL).

</Porta>

<Porta nivel="40anos" titulo="Aplicações em engenharia">

**Golpe de aríete em tubulações:** a equação de onda $\partial H/\partial t + (c/g)\partial V/\partial x = 0$, $\partial V/\partial t + g\partial H/\partial x = 0$ (onde $H$ = carga piezométrica, $V$ = velocidade, $c$ = velocidade da onda de pressão) descreve o transitório hidráulico. O fechamento rápido de uma válvula gera uma onda de pressão que viaja pelo sistema — a análise por d'Alembert prediz os picos de pressão.

**Sísmica de reflexão:** a equação de onda acústica $p_{tt} = c(x)^2\Delta p$ com $c$ variável descreve a propagação de ondas sísmicas. O método de reflexão (análogo às imagens para meios heterogêneos) é a base da sísmica exploratória para localização de reservatórios de petróleo.

**Impacto em estruturas — ondas de tensão:** um impacto brusco num barrote gera uma onda de compressão $\sigma_{tt} = E/\rho\cdot\sigma_{xx}$ com velocidade $c = \sqrt{E/\rho}$ (velocidade do som no sólido). O cone de dependência determina a região do sólido afetada pelo impacto num dado instante.

</Porta>

<Porta nivel="pratica" titulo="Passo a passo — d'Alembert">

1. **Identifique** $c$ na equação $u_{tt} = c^2 u_{xx}$.
2. **Leia** os dados iniciais: $u(x,0) = f(x)$ e $u_t(x,0) = g(x)$.
3. **Aplique** a fórmula:
$$u(x,t) = \frac{f(x+ct)+f(x-ct)}{2}+\frac{1}{2c}\int_{x-ct}^{x+ct}g(s)\,ds$$
4. **Para $g \equiv 0$:** $u = [f(x+ct)+f(x-ct)]/2$ — média das duas translações.
5. **Para $f \equiv 0$:** $u = \frac{1}{2c}\int_{x-ct}^{x+ct}g(s)\,ds$.
6. **Domínio semi-infinito:** extenda os dados como ímpar (extremidade fixa) ou par (extremidade livre) antes de aplicar d'Alembert.
7. **Verifique** substituindo na EDP e nas condições iniciais.

</Porta>

</DuasPortas>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — d'Alembert com dados iniciais triangulares" numero={1} fonte="Strauss — PDE §2.1, Ex. 3; Kreyszig §21.2, Ex. 5">

$u_{tt} = 4u_{xx}$ ($c=2$), $u(x,0) = \max(1-|x|,0)$ (triângulo), $u_t(x,0) = 0$.

$u(x,t) = \frac{1}{2}[\max(1-|x+2t|,0)+\max(1-|x-2t|,0)]$.

**Para $t = 0.3$:** dois meios triângulos, centrados em $x = -0.6$ e $x = 0.6$.

**Para $t = 0.5$:** os triângulos começam a se separar — a solução vale $1/2$ no meio ($|x| < 0.5$) e cai.

**Para $t > 1$:** dois meios triângulos completamente separados, viajando em sentidos opostos.

</Exemplo>

<Exemplo titulo="Ex. 2 — Energia conservada" numero={2} fonte="Strauss — PDE §2.2, Ex. 5; Iório — EDP §3.1, Ex. 4">

Para $u(x,t) = \sin(x+ct)$:

$u_t = c\cos(x+ct)$; $u_x = \cos(x+ct)$.

$u_t^2 + c^2u_x^2 = c^2\cos^2(x+ct)+c^2\cos^2(x+ct) = 2c^2\cos^2(x+ct)$.

Para uma onda num intervalo finito $[0,L]$ com condições periódicas, a energia média sobre um período temporal é constante — consistente com a conservação $dE/dt = 0$.

$dE/dt = \int_0^L u_t(u_{tt}-c^2u_{xx})\,dx = 0$ (usando integração por partes e condições de contorno). $\checkmark$

</Exemplo>

<Exemplo titulo="Ex. 3 — Reflexão num extremo fixo" numero={3} fonte="Strauss — PDE §2.1, Ex. 7; Churchill & Brown §10.2, Ex. 4">

$u_{tt} = u_{xx}$ ($c=1$) em $x\geq 0$, $u(0,t) = 0$.

$u(x,0) = \begin{cases}1 & 1\leq x\leq 2\\0 & \text{c.c.}\end{cases}$, $u_t(x,0) = 0$.

Extensão ímpar: $\tilde{f}(x) = -\tilde{f}(-x)$.

$u(x,t) = \frac{\tilde{f}(x+t)+\tilde{f}(x-t)}{2}$.

**Para $x > t$:** $u = [f(x+t)+f(x-t)]/2$ (como no caso infinito).

**Em $t = 1.5$, $x = 0.5$:** $u = [\tilde{f}(2)+\tilde{f}(-1)]/2 = [1+(-1)]/2 = 0$. A onda refletida cancela a incidente na parede.

</Exemplo>

## Exercícios

### Bloco A — Fórmula de d'Alembert

<Exercicio numero={1} fonte="Strauss — PDE §2.1, Ex. 1–10; Kreyszig §21.2, Ex. 1–8">
**(a)** Resolva $u_{tt} = 9u_{xx}$, $u(x,0) = \sin x$, $u_t(x,0) = 0$.

**(b)** Resolva $u_{tt} = u_{xx}$, $u(x,0) = 0$, $u_t(x,0) = \cos x$.

**(c)** Resolva $u_{tt} = c^2 u_{xx}$, $u(x,0) = xe^{-x^2}$, $u_t(x,0) = 0$. Descreva o comportamento para $t$ grande.
</Exercicio>

### Bloco B — Domínio semi-infinito e energia

<Exercicio numero={2} fonte="Strauss — PDE §2.1–2.2, Ex. 11–20; Iório — EDP §3.1, Ex. 1–8">
**(a)** Resolva $u_{tt} = u_{xx}$ em $x>0$ com $u(0,t)=0$, $u(x,0) = \sin(\pi x)$ para $0<x<1$ (e 0 c.c.), $u_t(x,0) = 0$.

**(b)** Resolva com extremidade livre: $u_{tt} = u_{xx}$, $x>0$, $u_x(0,t)=0$, $u(x,0) = f(x)$, $u_t(x,0) = 0$.

**(c)** Prove que a energia $E(t) = \frac{1}{2}\int_0^L(u_t^2+c^2u_x^2)\,dx$ é conservada para $u_{tt} = c^2u_{xx}$ com $u(0,t) = u(L,t) = 0$.
</Exercicio>

### Bloco C — Nível ITA/USP

<Exercicio numero={3} fonte="ITA MA-013; Strauss — PDE §2.3, Ex. 5–12">
**(a)** Prove que a solução de d'Alembert $u = [f(x+ct)+f(x-ct)]/2 + \frac{1}{2c}\int_{x-ct}^{x+ct}g\,ds$ depende dos dados apenas no intervalo $[x-ct,x+ct]$ (cone de dependência), e deduza que perturbações se propagam com velocidade exatamente $c$.

**(b)** Para $u_{tt} = c^2u_{xx}+h(x,t)$ (equação de onda não-homogênea), use o **princípio de Duhamel**: $u = \int_0^t v(x,t-s;s)\,ds$ onde $v(x,\tau;s)$ resolve $v_{\tau\tau} = c^2 v_{xx}$, $v(x,0;s)=0$, $v_\tau(x,0;s)=h(x,s)$. Verifique a fórmula para $h(x,t) = \sin x\sin t$, $c=1$.

**(c)** Prove a **unicidade** para o problema de Cauchy hiperbólico: se duas soluções $u$ e $v$ de $u_{tt}=c^2u_{xx}$ têm os mesmos dados iniciais, então $u=v$ para todo $(x,t)$ com $t>0$. *(Use a conservação de energia para $w = u-v$.)*
</Exercicio>
