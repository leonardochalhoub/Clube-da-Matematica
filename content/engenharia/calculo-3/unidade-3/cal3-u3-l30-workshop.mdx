# Workshop Unidade 3 — Equações Diferenciais Parciais

## Síntese dos Métodos

### Critério de Escolha do Método

| Domínio | Condições | Método Principal |
|---------|-----------|-----------------|
| Intervalo finito <Eq>{"(0,L)"}</Eq> | CCs homogêneas | Separação de variáveis + Fourier |
| Intervalo finito | CCs não-homogêneas | Redução a estado estacionário |
| Reta inteira <Eq>{"\\mathbb{R}"}</Eq> | Dado inicial em <Eq>{"L^2"}</Eq> | Transformada de Fourier |
| Semi-reta | CC em <Eq>{"x=0"}</Eq> | Extensão ímpar/par |
| Meio-plano | CC em fronteira | Transformada de Fourier em <Eq>{"x"}</Eq> |

### Fórmulas Essenciais

**d'Alembert** (<Eq>{"u_{tt} = c^2 u_{xx}"}</Eq>, domínio inteiro):
<Eq>{"u(x,t) = \\frac{f(x+ct)+f(x-ct)}{2} + \\frac{1}{2c}\\int_{x-ct}^{x+ct} g(s)\\,ds"}</Eq>

**Calor** (separação de variáveis em <Eq>{"(0,L)"}</Eq>, CC Dirichlet):
<Eq>{"u(x,t) = \\sum_{n=1}^{\\infty} B_n \\sin\\!\\left(\\frac{n\\pi x}{L}\\right) e^{-\\kappa(n\\pi/L)^2 t}"}</Eq>

**Laplace no disco** (raio <Eq>{"a"}</Eq>):
<Eq>{"u(r,\\theta) = \\frac{a_0}{2} + \\sum_{n=1}^{\\infty}\\left(\\frac{r}{a}\\right)^n\\!(a_n\\cos n\\theta + b_n\\sin n\\theta)"}</Eq>

**Transformada de Fourier — Calor** (domínio inteiro):
<Eq>{"u(x,t) = \\frac{1}{\\sqrt{4\\pi\\kappa t}}\\int_{-\\infty}^{\\infty} f(y)\\,e^{-(x-y)^2/(4\\kappa t)}\\,dy"}</Eq>

**Características** (EDP linear 1ª ordem <Eq>{"u_t + c u_x = 0"}</Eq>):
<Eq>{"u(x,t) = f(x - ct)"}</Eq>

### Classificação (EDP 2ª ordem)

<Eq>{"A u_{xx} + 2B u_{xy} + C u_{yy} + \\cdots = 0, \\quad \\Delta = B^2 - AC"}</Eq>

- <Eq>{"\\Delta > 0"}</Eq>: hiperbólica (onda)
- <Eq>{"\\Delta = 0"}</Eq>: parabólica (calor)
- <Eq>{"\\Delta < 0"}</Eq>: elíptica (Laplace)

# Workshop Unidade 3 — Equações Diferenciais Parciais

## Perspectiva Avançada

### A Estrutura Funcional das EDPs

Os três tipos de EDPs de 2ª ordem correspondem a três estruturas funcionais distintas.

**Tipo elíptico** (<Eq>{"\\Delta u = 0"}</Eq>): opera nos espaços de Sobolev <Eq>{"H^k(\\Omega)"}</Eq>. O teorema de regularidade elíptica garante que, se <Eq>{"f \\in H^s"}</Eq>, então <Eq>{"u \\in H^{s+2}"}</Eq>. A teoria de Fredholm se aplica ao operador <Eq>{"L = -\\Delta + V"}</Eq>.

**Tipo parabólico** (<Eq>{"u_t + Lu = 0"}</Eq>): o semigrupo <Eq>{"\\{e^{-tL}\\}_{t\\geq 0}"}</Eq> é analítico em <Eq>{"L^2"}</Eq>. A estimativa de regularidade parabólica: <Eq>{"u \\in L^2((0,T);H^2) \\cap H^1((0,T);L^2)"}</Eq>.

**Tipo hiperbólico** (<Eq>{"u_{tt} + Lu = 0"}</Eq>): energia <Eq>{"E(t) = \\|u_t\\|^2 + \\langle Lu,u\\rangle"}</Eq> é conservada. Velocidade de propagação finita: suporte de <Eq>{"u(\\cdot,t)"}</Eq> está no cone <Eq>{"x_0 \\pm ct"}</Eq>.

### Distribuições e EDPs

A transformada de Fourier estende-se ao espaço de distribuições temperadas <Eq>{"\\mathcal{S}'(\\mathbb{R}^n)"}</Eq>. A solução fundamental (função de Green) <Eq>{"G"}</Eq> de <Eq>{"Lu = f"}</Eq> satisfaz <Eq>{"LG = \\delta"}</Eq> no sentido distribucional.

Para o Laplaciano em <Eq>{"\\mathbb{R}^n"}</Eq> (<Eq>{"n \\geq 3"}</Eq>):
<Eq>{"G(x) = \\frac{c_n}{|x|^{n-2}}, \\quad c_n = \\frac{1}{(n-2)\\omega_n}"}</Eq>
onde <Eq>{"\\omega_n"}</Eq> é a área da esfera unitária em <Eq>{"\\mathbb{R}^n"}</Eq>.

### Choques e Leis de Conservação

A teoria moderna de leis de conservação hiperbólicas (<Eq>{"u_t + F(u)_x = 0"}</Eq>) usa soluções de entropia no sentido de Kružkov: <Eq>{"u"}</Eq> é solução de entropia se para todo <Eq>{"k \\in \\mathbb{R}"}</Eq>:
<Eq>{"\\partial_t|u-k| + \\partial_x[\\text{sgn}(u-k)(F(u)-F(k))] \\leq 0"}</Eq>
no sentido distribucional. Isso seleciona unicamente a solução fisicamente relevante.

## Estratégia Geral

Dado um PVIC, pergunte:
1. Qual é a EDP? (onda, calor, Laplace, outra?)

### Passo 2: Escolher o Método

```
DOMÍNIO FINITO?
  └── Sim → Separação de variáveis
        ├── CC homogêneas → direto
        └── CC não-homogêneas → estado estacionário + transiente
  └── Não → Transformada de Fourier
        ├── Reta inteira → TF em x
        ├── Semi-eixo → Extensão ímpar/par + d'Alembert (onda)
        └── Semi-plano → TF em x, EDO em y
```

### Passo 3: Executar e Verificar

- **Separação de variáveis:** SL → autovalores → autofunções → coeficientes de Fourier
- **d'Alembert:** estender os dados, aplicar a fórmula, checar domínio de dependência
- **TF:** transformar em <Eq>{"x"}</Eq>, resolver em <Eq>{"t"}</Eq> ou <Eq>{"y"}</Eq>, inverter
- **Características:** curvas características, solução implícita, detectar choque
