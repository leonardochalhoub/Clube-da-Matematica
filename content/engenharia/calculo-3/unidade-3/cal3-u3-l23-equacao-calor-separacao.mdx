<Porta nivel="formal" titulo="Método de separação de variáveis">

### Problema modelo

$$u_t = \kappa u_{xx},\quad 0<x<L,\;t>0$$
$$u(0,t) = u(L,t) = 0,\quad u(x,0) = f(x)$$

### Passo 1: Separação

Tente $u(x,t) = X(x)T(t)$:

$X T' = \kappa X'' T \Rightarrow \frac{T'}{\kappa T} = \frac{X''}{X} = -\lambda$

(constante, pois lado esquerdo depende só de $t$ e lado direito só de $x$).

### Passo 2: Problema de Sturm-Liouville

$$X'' + \lambda X = 0,\quad X(0) = X(L) = 0$$

Soluções não-triviais existem apenas para **autovalores** $\lambda_n = (n\pi/L)^2$ com **autofunções** $X_n = \sin(n\pi x/L)$, $n = 1,2,3,\ldots$

### Passo 3: Equação temporal

$$T'_n = -\kappa\lambda_n T_n \Rightarrow T_n(t) = e^{-\kappa\lambda_n t} = e^{-\kappa(n\pi/L)^2 t}$$

### Passo 4: Superposição e coeficientes de Fourier

$$u(x,t) = \sum_{n=1}^\infty b_n \sin\!\left(\frac{n\pi x}{L}\right)e^{-\kappa(n\pi/L)^2 t}$$

Com $u(x,0) = f(x)$:

$$b_n = \frac{2}{L}\int_0^L f(x)\sin\!\left(\frac{n\pi x}{L}\right)dx$$

### Comportamento assintótico

Para $t\to\infty$: $u\to 0$ (esfriamento). O modo dominante é $n=1$: $u\approx b_1 e^{-\kappa\pi^2 t/L^2}\sin(\pi x/L)$.

**Tempo de decaimento:** $\tau = L^2/(\kappa\pi^2)$ — proporcional a $L^2$ e inversamente a $\kappa$.

</Porta>

<Porta nivel="5anos" titulo="A temperatura 'suaviza' ao longo do tempo">

A equação do calor transforma qualquer perfil de temperatura inicial em algo cada vez mais suave. Com o tempo, os "picos" desaparecem primeiro (modos de alta frequência decaem mais rápido), restando apenas a variação mais lenta (modo fundamental).

É como misturar cores numa tela: os padrões finos desaparecem rapidamente, sobrando apenas o padrão grosseiro — que também desaparece, até tudo ficar uniforme (temperatura zero nas bordas frias).

</Porta>

<Porta nivel="10anos" titulo="Temperatura inicial retangular">

$f(x) = T_0$ (constante) em $[0,L]$.

$$b_n = \frac{2T_0}{L}\int_0^L\sin\!\left(\frac{n\pi x}{L}\right)dx = \frac{2T_0}{n\pi}[1-(-1)^n] = \begin{cases}\frac{4T_0}{n\pi} & n\text{ ímpar}\\0 & n\text{ par}\end{cases}$$

$$u(x,t) = \frac{4T_0}{\pi}\sum_{k=0}^\infty\frac{1}{2k+1}\sin\!\left(\frac{(2k+1)\pi x}{L}\right)e^{-\kappa(2k+1)^2\pi^2t/L^2}$$

**Para $t$ grande:** apenas o termo $k=0$ sobra: $u\approx \dfrac{4T_0}{\pi}\sin(\pi x/L)e^{-\kappa\pi^2t/L^2}$.

</Porta>

<Porta nivel="15anos" titulo="Condições de contorno de Neumann — extremidades isoladas">

Para $u_x(0,t) = u_x(L,t) = 0$ (extremidades isoladas), o problema de Sturm-Liouville dá:

$X'' + \lambda X = 0$, $X'(0) = X'(L) = 0$.

**Autovalores:** $\lambda_n = (n\pi/L)^2$, $n = 0,1,2,\ldots$ com $\lambda_0 = 0$.

**Autofunções:** $X_0 = 1$, $X_n = \cos(n\pi x/L)$ para $n\geq 1$.

Solução:
$$u(x,t) = \frac{a_0}{2} + \sum_{n=1}^\infty a_n\cos\!\left(\frac{n\pi x}{L}\right)e^{-\kappa(n\pi/L)^2t}$$

$$a_n = \frac{2}{L}\int_0^L f(x)\cos\!\left(\frac{n\pi x}{L}\right)dx;\quad a_0 = \frac{2}{L}\int_0^L f(x)\,dx$$

**Para $t\to\infty$:** $u\to a_0/2 = \frac{1}{L}\int_0^L f(x)\,dx$ — temperatura média inicial. Energia conservada! (Sem perda pelas bordas.)

</Porta>

<Porta nivel="25anos" titulo="Teoria espectral de Sturm-Liouville">

O problema geral de **Sturm-Liouville** (SL):
$$-(p(x)X')' + q(x)X = \lambda w(x)X,\quad a\leq x\leq b$$
com condições de contorno auto-adjuntas.

**Teorema:** O operador SL tem infinitos autovalores reais $\lambda_1 < \lambda_2 < \cdots \to+\infty$, e as autofunções $\{\phi_n\}$ formam uma **base ortonormal** em $L^2([a,b], w\,dx)$:
$$\int_a^b \phi_m(x)\phi_n(x)w(x)\,dx = \delta_{mn}$$

A expansão $f = \sum c_n\phi_n$ com $c_n = \int_a^b f\phi_n w\,dx$ converge em $L^2$ para $f$ integrável ao quadrado.

**Equação do calor com $\kappa$ variável:** $u_t = (p(x)u_x)_x - q(x)u$ tem solução $u = \sum c_n e^{-\lambda_n t}\phi_n(x)$ — o mesmo mecanismo, com autofunções do operador SL.

</Porta>

<Porta nivel="40anos" titulo="Aplicações em engenharia">

**Tratamento térmico de metais:** o perfil de temperatura numa peça $0\leq x\leq L$ durante têmpera satisfaz a equação do calor. O tempo de têmpera é determinado pelo modo dominante: $\tau_1 = L^2/(\kappa\pi^2)$. Para aço ($\kappa\approx 4\times 10^{-6}$ m²/s) e $L = 0.1$ m: $\tau_1\approx 250$ s. Peças mais espessas requerem tempo muito maior ($\propto L^2$).

**Difusão de dopantes em semicondutores:** o perfil de concentração de dopantes ($n$ ou $p$) após difusão satisfaz a equação de Fick: $c_t = D c_{xx}$. O perfil final depende do tempo e temperatura via $D(T) = D_0 e^{-E_a/(kT)}$ (Arrhenius). A série de Fourier fornece o perfil analítico para geometrias simples.

**Equação de Black-Scholes:** via a mudança $V(S,t) = e^{ax+b\tau}u(x,\tau)$ com $S = e^x$, $\tau = T-t$, a equação de Black-Scholes se reduz à equação do calor $u_\tau = u_{xx}$ — permitindo usar a solução analítica da equação do calor (núcleo de calor) para precificar opções europeias.

</Porta>

<Porta nivel="pratica" titulo="Passo a passo — separação de variáveis">

1. **Separe:** $u = X(x)T(t)$, obtenha $T'/(\kappa T) = X''/X = -\lambda$.
2. **Resolva o SL:** $X''+\lambda X = 0$ com as condições de contorno em $x$.
   - Dirichlet $(X(0)=X(L)=0)$: $\lambda_n = (n\pi/L)^2$, $X_n = \sin(n\pi x/L)$.
   - Neumann $(X'(0)=X'(L)=0)$: $\lambda_n = (n\pi/L)^2$, $X_n = \cos(n\pi x/L)$, inclua $\lambda_0=0$, $X_0=1$.
3. **Resolva** $T_n' = -\kappa\lambda_n T_n \Rightarrow T_n = e^{-\kappa\lambda_n t}$.
4. **Superponha:** $u = \sum c_n X_n(x)T_n(t)$.
5. **Calcule os coeficientes** usando $u(x,0) = f(x)$ e ortogonalidade:
   - Dirichlet: $b_n = \frac{2}{L}\int_0^L f(x)\sin(n\pi x/L)\,dx$.
   - Neumann: $a_n = \frac{2}{L}\int_0^L f(x)\cos(n\pi x/L)\,dx$, $a_0 = \frac{1}{L}\int_0^L f(x)\,dx$.

</Porta>

</DuasPortas>

## Exemplos resolvidos

<Exemplo titulo="Ex. 1 — Temperatura inicial senoidal" numero={1} fonte="Strauss — PDE §4.1, Ex. 1; Kreyszig §21.3, Ex. 3">

$u_t = \kappa u_{xx}$, $u(0,t)=u(\pi,t)=0$, $u(x,0) = 3\sin 2x - 5\sin 5x$.

Como $f(x) = 3\sin 2x - 5\sin 5x$ já é uma combinação de senoidais (com $L = \pi$):

$b_2 = 3$, $b_5 = -5$, todos os outros $b_n = 0$.

$$u(x,t) = 3\sin(2x)e^{-4\kappa t} - 5\sin(5x)e^{-25\kappa t}$$

**Observação:** o modo $n=5$ decai muito mais rápido que o $n=2$ (fator $25/4$). Para $t$ grande, apenas $3\sin(2x)e^{-4\kappa t}$ permanece.

</Exemplo>

<Exemplo titulo="Ex. 2 — Barra com temperatura inicial triangular" numero={2} fonte="Strauss — PDE §4.1, Ex. 4; Churchill & Brown §2.3, Ex. 8">

$u_t = u_{xx}$ ($\kappa=1$, $L=1$), $u(0,t)=u(1,t)=0$, $u(x,0) = \begin{cases}2x & 0\leq x\leq 1/2\\2(1-x) & 1/2\leq x\leq 1\end{cases}$.

$b_n = 2\left[\int_0^{1/2}2x\sin(n\pi x)\,dx + \int_{1/2}^1 2(1-x)\sin(n\pi x)\,dx\right] = \frac{8\sin(n\pi/2)}{n^2\pi^2}$.

Para $n$ par: $b_n = 0$. Para $n = 1,5,9,\ldots$: $b_n = 8/(n^2\pi^2)$. Para $n = 3,7,11,\ldots$: $b_n = -8/(n^2\pi^2)$.

$u(x,t) = \frac{8}{\pi^2}\left[\sin(\pi x)e^{-\pi^2 t} - \frac{1}{9}\sin(3\pi x)e^{-9\pi^2 t}+\cdots\right]$.

</Exemplo>

<Exemplo titulo="Ex. 3 — Equação não-homogênea (temperatura de contorno não nula)" numero={3} fonte="Strauss — PDE §4.2, Ex. 3; Kreyszig §21.3, Ex. 8">

$u_t = \kappa u_{xx}$, $u(0,t) = T_1$, $u(L,t) = T_2$, $u(x,0) = f(x)$.

**Desvio do estado estacionário:** defina $v(x) = T_1+(T_2-T_1)x/L$ (solução estacionária: $v_{xx}=0$ com as C.C.).

$w = u-v$ satisfaz $w_t = \kappa w_{xx}$, $w(0,t)=w(L,t)=0$, $w(x,0) = f(x)-v(x)$.

Aplique a fórmula anterior a $w$, com dado inicial $\tilde{f}(x) = f(x)-v(x)$.

**Resultado:** $u(x,t) = v(x) + \sum_{n=1}^\infty b_n\sin(n\pi x/L)e^{-\kappa(n\pi/L)^2 t}$

com $b_n = \frac{2}{L}\int_0^L[f(x)-v(x)]\sin(n\pi x/L)\,dx$.

Para $t\to\infty$: $u\to v(x)$ — perfil linear, o estado de equilíbrio. $\checkmark$

</Exemplo>

## Exercícios

### Bloco A — Separação de variáveis

<Exercicio numero={1} fonte="Strauss — PDE §4.1, Ex. 1–10; Kreyszig §21.3, Ex. 1–8">
**(a)** Resolva $u_t = 3u_{xx}$, $u(0,t)=u(\pi,t)=0$, $u(x,0)=\sin x + 2\sin 4x$.

**(b)** Resolva $u_t = u_{xx}$, $u_x(0,t)=u_x(1,t)=0$, $u(x,0) = \cos(2\pi x)$.

**(c)** Resolva $u_t = u_{xx}-u$ (equação de calor com decaimento), $u(0,t)=u(\pi,t)=0$, $u(x,0)=f(x)$.
</Exercicio>

### Bloco B — Aplicações

<Exercicio numero={2} fonte="Strauss — PDE §4.2, Ex. 1–8; Churchill & Brown §2.3–2.4, Ex. 1–10">
**(a)** Uma barra de comprimento $\pi$ tem extremidades em $T=0$. A temperatura inicial é $f(x) = x(\pi-x)$. Encontre a temperatura para $t>0$ e o tempo para o ponto médio atingir metade da temperatura inicial.

**(b)** Problema com temperatura de contorno não-nula: $u_t = u_{xx}$, $u(0,t)=20$, $u(1,t)=50$, $u(x,0) = 20+30x^2$. Encontre $u(x,t)$ e o estado de equilíbrio.

**(c)** Determine o **tempo de relaxação** da equação do calor em $[0,L]$ (tempo para a perturbação inicial decair a $1/e$ do valor inicial) em função de $\kappa$ e $L$.
</Exercicio>

### Bloco C — Nível ITA/USP

<Exercicio numero={3} fonte="ITA MA-013; Strauss — PDE §4.3, Ex. 5–12">
**(a)** Prove que as funções $\{\sin(n\pi x/L)\}_{n=1}^\infty$ são ortogonais em $L^2([0,L])$: $\int_0^L\sin(n\pi x/L)\sin(m\pi x/L)\,dx = (L/2)\delta_{mn}$. Use esse resultado para derivar a fórmula dos coeficientes $b_n$.

**(b)** Prove a **unicidade** da solução do problema de calor com Dirichlet: se $u$ e $v$ satisfazem a equação com os mesmos dados, então $u = v$. *(Dica: use $E(t) = \int_0^L w^2\,dx$ para $w = u-v$ e mostre $dE/dt\leq 0$, $E(0)=0$.)*

**(c)** Equação do calor com fonte: $u_t = \kappa u_{xx}+h(x,t)$, $u(0,t)=u(L,t)=0$, $u(x,0)=0$. Use o princípio de Duhamel para escrever a solução como $u(x,t) = \int_0^t\sum_n c_n(s)e^{-\kappa\lambda_n(t-s)}\sin(n\pi x/L)\,ds$ e identifique $c_n(s)$.
</Exercicio>
