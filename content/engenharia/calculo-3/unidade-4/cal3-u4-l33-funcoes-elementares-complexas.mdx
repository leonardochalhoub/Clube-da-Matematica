# As Mesmas Funções, Mas no Plano

Você conhece <Eq>{"e^x"}</Eq>, <Eq>{"\\ln x"}</Eq>, <Eq>{"\\sin x"}</Eq> e <Eq>{"\\cos x"}</Eq> nos números reais.

No plano complexo, essas funções se estendem de forma natural — mas ganham propriedades novas e surpreendentes. O logaritmo, por exemplo, se torna **multivalorado**: um número complexo tem infinitos logaritmos!

# Funções Elementares Complexas

## Exponencial Complexa

A fórmula de Euler define a exponencial complexa:
<Eq>{"e^z = e^{x+iy} = e^x(\\cos y + i\\sin y)"}</Eq>

Propriedades:
- <Eq>{"e^{z_1+z_2} = e^{z_1}e^{z_2}"}</Eq>
- <Eq>{"|e^z| = e^x"}</Eq>, <Eq>{"\\arg(e^z) = y"}</Eq>
- Periódica: <Eq>{"e^{z+2\\pi i} = e^z"}</Eq> (período <Eq>{"2\\pi i"}</Eq>)

## Logaritmo Complexo

O logaritmo complexo é multivalorado:
<Eq>{"\\log z = \\ln|z| + i\\arg(z) = \\ln r + i(\\theta + 2k\\pi), \\quad k \\in \\mathbb{Z}"}</Eq>

O **ramo principal** usa <Eq>{"\\theta = \\text{Arg}(z) \\in (-\\pi,\\pi]"}</Eq>:
<Eq>{"\\text{Log}\\,z = \\ln|z| + i\\,\\text{Arg}(z)"}</Eq>

## Trigonométricas Complexas

<Eq>{"\\sin z = \\frac{e^{iz}-e^{-iz}}{2i}, \\quad \\cos z = \\frac{e^{iz}+e^{-iz}}{2}"}</Eq>

# Funções Elementares Complexas

## Exponencial

<EquacaoCanonica
  formula="e^z = e^x(\cos y + i\sin y), \quad z = x + iy"
  legenda={<>Exponencial complexa via fórmula de Euler</>}
  audioTexto="e elevado a z é igual a e elevado a x, multiplicado por cosseno y mais i seno y."
/>

**Propriedades:**
1. <Eq>{"e^z"}</Eq> é inteira, <Eq>{"(e^z)' = e^z"}</Eq>
2. <Eq>{"e^z \\neq 0"}</Eq> para todo <Eq>{"z \\in \\mathbb{C}"}</Eq>
3. Periódica com período <Eq>{"2\\pi i"}</Eq>: <Eq>{"e^{z+2\\pi i} = e^z"}</Eq>
4. <Eq>{"|e^{iy}| = 1"}</Eq> para <Eq>{"y \\in \\mathbb{R}"}</Eq>

## Logaritmo — Função Multivalorada

Para <Eq>{"z \\neq 0"}</Eq>, <Eq>{"\\log z"}</Eq> é o conjunto de todos os <Eq>{"w"}</Eq> com <Eq>{"e^w = z"}</Eq>:
<Eq>{"\\log z = \\{\\ln|z| + i(\\theta_0 + 2k\\pi) : k \\in \\mathbb{Z}\\}"}</Eq>
onde <Eq>{"\\theta_0 = \\text{Arg}(z)"}</Eq>.

O **ramo principal** <Eq>{"\\text{Log}\\,z = \\ln|z| + i\\,\\text{Arg}(z)"}</Eq> é holomorfo em <Eq>{"\\mathbb{C} \\setminus (-\\infty,0]"}</Eq> (corte no semi-eixo real negativo), com:
<Eq>{"\\frac{d}{dz}\\text{Log}\\,z = \\frac{1}{z}, \\quad z \\notin (-\\infty,0]"}</Eq>

**Atenção:** <Eq>{"\\text{Log}(z_1 z_2) \\neq \\text{Log}(z_1) + \\text{Log}(z_2)"}</Eq> em geral (diferença de múltiplos de <Eq>{"2\\pi i"}</Eq>).

## Potências Complexas

Para <Eq>{"c \\in \\mathbb{C}"}</Eq> e <Eq>{"z \\neq 0"}</Eq>:
<Eq>{"z^c = e^{c\\,\\text{Log}\\,z}"}</Eq>

É holomorfa no mesmo domínio que <Eq>{"\\text{Log}"}</Eq>.

**Exemplos:**
- <Eq>{"i^i = e^{i\\,\\text{Log}(i)} = e^{i(\\pi i/2)} = e^{-\\pi/2} \\approx 0.2079"}</Eq> (número real!)
- <Eq>{"(-1)^{1/2} = e^{(1/2)\\text{Log}(-1)} = e^{i\\pi/2} = i"}</Eq>

## Funções Trigonométricas e Hiperbólicas

**Definições via exponencial:**
<Eq>{"\\sin z = \\frac{e^{iz}-e^{-iz}}{2i}, \\quad \\cos z = \\frac{e^{iz}+e^{-iz}}{2}"}</Eq>
<Eq>{"\\sinh z = \\frac{e^z-e^{-z}}{2}, \\quad \\cosh z = \\frac{e^z+e^{-z}}{2}"}</Eq>

**Relações entre hiperbólicas e trigonométricas:**
<Eq>{"\\sin(iz) = i\\sinh z, \\quad \\cos(iz) = \\cosh z"}</Eq>

**Identidades de Euler:**
<Eq>{"\\sin z = \\sin x\\cosh y + i\\cos x\\sinh y"}</Eq>
<Eq>{"\\cos z = \\cos x\\cosh y - i\\sin x\\sinh y"}</Eq>

**Módulos:** <Eq>{"|\\sin z|^2 = \\sin^2 x + \\sinh^2 y"}</Eq>; ilimitado para <Eq>{"y \\to \\pm\\infty"}</Eq>!

**Zeros:** <Eq>{"\\sin z = 0 \\iff z = n\\pi"}</Eq> (<Eq>{"n \\in \\mathbb{Z}"}</Eq>); <Eq>{"\\cos z = 0 \\iff z = (n+1/2)\\pi"}</Eq>.

# Funções Elementares Complexas — Análise Completa

## Superfícies de Riemann

O logaritmo <Eq>{"\\log z"}</Eq> não é uma função mas uma **relação multivalorada**. Para torná-lo uma função, usa-se a **superfície de Riemann** de <Eq>{"\\log"}</Eq>: infinitas cópias de <Eq>{"\\mathbb{C}\\setminus\\{0\\}"}</Eq> coladas ao longo de um corte, formando uma espiral.

O **ponto de ramificação** em <Eq>{"z=0"}</Eq>: ao contornar a origem uma vez, o valor de <Eq>{"\\log"}</Eq> muda por <Eq>{"2\\pi i"}</Eq>.

**Índice de ramificação** de <Eq>{"z^{1/n}"}</Eq>: o ponto <Eq>{"z=0"}</Eq> tem ramificação <Eq>{"n"}</Eq> (n folhas da superfície de Riemann).

## Função Exponencial: Bijeção em Faixas

<Eq>{"e^z: \\{x+iy : -\\pi < y \\leq \\pi\\} \\to \\mathbb{C}\\setminus\\{0\\}"}</Eq> é bijeção (biholomorfismo).

Mais geralmente, <Eq>{"e^z"}</Eq> leva faixas horizontais <Eq>{"\\{\\alpha < \\text{Im}(z) < \\beta\\}"}</Eq> em setores angulares <Eq>{"\\{\\alpha < \\arg(w) < \\beta\\}"}</Eq>.

## Funções Trigonométricas — Zeros e Singularidades

<Eq>{"\\tan z = \\sin z/\\cos z"}</Eq> tem:
- Zeros: <Eq>{"z = n\\pi"}</Eq>
- Polos simples: <Eq>{"z = (n+1/2)\\pi"}</Eq>
- Período: <Eq>{"\\pi"}</Eq>

A função <Eq>{"\\sec z = 1/\\cos z"}</Eq> é meromorfa com resíduos <Eq>{"(-1)^n"}</Eq> nos polos.

## Exemplos Resolvidos

<Exemplo
  numero={1}
  titulo="Logaritmo e Potências Complexas"
  fonte="Churchill & Brown, Complex Variables and Applications, McGraw-Hill, 9ª ed., §3.2–3.3, Exemplos 2 e 4"
>
**Calcule** <Eq>{"\\text{Log}(-1-i)"}</Eq> **e** <Eq>{"(-1-i)^{1+i}"}</Eq>.

**Resolução:**

<Eq>{"z = -1-i"}</Eq>. Módulo: <Eq>{"|z| = \\sqrt{1+1} = \\sqrt{2}"}</Eq>. Argumento principal: <Eq>{"z"}</Eq> está no 3º quadrante, então <Eq>{"\\text{Arg}(z) = -3\\pi/4"}</Eq>.

<Eq>{"\\text{Log}(-1-i) = \\ln\\sqrt{2} + i(-3\\pi/4) = \\frac{\\ln 2}{2} - \\frac{3\\pi i}{4}"}</Eq>

Para a potência:
<Eq>{"(-1-i)^{1+i} = e^{(1+i)\\text{Log}(-1-i)} = e^{(1+i)(\\frac{\\ln 2}{2} - \\frac{3\\pi i}{4})}"}</Eq>

Expandindo o expoente:
<Eq>{"(1+i)\\!\\left(\\frac{\\ln 2}{2} - \\frac{3\\pi i}{4}\\right) = \\frac{\\ln 2}{2} + \\frac{3\\pi}{4} + i\\!\\left(\\frac{\\ln 2}{2} - \\frac{3\\pi}{4}\\right)"}</Eq>

Logo:
<Eq>{"(-1-i)^{1+i} = e^{\\frac{\\ln 2}{2}+\\frac{3\\pi}{4}}\\cdot e^{i(\\frac{\\ln 2}{2}-\\frac{3\\pi}{4})}"}</Eq>
<Eq>{"= \\sqrt{2}\\,e^{3\\pi/4}\\left[\\cos\\!\\left(\\frac{\\ln 2}{2}-\\frac{3\\pi}{4}\\right)+i\\sin\\!\\left(\\frac{\\ln 2}{2}-\\frac{3\\pi}{4}\\right)\\right]"}</Eq>
</Exemplo>

<Exemplo
  numero={2}
  titulo="Módulo e Argumento de sin e cos"
  fonte="Churchill & Brown, Complex Variables and Applications, McGraw-Hill, 9ª ed., §3.4, Exemplo 1"
>
**Calcule** <Eq>{"\\sin(1+i)"}</Eq> **e** <Eq>{"|\\sin(1+i)|"}</Eq>.

**Resolução:**

Usando <Eq>{"\\sin(x+iy) = \\sin x\\cosh y + i\\cos x\\sinh y"}</Eq> com <Eq>{"x=1"}</Eq>, <Eq>{"y=1"}</Eq>:

<Eq>{"\\sin(1+i) = \\sin 1\\cdot\\cosh 1 + i\\cos 1\\cdot\\sinh 1"}</Eq>

Numericamente: <Eq>{"\\sin 1 \\approx 0.8415"}</Eq>, <Eq>{"\\cosh 1 \\approx 1.5431"}</Eq>, <Eq>{"\\cos 1 \\approx 0.5403"}</Eq>, <Eq>{"\\sinh 1 \\approx 1.1752"}</Eq>.

<Eq>{"\\sin(1+i) \\approx 1.2985 + 0.6350i"}</Eq>

Módulo:
<Eq>{"|\\sin(1+i)|^2 = \\sin^2(1)\\cosh^2(1) + \\cos^2(1)\\sinh^2(1)"}</Eq>
<Eq>{"= \\sin^2 1(1+\\sinh^2 1) + \\cos^2 1\\cdot\\sinh^2 1 = \\sin^2 1 + \\sinh^2 1 \\approx 1.4765"}</Eq>

<Eq>{"|\\sin(1+i)| \\approx 1.2985"}</Eq>
</Exemplo>

<Exemplo
  numero={3}
  titulo="Equação Trigonométrica Complexa"
  fonte="Churchill & Brown, Complex Variables and Applications, McGraw-Hill, 9ª ed., §3.4, Exercício 7"
>
**Resolva** <Eq>{"\\sin z = 2"}</Eq> **em** <Eq>{"\\mathbb{C}"}</Eq>.

**Resolução:**

Escreva <Eq>{"w = e^{iz}"}</Eq>. A equação <Eq>{"\\sin z = (e^{iz}-e^{-iz})/(2i) = 2"}</Eq> torna-se:
<Eq>{"e^{iz} - e^{-iz} = 4i \\implies w - w^{-1} = 4i \\implies w^2 - 4iw - 1 = 0"}</Eq>

Usando Báskara: <Eq>{"w = \\frac{4i \\pm \\sqrt{-16+4}}{2} = 2i \\pm \\sqrt{-3} = i(2\\pm\\sqrt{3})"}</Eq>

Portanto <Eq>{"e^{iz} = i(2\\pm\\sqrt{3})"}</Eq>. Tomando o logaritmo:
<Eq>{"iz = \\text{Log}(i(2\\pm\\sqrt{3})) + 2k\\pi i"}</Eq>
<Eq>{"= \\ln(2\\pm\\sqrt{3}) + \\frac{\\pi i}{2} + 2k\\pi i"}</Eq>

Dividindo por <Eq>{"i"}</Eq>:
<Eq>{"z = \\frac{\\pi}{2} + 2k\\pi - i\\ln(2\\pm\\sqrt{3}), \\quad k \\in \\mathbb{Z}"}</Eq>

Note: <Eq>{"(2+\\sqrt{3})(2-\\sqrt{3}) = 1"}</Eq>, então <Eq>{"\\ln(2-\\sqrt{3}) = -\\ln(2+\\sqrt{3})"}</Eq>; as duas famílias de soluções são conjugadas.
</Exemplo>

# Funções Elementares: Construção Rigorosa

## Exponencial como Homomorfismo

**Proposição.** A função <Eq>{"\\exp: (\\mathbb{C},+) \\to (\\mathbb{C}^*,\\cdot)"}</Eq> é homomorfismo de grupos surjetivo com núcleo <Eq>{"2\\pi i\\mathbb{Z}"}</Eq>. Portanto <Eq>{"\\mathbb{C}^* \\cong \\mathbb{C}/2\\pi i\\mathbb{Z}"}</Eq> como grupos.

## Logaritmo e Superfícies de Riemann

**Definição rigorosa.** A **superfície de Riemann** de <Eq>{"\\log"}</Eq> é o espaço de Riemann <Eq>{"\\mathcal{R} = \\{(z,\\theta) : z \\in \\mathbb{C}^*, \\theta \\in \\mathbb{R}, e^{i\\theta} = z/|z|\\}"}</Eq>, com a projeção <Eq>{"\\pi: \\mathcal{R} \\to \\mathbb{C}^*"}</Eq>, <Eq>{"\\pi(z,\\theta) = z"}</Eq>. O logaritmo <Eq>{"\\log: \\mathcal{R} \\to \\mathbb{C}"}</Eq> é então uma função unívoca e holomorfa.

**Ponto de ramificação:** <Eq>{"z=0"}</Eq> e <Eq>{"z=\\infty"}</Eq> são pontos de ramificação de índice infinito.

## Monodromia

Ao fazer um laço fechado <Eq>{"\\gamma"}</Eq> em torno da origem, o analítico continua de <Eq>{"\\text{Log}"}</Eq> ao longo de <Eq>{"\\gamma"}</Eq> retorna ao ponto inicial com valor acrescido de <Eq>{"2\\pi i"}</Eq>. O **grupo de monodromia** de <Eq>{"\\log z"}</Eq> em <Eq>{"z=0"}</Eq> é <Eq>{"\\mathbb{Z}"}</Eq> (gerado pela translação por <Eq>{"2\\pi i"}</Eq>).
