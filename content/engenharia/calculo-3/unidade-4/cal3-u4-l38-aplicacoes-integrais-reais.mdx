# Resíduos Resolvendo Integrais do Mundo Real

Algumas integrais reais são impossíveis de calcular diretamente — mas o Teorema dos Resíduos as resolve com elegância!

A ideia: "elevar" a integral real ao plano complexo, integrar ao redor de um contorno fechado usando resíduos, e depois separar a parte real que nos interessa.

</Porta>
<Porta nivel="10anos">

# Integrais Reais por Resíduos

O Teorema dos Resíduos permite calcular três tipos principais de integrais reais:

**Tipo 1:** <Eq>{"\\int_0^{2\\pi} R(\\cos\\theta,\\sin\\theta)\\,d\\theta"}</Eq> — usa <Eq>{"z = e^{i\\theta}"}</Eq>

**Tipo 2:** <Eq>{"\\int_{-\\infty}^{+\\infty} \\frac{p(x)}{q(x)}\\,dx"}</Eq> — contorno semicircular + Lema de Jordan

**Tipo 3:** <Eq>{"\\int_{-\\infty}^{+\\infty}\\frac{p(x)}{q(x)}e^{imx}\\,dx"}</Eq> — integrais de Fourier

Em cada caso, a integral real aparece como parte de uma integral de contorno complexa que calculamos por resíduos.

</Porta>
<Porta nivel="15anos">

# Aplicações: Integrais Reais via Resíduos

## Tipo 1 — Integrais Trigonométricas no Círculo

Para <Eq>{"I = \\int_0^{2\\pi}R(\\cos\\theta,\\sin\\theta)\\,d\\theta"}</Eq> com <Eq>{"R"}</Eq> função racional, use a substituição <Eq>{"z = e^{i\\theta}"}</Eq>:
<Eq>{"\\cos\\theta = \\frac{z+z^{-1}}{2}, \\quad \\sin\\theta = \\frac{z-z^{-1}}{2i}, \\quad d\\theta = \\frac{dz}{iz}"}</Eq>

A integral se torna <Eq>{"\\oint_{|z|=1}f(z)\\,dz = 2\\pi i\\sum_{|z_k|<1}\\text{Res}_{z=z_k}f"}</Eq>.

## Tipo 2 — Integrais Impróprias de Funções Racionais

Para <Eq>{"\\int_{-\\infty}^{+\\infty}\\frac{p(x)}{q(x)}\\,dx"}</Eq> com <Eq>{"q"}</Eq> sem zeros reais e <Eq>{"\\deg q \\geq \\deg p + 2"}</Eq>, use o contorno semicircular <Eq>{"C_R = [-R,R] \\cup \\Gamma_R"}</Eq> (semicírculo superior de raio <Eq>{"R"}</Eq>):

Pela estimativa ML, <Eq>{"\\int_{\\Gamma_R}f\\,dz \\to 0"}</Eq>, portanto:
<Eq>{"\\int_{-\\infty}^{+\\infty}\\frac{p(x)}{q(x)}\\,dx = 2\\pi i\\sum_{\\text{Im}(z_k)>0}\\text{Res}_{z=z_k}\\frac{p}{q}"}</Eq>

## Lema de Jordan

**Lema.** Se <Eq>{"f(z) \\to 0"}</Eq> uniformemente para <Eq>{"|z|=R \\to \\infty"}</Eq>, então para <Eq>{"m > 0"}</Eq>:
<Eq>{"\\int_{\\Gamma_R}f(z)e^{imz}\\,dz \\to 0 \\quad (R\\to\\infty)"}</Eq>
mesmo que <Eq>{"R\\cdot\\max_{\\Gamma_R}|f| \\not\\to 0"}</Eq>.

**Prova:** <Eq>{"e^{imz} = e^{im(x+iy)} = e^{imx}e^{-my}"}</Eq>; no semicírculo superior <Eq>{"y \\geq 0"}</Eq>, logo <Eq>{"|e^{imz}| = e^{-my} \\leq 1"}</Eq> e o fator exponencial amortece a integral.

## Tipo 3 — Integrais de Fourier

Para <Eq>{"\\int_{-\\infty}^{+\\infty}\\frac{p(x)}{q(x)}e^{imx}\\,dx"}</Eq> (<Eq>{"m>0"}</Eq>, <Eq>{"q"}</Eq> sem zeros reais, <Eq>{"\\deg q \\geq \\deg p + 1"}</Eq>):

Pelo Lema de Jordan, <Eq>{"\\int_{\\Gamma_R}f(z)e^{imz}\\,dz \\to 0"}</Eq>, portanto:
<Eq>{"\\int_{-\\infty}^{+\\infty}\\frac{p(x)}{q(x)}e^{imx}\\,dx = 2\\pi i\\sum_{\\text{Im}(z_k)>0}\\text{Res}_{z=z_k}\\frac{p(z)e^{imz}}{q(z)}"}</Eq>

Para <Eq>{"m<0"}</Eq>: use o semicírculo inferior.

## Polos no Eixo Real — Indentação

Se <Eq>{"q"}</Eq> tem zero simples real em <Eq>{"x_0"}</Eq>, use o contorno com indentação semicircular de raio <Eq>{"\\varepsilon \\to 0"}</Eq> ao redor de <Eq>{"x_0"}</Eq>:
<Eq>{"\\text{V.P.}\\int_{-\\infty}^{+\\infty}f(x)\\,dx = 2\\pi i\\sum_{\\text{Im}>0}\\text{Res} + \\pi i\\sum_{\\text{no eixo real}}\\text{Res}"}</Eq>

# Técnicas Avançadas de Integração por Resíduos

## Contorno de Chave-de-Fenda (Keyhole)

Para integrais do tipo <Eq>{"\\int_0^\\infty x^{\\alpha}f(x)\\,dx"}</Eq> com <Eq>{"0 < \\alpha < 1"}</Eq>, usa-se o contorno de chave-de-fenda com corte em <Eq>{"[0,\\infty)"}</Eq>.

Com <Eq>{"z^\\alpha = e^{\\alpha\\log z}"}</Eq> (ramo principal), a integral ao redor do contorno dá:
<Eq>{"(1-e^{2\\pi i\\alpha})\\int_0^\\infty x^\\alpha f(x)\\,dx = 2\\pi i\\sum_k \\text{Res}_{z=z_k}[z^\\alpha f(z)]"}</Eq>

## Somas de Séries por Resíduos

A função <Eq>{"\\pi\\cot(\\pi z)"}</Eq> tem polos simples em todos os inteiros com resíduo 1. Logo:
<Eq>{"\\sum_{n=-\\infty}^{+\\infty}f(n) = -\\pi\\sum_k \\text{Res}_{z=z_k}[\\cot(\\pi z)f(z)]"}</Eq>
(onde <Eq>{"z_k"}</Eq> são os polos de <Eq>{"f"}</Eq> não inteiros).

**Exemplo — Problema de Basel:** <Eq>{"\\sum_{n=1}^\\infty\\frac{1}{n^2} = \\frac{\\pi^2}{6}"}</Eq>.

De <Eq>{"\\sum_{n=-\\infty}^\\infty \\frac{1}{n^2}"}</Eq> (excluindo <Eq>{"n=0"}</Eq>) = <Eq>{"-\\pi\\sum_{\\text{polos de }1/z^2}\\text{Res}[\\pi\\cot(\\pi z)/z^2]"}</Eq>.

O polo de ordem 2 em <Eq>{"z=0"}</Eq>: <Eq>{"\\pi\\cot(\\pi z)/z^2"}</Eq> tem resíduo = coeficiente de <Eq>{"1/z"}</Eq> na expansão. Usando <Eq>{"\\pi\\cot(\\pi z) = \\frac{1}{z} - \\frac{\\pi^2 z}{3} - \\frac{\\pi^4 z^3}{45} - \\cdots"}</Eq>:
<Eq>{"\\frac{\\pi\\cot(\\pi z)}{z^2} = \\frac{1}{z^3} - \\frac{\\pi^2}{3z} - \\cdots"}</Eq>

Resíduo em <Eq>{"z=0"}</Eq> = <Eq>{"-\\pi^2/3"}</Eq>. Logo <Eq>{"2\\sum_{n=1}^\\infty 1/n^2 = \\pi^2/3"}</Eq>, portanto <Eq>{"\\sum 1/n^2 = \\pi^2/6"}</Eq>.

## Exemplos Resolvidos

<Exemplo
  numero={1}
  titulo="Integral Trigonométrica"
  fonte="Churchill & Brown, Complex Variables and Applications, McGraw-Hill, 9ª ed., §8.1, Exemplo 1"
>
**Calcule** <Eq>{"I = \\int_0^{2\\pi}\\frac{d\\theta}{2+\\cos\\theta}"}</Eq>.

**Resolução:**

Com <Eq>{"z = e^{i\\theta}"}</Eq>, <Eq>{"\\cos\\theta = (z+z^{-1})/2"}</Eq>, <Eq>{"d\\theta = dz/(iz)"}</Eq>:

<Eq>{"I = \\oint_{|z|=1}\\frac{1}{2+(z+z^{-1})/2}\\cdot\\frac{dz}{iz} = \\oint_{|z|=1}\\frac{2\\,dz}{iz(4+z+z^{-1})} = \\oint_{|z|=1}\\frac{2\\,dz}{i(4z+z^2+1)}"}</Eq>

Denominador: <Eq>{"z^2+4z+1 = 0 \\Rightarrow z = -2\\pm\\sqrt{3}"}</Eq>.

Apenas <Eq>{"z_1 = -2+\\sqrt{3}"}</Eq> satisfaz <Eq>{"|z_1| = |\\sqrt{3}-2| = 2-\\sqrt{3} < 1"}</Eq>.

<Eq>{"\\text{Res}_{z=z_1}\\frac{2}{i(z-z_1)(z-z_2)} = \\frac{2}{i(z_1-z_2)} = \\frac{2}{i(2\\sqrt{3})} = \\frac{1}{i\\sqrt{3}}"}</Eq>

<Eq>{"I = 2\\pi i \\cdot \\frac{1}{i\\sqrt{3}} = \\frac{2\\pi}{\\sqrt{3}}"}</Eq>
</Exemplo>

<Exemplo
  numero={2}
  titulo="Integral Imprópria de Função Racional"
  fonte="Churchill & Brown, Complex Variables and Applications, McGraw-Hill, 9ª ed., §8.2, Exemplo 1"
>
**Calcule** <Eq>{"\\int_{-\\infty}^{+\\infty}\\frac{dx}{(x^2+1)^2}"}</Eq>.

**Resolução:**

<Eq>{"f(z) = \\frac{1}{(z^2+1)^2} = \\frac{1}{(z+i)^2(z-i)^2}"}</Eq>

Polo de ordem 2 em <Eq>{"z=i"}</Eq> (semiplano superior):

<Eq>{"\\text{Res}_{z=i}f = \\lim_{z\\to i}\\frac{d}{dz}\\frac{(z-i)^2}{(z+i)^2(z-i)^2} = \\lim_{z\\to i}\\frac{d}{dz}\\frac{1}{(z+i)^2}"}</Eq>

<Eq>{"= \\lim_{z\\to i}\\frac{-2}{(z+i)^3} = \\frac{-2}{(2i)^3} = \\frac{-2}{-8i} = \\frac{1}{4i} = -\\frac{i}{4}"}</Eq>

<Eq>{"\\int_{-\\infty}^{+\\infty}\\frac{dx}{(x^2+1)^2} = 2\\pi i\\cdot\\left(-\\frac{i}{4}\\right) = \\frac{\\pi}{2}"}</Eq>
</Exemplo>

<Exemplo
  numero={3}
  titulo="Integral de Fourier via Lema de Jordan"
  fonte="Churchill & Brown, Complex Variables and Applications, McGraw-Hill, 9ª ed., §8.3, Exemplo 1"
>
**Calcule** <Eq>{"\\int_{-\\infty}^{+\\infty}\\frac{x\\sin(mx)}{x^2+a^2}\\,dx"}</Eq> **para** <Eq>{"m>0"}</Eq>, <Eq>{"a>0"}</Eq>.

**Resolução:**

Considere <Eq>{"I = \\text{Im}\\int_{-\\infty}^{+\\infty}\\frac{x e^{imx}}{x^2+a^2}\\,dx"}</Eq>.

Polos de <Eq>{"f(z) = ze^{imz}/(z^2+a^2)"}</Eq>: em <Eq>{"z = \\pm ia"}</Eq>. Apenas <Eq>{"z=ia"}</Eq> está no semiplano superior.

Polo simples em <Eq>{"z=ia"}</Eq>:
<Eq>{"\\text{Res}_{z=ia}f = \\frac{ia\\,e^{im(ia)}}{2ia} = \\frac{e^{-ma}}{2}"}</Eq>

Pelo Lema de Jordan (pois <Eq>{"z/(z^2+a^2)\\to 0"}</Eq> uniformemente):
<Eq>{"\\int_{-\\infty}^{+\\infty}\\frac{xe^{imx}}{x^2+a^2}\\,dx = 2\\pi i\\cdot\\frac{e^{-ma}}{2} = \\pi i e^{-ma}"}</Eq>

Tomando a parte imaginária:
<Eq>{"\\int_{-\\infty}^{+\\infty}\\frac{x\\sin(mx)}{x^2+a^2}\\,dx = \\pi e^{-ma}"}</Eq>

**Bônus:** a parte real dá <Eq>{"\\int_{-\\infty}^{+\\infty}\\frac{x\\cos(mx)}{x^2+a^2}\\,dx = 0"}</Eq> (integrando de função ímpar).
</Exemplo>

# Integrais por Resíduos: Justificação Rigorosa

## Lema de Jordan: Prova Completa

**Lema de Jordan.** Se <Eq>{"f"}</Eq> é contínua no semiplano superior para <Eq>{"|z| \\geq R_0"}</Eq> e <Eq>{"\\lim_{|z|\\to\\infty}f(z) = 0"}</Eq>, então para <Eq>{"m > 0"}</Eq>:
<Eq>{"\\int_{\\Gamma_R}f(z)e^{imz}\\,dz \\to 0 \\quad (R\\to\\infty)"}</Eq>
onde <Eq>{"\\Gamma_R = \\{Re^{i\\theta}: 0\\leq\\theta\\leq\\pi\\}"}</Eq>.

**Prova.** Seja <Eq>{"M_R = \\max_{|z|=R, \\text{Im}(z)\\geq 0}|f(z)|"}</Eq>. Na parametrização <Eq>{"z = Re^{i\\theta}"}</Eq>:
<Eq>{"\\left|\\int_{\\Gamma_R}f(z)e^{imz}\\,dz\\right| \\leq M_R R\\int_0^\\pi e^{-mR\\sin\\theta}\\,d\\theta \\leq 2M_R R\\int_0^{\\pi/2}e^{-mR\\cdot 2\\theta/\\pi}\\,d\\theta"}</Eq>
usando <Eq>{"\\sin\\theta \\geq 2\\theta/\\pi"}</Eq> em <Eq>{"[0,\\pi/2]"}</Eq> (desigualdade de Jordan). A integral vale <Eq>{"\\frac{\\pi}{2mR}(1-e^{-mR}) \\leq \\frac{\\pi}{2mR}"}</Eq>. Portanto:
<Eq>{"\\left|\\int_{\\Gamma_R}f\\,e^{imz}\\,dz\\right| \\leq M_R \\cdot \\frac{\\pi}{m} \\to 0"}</Eq>
pois <Eq>{"M_R \\to 0"}</Eq>.

## Valor Principal de Cauchy

**Definição.** O **valor principal de Cauchy** de uma integral imprópria é:
<Eq>{"\\text{V.P.}\\int_{-\\infty}^{+\\infty}f(x)\\,dx = \\lim_{R\\to\\infty}\\int_{-R}^{R}f(x)\\,dx"}</Eq>

Se a integral converge no sentido usual, o V.P. coincide com ela. A recíproca é falsa.

**Nota:** quando <Eq>{"f"}</Eq> tem polos reais, a integral usual diverge mas o V.P. pode existir.
