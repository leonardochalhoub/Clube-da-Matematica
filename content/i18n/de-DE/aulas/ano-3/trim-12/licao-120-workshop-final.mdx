<Teorema titulo="Fundamentalsatz der Calculus (Synthese)">

Sei $f$ stetig auf $[a, b]$ und $F$ eine beliebige Stammfunktion von $f$. Dann:

<Equation explicacao="Teil 1: die durch das Integral definierte Funktion ist differenzierbar und ihre Ableitung ist der Integrand." latex="\frac{d}{dx}\int_a^x f(t)\,dt = f(x), \quad x \in [a, b]" />

<Equation explicacao="Teil 2: das bestimmte Integral wird durch eine beliebige Stammfunktion evaluiert an den Grenzen berechnet." latex="\int_a^b f(x)\,dx = F(b) - F(a)" />

Der Fundamentalsatz ist die Brücke zwischen den zwei Hälften der Calculus — dem Differenziellen und dem Integralen. Er erscheint direkt in 6 der 40 Probleme des Workshops.

</Teorema>

### Was ist Synthese?

Synthese ist das Gegenteil einer Liste isolierter Werkzeuge. Ein konkretes Beispiel:

> *"Ein Unternehmen verkauft $q$ Einheiten pro Tag zu einem Preis von $p(q) = 120 - 2q$ Reais. Die Produktionskosten sind $C(q) = 200 + 40q + q^2$. Finde die Menge, die den Gewinn maximiert."*

Um zu lösen:
1. **Lektion 03** (lineare Funktion) — den Umsatz $R(q) = q \cdot p(q)$ identifizieren.
2. **Lektion 04** (quadratisch) — $L(q) = R(q) - C(q)$ ist quadratisch.
3. **Lektion 51-52** (Ableitung) — löse $L'(q) = 0$.
4. **Lektion 53** (zweite Ableitung) — bestätige, dass es ein Maximum ist.

Du erhältst diese Schritte nicht fertig. Du **rekonstruierst** sie aus deinem Wissen.

- **Aufnahmeprüfung**: ITA/IME-Frage erfordert 3-4 Techniken aus verschiedenen Bereichen.
- **Ingenieurwesen**: echte Probleme kommen niemals mit Etiketten.
- **Daten/KI**: neuronale Netze vermischen lineare Algebra + Calculus + Statistik.

## Gelöste Beispiele

<Exemplo titulo="Optimierung mit Ableitung — Gewinnmaximierung" numero="1">

**Problem:** Ein Unternehmen hat Umsatz $R(q) = 120q - 2q^2$ und Kosten $C(q) = 200 + 40q + q^2$ (in Reais, $q$ Einheiten/Tag). Finde die Menge $q^*$, die den Gewinn $L(q) = R(q) - C(q)$ maximiert.

**Strategie:** Stelle $L(q)$ auf, berechne $L'(q)$, setze gleich Null, überprüfe mit der zweiten Ableitung, dass es Maximum ist.

**Lösung:**

1. $L(q) = (120q - 2q^2) - (200 + 40q + q^2) = -3q^2 + 80q - 200$.
2. $L'(q) = -6q + 80$. Setze gleich Null: $q^* = 80/6 = 40/3 \approx 13,3$ Einheiten/Tag.
3. $L''(q) = -6 < 0$, was Maximum bestätigt.
4. <Eq>{`L(40/3) = -3(40/3)^2 + 80(40/3) - 200 = -\\frac{4800}{9} + \\frac{3200}{3} - 200 = \\frac{1400}{9} \\approx 155,6`}</Eq> Reais/Tag.

**Überprüfung:** $L'(13) = -78 + 80 = 2 > 0$ und $L'(14) = -84 + 80 = -4 < 0$, was bestätigt, dass das Maximum zwischen $q = 13$ und $q = 14$ liegt.

**Quelle.** [Active Calculus §3.3, Übung 3.3.3](https://activecalculus.org/single/sec-3-3-optimization.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Bestimmtes Integral durch Substitution — Fläche unter Kurve" numero="2">

**Problem:** Berechne $\displaystyle\int_0^{\pi/2} \sin^2 x \cos^3 x \; dx$.

**Strategie:** Separiere $\cos^3 x = \cos^2 x \cdot \cos x = (1 - \sin^2 x)\cos x$ und verwende Substitution $u = \sin x$.

**Lösung:**

1. Schreibe $\cos^3 x = (1 - \sin^2 x)\cos x$.
2. Sei $u = \sin x$, daher $du = \cos x\,dx$. Grenzen: $x=0 \Rightarrow u=0$; $x=\pi/2 \Rightarrow u=1$.
3. <Eq>{`\\displaystyle\\int_0^1 u^2(1 - u^2)\\,du = \\int_0^1 (u^2 - u^4)\\,du = \\left[\\frac{u^3}{3} - \\frac{u^5}{5}\\right]_0^1 = \\frac{1}{3} - \\frac{1}{5} = \\frac{2}{15}`}</Eq>.

**Überprüfung:** $0 < 2/15 \approx 0,133$. Der Integrand $\sin^2 x \cos^3 x \geq 0$ in $[0, \pi/2]$ mit Maximalwert um $x \approx 0,63$ rad, wobei $\sin x \approx 0,59$, $\cos x \approx 0,81$; Maximalwert $\approx 0,21$. Fläche $\approx 0,21 \times 1,57/2 \approx 0,16$. Größenordnung konsistent mit $2/15$.

**Quelle.** [Active Calculus §5.3, Übung 5.3.5](https://activecalculus.org/single/sec-5-3-substitution.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Diagonalisierung einer 2×2-Matrix — Eigenwerte und Eigenvektoren" numero="3">

**Problem:** Diagonalisiere <Eq>{`A = \\begin{pmatrix} 3 & 1 \\\\ 0 & 2 \\end{pmatrix}`}</Eq>.

**Strategie:** Berechne $\det(A - \lambda I) = 0$, finde Eigenwerte, dann Eigenvektoren. Stelle $P$ mit Spalten von Eigenvektoren auf und überprüfe $P^{-1}AP = D$.

**Lösung:**

1. $\det(A - \lambda I) = (3-\lambda)(2-\lambda) - 0 = (3-\lambda)(2-\lambda)$. Eigenwerte: $\lambda_1 = 3$, $\lambda_2 = 2$.
2. Für $\lambda_1 = 3$: <Eq>{`(A - 3I)\\mathbf{v} = 0 \\Rightarrow \\begin{pmatrix}0 & 1\\\\ 0 & -1\\end{pmatrix}\\mathbf{v} = 0 \\Rightarrow v_2 = 0`}</Eq>. Eigenvektor: <Eq>{`\\mathbf{v}_1 = (1, 0)^T`}</Eq>.
3. Für $\lambda_2 = 2$: <Eq>{`(A - 2I)\\mathbf{v} = 0 \\Rightarrow \\begin{pmatrix}1 & 1\\\\ 0 & 0\\end{pmatrix}\\mathbf{v} = 0 \\Rightarrow v_1 = -v_2`}</Eq>. Eigenvektor: <Eq>{`\\mathbf{v}_2 = (1, -1)^T`}</Eq>.
4. <Eq>{`P = \\begin{pmatrix}1 & 1 \\\\ 0 & -1\\end{pmatrix}`}</Eq>, <Eq>{`D = \\begin{pmatrix}3 & 0 \\\\ 0 & 2\\end{pmatrix}`}</Eq>.

**Überprüfung:** <Eq>{`AP = P \\begin{pmatrix}3&0\\\\0&2\\end{pmatrix}`}</Eq>. Spalte 1: $A(1,0)^T = (3,0)^T = 3(1,0)^T$. Spalte 2: $A(1,-1)^T = (2,-2)^T = 2(1,-1)^T$. Korrekt.

**Quelle.** [Linear Algebra Done Right, 4. Aufl., §5C Übung 5](https://linear.axler.net/) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Differenzialgleichung 2. Ordnung — einfacher harmonischer Oszillator" numero="4">

**Problem:** Löse $y'' + 4y = 0$ mit $y(0) = 1$, $y'(0) = 0$.

**Strategie:** Lineare homogene Differenzialgleichung 2. Ordnung mit konstanten Koeffizienten. Charakteristische Gleichung $r^2 + 4 = 0$ hat konjugiert komplexe Wurzeln.

**Lösung:**

1. Charakteristische Gleichung: $r^2 + 4 = 0 \Rightarrow r = \pm 2i$.
2. Allgemeine Lösung: $y(x) = C_1 \cos(2x) + C_2 \sin(2x)$.
3. Anfangsbedingung $y(0) = 1$: $C_1 \cdot 1 + C_2 \cdot 0 = 1 \Rightarrow C_1 = 1$.
4. $y'(x) = -2C_1 \sin(2x) + 2C_2 \cos(2x)$. Bedingung $y'(0) = 0$: $2C_2 = 0 \Rightarrow C_2 = 0$.
5. Lösung: $y(x) = \cos(2x)$.

**Überprüfung:** $y'' = -4\cos(2x)$. Also $y'' + 4y = -4\cos(2x) + 4\cos(2x) = 0$. Bedingungen: $y(0) = 1$, $y'(0) = -2\sin(0) = 0$. Korrekt.

**Quelle.** [Notes on Diffy Qs §2.2, Übung 2.2.1](https://www.jirka.org/diffyqs/) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="Einfache lineare Regression — Schätzung von Koeffizienten" numero="5">

**Problem:** Mit den Punkten $(1,2)$, $(2,3)$, $(3,5)$, $(4,4)$, $(5,6)$, finde die Regressionsgerade $\hat y = \hat\beta_0 + \hat\beta_1 x$ mit der Methode der kleinsten Quadrate.

**Strategie:** Verwende die Formeln <Eq>{`\\hat\\beta_1 = \\frac{\\sum(x_i - \\bar x)(y_i - \\bar y)}{\\sum(x_i - \\bar x)^2}`}</Eq> und $\hat\beta_0 = \bar y - \hat\beta_1 \bar x$.

**Lösung:**

1. $n = 5$. $\bar x = (1+2+3+4+5)/5 = 3$. $\bar y = (2+3+5+4+6)/5 = 4$.
2. $\sum(x_i - \bar x)^2 = (-2)^2 + (-1)^2 + 0^2 + 1^2 + 2^2 = 4+1+0+1+4 = 10$.
3. $\sum(x_i - \bar x)(y_i - \bar y) = (-2)(-2)+(-1)(-1)+(0)(1)+(1)(0)+(2)(2) = 4+1+0+0+4 = 9$.
4. $\hat\beta_1 = 9/10 = 0,9$. $\hat\beta_0 = 4 - 0,9 \times 3 = 4 - 2,7 = 1,3$.
5. Gerade: $\hat y = 1,3 + 0,9x$.

**Überprüfung:** Für $x = 3$: $\hat y = 1,3 + 2,7 = 4,0 = \bar y$. Die Regressionsgerade geht immer durch den Punkt $(\bar x, \bar y)$. Korrekt.

**Quelle.** [OpenIntro Statistics 4. Aufl., §8.1 Übung 8.1](https://www.openintro.org/book/os/) — CC-BY-SA.

</Exemplo>
