### Фундаментальные числовые множества

<Definicao titulo="Иерархия вещественных чисел">

- **Натуральные** $\mathbb{N} = \{0, 1, 2, 3, \ldots\}$. (Бразильское соглашение включает ноль; французское соглашение — исключает.)
- **Целые** $\mathbb{Z} = \{\ldots, -2, -1, 0, 1, 2, \ldots\}$ — замкнуты относительно сложения, вычитания и умножения.
- **Рациональные** $\mathbb{Q} = \{p/q \mid p \in \mathbb{Z},\ q \in \mathbb{Z}_{\neq 0}\}$ — всякое число, выражаемое как отношение целых.
- **Вещественные** $\mathbb{R}$ — заполняют числовую ось (заполняют "дыры" вроде $\sqrt{2}$, $\pi$, $e$).

</Definicao>

> "Любое вещественное число соответствует единственной позиции на числовой прямой. Верно и обратное: каждое место на числовой прямой соответствует ровно одному вещественному числу." — [OpenStax College Algebra 2e, §1.1](https://openstax.org/books/college-algebra-2e/pages/1-1-real-numbers-algebra-essentials#Figure_01_01_001)

<Definicao titulo="Рациональные и иррациональные числа">

> "Множество рациональных чисел записывается как $\lbrace m/n \mid m \text{ и } n \text{ — целые и } n \neq 0 \rbrace$. Из определения видно, что рациональные числа — это дроби (или частные) с целыми числителем и знаменателем, и знаменатель никогда не равен 0." — [OpenStax College Algebra 2e, §1.1](https://openstax.org/books/college-algebra-2e/pages/1-1-real-numbers-algebra-essentials#fs-id11713028028)

> "Такие числа называют *иррациональными*, потому что они не могут быть записаны как дроби. Эти числа составляют множество иррациональных чисел." — [OpenStax College Algebra 2e, §1.1](https://openstax.org/books/college-algebra-2e/pages/1-1-real-numbers-algebra-essentials#fs-id11713028028)

</Definicao>

- **Объединение**: $A \cup B = \{x : x \in A \text{ или } x \in B\}$
- **Пересечение**: $A \cap B = \{x : x \in A \text{ и } x \in B\}$
- **Разность**: $A \setminus B = \{x \in A : x \notin B\}$
- **Дополнение** (в универсуме $U$): $A^c = U \setminus A$

Представьте, что у вас есть коробка с **игрушками**. Другая коробка с **книгами**.

- **Объединение** (∪) — это сдвинуть две коробки в одну. Есть игрушки И книги.
- **Пересечение** (∩) — это то, что есть в ДВУХ коробках одновременно. Обычно пусто — игрушка не книга.
- Но если в одной коробке "**красные шарики**", а в другой "**маленькие шарики**", пересечение — это шарики, которые **красные И маленькие**.

</Porta>

<Porta nivel="10" titulo="Для десятилетнего ребёнка">

Математики любят организовывать числа в семейства.

- Семейство **натуральных** $\mathbb{N}$ — это только то, что вы используете для счёта: 0, 1, 2, 3, ...
- Семейство **целых** $\mathbb{Z}$ добавляет отрицательные: ..., −2, −1, 0, 1, 2, ...
- Семейство **рациональных** $\mathbb{Q}$ добавляет дроби: 1/2, 3/4, −5/7, ...
- Семейство **вещественных** $\mathbb{R}$ добавляет странные числа типа **π** (3,14159...) и $\sqrt{2}$ (1,41421...).

**Интервалы** — это короткие способы сказать "все числа между такими-то":
- `[0, 5]` означает "каждое число от 0 до 5, **включая** 0 и 5".
- `(0, 5)` означает "каждое число от 0 до 5, **кроме** 0 и 5".

</Porta>

<Porta nivel="15" titulo="Для пятнадцатилетнего подростка">

Это урок, который устанавливает **язык**, который мы будем использовать в течение следующих 3 лет. Вся продвинутая математика — исчисление, линейная алгебра, статистика — использует эту нотацию. Без неё это как читать физику без букв.

**4 центральных числовых множества:**

| Символ | Имя | Пример |
|---|---|---|
| $\mathbb{N}$ | натуральные | 0, 1, 2, 3, ... |
| $\mathbb{Z}$ | целые | ..., −3, −2, −1, 0, 1, 2, ... |
| $\mathbb{Q}$ | рациональные | 1/2, 3/4, −7/5, 0,333... = 1/3 |
| $\mathbb{R}$ | вещественные | всё это + $\pi$, $\sqrt{2}$, $e$ |

И важное замечание: **не каждое вещественное число рационально**. Иррациональные (такие как $\sqrt{2}$ и $\pi$) — это вещественные числа, которые НЕ могут быть записаны как дробь целых. Это теорема, известная со времён Пифагора (V век до н.э.) — элегантное доказательство вы увидите в упражнении 1.27 этого урока.

**Интервалы** — это сокращения для "всех вещественных чисел между такими пределами":

- `[3, 7]` = $\{x \in \mathbb{R} : 3 \leq x \leq 7\}$ (закрытый, с включёнными концами)
- `(3, 7)` = $\{x : 3 < x < 7\}$ (открытый, без концов)

Когда преподаватель пишет на доске $x \in [3, 7]$, он говорит: "x — это любое вещественное число от 3 до 7, включая 3 и 7". Компактнейше. Сравните с написанием этого в развёрнутом виде.

<Insight>

**Почему разница между $[3, 7]$ и $(3, 7)$?** Потому что в продвинутой математике "включать точку" и "приближаться к ней без достижения" — это разные явления. Когда вы изучите **предел** через несколько месяцев, вы увидите, что $\lim_{x \to 3^+}$ спрашивает, что происходит *когда x приближается к 3 без того, чтобы быть 3*. Разница между открытым и закрытым начинается здесь, сейчас, когда вам 15 лет.

</Insight>

</Porta>

### Критические моменты

**1. ℕ включает 0?** Бразильское соглашение (BNCC) и французское: ДА. Американское и различные классические: НЕТ. Я принимаю **0 ∈ ℕ** на протяжении этой программы, согласовано с BNCC. Когда читаете иностранную книгу, проверьте соглашение автора.

**2. Бразильская vs. англосаксонская нотация интервала:**
- BR: $]a, b[$ для открытого, $[a, b]$ для закрытого (нотация Бурбаки, унаследованная от Франции)
- Anglo: $(a, b)$ для открытого, $[a, b]$ для закрытого

Я принимаю **англо нотацию** (скобки для открытого) для совместимости с 90% книг open, на которые ссылаются в `livros/CATALOG.md`.

> "В этой книге мы будем использовать интервальную нотацию со скобками для открытых интервалов и квадратными скобками для закрытых интервалов, как это принято в англоязычной литературе." — [Stitz-Zeager, Precalculus, Cap. 1](https://www.stitz-zeager.com/szprecalculus07042013.pdf)

**3. Плотность ℚ в ℝ.** Между любыми двумя различными вещественными $a < b$ существует рациональное $q$ с $a < q < b$. **Доказательство** (Упражнение 1.29): использовать архимедову свойство — для всякого $\varepsilon > 0$ существует $n \in \mathbb{N}$ такое, что $1/n < \varepsilon$.

**4. Конечные vs. счётные бесконечные vs. несчётные множества.** Кантор (1874) доказал, что ℝ **несчётно**, но ℚ **счётно** — оба бесконечны, но с разными мощностями. Этот факт вы будете использовать в университетском анализе (Calculus IV / Real Analysis).

### Свойства вещественных чисел

> "Свойство коммутативности сложения утверждает, что числа можно складывать в любом порядке без влияния на сумму." — [OpenStax College Algebra 2e, §1.1](https://openstax.org/books/college-algebra-2e/pages/1-1-real-numbers-algebra-essentials#fs-id11713028028)

> "Распределительное свойство утверждает, что произведение множителя на сумму равно сумме произведений множителя на каждый член суммы." — [OpenStax College Algebra 2e, §1.1](https://openstax.org/books/college-algebra-2e/pages/1-1-real-numbers-algebra-essentials#fs-id11713028028)

### Кросс-доменное соединение

- **Исчисление**: область определения функции — это всегда подмножество ℝ.
- **Вероятность**: пространство элементарных исходов — это множество.
- **Линейная алгебра**: вектор — это кортеж в ℝⁿ или ℂⁿ.
- **Вычисления**: примитивные типы `int`, `float`, `bool` соответствуют ℤ (с границей), ℝ (с конечной точностью), $\{V, F\}$.

### Численный пример

Решите $|2x - 3| \leq 5$ и выразите результат в интервальной нотации:

$$|2x - 3| \leq 5 \iff -5 \leq 2x - 3 \leq 5 \iff -2 \leq 2x \leq 8 \iff -1 \leq x \leq 4$$

Ответ: $x \in [-1, 4]$.

<Porta nivel="40" titulo="Для пожилого профессионала">

Теория множеств — это основание ZFC (Цермело-Френкель + Аксиома выбора), поддерживающее всю современную математику. "Определения" интуитивные, которые мы представляем на этом уроке, имеют известные подводные камни:

- **Парадокс Рассела**: множество всех множеств, которые не содержат себя. Если оно содержит себя, то не содержит. Если не содержит, то содержит. Это сломало наивную теорию Кантора (1901) и привело Цермело к аксиоматизации теории с ограничением комбинирования.

- **Гипотеза континуума**: Кантор предположил, что не существует мощности между $|\mathbb{N}|$ и $|\mathbb{R}|$. Гёдель (1940) и Коэн (1963) доказали, что гипотеза **независима** от аксиом ZFC — и она, и её отрицание совместимы с ZFC.

- **Аксиома выбора**: кажется невинной, но подразумевает странные результаты, такие как Банах-Тарский (разложить сферу и переместить две, равные оригиналу). Решение принять AC практично, но философски деликатно.

В практической профессии (инженерия, прикладная наука, финансы) ничего из этого не появляется. Вы используете $\mathbb{R}^n$ как евклидово пространство и продолжаете. Но если когда-нибудь вы изучите анализ, логику или теорию множеств в аспирантуре, вы вернётесь к этим парадоксам.

### Что на самом деле "вещественное"?

Вычислительно ℝ не существует — каждая цифровая реализация использует **плавающую точку** (IEEE 754), с примерно 7 цифрами точности (float32) или примерно 15 (float64). Ошибки плавающей точки распространяются в численном расчёте (покрыто в семестре 10 с REAMAT). Когда вы напишете `0.1 + 0.2` на Python, вы получите `0.30000000000000004`. $\mathbb{Q} \subsetneq \mathbb{R}$ — это математическая абстракция; компьютер работает в намного меньшем конечном подмножестве, чем $\mathbb{Q}$.

</Porta>

### Пример 4: Область определения функции затрат

<Exemplo titulo="Перечисление элементов множества (применение)" numero="1">

**Задача:** Перечислите в нотации множества множество $A = \{x \in \mathbb{Z} : -2 < x \leq 3\}$.

**Стратегия:** Задача требует перечислить элементы множества. Нотация множества даёт нам две информации:
1. К какому числовому множеству принадлежат элементы: $\mathbb{Z}$ (целые числа).
2. Какие условия должны удовлетворять эти элементы: $-2 < x \leq 3$.
Мы должны объединить эти информации, чтобы выявить все целые числа, которые подходят.

**Решение:**

1. **Определить тип числа:** Элементы $x$ должны быть целыми ($\mathbb{Z}$).
2. **Анализировать первое условие:** $x > -2$. Это означает, что $x$ должно быть больше $-2$. Целые числа, которые удовлетворяют этой части, это $-1, 0, 1, 2, 3, \ldots$.
3. **Анализировать второе условие:** $x \leq 3$. Это означает, что $x$ должно быть меньше или равно $3$. Целые числа, которые удовлетворяют этой части, это $\ldots, 1, 2, 3$.
4. **Объединить условия:** Нам нужны целые $x$, которые *одновременно* больше $-2$ И меньше или равны $3$.
    *   Целые, большие чем $-2$: $\{-1, 0, 1, 2, 3, 4, \ldots\}$
    *   Целые, меньшие или равные $3$: $\{\ldots, -1, 0, 1, 2, 3\}$
    *   Пересечение этих двух множеств это $\{-1, 0, 1, 2, 3\}$.

**Проверка:** Все перечисленные числа целые.
- $-1$ больше чем $-2$ и меньше или равно $3$. (OK)
- $0$ больше чем $-2$ и меньше или равно $3$. (OK)
- $1$ больше чем $-2$ и меньше или равно $3$. (OK)
- $2$ больше чем $-2$ и меньше или равно $3$. (OK)
- $3$ больше чем $-2$ и меньше или равно $3$. (OK)
Ни одно другое целое число между $-2$ и $3$ (исключая $-2$, включая $3$) не было опущено.


**Источник.** [OpenStax — College Algebra 2e §1.1](https://openstax.org/books/college-algebra-2e/pages/1-1-real-numbers-algebra-essentials) — лицензия CC-BY 4.0.
</Exemplo>

<Exemplo titulo="Пересечение интервалов (промежуточный)" numero="2">

**Задача:** Даны интервалы $A = [-3, 7)$ и $B = (1, 10]$, вычислите $A \cap B$.

**Стратегия:** Пересечение двух множеств включает только элементы, которые принадлежат *обоим* множествам. Опять же, визуализация на числовой прямой — наиболее эффективный инструмент.

**Решение:**

1. **Визуализировать интервал $A$:** $A = [-3, 7)$ идёт от -3 (включен) до 7 (исключен).
    ```
    ←—————[----------)————→
         -3          7
    ```
2. **Визуализировать интервал $B$:** $B = (1, 10]$ идёт от 1 (исключен) до 10 (включен).
    ```
    ←——————————(----------]————→
               1          10
    ```
3. **Объединить для пересечения:** Нам нужно найти область, где два интервала перекрываются.
    *   Самая левая точка, где оба присутствуют: $1$. Но $1$ исключен в $B$, поэтому он исключен в пересечении.
    *   Самая правая точка, где оба присутствуют: $7$. Но $7$ исключен в $A$, поэтому он исключен в пересечении.
    *   Область перекрытия находится между $1$ (исключен) и $7$ (исключен).

$$ A \cap B = (1, 7) $$

**Проверка:**
- Точка в пересечении: $x=3$. Находится в $A$ (поскольку $-3 \leq 3 < 7$) и в $B$ (поскольку $1 < 3 \leq 10$). (OK)
- Точка только в $A$: $x=-2$. Не находится в $B$. (OK)
- Точка только в $B$: $x=8$. Не находится в $A$. (OK)
- Концы: $1$ не находится в $B$, $7$ не находится в $A$. Оба исключены в пересечении.
Ответ согласован.


**Источник.** [Stitz–Zeager — Precalculus §1.2](https://www.stitz-zeager.com/szprecalculus07042013.pdf) — лицензия CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="Неравенство с модулем, тип |u| ≤ c (промежуточный)" numero="3">

**Задача:** Решите неравенство $|x - 4| \leq 3$ и выразите решение в интервальной нотации.

**Стратегия:** Неравенства с абсолютной величиной вида $|u| \leq c$ (где $c > 0$) можно переписать как составное неравенство: $-c \leq u \leq c$. Мы применим это свойство и затем решим для $x$.

**Решение:**

1. **Переписать неравенство:** Свойство абсолютного значения позволяет нам преобразовать $|x - 4| \leq 3$ в:
    $$ -3 \leq x - 4 \leq 3 $$
2. **Изолировать $x$:** Чтобы изолировать $x$, добавим $4$ ко всем частям неравенства:
    $$ -3 + 4 \leq x - 4 + 4 \leq 3 + 4 $$
    $$ 1 \leq x \leq 7 $$
3. **Выразить в интервальной нотации:** Неравенство $1 \leq x \leq 7$ означает, что $x$ может быть любым вещественным числом между 1 и 7, включая 1 и 7.

$$ \text{Решение: } [1, 7] $$

**Проверка:**
- Проверить точку внутри интервала: $x=5$. $|5 - 4| = |1| = 1$. $1 \leq 3$. (OK)
- Проверить конец: $x=1$. $|1 - 4| = |-3| = 3$. $3 \leq 3$. (OK)
- Проверить другой конец: $x=7$. $|7 - 4| = |3| = 3$. $3 \leq 3$. (OK)
- Проверить точку вне интервала: $x=0$. $|0 - 4| = |-4| = 4$. $4 \not\leq 3$. (OK)
- Проверить точку вне интервала: $x=8$. $|8 - 4| = |4| = 4$. $4 \not\leq 3$. (OK)
Решение верно.


**Источник.** [OpenStax — College Algebra 2e §1.7](https://openstax.org/books/college-algebra-2e/pages/1-7-linear-inequalities-and-absolute-value-inequalities) — лицензия CC-BY 4.0.
</Exemplo>

<Exemplo titulo="Квадратное неравенство (продвинутый)" numero="4">

**Задача:** Определите множество решений неравенства $x^2 - x - 6 > 0$ в интервальной нотации.

**Стратегия:** Для решения квадратного неравенства сначала найдём корни связанного квадратного уравнения ($x^2 - x - 6 = 0$). Эти корни делят реальную прямую на интервалы. Затем тестируем точку в каждом интервале, чтобы увидеть, где неравенство удовлетворяется.

**Решение:**

1. **Найти корни связанного уравнения:** $x^2 - x - 6 = 0$.
    *   Мы можем разложить уравнение: $(x - 3)(x + 2) = 0$.
    *   Корни это $x = 3$ и $x = -2$.
2. **Разделить реальную прямую на интервалы:** Корни $-2$ и $3$ делят реальную прямую на три интервала:
    *   $(-\infty, -2)$
    *   $(-2, 3)$
    *   $(3, +\infty)$
3. **Тестировать точку в каждом интервале:**
    *   **Интервал $(-\infty, -2)$:** Выберите $x = -3$.
        $(-3)^2 - (-3) - 6 = 9 + 3 - 6 = 6$. Поскольку $6 > 0$, этот интервал *удовлетворяет* неравенству.
    *   **Интервал $(-2, 3)$:** Выберите $x = 0$.
        $(0)^2 - (0) - 6 = -6$. Поскольку $-6 \not> 0$, этот интервал *не удовлетворяет* неравенству.
    *   **Интервал $(3, +\infty)$:** Выберите $x = 4$.
        $(4)^2 - (4) - 6 = 16 - 4 - 6 = 6$. Поскольку $6 > 0$, этот интервал *удовлетворяет* неравенству.
4. **Объединить интервалы, которые удовлетворяют:** Решение — это объединение интервалов, где неравенство верно. Обратите внимание, что неравенство строго больше чем 0, поэтому корни не включены.

$$ \text{Решение: } (-\infty, -2) \cup (3, +\infty) $$

**Проверка:**
- Парабола $y = x^2 - x - 6$ имеет вогнутость вверх (коэффициент $x^2$ положительный). Это означает, что значения функции положительны "вне" корней и отрицательны "между" корнями. Найденное решение согласуется с графиком параболы.


**Источник.** [OpenStax — College Algebra 2e §3.6](https://openstax.org/books/college-algebra-2e/pages/3-6-other-types-of-equations) — лицензия CC-BY 4.0.
</Exemplo>

<Exemplo titulo="Моделирование с исключением точки (реальное моделирование)" numero="5">

**Задача:** Датчик температуры работает корректно в окружающей среде, где температура $T$ (в Цельсиях) должна быть между $10\,°C$ (включительно) и $40\,°C$ (исключительно). Кроме того, по определённому требованию температура не может быть ровно $25\,°C$. Выразите диапазон допустимой работы для $T$ как объединение интервалов.

**Стратегия:** Сначала определим базовый интервал работы. Затем удалим конкретную точку, которая не разрешена. Удаление одной точки из интервала может привести к двум несвязным интервалам.

**Решение:**

1. **Определить базовый интервал:** Температура должна быть между $10\,°C$ (включительно) и $40\,°C$ (исключительно). Это представляется интервалом $[10, 40)$.
2. **Определить точку для исключения:** Температура не может быть $25\,°C$.
3. **Удалить точку из базового интервала:** Число $25$ находится внутри интервала $[10, 40)$. При удалении $25$ интервал делится на две части:
    *   Все числа от $10$ (включительно) до $25$ (исключительно): $[10, 25)$.
    *   Все числа от $25$ (исключительно) до $40$ (исключительно): $(25, 40)$.
4. **Выразить как объединение интервалов:** Диапазон допустимой работы — это объединение этих двух несвязных интервалов.

$$ \text{Диапазон работы: } [10, 25) \cup (25, 40) $$

**Проверка:**
- $T=10$: Допустимо. Находится в первом интервале.
- $T=20$: Допустимо. Находится в первом интервале.
- $T=25$: Не допустимо. Не находится ни в одном из интервалов.
- $T=30$: Допустимо. Находится во втором интервале.
- $T=40$: Не допустимо. Исключено из исходного интервала.
Решение верно и удовлетворяет всем условиям.


**Источник.** [Yoshiwara — Modeling, Functions, and Graphs cap. 1](https://textbooks.aimath.org/textbooks/approved-textbooks/yoshiwara/) — свободная лицензия.
</Exemplo>

<Exercicio numero="1.17" dificuldade="compreensao"
