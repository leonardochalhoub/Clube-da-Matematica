### Фундаментальные числовые множества

<Definicao titulo="Иерархия действительных чисел">

- **Натуральные числа** $\mathbb{N} = \{0, 1, 2, 3, \ldots\}$. (Бразильское соглашение включает ноль; французское соглашение исключает.)
- **Целые числа** $\mathbb{Z} = \{\ldots, -2, -1, 0, 1, 2, \ldots\}$ — замкнуто относительно сложения, вычитания и умножения.
- **Рациональные числа** $\mathbb{Q} = \{p/q \mid p \in \mathbb{Z},\ q \in \mathbb{Z}_{\neq 0}\}$ — всякое число, выразимое как отношение целых.
- **Действительные числа** $\mathbb{R}$ — пополняют числовую ось (заполняют "дыры" как $\sqrt{2}$, $\pi$, $e$).

</Definicao>

> "Любое действительное число соответствует уникальной позиции на числовой прямой. Обратное также верно: каждая позиция на числовой прямой соответствует ровно одному действительному числу." — [OpenStax College Algebra 2e, §1.1](https://openstax.org/books/college-algebra-2e/pages/1-1-real-numbers-algebra-essentials#Figure_01_01_001)

<Definicao titulo="Рациональные и иррациональные числа">

> "Множество рациональных чисел записывается как $\lbrace m/n \mid m \text{ и } n \text{ — целые числа и } n \neq 0 \rbrace$. Из определения видно, что рациональные числа — это дроби (или частные), содержащие целые числа в числителе и знаменателе, и знаменатель никогда не равен нулю." — [OpenStax College Algebra 2e, §1.1](https://openstax.org/books/college-algebra-2e/pages/1-1-real-numbers-algebra-essentials#fs-id11713028028)

> "Такие числа называют *иррациональными*, потому что они не могут быть записаны как дроби. Эти числа образуют множество иррациональных чисел." — [OpenStax College Algebra 2e, §1.1](https://openstax.org/books/college-algebra-2e/pages/1-1-real-numbers-algebra-essentials#fs-id11713028028)

</Definicao>

### Операции над множествами

<Definicao titulo="Объединение, пересечение, разность, дополнение">

- **Объединение**: $A \cup B = \{x : x \in A \text{ или } x \in B\}$
- **Пересечение**: $A \cap B = \{x : x \in A \text{ и } x \in B\}$
- **Разность**: $A \setminus B = \{x \in A : x \notin B\}$
- **Дополнение** (в универсуме $U$): $A^c = U \setminus A$

Представь, у тебя есть коробка с **игрушками**. Другая коробка с **книгами**.

- **Объединение** (∪) — это сложить обе коробки в одну. Есть и игрушки И книги.
- **Пересечение** (∩) — это то, что есть В ОБЕИХ коробках одновременно. Обычно пусто — игрушка не является книгой.
- Но если в одной коробке "**красные мячики**", а в другой "**маленькие мячики**", то пересечение — это мячики, которые **красные И маленькие**.

<Porta nivel="10" titulo="Для десятилетнего ребенка">

Математики любят организовать числа в семьи.

- Семья **натуральных чисел** $\mathbb{N}$ — это только то, что ты используешь для счёта: 0, 1, 2, 3, ...
- Семья **целых чисел** $\mathbb{Z}$ добавляет отрицательные: ..., −2, −1, 0, 1, 2, ...
- Семья **рациональных чисел** $\mathbb{Q}$ добавляет дроби: 1/2, 3/4, −5/7, ...
- Семья **действительных чисел** $\mathbb{R}$ добавляет странные числа, как **π** (3,14159...) и $\sqrt{2}$ (1,41421...).

И **интервалы** — это короткие способы сказать "все числа между таким-то и таким-то":
- `[0, 5]` означает "любое число от 0 до 5, **включая** 0 и 5".
- `(0, 5)` означает "любое число от 0 до 5, **но без** 0 и без 5".

</Porta>

Это урок, который устанавливает **язык**, который мы будем использовать в течение следующих 3 лет. Вся продвинутая математика — исчисление, линейная алгебра, статистика — использует эту нотацию. Без неё это как пытаться читать книгу по физике, не зная букв.

**4 основных числовых множества:**

| Символ | Название | Пример |
|---|---|---|
| $\mathbb{N}$ | натуральные | 0, 1, 2, 3, ... |
| $\mathbb{Z}$ | целые | ..., −3, −2, −1, 0, 1, 2, ... |
| $\mathbb{Q}$ | рациональные | 1/2, 3/4, −7/5, 0,333... = 1/3 |
| $\mathbb{R}$ | действительные | всё это + $\pi$, $\sqrt{2}$, $e$ |

И важное замечание: **не все действительные числа рациональны**. Иррациональные (как $\sqrt{2}$ и $\pi$) — это действительные числа, которые НЕ могут быть записаны как дробь целых. Это теорема, известная со времён Пифагора (V век до н.э.) — элегантное доказательство ты увидишь в упражнении 1.27 этого урока.

**Интервалы** — это сокращения для "все действительные числа между такими-то пределами":

- `[3, 7]` = $\{x \in \mathbb{R} : 3 \leq x \leq 7\}$ (замкнутый, с краями включенными)
- `(3, 7)` = $\{x : 3 < x < 7\}$ (открытый, без краев)

Когда учитель напишет на доске $x \in [3, 7]$, он говорит: "x — любое действительное число между 3 и 7, включая 3 и 7". Очень компактно. Сравни с написанием этого в развёрнутом виде.

<Insight>

**Почему есть разница между $[3, 7]$ и $(3, 7)$?** Потому что в продвинутой математике "включить точку" и "приблизиться к ней без достижения" — это разные явления. Когда ты будешь изучать **предел** через несколько месяцев, увидишь, что $\lim_{x \to 3^+}$ спрашивает, что происходит *когда x приближается к 3 без того, чтобы быть 3*. Разница между открытым и замкнутым начинается здесь, сейчас, когда тебе 15.

</Insight>

### Критические моменты

**1. ℕ включает 0?** Бразильское соглашение (BNCC) и французское: ДА. Американское и различные классические: НЕТ. Я принимаю **0 ∈ ℕ** на протяжении этой программы, согласно BNCC. Когда читаешь иностранную книгу, проверь соглашение автора.

**2. Нотация интервала: бразильская vs англосаксонская:**
- BR: $]a, b[$ для открытого, $[a, b]$ для замкнутого (нотация Бурбаки, унаследованная от Франции)
- Англосаксонская: $(a, b)$ для открытого, $[a, b]$ для замкнутого

Я использую **англосаксонскую нотацию** (скобки для открытого) для совместимости с 90% открытых книг, упоминаемых в `livros/CATALOG.md`.

> "В этой книге мы используем нотацию интервала со скобками для открытых интервалов и квадратными скобками для замкнутых интервалов, как это принято в англоязычной литературе." — [Stitz-Zeager, Precalculus, Гл. 1](https://www.stitz-zeager.com/szprecalculus07042013.pdf)

**3. Плотность ℚ в ℝ.** Между любыми двумя различными действительными $a < b$ существует рациональное $q$ такое, что $a < q < b$. **Доказательство** (Упр. 1.29): использовать архимедово свойство — для всякого $\varepsilon > 0$ существует $n \in \mathbb{N}$ такое, что $1/n < \varepsilon$.

**4. Конечные множества vs счётные бесконечные vs несчётные.** Кантор (1874) доказал, что ℝ **несчётно**, но ℚ **счётно** — оба бесконечны, но с различными мощностями. Этот факт ты будешь использовать в университетском анализе (Анализ IV / Вещественный анализ).

### Свойства действительных чисел

> "Коммутативное свойство сложения утверждает, что числа можно складывать в любом порядке без влияния на сумму." — [OpenStax College Algebra 2e, §1.1](https://openstax.org/books/college-algebra-2e/pages/1-1-real-numbers-algebra-essentials#fs-id11713028028)

> "Распределительное свойство утверждает, что произведение множителя на сумму равно сумме произведений множителя на каждое слагаемое суммы." — [OpenStax College Algebra 2e, §1.1](https://openstax.org/books/college-algebra-2e/pages/1-1-real-numbers-algebra-essentials#fs-id11713028028)

### Связь между областями

- **Исчисление**: область определения функции всегда подмножество ℝ.
- **Вероятность**: пространство исходов — это множество.
- **Линейная алгебра**: векторы — это кортежи в ℝⁿ или ℂⁿ.
- **Компьютерные науки**: примитивные типы `int`, `float`, `bool` соответствуют ℤ (с ограничением), ℝ (с конечной точностью), $\{T, F\}$.

### Числовой пример

Реши $|2x - 3| \leq 5$ и вырази результат в нотации интервала:

$$|2x - 3| \leq 5 \iff -5 \leq 2x - 3 \leq 5 \iff -2 \leq 2x \leq 8 \iff -1 \leq x \leq 4$$

Ответ: $x \in [-1, 4]$.

<Porta nivel="40" titulo="Для профессионала">

Теория множеств — это основание ZFC (Цермело-Френкель + аксиома выбора), которое поддерживает всю современную математику. "Определения", которые мы представили в этом уроке, содержат известные подводные камни:

- **Парадокс Рассела**: множество всех множеств, которые не содержат себя. Если оно содержит себя, то не содержит. Если не содержит, то содержит. Это разрушило наивную теорию Кантора (1901) и побудило Цермело аксиоматизировать теорию с ограничением понимания.

- **Гипотеза континуума**: Кантор предположил, что нет мощности между $|\mathbb{N}|$ и $|\mathbb{R}|$. Гёдель (1940) и Коэн (1963) доказали, что гипотеза **независима** от аксиом ZFC — как она, так и её отрицание согласуются с ZFC.

- **Аксиома выбора**: кажущаяся невинной, но имплицирует странные результаты, такие как Банах-Тарский (разложить сферу и собрать две равные исходной). Решение принять АВ — практическое, но философски деликатное.

В практической работе (инженерия, прикладная наука, финансы) ничего этого не появляется. Ты используешь $\mathbb{R}^n$ как евклидово пространство и продолжаешь. Но если когда-нибудь пойдёшь в аспирантуру по анализу, логике или теории множеств, вернёшься к этим парадоксам.

### Что такое "действительное" на самом деле?

Вычислительно ℝ не существует — всякая цифровая реализация использует **плавающую точку** (IEEE 754), с ~7 цифрами точности (float32) или ~15 (float64). Ошибки плавающей точки распространяются в численном расчёте. Когда запишешь `0.1 + 0.2` в Python, получишь `0.30000000000000004`. $\mathbb{Q} \subsetneq \mathbb{R}$ — это математическая абстракция; компьютер работает в гораздо меньшем конечном подмножестве $\mathbb{Q}$.

</Porta>

### Пример 1: Возрастной диапазон экзамена

Регистрация на экзамен 2025 принимает кандидатов 16 лет и старше. В нотации:

$$\text{возраст кандидата} \in [16, +\infty)$$

Обрати внимание на полуоткрытый справа интервал (нет верхнего предела).

### Пример 2: Минимальная зарплата и налоговое освобождение

В 2025 в Бразилии полное налоговое освобождение для доходов:

$$\text{ежемесячный доход} \in [0,\ 2\,824]$$

(Диапазон в R\$.) Выше этого — прогрессивная налоговая ставка.

### Пример 3: Диапазоны гликемии натощак (медицина)

| Диапазон | Интервал (мг/дл) | Диагноз |
|---|---|---|
| Норма | $[0, 99]$ | здоров |
| Предиабет | $[100, 125]$ | внимание |
| Диабет | $[126, +\infty)$ | лечение |

Всякая медицинская директива выражается как **разбиение** множества возможных значений на интервалы. Если ты будешь биомедицинским инженером или разработчиком ПО для здравоохранения, будешь работать с этими диапазонами каждый день.

### Пример 4: Область функции стоимости

Функция стоимости $C(q) = 50 + 12q + 0,5q^2$ для производства $q$ единиц.

Математическая область: $C: \mathbb{R} \to \mathbb{R}$.
Физическая (реальная) область: $q \in \{0, 1, 2, 3, \ldots\} = \mathbb{N}$ (ты не производишь половину автомобиля).

Когда расчёт "оптимальной точки" даст $q^* = 17,3$, это твоя работа как инженера решить, округлить до 17 или 18 — непрерывная математика даёт решение в ℝ; приложение требует решение в ℕ. Это напряжение **дискретное vs непрерывное** — один из пяти источников эпистемологических трудностей в исчислении согласно Резенде (UFF, 2003).

<Exemplo titulo="Перечисление элементов множества (приложение)" numero="1">

**Задача:** Перечисли в нотации скобок множество $A = \{x \in \mathbb{Z} : -2 < x \leq 3\}$.

**Стратегия:** Задача просит перечислить элементы множества. Нотация множества даёт две информации:
1.  К какому числовому множеству относятся элементы: $\mathbb{Z}$ (целые числа).
2.  Какие условия эти элементы должны удовлетворять: $-2 < x \leq 3$.
Мы объединим эту информацию для определения всех целых, которые подходят.

**Решение:**

1.  **Определить тип числа:** Элементы $x$ должны быть целыми ($\mathbb{Z}$).
2.  **Анализировать первое условие:** $x > -2$. Это означает, что $x$ должно быть больше $-2$. Целые, удовлетворяющие этому: $-1, 0, 1, 2, 3, \ldots$.
3.  **Анализировать второе условие:** $x \leq 3$. Это означает, что $x$ должно быть не больше $3$. Целые, удовлетворяющие этому: $\ldots, 1, 2, 3$.
4.  **Объединить условия:** Нам нужны целые $x$, которые одновременно больше $-2$ И не больше $3$.
    *   Целые больше $-2$: $\{-1, 0, 1, 2, 3, 4, \ldots\}$
    *   Целые не больше $3$: $\{\ldots, -1, 0, 1, 2, 3\}$
    *   Пересечение: $\{-1, 0, 1, 2, 3\}$.

**Проверка:** Все перечисленные — целые.
- $-1$ больше $-2$ и не больше $3$. (ОК)
- $0$ больше $-2$ и не больше $3$. (ОК)
- $1$ больше $-2$ и не больше $3$. (ОК)
- $2$ больше $-2$ и не больше $3$. (ОК)
- $3$ больше $-2$ и не больше $3$. (ОК)
Никакой другой целый между $-2$ и $3$ (исключая $-2$, включая $3$) не пропущен.


**Источник.** [OpenStax — College Algebra 2e §1.1](https://openstax.org/books/college-algebra-2e/pages/1-1-real-numbers-algebra-essentials) — CC-BY 4.0.
</Exemplo>

<Exemplo titulo="Пересечение интервалов (промежуточный)" numero="2">

**Задача:** Даны интервалы $A = [-3, 7)$ и $B = (1, 10]$, вычисли $A \cap B$.

**Стратегия:** Пересечение двух множеств включает только элементы, принадлежащие *обоим* множествам. Опять же, визуализация на числовой прямой — самый эффективный инструмент.

**Решение:**

1.  **Визуализировать интервал $A$:** $A = [-3, 7)$ идёт от -3 (включено) до 7 (исключено).
    ```
    ←—————[----------)————→
         -3          7
    ```
2.  **Визуализировать интервал $B$:** $B = (1, 10]$ идёт от 1 (исключено) до 10 (включено).
    ```
    ←——————————(----------]————→
               1          10
    ```
3.  **Объединить для пересечения:** Нам нужно найти область, где оба интервала перекрываются.
    *   Самая левая точка, где оба присутствуют: $1$. Но $1$ исключен в $B$, так что исключен в пересечении.
    *   Самая правая точка, где оба присутствуют: $7$. Но $7$ исключен в $A$, так что исключен в пересечении.
    *   Перекрывающаяся область — между $1$ (исключено) и $7$ (исключено).

$$ A \cap B = (1, 7) $$

**Проверка:**
- Точка в пересечении: $x=3$. Находится в $A$ (так как $-3 \leq 3 < 7$) и в $B$ (так как $1 < 3 \leq 10$). (ОК)
- Точка только в $A$: $x=-2$. Не в $B$. (ОК)
- Точка только в $B$: $x=8$. Не в $A$. (ОК)
- Концы: $1$ не в $B$, $7$ не в $A$. Оба исключены в пересечении.
Ответ согласован.


**Источник.** [Stitz–Zeager — Precalculus §1.2](https://www.stitz-zeager.com/szprecalculus07042013.pdf) — CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="Неравенство с модулем, типа |u| ≤ c (промежуточный)" numero="3">

**Задача:** Реши неравенство $|x - 4| \leq 3$ и вырази решение в нотации интервала.

**Стратегия:** Неравенства с абсолютной величиной типа $|u| \leq c$ (где $c > 0$) можно переписать как составное неравенство: $-c \leq u \leq c$. Применим это свойство, а затем решим для $x$.

**Решение:**

1.  **Переписать неравенство:** Свойство абсолютной величины позволяет трансформировать $|x - 4| \leq 3$ в:
    $$ -3 \leq x - 4 \leq 3 $$
2.  **Изолировать $x$:** Чтобы изолировать $x$, прибавим $4$ ко всем частям неравенства:
    $$ -3 + 4 \leq x - 4 + 4 \leq 3 + 4 $$
    $$ 1 \leq x \leq 7 $$
3.  **Выразить в нотации интервала:** Неравенство $1 \leq x \leq 7$ означает, что $x$ может быть любым действительным числом между 1 и 7, включая 1 и 7.

$$ \text{Решение: } [1, 7] $$

**Проверка:**
- Тест точки внутри интервала: $x=5$. $|5 - 4| = |1| = 1$. $1 \leq 3$. (ОК)
- Тест конца: $x=1$. $|1 - 4| = |-3| = 3$. $3 \leq 3$. (ОК)
- Тест другого конца: $x=7$. $|7 - 4| = |3| = 3$. $3 \leq 3$. (ОК)
- Тест точки вне интервала: $x=0$. $|0 - 4| = |-4| = 4$. $4 \not\leq 3$. (ОК)
- Тест точки вне интервала: $x=8$. $|8 - 4| = |4| = 4$. $4 \not\leq 3$. (ОК)
Решение верно.


**Источник.** [OpenStax — College Algebra 2e §1.7](https://openstax.org/books/college-algebra-2e/pages/1-7-linear-inequalities-and-absolute-value-inequalities) — CC-BY 4.0.
</Exemplo>

<Exemplo titulo="Квадратное неравенство (продвинутый)" numero="4">

**Задача:** Определи множество решений неравенства $x^2 - x - 6 > 0$ в нотации интервала.

**Стратегия:** Чтобы решить квадратное неравенство, сначала найди корни связанного квадратного уравнения ($x^2 - x - 6 = 0$). Эти корни разбивают действительную прямую на интервалы. Затем протестируем точку в каждом интервале, чтобы увидеть, где неравенство удовлетворяется.

**Решение:**

1.  **Найти корни связанного уравнения:** $x^2 - x - 6 = 0$.
    *   Можем разложить: $(x - 3)(x + 2) = 0$.
    *   Корни: $x = 3$ и $x = -2$.
2.  **Разбить действительную прямую на интервалы:** Корни $-2$ и $3$ разбивают действительную прямую на три интервала:
    *   $(-\infty, -2)$
    *   $(-2, 3)$
    *   $(3, +\infty)$
3.  **Протестировать точку в каждом интервале:**
    *   **Интервал $(-\infty, -2)$:** Выбери $x = -3$.
        $(-3)^2 - (-3) - 6 = 9 + 3 - 6 = 6$. Так как $6 > 0$, этот интервал *удовлетворяет* неравенство.
    *   **Интервал $(-2, 3)$:** Выбери $x = 0$.
        $(0)^2 - (0) - 6 = -6$. Так как $-6 \not> 0$, этот интервал *не удовлетворяет* неравенство.
    *   **Интервал $(3, +\infty)$:** Выбери $x = 4$.
        $(4)^2 - (4) - 6 = 16 - 4 - 6 = 6$. Так как $6 > 0$, этот интервал *удовлетворяет* неравенство.
4.  **Объединить интервалы, которые удовлетворяют:** Решение — объединение интервалов, где неравенство верно. Обрати внимание, что неравенство строго больше нуля, так что корни не включены.

$$ \text{Решение: } (-\infty, -2) \cup (3, +\infty) $$

**Проверка:**
- Парабола $y = x^2 - x - 6$ имеет ветви вверх (коэффициент $x^2$ положительный). Это означает, что значения функции положительны "снаружи" корней и отрицательны "между" корнями. Найденное решение согласуется с графиком параболы.


**Источник.** [OpenStax — College Algebra 2e §3.6](https://openstax.org/books/college-algebra-2e/pages/3-6-other-types-of-equations) — CC-BY 4.0.
</Ejemplo>

<Ejemplo titulo="Моделирование с исключением точки (реальное моделирование)" numero="5">

**Задача:** Датчик температуры работает правильно в окружающей среде, где температура $T$ (в Цельсии) должна быть между $10\,°C$ (включая) и $40\,°C$ (исключая). Кроме того, по специальному требованию, температура не может быть ровно $25\,°C$. Вырази правильную рабочую область для $T$ как объединение интервалов.

**Стратегия:** Сначала определи базовый интервал работы. Затем исключи специфическую точку, которая не разрешена. Исключение одной точки из интервала может дать два несвязанных интервала.

**Решение:**

1.  **Определить базовый интервал:** Температура должна быть между $10\,°C$ (включая) и $40\,°C$ (исключая). Это представляется интервалом $[10, 40)$.
2.  **Определить исключаемую точку:** Температура не может быть $25\,°C$.
3.  **Исключить точку из базового интервала:** Число $25$ находится внутри интервала $[10, 40)$. Исключив $25$, интервал разбивается на две части:
    *   Все числа от $10$ (включая) до $25$ (исключая): $[10, 25)$.
    *   Все числа от $25$ (исключая) до $40$ (исключая): $(25, 40)$.
4.  **Выразить как объединение интервалов:** Правильная рабочая область — объединение этих двух несвязанных интервалов.

$$ \text{Рабочая область: } [10, 25) \cup (25, 40) $$

**Проверка:**
- $T=10$: Правильно. Находится в первом интервале.
- $T=20$: Правильно. Находится в первом интервале.
- $T=25$: Неправильно. Не находится ни в одном интервале.
- $T=30$: Правильно. Находится во втором интервале.
- $T=40$: Неправильно. Исключена из исходного интервала.
Решение верно и удовлетворяет всем условиям.


**Источник.** [Yoshiwara — Modeling, Functions, and Graphs гл. 1](https://textbooks.aimath.org/textbooks/approved-textbooks/yoshiwara/) — свободная лицензия.
</Exemplo>
