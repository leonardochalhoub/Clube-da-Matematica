### Фундаментальные тождества

<Definicao titulo="Тождества, используемые в тригонометрических интегралах">

Следующие тождества являются ключевыми инструментами:

- **Пифагор:** $\sin^2 x + \cos^2 x = 1$; $1 + \tan^2 x = \sec^2 x$; $1 + \cot^2 x = \csc^2 x$.
- **Чётная степень (полуугол):**

<Equation explicacao="Редуцирует sin² и cos² к функциям двойного угла — необходимо для чётных показателей." latex="\sin^2 x = \frac{1 - \cos 2x}{2}, \qquad \cos^2 x = \frac{1 + \cos 2x}{2}." />

- **Произведение в сумму:** $\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$.

</Definicao>

### Паттерны для $\int \sin^n x \cos^m x\, dx$

<Definicao titulo="Стратегия по чётности показателей">

| Случай | Стратегия |
|---|---|
| $n$ нечётно | Выделите $\sin x\, dx$; преобразуйте $\sin^{n-1}$ через $\sin^2 = 1 - \cos^2$; подставьте $u = \cos x$ |
| $m$ нечётно | Выделите $\cos x\, dx$; преобразуйте $\cos^{m-1}$ через $\cos^2 = 1 - \sin^2$; подставьте $u = \sin x$ |
| Оба чётны | Повторно используйте полуугол |

Для $\int \tan^n x \sec^m x\, dx$:

| Случай | Стратегия |
|---|---|
| $m$ чётно | Выделите $\sec^2 x\, dx$; преобразуйте через $\sec^2 = 1 + \tan^2$; подстановка $u = \tan x$ |
| $n$ нечётно | Выделите $\sec x \tan x\, dx$; преобразуйте через $\tan^2 = \sec^2 - 1$; подстановка $u = \sec x$ |

</Definicao>

> "Стратегия интегрирования произведения степеней синуса и косинуса зависит от чётности показателей. Когда один из показателей нечётен, мы "откалываем" один множитель и используем тождество Пифагора для преобразования оставшейся чётной степени." — [OpenStax Calculus Vol. 2, §3.2](https://openstax.org/books/calculus-volume-2/pages/3-2-trigonometric-integrals)

### Формулы редукции

<Teorema titulo="Формула редукции для sinⁿ">

$$\int \sin^n x\, dx = -\frac{\sin^{n-1}x \cos x}{n} + \frac{n-1}{n}\int \sin^{n-2}x\, dx.$$

Аналогичные формулы существуют для $\cos^n$, $\tan^n$, $\sec^n$, $\csc^n$.

**Доказательство:** интегрирование по частям с $u = \sin^{n-1}x$, $dv = \sin x\, dx$, плюс тождество $\sin^2 = 1 - \cos^2$.

</Teorema>

<Insight>

**Подстановка Вейерштрасса** (универсальная): $t = \tan(x/2)$ преобразует любой рациональный интеграл от $\sin x$, $\cos x$ в рациональный интеграл от $t$. Через разложение на простые дроби всё становится элементарным — но результат может быть сложным. Используйте, когда другие стратегии не работают.

</Insight>

</Porta>

<Porta nivel="5" titulo="Для пятилетнего ребёнка">

Знаете, как вы надеваете костюм привидения, чтобы никто вас не узнал, а потом его снимаете? Тригонометрическая подстановка — это то же самое.

У вас есть $\sqrt{1 - x^2}$ — сложно работать. Вы меняете $x$ на $\sin\theta$ — переодеваетесь! Радикал исчезает и становится $\cos\theta$. После вычисления с $\theta$ вы снимаете костюм и возвращаетесь к $x$.

</Porta>

<Porta nivel="10" titulo="Для десятилетнего ребёнка">

Есть одно тождество, которое вы знаете: $\sin^2\theta + \cos^2\theta = 1$.

Это означает, что $\sqrt{1 - \sin^2\theta} = \cos\theta$ (при условии, что $\cos\theta \geq 0$).

Итак, если у вас есть $\sqrt{1 - x^2}$ и вы полагаете $x = \sin\theta$, радикал исчезает и становится $\cos\theta$.

После интегрирования по $\theta$ вы используете треугольник: если $\sin\theta = x$ и гипотенуза равна 1, то прилежащий катет равен $\sqrt{1 - x^2}$. Это даёт вам $\cos\theta$, $\tan\theta$ и т. д. в терминах $x$ — и вы "отменяете" подстановку.

</Porta>

<Porta nivel="15" titulo="Для пятнадцатилетнего подростка">

### Степени синуса и косинуса

**Случай 1 (нечётный показатель):** $\int \sin^3 x\, dx$.

Выделите одно $\sin x\, dx$, преобразуйте остаток: $\sin^2 x = 1 - \cos^2 x$.

$\int (1 - \cos^2 x)\sin x\, dx$. Подстановка $u = \cos x$: $-\int(1 - u^2)\, du = -u + u^3/3 + C = -\cos x + \cos^3 x/3 + C$.

**Случай 2 (чётные показатели):** $\int \sin^2 x\, dx$.

Используйте полуугол: $\int \frac{1 - \cos 2x}{2}\, dx = \frac{x}{2} - \frac{\sin 2x}{4} + C$.

### Тригонометрическая подстановка

**Пример:** $\int \sqrt{1 - x^2}\, dx$.

Подстановка $x = \sin\theta$, $dx = \cos\theta\, d\theta$, $\sqrt{1-x^2} = \cos\theta$.

Интеграл становится $\int \cos^2\theta\, d\theta = \theta/2 + \sin(2\theta)/4 + C$.

Вернитесь: $\theta = \arcsin x$, $\sin(2\theta) = 2\sin\theta\cos\theta = 2x\sqrt{1-x^2}$.

Результат: $\dfrac{\arcsin x}{2} + \dfrac{x\sqrt{1-x^2}}{2} + C$.

**Треугольник отсчёта:** всегда рисуйте — это ключ к преобразованию тригонометрических функций $\theta$ обратно в $x$.

</Porta>

<Porta nivel="25" titulo="Для студента инженерного факультета">

### Таблица основных интегралов

- $\int \sin^2 x\, dx = (x - \sin x\cos x)/2 + C$.
- $\int \cos^2 x\, dx = (x + \sin x\cos x)/2 + C$.
- $\int \tan x\, dx = -\ln\lvert\cos x\rvert + C = \ln\lvert\sec x\rvert + C$.
- $\int \cot x\, dx = \ln\lvert\sin x\rvert + C$.
- $\int \sec x\, dx = \ln\lvert\sec x + \tan x\rvert + C$.
- $\int \csc x\, dx = -\ln\lvert\csc x + \cot x\rvert + C$.
- $\int \sec^2 x\, dx = \tan x + C$; $\int \csc^2 x\, dx = -\cot x + C$.
- $\int \sec x\tan x\, dx = \sec x + C$.

### Инженерные приложения

- **RMS синусоиды:** $V_{rms} = V_0/\sqrt{2}$ — через $\int_0^T \sin^2(\omega t)\, dt = T/2$.
- **Распределение Коши:** $\int_{-\infty}^\infty 1/(\pi(1+x^2))\, dx = 1$ — подстановка $x = \tan\theta$.
- **Длина дуги эллипса:** $\int \sqrt{1 - k^2\sin^2\theta}\, d\theta$ — эллиптический интеграл, без замкнутой формы.
- **Коэффициенты Фурье:** $a_n = (1/\pi)\int_{-\pi}^\pi f(x)\cos(nx)\, dx$ — для тригонометрического $f$, прямое вычисление через тождества.

### Эйлер и комплексные тождества

Степени $\sin x$ и $\cos x$ вычисляются через Эйлера: $\sin x = (e^{ix} - e^{-ix})/(2i)$, $\cos x = (e^{ix} + e^{-ix})/2$. Биномиальное разложение + интегрирование комплексных экспонент, затем вещественная/мнимая части.

</Porta>

<Porta nivel="40" titulo="Для старшего специалиста">

### Подстановка Вейерштрасса (универсальная)

$t = \tan(x/2)$ преобразует любую рациональную функцию от $\sin x$ и $\cos x$ в рациональную от $t$:

$$\sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2\,dt}{1+t^2}.$$

Полученный интеграл решается разложением на простые дроби. Однако результат может быть более сложным, чем прямые методы — используйте, когда другие стратегии не работают или в CAS.

### Эллиптические интегралы

$\int \sqrt{1 - k^2\sin^2\theta}\, d\theta = E(k)$ и $\int d\theta/\sqrt{1 - k^2\sin^2\theta} = K(k)$ — эллиптические интегралы Лежандра. Они не элементарны при $k \neq 0$. Появляются в длине эллипса, точном маятнике, гравитации.

### Анализ Фурье

Коэффициенты $a_n, b_n$ обобщённого ряда Фурье вычисляются через тригонометрические интегралы. Гладкость $f$ контролирует убывание $|a_n|$, $|b_n|$ — анализ Фурье связывает тригонометрические интегралы с теорией аппроксимации.

### Дифференциальная геометрия

Длина дуги $L = \int \sqrt{1 + (f')^2}\, dx$ включает тригонометрическую подстановку, когда $f' = \tan\theta$. Кривизна $\kappa = |f''|/(1 + (f')^2)^{3/2}$ появляется интегрированием при вычислении длины дуги в натуральных координатах. Подстановка в несколько переменных: сферические и цилиндрические координаты — якобианы тригонометрические.

</Porta>

<Porta nivel="pratica" titulo="Практическое применение">

**Рецепт для тригонометрических интегралов:**

1. Посмотрите на показатели $\sin$ и $\cos$.
2. Какой-то нечётный? Выделите одну копию этого множителя с его $dx$, преобразуйте остаток.
3. Оба чётны? Используйте $\sin^2 = (1 - \cos 2x)/2$ и $\cos^2 = (1 + \cos 2x)/2$.
4. Радикал $\sqrt{a^2 \pm x^2}$ или $\sqrt{x^2 - a^2}$? Применяйте тригонометрическую подстановку из таблицы.
5. После подстановки нарисуйте треугольник отсчёта, чтобы вернуться к $x$.
6. Проверьте дифференцированием.

### Площадь круга — каноническая проверка

$A = 4\int_0^r \sqrt{r^2 - x^2}\, dx$. Подстановка $x = r\sin\theta$: интеграл становится $4r^2\int_0^{\pi/2}\cos^2\theta\, d\theta = 4r^2\cdot\pi/4 = \pi r^2$.

### RMS синусоиды — цепи

Напряжение $v(t) = V_0\sin(\omega t)$ за один период $T = 2\pi/\omega$:

$$V_{rms} = \sqrt{\frac{1}{T}\int_0^T V_0^2\sin^2(\omega t)\, dt} = V_0\sqrt{\frac{1}{2}} = \frac{V_0}{\sqrt{2}} \approx 0{,}707\, V_0.$$

### Типичные ошибки

- Забыть якобиан $dx \to a\cos\theta\, d\theta$ (или $a\sec^2\theta\, d\theta$) — приводит к пропущенному множителю $a$.
- Не вернуться от $\theta$ к $x$ с помощью треугольника.
- Путать $\sin^2 x$ (степень) с $\sin(2x)$ (двойной угол).
- При $x = a\sec\theta$ забыть правильную ветвь $\theta$.

</Porta>

## Примеры решённых задач

<Exemplo titulo="Нечётная степень синуса (базовый уровень)" numero="1">

**Задача.** Вычислите $\int \sin^3 x\, dx$.

**Стратегия.** Нечётный показатель: выделите $\sin x\, dx$, преобразуйте $\sin^2 = 1 - \cos^2$, подставьте $u = \cos x$.

**Решение.**

$\int \sin^3 x\, dx = \int \sin^2 x \cdot \sin x\, dx = \int (1 - \cos^2 x)\sin x\, dx$.

Подстановка $u = \cos x$, $du = -\sin x\, dx$:

$-\int (1 - u^2)\, du = -u + u^3/3 + C = -\cos x + \frac{\cos^3 x}{3} + C$.

**Проверка.** Дифференцируя: $\sin x - \cos^2 x\sin x = \sin x(1 - \cos^2 x) = \sin^3 x$. Правильно.

**Источник.** [APEX Calculus §6.3, Example 6.3.1](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Чётные показатели — полуугол (базовый уровень)" numero="2">

**Задача.** Вычислите $\int \sin^2 x \cos^2 x\, dx$.

**Стратегия.** Оба чётны: используйте $\sin x\cos x = \sin(2x)/2$ и затем полуугол.

**Решение.**

$\sin^2 x\cos^2 x = (\sin x\cos x)^2 = \frac{\sin^2(2x)}{4} = \frac{1}{4}\cdot\frac{1 - \cos 4x}{2} = \frac{1 - \cos 4x}{8}$.

$$\int \sin^2 x\cos^2 x\, dx = \frac{x}{8} - \frac{\sin 4x}{32} + C.$$

**Проверка.** Дифференцируя: $1/8 - \cos(4x)/8 = (1 - \cos 4x)/8 = \sin^2(2x)/4 = \sin^2 x\cos^2 x$. Правильно.

**Источник.** [OpenStax Calculus Vol. 2, §3.2, Example 3.12](https://openstax.org/books/calculus-volume-2/pages/3-2-trigonometric-integrals) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Подстановка x = a sin θ для √(a² − x²) (средний уровень)" numero="3">

**Задача.** Вычислите $\int \sqrt{4 - x^2}\, dx$.

**Стратегия.** Радикал $\sqrt{a^2 - x^2}$ с $a = 2$: подстановка $x = 2\sin\theta$.

**Решение.**

$dx = 2\cos\theta\, d\theta$; $\sqrt{4 - x^2} = \sqrt{4 - 4\sin^2\theta} = 2\cos\theta$ (с $\theta \in [-\pi/2, \pi/2]$).

$\int 2\cos\theta \cdot 2\cos\theta\, d\theta = 4\int\cos^2\theta\, d\theta = 4\cdot\frac{\theta + \sin\theta\cos\theta}{2} = 2\theta + 2\sin\theta\cos\theta + C$.

Треугольник отсчёта ($\sin\theta = x/2$, гипотенуза 2, прилежащий катет $\sqrt{4-x^2}$):

$\theta = \arcsin(x/2)$; $\cos\theta = \sqrt{4-x^2}/2$.

Результат: $2\arcsin(x/2) + 2\cdot\frac{x}{2}\cdot\frac{\sqrt{4-x^2}}{2} + C = 2\arcsin(x/2) + \frac{x\sqrt{4-x^2}}{2} + C$.

**Проверка.** Дифференцируя (цепное правило): $\frac{2}{\sqrt{4-x^2}} + \frac{\sqrt{4-x^2} - x^2/\sqrt{4-x^2}}{2} = \frac{2}{\sqrt{4-x^2}} + \frac{4 - 2x^2}{2\sqrt{4-x^2}} = \sqrt{4-x^2}$. Правильно.

**Источник.** [APEX Calculus §6.4, Example 6.4.2](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Подстановка x = a tan θ для √(a² + x²) (средний уровень)" numero="4">

**Задача.** Вычислите $\int \dfrac{1}{\sqrt{1 + x^2}}\, dx$.

**Стратегия.** Радикал $\sqrt{a^2 + x^2}$ с $a = 1$: подстановка $x = \tan\theta$.

**Решение.**

$dx = \sec^2\theta\, d\theta$; $\sqrt{1+x^2} = \sec\theta$.

$\int \frac{\sec^2\theta}{\sec\theta}\, d\theta = \int \sec\theta\, d\theta = \ln\lvert\sec\theta + \tan\theta\rvert + C$.

Треугольник ($\tan\theta = x$, гипотенуза $\sqrt{1+x^2}$): $\sec\theta = \sqrt{1+x^2}$, $\tan\theta = x$.

Результат: $\ln\lvert x + \sqrt{1+x^2}\rvert + C$ (эквивалентно $\text{arcsinh}(x) + C$).

**Проверка.** Дифференцируя $\ln(x + \sqrt{1+x^2})$: $\frac{1 + x/\sqrt{1+x^2}}{x + \sqrt{1+x^2}} = \frac{(\sqrt{1+x^2}+x)/\sqrt{1+x^2}}{x+\sqrt{1+x^2}} = \frac{1}{\sqrt{1+x^2}}$. Правильно.

**Источник.** [OpenStax Calculus Vol. 2, §3.3, Example 3.15](https://openstax.org/books/calculus-volume-2/pages/3-3-trigonometric-substitution) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Формула редукции и применение (сложный уровень)" numero="5">

**Задача.** Выведите формулу редукции $\int \sin^n x\, dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n-1}{n}\int\sin^{n-2}x\, dx$ и используйте её для вычисления $\int_0^{\pi/2}\sin^4 x\, dx$.

**Стратегия.** Вывести интегрированием по частям; применить для $n = 4$ и $n = 2$.

**Решение.**

**Вывод:** $u = \sin^{n-1}x$, $dv = \sin x\, dx$. $du = (n-1)\sin^{n-2}x\cos x\, dx$, $v = -\cos x$.

$\int\sin^n x\, dx = -\sin^{n-1}x\cos x + (n-1)\int\cos^2 x\sin^{n-2}x\, dx$.

Подставьте $\cos^2 x = 1 - \sin^2 x$:

$(n-1)\int(1 - \sin^2 x)\sin^{n-2}x\, dx = (n-1)\int\sin^{n-2}x\, dx - (n-1)\int\sin^n x\, dx$.

Переставьте: $n\int\sin^n x\, dx = -\sin^{n-1}x\cos x + (n-1)\int\sin^{n-2}x\, dx$. Разделите на $n$.

**Применение:** $n = 4$: $\int\sin^4 x\, dx = -\frac{\sin^3 x\cos x}{4} + \frac{3}{4}\int\sin^2 x\, dx$.

$\int\sin^2 x\, dx = x/2 - \sin(2x)/4$.

Вычисление на $[0, \pi/2]$: $\int_0^{\pi/2}\sin^4 x\, dx = 0 + \frac{3}{4}\left[\frac{\pi}{4} - 0\right] = \frac{3\pi}{16}$.

**Проверка.** Формула Уоллиса: $\int_0^{\pi/2}\sin^4 x\, dx = \frac{3\cdot 1}{4\cdot 2}\cdot\frac{\pi}{2} = \frac{3\pi}{16}$. Подтверждает.

**Источник.** [APEX Calculus §6.3, Theorem 6.3.1](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>
