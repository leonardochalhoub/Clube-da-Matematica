### Теорема замены переменной

<Teorema titulo="Подстановка (замена переменной)">

Пусть $g: [a, b] \to \mathbb{R}$ дифференцируема с непрерывной $g'$, и $f$ непрерывна на образе $g$. Тогда:

$$\int_a^b f(g(x))\, g'(x)\, dx = \int_{g(a)}^{g(b)} f(u)\, du.$$

**Неопределённый интеграл:** если $F' = f$, то $\int f(g(x))\, g'(x)\, dx = F(g(x)) + C$.

</Teorema>

> "Правило подстановки при интегрировании является аналогом цепного правила при дифференцировании." — [OpenStax Calculus Vol. 1, §5.5](https://openstax.org/books/calculus-volume-1/pages/5-5-substitution)

**Доказательство.** Если $F' = f$, то по цепному правилу: $(F \circ g)' = f(g(x)) \cdot g'(x)$. Таким образом, $F \circ g$ является первообразной $f(g(x)) g'(x)$. По Основной теореме анализа:

$$\int_a^b f(g(x)) g'(x)\, dx = F(g(b)) - F(g(a)) = \int_{g(a)}^{g(b)} f(u)\, du. \quad \square$$

### Механическая процедура

<Definicao titulo="Шаги подстановки">

1. **Определите** $u = g(x)$ — обычно "внутреннее" выражение составной функции.
2. **Вычислите** $du = g'(x)\, dx$ и, если необходимо, решите относительно $dx$.
3. **Перепишите** интеграл полностью в терминах $u$: подынтегральное выражение и $dx$ должны исчезнуть.
4. **Определённый интеграл:** замените также пределы интегрирования: $a \to g(a)$, $b \to g(b)$.
5. **Вычислите** интеграл по $u$ (должен быть проще исходного).
6. **Неопределённый интеграл:** вернитесь к $u = g(x)$ для выражения в терминах $x$.

</Definicao>

### Признак, что подстановка будет работать

Подынтегральное выражение должно содержать $f(\text{что-то})$, умноженное на **производную "что-то"** (или постоянное кратное этой производной).

Примеры паттерна:

| Подынтегральное выражение | $u$ | $du$ |
|---|---|---|
| $2x\, e^{x^2}$ | $x^2$ | $2x\, dx$ |
| $\cos x \cdot e^{\sin x}$ | $\sin x$ | $\cos x\, dx$ |
| $\frac{x}{x^2 + 1}$ | $x^2 + 1$ | $2x\, dx$ (требует корректировки $1/2$) |
| $x^2(x^3 + 1)^5$ | $x^3 + 1$ | $3x^2\, dx$ (корректировка $1/3$) |

<Insight>

**Корректировка постоянной:** если $g'(x)$ в подынтегральном выражении умножено на постоянную $k$, отличную от 1 (но не на точное значение $g'$), просто разделите и умножьте на $k$:

$$\int x\, e^{x^2}\, dx = \frac{1}{2}\int 2x\, e^{x^2}\, dx = \frac{1}{2} e^{x^2} + C.$$

Это работает с постоянными, но **не** с переменными или функциями $x$.

</Insight>

<Porta nivel="10" titulo="Для десятилетнего ребёнка">

Помните **цепное правило** при дифференцировании? $(\sin(x^2))' = \cos(x^2) \cdot 2x$.

Цепное правило "создаёт" произведение. Подстановка — это **путь назад**: когда вы видите $\cos(x^2) \cdot 2x$, вы узнаёте, что это "потомок" цепного правила, и возвращаетесь к $\sin(x^2)$.

**Как делать:** назовите "внутреннее дело" как $u$. Например, $u = x^2$. Тогда $du = 2x\, dx$. Интеграл $\int \cos(x^2) \cdot 2x\, dx$ становится $\int \cos u\, du = \sin u + C = \sin(x^2) + C$.

Подстановка работает, когда вы **видите паттерн**. Это приходит с практикой.

</Porta>

<Porta nivel="15" titulo="Для подростка 15 лет">

Подстановка — самый важный метод интегрирования. Каждый раз, когда цепное правило создавало произведение при дифференцировании, подстановка разбирает это произведение при интегрировании.

**Пошагово для $\int 2x(x^2+1)^3\, dx$:**

1. Выберите $u = x^2 + 1$ ("внутреннее дело" степени).
2. Вычислите: $du = 2x\, dx$ — именно то, что осталось!
3. Перепишите: $\int u^3\, du$.
4. Интегрируйте: $u^4/4 + C$.
5. Вернитесь: $\frac{(x^2+1)^4}{4} + C$.

**Проверка:** дифференцируйте результат по цепному правилу:
$\left(\frac{(x^2+1)^4}{4}\right)' = \frac{4(x^2+1)^3}{4} \cdot 2x = 2x(x^2+1)^3$. Сходится.

**Определённый интеграл с подстановкой:**

Кроме замены переменной, замените и пределы:

$$\int_0^1 2x(x^2+1)^3\, dx: \quad u(0) = 1, \quad u(1) = 2.$$

$$\int_1^2 u^3\, du = \left[\frac{u^4}{4}\right]_1^2 = 4 - \frac{1}{4} = \frac{15}{4}.$$

</Porta>

<Porta nivel="25" titulo="Для студента инженерного дела">

Подстановка — это обращение цепного правила. Формально говоря:

### Условия для определённого интеграла

Для версии с заменой пределов $g$ должна быть **непрерывна и дифференцируема** на $[a, b]$. Не требуется, чтобы $g$ была инъективна для неопределённого интеграла, но для определённого интеграла с заменой пределов, если $g$ не монотонна, может потребоваться разбить интервал в точках, где $g'$ меняет знак.

### Специальные подстановки

**Радикалы:** $\sqrt{ax + b}$ — возьмите $u = ax + b$.

**Тригонометрические функции:** $\int \tan x\, dx = \int \frac{\sin x}{\cos x}\, dx$. Возьмите $u = \cos x$, $du = -\sin x\, dx$:

$$\int \tan x\, dx = -\int \frac{du}{u} = -\ln|u| + C = -\ln|\cos x| + C = \ln|\sec x| + C.$$

**Составная экспоненциальная:** $\int e^{ax}\, dx = \frac{1}{a}e^{ax} + C$ (корректировка постоянной: $u = ax$, $du = a\, dx$).

> "Одна из ключей к тому, чтобы узнать, какую подстановку использовать, — определить «внутреннюю» функцию — ту, которая, если бы была дифференцирована, производила бы множительный фактор, присутствующий в подынтегральном выражении." — [APEX Calculus, §6.1](https://www.apexcalculus.com/)

### Когда подстановка не работает

Подстановка не работает, когда $g'(x)$ **не появляется** в подынтегральном выражении — или появляется, умноженная на функцию $x$, которая не является постоянной. Например, $\int x^2 e^{x^3 + x}\, dx$ не имеет простой подстановки, потому что производная $x^3 + x$ равна $3x^2 + 1$, не $x^2$.

Когда прямая подстановка не работает: попробуйте интегрирование по частям (Лекция 85).

### В производстве (SymPy)

```python
import sympy as sp
x = sp.Symbol('x')
print(sp.integrate(2*x * (x**2+1)**3, x))
# => (x**2 + 1)**4/4
```

### Замена переменной в анализе

Теорема замены переменной в $\mathbb{R}^n$ (для кратных интегралов) такова:

$$\int_{\phi(\Omega)} f(y)\, dy = \int_\Omega f(\phi(x)) |\det J_\phi(x)|\, dx,$$

где $J_\phi$ — якобиева матрица $\phi$. В 1D $|\det J_\phi| = |g'(x)|$, восстанавливая обычную подстановку. В 2D и 3D якобиан измеряет "искажение площади/объёма" замены координат — это основа интегралов в полярных, цилиндрических и сферических координатах.

### Подстановка в теории вероятностей

Если $X$ — случайная величина с плотностью $f_X$, и $Y = g(X)$ с $g$ монотонной и дифференцируемой, плотность $Y$ такова:

$$f_Y(y) = f_X(g^{-1}(y)) \cdot \left|\frac{d}{dy} g^{-1}(y)\right|.$$

Это точно теорема замены переменной, применённая к плотности. Фундаментально для моделирования методом Монте-Карло (метод обратного преобразования).

### Интегрирование подстановкой в ОДУ

Метод **разделения переменных** для $\frac{dy}{dx} = h(x)k(y)$ — это скрытая подстановка: $\int \frac{dy}{k(y)} = \int h(x)\, dx$. Техника сводит ОДУ к двум независимым антидифференцированиям.

### Тригонометрическая подстановка (предпросмотр Лекции 87)

Для подынтегральных выражений с $\sqrt{a^2 - x^2}$, $\sqrt{a^2 + x^2}$, $\sqrt{x^2 - a^2}$, используется тригонометрическая подстановка ($x = a\sin\theta$, $a\tan\theta$, $a\sec\theta$) для исключения радикалов через пифагоровы тождества. Обобщение того же принципа.

### Сложные проценты с переменными взносами

Скорость роста инвестиций с растущими взносами составляет $r(t) = 1000 e^{0{,}06t}$ реалов в месяц. Накопленная стоимость за 12 месяцев:

$$V = \int_0^{12} 1000 e^{0{,}06t}\, dt.$$

Подстановка: $u = 0{,}06t$, $du = 0{,}06\, dt$, тогда $dt = du/0{,}06$.

$$V = \frac{1000}{0{,}06}\int_0^{0{,}72} e^u\, du = \frac{1000}{0{,}06}[e^{0{,}72} - 1] \approx 16.667 \times 1{,}054 \approx \text{R\$ }17.567.$$

### Скорость с демпфированием

Автомобиль имеет ускорение $a(t) = 5e^{-0{,}2t}$ м/с². Скорость после 10 с (начиная с покоя):

$$v(10) = \int_0^{10} 5e^{-0{,}2t}\, dt.$$

$u = -0{,}2t$, $du = -0{,}2\, dt$:

$$= \frac{5}{-0{,}2}[e^{-0{,}2t}]_0^{10} = -25(e^{-2} - 1) = 25(1 - e^{-2}) \approx 25 \times 0{,}865 \approx 21{,}6\text{ м/с}.$$

### SymPy для проверки

```python
import sympy as sp
x = sp.Symbol('x')
# Подстановка: интеграл от x*sqrt(x^2 + 1)
print(sp.integrate(x * sp.sqrt(x**2 + 1), x))
# => (x**2 + 1)**(3/2)/3
```

## Решённые примеры

<Exemplo numero="1" titulo="Прямая подстановка с экспоненциальной (базовая)">

**Задача.** Вычислите $\displaystyle\int 3x^2 e^{x^3}\, dx$.

**Стратегия.** Подынтегральное выражение имеет форму $f(g(x)) \cdot g'(x)$ с $g(x) = x^3$ и $g'(x) = 3x^2$.

**Решение.**
$u = x^3$, $du = 3x^2\, dx$.

$$\int 3x^2 e^{x^3}\, dx = \int e^u\, du = e^u + C = e^{x^3} + C.$$

**Проверка.** $(e^{x^3})' = e^{x^3} \cdot 3x^2 = 3x^2 e^{x^3}$. Сходится.

**Источник.** [APEX Calculus, §6.1, Пример 6.1.2](https://www.apexcalculus.com/) — CC-BY-NC.

</Exemplo>

<Exemplo numero="2" titulo="Корректировка постоянной (базовая)">

**Задача.** Вычислите $\displaystyle\int x(x^2 + 5)^4\, dx$.

**Стратегия.** $g(x) = x^2 + 5$, $g'(x) = 2x$. Подынтегральное выражение имеет $x$ (половину $g'$), поэтому требуется корректировка на $1/2$.

**Решение.**
$u = x^2 + 5$, $du = 2x\, dx$, тогда $x\, dx = du/2$.

$$\int x(x^2+5)^4\, dx = \int u^4 \cdot \frac{du}{2} = \frac{1}{2} \cdot \frac{u^5}{5} + C = \frac{(x^2+5)^5}{10} + C.$$

**Проверка.** $\left(\frac{(x^2+5)^5}{10}\right)' = \frac{5(x^2+5)^4 \cdot 2x}{10} = x(x^2+5)^4$. Сходится.

**Источник.** [APEX Calculus, §6.1, Пример 6.1.4](https://www.apexcalculus.com/) — CC-BY-NC.

</Exemplo>

<Exemplo numero="3" titulo="Подстановка в определённом интеграле с заменой пределов (промежуточная)">

**Задача.** Вычислите $\displaystyle\int_0^1 2x(x^2 + 1)^3\, dx$.

**Стратегия.** $u = x^2 + 1$, $du = 2x\, dx$. Замените пределы: $u(0) = 1$, $u(1) = 2$.

**Решение.**
$$\int_0^1 2x(x^2+1)^3\, dx = \int_1^2 u^3\, du = \left[\frac{u^4}{4}\right]_1^2 = \frac{16}{4} - \frac{1}{4} = \frac{15}{4}.$$

**Проверка.** Без замены пределов: первообразная $(x^2+1)^4/4$. Оценить при $x=1$ и $x=0$: $2^4/4 - 1^4/4 = 4 - 1/4 = 15/4$. Сходится.

**Источник.** [OpenStax Calculus Vol. 1, §5.5, Пример 5.38](https://openstax.org/books/calculus-volume-1/pages/5-5-substitution) — CC-BY-NC-SA.

</Exemplo>

<Exemplo numero="4" titulo="Подстановка с тригонометрической функцией (промежуточная)">

**Задача.** Вычислите $\displaystyle\int \sin^3 x \cos x\, dx$.

**Стратегия.** $g(x) = \sin x$, $g'(x) = \cos x$ — появляется явно в подынтегральном выражении.

**Решение.**
$u = \sin x$, $du = \cos x\, dx$.

$$\int \sin^3 x \cos x\, dx = \int u^3\, du = \frac{u^4}{4} + C = \frac{\sin^4 x}{4} + C.$$

**Проверка.** $\left(\frac{\sin^4 x}{4}\right)' = \frac{4\sin^3 x \cos x}{4} = \sin^3 x \cos x$. Сходится.

**Источник.** [OpenStax Calculus Vol. 1, §5.5, Пример 5.36](https://openstax.org/books/calculus-volume-1/pages/5-5-substitution) — CC-BY-NC-SA.

</Exemplo>

<Exemplo numero="5" titulo="Интеграл от тангенса подстановкой (сложно)">

**Задача.** Вычислите $\displaystyle\int \tan x\, dx$.

**Стратегия.** Запишите $\tan x = \sin x / \cos x$, затем возьмите $u = \cos x$.

**Решение.**
$u = \cos x$, $du = -\sin x\, dx$, тогда $\sin x\, dx = -du$.

$$\int \frac{\sin x}{\cos x}\, dx = \int \frac{-du}{u} = -\ln|u| + C = -\ln|\cos x| + C = \ln|\sec x| + C.$$

**Проверка.** $(\ln|\sec x|)' = \frac{\sec x \tan x}{\sec x} = \tan x$. Сходится.

**Источник.** [APEX Calculus, §6.1, Пример 6.1.8](https://www.apexcalculus.com/) — CC-BY-NC.

</Exemplo>
