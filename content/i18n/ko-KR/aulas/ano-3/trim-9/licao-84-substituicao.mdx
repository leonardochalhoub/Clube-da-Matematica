### 변수 변환 정리

<Teorema titulo="치환 (변수 변환)">

$g: [a, b] \to \mathbb{R}$이 미분가능하고 $g'$이 연속이며, $f$가 $g$의 치역에서 연속이라고 하면:

$$\int_a^b f(g(x))\, g'(x)\, dx = \int_{g(a)}^{g(b)} f(u)\, du.$$

**부정적분 버전:** $F' = f$이면, $\int f(g(x))\, g'(x)\, dx = F(g(x)) + C$.

</Teorema>

> "치환 규칙은 적분에서 연쇄 법칙의 미분과 동등합니다." — [OpenStax Calculus Vol. 1, §5.5](https://openstax.org/books/calculus-volume-1/pages/5-5-substitution)

**증명.** $F' = f$이면 연쇄 법칙으로: $(F \circ g)' = f(g(x)) \cdot g'(x)$. 따라서 $F \circ g$는 $f(g(x)) g'(x)$의 부정적분입니다. 미적분학 기본정리 2에 의해:

$$\int_a^b f(g(x)) g'(x)\, dx = F(g(b)) - F(g(a)) = \int_{g(a)}^{g(b)} f(u)\, du. \quad \square$$

### 기계적 절차

<Definicao titulo="치환의 단계">

1. **확인**: $u = g(x)$ — 일반적으로 합성함수의 "내부" 식.
2. **계산**: $du = g'(x)\, dx$이고 필요하면 $dx$에 대해 풉니다.
3. **다시 쓰기**: 적분 전체를 $u$로 표현: 피적분함수와 $dx$가 모두 사라져야 합니다.
4. **정적분**: 적분 한계도 변환: $a \to g(a)$, $b \to g(b)$.
5. **계산**: $u$에 대한 적분 (원래보다 더 간단해야 함).
6. **부정적분**: $u = g(x)$로 돌아와서 $x$로 표현합니다.

</Definicao>

### 치환이 작동할 신호

피적분함수가 $f(\text{무언가})$를 포함하고 **"무언가"의 도함수** (또는 그 도함수의 상수배)가 곱해져 있어야 합니다.

패턴의 예:

| 피적분함수 | $u$ | $du$ |
|---|---|---|
| $2x\, e^{x^2}$ | $x^2$ | $2x\, dx$ |
| $\cos x \cdot e^{\sin x}$ | $\sin x$ | $\cos x\, dx$ |
| $\frac{x}{x^2 + 1}$ | $x^2 + 1$ | $2x\, dx$ (상수배 $1/2$ 필요) |
| $x^2(x^3 + 1)^5$ | $x^3 + 1$ | $3x^2\, dx$ (상수배 $1/3$ 필요) |

<Insight>

**상수 조정:** 만약 $g'(x)$가 피적분함수에서 상수배 $k$로 곱해져 있으면 (정확한 값이 아니어도), $k$로 나누고 곱하면 됩니다:

$$\int x\, e^{x^2}\, dx = \frac{1}{2}\int 2x\, e^{x^2}\, dx = \frac{1}{2} e^{x^2} + C.$$

이는 상수에만 작동하고 **변수나** $x$의 함수에는 작동하지 않습니다.

</Insight>

어려운 것들을 더해야 할 때가 있다고 상상해 보세요. 각 어려운 조각을 동전으로 바꿀 수 있다고 알아차렸습니다. 그리고 동전을 세는 것은 쉽습니다. 나중에 동전을 다시 필요한 것으로 바꿉니다.

치환은 바로 그것입니다: 어려운 형태를 쉬운 형태로 바꿔서 계산하고, 나중에 다시 변환합니다.

</Porta>

<Porta nivel="10" titulo="10살 아이를 위해">

**연쇄 법칙**을 미분에서 본 적 있나요? $(\sin(x^2))' = \cos(x^2) \cdot 2x$.

연쇄 법칙은 곱셈을 "만듭니다". 치환은 **거꾸로 가는 길**: $\cos(x^2) \cdot 2x$를 보면, 이것이 연쇄 법칙으로 만들어진 것임을 알아차리고 $\sin(x^2)$로 돌아갑니다.

**어떻게 하는가:** "안쪽 것"을 $u$라고 부릅니다. 예를 들어, $u = x^2$. 그러면 $du = 2x\, dx$입니다. 적분 $\int \cos(x^2) \cdot 2x\, dx$는 $\int \cos u\, du = \sin u + C = \sin(x^2) + C$가 됩니다.

치환은 **패턴을 볼** 때 작동합니다. 이는 연습으로 나옵니다.

</Porta>

<Porta nivel="15" titulo="15살 청소년을 위해">

치환은 적분의 가장 중요한 기법입니다. 연쇄 법칙이 미분할 때 곱셈을 만들었다면, 치환은 적분할 때 그 곱셈을 거슬러 올라갑니다.

**$\int 2x(x^2+1)^3\, dx$에 대한 단계별:**

1. $u = x^2 + 1$ 선택 (거듭제곱 안의 "것").
2. 계산: $du = 2x\, dx$ — 정확히 남은 것!
3. 다시 쓰기: $\int u^3\, du$.
4. 적분: $u^4/4 + C$.
5. 돌아가기: $\frac{(x^2+1)^4}{4} + C$.

**확인:** 연쇄 법칙으로 결과를 미분:
$\left(\frac{(x^2+1)^4}{4}\right)' = \frac{4(x^2+1)^3}{4} \cdot 2x = 2x(x^2+1)^3$. 맞습니다.

**정적분에서의 치환:**

변수를 치환할 뿐만 아니라 한계도 바꿉니다:

$$\int_0^1 2x(x^2+1)^3\, dx: \quad u(0) = 1, \quad u(1) = 2.$$

$$\int_1^2 u^3\, du = \left[\frac{u^4}{4}\right]_1^2 = 4 - \frac{1}{4} = \frac{15}{4}.$$

</Porta>

<Porta nivel="25" titulo="공학 학생을 위해">

치환은 연쇄 법칙의 역과정입니다. 형식적으로:

### 정적분에 대한 가정

한계 교환이 있는 버전에서, $g$는 $[a, b]$에서 **연속이고 미분가능**해야 합니다. 부정적분 버전에서 $g$가 일대일 대응일 필요는 없지만, 한계 교환이 있는 정적분 버전에서 $g$가 단조가 아니면, 구간을 $g'$의 부호가 바뀌는 점에서 나누어야 할 수 있습니다.

### 특별한 치환

**무리식:** $\sqrt{ax + b}$ — $u = ax + b$로 놓습니다.

**삼각함수:** $\int \tan x\, dx = \int \frac{\sin x}{\cos x}\, dx$. $u = \cos x$, $du = -\sin x\, dx$ 놓으면:

$$\int \tan x\, dx = -\int \frac{du}{u} = -\ln|u| + C = -\ln|\cos x| + C = \ln|\sec x| + C.$$

**지수 합성:** $\int e^{ax}\, dx = \frac{1}{a}e^{ax} + C$ (상수 조정: $u = ax$, $du = a\, dx$).

> "어떤 치환을 사용할지 알아내기 위한 핵심 중 하나는 '내부' 함수를 인식하는 것입니다 — 그것을 미분하면 피적분함수에 있는 곱셈 인수가 나올 함수." — [APEX Calculus, §6.1](https://www.apexcalculus.com/)

### 치환 실패

치환이 실패하는 경우는 $g'(x)$가 피적분함수에 **나타나지 않을** 때 — 또는 $x$의 비상수 함수로 곱해져 있을 때입니다. 예를 들어, $\int x^2 e^{x^3 + x}\, dx$는 간단한 치환이 없습니다. $x^3 + x$의 도함수는 $3x^2 + 1$이지 $x^2$가 아니기 때문입니다.

직접 치환이 실패하면: 부분적분을 시도해 봅시다 (단원 85).

### 프로덕션에서 (SymPy)

```python
import sympy as sp
x = sp.Symbol('x')
print(sp.integrate(2*x * (x**2+1)**3, x))
# => (x**2 + 1)**4/4
```

</Porta>

### 분석에서의 변수 변환

$\mathbb{R}^n$에서의 변수 변환 정리 (다중적분):

$$\int_{\phi(\Omega)} f(y)\, dy = \int_\Omega f(\phi(x)) |\det J_\phi(x)|\, dx,$$

여기서 $J_\phi$는 $\phi$의 야코비 행렬입니다. 1차원에서 $|\det J_\phi| = |g'(x)|$로 통상적인 치환을 회복합니다. 2차, 3차원에서 야코비안은 좌표 변환의 "면적/부피 왜곡"을 측정합니다 — 극좌표, 원통좌표, 구면좌표의 적분 기초입니다.

### 확률에서의 치환

만약 $X$가 밀도 $f_X$를 가진 확률변수이고, $Y = g(X)$에서 $g$가 단조이고 미분가능하면, $Y$의 밀도는:

$$f_Y(y) = f_X(g^{-1}(y)) \cdot \left|\frac{d}{dy} g^{-1}(y)\right|.$$

이는 정확히 밀도에 적용된 변수 변환 정리입니다. 몬테카를로 시뮬레이션 (역변환 방법)에 필수입니다.

### 미분방정식에서의 치환 적분

$\frac{dy}{dx} = h(x)k(y)$에 대한 **변수 분리** 방법은 숨겨진 치환입니다: $\int \frac{dy}{k(y)} = \int h(x)\, dx$. 기법은 미분방정식을 두 독립적인 부정적분으로 축소합니다.

### 삼각함수 치환 (단원 87 미리보기)

$\sqrt{a^2 - x^2}$, $\sqrt{a^2 + x^2}$, $\sqrt{x^2 - a^2}$를 포함하는 피적분함수에는 삼각함수 치환 ($x = a\sin\theta$, $a\tan\theta$, $a\sec\theta$)을 사용하여 피타고라스 항등식으로 무리식을 제거합니다. 같은 원리의 일반화입니다.

</Porta>

<Porta nivel="pratica" titulo="실제 응용 — 브라질 데이터">

### 변동 유입금이 있는 복리이자

투자 유입금 성장률이 $r(t) = 1000 e^{0{,}06t}$ 레알/월이면, 12개월 누적:

$$V = \int_0^{12} 1000 e^{0{,}06t}\, dt.$$

치환: $u = 0{,}06t$, $du = 0{,}06\, dt$이면 $dt = du/0{,}06$.

$$V = \frac{1000}{0{,}06}\int_0^{0{,}72} e^u\, du = \frac{1000}{0{,}06}[e^{0{,}72} - 1] \approx 16.667 \times 1{,}054 \approx \text{R\$ }17.567.$$

### 감쇠 속도

차량의 가속도가 $a(t) = 5e^{-0{,}2t}$ m/s²이면, 정지에서 출발한 10초 후 속도:

$$v(10) = \int_0^{10} 5e^{-0{,}2t}\, dt.$$

$u = -0{,}2t$, $du = -0{,}2\, dt$:

$$= \frac{5}{-0{,}2}[e^{-0{,}2t}]_0^{10} = -25(e^{-2} - 1) = 25(1 - e^{-2}) \approx 25 \times 0{,}865 \approx 21{,}6\text{ m/s}.$$

### 확인을 위한 SymPy

```python
import sympy as sp
x = sp.Symbol('x')
# 치환: x*sqrt(x^2 + 1)의 적분
print(sp.integrate(x * sp.sqrt(x**2 + 1), x))
# => (x**2 + 1)**(3/2)/3
```

## 풀이된 예제

<Exemplo numero="1" titulo="지수함수가 있는 직접 치환 (기초)">

**문제.** $\displaystyle\int 3x^2 e^{x^3}\, dx$를 계산하세요.

**전략.** 피적분함수는 $f(g(x)) \cdot g'(x)$ 꼴이고, $g(x) = x^3$, $g'(x) = 3x^2$.

**풀이.**
$u = x^3$, $du = 3x^2\, dx$.

$$\int 3x^2 e^{x^3}\, dx = \int e^u\, du = e^u + C = e^{x^3} + C.$$

**확인.** $(e^{x^3})' = e^{x^3} \cdot 3x^2 = 3x^2 e^{x^3}$. 맞습니다.

**출처.** [APEX Calculus, §6.1, 예제 6.1.2](https://www.apexcalculus.com/) — CC-BY-NC.

</Exemplo>

<Exemplo numero="2" titulo="상수 조정 (기초)">

**문제.** $\displaystyle\int x(x^2 + 5)^4\, dx$를 계산하세요.

**전략.** $g(x) = x^2 + 5$, $g'(x) = 2x$. 피적분함수에 $x$ ($g'$의 절반)이 있으므로, $1/2$로 조정 필요.

**풀이.**
$u = x^2 + 5$, $du = 2x\, dx$이므로 $x\, dx = du/2$.

$$\int x(x^2+5)^4\, dx = \int u^4 \cdot \frac{du}{2} = \frac{1}{2} \cdot \frac{u^5}{5} + C = \frac{(x^2+5)^5}{10} + C.$$

**확인.** $\left(\frac{(x^2+5)^5}{10}\right)' = \frac{5(x^2+5)^4 \cdot 2x}{10} = x(x^2+5)^4$. 맞습니다.

**출처.** [APEX Calculus, §6.1, 예제 6.1.4](https://www.apexcalculus.com/) — CC-BY-NC.

</Exemplo>

<Exemplo numero="3" titulo="정적분에서 한계 교환이 있는 치환 (중급)">

**문제.** $\displaystyle\int_0^1 2x(x^2 + 1)^3\, dx$를 계산하세요.

**전략.** $u = x^2 + 1$, $du = 2x\, dx$. 한계 교환: $u(0) = 1$, $u(1) = 2$.

**풀이.**
$$\int_0^1 2x(x^2+1)^3\, dx = \int_1^2 u^3\, du = \left[\frac{u^4}{4}\right]_1^2 = \frac{16}{4} - \frac{1}{4} = \frac{15}{4}.$$

**확인.** 한계 교환 없이: 부정적분 $(x^2+1)^4/4$. $x=1$과 $x=0$에서 평가: $2^4/4 - 1^4/4 = 4 - 1/4 = 15/4$. 맞습니다.

**출처.** [OpenStax Calculus Vol. 1, §5.5, 예제 5.38](https://openstax.org/books/calculus-volume-1/pages/5-5-substitution) — CC-BY-NC-SA.

</Exemplo>

<Exemplo numero="4" titulo="삼각함수가 있는 치환 (중급)">

**문제.** $\displaystyle\int \sin^3 x \cos x\, dx$를 계산하세요.

**전략.** $g(x) = \sin x$, $g'(x) = \cos x$ — 피적분함수에 명시적으로 나타남.

**풀이.**
$u = \sin x$, $du = \cos x\, dx$.

$$\int \sin^3 x \cos x\, dx = \int u^3\, du = \frac{u^4}{4} + C = \frac{\sin^4 x}{4} + C.$$

**확인.** $\left(\frac{\sin^4 x}{4}\right)' = \frac{4\sin^3 x \cos x}{4} = \sin^3 x \cos x$. 맞습니다.

**출처.** [OpenStax Calculus Vol. 1, §5.5, 예제 5.36](https://openstax.org/books/calculus-volume-1/pages/5-5-substitution) — CC-BY-NC-SA.

</Exemplo>

<Exemplo numero="5" titulo="치환으로 탄젠트 적분 (도전)">

**문제.** $\displaystyle\int \tan x\, dx$를 계산하세요.

**전략.** $\tan x = \sin x / \cos x$로 쓴 후, $u = \cos x$ 놓으세요.

**풀이.**
$u = \cos x$, $du = -\sin x\, dx$이므로 $\sin x\, dx = -du$.

$$\int \frac{\sin x}{\cos x}\, dx = \int \frac{-du}{u} = -\ln|u| + C = -\ln|\cos x| + C = \ln|\sec x| + C.$$

**확인.** $(\ln|\sec x|)' = \frac{\sec x \tan x}{\sec x} = \tan x$. 맞습니다.

**출처.** [APEX Calculus, §6.1, 예제 6.1.8](https://www.apexcalculus.com/) — CC-BY-NC.

</Exemplo>

  solucao={<>상수 조정의 일반적 경우를 확인하려고 합니다: <Eq>{`\\int f(u)\\, du = F(u) + C`}</Eq>이면, <Eq>{`\\int f(ax + b)\\, dx = \\frac{1}{a}F(ax+b) + C`}</Eq>. <Eq>{`u = ax + b`}</Eq>로 놓고, <Eq>{`du = a\\, dx`}</Eq>, 따라서 <Eq>{`dx = du/a`}</Eq>. 적분: <Eq>{`\\int f(u) \\cdot \\frac{du}{a} = \\frac{1}{a}F(u) + C = \\frac{1}{a}F(ax+b) + C`}</Eq>. 미분으로 확인: <Eq>{`\\frac{d}{dx}\\left[\\frac{1}{a}F(ax+b)\\right] = \\frac{1}{a} \\cdot F'(ax+b) \\cdot a = F'(ax+b) = f(ax+b)`}</Eq>.</>}
