### 기본 항등식

<Definicao titulo="삼각함수 적분에 사용되는 항등식">

다음 항등식들이 핵심 도구입니다:

- **피타고라스 항등식:** $\sin^2 x + \cos^2 x = 1$; $1 + \tan^2 x = \sec^2 x$; $1 + \cot^2 x = \csc^2 x$.
- **짝수 거듭제곱 (반각 공식):**

<Equation explicacao="sin²와 cos²를 이배각 함수로 축약합니다. — 짝수 지수에 필수적입니다." latex="\sin^2 x = \frac{1 - \cos 2x}{2}, \qquad \cos^2 x = \frac{1 + \cos 2x}{2}." />

- **곱을 합으로:** $\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$.

</Definicao>

### $\int \sin^n x \cos^m x\, dx$ 패턴

<Definicao titulo="지수의 홀짝성에 따른 전략">

| 상황 | 전략 |
|---|---|
| $n$ 홀수 | $\sin x\, dx$ 예약; $\sin^2 = 1 - \cos^2$로 $\sin^{n-1}$ 변환; $u = \cos x$ 치환 |
| $m$ 홀수 | $\cos x\, dx$ 예약; $\cos^2 = 1 - \sin^2$로 $\cos^{m-1}$ 변환; $u = \sin x$ 치환 |
| 모두 짝수 | 반각 공식 반복 사용 |

$\int \tan^n x \sec^m x\, dx$의 경우:

| 상황 | 전략 |
|---|---|
| $m$ 짝수 | $\sec^2 x\, dx$ 예약; $\sec^2 = 1 + \tan^2$로 변환; $u = \tan x$ 치환 |
| $n$ 홀수 | $\sec x \tan x\, dx$ 예약; $\tan^2 = \sec^2 - 1$로 변환; $u = \sec x$ 치환 |

</Definicao>

> "사인과 코사인의 거듭제곱의 곱을 적분하는 전략은 지수의 홀짝성에 따라 다릅니다. 지수 중 하나가 홀수일 때, 한 인수를 '떼어내고' 피타고라스 항등식을 사용하여 나머지 짝수 거듭제곱을 변환합니다." — [OpenStax Calculus Vol. 2, §3.2](https://openstax.org/books/calculus-volume-2/pages/3-2-trigonometric-integrals)

### 축약 공식

<Teorema titulo="sinⁿ에 대한 축약 공식">

$$\int \sin^n x\, dx = -\frac{\sin^{n-1}x \cos x}{n} + \frac{n-1}{n}\int \sin^{n-2}x\, dx.$$

유사한 공식이 $\cos^n$, $\tan^n$, $\sec^n$, $\csc^n$에 대해 존재합니다.

**증명:** $u = \sin^{n-1}x$, $dv = \sin x\, dx$를 사용한 부분 적분, 더하기 항등식 $\sin^2 = 1 - \cos^2$.

</Teorema>

<Insight>

**Weierstrass 치환** (범용): $t = \tan(x/2)$는 $\sin x$, $\cos x$의 임의의 유리함수 적분을 t의 유리함수 적분으로 변환합니다. 부분분수로 모든 것이 기본적입니다. — 하지만 결과는 복잡할 수 있습니다. 다른 전략이 실패할 때 사용하세요.

</Insight>

<Porta nivel="5" titulo="5살 아이를 위해">

유령 옷을 입어서 아무도 당신을 못 알아보게 한 다음 벗는 것처럼 생각해 보세요. 삼각함수 치환이 그렇게 작동합니다.

당신은 $\sqrt{1 - x^2}$를 가지고 있습니다. 열심히 다루기 어렵습니다. 당신은 $x$를 $\sin\theta$로 바꿉니다. — 변장합니다! 제곱근이 사라지고 $\cos\theta$가 됩니다. $\theta$로 계산한 후, 변장을 벗고 다시 $x$로 돌아갑니다.

</Porta>

<Porta nivel="10" titulo="10살 아이를 위해">

당신이 알고 있는 항등식이 하나 있습니다: $\sin^2\theta + \cos^2\theta = 1$.

이것은 $\sqrt{1 - \sin^2\theta} = \cos\theta$라는 뜻입니다 (만약 $\cos\theta \geq 0$이면).

그래서 만약 당신이 $\sqrt{1 - x^2}$를 가지고 있고 $x = \sin\theta$를 한다면, 제곱근이 사라지고 $\cos\theta$가 됩니다.

$\theta$로 적분한 후, 당신은 삼각형을 사용합니다: 만약 $\sin\theta = x$이고 빗변이 1이라면, 인접한 변은 $\sqrt{1 - x^2}$입니다. 이것이 당신에게 $\cos\theta$, $\tan\theta$, 등을 x의 항으로 줍니다. — 그리고 당신은 치환을 "취소"합니다.

</Porta>

<Porta nivel="15" titulo="15살 청소년을 위해">

### 사인과 코사인의 거듭제곱

**경우 1 (홀수 지수):** $\int \sin^3 x\, dx$.

한 개의 $\sin x\, dx$를 예약하고, 나머지를 변환합니다: $\sin^2 x = 1 - \cos^2 x$.

$\int (1 - \cos^2 x)\sin x\, dx$. 치환 $u = \cos x$: $-\int(1 - u^2)\, du = -u + u^3/3 + C = -\cos x + \cos^3 x/3 + C$.

**경우 2 (짝수 지수):** $\int \sin^2 x\, dx$.

반각 공식 사용: $\int \frac{1 - \cos 2x}{2}\, dx = \frac{x}{2} - \frac{\sin 2x}{4} + C$.

### 삼각함수 치환

**예:** $\int \sqrt{1 - x^2}\, dx$.

치환 $x = \sin\theta$, $dx = \cos\theta\, d\theta$, $\sqrt{1-x^2} = \cos\theta$.

적분은 $\int \cos^2\theta\, d\theta = \theta/2 + \sin(2\theta)/4 + C$가 됩니다.

돌아가기: $\theta = \arcsin x$, $\sin(2\theta) = 2\sin\theta\cos\theta = 2x\sqrt{1-x^2}$.

결과: $\dfrac{\arcsin x}{2} + \dfrac{x\sqrt{1-x^2}}{2} + C$.

**참조 삼각형:** 항상 그리세요. — 삼각함수 $\theta$를 x로 다시 변환하는 열쇠입니다.

</Porta>

<Porta nivel="25" titulo="공학 학생을 위해">

### 기본 적분의 정신적 표

- $\int \sin^2 x\, dx = (x - \sin x\cos x)/2 + C$.
- $\int \cos^2 x\, dx = (x + \sin x\cos x)/2 + C$.
- $\int \tan x\, dx = -\ln\lvert\cos x\rvert + C = \ln\lvert\sec x\rvert + C$.
- $\int \cot x\, dx = \ln\lvert\sin x\rvert + C$.
- $\int \sec x\, dx = \ln\lvert\sec x + \tan x\rvert + C$.
- $\int \csc x\, dx = -\ln\lvert\csc x + \cot x\rvert + C$.
- $\int \sec^2 x\, dx = \tan x + C$; $\int \csc^2 x\, dx = -\cot x + C$.
- $\int \sec x\tan x\, dx = \sec x + C$.

### 공학적 연결

- **정현파의 제곱평균제곱근:** $V_{rms} = V_0/\sqrt{2}$ — $\int_0^T \sin^2(\omega t)\, dt = T/2$를 통해.
- **코시 분포:** $\int_{-\infty}^\infty 1/(\pi(1+x^2))\, dx = 1$ — 치환 $x = \tan\theta$.
- **타원의 호의 길이:** $\int \sqrt{1 - k^2\sin^2\theta}\, d\theta$ — 타원 적분, 닫힌 형식 없음.
- **푸리에 계수:** $a_n = (1/\pi)\int_{-\pi}^\pi f(x)\cos(nx)\, dx$ — f가 삼각함수이면, 항등식으로 직접 계산.

### 오일러와 복소수 항등식

사인과 코사인의 거듭제곱은 오일러를 통해 계산할 수 있습니다: $\sin x = (e^{ix} - e^{-ix})/(2i)$, $\cos x = (e^{ix} + e^{-ix})/2$. 이항 전개 + 복소 지수 적분, 그 다음 실부/허부.

</Porta>

<Porta nivel="40" titulo="경력 전문가를 위해">

### Weierstrass 치환 (범용)

$t = \tan(x/2)$는 $\sin x$와 $\cos x$의 임의의 유리함수를 t의 유리함수로 변환합니다:

$$\sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2\,dt}{1+t^2}.$$

결과 적분은 부분분수로 해결합니다. 그러나 결과는 직접 방법보다 더 복잡할 수 있습니다. — 다른 전략이 실패하거나 CAS에서 사용할 때 사용합니다.

### 타원 적분

$\int \sqrt{1 - k^2\sin^2\theta}\, d\theta = E(k)$ 그리고 $\int d\theta/\sqrt{1 - k^2\sin^2\theta} = K(k)$ — Legendre의 타원 적분. $k \neq 0$에 대해 기본적이지 않습니다. 타원의 호의 길이, 정확한 진자, 중력에서 나타납니다.

### 푸리에 분석

일반화된 푸리에 급수의 계수 $a_n, b_n$은 삼각함수 적분을 통해 계산됩니다. f의 평활도가 $|a_n|$, $|b_n|$의 감소를 제어합니다. — 푸리에 분석은 삼각함수 적분을 근사 이론과 연결합니다.

### 미분 기하학

호의 길이 $L = \int \sqrt{1 + (f')^2}\, dx$는 $f' = \tan\theta$일 때 삼각함수 치환을 포함합니다. 곡률 $\kappa = |f''|/(1 + (f')^2)^{3/2}$는 자연 좌표에서 호의 길이를 계산할 때 적분된 상태로 나타납니다. 다변수의 삼각함수 치환: 구면 및 원통 좌표는 삼각함수 야코비안입니다.

</Porta>

<Porta nivel="pratica" titulo="실제 응용">

**삼각함수 적분 레시피:**

1. $\sin$과 $\cos$의 지수를 봅니다.
2. 홀수인 것이 있나요? 그 인수의 한 복사본을 그 $dx$로 예약하고, 나머지를 변환합니다.
3. 모두 짝수인가? $\sin^2 = (1 - \cos 2x)/2$와 $\cos^2 = (1 + \cos 2x)/2$를 사용합니다.
4. 근호 $\sqrt{a^2 \pm x^2}$ 또는 $\sqrt{x^2 - a^2}$? 표에서 삼각함수 치환을 적용합니다.
5. 삼각함수 치환 후, 참조 삼각형을 그려 x로 돌아갑니다.
6. 미분으로 확인합니다.

### 원의 넓이 — 표준 검증

$A = 4\int_0^r \sqrt{r^2 - x^2}\, dx$. 치환 $x = r\sin\theta$: 적분은 $4r^2\int_0^{\pi/2}\cos^2\theta\, d\theta = 4r^2\cdot\pi/4 = \pi r^2$가 됩니다.

### 정현파의 제곱평균제곱근 — 회로

한 주기에서 전압 $v(t) = V_0\sin(\omega t)$, $T = 2\pi/\omega$:

$$V_{rms} = \sqrt{\frac{1}{T}\int_0^T V_0^2\sin^2(\omega t)\, dt} = V_0\sqrt{\frac{1}{2}} = \frac{V_0}{\sqrt{2}} \approx 0{.}707\, V_0.$$

### 일반적인 실수

- 야코비안 $dx \to a\cos\theta\, d\theta$ (또는 $a\sec^2\theta\, d\theta$)를 빠뜨리기. — a 인수 누락을 야기합니다.
- 삼각형으로 $\theta$에서 x로 돌아가기를 잊기.
- $\sin^2 x$ (거듭제곱)와 $\sin(2x)$ (이배각)를 혼동하기.
- $x = a\sec\theta$에서 θ의 올바른 분지를 빠뜨리기.

</Porta>

## 풀이 예제

<Exemplo titulo="사인의 홀수 거듭제곱 (기본)" numero="1">

**문제.** $\int \sin^3 x\, dx$를 계산하세요.

**전략.** 홀수 지수: $\sin x\, dx$ 예약, $\sin^2 = 1 - \cos^2$ 변환, $u = \cos x$ 치환.

**풀이.**

$\int \sin^3 x\, dx = \int \sin^2 x \cdot \sin x\, dx = \int (1 - \cos^2 x)\sin x\, dx$.

치환 $u = \cos x$, $du = -\sin x\, dx$:

$-\int (1 - u^2)\, du = -u + u^3/3 + C = -\cos x + \frac{\cos^3 x}{3} + C$.

**검증.** 미분: $\sin x - \cos^2 x\sin x = \sin x(1 - \cos^2 x) = \sin^3 x$. 정답.

**출처.** [APEX Calculus §6.3, Example 6.3.1](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="짝수 지수 — 반각 공식 (기본)" numero="2">

**문제.** $\int \sin^2 x \cos^2 x\, dx$를 계산하세요.

**전략.** 모두 짝수: $\sin x\cos x = \sin(2x)/2$를 사용한 다음 반각.

**풀이.**

$\sin^2 x\cos^2 x = (\sin x\cos x)^2 = \frac{\sin^2(2x)}{4} = \frac{1}{4}\cdot\frac{1 - \cos 4x}{2} = \frac{1 - \cos 4x}{8}$.

$$\int \sin^2 x\cos^2 x\, dx = \frac{x}{8} - \frac{\sin 4x}{32} + C.$$

**검증.** 미분: $1/8 - \cos(4x)/8 = (1 - \cos 4x)/8 = \sin^2(2x)/4 = \sin^2 x\cos^2 x$. 정답.

**출처.** [OpenStax Calculus Vol. 2, §3.2, Example 3.12](https://openstax.org/books/calculus-volume-2/pages/3-2-trigonometric-integrals) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="√(a² − x²)에 대한 x = a sin θ 치환 (중간 수준)" numero="3">

**문제.** $\int \sqrt{4 - x^2}\, dx$를 계산하세요.

**전략.** 근호 $\sqrt{a^2 - x^2}$, $a = 2$: 치환 $x = 2\sin\theta$.

**풀이.**

$dx = 2\cos\theta\, d\theta$; $\sqrt{4 - x^2} = \sqrt{4 - 4\sin^2\theta} = 2\cos\theta$ ($\theta \in [-\pi/2, \pi/2]$).

$\int 2\cos\theta \cdot 2\cos\theta\, d\theta = 4\int\cos^2\theta\, d\theta = 4\cdot\frac{\theta + \sin\theta\cos\theta}{2} = 2\theta + 2\sin\theta\cos\theta + C$.

참조 삼각형 ($\sin\theta = x/2$, 빗변 2, 인접한 변 $\sqrt{4-x^2}$):

$\theta = \arcsin(x/2)$; $\cos\theta = \sqrt{4-x^2}/2$.

결과: $2\arcsin(x/2) + 2\cdot\frac{x}{2}\cdot\frac{\sqrt{4-x^2}}{2} + C = 2\arcsin(x/2) + \frac{x\sqrt{4-x^2}}{2} + C$.

**검증.** 미분 (연쇄법칙): $\frac{2}{\sqrt{4-x^2}} + \frac{\sqrt{4-x^2} - x^2/\sqrt{4-x^2}}{2} = \frac{2}{\sqrt{4-x^2}} + \frac{4 - 2x^2}{2\sqrt{4-x^2}} = \sqrt{4-x^2}$. 정답.

**출처.** [APEX Calculus §6.4, Example 6.4.2](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="√(a² + x²)에 대한 x = a tan θ 치환 (중간 수준)" numero="4">

**문제.** $\int \dfrac{1}{\sqrt{1 + x^2}}\, dx$를 계산하세요.

**전략.** 근호 $\sqrt{a^2 + x^2}$, $a = 1$: 치환 $x = \tan\theta$.

**풀이.**

$dx = \sec^2\theta\, d\theta$; $\sqrt{1+x^2} = \sec\theta$.

$\int \frac{\sec^2\theta}{\sec\theta}\, d\theta = \int \sec\theta\, d\theta = \ln\lvert\sec\theta + \tan\theta\rvert + C$.

삼각형 ($\tan\theta = x$, 빗변 $\sqrt{1+x^2}$): $\sec\theta = \sqrt{1+x^2}$, $\tan\theta = x$.

결과: $\ln\lvert x + \sqrt{1+x^2}\rvert + C$ (동치: $\text{arcsinh}(x) + C$).

**검증.** $\ln(x + \sqrt{1+x^2})$ 미분: $\frac{1 + x/\sqrt{1+x^2}}{x + \sqrt{1+x^2}} = \frac{(\sqrt{1+x^2}+x)/\sqrt{1+x^2}}{x+\sqrt{1+x^2}} = \frac{1}{\sqrt{1+x^2}}$. 정답.

**출처.** [OpenStax Calculus Vol. 2, §3.3, Example 3.15](https://openstax.org/books/calculus-volume-2/pages/3-3-trigonometric-substitution) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="축약 공식과 응용 (도전)" numero="5">

**문제.** 축약 공식 $\int \sin^n x\, dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n-1}{n}\int\sin^{n-2}x\, dx$를 유도하고, 이를 사용하여 $\int_0^{\pi/2}\sin^4 x\, dx$를 계산하세요.

**전략.** 부분 적분으로 유도; $n = 4$와 $n = 2$에 적용.

**풀이.**

**유도:** $u = \sin^{n-1}x$, $dv = \sin x\, dx$. $du = (n-1)\sin^{n-2}x\cos x\, dx$, $v = -\cos x$.

$\int\sin^n x\, dx = -\sin^{n-1}x\cos x + (n-1)\int\cos^2 x\sin^{n-2}x\, dx$.

$\cos^2 x = 1 - \sin^2 x$로 치환:

$(n-1)\int(1 - \sin^2 x)\sin^{n-2}x\, dx = (n-1)\int\sin^{n-2}x\, dx - (n-1)\int\sin^n x\, dx$.

정리: $n\int\sin^n x\, dx = -\sin^{n-1}x\cos x + (n-1)\int\sin^{n-2}x\, dx$. n으로 나눔.

**응용:** $n = 4$: $\int\sin^4 x\, dx = -\frac{\sin^3 x\cos x}{4} + \frac{3}{4}\int\sin^2 x\, dx$.

$\int\sin^2 x\, dx = x/2 - \sin(2x)/4$.

$[0, \pi/2]$에서 평가: $\int_0^{\pi/2}\sin^4 x\, dx = 0 + \frac{3}{4}\left[\frac{\pi}{4} - 0\right] = \frac{3\pi}{16}$.

**검증.** Wallis 공식: $\int_0^{\pi/2}\sin^4 x\, dx = \frac{3\cdot 1}{4\cdot 2}\cdot\frac{\pi}{2} = \frac{3\pi}{16}$. 확인.

**출처.** [APEX Calculus §6.3, Theorem 6.3.1](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>
