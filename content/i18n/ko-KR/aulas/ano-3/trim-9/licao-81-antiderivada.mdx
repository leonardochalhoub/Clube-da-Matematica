### 부정적분과 적분상수

<Definicao titulo="부정적분">

구간 $I$ 위에 정의된 함수 $f: I \to \mathbb{R}$에 대해, 함수 $F: I \to \mathbb{R}$이 **부정적분**(또는 원시함수)이라는 것은 $I$의 모든 $x$에 대해 $F'(x) = f(x)$를 만족할 때이다.

$f$의 **적분상수를 포함한 부정적분**은 모든 부정적분의 족이며 다음과 같이 쓴다:

$$\int f(x)\, dx = F(x) + C, \quad C \in \mathbb{R}$$

</Definicao>

> "만약 $F$가 구간 $I$에서 $f$의 부정적분이면, $I$에서 $f$의 가장 일반적인 부정적분은 $F(x) + C$이다. 여기서 $C$는 임의의 상수이다." — [OpenStax Calculus Vol. 1, §4.10](https://openstax.org/books/calculus-volume-1/pages/4-10-antiderivatives)

<Definicao titulo="왜 상수 C가 필요한가?">

만약 $F' = f$라면, $(F + C)' = F' + 0 = f$이다. 따라서 $F$를 수직으로 평행이동한 모든 함수도 부정적분이다. 모든 $C \in \mathbb{R}$에 대해 그렇다.

**결론(평균값 정리의 결과):** 구간 $I$에서 $F$와 $G$가 모두 $f$의 부정적분이면, $F - G$는 $I$ 위에서 상수이다. 따라서 부정적분은 **상수를 제외하고** 유일하다.

</Definicao>

### 부정적분의 선형성

<Teorema titulo="적분의 선형성">

구간 $I$에서 부정적분이 존재하는 함수 $f$, $g$에 대해, 스칼라 $\alpha, \beta \in \mathbb{R}$일 때:

$$\int (\alpha f(x) + \beta g(x))\, dx = \alpha \int f(x)\, dx + \beta \int g(x)\, dx$$

</Teorema>

> "합의 규칙과 적분의 상수배 규칙은 함수의 임의의 일차결합의 부정적분이 부정적분의 일차결합임을 보여준다." — [APEX Calculus, §5.1](https://www.apexcalculus.com/)

<Insight>

**곱은 배분되지 않는다:** 일반적으로 $\int f(x) g(x)\, dx \neq \left(\int f\right)\left(\int g\right)$이다. 곱을 적분하려면 부분적분(강의 85) 또는 치환(강의 84)을 사용한다.

</Insight>

</Porta>

<Porta nivel="5" titulo="5살 아이를 위해">

당신은 **더하기**도 알고 **빼기**도 알죠? 빼기는 더하기를 반대로 한다. 사탕 3개를 받고 나중에 3개를 잃으면 원래 상태로 돌아온다.

**미분**은 1분에 받는 사탕 개수를 세는 것처럼 생각해 보세요. **부정적분**은 반대 방향으로 간다. 내가 당신이 1분에 얼마나 받았는지 말해주면, 당신은 처음에 사탕이 몇 개였는지 알아낼 수 있다.

하지만 문제가 있다: 처음에 사탕이 0개였는지 100개였는지 나는 모른다. 그래서 "+ C"를 쓴다 — C가 그 비밀을 간직한다.

</Porta>

<Porta nivel="10" titulo="10살 아이를 위해">

자동차의 속도계는 매 순간의 **속도**를 알려준다. **부정적분**은 반대 방향으로 간다. 속도가 주어지면 **위치**를 찾는다.

자동차가 $v(t) = 2t$ m/s로 움직인다면, $t$초 후 어디에 있을까? $2t$의 부정적분은 $t^2$이다. 따라서 위치 = $t^2 + C$이다. $C$는 처음 위치인데 따로 알아야 한다.

**다항식 팁**: $\int x^n$은 $x^{n+1}/(n+1)$이 된다. 지수에 1을 더하고 새로운 지수로 나눈다.

예제: $\int x^2\, dx = x^3/3$. $\int x^5\, dx = x^6/6$. 항상 마지막에 $+ C$를 넣는다.

</Porta>

<Porta nivel="15" titulo="15살 십대를 위해">

부정적분은 "**미분을 되돌리기**"이다. $f(x) = 2x$라면, 미분이 $2x$인 함수는 무엇일까? 답: $F(x) = x^2$이다. 왜냐하면 $(x^2)' = 2x$이기 때문이다.

하지만 $F(x) = x^2 + 5$도 작동한다. 그리고 $x^2 - 17$도 마찬가지다. 더해진 상수가 뭐든 상관없다. 따라서 우리는 이렇게 쓴다:

$$\int 2x\, dx = x^2 + C$$

$C$는 **적분상수** — 우리가 "시작점"을 모른다는 것을 인정한다.

**표를 사용하는 방법:**

| 적분하려고 함 | 규칙 | 결과 |
|---|---|---|
| $x^3$ | 멱: 1을 더하고 나눔 | $x^4/4 + C$ |
| $\sin x$ | 표에서 직접 | $-\cos x + C$ |
| $e^x$ | 표에서 직접 | $e^x + C$ |
| $3x^2 - 4\sin x$ | 선형성 | $x^3 + 4\cos x + C$ |

**반드시 확인하기:** 결과를 미분하세요. $f(x)$가 나오면 맞다. 이 습관은 시험 전에 부호 오류를 찾는다.

<Insight>

미적분학의 기본정리(강의 83)는 부정적분이 넓이와 누적을 계산하는 열쇠임을 보여줄 것이다. 당신이 지금 부정적분을 배우는 이유는 기본정리가 사용할 도구이기 때문이다.

</Insight>

</Porta>

<Porta nivel="25" titulo="공학과 학생을 위해">

부정적분은 **연산적으로는** 미분의 반대이지만, **계산상으로는** 훨씬 더 어렵다. 부정적분이 초등함수가 아닌 초등함수들이 있다:

- $\int e^{-x^2}\, dx$ — 오차함수 erf, 확률론에서 필수이다.
- $\int \sin(x^2)\, dx$ — Fresnel 함수, 광학과 회절에서 나타난다.
- $\int \frac{\sin x}{x}\, dx$ — 사인 적분 $\text{Si}(x)$, 제어 이론에서 나타난다.

**Liouville (1835)**는 어떤 함수가 초등 부정적분을 갖는지 특성화했다. Risch (1969)는 이 결과를 결정 알고리즘으로 변환했다 — Mathematica와 SymPy에서 구현됨.

### 적분 전략의 순서

$\int f\, dx$를 만나면:

1. **표에서 직접 찾을 수 있나?** 망설이지 말고 사용하자.
2. **선형성이 있나?** 합과 스칼라로 나누자.
3. **치환** $u = g(x)$가 가능한가? 연쇄법칙의 역이다(강의 84).
4. **부분적분?** 곱의 규칙의 역이다(강의 85).
5. **부분분수**(강의 86)? 인수분해 가능한 분모가 있는 유리함수일 때.
6. **삼각함수 항등식**(강의 87)? 사인/코사인의 거듭제곱이 있으면.
7. **초등 부정적분이 없나?** Taylor 급수 또는 수치 적분을 사용하자.

### 초기조건이 C를 결정한다

실무에서(상미분방정식, 물리학, 금융) $C$는 초기조건으로 결정된다. $F'(t) = f(t)$이고 $F(0) = F_0$이면, $C = F_0 - F(0)\big|_{C=0}$이다. 초기조건이 없으면 $C$는 기호로 남는다.

> "부정적분을 찾는 문제는 미적분학의 기본정리의 우변을 계산하는 데뿐만 아니라 미분방정식을 푸는 데도 중요하다." — [APEX Calculus, §5.1](https://www.apexcalculus.com/)

</Porta>

<Porta nivel="40" titulo="고위 전문가를 위해">

부정적분의 구조는 대수적, 해석적 깊이가 상당하다.

### Liouville 정리와 Risch 알고리즘

**Liouville 정리**는 다음을 말한다: $f$가 초등함수이고 $\int f$도 초등함수라면, $\int f = v_0 + \sum c_i \ln v_i$이다. 여기서 $v_0, v_i$는 같은 함수 본체에서 초등함수이다. Risch (1969)는 이것을 **결정 알고리즘**으로 변환했다 — 주어진 초등함수에 대해, 알고리즘은 초등 부정적분이 존재하는지 결정하고, 존재하면 계산한다. Mathematica/Maple의 구현이 모든 현대 CAS의 엔진이다.

### Lebesgue 적분과 일반화

실해석의 맥락에서, $f \in L^1_{\text{loc}}(I)$(국소적분가능)에 대해, $F(x) = \int_a^x f(t)\, dt$는 **절대연속**이고 거의 모든 점에서 $F' = f$이다(Lebesgue). Henstock-Kurzweil 이론(게이지 적분)은 더 나아가 임의의 미분가능 함수의 도함수를 적분한다.

### 미분방정식과 신호에서의 역할

- **변수분리 미분방정식**: $dy/dx = g(x) h(y)$는 두 번의 부정적분으로 축소된다.
- **Laplace 변환**: $\mathcal{L}\{f\}(s) = \int_0^\infty e^{-st} f(t)\, dt$ — 시간 영역에서의 부정적분.
- **PID 제어**: 적분 부분 $I(t) = \int_0^t e(\tau)\, d\tau$는 정상 오차를 제거한다.
- **양자역학**: Feynman 경로 적분은 함수 공간의 무한 차원에서의 부정적분이다.

</Porta>

### 가속도에서의 차량 위치

차량이 $a(t) = 3\, \text{m/s}^2$로 균일하게 가속한다. 초기 속도: $v(0) = 0$. 초기 위치: $x(0) = 0$.

**속도:** $v(t) = \int a(t)\, dt = 3t + C_1$. $v(0) = 0$이므로: $C_1 = 0$, 따라서 $v(t) = 3t$.

**위치:** $x(t) = \int v(t)\, dt = \int 3t\, dt = \frac{3}{2}t^2 + C_2$. $x(0) = 0$이므로: $C_2 = 0$.

$t = 10\text{ s}$에서의 위치: $x(10) = \frac{3}{2} \cdot 100 = 150\text{ m}$.

### 투자 포트폴리오의 성장

투자 포트폴리오의 월별 성장률(R$ 단위, 브라질 헤알)이 $f(t) = 500 + 20t$(가속 성장)이라고 가정하자. 0개월에 R$ 10.000(십 수백 레알)에서 시작:

$$V(t) = \int (500 + 20t)\, dt = 500t + 10t^2 + C.$$

$V(0) = 10.000$일 때: $C = 10.000$. 12개월에: $V(12) = 500(12) + 10(144) + 10.000 = 6.000 + 1.440 + 10.000 = \text{R\$ }17.440$.

### SymPy 사용

```python
import sympy as sp
x = sp.symbols('x')

print(sp.integrate(f, x))
# => x**3 + 4*cos(x) + exp(x)
```

## 풀이 예제

<Exemplo numero="1" titulo="멱의 규칙과 선형성 (기본)">

**문제.** $\displaystyle\int (4x^3 - 6x + 5)\, dx$를 계산하시오.

**전략.** 선형성 적용: 각 단항식을 멱의 규칙 $\int x^n\, dx = x^{n+1}/(n+1) + C$로 따로따로 적분한다.

**풀이.**
$$\int (4x^3 - 6x + 5)\, dx = 4 \cdot \frac{x^4}{4} - 6 \cdot \frac{x^2}{2} + 5x + C = x^4 - 3x^2 + 5x + C.$$

**확인.** $(x^4 - 3x^2 + 5x + C)' = 4x^3 - 6x + 5$ . 맞다.

**출처.** [APEX Calculus, §5.1, 예제 5.1.3](https://www.apexcalculus.com/) — CC-BY-NC.

</Exemplo>

<Exemplo numero="2" titulo="삼각함수와 지수함수 (기본)">

**문제.** $\displaystyle\int (3\cos x - 2e^x + \sec^2 x)\, dx$를 계산하시오.

**전략.** 각 부분에 표를 직접 사용한다; 선형성은 우리가 부정적분들을 더할 수 있음을 보장한다.

**풀이.**
$$\int 3\cos x\, dx - 2\int e^x\, dx + \int \sec^2 x\, dx = 3\sin x - 2e^x + \tan x + C.$$

**확인.** $(3\sin x - 2e^x + \tan x + C)' = 3\cos x - 2e^x + \sec^2 x$ . 맞다.

**출처.** [OpenStax Calculus Vol. 1, §4.10, 예제 4.55](https://openstax.org/books/calculus-volume-1/pages/4-10-antiderivatives) — CC-BY-NC-SA.

</Exemplo>

<Exemplo numero="3" titulo="초기조건이 C를 결정한다 (중급)">

**문제.** $F'(x) = x^2 - 4x + 1$이고 $F(2) = -3$일 때 $F(x)$를 구하시오.

**전략.** 일반 족을 얻기 위해 적분한 다음, 조건 $F(2) = -3$을 사용하여 $C$를 결정한다.

**풀이.**
$$F(x) = \int (x^2 - 4x + 1)\, dx = \frac{x^3}{3} - 2x^2 + x + C.$$

초기조건: $F(2) = \frac{8}{3} - 8 + 2 + C = -3$, 따라서 $C = -3 - \frac{8}{3} + 6 = 3 - \frac{8}{3} = \frac{1}{3}$.

$$F(x) = \frac{x^3}{3} - 2x^2 + x + \frac{1}{3}.$$

**확인.** $F'(x) = x^2 - 4x + 1$이고 $F(2) = \frac{8}{3} - 8 + 2 + \frac{1}{3} = 3 - 8 + 2 = -3$. 맞다.

**출처.** [OpenStax Calculus Vol. 1, §4.10, 연습 4.284](https://openstax.org/books/calculus-volume-1/pages/4-10-antiderivatives) — CC-BY-NC-SA.

</Exemplo>

<Exemplo numero="4" titulo="적분 전에 대수적 확장 (중급)">

**문제.** $\displaystyle\int x(3x - 1)^2\, dx$를 계산하시오.

**전략.** 멱의 규칙을 적용하기 전에 제곱을 전개하고 분배한다. (치환도 가능하지만 전개가 더 직접적이다.)

**풀이.**
$(3x-1)^2 = 9x^2 - 6x + 1$이므로, $x(3x-1)^2 = 9x^3 - 6x^2 + x$.

$$\int (9x^3 - 6x^2 + x)\, dx = \frac{9x^4}{4} - 2x^3 + \frac{x^2}{2} + C.$$

**확인.** 미분: $9x^3 - 6x^2 + x = x(9x^2 - 6x + 1) = x(3x-1)^2$. 맞다.

**출처.** [APEX Calculus, §5.1, 연습 5.1.15](https://www.apexcalculus.com/) — CC-BY-NC.

</Exemplo>

<Exemplo numero="5" titulo="적분 전에 분수 재작성 (도전)">

**문제.** $\displaystyle\int \frac{x^3 + 2x}{x}\, dx$ (단, $x > 0$)를 계산하시오.

**전략.** 적분 전에 분자를 항별로 분모로 나누어 분수를 간단히 한다. $1/x$의 적분은 표에서 $\ln|x|$ 항목을 사용한다.

**풀이.**

$$\frac{x^3 + 2x}{x} = x^2 + 2, \quad x > 0.$$

$$\int (x^2 + 2)\, dx = \frac{x^3}{3} + 2x + C.$$

**확인.** $\left(\frac{x^3}{3} + 2x\right)' = x^2 + 2 = \frac{x^3 + 2x}{x}$ (단, $x \neq 0$). 맞다.

**출처.** [Active Calculus, §4.1, 미리보기 활동 4.1](https://activecalculus.org/single/sec-4-1-velocity-distance.html) — CC-BY-NC-SA.

</Exemplo>
