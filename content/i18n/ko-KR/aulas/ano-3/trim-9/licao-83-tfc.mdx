### TFC — 첫 번째 부분: 적분을 미분하기

<Teorema titulo="TFC 첫 번째 부분 (적분함수의 도함수)">

$f: [a, b] \to \mathbb{R}$이 **연속**이라고 하자. **적분함수**를 다음과 같이 정의합니다:

$$G(x) = \int_a^x f(t)\, dt, \quad x \in [a, b].$$

그러면 $G$는 $(a, b)$에서 미분가능하고 $G'(x) = f(x)$입니다.

</Teorema>

> "기본정리의 첫 번째 부분은 적분의 극한상한이 변할 때 그 적분으로 정의된 함수의 도함수가 극한상한에서 계산한 피적분함수와 같다는 것을 말합니다." — [OpenStax Calculus Vol. 1, §5.3](https://openstax.org/books/calculus-volume-1/pages/5-3-the-fundamental-theorem-of-calculus)

**TFC1의 증명.** 도함수의 정의에 의해:

$$G'(x) = \lim_{h \to 0} \frac{G(x+h) - G(x)}{h} = \lim_{h \to 0} \frac{1}{h} \int_x^{x+h} f(t)\, dt.$$

적분에 대한 평균값 정리에 의해, $x$와 $x+h$ 사이의 어떤 $c_h$가 존재하여 $\int_x^{x+h} f(t)\, dt = f(c_h) \cdot h$입니다. 따라서:

$$G'(x) = \lim_{h \to 0} f(c_h).$$

$h \to 0$일 때 $c_h \to x$이고 $f$가 연속이므로, $f(c_h) \to f(x)$입니다. 따라서 $G'(x) = f(x)$입니다. $\square$

### TFC — 두 번째 부분: 적분 계산

<Teorema titulo="TFC 두 번째 부분 (계산 공식)">

$f: [a, b] \to \mathbb{R}$이 **연속**이고 $F$가 $f$의 어떤 부정적분이라고 하자. 그러면:

$$\int_a^b f(x)\, dx = F(b) - F(a).$$

표기법: $F(x)\big|_a^b := F(b) - F(a)$.

</Teorema>

**TFC2의 증명.** TFC1에 의해, $G(x) = \int_a^x f(t)\, dt$는 $G' = f$를 만족합니다. $F' = f$도 성립하므로, $F - G$는 $(a, b)$에서 도함수가 0이므로, 어떤 상수 $C$에 대해 $F(x) = G(x) + C$입니다. 그러면:

$$F(b) - F(a) = [G(b) + C] - [G(a) + C] = G(b) - G(a) = \int_a^b f - 0 = \int_a^b f. \quad \square$$

### 라이프니츠 규칙 (변수 극한)

<Definicao titulo="적분 기호 아래에서의 미분">

$f$가 연속이고 $u(x)$, $v(x)$가 미분가능하면:

$$\frac{d}{dx} \int_{u(x)}^{v(x)} f(t)\, dt = f(v(x))\, v'(x) - f(u(x))\, u'(x).$$

(연쇄법칙을 적용한 TFC1의 결과.)

</Definicao>

<Insight>

**왜 TFC를 "기본"정리라고 할까요?** TFC 이전에는 $\int_a^b f$를 계산하기 위해 리만 합의 극한으로 진행해야 했으므로, 상수가 아닌 함수의 경우 매우 번거로웠습니다. TFC 이후에는 문제가 다음과 같이 단순화되었습니다: **부정적분을 찾은 후 두 끝점에서의 값을 계산하기**. 이것은 미적분학을 분석의 도구에서 공학의 도구로 변환했습니다.

</Insight>

</Porta>

<Porta nivel="5" titulo="5살 어린이를 위해">

계단을 상상해 보세요. 각 계단마다 높이가 있습니다. 전체적으로 **얼마나 올라갔는지** 알고 싶습니다. 각 계단을 측정할 필요는 없습니다 — 단지 **지금 어디에 있는지**와 어디서 시작했는지 확인하고 차를 구하면 됩니다.

기본정리는 이렇게 말합니다: 누적된 전체를 계산하려면 **어디에 도착했는지**와 **어디서 출발했는지**만 알면 됩니다.

</Porta>

<Porta nivel="10" titulo="10살 어린이를 위해">

적분은 조각들을 합해서 넓이를 계산합니다. 미분은 변화의 속도를 측정합니다. 매우 다른 일처럼 보입니다!

기본정리는 이들이 **역함수 관계**라는 것을 보여줍니다. 더하기와 빼기처럼요.

**마법의 공식:** $\int_a^b f$를 계산하려면, 도함수가 $f$인 함수 $F$를 찾으세요. 그러면 적분은 단지 $F(b) - F(a)$입니다.

예: $\int_0^3 x^2\, dx$. $(x^3/3)' = x^2$이므로, 적분은 $3^3/3 - 0 = 9$입니다.

기본정리 없이: 무한히 많은 직사각형을 더해야 합니다. 기본정리로: 세 번의 간단한 계산. 이것이 미적분학에서 가장 중요한 정리인 이유입니다.

</Porta>

<Porta nivel="15" titulo="15살 청소년을 위해">

기본정리는 **두 부분**으로 이루어져 있습니다:

**첫 번째 부분 (TFC1):** 함수를 적분한 다음 결과를 미분하면 원래 함수로 돌아갑니다. 수학적으로: $\frac{d}{dx}\int_a^x f(t)\, dt = f(x)$.

**두 번째 부분 (TFC2):** $\int_a^b f$를 계산하려면, 부정적분 $F$를 찾아서 $F(b) - F(a)$를 계산하면 됩니다.

**실제로 TFC2를 적용하는 방법:**

1. 피적분함수 $f(x)$를 파악합니다.
2. $F'(x) = f(x)$인 $F$를 찾습니다 (부정적분 표를 사용하세요).
3. $F(b) - F(a)$를 계산합니다.

**완전한 예:**

$\int_1^4 (3x^2 + 2x)\, dx$.
- $F(x) = x^3 + x^2$.
- $F(4) - F(1) = (64 + 16) - (1 + 1) = 80 - 2 = 78$.

**확인:** $F(x) = x^3 + x^2$를 미분합니다. $3x^2 + 2x$를 얻습니다. 맞습니다.

</Porta>

<Porta nivel="25" titulo="공학 학생을 위해">

기본정리는 미적분학의 두 부분을 연결하는 접착제입니다. 실용적으로:

### TFC1 — 변수 극한을 가진 적분 미분

상미분방정식과 적분방정식에서 자주 나타나는 상황:

$$\frac{d}{dx}\int_0^{x^2} \sin(t)\, dt = \sin(x^2) \cdot 2x.$$

일반 규칙 (라이프니츠): 극한상한이 $v(x)$이고 극한하한이 $u(x)$이면:

$$\frac{d}{dx}\int_{u(x)}^{v(x)} f(t)\, dt = f(v(x)) v'(x) - f(u(x)) u'(x).$$

> "기본정리의 첫 번째 부분은 적분을 미분할 수 있게 해주는 정리로, 물리에서 한 양이 다른 양의 적분으로 정의될 때 기본입니다." — [APEX Calculus, §5.4](https://www.apexcalculus.com/)

### TFC2 — 대수학으로 축약

TFC2는 $\int_a^b f$의 계산을 $F' = f$를 만족하는 $F$를 찾는 대수 문제로 축약합니다. 적분 기법의 전체 목록 (치환, 부분적분, 부분분수)은 **오직** 이 대수 문제를 풀기 위해 존재합니다.

### 오류 분석

가장 흔한 실수는 차의 순서를 잊는 것입니다: $F(b) - F(a)$이지 $F(a) - F(b)$가 아닙니다. 계산 중에 항상 $\big|_a^b$를 명시적으로 쓰세요.

### TFC 수치해석에서

$f$가 초등함수의 부정적분을 갖지 않을 때 (예: $e^{-x^2}$), 수치 방법을 사용합니다:
- **심프슨 방법**: 정확도 $O(\Delta x^4)$로, 매끄러운 함수에 적합합니다.
- **가우스-크론로드 구적법**: 적응형이며, `scipy.integrate.quad`의 표준입니다.
- **몬테카를로**: 다른 방법이 척도가 나빠지는 고차원에서 실행가능합니다.

</Porta>

### 역사적 맥락에서의 TFC

뉴턴은 1666년경 "유율법" 맥락에서 기본정리를 발전시켰습니다 (도함수는 "유율"이고 적분은 "유동"이었습니다). 라이프니츠는 1675년-1676년경에 독립적으로 발전시켰으며, $\int$와 $dx$ 표기법은 오늘날까지 지속됩니다.

유명한 우선순위 분쟁 (18세기)은 민족주의에 크게 영향을 받았습니다 — 런던 왕립학회는 라이프니츠를 표절로 고발했으며, 재판부는 뉴턴이 주재했습니다. 현대 역사학은 독립적인 병렬 발전을 인정합니다.

### 르베스그 미적분학에서의 TFC

르베스그 이론에서는, 기본정리가 더 세심한 가정을 요구합니다:

- **TFC1 (르베스그):** $f \in L^1([a,b])$이면, $G(x) = \int_a^x f$는 절대연속이고 $G' = f$ a.e.입니다.
- **TFC2 (르베스그):** $F$가 절대연속이고 $F' = f$ a.e.이고 $\int_a^b f = F(b) - F(a)$이면, 이것이 성립합니다.

병적 예시: **칸토르 함수** (악마의 계단)는 연속이고 a.e.에서 도함수가 0이지만, $F(1) - F(0) = 1 \neq 0 = \int_0^1 F'$입니다. 이는 칸토르 함수가 절대연속이 아니기 때문으로, 르베스그 기본정리의 가정을 위반합니다.

### 양적 금융에서의 TFC

블랙-숄즈 공식의 유도에서는 이토 보조정리를 사용합니다 — 기본정리의 확률론적 버전입니다. 형식적으로: $dF(W_t) = F'(W_t)\, dW_t + \frac{1}{2}F''(W_t)\, dt$인데, $W_t$는 브라운 운동입니다. 추가 항 $\frac{1}{2}F''$는 브라운 운동의 이차변동의 "2계 수정" — 확률론적 공간의 기본정리와 유사합니다.

</Porta>

<Porta nivel="pratica" titulo="실제 적용 — 브라질 데이터">

### 차량 연료 소비

트럭 차량은 소비율 $c(t) = 200 + 30t$ 리터/시간 (짐 축적으로 인한 선형 증가)입니다. 처음 8시간의 총 소비:

$$C = \int_0^8 (200 + 30t)\, dt = \left[200t + 15t^2\right]_0^8 = 1600 + 960 = 2560\text{ 리터.}$$

R\$ 6.50/리터로: 총 연료 비용 = R\$ 16.640.

### 변수 극한을 가진 적분의 도함수

환경에 축적된 CO2의 양은 $A(x) = \int_0^x e^{-t/10}\, dt$입니다. 시간 $x$에서의 축적 속도는, 기본정리 첫 번째 부분으로:

$$A'(x) = e^{-x/10}.$$

적분을 계산할 필요가 없습니다 — 기본정리 첫 번째 부분이 직접 도함수를 제공합니다.

### 계산 검증

```python
import sympy as sp
x = sp.Symbol('x')
F = sp.integrate(x**2 + 3*x, x)        # 부정적분
result = F.subs(x, 4) - F.subs(x, 1)  # TFC2
print(result)  # => 33
```

## 풀이된 예제

<Exemplo numero="1" titulo="다항식에 적용된 TFC2 (기초)">

**문제.** $\displaystyle\int_1^3 (x^2 + 2x - 1)\, dx$를 계산합니다.

**전략.** TFC2로 부정적분을 찾습니다: $F'(x) = x^2 + 2x - 1$인 $F(x)$를 찾습니다. 그 다음 $F(3) - F(1)$을 계산합니다.

**풀이.**
$$F(x) = \frac{x^3}{3} + x^2 - x.$$

$$\int_1^3 (x^2 + 2x - 1)\, dx = F(3) - F(1) = \left(9 + 9 - 3\right) - \left(\frac{1}{3} + 1 - 1\right) = 15 - \frac{1}{3} = \frac{44}{3}.$$

**검증.** $F'(x) = x^2 + 2x - 1$. 맞습니다.

**출처.** [APEX Calculus, §5.4, 예제 5.4.2](https://www.apexcalculus.com/) — CC-BY-NC.

</Exemplo>

<Exemplo numero="2" titulo="삼각함수를 가진 TFC2 (기초)">

**문제.** $\displaystyle\int_0^{\pi/2} (\cos x + 2\sin x)\, dx$를 계산합니다.

**전략.** 표에서 $\cos x$와 $\sin x$의 부정적분을 찾고; 끝점에서 평가합니다.

**풀이.**
$$F(x) = \sin x - 2\cos x.$$

$$\int_0^{\pi/2} (\cos x + 2\sin x)\, dx = F(\pi/2) - F(0) = (1 - 0) - (0 - 2) = 1 + 2 = 3.$$

**검증.** $F'(x) = \cos x + 2\sin x$. 맞습니다.

**출처.** [OpenStax Calculus Vol. 1, §5.3, 예제 5.22](https://openstax.org/books/calculus-volume-1/pages/5-3-the-fundamental-theorem-of-calculus) — CC-BY-NC-SA.

</Exemplo>

<Exemplo numero="3" titulo="적분을 미분하기 위한 TFC1 (중급)">

**문제.** $\displaystyle\frac{d}{dx}\int_1^{x^3} \cos(t^2)\, dt$를 계산합니다.

**전략.** 기본정리 첫 번째 부분과 연쇄법칙을 결합합니다: 극한상한은 $v(x) = x^3$입니다.

**풀이.**
$$\frac{d}{dx}\int_1^{x^3} \cos(t^2)\, dt = \cos((x^3)^2) \cdot (x^3)' = \cos(x^6) \cdot 3x^2.$$

**검증.** 라이프니츠 일반 규칙: $\frac{d}{dx}\int_a^{v(x)} f(t)\, dt = f(v(x)) \cdot v'(x)$. $f(t) = \cos(t^2)$, $v(x) = x^3$을 적용하면: $\cos(x^6) \cdot 3x^2$. 맞습니다.

**출처.** [APEX Calculus, §5.4, 예제 5.4.5](https://www.apexcalculus.com/) — CC-BY-NC.

</Exemplo>

<Exemplo numero="4" titulo="두 극한이 모두 변할 때 라이프니츠 규칙 (중급)">

**문제.** $x > 0$일 때 $\displaystyle\frac{d}{dx}\int_x^{x^2} \frac{1}{t}\, dt$를 계산합니다.

**전략.** 일반 라이프니츠 규칙: $f(v(x))v'(x) - f(u(x))u'(x)$이고, $v(x) = x^2$, $u(x) = x$, $f(t) = 1/t$입니다.

**풀이.**
$$\frac{d}{dx}\int_x^{x^2} \frac{1}{t}\, dt = \frac{1}{x^2} \cdot 2x - \frac{1}{x} \cdot 1 = \frac{2}{x} - \frac{1}{x} = \frac{1}{x}.$$

**검증.** 다른 방법: $\int_x^{x^2} \frac{1}{t}\, dt = \ln(x^2) - \ln x = 2\ln x - \ln x = \ln x$. 미분하면: $(\ln x)' = 1/x$. 맞습니다.

**출처.** [OpenStax Calculus Vol. 1, §5.3, 연습 5.132](https://openstax.org/books/calculus-volume-1/pages/5-3-the-fundamental-theorem-of-calculus) — CC-BY-NC-SA.

</Exemplo>

<Exemplo numero="5" titulo="부호 변화가 있는 곡선과 축 사이의 넓이 (도전)">

**문제.** $y = x^2 - 4$와 $x$축 사이의 전체 기하학적 넓이를 $[-3, 3]$에서 계산합니다.

**전략.** 함수 $f(x) = x^2 - 4$는 $(-2, 2)$에서 음수이고 밖에서 양수입니다. 구간을 영점에서 나누어 올바른 부호로 넓이를 합합니다.

**풀이.**
영점: $x^2 = 4 \Rightarrow x = \pm 2$.

$[-3, -2]$와 $[2, 3]$에서: $f \geq 0$. $[-2, 2]$에서: $f \leq 0$.

$$A = \int_{-3}^{-2}(x^2-4)\, dx + \left|\int_{-2}^{2}(x^2-4)\, dx\right| + \int_2^3(x^2-4)\, dx.$$

$F(x) = x^3/3 - 4x$.

- $F(-2) - F(-3) = (-8/3 + 8) - (-9 + 12) = 16/3 - 3 = 7/3$.
- $F(2) - F(-2) = (8/3 - 8) - (-8/3 + 8) = -32/3$. 절대값: $32/3$.
- $F(3) - F(2) = (9 - 12) - (8/3 - 8) = -3 + 16/3 = 7/3$.

전체 넓이: $7/3 + 32/3 + 7/3 = 46/3$.

**검증.** 적분 $\int_{-3}^3 (x^2 - 4)\, dx = F(3) - F(-3) = (9-12) - (-9+12) = -3 - 3 = -6 \neq 46/3$. 정적분은 $f$가 부호를 바꿀 때 기하학적 넓이와 다릅니다.

**출처.** [Active Calculus, §4.4, 연습 4.4.5](https://activecalculus.org/single/sec-4-4-FTC.html) — CC-BY-NC-SA.

</Exemplo>

<Exercicio
  numero="83.30"
  dificuldade="demonstracao"
  solucao={<>TFC2를 증명하려고 합니다: $F' = f$이고 $f$가 $[a,b]$에서 연속이면, $\int_a^b f = F(b) - F(a)$입니다. TFC1에 의해, $G(x) = \int_a^x f(t)\, dt$는 $G' = f = F'$를 만족합니다. 따라서 $(F - G)' = 0$은 $(a,b)$에서 성립합니다. 평균값 정리의 결과에 의해, $F(x) - G(x) = C$ (상수). $G(a) = 0$이므로, $F(a) - G(a) = C \Rightarrow C = F(a)$입니다. 따라서 $G(x) = F(x) - F(a)$입니다. $x = b$에서: $G(b) = \int_a^b f = F(b) - F(a)$입니다.</>}
  fonte={{ livro: "Active Calculus", url: "https://activecalculus.org/single/sec-4-4-FTC.html", secao: "§4.4", licenca: "CC-BY-NC-SA" }}
>
TFC1로부터 TFC2를 증명합니다: 만약 $F' = f$이고 $f$가 $[a,b]$에서 연속이면, $\int_a^b f(x)\, dx = F(b) - F(a)$입니다.
</Exercicio>
