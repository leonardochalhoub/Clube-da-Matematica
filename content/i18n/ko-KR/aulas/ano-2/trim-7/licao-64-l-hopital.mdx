<Porta nivel="formal" titulo="형식적 선언, 증명, 확장">

### 형식적 선언

<Teorema titulo="로피탈의 정리 (0/0 및 ∞/∞ 형태)">

<Eq>{`f`}</Eq>와 <Eq>{`g`}</Eq>가 <Eq>{`a`}</Eq>의 열린 근방에서 미분가능하고 (<Eq>{`a`}</Eq>에서는 제외 가능), <Eq>{`g'(x) \\neq 0`}</Eq>이라고 하자.

<Eq>{`\\lim_{x \\to a} f(x) = \\lim_{x \\to a} g(x) = 0`}</Eq> (형태 <Eq>{`0/0`}</Eq>)이거나 <Eq>{`\\lim_{x \\to a} |f(x)| = \\lim_{x \\to a} |g(x)| = \\infty`}</Eq> (형태 <Eq>{`\\infty/\\infty`}</Eq>)이면:

<Eq display>{`\\lim_{x \\to a} \\frac{f(x)}{g(x)} = \\lim_{x \\to a} \\frac{f'(x)}{g'(x)}`}</Eq>

우변의 극한이 존재하거나 <Eq>{`\\pm\\infty`}</Eq>일 때 성립한다.

**적용성:** 정리는 <Eq>{`x \\to a^+`}</Eq>, <Eq>{`x \\to a^-`}</Eq>, <Eq>{`x \\to +\\infty`}</Eq>, <Eq>{`x \\to -\\infty`}</Eq>에도 적용된다.

</Teorema>

> "로피탈의 정리는 분자와 분모가 모두 0 또는 ∞로 접근할 때 분수 극한의 계산을 단순화한다. 핵심은 부정형을 인식하고, 정리를 적용한 후, 결과 극한이 실제로 존재하는지 확인하는 것이다." — [OpenStax Calculus Vol. 1, §4.8](https://openstax.org/books/calculus-volume-1/pages/4-8-lhopitals-rule)

### 증명의 핵심 아이디어 (경우 0/0)

**Cauchy 평균값 정리**에 의해: <Eq>{`f(a) = g(a) = 0`}</Eq>이면, <Eq>{`a`}</Eq> 근처의 <Eq>{`x`}</Eq>에 대해 <Eq>{`a`}</Eq>와 <Eq>{`x`}</Eq> 사이에 <Eq>{`\\xi`}</Eq>가 존재하여:

<Eq display>{`\\frac{f(x)}{g(x)} = \\frac{f(x) - f(a)}{g(x) - g(a)} = \\frac{f'(\\xi)}{g'(\\xi)}`}</Eq>

<Eq>{`x \\to a`}</Eq>일 때, <Eq>{`\\xi \\to a`}</Eq>이고, 극한은 <Eq>{`f(x)/g(x) \\to f'(a)/g'(a)`}</Eq>로 진행한다 (도함수의 비가 수렴할 때).

### 다른 부정형으로의 확장

<Definicao titulo="축약 표">

| 형태 | 축약 |
|---|---|
| <Eq>{`0/0`}</Eq> | 로피탈 직접 적용 |
| <Eq>{`\\infty/\\infty`}</Eq> | 로피탈 직접 적용 |
| <Eq>{`0 \\cdot \\infty`}</Eq> | 다시 쓰기: <Eq>{`f \\cdot g = f / (1/g)`}</Eq> 또는 <Eq>{`g / (1/f)`}</Eq> |
| <Eq>{`\\infty - \\infty`}</Eq> | 분수로 합치기 (최소공배수 또는 유리화) |
| <Eq>{`1^\\infty, 0^0, \\infty^0`}</Eq> | 로그 취하기: <Eq>{`f^g = e^{g \\ln f}`}</Eq>; 지수에 로피탈 적용 |

</Definicao>

<Insight>

**정리 사용 시 주의:**
1. **적용 전에 형태 확인하기.** <Eq>{`\\lim f/g`}</Eq>가 <Eq>{`0/0`}</Eq> 또는 <Eq>{`\\infty/\\infty`}</Eq>가 아니면 로피탈은 **무효**이다.
2. **루프:** <Eq>{`\\lim (e^x - 1)/\\sin x`}</Eq>는 부정확하게 적용되면 순환에 들어갈 수 있다. 결과가 수렴하는지 확인하자.
3. **대안:** Taylor 급수는 부정형을 루프의 위험 없이 더 빠르게 해결하는 경우가 많다.

</Insight>

> "주의: 로피탈의 정리는 함수의 몫의 극한이 이들 도함수의 몫의 극한과 같다고 말하며, 단 원래 극한이 0/0 또는 ∞/∞ 형태여야 한다. 이것은 몫의 도함수와 같지 않다." — [Active Calculus §2.8](https://activecalculus.org/single/sec-2-8-LHR.html)

</Porta>

<Porta nivel="5" titulo="5살 아이를 위해">

두 개의 블록 더미가 줄어들고 있다고 생각해보자. 두 더미가 동시에 0에 도달하면 "상대적으로" 어느 것이 더 큰지 말하기 어렵다. 둘 다 사라졌으니까!

로피탈의 정리는 마법 같은 트릭이다: 더미를 비교하는 대신, **더미가 얼마나 빨리 줄어드는지** 비교한다. 누가 더 빠르게 줄어들까? 그 속도가 중요한 거야!

자동차에 비유하면: 두 차가 모두 멈출 때까지 브레이크를 밟으면, 중요한 것은 어디에 멈췄는가가 아니라, 누가 더 급하게 멈췄는가이다.

</Porta>

<Porta nivel="10" titulo="10살 아이를 위해">

<Eq>{`\\lim_{x \\to 0} \\frac{\\sin x}{x}`}</Eq>를 계산하고 싶다고 하자.

<Eq>{`x = 0`}</Eq>을 대입하면 <Eq>{`0/0`}</Eq>이 된다. 계산할 수 없다.

로피탈의 정리는 이렇게 말한다: <Eq>{`0/0`}</Eq>이 나타나면, **분자와 분모를 각각 따로 미분**하고 극한을 다시 시도해볼 수 있다:

<Eq display>{`\\lim_{x \\to 0} \\frac{\\sin x}{x} = \\lim_{x \\to 0} \\frac{\\cos x}{1} = \\frac{1}{1} = 1`}</Eq>

이것이 작동하는 이유는 도함수가 "변화의 속도"를 측정하기 때문이다. 모든 것이 0으로 갈 때, 변화의 속도의 비가 어느 함수가 0으로 더 빠르게 가는지 알려준다.

</Porta>

<Porta nivel="15" titulo="고등학교 학생을 위해">

**로피탈 언제 쓰나:**

1. 보통대로 극한을 계산하자.
2. <Eq>{`0/0`}</Eq> 또는 <Eq>{`\\infty/\\infty`}</Eq>가 나오면: 부정형이다.
3. 분자와 분모를 **따로따로** 미분한다 (몫의 미분법이 아니다!).
4. 극한을 다시 시도한다. 여전히 부정형이면 반복한다.

**다른 형태들:**

- <Eq>{`0 \\cdot \\infty`}</Eq>: 분수로 다시 쓰고 로피탈을 적용한다.
- <Eq>{`1^\\infty`}</Eq> 또는 <Eq>{`0^0`}</Eq>: <Eq>{`\\ln`}</Eq>을 취하고, 로그의 극한을 계산한 후, 지수화한다.

**고전적 함정:** 로피탈을 적용하기 전에 형태가 **정말** 부정형인지 확인한다. <Eq>{`\\lim_{x \\to 0} (x + 1)/x`}</Eq>에서 결과는 <Eq>{`\\infty`}</Eq>이다. <Eq>{`\\infty/\\infty`}</Eq> 형태가 아니므로 로피탈이 적용되지 않는다.

</Porta>

<Porta nivel="25" titulo="공학과 학생을 위해">

로피탈의 정리는 **Cauchy 평균값 정리**(Lagrange 평균값 정리의 일반화)의 결과이다: <Eq>{`f`}</Eq>와 <Eq>{`g`}</Eq>가 <Eq>{`[a, b]`}</Eq>에서 연속이고 <Eq>{`(a, b)`}</Eq>에서 미분가능하며 <Eq>{`g' \\neq 0`}</Eq>이면, <Eq>{`c \\in (a, b)`}</Eq>가 존재하여:

<Eq display>{`\\frac{f(b) - f(a)}{g(b) - g(a)} = \\frac{f'(c)}{g'(c)}`}</Eq>

**대안 — Taylor 급수:** <Eq>{`f`}</Eq>와 <Eq>{`g`}</Eq>가 <Eq>{`a`}</Eq> 근처에서 해석적이면, 급수로 전개하고 나눈다. 로피탈을 여러 번 적용하는 것보다 자주 더 빠르다.

예시: <Eq>{`\\lim_{x \\to 0} (\\sin x - x)/x^3`}</Eq>. Taylor: <Eq>{`\\sin x = x - x^3/6 + \\ldots`}</Eq>이므로 <Eq>{`\\sin x - x = -x^3/6 + \\ldots`}</Eq>. 따라서 극한은 <Eq>{`-1/6`}</Eq>이다. 로피탈을 세 번 적용하면 같은 결과인데, Taylor가 더 직접적이다.

**무한대의 위계:** <Eq>{`x \\to \\infty`}</Eq>일 때 <Eq>{`\\ln x \\ll x^n \\ll e^x \\ll e^{x^2}`}</Eq>. 로피탈은 도함수가 이 위계를 보존함을 형식화한다.

</Porta>

<Porta nivel="40" titulo="고위 전문가를 위해">

이 정리의 뒷이야기는 수학 역사의 가장 흥미로운 에피소드 중 하나이다. Johann Bernoulli는 1694년에 결과를 발견했고 학생 Marquis de L'Hôpital에게 알렸다. L'Hôpital은 역사상 첫 번째 미적분학 책인 "Analyse des Infiniment Petits" (1696)에 이를 포함시켰으나 Bernoulli를 명시하지 않았다. 그 결과는 오늘날까지 틀린 이름으로 불린다.

1821년에 발표된 Cauchy 평균값 정리가 엄밀한 증명을 제공했다. 그 전에는 "극한"이 직관적으로 다루어졌고 정리는 Leibniz의 미분 분석 논증으로 정당화되었다.

현대 실해석학에서 로피탈의 정리는 상대적 변화율에 관한 정리이다. Landau의 작은 o 표기법으로 보면, <Eq>{`f(x) = o(g(x))`}</Eq>가 <Eq>{`a`}</Eq> 근처에서 성립하고 정칙성 조건 하에 <Eq>{`f'/g' \\to 0`}</Eq>도 성립함을 말한다. 역은 섬세하다. <Eq>{`f'/g'`}</Eq>가 발산하지만 <Eq>{`f/g`}</Eq>는 수렴하는 함수들이 있다 (APEX §6.7의 반례 참고).

정량 금융에서 부정형의 극한은 옵션 가격 결정에 나타난다: Black-Scholes 모델에서 변동성 <Eq>{`\\sigma \\to 0`}</Eq>일 때, 가격은 동등 가치로 수렴한다. 이는 Black-Scholes 로그 공식의 <Eq>{`0/0`}</Eq> 형태 극한으로, 로피탈로 정확히 해결된다.

</Porta>

<Porta nivel="pratica" titulo="브라질 실무 적용">

**연속 이자 계산의 자연 극한.** 수 <Eq>{`e`}</Eq>는 부정형 <Eq>{`1^\\infty`}</Eq>의 고전적 극한으로 나타난다:

<Eq display>{`e = \\lim_{n \\to \\infty} \\left(1 + \\frac{1}{n}\\right)^n`}</Eq>

로그를 취하자: <Eq>{`\\ln L = \\lim_{n \\to \\infty} n \\ln(1 + 1/n)`}</Eq> — <Eq>{`\\infty \\cdot 0`}</Eq> 형태. 다시 쓰면:

<Eq display>{`\\ln L = \\lim_{n \\to \\infty} \\frac{\\ln(1 + 1/n)}{1/n}`}</Eq>

<Eq>{`0/0`}</Eq> 형태. 로피탈: 분자는 <Eq>{`(-1/n^2)/(1+1/n)`}</Eq>으로, 분모는 <Eq>{`-1/n^2`}</Eq>로 미분된다. 비: <Eq>{`1/(1+1/n) \\to 1`}</Eq>. 따라서 <Eq>{`\\ln L = 1`}</Eq>, 즉 <Eq>{`L = e`}</Eq>.

**ENEM 및 수능 응용:** 극한 <Eq>{`\\lim_{x \\to 0} \\sin(x)/x = 1`}</Eq> — 로피탈로 우아하게 증명됨 — 는 FUVEST 및 Unicamp와 같은 브라질 대입 시험에서 요구하는 삼각 극한의 기초이다.

**국가 금융 시스템:** 연 이자율을 연속 이자율로 변환할 때 정확히 <Eq>{`e^{rt}`}</Eq>를 사용한다. 중앙은행은 위험 모델에서 연속 복리를 사용한다.

</Porta>

## 풀이된 예시

<Exemplo titulo="간단한 0/0 형태">

**문제.** <Eq>{`\\lim_{x \\to 0} \\dfrac{\\sin x}{x}`}</Eq>를 계산하라.

**전략.** 부정형 확인; 로피탈 한 번 적용.

**풀이.**

직접 대입: <Eq>{`\\sin 0 / 0 = 0/0`}</Eq> — 부정형. 조건 충족 (<Eq>{`f = \\sin x`}</Eq>와 <Eq>{`g = x`}</Eq>는 미분가능, <Eq>{`g' = 1 \\neq 0`}</Eq>).

<Eq display>{`\\lim_{x \\to 0} \\frac{\\sin x}{x} \\stackrel{0/0}{=} \\lim_{x \\to 0} \\frac{\\cos x}{1} = \\cos 0 = 1`}</Eq>

**확인.** 이 결과는 기본 삼각 극한이다. Taylor 전개 <Eq>{`\\sin x = x - x^3/6 + \\ldots`}</Eq>와 일치하므로 <Eq>{`\\sin x/x \\to 1`}</Eq>.

**출처.** [Active Calculus §2.8, Exercise 2.8.1](https://activecalculus.org/single/sec-2-8-LHR.html) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="반복된 로피탈이 있는 0/0 형태">

**문제.** <Eq>{`\\lim_{x \\to 0} \\dfrac{e^x - 1 - x}{x^2}`}</Eq>를 계산하라.

**전략.** <Eq>{`0/0`}</Eq> 형태. 로피탈을 한 번 이상 적용해야 할 수 있다.

**풀이.**

직접 대입: <Eq>{`(1-1-0)/0 = 0/0`}</Eq>.

<Eq display>{`\\lim_{x \\to 0} \\frac{e^x - 1 - x}{x^2} \\stackrel{0/0}{=} \\lim_{x \\to 0} \\frac{e^x - 1}{2x} \\stackrel{0/0}{=} \\lim_{x \\to 0} \\frac{e^x}{2} = \\frac{1}{2}`}</Eq>

**확인.** Taylor: <Eq>{`e^x = 1 + x + x^2/2 + \\ldots`}</Eq>이므로 <Eq>{`e^x - 1 - x = x^2/2 + \\ldots`}</Eq>이고 몫은 <Eq>{`\\to 1/2`}</Eq>. 확인됨.

**출처.** [OpenStax Calculus Vol. 1, §4.8, Example 4.40](https://openstax.org/books/calculus-volume-1/pages/4-8-lhopitals-rule) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="x → ∞일 때 ∞/∞ 형태">

**문제.** <Eq>{`\\lim_{x \\to \\infty} \\dfrac{x^2}{e^x}`}</Eq>를 계산하라.

**전략.** <Eq>{`\\infty/\\infty`}</Eq> 형태. 해결될 때까지 반복 로피탈 적용.

**풀이.**

<Eq display>{`\\lim_{x \\to \\infty} \\frac{x^2}{e^x} \\stackrel{\\infty/\\infty}{=} \\lim_{x \\to \\infty} \\frac{2x}{e^x} \\stackrel{\\infty/\\infty}{=} \\lim_{x \\to \\infty} \\frac{2}{e^x} = 0`}</Eq>

**확인.** 결과는 0이다. 지수가 모든 거듭제곱보다 더 빠르게 증가한다. 이것은 위계 <Eq>{`x^n = o(e^x)`}</Eq> (모든 <Eq>{`n`}</Eq>에 대해)를 확인한다.

**출처.** [Active Calculus §2.8, Example 2.8.3](https://activecalculus.org/single/sec-2-8-LHR.html) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="로그를 이용한 1^∞ 형태">

**문제.** <Eq>{`\\lim_{x \\to 0^+} x^x`}</Eq>를 계산하라 (<Eq>{`0^0`}</Eq> 형태).

**전략.** 로그를 취해 <Eq>{`0/0`}</Eq> 또는 <Eq>{`\\infty/\\infty`}</Eq> 형태로 변환한 후, 지수화한다.

**풀이.**

<Eq>{`L = \\lim_{x \\to 0^+} x^x`}</Eq>라 하자. 그러면 <Eq>{`\\ln L = \\lim_{x \\to 0^+} x \\ln x`}</Eq> — <Eq>{`0 \\cdot (-\\infty)`}</Eq> 형태.

다시 쓰면: <Eq>{`x \\ln x = \\dfrac{\\ln x}{1/x}`}</Eq> — <Eq>{`\\infty/\\infty`}</Eq> 형태.

<Eq display>{`\\ln L = \\lim_{x \\to 0^+} \\frac{\\ln x}{1/x} \\stackrel{\\infty/\\infty}{=} \\lim_{x \\to 0^+} \\frac{1/x}{-1/x^2} = \\lim_{x \\to 0^+} (-x) = 0`}</Eq>

따라서 <Eq>{`L = e^0 = 1`}</Eq>. 극한 <Eq>{`\\lim_{x \\to 0^+} x^x = 1`}</Eq>.

**확인.** 수치적으로: <Eq>{`(0{,}1)^{0{,}1} \\approx 0{,}794`}</Eq>, <Eq>{`(0{,}01)^{0{,}01} \\approx 0{,}955`}</Eq>, 1로 수렴한다.

**출처.** [OpenStax Calculus Vol. 1, §4.8, Example 4.43](https://openstax.org/books/calculus-volume-1/pages/4-8-lhopitals-rule) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="조합을 통한 ∞ − ∞ 형태">

**문제.** <Eq>{`\\lim_{x \\to 0} \\left(\\dfrac{1}{\\sin x} - \\dfrac{1}{x}\\right)`}</Eq>를 계산하라.

**전략.** <Eq>{`\\infty - \\infty`}</Eq> 형태. 하나의 분수로 합친 다음 로피탈 적용.

**풀이.**

<Eq display>{`\\frac{1}{\\sin x} - \\frac{1}{x} = \\frac{x - \\sin x}{x \\sin x}`}</Eq>

<Eq>{`x \\to 0`}</Eq>일 때: 분자 <Eq>{`\\to 0`}</Eq>, 분모 <Eq>{`\\to 0`}</Eq> — <Eq>{`0/0`}</Eq> 형태.

<Eq display>{`\\lim_{x \\to 0} \\frac{x - \\sin x}{x \\sin x} \\stackrel{0/0}{=} \\lim_{x \\to 0} \\frac{1 - \\cos x}{\\sin x + x \\cos x} \\stackrel{0/0}{=} \\lim_{x \\to 0} \\frac{\\sin x}{2\\cos x - x\\sin x} = \\frac{0}{2} = 0`}</Eq>

**확인.** Taylor: <Eq>{`x - \\sin x = x^3/6 - \\ldots`}</Eq>이고 <Eq>{`x \\sin x = x^2 - x^4/6 + \\ldots`}</Eq>. 몫: <Eq>{`(x^3/6)/x^2 = x/6 \\to 0`}</Eq>. 확인됨.

**출처.** [APEX Calculus §6.7, Example 6.7.4](https://www.apexcalculus.com/) · CC-BY-NC

</Exemplo>
