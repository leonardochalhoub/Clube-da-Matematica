### 도함수의 정의

<Definicao titulo="한 점에서의 도함수">

$f: I \to \mathbb{R}$가 열린 구간 $I$에서 정의되고 $a \in I$일 때, **$a$에서의 도함수** $f'(a)$는 다음 극한값이다:

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

극한값이 존재하고 유한할 때 이를 구한다. 이 경우 $f$는 **$a$에서 미분가능**하다고 말한다.

**다른 형태** ($x = a + h$, $h = x - a$ 치환):

$$f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$

</Definicao>

> "We say that a function $f$ is differentiable at $x = a$ whenever $f'(a)$ exists. […] The derivative measures the instantaneous rate of change of the function, as well as the slope of the tangent line to the function at the given point." — [Boelkins, Active Calculus §1.3](https://activecalculus.org/single/sec-1-3-derivative-pt.html)

> "The derivative of a function $f(x)$ at a point $a$ in its domain, if it exists, is $f'(a) = \lim_{h \to 0}\frac{f(a+h)-f(a)}{h}$." — [OpenStax Calculus Vol. 1, §3.1](https://openstax.org/books/calculus-volume-1/pages/3-1-defining-the-derivative)

### 접선과 법선

$f$가 $a$에서 미분가능할 때:

- **$(a, f(a))$에서의 접선**: $\quad y - f(a) = f'(a)(x - a)$
- **$(a, f(a))$에서의 법선** (접선에 수직이며, $f'(a) \neq 0$): $\quad y - f(a) = -\dfrac{1}{f'(a)}(x - a)$

### 미분가능성의 기본 정리

<Teorema titulo="미분가능성은 연속성을 함축한다">

$f$가 $a$에서 미분가능하면, $f$는 $a$에서 연속이다.

**증명.** $f(a+h) - f(a) = \dfrac{f(a+h) - f(a)}{h} \cdot h$로 쓴다. $h \to 0$일 때 첫 번째 인수는 $f'(a)$로 수렴하고(가정에 의해) $h \to 0$이다. 따라서 $f(a+h) - f(a) \to f'(a) \cdot 0 = 0$, 즉 $\lim_{h \to 0} f(a+h) = f(a)$이다. $\square$

**역은 거짓이다.** $f(x) = |x|$는 $0$에서 연속이지만 미분가능하지 않다 (좌미분 $-1$, 우미분 $+1$이 다름).

</Teorema>

> "If $f$ is differentiable at $a$, then $f$ is continuous at $a$. […] The converse is not true, and a function can be continuous but fail to be differentiable at a point." — [OpenStax Calculus Vol. 1, §3.2](https://openstax.org/books/calculus-volume-1/pages/3-2-the-derivative-as-a-function)

### 미분 불가능한 점들

<Definicao titulo="병리적 점들의 분류">

- **뾰족점(코너)**: 좌미분과 우미분이 존재하지만 다름. 예: $|x|$ (점 $x = 0$).
- **첨점**: $f'(x) \to \pm\infty$ (양쪽에서). 예: $x^{2/3}$ (점 $x = 0$).
- **수직 접선**: $f'(a) = +\infty$ (또는 $-\infty$). 예: $\sqrt[3]{x}$ (점 $x = 0$).
- **불연속점**: $f$가 $a$에서 연속이 아니면 미분가능하지도 않음.

</Definicao>

### 정의에 의한 기본 도함수들

| 함수 $f(x)$ | $f'(x)$ |
|---|---|
| $c$ (상수) | $0$ |
| $x$ | $1$ |
| $x^2$ | $2x$ |
| $x^3$ | $3x^2$ |
| $x^n$ ($n \in \mathbb{Z}$) | $n x^{n-1}$ |
| $\dfrac{1}{x}$ | $-\dfrac{1}{x^2}$ |
| $\sqrt{x}$ | $\dfrac{1}{2\sqrt{x}}$ |

<Insight>

이 표의 각 행은 정의에서 증명된 정리이다. 단원 52–53에서는 도함수 법칙(합, 곱, 몫, 연쇄)을 정식화하여 매번 정의를 재적용하지 않아도 된다. 그러나 기본 법칙에 맞지 않는 새로운 함수의 도함수는 항상 정의로 돌아간다.

</Insight>

<Porta nivel="5" titulo="5살 아이를 위해">

자동차를 타고 한 도시에서 다른 도시로 가고 있다고 상상해 봐. 어떨 땐 **천천히**, 어떨 땐 **빠르게** 가지.

속도계가 지금 이 순간의 속도를 보여 주잖아.

**도함수**는 마치 수학적 속도계 같아. "이 함수가 지금 얼마나 빠르게 변하고 있어?"라고 말해 준단 말이야. 함수가 가파르게 올라가면 도함수가 커. 함수가 가만히 있으면 도함수는 0이야.

이렇게 생각해 봐: 100미터를 10초에 걸어갔어. 평균 속도는 1초에 10미터야. 그런데 처음엔 뛰었고 나중엔 천천히 걸었을 수도 있지?

**정확한 한 순간의 속도** — 그게 도함수야.

</Porta>

<Porta nivel="10" titulo="10살 아이를 위해">

너는 이미 **평균 속도**를 계산하는 법을 알아: 거리를 시간으로 나누면 돼. 100미터를 10초에 갔으니까, 평균 속도는 10m/s.

그런데 **정확히 이 순간**의 속도는 뭘까? 정말 작은 시간 구간을 잡아서, 그 구간에서의 평균 속도를 계산한 다음, 그 구간을 계속 더 작게 줄여 가는 거야.

**도함수**는 구간이 무한히 작아질 때 일어나는 일이야 — 함수의 "순간 속도"야.

**실제 예:** 위치가 $s(t) = t^2$ 미터라고 해. $t = 3$초일 때 뭘까?

- 1초 구간: $\frac{s(4) - s(3)}{1} = \frac{16 - 9}{1} = 7$ m/s
- 0.1초 구간: $\frac{s(3.1) - s(3)}{0.1} = \frac{9.61 - 9}{0.1} = 6.1$ m/s
- 0.01초 구간: $\frac{s(3.01) - s(3)}{0.01} = \frac{9.0601 - 9}{0.01} = 6.01$ m/s
- 극한: 정확한 속도 = **6 m/s**.

숫자 6이 $s(t) = t^2$의 점 $t = 3$에서의 도함수야.

</Porta>

<Porta nivel="15" titulo="15살 청소년을 위해">

$f$의 $a$에서 $a + h$ 구간의 **평균 변화율**은:

$$\frac{f(a+h) - f(a)}{h}$$

기하학적으로, 이건 점 $(a, f(a))$와 $(a+h, f(a+h))$를 지나는 **할선**의 기울기다.

$h \to 0$일 때, 할선이 "회전"하여 점 $(a, f(a))$에서 그래프에 그은 **접선**에 가까워진다. 이 접선의 기울기가 도함수 $f'(a)$다.

### 정의에 의한 계산법

1. $f(a + h)$ 계산 — 공식에서 $x$를 $a + h$로 치환.
2. $f(a)$를 빼고 $h$로 나눔.
3. **대수적으로 단순화** — 분모의 $h$를 약분.
4. 극한 $h \to 0$ 취함.

### 예: $f(x) = x^2$

$$f'(a) = \lim_{h \to 0} \frac{(a+h)^2 - a^2}{h} = \lim_{h \to 0} \frac{a^2 + 2ah + h^2 - a^2}{h} = \lim_{h \to 0} \frac{2ah + h^2}{h} = \lim_{h \to 0} (2a + h) = 2a$$

따라서 $f'(x) = 2x$ — $x^2$의 도함수는 $2x$.

### 도함수가 존재하지 않는 경우

- **뾰족점**: $|x|$ (점 $x = 0$) — 좌미분 $f'_-(0) = -1$, 우미분 $f'_+(0) = +1$. 다름: 미분 불가능.
- **불연속점**: $f$가 점프하면 접선을 정의할 수 없다.

<Insight>

도함수는 미적분의 중심 개념이다. 속도(위치의 도함수), 가속도(속도의 도함수), 한계 비용(비용의 도함수), 순간 이자율(자본의 도함수) — 모두 도함수다. 극한을 통한 정의를 배우는 것은 이 모든 개념의 DNA를 배우는 것이다.

</Insight>

</Porta>

<Porta nivel="25" titulo="공학과 학생을 위해">

극한으로 정의하는 방법이 **기초**다. 도함수 법칙(단원 52)과 연쇄 법칙(단원 53)은 이 정의에서 증명된 정리들이다. 단순한 계산뿐 아니라 **결과를 증명**하기 위해 이를 숙달해야 한다.

### 증명: 미분가능성은 연속성을 함축

$f'(a)$가 존재한다고 가정하자. 다음을 쓸 수 있다:

$$f(a+h) - f(a) = \frac{f(a+h) - f(a)}{h} \cdot h \;\xrightarrow{h \to 0}\; f'(a) \cdot 0 = 0$$

극한으로의 이행은 유한 극한과 $h \to 0$의 곱을 사용한다. 따라서 $\lim_{h \to 0} f(a+h) = f(a)$, 즉 $f$는 $a$에서 연속이다. $\square$

### 측면(한쪽) 미분가능성

$$f'_+(a) = \lim_{h \to 0^+} \frac{f(a+h)-f(a)}{h}, \qquad f'_-(a) = \lim_{h \to 0^-} \frac{f(a+h)-f(a)}{h}$$

$f$가 $a$에서 미분가능한 필요충분조건은 $f'_+(a) = f'_-(a)$ (둘 다 유한)이다.

### 정의에 의한 도함수 — 완전한 계산들

**$f(x) = 1/x$:** $a \neq 0$일 때:

$$f'(a) = \lim_{h \to 0} \frac{\frac{1}{a+h} - \frac{1}{a}}{h} = \lim_{h \to 0} \frac{\frac{a - (a+h)}{a(a+h)}}{h} = \lim_{h \to 0} \frac{-h}{h \cdot a(a+h)} = \lim_{h \to 0} \frac{-1}{a(a+h)} = \frac{-1}{a^2}$$

**$f(x) = \sqrt{x}$:** $a > 0$일 때:

$$f'(a) = \lim_{h \to 0} \frac{\sqrt{a+h} - \sqrt{a}}{h} = \lim_{h \to 0} \frac{(\sqrt{a+h} - \sqrt{a})(\sqrt{a+h}+\sqrt{a})}{h(\sqrt{a+h}+\sqrt{a})} = \lim_{h \to 0} \frac{h}{h(\sqrt{a+h}+\sqrt{a})} = \frac{1}{2\sqrt{a}}$$

### 중요한 병리 현상들

- $f(x) = x^2 \sin(1/x)$, $f(0) = 0$: 점 0에서 미분가능 ($f'(0) = 0$)이지만 $f'$은 0에서 연속이 아님.
- **바이어슈트라스 함수**: $\mathbb{R}$에서 연속이지만 어느 점에서도 미분 불가능. 연속성 $\not\Rightarrow$ 미분가능성.
- $f(x) = \sqrt[3]{x}$: $f'(0) = +\infty$ — 수직 접선, 고전적 의미의 미분 불가능.

### 학문 분야 연계

- **물리학:** $v = ds/dt$, $a = dv/dt$, 힘 $F = dp/dt$ (2 법칙을 도함수 형태로).
- **정량 금융:** 지속 수익률 $r = d(\ln S)/dt$; 옵션의 델타 $\Delta = \partial V/\partial S$.
- **확률론:** $f(x) = F'(x)$ — 확률밀도함수는 누적분포함수의 도함수.
- **기계학습:** 경사 하강 — $\theta \leftarrow \theta - \eta\, \nabla L$; 역전파는 각 가중치에서 도함수 사용.

</Porta>

<Porta nivel="40" titulo="고위급 전문가를 위해">

라그랑주/뉴턴의 도함수는 현대 응용 수학 전체를 지탱하는 일반화 계단의 첫 걸음이다.

### 도함수를 선형 연산자로

도함수 연산자 $D: C^1(I) \to C^0(I)$는 **선형**이다 ($D(af+bg) = aD(f)+bD(g)$) 하지만 노름 $C^0$에서 **유계가 아니다**: $f_n(x) = \sin(nx)/n$을 생각해 보자 — 균일하게 0으로 수렴하지만 $f_n'(x) = \cos(nx)$는 수렴하지 않는다. 따라서 잘 정의된 편미분방정식은 소볼레프 공간 $W^{k,p}$를 요구한다.

### 일반화들

- **프레셰 미분**(바나흐): $f: X \to Y$가 $x$에서 미분가능 ⟺ 연속 선형 연산자 $A: X \to Y$가 존재하여 $\|f(x+h) - f(x) - Ah\|_Y / \|h\|_X \to 0$. $A = Df(x)$ — 유한차원에서는 야코비안.
- **가토 미분**(방향): $D_v f(x) = \lim_{t\to 0}[f(x+tv)-f(x)]/t$. 프레셰보다 약함; 비매끄러운 최적화에 유용.
- **분포적 미분**(슈바르츠): $\langle T', \varphi\rangle = -\langle T, \varphi'\rangle$. 헤비사이드의 미분 가능 (결과: 디랙 델타). 현대 편미분방정식의 기초.
- **자동 미분(autodiff):** 전진 모드(제트/이중수)와 역진 모드(쌍대); JAX/PyTorch 구현. 그래디언트 비용 $\approx 2\times$ 함수 비용 — 바우르–슈트라센 정리.

### 이토 미적분과 금융

이토 과정 $dS_t = \mu S_t\,dt + \sigma S_t\,dW_t$에서 고전적 도함수 $dS/dt$는 존재하지 않는다 (경로는 q.s. $\alpha$-횔더, $\alpha < 1/2$). 이토 공식을 사용한다:

$$df(S_t) = f'(S_t)\,dS_t + \tfrac{1}{2}f''(S_t)\,\sigma^2 S_t^2\,dt$$

2차 항 $\frac{1}{2}f''$ (2차 보정)은 이토를 고전 미적분과 분리하는 것이며 블랙–숄즈 방정식(단원 119)의 항 $\frac{1}{2}\sigma^2$의 기원이다.

### 수치 차분

- 전진: $f'(a) \approx \frac{f(a+h)-f(a)}{h}$, 오차 $O(h)$.
- 후진: $f'(a) \approx \frac{f(a)-f(a-h)}{h}$, 오차 $O(h)$.
- 중심: $f'(a) \approx \frac{f(a+h)-f(a-h)}{2h}$, 오차 $O(h^2)$ — 수치 계산에는 항상 선호.
- IEEE-754 부동소수점에서, $h \approx \sqrt{\varepsilon_{\text{mach}}} \approx 10^{-8}$은 전진 차분의 전체 오차를 최소화 (절단 오차와 소거 오차 간 절충).

### 추천 도서

- **Spivak, Calculus**, 9–10장: 최대 해석적 엄밀함으로 정의.
- **Rudin, Principles of Mathematical Analysis**, 5장: 거리 공간에서의 미분.
- **Griewank & Walther, Evaluating Derivatives (2판):** 자동 미분의 바이블.

<Porta nivel="pratica" titulo="실제 응용 — 정의 사용 시기">

### 정의가 필요한 경우 (법칙이 아닌)

1. **의심스러운 점에서 미분가능성 검증** (조각별 정의 부위, 뾰족점, 원점).
2. **함수가 미분 불가능임을 증명** — 한쪽 미분값을 계산하여 다름을 보임.
3. **법칙 증명** (곱, 몫, 연쇄) — 한 번 하면 결과 사용.
4. **수치 차분** — $f$가 분석 공식 없이 블랙박스일 때.

### 미분가능성 진단 워크플로우

1. $f$가 $a$에서 정의되고 연속인지 확인 (필요조건).
2. 좌미분 $f'_-(a)$와 우미분 $f'_+(a)$ 각각 계산.
3. 같고 유한? **미분가능.** 다름? **뾰족점.** 둘 다 $\pm\infty$? **수직 접선.** 다른 방식 발산? **미분 불가능.**

### 기호 계산 — SymPy

```python
import sympy as sp
x, h, a = sp.symbols('x h a')
f = x**3 - 2*x
deriv = sp.limit((f.subs(x, a + h) - f.subs(x, a)) / h, h, 0)
print(deriv)  # 3*a**2 - 2
```

### 전형적 오류

- **분자를 합치기 전에** $h$ 약분 — 항상 먼저 전개하기.
- **$h$를 분모에서 약분하기 전에** 극한 $h \to 0$ 취하기 — 몫이 여전히 $0/0$; 먼저 대수적으로 $h$ 제거 필요.
- $f'(a)$ (숫자 — 한 점에서의 도함수)과 $f'(x)$ (함수 — 도함수 함수) 혼동.
- $h \to 0$이 양쪽에서임을 잊음 — 한쪽 미분값이 일치해야 함.

### 직접 응용

| 분야 | $f(t)$ | $f'(t)$ |
|---|---|---|
| 역학 | 위치 $s(t)$ | 속도 $v(t)$ |
| 역학 | 속도 $v(t)$ | 가속도 $a(t)$ |
| 재무 | 비용 $C(q)$ | 한계 비용 $C'(q)$ |
| 전기 | 전하 $q(t)$ | 전류 $i(t) = dq/dt$ |
| 생물학 | 개체군 $P(t)$ | 성장률 $P'(t)$ |

## 풀이 예제

<Exemplo titulo="정의에 의한 $x^2$의 도함수" numero="1">

**문제:** 도함수의 정의를 이용하여 $f(x) = x^2$에 대해 $f'(x)$를 구하시오.

**전략:** 정의 $f'(a) = \lim_{h \to 0} \frac{f(a+h)-f(a)}{h}$를 직접 적용하고 분모에서 $h$를 제거하기 위해 대수적으로 단순화한다.

**풀이:**

1. **$f(a+h)$ 계산:**
$$f(a+h) = (a+h)^2 = a^2 + 2ah + h^2$$

2. **증분 몫 작성:**
$$\frac{f(a+h)-f(a)}{h} = \frac{a^2 + 2ah + h^2 - a^2}{h} = \frac{2ah + h^2}{h}$$

3. **$h$ 약분** (극한 과정에서 $h \neq 0$이므로 유효):
$$\frac{2ah + h^2}{h} = \frac{h(2a + h)}{h} = 2a + h$$

4. **극한 취하기:**
$$f'(a) = \lim_{h \to 0}(2a + h) = 2a$$

$a$가 임의이므로, 도함수 함수는 $f'(x) = 2x$이다.

**검산:** $x = 3$에서, $f'(3) = 6$. 접선은 점 $(3, 9)$를 지나고 기울기 6: $y = 6x - 9$. 확인점: $f(3.1) = 9.61$이고 $y(3.1) = 6(3.1) - 9 = 9.6$ — 작은 $h$에 대해 접선이 그래프를 잘 근사한다. $\checkmark$

**출처:** [Active Calculus, §1.3, Activity 1.3.2](https://activecalculus.org/single/sec-1-3-derivative-pt.html) — CC-BY-SA 4.0 라이선스.
</Exemplo>

<Exemplo titulo="정의에 의한 $1/x$의 도함수" numero="2">

**문제:** $f(x) = \dfrac{1}{x}$ ($a \neq 0$)에 대해 정의를 이용하여 $f'(a)$를 구하시오.

**전략:** 핵심 단계는 분자의 분수들을 하나의 분수로 결합하여 분모에서 $h$를 약분하는 것이다.

**풀이:**

1. **증분 몫:**
$$\frac{f(a+h)-f(a)}{h} = \frac{\dfrac{1}{a+h} - \dfrac{1}{a}}{h}$$

2. **분자의 분수 결합** (최소공배수 $a(a+h)$):
$$= \frac{\dfrac{a - (a+h)}{a(a+h)}}{h} = \frac{-h}{h \cdot a(a+h)}$$

3. **$h$ 약분:**
$$= \frac{-1}{a(a+h)}$$

4. **$h \to 0$의 극한 취하기:**
$$f'(a) = \lim_{h \to 0} \frac{-1}{a(a+h)} = \frac{-1}{a \cdot a} = -\frac{1}{a^2}$$

**결과:** $(1/x)' = -1/x^2$. 기하학적으로: 쌍곡선 $y = 1/x$는 모든 $x \neq 0$에서 음의 기울기 접선을 가진다 — 함수는 구간 $x > 0$과 $x < 0$에서 항상 감소한다.

**검산:** $a = 2$에서: $f'(2) = -1/4$. 접선: $y - 1/2 = -\tfrac{1}{4}(x-2) \Rightarrow y = -x/4 + 1$. $x = 2.1$에서: 접선 값 $0.475$; $f(2.1) = 1/2.1 \approx 0.476$. $\checkmark$

**출처:** [OpenStax Calculus Volume 1, §3.1, Example 3.6](https://openstax.org/books/calculus-volume-1/pages/3-1-defining-the-derivative) — CC-BY-NC-SA 4.0 라이선스.
</Exemplo>

<Exemplo titulo="$x^3$에 대한 접선의 방정식" numero="3">

**문제:** $f(x) = x^3$의 그래프에 점 $x = 2$에서 그은 접선의 방정식을 구하시오.

**전략:** 접선의 방정식은 $y - f(a) = f'(a)(x - a)$이다. $f(a)$와 $f'(a)$가 필요하다.

**풀이:**

1. **$f(2) = 2^3 = 8$ 계산**. 접점은 $(2, 8)$.

2. **정의에 의해 $f'(a)$ 계산:**
$$\frac{(a+h)^3 - a^3}{h} = \frac{a^3 + 3a^2h + 3ah^2 + h^3 - a^3}{h} = \frac{3a^2h + 3ah^2 + h^3}{h} = 3a^2 + 3ah + h^2$$

$$f'(a) = \lim_{h \to 0}(3a^2 + 3ah + h^2) = 3a^2$$

따라서 $f'(2) = 3 \cdot 4 = 12$.

3. **접선의 방정식:**
$$y - 8 = 12(x - 2) \implies y = 12x - 16$$

**검산:** $x = 2.1$에서: $f(2.1) = (2.1)^3 = 9.261$; 접선: $y = 12(2.1) - 16 = 9.2$. 절대 오차 $0.061$ — 선형 근사에 예상되는 대로 $h^2$에 따라 증가. $\checkmark$

**출처:** [APEX Calculus, §2.1, Example 2.1.3](https://www.apexcalculus.com/) — CC-BY-NC 4.0 라이선스.
</Exemplo>

<Exemplo titulo="미분 불가능성: 절댓값의 뾰족점" numero="4">

**문제:** $f(x) = |x|$가 $x = 0$에서 미분가능한가?

**전략:** 한쪽 미분 $f'_-(0)$과 $f'_+(0)$을 각각 계산한다. 다르면 $f$는 0에서 미분 불가능하다.

**풀이:**

1. **우미분** ($h \to 0^+$, 그러면 $h > 0$, 따라서 $|h| = h$):
$$f'_+(0) = \lim_{h \to 0^+} \frac{|0+h| - |0|}{h} = \lim_{h \to 0^+} \frac{h}{h} = 1$$

2. **좌미분** ($h \to 0^-$, 그러면 $h < 0$, 따라서 $|h| = -h$):
$$f'_-(0) = \lim_{h \to 0^-} \frac{|0+h| - |0|}{h} = \lim_{h \to 0^-} \frac{-h}{h} = -1$$

3. **결론:** $f'_+(0) = 1 \neq -1 = f'_-(0)$.

한쪽 미분값이 다르므로, $f(x) = |x|$는 **$x = 0$에서 미분 불가능** — 그래프에 뾰족점(코너)이 있다. $f$는 0에서 연속이라는 점 ($\lim_{x\to 0}|x| = 0 = |0|$)에 유의하여, **연속성이 미분가능성을 함축하지 않음**을 확인한다.

**검산:** $|x|$의 그래프는 $x > 0$에서 기울기 $+1$, $x < 0$에서 기울기 $-1$. $x = 0$에서 유일한 접선이 존재하지 않는다. $\checkmark$

**출처:** [Active Calculus, §1.7, Activity 1.7.3](https://activecalculus.org/single/sec-1-7-lim-cont-diff.html) — CC-BY-SA 4.0 라이선스.
</Exemplo>

<Exemplo titulo="한계 비용 — 경제학적 응용" numero="5">

**문제:** 어떤 회사가 제품 $q$개를 생산할 때 총 비용이 $C(q) = q^2 + 30q + 500$ 원이다. 도함수의 정의를 이용하여 $q = 50$일 때 한계 비용을 구하고 결과를 해석하시오.

**전략:** 한계 비용 = $C'(q)$는 양에 대한 비용의 순간 변화율. 정의에 의해 계산하여 $q = 50$에서 평가한다.

**풀이:**

1. **증분 몫:**
$$\frac{C(q+h) - C(q)}{h} = \frac{(q+h)^2 + 30(q+h) + 500 - (q^2 + 30q + 500)}{h}$$

$$= \frac{q^2 + 2qh + h^2 + 30q + 30h + 500 - q^2 - 30q - 500}{h} = \frac{2qh + h^2 + 30h}{h}$$

$$= 2q + h + 30$$

2. **극한 취하기:**
$$C'(q) = \lim_{h \to 0}(2q + h + 30) = 2q + 30$$

3. **$q = 50$에서 평가:**
$$C'(50) = 2(50) + 30 = 130 \text{ 원}$$

**해석:** 50개를 생산할 때, 추가 1개 생산의 비용은 약 130 원. $C(51) - C(50) = (2601 + 1530 + 500) - (2500 + 1500 + 500) = 4631 - 4500 = 131$ 원 — 한계 비용이 1 원 저과(2차 오차로 예상되는 차이).

**검산:** $C'(q) = 2q + 30 > 0$ (모든 $q > 0$): 비용 증가, 예상대로. $q = 0$에서: $C'(0) = 30$ — 첫 번째 단위의 한계 비용 30 원. $\checkmark$

**출처:** [OpenStax Calculus Volume 1, §3.1, 경제학적 응용 예제 — 한계 비용](https://openstax.org/books/calculus-volume-1/pages/3-1-defining-the-derivative) — CC-BY-NC-SA 4.0 라이선스.
</Exemplo>

### 구간 C — 미분가능성: 의심 점 분석 (51.21 ~ 51.30)

<Exercicio
  numero="51.21"
  dificuldade="compreensao"
  opcoes={[
    { texto: "예, $f'(0) = 0$" },
    { texto: "아니오. $f'_-(0) = -1$이고 $f'_+(0) = 1$이기 때문", correta: true },
    { texto: "예, $f'(0) = 1$" },
    { texto: "아니오. $f$가 0에서 불연속이기 때문" },
  ]}
  solucao={<>우미분: <Eq>{`\\lim_{h \\to 0^+} |h|/h = 1`}</Eq>. 좌미분: <Eq>{`\\lim_{h \\to 0^-} |h|/h = -1`}</Eq>. <Eq>{`f'_+(0) \\neq f'_-(0)`}</Eq>이므로, 점 0에서 도함수 없음. $f$는 0에서 연속이라는 점 주목 — 연속성이 미분가능성을 보장하지 않는 표준 예.</>}
  passos={<>
    <ol>
      <li><strong>연속성 확인.</strong> <Eq>{`\\lim_{x \\to 0}|x| = 0 = |0|`}</Eq>. 연속 — 하지만 연속이 미분가능함을 보장하지 않음.</li>
      <li><strong>우미분 ($h > 0$).</strong> <Eq>{`\\lim_{h \\to 0^+}\\frac{|0+h|-|0|}{h} = \\lim_{h \\to 0^+}\\frac{h}{h} = 1`}</Eq>.</li>
      <li><strong>좌미분 ($h < 0$).</strong> $h < 0$이므로 <Eq>{`|h| = -h`}</Eq>. 따라서 <Eq>{`\\lim_{h \\to 0^-}\\frac{-h}{h} = -1`}</Eq>.</li>
      <li><strong>결론.</strong> <Eq>{`1 \\neq -1`}</Eq>: 한쪽 미분이 다름. 0에서 미분 불가능. 그래프는 점 <Eq>{`(0,0)`</Eq>에 뾰족점 있음.</li>
    </ol>
