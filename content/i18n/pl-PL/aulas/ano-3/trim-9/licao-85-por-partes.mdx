### Wyprowadzenie wzoru

<Definicao titulo="Całkowanie przez części">

Niech $u(x)$ i $v(x)$ będą funkcjami różniczkowalnymi na $[a, b]$, gdzie $u'$ i $v'$ są ciągłe. Reguła iloczynu głosi:

$$\frac{d}{dx}[u(x)v(x)] = u'(x)v(x) + u(x)v'(x).$$

Całkując obie strony od $a$ do $b$ i stosując Zasadnicze Twierdzenie Rachunku Całkowego:

$$[u(x)v(x)]_a^b = \int_a^b u'(x)v(x)\, dx + \int_a^b u(x)v'(x)\, dx.$$

Przegrupowując:

$$\int_a^b u(x)v'(x)\, dx = [u(x)v(x)]_a^b - \int_a^b v(x)u'(x)\, dx.$$

W notacji różniczkowej ($dv = v'(x)\, dx$, $du = u'(x)\, dx$):

<Equation explicacao="Wzór całkowania przez części — postać nieoznaczona." latex="\int u\, dv = uv - \int v\, du." />

</Definicao>

> "The formula for integration by parts comes from the product rule for differentiation: if $u$ and $v$ are both functions of $x$, then $(uv)' = u'v + uv'$. Integrating both sides and rearranging gives $\int u\, dv = uv - \int v\, du$." — [Active Calculus §5.4](https://activecalculus.org/single/sec-5-4-parts.html)

### Heurystyka LIATE

<Definicao titulo="Kolejność preferencji dla u (LIATE)">

Aby wybrać $u$ (funkcję, która będzie różniczkowana), preferuj w kolejności:

1. **L**ogarytmiczna: $\ln x$, $\log_a x$
2. **I**nversa trygonometryczna: $\arctan x$, $\arcsin x$, $\arccos x$
3. **A**lgebraiczna: $x^n$, wielomiany
4. **T**rygonometryczna: $\sin x$, $\cos x$, $\tan x$
5. **E**wykładnicza: $e^x$, $a^x$

Pierwsza kategoria, która się pojawi w całkowaniu, staje się $u$. Reszta to $dv$.

**Logika:** funkcje logarytmiczne i odwrotne trygonometryczne mają pochodne, które upraszczają się (z transcendentalnych na algebraiczne); funkcje wykładnicze i trygonometryczne reprodukują się przy różniczkowaniu. Dlatego $u$ powinno być czynnikiem, który „poprawia się" przy różniczkowaniu.

</Definicao>

> "A useful heuristic for deciding which function to call $u$ in integration by parts is the acronym LIATE, which stands for Logarithmic, Inverse trigonometric, Algebraic, Trigonometric, and Exponential functions." — [OpenStax Calculus Vol. 2, §3.1](https://openstax.org/books/calculus-volume-2/pages/3-1-integration-by-parts)

<Teorema titulo="Trick: całka, która wraca do siebie">

Dla $I = \int e^x \cos x\, dx$:

Zastosuj części z $u = \cos x$, $dv = e^x dx$: $I = e^x \cos x + \int e^x \sin x\, dx$.

Zastosuj części ponownie z $u = \sin x$: $I = e^x \cos x + e^x \sin x - I$.

Dlatego $2I = e^x(\cos x + \sin x)$, i:

<Equation explicacao="Wynik tricku, gdy całka pierwotna pojawia się ponownie po dwóch aplikacjach." latex="I = \frac{e^x(\sin x + \cos x)}{2} + C." />

**Warunek:** trick działa, gdy druga aplikacja odtwarza całkę pierwotną z tym samym znakiem (a nie ze zmienionym znakiem, co dałoby tożsamość zerową).

</Teorema>

<Insight>

**Części to transfer pochodnej.** Tożsamość $\int u\, dv = uv - \int v\, du$ przenosi operację różniczkowania z jednego czynnika na inny. W przestrzeniach funkcyjnych z zerowymi warunkami brzegowymi to czyni $d/dx$ antysymetrycznym w $L^2$ — podstawa słabego sformułowania PDE.

</Insight>

<Porta nivel="10" titulo="Dla dziecka w wieku 10 lat">

Pamiętasz, że pochodna iloczynu ma dwa wyrazy? Jeśli $f = u \cdot v$, to $f' = u'v + uv'$.

Teraz wyobraź sobie, że całkujesz obie strony:

$uv = \int u'v\, dx + \int uv'\, dx$

Przegrupowując: $\int uv'\, dx = uv - \int u'v\, dx$.

**Praktyczne tłumaczenie:** gdy masz iloczyn do całkowania, możesz zamienić na $uv$ minus **kolejna całka**. Jeśli nowa całka będzie prostsza, wygrałeś.

**Przykład**: $\int x \sin x\, dx$. $x$ jest algebraiczny (upraszcza się przy różniczkowaniu: staje się $1$). $\sin x$ ma funkcję pierwotną $-\cos x$.

Dlatego $u = x$, $dv = \sin x\, dx$. Po zastosowaniu wzoru: $-x\cos x + \int \cos x\, dx = -x\cos x + \sin x + C$.

**Trick LIATE**: z Log, Inv-trig, Algebraiczny, Trig, Exp — pierwsza, która się pojawi, staje się $u$.

</Porta>

<Porta nivel="15" titulo="Dla nastolatka w wieku 15 lat">

Wzór to $\int u\, dv = uv - \int v\, du$.

**Przepis w 5 krokach:**

1. Zidentyfikuj iloczyn w całkowaniu.
2. Użyj **LIATE** aby wybrać $u$ (Log > Inv-trig > Algebraiczny > Trig > Exp).
3. Reszta to $dv$. Oblicz $du = u'\, dx$ i $v = \int dv$.
4. Zastosuj wzór.
5. Rozwiąż $\int v\, du$ — powinno być prostsze.

**Trzy fundamentalne wzorce:**

**1.** $\int x e^x\, dx$: $u = x$ (Algebraiczny), $dv = e^x dx$. Wynik: $xe^x - e^x + C$.

**2.** $\int \ln x\, dx$: $u = \ln x$ (Log), $dv = dx$. Wtedy $du = dx/x$, $v = x$. Wynik: $x \ln x - x + C$.

**3.** $\int e^x \cos x\, dx$: zastosuj dwa razy — całka wraca. Izoluj: wynik $e^x(\sin x + \cos x)/2 + C$.

**Kiedy NIE używać części**: jeśli widzisz $\int x e^{x^2}\, dx$, to podstawienie (chain ukryta), nie części.

</Porta>

Części systemowo rozwiązuje klasę **iloczyn wielomian × (exp, trig, log, inv-trig)**.

### Tabela wzorców

| Całka | $u$ | Uwaga |
|---|---|---|
| $\int x^n e^{ax}\, dx$ | $x^n$ | Zastosuj $n$ razy; metoda tabelaryczna przyspiesza |
| $\int x^n \sin(ax)\, dx$ | $x^n$ | To samo |
| $\int x^n \ln x\, dx$ | $\ln x$ | Jedna aplikacja; czysty wynik |
| $\int e^{ax}\cos(bx)\, dx$ | dowolny | Dwie aplikacje + izoluj $I$ |
| $\int \arctan x\, dx$ | $\arctan x$ | $dv = dx$; $v = x$; potem podstawienie |
| $\int \arcsin x\, dx$ | $\arcsin x$ | $dv = dx$; $v = x$; potem podstawienie |

### Fundamentalne połączenia

- **Laplace**: $\mathcal{L}\{t\} = \int_0^\infty t e^{-st}\, dt = 1/s^2$ — obliczone przez części.
- **Funkcja Gamma**: $\Gamma(n+1) = n \Gamma(n)$ — wykazane przez części + $\Gamma(1) = 1$.
- **Współczynniki Fouriera**: $a_n = (1/\pi)\int_{-\pi}^\pi f(x)\cos(nx)\, dx$ — części redukują, gdy $f$ jest wielomianowa.
- **Transformacja Laplace'a $t^n$**: $n!/(s^{n+1})$ — części iterowana.

### Szczegółowa metoda tabelaryczna

Dla $\int x^3 e^x\, dx$:

| D | I | Znak |
|---|---|---|
| $x^3$ | $e^x$ | + |
| $3x^2$ | $e^x$ | − |
| $6x$ | $e^x$ | + |
| $6$ | $e^x$ | − |
| $0$ | — | — |

Wynik: $x^3 e^x - 3x^2 e^x + 6x e^x - 6e^x + C = e^x(x^3 - 3x^2 + 6x - 6) + C$.

### Wzory redukcyjne

Przez części: $\int \sin^n x\, dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n-1}{n}\int \sin^{n-2}x\, dx$.

To samo dla $\cos^n$, $\sec^n$, $\csc^n$.

### Uogólnienie: tożsamość Greena

W wymiarze $n$, całkowanie przez części to:

$$\int_\Omega u\, \nabla \cdot \mathbf{F}\, dV = \int_{\partial\Omega} u\, \mathbf{F} \cdot \mathbf{n}\, dS - \int_\Omega \nabla u \cdot \mathbf{F}\, dV.$$

Dla $\mathbf{F} = \nabla v$: pierwsza tożsamość Greena $\int u\, \Delta v = \oint u\, \partial_n v - \int \nabla u \cdot \nabla v$.

### Słabe sformułowanie w MES

Równanie Poissona $-\Delta u = f$ w $\Omega$ z $u|_{\partial\Omega} = 0$ — części przenoszą pochodną do funkcji testowej $v \in H^1_0$:

$$\int_\Omega \nabla u \cdot \nabla v\, dV = \int_\Omega f v\, dV \quad \forall v \in H^1_0(\Omega).$$

Bez tego transferu przez części, nie byłoby sformułowania wariacyjnego. FEniCS, Firedrake, deal.II implementują to symbolowo.

### Sprzężenie operatora różniczkowego

W $L^2$ z zerowymi warunkami brzegowymi: $\langle Du, v\rangle = -\langle u, Dv\rangle$ — $D = d/dx$ jest antysymetryczne. Uogólniając, sprzężenie formalne $L = \sum a_k \partial^k$ to $L^* = \sum (-1)^k \partial^k (a_k \cdot)$. Części to dowodzą.

### Analiza Fouriera i gładkość

Części iterowana wykazuje: $|\hat{f}(n)| = O(n^{-k})$ wtedy i tylko wtedy, gdy $f \in C^{k-1}$ z $f^{(k)} \in L^1$. Połączenie między gładkością w przestrzeni fizycznej i rozkładem w częstotliwości — centralne w teorii falkowej i kompresji.

### Mechanika kwantowa

Hermityczność pędu $\hat{p} = -i\hbar\, \partial_x$ wymaga $\langle \psi_1 | \hat{p} \psi_2 \rangle = \langle \hat{p}\psi_1 | \psi_2 \rangle$, wykazane przez części + warunek brzegowy (funkcja falowa zanika w nieskończoności).

<Porta nivel="pratica" titulo="Aplikacja praktyczna">

**Kompletny przepis:**

1. Całkowanie ma iloczyn? Jeśli tak, części. Jeśli nie, zastanów się nad podstawieniem.
2. Zastosuj **LIATE** dla $u$.
3. $du = u'\, dx$, $v = \int dv$.
4. $uv - \int v\, du$.
5. Jeśli $\int v\, du$ jest nadal iloczynem: iteruj (lub użyj tabeli DI).
6. Jeśli całka wróciła: izoluj $I$.
7. Sprawdź: różniczkuj wynik — powinien odtworzyć całkowanie.

### Aplikacje brazylskie

**Wartość bieżąca rosnącego strumienia:** dochód $C(t) = t$ tys. reali na rok, stopa $r = 10\%$, na $T = 5$ lat:

$$VP = \int_0^5 t \cdot e^{-0{,}1 t}\, dt.$$

Przez części: $u = t$, $dv = e^{-0{,}1t}\, dt$. Wynik: około 9,48 tys. reali.

**Oczekiwanie zmiennej wykładniczej:** $E[X] = \int_0^\infty x \lambda e^{-\lambda x}\, dx = 1/\lambda$ — części z $u = x$.

**Wzór Laplace'a dla ODE obwodów:** $\mathcal{L}\{t^n\} = n!/s^{n+1}$ — części iterowana.

## Przykłady rozwiązane

<Exemplo titulo="Całka kanoniczna xeˣ (podstawowe)" numero="1">

**Problem.** Oblicz $\int x e^x\, dx$.

**Strategia.** LIATE: $x$ jest Algebraiczny, $e^x$ jest Wykładniczy. $u = x$ (upraszcza się przy różniczkowaniu), $dv = e^x\, dx$.

**Rozwiązanie.**

$du = dx$, $v = e^x$.

$$\int x e^x\, dx = x e^x - \int e^x\, dx = x e^x - e^x + C = e^x(x - 1) + C.$$

**Weryfikacja.** Różniczkuj $e^x(x-1) + C$: reguła iloczynu daje $e^x(x-1) + e^x = xe^x$. Prawidłowo.

**Źródło.** [Active Calculus §5.4, Activity 5.4.2](https://activecalculus.org/single/sec-5-4-parts.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Całka z ln x (trick dv = dx)" numero="2">

**Problem.** Oblicz $\int \ln x\, dx$.

**Strategia.** Logarytm sam: $u = \ln x$, $dv = dx$ (wybór nieoczywisty ale prawidłowy).

**Rozwiązanie.**

$du = dx/x$, $v = x$.

$$\int \ln x\, dx = x \ln x - \int x \cdot \frac{1}{x}\, dx = x \ln x - \int 1\, dx = x \ln x - x + C.$$

**Weryfikacja.** Różniczkuj $x \ln x - x$: $\ln x + x \cdot (1/x) - 1 = \ln x + 1 - 1 = \ln x$. Prawidłowo.

**Źródło.** [APEX Calculus §6.2, Example 6.2.2](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Wielomian x² z tabelą DI (średnio zaawansowane)" numero="3">

**Problem.** Oblicz $\int x^2 e^x\, dx$ metodą tabelaryczną.

**Strategia.** Wielomian stopnia 2 × wykładnicza: metoda DI (różniczkuj $x^2$ do zera, całkuj $e^x$ iteracyjnie).

**Rozwiązanie.**

| D | I | Znak |
|---|---|---|
| $x^2$ | $e^x$ | + |
| $2x$ | $e^x$ | − |
| $2$ | $e^x$ | + |
| $0$ | — | — |

Sumując iloczyny przekątne ze zmiennymi znakami:

$$\int x^2 e^x\, dx = x^2 e^x - 2x e^x + 2e^x + C = e^x(x^2 - 2x + 2) + C.$$

**Weryfikacja.** Różniczkując $e^x(x^2 - 2x + 2)$: $e^x(x^2 - 2x + 2) + e^x(2x - 2) = e^x x^2$. Prawidłowo.

**Źródło.** [APEX Calculus §6.2, Example 6.2.4](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Trick: całka, która wraca (eˣ cos x)" numero="4">

**Problem.** Oblicz $I = \int e^x \cos x\, dx$.

**Strategia.** Dwie aplikacje części — całka pojawi się ponownie. Izoluj $I$.

**Rozwiązanie.**

1. aplikacja: $u = \cos x$, $dv = e^x\, dx$, $du = -\sin x\, dx$, $v = e^x$.

$$I = e^x \cos x + \int e^x \sin x\, dx.$$

2. aplikacja: $u = \sin x$, $dv = e^x\, dx$, $du = \cos x\, dx$, $v = e^x$.

$$I = e^x \cos x + e^x \sin x - \int e^x \cos x\, dx = e^x \cos x + e^x \sin x - I.$$

Dlatego $2I = e^x(\cos x + \sin x)$:

$$I = \frac{e^x(\sin x + \cos x)}{2} + C.$$

**Weryfikacja.** Różniczkując: $\frac{e^x(\sin x + \cos x) + e^x(\cos x - \sin x)}{2} = \frac{2e^x \cos x}{2} = e^x \cos x$. Prawidłowo.

**Źródło.** [OpenStax Calculus Vol. 2, §3.1, Example 3.3](https://openstax.org/books/calculus-volume-2/pages/3-1-integration-by-parts) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Całka oznaczona z częściami (wyzwanie)" numero="5">

**Problem.** Oblicz $\int_0^\pi x \sin x\, dx$.

**Strategia.** LIATE: $u = x$, $dv = \sin x\, dx$. Zastosuj części i ewaluuj w granicach.

**Rozwiązanie.**

$du = dx$, $v = -\cos x$.

$$\int_0^\pi x \sin x\, dx = [-x \cos x]_0^\pi + \int_0^\pi \cos x\, dx.$$

$[-x \cos x]_0^\pi = -\pi\cos\pi - 0 = -\pi(-1) = \pi$.

$\int_0^\pi \cos x\, dx = [\sin x]_0^\pi = 0 - 0 = 0$.

Dlatego $\int_0^\pi x \sin x\, dx = \pi + 0 = \pi$.

**Weryfikacja.** Wynik $\pi$ jest klasyczny — potwierdza się numerycznie ($\approx 3{,}1416$). Asymetria znaku $x\sin x$ w $[0, \pi]$ (zawsze pozytywna) gwarantuje dodatni wynik.

**Źródło.** [Active Calculus §5.4, Exercise 5.4.3](https://activecalculus.org/single/sec-5-4-parts.html) — CC-BY-NC-SA.

</Exemplo>
