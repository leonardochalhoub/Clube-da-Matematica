### Problem ogólny

<Definicao titulo="EDO liniowa jednorodna drugiego rzędu ze stałymi współczynnikami">

$$ay'' + by' + cy = 0, \quad a, b, c \in \mathbb{R},\ a \neq 0$$

**Przestrzeń rozwiązań:** Z twierdzenia o istnieniu i jednoznaczności zbiór rozwiązań jest przestrzenią wektorową **wymiaru 2** — dwa liniowo niezależne rozwiązania generują całą rodzinę.

</Definicao>

### Ansatz i równanie charakterystyczne

Podstaw $y = e^{\lambda x}$: $y' = \lambda e^{\lambda x}$, $y'' = \lambda^2 e^{\lambda x}$.

$$a\lambda^2 e^{\lambda x} + b\lambda e^{\lambda x} + c e^{\lambda x} = 0 \;\Rightarrow\; a\lambda^2 + b\lambda + c = 0$$

Ponieważ $e^{\lambda x} \neq 0$, wszystko redukuje się do równania algebraicznego kwadratowego.

<Teorema titulo="Trzy przypadki wyznaczane przez deltę">

Niech $\Delta = b^2 - 4ac$.

**Przypadek 1 — $\Delta > 0$:** pierwiastki rzeczywiste różne $\lambda_1 \neq \lambda_2$.
$$y = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$$

**Przypadek 2 — $\Delta = 0$:** pierwiastek podwójny $\lambda = -b/(2a)$.
$$y = (C_1 + C_2 x)\,e^{\lambda x}$$

**Przypadek 3 — $\Delta < 0$:** pierwiastki zespolone sprzężone $\lambda = \alpha \pm i\beta$, gdzie $\alpha = -b/(2a)$, $\beta = \sqrt{4ac-b^2}/(2a)$.
$$y = e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$$

</Teorema>

> "If $b^2 - 4ac > 0$, the characteristic equation has two distinct real roots $r_1, r_2$, and the general solution of [the ODE] is $y = c_1 e^{r_1 x} + c_2 e^{r_2 x}$." — [Lebl, Notes on Diffy Qs, §2.2](https://www.jirka.org/diffyqs/html/socc_section.html)

### Przypadek pierwiastka podwójnego

<Insight>

Dlaczego pojawia się czynnik $x$? Przy pierwiastku podwójnym $\lambda$, $e^{\lambda x}$ jest rozwiązaniem, ale potrzebujemy drugiego. Redukcja rzędu pokazuje, że $x e^{\lambda x}$ jest drugim rozwiązaniem niezależnym. Sprawdzenie: $(xe^{\lambda x})'' + b/a\,(xe^{\lambda x})' + c/a\,(xe^{\lambda x}) = e^{\lambda x}(a\lambda^2 + b\lambda + c)/a + e^{\lambda x}(2\lambda + b/a) = 0$ gdy $\Delta = 0$.

</Insight>

### Równania niejednorodne

Dla $ay'' + by' + cy = q(x)$: rozwiązanie ogólne $y = y_h + y_p$.

$y_h$: rozwiązanie równania jednorodnego (dwa parametry wolne).

$y_p$: dowolne rozwiązanie szczególne — otrzymane przez **współczynniki do wyznaczenia** (gdy $q$ jest kombinacją wielomianu, funkcji wykładniczej, sinusa/cosinusa) lub **wariację parametrów** (ogólna).

</Porta>

<Porta nivel="5" titulo="Dla dziecka pięcioletniego">

Pomyśl o huśtawce. Pchasz ją i huśta się tam i z powrotem. Pytanie brzmi: jak się porusza w miarę upływu czasu?

Matematycy odkryli, że ruch huśtawki spełnia równanie zawierające $y''$ (jak szybko zmienia się prędkość). Bez tarcia: huśta się wiecznie. Z małym tarciem: huśta się i powoli zatrzymuje. Z dużym tarciem: idzie prosto do spoczynku bez huśtania.

Każdy z tych przypadków odpowiada jednemu z trzech typów rozwiązania naszego równania.

</Porta>

<Porta nivel="10" titulo="Dla dziecka dziesięcioletniego">

Na poprzedniej lekcji rozwiązywaliśmy EDO pierwszego rzędu (tylko $y'$). Teraz mamy $y''$ — przyspieszenie — też.

Sztuczka: test $y = e^{\lambda x}$. Jeśli to zadziała, znajdziesz $\lambda$ rozwiązując **równanie drugiego stopnia** — równanie charakterystyczne.

Mogą się zdarzyć trzy rzeczy:
1. Dwa różne pierwiastki rzeczywiste → suma dwóch funkcji wykładniczych.
2. Pierwiastek podwójny → funkcja wykładnicza pomnożona przez $(C_1 + C_2 x)$.
3. Pierwiastki zespolone → funkcja wykładnicza z sinusami i cosinusami (oscylacja!).

Przypadek 3 jest najpiękniejszy: pojawia się w każdym systemie, który oscyluje — wahadło, sprężyna, obwód LC.

</Porta>

<Porta nivel="15" titulo="Dla nastolatka piętnastoletniego">

$ay'' + by' + cy = 0$ ze stałymi rzeczywistymi $a, b, c$. Rozwiązanie ogólne **zawsze ma dwa parametry wolne** $C_1$ i $C_2$ (warunki początkowe $y(0)$ i $y'(0)$ determinują oba).

### Kompletny algorytm

1. Napisz równanie charakterystyczne: $a\lambda^2 + b\lambda + c = 0$.
2. Oblicz $\Delta = b^2 - 4ac$.
3. Jeśli $\Delta > 0$: $\lambda_{1,2} = (-b \pm \sqrt{\Delta})/(2a)$. Rozwiązanie: $C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$.
4. Jeśli $\Delta = 0$: $\lambda = -b/(2a)$. Rozwiązanie: $(C_1 + C_2 x)e^{\lambda x}$.
5. Jeśli $\Delta < 0$: $\lambda = \alpha \pm i\beta$, z $\alpha = -b/(2a)$, $\beta = \sqrt{-\Delta}/(2a)$. Rozwiązanie: $e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$.

### Dlaczego używać $e^{\alpha x}(\cos\beta x + \sin\beta x)$ zamiast liczb zespolonych?

Ze wzoru Eulera: $e^{(\alpha+i\beta)x} = e^{\alpha x}(\cos\beta x + i\sin\beta x)$. Części rzeczywista i urojona to obie rzeczywiste rozwiązania. Ich rzeczywista kombinacja daje ogólne rozwiązanie rzeczywiste.

### Przykład: $y'' + 4y = 0$

$\lambda^2 + 4 = 0 \Rightarrow \lambda = \pm 2i$. Tu $\alpha = 0$, $\beta = 2$.

$y = C_1\cos 2x + C_2\sin 2x$ — czysta oscylacja.

Z $y(0) = 1$, $y'(0) = 0$: $C_1 = 1$, $C_2 = 0$. $y = \cos 2x$.

</Porta>

<Porta nivel="25" titulo="Dla studenta inżynierii">

### Klasyfikacja systemów drugiego rzędu

Każdy liniowy system drugiego rzędu ze stałymi współczynnikami należy do jednego z trzech reżimów:

| Przypadek | $\Delta$ | Pierwiastki | Zachowanie |
|---|---|---|---|
| Tłumienie nadmierne | $> 0$ | $\lambda_1, \lambda_2 < 0$ | Zanik bez oscylacji |
| Tłumienie krytyczne | $= 0$ | $\lambda$ podwójny, rzeczywisty ujemny | Szybszy zanik bez oscylacji |
| Tłumienie niedostateczne | $< 0$ | $\alpha \pm i\beta$, $\alpha < 0$ | Oscylacja z zaником |
| Bez tłumienia | $= 0$, brak rozpraszania | $\pm i\beta$ (czysto urojone) | Wieczna oscylacja |
| Niestabilny | dowolny | $\text{Re}(\lambda) > 0$ | Wzrost wykładniczy |

### Rozwiązanie niejednorodne — współczynniki do wyznaczenia

Dla $q(x) = $ wielomian, funkcja wykładnicza, sinus/cosinus: zgadnij formę dla $y_p$ i wyznacz współczynniki.

| $q(x)$ | Forma próbna dla $y_p$ (jeśli $\lambda_p$ nie jest pierwiastkiem charakterystycznym) |
|---|---|
| $x^n$ | $A_n x^n + \ldots + A_0$ |
| $e^{kx}$ | $Ae^{kx}$ |
| $\cos\omega x$ lub $\sin\omega x$ | $A\cos\omega x + B\sin\omega x$ |
| $x^n e^{kx}$ | $(A_n x^n + \ldots + A_0)e^{kx}$ |

**Reguła modyfikacji**: jeśli $\lambda_p$ jest pierwiastkiem charakterystycznym krotności $m$, pomnóż próbę przez $x^m$.

### Wariacja parametrów

Ogólnie: $y_p = -y_1 \int \frac{y_2 q}{W}\,dx + y_2 \int \frac{y_1 q}{W}\,dx$, gdzie $W = y_1 y_2' - y_2 y_1'$ to Wronskian.

### Transformacja Laplace'a

$a(s^2 Y - sy_0 - y_0') + b(sY - y_0) + cY = Q(s)$. Rozwiązuje warunki początkowe bezpośrednio, bez rozdzielania $y_h$ i $y_p$.

</Porta>

<Porta nivel="40" titulo="Dla starszego specjalisty">

### Fundament: przestrzeń rozwiązań

Przez Picarda-Lindelöfa, problem wartości początkowej $ay'' + by' + cy = 0$, $y(x_0) = y_0$, $y'(x_0) = y_1$ ma jednoznaczne rozwiązanie globalne (dla stałych współczynników, na całym $\mathbb{R}$). Przestrzeń rozwiązań jest izomorficzna do $\mathbb{R}^2$ poprzez $(y_0, y_1) \mapsto y$.

**Wronskian** $W[y_1, y_2](x) = y_1 y_2' - y_2 y_1'$ jest stały albo identycznie równy zeru (Abel). $W \neq 0$ wtedy i tylko wtedy, gdy $\{y_1, y_2\}$ jest bazą przestrzeni rozwiązań.

### Teoria spektralna

Dla $\mathcal{L} = a\,d^2/dx^2 + b\,d/dx + c$, wartości własne $-\mathcal{L}$ w przestrzeni $L^2([0,\pi])$ z warunkami Dirichleta tworzą spektrum dyskretne $\{\lambda_n\}_{n \geq 1}$ — problem Sturma-Liouville'a. Funkcje własne $\{\sin n\pi x\}$ tworzą bazę ortonormalną: szereg Fouriera.

### Green i sploty

Funkcja Greena $G(x,s)$ operatora $\mathcal{L}$ spełnia $\mathcal{L}G = \delta(x-s)$. Rozwiązanie szczególne równania niejednorodnego to $y_p(x) = \int G(x,s)q(s)\,ds$. Dla $ay'' + by' + cy = q$:

$$G(x,s) = \frac{y_1(s) y_2(x) - y_1(x) y_2(s)}{a\,W(s)}\, H(x-s)$$

gdzie $H$ to Heaviside (przyczynowość).

### Stabilność Lapunowa

Dla $\ddot y + 2\zeta\omega_0\dot y + \omega_0^2 y = 0$: energia całkowita $E = \frac{1}{2}\dot y^2 + \frac{1}{2}\omega_0^2 y^2$. $\dot E = -2\zeta\omega_0 \dot y^2 \leq 0$ (dla $\zeta \geq 0$). Tłumienie krytyczne ($\zeta = 1$) jest najszybsze bez oscylacji — optymalne dla zawieszenia pojazdu.

### Nagroda Nobla i oscylatory

Model oscylatora liniowego drugiego rzędu stanowi fundament całej teorii detekacji fal grawitacyjnych: interferometry LIGO używają rezonatorów drugiego rzędu na częstotliwości 150 Hz. Kip Thorne, Barry Barish i Rainer Weiss otrzymali [Nagrodę Nobla z Fizyki 2017](https://www.nobelprize.org/prizes/physics/2017/summary/) za bezpośrednią detekcję fal grawitacyjnych — zależną od tej teorii.

</Porta>

<Porta nivel="pratica" titulo="Zastosowanie praktyczne">

### Algorytm kieszonkowy

Dla $ay'' + by' + cy = 0$:

1. $\Delta = b^2 - 4ac$.
2. Jeśli $\Delta > 0$: $\lambda = (-b \pm \sqrt{\Delta})/(2a)$ — dwa rzeczywiste. $y = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$.
3. Jeśli $\Delta = 0$: $\lambda = -b/(2a)$. $y = (C_1 + C_2 x)e^{\lambda x}$.
4. Jeśli $\Delta < 0$: $\alpha = -b/(2a)$, $\beta = \sqrt{-\Delta}/(2a)$. $y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$.

### Błędy klasyczne

- Zapomnienie, że $\Delta < 0$ wymaga **części rzeczywistej** w wykładniku: to $e^{\alpha x}\cos\beta x$, a nie $\cos\beta x$.
- Przy pierwiastku podwójnym: pamiętaj o czynniku $x$ w drugim rozwiązaniu.
- Przy narzucaniu warunków początkowych: użyj $y'(0)$ poprawnie — pochodną oblicz przed podstawieniem $x = 0$.

### Model: oscylator elektryczny LC

Obwód LC: $L\ddot q + q/C = 0$, $q(0) = Q_0$, $\dot q(0) = 0$.

$\lambda^2 + 1/(LC) = 0 \Rightarrow \lambda = \pm i/\sqrt{LC} = \pm i\omega_0$.

$q(t) = Q_0\cos(\omega_0 t)$, $i(t) = \dot q = -Q_0\omega_0\sin(\omega_0 t)$.

Częstotliwość rezonansowa: $\omega_0 = 1/\sqrt{LC}$ [rad/s] — podstawa filtrów radiowych.

### Synteza

| EDO | Charakterystyka | Rozwiązanie |
|---|---|---|
| $y'' - 5y' + 6y = 0$ | $\lambda^2-5\lambda+6 = (\lambda-2)(\lambda-3) = 0$ | $C_1 e^{2x} + C_2 e^{3x}$ |
| $y'' - 4y' + 4y = 0$ | $(\lambda-2)^2 = 0$ | $(C_1+C_2 x)e^{2x}$ |
| $y'' + 4y = 0$ | $\lambda = \pm 2i$ | $C_1\cos 2x + C_2\sin 2x$ |
| $y'' + 2y' + 5y = 0$ | $\lambda = -1 \pm 2i$ | $e^{-x}(C_1\cos 2x + C_2\sin 2x)$ |

</Porta>

## Przykłady rozwiązane

<Exemplo titulo="Przypadek 1 — pierwiastkami rzeczywisty różne" numero="1">

**Problem.** Rozwiąż $y'' - 5y' + 6y = 0$, $y(0) = 2$, $y'(0) = 3$.

**Strategia.** $\Delta = 25 - 24 = 1 > 0$: dwa pierwiastkami rzeczywisty różne.

**Rozwiązanie.**

Równanie charakterystyczne: $\lambda^2 - 5\lambda + 6 = (\lambda-2)(\lambda-3) = 0$.

$\lambda_1 = 2$, $\lambda_2 = 3$. Rozwiązanie ogólne: $y = C_1 e^{2x} + C_2 e^{3x}$.

$y(0) = C_1 + C_2 = 2$.

$y'(0) = 2C_1 + 3C_2 = 3$.

System: $C_1 = 3$, $C_2 = -1$.

$$y = 3e^{2x} - e^{3x}$$

**Weryfikacja.** $y'' - 5y' + 6y = (12-15+6\cdot 3)e^{2x} + (-9+15-6)e^{3x} = 12e^{2x} \cdot 0 + 0 = 0$. $y(0) = 3 - 1 = 2$, $y'(0) = 6 - 3 = 3$. Prawidłowo.

**Źródło.** [Lebl, Notes on Diffy Qs, §2.2, Example 2.2.1](https://www.jirka.org/diffyqs/html/socc_section.html) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="Przypadek 2 — pierwiastek podwójny" numero="2">

**Problem.** Rozwiąż $y'' - 4y' + 4y = 0$, $y(0) = 1$, $y'(0) = 0$.

**Strategia.** $\Delta = 16 - 16 = 0$: pierwiastek podwójny.

**Rozwiązanie.**

$\lambda^2 - 4\lambda + 4 = (\lambda-2)^2 = 0$. Pierwiastek podwójny $\lambda = 2$.

$y = (C_1 + C_2 x)e^{2x}$.

$y(0) = C_1 = 1$.

$y'(x) = C_2 e^{2x} + 2(C_1 + C_2 x)e^{2x}$.

$y'(0) = C_2 + 2C_1 = 0 \Rightarrow C_2 = -2$.

$$y = (1 - 2x)e^{2x}$$

**Weryfikacja.** $y' = -2e^{2x} + 2(1-2x)e^{2x} = (2-4x-2)e^{2x} = -4xe^{2x}$. $y'' = -4e^{2x} - 8xe^{2x}$. $y''-4y'+4y = (-4-8x)e^{2x} - 4(-4x)e^{2x} + 4(1-2x)e^{2x} = (-4-8x+16x+4-8x)e^{2x} = 0$. Prawidłowo.

**Źródło.** [Lebl, Notes on Diffy Qs, §2.2, Example 2.2.2](https://www.jirka.org/diffyqs/html/socc_section.html) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="Przypadek 3 — pierwiastkami zespolone sprzężone (oscylacja tłumiona)" numero="3">

**Problem.** Rozwiąż $y'' + 2y' + 5y = 0$, $y(0) = 1$, $y'(0) = 2$.

**Strategia.** $\Delta = 4 - 20 = -16 < 0$: zespolone. $\alpha = -1$, $\beta = 2$.

**Rozwiązanie.**

$\lambda = (-2 \pm \sqrt{-16})/2 = -1 \pm 2i$.

$y = e^{-x}(C_1\cos 2x + C_2\sin 2x)$.

$y(0) = C_1 = 1$.

$y'(x) = -e^{-x}(C_1\cos 2x + C_2\sin 2x) + e^{-x}(-2C_1\sin 2x + 2C_2\cos 2x)$.

$y'(0) = -C_1 + 2C_2 = 2 \Rightarrow 2C_2 = 3 \Rightarrow C_2 = 3/2$.

$$y = e^{-x}\!\left(\cos 2x + \frac{3}{2}\sin 2x\right)$$

**Weryfikacja.** Równanie charakterystyczne ma pierwiastkami $-1 \pm 2i$, oba z częścią rzeczywistą $-1 < 0$: rozwiązanie zanika wykładniczo. $y(0) = 1$, $y'(0) = -1 + 3 = 2$. Prawidłowo.

**Źródło.** [Lebl, Notes on Diffy Qs, §2.2, Example 2.2.3](https://www.jirka.org/diffyqs/html/socc_section.html) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="Niejednorodna przez współczynniki do wyznaczenia" numero="4">

**Problem.** Rozwiąż $y'' - y' - 2y = e^{3x}$.

**Strategia.** $y = y_h + y_p$. Dla $q = e^{3x}$ i $3$ nie jest pierwiastkiem charakterystycznym: próba $y_p = Ae^{3x}$.

**Rozwiązanie.**

$\lambda^2 - \lambda - 2 = (\lambda-2)(\lambda+1) = 0$. $y_h = C_1 e^{2x} + C_2 e^{-x}$.

Próba: $y_p = Ae^{3x}$. Podstaw:

$9Ae^{3x} - 3Ae^{3x} - 2Ae^{3x} = e^{3x} \Rightarrow 4A = 1 \Rightarrow A = 1/4$.

$$y = C_1 e^{2x} + C_2 e^{-x} + \frac{1}{4}e^{3x}$$

**Weryfikacja.** $y_p'' - y_p' - 2y_p = (9/4 - 3/4 - 2/4)e^{3x} = (9-3-2)/4\,e^{3x} = e^{3x}$. Prawidłowo.

**Źródło.** [Lebl, Notes on Diffy Qs, §2.3, Example 2.3.1](https://www.jirka.org/diffyqs/html/uc_section.html) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="Niejednorodna z rezonancją (reguła modyfikacji)" numero="5">

**Problem.** Rozwiąż $y'' - 3y' + 2y = e^{2x}$.

**Strategia.** Spróbuj $y_p = Ae^{2x}$ — ale $\lambda = 2$ jest pierwiastkiem charakterystycznym! Reguła modyfikacji: pomnóż przez $x$.

**Rozwiązanie.**

$\lambda^2 - 3\lambda + 2 = (\lambda-1)(\lambda-2) = 0$. $y_h = C_1 e^x + C_2 e^{2x}$.

$\lambda = 2$ jest pierwiastkiem prostym: spróbuj $y_p = Axe^{2x}$.

$y_p' = Ae^{2x} + 2Axe^{2x}$, $y_p'' = 4Ae^{2x} + 4Axe^{2x}$.

$y_p'' - 3y_p' + 2y_p = (4A + 4Ax)e^{2x} - (3A + 6Ax)e^{2x} + 2Axe^{2x} = Ae^{2x}$.

$A = 1$. Zatem $y_p = xe^{2x}$.

$$y = C_1 e^x + C_2 e^{2x} + xe^{2x}$$

**Weryfikacja.** $y_p = xe^{2x}$: $y_p'' - 3y_p' + 2y_p = (4+4x)e^{2x} - 3(1+2x)e^{2x} + 2xe^{2x} = (4+4x-3-6x+2x)e^{2x} = e^{2x}$. Prawidłowo.

**Źródło.** [Lebl, Notes on Diffy Qs, §2.3, Example 2.3.2](https://www.jirka.org/diffyqs/html/uc_section.html) — CC-BY-SA.

</Exemplo>
