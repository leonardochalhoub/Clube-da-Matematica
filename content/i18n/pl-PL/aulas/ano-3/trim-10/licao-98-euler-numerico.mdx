<Porta nivel="formal" titulo="Wyprowadzenie i analiza błędu">

### Problem wartości początkowej

Dane zagadnienie początkowe:

$$y' = f(x, y), \quad y(x_0) = y_0$$

Chcemy aproksymować $y(x)$ dla $x \in [x_0, X]$ bez jawnego rozwiązania.

### Dyskretyzacja

Podzielmy przedział na $N$ równych podprzedziałów:

$$h = \frac{X - x_0}{N}, \qquad x_n = x_0 + n\,h, \quad n = 0, 1, \ldots, N$$

<Definicao titulo="Metoda Eulera jawna (forward Euler)">

Aproksymacja $y_n \approx y(x_n)$ dana przez rekurencję:

<Equation explicacao="Każdy y_n+1 jest szacowany przez linię całkową do wykresu y w (x_n, y_n), ze nachyleniem f(x_n, y_n)." latex="y_{n+1} = y_n + h\,f(x_n,\, y_n)" />

Geometrycznie: podążamy za tangensem do krzywej rozwiązania przez krok długości $h$.

</Definicao>

> "The simplest numerical method for solving $y' = f(x,y)$, $y(x_0) = y_0$, is *Euler's method*. We replace $y'$ with the difference quotient $(y_{n+1} - y_n)/h$ and evaluate $f$ at $x_n$: this gives $y_{n+1} = y_n + hf(x_n, y_n)$." — [Lebl, Notes on Diffy Qs §1.7](https://www.jirka.org/diffyqs/html/numer_section.html)

### Analiza błędu przez szereg Taylora

<Definicao titulo="Błąd lokalny obcięcia">

Przez rozwinięcie Taylora wokół $x_n$:

$$y(x_n + h) = y(x_n) + h\,y'(x_n) + \frac{h^2}{2}\,y''(\xi_n), \quad \xi_n \in (x_n, x_{n+1})$$

Ponieważ $y' = f(x,y)$, metoda Eulera używa tylko dwóch pierwszych wyrazów. **Błąd lokalny** (na krok) to:

$$e_n = y(x_{n+1}) - y_{n+1} = \frac{h^2}{2}\,y''(\xi_n) = O(h^2)$$

</Definicao>

<Definicao titulo="Błąd globalny obcięcia">

W $N = (X-x_0)/h$ krokach błędy lokalne się akumulują:

$$E = |y(X) - y_N| \leq C\,h \cdot N \cdot e_{\text{lokalny}} = O(h)$$

**Metoda Eulera jest rzędu pierwszego**: zmniejszenie $h$ o połowę zmniejsza błąd globalny o połowę (nie o ćwierć).

</Definicao>

<Teorema titulo="Zbieżność metody Eulera">

Jeśli $f$ jest Lipschitzowska względem $y$ (stała $L$) i $y''$ jest ograniczona przez $M$ na $[x_0, X]$, to:

$$|y(x_n) - y_n| \leq \frac{Mh}{2L}\bigl(e^{L(x_n-x_0)} - 1\bigr)$$

W szczególności, $|y(X) - y_N| \to 0$ gdy $h \to 0$: metoda **zbiega**.

</Teorema>

<Insight>
Metoda Eulera jest jednocześnie najprostsza i najmniej dokładna. Jej wartość pedagogiczna jest ogromna: cała teoria metod jednokrokowych (Runge-Kutta) jest uogólnieniem podstawowej idei "podążania za tangensem". RK4 nie jest cztery razy bardziej skomplikowana — to ta sama idea zastosowana cztery razy z inteligentnymi wagami.
</Insight>

<Porta nivel="5" titulo="Dla pięciolatka">

Wyobraź sobie, że jesteś na mapie i chcesz dotrzeć do skarbu. Nie znasz całej ścieżki, ale wiesz, **w którą stronę teraz wskazać**.

Robisz mały kroczek w tę stronę. Stopp. Patrzysz ponownie, w którą stronę wskazujesz. Robisz kolejny kroczek. Powtarzasz.

Jeśli kroczki będą za duże, zbłądzisz. Jeśli będą za małe, dojdziesz prawie na pewno, ale będzie to trwać bardzo długo.

**Metoda Eulera** robi dokładnie to z równaniami — robi kroczki podążając za kierunkiem, który równanie wskazuje.

</Porta>

<Porta nivel="10" titulo="Dla dziesięciolatka">

Wyobraź sobie, że chcesz wiedzieć, gdzie jest piłeczka, która pada, ale nie znasz dokładnego wzoru. Znasz prędkość w każdej chwili: $v(t) = f(t, x)$.

Metoda Eulera mówi:
1. Zacznij w $x_0$, $t_0$.
2. Prędkość teraz to $v_0 = f(t_0, x_0)$.
3. Zrób kroczek: $x_1 = x_0 + h \times v_0$, $t_1 = t_0 + h$.
4. Powtórz: prędkość w $t_1$ to $v_1 = f(t_1, x_1)$. Zrób kolejny krok: $x_2 = x_1 + h \times v_1$.

Im mniejszy krok $h$, tym dokładniejsze. Całkowity błąd jest proporcjonalny do $h$ — zmniejszenie kroku o połowę zmniejsza błąd o połowę.

</Porta>

<Porta nivel="15" titulo="Dla ucznia szkoły średniej">

**Metoda Eulera** rozwiązuje numerycznie każde równanie różniczkowe zwyczajne 1. rzędu:

$$y' = f(x, y), \quad y(x_0) = y_0$$

**Algorytm:**

1. Wybierz krok $h$ (im mniejszy, tym dokładniejszy i wolniejszy).
2. Dla $n = 0, 1, 2, \ldots, N-1$:
   - Oblicz $f(x_n, y_n)$ — nachylenie w obecnym punkcie.
   - $y_{n+1} = y_n + h \cdot f(x_n, y_n)$
   - $x_{n+1} = x_n + h$

**Dlaczego to działa?** Równanie różniczkowe mówi, że nachylenie krzywej w $(x_n, y_n)$ wynosi $f(x_n, y_n)$. Linia styczna z tym nachyleniem prowadzi nas do oszacowania następnego punktu.

**Szybki przykład:** $y' = y$, $y(0) = 1$, $h = 0{,}1$, chcemy $y(0{,}3)$.

- $y_1 = 1 + 0{,}1 \times 1 = 1{,}1$
- $y_2 = 1{,}1 + 0{,}1 \times 1{,}1 = 1{,}21$
- $y_3 = 1{,}21 + 0{,}1 \times 1{,}21 = 1{,}331$

Dokładnie: $e^{0{,}3} \approx 1{,}3499$. Błąd $\approx 0{,}019$ (1,4%).

</Porta>

<Porta nivel="25" titulo="Dla studenta inżynierii">

Dane zagadnienie początkowe $y' = f(x,y)$, $y(x_0) = y_0$, **Euler jawny** to:

$$y_{n+1} = y_n + h\,f(x_n, y_n)$$

**Analiza stabilności.** Dla równania testowego $y' = \lambda y$ ($\lambda \in \mathbb{C}$):

$$y_{n+1} = (1 + h\lambda)\,y_n$$

Rozwiązanie numeryczne zanika, jeśli $|1 + h\lambda| < 1$. Dla $\lambda = -a + i b$ ($a > 0$): region stabilności to dysk $|1 + h\lambda| < 1$ w płaszczyźnie $h\lambda$. Euler jawny ma **skończony region stabilności** — niestabilny dla dużego $h$ nawet jeśli ODE jest stabilne. To jest fundamentalny problem metody dla równań sztywnych (stiff).

**Euler niejawny:** $y_{n+1} = y_n + h\,f(x_{n+1}, y_{n+1})$ — rozwiąż równanie niejawne dla $y_{n+1}$. Dla równania testowego: $|1/(1-h\lambda)| < 1$ zawsze gdy $\Re(\lambda) < 0$ — **A-stabilny**.

**Metoda Heuna (RK2):**

$$k_1 = f(x_n, y_n), \quad k_2 = f(x_n + h, y_n + h k_1), \quad y_{n+1} = y_n + \frac{h}{2}(k_1 + k_2)$$

Błąd globalny $O(h^2)$. Interpretuj $k_2$ jako nachylenie w punkcie Eulera i uśrednij dwa nachylenia.

**RK4 klasyczne (Runge-Kutta 4. rzędu):**

$$k_1 = f(x_n, y_n), \quad k_2 = f\!\left(x_n + \tfrac{h}{2}, y_n + \tfrac{h}{2}k_1\right)$$
$$k_3 = f\!\left(x_n + \tfrac{h}{2}, y_n + \tfrac{h}{2}k_2\right), \quad k_4 = f(x_n + h, y_n + h k_3)$$
$$y_{n+1} = y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

Błąd globalny $O(h^4)$. Standard przemysłu dla niesztywnych ODE.

</Porta>

<Porta nivel="40" titulo="Dla seniora zawodowego">

Metoda Eulera pochodzi z 1768 roku (opublikowana w *Institutionum calculi integralis*, Vol. I). Analiza błędu przez szereg Taylora i formalna zbieżność zawdzięczają się Cauchyemu (1824). Nowoczesna teoria metod Runge-Kutty została rozwinięta przez Carla Rungego (1895) i Wilhelma Kuttę (1901), którzy wyprowadzili współczynniki RK4 przez porównanie ze skróconą serią Taylora dla $y(x+h)$.

**Perspektywa współczesna.** Metoda Eulera to metoda Runge-Kutty z 1 etapem i 1. rzędem. Ogólna teoria RK jest kodowana w **tablicach Butchera** — macierzach $(A, b, c)$ opisujących wagi i węzły każdej metody. Euler: $A = [0]$, $b = [1]$, $c = [0]$. RK4: tablica $4 \times 4$ z wagami $[1/6, 1/3, 1/3, 1/6]$.

**Sztywność i metody niejawne.** Równania sztywne pojawiają się, gdy jakobian $\partial f/\partial y$ ma wartości własne o bardzo różnych magnitudach. Metody jawne jak Euler wymagają $h$ proporcjonalnego do najmniejszej wartości własnej (najszybszej) — koszt ogromny. Metody A-stabilne (Euler niejawny, Crank-Nicolson, metody BDF) ignorują problem stabilności i używają $h$ proporcjonalnego do skali zainteresowania.

**Zastosowania inżynierskie:** symulacja sieci dystrybucji energii elektrycznej (ANEEL używa PSCAD/EMTP — Euler niejawny z krokiem 10–50 μs), symulacja łańcuchów molekularnych w biochemii (Euler symplektyczny zachowuje pole fazowe), dynamika orbitalna (integratory symplektyczne Yoshidy).

**W Polsce:** rozmaite ośrodki naukowe utrzymują nowoczesne implementacje wszystkich metod z tej lekcji w Pythonie, Matlabie i języku C.

</Porta>

<Porta nivel="pratica" titulo="Zastosowania z danymi polskimi">

**Wzrost startuu w Polsce.** Fintech w Warszawie rośnie w tempie $P'(t) = 0{,}15\,P(1 - P/10000)$ użytkowników na miesiąc (logistyczne, pojemność 10 000). Z $P(0) = 500$, symuluj Eulerem z $h = 1$ miesiąc przez 12 miesięcy.

Krok 0: $f(0, 500) = 0{,}15 \times 500 \times (1 - 500/10000) = 71{,}25$. $P_1 = 500 + 71{,}25 \approx 571$.

Krok 1: $f(1, 571) = 0{,}15 \times 571 \times (1 - 571/10000) \approx 80{,}7$. $P_2 \approx 652$.

Po 12 iteracjach: $P(12) \approx 1\,750$ użytkowników. Dokładne rozwiązanie (logistyczne): $\approx 1\,780$. Błąd: 1,7%.

**Zaopatrzenie — ODE przepływu.** Przepływ $Q(t)$ [m³/h] w zbiorniku wodociągów zmienia się zgodnie z $Q' = -kQ^{0{,}5}$, $Q(0) = 10000$ m³. Z $k = 0{,}02$, Euler z $h = 10$ h: $Q_1 = 10000 - 0{,}02 \times 100 \times 10 = 9980$ m³. Tablica 24 kroków daje $Q(240) \approx 7\,100$ m³.

</Porta>

## Przykłady rozwiązane

<Exemplo numero="98.1" titulo="Euler w 4 krokach — ODE wykładniczy">

**Problem.** Użyj metody Eulera z $h = 0{,}1$ aby aproksymować $y(0{,}4)$ dla $y' = -y$, $y(0) = 1$. Porównaj z wartością dokładną.

**Strategia.** Zastosuj rekurencję $y_{n+1} = y_n + h(-y_n) = y_n(1-h)$ cztery razy.

**Rozwiązanie.**

| $n$ | $x_n$ | $y_n$ | $f = -y_n$ | $y_{n+1}$ |
|---|---|---|---|---|
| 0 | 0 | 1,0000 | -1,0000 | 0,9000 |
| 1 | 0,1 | 0,9000 | -0,9000 | 0,8100 |
| 2 | 0,2 | 0,8100 | -0,8100 | 0,7290 |
| 3 | 0,3 | 0,7290 | -0,7290 | 0,6561 |

$y_4 = 0{,}6561$. Dokładnie: $e^{-0{,}4} \approx 0{,}6703$. Błąd względny: $\approx 2{,}12\%$.

**Weryfikacja.** W każdym kroku mnożymy przez $(1-h) = 0{,}9$, zatem $y_4 = (0{,}9)^4 = 0{,}6561$ $\checkmark$. Błąd rośnie z $h$ — dla $h = 0{,}05$ błąd spadłby do $\approx 1{,}06\%$.

**Źródło.** [Lebl, Notes on Diffy Qs §1.7, Example 1.7.1](https://www.jirka.org/diffyqs/html/numer_section.html) — CC-BY-SA

</Exemplo>

<Exemplo numero="98.2" titulo="Euler w równaniu nieliniowym">

**Problem.** Oszacuj $y(1)$ dla $y' = y^2$, $y(0) = 0{,}5$, używając Eulera z $h = 0{,}25$.

**Strategia.** Dokładne rozwiązanie to $y = 1/(2-x)$ (blow-up w $x = 2$). Z 4 krokami do $x = 1$.

**Rozwiązanie.**

$n=0$: $f(0, 0{,}5) = 0{,}25$. $y_1 = 0{,}5 + 0{,}25 \times 0{,}25 = 0{,}5625$.

$n=1$: $f(0{,}25, 0{,}5625) = 0{,}31641$. $y_2 = 0{,}5625 + 0{,}25 \times 0{,}31641 = 0{,}6416$.

$n=2$: $f(0{,}5, 0{,}6416) = 0{,}4117$. $y_3 = 0{,}6416 + 0{,}25 \times 0{,}4117 = 0{,}7445$.

$n=3$: $f(0{,}75, 0{,}7445) = 0{,}5543$. $y_4 = 0{,}7445 + 0{,}25 \times 0{,}5543 = 0{,}8831$.

Dokładnie: $y(1) = 1/(2-1) = 1$. Błąd: $11{,}7\%$.

**Weryfikacja.** Błąd jest duży, ponieważ $f = y^2$ rośnie i styczne niedoestymują krzywą. Zmniejszenie do $h = 0{,}1$ (10 kroków) zmniejszyłoby do $\approx 5{,}8\%$, potwierdzając rząd 1.

**Źródło.** [OpenStax Calculus Volume 2, §4.2, Example 4.2](https://openstax.org/books/calculus-volume-2/pages/4-2-direction-fields-and-eulers-method) — CC-BY-NC-SA

</Exemplo>

<Exemplo numero="98.3" titulo="Porównanie Euler versus RK4">

**Problem.** Dla $y' = x + y$, $y(0) = 1$, aproksymuj $y(0{,}2)$ z $h = 0{,}1$ używając (a) Eulera i (b) RK4. Dokładne rozwiązanie: $y = 2e^x - x - 1$.

**Strategia.** Zastosuj formuły każdej metody i porównaj błędy.

**Rozwiązanie.**

Dokładnie: $y(0{,}2) = 2e^{0{,}2} - 0{,}2 - 1 \approx 2 \times 1{,}2214 - 1{,}2 = 1{,}2428$.

**(a) Euler:**

$n=0$: $f(0,1) = 1$. $y_1 = 1 + 0{,}1 \times 1 = 1{,}1$.

$n=1$: $f(0{,}1, 1{,}1) = 0{,}1 + 1{,}1 = 1{,}2$. $y_2 = 1{,}1 + 0{,}1 \times 1{,}2 = 1{,}22$.

Błąd Eulera: $|1{,}2428 - 1{,}22| = 0{,}0228$.

**(b) RK4 (krok $n=0 \to n=1$, $h=0{,}1$):**

$k_1 = 0 + 1 = 1$; $k_2 = (0{,}05) + (1 + 0{,}05) = 1{,}1$; $k_3 = 0{,}05 + (1 + 0{,}05) = 1{,}1$; $k_4 = 0{,}1 + (1 + 0{,}1) = 1{,}2$.

$y_1 = 1 + (0{,}1/6)(1 + 2{,}2 + 2{,}2 + 1{,}2) = 1 + 0{,}1 \times 1{,}1\overline{0}\approx 1{,}1103$.

<Exemplo numero="98.4" titulo="Euler niejawny — stabilność w równaniu sztywnym">

**Problem.** $y' = -100y$, $y(0) = 1$. Porównaj Euler jawny z $h = 0{,}03$ (niestabilny) i $h = 0{,}01$ (stabilny).

**Strategia.** Analizuj $|1 + h\lambda|$ z $\lambda = -100$.

**Rozwiązanie.**

Współczynnik amplifikacji Euler jawny: $r = 1 + h\lambda = 1 - 100h$.

- $h = 0{,}03$: $r = 1 - 3 = -2$. $|r| = 2 > 1$ — **niestabilny**: $y_n = (-2)^n \to \pm\infty$.
- $h = 0{,}01$: $r = 1 - 1 = 0$. $|r| = 0 < 1$ — stabilny (na granicy), $y_n = 0$ w 1 kroku (nadtłumienie).
- $h = 0{,}02$: $r = 1 - 2 = -1$. $|r| = 1$ — oscyluje bez tłumienia.

Region stabilności Eulera: $h < 2/|\lambda| = 0{,}02$ dla tego równania. Dokładne rozwiązanie $e^{-100x}$ zanika w $x \sim 0{,}01$ — kroki znacznie mniejsze niż skala zainteresowania.

**Weryfikacja.** Euler niejawny: $r_{imp} = 1/(1-h\lambda) = 1/(1+100h)$. Dla każdego $h > 0$: $|r_{imp}| < 1$ $\checkmark$ — zawsze stabilny.

**Źródło.** [REAMAT UFRGS, Cálculo Numérico §8.4](https://www.ufrgs.br/reamat/CalculoNumerico/livro-py/s_estabilidade_de_metodos_numericos.html) — CC-BY-SA

</Exemplo>

<Exemplo numero="98.5" titulo="Euler dla systemu ODE — oscylator">

**Problem.** System $x' = v$, $v' = -x$ (oscylator harmoniczny), WP: $x(0) = 1$, $v(0) = 0$, $h = 0{,}1$, symuluj 3 kroki.

**Strategia.** Zastosuj Euler do każdej składowej jednocześnie.

**Rozwiązanie.**

Stan: $x_n$, $v_n$. Funkcje $f_1 = v$ i $f_2 = -x$.

Krok 0: $x_0 = 1$, $v_0 = 0$. Nachylenia: $\dot x = 0$, $\dot v = -1$.

$x_1 = 1 + 0.1 \times 0 = 1$; $v_1 = 0 + 0.1 \times (-1) = -0.1$.

Krok 1: $x_1 = 1$, $v_1 = -0.1$. Nachylenia: $\dot x = -0.1$, $\dot v = -1$.

$x_2 = 1 + 0.1 \times (-0.1) = 0.99$; $v_2 = -0.1 + 0.1 \times (-1) = -0.2$.

Krok 2: $x_2 = 0.99$, $v_2 = -0.2$. Nachylenia: $\dot x = -0.2$, $\dot v = -0.99$.

$x_3 = 0.99 + 0.1 \times (-0.2) = 0.97$; $v_3 = -0.2 + 0.1 \times (-0.99) = -0.299$.

Dokładnie w $t = 0.3$: $x = \cos(0.3) \approx 0.9553$, $v = -\sin(0.3) \approx -0.2955$. Euler przeszacowuje $x$ — nie zachowuje energii. Euler symplektyczny rozwiązuje: oblicza $v_{n+1}$ najpierw, potem używa go dla $x_{n+1}$.

**Źródło.** [Lebl, Notes on Diffy Qs §1.7, Exercise 1.7.4](https://www.jirka.org/diffyqs/html/numer_section.html) — CC-BY-SA

</Exemplo>
