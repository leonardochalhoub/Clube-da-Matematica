### Derivación de la fórmula

<Definicao titulo="Integración por partes">

Sean $u(x)$ y $v(x)$ funciones derivables en $[a, b]$, con $u'$ y $v'$ continuas. La regla del producto afirma:

$$\frac{d}{dx}[u(x)v(x)] = u'(x)v(x) + u(x)v'(x).$$

Integrando ambos lados de $a$ a $b$ y aplicando el Teorema Fundamental del Cálculo:

$$[u(x)v(x)]_a^b = \int_a^b u'(x)v(x)\, dx + \int_a^b u(x)v'(x)\, dx.$$

Reorganizando:

$$\int_a^b u(x)v'(x)\, dx = [u(x)v(x)]_a^b - \int_a^b v(x)u'(x)\, dx.$$

En notación diferencial ($dv = v'(x)\, dx$, $du = u'(x)\, dx$):

<Equation explicacao="Fórmula de integración por partes — forma indefinida." latex="\int u\, dv = uv - \int v\, du." />

</Definicao>

> "The formula for integration by parts comes from the product rule for differentiation: if $u$ and $v$ are both functions of $x$, then $(uv)' = u'v + uv'$. Integrating both sides and rearranging gives $\int u\, dv = uv - \int v\, du$." — [Active Calculus §5.4](https://activecalculus.org/single/sec-5-4-parts.html)

### Heurística LIATE

<Definicao titulo="Orden de preferencia para u (LIATE)">

Para elegir $u$ (la función que será derivada), prefiera en orden:

1. **L**ogarítmica: $\ln x$, $\log_a x$
2. **I**nversa trigonométrica: $\arctan x$, $\arcsin x$, $\arccos x$
3. **A**lgebraica: $x^n$, polinomios
4. **T**rigonométrica: $\sin x$, $\cos x$, $\tan x$
5. **E**xponencial: $e^x$, $a^x$

La primera categoría que aparece en el integrando se convierte en $u$. El resto es $dv$.

**Lógica:** logarítmicas e inversas trigonométricas tienen derivadas que se simplifican (de trascendente a algebraica); exponenciales y trig se reproducen al derivar. Luego $u$ debe ser el factor que "mejora" al derivar.

</Definicao>

> "A useful heuristic for deciding which function to call $u$ in integration by parts is the acronym LIATE, which stands for Logarithmic, Inverse trigonometric, Algebraic, Trigonometric, and Exponential functions." — [OpenStax Calculus Vol. 2, §3.1](https://openstax.org/books/calculus-volume-2/pages/3-1-integration-by-parts)

<Teorema titulo="Truco: integral que regresa a sí misma">

Para $I = \int e^x \cos x\, dx$:

Aplica partes con $u = \cos x$, $dv = e^x dx$: $I = e^x \cos x + \int e^x \sin x\, dx$.

Aplica partes nuevamente con $u = \sin x$: $I = e^x \cos x + e^x \sin x - I$.

Portanto $2I = e^x(\cos x + \sin x)$, y:

<Equation explicacao="Resultado del truco cuando la integral original reaparece después de dos aplicaciones." latex="I = \frac{e^x(\sin x + \cos x)}{2} + C." />

**Condición:** el truco funciona cuando la segunda aplicación reproduce la integral original con el mismo signo (y no con signo invertido, que daría identidad nula).

</Teorema>

<Insight>

**Partes es transferencia de derivada.** La identidad $\int u\, dv = uv - \int v\, du$ mueve la operación de diferenciación de un factor al otro. En espacios funcionales con condiciones de frontera nulas, esto hace que $d/dx$ sea antisimétrico en $L^2$ — base de la formulación débil de EDPs.

</Insight>

</Porta>

<Porta nivel="10" titulo="Para un niño de 10 años">

¿Recuerdas que la derivada de un producto tiene dos términos? Si $f = u \cdot v$, entonces $f' = u'v + uv'$.

Ahora imagina que integras ambos lados:

$uv = \int u'v\, dx + \int uv'\, dx$

Reorganizando: $\int uv'\, dx = uv - \int u'v\, dx$.

**Traducción práctica:** cuando tienes un producto para integrar, puedes trocar por $uv$ menos **otra integral**. Si la nueva integral es más simple, ¡ganaste!

**Ejemplo**: $\int x \sin x\, dx$. $x$ es algebraico (se simplifica al derivar: se convierte en $1$). $\sin x$ tiene antiderivada $-\cos x$.

Entonces $u = x$, $dv = \sin x\, dx$. Después de la fórmula: $-x\cos x + \int \cos x\, dx = -x\cos x + \sin x + C$.

**Truco LIATE**: de Log, Inv-trig, Algebraico, Trig, Exp — la primera que aparece se convierte en $u$.

</Porta>

<Porta nivel="15" titulo="Para un adolescente de 15 años">

La fórmula es $\int u\, dv = uv - \int v\, du$.

**Receta en 5 pasos:**

1. Identifica producto en el integrando.
2. Usa **LIATE** para elegir $u$ (Log > Inv-trig > Algebraico > Trig > Exp).
3. El resto es $dv$. Calcula $du = u'\, dx$ y $v = \int dv$.
4. Aplica la fórmula.
5. Resuelve $\int v\, du$ — debe ser más simple.

**Tres patrones fundamentales:**

**1.** $\int x e^x\, dx$: $u = x$ (Algebraico), $dv = e^x dx$. Resultado: $xe^x - e^x + C$.

**2.** $\int \ln x\, dx$: $u = \ln x$ (Log), $dv = dx$. Entonces $du = dx/x$, $v = x$. Resultado: $x \ln x - x + C$.

**3.** $\int e^x \cos x\, dx$: aplica dos veces — la integral regresa. Aísla: resultado $e^x(\sin x + \cos x)/2 + C$.

**Cuándo NO usar partes**: si ves $\int x e^{x^2}\, dx$, es sustitución (cadena disfrazada), no partes.

</Porta>

Partes resuelve sistemáticamente la clase **producto polinomio × (exp, trig, log, inv-trig)**.

### Conexiones fundamentales

- **Laplace**: $\mathcal{L}\{t\} = \int_0^\infty t e^{-st}\, dt = 1/s^2$ — calculado por partes.
- **Función Gamma**: $\Gamma(n+1) = n \Gamma(n)$ — demostrado vía partes + $\Gamma(1) = 1$.
- **Coeficientes de Fourier**: $a_n = (1/\pi)\int_{-\pi}^\pi f(x)\cos(nx)\, dx$ — partes reduce cuando $f$ es polinomial.
- **Transformada de Laplace de $t^n$**: $n!/(s^{n+1})$ — partes iterada.

### Método tabular detallado

Para $\int x^3 e^x\, dx$:

| D | I | Signo |
|---|---|---|
| $x^3$ | $e^x$ | + |
| $3x^2$ | $e^x$ | − |
| $6x$ | $e^x$ | + |
| $6$ | $e^x$ | − |
| $0$ | — | — |

Resultado: $x^3 e^x - 3x^2 e^x + 6x e^x - 6e^x + C = e^x(x^3 - 3x^2 + 6x - 6) + C$.

### Fórmulas de reducción

Vía partes: $\int \sin^n x\, dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n-1}{n}\int \sin^{n-2}x\, dx$.

Ídem para $\cos^n$, $\sec^n$, $\csc^n$.

### Generalización: identidad de Green

En dimensión $n$, integración por partes es:

$$\int_\Omega u\, \nabla \cdot \mathbf{F}\, dV = \int_{\partial\Omega} u\, \mathbf{F} \cdot \mathbf{n}\, dS - \int_\Omega \nabla u \cdot \mathbf{F}\, dV.$$

Para $\mathbf{F} = \nabla v$: primera identidad de Green $\int u\, \Delta v = \oint u\, \partial_n v - \int \nabla u \cdot \nabla v$.

### Formulación débil en FEM

La ecuación de Poisson $-\Delta u = f$ en $\Omega$ con $u|_{\partial\Omega} = 0$ — partes mueve la derivada a la función prueba $v \in H^1_0$:

$$\int_\Omega \nabla u \cdot \nabla v\, dV = \int_\Omega f v\, dV \quad \forall v \in H^1_0(\Omega).$$

Sin esa transferencia vía partes, no existiría formulación variacional. FEniCS, Firedrake, deal.II lo implementan simbólicamente.

### Adjunto de operador diferencial

En $L^2$ con condiciones de frontera nulas: $\langle Du, v\rangle = -\langle u, Dv\rangle$ — $D = d/dx$ es antisimétrico. Generalizando, el adjunto formal de $L = \sum a_k \partial^k$ es $L^* = \sum (-1)^k \partial^k (a_k \cdot)$. Partes lo prueba.

### Análisis de Fourier y suavidad

Partes iterada prueba: $|\hat{f}(n)| = O(n^{-k})$ si y solo si $f \in C^{k-1}$ con $f^{(k)} \in L^1$. Conexión entre suavidad en el espacio físico y decaimiento en frecuencia — central en teoría de wavelets y compresión.

### Mecánica cuántica

Hermiticidad del momento $\hat{p} = -i\hbar\, \partial_x$ requiere $\langle \psi_1 | \hat{p} \psi_2 \rangle = \langle \hat{p}\psi_1 | \psi_2 \rangle$, demostrado vía partes + condición de frontera (función de onda decae a cero en el infinito).

</Porta>

<Porta nivel="pratica" titulo="Aplicación práctica">

**Receta completa:**

1. ¿El integrando tiene producto? Si sí, partes. Si no, considera sustitución.
2. Aplica **LIATE** para $u$.
3. $du = u'\, dx$, $v = \int dv$.
4. $uv - \int v\, du$.
5. Si $\int v\, du$ aún es producto: itera (o usa tabla DI).
6. Si la integral regresó: aísla $I$.
7. Verifica: deriva el resultado — debe reproducir el integrando.

### Aplicaciones brasileñas

**Valor presente de flujo creciente:** una renta $C(t) = t$ mil reales por año, tasa $r = 10\%$, por $T = 5$ años:

$$VP = \int_0^5 t \cdot e^{-0{,}1 t}\, dt.$$

Por partes: $u = t$, $dv = e^{-0{,}1t}\, dt$. Resultado: aproximadamente 9,48 mil reales.

**Esperanza de variable exponencial:** $E[X] = \int_0^\infty x \lambda e^{-\lambda x}\, dx = 1/\lambda$ — partes con $u = x$.

**Fórmula de Laplace para EDOs de circuitos:** $\mathcal{L}\{t^n\} = n!/s^{n+1}$ — partes iterada.

### Errores clásicos

- Olvidar el signo negativo en $-\int v\, du$.
- Elegir $u$ que complica (contra-LIATE).
- No iterar cuando polinomio tiene grado > 1.
- Olvidar $+ C$ en la integral indefinida.

## Ejemplos resolvidos

<Exemplo titulo="Integral canónica xeˣ (básico)" numero="1">

**Problema.** Calcula $\int x e^x\, dx$.

**Estrategia.** LIATE: $x$ es Algebraico, $e^x$ es Exponencial. $u = x$ (se simplifica al derivar), $dv = e^x\, dx$.

**Resolución.**

$du = dx$, $v = e^x$.

$$\int x e^x\, dx = x e^x - \int e^x\, dx = x e^x - e^x + C = e^x(x - 1) + C.$$

**Verificación.** Deriva $e^x(x-1) + C$: regla del producto da $e^x(x-1) + e^x = xe^x$. Correcto.

**Fuente.** [Active Calculus §5.4, Activity 5.4.2](https://activecalculus.org/single/sec-5-4-parts.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Integral de ln x (truco dv = dx)" numero="2">

**Problema.** Calcula $\int \ln x\, dx$.

**Estrategia.** Logarítmico solo: $u = \ln x$, $dv = dx$ (elección no obvia pero correcta).

**Resolución.**

$du = dx/x$, $v = x$.

$$\int \ln x\, dx = x \ln x - \int x \cdot \frac{1}{x}\, dx = x \ln x - \int 1\, dx = x \ln x - x + C.$$

**Verificación.** Deriva $x \ln x - x$: $\ln x + x \cdot (1/x) - 1 = \ln x + 1 - 1 = \ln x$. Correcto.

**Fuente.** [APEX Calculus §6.2, Example 6.2.2](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Polinomio x² con tabla DI (intermedio)" numero="3">

**Problema.** Calcula $\int x^2 e^x\, dx$ por el método tabular.

**Estrategia.** Polinomio de grado 2 × exponencial: método DI (deriva $x^2$ hasta cero, integra $e^x$ repetidamente).

**Resolución.**

| D | I | Signo |
|---|---|---|
| $x^2$ | $e^x$ | + |
| $2x$ | $e^x$ | − |
| $2$ | $e^x$ | + |
| $0$ | — | — |

Sumando productos diagonales con signos alternados:

$$\int x^2 e^x\, dx = x^2 e^x - 2x e^x + 2e^x + C = e^x(x^2 - 2x + 2) + C.$$

**Verificación.** Derivando $e^x(x^2 - 2x + 2)$: $e^x(x^2 - 2x + 2) + e^x(2x - 2) = e^x x^2$. Correcto.

**Fuente.** [APEX Calculus §6.2, Example 6.2.4](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Truco: integral que regresa (eˣ cos x)" numero="4">

**Problema.** Calcula $I = \int e^x \cos x\, dx$.

**Estrategia.** Dos aplicaciones de partes — la integral reaparecerá. Aísla $I$.

**Resolución.**

1.ª aplicación: $u = \cos x$, $dv = e^x\, dx$, $du = -\sin x\, dx$, $v = e^x$.

$$I = e^x \cos x + \int e^x \sin x\, dx.$$

2.ª aplicación: $u = \sin x$, $dv = e^x\, dx$, $du = \cos x\, dx$, $v = e^x$.

$$I = e^x \cos x + e^x \sin x - \int e^x \cos x\, dx = e^x \cos x + e^x \sin x - I.$$

Portanto $2I = e^x(\cos x + \sin x)$:

$$I = \frac{e^x(\sin x + \cos x)}{2} + C.$$

**Verificación.** Derivando: $\frac{e^x(\sin x + \cos x) + e^x(\cos x - \sin x)}{2} = \frac{2e^x \cos x}{2} = e^x \cos x$. Correcto.

**Fuente.** [OpenStax Calculus Vol. 2, §3.1, Example 3.3](https://openstax.org/books/calculus-volume-2/pages/3-1-integration-by-parts) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Integral definida con partes (desafío)" numero="5">

**Problema.** Calcula $\int_0^\pi x \sin x\, dx$.

**Estrategia.** LIATE: $u = x$, $dv = \sin x\, dx$. Aplica partes y evalúa en los límites.

**Resolución.**

$du = dx$, $v = -\cos x$.

$$\int_0^\pi x \sin x\, dx = [-x \cos x]_0^\pi + \int_0^\pi \cos x\, dx.$$

$[-x \cos x]_0^\pi = -\pi\cos\pi - 0 = -\pi(-1) = \pi$.

$\int_0^\pi \cos x\, dx = [\sin x]_0^\pi = 0 - 0 = 0$.

Portanto $\int_0^\pi x \sin x\, dx = \pi + 0 = \pi$.

**Verificación.** El resultado $\pi$ es clásico — se confirma numéricamente ($\approx 3{,}1416$). La asimetría del signo de $x\sin x$ en $[0, \pi]$ (siempre positiva) garantiza resultado positivo.

**Fuente.** [Active Calculus §5.4, Exercise 5.4.3](https://activecalculus.org/single/sec-5-4-parts.html) — CC-BY-NC-SA.

</Exemplo>
