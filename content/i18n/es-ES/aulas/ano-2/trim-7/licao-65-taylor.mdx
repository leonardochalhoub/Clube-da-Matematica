<Porta nivel="formal" titulo="Definición rigurosa y propiedades">

### Polinomio de Taylor

<Definicao titulo="Polinomio de Taylor de orden n">
Sea $f: I \to \mathbb{R}$ con $n$ derivadas en $a \in I$. El **polinomio de Taylor** de orden $n$ en torno de $a$ es
$$P_n(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!} (x - a)^k = f(a) + f'(a)(x-a) + \frac{f''(a)}{2!}(x-a)^2 + \cdots + \frac{f^{(n)}(a)}{n!}(x-a)^n.$$

Cuando $a = 0$, $P_n$ se llama **polinomio de Maclaurin** de $f$.
</Definicao>

> "If $f$ has $n$ derivatives at $x = a$, then the $n$th-order Taylor polynomial of $f$ centered at $a$ is $p_n(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x-a)^k$." — [APEX Calculus §8.6](https://www.apexcalculus.com/downloads)

<Teorema titulo="Unicidad del polinomio de Taylor">
$P_n$ es el único polinomio de grado $\leq n$ tal que $P_n^{(k)}(a) = f^{(k)}(a)$ para $k = 0, 1, \ldots, n$.
</Teorema>

### Residuo de Lagrange

<Definicao titulo="Resto de Taylor (forma de Lagrange)">
Si $f$ tiene $n+1$ derivadas continuas en una vecindad de $a$, el **residuo** $R_n(x) = f(x) - P_n(x)$ satisface
$$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}$$
para algún $\xi$ estrictamente entre $a$ y $x$.
</Definicao>

> "Let $f$ have $n + 1$ derivatives on an open interval $I$ and let $a \in I$. For each $x \in I$ there exists a value $c$ between $a$ and $x$ such that $R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}$." — [OpenStax Calculus Vol. 2 §6.3](https://openstax.org/books/calculus-volume-2/pages/6-3-taylor-and-maclaurin-series)

<Insight titulo="Identidad de Euler vía Taylor">
Sustituyendo $x \to ix$ en la serie de $e^x$:
$$e^{ix} = \sum_{k=0}^\infty \frac{(ix)^k}{k!} = \underbrace{\sum_{k=0}^\infty \frac{(-1)^k x^{2k}}{(2k)!}}_{\cos x} + i\underbrace{\sum_{k=0}^\infty \frac{(-1)^k x^{2k+1}}{(2k+1)!}}_{\sin x}.$$
Luego $e^{ix} = \cos x + i\sin x$. En $x = \pi$: $e^{i\pi} + 1 = 0$ — la identidad de Euler.
</Insight>

Imagina una curva **toda tortuosa**. Quieres **copiarla** cerca de un punto, pero solo puedes usar una regla y un lápiz.

Colocas la regla igual a la inclinación de la curva en ese punto. ¡Ya se parece!

Si también usas un **arco de círculo** para ajustar la curvatura, se parece aún más.

Cada **cosa que añades** (inclinación, curvatura, siguiente cosa...) hace la copia más fiel. El polinomio de Taylor es la **receta de copia perfecta** — cuantos más términos, mejor.

<Porta nivel="10" titulo="Para un niño de 10 años">

La idea es simple: cualquier función "buena" puede ser **imitada por un polinomio** cerca de un punto.

La fórmula de Maclaurin (cuando el punto es $0$) es:

$$f(x) \approx f(0) + f'(0)\cdot x + \frac{f''(0)}{2}\cdot x^2 + \frac{f'''(0)}{6}\cdot x^3 + \cdots$$

Cada nuevo término usa una derivada más. Más términos = mejor imitación.

**Ejemplo con seno:** En $x = 0$: $\sin 0 = 0$, $\cos 0 = 1$, $-\sin 0 = 0$, $-\cos 0 = -1$, ...

Entonces $\sin x \approx x - x^3/6 + x^5/120 - \cdots$

Para $x$ pequeño, $\sin x \approx x$ ya funciona — error menor que $0{,}2\%$ para $x < 0{,}1$ rad!

</Porta>

<Porta nivel="15" titulo="Para un adolescente de 15 años">

Taylor es el **puente entre funciones arbitrarias y polinomios** — los más fáciles de calcular.

**Receta:**
1. Elige un punto $a$ (casi siempre $a = 0$ — serie de Maclaurin).
2. Calcula $f(a),\, f'(a),\, f''(a),\, \ldots,\, f^{(n)}(a)$.
3. Arma $P_n(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x-a)^k$.

**Series que todo estudiante debe memorizar:**

- $e^x = 1 + x + x^2/2 + x^3/6 + \cdots$
- $\sin x = x - x^3/6 + x^5/120 - \cdots$
- $\cos x = 1 - x^2/2 + x^4/24 - \cdots$
- $\ln(1+x) = x - x^2/2 + x^3/3 - \cdots$ para $|x| < 1$

**Tres aplicaciones inmediatas:**

- **Aproximar valores:** $\sin(0{,}1) \approx 0{,}1 - 0{,}001/6 \approx 0{,}09983$.
- **Resolver límites:** $\lim_{x\to 0}\frac{e^x - 1 - x}{x^2} = \lim_{x\to 0}\frac{x^2/2 + O(x^3)}{x^2} = \frac{1}{2}$.
- **Ingeniería:** $\sin\theta \approx \theta$ para péndulo de ángulo pequeño — simplifica la ecuación diferencial.

</Porta>

<Porta nivel="25" titulo="Para un estudiante de ingeniería">

Taylor es el **instrumento quirúrgico del ingeniero**: sin él, no hay linealización, no hay análisis de pequeñas señales, no hay Newton-Raphson, no hay Runge-Kutta.

### Formas del residuo

$$f(x) = P_n(x) + R_n(x)$$

**Lagrange:** $R_n = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}$, algún $\xi$ entre $a$ y $x$.

**Integral:** $R_n = \int_a^x \frac{(x-t)^n}{n!} f^{(n+1)}(t)\, dt$.

**Big-O:** $R_n = O((x-a)^{n+1})$ — lectura rápida de orden de error.

### Aplicaciones prácticas

- **Linealización:** $f(x) \approx f(x_0) + f'(x_0)(x - x_0)$ — base de análisis de pequeñas señales en electrónica y control.
- **Newton-Raphson:** usa Taylor de orden 1: $f(x) \approx f(x_n) + f'(x_n)(x - x_n) = 0$ da $x_{n+1} = x_n - f(x_n)/f'(x_n)$.
- **Runge-Kutta:** deducido vía Taylor multivariado en $t$ e $y$; RK4 tiene error global $O(h^4)$.
- **Relaciones de dispersión:** $\omega(k) \approx \omega_0 + v_g(k - k_0) + \cdots$ — velocidad de grupo como coeficiente de Taylor.

### Taylor multivariado (orden 2)

$$f(\vec x) \approx f(\vec a) + \nabla f(\vec a)^T (\vec x - \vec a) + \tfrac{1}{2}(\vec x - \vec a)^T H(\vec a)(\vec x - \vec a)$$

donde $H$ es la **hessiana**. Crítico para optimización numérica.

### Convergencia: ni siempre garantizada

$f(x) = e^{-1/x^2}$ (con $f(0) = 0$) tiene todas las derivadas nulas en $0$, por lo tanto $P_n = 0$ para todo $n$. Pero $f \neq 0$ — función suave pero **no-analítica**. Taylor converge, pero NO converge a $f$.

</Porta>

<Porta nivel="40" titulo="Para un profesional sénior">

Taylor es el embrión de análisis compleja, teoría de perturbación, física matemática y optimización de segundo orden.

### Análisis compleja: funciones holomorfas son analíticas

Toda función **holomorfa** $f: \Omega \to \mathbb{C}$ es igual a su serie de Taylor en cualquier disco abierto donde está definida (Cauchy, 1820s). Esto es radicalmente más fuerte que en $\mathbb{R}$: suavidad real ($C^\infty$) no garantiza analiticidad; holomorfismo garantiza. La belleza está en esa rigidez.

### Perturbación cuántica

$H = H_0 + \lambda V$: auto-energía expandida en serie de Taylor en $\lambda$: $E_n(\lambda) = E_n^{(0)} + \lambda E_n^{(1)} + \lambda^2 E_n^{(2)} + \cdots$ Coeficientes vía Rayleigh-Schrödinger. Es Taylor aplicado en espacio de operadores.

### Series asintóticas vs. convergentes

Stirling: $\ln(n!) \sim n\ln n - n + \tfrac{1}{2}\ln(2\pi n) + \sum_k B_{2k}/(2k(2k-1)n^{2k-1})$. Esta serie **diverge** para todo $n$ fijo, pero truncada da excelente aproximación numérica. Diferencia filosófica: una serie puede ser útil incluso divergente — el error decrece antes de explotar.

### Aproximantes de Padé

Aproximación racional $f(x) \approx P_m(x)/Q_n(x)$ supera Taylor en radio efectivo para funciones con singularidades. Usados en mecánica cuántica (método de Padé-Borel) y aceleración de convergencia de series.

### Contexto histórico

Brook Taylor (1715) publica *Methodus Incrementorum* sin prueba de convergencia. Maclaurin (1742) populariza $a = 0$. Lagrange (1797) formaliza el residuo. Cauchy (1820s) prueba rigurosamente vía integral de contorno. Toda esta máquina llegó lista para Maxwell construir electromagnetismo y para Einstein linealizar la geodésica en torno de métrica plana.

</Porta>

<Porta nivel="pratica" titulo="Aplicación práctica">

**Receta en 4 pasos:**

1. **Identifica el punto** de expansión $a$ (generalmente $0$).
2. **Calcula derivadas** $f(a), f'(a), f''(a), \ldots$ hasta el orden deseado.
3. **Arma** $P_n(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x-a)^k$.
4. **Estima el error**: para serie alternada decreciente, $|R_n| < $ valor absoluto del primer término omitido.

### Trucos operacionales

- **Sustituye:** $\sin(x^2) = x^2 - (x^2)^3/6 + \cdots = x^2 - x^6/6 + \cdots$ — directo de la serie de sin.
- **Multiplica:** $e^x \sin x = (1 + x + x^2/2 + \cdots)(x - x^3/6 + \cdots)$, expande hasta el orden.
- **Integra/deriva:** $\arctan x = \int_0^x \frac{1}{1+t^2}\, dt = \int_0^x (1 - t^2 + t^4 - \cdots)\, dt = x - x^3/3 + x^5/5 - \cdots$

### Contexto brasileño — tasa de interés

En finanzas, $(1 + r)^n \approx 1 + nr$ para tasa $r$ pequeña (Taylor de orden 1). Error relativo: aproximadamente $\binom{n}{2} r^2$. Para $r = 1\%$ al mes y $n = 12$ meses: error $\approx 66 \times 0{,}0001 = 0{,}66\%$ — despreciable para estimación rápida de retorno anual.

## Ejemplos resolvidos

<Exemplo titulo="Maclaurin de e^x hasta orden 4 (aplicación directa)" numero="1">

**Problema.** Encuentra el polinomio de Maclaurin de $f(x) = e^x$ de orden 4 y estima el error en $x = 0{,}5$.

**Estrategia.** Como $\frac{d^k}{dx^k}e^x = e^x$, todas las derivadas en $a = 0$ valen $1$. Armar $P_4$ directamente. Usar residuo de Lagrange con $f^{(5)} = e^x$.

**Resolución.**

1. **Derivadas en $0$:** $f^{(k)}(0) = e^0 = 1$ para todo $k$.
2. **Polinomio:** $P_4(x) = 1 + x + \dfrac{x^2}{2} + \dfrac{x^3}{6} + \dfrac{x^4}{24}$.
3. **Error en $x = 0{,}5$:** $|R_4(0{,}5)| \leq \dfrac{e^\xi}{5!}(0{,}5)^5 \leq \dfrac{e^{0{,}5}}{120}\cdot\dfrac{1}{32} \approx \dfrac{1{,}649}{120 \cdot 32} \approx 0{,}000430$.
4. **Valor aproximado:** $P_4(0{,}5) = 1 + 0{,}5 + 0{,}125 + 0{,}02083 + 0{,}002604 \approx 1{,}6484$. Valor exacto: $e^{0{,}5} \approx 1{,}6487$ — error menor que $3 \times 10^{-4}$. $\checkmark$

**Verificación.** El error estimado $4{,}3 \times 10^{-4}$ es mayor que el error real $3 \times 10^{-4}$: el residuo de Lagrange es un mayorante. $\checkmark$

**Fuente.** [OpenStax Calculus Vol. 2, §6.3, Example 6.17](https://openstax.org/books/calculus-volume-2/pages/6-3-taylor-and-maclaurin-series) — CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="Taylor de ln x en torno de a = 1 (intermedio)" numero="2">

**Problema.** Obtén el polinomio de Taylor de orden 3 de $f(x) = \ln x$ centrado en $a = 1$.

**Estrategia.** Calcular $f, f', f'', f'''$ en $x = 1$. Armar $P_3$ con $(x - 1)$ como variable.

**Resolución.**

1. **Derivadas:** $f(x) = \ln x$, $f'(x) = 1/x$, $f''(x) = -1/x^2$, $f'''(x) = 2/x^3$.
2. **En $a = 1$:** $f(1) = 0$, $f'(1) = 1$, $f''(1) = -1$, $f'''(1) = 2$.
3. **Polinomio:**
$$P_3(x) = 0 + 1\cdot(x-1) + \frac{-1}{2!}(x-1)^2 + \frac{2}{3!}(x-1)^3 = (x-1) - \frac{(x-1)^2}{2} + \frac{(x-1)^3}{3}.$$
4. **Test en $x = 1{,}1$:** $P_3(1{,}1) = 0{,}1 - 0{,}005 + 0{,}000333 \approx 0{,}09533$. Valor exacto: $\ln(1{,}1) \approx 0{,}09531$. $\checkmark$

**Verificación.** La serie de $\ln(1+u) = u - u^2/2 + u^3/3 - \cdots$ con $u = x - 1$ coincide con $P_3$. $\checkmark$

**Fuente.** [Active Calculus §8.5, Activity 8.5.3](https://activecalculus.org/single/sec-8-5-taylor.html) — CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="Límite vía Taylor: lim (sin x - x)/x^3 (intermedio)" numero="3">

**Problema.** Calcula $\displaystyle\lim_{x \to 0} \frac{\sin x - x}{x^3}$.

**Estrategia.** Sustituir la serie de Maclaurin de $\sin x$ en el numerador y simplificar. Evita reglas de L'Hôpital iteradas.

**Resolución.**

1. **Serie:** $\sin x = x - \dfrac{x^3}{6} + \dfrac{x^5}{120} - \cdots$
2. **Numerador:** $\sin x - x = -\dfrac{x^3}{6} + \dfrac{x^5}{120} - \cdots$
3. **División por $x^3$:** $\dfrac{\sin x - x}{x^3} = -\dfrac{1}{6} + \dfrac{x^2}{120} - \cdots$
4. **Límite:** al tomar $x \to 0$, todos los términos con $x$ van a cero. El límite es $\mathbf{-1/6}$.

**Verificación.** Aplicando L'Hôpital tres veces también daría $-1/6$, pero el método de Taylor es más rápido. $\checkmark$

**Fuente.** [OpenStax Calculus Vol. 2, §6.3, Example 6.20](https://openstax.org/books/calculus-volume-2/pages/6-3-taylor-and-maclaurin-series) — CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="Error de aproximacion sin x ≈ x para pendulo (modelado)" numero="4">

**Problema.** Un péndulo usa la aproximación $\sin\theta \approx \theta$. Para $\theta = 15° = \pi/12$ rad, ¿cuál es el error relativo porcentual?

**Estrategia.** Calcular $\sin(\pi/12)$ exactamente y comparar con $\pi/12$. Estimar el error vía el próximo término de la serie: $-\theta^3/6$.

**Resolución.**

1. **Ángulo en radianes:** $\theta = \pi/12 \approx 0{,}2618$ rad.
2. **Valor exacto:** $\sin(\pi/12) = \sin(15°) = (\sqrt{6} - \sqrt{2})/4 \approx 0{,}2588$.
3. **Aproximación:** $\theta = 0{,}2618$.
4. **Error absoluto:** $|0{,}2618 - 0{,}2588| = 0{,}0030$.
5. **Error relativo:** $0{,}0030 / 0{,}2588 \approx 1{,}16\%$.
6. **Vía Taylor:** error $\approx \theta^3/6 = (0{,}2618)^3/6 \approx 0{,}00298$ — muy próximo al error calculado. $\checkmark$

**Verificación.** Para $\theta < 0{,}1$ rad ($\approx 5{,}7°$), el error cae bajo $0{,}017\%$ — justificando el uso en ingeniería. $\checkmark$

**Fuente.** [APEX Calculus §8.6, Exercise 8.6.13](https://www.apexcalculus.com/downloads) — CC-BY-NC.
</Exemplo>

<Exemplo titulo="Maclaurin por composicion: e^(sin x) hasta orden 3 (avanzado)" numero="5">

**Problema.** Obtén el polinomio de Maclaurin de $f(x) = e^{\sin x}$ hasta orden 3.

**Estrategia.** Sustituir la serie de $\sin x$ en la serie de $e^u$, agrupando términos hasta $x^3$.

**Resolución.**

1. **Serie de sin:** $\sin x = x - x^3/6 + O(x^5)$.
2. **$u = \sin x$:** entonces $e^u = 1 + u + u^2/2 + u^3/6 + O(u^4)$.
3. **Sustituyendo:** $u = x - x^3/6 + \cdots$, luego:
   - $u = x - x^3/6$
   - $u^2 = x^2 - 2x\cdot x^3/6 + \cdots = x^2 + O(x^4)$
   - $u^3 = x^3 + O(x^5)$
4. **Montaje:**
$$e^{\sin x} = 1 + \left(x - \tfrac{x^3}{6}\right) + \frac{x^2}{2} + \frac{x^3}{6} + O(x^4) = 1 + x + \frac{x^2}{2} + 0 \cdot x^3 + O(x^4).$$
5. **Resultado:** $P_3(x) = 1 + x + \dfrac{x^2}{2}$.

**Verificación.** En $x = 0$: $f(0) = e^0 = 1$ $\checkmark$. $f'(0) = e^{\sin 0}\cos 0 = 1$ $\checkmark$. $f''(0) = e^{\sin 0}(\cos^2 0 - \sin 0) = 1$ $\checkmark$.

**Fuente.** [APEX Calculus §8.6, Exercises 8.6.17–8.6.20](https://www.apexcalculus.com/downloads) — CC-BY-NC.
</Exemplo>
