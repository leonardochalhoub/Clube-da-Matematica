### Identités fondamentales

<Definicao titulo="Identités utilisées dans les intégrales trigonométriques">

Les identités suivantes sont les outils essentiels :

- **Pythagore :** $\sin^2 x + \cos^2 x = 1$ ; $1 + \tan^2 x = \sec^2 x$ ; $1 + \cot^2 x = \csc^2 x$.
- **Puissance paire (half-angle) :**

<Equation explicacao="Réduit sin² et cos² aux fonctions d'angle double — indispensable pour les exposants pairs." latex="\sin^2 x = \frac{1 - \cos 2x}{2}, \qquad \cos^2 x = \frac{1 + \cos 2x}{2}." />

- **Produit vers somme :** $\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$.

</Definicao>

### Motifs pour $\int \sin^n x \cos^m x\, dx$

<Definicao titulo="Stratégie selon la parité des exposants">

| Situation | Stratégie |
|---|---|
| $n$ impair | Réservez $\sin x\, dx$ ; convertissez $\sin^{n-1}$ via $\sin^2 = 1 - \cos^2$ ; substituez $u = \cos x$ |
| $m$ impair | Réservez $\cos x\, dx$ ; convertissez $\cos^{m-1}$ via $\cos^2 = 1 - \sin^2$ ; substituez $u = \sin x$ |
| Les deux pairs | Utilisez half-angle répétées |

Pour $\int \tan^n x \sec^m x\, dx$ :

| Situation | Stratégie |
|---|---|
| $m$ pair | Réservez $\sec^2 x\, dx$ ; convertissez via $\sec^2 = 1 + \tan^2$ ; sub $u = \tan x$ |
| $n$ impair | Réservez $\sec x \tan x\, dx$ ; convertissez via $\tan^2 = \sec^2 - 1$ ; sub $u = \sec x$ |

</Definicao>

> "The strategy for integrating a product of powers of sine and cosine depends on the parities of the exponents involved. When one of the exponents is odd, we 'peel off' one factor and use the Pythagorean identity to convert the remaining even power." — [OpenStax Calculus Vol. 2, §3.2](https://openstax.org/books/calculus-volume-2/pages/3-2-trigonometric-integrals)

> "The idea behind trigonometric substitution is to replace an expression involving a square root with a trigonometric expression, which is easier to integrate." — [APEX Calculus §6.4](https://www.apexcalculus.com/apex-calculus-v5.pdf)

### Formules de réduction

<Teorema titulo="Formule de réduction pour sinⁿ">

$$\int \sin^n x\, dx = -\frac{\sin^{n-1}x \cos x}{n} + \frac{n-1}{n}\int \sin^{n-2}x\, dx.$$

Des formules analogues existent pour $\cos^n$, $\tan^n$, $\sec^n$, $\csc^n$.

**Démonstration :** intégration par parties avec $u = \sin^{n-1}x$, $dv = \sin x\, dx$, plus l'identité $\sin^2 = 1 - \cos^2$.

</Teorema>

<Insight>

**Substitution de Weierstrass** (universelle) : $t = \tan(x/2)$ convertit toute intégrale rationnelle en $\sin x$, $\cos x$ en une intégrale rationnelle en $t$. Via les fractions partielles, tout devient élémentaire — mais le résultat peut être compliqué. Utilisez quand les autres stratégies échouent.

</Insight>

<Porta nivel="5" titulo="Pour un enfant de 5 ans">

Vous savez quand vous mettez un déguisement de fantôme pour que personne ne vous reconnaisse, puis vous l'enlevez ? La substitution trig, c'est comme ça.

Vous avez $\sqrt{1 - x^2}$ — difficile à manipuler. Vous remplacez $x$ par $\sin\theta$ — déguisement ! Le radical disparaît et devient $\cos\theta$. Après calcul avec $\theta$, vous enlevez le déguisement et revenez à $x$.

</Porta>

<Porta nivel="10" titulo="Pour un enfant de 10 ans">

Il y a une identité que vous connaissez : $\sin^2\theta + \cos^2\theta = 1$.

Cela signifie que $\sqrt{1 - \sin^2\theta} = \cos\theta$ (en supposant que $\cos\theta \geq 0$).

Donc si vous avez $\sqrt{1 - x^2}$ et vous faites $x = \sin\theta$, le radical disparaît et devient $\cos\theta$.

Après intégration avec $\theta$, vous utilisez un triangle : si $\sin\theta = x$ et l'hypoténuse est 1, le côté adjacent est $\sqrt{1 - x^2}$. Cela vous donne $\cos\theta$, $\tan\theta$, etc. en termes de $x$ — et vous « défaites » la substitution.

</Porta>

### Puissances de sinus et cosinus

**Cas 1 (exposant impair) :** $\int \sin^3 x\, dx$.

Réservez un $\sin x\, dx$, convertissez le reste : $\sin^2 x = 1 - \cos^2 x$.

$\int (1 - \cos^2 x)\sin x\, dx$. Sub $u = \cos x$ : $-\int(1 - u^2)\, du = -u + u^3/3 + C = -\cos x + \cos^3 x/3 + C$.

**Cas 2 (exposants pairs) :** $\int \sin^2 x\, dx$.

Utilisez half-angle : $\int \frac{1 - \cos 2x}{2}\, dx = \frac{x}{2} - \frac{\sin 2x}{4} + C$.

### Substitution trigonométrique

**Exemple :** $\int \sqrt{1 - x^2}\, dx$.

Sub $x = \sin\theta$, $dx = \cos\theta\, d\theta$, $\sqrt{1-x^2} = \cos\theta$.

L'intégrale devient $\int \cos^2\theta\, d\theta = \theta/2 + \sin(2\theta)/4 + C$.

Revenez : $\theta = \arcsin x$, $\sin(2\theta) = 2\sin\theta\cos\theta = 2x\sqrt{1-x^2}$.

Résultat : $\dfrac{\arcsin x}{2} + \dfrac{x\sqrt{1-x^2}}{2} + C$.

**Triangle de référence :** dessinez toujours — c'est la clé pour convertir les fonctions trig de $\theta$ de retour à $x$.

</Porta>

<Porta nivel="25" titulo="Pour un étudiant en ingénierie">

### Tableau mental des intégrales de base

- $\int \sin^2 x\, dx = (x - \sin x\cos x)/2 + C$.
- $\int \cos^2 x\, dx = (x + \sin x\cos x)/2 + C$.
- $\int \tan x\, dx = -\ln\lvert\cos x\rvert + C = \ln\lvert\sec x\rvert + C$.
- $\int \cot x\, dx = \ln\lvert\sin x\rvert + C$.
- $\int \sec x\, dx = \ln\lvert\sec x + \tan x\rvert + C$.
- $\int \csc x\, dx = -\ln\lvert\csc x + \cot x\rvert + C$.
- $\int \sec^2 x\, dx = \tan x + C$ ; $\int \csc^2 x\, dx = -\cot x + C$.
- $\int \sec x\tan x\, dx = \sec x + C$.

### Connexions d'ingénierie

- **RMS d'une sinusoïde :** $V_{rms} = V_0/\sqrt{2}$ — via $\int_0^T \sin^2(\omega t)\, dt = T/2$.
- **Distribution de Cauchy :** $\int_{-\infty}^\infty 1/(\pi(1+x^2))\, dx = 1$ — sub $x = \tan\theta$.
- **Longueur d'arc d'une ellipse :** $\int \sqrt{1 - k^2\sin^2\theta}\, d\theta$ — intégrale elliptique, sans formule fermée.
- **Coefficients de Fourier :** $a_n = (1/\pi)\int_{-\pi}^\pi f(x)\cos(nx)\, dx$ — pour $f$ trig, calcul direct par identités.

### Euler et identité complexe

Les puissances de $\sin x$ et $\cos x$ se calculent via Euler : $\sin x = (e^{ix} - e^{-ix})/(2i)$, $\cos x = (e^{ix} + e^{-ix})/2$. Expansion binomiale + intégration d'exponentielles complexes, puis partie réelle/imaginaire.

</Porta>

<Porta nivel="40" titulo="Pour un professionnel senior">

### Substitution de Weierstrass (universelle)

$t = \tan(x/2)$ transforme toute fonction rationnelle en $\sin x$ et $\cos x$ en rationnelle en $t$ :

$$\sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2\,dt}{1+t^2}.$$

L'intégrale résultante se résout par fractions partielles. Cependant le résultat peut être plus compliqué que les méthodes directes — utilisez quand les autres stratégies échouent ou en CAS.

### Intégrales elliptiques

$\int \sqrt{1 - k^2\sin^2\theta}\, d\theta = E(k)$ et $\int d\theta/\sqrt{1 - k^2\sin^2\theta} = K(k)$ — intégrales elliptiques de Legendre. Ne sont pas élémentaires pour $k \neq 0$. Surgissent dans la longueur d'une ellipse, le pendule exact, la gravitation.

### Analyse de Fourier

Les coefficients $a_n, b_n$ d'une série de Fourier généralisée se calculent via les intégrales trig. La régularité de $f$ contrôle la décroissance de $|a_n|$, $|b_n|$ — l'analyse de Fourier connecte les intégrales trig à la théorie de l'approximation.

### Géométrie différentielle

Longueur d'arc $L = \int \sqrt{1 + (f')^2}\, dx$ implique la sub trig quand $f' = \tan\theta$. Courbure $\kappa = |f''|/(1 + (f')^2)^{3/2}$ apparaît intégrée quand on calcule la longueur d'arc en coordonnées naturelles. Sub trig en plusieurs variables : coordonnées sphériques et cylindriques sont jacobiennes trig.

</Porta>

<Porta nivel="pratica" titulo="Application pratique">

**Recette pour les intégrales trig :**

1. Regardez les exposants de $\sin$ et $\cos$.
2. L'un est impair ? Réservez une copie de ce facteur avec son $dx$, convertissez le reste.
3. Les deux pairs ? Utilisez $\sin^2 = (1 - \cos 2x)/2$ et $\cos^2 = (1 + \cos 2x)/2$.
4. Radical $\sqrt{a^2 \pm x^2}$ ou $\sqrt{x^2 - a^2}$ ? Appliquez la sub trig du tableau.
5. Après sub trig, dessinez le triangle de référence pour revenir à $x$.
6. Vérifiez en dérivant.

### Aire du cercle — validation canonique

$A = 4\int_0^r \sqrt{r^2 - x^2}\, dx$. Sub $x = r\sin\theta$ : l'intégrale devient $4r^2\int_0^{\pi/2}\cos^2\theta\, d\theta = 4r^2\cdot\pi/4 = \pi r^2$.

### RMS d'une sinusoïde — circuits

Tension $v(t) = V_0\sin(\omega t)$ sur une période $T = 2\pi/\omega$ :

$$V_{rms} = \sqrt{\frac{1}{T}\int_0^T V_0^2\sin^2(\omega t)\, dt} = V_0\sqrt{\frac{1}{2}} = \frac{V_0}{\sqrt{2}} \approx 0{,}707\, V_0.$$

### Erreurs courantes

- Oublier la jacobienne $dx \to a\cos\theta\, d\theta$ (ou $a\sec^2\theta\, d\theta$) — cause un facteur $a$ manquant.
- Ne pas revenir de $\theta$ à $x$ avec le triangle.
- Confondre $\sin^2 x$ (puissance) avec $\sin(2x)$ (angle doublé).
- Avec $x = a\sec\theta$, oublier la branche correcte de $\theta$.

</Porta>

## Exemplos resolvidos

<Exemplo titulo="Potência ímpar de seno (básico)" numero="1">

**Problema.** Calcule $\int \sin^3 x\, dx$.

**Estratégia.** Expoente ímpar: reserve $\sin x\, dx$, converta $\sin^2 = 1 - \cos^2$, substitua $u = \cos x$.

**Resolução.**

$\int \sin^3 x\, dx = \int \sin^2 x \cdot \sin x\, dx = \int (1 - \cos^2 x)\sin x\, dx$.

Sub $u = \cos x$, $du = -\sin x\, dx$:

$-\int (1 - u^2)\, du = -u + u^3/3 + C = -\cos x + \frac{\cos^3 x}{3} + C$.

**Verificação.** Derivando: $\sin x - \cos^2 x\sin x = \sin x(1 - \cos^2 x) = \sin^3 x$. Correto.

**Fonte.** [APEX Calculus §6.3, Example 6.3.1](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Expoentes pares — half-angle (básico)" numero="2">

**Problema.** Calcule $\int \sin^2 x \cos^2 x\, dx$.

**Estratégia.** Ambos pares: use $\sin x\cos x = \sin(2x)/2$ e depois half-angle.

**Resolução.**

$\sin^2 x\cos^2 x = (\sin x\cos x)^2 = \frac{\sin^2(2x)}{4} = \frac{1}{4}\cdot\frac{1 - \cos 4x}{2} = \frac{1 - \cos 4x}{8}$.

$$\int \sin^2 x\cos^2 x\, dx = \frac{x}{8} - \frac{\sin 4x}{32} + C.$$

**Verificação.** Derivando: $1/8 - \cos(4x)/8 = (1 - \cos 4x)/8 = \sin^2(2x)/4 = \sin^2 x\cos^2 x$. Correto.

**Fonte.** [OpenStax Calculus Vol. 2, §3.2, Example 3.12](https://openstax.org/books/calculus-volume-2/pages/3-2-trigonometric-integrals) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Substituição x = a sin θ para √(a² − x²) (intermediário)" numero="3">

**Problema.** Calcule $\int \sqrt{4 - x^2}\, dx$.

**Estratégia.** Radical $\sqrt{a^2 - x^2}$ com $a = 2$: sub $x = 2\sin\theta$.

**Resolução.**

$dx = 2\cos\theta\, d\theta$; $\sqrt{4 - x^2} = \sqrt{4 - 4\sin^2\theta} = 2\cos\theta$ (com $\theta \in [-\pi/2, \pi/2]$).

$\int 2\cos\theta \cdot 2\cos\theta\, d\theta = 4\int\cos^2\theta\, d\theta = 4\cdot\frac{\theta + \sin\theta\cos\theta}{2} = 2\theta + 2\sin\theta\cos\theta + C$.

Triângulo de referência ($\sin\theta = x/2$, hipotenusa 2, cateto adjacente $\sqrt{4-x^2}$):

$\theta = \arcsin(x/2)$; $\cos\theta = \sqrt{4-x^2}/2$.

Resultado: $2\arcsin(x/2) + 2\cdot\frac{x}{2}\cdot\frac{\sqrt{4-x^2}}{2} + C = 2\arcsin(x/2) + \frac{x\sqrt{4-x^2}}{2} + C$.

**Verificação.** Derivando (regra da cadeia): $\frac{2}{\sqrt{4-x^2}} + \frac{\sqrt{4-x^2} - x^2/\sqrt{4-x^2}}{2} = \frac{2}{\sqrt{4-x^2}} + \frac{4 - 2x^2}{2\sqrt{4-x^2}} = \sqrt{4-x^2}$. Correto.

**Fonte.** [APEX Calculus §6.4, Example 6.4.2](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Substituição x = a tan θ para √(a² + x²) (intermediário)" numero="4">

**Problema.** Calcule $\int \dfrac{1}{\sqrt{1 + x^2}}\, dx$.

**Estratégia.** Radical $\sqrt{a^2 + x^2}$ com $a = 1$: sub $x = \tan\theta$.

**Resolução.**

$dx = \sec^2\theta\, d\theta$; $\sqrt{1+x^2} = \sec\theta$.

$\int \frac{\sec^2\theta}{\sec\theta}\, d\theta = \int \sec\theta\, d\theta = \ln\lvert\sec\theta + \tan\theta\rvert + C$.

Triângulo ($\tan\theta = x$, hipotenusa $\sqrt{1+x^2}$): $\sec\theta = \sqrt{1+x^2}$, $\tan\theta = x$.

Resultado: $\ln\lvert x + \sqrt{1+x^2}\rvert + C$ (equivalente a $\text{arcsinh}(x) + C$).

**Verificação.** Derivando $\ln(x + \sqrt{1+x^2})$: $\frac{1 + x/\sqrt{1+x^2}}{x + \sqrt{1+x^2}} = \frac{(\sqrt{1+x^2}+x)/\sqrt{1+x^2}}{x+\sqrt{1+x^2}} = \frac{1}{\sqrt{1+x^2}}$. Correto.

**Fonte.** [OpenStax Calculus Vol. 2, §3.3, Example 3.15](https://openstax.org/books/calculus-volume-2/pages/3-3-trigonometric-substitution) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Fórmula de redução e aplicação (desafio)" numero="5">

**Problema.** Derive a fórmula de redução $\int \sin^n x\, dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n-1}{n}\int\sin^{n-2}x\, dx$ e use-a para calcular $\int_0^{\pi/2}\sin^4 x\, dx$.

**Estratégia.** Derivar por partes; aplicar para $n = 4$ e $n = 2$.

**Resolução.**

**Derivação:** $u = \sin^{n-1}x$, $dv = \sin x\, dx$. $du = (n-1)\sin^{n-2}x\cos x\, dx$, $v = -\cos x$.

$\int\sin^n x\, dx = -\sin^{n-1}x\cos x + (n-1)\int\cos^2 x\sin^{n-2}x\, dx$.

Substitua $\cos^2 x = 1 - \sin^2 x$:

$(n-1)\int(1 - \sin^2 x)\sin^{n-2}x\, dx = (n-1)\int\sin^{n-2}x\, dx - (n-1)\int\sin^n x\, dx$.

Reorganize: $n\int\sin^n x\, dx = -\sin^{n-1}x\cos x + (n-1)\int\sin^{n-2}x\, dx$. Divida por $n$.

**Aplicação:** $n = 4$: $\int\sin^4 x\, dx = -\frac{\sin^3 x\cos x}{4} + \frac{3}{4}\int\sin^2 x\, dx$.

$\int\sin^2 x\, dx = x/2 - \sin(2x)/4$.

Avaliando em $[0, \pi/2]$: $\int_0^{\pi/2}\sin^4 x\, dx = 0 + \frac{3}{4}\left[\frac{\pi}{4} - 0\right] = \frac{3\pi}{16}$.

**Verificação.** Fórmula de Wallis: $\int_0^{\pi/2}\sin^4 x\, dx = \frac{3\cdot 1}{4\cdot 2}\cdot\frac{\pi}{2} = \frac{3\pi}{16}$. Confirma.

**Fonte.** [APEX Calculus §6.3, Theorem 6.3.1](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>
