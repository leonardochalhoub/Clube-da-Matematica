<Porta nivel="formal" titulo="演算的性質と絞り込み定理">

$\lim_{x \to a} f(x) = L$ と $\lim_{x \to a} g(x) = M$ とし、$L, M \in \mathbb{R}$ とします。以下の法則は$x \to a$、$x \to a^+$、$x \to a^-$、$x \to \pm\infty$すべてに対して成り立ちます。

### 極限の代数法則

<Definicao titulo="極限の法則（Boelkins §1.4 / OpenStax §2.3）">

| 法則 | 述べ方 | 制限条件 |
|---|---|---|
| 和・差 | $\lim (f \pm g) = L \pm M$ | なし |
| 定数倍 | $\lim (c \cdot f) = cL$ | $c \in \mathbb{R}$ |
| 積 | $\lim (f \cdot g) = L \cdot M$ | なし |
| 商 | $\lim (f/g) = L/M$ | $M \neq 0$ |
| べき乗 | $\lim f^n = L^n$ | $n \in \mathbb{N}$ |
| 根号 | $\lim \sqrt[n]{f} = \sqrt[n]{L}$ | $n$が偶数なら $L \geq 0$ |
| 絶対値 | $\lim \lvert f \rvert = \lvert L \rvert$ | なし |

</Definicao>

> 「$\lim_{x\to a} f(x) = L$ で $\lim_{x\to a} g(x) = M$ ならば、$\lim_{x\to a}[f(x) + g(x)] = L + M$。」— [OpenStax Calculus Volume 1, §2.3, Theorem 2.4](https://openstax.org/books/calculus-volume-1/pages/2-3-the-limit-laws)

> 「$\lim_{x\to c} f(x) = L$ で $\lim_{x\to c} g(x) = K$ ならば、$\lim_{x\to c}[f(x) \cdot g(x)] = L \cdot K$。」— [APEX Calculus, §1.3, Theorem 1.3.1](https://www.apexcalculus.com/)

### 代入法則

<Definicao titulo="代入法則">

$f$が$a$で連続（多項式、分母が0でない有理関数、$\sin$、$\cos$、$e^x$、$a > 0$での$\ln x$など）ならば：

$$\lim_{x \to a} f(x) = f(a).$$

これにより、極限の計算は単に$a$での値を代入することに帰着します。

</Definicao>

### 合成

$\lim_{x \to a} g(x) = b$ で$f$が$b$で連続ならば：
$$\lim_{x \to a} f(g(x)) = f(b) = f\!\left(\lim_{x \to a} g(x)\right).$$

**連続でない場合の反例。** $g(x) = 0$（定数）とし、$f$が0で不連続とします。このとき$\lim g = 0$ですが、$\lim f(g(x)) = f(0) \neq \lim_{t \to 0} f(t)$となります。

### 絞り込み定理

<Teorema titulo="絞り込み定理（サンドイッチ定理）">

$a$のある近傍で$g(x) \leq f(x) \leq h(x)$（ただし$a$自体では不要）で、かつ

$$\lim_{x \to a} g(x) = L = \lim_{x \to a} h(x),$$

ならば$\lim_{x \to a} f(x) = L$です。

</Teorema>

> 「$a$を含む開区間で$x \neq a$に対して$g(x) \leq f(x) \leq h(x)$で、$\lim_{x\to a} g(x) = L = \lim_{x\to a} h(x)$ならば、$\lim_{x\to a} f(x) = L$。」— [OpenStax Calculus Volume 1, §2.3, Theorem 2.7](https://openstax.org/books/calculus-volume-1/pages/2-3-the-limit-laws)

**古典的な応用。** $\lim_{x \to 0} x^2 \sin(1/x) = 0$を示す：$-1 \leq \sin(1/x) \leq 1$に注意すると、$-x^2 \leq x^2\sin(1/x) \leq x^2$。両端で$\lim_{x \to 0}(\pm x^2) = 0$だから、極限は0です。

<Insight>

**約分は0での除算ではない。** $x \to 3$だが$x \neq 3$のとき、因子$(x - 3)$は極限の過程では決してゼロになりません。分子と分母から$(x - 3)$を約分することは完全に有効です — $x \neq 3$に対する通常の代数操作です。

<Porta nivel="5" titulo="5才の子ども向け">

あなたと友達が、ドアに向かって一緒に歩いていることを想像してください。あなたはそこに到着し、友達もそこに到着します。

二人がドアの前に一緒に集まって入ろうとすると、二人は同じ場所に到着します。極限はこのように働きます。二つのことが一つのポイントに近づいている場合、それらを合わせると、その結果も一つのポイントに近づきます。それぞれが到達するポイントを足すだけです。

特別なトリックがあります。もし一つのものが、同じ場所に到達する他の二つのもの**に挟まれて**いたら、それも到達します。行列の中にいるようなもの — あなたの前後の人は同じ部屋に行き、あなたも一緒に行きます。

除算には問題があります。ゼロで除算することはできません。だから、下の方がゼロに向かうとき、極限を除算する規則は機能せず、別の方法が必要になります。

</Porta>

<Porta nivel="10" titulo="10才の子ども向け">

極限には**数学の演算と仲良く付き合う良い習慣**があります。二つの関数がどこに向かっているかを知っているなら、それらの和、積、商がどこに向かっているかも知ることができます。

**基本的な規則：**
- 和：$f(x) \to 3$、$g(x) \to 5$（$x \to 2$のとき）なら、$f(x) + g(x) \to 3 + 5 = 8$。
- 積：$f(x) \cdot g(x) \to 3 \cdot 5 = 15$。
- 商：$f(x)/g(x) \to 3/5$ — **ただし下が0でないとき限る**。

**単純な関数は簡単です。** 多項式の場合、直接代入するだけです：$\lim_{x \to 2}(x^2 + 1) = 2^2 + 1 = 5$。

**サンドイッチの技巧。** ある関数が常に他の二つの関数の間に挟まれていて、その二つが同じポイントに到達するなら、中間の関数もそこに到達します。例：$-x^2 \leq x^2 \sin(1/x) \leq x^2$。$x \to 0$のとき、両端がゼロに向かうから、中間も向かいます。

**問題：** 時々代入すると$0/0$になります — これは約分するべき何かがあることを意味します。

</Porta>

<Porta nivel="15" titulo="15才の思春期向け">

この授業は、毎回エプシロン-デルタ定義に戻らずに**極限を計算するための代数的ツール**を提供します。

### 代入法則はいつ機能するか

連続関数（多項式、正弦関数、指数関数、正定義域での対数など）に対しては、直接代入するだけです：
$$\lim_{x \to 3} (x^2 - 2x + 1) = 3^2 - 2 \cdot 3 + 1 = 4.$$

### $0/0$の形のとき：因数分解して約分

$\lim_{x \to 3} \dfrac{x^2 - 9}{x - 3}$を考えます。代入すると：$\dfrac{9 - 9}{3 - 3} = \dfrac{0}{0}$ — 不定形です。

因数分解します：$\dfrac{(x-3)(x+3)}{x-3} = x + 3$。代入します：$3 + 3 = 6$。**答え：6。**

カギは：$x \to 3$だが$x \neq 3$のとき、分子と分母から因子$(x - 3)$を約分することに問題はありません。

### 根号があるとき：共役を乗じる

$\lim_{x \to 0} \dfrac{\sqrt{x+4} - 2}{x}$：代入で$0/0$。分子から根号を消すために$\dfrac{\sqrt{x+4}+2}{\sqrt{x+4}+2}$を乗じます：

$$\frac{(x+4) - 4}{x(\sqrt{x+4}+2)} = \frac{x}{x(\sqrt{x+4}+2)} = \frac{1}{\sqrt{x+4}+2} \to \frac{1}{4}.$$

### 絞り込み定理

直接計算できないとき、関数を知っている二つの関数に挟みます：

$$\lim_{x \to 0} x^2 \sin(1/x) = 0 \quad \text{なぜなら} \quad -x^2 \leq x^2 \sin(1/x) \leq x^2.$$

</Porta>

<Porta nivel="25" titulo="工学学生向け">

代数性質は極限の計算を**代数**に帰着させます — 毎回エプシロン-デルタ証明をやり直さずに式を操作できます。しかし証明を理解することは、性質が**いつ失効するか**を知るのに役立ちます。

### 証明：和の法則

$\lim_{x \to a} f = L$ と $\lim_{x \to a} g = M$が与えられているとします。任意の$\varepsilon > 0$に対して：
- $0 < |x - a| < \delta_1$のとき$|f(x) - L| < \varepsilon/2$となる$\delta_1 > 0$が存在。
- $0 < |x - a| < \delta_2$のとき$|g(x) - M| < \varepsilon/2$となる$\delta_2 > 0$が存在。
- $\delta = \min(\delta_1, \delta_2)$とします。三角不等式により：
$$|(f + g) - (L + M)| \leq |f - L| + |g - M| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon. \quad \blacksquare$$

### 証明：絞り込み定理

$g(x) \leq f(x) \leq h(x)$ で $\lim g = \lim h = L$のとき：$\varepsilon > 0$に対して、$0 < |x - a| < \delta$のとき$|g - L|, |h - L| < \varepsilon$となるよう$\delta > 0$を選びます。すると：
$$L - \varepsilon < g(x) \leq f(x) \leq h(x) < L + \varepsilon \implies |f(x) - L| < \varepsilon. \quad \blacksquare$$

### 無限での有理関数の極限

$\lim_{x \to \infty} \dfrac{p(x)}{q(x)}$（$\deg p = m$、$\deg q = n$）に対して：分子と分母を$x^n$で除します：
- $m < n$：極限は0。
- $m = n$：極限は最高次係数の比。
- $m > n$：極限は$\pm \infty$。

### 工学での応用

- **RLC回路**：伝達関数$H(s) = N(s)/D(s)$。DC利得は$H(0) = N(0)/D(0)$（商の法則で、$D(0) \neq 0$のとき有効）。
- **数値解析**：オイラー法の打ち切り誤差は$O(h)$ — 絞り込み定理により$h \to 0$のとき誤差はゼロに向かいます。
- **信号処理**：$\lim_{t \to \infty} A \sin(\omega t)/t = 0$（絞り込み定理で、$-A/t \leq A\sin(\omega t)/t \leq A/t$）。

### 極限と他の演算の交換性

- 極限は**連続関数**と交換：$\lim f(g(x)) = f(\lim g(x))$。
- 極限は**有限和**と交換：自明。
- 極限は**無限和**（級数）と交換しない（一様収束条件なし）。
- 極限は**積分**と交換しない（ルベスグまたは優収束定理なし）。

</Porta>

<Porta nivel="40" titulo="上級専門家向け">

代数性質は、極限演算子$\lim_a$が、$a$で極限を持つ関数の空間上の**代数準同型**であることを反映しています。

### 代数構造

$\mathcal{C}_a = \{f : \mathbb{R} \to \mathbb{R} \mid \lim_{x \to a} f(x) \in \mathbb{R}\}$と定義します。すると：
- $\mathcal{C}_a$は$\mathbb{R}$上の**可換代数**：和、積、スカラー倍で閉じている。
- 汎関数$\Lambda_a : \mathcal{C}_a \to \mathbb{R}$、$\Lambda_a(f) = \lim_{x \to a} f(x)$は**代数準同型**（$+$、$\cdot$、$c \mapsto cL$を保存）。
- 核$\ker \Lambda_a = \{f : \lim_a f = 0\}$は$\mathcal{C}_a$の**イデアル**。

商の法則は帰結：$g \notin \ker \Lambda_a$なら$1/g \in \mathcal{C}_a$ で$\Lambda_a(1/g) = 1/M$。

### 絞り込み定理：位相的一般化

位相空間$(X, \tau)$で、$(x_\alpha)$がネットで$g(x_\alpha) \to L$、$h(x_\alpha) \to L$（$\mathbb{R}$内）、ネット沿いで$g \leq f \leq h$なら$f(x_\alpha) \to L$。$\mathbb{R}$の順序付けが本質的 — 結果は順序のない空間には直接一般化できません。

### 不定形と解析的特異点

$0/0$は代数的には分子と分母が共通因子を持つ場合です。正しい定式化：分子と分母は同じイデアル$(x - a)^k \mathcal{O}_a$に属します。ここで$\mathcal{O}_a$は$a$での解析関数環。零点の重複度が極限の存在性または無限性を決定します。

### 非標準解析

$^*\mathbb{R}$（非標準実数）では、代数性質は**転送原理**を介して転移：一階言語で$\mathbb{R}$で真の任意の文は$^*\mathbb{R}$でも真。$f$の$a$での極限が存在して$L$ならば、かつその場合に限り、すべての$x \approx a$、$x \neq a$に対して$f(x) \approx L$（無限に近い）。

### 機械学習との接続

連鎖法則（逆伝播）は合成関数の極限：$\lim_{h \to 0} \dfrac{f(g(x+h)) - f(g(x))}{h} = f'(g(x)) \cdot g'(x)$。極限の代数性質は、勾配が計算グラフに沿ったヤコビアンの積に分解することを保証します。

</Porta>

<Porta nivel="pratica" titulo="実践的アルゴリズムと実データ">

### ステップバイステップ：任意の極限に対処する方法

**ステップ1 — 代入法則を試す。** $f(a)$を試します。実数が出れば、それが極限です（連続関数の場合）。終了。

**ステップ2 — 不定形を識別する。** $0/0$または$\infty/\infty$が出れば：続けます。$k/0$（$k \neq 0$）が出れば：極限は$\pm\infty$または存在しません — 片側極限の符号を分析します。

**ステップ3 — 代数操作。**
- $0/0$（多項式）：分子と分母を因数分解して、$(x - a)$を約分。
- $0/0$（根号あり）：共役を乗じる。
- $\infty/\infty$（有理関数）：最高次で除す。

**ステップ4 — 絞り込み定理。** 正弦、余弦、またはゼロに向かう何かで掛けた振動関数がある場合は、$-1 \leq \sin(\cdot) \leq 1$を使って絞り込み定理を適用します。

**ステップ5 — SymPyで検証。**

```python
import sympy as sp
x = sp.symbols('x')
sp.limit((x**2 - 9) / (x - 3), x, 3)    # 6
sp.limit((sp.sqrt(x + 4) - 2) / x, x, 0)  # 1/4
sp.limit(x**2 * sp.sin(1/x), x, 0)      # 0
sp.limit((2*x**2 - 3*x + 1) / (x**2 + 5), x, sp.oo)  # 2
```

### 応用：累積インフレ率の変化率

過去12ヶ月の累積IPCA（ブラジルの物価指数）はローカルで$I(t) = 0.6t^2 - 4.8t + 10.5$でモデル化できます（パーセント、$t$は1月からの月数）。月$t = 4$での指数の瞬間的変化率は：

$$\lim_{\Delta t \to 0} \frac{I(4 + \Delta t) - I(4)}{\Delta t} = I'(4) = 1.2 \cdot 4 - 4.8 = 0.$$

このモデルでは、指数の最小値は$t = 4$（4月）で出現します。極限の代数性質 — エプシロン-デルタ定義ではなく — は、この変化率を単純な約分で計算することを可能にします。

### よくある誤り

- **先に約分する。** 因子$(x - a)$は$x \neq a$のときだけ約分できます — そしてそれがまさに「$a$に向かう」ことが保証することです。
- **$M = 0$のときに商の法則を適用する。** 分母がゼロに向かうなら、法則は成り立ちません。
- **根号の条件を忘れる。** $\lim \sqrt[n]{f} = \sqrt[n]{L}$は$n$が偶数のとき$L \geq 0$を要求します。
- **両側極限と片側極限を混同する。** 法則は個別の片側極限に成り立ちますが、両側極限は両側が存在して等しいことを要求します。

</Porta>

</DuasPortas>

## 解答例

<Exemplo titulo="多項式での直接代入" numero="1">

**問題。** $\lim_{x \to 3} (2x^2 - 5x + 1)$を計算してください。

**戦略。** 多項式はすべての点で連続です。直接代入の性質を適用します。

**解答。**

1. **$x = 3$で関数が連続であることを確認。** すべての多項式は$\mathbb{R}$で連続です。極限は単に$x = 3$での関数値です。

2. **$x = 3$を代入：**
$$\lim_{x \to 3}(2x^2 - 5x + 1) = 2(3)^2 - 5(3) + 1 = 18 - 15 + 1 = 4.$$

3. **なぜ機能するか。** 代数法則により：$\lim x^2 = 9$（べき乗の法則）、$\lim 2x^2 = 18$（定数倍）、$\lim 5x = 15$、$\lim 1 = 1$（定数）。合計：$18 - 15 + 1 = 4$。

**検証。** $x = 3.01$：$2(3.01)^2 - 5(3.01) + 1 = 18.1202 - 15.05 + 1 = 4.0702 \approx 4$。一貫性あり。

**出典。** [OpenStax Calculus Volume 1, §2.3](https://openstax.org/books/calculus-volume-1/pages/2-3-the-limit-laws) — CC-BY-NC-SA 4.0。

</Exemplo>

<Exemplo titulo="因数分解による0/0の不定形" numero="2">

**問題。** $\lim_{x \to 2} \dfrac{x^2 - 4}{x - 2}$を計算してください。

**戦略。** 直接代入で$0/0$を得ます。分子は平方差 — 因数分解して共通因子$(x - 2)$を約分。

**解答。**

1. **直接代入を試す。** $\dfrac{2^2 - 4}{2 - 2} = \dfrac{0}{0}$ — 不定形。代数操作が必要。

2. **分子を因数分解。** $x^2 - 4 = (x - 2)(x + 2)$。

3. **共通因子を約分。** $x \neq 2$のとき：
$$\frac{x^2 - 4}{x - 2} = \frac{(x-2)(x+2)}{x-2} = x + 2.$$

4. **極限を計算。** 直接代入を適用：
$$\lim_{x \to 2}(x + 2) = 2 + 2 = 4.$$

**検証。** $x = 2.01$：$\dfrac{(2.01)^2 - 4}{2.01 - 2} = \dfrac{0.0401}{0.01} = 4.01 \approx 4$。一貫性あり。

**出典。** [OpenStax Calculus Volume 1, §2.3, Example 2.17](https://openstax.org/books/calculus-volume-1/pages/2-3-the-limit-laws) — CC-BY-NC-SA 4.0。

</Exemplo>

<Exemplo titulo="有理化による0/0の不定形" numero="3">

**問題。** $\lim_{x \to 0} \dfrac{\sqrt{x + 4} - 2}{x}$を計算してください。

**戦略。** 代入で$0/0$。分子の根号を共役$(\sqrt{x+4} + 2)$で乗じて消す。

**解答。**

1. **直接代入を試す。** $\dfrac{\sqrt{0 + 4} - 2}{0} = \dfrac{0}{0}$ — 不定形。

2. **共役を乗じる。** $x \neq 0$のとき：
$$\frac{\sqrt{x+4}-2}{x} \cdot \frac{\sqrt{x+4}+2}{\sqrt{x+4}+2} = \frac{(x+4) - 4}{x(\sqrt{x+4}+2)} = \frac{x}{x(\sqrt{x+4}+2)}.$$

3. **$x$を約分** （有効、$x \neq 0$なので）：
$$= \frac{1}{\sqrt{x+4}+2}.$$

4. **直接代入を適用：**
$$\lim_{x \to 0} \frac{1}{\sqrt{x+4}+2} = \frac{1}{\sqrt{4}+2} = \frac{1}{4}.$$

**検証。** $x = 0.01$：$\dfrac{\sqrt{4.01} - 2}{0.01} \approx \dfrac{0.0025}{0.01} = 0.25 = \dfrac{1}{4}$。一貫性あり。

**出典。** [APEX Calculus, §1.3, Example 1.3.4](https://www.apexcalculus.com/) — CC-BY-NC 4.0。

</Exemplo>

<Exemplo titulo="振動関数を伴う絞り込み定理" numero="4">

**問題。** $\lim_{x \to 0} x^2 \cos(1/x) = 0$を証明してください。

**戦略。** $\cos(1/x)$は$x \to 0$のとき無限に振動します — 直接極限を計算できません。しかし$|\cos(1/x)| \leq 1$常に成立。絞り込み定理を使用。

**解答。**

1. **上限下限を設定。** すべての$x \neq 0$に対して：
$$-1 \leq \cos(1/x) \leq 1.$$

2. **$x^2 \geq 0$を乗じる** （不等号は反転しない）：
$$-x^2 \leq x^2 \cos(1/x) \leq x^2.$$

3. **上限下限の極限を計算：**
$$\lim_{x \to 0}(-x^2) = 0 \quad \text{かつ} \quad \lim_{x \to 0} x^2 = 0.$$

4. **絞り込み定理を適用。** $f(x) = x^2 \cos(1/x)$は$-x^2$と$x^2$の間に挟まれており、両者の極限が0：
$$\lim_{x \to 0} x^2 \cos(1/x) = 0. \quad \blacksquare$$

**なぜ絞り込み定理が必要か。** 積の法則は$\lim_{x \to 0} \cos(1/x)$が存在することを要求します — しかしそれは**存在しません**（$-1$と$1$の間で振動）。絞り込み定理はこの困難を回避します。

**出典。** [APEX Calculus, §1.3, Theorem 1.3.7](https://www.apexcalculus.com/) — CC-BY-NC 4.0。

</Exemplo>

<Exemplo titulo="無限での有理関数の極限" numero="5">

**問題。** $\lim_{x \to \infty} \dfrac{3x^2 - 2x + 1}{x^2 + 5x - 4}$を計算してください。

**戦略。** $\infty/\infty$形 — 分子と分母の次数は両者とも2。最高次係数を現すために$x^2$で全体を除す。

**解答。**

1. **次数を識別。** 分子：次数2。分母：次数2。$\infty/\infty$形。

2. **分子と分母を$x^2$で除す：**
$$\frac{3x^2 - 2x + 1}{x^2 + 5x - 4} = \frac{3 - 2/x + 1/x^2}{1 + 5/x - 4/x^2}.$$

3. **各項を計算。** $x \to \infty$のとき：$1/x \to 0$ かつ $1/x^2 \to 0$。

4. **代数法則を適用：**
$$\lim_{x \to \infty} \frac{3 - 2/x + 1/x^2}{1 + 5/x - 4/x^2} = \frac{3 - 0 + 0}{1 + 0 - 0} = 3.$$

**一般的結果。** 次数が等しいとき、極限は最高次係数の比。

**出典。** [OpenStax Calculus Volume 1, §2.3, Example 2.20](https://openstax.org/books/calculus-volume-1/pages/2-3-the-limit-laws) — CC-BY-NC-SA 4.0。

</Exemplo>

      <li><strong>解釈。</strong> 瞬間速度は、時間間隔がゼロに向かうときの平均速度の極限です。<em>豆知識：この計算は、<Eq>{`s(t) = t^2`}</Eq>の<Eq>{`t = 1`}</Eq>での導関数の定義そのものです。</em></li>
    </ol>
  </>}
  fonte={{ livro: "OpenStax Calculus Volume 1", url: "https://openstax.org/books/calculus-volume-1/pages/2-3-the-limit-laws", secao: "§2.3", pagina: "178", exercicio: "ex. 138 (adaptado)", licenca: "CC-BY-NC-SA 4.0" }}
>
粒子の位置は$s(t) = t^2$メートル。$t = 1$での瞬間速度を計算してください：$\lim_{\Delta t \to 0}\dfrac{s(1 + \Delta t) - s(1)}{\Delta t}$。
</Exercicio>
