<Porta nivel="formal" titulo="厳密な定義">

### 一方的極限：ε-δ定義

<Definicao titulo="右極限">

<Eq>{`\\lim_{x \\to a^+} f(x) = L`}</Eq> という記述は、すべての <Eq>{`\\varepsilon > 0`}</Eq> に対して <Eq>{`\\delta > 0`}</Eq> が存在し、

$$0 < x - a < \delta \implies \lvert f(x) - L \rvert < \varepsilon$$

となることを意味する。条件 <Eq>{`0 < x - a < \\delta`}</Eq> は <Eq>{`a < x < a + \\delta`}</Eq> に等価である。つまり <Eq>{`x`}</Eq> が <Eq>{`a`}</Eq> の**右側に**あり、けれども決して <Eq>{`a`}</Eq> そのものではないこと。

</Definicao>

<Definicao titulo="左極限">

<Eq>{`\\lim_{x \\to a^-} f(x) = M`}</Eq> という記述は、すべての <Eq>{`\\varepsilon > 0`}</Eq> に対して <Eq>{`\\delta > 0`}</Eq> が存在し、

$$0 < a - x < \delta \implies \lvert f(x) - M \rvert < \varepsilon$$

となることを意味する。条件 <Eq>{`0 < a - x < \\delta`}</Eq> は <Eq>{`a - \\delta < x < a`}</Eq> に等価である。つまり <Eq>{`x`}</Eq> が <Eq>{`a`}</Eq> の**左側に**あること。

</Definicao>

> "We say the function has a right-hand limit equal to L at a if for every number ε > 0 there exists a corresponding number δ > 0 such that for all x with 0 < x − a < δ we have |f(x) − L| < ε." — [OpenStax Calculus Volume 1, §2.2](https://openstax.org/books/calculus-volume-1/pages/2-2-the-limit-of-a-function)

### 側極限による存在定理

<Teorema titulo="双側極限存在性の判定法">

極限 <Eq>{`\\lim_{x \\to a} f(x)`}</Eq> が存在して <Eq>{`L`}</Eq> に等しいことと，

<Eq display>{`\\lim_{x \\to a^-} f(x) = L \\quad \\text{かつ} \\quad \\lim_{x \\to a^+} f(x) = L`}</Eq>

が成り立つことは同値である。もし <Eq>{`\\lim_{x \\to a^-} f(x) \\neq \\lim_{x \\to a^+} f(x)`}</Eq> ならば、双側極限は存在しない。この状況を**ジャンプ型不連続性**（jump discontinuity）と呼ぶ。

</Teorema>

> "A function has a limit at a point if and only if both the left and right limits exist at that point and are equal." — [APEX Calculus, §1.4](https://www.apexcalculus.com/)

### 量化形式の表

| 極限の種類 | $x$ の条件 | 量化形式 |
|---|---|---|
| $\lim_{x \to a} f(x) = L$ | $0 < \lvert x - a \rvert < \delta$ | $\lvert f(x) - L \rvert < \varepsilon$ |
| $\lim_{x \to a^+} f(x) = L$ | $0 < x - a < \delta$ | $\lvert f(x) - L \rvert < \varepsilon$ |
| $\lim_{x \to a^-} f(x) = L$ | $0 < a - x < \delta$ | $\lvert f(x) - L \rvert < \varepsilon$ |
| $\lim_{x \to a^+} f(x) = +\infty$ | $0 < x - a < \delta$ | $f(x) > M$ |

### 定義域境界の極限

$a$ が $f$ の定義域の左端点である場合（例えば $f(x) = \sqrt{x}$ で定義域が $[0, +\infty)$），右極限のみが関連性を持つ。

$$\lim_{x \to 0^+} \sqrt{x} = 0.$$

左極限は定義域がないため存在しない。このような場合、双側極限は存在する側極限と同定される。

<Insight>

側極限による存在定理は，飛躍型不連続を診断するための**普遍的な道具**である。すべての飛躍型不連続は二つの一方的極限を計算・比較することで検出できる。一致すれば極限は存在する。ただし$f(a)$がこの値と異なれば，関数は除去可能な不連続性を持つかもしれない（レッスン43参照）。

</Insight>

</Porta>

<Porta nivel="5" titulo="5才の子ども向け">

廊下を歩いていて、扉に近づくところを想像しよう。

廊下の**右側から**来ることも、**左側から**来ることもできる。

- 両側から来て、扉の向こうに**同じもの**が見えたら、グッド。極限は存在する。
- 片方からはおもちゃが見えて、もう片方からは本が見えたら、「扉の向こうの"もの"」は言えない。片方ごとに答えが違う。

数学者たちはこれを**側極限**と呼ぶ。片側だけから何かに近づくときに見つけるもの。

</Porta>

<Porta nivel="10" titulo="10才の子ども向け">

階段の段を上ったり下ったりすることを想像しよう。

関数 $f(x) = \lfloor x \rfloor$（$x$ 以下の最大整数）は，$x \in [1, 2)$ で 1，$x \in [2, 3)$ で 2。

$x$ が 2 に近づくと：
- **左側から**（1.9; 1.99; 1.999; ...）：$f(x) = 1$ ずっと。左極限 = 1。
- **右側から**（2.1; 2.01; 2.001; ...）：$f(x) = 2$ ずっと。右極限 = 2。

二つの側は**異なる答え**（1 と 2）を出す。だから $x = 2$ での双側極限は存在しない。これは**飛び出し**だ。

考え方はシンプル。関数がどこかの点から別の値へ"飛ぶ"なら，二つの側を別に計算する必要がある。

</Porta>

<Porta nivel="15" titulo="15才の少年・少女向け">

関数が何らかの点で"レシピ"を変えるたびに（区分定義関数など），質問する必要がある：**二つの側は同じ値に到達するか？**

### 実践的な判定法

$f(x) = \begin{cases} x + 1 & x < 2 \\ 3 & x = 2 \\ x^2 - 1 & x > 2 \end{cases}$ とする。

- 左側：$\lim_{x \to 2^-} (x + 1) = 3$。
- 右側：$\lim_{x \to 2^+} (x^2 - 1) = 4 - 1 = 3$。
- どちらも 3 に等しい：双側極限 = 3。（$f(2) = 3$ も，だから $f$ は 2 で連続。）

今度はレシピを変えよう：$g(x) = \begin{cases} x + 1 & x < 2 \\ x^2 & x \geq 2 \end{cases}$

- 左側：$\lim_{x \to 2^-} (x + 1) = 3$。
- 右側：$\lim_{x \to 2^+} x^2 = 4$。
- $3 \neq 4$：双側極限は**存在しない**。サイズ $|4 - 3| = 1$ のジャンプ型不連続。

### 一方的無限極限

$\lim_{x \to 0^+} \dfrac{1}{x} = +\infty$（正の値が限界なく増加）。

$\lim_{x \to 0^-} \dfrac{1}{x} = -\infty$（負の値が限界なく減少）。

片側は $+\infty$，もう片側は $-\infty$ に行くため，$x = 0$ での $1/x$ の双側極限は存在しない。$x = 0$ は垂直漸近線。

### 定義域境界での極限

$\lim_{x \to 0^+} \sqrt{x} = 0$。$\sqrt{x}$ は $x < 0$ で定義されないので、右極限のみ存在する。この極限は 0，そして $f$ は $x = 0$ で右連続。

<Insight>

側極限による存在定理は，不連続性診断の**普遍的な道具**である。すべてのジャンプ型不連続は二つの一方的極限を計算・比較することで検出できる。一致すれば極限は存在する。ただし $f(a)$ がこの値と異なれば，関数はまだ除去可能な不連続性を持つ（レッスン43で扱った）。

</Insight>

</Porta>

<Porta nivel="25" titulo="工学専攻生向け">

側極限は，**区分定義関数**，**整数値関数**，**スイッチング信号**，**急激な不連続を持つシステム**を分析するのに適切な道具である。

### 厳密な証明：$\lim_{x \to 0^+} \dfrac{1}{x} = +\infty$

任意の $M > 0$ に対して，$\delta = 1/M$ を選べ。$0 < x < \delta = 1/M$ のとき：

$$\frac{1}{x} > \frac{1}{\delta} = M.$$

したがって，どの $M > 0$ を選んでも，$f(x) = 1/x > M$ は $0 < x < 1/M$ のとき常に成り立つ。定義は満たされる。$\square$

### 証明：$\lim_{x \to 0^-} \dfrac{1}{x} = -\infty$

任意の $M < 0$ に対して，$\delta = 1/|M|$ を選べ。$-\delta < x < 0$ のとき：

$$x < 0 \implies \frac{1}{x} < 0 \implies \frac{1}{x} < -|M| = M.$$

したがって $1/x < M$ が $-1/|M| < x < 0$ のとき成り立つ。$\square$

### 証明：$\lim_{x \to 0^+} \sqrt{x} = 0$

$\varepsilon > 0$ を任意に選べ。$\delta = \varepsilon^2$ を選べ。$0 < x < \delta$ のとき：

$$|\sqrt{x} - 0| = \sqrt{x} < \sqrt{\delta} = \sqrt{\varepsilon^2} = \varepsilon. \quad \square$$

### スイッチング関数の分析（制御システム）

符号関数 $\mathrm{sgn}(x) = \begin{cases} +1 & x > 0 \\ 0 & x = 0 \\ -1 & x < 0 \end{cases}$ は次の性質を持つ：

$$\lim_{x \to 0^+} \mathrm{sgn}(x) = +1, \quad \lim_{x \to 0^-} \mathrm{sgn}(x) = -1.$$

$x = 0$ での振幅 2 のジャンプは，スライディングモード制御器において**チャタリング**を生成する。実務上の解決策は，$\mathrm{sgn}(x)$ を大きな $k$ に対し $\tanh(kx)$ で置き換えること。

### 確率論の累積分布関数

累積分布関数 $F_X(x) = P(X \leq x)$ は非減少で右連続：$\lim_{x \to a^+} F_X(x) = F_X(a)$。左極限は $F_X(a^-) = P(X < a)$。ジャンプ $F_X(a) - F_X(a^-) = P(X = a)$ ─ 連続確率変数ではジャンプはゼロ；離散確率変数では点確率。

</Porta>

<Porta nivel="40" titulo="シニア専門家向け">

### 位相学的解釈

$a$ での右側極限は，$a$ の右側近傍のフィルタ $\mathcal{F}^+ = \{V \cap (a, +\infty) : V \in \mathcal{V}(a)\}$ に関する $f$ の極限。左側極限はフィルタ $\mathcal{F}^-$ を使う。双側極限は穴の開いた近傍のフィルタ $\mathcal{V}^*(a)$ を使う。

側極限による存在定理は $\mathcal{V}^*(a) = \mathcal{F}^+ \vee \mathcal{F}^-$（包含の逆順でのフィルタの上限）を述べている。したがって極限が $\mathcal{V}^*(a)$ で存在することと，$\mathcal{F}^\pm$ の両方で存在して一致することは同値。

### 側ライムスープとライムイン

必ずしも収束しない関数に対して，以下を定義する：

$$\limsup_{x \to a^+} f(x) = \inf_{\delta > 0} \sup_{0 < x - a < \delta} f(x), \quad \liminf_{x \to a^+} f(x) = \sup_{\delta > 0} \inf_{0 < x - a < \delta} f(x).$$

極限 $\lim_{x \to a^+} f(x)$ が $\overline{\mathbb{R}}$ に存在することと，$\limsup = \liminf$ が成り立つことは同値。そのとき，両者は極限と一致する。

### 有界変動関数

有界変動関数 $f : [a, b] \to \mathbb{R}$ は**内部のすべての点**で側極限を持つ。不連続点の集合は最大可算。特に単調関数はすべての点で側極限を持つ─Darboux-Jordan による古典的結果。

### PDE と伝達条件

界面問題（二つの材料を持つ熱伝導，成層媒体の波動）では，解 $u$ が本質的に側極限の間の等式である伝達条件を満たす：$\lim_{x \to a^-} u(x) = \lim_{x \to a^+} u(x)$（ポテンシャル連続性）および $\lim_{x \to a^-} \kappa_1 u'(x) = \lim_{x \to a^+} \kappa_2 u'(x)$（フラックス連続性）。ここで $\kappa_i$ は二つの媒体の係数。

</Porta>

<Porta nivel="pratica" titulo="実務応用─料金表と段階的税率">

側極限は，システムが急激に体制を変えるときはいつでも現れる。

### 側極限計算の手順

**ステップ 1.** $x$ がどちら側から $a$ に近づくかを識別せよ（$a^+$ または $a^-$）。

**ステップ 2.** $f$ が区分定義なら，その側に対して"有効な公式"を選べ。

**ステップ 3.** その公式で $x \to a$ を代入せよ（通常に極限の代数を使う）。

**ステップ 4.** 二つの結果を比較せよ。一致すれば，双側極限が存在してその値である。

### 例：電力料金の段階別料金（ANEEL 2025）

| 消費量帯域（kWh/月） | 料金（R\$/kWh） |
|---|---|
| $[0, 30)$ | R\$ 0,42 |
| $[30, 100)$ | R\$ 0,58 |
| $[100, 220)$ | R\$ 0,71 |
| $[220, +\infty)$ | R\$ 0,85 |

料金 $t(c)$ を消費量 $c$ の関数として，$c = 30$ ジャンプがある：

$$\lim_{c \to 30^-} t(c) = 0{,}42, \quad \lim_{c \to 30^+} t(c) = 0{,}58.$$

側極限は存在するが異なる─ジャンプ型不連続。総コスト（料金の積分）は連続；飛躍するのは限界料金のみ。

### 頻出する誤り

1. **二つの側の確認を忘れる。** 公式が変わる点なら，常に $a^+$ と $a^-$ の両方を計算せよ。
2. **$f(a)$ と $\lim_{x \to a} f(x)$ を混同する。** 点での関数値は極限に影響しない。
3. **「極限は存在しない」と無限極限を言う。** 無限極限は特殊なケース─$\lim = +\infty$ と書くが，形式的には実数ではない。

</Porta>

## 解いた例

> 五つの例，難度は増加。グラフ読取から定数決定まで。各例は出典を示す。問題は常に開かれた教科書から来ている。

<Exemplo titulo="グラフから側極限を読み取る" numero="1">

**問題.** $f$ のグラフ：$x = 2$ の左側から来た曲線は $y = 3$ に近づく（開いた点）；右側から来た曲線は $y = 5$ に近づく（開いた点）；点 $(2, 1)$ に黒い点あり。$\lim_{x \to 2^-} f(x)$，$\lim_{x \to 2^+} f(x)$，$\lim_{x \to 2} f(x)$，$f(2)$ を求めよ。

**戦略.** グラフの各情報には異なる役割がある：曲線は側極限を明かす；黒い点は関数値を明かす。双側極限は側極限が一致した場合にのみ存在する。

**解答.** 

1. **左極限.** 曲線は $x \to 2^-$ で $y = 3$ に向かう（開いた点は 3 に到達しない）。したがって $\lim_{x \to 2^-} f(x) = 3$。

2. **右極限.** 曲線は $x \to 2^+$ で $y = 5$ に向かう。したがって $\lim_{x \to 2^+} f(x) = 5$。

3. **双側極限.** $3 \neq 5$ ゆえ，存在定理より：$\lim_{x \to 2} f(x)$ は**存在しない**。振幅 $|5 - 3| = 2$ のジャンプ型不連続。

4. **関数値.** 点 $(2, 1)$ の黒い点は $f(2) = 1$ を示す。この値は側極限と無関係。

**検証.** $f(2) = 1$ は二つの側極限（3 と 5）と異なる。これは矛盾しない：点での値は極限に影響しない。

**出典.** [OpenStax Calculus Volume 1, §2.2](https://openstax.org/books/calculus-volume-1/pages/2-2-the-limit-of-a-function) ─ CC-BY-NC-SA 4.0 ライセンス。

</Exemplo>

<Exemplo titulo="区分定義関数の側極限" numero="2">

**問題.** 

$$g(x) = \begin{cases} x^2 - 1 & x < 3 \\ 2x - 3 & x \geq 3 \end{cases}$$

とする。$\lim_{x \to 3^-} g(x)$，$\lim_{x \to 3^+} g(x)$ を計算し，$\lim_{x \to 3} g(x)$ が存在するか判定せよ。

**戦略.** $x < 3$ では公式 $x^2 - 1$ を使う。$x > 3$（右側極限では $x$ は決して 3 そのものではない）では $2x - 3$ を使う。$g$ での符号 $\geq$ は値 $g(3)$ に影響するのみ，側極限には影響しない。

**解答.** 

1. **左極限** ($x \to 3^-$，$x < 3$)：

$$\lim_{x \to 3^-} g(x) = \lim_{x \to 3} (x^2 - 1) = 9 - 1 = 8.$$

2. **右極限** ($x \to 3^+$，$x > 3$)：

$$\lim_{x \to 3^+} g(x) = \lim_{x \to 3} (2x - 3) = 6 - 3 = 3.$$

3. **比較.** $8 \neq 3$，したがって $\lim_{x \to 3} g(x)$ は**存在しない**。ジャンプは振幅 $|8 - 3| = 5$。

4. **関数値.** $g(3) = 2(3) - 3 = 3$。

**検証.** $\lim_{x \to 3^-} g(x) = 8 \neq g(3) = 3$：関数は $x = 3$ で左側でも不連続。

**出典.** [OpenStax Calculus Volume 1, §2.2, 例2.13](https://openstax.org/books/calculus-volume-1/pages/2-2-the-limit-of-a-function) ─ CC-BY-NC-SA 4.0 ライセンス。

</Exemplo>

<Exemplo titulo="極限存在のための定数決定" numero="3">

**問題.** 関数

$$h(x) = \begin{cases} ax + 1 & x < 2 \\ x^2 - 1 & x \geq 2 \end{cases}$$

が $\lim_{x \to 2} h(x)$ を持つべき。$a$ の値を求めよ。

**戦略.** 双側極限が存在するには，側極限が等しくなければならない。各極限を $a$ の関数として計算し，等式を立てる。

**解答.** 

1. **左極限：**

$$\lim_{x \to 2^-} h(x) = \lim_{x \to 2} (ax + 1) = 2a + 1.$$

2. **右極限：**

$$\lim_{x \to 2^+} h(x) = \lim_{x \to 2} (x^2 - 1) = 4 - 1 = 3.$$

3. **存在条件：** $2a + 1 = 3 \implies 2a = 2 \implies a = 1$。

4. **検証.** $a = 1$ で：左極限 = 3，右極限 = 3。双側極限は存在して 3。また $h(2) = 4 - 1 = 3$ ゆえ，$a = 1$ のとき $h$ は $x = 2$ で連続。

**出典.** [APEX Calculus, §1.4, 例1.4.7](https://www.apexcalculus.com/) ─ CC-BY-NC 4.0 ライセンス。

</Exemplo>

<Exemplo titulo="一方的無限極限と垂直漸近線" numero="4">

**問題.** $\lim_{x \to 1^+} \dfrac{1}{x - 1}$ と $\lim_{x \to 1^-} \dfrac{1}{x - 1}$ を計算せよ。垂直漸近線を特定せよ。

**戦略.** $x \to 1^+$（分母は正）および $x \to 1^-$（分母は負）のときの $x - 1$ の符号を分析せよ。

**解答.** 

1. **右側** ($x > 1$)：$x - 1 > 0$ ゆえ $1/(x - 1) > 0$。$x \to 1^+$ のとき $x - 1 \to 0^+$ ゆえ $1/(x-1) \to +\infty$。

$$\lim_{x \to 1^+} \frac{1}{x - 1} = +\infty.$$

2. **左側** ($x < 1$)：$x - 1 < 0$ ゆえ $1/(x - 1) < 0$。$x \to 1^-$ のとき $x - 1 \to 0^-$ ゆえ $1/(x-1) \to -\infty$。

$$\lim_{x \to 1^-} \frac{1}{x - 1} = -\infty.$$

3. **垂直漸近線.** 少なくとも一つの側極限が $x = 1$ で無限ゆえ，直線 $x = 1$ は $f(x) = 1/(x-1)$ のグラフの垂直漸近線。

4. **双側極限.** 二つの側は異なる（$+\infty \neq -\infty$）；双側極限は存在しない。

**検証.** $x = 1{,}01$ で：$1/(0{,}01) = 100 > 0$。$x = 0{,}99$ で：$1/(-0{,}01) = -100 < 0$。符号確認。

**出典.** [APEX Calculus, §1.4, 例1.4.2](https://www.apexcalculus.com/) ─ CC-BY-NC 4.0 ライセンス。

</Exemplo>

<Exemplo titulo="実務例─段階的料金プラン：側極限" numero="5">

**問題.** ストリーミングサービスは月額 $P(n)$（ブラジル・レアル）を同時画面数 $n$ に応じて課金する：

$$P(n) = \begin{cases} 19{,}90 & 1 \leq n \leq 2 \\ 34{,}90 & 3 \leq n \leq 4 \\ 54{,}90 & n \geq 5 \end{cases}.$$

$n \in \mathbb{R}^+$ について，段階型補間で $P$ を実数関数として実装しよう。$n = 2$ と $n = 4$ での側極限を計算せよ。

**戦略.** 実数 $n$ に対して $P$ を段階型補間で拡張：帯域 $[1, 2]$ は R\$ 19.90 を $n = 2{,}999\ldots$ まで保つ；次の帯域は $n = 3$ から始まる。各帯域の公式で極限を計算する。

**解答.** 

1. **$n = 2$ で：**

$$\lim_{n \to 2^-} P(n) = 19{,}90 \quad \text{（帯域} [1, 2]\text{）}, \qquad \lim_{n \to 2^+} P(n) = 34{,}90 \quad \text{（次の帯域）}.$$

R\$ 19.90 ≠ R\$ 34.90 ゆえ，$n = 2$ での双側極限は**存在しない**。ジャンプは R\$ 15.00。

2. **$n = 4$ で：**

$$\lim_{n \to 4^-} P(n) = 34{,}90, \qquad \lim_{n \to 4^+} P(n) = 54{,}90.$$

R\$ 34.90 ≠ R\$ 54.90 ゆえ，$n = 4$ での双側極限は**存在しない**。ジャンプは R\$ 20.00。

3. **解釈.** 各帯域の境界はジャンプ型不連続。顧客は帯域内のあらゆる画面数に対して同じ価格を支払う─段階関数，遷移点での不連続。

**検証.** 値 $P(2) = 19{,}90$（契約で定義）は右側極限と異なる─$f(a)$ と $\lim_{x \to a^+} f(x)$ が別の対象であることを示す。

**出典.** [Active Calculus, §1.2, アクティビティ1.2.2](https://activecalculus.org/single/sec-1-2-lim.html) ─ CC-BY-NC-SA 4.0 ライセンス。

</Exemplo>
