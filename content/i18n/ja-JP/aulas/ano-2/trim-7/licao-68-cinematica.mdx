### 基本的な定義

<Definicao titulo="位置、速度、加速度、ジャーク">
$s: I \subset \mathbb{R} \to \mathbb{R}$を時間$t$に関する微分可能な位置関数とします。

$$v(t) = \frac{ds}{dt} = s'(t), \qquad a(t) = \frac{dv}{dt} = s''(t), \qquad j(t) = \frac{da}{dt} = s'''(t).$$

- **速さ**: $|v(t)|$（非負スカラー；速度が負の場合と異なります）。
- **変位** ($[t_1, t_2]$区間)：$\Delta s = s(t_2) - s(t_1)$（負になることがあります）。
- **移動距離**: $\int_{t_1}^{t_2} |v(t)|\, dt$（常に非負です）。
</Definicao>

> "The instantaneous velocity of an object is the limit of the average velocities of the object over shorter and shorter time intervals." — [Active Calculus §1.1](https://activecalculus.org/single/sec-1-1-vel.html)

> "The position function $s(t)$ gives the position of an object along a number line at time $t$. The velocity function $v(t) = s'(t)$ gives the velocity of the object at time $t$." — [OpenStax Calculus Vol.1 §3.4](https://openstax.org/books/calculus-volume-1/pages/3-4-derivatives-as-rates-of-change)

### 標準的な運動パターン

| 運動 | $s(t)$ | $v(t)$ | $a(t)$ | 備考 |
|---|---|---|---|---|
| 静止 | $s_0$ | $0$ | $0$ | 固定点 |
| 等速(MRU) | $s_0 + v_0 t$ | $v_0$ | $0$ | $s \times t$グラフで直線 |
| 一定加速度(MUV) | $s_0 + v_0 t + \tfrac{1}{2}a_0 t^2$ | $v_0 + a_0 t$ | $a_0$ | 放物線 |
| 単振動(MHS) | $A\cos(\omega t + \phi)$ | $-A\omega\sin(\omega t + \phi)$ | $-A\omega^2\cos(\omega t + \phi)$ | $a = -\omega^2 s$ |
| 空気抵抗付き | 微分方程式で解く | $v_\infty(1-e^{-kt/m})$ | 0に減衰 | 終端速度 |

### トリチェリの定理（微積分による導出）

<Teorema titulo="トリチェリの方程式">
一定加速度$a_0$のMUVで、変位$\Delta s$および速度$v_0, v_f$は次を満たします。
$$v_f^2 = v_0^2 + 2a_0\,\Delta s.$$
**証明：** $v(t) = v_0 + a_0 t$、$s(t) = s_0 + v_0 t + \tfrac{1}{2}a_0 t^2$から $t = (v - v_0)/a_0$を導き出し、$\Delta s$に代入すると
$$\Delta s = v_0 \cdot \frac{v_f - v_0}{a_0} + \frac{1}{2}a_0\left(\frac{v_f - v_0}{a_0}\right)^2 = \frac{v_f^2 - v_0^2}{2a_0}. \quad \blacksquare$$
</Teorema>

### 単振動(MHS)

$x(t) = A\cos(\omega t + \phi)$は微分方程式 $\ddot x + \omega^2 x = 0$を満たします。

- 周期：$T = 2\pi/\omega$。
- 周波数：$f = 1/T$。
- ばね系：$\omega = \sqrt{k/m}$；小角度振動する振り子：$\omega = \sqrt{g/L}$。

<Insight>
MHSでは、加速度は常に変位に**比例し反対向き**です：$a = -\omega^2 x$。加速度の大きさは極値（$|x| = A$）で最大、平衡点で零です。速度の大きさは平衡点で最大、極値で零です。完全に逆転しています。
</Insight>

### $\mathbb{R}^n$での運動学

$\vec{r}(t) = (x(t), y(t), z(t)) \in \mathbb{R}^3$に対して：

$$\vec{v}(t) = \dot{\vec{r}}(t), \qquad \vec{a}(t) = \ddot{\vec{r}}(t), \qquad |\vec{v}| = \text{速さ}.$$

各成分は独立に導関数が求められます。曲線軌道での向心加速度：$a_c = v^2/\rho$（$\rho$は曲率半径）。

</Porta>

<Porta nivel="5" titulo="5歳の子ども向け">

直線路上のおもちゃの車を想像してください。

**車はどこにある？**これは**位置**です。定規の上のどの数字か。

**どのくらい速く動いている？**これは**速度**です。毎秒何センチ進むか。

**加速しているか、それとも減速しているか？**これは**加速度**です。速度が増えているか減っているか。

3つすべてが繋がっています。速度は毎秒ごとの位置の変わり方です。加速度は毎秒ごとの速度の変わり方です。階段のようなものです：位置 → 速度 → 加速度。

</Porta>

<Porta nivel="10" titulo="10歳の子ども向け">

物理では、時間が経つと物体は動きます。**運動学**はこれを数学で研究します。

- **位置** $s(t)$：物体がそれぞれの瞬間にどこにあるか。
- **速度** $v(t) = s'(t)$：位置がどのくらい速く変わるか。負になることがあります（後ろに動く）。
- **加速度** $a(t) = v'(t)$：速度がどのくらい速く変わるか。正 = 加速、負 = 減速。

**例**：石がビルから落ちます。$s(t) = 100 - 5t^2$メートル。
- $v(t) = -10t$（毎秒、下方向に毎秒10 m/sより速くなる）。
- $a(t) = -10$ m/s²（定数：重力です！）。
- 地面に当たるのは$s = 0 \Rightarrow t = \sqrt{20} \approx 4.5$秒。

導関数は位置を速度に、速度を加速度に変換します。2回適用される同じ操作です。

</Porta>

<Porta nivel="15" titulo="15歳の少年少女向け">

運動学は微積分の**最も直接的な応用**です。同じ微積分の公式が、自動車、惑星、バネを説明します。

### 3つの基本的な関数

| 量 | 定義 | 解釈 |
|---|---|---|
| 位置 $s(t)$ | 与えられた | 物体がどこにあるか |
| 速度 $v(t) = s'(t)$ | 1次導関数 | どのくらい速く、どの方向へ |
| 加速度 $a(t) = s''(t)$ | 2次導関数 | 速度の変化 |

### 標準的な運動

**MRU**：$a = 0$、$v$定数、$s(t) = s_0 + v_0 t$（直線）。

**MUV**（自由落下、傾斜面）：$a$定数、$s(t) = s_0 + v_0 t + \tfrac{1}{2}at^2$（放物線）。

トリチェリ：$v^2 = v_0^2 + 2a\Delta s$ — 時間が不要な場合に使用。

**MHS**（バネ、振り子）：$s(t) = A\cos(\omega t + \phi)$。加速度は$a = -\omega^2 s$ -- 常に平衡点へ指向します。周期 $T = 2\pi/\omega$。

### よくある注意点

- 速度**ゼロ**は加速度ゼロを意味しません（投げ上げた球は最高点で$v = 0$ですが$a = -g$）。
- **変位**（$\int v\, dt$）はゼロでも移動距離（$\int |v|\, dt > 0$）はゼロでない可能性があります。
- 符号は方向を示します；速さは速度の絶対値です。

</Porta>

<Porta nivel="25" titulo="工学部生向け">

運動学は古典力学、制御、ロボティックス、および数値シミュレーションの基礎です。

### ベクトル表現

$\vec{r}(t) \in \mathbb{R}^3$：$\vec{v} = \dot{\vec{r}}$、$\vec{a} = \ddot{\vec{r}}$、$\vec{j} = \dddot{\vec{r}}$。

Frenet-Serret座標系：$\vec{a} = \dot{v}\,\hat{T} + (v^2/\rho)\,\hat{N}$ -- 接線加速度と向心加速度。

### 一様円運動

$\vec{r} = R(\cos\omega t, \sin\omega t)$：$\vec{v} = R\omega(-\sin\omega t, \cos\omega t)$、$|\vec{v}| = R\omega$。

$\vec{a} = -\omega^2\vec{r}$ -- 向心加速度、常に中心を指向、大きさ$a_c = R\omega^2 = v^2/R$。

### 常微分方程式と位相空間

一般的な力での運動学：$m\ddot{s} = F(t, s, \dot{s})$ -- 2階常微分方程式。

システムとして書き直す：$\dot{s} = v$、$\dot{v} = F/m$。空間$(s, v)$は**位相空間**です。位相空間の軌道は交差しません（常微分方程式の解の一意性）。

### 空気抵抗（抵抗を伴う落下）

$m\dot{v} = -mg - bv$（線形抵抗）。解：$v(t) = v_\infty + (v_0 - v_\infty)e^{-bt/m}$、ここで$v_\infty = -mg/b$は**終端速度**です。二次抵抗（$bv^2$）：単純な閉形式解がなく、数値積分が必要です。

### ジャーク工学への応用

エレベーター（快適性）、ABS（アンチロック）、ロボットアーム（機械的磨耗）、高速鉄道レール制御の際にジャーク制限があります。現代の制御器は最大ジャークを指定する加速度プロフィールを規定します。

### 数値近似（有限差分）

$v_n \approx (s_{n+1} - s_n)/\Delta t$、$a_n \approx (v_{n+1} - v_n)/\Delta t$。Verlet法：$s_{n+1} = 2s_n - s_{n-1} + a_n (\Delta t)^2$ -- 保存系で安定。

</Porta>

<Porta nivel="40" titulo="シニア専門家向け">

運動学は、導関数が形式主義から物理的測定へと転じる場所です。

### 歴史的展望

**ガリレイ（1638年）** *Discorsi*で幾何学的な比例を使用して自由落下は$s \propto t^2$であることを実験的に推論しました（微積分なし）。**ニュートン（1687年）** *Principia*で$F = ma$を形式化し、それを記述するために微積分を発明しました。**ラグランジュ（1788年）** と**ハミルトン（1835年）** はすべてを変分的に書き直しました：軌道は$\int L\, dt$の極値です。

### 特殊相対論

$v \to c$の場合：位置と時間が混在します。固有速度$u^\mu = dx^\mu/d\tau$（四元ベクトル）。四元運動量保存$p^\mu = mu^\mu$は$F = ma$を一般化します。「導関数」はChristoffel記号による共変導関数になります。

### 量子力学

位置演算子$\hat{X}$と運動量演算子$\hat{P}$は$[\hat{X}, \hat{P}] = i\hbar$に従います。Heisenberg方程式：$d\hat{A}/dt = \frac{i}{\hbar}[\hat{H}, \hat{A}]$ -- 古典力学のPoisson括弧$\{A, H\}_\text{Poisson}$の量子類似物。

### 流体力学

物質微分$D/Dt = \partial_t + \vec{v}\cdot\nabla$は流体と共に移動する粒子の加速度を捉えます。Navier-Stokes：$\rho D\vec{v}/Dt = -\nabla p + \mu\nabla^2\vec{v} + \rho\vec{g}$。

### ロボティクスと最適制御

最適軌跡問題：$\int_0^T j(t)^2\, dt$を境界条件下で最小化 -- 5次多項式（*minimum-jerk trajectory*）につながります。工業用マニピュレータ、自律型、および手術用アームで使用されています。

### Nobel賞と導関数

[1921年ノーベル物理学賞](https://www.nobelprize.org/prizes/physics/1921/)はEinsteinに光電効果で授与されましたが、特殊相対論（1905年）-- 時空の導関数を再定義する -- は既に完成していました。すべての相対論的運動学は、Minkowski時空の微分構造の上に成立しています。

</Porta>

<Porta nivel="pratica" titulo="実践的な応用">

**6ステップのレシピ：**

1. **$s(t)$を特定**します -- 直接与えられる、または$v$の積分として。
2. **導関数を求める**：$v = s'$、$a = s'' = v'$。
3. **物体が静止**：$v(t) = 0$を$t$について解きます。
4. **最大高さ/位置**：$v = 0$かつ$a < 0$のとき。
5. **距離（変位ではなく）**：$\int |v|\, dt$ -- $v$が符号を変える場所で符号を切り替えます。
6. **時間なしのMUV**：トリチェリ $v^2 = v_0^2 + 2a\Delta s$。

### 注意事項

- **速度ゼロ $\neq$ 加速度ゼロ**：球が最上位にあるとき$v = 0$かつ$a = -10$ m/s²。
- **変位対距離**：往復5 kmの自動車は変位ゼロですが距離は10 km。
- **$a$の符号**：$v$の符号と反対は減速を意味します。

### ブラジルの実データ

**ENEM 2023 — 物理**：自動車が$v_0 = 20$ m/sで$a = -4$ m/s²で制動します。制動距離：
$v^2 = v_0^2 + 2a\Delta s \Rightarrow 0 = 400 - 8\Delta s \Rightarrow \Delta s = 50$ m。

**0-100テスト**：Fiat Pulse (2023)は0-100 km/hを10.5秒で加速します。
$a_{\text{med}} = \Delta v / \Delta t = (100/3.6)/10.5 \approx 2.6$ m/s²。

### クイック検証 (Python/SymPy)

```python
import sympy as sp
t = sp.symbols('t', positive=True)
s = 100 - 5*t**2
v, a = sp.diff(s, t), sp.diff(s, t, 2)
t_chao = sp.solve(s, t)[0]
print(f"v(t)={v}, a(t)={a}, t_chao={t_chao}, v_chao={v.subs(t, t_chao)}")
```

## 解答付き例

<Exemplo titulo="3次位置関数：速度、停止点、移動距離">

**問題。** 物体の位置が$s(t) = t^3 - 6t^2 + 9t$メートル、$t \geq 0$です。(a) $v(t)$と$a(t)$を求めてください。(b) 物体はいつ静止していますか？(c) $[0, 4]$で移動した距離は？

**戦略。** $s$を導関数して$v$と$a$を得ます。$v$のゼロが停止の瞬間です。距離のために、$|v|$を積分します -- 各ゼロで符号を切り替えます。

**解。**

(a) $v(t) = 3t^2 - 12t + 9 = 3(t-1)(t-3)$。 $a(t) = 6t - 12$。

(b) $v = 0 \Rightarrow t = 1$または$t = 3$。

(c) $v > 0$ ($[0,1)$で)；$v < 0$ ($(1,3)$で)；$v > 0$ ($(3,4]$で)。

$d = |s(1)-s(0)| + |s(3)-s(1)| + |s(4)-s(3)|$

$= |4 - 0| + |0 - 4| + |4 - 0| = 4 + 4 + 4 = 12$ m。

全体の変位：$s(4) - s(0) = 4$ m（距離よりずっと小さい！）。

**検証。** $v(1) = 3(0)(-2) = 0$ ✓；$v(3) = 3(2)(0) = 0$ ✓；$a(1) = -6 < 0$（$t=1$で減速） ✓。

**出典。** [Active Calculus §1.1, Exercise 1.1.4](https://activecalculus.org/single/sec-1-1-vel.html) — Boelkins · CC-BY-NC-SA。

<Exemplo titulo="初速度付き自由落下：落下時間と衝撃速度">

**問題。** 石が$h = 80$ m の塔から初速度$v_0 = 10$ m/sで下へ投げられます。$g = 10$ m/s²を採用し、原点を地面に取る（正は上向き）とき、以下を求めてください：(a) $s(t)$、(b) 衝撃時刻$t^*$、(c) 衝撃時の速度。

**戦略。** 初期条件$s(0) = 80$、$v(0) = -10$（負は下向き）で$s(t)$を立てます。$s(t^*) = 0$を解きます。

**解。**

$s(t) = 80 - 10t - 5t^2$。

$s(t^*) = 0 \Rightarrow 5t^2 + 10t - 80 = 0 \Rightarrow t^2 + 2t - 16 = 0$。

$t^* = \dfrac{-2 + \sqrt{4 + 64}}{2} = \dfrac{-2 + \sqrt{68}}{2} \approx \dfrac{-2 + 8.25}{2} \approx 3.12$ s。

$v(t^*) = -10 - 10(3.12) \approx -41.2$ m/s。 速さ： $\approx 41.2$ m/s $\approx 148$ km/h。

**検証。** $s(3.12) = 80 - 31.2 - 48.7 \approx 0.1 \approx 0$ ✓。 トリチェリ：$v^2 = 100 + 2(10)(80) = 1700 \Rightarrow v \approx 41.2$ m/s ✓。

**出典。** [OpenStax Calculus Vol. 1 §3.4, Example 3.33](https://openstax.org/books/calculus-volume-1/pages/3-4-derivatives-as-rates-of-change) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="単振動：振幅、周期、およびエネルギー">

**問題。** 質量$m = 2$ kgがばね定数$k = 50$ N/mのばねに取り付けられており、$A = 0.2$ mだけずれて静かに放されます。(a) $x(t)$を書き出してください。(b) 最大速度。(c) 機械エネルギー$E = \frac{1}{2}mv^2 + \frac{1}{2}kx^2$が定数であることを示してください。

**戦略。** $\omega = \sqrt{k/m}$。$x(0) = A$と$v(0) = 0$を使用：位相$\phi = 0$。エネルギー：$x$と$v$を代入し、三角恒等式で単純化します。

**解。**

$\omega = \sqrt{50/2} = 5$ rad/s。 $T = 2\pi/5 \approx 1.26$ s。

$x(t) = 0.2\cos(5t)$。

$v(t) = -0.2 \cdot 5 \sin(5t) = -\sin(5t)$ m/s。

最大速度：$|v|_{\max} = A\omega = 0.2 \cdot 5 = 1$ m/s（平衡点）。

エネルギー：
$$E = \tfrac{1}{2}(2)(-\sin 5t)^2 + \tfrac{1}{2}(50)(0.2\cos 5t)^2 = \sin^2(5t) + \cos^2(5t) = 1 \text{ J (定数)。 ✓}$$

**検証。** $t = 0$：$x = 0.2$、$v = 0$、$E = 0 + \frac{1}{2}(50)(0.04) = 1$ J ✓。

**出典。** [Active Calculus §1.5, Exercise 1.5.3](https://activecalculus.org/single/sec-1-5-units.html) — Boelkins · CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="空気抵抗：終端速度と解析解">

**問題。** 質量$m = 1$ kg の粒子が重力$g = 10$ m/s²で線形抵抗$F_{\text{arr}} = bv$、$b = 0.5$ kg/sで落下を始めます。(a) $v(t)$の常微分方程式を書いて解いてください。(b) 終端速度。(c) $v$が$v_\infty$の90%に達するのに何秒ですか？

**戦略。** 1階の分離可能な常微分方程式：$m\dot{v} = mg - bv$。変数分離。

**解。**

$\dot{v} = 10 - 0.5v$。解：$v(t) = v_\infty(1 - e^{-bt/m})$ただし$v_\infty = mg/b = 10/0.5 = 20$ m/s。

$v(t) = 20(1 - e^{-0.5t})$。

$v_\infty$の90%：$20(1 - e^{-0.5 t_{90}}) = 18 \Rightarrow e^{-0.5 t_{90}} = 0.1 \Rightarrow t_{90} = 2\ln(10)/0.5 \approx 4.6$ s。

**検証。** $v(0) = 0$ ✓。 $\lim_{t\to\infty} v(t) = 20$ m/s ✓。 $v'(0) = 20 \cdot 0.5 = 10$ m/s² = $g$ ✓。

**出典。** [APEX Calculus §2.4, Example 2.4.4](https://www.apexcalculus.com/) — Hartman et al. · CC-BY-NC。

</Exemplo>

<Exemplo titulo="円運動：導関数による向心加速度">

**問題。** 点が半径$R = 3$ m の円周を一定の角周波数$\omega = 2$ rad/sで通過します。位置は$\vec{r}(t) = 3(\cos 2t, \sin 2t)$です。以下を計算してください：(a) $\vec{v}(t)$と$|\vec{v}|$、(b) $\vec{a}(t)$そして$\vec{a} = -\omega^2\vec{r}$であることを示してください。

**戦略。** 各成分を独立に導関数します。$\vec{a}$の方向を特定します。

**解。**

$\vec{v}(t) = 3(-2\sin 2t, 2\cos 2t) = (-6\sin 2t, 6\cos 2t)$。

$|\vec{v}| = 6$ m/s（定数）= $R\omega = 3 \cdot 2$ ✓。

$\vec{a}(t) = (-12\cos 2t, -12\sin 2t) = -4(3\cos 2t, 3\sin 2t) = -4\vec{r}$。

$\omega^2 = 4$なので：$\vec{a} = -\omega^2\vec{r}$。大きさ：$|\vec{a}| = 12 = R\omega^2 = 3 \cdot 4$ ✓。

**検証。** $\vec{v} \cdot \vec{r} = 3 \cdot(-6\sin 2t\cos 2t + 6\cos 2t\sin 2t) = 0$ -- 等速円運動で速度は位置に垂直 ✓。

**出典。** [OpenStax Calculus Vol. 1 §3.4, Example 3.35](https://openstax.org/books/calculus-volume-1/pages/3-4-derivatives-as-rates-of-change) — CC-BY-NC-SA。

</Exemplo>
