### 凹凸性と凸性

<Definicao titulo="凸関数（上に凸）">
$f: I \to \mathbb{R}$が区間$I$で**凸**であるとは、すべての$x_1, x_2 \in I$と$t \in [0,1]$に対して
$$f(tx_1 + (1-t)x_2) \leq t\,f(x_1) + (1-t)\,f(x_2)$$
が成り立つことです。幾何学的には、$(x_1, f(x_1))$と$(x_2, f(x_2))$を結ぶ直線が**グラフの上または上に**位置します。
</Definicao>

> "The function $f$ is concave up on an interval $I$ if $f''(x) \geq 0$ for all $x \in I$." — [OpenStax Calculus Vol. 1 §4.5](https://openstax.org/books/calculus-volume-1/pages/4-5-derivatives-and-the-shape-of-a-graph)

**二次導関数による判定法：** $f$が$I$で二回微分可能ならば

- $f''(x) \geq 0$ on $I$ $\iff$ $f$は凸（上に凸）。
- $f''(x) \leq 0$ on $I$ $\iff$ $f$は凹（下に凸）。
- $f''(x) > 0$ 厳密に $\Rightarrow$ 厳密な凸性。

### 変曲点

<Definicao titulo="変曲点">
$x_0$が$f$の**変曲点**であるとは、$f$が$x_0$で連続で、かつ$f''$が$x_0$を通過する際に**符号を変える**ことです。
</Definicao>

**注意：** $f''(x_0) = 0$は必要条件ですが十分条件ではありません。典型的な反例：$f(x) = x^4$は$f''(0) = 0$ですが、$f''(x) \geq 0$が$0$の近傍全体で成り立ちます。符号の変化がないため、$0$は変曲点ではありません。

> "If the concavity changes at a point $(x_0, f(x_0))$, we call this a point of inflection. It must be the case that $f''(x_0)$ changes sign." — [APEX Calculus §3.4](https://www.apexcalculus.com/downloads)

### 極値判定の二次導関数テスト

<Teorema titulo="二次導関数テスト">
$f'(x_0) = 0$とします。このとき
- $f''(x_0) > 0$ $\Rightarrow$ $x_0$は**極小**。
- $f''(x_0) < 0$ $\Rightarrow$ $x_0$は**極大**。
- $f''(x_0) = 0$ $\Rightarrow$ **判定不可能**（より高階の導関数か$f'$の符号検定を使用）。
</Teorema>

**極小の証明：** $f'(x_0) = 0$で$f''(x_0) > 0$ならば、$f''$の連続性により$f''(x) > 0$が成り立つ近傍が存在します。したがって$f'$はこの近傍で増加しています。$f'(x_0) = 0$なので、$x_0$の左で$f' < 0$、右で$f' > 0$です。一次導関数判定法により、$x_0$は極小です。∎

<Insight titulo="ジェンセンの不等式">
$f$が凸 $\Rightarrow$ $f\!\left(\frac{x_1 + x_2}{2}\right) \leq \frac{f(x_1) + f(x_2)}{2}$。より一般に：確率変数$X$について、$f(E[X]) \leq E[f(X)]$。情報理論、熱力学、機械学習の基礎。
</Insight>

<Porta nivel="5" titulo="5歳児向け">

アイスクリームの**お椀**を空のまま上向きにして見てください。中央が下に落ち込む曲線です（$\cap$の形）。今度は普通のお椀を持ってください。中央が上に盛り上がっています（$\cup$の形）。

- 普通のお椀は**上に凸**です。アイスクリームを落とすと、真ん中に転がっていきます。
- 逆さまのお椀は**下に凸**です。アイスクリームは外に転がり落ちます。

**変曲点**は曲線が「お椀から帽子へ」（またはその逆）に**切り替わる瞬間**です。曲線が一瞬逆さまになるのです。

</Porta>

<Porta nivel="10" titulo="10歳児向け">

**二次導関数**$f''$は導関数の導関数です。これは**傾きがどのように変わっているか**を測ります。

- $f'' > 0$ならば：傾き$f'$が**増加**しています。グラフは$\cup$のように上に曲がります。
- $f'' < 0$ならば：傾き$f'$が**減少**しています。グラフは$\cap$のように下に曲がります。

**$f(x) = x^3$の例：**

$f'(x) = 3x^2$, $f''(x) = 6x$.

- $x < 0$のとき：$f'' < 0$ — グラフが下に曲がります。
- $x > 0$のとき：$f'' > 0$ — グラフが上に曲がります。
- $x = 0$のとき：$f''$が符号を変えます。**変曲点！**

**なぜ大事なのか？** $f'(x) = 0$の点が極大（グラフが下に曲がる=帽子）か極小（グラフが上に曲がる=お椀）かを判定するのです。

</Porta>

<Porta nivel="15" titulo="15歳向け">

凹凸性は$f'$の「物語」を完成させ、グラフの形を描きます：

| $f'$の符号 | $f''$の符号 | 挙動 |
|---|---|---|
| $+$ | $+$ | 増加＋加速（$\cup$上昇） |
| $+$ | $-$ | 増加＋減速 |
| $-$ | $+$ | 減少＋減速 |
| $-$ | $-$ | 減少＋加速（$\cap$下降） |

### 極値判定の二次導関数テスト

$f'(x_0) = 0$ならば：
- $f''(x_0) > 0$：**極小**（お椀）。
- $f''(x_0) < 0$：**極大**（帽子）。
- $f''(x_0) = 0$：**判定不可能** — $f'$の周辺で符号検定を実行。

### 変曲点：符号の変化が必須、ゼロだけでは不足

変曲点は$f''$が**符号を変える**点です。例：$f(x) = e^{-x^2/2}$（ガウス分布）。$f''(x) = (x^2-1)e^{-x^2/2}$。$x = \pm 1$で符号が変わります。標準正規分布（$\sigma = 1$）の場合、変曲点は$\mu \pm \sigma$にあります。

### 応用例

- **経済学：** 利益は$\pi'' < 0$の点で最大。$C(q)$の変曲点=限界利益の変化。
- **物理：** ポテンシャル$U$の最小値（$U'' > 0$）=安定平衡。小振動の周波数：$\omega = \sqrt{U''(x^*)/m}$。
- **統計学：** ガウス分布の変曲点は曲線の「中央」を定義します。

</Porta>

<Porta nivel="25" titulo="エンジニア学生向け">

凹凸性は最適化、機械学習、安定性分析の中心概念です。

### グローバル凸性と最適化

$f$が$I$で凸 $\Rightarrow$：
- すべての局所最小値は**グローバル**。
- 最小化点の集合は**凸**。
- 勾配法は（軽い条件下で）唯一の最小値に収束。

実際の応用：線形回帰では損失関数$L(\beta) = \|y - X\beta\|^2$は凸二次関数です（ヘッシアン$H = 2X^TX$は半正定値）。したがって$\nabla L = 0$は唯一の大域最小値$\hat\beta = (X^TX)^{-1}X^Ty$を与えます。

### 標準的な凸関数

- $x^2$, $e^x$, $-\ln x$ （$(0,\infty)$上）, $x\ln x$, $\max(0, x)$ （ReLU）。
- 凸関数の和は凸。凸関数の最大値は凸。
- $h(g(x))$は$h$が凸で増加、$g$が凸なら凸。

### シグモイド：非凸、変曲点は0

$\sigma(x) = 1/(1 + e^{-x})$は$\sigma''(x) = \sigma(x)(1 - \sigma(x))(1 - 2\sigma(x))$です。これは$x = 0$で符号を変えます — 変曲点。シグモイドを持つニューラルネットワークはパラメータ空間で**非凸**です。これが最適化をNP困難にします（ReLU が部分凸性を維持するのはこのため）。

### ML のジェンセン不等式

$f$が凸 $\Rightarrow$ $E[f(X)] \geq f(E[X])$。$f = -\ln$を使うと：$E[-\ln X] \geq -\ln E[X]$ — これはエントロピーの基礎です。VAE の ELBO（変分下界）導出も同じく。

### ヘッシアンと最適化景観

臨界点でのヘッシアン$H(x)$：正固有値=局所最小、負=局所最大、混在=鞍点。深い神経ネットワークでは臨界点のほぼすべてが**鞍点**です。これは SGD 収束に影響します。

</Porta>

<Porta nivel="40" titulo="シニア専門家向け">

凸性は現代最適化の中心であり、幾何学、確率、統計物理学に深い分岐を持ちます。

### 凸解析（Rockafellar, 1970）

中心的な概念：
- **部分微分** $\partial f(x)$：非微分可能な凸関数（例$|x|$）に対する$\nabla f$の一般化。
- **Fenchel 双対：** $f^*(p) = \sup_x(p\cdot x - f(x))$。根本的な双対性：$(f^*)^* = f$ （下半連続性の下で）。
- **サポート関数** $\sigma_C(x) = \sup_{y \in C} \langle x, y\rangle$：凸集合を特徴付け、線形計画法の基礎。

### 微分幾何学

ヘッシアンが二次形式を定義：符号（正定値、不定など）が極値 vs 鞍点を決定。リーマン多様体では**曲率断面**が$f''$を一般化：正=球面、負=双曲平面。リッチ曲率は一般相対論に現れます。

### 統計力学と相転移

自由エネルギー$F(\beta) = -\ln Z(\beta)$は$\beta = 1/T$で**凸**です — 比熱$C_V = k_B\beta^2\partial_\beta^2 \ln Z \geq 0$ （第二法則）。$F(T)$の変曲点は二次相転移（Landau, 1937）を示します。

### 凸最適化理論

凸問題は多項式時間で解けます（Khachiyan 1979 — 楕円体法；Karmarkar 1984 — 内点法）。階層：LP ⊂ QP ⊂ SOCP ⊂ SDP。ライブラリ：CVXPY, MOSEK, Gurobi。

### ML：損失景観と汎化

Keskar et al. (2017) が示したこと：「広い」最小値（ヘッシアンの固有値が小さい）は「狭い」最小値より汎化が優れています。直感：広い最小値は訓練集合の摂動に対して頑健 — これは最小値周辺で$f'' \ll 1$に対応します。2024-2026 年の活発な研究領域。

### 歴史的背景

Hadamard (1893) が$f''$を使い厳密な極値判定法。Minkowski (1896) 凸幾何学。Carathéodory, Fenchel, Moreau が20世紀に凸解析を確立。Boyd & Vandenberghe (2004) が『凸最適化』で標準化 （[web.stanford.edu/~boyd/cvxbook](https://web.stanford.edu/~boyd/cvxbook/) で無料配布）。

</Porta>

<Porta nivel="pratica" titulo="実践的な応用">

**5ステップの処方箋：**

1. **$f''(x)$を計算します。**
2. **ゼロと等式化**して変曲点の候補を見つけます。
3. **各区間で$f''$の符号をテスト**します。符号の変化=変曲点。
4. **臨界点（$f' = 0$）を分類**します：$f''$の符号が最小値、最大値、判定不可を決定。
5. **凹凸表を作成**してスケッチを描きます。

### 標準表

| 区間 | $f''$の符号 | 凹凸性 | 視覚的挙動 |
|---|---|---|---|
| $(-\infty, x_0)$ | $+$ | 上に凸 | $\cup$ |
| $(x_0, +\infty)$ | $-$ | 下に凸 | $\cap$ |

$x_0$での符号の変化が変曲点を確認します。

### Python/SymPy 検証

```python
import sympy as sp
x = sp.symbols('x')
f = x**3 - 3*x
f2 = sp.diff(f, x, 2)
inflexoes = sp.solve(f2, x)  # 候補
print("f'' =", f2, "| 候補:", inflexoes)
# 各候補周辺で符号をチェック
```

### 応用：限界逓減

生産コスト（限界収益逓減）：$C(q) = q^3 - 6q^2 + 15q + 100$。$C'' = 6q - 12 = 0$で$q = 2$。$q < 2$：$C'' < 0$（限界コスト逓減、規模の経済）。$q > 2$：$C'' > 0$（限界コスト増加、容量圧力）。$q = 2$の変曲点=**生産レジーム変化**。

## 解く例

<Exemplo titulo="f(x) = x^3 - 3x の凹凸性と変曲点（基本）" numero="1">

**問題。** $f(x) = x^3 - 3x$について、凹凸区間と変曲点を求めます。

**戦略。** $f''$を計算し、正負区間を判定し、ゼロ点で符号変化を確認。

**解法。**

1. **導関数：** $f'(x) = 3x^2 - 3$, $f''(x) = 6x$.
2. **$f''$のゼロ：** $6x = 0 \Rightarrow x = 0$.
3. **符号：** $f''(x) < 0$ for $x < 0$ （下に凸）; $f''(x) > 0$ for $x > 0$ （上に凸）。
4. **変曲点：** $f''$が$x = 0$で符号を変えます。点$(0, f(0)) = (0, 0)$が変曲点。

**検証。** スケッチ：$f(-2) = -8 + 6 = -2$; $f(0) = 0$; $f(2) = 8 - 6 = 2$。曲線は$-2$から$0$まで下に凸で上昇、$0$から$2$まで上に凸で上昇。一貫性あり ✓

**出典。** [APEX Calculus §3.4, Example 3.4.1](https://www.apexcalculus.com/downloads) — CC-BY-NC.
</Exemplo>

<Exemplo titulo="f(x) = x^4 - 4x^2 の極値判定（中級）" numero="2">

**問題。** $f(x) = x^4 - 4x^2$の臨界点を二次導関数テストで分類します。

**戦略。** $f' = 0$から臨界点を見つけ、各点で$f''$を計算し基準を適用。

**解法。**

1. **$f'(x) = 4x^3 - 8x = 4x(x^2 - 2) = 0 \Rightarrow x = 0,\, x = \pm\sqrt{2}$.**
2. **$f''(x) = 12x^2 - 8$.**
3. **評価：**
   - $f''(0) = -8 < 0$ $\Rightarrow$ **極大** at $x = 0$. $f(0) = 0$.
   - $f''(\sqrt{2}) = 24 - 8 = 16 > 0$ $\Rightarrow$ **極小** at $x = \sqrt{2}$. $f(\sqrt{2}) = 4 - 8 = -4$.
   - $f''(-\sqrt{2}) = 16 > 0$ $\Rightarrow$ **極小** at $x = -\sqrt{2}$. $f(-\sqrt{2}) = -4$.

**検証。** $x \to \pm\infty$で$f(x) \to +\infty$なので、$\pm\sqrt{2}$の最小値は大域最小で、$0$は局所最大。✓

**出典。** [OpenStax Calculus Vol. 1 §4.5, Example 4.38](https://openstax.org/books/calculus-volume-1/pages/4-5-derivatives-and-the-shape-of-a-graph) — CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="ガウス分布の変曲点（中級）" numero="3">

**問題。** $f(x) = e^{-x^2/2}$（正規分布の核）の変曲点を見つけます。

**戦略。** 二次微分し、$f'' = 0$と置いて符号を確認。

**解法。**

1. **$f'(x) = -x\,e^{-x^2/2}$.**
2. **$f''(x) = -e^{-x^2/2} + x^2 e^{-x^2/2} = (x^2 - 1)e^{-x^2/2}$.**
3. **$f''$のゼロ：** $x^2 - 1 = 0 \Rightarrow x = \pm 1$.
4. **符号：**
   - $|x| > 1$: $x^2 - 1 > 0 \Rightarrow f'' > 0$ （上に凸）。
   - $|x| < 1$: $x^2 - 1 < 0 \Rightarrow f'' < 0$ （下に凸）。
5. **変曲点：** $x = \pm 1$で$f''$が符号を変える。点：$(\pm 1, e^{-1/2}) \approx (\pm 1, 0.607)$。

**検証。** $\mathcal{N}(\mu, \sigma^2)$の変曲点は$\mu \pm \sigma$にあります。ここ$\mu = 0$, $\sigma = 1$ — 一貫。✓

</Exemplo>

<Exemplo titulo="判定不可ケース：f'' = 0 だが変曲点ではない（高度）" numero="4">

**問題。** $f(x) = x^4$について、$f''(0) = 0$ですが$x = 0$は変曲点ではなく局所最小であることを確認。

**戦略。** $x = 0$の周辺で$f''$が符号を変えないことを示す。

**解法。**

1. **$f'(x) = 4x^3 = 0 \Rightarrow x = 0$** （臨界点）。
2. **$f''(x) = 12x^2 \geq 0$ for all $x$。** 特に$f''(0) = 0$ — テスト不可。
3. **だが$f''(x) \geq 0$ in a neighborhood of 0**：符号は変わりません。
4. **結論：** $x = 0$は変曲点ではありません。大域最小（$f(x) = x^4 \geq 0$）。
5. **一次導関数テストで確認：** $f'(x) = 4x^3 < 0$ for $x < 0$ and $f'(x) > 0$ for $x > 0$ — 最小確認。

**検証。** グラフ$x^4$は「平ら」な底を持つ放物線 — 視覚的に最小値。✓

**出典。** [APEX Calculus §3.4, Note after Example 3.4.2](https://www.apexcalculus.com/downloads) — CC-BY-NC.
</Exemplo>

<Exemplo titulo="限界逓減コスト — 経済の変曲点（モデル化）" numero="5">

**問題。** 企業の生産コスト$C(q) = q^3 - 6q^2 + 15q + 100$（レアル）。変曲点を見つけ、経済的に解釈。

**戦略。** $C''$を計算し、変曲点を見つけ、限界コスト$MC = C'$の挙動を分析。

**解法。**

1. **$C'(q) = 3q^2 - 12q + 15 = MC(q)$** （限界コスト）。
2. **$C''(q) = 6q - 12$.**
3. **変曲点：** $C''(q) = 0 \Rightarrow q = 2$.
4. **$C''$の符号：** $q < 2$では$C'' < 0$ （限界コスト逓減 — 規模の経済）。$q > 2$では$C'' > 0$ （限界コスト増加 — 容量圧力）。
5. **変曲点：** $C(2) = 8 - 24 + 30 + 100 = 114$. 点$(2, 114)$。

**検証。** $MC(0) = 15$, $MC(2) = 12 - 24 + 15 = 3$, $MC(4) = 48 - 48 + 15 = 15$。$MC$は$q = 2$で最小 — $C$の変曲点と一貫。✓

**出典。** [Active Calculus §3.1, Exercise 3.1.5](https://activecalculus.org/single/sec-3-1-tests.html) — CC-BY-NC-SA.
</Exemplo>
