<Porta nivel="formal" titulo="定義、最大化、弾力性">

### 限界関数

<Definicao titulo="費用、収益、利益と限界">
与えられたもの：
- $C(q)$：$q$単位を生産する**総費用**。
- $R(q) = p(q) \cdot q$：**総収益**（完全競争では$p$は固定；独占では$p$は$q$に依存）。
- $\pi(q) = R(q) - C(q)$：**利益**。

**限界**は導関数です：
$$MC(q) = C'(q), \quad MR(q) = R'(q), \quad M\pi(q) = \pi'(q) = MR(q) - MC(q).$$
$MC(q)$は$(q+1)$番目の単位を生産するコストを近似します。
</Definicao>

> "限界費用関数は$C'(x)$で、これは費用関数の導関数です。限界収益関数は$R'(x)$です。" — [OpenStax Calculus Vol. 1 §4.7](https://openstax.org/books/calculus-volume-1/pages/4-7-applied-optimization-problems)

### 利益の最大化

$\pi'(q) = 0 \iff MR(q) = MC(q)$。

**2階条件：** $\pi''(q^*) < 0 \iff MR'(q^*) < MC'(q^*)$ — 限界費用が限界収益より速く増加します。

### 平均費用と限界費用

<Definicao titulo="平均費用">
$\bar{C}(q) = C(q)/q$。微分すると：
$$\bar{C}'(q) = \frac{C'(q) \cdot q - C(q)}{q^2} = \frac{MC(q) - \bar{C}(q)}{q}.$$
</Definicao>

したがって：$\bar{C}'(q) = 0 \iff MC(q) = \bar{C}(q)$。**限界費用曲線が平均費用曲線と交わる点は、ちょうど平均費用の最小値です。**

### 需要の価格弾力性

<Definicao titulo="価格弾力性">
需要関数$q = D(p)$に対して：
$$\varepsilon(p) = \frac{dq}{dp} \cdot \frac{p}{q} = D'(p) \cdot \frac{p}{q}.$$
- $|\varepsilon| > 1$：需要は**弾力的**（贅沢品、代替品がある商品）。価格を下げると収益が増えます。
- $|\varepsilon| < 1$：需要は**非弾力的**（必需品 — 塩、ガソリン）。価格を上げると収益が増えます。
- $|\varepsilon| = 1$：**単位弾力性**。収益は最大化されます。
</Definicao>

### 独占の価格設定

量$q$を選ぶ独占者（そして間接的に$p$を選ぶ）に対して：

$$MR = p + q\,\frac{dp}{dq} = p\!\left(1 + \frac{1}{\varepsilon}\right).$$

利益最大化（$MR = MC$）は**マークアップ規則**を与えます：
$$p^* = \frac{MC}{1 + 1/\varepsilon} = \frac{MC \cdot \varepsilon}{\varepsilon + 1}.$$

**ラーナー指数：** $L = (p - MC)/p = -1/\varepsilon$は市場力を測ります。

<Insight titulo="直線需要における弾力性">
直線需要$q = a - bp$に対して、弾力性$|\varepsilon| = bp/q$は$p$とともに増加します。$p = 0$で：$\varepsilon = 0$（非弾力的）。$q = 0$で：$|\varepsilon| \to \infty$（弾力的）。単位弾力性の点は需要曲線のちょうど中点で起こります — そこが収益最大化点です。
</Insight>

ビーチで**アイスキャンディー**を売ってるとしましょう。もう1本作るには、アイスクリームと木の棒が必要です — これが**限界費用**（もう1本作るのにかかるコスト）です。

あなたはアイスキャンディーをR$ 5.00で売ります。これが**限界収益**（もう1本売ったら得られるお金）です。

1本作るコストがR$ 5.00より少ないなら、作る価値があります。もう1本作るコストがちょうどR$ 5.00になったら、あなたは**完璧な点**にいます — そこからはお金を失い始めます。

この「もう1本作るコスト = もう1本売ったら得られるお金」という点が、**すべての利益が最大になる**ところです！

<Porta nivel="10" titulo="10歳の子どもへ">

経済学では、**導関数**が**限界**になります：

- $C(q)$ = $q$単位を生産する総費用。**MC** = $C'$ = **もう1単位**作るのにかかるコスト。
- $R(q)$ = 収益（入ってくるお金）。**MR** = $R'$ = **もう1単位**売ったら入ってくるお金。
- **利益最大化**：$MR > MC$の間は、もっと生産します。$MR = MC$になったら止めます。

**例：** $C(q) = 100 + 5q + 0{,}1q^2$（費用）、$p = 50$固定（競争）。$R = 50q$、$MR = 50$。$MC = 5 + 0{,}2q$。$MR = MC \Rightarrow 50 = 5 + 0{,}2q \Rightarrow q^* = 225$。

**弾力性**：価格を1%上げて数量が2%下がったら、弾力性は$-2$です。需要は**弾力的** — 価格に敏感です。

</Porta>

<Porta nivel="15" titulo="15歳のティーンへ">

限界分析は**ミクロ経済学の中核的な枠組み**です：すべての決定が「もう1単位作る価値があるか？」に帰着します。

### 基本構造

- **費用** $C(q)$：固定部分$F$ + 可変部分$V(q)$。
- **収益** $R(q) = p(q) \cdot q$。完全競争では$p$は与えられたもの；独占では$p$は$q$とともに低下します。
- **利益** $\pi(q) = R(q) - C(q)$。

### 平均費用対限界費用

$\bar{C}(q) = C(q)/q$：単位当たり費用。$MC(q) = C'(q)$：次の単位のコスト。

$\bar{C}$の最小値は$MC = \bar{C}$のところで起こります — もう1単位生産しても平均費用が低下しなくなるポイントです。

### 弾力性

$\varepsilon = (\Delta q/q)/(\Delta p/p)$：価格の百分比変化に対する数量の百分比変化。

- $|\varepsilon| > 1$：**弾力的** — 消費者は敏感です。例：航空券、ブランド衣類。
- $|\varepsilon| < 1$：**非弾力的** — 消費者は鈍感です。例：タバコ、医薬品、ガソリン。

### 作業済みの例

需要$q = 100 - 2p$（逆関数：$p = (100-q)/2$）。収益$R(q) = (100-q)q/2 = 50q - q^2/2$。

$MR(q) = 50 - q$。費用$C(q) = 10q + q^2/4$、$MC = 10 + q/2$。

$MR = MC \Rightarrow 50 - q = 10 + q/2 \Rightarrow 3q/2 = 40 \Rightarrow q^* \approx 26{,}7$。

</Porta>

<Porta nivel="25" titulo="工学部の学生へ">

限界分析は古典経済学、工学経済学、ファイナンス（限界効用）、オペレーションズリサーチ（動的価格設定）に登場します。

### 工学的な典型的費用関数

$C(q) = F + aq + bq^2 + cq^3$：固定費用$F$ + 線形（原材料） + 2次（超過勤務時間） + 3次（容量制約）。曲線$\bar{C}(q)$は$\cup$形です：規模で低下し、混雑で上昇します。

### 独占対完全競争

| | 完全競争 | 独占 |
|---|---|---|
| $p$ | 与えられたもの（価格受け取り人） | $p(q)$、選択される |
| $MR$ | $p$（定数） | $p + q\,dp/dq < p$ |
| 決定 | $MC = p$ | $MC = MR < p$ |
| 余剰 | 社会的に最大 | 過少生産 — デッドウェイト損失 |

### EOQ — 経済発注量

$T(q) = \frac{Dhq}{2} + \frac{SD}{q}$ここで$D$ = 年間需要、$h$ = 単位当たり年間維持費用、$S$ = 注文費用。$T'(q) = Dh/2 - SD/q^2 = 0 \Rightarrow q^* = \sqrt{2SD/h}$。在庫管理の標準的モデル。

### 動的価格設定と可変弾力性

Uber、航空会社、電子商取引は$\varepsilon$をリアルタイムで推定し、マークアップ$p = MC/(1 + 1/\varepsilon)$を通じて$p$を調整します。課題は観測データから$\varepsilon$を推定することです — 操作変数が標準的な方法です。

### 税金と帰着

単位あたりの税$t$：$MC \to MC + t$。新しい均衡：$q^*$は低下します。買い手と売り手の負担分割は弾力性に依存します：買い手の部分 $= \varepsilon_S/(\varepsilon_S - \varepsilon_D)$。

### ブラック・ショールズと限界分析

ポートフォリオ$\Pi = -V + \Delta S$ここで$\Delta = \partial V/\partial S$は**デルタ** — 限界オプション価格導関数です。リスク中立レプリケーション + 伊藤引理がブラック・ショールズPDEを与えます。[1997年経済学ノーベル賞](https://www.nobelprize.org/prizes/economic-sciences/1997/)はメルトンとショールズがこの導出で受賞しました。

</Porta>

<Porta nivel="40" titulo="シニア専門家へ">

限界分析は出発点です；現代経済学は一般均衡、確率力学、ゲーム理論で機能します。

### 一般均衡

ワルラス（1874）：すべての市場が同時均衡 — 各商品$i$に対して$MC_i = p_i$の方程式系。存在性は不動点定理で証明されました（Arrow-Debreu、1954 — [1972年経済学ノーベル賞](https://www.nobelprize.org/prizes/economic-sciences/1972/)）。競争的市場の効率性 = 福祉経済学の第1定理。

### ゲーム理論とナッシュ均衡

エージェントが相互作用するとき、ナッシュ（1950 — [1994年経済学ノーベル賞](https://www.nobelprize.org/prizes/economic-sciences/1994/)）は単独の最適化者を置き換えます。各エージェントは競争相手の行動を与えられた下で利益を最大化します — 1階条件は自分の選択に対する偏導関数です。クールノー、ベルトラン、スタッケルベルグはタイミングと構造をモデル化します。

### 確率制御最適化

Hamilton-Jacobi-Bellman：$V_t + \sup_u[f(x,u)V_x + \sigma^2/2 \cdot V_{xx}] = 0$。ベルマン方程式は限界1階条件を順序的意思決定に一般化します。ブラック・ショールズは$f$が線形でかつ制御がない特殊なケースです。

### 情報の非対称性

アカロフ（レモン市場、[2001年ノーベル賞](https://www.nobelprize.org/prizes/economic-sciences/2001/)）、スペンス（シグナリング）、スティグリッツ（スクリーニング）は標準的限界分析が情報非対称性では失敗することを示しました。介入がなければ非効率的均衡が出現します。

### 行動経済学

カーネマン（[2002年ノーベル賞](https://www.nobelprize.org/prizes/economic-sciences/2002/kahneman/facts/)）は限界合理性からの体系的乖離を文書化します：損失回避、アンカリング、双曲割引。限界分析は標準的ベンチマークのままです — しかし実際の行動は乖離します。

### キーンズ・ラムゼイ規則

動的モデルでは（Ramsey-Cass-Koopmans）、エージェントは$\int_0^\infty U(c(t)) e^{-\rho t} dt$を$\dot k = f(k) - c - \delta k$に従って最大化します。オイラー・ラグランジュ方程式は$\dot c/c = (f'(k) - \delta - \rho)/\sigma$を与えます — キーンズ・ラムゼイ規則。限界分析は変分法を通じて連続時間で機能します。

</Porta>

<Porta nivel="pratica" titulo="実践的な応用">

**5ステップのレシピ：**

1. $C(q)$と$p(q)$（または$q(p)$）を確認します。
2. $R(q) = p(q) \cdot q$、$MC = C'$、$MR = R'$を計算します。
3. $MR(q^*) = MC(q^*)$となる$q^*$を求めます。
4. 最大を確認：$\pi''(q^*) < 0$。
5. $p^* = p(q^*)$、$\pi^* = R(q^*) - C(q^*)$を計算します。

### クイック例 — ジュース会社

地元ジュース需要：$p(q) = 20 - 0{,}1q$（R$/瓶、$q$は単位/日）。費用：$C(q) = 200 + 5q + 0{,}05q^2$。

$R(q) = q(20 - 0{,}1q) = 20q - 0{,}1q^2$。$MR = 20 - 0{,}2q$。$MC = 5 + 0{,}1q$。

$MR = MC \Rightarrow 20 - 0{,}2q = 5 + 0{,}1q \Rightarrow 15 = 0{,}3q \Rightarrow q^* = 50$。

$p^* = 20 - 5 = 15$レアル。$\pi^* = 15 \times 50 - (200 + 250 + 125) = 750 - 575 = 175$レアル/日。

### 平均費用による検証

$\bar{C}(50) = 575/50 = 11{,}50$レアル。$p^* = 15 > \bar{C}$なので、会社は利益があります。✓

### 検証用Python

```python
import sympy as sp
q = sp.symbols('q', positive=True)
p_func = 20 - 0.1*q
R = p_func * q
C = 200 + 5*q + 0.05*q**2
profit = R - C
q_star = sp.solve(sp.diff(profit, q), q)
print(q_star, profit.subs(q, q_star[0]))
```

## 解いた例

<Exemplo titulo="限界費用と平均費用の最小値（基本）" numero="1">

**問題。** $C(q) = q^2 + 9$に対して、限界費用$MC$を見つけ、平均費用$\bar{C}$を最小にする量を見つけてください。

**戦略。** $MC = C'$を計算します。$\bar{C} = C/q$を微分して0と等しくして最小化します — または$MC = \bar{C}$の性質を最小値で使用します。

**解答。**

1. **$MC(q) = 2q$。**
2. **$\bar{C}(q) = q + 9/q$。**
3. **$\bar{C}'(q) = 1 - 9/q^2 = 0 \Rightarrow q^2 = 9 \Rightarrow q = 3$。**
4. **検証：** $\bar{C}(3) = 3 + 3 = 6$および$MC(3) = 6$。✓ — 最小平均費用が限界費用と一致します。

**検証。** $\bar{C}''(q) = 18/q^3 > 0$で$q = 3$：最小値が確認されました。✓

**出典。** [Yoshiwara — Modeling, Functions, and Graphs、第5章、演習5.3.9](https://yoshiwarabooks.org/mfg/Chap4.html) — オープンライセンス。
</Exemplo>

<Exemplo titulo="直線需要での利益最大化（中級）" numero="2">

**問題。** 需要$q = 100 - 2p$（逆関数：$p = 50 - q/2$）。費用$C(q) = 200 + 4q + q^2$。$q^*$、$p^*$、$\pi^*$を見つけてください。

**戦略。** $R(q)$、$MR$、$MC$を計算します。$MR = MC$と等しくして$q^*$を求めます。$\pi'' < 0$で確認します。

**解答。**

1. **$R(q) = pq = (50 - q/2)q = 50q - q^2/2$。$MR = 50 - q$。**
2. **$MC = 4 + 2q$。**
3. **$MR = MC \Rightarrow 50 - q = 4 + 2q \Rightarrow 3q = 46 \Rightarrow q^* \approx 15{,}3$。（近似；$q$が整数なら：$q^* = 15$。）**
4. **$p^* = 50 - 15/2 = 42{,}50$ R$。**
5. **$\pi^* = R(15) - C(15) = 637{,}50 - (200 + 60 + 225) = 637{,}50 - 485 = 152{,}50$ R$。**

**検証。** $\pi''(q) = -3 < 0$すべての$q$に対して — 最大値。✓

**出典。** [Yoshiwara — Modeling, Functions, and Graphs、第5章、演習5.3.15](https://yoshiwarabooks.org/mfg/Chap4.html) — オープンライセンス。
</Exemplo>

<Exemplo titulo="弾力性と最大収益（中級）" numero="3">

**問題。** 需要$q = 100 - 2p$。（a）$p = 20$での弾力性を計算してください。（b）収益が最大になる価格は何ですか？

**戦略。** $\varepsilon = D'(p) \cdot p/q$を適用します。$R = pq = p(100 - 2p)$を微分することで$R$を最大化します。

**解答。**

**(a) $p = 20$での弾力性：**
$D'(p) = -2$。$q(20) = 100 - 40 = 60$。
$\varepsilon = -2 \cdot 20/60 = -40/60 = -2/3$。

$|\varepsilon| < 1$なので：$p = 20$での需要は**非弾力的** — 価格を上げると収益が増えます。

**(b) 最大収益：**
$R(p) = p(100 - 2p) = 100p - 2p^2$。$R'(p) = 100 - 4p = 0 \Rightarrow p^* = 25$。

$R(25) = 25 \cdot 50 = 1250$ R$。検証：$\varepsilon(25) = -2 \cdot 25/50 = -1$（単位弾力性）。\checkmark

**検証。** $R'' = -4 < 0$ — 最大値が確認されました。\checkmark

**出典。** [Active Calculus §3.3、活動3.3.4](https://activecalculus.org/single/sec-3-3-optimization.html) — CC-BY-NC-SA。
</Exemplo>

<Exemplo titulo="経済発注量EOQ（実際のモデリング）" numero="4">

**問題。** 工場の年間需要$D = 10000$単位、注文費用$S = R\$\,200$/注文、保管費用$h = R\$\,4$/単位/年。経済発注量$q^*$を見つけてください。

**戦略。** $T(q) = Dhq/2 + SD/q$（年間総在庫費用 = 保管 + 注文）を最小化します。微分して0と等しくします。

**解答。**

1. **$T(q) = \frac{10000 \cdot 4}{2} q + \frac{200 \cdot 10000}{q} = 20000q + \frac{2000000}{q}$。**

    注意：値は簡略化されました：$T(q) = \frac{4q}{2} \cdot 10000/10000 + \ldots$ — 標準公式を直接使用すると：

**検証。** $T''(q) = 4000000/q^3 > 0$ — 最小値。✓ 直接公式$q^* = \sqrt{2SD/h} = \sqrt{2 \cdot 200 \cdot 10000/4} = \sqrt{1000000} = 1000$。✓

<Exemplo titulo="独占の価格設定と福祉損失（上級）" numero="5">

**問題。** 独占者の需要$p(q) = 100 - 2q$、費用$C(q) = q^2$。（a）独占均衡を見つけてください。（b）完全競争（$MC = p$）と比較してください。（c）福祉損失（デッドウェイト・ロス）を計算してください。

**戦略。** 独占：$MR = MC$。競争：$p = MC$。損失 = 2つの数量間の三角形の面積。

**解答。**

**(a) 独占：** $R = 100q - 2q^2$、$MR = 100 - 4q$。$MC = 2q$。$MR = MC \Rightarrow 100 - 4q = 2q \Rightarrow q_M = 100/6 \approx 16{,}7$。$p_M = 100 - 2(100/6) = 100 - 100/3 \approx 66{,}7$ R$。利益：$\pi = (p_M - \bar{C})q_M = \ldots \approx 833$ R$。

**(b) 競争：** $p = MC \Rightarrow 100 - 2q = 2q \Rightarrow q_C = 25$、$p_C = 50$ R$。

**(c) 福祉損失：** 独占は$16{,}7$ではなく$25$を生産します。損失は底辺$q_C - q_M \approx 8{,}3$、高さ$p_M - p_C \approx 16{,}7$の三角形の面積です：

デッドウェイト・ロス$\approx \frac{1}{2} \cdot 8{,}3 \cdot 16{,}7 \approx 69$ R$。

**検証。** $p_M > MC(q_M) = 2 \cdot 16{,}7 = 33{,}4$ — 独占は限界費用上を請求し、非効率性を確認します。✓

**出典。** [Yoshiwara — Modeling, Functions, and Graphs、第5章、演習5.3.20](https://yoshiwarabooks.org/mfg/Chap4.html) — オープンライセンス。
</Exemplo>
