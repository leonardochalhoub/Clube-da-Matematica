### 導関数の定義

<Definicao titulo="ある点での導関数">

$f: I \to \mathbb{R}$ を開区間 $I$ で定義された関数とし、$a \in I$ とします。$a$ における <strong>$f$ の導関数</strong> は極限

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

この極限が存在する（そして有限である）場合を指します。この場合、$f$ は $a$ で <strong>可微分</strong> であると言います。

**別形式** ($x = a + h$、$h = x - a$ の置換)：

$$f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$

</Definicao>

> "We say that a function $f$ is differentiable at $x = a$ whenever $f'(a)$ exists. […] The derivative measures the instantaneous rate of change of the function, as well as the slope of the tangent line to the function at the given point." — [Boelkins, Active Calculus §1.3](https://activecalculus.org/single/sec-1-3-derivative-pt.html)

> "The derivative of a function $f(x)$ at a point $a$ in its domain, if it exists, is $f'(a) = \lim_{h \to 0}\frac{f(a+h)-f(a)}{h}$." — [OpenStax Calculus Vol. 1, §3.1](https://openstax.org/books/calculus-volume-1/pages/3-1-defining-the-derivative)

### 等価な表記法

<Equation explicacao="以下の表記法はすべて同じオブジェクト、つまり f の導関数を表しています。Leibniz (dy/dx)、Lagrange (f')、Newton (ドット付き f)、演算子 D が最も使われます。" latex="f'(x) \;=\; \frac{df}{dx} \;=\; \frac{dy}{dx} \;=\; Df(x) \;=\; \dot{f}(x)" />

式 $\frac{df}{dx}\Big|_{x=a}$ は点 $a$ で評価された導関数を表します。

### 接線と法線

$f$ が $a$ で可微分であるとき：

- **接線** $(a, f(a))$ で：$\quad y - f(a) = f'(a)(x - a)$
- **法線** $(a, f(a))$ で（接線に垂直、$f'(a) \neq 0$ の場合）：$\quad y - f(a) = -\dfrac{1}{f'(a)}(x - a)$

### 可微分性の基本定理

<Teorema titulo="可微分性は連続性を含意する">

$f$ が $a$ で可微分ならば、$f$ は $a$ で連続です。

**証明。** $f(a+h) - f(a) = \dfrac{f(a+h) - f(a)}{h} \cdot h$ と書きます。$h \to 0$ のとき、第1因子は $f'(a)$ に収束し（仮説により）、$h \to 0$ です。したがって $f(a+h) - f(a) \to f'(a) \cdot 0 = 0$、すなわち $\lim_{h \to 0} f(a+h) = f(a)$。$\square$

**逆命題は偽です。** $f(x) = |x|$ は $0$ で連続ですが、$0$ で可微分ではありません（左右の導関数は $-1$ と $+1$ で異なります）。

</Teorema>

> "If $f$ is differentiable at $a$, then $f$ is continuous at $a$. […] The converse is not true, and a function can be continuous but fail to be differentiable at a point." — [OpenStax Calculus Vol. 1, §3.2](https://openstax.org/books/calculus-volume-1/pages/3-2-the-derivative-as-a-function)

### 非可微分性の点

<Definicao titulo="病的な点の分類">

- **角（コーナー）**：左右の導関数は存在するが異なります。例：$|x|$ を $x = 0$ で。
- **尖点**：$f'(x) \to \pm\infty$ 両側から。例：$x^{2/3}$ を $x = 0$ で。
- **垂直接線**：$f'(a) = +\infty$（または $-\infty$）。例：$\sqrt[3]{x}$ を $x = 0$ で。
- **不連続性**：$f$ が $a$ で連続でなければ、確実に可微分ではありません。

</Definicao>

### 定義による基本導関数

| 関数 $f(x)$ | $f'(x)$ |
|---|---|
| $c$（定数） | $0$ |
| $x$ | $1$ |
| $x^2$ | $2x$ |
| $x^3$ | $3x^2$ |
| $x^n$（$n \in \mathbb{Z}$） | $n x^{n-1}$ |
| $\dfrac{1}{x}$ | $-\dfrac{1}{x^2}$ |
| $\sqrt{x}$ | $\dfrac{1}{2\sqrt{x}}$ |

<Insight>

この表の各行は、公理ではなく、定義から証明された定理です。レッスン52-53は導関数化規則（和、積、商、鎖）を形式化します。これにより、新しい関数ごとに定義をやり直す必要がなくなります。ただし、既成の規則に適合しない新しい関数の導関数は、常に定義に帰着します。

</Insight>

<Porta nivel="5" titulo="5歳の子どもに向けて">

ある町から別の町へ向かう車に乗っているところを想像してください。時々、車は**ゆっくり**走ります。時々、**速く**走ります。

車のスピードメーターは、**今この瞬間**の速度を表しています。

**導関数**は数学的なスピードメーターのようなものです。「この関数が今どれくらい変わっているか」を示します。関数が急速に上昇していれば、導関数は大きいです。関数が止まっていれば、導関数はゼロです。

こう考えてみてください。あなたは10秒で100メートル歩きました。あなたの**平均速度**は秒速10メートルです。でも、その間ずっと同じ速度で歩いていたでしょうか？たぶん、最初は走って、後で歩くのが遅くなったのかもしれません。

**特定の秒間の正確な速度**—それが導関数です。

</Porta>

<Porta nivel="10" titulo="10歳の子どもに向けて">

あなたは既に**平均速度**の計算方法を知っています：距離を時間で割ります。100メートルを10秒で歩いたら、平均速度 = 秒速10メートル。

でも、**この瞬間**の速度は？そのために、非常に小さい時間間隔を取り、その間隔での平均速度を計算して、間隔をどんどん小さくしていきます。

**導関数**は、区間が無限に小さくなるときに起こることです—それは関数の「瞬間速度」です。

**実践例**：あなたの位置が $s(t) = t^2$（メートル）の場合、$t = 3$ 秒のときは？

- 1秒の間隔：$\frac{s(4) - s(3)}{1} = \frac{16 - 9}{1} = 7$ m/s
- 0.1秒の間隔：$\frac{s(3{,}1) - s(3)}{0{,}1} = \frac{9{,}61 - 9}{0{,}1} = 6{,}1$ m/s
- 0.01秒の間隔：$\frac{s(3{,}01) - s(3)}{0{,}01} = \frac{9{,}0601 - 9}{0{,}01} = 6{,}01$ m/s
- 極限では：正確な速度 = **秒速6メートル**。

数字の6は、点 $t = 3$ における $s(t) = t^2$ の導関数です。

</Porta>

<Porta nivel="15" titulo="15歳の十代の少年少女に向けて">

$a$ と $a + h$ の間の $f$ の **平均変化率** は：

$$\frac{f(a+h) - f(a)}{h}$$

幾何学的には、これは点 $(a, f(a))$ と $(a+h, f(a+h))$ を通る **割線** の傾きです。

$h \to 0$ のとき、割線は「回転」して、$(a, f(a))$ でのグラフへの **接線** に近づきます。この接線の傾きが導関数 $f'(a)$ です。

### 定義による計算のレシピ

1. $f(a + h)$ を計算—$x$ を $a + h$ に置き換えます。
2. $f(a)$ を引いて、$h$ で割ります。
3. **代数的に簡略化**—分母の $h$ をキャンセルします。
4. 極限 $h \to 0$ を取ります。

### 例：$f(x) = x^2$

$$f'(a) = \lim_{h \to 0} \frac{(a+h)^2 - a^2}{h} = \lim_{h \to 0} \frac{a^2 + 2ah + h^2 - a^2}{h} = \lim_{h \to 0} \frac{2ah + h^2}{h} = \lim_{h \to 0} (2a + h) = 2a$$

したがって $f'(x) = 2x$—$x^2$ の導関数は $2x$ です。

### 導関数が存在しない場合

- **角**：$|x|$ を $x = 0$ で—左から $f'_-(0) = -1$、右から $f'_+(0) = +1$。異なる：導関数なし。
- **不連続性**：$f$ が跳ねば、定義された接線を持つことはできません。

<Insight>

導関数は微積分の中心的な概念です。速度（位置の導関数）、加速度（速度の導関数）、限界費用（費用の導関数）、瞬時利息（資本の導関数）—すべてが導関数です。限界を通じて定義を学ぶことは、これらの考え方のDNAを学ぶことです。

</Insight>

</Porta>

<Porta nivel="25" titulo="工学部生向けに">

限界を通じた定義は **基礎** です。導関数化規則（レッスン52）と連鎖律（レッスン53）は、この定義から証明された定理です。計算だけでなく、**結果を実証する** ために、それを習得する必要があります。

### 実証：可微分性は連続性を含意する

$f'(a)$ が存在するとしましょう。次のように書きます：

$$f(a+h) - f(a) = \frac{f(a+h) - f(a)}{h} \cdot h \;\xrightarrow{h \to 0}\; f'(a) \cdot 0 = 0$$

極限への移行は：有限極限と $h \to 0$ の積を使用します。したがって $\lim_{h \to 0} f(a+h) = f(a)$、つまり $f$ は $a$ で連続です。$\square$

### 単側可微分性

$$f'_+(a) = \lim_{h \to 0^+} \frac{f(a+h)-f(a)}{h}, \qquad f'_-(a) = \lim_{h \to 0^-} \frac{f(a+h)-f(a)}{h}$$

$f$ が $a$ で可微分であるのは、$f'_+(a) = f'_-(a)$（両方とも有限）の場合のみです。

### 定義による導関数—完全な計算

**$f(x) = 1/x$：** $a \neq 0$ に対して：

$$f'(a) = \lim_{h \to 0} \frac{\frac{1}{a+h} - \frac{1}{a}}{h} = \lim_{h \to 0} \frac{\frac{a - (a+h)}{a(a+h)}}{h} = \lim_{h \to 0} \frac{-h}{h \cdot a(a+h)} = \lim_{h \to 0} \frac{-1}{a(a+h)} = \frac{-1}{a^2}$$

**$f(x) = \sqrt{x}$：** $a > 0$ に対して：

$$f'(a) = \lim_{h \to 0} \frac{\sqrt{a+h} - \sqrt{a}}{h} = \lim_{h \to 0} \frac{(\sqrt{a+h} - \sqrt{a})(\sqrt{a+h}+\sqrt{a})}{h(\sqrt{a+h}+\sqrt{a})} = \lim_{h \to 0} \frac{h}{h(\sqrt{a+h}+\sqrt{a})} = \frac{1}{2\sqrt{a}}$$

### 重要な病的関数

- $f(x) = x^2 \sin(1/x)$、$f(0) = 0$：$0$ で可微分（$f'(0) = 0$）だが、$f'$ は $0$ で連続でない。
- **Weierstrass関数**：$\mathbb{R}$ で連続だが、どの点でも可微分ではない。連続性 $\not\Rightarrow$ 可微分性。
- $f(x) = \sqrt[3]{x}$：$f'(0) = +\infty$—垂直接線、古典的な意味では可微分ではない。

### クロスドメイン

- **物理：** $v = ds/dt$、$a = dv/dt$、力 $F = dp/dt$（ニュートンの第2法則の導関数形式）。
- **定量金融：** 連続利回り $r = d(\ln S)/dt$；オプションのデルタ $\Delta = \partial V/\partial S$。
- **確率**：$f(x) = F'(x)$—確率密度を累積分布関数の導関数として。
- **機械学習：** 勾配降下—$\theta \leftarrow \theta - \eta\, \nabla L$；逆伝播は各重みで導関数を使用します。

</Porta>

<Porta nivel="40" titulo="シニアプロフェッショナル向けに">

Lagrange/Newtonの導関数は、現代の応用数学全体を支える、一連の一般化の最初のステップです。

### 導関数を線形演算子として

導関数演算子 $D: C^1(I) \to C^0(I)$ は **線形** です（$D(af+bg) = aD(f)+bD(g)$）が、$C^0$ ノルムで **有界ではありません**：$f_n(x) = \sin(nx)/n$ を取ります—均一に $0$ に収束しますが、$f_n'(x) = \cos(nx)$ は収束しません。これが、整形されたPDEはSobolev空間 $W^{k,p}$ を必要とする理由です。

### 一般化

- **Fréchet**（Banach）：$f: X \to Y$ が $x$ で可微分であるのは、連続線形演算子 $A: X \to Y$ が存在し、$\|f(x+h) - f(x) - Ah\|_Y / \|h\|_X \to 0$ である場合。$A = Df(x)$—有限次元の場合のヤコビアン。
- **Gâteaux**（方向的）：$D_v f(x) = \lim_{t\to 0}[f(x+tv)-f(x)]/t$。Fréchetより弱い；非滑らか最適化で有用。
- **分布的**（Schwartz）：$\langle T', \varphi\rangle = -\langle T, \varphi'\rangle$。Heavisideを導出できます（結果：Dirac デルタ）。現代のPDEの基礎。
- **自動微分（autodiff）**：フォワードモード（ジェット/デュアル数）と逆モード（余接線）；JAX/PyTorchでの実装。勾配のコストは関数のコスト≈2倍—Baur–Strassenの定理。

### Itôの計算と金融

Itôプロセス $dS_t = \mu S_t\,dt + \sigma S_t\,dW_t$ では、古典的な導関数 $dS/dt$ は存在しません（パスは $\alpha < 1/2$ に対して $\alpha$-Hölderです、a.s.）。Itôの公式を使用します：

$$df(S_t) = f'(S_t)\,dS_t + \tfrac{1}{2}f''(S_t)\,\sigma^2 S_t^2\,dt$$

$\frac{1}{2}f''$ 項（第2次補正）がItôと古典的な計算を分離し、Black–Scholes方程式の $\frac{1}{2}\sigma^2$ 項の源です（レッスン119）。

### 数値有限差分

- フォワード：$f'(a) \approx \frac{f(a+h)-f(a)}{h}$、誤差 $O(h)$。
- バックワード：$f'(a) \approx \frac{f(a)-f(a-h)}{h}$、誤差 $O(h)$。
- 中央：$f'(a) \approx \frac{f(a+h)-f(a-h)}{2h}$、誤差 $O(h^2)$—数値計算では常に好ましい。
- IEEE-754浮動小数点では、$h \approx \sqrt{\varepsilon_{\text{mach}}} \approx 10^{-8}$ がフォワード差分の総誤差を最小化します（丸め誤差と打ち切り誤差のトレードオフ）。

<Porta nivel="pratica" titulo="実践的応用—定義をいつ使うか">

### 定義が必要な場合（そして規則ではない場合）

1. **疑わしい点での可微分性の検証**（接合、角、原点）。
2. **関数が可微分ではないことを証明**—左右の導関数を計算し、異なることを示す。
3. **規則を実証**（積、商、連鎖律）—一度行われます；その後、結果を使用します。
4. **数値有限差分**—$f$ が式のない黒い箱の場合。

### 可微分性を診断するためのワークフロー

1. $f$ が $a$ で定義されているか、そして連続であるかを確認します（必要条件）。
2. $f'_-(a)$（左側からの極限）と $f'_+(a)$（右側からの極限）を個別に計算します。
3. 等しく有限ですか？**可微分。** 異なります？**角。** 両方とも $\pm\infty$？**垂直接線。** 異なる形で発散？**不可微分。**

### シンボリック計算—SymPy

```python
import sympy as sp
x, h, a = sp.symbols('x h a')
f = x**3 - 2*x
deriv = sp.limit((f.subs(x, a + h) - f.subs(x, a)) / h, h, 0)
print(deriv)  # 3*a**2 - 2
```

### 古典的な誤り

- 分子の項を組み合わせる**前に** $h$ をキャンセルする—常に最初に展開します。
- 分母で $h$ をキャンセルする**前に**極限 $h \to 0$ を取る—商はまだ $0/0$です；最初に代数的に $h$ を排除する必要があります。
- $f'(a)$（数値—ある点での導関数）と $f'(x)$（関数—導関数関数）を混同する。
- $h \to 0$ が双方向であることを忘れる—左右の導関数が一致する必要があります。

### 即座の応用

| コンテキスト | $f(t)$ | $f'(t)$ |
|---|---|---|
| 力学 | 位置 $s(t)$ | 速度 $v(t)$ |
| 力学 | 速度 $v(t)$ | 加速度 $a(t)$ |

## 解説付き例題

<Exemplo titulo="定義による $x^2$ の導関数" numero="1">

**問題：** 導関数の定義を使って、$f(x) = x^2$ について $f'(x)$ を計算してください。

**戦略：** $f'(a) = \lim_{h \to 0} \frac{f(a+h)-f(a)}{h}$ を直接適用し、極限を取る前に分母の $h$ を排除するために代数的に簡略化します。

**解法：**

1. **$f(a+h)$ を計算：**
$$f(a+h) = (a+h)^2 = a^2 + 2ah + h^2$$

2. **増分商を作成：**
$$\frac{f(a+h)-f(a)}{h} = \frac{a^2 + 2ah + h^2 - a^2}{h} = \frac{2ah + h^2}{h}$$

3. **$h$ をキャンセル**（極限プロセスで $h \neq 0$ のため有効）：
$$\frac{2ah + h^2}{h} = \frac{h(2a + h)}{h} = 2a + h$$

4. **極限を取る：**
$$f'(a) = \lim_{h \to 0}(2a + h) = 2a$$

$a$ は任意なので、導関数関数は $f'(x) = 2x$ です。

**検証：** $x = 3$ で、$f'(3) = 6$。接線は $(3, 9)$ を通り傾き6：$y = 6x - 9$。確認点：$f(3{,}1) = 9{,}61$ そして $y(3{,}1) = 6(3{,}1) - 9 = 9{,}6$—接線は小さい $h$ に対してグラフを近似します。$\checkmark$

**出典。** [Active Calculus, §1.3, Activity 1.3.2](https://activecalculus.org/single/sec-1-3-derivative-pt.html) — ライセンス CC-BY-SA 4.0。
</Exemplo>

<Exemplo titulo="定義による $1/x$ の導関数" numero="2">

**問題：** $a \neq 0$ で、定義を使って $f(x) = \dfrac{1}{x}$ について $f'(a)$ を計算してください。

**戦略：** 重要なステップは、分子の分数を単一の分数に結合することです。これにより分母の $h$ をキャンセルできます。

**解法：**

1. **増分商：**
$$\frac{f(a+h)-f(a)}{h} = \frac{\dfrac{1}{a+h} - \dfrac{1}{a}}{h}$$

2. **分子の分数を結合**（最小公分母 $a(a+h)$）：
$$= \frac{\dfrac{a - (a+h)}{a(a+h)}}{h} = \frac{-h}{h \cdot a(a+h)}$$

3. **$h$ をキャンセル：**
$$= \frac{-1}{a(a+h)}$$

4. **極限 $h \to 0$ を取る：**
$$f'(a) = \lim_{h \to 0} \frac{-1}{a(a+h)} = \frac{-1}{a \cdot a} = -\frac{1}{a^2}$$

**結果：** $(1/x)' = -1/x^2$。幾何学的には：双曲線 $y = 1/x$ はすべての $x \neq 0$ で負の傾きの接線を持ちます—関数は $x > 0$ と $x < 0$ の両半平面で常に減少しています。

**検証：** $a = 2$ で：$f'(2) = -1/4$。接線：$y - 1/2 = -\tfrac{1}{4}(x-2) \Rightarrow y = -x/4 + 1$。$x = 2{,}1$ で：接線は $0{,}475$ を与えます；$f(2{,}1) = 1/2{,}1 \approx 0{,}476$。$\checkmark$

**出典。** [OpenStax Calculus Volume 1, §3.1, Example 3.6](https://openstax.org/books/calculus-volume-1/pages/3-1-defining-the-derivative) — ライセンス CC-BY-NC-SA 4.0。
</Exemplo>

<Exemplo titulo="$x^3$ への接線の方程式" numero="3">

**問題：** $f(x) = x^3$ のグラフへの接線の方程式を点 $x = 2$ で求めてください。

**戦略：** 接線の方程式は $y - f(a) = f'(a)(x - a)$ です。$f(a)$ と $f'(a)$ が必要です。

**解法：**

1. **$f(2) = 2^3 = 8$ を計算**。接点は $(2, 8)$ です。

2. **定義を通じて $f'(a)$ を計算：**
$$\frac{(a+h)^3 - a^3}{h} = \frac{a^3 + 3a^2h + 3ah^2 + h^3 - a^3}{h} = \frac{3a^2h + 3ah^2 + h^3}{h} = 3a^2 + 3ah + h^2$$

$$f'(a) = \lim_{h \to 0}(3a^2 + 3ah + h^2) = 3a^2$$

したがって $f'(2) = 3 \cdot 4 = 12$。

3. **接線の方程式：**
$$y - 8 = 12(x - 2) \implies y = 12x - 16$$

**検証：** $x = 2{,}1$ で：$f(2{,}1) = (2{,}1)^3 = 9{,}261$；接線：$y = 12(2{,}1) - 16 = 9{,}2$。絶対誤差 $0{,}061$—線形近似の場合、予想通り $h^2$ で増加。$\checkmark$

**出典。** [APEX Calculus, §2.1, Example 2.1.3](https://www.apexcalculus.com/) — ライセンス CC-BY-NC 4.0。
</Exemplo>

<Exemplo titulo="非可微分性：絶対値の角" numero="4">

**問題：** $f(x) = |x|$ が $x = 0$ で可微分であるかどうかを調査してください。

**戦略：** 左右の導関数 $f'_-(0)$ と $f'_+(0)$ を別々に計算します。異なる場合、$f$ は $0$ で可微分ではありません。

**解法：**

1. **右側導関数**（$h \to 0^+$ のため $h > 0$、したがって $|h| = h$）：
$$f'_+(0) = \lim_{h \to 0^+} \frac{|0+h| - |0|}{h} = \lim_{h \to 0^+} \frac{h}{h} = 1$$

2. **左側導関数**（$h \to 0^-$ のため $h < 0$、したがって $|h| = -h$）：
$$f'_-(0) = \lim_{h \to 0^-} \frac{|0+h| - |0|}{h} = \lim_{h \to 0^-} \frac{-h}{h} = -1$$

3. **結論：** $f'_+(0) = 1 \neq -1 = f'_-(0)$。

左右の導関数が異なるため、$f(x) = |x|$ は **$x = 0$ で可微分ではありません**—グラフは $x = 0$ に角を持ちます。$f$ は $0$ で連続であることに注意してください（$\lim_{x\to 0}|x| = 0 = |0|$ なので）。これは **連続性は可微分性を含意しない** ことを確認しています。

**検証：** $|x|$ のグラフは $x > 0$ で傾き $+1$、$x < 0$ で傾き $-1$ を持ちます。$x = 0$ に唯一の接線は存在しません。$\checkmark$

**出典。** [Active Calculus, §1.7, Activity 1.7.3](https://activecalculus.org/single/sec-1-7-lim-cont-diff.html) — ライセンス CC-BY-SA 4.0。
</Exemplo>

<Exemplo titulo="限界費用—経済的応用" numero="5">

**問題：** ある企業は $q$ 単位の製品を総費用 $C(q) = q^2 + 30q + 500$ レアル（ブラジル通貨）で生産します。導関数の定義を使って、$q = 50$ 単位での限界費用を計算し、結果を解釈してください。

**戦略：** 限界費用 = $C'(q)$、数量に関する費用の瞬時変化率。定義で計算し、$q = 50$ で評価します。

**解法：**

1. **増分商：**
$$\frac{C(q+h) - C(q)}{h} = \frac{(q+h)^2 + 30(q+h) + 500 - (q^2 + 30q + 500)}{h}$$

$$= \frac{q^2 + 2qh + h^2 + 30q + 30h + 500 - q^2 - 30q - 500}{h} = \frac{2qh + h^2 + 30h}{h}$$

$$= 2q + h + 30$$

2. **極限を取る：**
$$C'(q) = \lim_{h \to 0}(2q + h + 30) = 2q + 30$$

3. **$q = 50$ で評価：**
$$C'(50) = 2(50) + 30 = 130 \text{ レアル}$$

**解釈：** 50単位を生産するときに、追加の各単位はおよそ130レアルかかります。$C(51) - C(50) = (2601 + 1530 + 500) - (2500 + 1500 + 500) = 4631 - 4500 = 131$ レアルであることに注目してください—限界費用は1レアル少なく見積もります（$h$ の第2次差）。

**検証：** $C'(q) = 2q + 30 > 0$ すべての $q > 0$：増加する費用、予想通り。$q = 0$ で：$C'(0) = 30$—第1単位の限界費用は30レアル。$\checkmark$

**出典。** [OpenStax Calculus Volume 1, §3.1, Applied Example — Marginal Cost](https://openstax.org/books/calculus-volume-1/pages/3-1-defining-the-derivative) — ライセンス CC-BY-NC-SA 4.0。
</Exemplo>
