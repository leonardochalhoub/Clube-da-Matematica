<Definicao titulo="関数">

$A$と$B$を空でない集合とします。$A$から$B$への**関数**$f$（$f: A \to B$と書く）は、$A$の各$x$を$B$のちょうど1つの要素$f(x)$に関連付ける関係です。

- $A$は$f$の**定義域**（$\operatorname{dom}(f)$と書く）。
- $B$は**終域**。
- $\operatorname{Im}(f) = \{f(x) : x \in A\} \subseteq B$は**像**。

</Definicao>

> 「関数は、各入力値が正確に1つの出力値を生成する関係です。」— [OpenStax College Algebra 2e, §3.1](https://openstax.org/books/college-algebra-2e/pages/3-1-functions-and-function-notation)

### 分類

<Definicao titulo="関数の種類">

- **単射**（1-1）：$x_1 \neq x_2 \Rightarrow f(x_1) \neq f(x_2)$。
- **全射**：$\operatorname{Im}(f) = B$（すべての$y \in B$に少なくとも1つの$x$がそれを写像する）。
- **全単射**：単射AND全射。

</Definicao>

<Porta nivel="5" titulo="5歳児向け">

魔法の機械を想像してください。**番号**を入れます。機械が少し考えます。別の**番号**が出てきます。

同じ番号を毎回入れると、機械は常に同じ答えを出します。常に。機械が時々ある答え、時々別の答えを出すなら、それは「関数」ではありません — それは単なるおかしな機械です。

</Porta>

<Porta nivel="10" titulo="10歳児向け">

関数は2つの数の間の**固定した関係**です。

例：数を2倍にする。**3**が入れば、**6**が出ます。**5**が入れば、**10**が出ます。**8.7**が入れば、**17.4**が出ます。ルールは「出力＝入力×2」です。

私たちはこれを$f(x) = 2x$と書きます。**f**は単なる名前です — 呼べば**g**、**h**、**double**、何でもいいです。**(x)**は入力される番号を入れる場所です。

関数は**科学のすべて**に表示されます：
- 車の速度は**時間の関数**：$v(t) = ?$
- 旅のコストは**距離の関数**：$C(d) = ?$
- 1日の気温は**時刻の関数**：$T(h) = ?$

</Porta>

<Porta nivel="15" titulo="15歳の思春期向け">

関数$f$は、各入力を唯一の出力に関連付けるルールです。有効な入力値の集合は**定義域**、実際に現れる出力値の集合は**像**です。

例：$f(x) = x^2$。

| $x$（入力） | $f(x)$（出力） |
|---:|---:|
| −2 | 4 |
| −1 | 1 |
| 0 | 0 |
| 1 | 1 |
| 2 | 4 |

定義域：$\mathbb{R}$（任意の実数を入力に使用できます）。像：$[0, +\infty)$（出力は決して負ではありません）。

**グラフ**はこの関数の放物線です：

<Porta nivel="25" titulo="工学生向け">

関数は、微積分プログラム全体の中で最も重要な数学的対象です。微分または積分を始める前に、関数が何であるかについての絶対的な明確さを持つ必要があります。

### 最大定義域

ステートメントが「$f(x) = \sqrt{x - 1}$を研究する」と言うときに定義域を指定しない場合、式が意味をなす最大部分集合である**自然最大定義域**を採用します。

- $\sqrt{x-1}$：$x - 1 \geq 0 \Rightarrow x \geq 1$、定義域＝$[1, +\infty)$。
- $1/(x-2)$：$x \neq 2$、定義域＝$\mathbb{R} \setminus \{2\}$。
- $\ln(x)$：$x > 0$、定義域＝$(0, +\infty)$。

> 「方程式で定義された関数の定義域を見つけるには、入力変数を操作不可にするすべての制限を特定します。」— [OpenStax College Algebra 2e, §3.2](https://openstax.org/books/college-algebra-2e/pages/3-2-domain-and-range)

### 合成

$(f \circ g)(x) = f(g(x))$。**注意**：一般に合成は可換ではありません。

例：$f(x) = x^2$、$g(x) = x + 1$。
- $(f \circ g)(x) = f(x+1) = (x+1)^2$
- $(g \circ f)(x) = g(x^2) = x^2 + 1$

異なります！

### なぜ単射性が重要なのか

関数は**逆関数**を持つためにだけ単射である必要があります。非単射関数は制限される必要があります。古典的な例：$f(x) = x^2$はℝで単射ではありませんが、$[0, +\infty)$では単射です。そこでその逆は$f^{-1}(y) = \sqrt{y}$です。

### 関数とモデリング

エンジニアリングでは、関数は**現象**を表すオブジェクトです：
- $T(t)$：温度は時間の関数（センサー）
- $V(I)$：電圧は電流の関数（オームの法則）
- $\sigma(\varepsilon)$：応力は変形の関数（フックの法則）

すべての寸法分析、すべてのキャリブレーション、すべてのモデル調整は、関数が何であるかを理解することから始まります。

</Porta>

<Porta nivel="40" titulo="シニアプロフェッショナル向け">

「ルールを関連付ける」としての関数の定義は非形式的です。厳密な定義（ブルバキのような）は：

> **関数** $f: A \to B$は、各$x \in A$に対して**正確に1つ**の$y \in B$が存在する$(x, y) \in f$となるような**部分集合**$f \subseteq A \times B$です。$y = f(x)$と書きます。

つまり、関数はそのグラフそのもの（集合の意味で）です。論理と集合論に対する操作定義。日々の計算はこの形式化を使用しませんが、実分析（微積分IV/大学実分析）で見ます。

### 関数を射として

カテゴリ（現代数学の言語）では、関数は**射**（集合間の）です。全単射は$\mathbf{Set}$のカテゴリの同型です。関数の合成は射の合成です。

### 関数とコンピュテーション

コンピュータサイエンスでは、関数は関数プログラミング（Haskell、Lisp）の中心的概念です。カリー化 — $f: A \times B \to C$を$f': A \to (B \to C)$に変換する — は日常的な型操作です。本番環境の「実际」関数は`User -> Order -> Promise<Receipt>`のような署名を持つ可能性があります — それはちょうど副作用を持つ数学的$f: A \to B \to C$です。

### モデリングの制限

実際の物理現象では、「関数」は抽象化です：
- **ヒステリシス**：状態は現在の入力だけでなく、過去の軌跡に依存します（塑性変形）。関数ではありません。
- **量子**：測定は確率的です — 単一の確定的値がありません。確率分布です。
- **カオス**：初期条件の小さな変動は任意に異なる軌跡を生成します。理論的には確定的で、実際には予測不可能です。

これらすべてのケースで、関数の概念は不十分であり、より豊かな抽象化（マップ、確率過程、力学）が登場します。

</Porta>

<Porta nivel="pratica" titulo="実践 — 実データの例">

### 例1：タクシー料金（アフィンモデル）

サンパウロでのタクシーの料金：

$$T(d) = 5.50 + 3.10 \cdot d$$

ここで$T$はR\$での値、$d$はkmでの距離です。

- 定義域：$d \geq 0$ → $[0, +\infty)$
- 像：$T \geq 5.50$ → $[5.50, +\infty)$
- $T(0) = 5.50$は**バンデイラ**（乗車の固定コスト）
- $T(10) = 5.50 + 31 = 36.50$

### 例2：BMI（体格指数）

$$\text{BMI}(p, h) = \frac{p}{h^2}$$

- **2つの変数**（体重$p$（kg）、身長$h$（m））の関数。
- 物理的定義域：$p > 0$、$h > 0$ → $(0, +\infty)^2$。
- 像：$(0, +\infty)$。

WHO分類：
- BMI < 18.5：低体重
- 18.5 ≤ BMI < 25：標準
- 25 ≤ BMI < 30：過体重
- BMI ≥ 30：肥満

### 例3：Selic金利（時間の関数、不連続）

Selicはコペム会合で約45日ごとに決定されます。会合の間は一定です。「階段」関数：

```
Selic(jan/2025) = 13.25%
Selic(mar/2025) = 14.25%
Selic(mai/2025) = 14.75%  (その後ずっと保持)
```

定義域：時間（日付）。終域：パーセンテージ。像：離散的、コペムで指定された値。

</Porta>

## 解法例

> 難易度が上がる5つの例 — 最も直接的な（数値評価と定義域の読み取り）から実モデリング（段階的料金）まで。各例は出典を引用しています。

<Exemplo titulo="例1 — 評価と直接的な定義域（応用）" numero="1">

**問題：** $f(x) = 3x^2 - 2x + 1$に対して、$f(-1)$、$f(0)$、$f(2)$を計算します。最大定義域を決定します。

**戦略：** 関数のある点での評価は、変数を与えられた値に置き換え、計算することを意味します。多項式の最大定義域は、多項式がどの実数でも定義されているため、すべての$\mathbb{R}$です。

**解法：**

1. **$f(-1)$：** $x = -1$を代入：
    $f(-1) = 3(-1)^2 - 2(-1) + 1 = 3(1) + 2 + 1 = 6$。
2. **$f(0)$：** $x = 0$を代入：
    $f(0) = 3(0)^2 - 2(0) + 1 = 0 - 0 + 1 = 1$。
3. **$f(2)$：** $x = 2$を代入：
    $f(2) = 3(2)^2 - 2(2) + 1 = 3(4) - 4 + 1 = 12 - 4 + 1 = 9$。
4. **定義域：** $f$は多項式なので制限がありません。定義域 = $\mathbb{R}$。

**確認：** 3つの値はすべて有限です。一貫性を確認するには、$f(0) = 1$が独立係数であることに注意してください — すべての多項式に対して常に当てはまります。

**出典。** [OpenStax — College Algebra 2e §3.1](https://openstax.org/books/college-algebra-2e/pages/3-1-functions-and-function-notation) — CC-BY 4.0ライセンス。
</Exemplo>

<Exemplo titulo="例2 — 組み合わせた制限での最大定義域（中級）" numero="2">

**問題：** $f(x) = \dfrac{\sqrt{x + 2}}{x - 3}$の最大定義域を決定します。

**戦略：** 同時に2つの制限があります：被平方根$x + 2$は非負である必要があります（実数の平方根が存在するため）、分母$x - 3$はゼロではできません。定義域はこれら2つの条件の交集合です。

**解法：**

1. **平方根の制限：** $x + 2 \geq 0 \Rightarrow x \geq -2$、または$x \in [-2, +\infty)$。
2. **分母の制限：** $x - 3 \neq 0 \Rightarrow x \neq 3$、または$x \in \mathbb{R} \setminus \{3\}$。
3. **交集合：** $[-2, +\infty) \cap (\mathbb{R} \setminus \{3\}) = [-2, 3) \cup (3, +\infty)$。

**確認：**
- $x = -2$：$\sqrt{0}/(-5) = 0$。OK（含まれる）。
- $x = 3$：ゼロで除算。除外。OK。
- $x = -3$：$\sqrt{-1}$は実数に存在しません。除外。OK。
- $x = 5$：$\sqrt{7}/2$。OK。

**出典。** [OpenStax — College Algebra 2e §3.2](https://openstax.org/books/college-algebra-2e/pages/3-2-domain-and-range) — CC-BY 4.0ライセンス。
</Exemplo>
