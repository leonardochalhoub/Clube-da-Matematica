### 中心的な質問

> 「与えられた数列$(a_n)$について、$n \to \infty$のとき項がどの値に近づくか（存在すれば）？」

その値が存在するとき、数列は**収束する**と言い、$\lim_{n \to \infty} a_n = L$と記述します。

<Definicao titulo="数列の極限（直感的版）">

$\lim_{n \to \infty} a_n = L$であるとは、$a_n$の項が$n$が十分大きいときに$L$に**任意に近くなる**ことです。

厳密な定式化（第41講）:

$$\forall \varepsilon > 0,\ \exists N \in \mathbb{N} :\ n \geq N \Rightarrow |a_n - L| < \varepsilon$$

今のところは「近づく」を信頼してください。

</Definicao>

> 「数列$\{a_n\}$が実数$L$に収束する当且つのみの条件は、すべての$\varepsilon > 0$に対して、$n > N$なら$|a_n - L| < \varepsilon$となるような整数$N$が存在することである。」— [OpenStax Calculus Volume 2, §5.1](https://openstax.org/books/calculus-volume-2/pages/5-1-sequences)

### 注目する極限

| 数列 | 極限 | 直感的正当化 |
|---|---|---|
| $1/n$ | $0$ | 項がますます小さくなる |
| $1/n^k$ ($k > 0$) | $0$ | 同じく、より速く |
| $q^n$ ($\|q\| < 1$) | $0$ | 減少する等比数列（第18講） |
| $q^n$ ($\|q\| > 1$) | 存在しない | 等比数列が爆発 |
| $(1 + 1/n)^n$ | $e \approx 2{,}71828$ | オイラー数 |
| $\sqrt[n]{n}$ | $1$ | 対数を経由 |
| $n^k / a^n$ ($a > 1$) | $0$ | 指数が多項式を打ち勝つ |
| $n! / n^n$ | $0$ | $n^n$が階乗より速く爆発 |

### 極限での演算

$\lim a_n = A$かつ$\lim b_n = B$（両者有限）なら:

<Equation numero="1"
  explicacao="和の極限は極限の和——両者が存在し有限な場合すべてに成立。"
  latex="\lim(a_n \pm b_n) = A \pm B,\quad \lim(a_n \cdot b_n) = A \cdot B,\quad \lim\frac{a_n}{b_n} = \frac{A}{B}\ (B \neq 0)" />

### 収束しない数列

- **$\pm\infty$へ発散**: $a_n = n$、$a_n = 2^n$。
- **限りなく振動**: $a_n = (-1)^n$ — $1$と$-1$を交互に。
- **有界だが限界なし**: $a_n = \sin n$ — 有界だが収束しない。

### 絞り込み定理（Sandwich）

<Teorema titulo="絞り込み定理">

$a_n \leq b_n \leq c_n$（$n \geq N_0$）を満たす数列$(a_n), (b_n), (c_n)$が存在し、

$$\lim_{n \to \infty} a_n = \lim_{n \to \infty} c_n = L$$

なら$\lim_{n \to \infty} b_n = L$。

</Teorema>

> 「絞り込み定理：すべての$n \geq N$に対して$a_n \leq b_n \leq c_n$かつ$\lim_{n\to\infty} a_n = \lim_{n\to\infty} c_n = L$なら$\lim_{n\to\infty} b_n = L$。」— [Lebl, Basic Analysis I, §2.1](https://www.jirka.org/ra/)

### 単調有界判定法

<Teorema titulo="単調有界は収束（Bolzano-Weierstrass）">

$\mathbb{R}$のすべての単調有界数列は収束する。

**実践的系**: $(1 + 1/n)^n$が極限を持つことを示すには、それが増加列で上界が$3$（二項定理経由）を示せば十分。収束の存在が確実だが、正確な値を計算せず。

</Teorema>

<Insight>

**数列の極限と関数の極限が同じ概念なのはなぜ？** 数列は関数$f: \mathbb{N} \to \mathbb{R}$だから。第41講で$\lim_{x \to \infty} f(x)$を学ぶとき、自然に定義域$\mathbb{R}$に拡張される。数列の$\varepsilon$-$N$は関数の$\varepsilon$-$M$に。すべての導関数$f'(a) = \lim_{h \to 0}(f(a+h)-f(a))/h$は数列の極限です。

</Insight>

<Porta nivel="5" titulo="5歳児向け">

長い、長い廊下を想像してください。一番奥に扉があります。大きな一歩、それから小さな一歩、さらに小さく、ほんの小さなジャンプ...

毎回もっと小さく。でも、あなたは扉に**近づいている**。本当に近く。

「扉」が**極限**です。小さな歩みが数列の項。あなたが極限に近づく（必ずしも触れることなく）。

例: $1, 1/2, 1/3, 1/4, 1/5, \ldots$

毎回**ゼロ**に近づく。扉はゼロ。

</Porta>

<Porta nivel="10" titulo="10歳児向け">

数列$1/n$は項$1, 1/2, 1/3, 1/4, 1/5, \ldots, 1/100, \ldots, 1/1\,000\,000, \ldots$を持っています

**どこへいくのか？** **ゼロへ**。正確にはゼロに到達しないが、好きなだけ近くに。

この「どこへいくのか」が**極限**。こう書きます:

$$\lim_{n \to \infty} \frac{1}{n} = 0$$

読み方：「$n$が無限大に向かうときの$1/n$の極限はゼロ」。

**他の例:**
- $\lim (1/2)^n = 0$ — 毎回半分になる等比数列。
- $\lim n = \infty$ — 増え続ける、固定的目的地なし。
- $\lim (-1)^n$ 存在しない — $1$と$-1$の間を永遠に飛び回る。
- $\lim (1 + 1/n)^n = e \approx 2{,}71828$ — 有名なオイラー数。

**なぜ重要？** 極限が**微積分のベース**だから。これからの年間で勉強する毎つの導関数と積分は隠れた極限。

</Porta>

<Porta nivel="15" titulo="15歳の青年向け">

**数列の極限とは何か？** ゲーム：数列$(a_n)$が極限$L$を持つとは、項がLに任意に近くなることです、十分に大きなnのために。

$$\lim_{n \to \infty} \frac{1}{n} = 0, \quad \lim_{n \to \infty} \frac{3n+5}{n+2} = 3, \quad \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$$

**多項式の比$\lim P(n)/Q(n)$の速い技:**

| もし | そら |
|---|---|
| $\deg P = \deg Q$ | 主係数の比 |
| $\deg P > \deg Q$ | $\pm \infty$ (発散) |
| $\deg P < \deg Q$ | $0$ |

**なぜ重要？** このレッスンは**意図的に直感的**。厳密な定式化($\varepsilon$-$N$)は第5学期の第41講に。今のところ：「近づく」を信頼して、演習で練習。

しかし既に記録して：**すべての導関数は極限**。第5学期で$f'(x) = \lim_{h \to 0}(f(x+h)-f(x))/h$を計算するとき、それは数列の極限です——ちょうどこの授業の概念。

**等比数列の実用基準:** $\lim q^n = 0$ if $|q| < 1$；$\lim q^n = +\infty$ if $q > 1$；存在しない if $q \leq -1$。

</Porta>

<Porta nivel="25" titulo="工学生向け">

極限は**分析のキー概念**。数列が収束するか否か；収束するとき、極限は一意（一意性——演習19.33）。

### 基本定理

- **絞り込み**: $a_n \leq b_n \leq c_n$かつ$\lim a_n = \lim c_n = L$なら、$\lim b_n = L$。
- **単調有界は収束**: $\mathbb{R}$のすべての単調有界数列は極限を持つ（$\mathbb{R}$の完全性）。
- **Cauchy $\Rightarrow$ 収束**: $\mathbb{R}$のCauchy列は常に収束（完全性等価）。

### 漸近記法（計算機科学）

- $a_n = O(b_n)$：$|a_n/b_n|$有界——同じ成長順序。
- $a_n = o(b_n)$：$a_n/b_n \to 0$ — $a_n$は$b_n$より「ずっと小さい」。
- $a_n \sim b_n$：$a_n/b_n \to 1$ — 漸近的に等価。

例：$n \ln n = o(n^2)$；$\ln n = o(n^{0.01})$；$\binom{2n}{n} \sim 4^n / \sqrt{\pi n}$ (Stirling)。

### 数$e$

$$e = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = \sum_{k=0}^\infty \frac{1}{k!} \approx 2{,}71828\ldots$$

一般化：$\lim_{n \to \infty} (1 + r/n)^n = e^r$ — 連続利息、指数減衰、ODE $\dot y = ky$の基礎。

### 工学応用

- **LTIシステム安定性**: 極$p$で$|p| < 1 \Leftrightarrow$インパルス応答$p^n \to 0 \Leftrightarrow$システム安定。
- **Newton-Raphson収束**: 反復$x_{n+1} = x_n - f(x_n)/f'(x_n)$は単純根付近**二次収束**。
- **MCMC** (Metropolis-Hastings)：遍歴的鎖は定常分布に収束。
- **SGD** (確率勾配降下法)：$\eta_n \to 0$適切に、パラメータは最小値に収束（凸性下で）。

### 注意：$1^\infty$の形

$\lim (1 + 1/n)^n = e \neq 1^{\infty}$ — $1^\infty$の形は**不定**。素朴に「底は1に、極限は$1^{\infty} = 1$」と計算しないで。$\lim (1 + r/n)^{nt} = e^{rt}$を使用。

</Porta>

<Porta nivel="40" titulo="シニア専門家向け">

極限は**$\mathbb{R}$を定義する**概念。古典的構成：

- **Cauchy**: $\mathbb{R}$ = 有理数のCauchy列の同値類。
- **Dedekind**: $\mathbb{R}$ = $\mathbb{Q}$の切断。

両方同等。選択は**通常メトリック空間** $\mathbb{Q}$ を通常ノルム内で定義。完全性は、すべてのCauchy列が収束することを確実にする——$\mathbb{Q}$にはない性質（例：$\sqrt 2$に近づく有理数列はCauchyだが$\mathbb{Q}$で収束しない）。

### 潜在的位相

収束は**位相的現象**：$a_n \to L$とは、$Lの$のすべての開いた近傍が、ある$N$から全ての$a_n$を含むこと。距離空間では、近傍 = 球$B(L, \varepsilon)$。

### 一般化

- **$\mathbb{R}^n$**：成分による収束（ユークリッドノルム）。
- **関数空間**：点別収束、一様収束、$L^p$収束——一般に異なる。$f_n(x) = x^n$ in $[0,1]$：非連続関数に点別収束、不均一でなく。
- **ネット（nets）の極限**：部分順序集合に数列を一般化（一般位相）。
- **カテゴリック極限**：圏論で、数列、積、プルバック等の極限を統一する普遍構造。

### ML/DLと統計学

- **大数の法則**：$\bar X_n \to \mu$ — Monte Carlo、batch SGDの基礎。
- **中心極限定理**：$\sqrt n (\bar X_n - \mu)/\sigma \to N(0,1)$ — 信頼区間の正当化。
- **SGD収束**：勾配は$O(1/\sqrt T)$として凸性下Lipschitzで減衰。証明はLyapunov数列使用。
- **深いネットの破壊的忘却**：勾配は層を超えて幾何学的に減衰——分散がゼロに（消失勾配問題）。

```python
import sympy as sp
n = sp.symbols('n', integer=True, positive=True)
print(sp.limit((1 + 1/n)**n, n, sp.oo))    # E
print(sp.limit((3*n + 5)/(n + 2), n, sp.oo))  # 3
print(sp.limit(n**100 / 2**n, n, sp.oo))   # 0  (指数が勝つ)
print(sp.limit(sp.sin(n)/n, n, sp.oo))     # 0
```

### シナリオ1：連続複利（SELIC）

SELICが年$r = 10{,}75\%$で、年$n$回複利するなら、年係数は$(1 + r/n)^n$。$n \to \infty$（連続複利）の時：

$$\lim_{n \to \infty} \left(1 + \frac{0{,}1075}{n}\right)^n = e^{0{,}1075} \approx 1{,}1134$$

R\$ 10.000を適用して、1年後：R\$ 11.134。単純年複利と比較：R\$ 11.075。差はオイラーによる制限から。

### シナリオ2：キャパシタの放電（電子工学）

抵抗を通して放電するキャパシタは$V_n = V_0 \cdot (0{,}9)^n$に従う各期間。$|0{,}9| < 1$だから:

$$\lim_{n \to \infty} V_n = V_0 \cdot 0 = 0 \text{ V}$$

キャパシタは完全に放電——ゼロ極限。比が$q = 1{,}1 > 1$なら、電圧は爆発（回路不安定性）。

### シナリオ3：反復アルゴリズムの収束

Hero法（バビロニア法、紀元前1世紀）$\sqrt c$用:

$$a_1 = 1, \quad a_{n+1} = \frac{a_n + c/a_n}{2}$$

$c = 5$: $a_1 = 1$、$a_2 = 3$、$a_3 = 2{,}333$、$a_4 = 2{,}2381$、$a_5 \approx 2{,}23607$ — すでに$\sqrt 5 \approx 2{,}23607$の5桁正確。**二次収束**：正確な桁数が各反復で倍に。極限は固定点で計算：$L = (L + c/L)/2 \Rightarrow L^2 = c \Rightarrow L = \sqrt c$。

## 解答済み例

<Exemplo titulo="1/nの極限——創始例" numero="1">

**問題:** $\lim_{n \to \infty} 1/n$を計算してください。

**戦略:** 数列を数値的に観察。項は無限に減少——直感的極限はゼロ。確認するため：任意のターゲット$\varepsilon > 0$、$n > 1/\varepsilon$なら$1/n < \varepsilon$。

**解答:**

1. **いくつかの項をリスト。** $1,\ 1/2,\ 1/3,\ 1/4,\ \ldots,\ 1/100,\ \ldots,\ 1/10^6,\ \ldots$
2. **傾向を観察。** 任意の$\varepsilon > 0$、$n > 1/\varepsilon$を取ると$1/n < \varepsilon$。
3. **結論。** $\lim_{n \to \infty} 1/n = 0$。

**確認:** $1/10^6 = 10^{-6}$、$1/10^{12} = 10^{-12}$。ゼロに近づくが決してタッチしない。

**情報源。** [Active Calculus §8.1 (Sequences)](https://activecalculus.org/single/sec-8-1-sequences.html) — ライセンスCC-BY-NC-SA。収束概念の標準的開始例。

</Exemplo>

<Exemplo titulo="多項式の比の極限" numero="2">

**問題:** $\lim_{n \to \infty} \dfrac{3n + 5}{n + 2}$を計算。

**戦略:** 分子と分母を$n$（最大の力存在）で割る。ゼロに向かう項を分離。

**解答:**

1. **すべてを$n$で割ります。** $\dfrac{3n + 5}{n + 2} = \dfrac{3 + 5/n}{1 + 2/n}$。
2. **極限を取ります。** $5/n \to 0$と$2/n \to 0$だから：$\dfrac{3 + 0}{1 + 0} = 3$。
3. **結論。** $\lim_{n \to \infty} \dfrac{3n + 5}{n + 2} = 3$。

**確認:** $n = 1\,000$: $(3\,005)/(1\,002) \approx 2{,}999$。$n = 10^6$: $\approx 2{,}999999$。$3$に収束。

**技。** $\lim P(n)/Q(n)$ ($\deg P = \deg Q$)の場合、極限は最大次の係数の比。ここ：$3/1 = 3$。

**情報源。** [Lebl — Basic Analysis I §2.2](https://www.jirka.org/ra/) — ライセンスCC-BY-SA。数列の極限定理。

</Exemplo>

<Exemplo titulo="根の差——共役の技" numero="3">

**問題:** $\lim_{n \to \infty} (\sqrt{n+1} - \sqrt{n})$を計算。

**戦略:** 不定形$\infty - \infty$。共役$\sqrt{n+1} + \sqrt{n}$で掛ける理性化。

**解答:**

1. **共役で掛けます。** $\sqrt{n+1} - \sqrt{n} = \dfrac{(\sqrt{n+1} - \sqrt{n})(\sqrt{n+1} + \sqrt{n})}{\sqrt{n+1} + \sqrt{n}} = \dfrac{(n+1) - n}{\sqrt{n+1} + \sqrt{n}} = \dfrac{1}{\sqrt{n+1} + \sqrt{n}}$。
2. **分母を分析。** $\sqrt{n+1} + \sqrt{n} \to +\infty$。
3. **結論。** $\lim_{n \to \infty} \dfrac{1}{\sqrt{n+1} + \sqrt{n}} = 0$。

**確認:** $n = 100$: $\sqrt{101} - 10 \approx 0{,}0499$。$n = 10\,000$: $\approx 0{,}005$。ゼロに向かう。

**情報源。** [Lebl — Basic Analysis I §2.2](https://www.jirka.org/ra/) — ライセンスCC-BY-SA。根を含む$\infty - \infty$形式の標準技。

</Exemplo>

<Exemplo titulo="オイラー数(1+1/n)^nを経由" numero="4">

**問題:** $\lim_{n \to \infty} (1 + 1/n)^n = e \approx 2{,}71828$を直感的に示す。

**戦略:** 増加するnに対して数値的に計算。単調有界基準が極限の存在を確実にする。

**解答:**

1. **いくつかの項を計算。**

   | $n$ | $(1 + 1/n)^n$ |
   |---|---|
   | $1$ | $2$ |
   | $10$ | $2{,}5937$ |
   | $100$ | $2{,}7048$ |
   | $1\,000$ | $2{,}7169$ |
   | $10^6$ | $2{,}71828$ |

2. **単調性と有界性を観察。** Newton二項を通じて、数列が増加列で上界$3$を持つことを示せます。単調有界定理で、極限が存在。

3. **極限を特定。** 数値$e \approx 2{,}71828\ldots$この極限として定義（級数$\sum 1/k!$等価）。

**確認:** SymPy: `sp.limit((1 + 1/n)**n, n, sp.oo)` `E`を返す。

**なぜ重要？** 一般化：$\lim_{n \to \infty} (1 + r/n)^n = e^r$。連続複利率$r$、年係数は$e^r$。接続は第5学期で正式化。

**情報源。** [Active Calculus §8.1](https://activecalculus.org/single/sec-8-1-sequences.html) — ライセンスCC-BY-NC-SA。厳密な証明[Lebl §2.4](https://www.jirka.org/ra/)。

</Exemplo>

<Exemplo titulo="再帰の不動点——Hero法" numero="5">

**問題:** $a_1 = 1$、$a_{n+1} = (a_n + 2/a_n)/2$。どの値に収束？

**戦略:** $a_n \to L$なら、$a_{n+1} \to L$も。再帰でL極限を通す、Lで代数方程式（不動点方程式）を得る。

**解答:**

1. **極限$L$が存在と仮定。** $a_{n+1} \to L$（同じ数列、1偏移）。
2. **再帰で極限を通す。** $L = (L + 2/L)/2 \Rightarrow 2L = L + 2/L \Rightarrow L = 2/L \Rightarrow L^2 = 2$。
3. **解く。** $L = \pm\sqrt{2}$。$a_1 = 1 > 0$で再帰が正を保つので、$L = \sqrt{2} \approx 1{,}41421$。

**数値確認:**

| $n$ | $a_n$ |
|---|---|
| $1$ | $1{,}000000$ |
| $2$ | $1{,}500000$ |
| $3$ | $1{,}416667$ |
| $4$ | $1{,}414216$ |
| $5$ | $1{,}414214$ |

**接続。** これはNewton-Raphson反復$f(x) = x^2 - 2$。二次収束：正確な桁が各反復で倍に。Hero of Alexandria（紀元前1世紀）算法、17世紀Newton再発見。

**情報源。** [Active Calculus §8.1](https://activecalculus.org/single/sec-8-1-sequences.html)と[OpenStax Calculus Volume 2 §5.1](https://openstax.org/books/calculus-volume-2/pages/5-1-sequences) — ライセンスCC-BY-NC-SA。

</Exemplo>
