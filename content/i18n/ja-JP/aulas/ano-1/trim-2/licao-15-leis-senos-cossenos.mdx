<Definicao titulo="正弦法則">

任意の三角形 $ABC$ について、辺 $a, b, c$ がそれぞれ角 $A, B, C$ の対辺とするとき：

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

ここで $R$ は三角形の**外接円の半径**である。

</Definicao>

<Definicao titulo="余弦法則">

任意の三角形 $ABC$ について：

$$c^2 = a^2 + b^2 - 2ab\cos C$$

他の辺についても同様。$C = 90°$ のとき、$\cos C = 0$ となり **ピタゴラスの定理** に戻る。

</Definicao>

> "The Law of Sines can be used to solve oblique triangles, which are non-right triangles." — [OpenStax Algebra and Trigonometry 2e §10.1](https://openstax.org/books/algebra-and-trigonometry-2e/pages/10-1-non-right-triangles-law-of-sines)

> "The Law of Cosines is a generalization of the Pythagorean Theorem. We can use it to find a missing side when two sides and the included angle are known." — [Stitz–Zeager, Precalculus §11.3](https://www.stitz-zeager.com/szprecalculus07042013.pdf)

<Teorema titulo="正弦法則の証明（鋭角三角形）">
$C$ から辺 $\overline{AB}$ に下ろした高さを $h$ とする。直角三角形 $ACH$ から：$h = b \sin A$。直角三角形 $BCH$ から：$h = a \sin B$。等しいとすると：

$$b \sin A = a \sin B \implies \frac{a}{\sin A} = \frac{b}{\sin B}$$

別の頂点から同様に下ろすことで、この比が $c/\sin C$ にも等しいことが示される。$C = 90°$ のとき：$\sin C = 1$、したがって $c = 2R$ — 斜辺は外接円の直径である（**タレスの定理**）。∎
</Teorema>

<Teorema titulo="余弦法則の証明（内積による）">
原点を $C$ に置く。$\vec{u} = \vec{CA}$、$\vec{v} = \vec{CB}$ とすると、$|\vec{u}| = b$、$|\vec{v}| = a$。このとき $\vec{AB} = \vec{v} - \vec{u}$ で $|\vec{AB}| = c$。

$$c^2 = |\vec{v} - \vec{u}|^2 = |\vec{v}|^2 + |\vec{u}|^2 - 2\,\vec{u}\cdot\vec{v} = a^2 + b^2 - 2ab\cos C \qquad \square$$

この証明は任意の三角形（鋭角、鈍角、直角）で成立する。∎
</Teorema>

### どちらの法則を使うか

<Definicao titulo="法則選択ガイド">

| 既知条件 | 求めたい量 | 使う法則 |
|---|---|---|
| 2角＋1辺（AAS、ASA） | 残りの辺 | **正弦法則** |
| 2辺＋対角（SSA） | 残りの量（曖昧性あり） | **正弦法則** |
| 2辺＋挟角（SAS） | 第3の辺 | **余弦法則** |
| 3辺（SSS） | ある角 | **逆向き余弦法則** |

**SSA曖昧ケース**（$a$、$b$、$A$ が与えられ $A < 90°$ のとき）：$h = b\sin A$ を計算する。

- $a < h$：三角形なし
- $a = h$ または $a \geq b$：ちょうど 1 つの三角形
- $h < a < b$：2 つの三角形

</Definicao>

### 三角形の面積

<Equation explicacao="ヘロンの公式：3辺だけから面積を求める（角は不要）。半周長：s = (a+b+c)/2。" latex="\text{面積} = \sqrt{s(s-a)(s-b)(s-c)}" />

<Insight>

**余弦法則は内積である。** 恒等式 $|\vec{v} - \vec{u}|^2 = |\vec{v}|^2 + |\vec{u}|^2 - 2\,\vec{u}\cdot\vec{v}$ は、$\vec{u}\cdot\vec{v} = |\vec{u}||\vec{v}|\cos C$ のとき、余弦法則そのものである。線形代数では、これはノルムと角による内積の*定義*であり、高次元空間での「距離」を一般化する公式（マハラノビス距離、RBFカーネルなど）でもある。

</Insight>

<Porta nivel="10" titulo="10歳児向け">

ピタゴラスは直角三角形のときだけ成り立つ。でも三角形が「普通の」場合はどうする？例えば、鋭角（角がすべて 90° より小さい）または鈍角（1 つの角が 90° より大きい）。

そのときは**正弦法則**または**余弦法則**を使う。

**正弦法則**：任意の三角形について、$\dfrac{\text{辺}}{\text{対角の正弦}}$ の比は同じ。例えば、1辺が 10 で対角が 30°、別の辺が 14 で対角が $B$ なら、$14/\sin B = 10/\sin 30°$。方程式を解く。

**余弦法則**：ピタゴラスの一般化。$c^2 = a^2 + b^2$ ではなく、$c^2 = a^2 + b^2 - 2ab \cos C$ 。$C = 90°$ のとき、$\cos 90° = 0$ で最後の項は消え、ピタゴラスに戻る。

**どこに出てくる？** 測量（土地を測る）、航海（GPS は三角測量を使う）、天文学（星までの距離を計算）、工学（ベクトルと力）。

</Porta>

<Porta nivel="15" titulo="15歳の思春期向け">

第11講で、「直角三角形を解く」ことを学んだ：1辺と 1 角が与えられたら、他の辺を見つける。

でも三角形に**90°の角がない**場合はどうする？ピタゴラスは働かず、直角三角形の sin/cos も使えない。

解決策：**正弦法則**と**余弦法則**。**任意の**三角形で機能する。

**正弦法則**：各辺とそれの対角の正弦の比は一定。
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$$

**余弦法則**：$c^2 = a^2 + b^2 - 2ab\cos C$。辺 $a$ と $b$ に挟まれた角 $C$ の余弦で「修正された」ピタゴラス。

実際には：3 つの測定値（3 辺、または 2 辺と 1 角など）が与えられて、残りを求める。正しい法則を適用して計算する。

**例**：北に 5 km、東に 60° 曲がって 3 km さらに行く。出発点からどのくらい遠い？

余弦法則：$d^2 = 5^2 + 3^2 - 2 \cdot 5 \cdot 3 \cdot \cos(120°) = 25 + 9 + 15 = 49$。したがって $d = 7$ km。

（三角形の内角は、経路の曲がりから $180° - 60° = 120°$。）

**クイック判定**：2 辺に挟まれた角がある？余弦法則を使う。2 つの角がある？正弦法則を使う。

</Porta>

<Porta nivel="25" titulo="工学学生向け">

正弦法則と余弦法則は以下の分野で基本的である：

- **測量・地籍**：直接アクセスできない点の三角測量。
- **航海**：GPS は 4 つ以上の衛星を組み合わせた 3D 三角測量を行う — 余弦法則の多次元版。
- **天文学**：年差は正弦法則を使う。
- **ロボット工学**：2 つのリンク付きロボットアームの逆運動学は余弦法則で解く。

### 三角形の面積

$$\text{面積} = \frac{1}{2} ab \sin C$$

「底×高/2」から来ており、高さ $= a \sin C$。$C = 90°$ のとき、「脚×脚/2」に戻る。

### ヘロンの公式

3 辺 $a, b, c$ が与えられ、半周長 $s = (a+b+c)/2$ のとき：
$$\text{面積} = \sqrt{s(s-a)(s-b)(s-c)}$$

余弦法則と恒等式 $\sin^2 + \cos^2 = 1$ を組み合わせることで証明される。

### ベクトルとの接続

余弦法則は膨張 $|\vec u - \vec v|^2 = |\vec u|^2 + |\vec v|^2 - 2 \vec u \cdot \vec v$ に等しい — 線形代数では、ノルムと角による内積の*定義そのもの*である。

### 行列による解法（プレビュー）

ベクトル $\vec u, \vec v$ で定義された三角形について：
- 対辺：$|\vec u - \vec v|$
- 挟まれた角：$\arccos(\vec u \cdot \vec v / (|\vec u| |\vec v|))$
- 面積：$|\vec u \times \vec v|/2$（3D）、または $|u_1 v_2 - u_2 v_1|/2$（2D）。

</Porta>

<Porta nivel="40" titulo="上級専門家向け">

正弦法則と余弦法則は、リーマン多様体上の**ピタゴラスの定理の一般化**、または内積空間における**平行四辺形則**の特例である。

### 非ユークリッド幾何での一般化

球面幾何（半径 $R$）では：
$$\cos(c/R) = \cos(a/R)\cos(b/R) + \sin(a/R)\sin(b/R) \cos C$$

$R \to \infty$ のとき（Taylor 展開 2 次まで）、平面余弦法則に収束する。

双曲幾何では：
$$\cosh c = \cosh a \cosh b - \sinh a \sinh b \cos C$$

### GNSS/GPS の応用

受信機は各衛星からの信号到着時間を測定する（疑似距離）。三角測量は $|\vec p - \vec s_i| = c (t_i - \delta)$ の連立方程式を解く。ここで $\vec p$ は位置、$\vec s_i$ は衛星、$\delta$ は時計オフセット。初期推定の近くで線形化し、ノルムの勾配を使う — 正確には、余弦法則を微分したもの。

### 数値計算

```python
import numpy as np
import sympy as sp

# 余弦法則の数値版：
a, b, c = 7, 8, 9
C = np.arccos((a**2 + b**2 - c**2) / (2*a*b))
print(np.degrees(C))   # ~73.4°

# ヘロン：
s = (a + b + c) / 2
area = np.sqrt(s*(s-a)*(s-b)*(s-c))
print(area)   # ~26.83

# シンボリック：
A, B, c = sp.symbols('A B c', positive=True)
sp.solve(sp.Eq(c**2, A**2 + B**2 - 2*A*B*sp.cos(sp.pi/3)), c)
```

### 落とし穴

- **SSA 曖昧性**：0、1、または 2 つの解を与える — 航海問題の古典的なエラー源。
- **「細い」三角形の Heron**：$a + b \approx c$ のとき、$s - c$ は小さく数値消去が生じる。**Kahan の数値的に安定した公式**を使う：$a \geq b \geq c$ と順序付けして $\sqrt{(a + (b+c))(c - (a-b))(c + (a-b))(a + (b-c))}/4$ を計算。
- **電卓の度/弧度切り替え**：いつものように。

</Porta>

<Porta nivel="pratica" titulo="実用的応用">

**レシピ：任意の三角形が与えられたら、すべての辺と角を求める。**

1. **何が揃っているか列挙する**（角、辺）。
2. **データを数える**：3 つの独立した情報で三角形が定まる（SSA 曖昧性を除く）。
3. **法則を選ぶ**：
   - 2 つの角？ → 正弦法則。
   - 2 辺 + 挟角？ → 余弦法則。
   - 3 辺？ → 逆向き余弦法則。
4. **適用する**。
5. **角の和** $A + B + C = \pi$ を使って完成させる。

### Wolfram/SymPy/NumPy ワークフロー

```python
import numpy as np
import sympy as sp

# 例：a = 8、A = 30°、B = 45°、b を求める
A_rad = np.radians(30)
B_rad = np.radians(45)
a = 8
b = a * np.sin(B_rad) / np.sin(A_rad)
print(b)   # ~11.3137

# SymPy による余弦法則：
a, b, c, C = sp.symbols('a b c C', positive=True)
expr = sp.sqrt(a**2 + b**2 - 2*a*b*sp.cos(C))
print(expr.subs({a: 5, b: 7, C: sp.pi/3}))   # sqrt(39)
```

### 何に気をつけるか

- **SSA 曖昧ケース**：常に、0、1、または 2 つの三角形があるかを確認してから先に進む。
- **退化三角形**：$a + b = c$ なら線分（三角形ではない）。$a + b < c$ は不可能。
- **計算後の角の和 $\neq 180°$**：数値誤差（おそらく丸め）またはコサイン符号の誤り。
- **現地三角測量**：通常 1° の公称誤差で測定。誤差伝播は長距離で 5° まで拡大。

## 解法例

> 難度が上昇する 5 つの例 — 最も直接的（AAS 正弦法則）から実世界のモデル化（ロボットアームの逆運動学）まで。各例は元の問題の出典を示す：問題は常に公開されている教科書から来ている。

<Exemplo titulo="AAS 正弦法則（応用）" numero="1">

**問題：** 三角形 $ABC$ で、$A = 30°$、$B = 45°$、辺 $a = 8$。辺 $b$ を計算せよ。

**戦略：** 2 つの角と対辺が 1 つ（AAS ケース）ある。正弦法則が直接解く：比を立てて $b$ を隔離。

**解法：**

1. **正弦法則を適用する。** $\dfrac{a}{\sin A} = \dfrac{b}{\sin B}$、つまり $\dfrac{8}{\sin 30°} = \dfrac{b}{\sin 45°}$。
2. **特殊値を代入。** $\sin 30° = 1/2$、$\sin 45° = \sqrt 2 / 2$。
3. **$b$ を隔離。** $b = 8 \cdot \dfrac{\sin 45°}{\sin 30°} = 8 \cdot \dfrac{\sqrt 2 / 2}{1/2} = 8\sqrt 2 \approx 11{,}31$。

$$b = 8\sqrt 2 \approx 11{,}31.$$

**検証：** $B > A$ なので $b > a$ であるべき。実際 $11{,}31 > 8$。チェック。

**出典。** [OpenStax — Algebra and Trigonometry 2e §10.1](https://openstax.org/books/algebra-and-trigonometry-2e/pages/10-1-non-right-triangles-law-of-sines) — CC-BY 4.0 ライセンス。
</Exemplo>

<Exemplo titulo="SAS 余弦法則（応用）" numero="2">

**問題：** 三角形の辺 $a = 5$、$b = 7$、挟角 $C = 60°$。第 3 の辺 $c$ を計算せよ。

**戦略：** 2 辺と挟角（SAS）がある。正確に余弦法則を使って挟角の対辺を求めるケース。

**解法：**

1. **法則を適用。** $c^2 = a^2 + b^2 - 2ab \cos C$。
2. **代入。** $c^2 = 25 + 49 - 2 \cdot 5 \cdot 7 \cdot \cos 60° = 74 - 70 \cdot \tfrac{1}{2} = 74 - 35 = 39$。
3. **ルートを取る。** $c = \sqrt{39} \approx 6{,}24$。

**検証：** $c$ は $|a - b| = 2$ と $a + b = 12$ の間にあるべき（三角不等式）。$6{,}24 \in (2, 12)$。チェック。

**出典。** [Stitz–Zeager — Precalculus §11.3](https://www.stitz-zeager.com/szprecalculus07042013.pdf) — CC-BY-NC-SA ライセンス。
</Exemplo>

<Exemplo titulo="逆向き余弦法則 — 3 辺から角を求める（中級）" numero="3">

**問題：** 三角形の辺 $a = 5$、$b = 6$、$c = 7$。角 $C$ を計算せよ。

**戦略：** SSS — 3 辺がわかっている。$\cos C$ について余弦法則を並べ替えて $\arccos$ を適用。

**解法：**

1. **余弦法則を並べ替える。** $\cos C = \dfrac{a^2 + b^2 - c^2}{2ab}$。
2. **代入。** $\cos C = \dfrac{25 + 36 - 49}{2 \cdot 5 \cdot 6} = \dfrac{12}{60} = \dfrac{1}{5} = 0{,}2$。
3. **arccos を適用。** $C = \arccos(0{,}2) \approx 78{,}46°$。

$$C \approx 78{,}46°.$$

**検証：** 三角形はほぼ二等辺で $c$ が最大辺なので、$C$ が最大角であると予想。余弦法則から：$A = \arccos((36+49-25)/(2\cdot 6 \cdot 7)) = \arccos(60/84) \approx 44{,}42°$、$B \approx 57{,}12°$。和：$44{,}42 + 57{,}12 + 78{,}46 \approx 180°$。チェック。

**出典。** [OpenStax — Algebra and Trigonometry 2e §10.2](https://openstax.org/books/algebra-and-trigonometry-2e/pages/10-2-non-right-triangles-law-of-cosines) — CC-BY 4.0 ライセンス。
</Exemplo>

<Exemplo titulo="SSA 曖昧ケース（上級）" numero="4">

**問題：** 三角形で $a = 5$、$b = 8$、$A = 30°$。これらの条件を満たす三角形は何個？すべて求めよ。

**戦略：** SSA は曖昧ケース。$h = b \sin A$ を計算して $a$ と比較し、0、1、または 2 つの三角形があるか決定。次に正弦法則を各ケースに適用。

**解法：**

1. **$h$ を計算。** $h = b \sin A = 8 \cdot \sin 30° = 8 \cdot 0{,}5 = 4$。
2. **解の個数を決定。** $h = 4 < a = 5 < b = 8$ なので、**2 つの三角形**がある。
3. **正弦法則を適用。** $\dfrac{\sin B}{b} = \dfrac{\sin A}{a} \Rightarrow \sin B = \dfrac{8 \cdot 0{,}5}{5} = 0{,}8$。
4. **2 つの角 $B$ を求める。** $B_1 = \arcsin(0{,}8) \approx 53{,}13°$ と $B_2 = 180° - 53{,}13° \approx 126{,}87°$。
5. **各ケースで $C$ を計算。** $C_1 = 180° - 30° - 53{,}13° = 96{,}87°$。$C_2 = 180° - 30° - 126{,}87° = 23{,}13°$。
6. **各ケースで $c$ を計算。** $c_1 = a \cdot \sin C_1 / \sin A = 5 \cdot \sin 96{,}87° / 0{,}5 \approx 9{,}93$。$c_2 = 5 \cdot \sin 23{,}13° / 0{,}5 \approx 3{,}93$。

**検証：** 各三角形で $A + B + C = 180°$ で、三角不等式が成り立つ（すべての辺が正で $|a-b| < c < a+b$）。両方ともチェック。

**出典。** [Stitz–Zeager — Precalculus §11.2](https://www.stitz-zeager.com/szprecalculus07042013.pdf) — CC-BY-NC-SA ライセンス。
</Exemplo>

<Exemplo titulo="測量 — 第 3 頂点経由の距離（実世界モデル化）" numero="5">

**問題：** 2 つの点 $AB$ 間の距離を測るため（川で隔たれている）、測量士は岸に点 $C$ を選ぶ。$AC = 50$ m、$BC = 70$ m、角 $\hat{ACB} = 60°$。$AB$ を計算せよ。

**戦略：** 古典 SAS シナリオ — 2 つの辺 $AC$ と $BC$ が既知で、その間の角がある。余弦法則が対辺 $AB$ に直接解く。

**解法：**

1. **配置を特定。** 三角形 $ABC$ で辺 $b = AC = 50$ m、$a = BC = 70$ m、それらの間の角 $C = 60°$。第 3 の辺 $c = AB$ が欲しい。
2. **余弦法則を適用。** $c^2 = a^2 + b^2 - 2ab\cos C = 70^2 + 50^2 - 2 \cdot 70 \cdot 50 \cdot \cos 60°$。
3. **計算。** $c^2 = 4900 + 2500 - 7000 \cdot 0{,}5 = 7400 - 3500 = 3900$。
4. **ルートを取る。** $c = \sqrt{3900} = 10\sqrt{39} \approx 62{,}45$ m。

$$AB \approx 62{,}45\ \text{m}.$$

**検証：** 角 $C$ が鋭角で辺 $a, b$ が著しく異ならないから、対辺は比較可能に大きいであるべき。$62{,}45$ は $|70-50| = 20$ と $70+50 = 120$ の間、三角不等式内。チェック。

**出典。** [OpenStax — University Physics Vol. 1, cap. 2](https://openstax.org/books/university-physics-volume-1/pages/2-introduction) — CC-BY 4.0 ライセンス。
</Exemplo>
