### 三角関数

<Definicao titulo="サイン、コサイン、タンジェント関数">

- $\sin: \mathbb{R} \to [-1, 1]$ — 単位円上の点の $y$ 座標で定義。
- $\cos: \mathbb{R} \to [-1, 1]$ — 単位円上の点の $x$ 座標で定義。
- $\tan: \mathbb{R} \setminus \{(2k+1)\pi/2 \mid k \in \mathbb{Z}\} \to \mathbb{R}$ — $\tan x = \sin x / \cos x$ で定義。

基本周期：$\sin$ と $\cos$ は周期 $2\pi$；$\tan$ は周期 $\pi$。

</Definicao>

> 「サイン関数とコサイン関数は周期 $2\pi$ の周期関数。つまり、すべての入力 $t$ に対して、$\sin(t + 2\pi) = \sin t$ かつ $\cos(t + 2\pi) = \cos t$。」—  [OpenStax Algebra and Trigonometry 2e, §6.1](https://openstax.org/books/algebra-and-trigonometry-2e/pages/6-1-graphs-of-the-sine-and-cosine-functions)

> 「サイン関数とコサイン関数の基本周期は $2\pi$。サイン関数の定義域はすべての実数。値域は $[-1, 1]$。」— [Stitz–Zeager Precalculus, §10.5](https://www.stitz-zeager.com/szprecalculus07042013.pdf)

### 一般化された正弦関数

<Definicao titulo="y = A sin(ωt + φ) + k のパラメータ">

$y(t) = A \sin(\omega t + \varphi) + k$ で $A > 0$、$\omega > 0$：

| パラメータ | 名前 | 効果 |
|-----------|------|--------|
| $A$ | 振幅 | 中心軸から頂点までの距離；値域 $[k-A,\, k+A]$ |
| $\omega$ | 角周波数（rad/s） | $T = 2\pi/\omega$；$f = \omega/(2\pi)$ |
| $\varphi$ | 初期位相（rad） | 水平シフト：最大は $\omega t + \varphi = \pi/2$ で |
| $k$ | 鉛直シフト | グラフの中心軸 |

</Definicao>

### tan x のグラフ

<Definicao titulo="タンジェント関数">

$\tan x = \sin x / \cos x$。周期 $\pi$、**鉛直漸近線** $x = \pi/2 + k\pi$（$\cos x = 0$ の場所）。値域：$\mathbb{R}$。各周期で増加。

</Definicao>

### 逆数関数

<Definicao titulo="コセカント、セカント、コタンジェント">

- $\csc x = 1/\sin x$、定義域 $\mathbb{R} \setminus \{k\pi\}$
- $\sec x = 1/\cos x$、定義域 $\mathbb{R} \setminus \{(2k+1)\pi/2\}$
- $\cot x = \cos x / \sin x$、定義域 $\mathbb{R} \setminus \{k\pi\}$

</Definicao>

<Insight>
関係 $\cos x = \sin(x + \pi/2)$ は、コサインがサインを $\pi/2$ 左にシフトしたものであることを示す。この90°の位相差はAC回路では基本的：インダクタの電圧と電流の位相差は正確に $\pi/2$。
</Insight>

</Porta>

<Porta nivel="5" titulo="5歳児向け">

なわとびを想像してください。なわが上下して、上下して、上下して — いつも同じ。止まることはなく、高さは変わりません。

毎瞬間のなわの高さで素敵な絵が描けます。数学者たちはこの絵を**サインの波**と呼びます。なわが上にあるときサインは $1$。下にあるときサインは $-1$。

なわを変えられます：高くしたり、速くしたり、別の場所から始めたり。いつも素敵な波になります。

</Porta>

<Porta nivel="10" titulo="10歳児向け">

三角関数は**いつも同じ方法で繰り返す関数** — 海の波のように。上がって、下がって、上がって、下がって。

基本的な波は**サイン**。 $1$（頂点）まで上がって、 $-1$（底）まで下がって、完全な回転ごと（ $2\pi$ ラジアン）に繰り返します。

一般式は $y = A\sin(\omega t + \varphi) + k$ で4つのコントロールがあります：
- **$A$** — 波の高さ（振幅）。
- **$\omega$** — 振動の速度（1秒間の波数）。
- **$\varphi$** — 波が始まる場所（位相）。
- **$k$** — 波の中央がどこにあるか（鉛直シフト）。

どこに現れるか？音（ギター弦の振動）、潮汐（1日2回上下）、振り子、ばね、電気コンセント（1秒間に60回上下）。

</Porta>

<Porta nivel="15" titulo="15歳の青少年向け">

三角関数は**周期関数** — $2\pi$ ごとに繰り返します。$\sin x$ のグラフは $1$ まで上がって、 $-1$ まで下がって、再び始まる波です。

式 $y = A\sin(\omega t + \varphi) + k$ は4つのコントロールがあります：

- $A$：**振幅** — 中心軸から頂点までの距離。
- $\omega$：**角周波数**（rad/s） — どのくらい速く振動するか。
- $\varphi$：**位相** — 水平シフト。
- $k$：**鉛直シフト** — 中心軸がどこにあるか。

**周期** $T = 2\pi/\omega$ と **周波数** $f = 1/T = \omega/(2\pi)$。

$\sin$ と $\cos$ の違いは位相差だけ：$\cos x = \sin(x + \pi/2)$。

**例 — サルバドールの潮汐：** 0.5 m と 2.5 m の間で振動し、周期は12時間。
- 中心：$k = (0{,}5 + 2{,}5)/2 = 1{,}5$ m。
- 振幅：$A = (2{,}5 - 0{,}5)/2 = 1$ m。
- 角周波数：$\omega = 2\pi/12 = \pi/6$ rad/h。
- モデル：$h(t) = 1{,}5 + \sin(\pi t/6)$。

</Porta>

<Porta nivel="25" titulo="工学学生向け">

三角関数は**信号処理の心臓**。線形時間不変（LTI）系の解析はすべて次に基づく：

1. 入力信号を正弦波／余弦波に分解（フーリエ）。
2. 各成分に伝達関数 $H(j\omega)$ を適用。
3. 出力を再構成。

### 別の形式：$A\sin + B\cos$

$$A\sin(\omega t) + B\cos(\omega t) = R\sin(\omega t + \varphi)$$

ここで $R = \sqrt{A^2 + B^2}$ 、$\tan\varphi = B/A$。同じ周波数の正弦波と余弦波の任意の線形結合は別の正弦波 — 振動の重ね合わせで基本的な性質。

### 導関数（引数はラジアンのときのみ有効）

$$(\sin x)' = \cos x, \qquad (\cos x)' = -\sin x, \qquad (\tan x)' = \sec^2 x$$

サインの4階導関数がサインを再現：$\sin'''' = \sin$。

### 工学での応用

- **AC（交流）：** $V(t) = V_0\sin(\omega t)$ で $\omega = 2\pi \cdot 60$ rad/s（ブラジル）。実効電圧 $V_{ef} = V_0/\sqrt{2} \approx 220$ V。
- **音響学：** オーケストラのラ — $f = 440$ Hz、$\omega = 880\pi$ rad/s。
- **質量-ばね系（SHM）：** $x(t) = A\sin(\omega_n t + \varphi)$ で $\omega_n = \sqrt{k/m}$。
- **潮汐：** 月周期と太陽周期の正弦波の重ね合わせ（M2、S2、K1、O1）。
- **AM変調：** $V(t) = (1 + m(t))\cos(\omega_c t)$。

### 有用な恒等式

$$\sin^2 x = \frac{1 - \cos 2x}{2}, \qquad \cos^2 x = \frac{1 + \cos 2x}{2}$$
$$\sin A\cos B = \frac{\sin(A+B) + \sin(A-B)}{2}$$

</Porta>

<Porta nivel="40" titulo="シニアプロフェッショナル向け">

正弦波関数は微分演算子 $d/dt$ の**固有関数**：$y(t) = e^{j\omega t}$ ならば $dy/dt = j\omega y$。これはフーリエが機能する基本的な理由 — 正弦波はあらゆるLTI系の固有ベクトル。

### 実験データでのパラメータ識別

実際には、ノイズを含む周期的と思われるデータ $\{y_i\}$ が与えられたとき、$A$、$\omega$、$\varphi$ を推定するのに：

1. **FFT：** スペクトルのピーク $\Rightarrow$ $\omega$ 推定。
2. **最小二乗法** $A\cos\varphi$ と $A\sin\varphi$ をパラメータとして線形化後。
3. **ゴーテルゼルアルゴリズム** $\omega$ が既知の場合（DTMF、モデム）。

### 計算上の落とし穴

- **エイリアシング（ナイキスト-シャノン定理）：** 周波数 $f > f_s/2$ の波をサンプリングすると虚構の周波数 $|f - f_s|$ の信号が生じます。$f_s > 2f_{\max}$ が必要。
- **$x$ が小さいときの $\sin x$ での破滅的キャンセル：** $\sin x \approx x - x^3/6$ を使用。
- **非常に大きい $x$ の剰余削減：** GPU のクラシックバグの源 — ペイン-ハネク法を使用。

### 現代の接続

- **トランスフォーマーの位置エンコーディング**（Vaswani 2017）：$PE_{pos,\,2i} = \sin(pos/10000^{2i/d})$ — 幾何学的間隔の周波数を持つ正弦波で時間順序を組み込む。
- **SIREN**（Sitzmann 2020）：活性化 $\sin(\omega_0 x)$ を持つニューラルネットワークは画像と滑らかな表面を ReLU より良く表現、微分可能で導関数が良好に振る舞う。

```python
import sympy as sp
t, omega = sp.symbols('t omega', real=True)
y = sp.sin(omega*t) + sp.sqrt(3)*sp.cos(omega*t)
# A sin(omega t + phi) に因数分解：
sp.simplify(y.rewrite(sp.cos))  # 2*sin(omega*t + pi/3)
```

</Porta>

<Porta nivel="pratica" titulo="実用的な応用">

**レシピ：周期現象を正弦波でモデル化する。**

1. **平均値を識別：** $k = (\max + \min)/2$。
2. **振幅を計算：** $A = (\max - \min)/2$。
3. **周期 $T$ を決定。** $\omega = 2\pi/T$ に変換。
4. **位相 $\varphi$ を決定** 初期条件 $(t_0, y_0)$ を使用。

**例 — ブラジリアの気温：** 18°C（7月）と23°C（10月）の間で振動。$k = 20{,}5$、$A = 2{,}5$、$T = 12$ ヶ月、$\omega = \pi/6$。

**例 — サルバドールの潮汐：** 0.5 m と 2.5 m の間、周期12時間、平均水位で上昇中 $t = 0$。モデル：$h(t) = 1{,}5 + \sin(\pi t/6)$ m。

```python
import sympy as sp
t = sp.symbols('t', real=True)
T = 12
omega = 2*sp.pi / T
A, k, phi = 1, 1.5, 0
mare = A*sp.sin(omega*t + phi) + k
# 潮汐はいつ最大か？（= 2.5）
sp.solve(sp.Eq(mare, 2.5), t)  # t = 3 h
```

**モデル化時のチェックリスト：**

- 電卓モード：度ではなくラジアン。
- $\omega$ の単位は $t$ と一致していなければならない（rad/h、rad/s など）。
- 初期位相：$\sin$ は増加零から始まる；$\cos$ は最大から始まる。
- $\tan$ は鉛直漸近線を持つ — $\cos$ で除算するときは注意。

</Porta>

## 解答済み例

<Exemplo titulo="振幅、周期、値域を識別（応用）" numero="1">

**問題：** $y = 3\sin(2x) + 1$ について、振幅、周期、周波数、値域を識別してください。

**戦略：** $y = A\sin(\omega x + \varphi) + k$ と比較して、定義を直接適用。

**解：**

1. **パラメータ：** $A = 3$、$\omega = 2$、$\varphi = 0$、$k = 1$。
2. **振幅：** $|A| = 3$。
3. **周期：** $T = 2\pi/\omega = 2\pi/2 = \pi$。
4. **周波数：** $f = 1/T = 1/\pi$ （$x$ の単位ごとの周期）。
5. **値域：** $[k - A,\, k + A] = [-2,\, 4]$。

**検証：** $x = \pi/4$ で：$y = 3\sin(\pi/2) + 1 = 3 + 1 = 4$（最大）。$x = 3\pi/4$ で：$y = 3\sin(3\pi/2) + 1 = -3 + 1 = -2$（最小）。値域 $[-2, 4]$ を確認。✓

**出典。** [OpenStax — Algebra and Trigonometry 2e §6.1](https://openstax.org/books/algebra-and-trigonometry-2e/pages/6-1-graphs-of-the-sine-and-cosine-functions) — CC-BY 4.0 ライセンス。
</Exemplo>

<Exemplo titulo="基本的な三角方程式を解く（応用）" numero="2">

**問題：** $\sin x = 1/2$ を $x \in [0, 2\pi)$ で解いてください。

**戦略：** 単位円を使ってサインが 1/2 に等しい区間内のすべての角度を識別。

**解：**

1. **参照解：** $\sin(\pi/6) = 1/2$（第1象限）。
2. **対称性：** サインは第1象限と第2象限で正。第2象限では：$\sin(\pi - \pi/6) = \sin(5\pi/6) = 1/2$。
3. **解集合：** $\{\pi/6,\; 5\pi/6\}$。

**検証：** $\sin(5\pi/6) = \sin(\pi - \pi/6) = \sin(\pi/6) = 1/2$。✓

**出典。** [OpenStax — Algebra and Trigonometry 2e §7.5](https://openstax.org/books/algebra-and-trigonometry-2e/pages/7-5-solving-trigonometric-equations) — CC-BY 4.0 ライセンス。
</Exemplo>

<Exemplo titulo="正弦潮汐モデリング（中級）" numero="3">

**問題：** 湾の潮汐は 0.5 m と 2.5 m の間で、周期12時間で振動します。$t = 0$ で潮汐は平均水位で上昇中。$h(t)$ をモデル化してください。

**戦略：** 正弦モデリングレシピで $k$、$A$、$\omega$、$\varphi$ を識別。

**解：**

1. **平均値：** $k = (0{,}5 + 2{,}5)/2 = 1{,}5$ m。
2. **振幅：** $A = (2{,}5 - 0{,}5)/2 = 1$ m。
3. **角周波数：** $\omega = 2\pi/12 = \pi/6$ rad/h。
4. **位相：** $t = 0$ で $h = 1{,}5$（平均水位）で上昇中。$\sin 0 = 0$ かつ $(\sin)' = \cos > 0$ だから、$\varphi = 0$。
5. **モデル：** $h(t) = 1{,}5 + \sin(\pi t/6)$、$t$ は時間。

**検証：** $t = 3$ h で、$h = 1{,}5 + \sin(\pi/2) = 2{,}5$（最高潮位）。$t = 9$ h で、$h = 1{,}5 + \sin(3\pi/2) = 0{,}5$（最低潮位）。✓

**出典。** [Active Calculus §0.7 (Trigonometry)](https://activecalculus.org/single/sec-0-7-trigonometry.html) — CC-BY-NC-SA ライセンス。
</Exemplo>

<Exemplo titulo="ネットワーク交流実効電圧（上級）" numero="4">

**問題：** ブラジルの電力網の電圧は $V(t) = 311\sin(120\pi t)$ V。次を決定：(a) 振幅、(b) Hz の周波数、(c) 周期、(d) 実効電圧 $V_{ef} = V_0/\sqrt{2}$。

**戦略：** $A\sin(\omega t)$ と比較して実効電圧の定義を適用。

**解：**

1. **振幅：** $V_0 = 311$ V。
2. **角周波数：** $\omega = 120\pi$ rad/s。
3. **周波数：** $f = \omega/(2\pi) = 60$ Hz。
4. **周期：** $T = 1/60$ s $\approx 16{,}67$ ms。
5. **実効電圧：** $V_{ef} = 311/\sqrt{2} \approx 220$ V。

**検証：** 220 V 実効値はブラジルの 60 Hz ネットワークの正確な定格。✓

<Exemplo titulo="2次三角方程式（実モデリング）" numero="5">

**問題：** $2\sin^2 x + \sin x - 1 = 0$ を $x \in [0, 2\pi)$ で解いてください。

**戦略：** $u = \sin x$ に置換して $u$ の二次方程式を解き、その後対応する $x$ を見つける。

**解：**

1. **$u = \sin x$ に置換：** $2u^2 + u - 1 = 0$。
2. **因数分解：** $(2u - 1)(u + 1) = 0$、$u_1 = 1/2$ かつ $u_2 = -1$。
3. **$x$ に戻る：**
   - $\sin x = 1/2$：$x \in \{\pi/6,\; 5\pi/6\}$。
   - $\sin x = -1$：$x = 3\pi/2$。
4. **解集合：** $\{\pi/6,\; 5\pi/6,\; 3\pi/2\}$。

**検証：** $x = \pi/6$：$2(1/4) + 1/2 - 1 = 0$。✓ $x = 3\pi/2$：$2(1) + (-1) - 1 = 0$。✓

**出典。** [Stitz–Zeager Precalculus §10.7](https://www.stitz-zeager.com/szprecalculus07042013.pdf) — CC-BY-NC-SA ライセンス。
</Exemplo>
