### TFC — 第1部：積分を導出する

<Teorema titulo="TFC 第1部（積分関数の導関数）">

$f: [a, b] \to \mathbb{R}$ が**連続**であるとします。**積分関数**を定義します：

$$G(x) = \int_a^x f(t)\, dt, \quad x \in [a, b].$$

このとき、$G$ は $(a, b)$ で微分可能であり、$G'(x) = f(x)$ です。

</Teorema>

> 「TFC1は、上の極限が可変な積分で定義された関数の導関数が、上の極限での被積分関数の値に等しいことを述べています。」— [OpenStax Calculus Vol. 1, §5.3](https://openstax.org/books/calculus-volume-1/pages/5-3-the-fundamental-theorem-of-calculus)

**TFC1の証明。** 導関数の定義により：

$$G'(x) = \lim_{h \to 0} \frac{G(x+h) - G(x)}{h} = \lim_{h \to 0} \frac{1}{h} \int_x^{x+h} f(t)\, dt.$$

積分の平均値定理により、$x$ と $x+h$ の間に $c_h$ が存在して $\int_x^{x+h} f(t)\, dt = f(c_h) \cdot h$ です。したがって：

$$G'(x) = \lim_{h \to 0} f(c_h).$$

$h \to 0$ のとき $c_h \to x$ であり、$f$ は連続であるから、$f(c_h) \to f(x)$ です。したがって $G'(x) = f(x)$ です。 $\square$

### TFC — 第2部：積分を計算する

<Teorema titulo="TFC 第2部（評価公式）">

$f: [a, b] \to \mathbb{R}$ が**連続**であり、$F$ が $f$ の任意の原始関数であるとします。このとき：

$$\int_a^b f(x)\, dx = F(b) - F(a).$$

表記法：$F(x)\big|_a^b := F(b) - F(a)$。

</Teorema>

**TFC2の証明。** TFC1により、$G(x) = \int_a^x f(t)\, dt$ は $G' = f$ を満たします。また $F' = f$ であるから、$F - G$ は $(a, b)$ で導関数がゼロであり、したがってある定数 $C$ に対して $F(x) = G(x) + C$ です。すると：

$$F(b) - F(a) = [G(b) + C] - [G(a) + C] = G(b) - G(a) = \int_a^b f - 0 = \int_a^b f. \quad \square$$

### ライプニッツ則（可変な極限）

<Definicao titulo="積分記号下での微分">

$f$ が連続であり、$u(x)$、$v(x)$ が微分可能であるとき：

$$\frac{d}{dx} \int_{u(x)}^{v(x)} f(t)\, dt = f(v(x))\, v'(x) - f(u(x))\, u'(x).$$

（TFC1をチェーンルール経由で適用した結果。）

</Definicao>

<Insight>

**なぜTFCは「基本的」なのか？** TFCの前は、$\int_a^b f$ を計算するには、リーマン和の極限を取る必要がありました。これは定数関数以外ではかなり大変です。TFCの後は、問題は単純に**原始関数を見つけて2つの値を評価する**ことに帰着します。これは微積分学を解析ツールから工学ツールに変えました。

</Insight>

</Porta>

<Porta nivel="5" titulo="5歳の子どもへ">

階段を想像してください。各段の高さがあります。あなたは**合計でどのくらい上ったか**知りたいとします。各段を測る必要はありません。**今どこにいるか**と**どこから始めたか**を見て、その差を取るだけです。

TFCは言っています：累積された合計を計算するには、**どこに到達したか**と**どこから始めたか**を知るだけでよい、と。

</Porta>

<Porta nivel="10" titulo="10歳の子どもへ">

積分は小さな断片を足し合わせて面積を計算します。導関数は変化の速度を測ります。これらは全く異なることに見えます！

TFCは、これらが**逆操作**であることを示します。足し算と引き算のようにです。

**魔法のレシピ：** $\int_a^b f$ を計算するには、導関数が $f$ である関数 $F$ を見つけます。積分はただ $F(b) - F(a)$ です。

例：$\int_0^3 x^2\, dx$。$(x^3/3)' = x^2$ だから、積分は $3^3/3 - 0 = 9$ です。

TFCなし：無限個の長方形を足す必要があります。TFC付き：3つの計算。だからTFCは微積分学で最も重要な定理です。

</Porta>

<Porta nivel="15" titulo="15歳の思春期の子どもへ">

TFCは**2つの部分**を持ちます：

**第1部（TFC1）：** 関数を積分してその結果を導出すると、元の関数に戻ります。数学的には：$\frac{d}{dx}\int_a^x f(t)\, dt = f(x)$。

**第2部（TFC2）：** $\int_a^b f$ を計算するには、原始関数 $F$ を見つけて $F(b) - F(a)$ を計算するだけです。

**実際にTFC2を使う方法：**

1. 被積分関数 $f(x)$ を特定します。
2. $F'(x) = f(x)$ を満たす $F$ を見つけます（原始関数の表を使用）。
3. $F(b) - F(a)$ を計算します。

**完全な例：**

$\int_1^4 (3x^2 + 2x)\, dx$。
- $F(x) = x^3 + x^2$。
- $F(4) - F(1) = (64 + 16) - (1 + 1) = 80 - 2 = 78$。

**検証：** $F(x) = x^3 + x^2$ を導出します。$3x^2 + 2x$ を得ます。一致します。

</Porta>

<Porta nivel="25" titulo="工学部の学生へ">

TFCは微積分学の2つの半分を結ぶ接着剤です。実際的には：

### TFC1 — 可変な極限を持つ積分を導出する

微分方程式と積分方程式で頻繁に出現する状況：

$$\frac{d}{dx}\int_0^{x^2} \sin(t)\, dt = \sin(x^2) \cdot 2x.$$

一般的なルール（ライプニッツ）：上の極限が $v(x)$ で下の極限が $u(x)$ の場合：

$$\frac{d}{dx}\int_{u(x)}^{v(x)} f(t)\, dt = f(v(x)) v'(x) - f(u(x)) u'(x).$$

> 「TFC1は積分を微分することを可能にする定理です。量がもう一つの量の積分として定義される物理学で基本的です。」— [APEX Calculus, §5.4](https://www.apexcalculus.com/)

### TFC2 — 代数への還元

TFC2は、$\int_a^b f$ の計算を $F' = f$ である $F$ を見つけるという代数的問題に還元します。積分技術のカタログ（置換、部分積分、部分分数分解）は**この代数的問題を解く目的で存在します**。

### エラー分析

最も一般的なエラーは差の符号を忘れることです：$F(b) - F(a)$ であって、$F(a) - F(b)$ ではありません。計算中は常に $\big|_a^b$ を明示的に書いてください。

### 数値解析でのTFC

$f$ が初等的な原始関数を持たない場合（例：$e^{-x^2}$）、数値的手法を使用します：
- **シンプソン法**：精度 $O(\Delta x^4)$、滑らかな関数に適切。
- **ガウス・クロンロッド求積法**：適応的、`scipy.integrate.quad` の標準。
- **モンテカルロ法**：他の方法が悪いスケーリングをする高次元で実行可能。

</Porta>

<Porta nivel="40" titulo="シニア専門家へ">

### 歴史的文脈でのTFC

ニュートンは1666年頃、「流率法」（導関数を「流率」、積分を「流量」と呼ぶ）の文脈でTFCを定式化しました。ライプニッツは独立して1675～1676年に開発し、今日まで続く $\int$ と $dx$ の記号を使いました。

有名な優先権論争（18世紀）は、国家主義によって大いに喚起されました。ロンドンの王立学会はライプニッツをプラギアリズムで非難しました。陪審団はニュートンが議長を務めていました。現代の歴史学は独立した並行開発を認識しています。

### ルベーグ微積分でのTFC

ルベーグ理論では、TFCはより注意深い仮説を必要とします：

- **TFC1（ルベーグ）：** $f \in L^1([a,b])$ なら、$G(x) = \int_a^x f$ は絶対連続で、$G' = f$ ほぼ至るところ。
- **TFC2（ルベーグ）：** $F$ が絶対連続で $F' = f$ ほぼ至るところなら、$\int_a^b f = F(b) - F(a)$。

病的な例：**カントール関数**（悪魔の階段）は連続で、ほぼ至るところ導関数がゼロですが、$F(1) - F(0) = 1 \neq 0 = \int_0^1 F'$ です。これはカントール関数が絶対連続**ではない**ためで、ルベーグのTFC2の仮説に違反しています。

### 数量化学資におけるTFC

ブラック・ショールズ公式では、価格の導出はイトーの補題を使用します。これはTFCの確率的バージョンです。正式には：$dF(W_t) = F'(W_t)\, dW_t + \frac{1}{2}F''(W_t)\, dt$、ここで $W_t$ はブラウン運動です。追加の $\frac{1}{2}F''$ は、ブラウン運動の2次変動の「2次補正」です。これはTFCの確率空間での類似物です。

</Porta>

<Porta nivel="pratica" titulo="実践的応用 — ブラジル・データ">

### 車隊の燃料消費

トラックの車隊の消費率は $c(t) = 200 + 30t$ リットル/時間（荷物の蓄積による線形成長）です。最初の8時間での総消費量：

$$C = \int_0^8 (200 + 30t)\, dt = \left[200t + 15t^2\right]_0^8 = 1600 + 960 = 2560\text{ リットル。}$$

R$ 6.50/リットルの場合：燃料の総費用 = R$ 16.640。

### 可変な極限を持つ積分の導関数

ある環境に蓄積されるCO2の量は $A(x) = \int_0^x e^{-t/10}\, dt$ です。瞬間 $x$ での蓄積率は、TFC1により：

$$A'(x) = e^{-x/10}.$$

積分を計算する必要はありません。TFC1は導関数を直接与えます。

### 計算による検証

```python
import sympy as sp
x = sp.Symbol('x')
F = sp.integrate(x**2 + 3*x, x)        # 原始関数
result = F.subs(x, 4) - F.subs(x, 1)  # TFC2
print(result)  # => 33
```

## 解かれた例

<Exemplo numero="1" titulo="多項式に適用されたTFC2（基本）">

**問題。** $\displaystyle\int_1^3 (x^2 + 2x - 1)\, dx$ を計算します。

**戦略。** TFC2による原始関数を見つけます：$F'(x) = x^2 + 2x - 1$ である $F(x)$。その後 $F(3) - F(1)$。

**解。**
$$F(x) = \frac{x^3}{3} + x^2 - x.$$

$$\int_1^3 (x^2 + 2x - 1)\, dx = F(3) - F(1) = \left(9 + 9 - 3\right) - \left(\frac{1}{3} + 1 - 1\right) = 15 - \frac{1}{3} = \frac{44}{3}.$$

**検証。** $F'(x) = x^2 + 2x - 1$。一致します。

**出典。** [APEX Calculus, §5.4, 例 5.4.2](https://www.apexcalculus.com/) — CC-BY-NC。

</Exemplo>

<Exemplo numero="2" titulo="三角関数を伴うTFC2（基本）">

**問題。** $\displaystyle\int_0^{\pi/2} (\cos x + 2\sin x)\, dx$ を計算します。

**戦略。** $\cos x$ と $\sin x$ の原始関数を表から取得し、端点で評価します。

**解。**
$$F(x) = \sin x - 2\cos x.$$

$$\int_0^{\pi/2} (\cos x + 2\sin x)\, dx = F(\pi/2) - F(0) = (1 - 0) - (0 - 2) = 1 + 2 = 3.$$

**検証。** $F'(x) = \cos x + 2\sin x$。一致します。

**出典。** [OpenStax Calculus Vol. 1, §5.3, 例 5.22](https://openstax.org/books/calculus-volume-1/pages/5-3-the-fundamental-theorem-of-calculus) — CC-BY-NC-SA。

</Exemplo>

<Exemplo numero="3" titulo="積分を導出するためのTFC1（中級）">

**問題。** $\displaystyle\frac{d}{dx}\int_1^{x^3} \cos(t^2)\, dt$ を計算します。

**戦略。** TFC1をチェーンルールと組み合わせます：上の極限は $v(x) = x^3$。

**解。**
$$\frac{d}{dx}\int_1^{x^3} \cos(t^2)\, dt = \cos((x^3)^2) \cdot (x^3)' = \cos(x^6) \cdot 3x^2.$$

**検証。** ライプニッツの一般的なルール：$\frac{d}{dx}\int_a^{v(x)} f(t)\, dt = f(v(x)) \cdot v'(x)$。$f(t) = \cos(t^2)$、$v(x) = x^3$ で適用：$\cos(x^6) \cdot 3x^2$。一致します。

**出典。** [APEX Calculus, §5.4, 例 5.4.5](https://www.apexcalculus.com/) — CC-BY-NC。

</Exemplo>

<Exemplo numero="4" titulo="両方の極限が可変なライプニッツ則（中級）">

**問題。** $x > 0$ に対して $\displaystyle\frac{d}{dx}\int_x^{x^2} \frac{1}{t}\, dt$ を計算します。

**戦略。** 一般的なライプニッツ則：$f(v(x))v'(x) - f(u(x))u'(x)$ と $v(x) = x^2$、$u(x) = x$、$f(t) = 1/t$。

**解。**
$$\frac{d}{dx}\int_x^{x^2} \frac{1}{t}\, dt = \frac{1}{x^2} \cdot 2x - \frac{1}{x} \cdot 1 = \frac{2}{x} - \frac{1}{x} = \frac{1}{x}.$$

**検証。** または：$\int_x^{x^2} \frac{1}{t}\, dt = \ln(x^2) - \ln x = 2\ln x - \ln x = \ln x$。導出：$(\ln x)' = 1/x$。一致します。

**出典。** [OpenStax Calculus Vol. 1, §5.3, 演習 5.132](https://openstax.org/books/calculus-volume-1/pages/5-3-the-fundamental-theorem-of-calculus) — CC-BY-NC-SA。

</Exemplo>

<Exemplo numero="5" titulo="曲線と軸の間の領域、符号の変化（挑戦）">

**問題。** $y = x^2 - 4$ と $x$ 軸の間の全幾何学的面積を $[-3, 3]$ で計算します。

**戦略。** 関数 $f(x) = x^2 - 4$ は $(-2, 2)$ で負、外側で正です。正しい符号で面積を合計するために、ゼロを見つけるたびに区間を分割します。

**解。**
ゼロ：$x^2 = 4 \Rightarrow x = \pm 2$。

$[-3, -2]$ および $[2, 3]$ では：$f \geq 0$。$[-2, 2]$ では：$f \leq 0$。

$$A = \int_{-3}^{-2}(x^2-4)\, dx + \left|\int_{-2}^{2}(x^2-4)\, dx\right| + \int_2^3(x^2-4)\, dx.$$

$F(x) = x^3/3 - 4x$。

- $F(-2) - F(-3) = (-8/3 + 8) - (-9 + 12) = 16/3 - 3 = 7/3$。
- $F(2) - F(-2) = (8/3 - 8) - (-8/3 + 8) = -32/3$。絶対値：$32/3$。
- $F(3) - F(2) = (9 - 12) - (8/3 - 8) = -3 + 16/3 = 7/3$。

総面積：$7/3 + 32/3 + 7/3 = 46/3$。

**検証。** 積分 $\int_{-3}^3 (x^2 - 4)\, dx = F(3) - F(-3) = (9-12) - (-9+12) = -3 - 3 = -6 \neq 46/3$。$f$ が符号を変えるとき、定積分は幾何学的面積と異なります。

**出典。** [Active Calculus, §4.4, 演習 4.4.5](https://activecalculus.org/single/sec-4-4-FTC.html) — CC-BY-NC-SA。

</Exemplo>
