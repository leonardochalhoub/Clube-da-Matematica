### 密度和参数

<Definicao titulo="正态分布 N(mu, sigma^2)">

$X \sim \mathcal N(\mu, \sigma^2)$ 当且仅当 $X$ 的密度为：

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}}\,\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right), \quad x \in \mathbb{R}$$

- $\mu \in \mathbb{R}$：**位置**参数（均值 = 中位数 = 众数）。
- $\sigma > 0$：**尺度**参数（标准差）。
- $\sigma^2$：方差。

正规化性质 $\int_{-\infty}^{+\infty} f(x)\,dx = 1$ 遵循经典高斯结果：$\int_{-\infty}^{+\infty} e^{-x^2/2}\,dx = \sqrt{2\pi}$（使用极坐标证明）。

</Definicao>

> "如果 $X$ 是一个随机变量，$X$ 服从均值 $\mu$ 和标准差 $\sigma$ 的正态分布，我们记为 $X \sim N(\mu, \sigma)$。均值 $\mu$ 是对称曲线的中心，标准差 $\sigma$ 给出了分布的宽度。" — [OpenStax Statistics §6.1](https://openstax.org/books/statistics/pages/6-1-the-standard-normal-distribution)

<Definicao titulo="标准正态分布和标准化">

$Z \sim \mathcal N(0, 1)$。累积分布函数：

$$\Phi(z) = P(Z \leq z) = \int_{-\infty}^z \frac{1}{\sqrt{2\pi}} e^{-t^2/2}\,dt$$

没有初等闭形式——通过表格或数值计算。

**标准化**：如果 $X \sim \mathcal N(\mu, \sigma^2)$，则 $Z = (X - \mu)/\sigma \sim \mathcal N(0,1)$。

**对称性**：$\Phi(-z) = 1 - \Phi(z)$。

**重要分位数**：
- $z_{0{,}975} = 1{,}96$（双侧 95% 置信区间）。
- $z_{0{,}95} = 1{,}645$（单侧 95% 置信区间）。
- $z_{0{,}995} = 2{,}576$（双侧 99% 置信区间）。

</Definicao>

> "正态分布围绕其均值对称...正态分布曲线下，距离均值一个标准差内的面积约为 68%，两个标准差内约为 95%，三个标准差内约为 99.7%。" — [OpenIntro Statistics §3.5](https://www.openintro.org/book/os/)

<Teorema titulo="68-95-99.7 法则（Sigma 法则）">

对于 $X \sim \mathcal N(\mu, \sigma^2)$：

$$P(\mu - \sigma \leq X \leq \mu + \sigma) \approx 0{,}6827$$

$$P(\mu - 2\sigma \leq X \leq \mu + 2\sigma) \approx 0{,}9545$$

$$P(\mu - 3\sigma \leq X \leq \mu + 3\sigma) \approx 0{,}9973$$

</Teorema>

<Teorema titulo="闭包性质">

1. **线性组合**：$aX + b \sim \mathcal N(a\mu + b,\; a^2\sigma^2)$。
2. **独立和**：如果 $X \sim \mathcal N(\mu_1, \sigma_1^2)$ 和 $Y \sim \mathcal N(\mu_2, \sigma_2^2)$ 独立，则 $X + Y \sim \mathcal N(\mu_1+\mu_2,\; \sigma_1^2+\sigma_2^2)$。
3. **样本均值**：$\bar X = (1/n)\sum X_i$ 其中 $X_i$ 来自 $\mathcal N(\mu, \sigma^2)$ 的 iid 样本，满足 $\bar X \sim \mathcal N(\mu, \sigma^2/n)$。

</Teorema>

<Insight>

正态分布在所有具有固定均值 $\mu$ 和方差 $\sigma^2$ 的分布中最大化**微分熵**。这提供了一个贝叶斯理由：假设正态性意味着在给定均值和方差约束的情况下假设最少的额外信息——与已知条件兼容的"最不可知"的分布。

</Insight>

<Porta nivel="5" titulo="5 岁儿童">

想象测量你年龄的**一千个孩子**的身高。大多数接近平均身高。很少有人非常矮，很少有人非常高。

如果你做一个图表，就会出现一个**对称的山**——著名的**钟形曲线**。这个山就是正态分布。

越接近中心，孩子越多。在边缘，几乎没有人。

</Porta>

<Porta nivel="10" titulo="10 岁儿童">

正态分布是自然界中最常见的分布：

- 人的身高
- 实验室测量中的误差
- 设计良好的考试的分数
- 树上叶子的大小

两个数字完全描述曲线：

- $\mu$（**均值**）：峰值的位置。
- $\sigma$（**标准差**）：曲线有多宽。

**魔法 68-95-99.7 法则**：
- 68% 的数据位于 $\mu - \sigma$ 和 $\mu + \sigma$ 之间。
- 95% 位于 $\mu - 2\sigma$ 和 $\mu + 2\sigma$ 之间。
- 99.7% 位于 $\mu - 3\sigma$ 和 $\mu + 3\sigma$ 之间。

例子：巴西成年人身高：$\mu = 170$ cm，$\sigma = 8$ cm。则 95% 的人身高在 154 到 186 cm 之间。

</Porta>

<Porta nivel="15" titulo="15 岁青少年">

正态分布之所以重要有三个原因：

1. **自然出现**：当许多小的独立因素加起来时，结果趋向于正态（中心极限定理——下一课）。
2. **简单的代数**：独立正态分布的和和均值也是正态分布。
3. **支撑统计推断**：置信区间、假设检验、回归分析。

### 如何使用 Z 表

计算任何 $\mathcal N(\mu, \sigma^2)$ 中的 $P(X \leq c)$：

1. 标准化：$z = (c - \mu)/\sigma$。
2. 查询表 $\Phi(z)$（或使用 `DIST.NORMP.N(z; TRUE)`）。
3. 对于 $P(X \geq c)$：使用对称性 $\Phi(-z) = 1 - \Phi(z)$。

**例子**：均值为 70，标准差为 10 的考试。$P(X \geq 85)$？
$z = (85-70)/10 = 1{,}5$。$P(Z \geq 1{,}5) = 1 - \Phi(1{,}5) \approx 1 - 0{,}933 = 0{,}067$（6.7%）。

### 历史

卡尔·弗里德里希·高斯（1809）使用正态分布来模拟天文观察中的误差（"正常误差"）。亚伯拉罕·德·莫弗尔（1733）已经将曲线推导为二项分布的极限。因此"高斯分布"和"正态分布"是同义词。

### 正态分布不适用的情况

- 收入和房地产价格（长尾分布）。
- 稀有计数（泊松分布）。
- 等待时间（指数分布）。
- 金融收益（尾部比正态分布更重——"黑天鹅"）。

</Porta>

### 均值的置信区间

对于来自 $\mathcal N(\mu, \sigma^2)（\sigma$ 已知）的 iid $X_1, \ldots, X_n$：

$$\bar X \sim \mathcal N\!\left(\mu, \frac{\sigma^2}{n}\right) \implies \bar X \pm 1{,}96\,\frac{\sigma}{\sqrt n} \text{ 是 } \mu \text{ 的 95% 置信区间}$$

$\sigma$ 未知时：用 $s$ 替换并使用 **t 学生分布**（第 79+ 课）。

### 均值的 z 检验

$H_0: \mu = \mu_0$。检验统计量：

$$z = \frac{\bar X - \mu_0}{\sigma/\sqrt n}$$

在 $H_0$ 下拒绝（双侧，$\alpha = 5\%$）如果 $|z| > 1{,}96$。

### 公差工程（六西格玛）

产品直径 $\mathcal N(10{,}00;\; 0{,}02^2)$ mm。公差 $10{,}00 \pm 0{,}05$ mm。

$z = 0{,}05/0{,}02 = 2{,}5$。$P(|Z| > 2{,}5) = 2\Phi(-2{,}5) \approx 1{,}24\%$。

每 1000 件产品：约 12 件不合格。对于六西格玛（3.4 ppm）：$z \approx 4{,}5$。

### 正态混合（GMM）

$$f(x) = \sum_k \pi_k\,\mathcal N(x;\, \mu_k, \sigma_k^2)$$

模拟异质化种群（例：混合种群的身高、聚类分数）。通过 EM 算法调整。是机器学习中高斯混合模型的基础。

### Q-Q 图（正态性诊断）

绘制样本分位数与 $\mathcal N(0,1)$ 的理论分位数。直线 $y = x$ 表示正态性。曲线表示偏态（偏度）或重尾（峰度）。由 Shapiro-Wilk 检验（$n < 50$）或 Anderson-Darling 补充。

### Python 实现

```python
from scipy.stats import norm
norm.cdf(1.96)                       # 0.975
norm.ppf(0.975)                      # 1.96
norm.pdf(0)                          # 0.3989 (N(0,1) 的峰值)
norm.cdf(85, loc=70, scale=10)       # P(X <= 85) with mu=70, sigma=10
norm.rvs(loc=0, scale=1, size=1000)  # 样本
```

### 特征函数刻画

$\mathcal N(\mu, \sigma^2)$ 的特征函数为：

$$\varphi(t) = E[e^{itX}] = \exp\!\left(i\mu t - \frac{\sigma^2 t^2}{2}\right)$$

在有限方差分布中，唯一具有二次对数特征函数的分布。允许通过 Lévy 连续性定理证明 CLT：如果 $\varphi_{X_n}(t) \to e^{-t^2/2}$ 逐点收敛，则 $X_n$ 按分布收敛到 $Z \sim \mathcal N(0,1)$。

### 多元正态分布

$\mathbf X \sim \mathcal N(\boldsymbol\mu, \Sigma)$ 具有均值向量 $\boldsymbol\mu$ 和半正定协方差矩阵 $\Sigma$。密度：

$$f(\mathbf x) = \frac{1}{(2\pi)^{p/2}|\Sigma|^{1/2}} \exp\!\left(-\frac{1}{2}(\mathbf x - \boldsymbol\mu)^\top \Sigma^{-1} (\mathbf x - \boldsymbol\mu)\right)$$

边际分布和条件分布仍为正态。是 PCA、多元线性回归、卡尔曼滤波器、高斯过程和贝叶斯神经网络的基础。

### 细尾 vs. 重尾

正态分布的尾部衰减为 $e^{-x^2/2}$ ——超指数快速衰减。距离平均值 5σ 的事件应该每百万次观察中出现 < 10^{-6} 次。在金融中：LTCM（1998）和 2008 年危机涉及"10σ"事件。教训：**重尾**分布（t 学生、帕累托、Lévy 稳定）更好地模拟极端风险。

### 最大熵

在 $\mathbb{R}$ 上所有具有固定 $E[X] = \mu$ 和 $E[X^2] = \sigma^2 + \mu^2$ 的分布中，正态分布最大化微分熵 $h(X) = -\int f \log f\,dx$。这是统计贝叶斯建模中最大熵原理的理由。

### 布朗运动和 Black-Scholes

Wiener 过程 $W_t$ 有增量 $W_{t+\Delta} - W_t \sim \mathcal N(0, \Delta)$，独立。它是 CLT 的连续基础：iid 跳跃和的极限。Black-Scholes 公式（第 119 课）明确使用 $W_t$ 和标准正态 $\Phi$ 来定价期权。参见[经济学诺贝尔奖 1997](https://www.nobelprize.org/prizes/economic-sciences/1997/summary/)。

<Porta nivel="pratica" titulo="实际应用">

### 4 步配方

1. **确定总体的 $\mu$ 和 $\sigma$**。
2. **标准化**：$z = (x - \mu)/\sigma$。
3. **查询表** $\Phi(z)$ 或使用电子表格/Python。
4. **使用对称性**：$P(X \geq c) = 1 - P(X \leq c) = \Phi(-z)$。

### 在电子表格中（Excel / LibreOffice）

| 函数 | 结果 |
|---|---|
| `DIST.NORMP.N(z; TRUE)` | $\Phi(z)$ |
| `DIST.NORM.N(x; mu; sigma; TRUE)` | $P(X \leq x)$ |
| `INV.NORMP.N(prob)` | 分位数 $z$ |
| `INV.NORM.N(prob; mu; sigma)` | $\mathcal N(\mu,\sigma^2)$ 的分位数 |

### 何时不用正态分布

- 严格正向且长尾的数据：**对数正态**（工资、价格）。
- 稀有计数：**泊松分布**。
- 等待事件的时间：**指数**或 **Weibull**。
- 日收益：**t 学生**（尾部更重）。
- 比例：**二项**或 **beta**。

### 正态性快速验证

1. 直方图关于钟形对称？
2. 68% 的数据在 $[\bar x - s;\; \bar x + s]$ 内？
3. Q-Q 图是直线？
4. Shapiro-Wilk 检验（$n < 50$）$p$ 值 > 0.05？

## 解决的例题

<Exemplo numero="76.1" titulo="标准化和 Z 表" dificuldade="basico">

**问题。** $X \sim \mathcal N(70, 10^2)$。计算 $P(X \leq 85)$。

**策略。** 标准化并查询表 $\Phi$。

**解。**

$$z = \frac{85 - 70}{10} = 1{,}5$$

$$P(X \leq 85) = P(Z \leq 1{,}5) = \Phi(1{,}5) \approx 0{,}9332$$

**验证。** 85 在均值上方 $1{,}5\sigma$。根据 68-95-99.7 法则，约 84% 在 $\mu + \sigma = 80$ 下方，更多在 $\mu + 1{,}5\sigma = 85$ 下方。结果约 93% 是合理的。

**来源。** [OpenIntro Statistics §3.5](https://www.openintro.org/book/os/) — CC-BY-SA。

</Exemplo>

<Exemplo numero="76.2" titulo="应用 68-95-99.7 法则" dificuldade="basico">

**问题。** 智商遵循 $\mathcal N(100, 15^2)$。人口中智商在 85 到 115 之间的比例是多少？超过 130 的比例呢？

**策略。** 确定 σ 倍数位置并应用法则。

**解。**

- 85 = $\mu - \sigma$ 和 115 = $\mu + \sigma$（间隔 $\pm 1\sigma$）：$P(85 \leq X \leq 115) \approx 68\%$。
- 130 = $\mu + 2\sigma$：$P(X > 130) = (1 - 0{,}9545)/2 \approx 2{,}28\%$。

**验证。** 68% 在 $\pm 1\sigma$ 之间，2.28% 在 $+2\sigma$ 上方是标准正态表的制表结果。智商量表被刻意校准为 $\sigma = 15$ 并使这些百分位有意义。

**来源。** [OpenStax Statistics §6.1](https://openstax.org/books/statistics/pages/6-1-the-standard-normal-distribution) — CC-BY。

</Exemplo>

<Exemplo numero="76.3" titulo="工程公差" dificuldade="intermediario">

**问题。** 产品直径 $\mathcal N(10{,}00;\; 0{,}02^2)$ mm。规范 $10{,}00 \pm 0{,}05$ mm。不合格的比例是多少？

**策略。** 通过标准化计算 $P(|X - 10| > 0{,}05)$。

**解。**

$$z = \frac{0{,}05}{0{,}02} = 2{,}5$$

$$P(|X - 10| > 0{,}05) = P(|Z| > 2{,}5) = 2\Phi(-2{,}5) = 2 \times 0{,}0062 = 0{,}0124$$

约 $1{,}24\%$ 的产品被拒绝——每 1000 件约 **12 件**。

**验证。** $z = 2{,}5$ 在 $2\sigma$（2.28% 外）和 $3\sigma$（0.27% 外）之间。结果 1.24% 与此区间一致。对于六西格玛（3.4 ppm），需要 $z \approx 4{,}5$。

**来源。** [OpenStax Statistics §6.3](https://openstax.org/books/statistics/pages/6-3-estimating-the-binomial-with-the-normal-distribution) — CC-BY。

</Exemplo>

<Exemplo numero="76.4" titulo="均值的置信区间" dificuldade="intermediario">

**问题。** 25 件产品样本，$\bar X = 105$ mm，$\sigma = 10$ mm（已知）。构造 $\mu$ 的 95% 置信区间。

**策略。** 使用 $\bar X \sim \mathcal N(\mu, \sigma^2/n)$ 和 $z_{0{,}975} = 1{,}96$。

**解。**

$$SE = \frac{\sigma}{\sqrt n} = \frac{10}{\sqrt{25}} = 2$$

$$IC_{95\%} = \left[\bar X - 1{,}96 \cdot SE;\; \bar X + 1{,}96 \cdot SE\right] = [105 - 3{,}92;\; 105 + 3{,}92] = [101{,}08;\; 108{,}92]$$

**验证。** 置信区间的总宽度为 $2 \times 3{,}92 = 7{,}84$ mm。因为 $\sigma = 10$ 和 $n = 25$，标准误为 2——种群标准差的一半，由 $\sqrt{25}$ 减小。该间隔在 95% 的样本中覆盖真实均值。

**来源。** [OpenIntro Statistics §4.2](https://www.openintro.org/book/os/) — CC-BY-SA。

</Exemplo>

<Exemplo numero="76.5" titulo="推导：高斯积分" dificuldade="avancado">

**问题。** 证明 $\int_{-\infty}^{+\infty} e^{-x^2/2}\,dx = \sqrt{2\pi}$ 使用极坐标技巧。

**策略。** 计算 $I^2$，其中 $I = \int e^{-x^2/2}\,dx$，并转换为极坐标。

**解。** 设 $I = \int_{-\infty}^{+\infty} e^{-x^2/2}\,dx$。

$$I^2 = \left(\int_{-\infty}^{+\infty} e^{-x^2/2}\,dx\right)\!\left(\int_{-\infty}^{+\infty} e^{-y^2/2}\,dy\right) = \int_{-\infty}^{+\infty}\!\int_{-\infty}^{+\infty} e^{-(x^2+y^2)/2}\,dx\,dy$$

极坐标：$x = r\cos\theta$，$y = r\sin\theta$，雅可比行列式 $r$：

$$I^2 = \int_0^{2\pi}\!\int_0^{+\infty} e^{-r^2/2}\,r\,dr\,d\theta = 2\pi \int_0^{+\infty} r\,e^{-r^2/2}\,dr$$

替换 $u = r^2/2$：$\int_0^\infty r e^{-r^2/2}\,dr = [-e^{-r^2/2}]_0^\infty = 1$。

因此 $I^2 = 2\pi$，所以 $I = \sqrt{2\pi}$。

**验证。** 密度 $f(x) = e^{-x^2/2}/\sqrt{2\pi}$ 在 $\mathbb R$ 上积分为 1——与 $Z$ 的正态性一致。

**来源。** [Introduction to Probability — Grinstead, Snell §5.2](https://chance.dartmouth.edu/teaching_aids/books_articles/probability_book/book.html) — GNU FDL。

</Exemplo>
