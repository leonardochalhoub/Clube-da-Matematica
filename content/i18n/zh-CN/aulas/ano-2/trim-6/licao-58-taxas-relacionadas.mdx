<Porta nivel="formal" titulo="一般方法和标准模型">

### 相关变化率的一般策略

1. **识别**动态变量（取决于$t$）和问题的常数。
2. **写出**几何或物理方程，将变量联系起来——对所有$t$有效。
3. **对$t$求导两边**，对每个动态变量使用链式法则。
4. **代入**感兴趣时刻的数值（从不在求导前代入）。
5. **分离**所需变化率并验证单位和符号。

<Definicao titulo="相关变化率">

给定两个量$u(t)$和$v(t)$通过方程$F(u, v) = 0$对所有$t$相关，在$t$处对链式法则求导得到：

$$\frac{\partial F}{\partial u}\,\dot u + \frac{\partial F}{\partial v}\,\dot v = 0$$

已知其中一个变化率（$\dot u$或$\dot v$）和感兴趣时刻的变量值，可分离出未知变化率。

</Definicao>

> "当两个量通过一个方程相关时，该量的变化率也相关。我们可以用该方程两边都对时间求导并对时间应用链式法则来找到这个变化率。" — [OpenStax Calculus Vol. 1, §4.1](https://openstax.org/books/calculus-volume-1/pages/4-1-related-rates)

### 标准模型

| 场景 | 基本方程 | 动态变量 |
|---|---|---|
| 球形气球 | $V = \frac{4}{3}\pi r^3$ | $V(t),\; r(t)$ |
| 梯子下滑 | $x^2 + y^2 = L^2$ | $x(t),\; y(t)$ |
| 圆锥形水箱 | $V = \frac{1}{3}\pi r^2 h$ | $V(t),\; r(t),\; h(t)$ |
| 两辆汽车分离 | $D^2 = x^2 + y^2$ | $x(t),\; y(t),\; D(t)$ |
| 影子（相似性） | 按比例相关 | 距离、影子 |
| 仰角 | $\tan\theta = h/x$ | $\theta(t),\; x(t)$ |

### 链式法则——一般形式

若$F(x_1(t), \ldots, x_n(t)) = C$（常数），则：

$$\frac{d}{dt}F = \sum_{i=1}^n \frac{\partial F}{\partial x_i}\,\dot x_i = 0$$

对$t$的隐微分。结果是变化率$\dot x_i$中的线性方程，从中分离出所需的。

</Porta>

<Porta nivel="5" titulo="对5岁孩子">

想象你用空气填充一个**气球**。气球变胖——**半径增长**。同时，**体积增加**。

你吹得越快（体积进入越快），半径增长越快。两件事一起发生：一个改变，另一个也改变。

数学帮助你发现："如果我知道一个的速度，另一个的速度是多少？"

相关变化率正是这个：两个量在时间中一起移动。

</Porta>

<Porta nivel="10" titulo="对10岁学生">

**标准问题**：球形气球以100立方厘米每秒的速度充气。当$r = 10$厘米时，半径增长有多快？

**逐步：**

1. 球体积：$V = \frac{4}{3}\pi r^3$。
2. 对$t$的所有内容求导：$\frac{dV}{dt} = 4\pi r^2 \cdot \frac{dr}{dt}$。
3. 代入已知数据：$100 = 4\pi (10)^2 \cdot \frac{dr}{dt} = 400\pi\,\frac{dr}{dt}$。
4. 分离：$\frac{dr}{dt} = \frac{100}{400\pi} = \frac{1}{4\pi} \approx 0{,}08$ cm/s。

**梯子问题**：5米梯子靠在墙上。脚向外滑动，速度为0.5米每秒。当脚离墙3米时，顶部下降有多快？

1. 勾股定理：$x^2 + y^2 = 25$。
2. 对$t$求导：$2x\,\dot x + 2y\,\dot y = 0$。
3. 在$x = 3$时：$y = \sqrt{25 - 9} = 4$。用$\dot x = 0{,}5$：

$$6(0{,}5) + 8\,\dot y = 0 \implies \dot y = -\tfrac{3}{8} = -0{,}375 \text{ m/s.}$$

负号表示顶部**下降**。

</Porta>
