### 求导工具的层级结构

<Definicao titulo="导数——通过极限的定义">

设 $f$ 在包含 $a$ 的开区间内有定义。<strong>$f$ 在 $a$ 处的导数</strong>定义为

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

当此极限存在且有限时。如果存在，我们称 $f$ 在 $a$ 处**可导**。

- 几何意义：$f$ 在点 $(a, f(a))$ 处图像切线的斜率。
- 物理意义：$f$ 在时刻 $a$ 处的瞬时变化率。

</Definicao>

> "函数 $f$ 在值 $a$ 处的导数，记为 $f'(a)$，由公式 $f'(a) = \lim_{h\to 0}\frac{f(a+h)-f(a)}{h}$ 定义，前提是此极限存在。" — [Active Calculus, §1.3](https://activecalculus.org/single/sec-1-3-derivative-pt.html)

### 基本导数表

| $f(x)$ | $f'(x)$ | 规则 |
|---|---|---|
| $x^n$ | $n x^{n-1}$ | 幂函数法则 |
| $e^x$ | $e^x$ | 自然指数 |
| $a^x$ | $a^x \ln a$ | 一般指数 |
| $\ln x$ | $1/x$ | 对数 |
| $\sin x$ | $\cos x$ | 正弦 |
| $\cos x$ | $-\sin x$ | 余弦 |
| $\tan x$ | $\sec^2 x$ | 正切 |
| $\arcsin x$ | $1/\sqrt{1-x^2}$ | 反正弦 |
| $\arctan x$ | $1/(1+x^2)$ | 反正切 |

### 运算法则

<Definicao titulo="乘积、商和链式法则">

设 $f, g$ 可导。则：

- **乘积（莱布尼兹）：** $(fg)' = f'g + fg'$
- **商：** $\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}$（其中 $g \neq 0$）
- **链式：** $(f \circ g)'(x) = f'(g(x)) \cdot g'(x)$

</Definicao>

> "乘积法则指出：若 $f$ 和 $g$ 可导，则 $\frac{d}{dx}[f(x)g(x)] = f'(x)g(x) + f(x)g'(x)$。" — [OpenStax Calculus Vol. 1, §3.3](https://openstax.org/books/calculus-volume-1/pages/3-3-differentiation-rules)

### 隐函数求导和高阶导数

<Definicao titulo="隐函数求导">

给定 $F(x, y) = 0$，其中 $y = y(x)$ 隐式定义，对两边关于 $x$ 求导，将 $y$ 视为 $x$ 的函数（每个含 $y$ 的项使用链式法则），然后代数求解 $y'$。

对于高阶导数：$f''(x) = (f')'(x)$，$f^{(n)} = (f^{(n-1)})'$。

</Definicao>

### 线性化和相关变化率

<Definicao titulo="局部线性化">

**线性化** $f$ 在 $a$ 处为 $L(x) = f(a) + f'(a)(x - a)$。几何上就是切线。当 $|x - a| \ll 1$ 时作为近似有效。

</Definicao>

<Definicao titulo="相关变化率">

当两个量 $u, v$ 都依赖于时间 $t$ 且通过方程 $F(u, v) = 0$ 相关联时，对该方程关于 $t$ 求导得到链式法则形式：

$$\frac{dF}{dt} = F_u \frac{du}{dt} + F_v \frac{dv}{dt} = 0$$

已知其中一个 $du/dt$ 或 $dv/dt$，即可确定另一个。

</Definicao>

### 可导性的基本定理

<Teorema titulo="可导蕴含连续">

若 $f$ 在 $a$ 处可导，则 $f$ 在 $a$ 处连续。

**证明。** $\lim_{x \to a} [f(x) - f(a)] = \lim_{x \to a} \frac{f(x)-f(a)}{x-a} \cdot (x-a) = f'(a) \cdot 0 = 0.$ 因此 $\lim_{x \to a} f(x) = f(a)$。

逆命题为假：$f(x) = |x|$ 在 $0$ 处连续但不可导。 ∎

</Teorema>

> "若 $f$ 在 $a$ 处可导，则 $f$ 在 $a$ 处连续。" — [Active Calculus, §1.7](https://activecalculus.org/single/sec-1-7-lim-cont-diff.html)

### 模式识别

| 题目中的信号 | 技术 |
|---|---|
| "直接计算 $f'(a)$" | 规则 + 表格 |
| "$y = f($复合$)$" | 链式法则 |
| "$F(x, y) = 0$，求 $y'$" | 隐函数求导 |
| "$f''$，凹凸性，拐点" | 高阶导数 |
| "$\arcsin$，$\arctan$，$\ln$，$e^x$，$a^x$ 的导数" | 反函数表 |
| "在 $a$ 附近近似 $f(x)$" | 线性化 |
| "$X$ 随时间变化有多快？" | 相关变化率 |
| "$f$ 在 $a$ 处可导吗？" | 检查连续性 + 双侧极限 |

<Insight>

链式法则是几乎一切的引擎：隐函数求导、反函数、相关变化率、复合线性化——所有这些都是在不同场景下应用链式法则。掌握了链式法则就掌握了整个学期。

</Insight>

## 已解决的示例

<Exemplo titulo="通过极限的定义——直接计算">

**问题。** 对于 $f(x) = x^2 - 3x + 1$，使用导数定义计算 $f'(2)$。

**策略。** 直接应用 $f'(2) = \lim_{h \to 0} \dfrac{f(2+h) - f(2)}{h}$，展开分子并约去 $h$。

**解法。**

$$f(2+h) = (2+h)^2 - 3(2+h) + 1 = 4 + 4h + h^2 - 6 - 3h + 1 = -1 + h + h^2$$

$$f(2) = 4 - 6 + 1 = -1$$

$$\frac{f(2+h) - f(2)}{h} = \frac{(-1 + h + h^2) - (-1)}{h} = \frac{h + h^2}{h} = 1 + h$$

$$f'(2) = \lim_{h \to 0}(1 + h) = 1$$

**验证。** 用规则：$f'(x) = 2x - 3$，所以 $f'(2) = 4 - 3 = 1$。一致。

**来源。** [Active Calculus — Boelkins, §1.3, Preview Activity 1.3.1](https://activecalculus.org/single/sec-1-3-derivative-pt.html) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="链式法则与双重复合">

**问题。** 计算 $f'(x)$，其中 $f(x) = \sin^3(2x + 1)$。

**策略。** 识别复合结构：$f = u^3$，其中 $u = \sin(v)$ 且 $v = 2x+1$。应用链式法则两次。

**解法。**

$$f(x) = [\sin(2x+1)]^3$$

设 $u = \sin(2x+1)$，则 $f = u^3$ 且 $f' = 3u^2 \cdot u'$。

通过链式法则计算 $u'$：$u' = \cos(2x+1) \cdot (2x+1)' = 2\cos(2x+1)$。

因此：

$$f'(x) = 3\sin^2(2x+1) \cdot 2\cos(2x+1) = 6\sin^2(2x+1)\cos(2x+1)$$

**验证。** 在 $x = 0$：$f'(0) = 6\sin^2(1)\cos(1) \approx 6(0{,}708)(0{,}540) \approx 2{,}296$。数值确认：$\dfrac{f(0{,}001) - f(0)}{0{,}001} \approx 2{,}296$。一致。

**来源。** [Active Calculus — Boelkins, §2.5, Example 2.5.3](https://activecalculus.org/single/sec-2-5-chain.html) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="隐函数求导——曲线的切线">

**问题。** 求曲线 $x^3 + y^3 = 9$ 在点 $(1, 2)$ 处切线的方程。

**策略。** 对两边关于 $x$ 求导，将 $y$ 视为 $x$ 的函数，求解 $y'$，在 $(1, 2)$ 处求值，并写出切线方程。

**解法。**

对 $x^3 + y^3 = 9$ 求导：

$$3x^2 + 3y^2 \cdot y' = 0 \implies y' = -\frac{x^2}{y^2}$$

在 $(1, 2)$：

$$y'\big|_{(1,2)} = -\frac{1}{4}$$

切线方程（点斜式）：

$$y - 2 = -\frac{1}{4}(x - 1) \implies y = -\frac{x}{4} + \frac{9}{4}$$

**验证。** 点 $(1, 2)$ 在曲线上：$1 + 8 = 9$。直线过点 $(1, 2)$：$-\tfrac{1}{4} + \tfrac{9}{4} = 2$。正确。

**来源。** [OpenStax Calculus Vol. 1 — §3.8, Example 3.71](https://openstax.org/books/calculus-volume-1/pages/3-8-implicit-differentiation) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="线性化——立方根的近似">

**问题。** 使用 $f(x) = \sqrt[3]{x}$ 在 $a = 8$ 处的线性化来近似 $\sqrt[3]{8{,}1}$。

**策略。** 计算 $L(x) = f(a) + f'(a)(x - a)$ 并在 $x = 8{,}1$ 处求值。

**解法。**

$f(x) = x^{1/3}$，因此 $f'(x) = \dfrac{1}{3}x^{-2/3}$。

在 $a = 8$：

$$f(8) = 2, \qquad f'(8) = \frac{1}{3} \cdot 8^{-2/3} = \frac{1}{3} \cdot \frac{1}{4} = \frac{1}{12}$$

$$L(x) = 2 + \frac{1}{12}(x - 8) \implies \sqrt[3]{8{,}1} \approx L(8{,}1) = 2 + \frac{0{,}1}{12} \approx 2{,}00833$$

**验证。** 精确值：$8{,}1^{1/3} \approx 2{,}00832$。相对误差 $< 0{,}001\%$。

**来源。** [OpenStax Calculus Vol. 1 — §4.2, Example 4.11](https://openstax.org/books/calculus-volume-1/pages/4-2-linear-approximations-and-differentials) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="相关变化率——球形气球">

**问题。** 一个球形气球的半径以每秒 $3$ 厘米的速率增加。当半径为 $10$ 厘米时，体积的变化率是多少？

**策略。** 写出 $V = \tfrac{4}{3}\pi r^3$，关于 $t$ 求导（使用链式法则），代入 $r = 10$ 和 $\dfrac{dr}{dt} = 3$。

**解法。**

$$V = \frac{4}{3}\pi r^3 \implies \frac{dV}{dt} = 4\pi r^2 \cdot \frac{dr}{dt}$$

代入 $r = 10$ 和 $\dfrac{dr}{dt} = 3$：

$$\frac{dV}{dt} = 4\pi (10)^2 \cdot 3 = 1200\pi \approx 3\,769{,}9 \text{ cm}^3/\text{s}$$

**验证。** 单位：$\text{cm}^2 \cdot \text{cm/s} = \text{cm}^3/\text{s}$。正确。体积增长很快，因为表面积 $4\pi r^2 = 400\pi$ 很大。

**来源。** [Active Calculus — Boelkins, §3.5, Example 3.5.1](https://activecalculus.org/single/sec-3-5-related-rates.html) — CC-BY-NC-SA。

<Exercicio
  numero="60.49"
  dificuldade="compreensao"
  opcoes={[
    { texto: "在 $x = 0$ 处连续但不可导：差分商的单侧极限不同（$-1 \\neq +1$）", correta: true },
    { texto: "在 $x = 0$ 处可导，$f'(0) = 0$" },
    { texto: "在 $x = 0$ 处可导，$f'(0) = 1$" },
    { texto: "在 $x = 0$ 处不连续" },
  ]}
  solucao={<><Eq>{`f(x) = |x|`}</Eq> 在0处连续（单侧极限与 <Eq>{`f(0)=0`}</Eq> 一致）。但差分商的单侧极限为：左侧 <Eq>{`\\to -1`}</Eq>，右侧 <Eq>{`\\to +1`}</Eq>。由于 <Eq>{`-1 \\neq +1`}</Eq>，双侧极限不存在：<Eq>{`f`}</Eq> 在0处不可导。</>}
  passos={<><ol>
    <li>左极限：<Eq>{`\\lim_{h\\to0^-}\\frac{|h|}{h} = \\frac{-h}{h} = -1`}</Eq>。</li>
    <li>右极限：<Eq>{`\\lim_{h\\to0^+}\\frac{|h|}{h} = \\frac{h}{h} = +1`}</Eq>。</li>
    <li>由于 <Eq>{`-1 \\neq +1`}</Eq>，双侧极限不存在。</li>
    <li>因此 <Eq>{`f'(0)`}</Eq> 不存在——<Eq>{`f`}</Eq> 在0处连续但不可导。</li>
    <li><em>注意：</em><Eq>{`|x|`}</Eq> 的图像在 <Eq>{`x=0`}</Eq> 处有一个"拐角"——非可导性的视觉标志。</li>
  </ol></>}
  fonte={{ livro: "Active Calculus", url: "https://activecalculus.org/single/sec-1-7-lim-cont-diff.html", secao: "§1.7", pagina: "65", exercicio: "1.7.7", licenca: "CC-BY-NC-SA" }}

</Exercicio>
