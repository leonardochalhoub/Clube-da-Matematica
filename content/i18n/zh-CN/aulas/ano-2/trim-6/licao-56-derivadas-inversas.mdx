### 反函数导数定理

<Definicao titulo="反函数的导数">

设$f: I \to J$在$I$上连续、严格单调、在$a \in I$处可导，且$f'(a) \neq 0$。设$b = f(a)$。则$f^{-1}$在$b$处可导，且：

$$\boxed{(f^{-1})'(b) = \frac{1}{f'(a)} = \frac{1}{f'(f^{-1}(b))}}$$

</Definicao>

> "若$f$是一一的可导函数，$f(a) = b$且$f'(a) \neq 0$，则$f^{-1}$在$b$处可导，且$(f^{-1})'(b) = 1/f'(a)$。" — [Active Calculus §2.6, Theorem 2.6.2](https://activecalculus.org/single/sec-2-6-inverse.html)

### 通过链式法则的证明

从恒等式$f(f^{-1}(y)) = y$出发，对$y$求导，使用链式法则：

$$f'(f^{-1}(y)) \cdot (f^{-1})'(y) = 1$$

由于$f'(f^{-1}(y)) \neq 0$（由假设），两边除以该式：

$$\boxed{(f^{-1})'(y) = \frac{1}{f'(f^{-1}(y))}}$$

### 几何解释

$f^{-1}$的图像是$f$的图像关于直线$y = x$的镜像。斜率为$m$的切线在$f$上点$(a, b)$处，经镜像反射后在$f^{-1}$上点$(b, a)$处变为斜率$1/m$——反射交换了$\Delta x$和$\Delta y$的角色。

<Insight>

**当$f'(a) = 0$时的病态情况**。若$f$在$a$处的切线水平（斜率0），则$f^{-1}$在$b = f(a)$处的切线将是竖直的——斜率无穷大。公式因除以零而失败。典型例子：$f(x) = x^3$，$f'(0) = 0$，而$f^{-1}(y) = y^{1/3}$在原点处有竖直切线。反函数存在，但在$y = 0$处不可导。

</Insight>

<Teorema titulo="a的x次方的导数">

对于$a > 0$，$a \neq 1$，经由$a^x = e^{x \ln a}$和链式法则：

$$\frac{d}{dx} a^x = a^x \ln a$$

特别地，$(e^x)' = e^x$（情形$a = e$，$\ln e = 1$）。

</Teorema>

> "一般地，对任何$a > 0$且$a \neq 1$，存在$a^x$导数的公式：$\frac{d}{dx}(a^x) = a^x \ln a$。此公式是链式法则应用于$a^x = e^{x \ln a}$的特例。" — [OpenStax Calculus Volume 1 §3.7](https://openstax.org/books/calculus-volume-1/pages/3-7-derivatives-of-inverse-functions)

### 反三角函数的链式法则

对于$u = g(x)$可导：
$$\frac{d}{dx}\arcsin(g(x)) = \frac{g'(x)}{\sqrt{1 - g(x)^2}}, \qquad \frac{d}{dx}\arctan(g(x)) = \frac{g'(x)}{1 + g(x)^2}$$

</Porta>

<Porta nivel="5" titulo="对一个5岁小孩">

想象一台**拿一个数字并对其做某事**的机器。例如，机器加倍：输入3，输出6。

**反向**机器撤销原机器所做的事。输入6，输出3。

现在考虑**每台机器的速度**。若原机器走得很**快**（数字改变很多），反向机器走得很**慢**——因为她在撤销原机器做的快速工作。

若原机器快5倍，反向机器就慢5倍。

**速度的倒数 = 反向的速度。** 就像爬山与下山：爬一座山用时10分钟，下来时每米高度的速度就慢10倍。

</Porta>

<Porta nivel="10" titulo="对一个10岁小孩">

函数和它们的反函数互相撤销：$f(f^{-1}(y)) = y$。

例子：$f(x) = x^2$和$f^{-1}(y) = \sqrt{y}$。输入9，$f^{-1}(9) = 3$，然后$f(3) = 9$。回到原点。

**反函数导数的法则**：反函数的导数是原函数导数的倒数——在对应点处测量。

对于$f(x) = x^2$：导数是$f'(x) = 2x$。在$x = 3$处：$f'(3) = 6$。反函数$\sqrt{y}$在$y = 9$处的导数是$1/6$。验证：$(\sqrt{y})' = 1/(2\sqrt{y})$；在$y = 9$处：$1/(2 \cdot 3) = 1/6$。相符。

**著名反函数及其导数**：

- $\arcsin x$：撤销正弦。导数：$1/\sqrt{1-x^2}$。
- $\arctan x$：撤销正切。导数：$1/(1+x^2)$。
- $\ln x$：撤销$e^x$。导数：$1/x$。

$f^{-1}$的图像是$f$的图像关于对角线$y = x$的反射。斜率为$m$的切线在反射后变为斜率$1/m$。

</Porta>

<Porta nivel="15" titulo="对一个15岁少年">

此课生成你之前不知道如何求导的所有导数：$\arcsin$、$\arccos$、$\arctan$、$\ln$、$\log_a$。**不要死记——考试时推导。**

### 求$f^{-1}$导数的通用方法

1. 写出$y = f^{-1}(x)$。则$f(y) = x$。
2. 对$x$求导两边（在$y$处使用链式法则）：$f'(y) \cdot y' = 1$。
3. 隔离：$y' = \dfrac{1}{f'(y)}$。
4. 使用$f(y) = x$和恒等式用$x$重写$f'(y)$。

### 完整例子：$(\arcsin x)'$

设$y = \arcsin x$。则$\sin y = x$，其中$y \in [-\pi/2,\, \pi/2]$。

求导：$\cos y \cdot y' = 1$，所以$y' = \dfrac{1}{\cos y}$。

在区间$[-\pi/2, \pi/2]$内，余弦为正，故$\cos y = \sqrt{1 - \sin^2 y} = \sqrt{1 - x^2}$。

$$(\arcsin x)' = \frac{1}{\sqrt{1 - x^2}}$$

### 完整例子：$(\arctan x)'$

设$y = \arctan x$。则$\tan y = x$。

求导：$\sec^2 y \cdot y' = 1$，所以$y' = \dfrac{1}{\sec^2 y} = \dfrac{1}{1 + \tan^2 y} = \dfrac{1}{1 + x^2}$。

$$(\arctan x)' = \frac{1}{1 + x^2}$$

### 完整例子：$(\ln x)'$

设$y = \ln x$。则$e^y = x$。

求导：$e^y \cdot y' = 1$，所以$y' = \dfrac{1}{e^y} = \dfrac{1}{x}$。

$$(\ln x)' = \frac{1}{x}$$

### 求导为零的恒等式

- $\arcsin x + \arccos x = \pi/2$：导数中各项相消。
- $\arctan x + \arctan(1/x) = \pi/2$，对于$x > 0$。

</Porta>

<Porta nivel="25" titulo="对一个工程学生">

反函数的导数是对数、反三角函数、反双曲函数和概率中变量变换的**构建块**。

### 反函数定理（形式版本）

若$f \in C^1$在$x_0$附近且$f'(x_0) \neq 0$，则$f$局部可逆，$f^{-1} \in C^1$在$y_0 = f(x_0)$附近，且：

$$(f^{-1})'(y_0) = \frac{1}{f'(x_0)}$$

多变量情形：对于$f: U \subset \mathbb{R}^n \to \mathbb{R}^n$，其Jacobian矩阵$J_f(x_0)$可逆，$D(f^{-1})(y_0) = J_f(x_0)^{-1}$。

### 通过对数的反双曲函数导数

由于$\text{arcsinh}\, x = \ln(x + \sqrt{x^2+1})$，求导得：

$$(\text{arcsinh}\, x)' = \frac{1 + x/\sqrt{x^2+1}}{x + \sqrt{x^2+1}} = \frac{1}{\sqrt{x^2+1}}$$

类似地：$(\text{arccosh}\, x)' = 1/\sqrt{x^2-1}$，对$x > 1$；$(\text{arctanh}\, x)' = 1/(1-x^2)$，对$|x| < 1$。

### 积分中的变量替换

若$Y = f(X)$且$f$可逆可导，变量替换公式为：

$$\int_A g(y)\,dy = \int_{f^{-1}(A)} g(f(x))\,|f'(x)|\,dx$$

Jacobian矩阵$|f'(x)|$出现是因为$(f^{-1})'(y) = 1/f'(x)$——它是同一个对象。

### 概率中的密度变换

若$X$有密度$f_X(x)$且$Y = g(X)$，其中$g$单调：

$$f_Y(y) = f_X(g^{-1}(y)) \cdot \left|(g^{-1})'(y)\right| = f_X(g^{-1}(y)) \cdot \frac{1}{|g'(g^{-1}(y))|}$$

出现在**样本生成**中（逆变换方法）：生成$U \sim \text{Unif}[0,1]$，取$X = F^{-1}(U)$。

### 工程应用

- **Snell定律**：临界角$\theta_c = \arcsin(n_2/n_1)$。灵敏度$d\theta_c/dn_1$通过$\arcsin$的导数。
- **GPS**：仰角$\theta = \arctan(h/d)$。对高度$h$变化的灵敏度。
- **控制**：非线性系统反演在操作点附近线性化使用$(f^{-1})'$。

### 病态情况：$f'(x_0) = 0$

若$f'(x_0) = 0$，规则失败：反函数在$y_0 = f(x_0)$处有竖直切线，因此$(f^{-1})'(y_0)$不存在。例：$f(x) = x^3$，$f'(0) = 0$，$f^{-1}(y) = y^{1/3}$，$(f^{-1})'(0)$为无穷大。

</Porta>

<Porta nivel="40" titulo="对一个资深专业人士">

反函数的导数是**反函数定理**(IFT)的特例，微分几何中的中心定理之一。各个几何层次都存在版本。

### 流形上的IFT

对于$f: M \to N$是流形间的$C^1$微分同胚，微分$df_p: T_pM \to T_{f(p)}N$是同构，且：

$$d(f^{-1})_{f(p)} = (df_p)^{-1}$$

标量方程$(f^{-1})'(b) = 1/f'(a)$是情形$M = N = \mathbb{R}$。

### 生成式机器学习中的规范化流

如Real-NVP和Glow等模型组合具有可处理Jacobian的可逆变换。对数似然为：

$$\log p_Y(y) = \log p_X(x) - \log |\det J_f(x)|, \quad x = f^{-1}(y)$$

高效计算$\det J_f$（三角形架构）是流设计的核心。反函数法则保证$f^{-1}$的Jacobian是$J_f^{-1}$，可计算。

### Black-Scholes中的隐含波动率

在期权定价中，隐含波动率$\sigma_{\text{imp}}(K, T)$由$\text{BS}(\sigma) = V_{\text{market}}$隐式定义，其中BS是Black-Scholes公式。灵敏度为：

$$\frac{d\sigma_{\text{imp}}}{dV} = \frac{1}{\text{BS}'(\sigma)} = \frac{1}{\text{Vega}}$$

完全是反函数导数公式——正是为什么Vega在Black-Scholes模型中永远不能为零，否则会造成反演问题。

### Lambert W函数

$W(x)$满足$W(x) e^{W(x)} = x$。隐式求导：

$$W'(x) = \frac{W(x)}{x(1 + W(x))}$$

出现在增长模型、非线性热方程和图论中。

### 分析连接：反函数的可导性

IFT严格强于基本定义：保证$f^{-1}$从$f$继承$C^k$（$f \in C^k \Rightarrow f^{-1} \in C^k$）。病态情况（$f'$摆动至零）在非光滑边界条件的微分方程中相关。

</Porta>

<Porta nivel="pratica" titulo="实际应用">

**何时使用？** 只要需要求$\arcsin$、$\arccos$、$\arctan$、$\ln$、$\log_a$、$a^x$或任何反双曲函数的导数。

### 求导工作流

1. 识别：$y = f^{-1}(x)$，因此$f(y) = x$。
2. 对$x$求导两边（链式）：$f'(y) \cdot y' = 1$。
3. 隔离$y'$：$y' = 1/f'(y)$。
4. 通过三角恒等式或代数恒等式用$x$重写。

### 用SymPy验证

```python
import sympy as sp
x = sp.symbols('x', real=True)
print(sp.diff(sp.asin(x), x))    # 1/sqrt(1 - x**2)
print(sp.diff(sp.acos(x), x))    # -1/sqrt(1 - x**2)
print(sp.diff(sp.atan(x), x))    # 1/(x**2 + 1)
print(sp.diff(sp.log(x), x))     # 1/x
print(sp.diff(sp.log(x, 2), x))  # 1/(x*log(2))
print(sp.diff(sp.asinh(x), x))   # 1/sqrt(x**2 + 1)
```

### 常见错误

- $\arcsin x \neq 1/\sin x$——完全不同的函数。
- $\arcsin$的定义域：仅$|x| \leq 1$。超出此范围，不存在。
- $\text{arccosh}$的定义域：仅$x \geq 1$。
- 当$f'(a) = 0$时应用公式——此时反函数有竖直切线。

### 快速查询表

| 需要求导 | 使用 |
|---|---|
| $\arctan(ax + b)$ | $a/(1+(ax+b)^2)$ |
| $\arcsin(\sqrt{x})$ | $1/(2\sqrt{x}\sqrt{1-x})$ |
| $\ln(f(x))$ | $f'(x)/f(x)$（对数求导） |
| $a^{g(x)}$ | $a^{g(x)} \ln a \cdot g'(x)$ |

### 巴西背景

在金融市场数据分析中，$\arctan$函数出现在限定极端收益的建模中。在GPS（包括部署在民航中的巴西GBAS系统）中，角灵敏度$d\theta/dh = d/dh[\arctan(h/d)] = d/(d^2+h^2)$决定了从高度误差传播到位置误差。

## 已解答的示例

<Exemplo titulo="通过隐式求导的反正切导数（基础）" numero="1">

**问题**：从通过隐式求导的定义出发，求$(\arctan x)'$。

**策略**：使用标准方法：写出反函数关系$\tan y = x$，隐式求导，然后用$x$重写结果。

**求解**：

1. 设$y = \arctan x$。由反函数定义，$\tan y = x$，其中$y \in (-\pi/2,\, \pi/2)$。

2. 对$x$求导两边：
$$\sec^2 y \cdot \frac{dy}{dx} = 1$$

3. 隔离$dy/dx$：
$$\frac{dy}{dx} = \frac{1}{\sec^2 y}$$

4. 重写$\sec^2 y$：由恒等式$\sec^2 y = 1 + \tan^2 y$且$\tan y = x$：
$$\sec^2 y = 1 + x^2$$

5. 因此：
$$\frac{dy}{dx} = \frac{1}{1 + x^2}$$

**验证**：在$x = 0$：$(f^{-1})'(0) = 1/(1+0) = 1$。由于$f(x) = \tan x$有$f'(0) = \sec^2 0 = 1$，$1/f'(0) = 1$。相符。

**来源**。[Active Calculus §2.6](https://activecalculus.org/single/sec-2-6-inverse.html) — Boelkins · CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="通过exp反函数的ln导数（基础）" numero="2">

**问题**：从$e^y = x$出发，求$(\ln x)'$。

**策略**：$\ln$是$e^x$的反函数。使用隐式求导，利用$e^y = x$。

**求解**：

1. 设$y = \ln x$。则$e^y = x$（对数的定义）。

2. 对$x$求导两边：
$$e^y \cdot \frac{dy}{dx} = 1$$

3. 隔离$dy/dx$：
$$\frac{dy}{dx} = \frac{1}{e^y}$$

4. 代入$e^y = x$：
$$\frac{dy}{dx} = \frac{1}{x}$$

**结果**：$(\ln x)' = 1/x$，对$x > 0$。

**$\log_a x$的导数**：由$\log_a x = \ln x / \ln a$：
$$(\log_a x)' = \frac{1}{x \ln a}$$

**验证**：在$x = 1$：$(\ln x)'\big|_{x=1} = 1$。$y = \ln x$在$(1, 0)$处的切线斜率为1。相符。

**来源**。[OpenStax Calculus Volume 1 §3.7](https://openstax.org/books/calculus-volume-1/pages/3-7-derivatives-of-inverse-functions) — CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="arcsin的链式法则——合成arcsin(2x)" numero="3">

**问题**：计算$\dfrac{d}{dx}\arcsin(2x)$。

**策略**：应用公式$(\arcsin u)' = u'/\sqrt{1-u^2}$，其中$u = 2x$。

**求解**：

1. 识别$u = 2x$，因此$u' = 2$。

2. 应用链式法则：
$$\frac{d}{dx}\arcsin(2x) = \frac{2}{\sqrt{1 - (2x)^2}} = \frac{2}{\sqrt{1 - 4x^2}}$$

3. 结果对$|2x| < 1$有效，即$x \in (-1/2,\, 1/2)$。

**验证**：对$x = 0$：导数$= 2/\sqrt{1} = 2$。由差分：$\arcsin(2 \cdot 0.01) \approx 0.020$，除以$0.01$得$\approx 2.00$。相符。

**来源**。[Active Calculus §2.6, 练习 2.6.2](https://activecalculus.org/single/sec-2-6-inverse.html) — Boelkins · CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="无显式公式的反函数定理——计算(f^{-1})'(b)" numero="4">

**问题**：设$f(x) = x^3 + 2x + 1$。计算$(f^{-1})'(4)$。

**策略**：不知道$f^{-1}$的显式形式，但可使用$(f^{-1})'(b) = 1/f'(f^{-1}(b))$。需要找$a$使得$f(a) = 4$。

**求解**：

1. 找$a$使得$f(a) = 4$：
$$a^3 + 2a + 1 = 4 \implies a^3 + 2a - 3 = 0$$

试$a = 1$：$1 + 2 - 3 = 0$。故$a = 1$，即$f(1) = 4$。

2. 计算$f'(x) = 3x^2 + 2$。

3. 在$a = 1$处求值：$f'(1) = 3(1)^2 + 2 = 5$。

4. 应用定理：
$$(f^{-1})'(4) = \frac{1}{f'(1)} = \frac{1}{5}$$

**验证**：$f$严格递增（$f'(x) = 3x^2 + 2 > 0$对所有$x$），故$f^{-1}$存在。在$b = 4$处，$f^{-1}$的斜率是$1/5$。

**来源**。[Active Calculus §2.6, 练习 2.6.4](https://activecalculus.org/single/sec-2-6-inverse.html) — Boelkins · CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="对数求导——x的x次方的导数" numero="5">

**问题**：求$y = x^x$（对$x > 0$）的导数。

**策略**：$x^x$既不是固定幂也不是固定指数——使用对数求导：两边取ln然后求导。

**求解**：

1. 两边取ln：
$$\ln y = x \ln x$$

2. 对$x$隐式求导：
$$\frac{1}{y} \cdot \frac{dy}{dx} = \ln x + x \cdot \frac{1}{x} = \ln x + 1$$

3. 隔离$dy/dx$，乘以$y = x^x$：
$$\frac{dy}{dx} = x^x (\ln x + 1)$$

**特殊情况**：在$x = 1$：$dy/dx = 1^1(\ln 1 + 1) = 1 \cdot 1 = 1$。$y = x^x$在$(1, 1)$处的切线斜率为1。

**推广**：对$y = f(x)^{g(x)}$，对数求导给出：
$$\frac{dy}{dx} = f(x)^{g(x)} \left(g'(x)\ln f(x) + \frac{g(x) f'(x)}{f(x)}\right)$$

**来源**。[OpenStax Calculus Volume 1 §3.7](https://openstax.org/books/calculus-volume-1/pages/3-7-derivatives-of-inverse-functions) — CC-BY-NC-SA.
</Exemplo>
