<Porta nivel="formal" titulo="定义与隐函数定理">

### 动机

一条平面曲线可以用方程 $F(x, y) = 0$ 表示，而无需将 $y$ 明确地求解出来。圆 $x^2 + y^2 = r^2$ 和笛卡尔叶形线 $x^3 + y^3 = 3axy$ 是典型例子。隐函数求导绕过了这一障碍。

### 正式方法

设 $F(x, y) = 0$ 是在点 $(a, b)$ 附近将 $y$ 定义为 $x$ 的函数的方程。

<Definicao titulo="隐函数求导算法">

1. 将方程写成 $F(x, y) = 0$ 的形式。
2. 对等式两边关于 $x$ 求导。每当 $y$ 出现时，应用链式法则：

$$\frac{d}{dx}\bigl[G(y)\bigr] = G'(y)\,\frac{dy}{dx}$$

3. 将所有包含 $\tfrac{dy}{dx}$ 的项收集在左边。
4. 提取 $\tfrac{dy}{dx}$ 并除以。

</Definicao>

### 典型例子：圆

$$x^2 + y^2 = r^2$$

求导得：$2x + 2y\,y' = 0$，因此 $y' = -\dfrac{x}{y}$（在 $y \neq 0$ 时有效）。

### 经典曲线表

| 曲线 | 方程 $F(x,y)=0$ | $dy/dx$ |
|---|---|---|
| 圆 | $x^2 + y^2 - r^2 = 0$ | $-x/y$ |
| 椭圆 | $x^2/a^2 + y^2/b^2 - 1 = 0$ | $-(b^2 x)/(a^2 y)$ |
| 双曲线 | $x^2/a^2 - y^2/b^2 - 1 = 0$ | $(b^2 x)/(a^2 y)$ |
| 笛卡尔叶形线 | $x^3 + y^3 - 3axy = 0$ | $(ay - x^2)/(y^2 - ax)$ |

> "如果关联 $x$ 和 $y$ 的方程无法显式求解 $y$，我们仍可以通过隐式求导来找到 $y'$。" — [OpenStax Calculus Volume 1, §3.8](https://openstax.org/books/calculus-volume-1/pages/3-8-implicit-differentiation)

### 隐函数定理（一维版本）

<Teorema titulo="隐函数定理（标量情形）">

设 $F: \mathbb{R}^2 \to \mathbb{R}$ 在 $(a, b)$ 的开邻域内为 $C^1$ 类，$F(a, b) = 0$ 且 $F_y(a, b) \neq 0$。则存在包含 $a$ 的开区间 $I$ 和唯一的 $C^1$ 类函数 $y = g(x)$（在 $I$ 上），使得 $g(a) = b$ 且对所有 $x \in I$ 有 $F(x, g(x)) = 0$。此外：

<Equation numero="TFI" explicacao="隐函数求导公式是将链式法则应用于复合函数 F(x, g(x)) = 0 的直接结果。" latex="g'(x) = -\frac{F_x(x,\,g(x))}{F_y(x,\,g(x))}" />
</Teorema>

**何时失效。** 如果 $F_y(a, b) = 0$，曲线在该点可能有竖直切线，或可能不局部定义一个函数。例子：圆在点 $(\pm r, 0)$ 处——$F_y = 2y = 0$。

<Insight>

条件 $F_y \neq 0$ 是关键假设。从几何上看，$\nabla F = (F_x, F_y)$ 是 $F$ 的梯度，垂直于曲线。切向量为 $T = (-F_y, F_x)$。因此切线的斜率是 $T_y/T_x = F_x/(-F_y) = -F_x/F_y$——正好是隐函数求导公式。当 $F_y = 0$ 时，切向量竖直，斜率不存在。

</Insight>

### 二阶隐函数求导

对 $y' = -F_x/F_y$ 再应用 $\tfrac{d}{dx}$，使用商法则并记住 $y$ 依赖于 $x$。

</Porta>

<Porta nivel="5" titulo="五岁儿童版">

想象你在纸上画了一个**圆**。这个圆不是一个简单的函数——对于每个水平位置，圆上有两个点：一个在上面，一个在下面。

但我们可以问：如果我向右走一点，上面的点是上升还是下降，上升或下降多少？这就是圆的**斜率**。

隐函数求导的技巧是：与其试图分离"上面"和"下面"，我们**对整个圆的方程求导**，将 $y$ 视为 $x$ 的函数。

这就像试图找出一个密闭箱子里有多少个苹果，不用打开箱子——只需要称重并使用你知道的东西。

</Porta>

<Porta nivel="10" titulo="十岁儿童版">

有时你有一个方程，它以一种不可能（或很费力）分离 $y$ 的方式混合了 $x$ 和 $y$。例如：

$$x^3 + y^3 = 6xy$$

这是**笛卡尔叶形线**——一条美丽的曲线，无法写成"$y =$ 某个简单东西"。

技巧是：**对所有东西关于 $x$ 求导**，记住当 $x$ 变化时 $y$ 也变化。每次你对包含 $y$ 的项求导时，在旁边加一个 $y'$（由链式法则）。

**圆上的例子。** $x^2 + y^2 = 25$。对两边关于 $x$ 求导：

$$2x + 2y \cdot y' = 0$$

$2y \cdot y'$ 出现是因为 $y^2$ 通过 $y$ 依赖于 $x$。分离得：

$$y' = -\frac{x}{y}$$

在圆上的点 $(3, 4)$ 处：$y' = -3/4$。即，在那里圆的切线斜率为 $-3/4$。

</Porta>

<Porta nivel="15" titulo="十五岁青少年版">

**为什么要使用隐函数求导？** 因为许多重要的曲线——圆、椭圆、叶形线——不是函数的图像。即使可能分离 $y$，结果也可能极其复杂，以至于使用隐方程更简洁。

### 分步方法

1. **将 $y$ 视为 $x$ 的函数**——记为 $y(x)$。
2. **对每一项求导**关于 $x$。
3. **每当 $y$ 出现时应用链式法则**：$\dfrac{d}{dx}[y^n] = n\,y^{n-1}\,y'$。
4. **将所有包含 $y'$ 的项收集**在等式的一边。
5. **分离 $y'$**通过除法。

### 完整例子：$x^2 + xy + y^2 = 7$

对每一项关于 $x$ 求导：

$$\frac{d}{dx}[x^2] + \frac{d}{dx}[xy] + \frac{d}{dx}[y^2] = 0$$

$$2x + \bigl(y + x\,y'\bigr) + 2y\,y' = 0$$

（$xy$ 项需要乘积法则：$(x)' y + x(y)' = y + x y'$。）

收集 $y'$：

$$x\,y' + 2y\,y' = -2x - y$$

$$y'(x + 2y) = -2x - y$$

$$y' = \frac{-2x - y}{x + 2y}$$

### 在某点处的切线

要在 $(a, b)$ 处求切线：在该点评估 $y'$ 并写出 $y - b = y'(a, b)\cdot(x - a)$。

### 切线何时水平或竖直？

- **水平**：$y' = 0 \Rightarrow$ 分子 $= 0$。
- **竖直**：$y'$ 不存在 $\Rightarrow$ 分母 $= 0$（且分子 $\neq 0$）。

<Insight>

隐函数求导直接连接到**链式法则**：对 $F(x, y(x)) = 0$ 求导，得到 $F_x + F_y \cdot y' = 0$，因此 $y' = -F_x/F_y$。你在第53课中学到的所有内容都在这里——隐函数求导不是新技巧，而是伪装的链式法则。

</Insight>

</Porta>

<Porta nivel="25" titulo="工程学生版">

### 几何与分析解释

曲线 $\{(x,y) : F(x,y) = 0\}$ 有梯度向量 $\nabla F = (F_x, F_y)$ 垂直于曲线。切向量为 $T = (-F_y, F_x)$（旋转90°）。切线的斜率为：

$$\frac{T_y}{T_x} = \frac{F_x}{-F_y} = -\frac{F_x}{F_y}$$

这完全符合隐函数求导公式。

### 对数导数

对于形如 $y = u(x)^{v(x)}$ 的函数，最简洁的方法是先取对数再求导：

$$\ln y = v(x)\,\ln u(x) \implies \frac{y'}{y} = v'(x)\,\ln u(x) + v(x)\,\frac{u'(x)}{u(x)}$$

例：$y = x^x$。则 $\ln y = x \ln x$，且 $y'/y = \ln x + 1$，因此 $y' = x^x(\ln x + 1)$。

### 二阶隐函数求导

给定 $y' = -F_x/F_y$，再次应用 $d/dx$ 使用商法则并记住 $F_x, F_y$ 依赖于 $x$ 和 $y(x)$。

对于 $F(x,y) = x^2 + y^2 - r^2$：$F_x = 2x$，$F_y = 2y$，$y' = -x/y$。

$$y'' = -\frac{y - x\,y'}{y^2} = -\frac{y + x^2/y}{y^2} = -\frac{y^2 + x^2}{y^3} = -\frac{r^2}{y^3}$$

### 跨领域应用

- **热力学**：状态方程 $f(P,V,T)=0$。保持 $T$ 固定：$\left(\frac{\partial P}{\partial V}\right)_T = -F_V/F_P$（带参数的隐函数求导）。
- **拉格朗日力学**：完整约束 $g(q_1,\ldots,q_n)=0$——拉格朗日乘数法使用 $g$ 的梯度，这是隐函数求导的推广。
- **经济学**：无差异曲线 $U(x_1, x_2) = \bar{U}$——边际替代率为 $-U_{x_1}/U_{x_2}$，正好是隐 $y'$。
- **机器学习**："可微优化"（CvxpyLayers、OptNet）使用隐函数定理通过优化子问题传播梯度。

> "关键思想是，尽管 $y$ 是隐式定义的，我们仍可以通过将 $y$ 视为 $x$ 的函数并应用链式法则来计算 $dy/dx$。" — [Active Calculus 2.0, §2.7](https://activecalculus.org/single/sec-2-7-implicit.html)

</Porta>

### 巴拿赫空间中的隐函数定理

标量隐函数求导是一个更一般的结果的情形 $n=m=1$。

<Teorema titulo="隐函数定理 — 巴拿赫版本（非正式）">

设 $X, Y, Z$ 为巴拿赫空间，$F: X \times Y \to Z$ 为 $C^1$ 类。如果 $F(a,b) = 0$ 且 $D_y F(a,b): Y \to Z$ 是同构（连续线性双射，反函数连续），则存在 $(a,b)$ 的邻域 $U \times V$ 和唯一的 $C^1$ 类函数 $g: U \to V$ 满足 $F(x, g(x)) = 0$。$g$ 的导数为：

$$g'(a) = -\bigl[D_y F(a,b)\bigr]^{-1} \circ D_x F(a,b)$$

</Teorema>

**退化情形。** 当 $D_y F$ 奇异（不可逆）时，隐函数定理失效，出现**分岔**——这正是分岔理论中的关键点（Crandall–Rabinowitz, 1971）。

### 隐波动率（布朗-舒尔茨模型）

在金融中，$\sigma^*$（隐波动率）由 $V_{\text{BS}}(S, K, T, r, \sigma^*) = V_{\text{mkt}}$ 定义。根据隐函数定理：

$$\frac{d\sigma^*}{dV_{\text{mkt}}} = \frac{1}{\partial V_{\text{BS}}/\partial \sigma} = \frac{1}{\mathcal{V}}$$

其中 $\mathcal{V}$ 是Vega。隐函数求导从字面上是Vega的倒数——这正是交易者如何在实时校准波动率模型。

### 约束优化与KKT条件

最小化 $f(x)$ s.a. $g(x) = 0$ 的KKT条件是关于 $(x^*, \lambda^*)$ 的隐式系统。最优解对参数的敏感性（包络定理）是KKT系统的隐函数求导。因此隐函数求导是所有非线性规划中敏感性分析的核心。

### 数值延拓

预报-校正方法（Keller, 1977）追踪随着 $\lambda$ 变化的 $F(x, \lambda) = 0$ 解的分支。预报步使用 $dx/d\lambda$（隐函数）；校正步使用牛顿法。是AUTO和MATCONT等软件的基础。

</Porta>

<Porta nivel="pratica" titulo="实际应用与常见错误">

### 何时使用隐函数求导

使用于以下情况：
- 方程关联 $x$ 和 $y$ 而无法轻易分离 $y$（圆、椭圆、隐曲线）。
- 分离 $y$ 会产生更复杂的表达式（立方根、超越函数）。
- 你只需在特定点处的 $dy/dx$ 而无需全局函数。

### 完整工作流

1. 识别方程 $F(x, y) = 0$。
2. 关于 $x$ 求导**每一项**。要记住的规则：
   - $\dfrac{d}{dx}[y] = y'$
   - $\dfrac{d}{dx}[y^2] = 2y\,y'$
   - $\dfrac{d}{dx}[y^n] = n\,y^{n-1}\,y'$
   - $\dfrac{d}{dx}[x\,y] = y + x\,y'$（乘积法则）
   - $\dfrac{d}{dx}[\sin y] = \cos y \cdot y'$
   - $\dfrac{d}{dx}[e^y] = e^y \cdot y'$
3. 将 $y'$ 项收集在左边。
4. 分离 $y'$。
5. 在该点评估以获得数值斜率。

### 常见错误

1. **对 $y$ 项求导时忘记 $y'$。** $\dfrac{d}{dx}[y^2] = 2y$ 是错的。正确：$2y\,y'$。
2. **忘记 $xy$ 中的乘积法则：**导数是 $y + x\,y'$，而不仅仅 $y'$。
3. **未检查分母为零处。** 如果 $F_y = 0$ 在该点，$y'$ 在那里不存在（竖直切线）。
4. **混淆 $\partial F/\partial y$ 与 $dy/dx$。** 它们是不同的对象：一个是偏导，另一个是要求的总导数。

### 考试中的问题类型

- 计算给定曲线的 $dy/dx$。
- 求在 $(a, b)$ 处的切线方程。
- 找到水平或竖直切线的点。
- 隐式计算 $y''$。

</Porta>

</DuasPortas>

## 已解决的例子

<Exemplo titulo="圆的隐函数求导（基础）" numero="1">

**问题。** 求圆 $x^2 + y^2 = 25$ 的 $dy/dx$。

**策略。** 这是隐函数求导的标准例子。直接对 $x$ 求导，记住 $y$ 是 $x$ 的函数。

**解决方案。**

1. 对等式两边关于 $x$ 求导：

$$\frac{d}{dx}\bigl[x^2 + y^2\bigr] = \frac{d}{dx}[25]$$

2. 对 $y^2$ 应用链式法则：

$$2x + 2y\,\frac{dy}{dx} = 0$$

3. 分离 $dy/dx$：

$$2y\,\frac{dy}{dx} = -2x \implies \frac{dy}{dx} = -\frac{x}{y}$$

**在点 $(3, 4)$ 处验证：** 该点在曲线上（$9 + 16 = 25$）。斜率为 $dy/dx = -3/4$。切线为 $y - 4 = -\tfrac{3}{4}(x - 3)$，或 $3x + 4y = 25$。从几何上：到 $(3,4)$ 的半径斜率为 $4/3$，而 $(-3/4)(4/3) = -1$，确认切线与半径垂直。

**来源。** [OpenStax Calculus Volume 1 §3.8](https://openstax.org/books/calculus-volume-1/pages/3-8-implicit-differentiation), 例 3.68, p. 318 — CC-BY-NC-SA 4.0 许可。
</Exemplo>

<Exemplo titulo="椭圆的隐函数求导 — 特定点的切线" numero="2">

**问题。** 对于椭圆 $\dfrac{x^2}{16} + \dfrac{y^2}{9} = 1$，求 $dy/dx$ 和在点 $\left(2, \tfrac{3\sqrt{3}}{2}\right)$ 处的切线方程。

**策略。** 应用隐函数求导，然后在给定点评估。

**解决方案。**

1. 求导：

$$\frac{d}{dx}\left[\frac{x^2}{16} + \frac{y^2}{9}\right] = 0 \implies \frac{2x}{16} + \frac{2y}{9}\,y' = 0$$

2. 简化：

$$\frac{x}{8} + \frac{2y}{9}\,y' = 0 \implies y' = -\frac{9x}{16y}$$

3. 在点 $\left(2, \tfrac{3\sqrt{3}}{2}\right)$ 处：

$$y' = -\frac{9 \cdot 2}{16 \cdot \tfrac{3\sqrt{3}}{2}} = -\frac{18}{24\sqrt{3}} = -\frac{3}{4\sqrt{3}} = -\frac{\sqrt{3}}{4}$$

4. 切线方程：

$$y - \frac{3\sqrt{3}}{2} = -\frac{\sqrt{3}}{4}\left(x - 2\right) \implies y = -\frac{\sqrt{3}}{4}\,x + 2\sqrt{3}$$

**验证：** 代入 $x = 2$：$y = -\sqrt{3}/2 + 2\sqrt{3} = 3\sqrt{3}/2$。正确。

**来源。** [Active Calculus 2.0 §2.7](https://activecalculus.org/single/sec-2-7-implicit.html), 预览活动 2.7.1, p. 154 — CC-BY-NC-SA 4.0 许可。
</Exemplo>

<Exemplo titulo="笛卡尔叶形线 — 带乘积法则的隐函数求导" numero="3">

**问题。** 求笛卡尔叶形线 $x^3 + y^3 = 3xy$ 的 $dy/dx$。

**策略。** 右边 $3xy$ 求导时需要乘积法则。然后收集并分离 $y'$。

**解决方案。**

1. 对两边关于 $x$ 求导：

$$3x^2 + 3y^2\,y' = 3\,(y + x\,y')$$

(右边：$\dfrac{d}{dx}[3xy] = 3\left[(1)\cdot y + x \cdot y'\right] = 3y + 3x\,y'$.)

2. 展开并收集 $y'$ 项：

$$3x^2 + 3y^2\,y' = 3y + 3x\,y'$$

$$3y^2\,y' - 3x\,y' = 3y - 3x^2$$

$$y'(3y^2 - 3x) = 3(y - x^2)$$

3. 分离 $y'$：

$$y' = \frac{3(y - x^2)}{3(y^2 - x)} = \frac{y - x^2}{y^2 - x}$$

**验证：** 在点 $\left(\tfrac{3}{2}, \tfrac{3}{2}\right)$（属于 $a=1$ 的叶形线）：

$$y' = \frac{3/2 - 9/4}{9/4 - 3/2} = \frac{-3/4}{3/4} = -1$$

切线斜率为 $-1$，这对由对称性在 $y = x$ 平分线处的曲线是有意义的。

**来源。** [OpenStax Calculus Volume 1 §3.8](https://openstax.org/books/calculus-volume-1/pages/3-8-implicit-differentiation), 练习 175, p. 325 — CC-BY-NC-SA 4.0 许可。
</Exemplo>

<Exemplo titulo="隐二阶导数" numero="4">

**问题。** 对于 $x^2 + y^2 = r^2$，用 $x$、$y$ 和 $r$ 表示 $d^2y/dx^2$。

**策略。** 我们已知 $y' = -x/y$。再对 $x$ 求导一次，应用商法则并将 $y'$ 代入结果表达式中。

**解决方案。**

1. 从 $y' = -\dfrac{x}{y}$ 开始。

2. 使用商法则应用 $\dfrac{d}{dx}$：

$$y'' = -\frac{(x)'\,y - x\,(y)'}{y^2} = -\frac{y - x\,y'}{y^2}$$

3. 代入 $y' = -x/y$：

$$y'' = -\frac{y - x \cdot (-x/y)}{y^2} = -\frac{y + x^2/y}{y^2} = -\frac{y^2 + x^2}{y^3}$$

4. 使用 $x^2 + y^2 = r^2$：

$$y'' = -\frac{r^2}{y^3}$$

**解释。** 对于 $y > 0$（圆的上半部分），$y'' = -r^2/y^3 < 0$ ——曲线向下凹，这在几何上对上半圆是正确的。

**来源。** [Active Calculus 2.0 §2.7](https://activecalculus.org/single/sec-2-7-implicit.html), 活动 2.7.3, p. 158 — CC-BY-NC-SA 4.0 许可。
</Exemplo>

<Exemplo titulo="对数导数与三角隐曲线" numero="5">

**问题（两部分）。**
(a) 如果 $y = x^{\sin x}$（其中 $x > 0$），使用对数导数求 $y'$。
(b) 求 $\sin(xy) = x - y$ 的 $dy/dx$。在 $(0, 0)$ 处评估。

**策略。** (a) 取对数再求导可消除可变指数。(b) 隐函数求导，其中 $\sin(xy)$ 的链式法则在参数中需要乘积法则。

**解决方案 — 部分(a)。**

1. 两边取 $\ln$：$\ln y = \sin x \cdot \ln x$。

2. 关于 $x$ 求导：

$$\frac{y'}{y} = \cos x \cdot \ln x + \sin x \cdot \frac{1}{x}$$

3. 乘以 $y = x^{\sin x}$：

$$y' = x^{\sin x}\!\left(\cos x\,\ln x + \frac{\sin x}{x}\right)$$

**解决方案 — 部分(b)。**

1. 对 $\sin(xy) = x - y$ 求导：

$$\cos(xy) \cdot \frac{d}{dx}[xy] = 1 - y'$$

$$\cos(xy) \cdot (y + x\,y') = 1 - y'$$

2. 展开并收集：

$$y\cos(xy) + x\cos(xy)\,y' = 1 - y'$$

$$y' \bigl(x\cos(xy) + 1\bigr) = 1 - y\cos(xy)$$

$$y' = \frac{1 - y\cos(xy)}{1 + x\cos(xy)}$$

3. 在 $(0, 0)$：$\cos(0 \cdot 0) = \cos 0 = 1$。

$$y'(0,0) = \frac{1 - 0 \cdot 1}{1 + 0 \cdot 1} = \frac{1}{1} = 1$$

**验证：** $(0,0)$ 满足 $\sin(0 \cdot 0) = 0 - 0$ 吗？$\sin(0) = 0$。正确。

**来源。** [APEX Calculus §2.6](https://www.apexcalculus.com/), 例 2.6.4 和 2.6.5, p. 117 — CC-BY-NC 4.0 许可。
</Exemplo>
