<Porta nivel="formal" titulo="定义、最大化和弹性">

### 边际函数

<Definicao titulo="成本、收益、利润及其边际值">
给定：
- $C(q)$：**总成本**生产$q$个单位。
- $R(q) = p(q) \cdot q$：**总收益**（在完全竞争中$p$是固定的；在垄断中$p$依赖于$q$）。
- $\pi(q) = R(q) - C(q)$：**利润**。

**边际值**是导数：
$$MC(q) = C'(q), \quad MR(q) = R'(q), \quad M\pi(q) = \pi'(q) = MR(q) - MC(q).$$
$MC(q)$约等于生产第$(q+1)$个单位的成本。
</Definicao>

> "边际成本函数是$C'(x)$，即成本函数的导数。边际收益函数是$R'(x)$。" — [OpenStax Calculus Vol. 1 §4.7](https://openstax.org/books/calculus-volume-1/pages/4-7-applied-optimization-problems)

### 利润最大化

$\pi'(q) = 0 \iff MR(q) = MC(q)$。

**二阶条件：** $\pi''(q^*) < 0 \iff MR'(q^*) < MC'(q^*)$ ——边际成本增长速度快于边际收益。

### 平均成本和边际成本

<Definicao titulo="平均成本">
$\bar{C}(q) = C(q)/q$。求导：
$$\bar{C}'(q) = \frac{C'(q) \cdot q - C(q)}{q^2} = \frac{MC(q) - \bar{C}(q)}{q}.$$
</Definicao>

因此：$\bar{C}'(q) = 0 \iff MC(q) = \bar{C}(q)$。**边际成本曲线在平均成本曲线的最小值处穿过它。**

### 需求的价格弹性

<Definicao titulo="价格弹性">
对于需求函数$q = D(p)$：
$$\varepsilon(p) = \frac{dq}{dp} \cdot \frac{p}{q} = D'(p) \cdot \frac{p}{q}.$$
- $|\varepsilon| > 1$：需求**富有弹性**（奢侈品、有替代品的商品）。降价会增加收益。
- $|\varepsilon| < 1$：需求**缺乏弹性**（必需品——盐、汽油）。涨价会增加收益。
- $|\varepsilon| = 1$：**单位弹性**。收益最大。
</Definicao>

### 垄断定价

对于选择$q$的垄断企业（进而间接选择$p$）：

$$MR = p + q\,\frac{dp}{dq} = p\!\left(1 + \frac{1}{\varepsilon}\right).$$

最大利润（$MR = MC$）给出**定价规则：**
$$p^* = \frac{MC}{1 + 1/\varepsilon} = \frac{MC \cdot \varepsilon}{\varepsilon + 1}.$$

**勒纳指数：** $L = (p - MC)/p = -1/\varepsilon$ 衡量市场力量。

<Insight titulo="直线需求的弹性">
对于线性需求$q = a - bp$，弹性$|\varepsilon| = bp/q$随$p$增加。在$p = 0$时：$\varepsilon = 0$（缺乏弹性）。在$q = 0$时：$|\varepsilon| \to \infty$（富有弹性）。单位弹性点恰好在需求的中点——收益最大的地方。
</Insight>

<Porta nivel="5" titulo="给5岁小孩的解释">

想象你在海滩上卖**冰棍**。为了多做一根冰棍，你需要花费一定量的冰淇淋和木棍——这就是**边际成本**（多做一个的成本）。

你每根冰棍卖5元。这是**边际收益**（多卖一个获得多少）。

只要做一根冰棍的成本少于5元，做就是值得的。当做一根冰棍刚好花5元时，你就在**完美点**——之后开始赔钱。

这个"多做一个的成本=多卖一个的收益"的点就是**利润最大**的地方！

</Porta>

<Porta nivel="10" titulo="给10岁小孩的解释">

在经济学中，**导数**变成**边际值**：

- $C(q)$ = 生产$q$个单位的总成本。**MC** = $C'$ = 生产**一个额外单位**的成本。
- $R(q)$ = 收益（进来的钱）。**MR** = $R'$ = **一个额外单位**带来多少收入。
- **利润最大化**：继续生产，只要$MR > MC$。当$MR = MC$时停止。

**例子：** $C(q) = 100 + 5q + 0,1q^2$（成本），$p = 50$固定（竞争）。$R = 50q$，$MR = 50$。$MC = 5 + 0,2q$。$MR = MC \Rightarrow 50 = 5 + 0,2q \Rightarrow q^* = 225$。

**弹性**：如果你涨价1%数量下降2%，弹性是$-2$。需求**富有弹性**——对价格敏感。

</Porta>

<Porta nivel="15" titulo="给15岁青少年的解释">

边际分析是**微观经济学的核心模型**：每个决策都归结为"再多一个单位值得吗？"

### 基本结构

- **成本** $C(q)$：固定部分$F$+可变部分$V(q)$。
- **收益** $R(q) = p(q) \cdot q$。在完全竞争中$p$是给定的；在垄断中$p$随$q$下降。
- **利润** $\pi(q) = R(q) - C(q)$。

### 平均成本 vs 边际成本

$\bar{C}(q) = C(q)/q$：每单位的成本。$MC(q) = C'(q)$：下一个单位的成本。

$\bar{C}$的最小值发生在$MC = \bar{C}$处——那是生产一个额外单位不再能降低平均成本的地方。

### 弹性

$\varepsilon = (\Delta q/q)/(\Delta p/p)$：数量百分比变化对价格百分比变化。

- $|\varepsilon| > 1$：**富有弹性**——消费者敏感。例：机票、名牌服装。
- $|\varepsilon| < 1$：**缺乏弹性**——消费者不敏感。例：烟草、药物、汽油。

### 实例讲解

需求$q = 100 - 2p$（反函数：$p = (100-q)/2$）。收益$R(q) = (100-q)q/2 = 50q - q^2/2$。

$MR(q) = 50 - q$。成本$C(q) = 10q + q^2/4$，$MC = 10 + q/2$。

$MR = MC \Rightarrow 50 - q = 10 + q/2 \Rightarrow 3q/2 = 40 \Rightarrow q^* \approx 26,7$。

</Porta>

<Porta nivel="25" titulo="给工程学学生的解释">

边际分析出现在古典经济学、工程经济学、金融（边际效用）和运筹学（动态定价）中。

### 工程中的典型成本函数

$C(q) = F + aq + bq^2 + cq^3$：固定成本$F$+线性（原材料）+二次（加班费）+三次（产能瓶颈）。曲线$\bar{C}(q)$呈U形：随规模下降，随拥堵上升。

### 垄断 vs 完全竞争

| | 完全竞争 | 垄断 |
|---|---|---|
| $p$ | 给定（价格接受者） | $p(q)$，选择的 |
| $MR$ | $p$（常数） | $p + q\,dp/dq < p$ |
| 决策 | $MC = p$ | $MC = MR < p$ |
| 剩余 | 社会最优 | 产量不足——死重损失 |

### EOQ——经济订单量

$T(q) = \frac{Dhq}{2} + \frac{SD}{q}$，其中$D$ = 年需求，$h$ = 每单位每年维护成本，$S$ = 订单成本。$T'(q) = Dh/2 - SD/q^2 = 0 \Rightarrow q^* = \sqrt{2SD/h}$。库存管理的标准模型。

### 动态定价和可变弹性

Uber、航空公司和电子商务实时估计$\varepsilon$并通过标记$p = MC/(1 + 1/\varepsilon)$调整。挑战是用观测数据估计$\varepsilon$——工具变量是标准方法。

### 税收和税收归宿

单位税$t$：$MC \to MC + t$。新均衡：$q^*$下降。买家和卖家之间的负担分配取决于弹性：买家部分$= \varepsilon_S/(\varepsilon_S - \varepsilon_D)$。

### 通过边际分析的Black-Scholes

投资组合$\Pi = -V + \Delta S$，其中$\Delta = \partial V/\partial S$是**delta**——期权价格的边际导数。无风险复制+Itô给出Black-Scholes偏微分方程。[1997年经济学诺贝尔奖](https://www.nobelprize.org/prizes/economic-sciences/1997/)授予Merton和Scholes因为这个推导。

</Porta>

<Porta nivel="40" titulo="给资深专业人士的解释">

边际分析是起点；现代经济学在一般均衡、动态随机和博弈论中工作。

### 一般均衡

Walras（1874）：所有市场同时处于均衡——每个商品$i$的方程组$MC_i = p_i$。存在性通过不动点定理证明（Arrow-Debreu，1954——[1972年诺贝尔奖](https://www.nobelprize.org/prizes/economic-sciences/1972/)）。竞争性市场的效率=第一福利定理。

### 博弈论和纳什均衡

当代理人互动时，Nash（1950——[1994年诺贝尔奖](https://www.nobelprize.org/prizes/economic-sciences/1994/)）取代孤立的优化者。每个代理人在给定竞争对手行为的情况下最大化利润——一阶条件是关于自己选择的偏导数。Cournot、Bertrand、Stackelberg模型化时序和结构。

### 随机最优控制

Hamilton-Jacobi-Bellman：$V_t + \sup_u[f(x,u)V_x + \sigma^2/2 \cdot V_{xx}] = 0$。Bellman方程为序列决策推广边际一阶条件。Black-Scholes是有线性$f$且无控制的特例。

### 信息不对称

Akerlof（柠檬市场，[2001年诺贝尔奖](https://www.nobelprize.org/prizes/economic-sciences/2001/)）、Spence（信号传递）、Stiglitz（筛选）表明标准边际分析在信息不对称下失效。无干预时出现无效率均衡。

### 行为经济学

Kahneman（[2002年诺贝尔奖](https://www.nobelprize.org/prizes/economic-sciences/2002/kahneman/facts/)）记录了离开边际理性的系统偏差：损失厌恶、锚定、双曲贴现。边际分析仍然是规范基准——但真实行为会偏离。

### Keynes-Ramsey规则

在动态模型中（Ramsey-Cass-Koopmans），代理人最大化$\int_0^\infty U(c(t)) e^{-\rho t} dt$，受限于$\dot k = f(k) - c - \delta k$。Euler-Lagrange方程给出$\dot c/c = (f'(k) - \delta - \rho)/\sigma$——Keynes-Ramsey规则。边际分析在连续时间中通过变分法运作。

</Porta>

<Porta nivel="pratica" titulo="实际应用">

**5步流程：**

1. 识别$C(q)$和$p(q)$（或$q(p)$）。
2. 计算$R(q) = p(q) \cdot q$、$MC = C'$、$MR = R'$。
3. 找$q^*$使$MR(q^*) = MC(q^*)$。
4. 确认最大值：$\pi''(q^*) < 0$。
5. 计算$p^* = p(q^*)$、$\pi^* = R(q^*) - C(q^*)$。

### 快速例子——果汁公司

当地果汁需求：$p(q) = 20 - 0,1q$（元/瓶，$q$单位/天）。成本：$C(q) = 200 + 5q + 0,05q^2$。

$R(q) = q(20 - 0,1q) = 20q - 0,1q^2$。$MR = 20 - 0,2q$。$MC = 5 + 0,1q$。

$MR = MC \Rightarrow 20 - 0,2q = 5 + 0,1q \Rightarrow 15 = 0,3q \Rightarrow q^* = 50$。

$p^* = 20 - 5 = 15$元。$\pi^* = 15 \times 50 - (200 + 250 + 125) = 750 - 575 = 175$元/天。

### 通过平均成本验证

$\bar{C}(50) = 575/50 = 11,50$元。由于$p^* = 15 > \bar{C}$，公司有利润。$\checkmark$

### Python验证

```python
import sympy as sp
q = sp.symbols('q', positive=True)
p_func = 20 - 0.1*q
R = p_func * q
C = 200 + 5*q + 0.05*q**2
profit = R - C
q_star = sp.solve(sp.diff(profit, q), q)
print(q_star, profit.subs(q, q_star[0]))
```

## 已解决的例子

<Exemplo titulo="边际成本和最小平均成本（基础）" numero="1">

**问题。** 对于$C(q) = q^2 + 9$，找边际成本$MC$和使平均成本$\bar{C}$最小的数量。

**策略。** 计算$MC = C'$。最小化$\bar{C} = C/q$通过求导并令其为零——或使用性质$MC = \bar{C}$在最小值处。

**解。**

1. **$MC(q) = 2q$。**
2. **$\bar{C}(q) = q + 9/q$。**
3. **$\bar{C}'(q) = 1 - 9/q^2 = 0 \Rightarrow q^2 = 9 \Rightarrow q = 3$。**
4. **验证：** $\bar{C}(3) = 3 + 3 = 6$且$MC(3) = 6$。$\checkmark$ ——平均成本最小值与边际成本重合。

**验证。** $\bar{C}''(q) = 18/q^3 > 0$在$q = 3$：最小值确认。$\checkmark$

**来源。** [Yoshiwara — Modeling, Functions, and Graphs, 第 5 章, 练习 5.3.9](https://yoshiwarabooks.org/mfg/Chap4.html) ——开放许可。
</Exemplo>

<Exemplo titulo="线性需求的利润最大化（中级）" numero="2">

**问题。** 需求$q = 100 - 2p$（反函数：$p = 50 - q/2$）。成本$C(q) = 200 + 4q + q^2$。找$q^*$、$p^*$和$\pi^*$。

**策略。** 计算$R(q)$、$MR$和$MC$。令$MR = MC$找$q^*$。用$\pi'' < 0$确认。

**解。**

1. **$R(q) = pq = (50 - q/2)q = 50q - q^2/2$。$MR = 50 - q$。**
2. **$MC = 4 + 2q$。**
3. **$MR = MC \Rightarrow 50 - q = 4 + 2q \Rightarrow 3q = 46 \Rightarrow q^* \approx 15,3$。（近似；如果$q$是整数：$q^* = 15$。）**
4. **$p^* = 50 - 15/2 = 42,50$元。**
5. **$\pi^* = R(15) - C(15) = 637,50 - (200 + 60 + 225) = 637,50 - 485 = 152,50$元。**

**验证。** $\pi''(q) = -3 < 0$对任何$q$——最大值。$\checkmark$

**来源。** [Yoshiwara — Modeling, Functions, and Graphs, 第 5 章, 练习 5.3.15](https://yoshiwarabooks.org/mfg/Chap4.html) ——开放许可。
</Exemplo>

<Exemplo titulo="弹性和最大收益（中级）" numero="3">

**问题。** 需求$q = 100 - 2p$。(a)在$p = 20$处计算弹性。(b)在什么价格收益最大？

**策略。** 应用$\varepsilon = D'(p) \cdot p/q$。通过求导最大化$R = pq = p(100 - 2p)$。

**解。**

**(a)在$p = 20$处的弹性：**
$D'(p) = -2$。$q(20) = 100 - 40 = 60$。
$\varepsilon = -2 \cdot 20/60 = -40/60 = -2/3$。

由于$|\varepsilon| < 1$：需求在$p = 20$处**缺乏弹性**——涨价会增加收益。

**(b)最大收益：**
$R(p) = p(100 - 2p) = 100p - 2p^2$。$R'(p) = 100 - 4p = 0 \Rightarrow p^* = 25$。

$R(25) = 25 \cdot 50 = 1250$元。验证：$\varepsilon(25) = -2 \cdot 25/50 = -1$（单位弹性）。$\checkmark$

**验证。** $R'' = -4 < 0$——最大值确认。$\checkmark$

**来源。** [Active Calculus §3.3, 活动 3.3.4](https://activecalculus.org/single/sec-3-3-optimization.html) ——CC-BY-NC-SA。
</Exemplo>

<Exemplo titulo="经济订单量EOQ（现实建模）" numero="4">

**问题。** 一家工厂的年需求$D = 10000$单位，订单成本$S = 200$元/订单，仓储成本$h = 4$元/单位/年。找经济订单量$q^*$。

**策略。** 最小化$T(q) = Dhq/2 + SD/q$（年总库存成本=仓储+订单）。求导并令其为零。

**解。**

1. **$T(q) = \frac{10000 \cdot 4}{2} q + \frac{200 \cdot 10000}{q} = 20000q + \frac{2000000}{q}$。**

    注意：值已简化：$T(q) = \frac{4q}{2} \cdot 10000/10000 + \ldots$ ——直接使用标准公式：

    $T(q) = \frac{Dhq}{2} + \frac{SD}{q} = \frac{4 \cdot q}{2} + \frac{200 \cdot 10000}{q} = 2q + \frac{2000000}{q}$。

2. **$T'(q) = 2 - 2000000/q^2 = 0 \Rightarrow q^2 = 1000000 \Rightarrow q^* = 1000$单位。**

3. **$T(1000) = 2000 + 2000 = 4000$元/年。**

**验证。** $T''(q) = 4000000/q^3 > 0$——最小值。$\checkmark$ 直接公式$q^* = \sqrt{2SD/h} = \sqrt{2 \cdot 200 \cdot 10000/4} = \sqrt{1000000} = 1000$。$\checkmark$

**来源。** [OpenStax Calculus Vol. 1 §4.7, 例 4.38](https://openstax.org/books/calculus-volume-1/pages/4-7-applied-optimization-problems) ——CC-BY-NC-SA。
</Exemplo>

<Exemplo titulo="垄断定价和福利损失（高级）" numero="5">

**问题。** 垄断企业有需求$p(q) = 100 - 2q$和成本$C(q) = q^2$。(a)找垄断均衡。(b)与完全竞争比较（$MC = p$）。(c)计算福利损失（死重损失）。

**策略。** 垄断：$MR = MC$。竞争：$p = MC$。损失=两个数量之间的三角形面积。

**解。**

**(a)垄断：** $R = 100q - 2q^2$，$MR = 100 - 4q$。$MC = 2q$。$MR = MC \Rightarrow 100 - 4q = 2q \Rightarrow q_M = 100/6 \approx 16,7$。$p_M = 100 - 2(100/6) = 100 - 100/3 \approx 66,7$元。利润：$\pi = (p_M - \bar{C})q_M = \ldots \approx 833$元。

**(b)竞争：** $p = MC \Rightarrow 100 - 2q = 2q \Rightarrow q_C = 25$，$p_C = 50$元。

**(c)福利损失：** 垄断生产$16,7$而非$25$。损失是底边$q_C - q_M \approx 8,3$和高$p_M - p_C \approx 16,7$的三角形面积：

死重损失$\approx \frac{1}{2} \cdot 8,3 \cdot 16,7 \approx 69$元。

**验证。** $p_M > MC(q_M) = 2 \cdot 16,7 = 33,4$——垄断价格高于边际成本，确认无效率。$\checkmark$

**来源。** [Yoshiwara — Modeling, Functions, and Graphs, 第 5 章, 练习 5.3.20](https://yoshiwarabooks.org/mfg/Chap4.html) ——开放许可。
</Exemplo>
