### 凹凸性

<Definicao titulo="凸函数（凹函数）">
$f: I \to \mathbb{R}$在$I$上是<strong>凸的</strong>，当且仅当对所有$x_1, x_2 \in I$和$t \in [0,1]$成立：
$$f(tx_1 + (1-t)x_2) \leq t\,f(x_1) + (1-t)\,f(x_2).$$
几何上：点$(x_1, f(x_1))$和$(x_2, f(x_2))$之间的弦段<strong>位于或在</strong>图像上方。
</Definicao>

> "函数$f$在区间$I$上向上凹，当且仅当对所有$x \in I$有$f''(x) \geq 0$。" — [OpenStax Calculus Vol. 1 §4.5](https://openstax.org/books/calculus-volume-1/pages/4-5-derivatives-and-the-shape-of-a-graph)

**通过二阶导数的判别准则：**若$f$在$I$上二阶可导：

- $f''(x) \geq 0$在$I$上 $\iff$ $f$凸（向上凹）。
- $f''(x) \leq 0$在$I$上 $\iff$ $f$凹（向下凹）。
- $f''(x) > 0$严格成立 $\Rightarrow$ 严格凸性。

### 拐点

<Definicao titulo="拐点">
如果$f$在$x_0$处连续，且$f''$在$x_0$处<strong>改变符号</strong>，则$x_0$是$f$的<strong>拐点</strong>。
</Definicao>

**注意：**$f''(x_0) = 0$是必要条件但非充分条件。经典反例：$f(x) = x^4$在$x=0$处$f''(0) = 0$，但$f'' \geq 0$在$0$的邻域内——没有符号改变，因此$0$不是拐点。

> "如果凹凸性在点$(x_0, f(x_0))$处改变，我们称其为拐点。此时$f''(x_0)$必须改变符号。" — [APEX Calculus §3.4](https://www.apexcalculus.com/downloads)

### 二阶导数检验法找极值

<Teorema titulo="二阶导数检验法">
设$f'(x_0) = 0$。则：
- $f''(x_0) > 0$ $\Rightarrow$ $x_0$是<strong>极小值点</strong>。
- $f''(x_0) < 0$ $\Rightarrow$ $x_0$是<strong>极大值点</strong>。
- $f''(x_0) = 0$ $\Rightarrow$ <strong>不确定</strong>（用高阶导数或$f'$的符号检验）。
</Teorema>

**极小值的证明：**若$f'(x_0) = 0$且$f''(x_0) > 0$，由$f''$的连续性存在一个邻域使$f''(x) > 0$，因此$f'$在该邻域上递增。因为$f'(x_0) = 0$，在$x_0$左边有$f' < 0$，右边有$f' > 0$——由一阶导数检验法，$x_0$是极小值点。 ∎

<Insight titulo="Jensen不等式">
$f$凸 $\Rightarrow$ $f\!\left(\frac{x_1 + x_2}{2}\right) \leq \frac{f(x_1) + f(x_2)}{2}$。更一般地：对随机变量$X$，$f(E[X]) \leq E[f(X)]$。是信息论、热力学和机器学习的基石。
</Insight>

</Porta>

<Porta nivel="5" titulo="给5岁孩子讲">

拿一个<strong>空碗</strong>倒扣过来：你得到一条从中间向下弯的曲线（像$\cap$）。现在拿正常放的碗：从中间向上弯的曲线（像$\cup$）。

- 正常的碗是<strong>向上凹</strong>——任何放进去的冰淇淋球都会滚向下方，到中心。
- 倒扣的碗是<strong>向下凹</strong>——任何东西都会滑出去。

<strong>拐点</strong>是曲线从一种碗变成另一种碗的那一刻——或反之。是那一瞬间曲线"翻了个身"。

</Porta>

<Porta nivel="10" titulo="给10岁孩子讲">

<strong>二阶导数</strong>$f''$是导数的导数——它测量<strong>斜率如何变化</strong>。

- 如果$f'' > 0$：斜率$f'$在<strong>增加</strong>。图像向上弯曲，像$\cup$。
- 如果$f'' < 0$：斜率$f'$在<strong>减少</strong>。图像向下弯曲，像$\cap$。

**用$f(x) = x^3$的例子：**

$f'(x) = 3x^2$，$f''(x) = 6x$。

- 当$x < 0$时：$f'' < 0$ —— 向下弯曲。
- 当$x > 0$时：$f'' > 0$ —— 向上弯曲。
- 在$x = 0$处：$f''$改变符号。**这是拐点！**

**为什么重要？**它决定了$f'(x) = 0$的点是极大值（向下弯曲=帽形）还是极小值（向上弯曲=碗形）。

</Porta>

<Porta nivel="15" titulo="给15岁少年讲">

凹凸性完成了$f'$的"故事"来描述图像的形状：

| $f'$的符号 | $f''$的符号 | 行为 |
|---|---|---|
| $+$ | $+$ | 递增且加速（$\cup$向上） |
| $+$ | $-$ | 递增且减速 |
| $-$ | $+$ | 递减且减速 |
| $-$ | $-$ | 递减且加速（$\cap$向下） |

### 二阶导数检验法找极值

如果$f'(x_0) = 0$：
- $f''(x_0) > 0$：**极小值**（碗形）。
- $f''(x_0) < 0$：**极大值**（帽形）。
- $f''(x_0) = 0$：**不确定** —— 对$f'$做符号检验。

### 拐点：符号改变，零不够

拐点是$f''$**改变符号**的地方。例子：$f(x) = e^{-x^2/2}$（高斯分布）。$f''(x) = (x^2-1)e^{-x^2/2}$。在$x = \pm 1$处符号改变。因此，对于$\sigma = 1$的正态分布，拐点在$\mu \pm \sigma$。

### 应用

- **经济学：**利润在$\pi'' < 0$处最大。$C(q)$的拐点=边际收益的变化。
- **物理学：**势能最小值$U$（其中$U'' > 0$）是稳定平衡。小振荡频率：$\omega = \sqrt{U''(x^*)/m}$。
- **统计学：**高斯分布的拐点定义曲线的"中间"。

</Porta>

<Porta nivel="25" titulo="给工程专业学生讲">

凹凸性是优化、机器学习和稳定性分析的核心概念。

### 全局凸性与优化

$f$在$I$上凸 $\Rightarrow$：
- 每个极小值都是**全局最小值**。
- 最小值点的集合是**凸的**。
- 梯度下降算法在温和条件下收敛到唯一最小值。

实际后果：在线性回归中，损失函数$L(\beta) = \|y - X\beta\|^2$是凸二次型（Hessian矩阵$H = 2X^TX$半正定）——因此$\nabla L = 0$给出唯一的全局解：$\hat\beta = (X^TX)^{-1}X^Ty$。

### 典型的凸函数

- $x^2$、$e^x$、$-\ln x$（在$(0,\infty)$）、$x\ln x$、$\max(0, x)$（ReLU）。
- 凸函数之和是凸的。凸函数的逐点最大是凸的。
- 如果$h$凸且递增，$g$凸，则$h(g(x))$凸。

### Sigmoid：非凸，在0处有拐点

$\sigma(x) = 1/(1 + e^{-x})$有$\sigma''(x) = \sigma(x)(1 - \sigma(x))(1 - 2\sigma(x))$。在$x = 0$处符号改变——拐点。带Sigmoid的神经网络在参数空间上是**非凸的**，这使全局优化不可行（这就是ReLU的吸引力，它保持分段凸性）。

### Jensen不等式——在机器学习中的应用

$f$凸 $\Rightarrow$ $E[f(X)] \geq f(E[X])$。用$f = -\ln$：$E[-\ln X] \geq -\ln E[X]$，熵的基础。用$f = -\ln$和$X$为概率分布：VAE中ELBO（变分下界）的推导。

### Hessian和优化景观

Hessian $H(x)$在临界点：正特征值=极小值，负特征值=极大值，混合特征值=鞍点。在深度神经网络中，临界点几乎全是**鞍点**，不是极小值——对SGD收敛的启示。

</Porta>

<Porta nivel="40" titulo="给资深专业人士讲">

凸性是现代优化的心脏，在几何、概率和统计物理中有深刻的分支。

### 凸分析（Rockafellar, 1970）

核心概念：
- **次微分** $\partial f(x)$：对非可微凸函数（如$|x|$）推广$\nabla f$。
- **Fenchel共轭：** $f^*(p) = \sup_x(p\cdot x - f(x))$。基本对偶性：$(f^*)^* = f$（在下半连续下）。
- **支撑函数** $\sigma_C(x) = \sup_{y \in C} \langle x, y\rangle$刻画凸集——线性规划的基础。

### 微分几何

Hessian定义二阶局部形状：符号（正定、非定、等）确定极值vs鞍点。在Riemann流形上，**截面曲率**推广$f''$：正=球面，负=双曲平面。Ricci曲率出现在广义相对论。

### 统计力学与相变

自由能$F(\beta) = -\ln Z(\beta)$在$\beta = 1/T$处是**凸的**——蕴含热容$C_V = k_B\beta^2\partial_\beta^2 \ln Z \geq 0$（第二定律）。$F(T)$的拐点标记二阶相变（Landau, 1937）。

### 凸优化理论

凸问题在多项式时间内可解（Khachiyan 1979——椭体方法；Karmarkar 1984——内点法）。层次：LP ⊂ QP ⊂ SOCP ⊂ SDP。库：CVXPY、MOSEK、Gurobi。

### 机器学习：损失景观与泛化

Keskar et al.（2017）证明"宽"极小值（Hessian特征值小）的泛化性比"尖"极小值好。直观：宽极小值对训练集扰动更鲁棒——对应$f'' \ll 1$在极小值附近。2024-2026年的活跃研究。

### 历史联系

Hadamard（1893）用$f''$做严格极值判别。Minkowski（1896）凸几何。Carathéodory、Fenchel、Moreau在20世纪巩固凸分析。Boyd & Vandenberghe（2004）用《凸优化》书让其在工程中成为规范（免费在[web.stanford.edu/~boyd/cvxbook](https://web.stanford.edu/~boyd/cvxbook/)）。

</Porta>

<Porta nivel="pratica" titulo="实际应用">

**5步菜谱：**

1. **计算$f''(x)$。**
2. **令其为零**找拐点候选。
3. **测试$f''$在各子区间的符号。** 符号改变 = 拐点。
4. **分类$f$的临界点** （$f' = 0$）：$f''$的符号确定极小值、极大值或不确定。
5. **做凹凸性表格**+画图。

### 标准表格

| 区间 | $f''$的符号 | 凹凸性 | 视觉行为 |
|---|---|---|---|
| $(-\infty, x_0)$ | $+$ | 向上 | $\cup$ |
| $(x_0, +\infty)$ | $-$ | 向下 | $\cap$ |

在$x_0$处符号改变确认拐点。

### Python/SymPy验证

```python
import sympy as sp
x = sp.symbols('x')
f = x**3 - 3*x
f2 = sp.diff(f, x, 2)
inflexoes = sp.solve(f2, x)  # 候选
print("f'' =", f2, "| 候选:", inflexoes)
# 验证每个候选周围的符号
```

### 应用：递减边际成本账户

有递减收益的生产成本：$C(q) = q^3 - 6q^2 + 15q + 100$。$C'' = 6q - 12 = 0$在$q = 2$。当$q < 2$：$C'' < 0$（边际成本递减，规模效应）。当$q > 2$：$C'' > 0$（边际成本递增，产能压力）。$q = 2$的拐点=$\textbf{生产制度改变}$的点。

</Porta>

## 解答的例题

<Exemplo titulo="f(x) = x^3 - 3x的凹凸性和拐点（基础）" numero="1">

**问题。** 对于$f(x) = x^3 - 3x$，确定凹凸性的区间和拐点。

**策略。** 计算$f''$，确定正负所在，在零点验证符号改变。

**解。**

1. **导数：** $f'(x) = 3x^2 - 3$，$f''(x) = 6x$。
2. **$f''$的零点：** $6x = 0 \Rightarrow x = 0$。
3. **符号：** 当$x < 0$时$f''(x) < 0$（向下凹）；当$x > 0$时$f''(x) > 0$（向上凹）。
4. **拐点：** $f''$在$x = 0$处改变符号。因此$(0, f(0)) = (0, 0)$是拐点。

**验证。** 在图像中：$f(-2) = -8 + 6 = -2$；$f(0) = 0$；$f(2) = 8 - 6 = 2$。曲线从$-2$到$0$向上凹向下，然后从$0$到$2$向上凹向上——一致。 ✓

**来源。** [APEX Calculus §3.4, Example 3.4.1](https://www.apexcalculus.com/downloads) — CC-BY-NC。
</Exemplo>

<Exemplo titulo="f(x) = x^4 - 4x^2的二阶导数检验极值（中级）" numero="2">

**问题。** 用二阶导数检验法分类$f(x) = x^4 - 4x^2$的临界点。

**策略。** 通过$f' = 0$找临界点，计算每一点的$f''$并应用判别准则。

**解。**

1. **$f'(x) = 4x^3 - 8x = 4x(x^2 - 2) = 0 \Rightarrow x = 0,\, x = \pm\sqrt{2}$。**
2. **$f''(x) = 12x^2 - 8$。**
3. **求值：**
   - $f''(0) = -8 < 0$ $\Rightarrow$ **极大值** 在$x = 0$。$f(0) = 0$。
   - $f''(\sqrt{2}) = 24 - 8 = 16 > 0$ $\Rightarrow$ **极小值** 在$x = \sqrt{2}$。$f(\sqrt{2}) = 4 - 8 = -4$。
   - $f''(-\sqrt{2}) = 16 > 0$ $\Rightarrow$ **极小值** 在$x = -\sqrt{2}$。$f(-\sqrt{2}) = -4$。

**验证。** 因为$f(x) \to +\infty$当$x \to \pm\infty$，在$\pm\sqrt{2}$的极小值是全局的，在$0$的极大值是局部的（但非全局）。 ✓

**来源。** [OpenStax Calculus Vol. 1 §4.5, Example 4.38](https://openstax.org/books/calculus-volume-1/pages/4-5-derivatives-and-the-shape-of-a-graph) — CC-BY-NC-SA。
</Exemplo>

<Exemplo titulo="高斯分布的拐点（中级）" numero="3">

**问题。** 找$f(x) = e^{-x^2/2}$（正态分布的核心）的拐点。

**策略。** 求两次导数，令$f'' = 0$并验证符号改变。

**解。**

1. **$f'(x) = -x\,e^{-x^2/2}$。**
2. **$f''(x) = -e^{-x^2/2} + x^2 e^{-x^2/2} = (x^2 - 1)e^{-x^2/2}$。**
3. **$f''$的零点：** $x^2 - 1 = 0 \Rightarrow x = \pm 1$。
4. **符号：**
   - $|x| > 1$：$x^2 - 1 > 0 \Rightarrow f'' > 0$（向上凹）。
   - $|x| < 1$：$x^2 - 1 < 0 \Rightarrow f'' < 0$（向下凹）。
5. **拐点：** 在$x = \pm 1$，$f''$改变符号。点：$(\pm 1, e^{-1/2}) = (\pm 1, \approx 0.607)$。

**验证。** 对于$\mathcal{N}(\mu, \sigma^2)$，拐点在$\mu \pm \sigma$。这里$\mu = 0$，$\sigma = 1$——一致。 ✓

**来源。** [Active Calculus §3.1, Activity 3.1.3](https://activecalculus.org/single/sec-3-1-tests.html) — CC-BY-NC-SA。
</Exemplo>

<Exemplo titulo="情况不确定：$f'' = 0$在临界点不是拐点（高级）" numero="4">

**问题。** 对于$f(x) = x^4$，验证$f''(0) = 0$但$x = 0$是极小值（不是拐点）。

**策略。** 表明$f''$在$x = 0$处不改变符号。

**解。**

1. **$f'(x) = 4x^3 = 0 \Rightarrow x = 0$** （临界点）。
2. **$f''(x) = 12x^2 \geq 0$对所有$x$。** 特别是$f''(0) = 0$——检验不确定。
3. **但$f''(x) \geq 0$在$0$的邻域**：不改变符号。
4. **结论：** $x = 0$**不是**拐点。是全局极小值（$f(x) = x^4 \geq 0$对所有$x$，等号仅在$0$）。
5. **通过$f'$符号检验确认：** $f'(x) = 4x^3 < 0$当$x < 0$，$f'(x) > 0$当$x > 0$——极小值确认。

**验证。** $x^4$的图像是"压扁"的抛物线，底部在$0$——视觉上是极小值。 ✓

**来源。** [APEX Calculus §3.4, Note after Example 3.4.2](https://www.apexcalculus.com/downloads) — CC-BY-NC。
</Exemplo>

<Exemplo titulo="有递减收益的成本——经济应用的拐点（建模）" numero="5">

**问题。** 公司的生产成本$C(q) = q^3 - 6q^2 + 15q + 100$（单位：雷亚尔）。找拐点并经济学解释。

**策略。** 计算$C''$，找拐点，分析边际成本$MC = C'$的行为。

**解。**

1. **$C'(q) = 3q^2 - 12q + 15 = MC(q)$** （边际成本）。
2. **$C''(q) = 6q - 12$。**
3. **拐点：** $C''(q) = 0 \Rightarrow q = 2$。
4. **$C''$的符号：** 当$q < 2$，$C'' < 0$（边际成本递减——规模效应）。当$q > 2$，$C'' > 0$（边际成本递增——产能压力）。
5. **拐点：** $C(2) = 8 - 24 + 30 + 100 = 114$。点$(2, 114)$。

**验证。** $MC(0) = 15$，$MC(2) = 12 - 24 + 15 = 3$，$MC(4) = 48 - 48 + 15 = 15$。$MC$在$q = 2$的极小值——与$C$的拐点一致。 ✓

</Exemplo>
