### 基本定义

<Definicao titulo="位置、速度、加速度、急动度">
设$s: I \subset \mathbb{R} \to \mathbb{R}$是关于时间$t$的位置函数，其中$s$可导。

$$v(t) = \frac{ds}{dt} = s'(t), \qquad a(t) = \frac{dv}{dt} = s''(t), \qquad j(t) = \frac{da}{dt} = s'''(t).$$

- **速率**：$|v(t)|$（非负标量；当$v < 0$时不同于速度）。
- **位移** 在 $[t_1, t_2]$ 上：$\Delta s = s(t_2) - s(t_1)$（可以为负）。
- **行程距离**：$\int_{t_1}^{t_2} |v(t)|\, dt$（总是非负）。
</Definicao>

> "物体的瞬时速度是该物体在越来越短的时间间隔内平均速度的极限。" — [Active Calculus §1.1](https://activecalculus.org/single/sec-1-1-vel.html)

> "位置函数$s(t)$给出物体在时间$t$时沿数轴的位置。速度函数$v(t) = s'(t)$给出物体在时间$t$时的速度。" — [OpenStax Calculus Vol.1 §3.4](https://openstax.org/books/calculus-volume-1/pages/3-4-derivatives-as-rates-of-change)

### 标准运动情况

| 运动 | $s(t)$ | $v(t)$ | $a(t)$ | 备注 |
|---|---|---|---|---|
| 静止 | $s_0$ | $0$ | $0$ | 固定点 |
| 匀速 (MRU) | $s_0 + v_0 t$ | $v_0$ | $0$ | $s \times t$图上是直线 |
| 匀加速 (MUV) | $s_0 + v_0 t + \tfrac{1}{2}a_0 t^2$ | $v_0 + a_0 t$ | $a_0$ | 抛物线 |
| 简谐振动 (MHS) | $A\cos(\omega t + \phi)$ | $-A\omega\sin(\omega t + \phi)$ | $-A\omega^2\cos(\omega t + \phi)$ | $a = -\omega^2 s$ |
| 空气阻力 | 通过常微分方程分析 | $v_\infty(1-e^{-kt/m})$ | 衰减至0 | 终端速度 |

### 托里切利定理（通过微积分推导）

<Teorema titulo="托里切利方程">
对于匀加速度$a_0$的MUV，位移$\Delta s$和速度$v_0, v_f$满足：
$$v_f^2 = v_0^2 + 2a_0\,\Delta s.$$
**证明：** $v(t) = v_0 + a_0 t$，$s(t) = s_0 + v_0 t + \tfrac{1}{2}a_0 t^2$。从$t = (v - v_0)/a_0$代入$\Delta s$：
$$\Delta s = v_0 \cdot \frac{v_f - v_0}{a_0} + \frac{1}{2}a_0\left(\frac{v_f - v_0}{a_0}\right)^2 = \frac{v_f^2 - v_0^2}{2a_0}. \quad \blacksquare$$
</Teorema>

### 简谐运动 (MHS)

$x(t) = A\cos(\omega t + \phi)$满足常微分方程$\ddot x + \omega^2 x = 0$。

- 周期：$T = 2\pi/\omega$。
- 频率：$f = 1/T$。
- 对于弹簧：$\omega = \sqrt{k/m}$；对于摆（小角度）：$\omega = \sqrt{g/L}$。

<Insight>
在MHS中，加速度总是**与位移成正比且相反**：$a = -\omega^2 x$。加速度的大小在极端位置最大（其中$|x| = A$），在平衡点为零。速度的大小在平衡点最大，在极端位置为零——恰好相反。
</Insight>

### $\mathbb{R}^n$中的运动学

对于$\vec{r}(t) = (x(t), y(t), z(t)) \in \mathbb{R}^3$：

$$\vec{v}(t) = \dot{\vec{r}}(t), \qquad \vec{a}(t) = \ddot{\vec{r}}(t), \qquad |\vec{v}| = \text{速率}.$$

每个分量独立求导。曲线轨迹中的向心加速度：$a_c = v^2/\rho$（其中$\rho$是曲率半径）。

</Porta>

<Porta nivel="5" titulo="给5岁小孩">

想象玩具车在直轨道上。

**车在哪里？** 这就是**位置**——尺子上的哪个数字。

**它走得有多快？** 这是**速度**——每秒走多少厘米。

**它是在加速还是减速？** 这是**加速度**——速度在增加还是减少？

三件事联系在一起：速度是位置每秒如何变化。加速度是速度每秒如何变化。这是一个阶梯：位置→速度→加速度。

</Porta>

<Porta nivel="10" titulo="给10岁小孩">

在物理中，时间流逝，物体移动。**运动学**用数学研究这个。

- **位置**$s(t)$：物体在每一瞬间的位置。
- **速度**$v(t) = s'(t)$：位置变化有多快。可以是负数（向后走）。
- **加速度**$a(t) = v'(t)$：速度变化有多快。正数=加速；负数=减速。

**例子**：石头从建筑物掉下来。$s(t) = 100 - 5t^2$米。
- $v(t) = -10t$（每秒，它向下快10米/秒）。
- $a(t) = -10$米/秒²（常数：这就是重力！）。
- 砸中地面当$s = 0 \Rightarrow t = \sqrt{20} \approx 4.5$秒。

导数将位置变换为速度，速度变为加速度。这是同一操作应用两次。

</Porta>

<Porta nivel="15" titulo="给15岁青少年">

运动学是**导数在物理中最直接的应用**。同样的微积分公式描述汽车、行星、弹簧。

### 三个基本函数

| 量 | 定义 | 解释 |
|---|---|---|
| 位置$s(t)$ | 给定 | 物体在哪里 |
| 速度$v(t) = s'(t)$ | 一阶导数 | 多快及方向 |
| 加速度$a(t) = s''(t)$ | 二阶导数 | 速度的变化 |

### 标准运动

**MRU**（匀速直线运动）：$a = 0$，$v$常数，$s(t) = s_0 + v_0 t$（直线）。

**MUV**（匀加速，自由落体，斜面）：$a$常数，$s(t) = s_0 + v_0 t + \tfrac{1}{2}at^2$（抛物线）。

托里切利：$v^2 = v_0^2 + 2a\Delta s$——当不需要时间时消除时间。

**MHS**（弹簧、摆）：$s(t) = A\cos(\omega t + \phi)$。加速度是$a = -\omega^2 s$——总是指向平衡点。周期$T = 2\pi/\omega$。

### 常见注意事项

- 速度**为零**不意味着加速度为零（球在最高点$v = 0$但$a = -g$）。
- **位移**（$\int v\, dt$）可以为零，即使行程距离（$\int |v|\, dt > 0$）为正。
- 符号表示方向；速率是速度的绝对值。

</Porta>

<Porta nivel="25" titulo="给工程学生">

运动学是古典力学、控制、机器人和数值模拟的基础。

### 向量表述

$\vec{r}(t) \in \mathbb{R}^3$：$\vec{v} = \dot{\vec{r}}$，$\vec{a} = \ddot{\vec{r}}$，$\vec{j} = \dddot{\vec{r}}$。

在Frenet-Serret坐标中：$\vec{a} = \dot{v}\,\hat{T} + (v^2/\rho)\,\hat{N}$——切向加速度和向心加速度。

### 匀速圆周运动

$\vec{r} = R(\cos\omega t, \sin\omega t)$：$\vec{v} = R\omega(-\sin\omega t, \cos\omega t)$，$|\vec{v}| = R\omega$。

$\vec{a} = -\omega^2\vec{r}$——向心加速度，总是指向中心，大小$a_c = R\omega^2 = v^2/R$。

### 常微分方程和相空间

带一般力的运动学：$m\ddot{s} = F(t, s, \dot{s})$——二阶常微分方程。

改写为系统：$\dot{s} = v$，$\dot{v} = F/m$。$(s, v)$空间就是**相空间**。相空间中的轨迹不会相交（常微分方程解的唯一性）。

### 空气阻力（带阻尼下落）

$m\dot{v} = -mg - bv$（线性阻力）。解：$v(t) = v_\infty + (v_0 - v_\infty)e^{-bt/m}$，其中$v_\infty = -mg/b$是**终端速度**。对于二次阻力（$bv^2$）：没有简单闭形式——需要数值积分。

### 急动度和工程应用

有限急动度应用于：电梯（舒适）、ABS（防抱死）、机械臂（机械磨损）、高铁轨道。现代控制器指定具有最大急动度的加速曲线。

### 数值近似（有限差分）

$v_n \approx (s_{n+1} - s_n)/\Delta t$，$a_n \approx (v_{n+1} - v_n)/\Delta t$。Verlet方法：$s_{n+1} = 2s_n - s_{n-1} + a_n (\Delta t)^2$——对保守系统稳定。

</Porta>

<Porta nivel="40" titulo="给资深专业人士">

运动学是导数从形式主义变成物理量的地方。

### 历史视角

**伽利略（1638）**在《谈话录》中通过实验推导出自由落体$s \propto t^2$——没有微积分，使用几何比例。**牛顿（1687）**在《自然哲学的数学原理》中正式确立$F = ma$并发明微积分来描述它。**拉格朗日（1788）**和**哈密顿（1835）**用变分法重新表述：轨迹是$\int L\, dt$的极值。

### 狭义相对论

对于$v \to c$：位置和时间混合。本心速度$u^\mu = dx^\mu/d\tau$（四矢量）。四动量守恒$p^\mu = mu^\mu$推广$F = ma$。"导数"变为具有Christoffel联络的协变导数。

### 量子力学

位置算子$\hat{X}$和动量算子$\hat{P}$满足$[\hat{X}, \hat{P}] = i\hbar$。海森堡方程：$d\hat{A}/dt = \frac{i}{\hbar}[\hat{H}, \hat{A}]$——哈密顿力学泊松括号$\{A, H\}_\text{Poisson}$的量子类比。

### 流体力学

物质导数$D/Dt = \partial_t + \vec{v}\cdot\nabla$捕获随流体运动的粒子的加速度。Navier-Stokes：$\rho D\vec{v}/Dt = -\nabla p + \mu\nabla^2\vec{v} + \rho\vec{g}$。

### 机器人和最优控制

最优轨迹问题：在位置和速度边界条件的约束下，最小化$\int_0^T j(t)^2\, dt$——得到五次多项式（*最小急动度轨迹*）。用于工业操纵臂、自主机器人和手术机械臂。

### 诺贝尔奖和导数

[1921年物理学诺贝尔奖](https://www.nobelprize.org/prizes/physics/1921/)授予爱因斯坦光电效应，但狭义相对论（1905）——将导数重新定义在时空中——已经完成。所有相对论性运动学都建立在Minkowski时空的微分结构之上。

</Porta>

<Porta nivel="pratica" titulo="实用应用">

**6步配方：**

1. **识别**$s(t)$——直接给出，或作为$v$的积分。
2. **求导**：$v = s'$，$a = s'' = v'$。
3. **物体静止**：求解$v(t) = 0$得$t$。
4. **高度/位置最大**：当$v = 0$且$a < 0$。
5. **距离（不是位移）**：$\int |v|\, dt$——当$v$改变符号时改变符号。
6. **MUV无时间**：托里切利$v^2 = v_0^2 + 2a\Delta s$。

### 注意事项

- **速度为零$\neq$加速度为零**：球在顶部$v = 0$和$a = -10$米/秒²。
- **位移vs距离**：来回5公里的汽车位移为零但距离10公里。
- **$a$的符号**：与$v$的符号相反意味着减速。

### 巴西真实数据

**ENEM 2023——物理**：汽车以$v_0 = 20$米/秒速度制动，加速度$a = -4$米/秒²。制动距离：
$v^2 = v_0^2 + 2a\Delta s \Rightarrow 0 = 400 - 8\Delta s \Rightarrow \Delta s = 50$米。

**0-100测试**：Fiat Pulse（2023）加速0-100 km/h用10.5秒。
$a_{\text{avg}} = \Delta v / \Delta t = (100/3.6)/10.5 \approx 2.6$米/秒²。

### 快速验证（Python/SymPy）

```python
import sympy as sp
t = sp.symbols('t', positive=True)
s = 100 - 5*t**2
v, a = sp.diff(s, t), sp.diff(s, t, 2)
t_chao = sp.solve(s, t)[0]
print(f"v(t)={v}, a(t)={a}, t_chao={t_chao}, v_chao={v.subs(t, t_chao)}")
```

## 解答的例子

<Exemplo titulo="三次位置：速度、停止和行程距离">

**问题。** 物体位置为$s(t) = t^3 - 6t^2 + 9t$米，$t \geq 0$。(a)求$v(t)$和$a(t)$。(b)物体何时停止？(c)在$[0, 4]$中行程距离是多少？

**策略。** 对$s$求导得$v$和$a$。$v$的零点给出停止时刻。对于距离，积分$|v|$——在每个零点处改变符号。

**解。**

(a) $v(t) = 3t^2 - 12t + 9 = 3(t-1)(t-3)$。$a(t) = 6t - 12$。

(b) $v = 0 \Rightarrow t = 1$或$t = 3$。

(c) $v > 0$在$[0,1)$；$v < 0$在$(1,3)$；$v > 0$在$(3,4]$。

$d = |s(1)-s(0)| + |s(3)-s(1)| + |s(4)-s(3)|$

$= |4 - 0| + |0 - 4| + |4 - 0| = 4 + 4 + 4 = 12$米。

总位移：$s(4) - s(0) = 4$米（远小于距离！）。

**验证。** $v(1) = 3(0)(-2) = 0$ ✓；$v(3) = 3(2)(0) = 0$ ✓；$a(1) = -6 < 0$（$t=1$时减速）✓。

**来源。** [Active Calculus §1.1, Exercise 1.1.4](https://activecalculus.org/single/sec-1-1-vel.html) — Boelkins · CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="带初始速度的自由落体：下落时间和撞击速度">

**问题。** 石头从高度$h = 80$米的塔顶以初速度$v_0 = 10$米/秒向下抛出。采用$g = 10$米/秒²，原点在地面（正向上），求：(a)$s(t)$，(b)撞击时刻$t^*$，(c)撞击时的速度。

**策略。** 用初始条件$s(0) = 80$、$v(0) = -10$（负号=向下）组成$s(t)$。解$s(t^*) = 0$。

**解。**

$s(t) = 80 - 10t - 5t^2$。

$s(t^*) = 0 \Rightarrow 5t^2 + 10t - 80 = 0 \Rightarrow t^2 + 2t - 16 = 0$。

$t^* = \dfrac{-2 + \sqrt{4 + 64}}{2} = \dfrac{-2 + \sqrt{68}}{2} \approx \dfrac{-2 + 8.25}{2} \approx 3.12$秒。

$v(t^*) = -10 - 10(3.12) \approx -41.2$米/秒。速率：$\approx 41.2$米/秒$\approx 148$千米/时。

**验证。** $s(3.12) = 80 - 31.2 - 48.7 \approx 0.1 \approx 0$ ✓。托里切利：$v^2 = 100 + 2(10)(80) = 1700 \Rightarrow v \approx 41.2$米/秒✓。

<Exemplo titulo="简谐运动：振幅、周期和能量">

**问题。** $m = 2$千克的质量连接到弹簧$k = 50$牛/米，位移$A = 0.2$米并从静止释放。(a)写出$x(t)$。(b)最大速度。(c)证明机械能$E = \frac{1}{2}mv^2 + \frac{1}{2}kx^2$是常数。

**策略。** $\omega = \sqrt{k/m}$。以$x(0) = A$和$v(0) = 0$：相位$\phi = 0$。能量：代入$x$和$v$并用三角恒等式简化。

**解。**

$\omega = \sqrt{50/2} = 5$弧度/秒。$T = 2\pi/5 \approx 1.26$秒。

$x(t) = 0.2\cos(5t)$。

$v(t) = -0.2 \cdot 5 \sin(5t) = -\sin(5t)$米/秒。

最大速度：$|v|_{\max} = A\omega = 0.2 \cdot 5 = 1$米/秒（在平衡点）。

能量：
$$E = \tfrac{1}{2}(2)(-\sin 5t)^2 + \tfrac{1}{2}(50)(0.2\cos 5t)^2 = \sin^2(5t) + \cos^2(5t) = 1 \text{ J（常数）。✓}$$

**验证。** 在$t = 0$：$x = 0.2$，$v = 0$，$E = 0 + \frac{1}{2}(50)(0.04) = 1$焦耳✓。

**来源。** [Active Calculus §1.5, Exercise 1.5.3](https://activecalculus.org/single/sec-1-5-units.html) — Boelkins · CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="空气阻力：终端速度和解析解">

**问题。** $m = 1$千克的粒子从静止下落，重力加速度$g = 10$米/秒²，线性阻力$F_{\text{arr}} = bv$，$b = 0.5$千克/秒。(a)写出并解$v(t)$的常微分方程。(b)终端速度。(c)$v$达到$v_\infty$的90%需要多少秒？

**策略。** 一阶可分离常微分方程：$m\dot{v} = mg - bv$。分离变量。

**解。**

$\dot{v} = 10 - 0.5v$。解：$v(t) = v_\infty(1 - e^{-bt/m}$，其中$v_\infty = mg/b = 10/0.5 = 20$米/秒。

$v(t) = 20(1 - e^{-0.5t})$。

$v_\infty$的90%：$20(1 - e^{-0.5 t_{90}}) = 18 \Rightarrow e^{-0.5 t_{90}} = 0.1 \Rightarrow t_{90} = 2\ln(10)/0.5 \approx 4.6$秒。

**验证。** $v(0) = 0$ ✓。$\lim_{t\to\infty} v(t) = 20$米/秒✓。$v'(0) = 20 \cdot 0.5 = 10$米/秒² = $g$ ✓。

**来源。** [APEX Calculus §2.4, Example 2.4.4](https://www.apexcalculus.com/) — Hartman et al. · CC-BY-NC。

</Exemplo>

<Exemplo titulo="圆周运动：通过导数的向心加速度">

**问题。** 一点以常角频率$\omega = 2$弧度/秒围绕半径$R = 3$米的圆周运动。位置为$\vec{r}(t) = 3(\cos 2t, \sin 2t)$。计算：(a)$\vec{v}(t)$和$|\vec{v}|$，(b)$\vec{a}(t)$并证明$\vec{a} = -\omega^2\vec{r}$。

**策略。** 独立求导每个分量。识别$\vec{a}$的方向。

**解。**

$\vec{v}(t) = 3(-2\sin 2t, 2\cos 2t) = (-6\sin 2t, 6\cos 2t)$。

$|\vec{v}| = 6$米/秒（常数）= $R\omega = 3 \cdot 2$ ✓。

由于$\omega^2 = 4$：$\vec{a} = -\omega^2\vec{r}$。大小：$|\vec{a}| = 12 = R\omega^2 = 3 \cdot 4$ ✓。

**验证。** $\vec{v} \cdot \vec{r} = 3 \cdot(-6\sin 2t\cos 2t + 6\cos 2t\sin 2t) = 0$——在MCU中速度垂直于位置✓。
