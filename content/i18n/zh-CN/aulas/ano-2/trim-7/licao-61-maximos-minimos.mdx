### 局部极值和绝对极值

<Definicao titulo="局部最大值和最小值">

设 <Eq>{`f`}</Eq> 定义在定义域 <Eq>{`D`}</Eq> 上，<Eq>{`c \\in D`}</Eq>。

- <Eq>{`c`}</Eq> 是 <Eq>{`f`}</Eq> 的**局部最大值点**，若存在 <Eq>{`\\delta > 0`}</Eq> 使得对所有 <Eq>{`x \\in D`}</Eq> 且 <Eq>{`|x - c| < \\delta`}</Eq>，有 <Eq>{`f(c) \\geq f(x)`}</Eq>。
- <Eq>{`c`}</Eq> 是 <Eq>{`f`}</Eq> 的**局部最小值点**，若存在 <Eq>{`\\delta > 0`}</Eq> 使得对所有 <Eq>{`x \\in D`}</Eq> 且 <Eq>{`|x - c| < \\delta`}</Eq>，有 <Eq>{`f(c) \\leq f(x)`}</Eq>。
- **绝对极值**（全局）：对**所有** <Eq>{`x \\in D`}</Eq>，<Eq>{`f(c) \\geq f(x)`}</Eq>（或 <Eq>{`\\leq`}</Eq>）。

</Definicao>

<Definicao titulo="临界点">

<Eq>{`c`}</Eq> 是 <Eq>{`f`}</Eq> 的**临界点**，若：
1. <Eq>{`c`}</Eq> 在定义域的内部，**且**
2. <Eq>{`f'(c) = 0`}</Eq> 或 <Eq>{`f'(c)`}</Eq> 不存在。

</Definicao>

> "若 f 在 c 处有局部最大值或最小值，则 c 是 f 的临界点。" — [Active Calculus §3.1](https://activecalculus.org/single/sec-3-1-tests.html)

<Teorema titulo="费马定理">

若 <Eq>{`f`}</Eq> 在 <Eq>{`c`}</Eq> 处有局部极值（<Eq>{`c`}</Eq> 在定义域内部）且 <Eq>{`f`}</Eq> 在 <Eq>{`c`}</Eq> 处可导，则 <Eq display>{`f'(c) = 0.`}</Eq>

**注意——逆命题为假。** <Eq>{`f'(c) = 0`}</Eq> 不意味着有极值：函数 <Eq>{`f(x) = x^3`}</Eq> 在 <Eq>{`x = 0`}</Eq> 时有 <Eq>{`f'(0) = 0`}</Eq>，但 <Eq>{`c = 0`}</Eq> 是拐点，不是极值点。

</Teorema>

<Insight>

费马定理说：每个局部极值点（内部且可导）都是临界点。但不是每个临界点都是极值点。临界点是**候选点**——下面的测试来判定。

</Insight>

### 第一导数测试

<Definicao titulo="符号变化判别法">

设 <Eq>{`c`}</Eq> 是 <Eq>{`f`}</Eq> 连续的临界点。当 <Eq>{`x`}</Eq> 在 <Eq>{`c`}</Eq> 附近时：

- <Eq>{`f'`}</Eq> 在 <Eq>{`c`}</Eq> 处从 <Eq>{`+`}</Eq> 变为 <Eq>{`-`}</Eq> → **局部最大值**。
- <Eq>{`f'`}</Eq> 在 <Eq>{`c`}</Eq> 处从 <Eq>{`-`}</Eq> 变为 <Eq>{`+`}</Eq> → **局部最小值**。
- <Eq>{`f'`}</Eq> 在 <Eq>{`c`}</Eq> 处不变号 → **既非最大值也非最小值**（拐点）。

</Definicao>

### 第二导数测试

<Definicao titulo="凹凸性判别法">

设 <Eq>{`c`}</Eq> 是满足 <Eq>{`f'(c) = 0`}</Eq> 且 <Eq>{`f''(c)`}</Eq> 存在的临界点：

- <Eq>{`f''(c) > 0`}</Eq> → **局部最小值**（抛物线开口向上）。
- <Eq>{`f''(c) < 0`}</Eq> → **局部最大值**（抛物线开口向下）。
- <Eq>{`f''(c) = 0`}</Eq> → **不确定**（使用第一导数测试）。

</Definicao>

> "当第二导数测试不确定时，我们诉诸第一导数测试。" — [OpenStax Calculus Vol. 1, §4.5](https://openstax.org/books/calculus-volume-1/pages/4-5-derivatives-and-the-shape-of-a-graph)

### 极值的Weierstrass定理（极值定理）

<Teorema titulo="闭区间上的绝对极值">

若 <Eq>{`f`}</Eq> 在 <Eq>{`[a, b]`}</Eq> 上连续，则 <Eq>{`f`}</Eq> 在 <Eq>{`[a, b]`}</Eq> 的某点达到其绝对最大值和绝对最小值。

</Teorema>

### [a, b] 上绝对极值的算法

<Definicao titulo="闭端点法">

1. 找出 <Eq>{`f`}</Eq> 在内部 <Eq>{`(a, b)`}</Eq> 的所有临界点。
2. 计算 <Eq>{`f`}</Eq> 在每个临界点和端点 <Eq>{`a`}</Eq>、<Eq>{`b`}</Eq> 处的值。
3. **最大值**是绝对最大值；**最小值**是绝对最小值。

</Definicao>

<Porta nivel="5" titulo="对于5岁儿童">

想象一个**过山车**。有地方是**山顶**（周围都是最高点），有地方是**山谷**（周围都是最低点）。

在山顶，如果你向两边看，你会看到周围都更低。在山谷底部，周围都更高。

特殊的技巧：**当你恰好在山顶或山谷时，轨道是完全平的**——没有任何倾斜。这帮助我们找到这些特殊的地方！

</Porta>

<Porta nivel="10" titulo="对于10岁儿童">

当你绘制函数的图形时，它上升和下降。最高点是**最大值**，最低点是**最小值**。

**怎么找？** 在山丘的顶部或山谷的底部，图形的斜率是**零**——切线是水平的。所以：

1. 计算 <Eq>{`f'(x)`}</Eq>。
2. 求解 <Eq>{`f'(x) = 0`}</Eq>。
3. 看函数是否在前面上升、后面下降（最大值），还是前面下降、后面上升（最小值）。

例子：<Eq>{`f(x) = x^2`}</Eq>。导数：<Eq>{`f'(x) = 2x`}</Eq>。令其为零：<Eq>{`x = 0`}</Eq>。因为 <Eq>{`f'`}</Eq> 在 <Eq>{`x = 0`}</Eq> 处从负变为正，这是一个**最小值**——事实上，<Eq>{`x^2`}</Eq> 在 <Eq>{`x = 0`}</Eq> 处有其最小值。

</Porta>

<Porta nivel="15" titulo="对于高中学生">

**核心问题：** 给定一个图，峰值和谷值在哪里？

### 逐步过程

1. **求导：** 计算 <Eq>{`f'(x)`}</Eq>。
2. **临界点：** 求解 <Eq>{`f'(x) = 0`}</Eq> 并标记 <Eq>{`f'`}</Eq> 不存在的地方。
3. **用第一测试分类：** 制作 <Eq>{`f'`}</Eq> 符号的表格。
   - <Eq>{`(+)`}</Eq> 之前，<Eq>{`(-)`}</Eq> 之后 → 局部最大值。
   - <Eq>{`(-)`}</Eq> 之前，<Eq>{`(+)`}</Eq> 之后 → 局部最小值。
4. （快速替代）**第二测试：** 在临界点计算 <Eq>{`f''(c)`}</Eq>。
   - <Eq>{`f''(c) < 0`}</Eq> → 最大值。<Eq>{`f''(c) > 0`}</Eq> → 最小值。<Eq>{`f''(c) = 0`}</Eq> → 使用第一测试。

**在** <Eq>{`[a, b]`}</Eq> **上的绝对极值：** 在临界点和端点计算 <Eq>{`f`}</Eq>。最大值获胜；最小值获胜。

**注意：** <Eq>{`f'(c) = 0`}</Eq> **不保证**极值。在 <Eq>{`f(x) = x^3`}</Eq> 中，有 <Eq>{`f'(0) = 0`}</Eq> 但 <Eq>{`x = 0`}</Eq> 是拐点——函数在那里不改变单调性。

</Porta>

<Porta nivel="25" titulo="对于工程学生">

### 正式基础

**费马定理**保证了可导的内部局部极值是临界点。逆命题不成立：<Eq>{`x^3`}</Eq> 表明 <Eq>{`f'(c) = 0`}</Eq> 可能发生在拐点处，没有单调性的变化。

**极值定理**（Weierstrass）保证了当 <Eq>{`f`}</Eq> 在 <Eq>{`[a, b]`}</Eq> 上连续时绝对极值的存在——但不提供位置。绝对极值算法：

1. 内部临界点（其中 <Eq>{`f' = 0`}</Eq> 或不存在）。
2. 端点 <Eq>{`a, b`}</Eq>。
3. 在所有点计算 <Eq>{`f`}</Eq>。绝对最大值和最小值是该集合的极值。

### 测试

**第一导数：** 分析 <Eq>{`f'`}</Eq> 在 <Eq>{`c`}</Eq> 周围的符号变化。更通用——即使 <Eq>{`f''(c)`}</Eq> 不存在或为零时也有效。

**第二导数：** 在 <Eq>{`c`}</Eq> 处，其中 <Eq>{`f'(c) = 0`}</Eq>：若 <Eq>{`f''(c) > 0`}</Eq>，函数有正曲率（向上凹）→ 局部最小值。若 <Eq>{`f''(c) < 0`}</Eq>，向下凹 → 局部最大值。情况 <Eq>{`f''(c) = 0`}</Eq> 不确定：可能是拐点（<Eq>{`x^3`}</Eq>）、最小值（<Eq>{`x^4`}</Eq>）或最大值（<Eq>{`-x^4`}</Eq>）。

**与变分法的联系：** 欧拉-拉格朗日条件是泛函优化中 <Eq>{`f'(c) = 0`}</Eq> 的推广，是分析力学和最优控制的支柱。

</Porta>

<Porta nivel="40" titulo="对于资深专业人士">

寻找极值的问题与微积分本身一样古老。费马在牛顿和莱布尼茨正式化微积分的两十年前，就已经使用"适配法"（adequality）来寻找最大值和最小值——用 <Eq>{`x + e`}</Eq> 替换 <Eq>{`x`}</Eq>，等于原始值，然后让 <Eq>{`e \\to 0`}</Eq>。这是导数概念存在之前对导数的直觉。

极值定理由Weierstrass在19世纪正式化，要求实数的完备性——一个性质，Cantor直到几十年后才公理化。没有完备性，有孔洞的连续统可能有一个从不达到其上确界的连续函数。

在应用优化中：工程师、经济学家和数据科学家使用推广——约束的拉格朗日乘数法、非线性规划的KKT条件（Karush-Kuhn-Tucker）以及高维梯度为零。这堂课的直觉——"候选点是梯度消失的地方"——是通用的。高维中的挑战是区分最大值、最小值和鞍点（其中 <Eq>{`\\nabla f = 0`}</Eq> 但既不是最大值也不是最小值）。

在机器学习中，梯度下降避免直接计算临界点：它在 <Eq>{`-\\nabla f`}</Eq> 方向迭代，收敛（我们希望）到局部最小值。背后的理论——学习速率、收敛——是这节课所学的直接应用。

</Porta>

<Porta nivel="pratica" titulo="巴西实际应用">

**面包店的最大利润。** 一家面包店每天生产 <Eq>{`x`}</Eq> 单位的面包（以百计）。日利润（以雷亚尔计）按以下方式建模：

<Eq display>{`L(x) = -2x^2 + 12x - 10, \quad x \in [0, 5]`}</Eq>

**步骤1——临界点：** <Eq>{`L'(x) = -4x + 12 = 0 \\Rightarrow x = 3`}</Eq>。

**步骤2——比较：** <Eq>{`L(0) = -10`}</Eq>，<Eq>{`L(3) = -18 + 36 - 10 = 8`}</Eq>，<Eq>{`L(5) = -50 + 60 - 10 = 0`}</Eq>。

**结论：** 最大日利润R\$ 800，生产300个单位。低于100个单位（x小于1）或高于500个单位（x大于5）时，业务亏损。

**与ENEM的联系：** 优化问题在ENEM中出现，使用二次模型。这里的算法——求导、设为零、与定义域端点比较——正是要求的方法。

</Porta>

## 已解答的例子

<Exemplo titulo="三次多项式的临界点">

**问题。** 找出 <Eq>{`f(x) = x^3 - 3x^2 - 9x + 5`}</Eq> 的所有临界点并分类。

**策略。** 求导、设为零并使用第二导数测试。

**求解。**

<Eq display>{`f'(x) = 3x^2 - 6x - 9 = 3(x^2 - 2x - 3) = 3(x-3)(x+1)`}</Eq>

临界点：<Eq>{`x = 3`}</Eq> 和 <Eq>{`x = -1`}</Eq>。

第二导数：<Eq>{`f''(x) = 6x - 6`}</Eq>。

- <Eq>{`f''(-1) = -12 < 0`}</Eq> → **局部最大值**在 <Eq>{`x = -1`}</Eq>，<Eq>{`f(-1) = -1 - 3 + 9 + 5 = 10`}</Eq>。
- <Eq>{`f''(3) = 12 > 0`}</Eq> → **局部最小值**在 <Eq>{`x = 3`}</Eq>，<Eq>{`f(3) = 27 - 27 - 27 + 5 = -22`}</Eq>。

**验证。** <Eq>{`f'`}</Eq> 的符号表：对 <Eq>{`x < -1`}</Eq>，<Eq>{`f' > 0`}</Eq>（上升）。对 <Eq>{`-1 < x < 3`}</Eq>，<Eq>{`f' < 0`}</Eq>（下降）。对 <Eq>{`x > 3`}</Eq>，<Eq>{`f' > 0`}</Eq>（上升）。与 <Eq>{`-1`}</Eq> 处最大值和 <Eq>{`3`}</Eq> 处最小值一致。

**来源。** [Active Calculus §3.1, Activity 3.1.2](https://activecalculus.org/single/sec-3-1-tests.html) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="闭区间上的绝对极值">

**问题。** 确定 <Eq>{`f(x) = x^3 - 6x^2 + 9x + 2`}</Eq> 在 <Eq>{`[0, 4]`}</Eq> 上的绝对极值。

**策略。** 绝对极值算法：内部临界点 + 端点。

**求解。**

<Eq display>{`f'(x) = 3x^2 - 12x + 9 = 3(x^2 - 4x + 3) = 3(x-1)(x-3)`}</Eq>

<Eq>{`(0,4)`}</Eq> 中的临界点：<Eq>{`x = 1`}</Eq> 和 <Eq>{`x = 3`}</Eq>。

评估：

- <Eq>{`f(0) = 2`}</Eq>
- <Eq>{`f(1) = 1 - 6 + 9 + 2 = 6`}</Eq>
- <Eq>{`f(3) = 27 - 54 + 27 + 2 = 2`}</Eq>
- <Eq>{`f(4) = 64 - 96 + 36 + 2 = 6`}</Eq>

**绝对最大值：** <Eq>{`f = 6`}</Eq>，在 <Eq>{`x = 1`}</Eq> 和 <Eq>{`x = 4`}</Eq> 处达到。**绝对最小值：** <Eq>{`f = 2`}</Eq>，在 <Eq>{`x = 0`}</Eq> 和 <Eq>{`x = 3`}</Eq> 处达到。

**验证。** 端点处的极值是有效的——算法必须包括 <Eq>{`a`}</Eq> 和 <Eq>{`b`}</Eq>。

**来源。** [OpenStax Calculus Vol. 1, §4.3, Example 4.13](https://openstax.org/books/calculus-volume-1/pages/4-3-maxima-and-minima) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="没有极值的临界点（拐点）">

**问题。** 证明 <Eq>{`f(x) = x^3`}</Eq> 在 <Eq>{`x = 0`}</Eq> 处有临界点，但该点不是局部极值。

**策略。** 应用第一导数测试来验证没有符号变化。

**求解。**

<Eq display>{`f'(x) = 3x^2`}</Eq>

<Eq>{`f'(0) = 0`}</Eq> → <Eq>{`x = 0`}</Eq> 是临界点。

对 <Eq>{`x < 0`}</Eq>：<Eq>{`3x^2 > 0`}</Eq>。对 <Eq>{`x > 0`}</Eq>：<Eq>{`3x^2 > 0`}</Eq>。<Eq>{`f'`}</Eq> 的符号**不变** → 无局部极值。

**验证。** <Eq>{`f(-1) = -1 < f(0) = 0 < f(1) = 1`}</Eq>：函数在 <Eq>{`0`}</Eq> 的整个邻域中严格上升，确认既不是最大值也不是最小值。

<Exemplo titulo="带平方根的第一导数测试">

**问题。** 找出 <Eq>{`f(x) = x^{2/3}`}</Eq> 的局部极值。

**策略。** 导数在 <Eq>{`x = 0`}</Eq> 处不存在；即使没有 <Eq>{`f' = 0`}</Eq>，这也会创建一个临界点。

**求解。**

<Eq display>{`f'(x) = \\frac{2}{3}x^{-1/3} = \\frac{2}{3\\sqrt[3]{x}}`}</Eq>

<Eq>{`f'(0)`}</Eq> 不存在（分母为零），且 <Eq>{`f(0) = 0`}</Eq> 存在 → <Eq>{`x = 0`}</Eq> 是临界点。

符号表：对 <Eq>{`x < 0`}</Eq>，<Eq>{`x^{1/3} < 0`}</Eq>，所以 <Eq>{`f' < 0`}</Eq>。对 <Eq>{`x > 0`}</Eq>，<Eq>{`f' > 0`}</Eq>。在 <Eq>{`x = 0`}</Eq> 处从 <Eq>{`(-)`}</Eq> 到 <Eq>{`(+)`}</Eq> 的变化 → **局部最小值**。

**验证。** <Eq>{`f(x) = x^{2/3} \\geq 0`}</Eq> 对所有 <Eq>{`x`}</Eq>，且 <Eq>{`f(0) = 0`}</Eq> → 也是绝对最小值。

<Exemplo titulo="闭区间上三角函数的极值">

**问题。** 确定 <Eq>{`f(x) = 2\\sin x - x`}</Eq> 在 <Eq>{`[0, 2\\pi]`}</Eq> 上的绝对极值。

**策略。** 求导，找到临界点（余弦的根），应用算法。

**求解。**

<Eq display>{`f'(x) = 2\\cos x - 1 = 0 \\implies \\cos x = \\tfrac{1}{2} \\implies x = \\tfrac{\\pi}{3},\\; x = \\tfrac{5\\pi}{3}`}</Eq>

- <Eq>{`f(0) = 0`}</Eq>
- <Eq>{`f(\\pi/3) = 2 \\cdot (\\sqrt{3}/2) - \\pi/3 = \\sqrt{3} - \\pi/3 \\approx 0{,}685`}</Eq>
- <Eq>{`f(5\\pi/3) = 2 \\cdot (-\\sqrt{3}/2) - 5\\pi/3 = -\\sqrt{3} - 5\\pi/3 \\approx -6{,}97`}</Eq>
- <Eq>{`f(2\\pi) = 0 - 2\\pi \\approx -6{,}28`}</Eq>

**绝对最大值：** <Eq>{`f(\\pi/3) = \\sqrt{3} - \\pi/3`}</Eq>。**绝对最小值：** <Eq>{`f(5\\pi/3) = -\\sqrt{3} - 5\\pi/3`}</Eq>。
