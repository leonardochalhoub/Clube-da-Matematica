### 约束优化问题

<Definicao titulo="通用结构">

一个**优化问题**有三个要素：

1. 一个**目标函数** <Eq>{`Q`}</Eq>，我们想要最大化或最小化。
2. 一个或多个**决策变量**和由上下文决定的**物理定义域** <Eq>{`[a, b]`}</Eq>。
3. 一个或多个**约束**，关联变量——用来化简为单变量。

</Definicao>

### 优化算法（单变量）

<Definicao titulo="标准程序">

1. **定义**要优化的量，并用有物理意义的名称为变量命名。
2. **写出**方程 <Eq>{`Q = f(x, y, \\ldots)`}</Eq> 的目标函数。
3. **使用约束**消除次要变量，得到 <Eq>{`Q = f(x)`}</Eq>，定义域为 <Eq>{`x \\in [a, b]`}</Eq>。
4. **应用绝对极值算法**：内部临界点加端点评估。
5. **解释**问题背景下的结果（单位、物理可行性）。

</Definicao>

> "Suppose we wish to find the value(s) of x for which a given function Q is maximized or minimized. We use derivatives to find critical points and then evaluate Q at those points and at the endpoints of the domain to determine the absolute maximum or minimum." — [Active Calculus §3.3](https://activecalculus.org/single/sec-3-3-optimization.html)

### 典型例子：体积固定的圆柱形罐头

<Definicao titulo="罐头问题">

已知：体积 <Eq>{`V`}</Eq> 固定（参数）。最小化总表面积 <Eq>{`A = 2\\pi r^2 + 2\\pi r h`}</Eq>。

**约束：** <Eq>{`\\pi r^2 h = V \\Rightarrow h = V/(\\pi r^2)`}</Eq>。

**化简目标函数：**
<Eq display>{`A(r) = 2\\pi r^2 + \\frac{2V}{r}, \quad r > 0`}</Eq>

**临界点：**
<Eq display>{`A'(r) = 4\\pi r - \\frac{2V}{r^2} = 0 \\implies r^* = \\sqrt[3]{\\frac{V}{2\\pi}}`}</Eq>

**最优尺寸：** 代入得 <Eq>{`h^* = 2r^*`}</Eq>。最少材料的罐头**高度等于直径**。

</Definicao>

<Insight>

最优罐头（<Eq>{`h = 2r`}</Eq>）最小化表面积/体积比。真实的饮料罐偏离这个比例是由于堆积和强度因素，而不是纯数学优化。

</Insight>

> "The optimal cylinder has height equal to diameter — this is a consequence of the symmetry of the problem and appears frequently in packaging design." — [OpenStax Calculus Vol. 1, §4.7](https://openstax.org/books/calculus-volume-1/pages/4-7-applied-optimization-problems)

<Porta nivel="5" titulo="给5岁儿童">

想象你有一根绳子，想为你的小狗做**最大的围栏**来玩耍。

如果你把围栏做得**很长很窄**，小狗很难从一边走到另一边。

如果做成**小正方形**，小狗就有更多地方玩！

诀窍是：用相同长度的绳子，不同的形状会有不同大小的空间。**正确的形状会封闭更多空间。** 数学帮我们找到最好的形状！

</Porta>

<Porta nivel="10" titulo="给10岁儿童">

你有40米的围栏，想围成一个矩形畜栏。最大的畜栏面积是多少？

设宽为 <Eq>{`x`}</Eq>。长为 <Eq>{`20 - x`}</Eq>（因为周长必须是40米）。

面积：<Eq>{`A(x) = x \\cdot (20 - x) = 20x - x^2`}</Eq>。

导数：<Eq>{`A'(x) = 20 - 2x = 0 \\Rightarrow x = 10`}</Eq>。

最大的畜栏是 <Eq>{`10 \\times 10 = 100`}</Eq> 平方米——是一个**正方形**！

</Porta>

<Porta nivel="15" titulo="给高中生">

应用优化有一个四步的方法。反复练习这些步骤直到它们变成自动的。

**第1步——建模：** 读题，写出目标函数 <Eq>{`Q`}</Eq>（你想最大/最小化什么）。

**第2步——化简：** 用约束消除多余变量。你需要 <Eq>{`Q = f(x)`}</Eq>，**只有一个**变量。

**第3步——求导：** 计算 <Eq>{`f'(x)`}</Eq>，令其为零，找 <Eq>{`x^*`}</Eq>。

**第4步——比较：** 在 <Eq>{`x^*`}</Eq> 和物理定义域的边界处评估 <Eq>{`f`}</Eq>。最大（或最小）值获胜。

**第2步的建议：** 当题目说"周长固定"、"体积固定"、"预算固定"，这就是约束。分离一个变量并代入。

**注意物理定义域：** 长度是正数；<Eq>{`0 < x < L`}</Eq>。永远不要忽略这一点。

</Porta>

<Porta nivel="25" titulo="给工程学生">

单变量优化是通用数学规划问题中最简单的情况。这里技术是直接的：极值定理保证了如果定义域是紧的且 <Eq>{`f`}</Eq> 连续，最优值存在——绝对极值算法会找到它。

**当定义域是开的或无界时：** 最优值可能是唯一临界点。标准论证是：如果 <Eq>{`f(x) \\to +\\infty`}</Eq> 当 <Eq>{`x \\to 0^+`}</Eq> 和 <Eq>{`x \\to +\\infty`}</Eq> 时，且存在唯一内部临界点具有 <Eq>{`f'' > 0`}</Eq>，那么该点是全局最小值（不仅是局部的）。这个论证在罐头问题中明确出现。

**二阶建模：** 在经济学中，边际成本 <Eq>{`C'(x)`}</Eq> 和边际收入 <Eq>{`R'(x)`}</Eq> 决定最大利润点：<Eq>{`L'(x) = R'(x) - C'(x) = 0`}</Eq>，即边际收入 = 边际成本。这是新古典微观经济学的中心原理。

**扩展：** 在两个变量的情况下，<Eq>{`\\nabla f = 0`}</Eq> 与约束 <Eq>{`g = 0`}</Eq> 导致拉格朗日乘数法——本课程后的自然下一步。

</Porta>

<Porta nivel="40" titulo="给资深专业人士">

约束优化问题根源于17世纪的变分法。欧拉和拉格朗日推广到泛函——"哪个函数 <Eq>{`y(x)`}</Eq> 最小化 <Eq>{`\\int F(x,y,y') dx`}</Eq>？" 欧拉-拉格朗日方程是 <Eq>{`f'(x^*) = 0`}</Eq> 在无穷维空间的推广。

在最优控制（庞特里亚金，1950年代）中，问题是"哪个控制函数 <Eq>{`u(t)`}</Eq> 最小化轨迹上的成本？" 庞特里亚金最大值原理将本课程方法推广到动态系统。直接应用：火箭轨迹、资源管理、算法交易。

在当代机器学习中，神经网络训练问题是超高维优化（数十亿参数）。本课程的直觉——"梯度指向函数增长的地方；零梯度是最优值的候选"——是梯度下降（SGD、Adam等）的基础。

圆柱形罐头经济学在包装设计中重新出现：铝的成本按面积计算，而不是体积。比例 <Eq>{`h = 2r`}</Eq>（数学最优）让步于运输约束（堆积：更低矮的罐子）和销售（更大的标签）。真实工程是具有多个约束和冲突目标的优化。

</Porta>

<Porta nivel="pratica" titulo="巴西实际应用">

**问题：** 圣保罗一家小包装厂接到订单制作无盖纸板盒，尺寸为 12 厘米 × 8 厘米。为制盒，在四个角裁剪边长 <Eq>{`x`}</Eq> 厘米的正方形并折起边缘。

底面尺寸：<Eq>{`(12 - 2x) \\times (8 - 2x)`}</Eq>。高度：<Eq>{`x`}</Eq>。定义域：<Eq>{`0 < x < 4`}</Eq>。

<Eq display>{`V(x) = x(12-2x)(8-2x) = 4x^3 - 40x^2 + 96x`}</Eq>

<Eq display>{`V'(x) = 12x^2 - 80x + 96 = 4(3x^2 - 20x + 24)`}</Eq>

根：<Eq>{`x = \\frac{20 \\pm \\sqrt{400 - 288}}{6} = \\frac{20 \\pm \\sqrt{112}}{6}`}</Eq>。

<Eq>{`x_1 \\approx 1{,}57`}</Eq> 厘米（可行）和 <Eq>{`x_2 \\approx 5{,}10`}</Eq> 厘米（超出定义域）。

<Eq>{`V(1{,}57) \\approx 67{,}6`}</Eq> 立方厘米。因此，裁剪约 **1.57 厘米** 的正方形最大化盒子体积——一个直接的结果，可在工厂现场应用。

**在巴西：** 这种问题出现在包装优化中以减少材料浪费，与寻求ISO 14001认证（环境管理）的公司相关。

</Porta>

## 已解决的例子

<Exemplo titulo="一边固定的矩形围栏">

**问题。** 一个农民有120米的围栏，用现有的墙作为长边。最大面积的牧地尺寸是什么？

**策略。** 确定目标函数（面积）和约束（三条自由边的周长 = 120米）。消除一个变量并最大化。

**解决方案。**

设 <Eq>{`x`}</Eq> = 宽度（两边）和 <Eq>{`y`}</Eq> = 长度（与墙相对的边）。约束：<Eq>{`2x + y = 120 \\Rightarrow y = 120 - 2x`}</Eq>。

面积：<Eq>{`A(x) = xy = x(120 - 2x) = 120x - 2x^2`}</Eq>。定义域：<Eq>{`0 < x < 60`}</Eq>。

<Eq display>{`A'(x) = 120 - 4x = 0 \\implies x = 30 \\text{ 米}`}</Eq>

<Eq>{`y = 120 - 60 = 60`}</Eq> 米。最大面积：<Eq>{`30 \\times 60 = 1800`}</Eq> 平方米。

**验证。** <Eq>{`A''(30) = -4 < 0`}</Eq> → 最大值确认。在端点：<Eq>{`A(0) = A(60) = 0`}</Eq>。

**来源。** [OpenStax Calculus Vol. 1, §4.7, Example 4.33](https://openstax.org/books/calculus-volume-1/pages/4-7-applied-optimization-problems) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="无盖盒的最大体积">

**问题。** 从边长36厘米的方形纸板中，在四个角裁剪相等的正方形并折起边缘以形成无盖盒。哪个裁剪的大小最大化体积？

**策略。** 用裁剪正方形的边长 <Eq>{`x`}</Eq> 表示体积，求导，找临界点。

**解决方案。**

底面：<Eq>{`(36 - 2x)^2`}</Eq>。高度：<Eq>{`x`}</Eq>。定义域：<Eq>{`0 < x < 18`}</Eq>。

<Eq display>{`V(x) = x(36-2x)^2 = x(1296 - 144x + 4x^2) = 4x^3 - 144x^2 + 1296x`}</Eq>

<Eq display>{`V'(x) = 12x^2 - 288x + 1296 = 12(x^2 - 24x + 108) = 12(x-6)(x-18)`}</Eq>

根：<Eq>{`x = 6`}</Eq>（可行）和 <Eq>{`x = 18`}</Eq>（端点，<Eq>{`V = 0`}</Eq>）。

<Eq>{`V(6) = 6 \\cdot 24^2 = 6 \\cdot 576 = 3456`}</Eq> 立方厘米。

**验证。** <Eq>{`V''(6) = 24 \\cdot 6 - 288 = -144 < 0`}</Eq> → 最大值。

**来源。** [OpenStax Calculus Vol. 1, §4.7, Example 4.32](https://openstax.org/books/calculus-volume-1/pages/4-7-applied-optimization-problems) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="最小表面积的圆柱形罐">

**问题。** 一个圆柱形罐必须容纳 <Eq>{`V = 1000`}</Eq> 立方厘米。确定最小化材料总面积的半径和高度。

**策略。** 使用 <Eq>{`h = V/(\\pi r^2)`}</Eq> 将面积表示为半径的函数，求导。

**解决方案。**

<Eq display>{`A(r) = 2\\pi r^2 + \\frac{2V}{r} = 2\\pi r^2 + \\frac{2000}{r}`}</Eq>

<Eq display>{`A'(r) = 4\\pi r - \\frac{2000}{r^2} = 0 \\implies r^3 = \\frac{2000}{4\\pi} = \\frac{500}{\\pi}`}</Eq>

<Eq display>{`r^* = \\sqrt[3]{\\frac{500}{\\pi}} \\approx 5{,}42 \\text{ 厘米}`}</Eq>

<Eq>{`h^* = 1000/(\\pi \\cdot r^{*2}) \\approx 10{,}84`}</Eq> 厘米 <Eq>{`= 2r^*`}</Eq> ——高度等于直径。

**验证。** <Eq>{`A''(r) = 4\\pi + 4000/r^3 > 0`}</Eq> 对所有 <Eq>{`r > 0`}</Eq> ——全局最小值。

**来源。** [Active Calculus §3.3, Activity 3.3.2](https://activecalculus.org/single/sec-3-3-optimization.html) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="点到直线的最小距离">

**问题。** 确定直线 <Eq>{`y = 2x + 3`}</Eq> 上最接近原点的点。

**策略。** 最小化 <Eq>{`d^2 = x^2 + y^2`}</Eq>（等价于最小化 <Eq>{`d`}</Eq>）代入 <Eq>{`y = 2x + 3`}</Eq>。

**解决方案。**

<Eq display>{`D(x) = x^2 + (2x+3)^2 = 5x^2 + 12x + 9`}</Eq>

<Eq display>{`D'(x) = 10x + 12 = 0 \\implies x^* = -\\tfrac{6}{5}`}</Eq>

<Eq>{`y^* = 2(-6/5) + 3 = 3/5`}</Eq>。距离：<Eq>{`d = \\sqrt{(6/5)^2 + (3/5)^2} = \\sqrt{45/25} = 3\\sqrt{5}/5`}</Eq>。

**验证。** <Eq>{`D''(x) = 10 > 0`}</Eq> → 最小值。解析点-直线距离公式得同样结果：<Eq>{`d = |0 - 0 + 3|/\\sqrt{5} = 3/\\sqrt{5} = 3\\sqrt{5}/5`}</Eq>。

**来源。** [APEX Calculus §4.3, Example 4.3.2](https://www.apexcalculus.com/) · CC-BY-NC

</Exemplo>

<Exemplo titulo="非线性成本下的最大利润">

**问题。** 一个企业有收入 <Eq>{`R(x) = 200x - x^2`}</Eq> 和成本 <Eq>{`C(x) = x^3/3 - 7x^2 + 111x + 50`}</Eq>，对 <Eq>{`x \\in [0, 14]`}</Eq> 单位。最大化利润。

**策略。** 利润 <Eq>{`L = R - C`}</Eq>。求导，找临界点，与端点比较。

**解决方案。**

<Eq display>{`L(x) = 200x - x^2 - \\frac{x^3}{3} + 7x^2 - 111x - 50 = -\\frac{x^3}{3} + 6x^2 + 89x - 50`}</Eq>

<Eq display>{`L'(x) = -x^2 + 12x + 89`}</Eq>

判别式：<Eq>{`144 + 356 = 500`}</Eq>。根：<Eq>{`x = \\frac{-12 \\pm \\sqrt{500}}{-2}`}</Eq>。在 <Eq>{`[0,14]`}</Eq> 的正根：<Eq>{`x^* \\approx 14`}</Eq> ...重新计算：<Eq>{`x = (12 + \\sqrt{500})/2 \\approx (12 + 22{,}36)/2 \\approx 17{,}18`}</Eq>（超出）。较小的根：<Eq>{`(12 - 22{,}36)/2 \\approx -5{,}18`}</Eq>（超出）。因此 <Eq>{`L'(x) > 0`}</Eq> 在 <Eq>{`[0,14]`}</Eq> ——<Eq>{`L`}</Eq> 递增：最大值在端点 <Eq>{`x = 14`}</Eq>。

<Eq>{`L(14) = -2744/3 + 6(196) + 89(14) - 50 = -914{,}67 + 1176 + 1246 - 50 \\approx 1457`}</Eq>。

**验证。** 检查 <Eq>{`L(0) = -50`}</Eq> 确认在端点 <Eq>{`x = 14`}</Eq> 的绝对最大值。

**来源。** [Active Calculus §3.3, Exercise 3.3.4](https://activecalculus.org/single/sec-3-3-optimization.html) · CC-BY-NC-SA

</Exemplo>
