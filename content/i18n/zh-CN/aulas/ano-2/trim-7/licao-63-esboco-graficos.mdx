### 八个正式步骤

<Definicao titulo="通过微积分进行草图绘制的管道">

1. **定义域** <Eq>{`D \\subseteq \\mathbb{R}`}</Eq>：<Eq>{`f`}</Eq>被定义的地方。识别分母的零点、负被开方数、非正数的对数。

2. **截距：** <Eq>{`f(0)`}</Eq>（竖直截距）；<Eq>{`f(x) = 0`}</Eq>的根（水平截距，当可达到时）。

3. **对称性：** <Eq>{`f(-x) = f(x)`}</Eq> → 偶函数（关于<Eq>{`y`}</Eq>轴对称）；<Eq>{`f(-x) = -f(x)`}</Eq> → 奇函数（关于原点对称）；周期性。

4. **渐近线：**
   - **竖直渐近线** 在 <Eq>{`x = a`}</Eq>：<Eq>{`\\lim_{x \\to a^\\pm} f(x) = \\pm\\infty`}</Eq>。
   - **水平渐近线** <Eq>{`y = L`}</Eq>：<Eq>{`\\lim_{x \\to \\pm\\infty} f(x) = L`}</Eq>。
   - **斜渐近线** <Eq>{`y = mx + b`}</Eq>：<Eq>{`m = \\lim_{x \\to \\infty} f(x)/x`}</Eq> 和 <Eq>{`b = \\lim_{x \\to \\infty}(f(x) - mx)`}</Eq>。

5. **第一阶导数** <Eq>{`f'`}</Eq>：求临界点。符号表 → 增长区间（<Eq>{`f' > 0`}</Eq>）和减少区间（<Eq>{`f' < 0`}</Eq>），局部极值。

6. **第二阶导数** <Eq>{`f''`}</Eq>：求拐点候选点（<Eq>{`f'' = 0`}</Eq>或不存在）。符号表 → 向上凹（<Eq>{`f'' > 0`}</Eq>）或向下凹（<Eq>{`f'' < 0`}</Eq>）。

7. **拐点：** 点<Eq>{`c`}</Eq>其中<Eq>{`f''`}</Eq>**改变符号**（凹凸性交换）。

8. **草图：** 标记截距、渐近线（虚线）、极值和拐点；绘制曲线，尊重每个区间中的增减性和凹凸性。

</Definicao>

> "If f'(x) > 0 on an interval, then f is increasing on that interval. If f''(x) > 0, then f is concave up. These two pieces of information, combined with critical and inflection points, give a complete picture of the graph." — [OpenStax Calculus Vol. 1, §4.5](https://openstax.org/books/calculus-volume-1/pages/4-5-derivatives-and-the-shape-of-a-graph)

|---|---|---|
| <Eq>{`> 0`}</Eq> | <Eq>{`> 0`}</Eq> | 增加，向上凹 |
| <Eq>{`> 0`}</Eq> | <Eq>{`< 0`}</Eq> | 增加，向下凹 |
| <Eq>{`< 0`}</Eq> | <Eq>{`> 0`}</Eq> | 减少，向上凹 |
| <Eq>{`< 0`}</Eq> | <Eq>{`< 0`}</Eq> | 减少，向下凹 |

### 凹凸性和拐点的定义

<Definicao titulo="凹凸性">

<Eq>{`f`}</Eq>在<Eq>{`I`}</Eq>上**向上凹**如果对所有<Eq>{`x \\in I`}</Eq>有<Eq>{`f''(x) > 0`}</Eq> — 曲线位于任何切线之上。<Eq>{`f`}</Eq>在<Eq>{`I`}</Eq>上**向下凹**如果<Eq>{`f''(x) < 0`}</Eq>。

</Definicao>

<Definicao titulo="拐点">

<Eq>{`c`}</Eq>是<Eq>{`f`}</Eq>的**拐点**如果<Eq>{`f`}</Eq>在<Eq>{`c`}</Eq>处连续且<Eq>{`f''`}</Eq>在<Eq>{`c`}</Eq>处改变符号。

</Definicao>

<Insight>

<Eq>{`f''(c) = 0`}</Eq>是拐点的必要条件但不充分。例：<Eq>{`f(x) = x^4`}</Eq>有<Eq>{`f''(0) = 0`}</Eq>，但凹凸性在<Eq>{`0`}</Eq>处不改变——不是拐点。

</Insight>

<Porta nivel="5" titulo="给5岁儿童讲解">

想象你正在绘制一条山路。这条路有时上升，有时下降。

当上升时，导数为正。当下降时，导数为负。在山顶，它短暂停止后开始下降——那是特殊的点。

现在观察道路的曲率。有时道路**向上弯曲**（像碗）有时**向下弯曲**（像圆顶）。曲线改变的地方就是拐点。

在绘制任何东西之前，找到这些特殊的地方是聪明的。然后只需连接这些点！

</Porta>

<Porta nivel="10" titulo="给10岁儿童讲解">

为了制作<Eq>{`f(x)`}</Eq>的好草图，遵循这个列表：

1. 函数在哪里存在？（定义域）
2. 它在哪里穿过轴？（<Eq>{`f(0)`}</Eq>和<Eq>{`f(x) = 0`}</Eq>的位置）
3. 它在什么地方趋向无穷？（渐近线）
4. 它在哪里**上升**（<Eq>{`f' > 0`}</Eq>）或**下降**（<Eq>{`f' < 0`}</Eq>）？
5. 它在哪里**向上弯**（<Eq>{`f'' > 0`}</Eq>）或**向下弯**（<Eq>{`f'' < 0`}</Eq>）？

有了这5个问题的答案，绘制几乎自动完成！

</Porta>

<Porta nivel="15" titulo="给高中学生讲解">

**草图绘制流程**有8个步骤。你可以用首字母缩略词**DISSECF**记住它们（定义域、截距、对称性、<Eq>{`f'`}</Eq>的符号、极值、凹凸性、拐点、图形）。

**关键步骤——符号表：** 在临界点和拐点处分割实数轴。在每个区间中，确定<Eq>{`f' > 0`}</Eq>还是<Eq>{`< 0`}</Eq>以及<Eq>{`f'' > 0`}</Eq>还是<Eq>{`< 0`}</Eq>。这完全决定了曲线在每段的行为。

**斜渐近线：** 在有理函数中当分子次数=分母次数+1时发生。进行多项式除法找到<Eq>{`y = mx + b`}</Eq>。

**拐点≠临界点：** 局部极值有<Eq>{`f' = 0`}</Eq>；拐点有<Eq>{`f'' = 0`}</Eq>（有符号改变）。一个点可能两者都是（罕见）。

</Porta>

<Porta nivel="25" titulo="给工程学生讲解">

通过微积分的草图绘制是函数的**完整定性分析**，结合：

**中值定理（MVT）：** 支撑<Eq>{`f' > 0`}</Eq>蕴含严格增加。没有MVT，仅知道某点<Eq>{`f'(c) > 0`}</Eq>不保证区间上的增加。

**凹凸性和f''：** 如果<Eq>{`f''`}</Eq>存在且在<Eq>{`I`}</Eq>上为正，则<Eq>{`f'`}</Eq>在<Eq>{`I`}</Eq>上递增——函数在"加速"。在数值分析中，凹凸性影响积分方法的精度（当<Eq>{`f'' < 0`}</Eq>时梯形规则高估）。

**斜渐近线：** <Eq>{`f(x) = P(x)/Q(x)`}</Eq>其中<Eq>{`\\deg P = \\deg Q + 1`}</Eq>：进行欧几里得除法。商是斜渐近线；余数当<Eq>{`x \\to \\infty`}</Eq>时<Eq>{`\\to 0`}</Eq>。

**工程中的曲线：** 符号分析（Bode图）、结构中的载荷-位移曲线、热力学中的P-V曲线是这种定性分析的直接应用——当定性行为足够时，它替代了重型数值计算。

</Porta>

<Porta nivel="40" titulo="给资深专业人士讲解">

德语的**Kurvendiskussion**（曲线讨论），在Abitur中是必修的，正是这个流程——这是一个罕见的主题，其中德国、日本和新加坡课程在细节上汇聚。它代表单变量微分微积分的操作综合。

从历史上讲，莱布尼茨和约翰·伯努利已经在17世纪使用二阶导数来分类极值。现代形式化——包括凹凸性作为全局属性（非逐点）——来自19世纪柯西和魏尔斯特拉斯，当时分析用严格的分析论证替代了直观的几何论证。

在量化金融中，债券投资组合的**凸性**正是价格关于利率的二阶导数。风险经理使用凸性（正或负）来为收益率曲线的曲率定价——直接类似于本课中<Eq>{`f''`}</Eq>的分析。

在机器学习中，通过梯度（<Eq>{`f'`}</Eq>）和Hessian矩阵（高维<Eq>{`f''`}</Eq>）进行损失分析是直接扩展。鞍点（梯度消失但不是最小值的地方）是优化器的噩梦——完全类似于L61中已见的<Eq>{`f'(c) = 0`}</Eq>无极值的情况。

</Porta>

<Porta nivel="pratica" titulo="巴西实际应用">

**农业产量曲线分析。** 大豆产量每公顷作为施用肥料量的函数，有典型的行为：

<Eq display>{`P(x) = -0{,}01x^3 + 0{,}6x^2 - 2x + 10, \quad x \in [0, 40]`}</Eq>

其中<Eq>{`x`}</Eq>是每公顷肥料公斤数，<Eq>{`P`}</Eq>是每公顷袋数。

<Eq display>{`P'(x) = -0{,}03x^2 + 1{,}2x - 2`}</Eq>

<Eq>{`P'`}</Eq>的零点：判别式<Eq>{`1{,}44 - 0{,}24 = 1{,}20`}</Eq>。根：<Eq>{`x \\approx 1{,}84`}</Eq>和<Eq>{`x \\approx 38{,}16`}</Eq>。在区间<Eq>{`[0, 40]`}</Eq>上：产量从<Eq>{`x \\approx 1{,}84`}</Eq>增加到<Eq>{`x \\approx 38{,}16`}</Eq>。

<Eq>{`P''(x) = -0{,}06x + 1{,}2 = 0 \\Rightarrow x = 20`}</Eq> — 拐点，增长速率开始下降（边际生产率递减，农业微观经济学的基本原则）。

**实际理解：** 施用到38公斤/公顷会增加产量；超过此值时，过量肥料开始造成损害。20公斤处的拐点指示边际生产率最大的地方。

</Porta>

## 已解决的例子

<Exemplo titulo="三次多项式的完整草图">

**问题。** 绘制<Eq>{`f(x) = x^3 - 3x`}</Eq>的完整草图。

**策略。** 应用管道的8个步骤。

**解决方案。**

1. **定义域：** <Eq>{`\\mathbb{R}`}</Eq>。
2. **截距：** <Eq>{`f(0) = 0`}</Eq>。根：<Eq>{`x(x^2-3) = 0 \\Rightarrow x = 0, \\pm\\sqrt{3}`}</Eq>。
3. **对称性：** <Eq>{`f(-x) = -x^3 + 3x = -f(x)`}</Eq> → 奇函数。
4. **渐近线：** 无（多项式）。
5. **<Eq>{`f'(x) = 3x^2 - 3 = 3(x-1)(x+1)`}</Eq>**。临界点：<Eq>{`x = \\pm 1`}</Eq>。在<Eq>{`(-\\infty,-1)`}</Eq>和<Eq>{`(1,\\infty)`}</Eq>上递增；在<Eq>{`(-1,1)`}</Eq>上递减。局部最大值<Eq>{`f(-1) = 2`}</Eq>；局部最小值<Eq>{`f(1) = -2`}</Eq>。
6. **<Eq>{`f''(x) = 6x`}</Eq>**。零点在<Eq>{`x = 0`}</Eq>。在<Eq>{`x < 0`}</Eq>时向下凹；在<Eq>{`x > 0`}</Eq>时向上凹。
7. **拐点：** <Eq>{`x = 0`}</Eq>（<Eq>{`f''`}</Eq>改变符号）。点：<Eq>{`(0, 0)`}</Eq>。
8. **草图：** "S"形曲线经过原点，在<Eq>{`(-1, 2)`}</Eq>处有最大值，在<Eq>{`(1, -2)`}</Eq>处有最小值。

**验证。** 通过奇对称性，图形关于原点对称——值相符。

**来源。** [OpenStax Calculus Vol. 1, §4.5, Example 4.20](https://openstax.org/books/calculus-volume-1/pages/4-5-derivatives-and-the-shape-of-a-graph) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="具有水平渐近线的有理函数">

**问题。** 绘制<Eq>{`f(x) = \\dfrac{x^2}{x^2 + 1}`}</Eq>的草图。

**策略。** 识别渐近线，使用<Eq>{`f'`}</Eq>和<Eq>{`f''`}</Eq>。

**解决方案。**

1. **定义域：** <Eq>{`\\mathbb{R}`}</Eq>（分母永不为零）。
2. **截距：** <Eq>{`f(0) = 0`}</Eq>。唯一根：<Eq>{`x = 0`}</Eq>。
3. **对称性：** <Eq>{`f(-x) = f(x)`}</Eq> → 偶函数。
4. **水平渐近线：** <Eq>{`\\lim_{x \\to \\pm\\infty} x^2/(x^2+1) = 1`}</Eq>。直线<Eq>{`y = 1`}</Eq>。
5. **<Eq>{`f'(x) = 2x/(x^2+1)^2`}</Eq>**。对<Eq>{`x > 0`}</Eq>为正，对<Eq>{`x < 0`}</Eq>为负。在<Eq>{`x = 0`}</Eq>处有局部最小值（根据符号：<Eq>{`f'`}</Eq>从<Eq>{`-`}</Eq>变为<Eq>{`+`}</Eq>）。
6. **<Eq>{`f''(x) = (2(x^2+1)^2 - 2x \\cdot 2(x^2+1)\\cdot 2x)/(x^2+1)^4 = 2(1-3x^2)/(x^2+1)^3`}</Eq>**。零点：<Eq>{`x = \\pm 1/\\sqrt{3}`}</Eq>。
7. **拐点在** <Eq>{`x = \\pm 1/\\sqrt{3}`}</Eq>。<Eq>{`f'' > 0`}</Eq>在<Eq>{`|x| < 1/\\sqrt{3}`}</Eq>；<Eq>{`f'' < 0`}</Eq>在<Eq>{`|x| > 1/\\sqrt{3}`}</Eq>。
8. 对称曲线，从0开始，渐近增加到1。

**验证。** <Eq>{`0 \\leq f(x) < 1`}</Eq>对所有<Eq>{`x`}</Eq> — 与水平渐近线在1处一致。

**来源。** [APEX Calculus §3.5, Example 3.5.2](https://www.apexcalculus.com/) · CC-BY-NC

</Exemplo>

<Exemplo titulo="具有竖直和水平渐近线的函数">

**问题。** 绘制<Eq>{`f(x) = \\dfrac{2x}{x - 1}`}</Eq>的草图。

**策略。** 识别竖直渐近线（<Eq>{`x = 1`}</Eq>）和水平渐近线，然后分析<Eq>{`f'`}</Eq>。

**解决方案。**

1. **定义域：** <Eq>{`\\mathbb{R} \\setminus \\{1\\}`}</Eq>。
2. **截距：** <Eq>{`f(0) = 0`}</Eq>；根：<Eq>{`x = 0`}</Eq>。
3. **竖直渐近线：** <Eq>{`x = 1`}</Eq>（<Eq>{`f \\to \\pm\\infty`}</Eq>）。
4. **水平渐近线：** <Eq>{`\\lim_{x \\to \\pm\\infty} 2x/(x-1) = 2`}</Eq>。直线<Eq>{`y = 2`}</Eq>。
5. **<Eq>{`f'(x) = (2(x-1) - 2x)/(x-1)^2 = -2/(x-1)^2 < 0`}</Eq>**对所有<Eq>{`x \\neq 1`}</Eq>。函数在每支上严格递减。
6. **<Eq>{`f''(x) = 4/(x-1)^3`}</Eq>**。对<Eq>{`x > 1`}</Eq>为正（向上凹）；对<Eq>{`x < 1`}</Eq>为负（向下凹）。
7. **无拐点**（分母在<Eq>{`x = 1`}</Eq>之外永不为零）。
8. 两支：<Eq>{`x < 1`}</Eq>（递减，向下凹）和<Eq>{`x > 1`}</Eq>（递减，向上凹）。

**验证。** <Eq>{`f`}</Eq>永不穿过渐近线<Eq>{`y = 2`}</Eq>（验证：<Eq>{`2x/(x-1) = 2 \\Rightarrow 2x = 2x - 2`}</Eq>，不可能）。

<Exemplo titulo="具有斜渐近线的有理函数">

**问题。** 绘制<Eq>{`f(x) = \\dfrac{x^2 + 1}{x}`}</Eq>的草图。

**策略。** 通过多项式除法获得斜渐近线；分析<Eq>{`f'`}</Eq>和<Eq>{`f''`}</Eq>。

**解决方案。**

1. **定义域：** <Eq>{`\\mathbb{R} \\setminus \\{0\\}`}</Eq>。
2. **截距：** <Eq>{`f(x) = 0 \\Rightarrow x^2 + 1 = 0`}</Eq> — 无实根。在<Eq>{`x = 0`}</Eq>处无截距（超出定义域）。
3. **对称性：** <Eq>{`f(-x) = (-x^2 - 1)/(-x) = (x^2+1)/x = f(x)`}</Eq>...等等：<Eq>{`f(-x) = (x^2+1)/(-x) = -f(x)`}</Eq> → 奇函数。
4. **竖直渐近线：** <Eq>{`x = 0`}</Eq>。除法：<Eq>{`f(x) = x + 1/x`}</Eq> → 斜渐近线<Eq>{`y = x`}</Eq>。
5. **<Eq>{`f'(x) = 1 - 1/x^2`}</Eq>**。零点：<Eq>{`x = \\pm 1`}</Eq>。在<Eq>{`x = 1`}</Eq>处局部最小值（值2）；在<Eq>{`x = -1`}</Eq>处局部最大值（值−2）。
6. **<Eq>{`f''(x) = 2/x^3`}</Eq>**。对<Eq>{`x > 0`}</Eq>为正，对<Eq>{`x < 0`}</Eq>为负。无拐点（在0处不连续）。
7. **草图：** 两支双曲线，每支渐近接近<Eq>{`y = x`}</Eq>和<Eq>{`x = 0`}</Eq>。

**验证。** <Eq>{`f(x) - x = 1/x \\to 0`}</Eq>当<Eq>{`x \\to \\pm\\infty`}</Eq> — 斜渐近线确认。

**来源。** [APEX Calculus §3.5, Example 3.5.4](https://www.apexcalculus.com/) · CC-BY-NC

</Exemplo>
