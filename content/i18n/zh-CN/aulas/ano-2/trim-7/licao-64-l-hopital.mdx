### 正式陈述

<Teorema titulo="洛必达法则（0/0和∞/∞的形式）">

设 <Eq>{`f`}</Eq> 和 <Eq>{`g`}</Eq> 在 <Eq>{`a`}</Eq> 的某邻域内（可能除了 <Eq>{`a`}</Eq> 点本身）可导，且 <Eq>{`g'(x) \\neq 0`}</Eq>。

若 <Eq>{`\\lim_{x \\to a} f(x) = \\lim_{x \\to a} g(x) = 0`}</Eq>（0/0 形式），或若 <Eq>{`\\lim_{x \\to a} |f(x)| = \\lim_{x \\to a} |g(x)| = \\infty`}</Eq>（∞/∞ 形式），则：

<Eq display>{`\\lim_{x \\to a} \\frac{f(x)}{g(x)} = \\lim_{x \\to a} \\frac{f'(x)}{g'(x)}`}</Eq>

只要右侧极限存在（在 <Eq>{`\\mathbb{R}`}</Eq> 中或为 <Eq>{`\\pm\\infty`}</Eq>）。

**适用范围**：该法则同样适用于 <Eq>{`x \\to a^+`}</Eq>、<Eq>{`x \\to a^-`}</Eq>、<Eq>{`x \\to +\\infty`}</Eq> 和 <Eq>{`x \\to -\\infty`}</Eq>。

</Teorema>

> "洛必达法则简化了分子分母都趋于0或∞的商的极限计算。关键是识别不定式、应用该法则，并检验所得极限确实存在。" — [OpenStax Calculus Vol. 1, §4.8](https://openstax.org/books/calculus-volume-1/pages/4-8-lhopitals-rule)

### 证明思路（0/0 的情形）

由**柯西均值定理**：若 <Eq>{`f(a) = g(a) = 0`}</Eq>，对于 <Eq>{`x`}</Eq> 接近 <Eq>{`a`}</Eq>，存在 <Eq>{`\\xi`}</Eq> 介于 <Eq>{`a`}</Eq> 和 <Eq>{`x`}</Eq> 之间，使得：

<Eq display>{`\\frac{f(x)}{g(x)} = \\frac{f(x) - f(a)}{g(x) - g(a)} = \\frac{f'(\\xi)}{g'(\\xi)}`}</Eq>

当 <Eq>{`x \\to a`}</Eq> 时，有 <Eq>{`\\xi \\to a`}</Eq>，极限过程得出：<Eq>{`f(x)/g(x) \\to f'(a)/g'(a)`}</Eq>（当导数之比的极限收敛时）。

### 对其他不定式的扩展

<Definicao titulo="化简表">

| 形式 | 化简方法 |
|---|---|
| <Eq>{`0/0`}</Eq> | 直接应用洛必达法则 |
| <Eq>{`\\infty/\\infty`}</Eq> | 直接应用洛必达法则 |
| <Eq>{`0 \\cdot \\infty`}</Eq> | 改写：<Eq>{`f \\cdot g = f / (1/g)`}</Eq> 或 <Eq>{`g / (1/f)`}</Eq> |
| <Eq>{`\\infty - \\infty`}</Eq> | 通分（最小公倍数或有理化） |
| <Eq>{`1^\\infty, 0^0, \\infty^0`}</Eq> | 取对数：<Eq>{`f^g = e^{g \\ln f}`}</Eq>；对指数应用洛必达法则 |

</Definicao>

<Insight>

**应用洛必达法则的注意事项：**
1. **在应用前验证形式。** 若 <Eq>{`\\lim f/g`}</Eq> 不是 <Eq>{`0/0`}</Eq> 或 <Eq>{`\\infty/\\infty`}</Eq>，洛必达法则**无效**。
2. **循环**：<Eq>{`\\lim (e^x - 1)/\\sin x`}</Eq> 如果应用不当可能陷入循环。检查结果是否收敛。
3. **替代方法**：泰勒级数通常能更快且更安全地解决不定式，无需担心循环。

</Insight>

> "请注意：洛必达法则说的是商函数的极限等于导数的商的极限，前提是原极限取得0/0或∞/∞的形式。这与商的导数法则不同。" — [Active Calculus §2.8](https://activecalculus.org/single/sec-2-8-LHR.html)

</Porta>

<Porta nivel="5" titulo="对一个5岁儿童">

想象你有两堆积木在缩小。如果两堆都在同一时刻缩到零，就很难判断哪堆"相对来说"更大——它们都消失了！

洛必达法则就像一个技巧：与其比较这些堆，你转而比较**它们缩小的快度**。哪个缩小得更快？那个速度就是重点！

这就像赛车：如果两辆车都刹车停止，重要的不是它们停在哪里（都在同一个地方），而是谁刹得更急。

</Porta>

<Porta nivel="10" titulo="对一个10岁儿童">

你想计算 <Eq>{`\\lim_{x \\to 0} \\frac{\\sin x}{x}`}</Eq>。

如果代入 <Eq>{`x = 0`}</Eq>，得到 <Eq>{`0/0`}</Eq>：不行。

洛必达法则说：当你遇到 <Eq>{`0/0`}</Eq> 时，可以**分别对分子和分母求导**，然后重新计算极限：

<Eq display>{`\\lim_{x \\to 0} \\frac{\\sin x}{x} = \\lim_{x \\to 0} \\frac{\\cos x}{1} = \\frac{1}{1} = 1`}</Eq>

这之所以有效，是因为导数衡量"变化率"——当一切都趋于零时，变化率的比告诉我们哪个函数趋于零更快。

</Porta>

<Porta nivel="15" titulo="对高中学生">

**何时使用洛必达法则：**

1. 先正常计算极限。
2. 若得到 <Eq>{`0/0`}</Eq> 或 <Eq>{`\\infty/\\infty`}</Eq>：这是不定式。
3. **分别**对分子和分母求导（不是商法则！）。
4. 重新计算极限。若仍是不定式，重复。

**其他形式：**

- <Eq>{`0 \\cdot \\infty`}</Eq>：改写成分数形式，应用洛必达法则。
- <Eq>{`1^\\infty`}</Eq> 或 <Eq>{`0^0`}</Eq>：取 <Eq>{`\\ln`}</Eq>，计算对数的极限，然后求幂。

**常见陷阱**：在应用前验证形式是否确实是不定式。在 <Eq>{`\\lim_{x \\to 0} (x + 1)/x`}</Eq> 中，结果是 <Eq>{`\\infty`}</Eq>——不是 <Eq>{`\\infty/\\infty`}</Eq>，洛必达法则不适用。

</Porta>

<Porta nivel="25" titulo="对工科学生">

洛必达法则是**柯西均值定理**（拉格朗日均值定理的推广）的结果：若 <Eq>{`f`}</Eq> 和 <Eq>{`g`}</Eq> 在 <Eq>{`[a, b]`}</Eq> 上连续，在 <Eq>{`(a, b)`}</Eq> 上可导，且 <Eq>{`g' \\neq 0`}</Eq>，则存在 <Eq>{`c \\in (a, b)`}</Eq> 使得：

<Eq display>{`\\frac{f(b) - f(a)}{g(b) - g(a)} = \\frac{f'(c)}{g'(c)}`}</Eq>

**替代方法——泰勒级数**：如果 <Eq>{`f`}</Eq> 和 <Eq>{`g`}</Eq> 在 <Eq>{`a`}</Eq> 处解析，展开成级数后相除。通常比多次应用洛必达法则更快。

例如：<Eq>{`\\lim_{x \\to 0} (\\sin x - x)/x^3`}</Eq>。泰勒：<Eq>{`\\sin x = x - x^3/6 + \\ldots`}</Eq>，因此 <Eq>{`\\sin x - x = -x^3/6 + \\ldots`}</Eq>。极限为 <Eq>{`-1/6`}</Eq>。应用洛必达法则三次会得到相同结果——但泰勒法更直接。

**无穷大的阶**：<Eq>{`\\ln x \\ll x^n \\ll e^x \\ll e^{x^2}`}</Eq> 当 <Eq>{`x \\to \\infty`}</Eq> 时。洛必达法则形式化了导数保持这个阶层结构。

</Porta>

<Porta nivel="40" titulo="对资深专业人士">

这条法则背后的历史是数学中最有趣的插曲之一。约翰·伯努利在1694年发现了这个结果，并告知他的学生洛必达侯爵。洛必达将其纳入历史上第一部微积分教科书《无穷小分析》（1696年），却没有给伯努利署名——所以这个定理沿用了错误的名称到今天。

柯西均值定理发表于1821年，提供了严格的证明。在此之前，"极限"是直观处理的，该法则通过莱布尼茨微分分析的论证来解释。

在现代实分析中，洛必达法则是关于相对变化率的定理。用Landau记号表示，如果 <Eq>{`f(x) = o(g(x))`}</Eq> 在 <Eq>{`a`}</Eq> 附近，那么在规则性条件下，<Eq>{`f'/g' \\to 0`}</Eq> 也成立。反向不精确——存在导数比 <Eq>{`f'/g'`}</Eq> 发散但 <Eq>{`f/g`}</Eq> 收敛的函数（见APEX §6.7的反例）。

在量化金融中，不定式的极限出现在期权定价：在Black-Scholes模型中，当波动率 <Eq>{`\\sigma \\to 0`}</Eq> 时，价格收敛到平价值——这是一个涉及Black-Scholes对数公式中0/0形式的极限，正好用洛必达法则解决。

</Porta>

<Porta nivel="pratica" titulo="巴西实际应用">

**连续复利利息计算中的自然极限。** 数字 <Eq>{`e`}</Eq> 来自一个经典的 <Eq>{`1^\\infty`}</Eq> 不定式极限：

<Eq display>{`e = \\lim_{n \\to \\infty} \\left(1 + \\frac{1}{n}\\right)^n`}</Eq>

取对数：<Eq>{`\\ln L = \\lim_{n \\to \\infty} n \\ln(1 + 1/n)`}</Eq> ——形式 <Eq>{`\\infty \\cdot 0`}</Eq>。改写：

<Eq display>{`\\ln L = \\lim_{n \\to \\infty} \\frac{\\ln(1 + 1/n)}{1/n}`}</Eq>

形式 <Eq>{`0/0`}</Eq>。洛必达法则：分子的导数为 <Eq>{`(-1/n^2)/(1+1/n)`}</Eq>，分母的导数为 <Eq>{`-1/n^2`}</Eq>。比值：<Eq>{`1/(1+1/n) \\to 1`}</Eq>。因此 <Eq>{`\\ln L = 1`}</Eq>，即 <Eq>{`L = e`}</Eq>。

**在ENEM和大学入试中的应用**：极限 <Eq>{`\\lim_{x \\to 0} \\sin(x)/x = 1`}</Eq> ——通过洛必达法则优雅地证明——是巴西FUVEST和Unicamp等考试中要求的三角极限的基础。

**在国家金融系统中**：年利率转换为连续复合使用的正好是 <Eq>{`e^{rt}`}</Eq>，衍生自这个极限。巴西央行在风险模型中使用连续复合。

</Porta>

## 已解决的例子

<Exemplo titulo="简单的 0/0 形式">

**问题。** 计算 <Eq>{`\\lim_{x \\to 0} \\dfrac{\\sin x}{x}`}</Eq>。

**策略。** 检验不定式；应用洛必达法则一次。

**解答。**

直接代入：<Eq>{`\\sin 0 / 0 = 0/0`}</Eq> ——不定式。条件满足（<Eq>{`f = \\sin x`}</Eq> 和 <Eq>{`g = x`}</Eq> 可导，<Eq>{`g' = 1 \\neq 0`}</Eq>）。

<Eq display>{`\\lim_{x \\to 0} \\frac{\\sin x}{x} \\stackrel{0/0}{=} \\lim_{x \\to 0} \\frac{\\cos x}{1} = \\cos 0 = 1`}</Eq>

**验证。** 这个结果是三角基本极限——与泰勒展开式 <Eq>{`\\sin x = x - x^3/6 + \\ldots`}</Eq> 一致，因此 <Eq>{`\\sin x/x \\to 1`}</Eq>。

**来源。** [Active Calculus §2.8, Exercise 2.8.1](https://activecalculus.org/single/sec-2-8-LHR.html) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="反复应用洛必达法则的 0/0 形式">

**问题。** 计算 <Eq>{`\\lim_{x \\to 0} \\dfrac{e^x - 1 - x}{x^2}`}</Eq>。

**策略。** 形式 <Eq>{`0/0`}</Eq>。可能需要多次应用洛必达法则。

**解答。**

直接代入：<Eq>{`(1-1-0)/0 = 0/0`}</Eq>。

<Eq display>{`\\lim_{x \\to 0} \\frac{e^x - 1 - x}{x^2} \\stackrel{0/0}{=} \\lim_{x \\to 0} \\frac{e^x - 1}{2x} \\stackrel{0/0}{=} \\lim_{x \\to 0} \\frac{e^x}{2} = \\frac{1}{2}`}</Eq>

**验证。** 泰勒：<Eq>{`e^x = 1 + x + x^2/2 + \\ldots`}</Eq>，因此 <Eq>{`e^x - 1 - x = x^2/2 + \\ldots`}</Eq>，商 <Eq>{`\\to 1/2`}</Eq>。验证无误。

**来源。** [OpenStax Calculus Vol. 1, §4.8, Example 4.40](https://openstax.org/books/calculus-volume-1/pages/4-8-lhopitals-rule) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="形式 ∞/∞ 与 x → ∞">

**问题。** 计算 <Eq>{`\\lim_{x \\to \\infty} \\dfrac{x^2}{e^x}`}</Eq>。

**策略。** 形式 <Eq>{`\\infty/\\infty`}</Eq>。反复应用洛必达法则直到解决。

**解答。**

<Eq display>{`\\lim_{x \\to \\infty} \\frac{x^2}{e^x} \\stackrel{\\infty/\\infty}{=} \\lim_{x \\to \\infty} \\frac{2x}{e^x} \\stackrel{\\infty/\\infty}{=} \\lim_{x \\to \\infty} \\frac{2}{e^x} = 0`}</Eq>

**验证。** 结果为0——指数增长快于任何幂函数。这证实了 <Eq>{`x^n = o(e^x)`}</Eq> 对所有 <Eq>{`n`}</Eq> 成立的阶层结构。

**来源。** [Active Calculus §2.8, Example 2.8.3](https://activecalculus.org/single/sec-2-8-LHR.html) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="形式 1^∞ 通过取对数">

**问题。** 计算 <Eq>{`\\lim_{x \\to 0^+} x^x`}</Eq>（形式 <Eq>{`0^0`}</Eq>）。

**策略。** 取对数，转化为 <Eq>{`0/0`}</Eq> 或 <Eq>{`\\infty/\\infty`}</Eq> 形式；然后求幂。

**解答。**

设 <Eq>{`L = \\lim_{x \\to 0^+} x^x`}</Eq>。则 <Eq>{`\\ln L = \\lim_{x \\to 0^+} x \\ln x`}</Eq> ——形式 <Eq>{`0 \\cdot (-\\infty)`}</Eq>。

改写：<Eq>{`x \\ln x = \\dfrac{\\ln x}{1/x}`}</Eq> ——形式 <Eq>{`\\infty/\\infty`}</Eq>。

<Eq display>{`\\ln L = \\lim_{x \\to 0^+} \\frac{\\ln x}{1/x} \\stackrel{\\infty/\\infty}{=} \\lim_{x \\to 0^+} \\frac{1/x}{-1/x^2} = \\lim_{x \\to 0^+} (-x) = 0`}</Eq>

因此 <Eq>{`L = e^0 = 1`}</Eq>。极限 <Eq>{`\\lim_{x \\to 0^+} x^x = 1`}</Eq>。

**验证。** 数值上：<Eq>{`(0{,}1)^{0{,}1} \\approx 0{,}794`}</Eq>，<Eq>{`(0{,}01)^{0{,}01} \\approx 0{,}955`}</Eq>，收敛到1。

**来源。** [OpenStax Calculus Vol. 1, §4.8, Example 4.43](https://openstax.org/books/calculus-volume-1/pages/4-8-lhopitals-rule) · CC-BY-NC-SA

</Exemplo>

<Exemplo titulo="形式 ∞ − ∞ 通过合并">

**问题。** 计算 <Eq>{`\\lim_{x \\to 0} \\left(\\dfrac{1}{\\sin x} - \\dfrac{1}{x}\\right)`}</Eq>。

**策略。** 形式 <Eq>{`\\infty - \\infty`}</Eq>。合并为单一分数，然后应用洛必达法则。

**解答。**

<Eq display>{`\\frac{1}{\\sin x} - \\frac{1}{x} = \\frac{x - \\sin x}{x \\sin x}`}</Eq>

当 <Eq>{`x \\to 0`}</Eq> 时：分子 <Eq>{`\\to 0`}</Eq>，分母 <Eq>{`\\to 0`}</Eq> ——形式 <Eq>{`0/0`}</Eq>。

<Eq display>{`\\lim_{x \\to 0} \\frac{x - \\sin x}{x \\sin x} \\stackrel{0/0}{=} \\lim_{x \\to 0} \\frac{1 - \\cos x}{\\sin x + x \\cos x} \\stackrel{0/0}{=} \\lim_{x \\to 0} \\frac{\\sin x}{2\\cos x - x\\sin x} = \\frac{0}{2} = 0`}</Eq>

**验证。** 泰勒：<Eq>{`x - \\sin x = x^3/6 - \\ldots`}</Eq>，<Eq>{`x \\sin x = x^2 - x^4/6 + \\ldots`}</Eq>。商：<Eq>{`(x^3/6)/x^2 = x/6 \\to 0`}</Eq>。验证无误。

**来源。** [APEX Calculus §6.7, Example 6.7.4](https://www.apexcalculus.com/) · CC-BY-NC

</Exemplo>
