### 泰勒多项式

<Definicao titulo="n 阶泰勒多项式">
设 $f: I \to \mathbb{R}$ 在 $a \in I$ 处有 $n$ 阶导数。$f$ 在 $a$ 处的**n 阶泰勒多项式**为
$$P_n(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!} (x - a)^k = f(a) + f'(a)(x-a) + \frac{f''(a)}{2!}(x-a)^2 + \cdots + \frac{f^{(n)}(a)}{n!}(x-a)^n.$$

当 $a = 0$ 时，$P_n$ 称为 $f$ 的**n 阶麦克劳林多项式**。
</Definicao>

> "If $f$ has $n$ derivatives at $x = a$, then the $n$th-order Taylor polynomial of $f$ centered at $a$ is $p_n(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x-a)^k$." — [APEX Calculus §8.6](https://www.apexcalculus.com/downloads)

<Teorema titulo="泰勒多项式的唯一性">
$P_n$ 是唯一的次数 $\leq n$ 的多项式，满足对 $k = 0, 1, \ldots, n$ 有 $P_n^{(k)}(a) = f^{(k)}(a)$。
</Teorema>

### 拉格朗日余项

<Definicao titulo="泰勒余项（拉格朗日形式）">
若 $f$ 在 $a$ 的某邻域内有 $n+1$ 阶连续导数，则**余项** $R_n(x) = f(x) - P_n(x)$ 满足
$$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}$$
其中 $\xi$ 严格介于 $a$ 与 $x$ 之间。
</Definicao>

> "Let $f$ have $n + 1$ derivatives on an open interval $I$ and let $a \in I$. For each $x \in I$ there exists a value $c$ between $a$ and $x$ such that $R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}$." — [OpenStax Calculus Vol. 2 §6.3](https://openstax.org/books/calculus-volume-2/pages/6-3-taylor-and-maclaurin-series)

<Insight titulo="通过泰勒级数的欧拉恒等式">
在 $e^x$ 的级数中令 $x \to ix$：
$$e^{ix} = \sum_{k=0}^\infty \frac{(ix)^k}{k!} = \underbrace{\sum_{k=0}^\infty \frac{(-1)^k x^{2k}}{(2k)!}}_{\cos x} + i\underbrace{\sum_{k=0}^\infty \frac{(-1)^k x^{2k+1}}{(2k+1)!}}_{\sin x}.$$
因此 $e^{ix} = \cos x + i\sin x$。当 $x = \pi$ 时：$e^{i\pi} + 1 = 0$ ——欧拉恒等式。
</Insight>

<Porta nivel="5" titulo="给 5 岁小朋友讲">

想象一条**弯曲的曲线**。你想在某个点附近**复制**它，但只能用直尺和铅笔。

你把直尺放在曲线在那个点处的倾斜角度上。已经有点像了！

如果你再加上一个**圆弧**来调整曲线度，它就会更像了。

每**添加一样东西**（倾斜、弯曲、下一样...），复制就更加逼真。泰勒多项式就是**完美复制的秘诀**——项越多，越准确。

</Porta>

<Porta nivel="10" titulo="给 10 岁小朋友讲">

想法很简单：任何"表现良好"的函数都可以在某个点附近**用多项式来模仿**。

麦克劳林公式（当点是 $0$ 时）是：

$$f(x) \approx f(0) + f'(0)\cdot x + \frac{f''(0)}{2}\cdot x^2 + \frac{f'''(0)}{6}\cdot x^3 + \cdots$$

每个新项都用上了一个更高阶的导数。项越多 = 模仿得越好。

**正弦的例子：** 在 $x = 0$ 处：$\sin 0 = 0$，$\cos 0 = 1$，$-\sin 0 = 0$，$-\cos 0 = -1$，...

所以 $\sin x \approx x - x^3/6 + x^5/120 - \cdots$

对于小的 $x$，$\sin x \approx x$ 就够用了——当 $x < 0{,}1$ 弧度时误差小于 $0{,}2\%$！

</Porta>

<Porta nivel="15" titulo="给 15 岁少年讲">

泰勒是**任意函数与多项式之间的桥梁**——多项式是最容易计算的。

**秘诀：**
1. 选择一个点 $a$（通常 $a = 0$ ——麦克劳林级数）。
2. 计算 $f(a),\, f'(a),\, f''(a),\, \ldots,\, f^{(n)}(a)$。
3. 组织成 $P_n(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x-a)^k$。

**每个学生都应该记住的级数：**

- $e^x = 1 + x + x^2/2 + x^3/6 + \cdots$
- $\sin x = x - x^3/6 + x^5/120 - \cdots$
- $\cos x = 1 - x^2/2 + x^4/24 - \cdots$
- $\ln(1+x) = x - x^2/2 + x^3/3 - \cdots$ 当 $|x| < 1$

**三个直接应用：**

- **逼近数值：** $\sin(0{,}1) \approx 0{,}1 - 0{,}001/6 \approx 0{,}09983$。
- **解极限：** $\lim_{x\to 0}\frac{e^x - 1 - x}{x^2} = \lim_{x\to 0}\frac{x^2/2 + O(x^3)}{x^2} = \frac{1}{2}$。
- **工程学：** $\sin\theta \approx \theta$ 当 $\theta$ 是小角度时——简化摆的微分方程。

</Porta>

<Porta nivel="25" titulo="给工程学学生讲">

泰勒是**工程师的手术刀**：没有它，就没有线性化，没有小信号分析，没有牛顿-拉夫逊法，没有龙格-库塔法。

### 余项的形式

$$f(x) = P_n(x) + R_n(x)$$

**拉格朗日形式：** $R_n = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}$，某个 $\xi$ 在 $a$ 与 $x$ 之间。

**积分形式：** $R_n = \int_a^x \frac{(x-t)^n}{n!} f^{(n+1)}(t)\, dt$。

**Big-O：** $R_n = O((x-a)^{n+1})$ ——快速阅读误差阶数。

### 实际应用

- **线性化：** $f(x) \approx f(x_0) + f'(x_0)(x - x_0)$ ——电子学与控制中小信号分析的基础。
- **牛顿-拉夫逊：** 使用 1 阶泰勒：$f(x) \approx f(x_n) + f'(x_n)(x - x_n) = 0$ 得出 $x_{n+1} = x_n - f(x_n)/f'(x_n)$。
- **龙格-库塔：** 通过多变量泰勒在 $t$ 和 $y$ 上推导；RK4 有全局误差 $O(h^4)$。
- **色散关系：** $\omega(k) \approx \omega_0 + v_g(k - k_0) + \cdots$ ——群速度作为泰勒系数。

### 多变量泰勒（2 阶）

$$f(\vec x) \approx f(\vec a) + \nabla f(\vec a)^T (\vec x - \vec a) + \tfrac{1}{2}(\vec x - \vec a)^T H(\vec a)(\vec x - \vec a)$$

其中 $H$ 是**黑塞矩阵**。对数值优化至关重要。

### 收敛：不总是有保证的

$f(x) = e^{-1/x^2}$（$f(0) = 0$）在 $0$ 处所有导数都为零，因此对所有 $n$ 都有 $P_n = 0$。但 $f \neq 0$ ——光滑函数但**不解析**。泰勒级数确实存在，但**不收敛到** $f$。

</Porta>

<Porta nivel="40" titulo="给资深专业人士讲">

泰勒是复分析、微扰论、数学物理和二阶优化的胚胎。

### 复分析：全纯函数就是解析函数

每个**全纯函数** $f: \Omega \to \mathbb{C}$ 都等于它在任何其定义的开圆盘中的泰勒级数（柯西，1820 年代）。这在 $\mathbb{R}$ 上要强大得多：光滑性（$C^\infty$）不保证解析性；全纯性则保证。美妙之处在这种刚性。

### 量子扰动

$H = H_0 + \lambda V$：本征能量展开成关于 $\lambda$ 的泰勒级数：$E_n(\lambda) = E_n^{(0)} + \lambda E_n^{(1)} + \lambda^2 E_n^{(2)} + \cdots$ 系数通过 Rayleigh-Schrödinger 法。这是泰勒应用在算子空间。

### 渐近级数与收敛级数

Stirling：$\ln(n!) \sim n\ln n - n + \tfrac{1}{2}\ln(2\pi n) + \sum_k B_{2k}/(2k(2k-1)n^{2k-1})$。这个级数对**任何固定的** $n$ 都**发散**，但截断后给出很好的数值近似。哲学上的差异：一个级数即使发散也可能有用——误差会在爆炸之前先减小。

### Padé 近似

有理近似 $f(x) \approx P_m(x)/Q_n(x)$ 对有奇点的函数比泰勒有更好的有效半径。用于量子力学（Padé-Borel 方法）和级数收敛加速。

### 历史背景

Brook Taylor（1715）发表了 *Methodus Incrementorum*，没有收敛性证明。Maclaurin（1742）推广了 $a = 0$ 的情况。Lagrange（1797）形式化了余项。Cauchy（1820 年代）通过围道积分严格证明。这整套机器已经准备好让 Maxwell 构建电磁学，让 Einstein 在平坦度量附近线性化测地线。

</Porta>

<Porta nivel="pratica" titulo="实际应用">

**4 步食谱：**

1. **辨别展开点** $a$（通常 $0$）。
2. **计算导数** $f(a), f'(a), f''(a), \ldots$ 直到所需的阶。
3. **组织** $P_n(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x-a)^k$。
4. **估计误差**：对交替级数递减，$|R_n| < $ 第一个省略项的绝对值。

### 操作技巧

- **替换：** $\sin(x^2) = x^2 - (x^2)^3/6 + \cdots = x^2 - x^6/6 + \cdots$ ——直接来自 sin 级数。
- **乘法：** $e^x \sin x = (1 + x + x^2/2 + \cdots)(x - x^3/6 + \cdots)$，展开至所需阶。
- **积分/求导：** $\arctan x = \int_0^x \frac{1}{1+t^2}\, dt = \int_0^x (1 - t^2 + t^4 - \cdots)\, dt = x - x^3/3 + x^5/5 - \cdots$

### 巴西背景——利率

在金融中，$(1 + r)^n \approx 1 + nr$ 对小利率 $r$（1 阶泰勒）。相对误差：大约 $\binom{n}{2} r^2$。对于月利率 $r = 1\%$ 和 $n = 12$ 月：误差 $\approx 66 \times 0{,}0001 = 0{,}66\%$ ——对快速年回报率估计来说可以忽略。

```python
import sympy as sp

```

## 已解决的例子

<Exemplo titulo="e^x 的麦克劳林展开至 4 阶（直接应用）" numero="1">

**问题。** 求 $f(x) = e^x$ 的 4 阶麦克劳林多项式，并估计 $x = 0{,}5$ 处的误差。

**策略。** 由于 $\frac{d^k}{dx^k}e^x = e^x$，所有在 $a = 0$ 处的导数都等于 $1$。直接组织 $P_4$。使用拉格朗日余项，其中 $f^{(5)} = e^x$。

**求解。**

1. **在 $0$ 处的导数：** 对所有 $k$ 有 $f^{(k)}(0) = e^0 = 1$。
2. **多项式：** $P_4(x) = 1 + x + \dfrac{x^2}{2} + \dfrac{x^3}{6} + \dfrac{x^4}{24}$。
3. **$x = 0{,}5$ 处的误差：** $|R_4(0{,}5)| \leq \dfrac{e^\xi}{5!}(0{,}5)^5 \leq \dfrac{e^{0{,}5}}{120}\cdot\dfrac{1}{32} \approx \dfrac{1{,}649}{120 \cdot 32} \approx 0{,}000430$。
4. **近似值：** $P_4(0{,}5) = 1 + 0{,}5 + 0{,}125 + 0{,}02083 + 0{,}002604 \approx 1{,}6484$。精确值：$e^{0{,}5} \approx 1{,}6487$ ——误差小于 $3 \times 10^{-4}$。$\checkmark$

**验证。** 估计的误差 $4{,}3 \times 10^{-4}$ 大于实际误差 $3 \times 10^{-4}$：拉格朗日余项是一个上界。$\checkmark$

**来源。** [OpenStax Calculus Vol. 2, §6.3, Example 6.17](https://openstax.org/books/calculus-volume-2/pages/6-3-taylor-and-maclaurin-series) — CC-BY-NC-SA。
</Exemplo>

<Exemplo titulo="ln x 在 a = 1 处的泰勒展开（中级）" numero="2">

**问题。** 求 $f(x) = \ln x$ 在 $a = 1$ 处的 3 阶泰勒多项式。

**策略。** 计算 $f, f', f'', f'''$ 在 $x = 1$ 处的值。以 $(x - 1)$ 为变量组织 $P_3$。

**求解。**

1. **导数：** $f(x) = \ln x$，$f'(x) = 1/x$，$f''(x) = -1/x^2$，$f'''(x) = 2/x^3$。
2. **在 $a = 1$ 处：** $f(1) = 0$，$f'(1) = 1$，$f''(1) = -1$，$f'''(1) = 2$。
3. **多项式：**
$$P_3(x) = 0 + 1\cdot(x-1) + \frac{-1}{2!}(x-1)^2 + \frac{2}{3!}(x-1)^3 = (x-1) - \frac{(x-1)^2}{2} + \frac{(x-1)^3}{3}.$$
4. **在 $x = 1{,}1$ 处的测试：** $P_3(1{,}1) = 0{,}1 - 0{,}005 + 0{,}000333 \approx 0{,}09533$。精确值：$\ln(1{,}1) \approx 0{,}09531$。$\checkmark$

**验证。** $\ln(1+u) = u - u^2/2 + u^3/3 - \cdots$ 级数中令 $u = x - 1$ 与 $P_3$ 相符。$\checkmark$

**来源。** [Active Calculus §8.5, Activity 8.5.3](https://activecalculus.org/single/sec-8-5-taylor.html) — CC-BY-NC-SA。
</Exemplo>

<Exemplo titulo="通过泰勒求极限：lim (sin x - x)/x^3（中级）" numero="3">

**问题。** 计算 $\displaystyle\lim_{x \to 0} \frac{\sin x - x}{x^3}$。

**策略。** 将 $\sin x$ 的麦克劳林级数代入分子并化简。避免了多次应用洛必达法则。

**求解。**

1. **级数：** $\sin x = x - \dfrac{x^3}{6} + \dfrac{x^5}{120} - \cdots$
2. **分子：** $\sin x - x = -\dfrac{x^3}{6} + \dfrac{x^5}{120} - \cdots$
3. **除以 $x^3$：** $\dfrac{\sin x - x}{x^3} = -\dfrac{1}{6} + \dfrac{x^2}{120} - \cdots$
4. **极限：** 当 $x \to 0$ 时，所有含 $x$ 的项都趋于零。极限是 $\mathbf{-1/6}$。

**验证。** 应用洛必达法则三次也会得到 $-1/6$，但泰勒方法更快。$\checkmark$

**来源。** [OpenStax Calculus Vol. 2, §6.3, Example 6.20](https://openstax.org/books/calculus-volume-2/pages/6-3-taylor-and-maclaurin-series) — CC-BY-NC-SA。
</Exemplo>

<Exemplo titulo="近似 sin x ≈ x 对摆的误差（建模）" numero="4">

**问题。** 一个摆使用近似 $\sin\theta \approx \theta$。对于 $\theta = 15° = \pi/12$ 弧度，相对误差百分比是多少？

**策略。** 精确计算 $\sin(\pi/12)$ 并与 $\pi/12$ 比较。通过级数的下一项估计误差：$-\theta^3/6$。

**求解。**

1. **弧度制的角度：** $\theta = \pi/12 \approx 0{,}2618$ 弧度。
2. **精确值：** $\sin(\pi/12) = \sin(15°) = (\sqrt{6} - \sqrt{2})/4 \approx 0{,}2588$。
3. **近似：** $\theta = 0{,}2618$。
4. **绝对误差：** $|0{,}2618 - 0{,}2588| = 0{,}0030$。
5. **相对误差：** $0{,}0030 / 0{,}2588 \approx 1{,}16\%$。
6. **通过泰勒：** 误差 $\approx \theta^3/6 = (0{,}2618)^3/6 \approx 0{,}00298$ ——非常接近计算的误差。$\checkmark$

**验证。** 对于 $\theta < 0{,}1$ 弧度（约 $5{,}7°$），误差降至 $0{,}017\%$ 以下——证实了工程学中的使用。$\checkmark$

**来源。** [APEX Calculus §8.6, Exercise 8.6.13](https://www.apexcalculus.com/downloads) — CC-BY-NC。
</Exemplo>

<Exemplo titulo="通过复合的麦克劳林展开：e^(sin x) 至 3 阶（进阶）" numero="5">

**问题。** 求 $f(x) = e^{\sin x}$ 的麦克劳林多项式至 3 阶。

**策略。** 将 $\sin x$ 的级数代入 $e^u$ 的级数，聚集项至 $x^3$。

**求解。**

1. **sin 的级数：** $\sin x = x - x^3/6 + O(x^5)$。
2. **$u = \sin x$：** 则 $e^u = 1 + u + u^2/2 + u^3/6 + O(u^4)$。
3. **替换：** $u = x - x^3/6 + \cdots$，因此：
   - $u = x - x^3/6$
   - $u^2 = x^2 - 2x\cdot x^3/6 + \cdots = x^2 + O(x^4)$
   - $u^3 = x^3 + O(x^5)$
4. **组织：**
$$e^{\sin x} = 1 + \left(x - \tfrac{x^3}{6}\right) + \frac{x^2}{2} + \frac{x^3}{6} + O(x^4) = 1 + x + \frac{x^2}{2} + 0 \cdot x^3 + O(x^4).$$
5. **结果：** $P_3(x) = 1 + x + \dfrac{x^2}{2}$。

**验证。** 在 $x = 0$：$f(0) = e^0 = 1$ $\checkmark$。$f'(0) = e^{\sin 0}\cos 0 = 1$ $\checkmark$。$f''(0) = e^{\sin 0}(\cos^2 0 - \sin 0) = 1$ $\checkmark$。

**来源。** [APEX Calculus §8.6, Exercises 8.6.17–8.6.20](https://www.apexcalculus.com/downloads) — CC-BY-NC。
</Exemplo>
