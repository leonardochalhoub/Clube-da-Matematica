### 统计推断的三个支柱

<Definicao titulo="支柱1——置信区间估计">

设 $X_1, \ldots, X_n \overset{iid}{\sim} N(\mu, \sigma^2)$。

**均值的双侧置信水平 $1-\alpha$ 置信区间**（$\sigma$ 已知）：

<Equation explicacao="已知总体标准差的均值置信区间。" latex="\bar X \pm z_{\alpha/2}\frac{\sigma}{\sqrt{n}}" />

**$\sigma$ 未知时的置信区间**——使用 t 分布，自由度为 $n-1$：

<Equation explicacao="使用样本标准差的均值置信区间（更常见的实际应用）。" latex="\bar X \pm t_{\alpha/2;\,n-1}\frac{s}{\sqrt{n}}" />

**样本量** 以获得最大误差界 $E$：

<Equation explicacao="样本量公式：z的平方乘以西格玛，除以E的平方。" latex="n \geq \left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^2" />

</Definicao>

> "置信区间为总体参数提供了一个合理的值域。正确的解释：如果多次重复该程序，构建的区间中有 $(1-\alpha)100\%$ 将包含真实参数。" — [OpenIntro Statistics §5.2](https://www.openintro.org/book/os/)

<Definicao titulo="支柱2——假设检验（统一视角）">

所有假设检验都遵循相同的框架：

1. 陈述 $H_0$ 和 $H_1$。
2. 计算 $H_0$ 下的**检验统计量**。
3. 计算 **p值** = $P(\text{结果至少与观察结果一样极端} \mid H_0)$。
4. 如果 $p \leq \alpha$，拒绝 $H_0$。

**检验地图：**

| 场景 | 统计量 | 分布 |
|---|---|---|
| 1个均值，$\sigma$ 已知 | $Z = (\bar X - \mu_0)/(\sigma/\sqrt{n})$ | $N(0,1)$ |
| 1个均值，$\sigma$ 未知 | $T = (\bar X - \mu_0)/(s/\sqrt{n})$ | $t_{n-1}$ |
| 2个独立均值 | Welch $T$ | $t_{\nu}$（Welch 自由度） |
| $k$ 个均值 | $F = MS_B/MS_W$ | $F_{k-1,\,N-k}$ |
| 列联表 | $\chi^2 = \sum (O-E)^2/E$ | $\chi^2_{(r-1)(c-1)}$ |
| 比例vs参考值 | $Z = (\hat p - p_0)/\sqrt{p_0(1-p_0)/n}$ | $N(0,1)$ |

</Definicao>

<Definicao titulo="支柱3——回归与预测建模">

**简单线性回归** $\hat Y = \hat\beta_0 + \hat\beta_1 X$：

<Equation explicacao="简单回归的普通最小二乘估计量。" latex="\hat\beta_1 = \frac{S_{xy}}{S_{xx}},\quad \hat\beta_0 = \bar Y - \hat\beta_1 \bar X" />

**多元回归** $\hat{\mathbf{y}} = X\hat{\boldsymbol\beta}$：

<Equation explicacao="多元回归的向量最小二乘估计量。" latex="\hat{\boldsymbol\beta} = (X^\top X)^{-1} X^\top \mathbf{y}" />

**决定系数**及其调整版本：

<Equation explicacao="调整R平方对额外预测变量进行惩罚，这些变量对拟合没有贡献。" latex="R^2_{\text{adj}} = 1 - \frac{(1-R^2)(n-1)}{n-p-1}" />

</Definicao>

<Teorema titulo="贝叶斯信念更新规则">

设 $\theta$ 为感兴趣的参数，$D$ 为观察数据：

<Equation explicacao="后验分布正比于似然乘以先验。" latex="P(\theta \mid D) = \frac{P(D \mid \theta)\,P(\theta)}{P(D)} \propto P(D \mid \theta)\,P(\theta)" />

**Beta-Binomial 共轭：** 如果 $\theta \sim \text{Beta}(\alpha, \beta)$ 且 $X \mid \theta \sim \text{Bin}(n, \theta)$，则：

<Equation explicacao="当先验为Beta且似然为二项分布时的后验分布——先验通过累加成功和失败来更新。" latex="\theta \mid X \sim \text{Beta}(\alpha + X,\; \beta + n - X)" />

</Teorema>

<Porta nivel="5" titulo="五岁小孩的讲法">

想象你想知道**一个巨大罐子里有多少颗糖**。

- 你不数所有的——拿一把，数一下，然后**猜一个区间**："应该有200到300颗"。这就是**置信区间**。
- 你的朋友说"恰好有150颗"。你看了你的这把，想"如果只有150颗，这不太可能"。所以你说"我不相信！"——这就是**假设检验**。
- 昨天你对这个罐子已经有所了解。今天你把"昨天的知识"和你现在数的东西结合起来，变得更聪明了。这就是**贝叶斯**——通过结合所知和所见来学习。

这三种方法合在一起，就像是一个**很好的数字侦探**。

</Porta>

<Porta nivel="10" titulo="十岁小孩的讲法">

你在第11三学期学会了**从样本中得出结论**。

**之前是什么样，现在是什么样：**

以前，你计算整个班级的平均数——你**有了**所有数据。现在你用一个**样本**学习，对**世界**做出声明。

**三个方法：**

1. **置信区间：** "有95%的置信度，学校的平均成绩在6.2到7.1之间。"你不知道确切的值——给出一个合理的区间。

2. **假设检验：** "新教材提高了平均成绩吗？"你收集数据，计算如果没有改进这个结果的概率（p值），然后决定是否相信有改进。

3. **贝叶斯：** 你在收集数据之前就已经知道一些东西。用贝叶斯，你把之前知道的（先验）和观察到的（数据）结合起来，更新信念。

**选择方法：**

- 我想估计一个均值：用 $t$ 的置信区间。
- 我想比较两个组：$t$ 检验。
- 我想比较好几个组：方差分析。
- 我想交叉两个分类变量：卡方检验。
- 我想从 $X$ 预测 $Y$：回归。
- 我想更新我的信念：贝叶斯。

</Porta>

### 综合：频率论vs贝叶斯主义

**频率论视角**（第102–108课）：

- 参数（$\mu$、$\sigma$、$\beta$）是**未知常数**——它们没有分布。
- 置信区间：关于重复假想实验的覆盖率。
- p值：" 如果 $H_0$ 为真，这个结果的概率有多小？"

**贝叶斯视角**（第109课）：

- 参数有**反映不确定性的概率分布**。
- 可信区间：" 给定观察数据，有95%的概率 $\theta \in [a, b]$。"
- 更新：先验+似然=后验。

### 第11三学期揭示的联系

| 关系 | 细节 |
|---|---|
| 带虚拟变量的回归=t检验 | 1个二元预测变量→截距和系数是各组的均值 |
| 方差分析=带k-1个虚拟变量的回归 | 模型的总F=方差分析的F |
| 当 $k = 2$ 时 $F = T^2$ | 2个组的方差分析与双侧t检验相同 |
| 均匀先验下的MAP=MLE | 当你没有先验信息时，频率论和贝叶斯一致 |

### 经常犯的错误（永远不要犯这些）

1. **$p = 0{,}06$ 不是 $H_0$ 的证据**——只是"在5%水平下我们不拒绝 $H_0$"。
2. **统计显著性 $\neq$ 实际显著性**——微小的效应可能在 $n$ 很大时显著。
3. **相关性 $\neq$ 因果性**——回归不证明原因。
4. **$R^2$ 高 $\neq$ 模型好**——残差中可能有模式。
5. **p-挖掘**——测试多个假设而不做多重比较修正会增加第一类错误。

</Porta>

<Porta nivel="25" titulo="工程专业学生讲法">

### 一切都是广义线性模型（GLM）

线性回归、方差分析、t检验和卡方的对数线性模型都是**广义线性模型**的情况：

$$g(E[Y]) = X\beta$$

| 方法 | $Y$ 的分布 | 链接函数 $g$ |
|---|---|---|
| 线性回归 | 正态 | 恒等 |
| 方差分析 | 正态 | 恒等 |
| Logistic回归 | 伯努利 | Logit |
| Poisson回归 | Poisson | Log |
| 多项式回归 | 多项式 | 多元logit |

掌握GLM=掌握所有经典参数推断。

### 重新抽样：非参数替代方法

- **Bootstrap：** 任何统计量的置信区间和标准错误，无需分布假设。
- **排列：** 不需要正态性假设的p值。
- **交叉验证：** 稳健的预测评估。

### 功效分析（在实践中使用不足）

在任何数据收集之前，计算样本量以用80%的功效检测最小相关效应：

$$n = \frac{2\sigma^2(z_\alpha + z_\beta)^2}{\delta^2}$$

其中 $\delta$ 是最小可检测差异，$z_\alpha$ 和 $z_\beta$ 对应第一类和第二类错误。

没有功效分析，实验要么夭折，要么产生没人能重复的不确定结果。

### 专业分析检查清单

1. 预注册假设（OSF、AsPredicted）。
2. 功效分析和 $n$ 计算。
3. 用控制设计收集（随机化、盲法）。
4. 验证假设（正态性、同方差性、独立性）。
5. 报告：估计值+置信区间+效应量+p值。
6. 残差诊断（回归）。
7. 多重比较修正（Bonferroni、FDR）。

### 统计推断的哲学

四所学派形成了当前的格局：

- **Neyman-Pearson频率论：** 控制长期错误率（$\alpha$、$\beta$）。置信区间有频数覆盖，不是包含参数的概率。
- **Fisher：** p值作为反对 $H_0$ 的连续证据度量。没有拒绝/不拒绝二分法。
- **似然主义（Edwards）：** 似然比作为模型之间的证据度量。没有先验。
- **贝叶斯（Jeffreys、Lindley、McElreath）：** 参数有分布；后验是完整答案。允许关于假设的直接概率声明。

没有哪种方法普遍优越。选择取决于背景、目标和分析师接受的假设。

### 重复危机和我们学到的东西

2015年，开放科学合作组织复制了心理学的100项研究——只有36%复制成功。原因是工具性的：

1. P-挖掘和HARKing（已知结果后的假设）。
2. 忽视功效分析——小效应、样本不足。
3. 多重比较无修正。
4. 数据和代码不共享。
5. 发表偏差（负结果不出现）。

社区实现的解决方案：预注册、直接重复、开放科学、注册报告和 $p < 0{,}05$ 以外的指标（效应量、BIC、贝叶斯因子）。

### 当前前沿

- **因果推断（Pearl、Rubin）：** DAG、do-演算、工具变量、RDD、差分。经典统计估计关联；因果推断估计反事实。
- **高维：** $p \gg n$。Lasso、岭、弹性网、knockoffs（Candès）用于FDR控制。
- **选择性推断：** 变量选择后有效的p值。
- **贝叶斯计算：** HMC（Stan）、变分推断、ABC。使复杂分层模型易处理。
- **预测vs推理模型：** 机器学习最大化预测准确度；推断最大化可解释性和因果有效性。Breiman（2001）称这为"两种文化"。

### 统计学中的伦理

操纵数据、事后选择检验而不披露、不报告预指定分析——这些做法越过了科学诚信的底线。美国统计学会关于p值的声明（2016）对任何专业人士都是必读的。

### 案例1——圣保罗的平均租金

一家房地产公司从南区2卧室公寓中抽样 $n = 49$ 套。平均样本租金 R\$ 2.850/月，样本标准差 R\$ 420/月。

**平均租金的95%置信区间：**
$t_{0,025;\,48} \approx 2{,}011$。误差界：$2{,}011 \times 420/7 = 120{,}66$。
置信区间：R\$ 2.729 至 R\$ 2.971。

**检验：** 市政府声称平均租金是 R\$ 2.700。$T = (2850 - 2700)/(420/7) = 2{,}50$。双侧p值 $\approx 0{,}016 < 0{,}05$。拒绝 $H_0$。

### 案例2——ENEM中的组间比较

公立学校学生（组1，$n_1 = 200$，$\bar X_1 = 540$，$s_1 = 80$）vs私立（组2，$n_2 = 200$，$\bar X_2 = 590$，$s_2 = 75$）。Welch $T$，差异的95%置信区间。

### 案例3——登陆页面A/B测试

版本A：1000名访客中有120次转化。版本B：150/1000。比例差异的z检验：
$\hat p_A = 0{,}12$，$\hat p_B = 0{,}15$，$\hat p = 0{,}135$。
$Z = (0{,}15 - 0{,}12)/\sqrt{0{,}135 \cdot 0{,}865 \cdot (1/1000 + 1/1000)} = 2{,}09$。
双侧p值 $\approx 0{,}037 < 0{,}05$。B在5%水平上更好。

### 案例4——肥料和产量（方差分析）

4种肥料，每种25株植物，产量（kg/ha）。方差分析 $F(3, 96)$。如果 $F > F_{0,05;\,3,96} \approx 2{,}70$，某些肥料不同。事后检验：Tukey HSD。

### 案例5——房产价格回归

$Y$ = 价格（千雷亚尔），$X_1 = m^2$，$X_2$ = 卧室数，$X_3$ = 年龄。用 $n = 200$ 套房产进行OLS拟合。解释每个 $\hat\beta_i$、$R^2_{\text{adj}}$和残差诊断。

### 案例6——质量控制中的贝叶斯

一批零件中有缺陷比例 $\theta$。先验：$\text{Beta}(2, 18)$（经验：约10%缺陷）。检查 $n = 50$，发现 $x = 8$ 个缺陷。后验：$\text{Beta}(10, 60)$。后验平均：$10/70 \approx 14{,}3\%$。95%可信区间通过Beta的分位数。

## 已解决的例子

<Exemplo titulo="ENEM平均成绩的95%置信区间（标准差未知）" numero="1">

**问题。** 2023年ENEM数学科目的 $n = 36$ 名考生样本平均分 $\bar X = 580$ 分，样本标准差 $s = 90$ 分。为总体平均分 $\mu$ 构建95%置信区间。

**策略。** 因为 $\sigma$ 未知，使用 $n - 1 = 35$ 自由度的 $t$ 分布。从表中找 $t_{0,025;\,35}$。

**解决。**

$t_{0,025;\,35} = 2{,}030$。

误差界：$E = 2{,}030 \times \frac{90}{\sqrt{36}} = 2{,}030 \times 15 = 30{,}45$。

95%置信区间：$(580 - 30{,}45\;;\; 580 + 30{,}45) = (549{,}55\;;\; 610{,}45)$。

**验证。** 误差界随 $s$ 增加而增加，随 $\sqrt{n}$ 增加而减少。对于 $n = 144$，误差界为 $2{,}030 \times 90/12 = 15{,}2$——一半，因为 $n$ 增加了四倍。

**来源。** [OpenIntro Statistics §5.2](https://www.openintro.org/book/os/) — 练习 5.5，第222页 · CC-BY-SA。

</Exemplo>

<Exemplo titulo="单样本t检验与政府目标的比较" numero="2">

**问题。** 政府声称UBS平均就诊时间为 $\mu_0 = 20$ 分钟。一次审计抽样 $n = 25$ 次就诊：$\bar X = 24{,}8$ 分钟，$s = 7{,}2$ 分钟。在 $\alpha = 5\%$ 水平上，有证据证明真实平均值超过20分钟吗？

**策略。** 单侧右尾t检验（$H_1: \mu > 20$），$df = 24$。

**解决。**

$T = \frac{24{,}8 - 20}{7{,}2/\sqrt{25}} = \frac{4{,}8}{1{,}44} = 3{,}33$。

$t_{0,05;\,24} = 1{,}711$（单侧）。因为 $3{,}33 > 1{,}711$，拒绝 $H_0$。

p值：$P(t_{24} \geq 3{,}33) \approx 0{,}001 < 0{,}05$。有证据证明平均时间超过20分钟。

**验证。** 95%单侧置信区间下界：$24{,}8 - 1{,}711 \times 1{,}44 = 22{,}33$ 分钟。值 $\mu_0 = 20$ 在此限制下，确认拒绝。

**来源。** [Statistics, OpenStax §9.4](https://openstax.org/books/statistics/pages/9-4-comparing-two-independent-population-means) — 改编自例9.10，第476页 · CC-BY。

</Exemplo>

<Exemplo titulo="单因素方差分析——3种肥料的产量" numero="3">

**问题。** 三种肥料在 $n_i = 10$ 株植物的组中进行了测试。产量（kg）：$\bar X_1 = 12{,}0$，$\bar X_2 = 14{,}5$，$\bar X_3 = 13{,}2$。总平均 $\bar X = 13{,}23$。$SS_W = 162$（组内平方和）。在5%水平上，肥料之间有差异吗？

**策略。** 方差分析：计算 $SS_B$，获得 $F$，与 $F_{0,05;\,2,\,27}$ 比较。

**解决。**

$SS_B = 10[(12{,}0 - 13{,}23)^2 + (14{,}5 - 13{,}23)^2 + (13{,}2 - 13{,}23)^2]$
$= 10[1{,}513 + 1{,}613 + 0{,}001] = 31{,}27$。

$MS_B = 31{,}27/2 = 15{,}64$；$MS_W = 162/27 = 6{,}00$。

$F = 15{,}64 / 6{,}00 = 2{,}61$。

$F_{0,05;\,2,\,27} \approx 3{,}35$。因为 $2{,}61 < 3{,}35$，**不拒绝 $H_0$** ——在5%水平上没有证据表明肥料之间有差异。

**验证。** p值 $\approx 0{,}092 > 0{,}05$。结果一致。如果每组 $n_i = 20$，功效会更大，可能会有拒绝。

**来源。** [OpenIntro Statistics §7.5](https://www.openintro.org/book/os/) — 基于方差分析例，第319页 · CC-BY-SA。

</Exemplo>

<Exemplo titulo="简单线性回归——薪资对工作经验" numero="4">

**问题。** 以 $n = 20$ 名专业人员为例：$\bar X = 8$ 年，平均薪资 R\$ 6.200（$\bar Y = 6.200$），$S_{xx} = 180$，$S_{xy} = 54.000$。拟合回归模型并解释系数。

**策略。** 用最小二乘公式计算 $\hat\beta_1$ 和 $\hat\beta_0$；在背景中解释。

**解决。**

$\hat\beta_1 = S_{xy}/S_{xx} = 54.000/180 = 300$。

$\hat\beta_0 = \bar Y - \hat\beta_1 \bar X = 6.200 - 300 \times 8 = 3.800$。

模型：$\hat Y = 3.800 + 300\,X$（单位：雷亚尔，$X$ 单位：年）。

**解释。** 每增加一年工作经验，平均薪资增加 R\$ 300。截距 R\$ 3.800 是0年经验时的估计薪资（外推——谨慎使用）。

**验证。** 对于 $X = 10$ 年：$\hat Y = 3.800 + 3.000 = 6.800$ 雷亚尔（R\$ 6.800）。鉴于 $\bar Y = 6.200$ 当 $\bar X = 8$，是合理的。

**来源。** [OpenIntro Statistics §8.2](https://www.openintro.org/book/os/) — 基于练习 8.13（薪资数据），第360页 · CC-BY-SA。

</Exemplo>

<Exemplo titulo="贝叶斯更新——生产线上的缺陷比例" numero="5">

**问题。** 一位质量工程师相信生产线的缺陷比例 $\theta$ 先验为 $\text{Beta}(3, 17)$（先验平均 $= 3/20 = 15\%$）。检查 $n = 40$ 个零件并发现 $X = 4$ 个缺陷。后验分布是什么？对 $\theta$ 的新点估计是什么？

**策略。** 使用Beta-Binomial共轭：后验 $= \text{Beta}(\alpha + X, \beta + n - X)$。

**解决。**

后验：$\text{Beta}(3 + 4,\; 17 + 40 - 4) = \text{Beta}(7, 53)$。

后验平均：$7/(7+53) = 7/60 \approx 11{,}7\%$。

95%可信区间：$\text{Beta}(7, 53)$ 的2.5%和97.5%分位数，约 $[0{,}049;\; 0{,}221]$。

**验证。** 之前：先验平均15%。看到40个中的4个缺陷后（最大似然估计=10%），后验转移到11.7%——先验和数据的加权平均。随着样本量增加，后验越来越接近最大似然估计。

**来源。** [Statistical Thinking for the 21st Century, Ch. 15](https://statsthinking21.org/) — Beta-Binomial例的结构，§15.3 · CC-BY-NC。

</Exemplo>

    <p><em>趣事：</em>Beta分布被称为二项的共轭正好因为先验和后验有相同的分布族——更新只是加指数。</p>
  </>}
>

通过积分（或通过核识别）证明如果 $\theta \sim \text{Beta}(\alpha, \beta)$ 且 $X \mid \theta \sim \text{Bin}(n, \theta)$，则 $\theta \mid X \sim \text{Beta}(\alpha + X,\; \beta + n - X)$。
