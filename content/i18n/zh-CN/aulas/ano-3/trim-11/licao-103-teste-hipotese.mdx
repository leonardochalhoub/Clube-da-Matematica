### 假设检验的五个要素

<Definicao titulo="检验的形式结构">

1. **假设**：$H_0$（原假设）— 待检验的声明 — 对比 $H_1$（备选假设）。
2. **检验统计量** $T = T(X_1, \ldots, X_n)$：从样本计算出的在 $H_0$ 下有已知分布的值。
3. **显著性水平** $\alpha$：在 $H_0$ 为真时，拒绝 $H_0$ 的最大可容忍概率。典型值：$\alpha = 0{,}05$。
4. **拒绝域** $\mathcal{R}$：导致拒绝 $H_0$ 的 $T$ 值集合。
5. **决策**：若 $T \in \mathcal{R}$（或等价地，若 $p\text{-值} \leq \alpha$），则拒绝 $H_0$。

</Definicao>

> "零假设 $H_0$ 代表怀疑的主张。这是除非有充分证据反对它，否则将保持的现状。" — [OpenIntro Statistics, §5.1](https://www.openintro.org/book/os/)

### 错误与检验功效

<Definicao titulo="第I型错误、第II型错误和功效">

|  | $H_0$ 为真 | $H_0$ 为假 |
|---|---|---|
| **拒绝 $H_0$** | 第I型错误 ($\alpha$) | 正确决策（功效 $= 1-\beta$） |
| **未拒绝 $H_0$** | 正确决策 | 第II型错误 ($\beta$) |

- **第I型错误**（假阳性）：当 $H_0$ 为真时拒绝它。概率由 $\alpha$ 控制。
- **第II型错误**（假阴性）：当 $H_0$ 为假时未拒绝它。概率为 $\beta$（取决于 $H_1$、$\sigma$、$n$）。
- **功效** $= 1 - \beta$：检测到真实效应的概率。

对于固定的样本容量，减小 $\alpha$ 会增加 $\beta$（权衡）。不舍弃 $\alpha$ 而增加功效的方式：增加 $n$。

</Definicao>

### p值的形式定义

<Definicao titulo="p值">

**p值**是假设 $H_0$ 为真的条件下，检验统计量取得与观测值一样极端或更加极端的值的概率：

<Equation explicacao="双侧p值：考虑在零假设均值两侧的偏差。" latex="p = P(\lvert T \rvert \geq \lvert t_{\mathrm{obs}} \rvert \mid H_0) \quad \text{(双侧)}" />

<Equation explicacao="右尾p值：检测大于mu0的效应。" latex="p = P(T \geq t_{\mathrm{obs}} \mid H_0) \quad \text{(单侧 } H_1: \mu > \mu_0\text{)}" />

</Definicao>

> "p值衡量数据与 $H_0$ 的一致性程度。小的p值表明数据与 $H_0$ 不相容 — 而非 $H_0$ 以概率 $1-p$ 为假。" — [OpenIntro Statistics, §5.1](https://www.openintro.org/book/os/)

### 备选假设的类型

<Definicao titulo="双侧和单侧检验">

对于 $H_0: \mu = \mu_0$：

- $H_1: \mu \neq \mu_0$ — **双侧**。两侧拒绝域：$\lvert T \rvert > t_{\alpha/2}$。
- $H_1: \mu > \mu_0$ — **右尾单侧**。拒绝域：$T > t_\alpha$。
- $H_1: \mu < \mu_0$ — **左尾单侧**。拒绝域：$T < -t_\alpha$。

双侧检验更保守（双侧p值 = $2 \times$ 对应单侧p值）。

</Definicao>

<Insight>

p值**不是**：$H_0$ 为真的概率；结果由运气造成的概率；效应为真的概率。它仅仅是在指定模型下数据与 $H_0$ 相容性的一个衡量。美国统计学会（ASA）在2016年发布了一份正式声明，警告p值的不当使用。

</Insight>

</Porta>

<Porta nivel="5" titulo="给5岁孩子的解释">

你的朋友说他有一个**正常的**骰子。你怀疑它是不是作弊。如何证明？

你假设："好的，我假设这个骰子是正常的。"这就是**原假设** — 现状。

然后你掷骰子60次。如果掷出6的次数是40次（应该约10次），这明显有问题！这就是**p值很小** — 如果骰子是正常的，这些结果非常奇怪。

当结果异常到不可能是巧合时，你拒绝："这个骰子是作弊的！"

</Porta>

<Porta nivel="10" titulo="给10岁孩子的解释">

想象你怀疑一枚硬币是否作弊。你掷100次硬币，出现60次正面。

**第1步**：原假设 — "这枚硬币是公正的，正面出现50%的时间。"

**第2步**：备选假设 — "硬币是作弊的。"

**第3步**：关键问题 — 如果硬币公正，你在100次掷硬币中掷出70次或以上正面的概率是多少？

**第4步**：计算这个数字。这就是**p值**。如果它很小（小于5%），你得出结论：用运气来解释这一点是没有意义的 — 硬币是作弊的！

**实用规则**：p值小于0.05（5%）表明数据难以用原假设解释。我们拒绝它。

</Porta>

### 假设检验的逻辑

假设检验是一个形式协议，用于根据证据做出决策，同时控制错误的概率。

**5步结构：**

1. **表述 $H_0$ 和 $H_1$**：$H_0$ 是现状（无效应、无差异），$H_1$ 是你想要证明的。

2. **选择 $\alpha$**：通常社会科学为0.05（5%），医学为0.01（1%），粒子物理学为 $5 \times 10^{-7}$。

3. **计算检验统计量**：总结数据离 $H_0$ 的距离的数字。

4. **计算p值**：在 $H_0$ 为真的假设下，观察到某样极端的东西的概率。

5. **决策**：若 $p \leq \alpha$，拒绝 $H_0$。若 $p > \alpha$，"未拒绝"（注意：这并不意味着 $H_0$ 为真！）。

### 第I型错误对比第II型错误

你永远不会完全确定。可能的两个错误：

| 错误 | 何时发生 | 后果 |
|---|---|---|
| 第I型（假阳性） | 当 $H_0$ 为真时拒绝它 | 宣布一个不存在的效应 |
| 第II型（假阴性） | 当 $H_0$ 为假时未拒绝它 | 遗漏真实效应 |

$\alpha$ 控制第I型。增加 $n$ 减少第II型。

### 例子

一家工厂声称其灯泡的平均寿命为 $\mu_0 = 1000$ 小时。一个 $n = 25$ 个灯泡的样本给出 $\bar X = 980$ 小时，$s = 50$ 小时。

$H_0: \mu = 1000$ 小时对比 $H_1: \mu < 1000$ 小时（制造商高估了）。

t统计量：$T = (980 - 1000)/(50/\sqrt{25}) = -20/10 = -2{,}0$。

对于 $t_{24}$ 单侧 $\alpha = 0{,}05$：临界值 $\approx -1{,}711$。由于 $-2{,}0 < -1{,}711$，我们拒绝 $H_0$。

</Porta>

### 检验作为最优决策规则

Neyman-Pearson检验将问题形式化：给定第I型和第II型间的权衡，对于简单假设 $H_0: \theta = \theta_0$ 对比 $H_1: \theta = \theta_1$，**最优拒绝域**是什么？

**Neyman-Pearson引理**：水平 $\alpha$ 最有力的拒绝域是：

$$\mathcal{R}_{NP} = \left\{\mathbf{x} : \frac{L(\theta_1 \mid \mathbf{x})}{L(\theta_0 \mid \mathbf{x})} > c_\alpha\right\}$$

其中 $c_\alpha$ 被选择使得 $P(\mathbf{X} \in \mathcal{R}_{NP} \mid H_0) = \alpha$。

对于复合假设，广义似然比检验（GLRT）扩展了这一结果。

### 检验功效和 $n$ 的计算

**功效** $1 - \beta = P(\text{拒绝 } H_0 \mid H_1)$ 取决于：

- 真实距离 $\delta = |\mu_1 - \mu_0|$（效应大小）
- $\sigma$（变异性）
- $n$（样本容量）
- $\alpha$（显著性水平）

为了以功效 $1-\beta$ 和水平 $\alpha$ 检测差异 $\delta$（均值双侧检验）：

$$n = \frac{(z_{\alpha/2} + z_\beta)^2 \sigma^2}{\delta^2}$$

对于 $\alpha = 0{,}05$ 和功效80%（$z_\beta = 0{,}842$）：$n = (1{,}96 + 0{,}842)^2 \sigma^2/\delta^2 \approx 7{,}85\,\sigma^2/\delta^2$。

### p值作为随机统计量

在 $H_0$ 下，p值有分布 $\mathrm{Uniforme}(0,1)$。因此 $P(p \leq \alpha \mid H_0) = \alpha$ 确切地成立 — 确认 $\alpha$ 精确控制第I型错误率。在 $H_1$ 下，p值分布集中在0附近。

### 多重检验和FDR

进行 $m$ 个同时检验时，至少一个假阳性的概率（FWER）为 $1 - (1-\alpha)^m$。对于 $m = 20$ 和 $\alpha = 0{,}05$：FWER $= 1 - 0{,}95^{20} \approx 64\%$。

Bonferroni校正：每个检验使用 $\alpha/m$。替代方案：FDR控制（Benjamini-Hochberg, 1995）— 当许多检验在高维数据（基因组学、神经影像）中进行时更有力。

### 统计显著性对比实践意义

一个结果在统计上可能显著，但效应如此之小以至于在临床上无关。Cohen的**标准化效应大小**：

$$d = \frac{|\bar X - \mu_0|}{s}$$

$d = 0{,}2$（小），$d = 0{,}5$（中），$d = 0{,}8$（大）— Cohen的惯例。

### 重复危机和p值辩论

2016年，美国统计学会发布了一份前所未有的声明，列出了关于p值使用的六条原则，警告：

1. p值不是 $H_0$ 为真的概率。
2. p值高于0.05并不意味着没有效应。
3. 科学决策不应仅基于 $p < 0{,}05$。

重复性运动（Nosek等人，2015年：仅36%的100项心理学研究重现）揭示了p值的机械使用，结合p-hacking、HARKing和发表偏见，产生了一个系统地膨胀的科学文献体系。

### NHST的替代方案

- **等价性和非劣性**：检验 $|\mu - \mu_0| < \delta$（效应足够小以至于可以忽视）。在制药通用药物临床试验中是标准的。
- **贝叶斯因子**：$\mathrm{BF}_{10} = P(\text{数据} \mid H_1)/P(\text{数据} \mid H_0)$ — 直接比较假设。可解释：$\mathrm{BF} > 10$ 是 $H_1$ 的强证据。
- **贝叶斯分析**：后验 $P(\theta \mid \text{数据})$ 直接给出关于参数的概率。避免频率主义的混淆。
- **e值和任何时候有效推断**：一个扩展，允许在不膨胀 $\alpha$ 的情况下窥视数据，解决了过早停止实验的问题。

### 希格斯玻色子的检测和 $5\sigma$ 准则

2012年LHC对希格斯玻色子的发现使用了准则 $p < 2{,}9 \times 10^{-7}$（等价于标准正态分布中的 $5\sigma$）。比通常的0.05更严格的准则反映了：（1）宣布新粒子的不可逆性；（2）经过时间的多个检验；（3）假阳性的成本（新实验的建造）。François Englert和Peter Higgs因理论预测的确认获得了[2013年诺贝尔物理学奖](https://www.nobelprize.org/prizes/physics/2013/summary/)。

### 商业环境中的多重检验

电子商务平台的A/B测试经常涉及数百个同时实验。控制FDR而非FWER允许5%的显著检验为假阳性（预期），在发现假阳性的成本与检测真实效应的力量之间取得平衡。Shopify和Netflix已公开报告了使用贝叶斯框架来克服NHST在规模上的问题。

</Porta>

<Porta nivel="pratica" titulo="巴西实际应用">

### 国家卫生监督局（Anvisa）：新药疗效

一家实验室想要注册一种止痛药。协议要求证明相对于安慰剂的平均疼痛减少至少1分（在0到10分的量表上）。

$H_0: \mu_{\text{治疗}} - \mu_{\text{安慰剂}} \leq 1$（无效）
$H_1: \mu_{\text{治疗}} - \mu_{\text{安慰剂}} > 1$（有效）

使用 $\alpha = 0{,}01$（医学严谨性）和90%的功效，实验室计算所需的 $n$ 并规划临床试验。若 $p < 0{,}01$，则申请注册。

### 质量控制：灌装过程

一家工厂填充1升瓶子。如果 $\mu = 1000$ 毫升，该过程在控制中。每小时，他们收集 $n = 9$ 个瓶子。

$H_0: \mu = 1000$ 毫升对比 $H_1: \mu \neq 1000$ 毫升（双侧）。

如果样本均值超出 $1000 \pm 3\sigma/\sqrt{9} = 1000 \pm \sigma$，会触发警报。这是 $\bar X$ 控制图的 $3\sigma$ 限制（等价于每点约 $\alpha \approx 0{,}003$）。

### 全国中学教育考试（ENEM）：按学校比较表现

国家教育研究所（INEP）使用假设检验来验证一所学校的平均分是否明显不同于州平均分。使用 $n$ 很大的情况（所有学校），实际上任何差异都变成"统计显著的" — 因此报告效应大小（在量表上的分数差异）而不仅仅是p值很重要。

## 已解决的例子

<Exemplo numero="103.1" titulo="z检验双侧均值检验（基础）">

**问题。** 一家公司声称其咖啡包的平均重量为 $\mu_0 = 500$ 克。一个 $n = 36$ 个包的样本给出 $\bar X = 492$ 克，$\sigma = 24$ 克（已知）。在水平 $\alpha = 0{,}05$ 处，数据是否与该声明矛盾？

**策略。** $H_0: \mu = 500$，$H_1: \mu \neq 500$（双侧）。由于 $\sigma$ 已知，使用z统计量。

**求解。**

$$Z = \frac{\bar X - \mu_0}{\sigma/\sqrt{n}} = \frac{492 - 500}{24/\sqrt{36}} = \frac{-8}{4} = -2{,}00$$

双侧p值：$p = 2\,P(Z \leq -2{,}00) = 2 \times 0{,}0228 = 0{,}0456$。

由于 $p = 0{,}0456 < \alpha = 0{,}05$，**我们拒绝 $H_0$**。在5%水平上数据与公司的声明矛盾。

**验证。** 双侧 $\alpha = 0{,}05$ 的临界值为 $z_{0{,}025} = 1{,}960$。由于 $|{-}2{,}00| = 2{,}00 > 1{,}960$，按统计量拒绝与p值一致。一致。

**来源。** [OpenStax Statistics, §9.2, 例子9.3](https://openstax.org/books/statistics/pages/9-2-outcomes-and-the-type-i-and-type-ii-errors) — CC-BY。

</Exemplo>

<Exemplo numero="103.2" titulo="第I型和第II型错误的识别（概念）">

**问题。** 一个质量检验检查一批药物的有效成分平均浓度是否为50毫克（$H_0$）。在5%水平上，该批次被批准或拒绝。（a）在这个背景下第I型错误构成什么？（b）第II型错误呢？（c）哪一个更严重？

**策略。** 将正式定义映射到具体背景。

**求解。**

(a) **第I型错误**：当 $\mu = 50$ 毫克时拒绝 $H_0$ — 即拒绝实际上符合规格的批次。后果：浪费良好产品、返工成本。

(b) **第II型错误**：当 $\mu \neq 50$ 毫克时未拒绝 $H_0$ — 即批准规格外的批次。后果：药物用量不足或过量到达患者。

(c) 在大多数制药背景中，**第II型错误更严重**：规格外的药物可能对患者造成伤害。因此，临床试验使用小 $\alpha$ 但要求高功效（低 $\beta$），增加 $n$。

**验证。** 错误间的不对称性证明了按背景以不同方式校准 $\alpha$ 和 $\beta$ 的合理性 — 医学使用 $\alpha = 0{,}01$ 和80-90%功效。

**来源。** [OpenIntro Statistics, §5.2, 例子5.4](https://www.openintro.org/book/os/) — CC-BY-SA。

</Exemplo>

<Exemplo numero="103.3" titulo="功效和样本容量计算（中间）">

**问题。** 一个研究者想要检测紧急护理单位（UPA）的平均服务时间从 $\mu_0 = 30$ 分钟变为 $\mu_1 = 27$ 分钟（$\delta = 3$ 分钟），$\sigma = 10$ 分钟，$\alpha = 0{,}05$（双侧）和80%功效。最少需要多少 $n$？

**策略。** 应用功效的样本容量公式：$n = (z_{\alpha/2} + z_\beta)^2 \sigma^2/\delta^2$。

**求解。**

$z_{0{,}025} = 1{,}960$，$z_{0{,}20} = 0{,}842$（80%功效 $\Rightarrow \beta = 0{,}20$）。

$$n = \frac{(1{,}960 + 0{,}842)^2 \times 10^2}{3^2} = \frac{(2{,}802)^2 \times 100}{9} = \frac{7{,}851 \times 100}{9} \approx 87{,}2$$

四舍五入：$n = 88$ 个就诊。

**验证。** 若 $\delta = 6$ 分钟（效应翻倍）：$n = 7{,}851 \times 100/36 \approx 22$。更大的效应需要更小的样本 — 一致。

**来源。** [OpenIntro Statistics, §5.3, 例子5.7](https://www.openintro.org/book/os/) — CC-BY-SA。

</Exemplo>

<Exemplo numero="103.4" titulo="单侧检验 — 药物（中间）">

**问题。** 一种新的抗凝血药声称将凝血时间平均从 $\mu_0 = 12$ 秒减少到以下水平。一个 $n = 20$ 个患者的样本给出 $\bar X = 11{,}2$ 秒，$s = 2$ 秒。在水平 $\alpha = 0{,}05$ 处，该药物有效吗？

**策略。** $H_0: \mu \geq 12$，$H_1: \mu < 12$（左尾单侧）。使用19自由度的t统计量。

**求解。**

$$T = \frac{11{,}2 - 12}{2/\sqrt{20}} = \frac{-0{,}8}{0{,}4472} = -1{,}789$$

对于 $H_1: \mu < 12$，p值 $= P(t_{19} \leq -1{,}789)$。从t表：$P(t_{19} \leq -1{,}729) = 0{,}05$ 和 $P(t_{19} \leq -2{,}093) = 0{,}025$。因此 $p \approx 0{,}045$。

由于 $p = 0{,}045 < 0{,}05$，**我们拒绝 $H_0$**。证据表明药物减少了凝血时间。

**验证。** 单侧临界值：$t_{0{,}05,\,19} = -1{,}729$。由于 $T = -1{,}789 < -1{,}729$，按统计量拒绝与p值一致。一致。

**来源。** [OpenStax Statistics, §9.4, 例子9.8](https://openstax.org/books/statistics/pages/9-4-full-hypothesis-test-examples) — CC-BY。

</Exemplo>

<Exemplo numero="103.5" titulo="p值的常见误解和更正（高级）">

**问题。** 一个研究者在 $H_0: \mu = 0$ 的检验中获得 $p = 0{,}03$ 并声称："有97%的概率效应是真实的。"识别错误并表述正确的解释。

**策略。** 应用p值的形式定义并区分关于数据的概率和关于假设的概率。

**求解。**

这个声明**有两个原因是不正确的**：

1. p值是关于**数据**的概率（给定 $H_0$），而非关于**假设**的概率。$P(\text{数据} \mid H_0) \neq P(H_0 \mid \text{数据})$ — 混淆这两者是**条件转置谬论**（基础率忽视）。

2. $1 - p\text{-值} = 0{,}97$ 没有关于 $H_1$ 概率的解释。要获得 $P(H_1 \mid \text{数据})$，需要关于假设的先验的贝叶斯定理。

**正确解释**："如果 $H_0$ 为真，观察到一个与所得效应相同或更大的效应的概率只有3%。数据在5%显著性水平上与 $H_0$ 在统计上不相容。"

**验证。** 两个独立研究各有 $p = 0{,}04$ 不意味着第三个研究有 $p = 0{,}04$ — 证据的组合通过元分析完成，而非p值相乘。

**来源。** [OpenIntro Statistics, §5.1, 部分"Interpreting p-values"](https://www.openintro.org/book/os/) — CC-BY-SA。

</Exemplo>
