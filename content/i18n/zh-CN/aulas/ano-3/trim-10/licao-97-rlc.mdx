### 基尔霍夫电压定律

在电源为 $V(t)$ 的 RLC 级联电路中，电压下降之和等于电源：

$$V_L + V_R + V_C = V(t)$$

使用 $V_L = L\,\dot I$、$V_R = RI$、$V_C = Q/C$ 和 $I = \dot Q$：

<Equation explicacao="RLC电路的微分方程——带常系数的二阶线性微分方程。" latex="L\,\ddot{Q} + R\,\dot{Q} + \frac{Q}{C} = V(t)" />

<Definicao titulo="RLC电路的规范参数">

除以 $L$：

$$\ddot{Q} + 2\zeta\omega_0\,\dot{Q} + \omega_0^2\,Q = \frac{V(t)}{L}$$

- **无阻尼自然频率：** $\omega_0 = \dfrac{1}{\sqrt{LC}}$ [rad/s]
- **阻尼系数：** $\zeta = \dfrac{R}{2}\sqrt{\dfrac{C}{L}} = \dfrac{R}{2L}\cdot\dfrac{1}{\omega_0}$
- **品质因数：** $Q_f = \dfrac{1}{2\zeta} = \dfrac{1}{R}\sqrt{\dfrac{L}{C}}$
- **阻尼频率：** $\omega_d = \omega_0\sqrt{1-\zeta^2}$ （对 $\zeta < 1$ 有效）

</Definicao>

> "方程 $LQ'' + RQ' + Q/C = V(t)$ 是RLC电路方程的标准形式，其数学形式与阻尼质量-弹簧系统 $mx'' + cx' + kx = F(t)$ 完全相同，其中 $L$ 扮演质量的角色，$R$ 是阻尼常数，$1/C$ 是弹簧常数。" — [Lebl, Notes on Diffy Qs §2.6](https://www.jirka.org/diffyqs/html/sec_rlc.html)

### 特征方程分类

齐次方程 ($V = 0$)：$L\lambda^2 + R\lambda + 1/C = 0$。

$\Delta = R^2 - 4L/C$

<Definicao titulo="三种自由响应制度">

- **过阻尼** ($\zeta > 1$, $\Delta > 0$)：两个负实根 $\lambda$。缓慢指数返回平衡。
  $$Q_h(t) = C_1 e^{\lambda_1 t} + C_2 e^{\lambda_2 t}$$
- **临界阻尼** ($\zeta = 1$, $\Delta = 0$)：重根 $\lambda = -R/(2L)$。返回更快无振荡。
  $$Q_h(t) = (C_1 + C_2 t)\,e^{\lambda t}$$
- **欠阻尼** ($\zeta < 1$, $\Delta < 0$)：$\lambda = -\zeta\omega_0 \pm i\omega_d$。阻尼振荡。
  $$Q_h(t) = e^{-\zeta\omega_0 t}\bigl(C_1\cos\omega_d t + C_2\sin\omega_d t\bigr)$$

</Definicao>

### 稳态响应（强迫）

对于 $V(t) = V_0\cos(\omega t)$，特解：

$$Q_p(t) = \frac{V_0/L}{\sqrt{(\omega_0^2-\omega^2)^2 + (2\zeta\omega_0\omega)^2}}\cos(\omega t - \phi)$$

其中 $\tan\phi = \dfrac{2\zeta\omega_0\omega}{\omega_0^2-\omega^2}$。

<Teorema titulo="RLC电路中的共振">

电流幅度 $|I| = \omega|Q_p|$ 在 $\omega = \omega_0$ 时最大（级联共振）。在共振处，阻抗为纯电阻：$Z = R$。峰值电流为 $I_{\max} = V_0/R$。

品质因数 $Q_f = \omega_0 L/R$ 衡量电路在共振处的放大程度：带宽 $\Delta\omega = \omega_0/Q_f$。

</Teorema>

<Insight>
收音机AM通过调节 $C$（可变电容器）至 $\omega_0 = 2\pi f_{\text{station}}$ 而调谐。带宽 $\Delta\omega$ 决定选择性：$Q_f$ 高——狭窄且选择性强；$Q_f$ 低——同时接收多个台。
</Insight>

</Porta>

<Porta nivel="5" titulo="对5岁儿童">

想象一个**操场秋千**。有三个部分控制它：

- **你给秋千的推力**（让它动）——这是**电感**，储存运动能量。
- **看不见的弹簧**想把它拉回中心——这是**电容**，储存电能。
- **空气摩擦**让它停止——这是**电阻**。

当你以秋千的正确节奏推动时，它越来越高。这叫**共振**。你的汽车收音机用完全相同的原理来一次只接收一个台。

</Porta>

<Porta nivel="10" titulo="对10岁儿童">

一个**RLC电路**有三个级联连接的元件：

- **R（电阻）**：将电转化为热。制动。
- **L（电感）**：电线圈。抵抗电流变化，像重物。
- **C（电容）**：储存电荷，像弹簧。

**基尔霍夫定律**说电压之和为零。这变成一个有导数的方程：

$$L\,\ddot{Q} + R\,\dot{Q} + \frac{Q}{C} = V(t)$$

它*数学上完全相同*于你已经见过的质量-弹簧振荡器！对弹簧有效的每一个解都对电路有效。

如果没有电阻 ($R = 0$)，电流永远振荡——像一个理想摆。有电阻时，它会衰减。

</Porta>

<Porta nivel="15" titulo="对高中学生">

RLC的方程是**常系数二阶线性微分方程**的特例：

$$L\,\ddot{Q} + R\,\dot{Q} + \frac{Q}{C} = V(t)$$

**第1步——齐次解。** 设 $V = 0$ 并测试 $Q = e^{\lambda t}$：

$$L\lambda^2 + R\lambda + \frac{1}{C} = 0$$

$\Delta = R^2 - 4L/C$。有三种情况（过阻尼、临界、欠阻尼）。

**第2步——特解。** 对于 $V(t) = V_0\cos(\omega t)$，尝试 $Q_p = A\cos\omega t + B\sin\omega t$ 并通过代入确定 $A, B$。

**第3步——通解** = 齐次 + 特解。应用初始条件 $Q(0) = Q_0$、$I(0) = \dot Q(0) = I_0$ 来求 $C_1$ 和 $C_2$。

**重要量：**
- $\omega_0 = 1/\sqrt{LC}$：自然频率。
- $\zeta = R/(2\sqrt{L/C})$：阻尼因子。
- 共振：$\omega = \omega_0$ 最大化电流。

</Porta>

<Porta nivel="25" titulo="对工程学生">

RLC级联电路由以下描述：

$$L\,\ddot{Q} + R\,\dot{Q} + \frac{Q}{C} = V(t), \quad Q(0) = Q_0,\ \dot{Q}(0) = I_0$$

**频域分析。** 拉普拉斯变换（$V$ 一般）：

$$\left(Ls^2 + Rs + \frac{1}{C}\right)\hat{Q}(s) = \hat{V}(s) + LsQ_0 + LI_0 + RQ_0$$

传递函数（电流/电压，初始条件为零）：

$$H_I(s) = \frac{s\hat{Q}(s)}{\hat{V}(s)} = \frac{s}{Ls^2 + Rs + 1/C}$$

**阻抗：** $Z(j\omega) = R + j\omega L + \frac{1}{j\omega C}$。级联共振：$\Im(Z) = 0 \Rightarrow \omega_r = \omega_0$。

**品质因数：** $Q_f = \omega_0 L/R = \frac{1}{\omega_0 RC}$。衡量选择性——带宽 $BW = \omega_0/Q_f$ [rad/s]。

**能量：** $E(t) = \frac{1}{2}LI^2 + \frac{Q^2}{2C}$。耗散功率：$P_R = RI^2$。无功功率：$Q_{reactive} = I^2(\omega L - 1/(\omega C))$。

**稳态响应：** $\omega = \omega_0 \Rightarrow I_{\max} = V_0/R$ （仅受电阻限制）。对于 $Q_f \gg 1$，电容上的电压可超过源电压 $Q_f$ 倍——称为*共振处的电压增益*。

</Porta>

<Porta nivel="40" titulo="对资深专业人士">

RLC级联电路由19世纪末的Lord Kelvin和Arthur Kennelly正式分析，巩固了交流电路理论。系统机电类比由James Clerk Maxwell在《论电与磁》(1873)中探索，后来由Gabriel Kron在电机理论中正式化(1939)。

**系统的视角：** RLC级联是二阶调和振荡器，有两个自由度（状态 $[Q, I]^T$）。在状态空间：

$<Eq>{`\\frac{d}{dt}\\begin{pmatrix}Q\\\\I\\end{pmatrix} = \\begin{pmatrix}0 & 1\\\\-\\omega_0^2 & -2\\zeta\\omega_0\\end{pmatrix}\\begin{pmatrix}Q\\\\I\\end{pmatrix} + \\begin{pmatrix}0\\\\1/L\\end{pmatrix}V(t)`}</Eq>$

系统矩阵的特征值是极点 $s = -\zeta\omega_0 \pm j\omega_d$。在复 $s$ 平面，到原点的距离是 $\omega_0$，与负实轴的角度是 $\arccos\zeta$。

**现代应用：** 射频LC滤波器（AM无线电535–1605 kHz，FM 88–108 MHz）、VCO振荡器中的油箱电路、DC-DC转换器中的EMI抑制、元件公差分析（SPICE中的蒙特卡洛），电力传输网络中的共振（巴西735 kV线路在大型负荷扰动后欠阻尼问题）。品质因数 $Q_f$ 在光学（Fabry-Pérot腔）、量子力学（共振态）和宇宙学（解耦前的重子振荡）中重新出现。

</Porta>

<Porta nivel="pratica" titulo="巴西数据应用">

**巴西AM无线电。** 电台CBN São Paulo在1350 kHz广播。若 $L = 0{,}5$ mH，哪个 $C$ 调谐接收器？

$\omega_0 = 2\pi \times 1350 \times 10^3 \approx 8{,}48 \times 10^6$ rad/s。

$C = 1/(L\omega_0^2) = 1/(0{,}5 \times 10^{-3} \times (8{,}48 \times 10^6)^2) \approx 27{,}7$ pF。

可调电容10–50 pF覆盖整个AM范围（535–1605 kHz）。

**INMETRO和EMI标准。** ABNT NBR 15601要求家用设备在150 kHz至30 MHz范围内不超过某些限制。笔记本电源中的共模RLC滤波器衰减电磁干扰——滤波器的品质因数应足够低（$\zeta \approx 0{,}7$）以避免违反限制的共振峰值。

**电力网。** 无功补偿器（CTEEP和Eletrobras变电站中的电容器和电感器组）形成在60 Hz附近调谐的LC电路以进行功率因数校正，但 $\zeta$ 足够高以避免失控共振。

</Porta>

## 已解示例

<Exemplo numero="97.1" titulo="制度分类——元件数据">

**问题。** RLC级联电路：$L = 1$ H，$R = 6$ $\Omega$，$C = 1/8$ F。分类制度并写出一般齐次解。

**策略。** 计算 $\Delta = R^2 - 4L/C$；识别制度；写出 $Q_h$。

**解决方案。**

$\Delta = 36 - 4(1)(8) = 36 - 32 = 4 > 0$ — **过阻尼**。

特征方程：$\lambda^2 + 6\lambda + 8 = 0 \Rightarrow \lambda = (-6 \pm 2)/2$，因此 $\lambda_1 = -2$，$\lambda_2 = -4$。

$$Q_h(t) = C_1 e^{-2t} + C_2 e^{-4t}$$

**验证。** $Q_h' = -2C_1 e^{-2t} - 4C_2 e^{-4t}$，$Q_h'' = 4C_1 e^{-2t} + 16C_2 e^{-4t}$。代入 $Q'' + 6Q' + 8Q$：收集 $e^{-2t}$：$4C_1 - 12C_1 + 8C_1 = 0$ ✓。收集 $e^{-4t}$：$16C_2 - 24C_2 + 8C_2 = 0$ ✓。

**来源。** [Lebl, Notes on Diffy Qs §2.6, Example 2.6.1](https://www.jirka.org/diffyqs/html/sec_rlc.html) — CC-BY-SA

</Exemplo>

<Exemplo numero="97.2" titulo="欠阻尼制度与初始条件">

**问题。** $L = 1$ H，$R = 2$ $\Omega$，$C = 1/2$ F，$V = 0$。条件：$Q(0) = 1$ C，$I(0) = 0$ A。求 $Q(t)$。

**策略。** 计算 $\Delta$，识别欠阻尼制度，应用初始条件确定 $C_1, C_2$。

**解决方案。**

$\Delta = 4 - 4(1)(2) = 4 - 8 = -4 < 0$ — **欠阻尼**。

$\lambda = -1 \pm i$，因此 $\alpha = 1$，$\omega_d = 1$。

$$Q_h(t) = e^{-t}(C_1 \cos t + C_2 \sin t)$$

初始条件：$Q(0) = C_1 = 1$。

$\dot Q = e^{-t}[(-C_1 + C_2\omega_d)\cos t + (-C_2 - C_1\omega_d)\sin t]$... 与 $\omega_d = 1$：

$\dot Q(0) = -C_1 + C_2 = 0 \Rightarrow C_2 = 1$。

$$Q(t) = e^{-t}(\cos t + \sin t) = \sqrt{2}\,e^{-t}\cos\!\left(t - \frac{\pi}{4}\right)$$

**验证。** $Q(0) = 1$ ✓；$\dot Q(0) = -1 + 1 = 0$ ✓。幅度按 $\sqrt{2}e^{-t}$ 衰减 ✓。

**来源。** [Lebl, Notes on Diffy Qs §2.6, Exercise 2.6.2](https://www.jirka.org/diffyqs/html/sec_rlc.html) — CC-BY-SA

</Exemplo>

<Exemplo numero="97.3" titulo="强迫响应——稳态">

**问题。** $L = 0{,}1$ H，$R = 10$ $\Omega$，$C = 10^{-3}$ F，$V(t) = 50\cos(100t)$ V。求稳态电流 $I_p(t) = \dot Q_p$。

**策略。** 计算 $Z(j\omega)$ 并使用 $\hat I = \hat V/Z$。

**解决方案。**

$\omega = 100$ rad/s。$\omega_0 = 1/\sqrt{0{,}1 \times 10^{-3}} = 100$ rad/s — **共振！**

$Z(j100) = 10 + j(100 \times 0{,}1 - 1/(100 \times 10^{-3})) = 10 + j(10 - 10) = 10$ $\Omega$。

$I_p(t) = \frac{50}{10}\cos(100t) = 5\cos(100t)$ A。

在共振处，阻抗为纯电阻，电流达到最大值。

**验证。** $|Z|_{\omega=100} = 10$ $\Omega$ ✓；$I_{\max} = V_0/R = 50/10 = 5$ A ✓。

**来源。** [OpenStax University Physics Vol. 2, §14.5 Example 14.5](https://openstax.org/books/university-physics-volume-2/pages/14-5-resonance-in-an-ac-circuit) — CC-BY

</Exemplo>

<Exemplo numero="97.4" titulo="品质因数与带宽">

**问题。** AM收音机接收器：$L = 0{,}5$ mH，$C = 25$ pF，$R = 5$ $\Omega$。计算 $f_0$、$Q_f$ 和 $\Delta f$（带宽）。

**策略。** 直接应用 $f_0$、$Q_f$ 和 BW 的公式。

**解决方案。**

$\omega_0 = 1/\sqrt{0{,}5 \times 10^{-3} \times 25 \times 10^{-12}} = 1/\sqrt{1{,}25 \times 10^{-14}} \approx 8{,}94 \times 10^6$ rad/s。

$f_0 = \omega_0/(2\pi) \approx 1{,}42$ MHz （AM范围）。

$Q_f = \omega_0 L/R = (8{,}94 \times 10^6 \times 0{,}5 \times 10^{-3})/5 = 4470/5 = 894$。

$\Delta f = f_0/Q_f = 1{,}42 \times 10^6/894 \approx 1{,}59$ kHz。

AM频道宽度为10 kHz——$Q_f = 894$ 对AM来说过于选择，但适合FM立体声。

**验证。** $\zeta = 1/(2Q_f) = 1/1788 \approx 5{,}6 \times 10^{-4} \ll 1$ — 强欠阻尼 ✓。

**来源。** [OpenStax University Physics Vol. 2, §14.6](https://openstax.org/books/university-physics-volume-2/pages/14-6-rlc-series-circuits-with-ac) — CC-BY

</Exemplo>

<Exemplo numero="97.5" titulo="无电阻LC电路——纯振荡">

**问题。** $L = 4$ H，$C = 1/16$ F，$R = 0$，$V = 0$。$Q(0) = 0$，$I(0) = 2$ A。求 $Q(t)$ 和总能量。

**策略。** 无阻尼情况：$\ddot Q + \omega_0^2 Q = 0$，通解为正弦/余弦。

**解决方案。**

$\omega_0 = 1/\sqrt{4 \times 1/16} = 1/\sqrt{1/4} = 2$ rad/s。

$Q(t) = A\cos(2t) + B\sin(2t)$。

$Q(0) = A = 0 \Rightarrow Q(t) = B\sin(2t)$。

$\dot Q(0) = 2B = 2 \Rightarrow B = 1$。

$$Q(t) = \sin(2t), \quad I(t) = 2\cos(2t)$$

能量：$E = \frac{1}{2}L I^2 + \frac{Q^2}{2C} = \frac{1}{2}(4)(4\cos^2 2t) + \frac{\sin^2 2t}{2(1/16)} = 8\cos^2 2t + 8\sin^2 2t = 8$ J （常数 ✓）。

**来源。** [Trench, Elementary Differential Equations §6.2, Exercise 6.2.3](https://digitalcommons.trinity.edu/mono/9/) — 开放

</Exemplo>
