<Porta nivel="formal" titulo="推导与误差分析">

### 初值问题

给定初值问题：

$$y' = f(x, y), \quad y(x_0) = y_0$$

我们希望在 $x \in [x_0, X]$ 上逼近 $y(x)$，而无需闭形式表达式。

### 离散化

将区间分为 $N$ 个相等的子区间：

$$h = \frac{X - x_0}{N}, \qquad x_n = x_0 + n\,h, \quad n = 0, 1, \ldots, N$$

<Definicao titulo="欧拉显式方法（前进欧拉）">

近似值 $y_n \approx y(x_n)$ 由递推关系给出：

<Equation explicacao="每个 y_n+1 由 y 的图形在 (x_n, y_n) 处的切线估计，切线斜率为 f(x_n, y_n)。" latex="y_{n+1} = y_n + h\,f(x_n,\, y_n)" />

几何上：我们沿着解曲线的切线前进一步，步长为 $h$。

</Definicao>

> "求解 $y' = f(x,y)$, $y(x_0) = y_0$ 的最简单数值方法是*欧拉方法*。我们用差分商 $(y_{n+1} - y_n)/h$ 替换 $y'$，并在 $x_n$ 处求 $f$：这给出 $y_{n+1} = y_n + hf(x_n, y_n)$。" — [Lebl, Notes on Diffy Qs §1.7](https://www.jirka.org/diffyqs/html/numer_section.html)

### 泰勒级数误差分析

<Definicao titulo="局部截断误差">

在 $x_n$ 处进行泰勒展开：

$$y(x_n + h) = y(x_n) + h\,y'(x_n) + \frac{h^2}{2}\,y''(\xi_n), \quad \xi_n \in (x_n, x_{n+1})$$

因为 $y' = f(x,y)$，欧拉方法仅使用前两项。**局部误差**（每步）为：

$$e_n = y(x_{n+1}) - y_{n+1} = \frac{h^2}{2}\,y''(\xi_n) = O(h^2)$$

</Definicao>

<Definicao titulo="全局截断误差">

在 $N = (X-x_0)/h$ 步中，局部误差会累积：

$$E = |y(X) - y_N| \leq C\,h \cdot N \cdot e_{\text{local}} = O(h)$$

**欧拉方法是一阶的**：将 $h$ 减半只会将全局误差减半（不是四倍）。

</Definicao>

<Teorema titulo="欧拉方法的收敛性">

如果 $f$ 在 $y$ 中 Lipschitz 连续（常数 $L$）且 $y''$ 在 $[x_0, X]$ 中由 $M$ 界定，则：

$$|y(x_n) - y_n| \leq \frac{Mh}{2L}\bigl(e^{L(x_n-x_0)} - 1\bigr)$$

特别地，当 $h \to 0$ 时，$|y(X) - y_N| \to 0$：该方法**收敛**。

</Teorema>

<Insight>
欧拉方法既是最简单的，也是精度最低的。其教学价值巨大：所有单步方法（龙格-库塔）的理论都是"跟随切线"基本思想的一般化。RK4 并不复杂四倍 — 只是同一思想用巧妙的权重应用四次。
</Insight>

<Porta nivel="5" titulo="对5岁孩子">

想象你在地图上，想要找到宝藏。你不知道完整的路径，但你知道**现在应该朝哪个方向指向**。

你朝那个方向迈一小步。停下来。再次查看现在指向哪里。又迈一步。重复。

如果步子太大，你会走错路。如果步子太小，几乎能找到，但会花很长时间。

**欧拉方法**对方程做完全一样的事 — 按照方程指示的方向迈步。

</Porta>

<Porta nivel="10" titulo="对10岁孩子">

想象你想知道一个下落球的位置，但不知道精确公式。你知道每个时刻的速度：$v(t) = f(t, x)$。

欧拉方法说：
1. 从 $x_0$、$t_0$ 开始。
2. 现在的速度是 $v_0 = f(t_0, x_0)$。
3. 迈一步：$x_1 = x_0 + h \times v_0$，$t_1 = t_0 + h$。
4. 重复：在 $t_1$ 的速度是 $v_1 = f(t_1, x_1)$。迈下一步：$x_2 = x_1 + h \times v_1$。

步长 $h$ 越小越精确。全局误差与 $h$ 成正比 — 将步长减半会将误差减半。

</Porta>

<Porta nivel="15" titulo="对中学生">

**欧拉方法**数值求解任何一阶常微分方程：

$$y' = f(x, y), \quad y(x_0) = y_0$$

**算法：**

1. 选择一个步长 $h$（越小越精确，但越慢）。
2. 对于 $n = 0, 1, 2, \ldots, N-1$：
   - 计算 $f(x_n, y_n)$ — 当前点的斜率。
   - $y_{n+1} = y_n + h \cdot f(x_n, y_n)$
   - $x_{n+1} = x_n + h$

**为什么有效？** 微分方程说曲线在 $(x_n, y_n)$ 处的斜率是 $f(x_n, y_n)$。具有该斜率的切线将我们引导到下一个点的估计值。

**快速例子：** $y' = y$，$y(0) = 1$，$h = 0.1$，求 $y(0.3)$。

- $y_1 = 1 + 0.1 \times 1 = 1.1$
- $y_2 = 1.1 + 0.1 \times 1.1 = 1.21$
- $y_3 = 1.21 + 0.1 \times 1.21 = 1.331$

精确值：$e^{0.3} \approx 1.3499$。误差 $\approx 0.019$（1.4%）。

</Porta>

<Porta nivel="25" titulo="对工程学生">

给定初值问题 $y' = f(x,y)$，$y(x_0) = y_0$，**显式欧拉方法**是：

$$y_{n+1} = y_n + h\,f(x_n, y_n)$$

**稳定性分析。** 对于测试方程 $y' = \lambda y$（$\lambda \in \mathbb{C}$）：

$$y_{n+1} = (1 + h\lambda)\,y_n$$

当 $|1 + h\lambda| < 1$ 时数值解衰减。对于 $\lambda = -a + i b$（$a > 0$）：稳定区域是平面 $h\lambda$ 中的圆盘 $|1 + h\lambda| < 1$。显式欧拉有**有限稳定区域** — 对于大 $h$ 即使 ODE 是稳定的也会失稳。这是刚性方程方法的基本问题。

**隐式欧拉：** $y_{n+1} = y_n + h\,f(x_{n+1}, y_{n+1})$ — 求解 $y_{n+1}$ 的隐式方程。对于测试方程：当 $\Re(\lambda) < 0$ 时 $|1/(1-h\lambda)| < 1$ 始终成立 — **A-稳定**。

**Heun 方法（RK2）：**

$$k_1 = f(x_n, y_n), \quad k_2 = f(x_n + h, y_n + h k_1), \quad y_{n+1} = y_n + \frac{h}{2}(k_1 + k_2)$$

全局误差 $O(h^2)$。把 $k_2$ 解释为欧拉点的斜率并对两个斜率求平均。

**RK4 经典（四阶龙格-库塔）：**

$$k_1 = f(x_n, y_n), \quad k_2 = f\!\left(x_n + \tfrac{h}{2}, y_n + \tfrac{h}{2}k_1\right)$$
$$k_3 = f\!\left(x_n + \tfrac{h}{2}, y_n + \tfrac{h}{2}k_2\right), \quad k_4 = f(x_n + h, y_n + h k_3)$$
$$y_{n+1} = y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

全局误差 $O(h^4)$。非刚性 ODE 的行业标准。

</Porta>

<Porta nivel="40" titulo="对资深专业人士">

欧拉方法始于1768年（发表于*Institutionum calculi integralis*，第一卷）。泰勒级数的误差分析和收敛性正式分析归功于柯西（1824）。现代龙格-库塔方法理论由卡尔·龙格（1895）和威廉·库塔（1901）开发，他们通过与 $y(x+h)$ 的截断泰勒级数比较来推导 RK4 系数。

**现代视角。** 欧拉方法是单级一阶龙格-库塔方法。RK 的一般理论用**布彻表格**编码 — 矩阵 $(A, b, c)$ 描述每个方法的权重和节点。欧拉：$A = [0]$，$b = [1]$，$c = [0]$。RK4：$4 \times 4$ 表格，权重 $[1/6, 1/3, 1/3, 1/6]$。

**刚性与隐式方法。** 刚性方程出现在雅可比矩阵 $\partial f/\partial y$ 有幅度差异很大的特征值时。显式方法如欧拉要求 $h$ 与最小特征值（最快的）成正比 — 成本非常高。A-稳定方法（隐式欧拉、Crank-Nicolson、BDF 方法）忽略稳定性问题，使用与感兴趣尺度成正比的 $h$。

**工程应用：** 电力分配网络仿真（ANEEL 使用 PSCAD/EMTP — 隐式欧拉，步长10-50微秒），生化分子链仿真（简易欧拉保持相空间面积），轨道动力学（吉田辛形积分器）。

**在巴西：** REAMAT（UFRGS）维护葡萄牙语工程中最常用的数值计算教科书，用 Python 和 Scilab 实现本课所有方法。

</Porta>

<Porta nivel="pratica" titulo="巴西数据应用">

**巴西初创公司增长。** 库里蒂巴一家金融科技公司以 $P'(t) = 0.15\,P(1 - P/10000)$ 客户/月增长（逻辑增长，容量10000）。初始条件 $P(0) = 500$，用欧拉方法 $h = 1$ 月模拟12个月。

第0步：$f(0, 500) = 0.15 \times 500 \times (1 - 500/10000) = 71.25$。$P_1 = 500 + 71.25 \approx 571$。

第1步：$f(1, 571) = 0.15 \times 571 \times (1 - 571/10000) \approx 80.7$。$P_2 \approx 652$。

12次迭代后：$P(12) \approx 1750$ 客户。精确解（逻辑）：$\approx 1780$。误差：1.7%。

**供水 — 流量 ODE。** 圣保罗供水公司一个储液池的流量 $Q(t)$（立方米/小时）服从 $Q' = -kQ^{0.5}$，$Q(0) = 10000$ m³。当 $k = 0.02$ 时，用 $h = 10$ 小时的欧拉方法：$Q_1 = 10000 - 0.02 \times 100 \times 10 = 9980$ m³。24步表给出 $Q(240) \approx 7100$ m³。

</Porta>

## 已解决的例子

<Exemplo numero="98.1" titulo="四步欧拉 — 指数型 ODE">

**问题。** 使用步长 $h = 0.1$ 的欧拉方法逼近 $y(0.4)$，给定 $y' = -y$，$y(0) = 1$。与精确值比较。

**策略。** 应用递推关系 $y_{n+1} = y_n + h(-y_n) = y_n(1-h)$ 四次。

**求解。**

| $n$ | $x_n$ | $y_n$ | $f = -y_n$ | $y_{n+1}$ |
|---|---|---|---|---|
| 0 | 0 | 1.0000 | -1.0000 | 0.9000 |
| 1 | 0.1 | 0.9000 | -0.9000 | 0.8100 |
| 2 | 0.2 | 0.8100 | -0.8100 | 0.7290 |
| 3 | 0.3 | 0.7290 | -0.7290 | 0.6561 |

$y_4 = 0.6561$。精确值：$e^{-0.4} \approx 0.6703$。相对误差：$\approx 2.12\%$。

**验证。** 每步我们乘以 $(1-h) = 0.9$，所以 $y_4 = (0.9)^4 = 0.6561$ ✓。误差随 $h$ 增长 — 对于 $h = 0.05$，误差会降到 $\approx 1.06\%$。

**来源。** [Lebl, Notes on Diffy Qs §1.7, Example 1.7.1](https://www.jirka.org/diffyqs/html/numer_section.html) — CC-BY-SA

</Exemplo>

<Exemplo numero="98.2" titulo="非线性方程中的欧拉方法">

**问题。** 估计 $y(1)$，给定 $y' = y^2$，$y(0) = 0.5$，使用欧拉方法，$h = 0.25$。

**策略。** 精确解是 $y = 1/(2-x)$（在 $x = 2$ 处爆炸）。用4步到 $x = 1$。

**求解。**

$n=0$：$f(0, 0.5) = 0.25$。$y_1 = 0.5 + 0.25 \times 0.25 = 0.5625$。

$n=1$：$f(0.25, 0.5625) = 0.31641$。$y_2 = 0.5625 + 0.25 \times 0.31641 = 0.6416$。

$n=2$：$f(0.5, 0.6416) = 0.4117$。$y_3 = 0.6416 + 0.25 \times 0.4117 = 0.7445$。

$n=3$：$f(0.75, 0.7445) = 0.5543$。$y_4 = 0.7445 + 0.25 \times 0.5543 = 0.8831$。

精确值：$y(1) = 1/(2-1) = 1$。误差：11.7%。

**验证。** 误差较大是因为 $f = y^2$ 在增长，且切线低估了曲线。减小到 $h = 0.1$（10步）会将误差降低到 $\approx 5.8\%$，确认一阶性。

**来源。** [OpenStax Calculus Volume 2, §4.2, Example 4.2](https://openstax.org/books/calculus-volume-2/pages/4-2-direction-fields-and-eulers-method) — CC-BY-NC-SA

</Exemplo>

<Exemplo numero="98.3" titulo="欧拉方法与 RK4 的比较">

**问题。** 对于 $y' = x + y$，$y(0) = 1$，用 $h = 0.1$ 逼近 $y(0.2)$，使用(a)欧拉与(b)RK4。精确解：$y = 2e^x - x - 1$。

**策略。** 应用每个方法的公式并比较误差。

**求解。**

精确值：$y(0.2) = 2e^{0.2} - 0.2 - 1 \approx 2 \times 1.2214 - 1.2 = 1.2428$。

**(a) 欧拉：**

$n=0$：$f(0,1) = 1$。$y_1 = 1 + 0.1 \times 1 = 1.1$。

$n=1$：$f(0.1, 1.1) = 0.1 + 1.1 = 1.2$。$y_2 = 1.1 + 0.1 \times 1.2 = 1.22$。

欧拉误差：$|1.2428 - 1.22| = 0.0228$。

**(b) RK4（第 $n=0 \to n=1$ 步，$h=0.1$）：**

$k_1 = 0 + 1 = 1$；$k_2 = (0.05) + (1 + 0.05) = 1.1$；$k_3 = 0.05 + (1 + 0.05) = 1.1$；$k_4 = 0.1 + (1 + 0.1) = 1.2$。

$y_1 = 1 + (0.1/6)(1 + 2.2 + 2.2 + 1.2) = 1 + 0.1 \times 1.1\overline{0}\approx 1.1103$。

RK4 误差（两步）：$< 10^{-6}$ — 比欧拉好几个数量级。

**验证。** 当 $h$ 减半时误差比：欧拉 2:1（一阶）；RK4 16:1（四阶）✓。

**来源。** [REAMAT UFRGS, Cálculo Numérico §8.3](https://www.ufrgs.br/reamat/CalculoNumerico/livro-py/s_metodos_de_runge-kutta.html) — CC-BY-SA

<Exemplo numero="98.4" titulo="隐式欧拉 — 刚性方程的稳定性">

**问题。** $y' = -100y$，$y(0) = 1$。比较显式欧拉，$h = 0.03$（不稳定）与 $h = 0.01$（稳定）。

**策略。** 分析 $|1 + h\lambda|$，$\lambda = -100$。

**求解。**

显式欧拉的放大因子：$r = 1 + h\lambda = 1 - 100h$。

- $h = 0.03$：$r = 1 - 3 = -2$。$|r| = 2 > 1$ — **不稳定**：$y_n = (-2)^n \to \pm\infty$。
- $h = 0.01$：$r = 1 - 1 = 0$。$|r| = 0 < 1$ — 稳定（边界），$y_n = 0$ 一步内（过阻尼）。
- $h = 0.02$：$r = 1 - 2 = -1$。$|r| = 1$ — 无阻尼振荡。

欧拉稳定区域：对这个方程 $h < 2/|\lambda| = 0.02$。精确解 $e^{-100x}$ 在 $x \sim 0.01$ 衰减 — 步长远小于感兴趣的尺度。

**验证。** 隐式欧拉：$r_{imp} = 1/(1-h\lambda) = 1/(1+100h)$。对任何 $h > 0$：$|r_{imp}| < 1$ ✓ — 始终稳定。

**来源。** [REAMAT UFRGS, Cálculo Numérico §8.4](https://www.ufrgs.br/reamat/CalculoNumerico/livro-py/s_estabilidade_de_metodos_numericos.html) — CC-BY-SA

</Exemplo>

<Exemplo numero="98.5" titulo="常微分方程组的欧拉方法 — 振荡器">

**问题。** 系统 $x' = v$，$v' = -x$（简谐振荡器），初值：$x(0) = 1$，$v(0) = 0$，$h = 0.1$，模拟3步。

**策略。** 同时对每个分量应用欧拉方法。

**求解。**

状态：$x_n$，$v_n$。函数 $f_1 = v$ 和 $f_2 = -x$。

第0步：$x_0 = 1$，$v_0 = 0$。导数：$\dot x = 0$，$\dot v = -1$。

$x_1 = 1 + 0.1 \times 0 = 1$；$v_1 = 0 + 0.1 \times (-1) = -0.1$。

第1步：$x_1 = 1$，$v_1 = -0.1$。导数：$\dot x = -0.1$，$\dot v = -1$。

$x_2 = 1 + 0.1 \times (-0.1) = 0.99$；$v_2 = -0.1 + 0.1 \times (-1) = -0.2$。

第2步：$x_2 = 0.99$，$v_2 = -0.2$。导数：$\dot x = -0.2$，$\dot v = -0.99$。

$x_3 = 0.99 + 0.1 \times (-0.2) = 0.97$；$v_3 = -0.2 + 0.1 \times (-0.99) = -0.299$。

在 $t = 0.3$ 时精确值：$x = \cos(0.3) \approx 0.9553$，$v = -\sin(0.3) \approx -0.2955$。欧拉高估 $x$ — 不保持能量。辛欧拉方法解决这个问题：先计算 $v_{n+1}$，再用它计算 $x_{n+1}$。

**来源。** [Lebl, Notes on Diffy Qs §1.7, Exercise 1.7.4](https://www.jirka.org/diffyqs/html/numer_section.html) — CC-BY-SA

</Exemplo>
