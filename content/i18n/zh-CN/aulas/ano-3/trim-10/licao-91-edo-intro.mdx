<Porta nivel="formal" titulo="定义和分类">

### 常微分方程

<Definicao titulo="n阶常微分方程">

**n阶常微分方程（常微分方程）**是形式为

$$F\bigl(x,\, y,\, y',\, y'',\, \ldots,\, y^{(n)}\bigr) = 0$$

的方程，其中$y = y(x)$是未知函数，$y^{(k)}$表示其第$k$阶导数。一个在区间$I \subseteq \mathbb{R}$上的**解**是函数$y: I \to \mathbb{R}$，在$I$上$n$次可导，且对所有$x \in I$满足该方程。

</Definicao>

> "微分方程是包含一个或多个独立变量的函数及其导数的方程。" — [OpenStax Calculus Volume 2, §4.1](https://openstax.org/books/calculus-volume-2/pages/4-1-basics-of-differential-equations)

### 分类

<Definicao titulo="阶数、线性性、齐次性">

- **阶数：**出现的最高阶导数。$y'' + y = 0$是二阶；$y' + y = x$是一阶。
- **线性与非线性：**如果$y, y', \ldots, y^{(n)}$*线性出现*（不含相互乘积也不含非线性函数），则为线性。$y' + xy = 1$是线性的；$y' + y^2 = 0$不是。
- **齐次与非齐次**（对线性常微分方程）：如果不含导数的项为零则为齐次。$y'' + 3y' + 2y = 0$是齐次的；$y'' + 3y' + 2y = \sin x$不是。
- **常系数与变系数：**$y'' + 3y' + 2y = 0$有常系数；$xy'' + y = 0$有变系数$x$。

</Definicao>

### 通解和特解

<Definicao titulo="通解和初始条件">

- **n阶常微分方程的通解：**含有$n$个任意常数$C_1, C_2, \ldots, C_n$的函数族。
- **初始条件（IC）：**指定$y(x_0) = y_0$（对阶数≥ 2还需指定导数初值）。初始条件选择通解族中的**特解**。

</Definicao>

> "$y' = f(x)$的通解是$y = F(x) + C$，其中$F$是$f$的一个反导数，$C$是任意常数。为了确定$C$的唯一值，需要初始条件。" — [OpenStax Calculus Volume 2, §4.1](https://openstax.org/books/calculus-volume-2/pages/4-1-basics-of-differential-equations)

### 存在性和唯一性（Picard-Lindelöf）

<Teorema titulo="局部存在性和唯一性">

对于初值问题$y' = f(x, y)$，$y(x_0) = y_0$：如果$f$和$\partial f/\partial y$在$(x_0, y_0)$的某个开邻域内连续，那么存在包含$x_0$的开区间$I$，在此区间上解存在且**唯一**。

</Teorema>

**实际后果：**在陈述唯一性之前，需对每个常微分方程验证Picard-Lindelöf定理。常微分方程$y' = \sqrt{|y|}$，$y(0) = 0$违反了假设（偏导数在$y = 0$处不连续）并有无穷多个解。

<Porta nivel="5" titulo="给5岁孩子的解释">

想象一个水桶在滴水的水龙头下。每分钟进入相同量的水。

**变化规则**是："每分钟进入一杯水"。如果你知道这个规则，你可以计算10分钟后水桶里有多少水——只需相乘。

常微分方程正是这样：一个**关于事物如何变化的规则**。与其直接告诉你"有多少"，它告诉你"如何增长"。你的任务是从这个规则推断出"有多少"。

</Porta>

<Porta nivel="10" titulo="给10岁孩子的解释">

普通方程直接告诉你$y$是什么：例如$y = 3x + 2$。

**微分**方程告诉你$y$如何变化：例如$y' = 2x$（y的变化率是$2x$）。要找出$y$，你需要**积分**：

$$y' = 2x \implies y = x^2 + C$$

为什么出现$C$？因为$(x^2 + 5)'$给出$2x$，$(x^2 + 100)'$也给出$2x$。常数在求导时"消失"，所以当你反过来积分时，它作为未知数重新出现。

要固定$C$，你需要**初始条件**：如果我们知道$y(0) = 3$，代入$x = 0$：$3 = 0 + C$，因此$C = 3$且$y = x^2 + 3$。

常微分方程描述种群如何增长、药物如何离开体内、电容器如何放电。

</Porta>

<Porta nivel="15" titulo="给15岁少年的解释">

常微分方程是涉及函数及其导数的方程。最简单的模型：

$$y' = ky$$

意思是：$y$的变化率与$y$的当前值成正比。什么东西表现如此？

- **细菌**：$N' = rN$——细菌越多，繁殖越快。
- **连续复利**：$S' = rS$——钱越多，利息越多。
- **放射性衰变**：$N' = -\lambda N$（负号因为在减少）。

$y' = ky$在$y(0) = y_0$条件下的解是$y(t) = y_0 e^{kt}$——指数函数。常微分方程是从物理定律推导出这个公式的严格路径。

**识别日常生活中的常微分方程：**

| 短语 | 等价的常微分方程 |
|---|---|
| "每年增长5%（连续）" | $y' = 0{,}05\, y$ |
| "冷却速率与温度差成正比" | $T' = -k(T - T_a)$ |
| "无阻尼振荡" | $y'' + \omega^2 y = 0$ |

</Porta>

<Porta nivel="25" titulo="给工程专业学生的解释">

常微分方程是工程和应用科学中的标准建模语言。振动力学、控制论、电磁学、化学动力学、药物代谢动力学——所有问题都用常微分方程来表述。

### 最常见的常微分方程类型

| 类型 | 形式 | 应用 |
|---|---|---|
| 指数增长 | $y' = ky$ | 种群、连续复利 |
| 逻辑斯谛 | $y' = r\,y(1 - y/K)$ | 有容量极限的增长 |
| 牛顿冷却 | $T' = -k(T - T_a)$ | 热力学 |
| 质量-弹簧（简谐振动） | $y'' + \omega^2 y = 0$ | 机械振动 |
| RC电路 | $V' + V/(RC) = 0$ | 电子学 |

### 建模流程

1. **识别演化的量**$y$和独立变量$x$（时间、位置等）。
2. **写出变化定律**：将物理/生物/经济学翻译为导数。
3. **建立初始条件**（系统在$t = 0$的状态）。
4. **分类**：阶数、线性/非线性、齐次。
5. **求解**（解析求解如果可能；否则数值求解——Euler、RK4、隐式方法）。
6. **验证**与真实数据；迭代模型。

### 自治常微分方程的相图

对于$y' = f(y)$（$x$未显式出现），$f(y)$的图象揭示**平衡点**（$f = 0$）及其稳定性。在逻辑斯谛方程$y' = ry(1 - y/K)$中：平衡点在$y = 0$（不稳定）和$y = K$（稳定吸引子）。

### 与Black-Scholes的联系

Black-Scholes偏微分方程（第119课）是一个推广：

$$\frac{\partial V}{\partial t} + \tfrac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} + rS\frac{\partial V}{\partial S} - rV = 0$$

偏微分方程（*partial*微分方程）因为取决于两个变量（$S$和$t$）。但哲学是相同的：函数与其导数的关系，用边界条件求解。

</Porta>

<Porta nivel="40" titulo="给资深专业人士的解释">

### 定性理论：Poincaré和Lyapunov

当闭形式解不存在时（在非线性系统中常见），我们研究：

- **Lyapunov稳定性**：平衡点、吸引子、排斥点、鞍点。
- **分岔**：相图如何随参数变化（Hopf、pitchfork、鞍节点分岔）。
- **确定性混沌**：对初始条件的指数敏感性（Lorenz 1963——简化的大气对流方程）。

### 刚性常微分方程和隐式方法

具有多个时间尺度的常微分方程（"刚性"）：显式Euler要求极小的步长$h$，计算成本过高。解决方案：**BDF**（反向微分公式）、**Rosenbrock**、**Radau IIA**方法。在Python中：`scipy.integrate.solve_ivp(..., method='BDF')`。

### 随机微分方程（SDEs）

$$dX = \mu(X, t)\,dt + \sigma(X, t)\,dW_t$$

项$dW_t$：布朗运动的增量。是量化金融的基础（Black-Scholes模型来自Itô随机微分方程）、统计物理、分子生物学。数值求解：Euler-Maruyama、Milstein格式。

### 注意：无唯一解的常微分方程

$y' = \sqrt{|y|}$，$y(0) = 0$有无穷多个解——Picard-Lindelöf的Lipschitz条件在$y = 0$处被违反。基本课程：**总是在主张唯一性前验证假设**；不仅是"应用定理"。

### 具有时滞的方程（DDEs）

$y'(t) = f(t, y(t), y(t - \tau))$。出现在控制（传感器延迟）、流行病学（潜伏期）、经济学（数据滞后）中。相空间是无穷维的——分析截然不同。

### 量子力学作为算子常微分方程

薛定谔方程$i\hbar\,\partial_t \psi = \hat{H}\psi$是Hilbert空间$L^2(\mathbb{R}^3)$中的线性常微分方程。"哈密顿算子"$\hat{H}$充当$f(y)$的角色——概念结构与一阶线性常微分方程相同，但在无穷维函数空间中。

</Porta>

<Porta nivel="pratica" titulo="巴西数据的应用">

### 连续复利：Selic和财务应用

Selic目标利率：14.75%年（2026年5月）。连续复利模型：

$$S' = 0{,}1475\, S, \quad S(0) = S_0$$

解：$S(t) = S_0\, e^{0{,}1475\, t}$（$t$以年为单位）。

对于$S_0 =$ 10,000雷亚尔：
- 1年后：$S(1) = 10000 \cdot e^{0{,}1475} \approx$ 11,588雷亚尔
- 翻倍时间：$t^* = \ln 2 / 0{,}1475 \approx 4{,}7$年

### 药物的半衰期

布洛芬：在成年人体内的半衰期约2小时。衰减常微分方程：

$$C' = -k\, C, \quad k = \frac{\ln 2}{2} \approx 0{,}347 \text{ h}^{-1}$$

初始剂量400毫克：
- 6小时后：$C(6) = 400\, e^{-0{,}347 \times 6} \approx 50$毫克（12.5%的剂量）

### 咖啡冷却

咖啡90°C，室温25°C，常数$k = 0{,}05$分钟$^{-1}$（陶瓷杯的典型值）。牛顿定律：

$$T' = -0{,}05\,(T - 25), \quad T(0) = 90$$

解：$T(t) = 25 + 65\, e^{-0{,}05\, t}$。

20分钟后的温度：$T(20) = 25 + 65\, e^{-1} \approx 25 + 23{,}9 \approx 49$°C——仍然很热，但可以饮用。

### 求解前识别类型

在积分任何常微分方程之前：
1. 阶数是多少？（最高导数）
2. 是线性的吗？（$y$和导数线性出现）
3. 是可分离的吗？（可以写成$g(y)\,dy = h(x)\,dx$吗？）——预览第92课
4. 有闭形式解吗？还是需要数值方法？

## 已解的例题

<Exemplo titulo="验证解和初始条件（应用）" numero="1">

**问题：**验证$y(x) = 3e^{2x}$是$y' = 2y$在$y(0) = 3$条件下的解。然后，写出通解和曲线族。

**策略：**验证解时，对候选函数求导并代入常微分方程。初始条件确定通解中的常数。

**求解：**

1. **求导**$y = 3e^{2x}$：$y' = 6e^{2x}$。
2. **代入常微分方程**：$y' = 6e^{2x}$且$2y = 2 \cdot 3e^{2x} = 6e^{2x}$。相等——已验证。
3. **验证初始条件**：$y(0) = 3e^0 = 3$。已验证。
4. **通解**：$y = Ce^{2x}$（指数族）。对于每个$C \in \mathbb{R}$的值，我们得到一条满足$y' = 2y$的不同曲线。
5. **初始条件选择$C = 3$**：从$y(0) = Ce^0 = C = 3$。

**验证：**对任何$C$，$y' = 2Ce^{2x} = 2y$——整个族都满足常微分方程。

**来源。**[OpenStax — Calculus Volume 2 §4.1, Example 4.2](https://openstax.org/books/calculus-volume-2/pages/4-1-basics-of-differential-equations) — 许可证CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="直接积分求解（中等）" numero="2">

**问题：**求解初值问题$y'' = 6x$，$y(0) = 1$，$y'(0) = 2$。

**策略：**不含$y$或$y'$显式项的二阶常微分方程——通过两次连续积分求解，每次引入一个常数。两个初始条件确定两个常数。

**求解：**

1. **第一次积分**：$y'' = 6x \implies y' = 3x^2 + C_1$。
2. **应用初始条件$y'(0) = 2$**：$2 = 3(0) + C_1 \implies C_1 = 2$。因此$y' = 3x^2 + 2$。
3. **第二次积分**：$y' = 3x^2 + 2 \implies y = x^3 + 2x + C_2$。
4. **应用初始条件$y(0) = 1$**：$1 = 0 + 0 + C_2 \implies C_2 = 1$。
5. **特解**：$y(x) = x^3 + 2x + 1$。

**验证：**$y' = 3x^2 + 2$；$y'' = 6x$——满足常微分方程。$y(0) = 1$和$y'(0) = 2$——两个初始条件都满足。

**来源。**[Jiří Lebl — Notes on Diffy Qs §0.2](https://www.jirka.org/diffyqs/html/introde_section.html) — 许可证CC-BY-SA。

</Exemplo>

<Exemplo titulo="建模：牛顿冷却（中等）" numero="3">

**问题：**一杯85°C的茶放在20°C的房间里。冷却常数为$k = 0{,}04$分钟$^{-1}$。(a)写出并求解常微分方程。(b)多少分钟后温度达到50°C？

**策略：**牛顿冷却定律：冷却速率与物体温度和环境温度之差成正比。代入$u = T - T_a$来化简为$u' = -ku$。

**求解：**

1. **建立常微分方程**：$T' = -k(T - 20) = -0{,}04(T - 20)$，$T(0) = 85$。
2. **代换$u = T - 20$**：$u' = T'= -0{,}04\,u$，$u(0) = 65$。
3. **解**：$u(t) = 65\,e^{-0{,}04\,t}$，因此$T(t) = 20 + 65\,e^{-0{,}04\,t}$。
4. **找出$t$使得$T = 50$**：

$$50 = 20 + 65\,e^{-0{,}04\,t} \implies e^{-0{,}04\,t} = \frac{30}{65} \implies t = \frac{-\ln(30/65)}{0{,}04} \approx \frac{0{,}771}{0{,}04} \approx 19{,}3 \text{分钟}$$

**验证：**$T(19{,}3) = 20 + 65\,e^{-0{,}04 \times 19{,}3} = 20 + 65 \times 0{,}462 \approx 50$°C。一致。

**来源。**[OpenStax — Calculus Volume 2 §4.4, Example 4.14](https://openstax.org/books/calculus-volume-2/pages/4-4-the-logistic-equation) — 许可证CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="分类和线性性（中等）" numero="4">

**问题：**按阶数、线性性和（如果线性）齐次性对以下每个常微分方程分类：
(a) $y''' - 2y' + y = e^x$ &nbsp; (b) $y'' + (y')^2 = x$ &nbsp; (c) $xy' - y = 0$

**策略：**对每个方程：(i)识别最高阶导数确定阶数；(ii)检查$y$和导数是否仅线性出现（不含相互乘积，不含它们的非线性函数）；(iii)对线性常微分方程，检查右侧是否为零。

**求解：**

(a) $y''' - 2y' + y = e^x$：
- 阶数：**3**（最高阶导数是$y'''$）。
- 线性：**是**——$y$、$y'$、$y'''$以一次出现，无乘积。
- 齐次：**否**——右侧$e^x \neq 0$。

(b) $y'' + (y')^2 = x$：
- 阶数：**2**。
- 线性：**否**——项$(y')^2$在$y'$中是二次的。

(c) $xy' - y = 0$：
- 阶数：**1**。
- 线性：**是**——$y'$和$y$以一次出现。$y'$的系数是$x$（变量），但这不影响关于$y$的线性性。
- 齐次：**是**——右侧为零。

**验证：**与标准形式$a_n(x)y^{(n)} + \cdots + a_0(x)y = g(x)$比较。如果所有系数仅依赖于$x$，则为线性。

**来源。**[Jiří Lebl — Notes on Diffy Qs §0.2](https://www.jirka.org/diffyqs/html/introde_section.html) — 许可证CC-BY-SA。

</Exemplo>

<Exemplo titulo="建模：放射性衰变（建模）" numero="5">

**问题：**碳-14的半衰期为5730年。化石含有现代活生物体中14%碳-14的30%。估计化石的年龄。

**策略：**放射性衰变遵循$N' = -\lambda N$。半衰期给出$\lambda$。用$N(t)/N_0 = 0{,}30$，对$t$求解。

**求解：**

1. **衰变常数**：$\lambda = \ln 2 / \tau_{1/2} = \ln 2 / 5730 \approx 1{,}21 \times 10^{-4}$年$^{-1}$。
2. **常微分方程的解**：$N(t) = N_0\,e^{-\lambda t}$。
3. **应用条件$N(t)/N_0 = 0{,}30$**：

$$0{,}30 = e^{-\lambda t} \implies -\lambda t = \ln(0{,}30) \implies t = \frac{-\ln(0{,}30)}{\lambda} = \frac{\ln(10/3)}{1{,}21 \times 10^{-4}}$$

$$t = \frac{1{,}204}{1{,}21 \times 10^{-4}} \approx 9\,950 \text{年}$$

4. **答案**：化石约有9950年的历史。

**验证：**用$t = 5730$年，$N/N_0 = e^{-(\ln 2 / 5730) \times 5730} = e^{-\ln 2} = 0{,}5$（50%）——与半衰期定义一致。

**来源。**[Jiří Lebl — Notes on Diffy Qs §1.1](https://www.jirka.org/diffyqs/html/introtode_section.html) — 许可证CC-BY-SA。

</Exemplo>
