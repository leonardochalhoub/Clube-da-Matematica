<Porta nivel="formal" titulo="完整振荡子——四种制度">

### 运动方程

<Definicao titulo="质量-弹簧-阻尼模型">

$$m\ddot x + c\dot x + kx = F(t)$$

- $m > 0$：质量 [kg]。
- $c \geq 0$：粘性阻尼系数 [N·s/m]。
- $k > 0$：弹簧刚度常数 [N/m]。
- $F(t)$：外部力 [N]。

**无量纲形式：** 除以 $m$ 并定义 $\omega_0 = \sqrt{k/m}$，$\zeta = c/(2\sqrt{mk})$：

$$\ddot x + 2\zeta\omega_0\dot x + \omega_0^2 x = F(t)/m$$

</Definicao>

### 特征方程和制度

$\lambda^2 + 2\zeta\omega_0\lambda + \omega_0^2 = 0$。判别式 $\Delta = 4\omega_0^2(\zeta^2 - 1)$。

<Teorema titulo="振荡子的四种制度">

**未阻尼** （$c = 0$，$\zeta = 0$）：$\lambda = \pm i\omega_0$。
$$x(t) = A\cos(\omega_0 t) + B\sin(\omega_0 t)$$

**欠阻尼** （$0 < \zeta < 1$）：$\lambda = -\zeta\omega_0 \pm i\omega_d$，其中 $\omega_d = \omega_0\sqrt{1-\zeta^2}$。
$$x(t) = e^{-\zeta\omega_0 t}(A\cos\omega_d t + B\sin\omega_d t)$$

**临界阻尼** （$\zeta = 1$）：重根 $\lambda = -\omega_0$。
$$x(t) = (A + Bt)e^{-\omega_0 t}$$

**过阻尼** （$\zeta > 1$）：$\lambda_{1,2} = \omega_0(-\zeta \pm \sqrt{\zeta^2-1}) < 0$。
$$x(t) = Ae^{\lambda_1 t} + Be^{\lambda_2 t}$$

</Teorema>

> "当 $b^2 - 4km < 0$ 时情况最重要，这发生在阻尼很小时...在这种情况下，解以指数衰减的振幅摆动。" — [Lebl, Notes on Diffy Qs, §2.4](https://www.jirka.org/diffyqs/html/mech_section.html)

### 谐波强迫响应

对于 $F(t) = F_0\cos\omega t$：特解（稳态）

$$x_p(t) = \frac{F_0/m}{\sqrt{(\omega_0^2-\omega^2)^2 + 4\zeta^2\omega_0^2\omega^2}}\cos(\omega t - \phi)$$

其中 $\tan\phi = 2\zeta\omega_0\omega/(\omega_0^2 - \omega^2)$。

### 谐振

<Insight>

在 $\zeta = 0$ 时：如果 $\omega = \omega_0$，特解无限增长——$x_p = \tfrac{F_0}{2m\omega_0} t\sin(\omega_0 t)$。**纯谐振。** 对于 $\zeta > 0$：振幅在 $\omega_r = \omega_0\sqrt{1-2\zeta^2}$（低于 $\omega_0$）处有有限最大值。在 $\omega_r$ 的放大因子：$Q = 1/(2\zeta)$——**品质因子**。

</Insight>

<Porta nivel="5" titulo="对5岁孩子的解释">

想象一个弹簧，悬挂着一个重物。你拉下重物并释放。会发生什么？

- **无阻尼**：重物上下不停敲击，就像一个完美的秋千。
- **轻微阻尼**（欠阻尼）：敲击多次，每次都少一点，直到停止。
- **精确阻尼**（临界）：直接回到静止点，完全不敲击。这正是汽车悬挂的原理！
- **重度阻尼**（过阻尼）：下降缓慢，就像在蜂蜜里一样。

</Porta>

<Porta nivel="10" titulo="对10岁孩子的解释">

有重物的弹簧和阻尼器的方程正好是我们学过的二阶常微分方程，具有物理名称：

$$m \ddot x + c \dot x + k x = F(t)$$

$m$ = 质量，$k$ = 弹簧刚度，$c$ = 阻尼（摩擦力），$F(t)$ = 你施加的力。

特征方程给出 $\lambda^2 + (c/m)\lambda + k/m = 0$。发生的情况取决于 $c$：

- $c = 0$：永远摆动（理想秋千）。
- $c$ 很小：摆动并逐渐停止。
- $c$ 恰好值：以最快可能的方式停止而不摆动。
- $c$ 很大：缓慢停止而不摆动。

汽车悬挂被设计为临界阻尼：快速回到静止，不弹跳。

</Porta>

### 两个重要参数

$\omega_0 = \sqrt{k/m}$ —— 固有频率 [弧度/秒]。$f_0 = \omega_0/(2\pi)$ —— 频率，单位赫兹。

$\zeta = c/(2\sqrt{mk})$ —— 阻尼因子。无量纲的。

### 求解自由振荡子的算法

1. 写下 $\lambda^2 + 2\zeta\omega_0\lambda + \omega_0^2 = 0$。
2. 计算 $\Delta = 4\omega_0^2(\zeta^2 - 1)$。
3. 应用对应的情况（见表格）。

### 强迫响应和谐振

如果 $F(t) = F_0\cos\omega t$ 且 $\zeta = 0$：

- $\omega \neq \omega_0$：拍振摆动。
- $\omega = \omega_0$：谐振——振幅随 $t$ 线性增长。

**历史例子**：塔科马海峡大桥（1940）与风谐振，4小时后的振荡增长导致坍塌。涡旋频率 = 桥的固有频率。

### 初始条件的计算

对于 $x(0) = x_0$，$\dot x(0) = v_0$：代入通解，得到 $A$ 和 $B$ 的 $2 \times 2$ 系统。

</Porta>

<Porta nivel="25" titulo="对工程学生的解释">

### 频率响应

对于 $\ddot x + 2\zeta\omega_0\dot x + \omega_0^2 x = (F_0/m)\cos\omega t$，稳态振幅为：

$$|X(\omega)| = \frac{F_0/k}{\sqrt{(1-r^2)^2 + (2\zeta r)^2}}, \quad r = \frac{\omega}{\omega_0}$$

谐振峰值在 $r = \sqrt{1 - 2\zeta^2}$（当 $\zeta < 1/\sqrt{2} \approx 0.707$）。品质因子 $Q = 1/(2\zeta)$。

### -3 dB 带宽

带宽：$\Delta\omega = \zeta\omega_0 \cdot 2$（弧度/秒）。对于很小的 $\zeta$：$Q = \omega_0/\Delta\omega$。

### 传递函数

$H(s) = (1/m)/(s^2 + 2\zeta\omega_0 s + \omega_0^2)$。极点：$s = \omega_0(-\zeta \pm \sqrt{\zeta^2-1})$。

对于 $\zeta < 1$：复共轭极点，具有 $|s| = \omega_0$ 和角度 $\arccos\zeta$。

### 振动隔离

如果 $x$ 是底盘振动，$y$ 是乘客运动：

$$\ddot y + 2\zeta\omega_0\dot y + \omega_0^2 y = 2\zeta\omega_0\dot x + \omega_0^2 x$$

传递率 $|T(\omega)| = \sqrt{1 + (2\zeta r)^2}/\sqrt{(1-r^2)^2 + (2\zeta r)^2}$。

对于 $r > \sqrt{2}$：$|T| < 1$ —— 有效隔离。悬挂采用低 $\omega_0$ 设计，以确保在大部分道路振动频谱上 $r > \sqrt{2}$。

### 动态吸收（中和器）

向主系统添加质量 $m_2$ 和弹簧 $k_2$ 在 $\omega_0$ 处消除谐振（如果 $k_2/m_2 = \omega_0^2$）。这是摩天大楼（例如台北 101）中振动吸收器的原理。

</Porta>

<Porta nivel="40" titulo="对高级专业人士的解释">

### 模态分析

对于具有 $n$ 个自由度的系统：$\mathbf{M}\ddot{\mathbf{x}} + \mathbf{C}\dot{\mathbf{x}} + \mathbf{K}\mathbf{x} = \mathbf{F}(t)$。正常模式是问题 $(\mathbf{K} - \omega^2\mathbf{M})\boldsymbol{\phi} = \mathbf{0}$ 的特征向量。对于成比例阻尼（$\mathbf{C} = \alpha\mathbf{M} + \beta\mathbf{K}$），每个模式解耦——模态分析。

### Green函数响应

$G(t,\tau) = \frac{1}{m\omega_d}e^{-\zeta\omega_0(t-\tau)}\sin\omega_d(t-\tau)\,H(t-\tau)$ 是**脉冲响应函数**。任意强迫的解为：

$$x(t) = \int_0^t G(t,\tau) F(\tau)\,d\tau + x_h(t) \quad\text{（Duhamel积分）}$$

### 引力波检测

LIGO干涉仪被模型化为二阶振荡子：悬挂的镜子，$\omega_0 \approx 1$ Hz，检测频率 10–2000 Hz。信号分析需要方程 $m\ddot x + kx = h(t) L m \omega_L^2$，其中 $h$ 是度规变形。Kip Thorne、Barry Barish 和 Rainer Weiss 因这一检测获得 [2017年物理学诺贝尔奖](https://www.nobelprize.org/prizes/physics/2017/summary/) ——我们在这里研究的振荡子模型是分析的核心部分。

### 线性模型的批评

库仑摩擦（固体）是 $-\mu mg\,\text{sgn}(\dot x)$ —— 非线性。结构阻尼：$c = k\eta/\omega$（取决于频率）。非线性模型：Duffing（$kx + \epsilon x^3$）展现谐振滞后。

### 地震仪的设计

地震仪的固有周期 $T_0 = 2\pi/\omega_0$ 很长（远震 30–100 秒）。高灵敏度：$|X|/|Y| \approx r^2/(1-r^2)$，对于 $r \gg 1$（地震仪在谐振上方制度更好地捕捉）。

</Porta>

<Porta nivel="pratica" titulo="实际应用">

### 快速分类

计算 $c_c = 2\sqrt{mk}$（临界阻尼）。然后 $\zeta = c/c_c$。

| 条件 | 制度 | 行为 |
|---|---|---|
| $c = 0$ | 未阻尼 | 永久振荡 |
| $c < c_c$ | 欠阻尼 | 振荡并衰减 |
| $c = c_c$ | 临界阻尼 | 衰减而不振荡，最快可能 |
| $c > c_c$ | 过阻尼 | 衰减而不振荡，更缓慢 |

### 设计公式

阻尼频率：$\omega_d = \omega_0\sqrt{1 - \zeta^2}$。

对数递减：$\delta = \ln(x_n/x_{n+1}) = 2\pi\zeta/\sqrt{1-\zeta^2}$。允许实验测量 $\zeta$。

建立时间（至 2%）：$t_s \approx 4/(\zeta\omega_0)$。

### 实际谐振

在 $\omega = \omega_0$（无阻尼）时，振幅无限增长。有阻尼时，峰值约为 $|X|_{\max} \approx F_0/(2\zeta k)$，$\zeta$ 很小。

**设计规则**：将 $\omega$ 与 $\omega_0$ 相差至少 20%（在 $r < 0.8$ 或 $r > 1.2$ 处运行）。对于隔离，在 $r > \sqrt{2}$ 处运行。

### Python 工作流

```python
from scipy.integrate import odeint
import numpy as np

m, c, k = 1.0, 0.5, 4.0  # 欠阻尼
F0, omega = 1.0, 2.0
omega0 = np.sqrt(k/m)
zeta = c / (2*np.sqrt(m*k))

def osc(X, t):
    x, v = X
    return [v, (F0*np.cos(omega*t) - c*v - k*x)/m]

t = np.linspace(0, 20, 500)
sol = odeint(osc, [0, 0], t)
```

## 求解的示例

<Exemplo titulo="自由欠阻尼振荡子与初始条件" numero="1">

**问题。** $m = 1\,\text{kg}$，$k = 4\,\text{N/m}$，$c = 2\,\text{N·s/m}$。$x(0) = 1\,\text{m}$，$\dot x(0) = 0$。求 $x(t)$。

**策略。** 计算 $\omega_0$，$\zeta$，识别制度，求解初值问题。

**求解。**

$\omega_0 = \sqrt{4/1} = 2$ 弧度/秒。$\zeta = 2/(2\sqrt{1 \cdot 4}) = 2/4 = 0.5$。由于 $\zeta < 1$：欠阻尼。

$\omega_d = 2\sqrt{1-0.25} = 2\sqrt{0.75} = \sqrt{3} \approx 1.732$ 弧度/秒。

$x(t) = e^{-t}(A\cos\sqrt{3}\,t + B\sin\sqrt{3}\,t)$。

初值条件：$x(0) = A = 1$。$\dot x(0) = -A + \sqrt{3}\,B = 0 \Rightarrow B = 1/\sqrt{3}$。

$$x(t) = e^{-t}\!\left(\cos\sqrt{3}\,t + \frac{1}{\sqrt{3}}\sin\sqrt{3}\,t\right)$$

**验证。** 振幅以 $e^{-t}$ 衰减，以 $\omega_d = \sqrt{3}$ 摆动。在 $t = 0$：$x = 1$。$\dot x(0) = -1 + \sqrt{3}/\sqrt{3} = -1 + 1 = 0$。正确。

**来源。** [Lebl, Notes on Diffy Qs, §2.4, Example 2.4.1](https://www.jirka.org/diffyqs/html/mech_section.html) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="临界阻尼" numero="2">

**问题。** $m = 1\,\text{kg}$，$k = 9\,\text{N/m}$，$c$ 选择为临界。$x(0) = 2\,\text{m}$，$\dot x(0) = -6\,\text{m/s}$。

**策略。** $c_c = 2\sqrt{mk} = 6$。$\zeta = 1$。$\lambda = -\omega_0 = -3$。

**求解。**

$x(t) = (A + Bt)e^{-3t}$。

$x(0) = A = 2$。$\dot x(0) = B - 3A = -6 \Rightarrow B = -6 + 6 = 0$。

$$x(t) = 2e^{-3t}$$

系统以纯指数返回平衡，没有振荡。

**验证。** $\dot x = -6e^{-3t}$，$\ddot x = 18e^{-3t}$。$\ddot x + 6\dot x + 9x = 18 - 36 + 18 = 0$。正确。

**来源。** [Lebl, Notes on Diffy Qs, §2.4, Example 2.4.2](https://www.jirka.org/diffyqs/html/mech_section.html) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="正弦强迫和稳态" numero="3">

**问题。** $\ddot x + 2\dot x + 5x = 10\cos 2t$。求初始条件 $x(0) = 0$，$\dot x(0) = 0$ 的完整解。

**策略。** $y_h$ 带根 $-1 \pm 2i$；$y_p$ 带待定系数。

**求解。**

$y_h = e^{-t}(C_1\cos 2t + C_2\sin 2t)$。

尝试：$x_p = A\cos 2t + B\sin 2t$。

$x_p'' = -4A\cos 2t - 4B\sin 2t$，$x_p' = -2A\sin 2t + 2B\cos 2t$。

代入：$(5A - 4A + 4B)\cos 2t + (5B - 4B - 4A)\sin 2t = 10\cos 2t$。

$(A + 4B)\cos 2t + (B - 4A)\sin 2t = 10\cos 2t$。

系统：$A + 4B = 10$，$B - 4A = 0 \Rightarrow B = 4A$。那么 $A + 16A = 10 \Rightarrow A = 10/17$，$B = 40/17$。

$x = e^{-t}(C_1\cos 2t + C_2\sin 2t) + \frac{10}{17}\cos 2t + \frac{40}{17}\sin 2t$。

初值 $x(0) = 0$：$C_1 + 10/17 = 0 \Rightarrow C_1 = -10/17$。

$\dot x(0) = 0$：$-C_1 + 2C_2 + 80/17 = 0 \Rightarrow C_2 = -50/17$。

$$x(t) = \frac{e^{-t}}{17}(-10\cos 2t - 50\sin 2t) + \frac{10\cos 2t + 40\sin 2t}{17}$$

**验证。** 当 $t \to \infty$：$x \to x_p = (10\cos 2t + 40\sin 2t)/17$ —— 稳态。振幅 = $10\sqrt{1+16}/17 = 10\sqrt{17}/17 = 10/\sqrt{17} \approx 2.43$ m。

**来源。** [Lebl, Notes on Diffy Qs, §2.6, Example 2.6.1](https://www.jirka.org/diffyqs/html/forcedosc_section.html) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="纯谐振" numero="4">

**问题。** $\ddot x + \omega_0^2 x = F_0\cos\omega_0 t$（无阻尼，以固有频率强迫）。证明振幅无限增长。

**策略。** $\omega = \omega_0$ 是谐振频率；修改规则。

**求解。**

$x_h = C_1\cos\omega_0 t + C_2\sin\omega_0 t$。

由于 $\cos\omega_0 t$ 在 $x_h$ 中，尝试 $x_p = t(A\cos\omega_0 t + B\sin\omega_0 t)$。

$x_p'' = \omega_0^2 x_p \cdot (-) + (-2\omega_0 A\sin\omega_0 t + 2\omega_0 B\cos\omega_0 t)$。

代入 $\ddot x + \omega_0^2 x = F_0\cos\omega_0 t$：

$-2\omega_0 A\sin\omega_0 t + 2\omega_0 B\cos\omega_0 t = F_0\cos\omega_0 t$。

因此 $A = 0$，$B = F_0/(2\omega_0)$。

$$x_p(t) = \frac{F_0}{2\omega_0} t\sin(\omega_0 t)$$

振幅 $\frac{F_0}{2\omega_0} t$ 线性增长——纯谐振。

**验证。** $x_p = t\sin(\omega_0 t) \cdot F_0/(2\omega_0)$。求导并代入确认方程。

<Exemplo titulo="过阻尼：建立时间" numero="5">

**问题。** $m = 2\,\text{kg}$，$k = 8\,\text{N/m}$，$c = 12\,\text{N·s/m}$。$x(0) = 0.1\,\text{m}$，$\dot x(0) = 0$。计算 $\zeta$、解 $x(t)$ 和 $|x| < 0.01\,\text{m}$ 的时间。

**策略。** $\omega_0 = 2$，$\zeta = 12/(2\sqrt{16}) = 12/8 = 1.5$：过阻尼。

**求解。**

$\lambda_{1,2} = 2(-1.5 \pm \sqrt{2.25-1}) = 2(-1.5 \pm \sqrt{1.25}) = -3 \pm \sqrt{5}$。

$\lambda_1 \approx -3 + 2.236 = -0.764$；$\lambda_2 \approx -5.236$。

$x(t) = Ae^{-0.764t} + Be^{-5.236t}$。

初值：$A + B = 0.1$；$-0.764A - 5.236B = 0$。

求解：$B = -0.764A/5.236$。那么 $A(1 + 0.764/5.236) = 0.1 \Rightarrow A \approx 0.0838$，$B \approx 0.0162$。

对于 $|x| < 0.01$：由 $Ae^{-0.764t} < 0.01 \Rightarrow t > \ln(A/0.01)/0.764 \approx \ln(8.38)/0.764 \approx 2.75$ 秒占主导。

**验证。** $x(0) = A + B \approx 0.1$。$\dot x(0) = -0.764A - 5.236B \approx -0.064 + 0.085 \approx 0$。正确。

**来源。** [Lebl, Notes on Diffy Qs, §2.4, Exercise 2.4.4](https://www.jirka.org/diffyqs/html/mech_section.html) — CC-BY-SA。

</Exemplo>
