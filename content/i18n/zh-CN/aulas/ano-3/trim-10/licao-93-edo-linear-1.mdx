### 规范形式

<Definicao titulo="一阶线性常微分方程">

如果一个常微分方程可以写成以下形式，则称其为**一阶线性**的

$$y' + p(x)\,y = q(x)$$

其中 $p$ 和 $q$ 是区间 $I$ 上的连续函数。**线性**意味着 $y$ 和 $y'$ 的指数为 1，不存在 $y \cdot y'$ 或 $y^2$ 这样的乘积。

</Definicao>

> "形如 $y' + p(x)y = f(x)$ 的方程称为**一阶线性微分方程**。" — [Lebl, Notes on Diffy Qs, §1.4](https://www.jirka.org/diffyqs/html/firstode_section.html)

### 积分因子法

**为什么有效。** 我们希望 $\mu y' + \mu p y$ 是某个乘积的导数。由于 $(\mu y)' = \mu' y + \mu y'$，我们需要 $\mu' = \mu p$，即 $\mu'/\mu = p$。积分得：$\mu(x) = e^{\int p(x)\,dx}$。

<Teorema titulo="通过积分因子的通解">

设 $p, q$ 在 $I$ 上连续。$y' + p(x)y = q(x)$ 的通解为

$$y(x) = \frac{1}{\mu(x)}\left[\int \mu(x)\,q(x)\,dx + C\right], \quad \mu(x) = e^{\int p(x)\,dx}$$

对于每个初值条件 $y(x_0) = y_0$，存在唯一的解定义在整个 $I$ 上。

</Teorema>

### 齐次部分 + 特解分解

<Definicao titulo="解的分解">

- $y_h = C\,e^{-\int p\,dx}$ — **齐次解**（自由响应，无驱动）。
- $y_p$ — **特解**（对驱动 $q$ 的响应；$\int \mu q\,dx$ 中的任何 $C$）。
- $y = y_h + y_p$ — 通解。

</Definicao>

<Insight>

当 $p > 0$ 时，$y_h$ 衰减到零（稳定极点）。在稳态下，只有 $y_p$ 剩余。在电路中：$y_h$ 是瞬态；$y_p$ 是稳态。

</Insight>

<Porta nivel="5" titulo="给 5 岁小朋友讲">

想象一个**桶子**，底部有个洞。水从水龙头流入（输入），从洞流出（水流出的速度越快，桶里的水越多）。问题是：每一刻桶里有多少水？

这个"水同时流入和流出"的问题恰好就是一个一阶线性常微分方程。我们发现在**每一刻**有多少水在里面。

</Porta>

<Porta nivel="10" titulo="给 10 岁小朋友讲">

在上一节课，可分离常微分方程很容易解，因为你可以把所有含 $y$ 的项放在一边，所有含 $x$ 的项放在另一边。

但是 $y' + 3y = x$ **不能**这样分离。我们需要一个不同的技巧：**积分因子**。

想法：将方程乘以一个特殊的函数 $\mu$，使得左侧恰好变成 $(\mu y)'$。对于 $y' + 3y = x$，该因子是 $\mu = e^{3x}$：

$$e^{3x} y' + 3 e^{3x} y = x e^{3x} \;\;\Longrightarrow\;\; \bigl(e^{3x} y\bigr)' = x e^{3x}$$

现在对两边同时积分就完成了。通用配方总是 $\mu = e^{\int p\,dx}$。

</Porta>

<Porta nivel="15" titulo="给 15 岁少年讲">

方程 $y' + p(x)y = q(x)$ 是**线性**的，因为 $y$ 只出现且指数为 1（没有 $y^2$ 或 $y \cdot y'$）。这非常重要：线性方程保证有唯一解。

### 分步法

1. 将其放到标准形式 $y' + p\,y = q$（必要时除以 $y'$ 的系数）。
2. 计算 $\mu = e^{\int p\,dx}$（任何原函数，不加常数）。
3. 常微分方程变为 $(\mu y)' = \mu q$。
4. 积分：$\mu y = \int \mu q\,dx + C$。
5. 隔离：$y = \frac{1}{\mu}\bigl(\int \mu q\,dx + C\bigr)$。
6. 使用 $y(x_0) = y_0$ 确定 $C$。

### 完整示例

$y' + 2x y = 4x$，$y(0) = 5$。

- $p = 2x$，所以 $\mu = e^{x^2}$。
- $(e^{x^2} y)' = 4x e^{x^2}$。
- $e^{x^2} y = 2 e^{x^2} + C \Rightarrow y = 2 + C e^{-x^2}$。
- $y(0) = 5 \Rightarrow C = 3$。答案：$y = 2 + 3e^{-x^2}$。

### 解的结构

$y = \underbrace{C e^{-\int p\,dx}}_{y_h} + \underbrace{y_p}_{\text{特解}}$。

部分 $y_h$ 衰减（若 $p > 0$）或增长（若 $p < 0$）。部分 $y_p$ 是对驱动 $q$ 的响应。

</Porta>

<Porta nivel="25" titulo="给工程学生讲">

一阶线性常微分方程控制**所有一阶动态**：热力学、控制、化学、生物学。

### 控制的标准形式

$$\tau \dot y + y = K\,u(t)$$

$\tau$ = 时间常数；$K$ = 静态增益；$u$ = 输入。

### 对典型输入的响应

| 输入 $u(t)$ | 响应 $y(t)$（零初值） |
|---|---|
| 阶跃 $1$ | $K(1 - e^{-t/\tau})$ |
| 斜坡 $t$ | $K\bigl[t - \tau(1 - e^{-t/\tau})\bigr]$ |
| 脉冲 $\delta(t)$ | $(K/\tau)\,e^{-t/\tau}$ |
| $\sin\omega t$ | $\dfrac{K}{\sqrt{1+\omega^2\tau^2}}\sin(\omega t - \arctan\omega\tau)$ |

### 传递函数（拉普拉斯）

对于 $p$ 常数：$(s + p) Y(s) = Q(s) + y(0)$。传递函数 $H(s) = 1/(s+p)$ — 单个极点在 $s = -p$。

- $p > 0$：稳定（极点在左半平面）。
- $p < 0$：不稳定。

### 叠加原理

因为常微分方程是线性的，如果 $y_1$ 解决 $\mathcal{L}y = q_1$ 而 $y_2$ 解决 $\mathcal{L}y = q_2$，那么 $\alpha y_1 + \beta y_2$ 解决 $\mathcal{L}y = \alpha q_1 + \beta q_2$。傅里叶分析和拉普拉斯分析的基础。

### 直接应用

| 系统 | 常微分方程 | $\tau$ |
|---|---|---|
| RC 电路 | $RC\,\dot V + V = V_s$ | $RC$ |
| RL 电路 | $(L/R)\,\dot i + i = V/R$ | $L/R$ |
| CSTR 反应器 | $(V/Q)\,\dot c + c = c_{in}$ | $V/Q$ |
| 温度计 | $\tau\,\dot T + T = T_{\text{amb}}$ | $\tau$ 热常数 |

</Porta>

<Porta nivel="40" titulo="给资深专业人士讲">

一阶线性常微分方程位于**算子代数**、**函数分析**和**经典控制理论**的交集处。

### 算子观点

定义 $\mathcal{L} = \tfrac{d}{dx} + p(x)$ — 在 $C^1(I)$ 上的线性算子。常微分方程是 $\mathcal{L}y = q$。$\mathcal{L}$ 的**逆**是与**格林函数**的卷积积分：

$$y(x) = \int_{x_0}^{x} G(x, s)\,q(s)\,ds + y_h(x), \quad G(x,s) = \exp\!\left(-\int_s^x p(t)\,dt\right)$$

### 低通滤波器

对于 $p$ 常数，$\tau = 1/p$：$H(j\omega) = 1/(1 + j\omega\tau)$。

$$|H(j\omega)| = \frac{1}{\sqrt{1+\omega^2\tau^2}}, \quad \angle H = -\arctan(\omega\tau)$$

截止频率 $\omega_c = 1/\tau$。在 $\omega_c$ 以上的衰减为 $-20$ dB/dec。

### 李卡提方程

$y' = a(x)y^2 + b(x)y + c(x)$ — 非线性。通过代换 $y = -u'/(au)$ 可转化为二阶线性方程。与量子力学（达布势）的联系。

### 分布和格林函数

$G'(x,s) + pG(x,s) = \delta(x-s)$，其中 $G = H(x-s)\,e^{-p(x-s)}$（Heaviside）。因果性：$x$ 处的输出仅取决于 $s \leq x$。

### 通过 Lyapunov 的稳定性

对于 $\dot y + py = 0$，$p > 0$：$V(y) = y^2/2$ 是 Lyapunov 函数。$\dot V = -py^2 \leq 0$ — 全局指数稳定性。

### 宇宙学中的诺贝尔奖

在缓慢滚动暴胀模型中，暴胀场的扰动 $\delta\phi$ 遵循 Hubble 导数中的一阶线性常微分方程。Saul Perlmutter、Brian Schmidt 和 Adam Riess 因发现宇宙加速膨胀获得了 [2011 年物理学诺贝尔奖](https://www.nobelprize.org/prizes/physics/2011/summary/) — 支持它的扰动形式使用的正是这种结构。

</Porta>

<Porta nivel="pratica" titulo="实际应用">

### 完整配方

1. **规范形式**：$y' + p(x)y = q(x)$。若为 $a(x)y' + b(x)y = c(x)$，则除以 $a(x)$。
2. **计算** $\mu = e^{\int p\,dx}$（这里不加 $+C$）。
3. **乘以**：$(\mu y)' = \mu q$。
4. **积分**：$\mu y = \int \mu q\,dx + C$。
5. **隔离**：$y = \mu^{-1}\left(\int \mu q\,dx + C\right)$。
6. **使用** $y(x_0) = y_0$ 找到 $C$。

### 经典错误

- 在识别 $p$ 之前不除以 $y'$ 的系数。
- 符号错误：$y' - 2y = q$ 有 $p = -2$，所以 $\mu = e^{-2x}$。
- 计算 $\mu$ 时加上 $+C$（不必要 — 任何常数都会抵消）。
- 在 $\int \mu q\,dx$ 是多项式和指数的乘积时忘记分部积分。

### 模型：带连续存款的银行账户

账户余额以 $r = 5\%$ 年利率计息，并接收连续的 $d$ 雷亚尔/年存款：

$$\dot S = rS + d \quad\Longleftrightarrow\quad \dot S - rS = d$$

因子：$\mu = e^{-rt}$。解：$S(t) = S_0 e^{rt} + \dfrac{d}{r}(e^{rt} - 1)$。

对于 $S_0 = 0$，$d = 12\,000$/年，$r = 0.05$：10 年后，$S(10) = 12\,000 \cdot (e^{0.5}-1)/0.05 \approx 155\,262$（155 262 巴西雷亚尔）。

### 数值工作流（Python）

```python
from scipy.integrate import odeint
import numpy as np

p, q = lambda x: 2*x, lambda x: 4*x
rhs = lambda y, x: q(x) - p(x)*y[0]

x = np.linspace(0, 3, 300)
sol = odeint(rhs, [5], x)
# 验证：y = 2 + 3*exp(-x**2)
```

## 已解决的例子

<Exemplo titulo="最简单的常微分方程带初值" numero="1">

**问题。** 解 $y' + 2y = 6$，$y(0) = 1$。

**策略。** 识别 $p = 2$（常数），计算 $\mu$，积分。

**解。**

$p = 2$，$q = 6$。因子：$\mu = e^{2x}$。

$(e^{2x} y)' = 6 e^{2x}$。

$e^{2x} y = 3 e^{2x} + C \;\Rightarrow\; y = 3 + C e^{-2x}$。

$y(0) = 1 \;\Rightarrow\; 1 = 3 + C \;\Rightarrow\; C = -2$。

$$y(x) = 3 - 2 e^{-2x}$$

**验证。** $y' = 4 e^{-2x}$。那么 $y' + 2y = 4e^{-2x} + 6 - 4e^{-2x} = 6$。$y(0) = 3 - 2 = 1$。正确。

**来源。** [Lebl, Notes on Diffy Qs, §1.4, Example 1.4.1](https://www.jirka.org/diffyqs/html/firstode_section.html) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="积分因子带变动的 p" numero="2">

**问题。** 解 $y' + 2xy = 4x$，$y(0) = 5$。

**策略。** $p = 2x$ 不是常数；$\mu = e^{x^2}$。

**解。**

$\mu = e^{\int 2x\,dx} = e^{x^2}$。

$(e^{x^2} y)' = 4x e^{x^2}$。

$e^{x^2} y = \int 4x e^{x^2}\,dx = 2e^{x^2} + C \;\Rightarrow\; y = 2 + Ce^{-x^2}$。

$y(0) = 5 \;\Rightarrow\; C = 3$。

$$y(x) = 2 + 3e^{-x^2}$$

**验证。** $y' = -6x e^{-x^2}$。$y' + 2xy = -6xe^{-x^2} + 2x(2+3e^{-x^2}) = 4x$。正确。

**来源。** [Lebl, Notes on Diffy Qs, §1.4, Example 1.4.2](https://www.jirka.org/diffyqs/html/firstode_section.html) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="常微分方程带变动的 y 系数（三角学）" numero="3">

**问题。** 解 $y' + y\tan x = \sec x$。

**策略。** $p = \tan x$；$\int \tan x\,dx = -\ln|\cos x|$；所以 $\mu = \sec x$。

**解。**

$\mu = e^{-\ln|\cos x|} = \sec x$。

$(\sec x\cdot y)' = \sec^2 x$。

$y\sec x = \tan x + C \;\Rightarrow\; y = \sin x + C\cos x$。

**验证。** $y' = \cos x - C\sin x$。$y' + y\tan x = \cos x - C\sin x + (\sin x + C\cos x)\tan x = \cos x - C\sin x + \sin x \tan x + C\sin x = \cos x + \sin x\tan x = \cos x + \sin^2 x/\cos x = (cos^2 x + \sin^2 x)/\cos x = \sec x$。正确。

**来源。** [Trench, Elementary Differential Equations, §2.1, Example 2.1.3](https://digitalcommons.trinity.edu/mono/9/) — 开放。

</Exemplo>

<Exemplo titulo="带阶跃源的 RC 电路" numero="4">

**问题。** RC 电路：$R = 2\,\text{k}\Omega$，$C = 50\,\mu\text{F}$，源 $V_s = 12\,\text{V}$（在 $t = 0$ 连接），$V_C(0) = 0$。找到 $V_C(t)$ 并计算 $\tau$。

**策略。** RC 电路的常微分方程是 $\dot V_C + V_C/(RC) = V_s/(RC)$。识别 $p = 1/(RC)$，$q = V_s/(RC)$。

**解。**

$\tau = RC = 2000 \times 50 \times 10^{-6} = 0.1\,\text{s}$。

常微分方程：$\dot V_C + V_C/\tau = V_s/\tau$。

$\mu = e^{t/\tau}$。$(e^{t/\tau} V_C)' = (V_s/\tau)e^{t/\tau}$。

$e^{t/\tau} V_C = V_s e^{t/\tau} + C \;\Rightarrow\; V_C = V_s + Ce^{-t/\tau}$。

$V_C(0) = 0 \;\Rightarrow\; C = -V_s$。

$$V_C(t) = 12\bigl(1 - e^{-t/0.1}\bigr)\,\text{V}$$

在 $t = \tau = 0.1\,\text{s}$：$V_C \approx 12(1 - 1/e) \approx 7.58\,\text{V}$（12 V 的 63%）。在 $5\tau = 0.5\,\text{s}$：$V_C \approx 11.9\,\text{V}$（99%）。

**验证。** $\dot V_C = 12/0.1 \cdot e^{-10t} = 120 e^{-10t}$。$\dot V_C + 10 V_C = 120 e^{-10t} + 120(1 - e^{-10t}) = 120 = V_s/\tau$。正确。

**来源。** [OpenStax Calculus Volume 2, §4.5, Example 4.29](https://openstax.org/books/calculus-volume-2/pages/4-5-first-order-linear-equations) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="混合：装盐的水箱" numero="5">

**问题。** 200 L 的水箱最初含有 50 g 溶解的盐。盐水以 2 g/L 的浓度以 4 L/min 的速率流入；混合物以相同的速率流出。1 小时后盐的量 $Q(t)$。

**策略。** 质量平衡：$\dot Q = \text{输入} - \text{输出} = 4\cdot 2 - 4\cdot(Q/200)$。

**解。**

$\dot Q + Q/50 = 8$，$Q(0) = 50$。

$p = 1/50$，$\mu = e^{t/50}$。

$(e^{t/50} Q)' = 8 e^{t/50}$。

$Q = 400 + Ce^{-t/50}$。

$Q(0) = 50 \;\Rightarrow\; C = -350$。

$$Q(t) = 400 - 350\,e^{-t/50}\;\text{(g)}$$

在 $t = 60\,\text{min}$：$Q(60) = 400 - 350\,e^{-1.2} \approx 400 - 350 \times 0.3012 \approx 294.6\,\text{g}$。

**验证。** $\dot Q = 7 e^{-t/50}$。$\dot Q + Q/50 = 7e^{-t/50} + 8 - 7e^{-t/50} = 8$。正确。

**来源。** [Lebl, Notes on Diffy Qs, §1.5, Example 1.5.1](https://www.jirka.org/diffyqs/html/auteq_section.html) — CC-BY-SA。
