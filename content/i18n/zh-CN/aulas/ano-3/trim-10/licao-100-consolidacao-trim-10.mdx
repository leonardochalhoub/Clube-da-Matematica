<Definicao titulo="常微分方程分类流程图">

给定常微分方程，按顺序检查：

1. **阶数？** 有多少个导数？仅有 <Eq>{`y'`}</Eq>：一阶。有 <Eq>{`y''`}</Eq>：二阶。
2. **线性？** <Eq>{`y, y', y''`}</Eq> 中的所有项都是线性的吗（无乘积、无关于 <Eq>{`y`}</Eq> 的函数）？
3. **一阶线性**: <Eq>{`y' + p(x)y = q(x)`}</Eq> → 积分因子 <Eq>{`\\mu = e^{\\int p\\,dx}`}</Eq>。
4. **一阶可分离**: <Eq>{`y' = g(x)h(y)`}</Eq> → 分离并积分。
5. **常系数二阶**: <Eq>{`ay'' + by' + cy = q(x)`}</Eq> → 特征方程 + <Eq>{`y_p`}</Eq> 通过待定系数法或参数变换。
6. **非解析型**: 不符合上述任何形式的任何形式 → 数值方法（欧拉法/RK4）。

</Definicao>

> "存在性与唯一性定理说：在 <Eq>{`f`}</Eq> 和 <Eq>{`\\partial f/\\partial y`}</Eq> 连续的每个点 (x₀, y₀) 处，恰好存在一条解曲线。"
> — [Lebl, *Notes on Diffy Qs* §1.2](https://www.jirka.org/diffyqs/html/intro_section.html)

<Teorema titulo="二阶线性解的结构">

如果 <Eq>{`y_1, y_2`}</Eq> 是 <Eq>{`ay'' + by' + cy = 0`}</Eq> 的线性无关解，且 <Eq>{`y_p`}</Eq> 是 <Eq>{`ay'' + by' + cy = q(x)`}</Eq> 的任意一个特解，那么非齐次方程的所有解都是

<Equation latex="y = C_1 y_1 + C_2 y_2 + y_p, \quad C_1, C_2 \in \mathbb{R}." />

**证明（概要）。** 设 <Eq>{`z`}</Eq> 为另一个解；则 <Eq>{`z - y_p`}</Eq> 满足齐次方程，因此属于由 <Eq>{`y_1, y_2`}</Eq> 生成的空间。 <Eq>{`\\square`}</Eq>

<Porta nivel="5" titulo="随时间变化的方程">

我们学会了处理**始终在变化的东西**：冷却的温度、增长的种群、摇晃的桥梁。

对于每种变化类型，都存在一个**不同的技巧**。有时数学将变量分离成一个简单的计算。有时需要一个"魔法因子"来简化一切。当没有技巧有效时，计算机一步步做**直到得到答案**。

在这堂课中，我们汇总了所有技巧并为每个问题选择了正确的。

</Porta>

<Porta nivel="10" titulo="八种技术，一张地图">

在第10学期期间，您学到了**八种**处理变化方程的方法：

1. **可分离** — x和y分离：积分各边。
2. **一阶线性** — 积分因子将其转换为一边。
3. **马尔萨斯** — 成比例增长：指数。
4. **逻辑斯谛** — 具有承载能力限制的增长。
5. **二阶齐次** — 特征方程给出指数或正弦。
6. **振动** — 质量-弹簧带阻尼和强迫。
7. **RLC** — 与质量-弹簧相同，但有电子。
8. **欧拉法/RK4** — 当没有闭式公式时，计算机逐步求解。

**如何选择？** 看有多少个导数：仅有 <Eq>{`y'`}</Eq> → 一阶。有 <Eq>{`y''`}</Eq> → 二阶。如果您识别出规范模型之一（逻辑斯谛、冷却、质量-弹簧），请直接使用该模型。

</Porta>

<Porta nivel="15" titulo="决策流程图和常见错误">

### 快速决策

```
常微分方程来临：
├─ 仅有y'：一阶
│  ├─ x和y分离？ → 可分离，积分
│  ├─ 形式y' + p(x)y = q(x)？ → 积分因子
│  └─ 都不是？ → 代换（伯努利、恰当）或数值
└─ 有y''：二阶
   ├─ 常系数？
   │  ├─ 齐次 → 特征方程
   │  └─ 非齐次 → y_h + y_p（待定系数）
   └─ 变系数 → 柯西-欧拉、级数或数值
```

### 学期经典错误

- **在可分离中忘记常数解**：如果 <Eq>{`h(y_0) = 0`}</Eq>，则 <Eq>{`y \\equiv y_0`}</Eq> 是奇异解。除以 <Eq>{`h(y)`}</Eq> 仅在根之外有效。
- **在非线性常微分方程中使用积分因子**：<Eq>{`y' = y^2`}</Eq> 不是线性的，没有积分因子。
- **混淆 <Eq>{`\\omega_0`}</Eq> 和 <Eq>{`\\omega_d`}</Eq>**：自然频率vs阻尼频率。<Eq>{`\\omega_d = \\omega_0\\sqrt{1-\\zeta^2}`}</Eq>。
- **在刚性问题中使用大欧拉步长**：具有短时间常数的系统（R大的RLC）会破坏显式欧拉法的稳定性。
- **共振**：当力的频率为 <Eq>{`\\omega_0`}</Eq> 和 <Eq>{`\\zeta = 0`}</Eq> 时，<Eq>{`y_p`}</Eq> 必须包含因子 <Eq>{`t`}</Eq>。

### 快速验证

始终将解代入原始常微分方程。如果结果不匹配，解是错误的。

<Porta nivel="25" titulo="工程地图：领域和规范常微分方程">

常微分方程是**工程的语言**。每个领域都有其结构模型。

### 机械

- 平移动力学：<Eq>{`m\\ddot x = F`}</Eq>。
- 线性振动：<Eq>{`m\\ddot x + c\\dot x + kx = F(t)`}</Eq>。品质因数 <Eq>{`Q = 1/(2\\zeta)`}</Eq>。
- 稳定性：围绕平衡的线性化，<Eq>{`Df(x^*)`}</Eq> 的特征值。

### 电气

- RC、RL、LC、RLC：质量-弹簧的精确类似物。
- 传输线：电报员方程（EDP → 分离的常微分方程）。
- 电机：Park变换方程（dq0变换）。

### 化学与过程

- 一阶动力学：<Eq>{`\\dot c = -kc`}</Eq>。
- 具有放热反应的CSTR：质量+能量平衡、耦合常微分方程组。
- 扩散-反应（1D）：<Eq>{`D c'' = \\lambda c`}</Eq>（空间中的二阶常微分方程）。

### 控制

- PID控制二阶被控对象。闭环极点确定响应。
- 状态反馈：<Eq>{`\\dot{\\mathbf x} = A\\mathbf x + B\\mathbf u`}</Eq>、<Eq>{`\\mathbf u = -K\\mathbf x`}</Eq>。
- 劳斯-赫尔维茨准则：无需求解方程的稳定性。

### 专业工作流程

1. **从物理建模**（平衡）。
2. **无量纲化** — 识别Bi、Re、<Eq>{`\\zeta`}</Eq>、<Eq>{`\\omega_0 T`}</Eq>。
3. **线性化**如果 <Eq>{`\\Delta`}</Eq> 很小；解析变得容易。
4. **求解**解析或数值。
5. **使用实验或高保真度模拟进行验证**。
6. **优化参数**（控制、尺寸）。

</Porta>

<Porta nivel="40" titulo="动力系统、伴随和现代前沿">

### 几何和流

每个自治常微分方程 <Eq>{`\\dot x = f(x)`}</Eq> 在流形上定义一个**流** <Eq>{`\\phi_t`}</Eq>。核心概念：

- **平衡点**：<Eq>{`f(x^*) = 0`}</Eq>。哈特曼-格罗布曼：如果 <Eq>{`Df(x^*)`}</Eq> 没有纯虚特征值，<Eq>{`\\phi_t`}</Eq> 局部拓扑共轭于线性化。
- **稳定/不稳定流形**：不变；构造相肖像。
- **分岔**：鞍结、Hopf、周期倍增。参数分岔图。
- **混沌**：正李亚普诺夫指数。洛伦兹吸引子。

### 常微分方程的伴随

为了优化函数 <Eq>{`J = \\int_0^T g(x,u)\\,dt`}</Eq> 受约束 <Eq>{`\\dot x = f(x,u)`}</Eq>，关于 <Eq>{`u`}</Eq> 的梯度通过**反向伴随方程**计算。成本：一次前向积分 + 一次反向，与 <Eq>{`u`}</Eq> 的维度无关。现代反向传播在神经常微分方程中的基础（Chen等人，NeurIPS 2018）。

### 现代方法

- **SINDy**（Brunton等人，2016）：通过稀疏回归从数据中识别常微分方程。
- **神经常微分方程**：连续极限中的残差网络；用伴随训练。
- **PINN**（Raissi等人，2019）：最小化常微分方程残差 + 数据。
- **几何积分**：辛（Störmer-Verlet）保留能量；Lie群保留结构。

### 相关诺贝尔奖

詹姆斯·皮布尔斯因对物理宇宙学的理论贡献获得[2019年诺贝尔物理学奖](https://www.nobelprize.org/prizes/physics/2019/summary/)。弗里德曼方程——管辖宇宙膨胀——是尺度因子 <Eq>{`a(t)`}</Eq> 的一阶自治常微分方程。

### 随机微分方程

随机常微分方程：<Eq>{`dX = f(X)\\,dt + g(X)\\,dW`}</Eq>（Itô）。金融（Black-Scholes）、分子生物学（遗传噪声）、鲁棒控制。

### 模型选择：实用规则

在任何计算之前，在流程图中对问题进行分类。具有巴西背景的示例：

**简单流行病（新冠肺炎，巴西）：** <Eq>{`\\dot I = (\\beta - \\gamma)I`}</Eq> 开始时。可分离 → 指数。当 <Eq>{`S`}</Eq> 下降时：<Eq>{`\\dot I = (\\beta S/N - \\gamma)I`}</Eq>、SIR系统、数值求解。

**工业反应堆（巴西石油公司，炼油厂）：** 换热器出口温度：<Eq>{`mc_p \\dot T = UA(T_s - T)`}</Eq> — 一阶线性、积分因子。

**结构（保利斯塔大厦在风中）：** 振动的基本模式：<Eq>{`m\\ddot x + c\\dot x + kx = F_0\\cos(\\omega t)`}</Eq>。共振担忧如果 <Eq>{`\\omega \\approx \\omega_0`}</Eq>。

**音频滤波器（放大器，圣保罗）：** 低通RLC、<Eq>{`f_c = \\omega_0/(2\\pi) = 1/(2\\pi\\sqrt{LC})`}</Eq>。选择 <Eq>{`L`}</Eq> 和 <Eq>{`C`}</Eq> 为 <Eq>{`f_c = 1`}</Eq> kHz。

**药物动力学（ANVISA）：** 药物消失：<Eq>{`\\dot C = -k_e C`}</Eq>。半衰期 <Eq>{`t_{1/2} = \\ln 2/k_e`}</Eq>。对于扑热息痛，<Eq>{`t_{1/2} \\approx 2`}</Eq> h。

## 已解决的示例

<Exemplo titulo="分类和求解一阶可分离常微分方程">

**问题。** 求解初值问题 <Eq>{`y' = 2xy`}</Eq>、<Eq>{`y(0) = 3`}</Eq>。

**策略。** 验证是否可分离：重写为 <Eq>{`dy/y = 2x\\,dx`}</Eq> 并对各边积分。应用初始条件以确定常数。

**解决方案。**

<Equation latex="\frac{dy}{y} = 2x\,dx \;\Longrightarrow\; \ln|y| = x^2 + C_1 \;\Longrightarrow\; y = Ce^{x^2}." />

初始条件：<Eq>{`y(0) = C = 3`}</Eq>。解：<Eq>{`y = 3e^{x^2}`}</Eq>。

**验证。** <Eq>{`y' = 6xe^{x^2} = 2x\\cdot 3e^{x^2} = 2xy`}</Eq>。<Eq>{`y(0) = 3`}</Eq>。正确。

**来源。** [Lebl, *Notes on Diffy Qs* §1.3](https://www.jirka.org/diffyqs/html/separable_section.html)、习题1.3.2。

</Exemplo>

<Exemplo titulo="积分因子：具有非平凡q(x)的一阶线性常微分方程">

**问题。** 求解 <Eq>{`y' + (2/x)y = x^2`}</Eq>。

**策略。** 识别 <Eq>{`p(x) = 2/x`}</Eq> 并计算 <Eq>{`\\mu = e^{\\int 2/x\\,dx} = x^2`}</Eq>。将常微分方程乘以 <Eq>{`\\mu`}</Eq> 并将左边识别为乘积的导数。

**解决方案。**

<Exemplo titulo="具有真实人口数据的逻辑斯谛模型">

**问题。** 一个城市的人口：2000年50000人、2010年80000人。估计的承载能力为200000人。逻辑斯谛模型 <Eq>{`\\dot P = rP(1-P/K)`}</Eq>。找到 <Eq>{`r`}</Eq> 并预测2030年的人口。

<Exemplo titulo="应用于牛顿冷却的欧拉法：误差vs步长">

**问题。** 咖啡温度为90°C、<Eq>{`T_a = 22`}</Eq>°C、<Eq>{`k = 0{,}1`}</Eq> min⁻¹。使用欧拉法 <Eq>{`h = 2`}</Eq> min 计算 <Eq>{`T(4)`}</Eq>。与精确值比较。

**策略。** 常微分方程：<Eq>{`T' = -0{,}1(T - 22)`}</Eq>、<Eq>{`T(0) = 90`}</Eq>。两个欧拉步骤。精确解：<Eq>{`T(t) = 22 + 68e^{-0{,}1t}`}</Eq>。

**解决方案。**

步骤1（<Eq>{`t=0 \\to 2`}</Eq>）：<Eq>{`f(0, 90) = -0{,}1(90-22) = -6{,}8`}</Eq>。<Eq>{`T(2) \\approx 90 + 2\\times(-6{,}8) = 76{,}4`}</Eq>°C。

步骤2（<Eq>{`t=2 \\to 4`}</Eq>）：<Eq>{`f(2, 76{,}4) = -0{,}1(76{,}4-22) = -5{,}44`}</Eq>。<Eq>{`T(4) \\approx 76{,}4 + 2\\times(-5{,}44) = 65{,}52`}</Eq>°C。

精确：<Eq>{`T(4) = 22 + 68e^{-0{,}4} = 22 + 68\\times 0{,}6703 \\approx 67{,}6`}</Eq>°C。

**验证。** 欧拉局部误差公式：<Eq>{`O(h^2) = O(4) = 0{,}1^2 \\times 68 \\times (e^{-0{,}1 \\times 0}/2) \\approx 0{,}34`}</Eq>°C每步，累积到~0.68°C — 正确的阶数。

**来源。** [REAMAT UFRGS, *数值分析* 第8章](https://www.ufrgs.br/reamat/CalculoNumerico/livro-py/main.html)、第8.2节、示例8.3。

</Exemplo>
