### 标准形式和可分离性

<Definicao titulo="一阶可分离微分方程">

一阶微分方程 $\dfrac{dy}{dx} = F(x, y)$ 是**可分离的**，当且仅当 $F$ 能够分解为某个只关于 $x$ 的函数和某个只关于 $y$ 的函数的乘积：

$$\frac{dy}{dx} = g(x) \cdot h(y), \quad g : I \to \mathbb{R},\; h : J \to \mathbb{R}$$

**求解方法**（假设 $h(y) \neq 0$）：

1. 改写为：$\dfrac{dy}{h(y)} = g(x)\,dx$。
2. 两边积分：$\displaystyle\int \frac{dy}{h(y)} = \int g(x)\,dx + C$。
3. 得到 $H(y) = G(x) + C$，其中 $H' = 1/h$ 和 $G' = g$。
4. 求解 $y$（**显式解**），如果可能的话；否则，保持**隐式形式** $H(y) = G(x) + C$。

</Definicao>

> "A separable equation is actually the first kind of differential equation that can be solved explicitly." — [Lebl, Notes on Diffy Qs, §1.3](https://www.jirka.org/diffyqs/html/separable_section.html)

### 奇异解（平衡点）

<Definicao titulo="常数解和平衡点">

满足 $h(y^*) = 0$ 的值 $y^* \in J$ 生成**常数解** $y(x) \equiv y^*$，与 $g$ 无关。这些解不是通过积分过程得到的——必须在识别 $h$ 的零点后单独验证。

<Insight>

分离变量方法中除以 $h(y)$ **会消除**常数解。如果 $y^* = 0$ 是 $h$ 的零点，解 $y \equiv 0$ 可能不包含在族 $H(y) = G(x) + C$ 中——即使没有任何 $C$ 值能够重现它。

</Insight>

</Definicao>

### 存在性和唯一性定理（Picard-Lindelöf）

<Teorema titulo="可分离微分方程的局部存在性和唯一性">

设 $\dfrac{dy}{dx} = g(x)\,h(y)$ 且初值条件为 $y(x_0) = y_0$。如果 $g$ 在 $(x_0 - \delta, x_0 + \delta)$ 上连续，且 $h$ 在 $y_0$ 的某个邻域内**Lipschitz 连续**——即存在 $L > 0$ 使得 $|h(y_1) - h(y_2)| \leq L|y_1 - y_2|$——，那么存在 $\varepsilon > 0$ 和唯一解 $y : (x_0 - \varepsilon, x_0 + \varepsilon) \to \mathbb{R}$ 满足该初值问题。

</Teorema>

> "Theorem 1.2.1. If $f(x,y)$ is continuous and $\partial f/\partial y$ is continuous near some $(x_0, y_0)$, then a solution exists for $x$ near $x_0$, and is unique." — [Lebl, Notes on Diffy Qs, §1.2](https://www.jirka.org/diffyqs/html/picard_section.html)

### 方向场和定性分析

<Definicao titulo="方向场">

对于 $\dfrac{dy}{dx} = g(x)\,h(y)$，**方向场**在每一点 $(x, y)$ 处关联向量 $(1,\, g(x)h(y))$，表示该点处解的斜率。等斜线是满足 $g(x)h(y) = k$（常数斜率）的曲线。**水平等斜线**满足 $h(y^*) = 0$——它们是平衡点。

</Definicao>

### Osgood 准则（全局存在性）

<Teorema titulo="全局存在性的 Osgood 准则">

对于自治微分方程 $\dot y = h(y)$ 和初值 $y(0) = y_0 > 0$，解对所有 $t \geq 0$ 存在当且仅当

$$\int_{y_0}^{+\infty} \frac{dy}{h(y)} = +\infty.$$

如果积分收敛，则发生**有限时间爆破**——解在有限时刻 $T < +\infty$ 处逃至 $+\infty$，该时刻由 $T = \displaystyle\int_{y_0}^{+\infty} dy/h(y)$ 给出。

</Teorema>

**示例：** $\dot y = y^2$，$y(0) = 1$。$\displaystyle\int_1^\infty dy/y^2 = 1 < \infty$ ——爆破在 $T = 1$ 处。

</Porta>

<Porta nivel="5" titulo="对5岁小孩的解释">

想象你有一个装满**彩色小球**的盒子——一半是红色（这代表 $x$）一半是蓝色（这代表 $y$）。它们全都混在一起。

我们想要**分开**：把红色球放在一个杯子里，蓝色球放在另一个杯子里。然后你**分别**数每个杯子里的球（这就是所谓的积分）。最后你就能发现一个函数来描述增长或衰减。

这就是"分离变量"所做的：把所有关于 $x$ 的都放在同一侧，所有关于 $y$ 的都放在另一侧。然后"数"每一侧（这样你就能发现增长或衰减的规律）。

</Porta>

<Porta nivel="10" titulo="对10岁孩子的解释">

一个**微分方程**就像一个拼图：有人告诉你**某个东西每一瞬间如何变化**，你需要发现**这个东西随着时间如何演变**。

例如："一个细菌每小时分裂成两个。开始时有100个细菌。5小时后有多少个？"

在数学中：$\dfrac{dP}{dt} = P$（增长速度等于已经有的数量）。要求解它，我们使用**分离变量的技巧**：

$$\frac{dP}{P} = dt \;\Rightarrow\; \ln P = t + C \;\Rightarrow\; P(t) = P_0 \, e^t$$

当 $P_0 = 100$ 时：$P(5) = 100\,e^5 \approx 14\,841$ 个细菌。

这个技巧叫做**分离变量**：把所有与 $P$ 相关的放在一侧，所有与 $t$ 相关的放在另一侧，然后积分。只要能够"分离"这两个成分，这个办法就总是有效的。

</Porta>

<Porta nivel="15" titulo="对15岁青少年的解释">

一个**可分离的微分方程**具有形式 $\dfrac{dy}{dx} = g(x)\,h(y)$——两个函数的乘积，每个都只取决于一个变量。方法如下：

1. **分离**：除以 $h(y)$ 并乘以 $dx$：$\dfrac{dy}{h(y)} = g(x)\,dx$。
2. **积分**两边：$\displaystyle\int \frac{dy}{h(y)} = \int g(x)\,dx + C$。
3. **求解** $y$，如果可能的话。
4. **应用**初值条件来找出 $C$。

### 经典示例——放射性衰变

碳-14 的衰变速率与剩余数量成正比：$\dfrac{dN}{dt} = -k N$。

分离：$\dfrac{dN}{N} = -k\,dt$。
积分：$\ln |N| = -kt + C$。
取幂：$N(t) = N_0 e^{-kt}$。

当 $k = \ln 2 / 5730$（半衰期为5730年）且 $N_0 = 100\%$ 时，10000年后剩余 $N(10000) = e^{-10000k} \approx 29\%$。

### 不要忘记常数解

如果 $h(y^*) = 0$ 对某个 $y^*$ 成立，那么 $y \equiv y^*$ 是一个**不会出现**在你除以 $h(y)$ 时的解。总要检查。

<Insight>

分离变量是唯一一个**不需要线性性就能通用**的方法。大多数非线性微分方程没有解析解——但如果是可分离的，就有。

</Insight>

</Porta>

<Porta nivel="25" titulo="对工程学学生的解释">

可分离的是微分方程中**第一个可积闭类**。所有后续技术——积分因子、Bernoulli 替换、Riccati 方程——都将问题归结为可分离性或直接积分。

### 工程经典模型

| 现象 | 微分方程 | 解 |
|---|---|---|
| 放射性衰变 | $\dot N = -kN$ | $N_0 e^{-kt}$ |
| 电容器放电 | $\dot V = -V/(RC)$ | $V_0 e^{-t/RC}$ |
| 牛顿冷却定律 | $\dot T = -k(T - T_a)$ | $(T_0 - T_a)e^{-kt} + T_a$ |
| Malthus 增长 | $\dot P = rP$ | $P_0 e^{rt}$ |
| 逻辑斯谛增长 | $\dot P = rP(1-P/K)$ | $K/(1+Ae^{-rt})$ |
| 混合坦克出口 | $\dot c = -(Q/V)c$ | $c_0 e^{-Qt/V}$ |

### 通过部分分式的逻辑斯谛方程

微分方程 $\dfrac{dP}{dt} = rP\!\left(1 - \dfrac{P}{K}\right)$ 需要部分分式：

$$\int \frac{dP}{P(1-P/K)} = rt + C.$$

分解：$\dfrac{1}{P(1-P/K)} = \dfrac{1}{P} + \dfrac{1/K}{1-P/K}$。

积分：$\ln P - \ln(1-P/K) = rt + C$，故 $P(t) = \dfrac{K}{1 + A e^{-rt}}$（S 形曲线）。

### 有限时间爆破

$\dot y = y^2$，$y(0) = 1 \Rightarrow y(t) = 1/(1-t)$：解在 $t = 1$ 爆炸。**局部解总是存在；全局解，不是**。

### 跨领域应用

- **化学**：一阶反应动力学 $[\mathrm{A}]' = -k[\mathrm{A}]$。
- **药物动力学**：单室消除 $C(t) = C_0 e^{-k_e t}$。
- **量化金融**：连续复利 $\dot S = rS \Rightarrow S = S_0 e^{rt}$ ——Black-Scholes 模型的基础（第119课）。
- **宇宙学**：de Sitter 膨胀 $\dot a = H a \Rightarrow a = a_0 e^{Ht}$。

</Porta>

<Porta nivel="40" titulo="对高级专业人士的解释">

可分离性是**精确微分方程**的特例，并通过 **Lie 对称性**进行解释：微分方程 $dy/dx = g(x)h(y)$ 对由向量场 $X = g(x)\partial_x + h(y)\partial_y$ 生成的膨胀群是不变的。

### 几何视角——乘积流形

微分方程在平面 $(x,y)$ 上定义向量场 $V = (1, g(x)h(y))$。可分离性意味着 $V$ 分解为一维向量场的张量乘积：$V = \partial_x \otimes g \cdot \partial_y \otimes h$。变量改变 $u = \int dy/h(y)$，$v = \int g(x)dx$ 整直流：在 $(u,v)$ 中，微分方程变为 $du/dv = 1$ ——均匀平移。

### 全局存在性和 Osgood 准则

$\dot y = h(y)$ 的解，$y(0) = y_0$ 在 $[0, +\infty)$ 上存在当且仅当 $\int_{y_0}^\infty dy/h(y) = +\infty$（Osgood 准则）。否则，爆破在 $T = \int_{y_0}^\infty dy/h(y) < \infty$。

### 双曲型偏微分方程和特征线

双曲型偏微分方程 $\partial_t u + c(x)\partial_x u = 0$ 沿着**特征曲线** $dx/dt = c(x)$ 归结为可分离的微分方程。整个 Cauchy-Kovalevskaya 特征理论都基于这个要点。

### Hubble 定律和诺贝尔奖

宇宙学微分方程 $\dot a = Ha$（de Sitter）——其中 $H$ 是 Hubble 常数——是宇宙物理学中最著名的可分离微分方程。**宇宙加速膨胀**的发现，这在实验上确认了 $H > 0$ 在增加，为 Saul Perlmutter、Brian Schmidt 和 Adam Riess 赢得了 [2011 年物理学诺贝尔奖](https://www.nobelprize.org/prizes/physics/2011/summary/)。

### 数值 vs. 解析

积分 $\int dy/h(y)$ 可能不是基本函数——例如，$h(y) = e^{-y^2}$ 导向误差函数。在这些情况下，我们使用数值积分（Euler 法、Runge-Kutta 4——第98课）。可分离结构仍然很有价值，因为它将一个二维微分方程归结为两个一维问题。

</Porta>

<Porta nivel="pratica" titulo="实践——使用真实数据的建模">

### 6 步配方

1. 在形式 $dy/dx = g(x)\,h(y)$ 中识别 $g(x)$ 和 $h(y)$。
2. 分离：$dy/h(y) = g(x)\,dx$。
3. 对每一侧积分。
4. 仅在**一侧**添加 $+C$。
5. 求解 $y$（如果可能则求显式形式）。
6. 使用初值条件来固定 $C$。

### 咖啡冷却（牛顿）

一杯 90°C 的咖啡在 20°C 的房间里冷却。5 分钟后达到 70°C。何时达到 30°C？

牛顿定律：$\dfrac{dT}{dt} = -k(T - 20)$。

分离并积分：$T(t) = 20 + 70\,e^{-kt}$。从 $T(5) = 70$：$k = \dfrac{1}{5}\ln(70/50) \approx 0.0673\,\mathrm{min}^{-1}$。

对于 $T = 30$：$10 = 70\,e^{-kt}$，故 $t = \dfrac{\ln 7}{k} \approx 29.1$ 分钟。

### 药物浓度（药物动力学）

500 毫克静脉注射。消除速率 $k_e = 0.1\,\mathrm{h}^{-1}$。何时剩余少于 10%（少于 50 毫克）？

$C(t) = 500\,e^{-0.1t}$。求解：$50 = 500\,e^{-0.1t} \Rightarrow t = 10\ln 10 \approx 23.0\,\mathrm{h}$。

### 连续投资（金融）

年利率 6% 的储蓄和连续复利：$\dot S = 0.06\,S$，$S(0) = 10000$（R\$10,000）。

$S(t) = 10000\,e^{0.06t}$。当 $e^{0.06t} = 2$ 时翻倍，即 $t = \ln 2 / 0.06 \approx 11.6$ 年。

### 常见错误

- **忘记 $+C$**：解失去了自由参数——族被简化为一点。
- **忘记常数解**：$h(y^*) = 0$ 生成该方法捕获不了的解。
- **写 $\ln y$ 而不用模**：应该是 $\ln |y|$——定义域很重要。
- **不用初值条件固定 $C$**：给出曲线族，而不是特定的解。

</Porta>

<Exemplo titulo="dy/dx = ky 的通解（应用）" numero="1">

**问题。** 求解 $\dfrac{dy}{dx} = 3y$。

**策略。** 微分方程是可分离的，$g(x) = 3$ 和 $h(y) = y$。分离、积分、取幂。

**解。**

$$\frac{dy}{y} = 3\,dx$$

$$\int \frac{dy}{y} = \int 3\,dx + C \;\Rightarrow\; \ln|y| = 3x + C$$

$$|y| = e^{3x+C} = e^C\,e^{3x}.$$

写 $A = \pm e^C$（任意非零实常数）：

$$y(x) = A e^{3x}, \quad A \in \mathbb{R}\setminus\{0\}.$$

验证：$y = 0$ 也求解（常数解，因为 $h(0)=0$）。包括 $A = 0$。

**验证。** $y' = 3A e^{3x} = 3y$ ——正确。

**来源。** [Lebl, Notes on Diffy Qs, §1.3, ex. 1.3.1](https://www.jirka.org/diffyqs/html/separable_section.html) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="初值问题和初值条件——指数衰变（应用）" numero="2">

**问题。** 求解初值问题 $\dfrac{dy}{dx} = -\dfrac{y}{2}$，$y(0) = 4$。

**策略。** 分离变量、积分、应用初值条件来固定 $C$。

**解。**

$$\frac{dy}{y} = -\frac{1}{2}\,dx \;\Rightarrow\; \ln|y| = -\frac{x}{2} + C \;\Rightarrow\; y = A\,e^{-x/2}.$$

初值条件：$4 = A\,e^0 = A$，故 $A = 4$。

$$y(x) = 4\,e^{-x/2}.$$

**验证。** $y' = -2\,e^{-x/2} = -y/2$ 且 $y(0) = 4$ ——正确。

**来源。** [OpenStax Calculus Vol. 2, §4.3, Example 4.15](https://openstax.org/books/calculus-volume-2/pages/4-3-separable-equations) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="使用部分分式的微分方程——逻辑斯谛增长（中级）" numero="3">

**问题。** 求解 $\dfrac{dP}{dt} = P(1 - P)$，$P(0) = 0.1$。

**策略。** 在 $\dfrac{1}{P(1-P)}$ 中使用部分分式分离并积分。

**解。**

$$\frac{dP}{P(1-P)} = dt.$$

部分分式：$\dfrac{1}{P(1-P)} = \dfrac{1}{P} + \dfrac{1}{1-P}$。

$$\int\!\left(\frac{1}{P} + \frac{1}{1-P}\right)dP = \int dt + C$$

$$\ln P - \ln(1-P) = t + C \;\Rightarrow\; \ln\frac{P}{1-P} = t + C.$$

取幂：$\dfrac{P}{1-P} = e^{t+C} = A e^t$。

求解：$P = \dfrac{A e^t}{1 + A e^t} = \dfrac{1}{1 + B e^{-t}}$。

初值条件：$P(0) = 1/(1+B) = 0.1 \Rightarrow B = 9$。

$$P(t) = \frac{1}{1 + 9e^{-t}}.$$

**验证。** $P(0) = 1/10 = 0.1$ 且 $P \to 1$ 当 $t \to +\infty$ ——正确的逻辑斯谛行为。

**来源。** [Lebl, Notes on Diffy Qs, §1.3, ex. 1.3.4](https://www.jirka.org/diffyqs/html/separable_section.html) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="牛顿冷却定律——真实数据（中级/建模）" numero="4">

**问题。** 一个 90°C 的物体放在 20°C 的房间里。5 分钟后是 70°C。建模并确定何时达到 30°C。

**策略。** 牛顿冷却定律：$\dot T = -k(T - T_a)$。在 $u = T - 20$ 中分离并积分。

**解。**

设 $u = T - 20$。那么 $\dot u = \dot T = -ku$，故 $u(t) = u_0 e^{-kt}$。

当 $u_0 = 90 - 20 = 70$ 时：$u(t) = 70\,e^{-kt}$。

条件：$u(5) = 50$：

$$70 e^{-5k} = 50 \;\Rightarrow\; k = \frac{1}{5}\ln\!\frac{70}{50} = \frac{\ln(7/5)}{5} \approx 0.0673\,\mathrm{min}^{-1}.$$

对于 $T = 30 \Rightarrow u = 10$：

$$70\,e^{-kt} = 10 \;\Rightarrow\; t = \frac{\ln 7}{k} = \frac{5\ln 7}{\ln(7/5)} \approx 29.1\,\mathrm{min}.$$

**验证。** $T(5) = 20 + 70\,e^{-5 \times 0.0673} \approx 70°$C ——确认。

**来源。** [OpenStax Calculus Vol. 2, §4.3, Example 4.17](https://openstax.org/books/calculus-volume-2/pages/4-3-separable-equations) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="有限时间爆破——y 点 = y 平方（高级）" numero="5">

**问题。** 求解 $\dfrac{dy}{dt} = y^2$，$y(0) = 1$。证明解在有限时间爆炸并确定爆破时刻。

**策略。** 分离、积分（幂 $-2$）、隔离 $y$、识别奇点。

**解。**

$$\frac{dy}{y^2} = dt \;\Rightarrow\; \int y^{-2}\,dy = \int dt + C \;\Rightarrow\; -\frac{1}{y} = t + C.$$

故 $y(t) = \dfrac{-1}{t + C}$。

初值条件：$y(0) = -1/C = 1 \Rightarrow C = -1$。

$$y(t) = \frac{1}{1-t}.$$

解在 $(-\infty, 1)$ 上定义，当 $t \to 1^-$ 时满足 $y(t) \to +\infty$：**在 $t = 1$ 处爆破**。

**验证。** $y' = 1/(1-t)^2 = y^2$ 且 $y(0) = 1$ ——正确。Osgood 准则确认：$\int_1^\infty dy/y^2 = 1 < \infty$。

**来源。** [Lebl, Notes on Diffy Qs, §1.3, ex. 1.3.6](https://www.jirka.org/diffyqs/html/separable_section.html) — CC-BY-SA.

</Exemplo>
