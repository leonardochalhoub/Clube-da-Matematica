### Malthus 模型（1798）

<Definicao titulo="Malthus 增长">

$$\dot P = rP, \quad P(0) = P_0$$

- $r > 0$：指数增长 $P(t) = P_0 e^{rt}$。
- $r < 0$：指数衰减。
- 唯一平衡点：$P^* = 0$（$r > 0$ 时不稳定，$r < 0$ 时稳定）。

</Definicao>

> "如果种群的变化率与种群本身成正比，我们得到 Malthus 模型。" — [Lebl, Notes on Diffy Qs, §1.8](https://www.jirka.org/diffyqs/html/auteq_section.html)

### 逻辑模型（Verhulst，1838）

<Definicao titulo="Verhulst 逻辑方程">

$$\dot P = rP\left(1 - \frac{P}{K}\right)$$

- $r$：内禀增长率（量纲：1/时间）。
- $K$：**环境容纳量**（carrying capacity）。
- 该方程是**可分离且非线性的**。

</Definicao>

> "逻辑方程是另一个可分离的方程……假设是种群增长率与当前种群成正比，但当种群接近环境容纳量时减小。" — [OpenStax Calculus Volume 2, §4.4](https://openstax.org/books/calculus-volume-2/pages/4-4-the-logistic-equation)

### 闭形式解

通过部分分式分解：

$$P(t) = \frac{K}{1 + \left(\dfrac{K - P_0}{P_0}\right)e^{-rt}}$$

### 平衡点分析

<Teorema titulo="逻辑方程的平衡点和稳定性">

当 $r, K > 0$ 时，$\dot P = rP(1 - P/K)$ 的两个平衡点为：

- $P^* = 0$：**不稳定**（任何正扰动都会增长）。
- $P^* = K$：**稳定**（任何扰动都会被吸收）。

S 形曲线的拐点出现在 $P = K/2$。

</Teorema>

<Porta nivel="5" titulo="给 5 岁小孩的解释">

想象一个湖里有一批鱼。开始时鱼很少，繁殖很快。但当湖快要满的时候，没有足够的食物，繁殖速度就减慢了。

在 **Malthus 模型** 中：鱼会无限增长（就好像湖是无限的）。

在 **Verhulst 模型** 中：存在一个限制——湖最多能容纳 $K$ 条鱼。当满了以后，增长就停止了。

逻辑曲线有 **S 形**：开始缓慢，中间加速，然后饱和。

</Porta>

<Porta nivel="10" titulo="给 10 岁小孩的解释">

Thomas Malthus（1798）是一位牧师经济学家，他说："种群在固定周期内翻倍"。这就是**指数增长**：$P(t) = P_0 e^{rt}$。

问题是：指数增长永远不会停止，这在现实中是不可能的。

Pierre-François Verhulst（1838）进行了改进：距离上限 $K$（食物、空间、资源）越近，增长就越慢。方程是：

$$\dot P = rP\left(1 - \frac{P}{K}\right)$$

当 $P$ 很小时，因子 $(1 - P/K) \approx 1$，增长几乎是指数的。当 $P \to K$ 时，因子 $\to 0$，增长停止。

</Porta>

<Porta nivel="15" titulo="给 15 岁青少年的解释">

### 两个模型并排比较

**Malthus**：$\dot P = rP$。可分离，简单解 $P_0 e^{rt}$。无限增长。

**Verhulst**：$\dot P = rP(1 - P/K)$。也可分离，但有制动因子。

### 逐步求解 Verhulst

分离变量并使用部分分式：

$$\frac{dP}{P(1 - P/K)} = r\,dt$$

$$\frac{K\,dP}{P(K - P)} = r\,dt \;\Rightarrow\; \left(\frac{1}{P} + \frac{1}{K-P}\right)dP = r\,dt$$

积分：$\ln P - \ln(K-P) = rt + C_0$，或 $\ln\left(\dfrac{P}{K-P}\right) = rt + C_0$。

指数化：$\dfrac{P}{K-P} = A e^{rt}$，其中 $A = (K-P_0)/P_0$ 来自初始条件。求解：

$$P(t) = \frac{K}{1 + Ae^{-rt}}, \quad A = \frac{K - P_0}{P_0}$$

### 行为

- $P_0 < K/2$：S 形曲线，拐点在 $P = K/2$。
- $P_0 > K$：指数衰减到 $K$。
- $t \to \infty$：$P \to K$ 总是成立（如果 $r > 0$）。

### 稳定性

线性分析：$f(P) = rP(1-P/K)$。$f'(K) = -r < 0$：稳定。$f'(0) = r > 0$：不稳定。

</Porta>

<Porta nivel="25" titulo="给工程专业学生的解释">

### 通过线性化进行稳定性分析

平衡点 $P^* = 0$ 和 $P^* = K$。扰动 $p = P - P^*$：

**在 $P^* = K$**：$\dot p = f'(K)\,p = -r\,p$。指数稳定，速率为 $r$。

**在 $P^* = 0$**：$\dot p = f'(0)\,p = r\,p$。不稳定。

### 拐点作为管理目标

$\ddot P = 0 \Rightarrow P = K/2$。$\dot P$ 的最大值：在可持续渔业管理中，建议维持 $P \approx K/2$ 以最大化年度捕获量（最大可持续产量，MSY）。

MSY = $\dfrac{rK}{4}$（峰值捕获速率）。

### Harvey 逻辑模型

泛化：$\dot P = rP^m(1-(P/K)^n)$。当 $m = n = 1$ 时回归到逻辑模型。

### 竞争和捕食模型（扩展）

Lotka-Volterra（2 个物种）：

$$\dot x = ax - bxy, \quad \dot y = -cy + dxy$$

等价性：每个 $\dot x = ax - bxy = x(a - by)$ 都是 $x$ 中的逻辑模型，环境容纳量 $a/b$ 随 $y$ 变化。解：$(x, y)$ 中的闭合轨迹。

### 应用于流行病学（SIR）

Kermack-McKendrick（1927）的 SIR 模型有 $\dot I = \beta SI - \gamma I = I(\beta S - \gamma)$——类似于逻辑模型，用 $S$ 替代 $K$。

</Porta>

<Porta nivel="40" titulo="给资深专业人士的解释">

### 历史和背景

Malthus 在 1798 年发表《人口原理论文》是对 Condorcet 和 Godwin 的政治回应——而不是数学论文。Verhulst（1838）阅读了 Malthus，认识到无限增长的不可能性，并提出了现在以他名字命名的逻辑方程。

逻辑方程重新出现在：
- **统计热力学**：Fermi-Dirac 方程 $n(\varepsilon) = 1/(e^{(\varepsilon-\mu)/kT}+1)$ 在 $\varepsilon$ 中是逻辑的。
- **神经科学**：神经网络中的 sigmoid 激活函数。
- **流行病学**：Herd 阈值 $R_0 = 1$ 类似于不稳定平衡点 $P^* = 0$。

### 分岔图

对于 $\dot P = rP(1-P/K) - H$（捕获 $H$）：
- $H < rK/4$：两个平衡点（一个稳定，一个不稳定）。
- $H = rK/4$：鞍点分岔（两个平衡点碰撞）。
- $H > rK/4$：无平衡点——必然灭绝。

这是 **鱼类资源库崩溃点**——Elinor Ostrom 在公共资源治理中研究的现象（[2009 年经济学诺贝尔奖](https://www.nobelprize.org/prizes/economic-sciences/2009/summary/)）。

### Richards 方程

泛化：$\dot P = rP\left[1 - (P/K)^m\right]$。指数 $m$ 控制 S 形曲线的不对称性。对于 $m = 1$：Verhulst 逻辑。对于 $m \to 0$：Gompertz。

### 逻辑映射（离散时间）

$P_{n+1} = rP_n(1 - P_n)$——May（1976）的逻辑映射。对于 $r > 3{,}57$：确定性混沌。与 Feigenbaum 普遍性的联系：$\delta = 4{,}669...$

</Porta>

<Porta nivel="pratica" titulo="实际应用">

### 如何识别和使用模型

**Malthus**（指数）：当没有已知的资源限制时。例：前几小时的细菌生长，大流行初期（在采取措施之前）。

**Verhulst**（逻辑）：当存在饱和时。例：新产品在市场中的扩散，信息在社交网络中的传播，琼脂板上菌落的增长。

### 拟合真实数据：IBGE

巴西 1960 年：$P_0 = 70$ M。2000 年：$P = 170$ M。平均速率：$r \approx 2{,}2\%$/年。

取 $K = 250$ M（环境容纳量估计）：$A = (250-70)/70 \approx 2{,}57$。

$$P(t) = \frac{250}{1 + 2{,}57\,e^{-0{,}022t}}$$

2024 年（$t = 64$）：$P \approx 217$ M——接近实际数据（IBGE 2023 年 214 M）。

### 速查表

| 数量 | Malthus | Verhulst |
|---|---|---|
| $P(t)$ | $P_0 e^{rt}$ | $K/(1 + A e^{-rt})$ |
| $P(\infty)$ | $\infty$ | $K$ |
| 拐点 | 无 | $t^* = \ln(A)/r$ |
| $P(t^*)$ | — | $K/2$ |

### Python 工作流

```python
from scipy.integrate import odeint
import numpy as np

r, K, P0 = 0.022, 250, 70
f = lambda P, t: r * P * (1 - P/K)
t = np.linspace(0, 100, 500)
sol = odeint(f, P0, t)
# 与闭形式解比较
P_exato = K / (1 + ((K - P0)/P0) * np.exp(-r*t))
```

## 解决的例子

<Exemplo titulo="Malthus 增长与倍增" numero="1">

**问题。** 一个细菌菌落每 20 分钟翻倍。如果 $P_0 = 1000$，2 小时后有多少细菌？

**策略。** Malthus 模型：$P(t) = P_0 e^{rt}$。通过倍增周期 $T_2 = 20$ 分钟计算 $r$。

**解。**

$P(20) = 2P_0 \Rightarrow e^{20r} = 2 \Rightarrow r = \ln 2 / 20 \approx 0{,}0347\,\text{min}^{-1}$。

在 $t = 120$ 分钟时：$P(120) = 1000 \cdot e^{120 \cdot \ln 2/20} = 1000 \cdot 2^6 = 64\,000$。

**验证。** 2 小时 = 6 个倍增周期：$1000 \times 2^6 = 64\,000$。正确。

**来源。** [Lebl, Notes on Diffy Qs, §1.3, Example 1.3.1](https://www.jirka.org/diffyqs/html/auteq_section.html) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="带环境容纳量的逻辑模型" numero="2">

**问题。** 保护区内的鹿种群有 $K = 1200$，$r = 0{,}4$/年，$P(0) = 200$。求 $P(t)$ 并计算 $P = 900$ 的时刻。

**策略。** 逻辑的闭形式公式。对于 $P = 900$：在 $t$ 中求解。

**解。**

$A = (K - P_0)/P_0 = (1200 - 200)/200 = 5$。

$$P(t) = \frac{1200}{1 + 5e^{-0{,}4t}}$$

对于 $P = 900$：$900(1 + 5e^{-0{,}4t}) = 1200 \Rightarrow 1 + 5e^{-0{,}4t} = 4/3 \Rightarrow e^{-0{,}4t} = 1/15$。

$t = \ln(15)/0{,}4 \approx 2{,}71/0{,}4 \approx 6{,}8$ 年。

**验证。** $P(6{,}8) = 1200/(1 + 5e^{-2{,}71}) \approx 1200/(1 + 5 \times 0{,}0667) \approx 1200/1{,}333 \approx 900$。正确。

**来源。** [OpenStax Calculus Volume 2, §4.4, Example 4.14](https://openstax.org/books/calculus-volume-2/pages/4-4-the-logistic-equation) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="部分分式推导逻辑解" numero="3">

**问题。** 从 $\dot P = rP(1 - P/K)$，$P(0) = P_0$ 推导逻辑的闭形式公式。

**策略。** 分离变量并进行部分分式分解。

**解。**

$$\frac{dP}{P(1-P/K)} = r\,dt \;\Rightarrow\; \frac{K\,dP}{P(K-P)} = r\,dt$$

部分分式：$\dfrac{K}{P(K-P)} = \dfrac{1}{P} + \dfrac{1}{K-P}$。

积分：$\ln P - \ln(K-P) = rt + C_0 \Rightarrow \ln\!\left(\dfrac{P}{K-P}\right) = rt + C_0$。

令 $A = e^{C_0}$：$\dfrac{P}{K-P} = A e^{rt}$。

求解：$P = Ae^{rt}(K-P) \Rightarrow P(1 + Ae^{rt}) = KAe^{rt} \Rightarrow P = \dfrac{KAe^{rt}}{1+Ae^{rt}} = \dfrac{K}{1 + A^{-1}e^{-rt}}$。

对于 $t = 0$：$P_0 = K/(1+1/A) \Rightarrow A = (K-P_0)/P_0$。

$$P(t) = \frac{K}{1 + \frac{K-P_0}{P_0}\,e^{-rt}}$$

**验证。** $P(0) = K/(1+(K-P_0)/P_0) = KP_0/K = P_0$。$\lim_{t\to\infty} P(t) = K$。正确。

**来源。** [Lebl, Notes on Diffy Qs, §1.7, Example 1.7.1](https://www.jirka.org/diffyqs/html/auteq_section.html) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="拐点和最大可持续产量" numero="4">

**问题。** 对于逻辑 $r = 0{,}3$/年，$K = 500$，$P_0 = 50$：(a) 求拐点时刻 $t^*$；(b) 计算最大可持续产量 (MSY)。

**策略。** 拐点在 $P = K/2 = 250$ 处。MSY = $\dot P$ 的最大值。

**解。**

**(a)** 取 $A = (500-50)/50 = 9$：$P(t^*) = 250 \Rightarrow 500/(1+9e^{-0{,}3t^*}) = 250 \Rightarrow 9e^{-0{,}3t^*} = 1 \Rightarrow t^* = \ln(9)/0{,}3 \approx 7{,}3$ 年。

**(b)** $\dot P_{\max} = rK/4 = 0{,}3 \times 500/4 = 37{,}5$ 只/年（在 $P = 250$ 处发生）。

**验证。** $\dot P(250) = 0{,}3 \times 250 \times (1-250/500) = 75 \times 0{,}5 = 37{,}5$。正确。

**来源。** [OpenStax Calculus Volume 2, §4.4, Exercise 186](https://openstax.org/books/calculus-volume-2/pages/4-4-the-logistic-equation) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="IBGE 数据中的 Malthus 与逻辑对比" numero="5">

**问题。** 巴西：$P_0 = 95$ M（1970），$r = 2{,}5\%$/年。使用 $K = 250$ M，比较 Malthus 预测与逻辑模型在 2024 年（$t = 54$ 年）的结果。实际数据：214 M。

**策略。** 计算两个公式在 $t = 54$ 的值。

**解。**

**Malthus**：$P(54) = 95 \cdot e^{0{,}025 \times 54} = 95 \cdot e^{1{,}35} \approx 95 \times 3{,}857 \approx 366$ M。

**Verhulst**：$A = (250-95)/95 \approx 1{,}632$。$P(54) = 250/(1 + 1{,}632\,e^{-1{,}35}) = 250/(1 + 1{,}632 \times 0{,}259) \approx 250/1{,}423 \approx 176$ M。

相对误差：Malthus +71%；Verhulst +18%。

**备注。** 没有模型能够捕捉迁移、城市化和生育率下降。逻辑模型更好，但 $r$ 随时间变化。

**来源。** [Lebl, Notes on Diffy Qs, §1.7, Exercise 1.7.4](https://www.jirka.org/diffyqs/html/auteq_section.html) — CC-BY-SA。
