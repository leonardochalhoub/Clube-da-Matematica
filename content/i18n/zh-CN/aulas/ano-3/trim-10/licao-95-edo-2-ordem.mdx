### 一般问题

<Definicao titulo="二阶常系数线性齐次微分方程">

$$ay'' + by' + cy = 0, \quad a, b, c \in \mathbb{R},\ a \neq 0$$

**解空间：** 根据存在性与唯一性定理，解的集合构成一个 **维数为 2** 的向量空间 — 两个线性无关的解生成整个族。

</Definicao>

### Ansatz 与特征方程

代入 $y = e^{\lambda x}$：$y' = \lambda e^{\lambda x}$，$y'' = \lambda^2 e^{\lambda x}$。

$$a\lambda^2 e^{\lambda x} + b\lambda e^{\lambda x} + c e^{\lambda x} = 0 \;\Rightarrow\; a\lambda^2 + b\lambda + c = 0$$

由于 $e^{\lambda x} \neq 0$，一切问题归结为代数二次方程。

<Teorema titulo="按判别式的三种情况">

设 $\Delta = b^2 - 4ac$。

**情况 1 — $\Delta > 0$：** 两个不同的实根 $\lambda_1 \neq \lambda_2$。
$$y = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$$

**情况 2 — $\Delta = 0$：** 二重实根 $\lambda = -b/(2a)$。
$$y = (C_1 + C_2 x)\,e^{\lambda x}$$

**情况 3 — $\Delta < 0$：** 共轭复根 $\lambda = \alpha \pm i\beta$，其中 $\alpha = -b/(2a)$，$\beta = \sqrt{4ac-b^2}/(2a)$。
$$y = e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$$

</Teorema>

> "If $b^2 - 4ac > 0$, the characteristic equation has two distinct real roots $r_1, r_2$, and the general solution of [the ODE] is $y = c_1 e^{r_1 x} + c_2 e^{r_2 x}$." — [Lebl, Notes on Diffy Qs, §2.2](https://www.jirka.org/diffyqs/html/socc_section.html)

### 二重根的情况

<Insight>

为什么出现 $x$ 因子？对于二重根 $\lambda$，$e^{\lambda x}$ 是一个解，但我们需要另一个。降阶法表明 $x e^{\lambda x}$ 是第二个线性无关的解。验证：$(xe^{\lambda x})'' + b/a\,(xe^{\lambda x})' + c/a\,(xe^{\lambda x}) = e^{\lambda x}(a\lambda^2 + b\lambda + c)/a + e^{\lambda x}(2\lambda + b/a) = 0$，当 $\Delta = 0$ 时。

</Insight>

### 非齐次方程

对于 $ay'' + by' + cy = q(x)$：通解 $y = y_h + y_p$。

$y_h$：齐次方程的解（两个自由参数）。

$y_p$：任意一个特解 — 通过 **待定系数法** 得到（当 $q$ 是多项式、指数、正弦/余弦的组合时）或通过 **参数变易法**（通用）。

</Porta>

<Porta nivel="5" titulo="对 5 岁小朋友">

想象一个秋千。你推动它，它就摇晃。问题是：随着时间，它的运动会怎样？

数学家发现秋千的运动遵循包含 $y''$（加速度）的方程。如果没有摩擦力：永远摇晃。摩擦力小：摇晃并逐渐停止。摩擦力大：直接回到静止位置而不摇晃。

这三种情况对应我们方程的三种解。

</Porta>

<Porta nivel="10" titulo="对 10 岁小朋友">

在上节课我们解了一阶微分方程（只有 $y'$）。现在我们有 $y''$（加速度）。

诀窍：尝试 $y = e^{\lambda x}$。如果这有效，你可以通过解 **二次方程** — 特征方程来找 $\lambda$。

可能发生三件事：
1. 两个不同的实根 → 两个指数之和。
2. 二重根 → 指数乘以 $(C_1 + C_2 x)$。
3. 复根 → 含有正弦和余弦的指数（振荡！）。

情况 3 最漂亮：出现在任何振荡系统 — 摆、弹簧、LC 电路。

</Porta>

<Porta nivel="15" titulo="对 15 岁青少年">

$ay'' + by' + cy = 0$，其中 $a, b, c$ 是常数实数。通解**总是有两个自由参数** $C_1$ 和 $C_2$（初值条件 $y(0)$ 和 $y'(0)$ 确定两者）。

### 完整算法

1. 写出特征方程：$a\lambda^2 + b\lambda + c = 0$。
2. 计算 $\Delta = b^2 - 4ac$。
3. 若 $\Delta > 0$：$\lambda_{1,2} = (-b \pm \sqrt{\Delta})/(2a)$。解：$C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$。
4. 若 $\Delta = 0$：$\lambda = -b/(2a)$。解：$(C_1 + C_2 x)e^{\lambda x}$。
5. 若 $\Delta < 0$：$\lambda = \alpha \pm i\beta$，其中 $\alpha = -b/(2a)$，$\beta = \sqrt{-\Delta}/(2a)$。解：$e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$。

### 为什么用 $e^{\alpha x}(\cos\beta x + \sin\beta x)$ 而不用复数？

由欧拉公式：$e^{(\alpha+i\beta)x} = e^{\alpha x}(\cos\beta x + i\sin\beta x)$。实部和虚部都是实解。它们的实组合给出通实解。

### 例子：$y'' + 4y = 0$

$\lambda^2 + 4 = 0 \Rightarrow \lambda = \pm 2i$。这里 $\alpha = 0$，$\beta = 2$。

$y = C_1\cos 2x + C_2\sin 2x$ — 纯振荡。

带上 $y(0) = 1$，$y'(0) = 0$：$C_1 = 1$，$C_2 = 0$。$y = \cos 2x$。

</Porta>

<Porta nivel="25" titulo="对工程系学生">

### 二阶系统分类

每个常系数二阶线性系统都属于三种机制之一：

| 情况 | $\Delta$ | 根 | 行为 |
|---|---|---|---|
| 过阻尼 | $> 0$ | $\lambda_1, \lambda_2 < 0$ | 衰减无振荡 |
| 临界阻尼 | $= 0$ | 二重 $\lambda$，实负数 | 最快衰减无振荡 |
| 欠阻尼 | $< 0$ | $\alpha \pm i\beta$，$\alpha < 0$ | 振荡衰减 |
| 无阻尼 | $= 0$，无耗散 | $\pm i\beta$（纯虚数） | 永久振荡 |
| 不稳定 | 任意 | $\text{Re}(\lambda) > 0$ | 指数增长 |

### 非齐次解 — 待定系数法

对于 $q(x) = $ 多项式、指数、正弦/余弦：猜测 $y_p$ 的形式并确定系数。

| $q(x)$ | 如果 $\lambda_p$ 不是特征根，则 $y_p$ 的尝试形式 |
|---|---|
| $x^n$ | $A_n x^n + \ldots + A_0$ |
| $e^{kx}$ | $Ae^{kx}$ |
| $\cos\omega x$ 或 $\sin\omega x$ | $A\cos\omega x + B\sin\omega x$ |
| $x^n e^{kx}$ | $(A_n x^n + \ldots + A_0)e^{kx}$ |

**修正法则**：如果 $\lambda_p$ 是重数为 $m$ 的特征根，将尝试乘以 $x^m$。

### 参数变易法

通用形式：$y_p = -y_1 \int \frac{y_2 q}{W}\,dx + y_2 \int \frac{y_1 q}{W}\,dx$，其中 $W = y_1 y_2' - y_2 y_1'$ 是朗斯基行列式。

### 拉普拉斯变换

$a(s^2 Y - sy_0 - y_0') + b(sY - y_0) + cY = Q(s)$。直接解决初值条件，无需分离 $y_h$ 和 $y_p$。

</Porta>

<Porta nivel="40" titulo="对资深专业人士">

### 基础：解空间

根据 Picard-Lindelöf 定理，初值问题 $ay'' + by' + cy = 0$，$y(x_0) = y_0$，$y'(x_0) = y_1$ 有全局唯一解（常数系数时在整个 $\mathbb{R}$ 上）。解空间与 $\mathbb{R}^2$ 同构，通过映射 $(y_0, y_1) \mapsto y$。

**朗斯基行列式** $W[y_1, y_2](x) = y_1 y_2' - y_2 y_1'$ 为常数或恒为零（Abel）。$W \neq 0$ 当且仅当 $\{y_1, y_2\}$ 是解空间的基。

### 谱论

对算子 $\mathcal{L} = a\,d^2/dx^2 + b\,d/dx + c$，在 Dirichlet 边界条件下的 $L^2([0,\pi])$ 中，$-\mathcal{L}$ 的特征值构成离散谱 $\{\lambda_n\}_{n \geq 1}$ — Sturm-Liouville 问题。特征函数 $\{\sin n\pi x\}$ 构成标准正交基：傅里叶级数。

### Green 函数和卷积

$\mathcal{L}$ 的 Green 函数 $G(x,s)$ 满足 $\mathcal{L}G = \delta(x-s)$。非齐次方程的特解为 $y_p(x) = \int G(x,s)q(s)\,ds$。对于 $ay'' + by' + cy = q$：

$$G(x,s) = \frac{y_1(s) y_2(x) - y_1(x) y_2(s)}{a\,W(s)}\, H(x-s)$$

其中 $H$ 是 Heaviside 函数（因果性）。

### Lyapunov 稳定性

对于 $\ddot y + 2\zeta\omega_0\dot y + \omega_0^2 y = 0$：总能 $E = \frac{1}{2}\dot y^2 + \frac{1}{2}\omega_0^2 y^2$。$\dot E = -2\zeta\omega_0 \dot y^2 \leq 0$（当 $\zeta \geq 0$ 时）。临界阻尼（$\zeta = 1$）是最快的无振荡衰减 — 汽车悬架的最优选择。

### 诺贝尔奖和振荡器

二阶线性振荡器的模型是引力波探测理论的基础：LIGO 干涉仪使用频率为 150 Hz 的二阶谐振腔。Kip Thorne、Barry Barish 和 Rainer Weiss 因直接探测引力波获得了 [2017 年诺贝尔物理奖](https://www.nobelprize.org/prizes/physics/2017/summary/) — 这取决于此理论。

</Porta>

<Porta nivel="pratica" titulo="实际应用">

### 口袋算法

对 $ay'' + by' + cy = 0$：

1. $\Delta = b^2 - 4ac$。
2. 若 $\Delta > 0$：$\lambda = (-b \pm \sqrt{\Delta})/(2a)$ — 两个实数。$y = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$。
3. 若 $\Delta = 0$：$\lambda = -b/(2a)$。$y = (C_1 + C_2 x)e^{\lambda x}$。
4. 若 $\Delta < 0$：$\alpha = -b/(2a)$，$\beta = \sqrt{-\Delta}/(2a)$。$y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$。

### 常见错误

- 忘记 $\Delta < 0$ 需要指数的 **实部**：是 $e^{\alpha x}\cos\beta x$，不是 $\cos\beta x$。
- 二重根：记住第二个解中的 $x$ 因子。
- 施加初值：正确使用 $y'(0)$ — 代入 $x = 0$ 前先对 $y$ 求导。

### 模型：LC 电振荡器

LC 电路：$L\ddot q + q/C = 0$，$q(0) = Q_0$，$\dot q(0) = 0$。

$\lambda^2 + 1/(LC) = 0 \Rightarrow \lambda = \pm i/\sqrt{LC} = \pm i\omega_0$。

$q(t) = Q_0\cos(\omega_0 t)$，$i(t) = \dot q = -Q_0\omega_0\sin(\omega_0 t)$。

共振频率：$\omega_0 = 1/\sqrt{LC}$ [弧度/秒] — 收音机滤波器的基础。

### 综合表

| 微分方程 | 特征方程 | 解 |
|---|---|---|
| $y'' - 5y' + 6y = 0$ | $\lambda^2-5\lambda+6 = (\lambda-2)(\lambda-3) = 0$ | $C_1 e^{2x} + C_2 e^{3x}$ |
| $y'' - 4y' + 4y = 0$ | $(\lambda-2)^2 = 0$ | $(C_1+C_2 x)e^{2x}$ |
| $y'' + 4y = 0$ | $\lambda = \pm 2i$ | $C_1\cos 2x + C_2\sin 2x$ |
| $y'' + 2y' + 5y = 0$ | $\lambda = -1 \pm 2i$ | $e^{-x}(C_1\cos 2x + C_2\sin 2x)$ |

</Porta>

## 已解决的例子

<Exemplo titulo="情况 1 — 不同实根" numero="1">

**问题。** 解 $y'' - 5y' + 6y = 0$，$y(0) = 2$，$y'(0) = 3$。

**策略。** $\Delta = 25 - 24 = 1 > 0$：两个不同的实数。

**求解。**

特征方程：$\lambda^2 - 5\lambda + 6 = (\lambda-2)(\lambda-3) = 0$。

$\lambda_1 = 2$，$\lambda_2 = 3$。通解：$y = C_1 e^{2x} + C_2 e^{3x}$。

$y(0) = C_1 + C_2 = 2$。

$y'(0) = 2C_1 + 3C_2 = 3$。

系统：$C_1 = 3$，$C_2 = -1$。

$$y = 3e^{2x} - e^{3x}$$

**验证。** $y'' - 5y' + 6y = (12-15+6\cdot 3)e^{2x} + (-9+15-6)e^{3x} = 12e^{2x} \cdot 0 + 0 = 0$。$y(0) = 3 - 1 = 2$，$y'(0) = 6 - 3 = 3$。正确。

**来源。** [Lebl, Notes on Diffy Qs, §2.2, Example 2.2.1](https://www.jirka.org/diffyqs/html/socc_section.html) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="情况 2 — 二重根" numero="2">

**问题。** 解 $y'' - 4y' + 4y = 0$，$y(0) = 1$，$y'(0) = 0$。

**策略。** $\Delta = 16 - 16 = 0$：二重根。

**求解。**

$\lambda^2 - 4\lambda + 4 = (\lambda-2)^2 = 0$。二重根 $\lambda = 2$。

$y = (C_1 + C_2 x)e^{2x}$。

$y(0) = C_1 = 1$。

$y'(x) = C_2 e^{2x} + 2(C_1 + C_2 x)e^{2x}$。

$y'(0) = C_2 + 2C_1 = 0 \Rightarrow C_2 = -2$。

$$y = (1 - 2x)e^{2x}$$

**验证。** $y' = -2e^{2x} + 2(1-2x)e^{2x} = (2-4x-2)e^{2x} = -4xe^{2x}$。$y'' = -4e^{2x} - 8xe^{2x}$。$y''-4y'+4y = (-4-8x)e^{2x} - 4(-4x)e^{2x} + 4(1-2x)e^{2x} = (-4-8x+16x+4-8x)e^{2x} = 0$。正确。

**来源。** [Lebl, Notes on Diffy Qs, §2.2, Example 2.2.2](https://www.jirka.org/diffyqs/html/socc_section.html) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="情况 3 — 共轭复根（阻尼振荡）" numero="3">

**问题。** 解 $y'' + 2y' + 5y = 0$，$y(0) = 1$，$y'(0) = 2$。

**策略。** $\Delta = 4 - 20 = -16 < 0$：复数。$\alpha = -1$，$\beta = 2$。

**求解。**

$\lambda = (-2 \pm \sqrt{-16})/2 = -1 \pm 2i$。

$y = e^{-x}(C_1\cos 2x + C_2\sin 2x)$。

$y(0) = C_1 = 1$。

$y'(x) = -e^{-x}(C_1\cos 2x + C_2\sin 2x) + e^{-x}(-2C_1\sin 2x + 2C_2\cos 2x)$。

$y'(0) = -C_1 + 2C_2 = 2 \Rightarrow 2C_2 = 3 \Rightarrow C_2 = 3/2$。

$$y = e^{-x}\!\left(\cos 2x + \frac{3}{2}\sin 2x\right)$$

**验证。** 特征方程的根 $-1 \pm 2i$ 都有实部 $-1 < 0$：解指数衰减。$y(0) = 1$，$y'(0) = -1 + 3 = 2$。正确。

**来源。** [Lebl, Notes on Diffy Qs, §2.2, Example 2.2.3](https://www.jirka.org/diffyqs/html/socc_section.html) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="非齐次方程（待定系数法）" numero="4">

**问题。** 解 $y'' - y' - 2y = e^{3x}$。

**策略。** $y = y_h + y_p$。对 $q = e^{3x}$ 且 3 不是特征根：尝试 $y_p = Ae^{3x}$。

**求解。**

$\lambda^2 - \lambda - 2 = (\lambda-2)(\lambda+1) = 0$。$y_h = C_1 e^{2x} + C_2 e^{-x}$。

尝试：$y_p = Ae^{3x}$。代入：

$9Ae^{3x} - 3Ae^{3x} - 2Ae^{3x} = e^{3x} \Rightarrow 4A = 1 \Rightarrow A = 1/4$。

$$y = C_1 e^{2x} + C_2 e^{-x} + \frac{1}{4}e^{3x}$$

**验证。** $y_p'' - y_p' - 2y_p = (9/4 - 3/4 - 2/4)e^{3x} = (9-3-2)/4\,e^{3x} = e^{3x}$。正确。

**来源。** [Lebl, Notes on Diffy Qs, §2.3, Example 2.3.1](https://www.jirka.org/diffyqs/html/uc_section.html) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="非齐次方程（共振 — 修正法则）" numero="5">

**问题。** 解 $y'' - 3y' + 2y = e^{2x}$。

**策略。** 尝试 $y_p = Ae^{2x}$ — 但 $\lambda = 2$ 是特征根！修正法则：乘以 $x$。

**求解。**

$\lambda^2 - 3\lambda + 2 = (\lambda-1)(\lambda-2) = 0$。$y_h = C_1 e^x + C_2 e^{2x}$。

$\lambda = 2$ 是简单根：尝试 $y_p = Axe^{2x}$。

$y_p' = Ae^{2x} + 2Axe^{2x}$，$y_p'' = 4Ae^{2x} + 4Axe^{2x}$。

$y_p'' - 3y_p' + 2y_p = (4A + 4Ax)e^{2x} - (3A + 6Ax)e^{2x} + 2Axe^{2x} = Ae^{2x}$。

$A = 1$。故 $y_p = xe^{2x}$。

$$y = C_1 e^x + C_2 e^{2x} + xe^{2x}$$

**验证。** $y_p = xe^{2x}$：$y_p'' - 3y_p' + 2y_p = (4+4x)e^{2x} - 3(1+2x)e^{2x} + 2xe^{2x} = (4+4x-3-6x+2x)e^{2x} = e^{2x}$。正确。

**来源。** [Lebl, Notes on Diffy Qs, §2.3, Example 2.3.2](https://www.jirka.org/diffyqs/html/uc_section.html) — CC-BY-SA。

</Exemplo>
