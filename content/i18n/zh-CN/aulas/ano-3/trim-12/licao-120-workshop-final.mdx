### 完成的项目结构

<Definicao titulo="项目的四大支柱">

120 课项目分为四个支柱：

- **微积分** （第 5–8 三月期）：极限、导数、积分、级数、常微分方程。基础：求导规则、微积分基本定理、泰勒级数、二阶线性方程。
- **线性代数** （第 9–10 三月期）：矩阵、线性系统、行列式、向量空间、特征值、奇异值分解。基础：高斯消元、谱定理、矩阵分解。
- **概率论与统计** （第 10–11 三月期）：分布、中心极限定理、置信区间、假设检验、回归。基础：正态分布、卡方分布、期望值、方差。
- **应用建模** （第 11–12 三月期）：应用常微分方程、量化金融（Black-Scholes）、机器学习基础。基础：可分离和线性常微分方程、伊藤引理、梯度下降。

</Definicao>

<Teorema titulo="微积分基本定理（综合版）">

设 $f$ 在 $[a, b]$ 上连续，$F$ 为 $f$ 的任意反导数。则：

<Equation explicacao="第 1 部分：由积分定义的函数是可导的，其导数是被积函数。" latex="\frac{d}{dx}\int_a^x f(t)\,dt = f(x), \quad x \in [a, b]" />

<Equation explicacao="第 2 部分：定积分可通过在端点处计算任意反导数来计算。" latex="\int_a^b f(x)\,dx = F(b) - F(a)" />

基本定理是微积分两半的桥梁——微分和积分。它直接出现在此工作坊的 6 道题中。

</Teorema>

### 什么是综合？

综合与孤立工具列表相反。具体例子：

> *"一家公司每天以价格 $p(q) = 120 - 2q$ 雷亚尔销售 $q$ 单位。生产成本为 $C(q) = 200 + 40q + q^2$。找到使利润最大化的数量。"*

要解决：
1. **第 3 课**（一次函数）——识别收入 $R(q) = q \cdot p(q)$。
2. **第 4 课**（二次函数）— $L(q) = R(q) - C(q)$ 是二次函数。
3. **第 51-52 课**（导数）——求解 $L'(q) = 0$。
4. **第 53 课**（二阶导数）——确认是最大值。

你不会得到这些步骤。你**从你的知识中重新构建它们**。

### 为什么这很重要？

- **高考**：ITA/IME 题目需要来自不同领域的 3-4 种技术。
- **工程**：真实问题从不标有标签。
- **数据/人工智能**：神经网络混合了线性代数 + 微积分 + 统计。

## 已解决的例子

<Exemplo titulo="利用导数的优化——利润最大化" numero="1">

**问题：** 一家公司的收入为 $R(q) = 120q - 2q^2$，成本为 $C(q) = 200 + 40q + q^2$（单位：雷亚尔，$q$ 单位/天）。找到使利润 $L(q) = R(q) - C(q)$ 最大化的数量 $q^*$。

**策略：** 建立 $L(q)$，计算 $L'(q)$，令其为零，用二阶导数验证是最大值。

**解决方案：**

1. $L(q) = (120q - 2q^2) - (200 + 40q + q^2) = -3q^2 + 80q - 200$。
2. $L'(q) = -6q + 80$。令其为零：$q^* = 80/6 = 40/3 \approx 13.3$ 单位/天。
3. $L''(q) = -6 < 0$，确认最大值。
4. $L(40/3) = -3(40/3)^2 + 80(40/3) - 200 = -\frac{4800}{9} + \frac{3200}{3} - 200 = \frac{1400}{9} \approx 155.6$ 雷亚尔/天。

**验证：** $L'(13) = -78 + 80 = 2 > 0$ 且 $L'(14) = -84 + 80 = -4 < 0$，确认最大值在 $q = 13$ 和 $q = 14$ 之间。

**来源。** [Active Calculus §3.3，练习 3.3.3](https://activecalculus.org/single/sec-3-3-optimization.html) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="使用替换的定积分——曲线下面积" numero="2">

**问题：** 计算 $\displaystyle\int_0^{\pi/2} \sin^2 x \cos^3 x \; dx$。

**策略：** 分离 $\cos^3 x = \cos^2 x \cdot \cos x = (1 - \sin^2 x)\cos x$ 并使用替换 $u = \sin x$。

**解决方案：**

1. 将 $\cos^3 x = (1 - \sin^2 x)\cos x$ 写下来。
2. 令 $u = \sin x$，因此 $du = \cos x\,dx$。极限：$x=0 \Rightarrow u=0$；$x=\pi/2 \Rightarrow u=1$。
3. $\displaystyle\int_0^1 u^2(1 - u^2)\,du = \int_0^1 (u^2 - u^4)\,du = \left[\frac{u^3}{3} - \frac{u^5}{5}\right]_0^1 = \frac{1}{3} - \frac{1}{5} = \frac{2}{15}$。

**验证：** $0 < 2/15 \approx 0.133$。被积函数 $\sin^2 x \cos^3 x \geq 0$ 在 $[0, \pi/2]$ 上，最大值约在 $x \approx 0.63$ rad，其中 $\sin x \approx 0.59$，$\cos x \approx 0.81$；最大值 $\approx 0.21$。面积 $\approx 0.21 \times 1.57/2 \approx 0.16$。数量级与 $2/15$ 一致。

**来源。** [Active Calculus §5.3，练习 5.3.5](https://activecalculus.org/single/sec-5-3-substitution.html) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="2×2 矩阵的对角化——特征值和特征向量" numero="3">

**问题：** 对角化 $A = \begin{pmatrix} 3 & 1 \\ 0 & 2 \end{pmatrix}$。

**策略：** 计算 $\det(A - \lambda I) = 0$，找到特征值，然后求特征向量。用特征向量的列组成 $P$ 并验证 $P^{-1}AP = D$。

**解决方案：**

1. $\det(A - \lambda I) = (3-\lambda)(2-\lambda) - 0 = (3-\lambda)(2-\lambda)$。特征值：$\lambda_1 = 3$，$\lambda_2 = 2$。
2. 对于 $\lambda_1 = 3$：$(A - 3I)\mathbf{v} = 0 \Rightarrow \begin{pmatrix}0 & 1\\ 0 & -1\end{pmatrix}\mathbf{v} = 0 \Rightarrow v_2 = 0$。特征向量：$\mathbf{v}_1 = (1, 0)^T$。
3. 对于 $\lambda_2 = 2$：$(A - 2I)\mathbf{v} = 0 \Rightarrow \begin{pmatrix}1 & 1\\ 0 & 0\end{pmatrix}\mathbf{v} = 0 \Rightarrow v_1 = -v_2$。特征向量：$\mathbf{v}_2 = (1, -1)^T$。
4. $P = \begin{pmatrix}1 & 1 \\ 0 & -1\end{pmatrix}$，$D = \begin{pmatrix}3 & 0 \\ 0 & 2\end{pmatrix}$。

**验证：** $AP = P \begin{pmatrix}3&0\\0&2\end{pmatrix}$。第 1 列：$A(1,0)^T = (3,0)^T = 3(1,0)^T$。第 2 列：$A(1,-1)^T = (2,-2)^T = 2(1,-1)^T$。正确。

**来源。** [Linear Algebra Done Right，第 4 版，§5C 练习 5](https://linear.axler.net/) — CC-BY-NC。

</Exemplo>

<Exemplo titulo="2 阶常微分方程——简单调和振动器" numero="4">

**问题：** 用初始条件 $y(0) = 1$，$y'(0) = 0$ 求解 $y'' + 4y = 0$。

**策略：** 常系数齐次二阶线性方程。特征方程 $r^2 + 4 = 0$ 有共轭复根。

**解决方案：**

1. 特征方程：$r^2 + 4 = 0 \Rightarrow r = \pm 2i$。
2. 通解：$y(x) = C_1 \cos(2x) + C_2 \sin(2x)$。
3. 初始条件 $y(0) = 1$：$C_1 \cdot 1 + C_2 \cdot 0 = 1 \Rightarrow C_1 = 1$。
4. $y'(x) = -2C_1 \sin(2x) + 2C_2 \cos(2x)$。条件 $y'(0) = 0$：$2C_2 = 0 \Rightarrow C_2 = 0$。
5. 解：$y(x) = \cos(2x)$。

**验证：** $y'' = -4\cos(2x)$。因此 $y'' + 4y = -4\cos(2x) + 4\cos(2x) = 0$。条件：$y(0) = 1$，$y'(0) = -2\sin(0) = 0$。正确。

**来源。** [Notes on Diffy Qs §2.2，练习 2.2.1](https://www.jirka.org/diffyqs/) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="简单线性回归——系数估计" numero="5">

**问题：** 对点 $(1,2)$、$(2,3)$、$(3,5)$、$(4,4)$、$(5,6)$，用最小二乘法找到回归线 $\hat y = \hat\beta_0 + \hat\beta_1 x$。

**策略：** 使用公式 $\hat\beta_1 = \frac{\sum(x_i - \bar x)(y_i - \bar y)}{\sum(x_i - \bar x)^2}$ 和 $\hat\beta_0 = \bar y - \hat\beta_1 \bar x$。

**解决方案：**

1. $n = 5$。$\bar x = (1+2+3+4+5)/5 = 3$。$\bar y = (2+3+5+4+6)/5 = 4$。
2. $\sum(x_i - \bar x)^2 = (-2)^2 + (-1)^2 + 0^2 + 1^2 + 2^2 = 4+1+0+1+4 = 10$。
3. $\sum(x_i - \bar x)(y_i - \bar y) = (-2)(-2)+(-1)(-1)+(0)(1)+(1)(0)+(2)(2) = 4+1+0+0+4 = 9$。
4. $\hat\beta_1 = 9/10 = 0.9$。$\hat\beta_0 = 4 - 0.9 \times 3 = 4 - 2.7 = 1.3$。
5. 直线：$\hat y = 1.3 + 0.9x$。

**验证：** 对于 $x = 3$：$\hat y = 1.3 + 2.7 = 4.0 = \bar y$。回归线总是通过点 $(\bar x, \bar y)$。正确。

**来源。** [OpenIntro Statistics 第 4 版，§8.1 练习 8.1](https://www.openintro.org/book/os/) — CC-BY-SA。

</Exemplo>
