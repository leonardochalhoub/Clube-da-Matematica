### 模型和经典方程

<Definicao titulo="几何布朗运动（GBM）">

Black-Scholes假设资产价格 $S_t$ 按照随机过程演变：

$$dS = \mu S\,dt + \sigma S\,dW_t$$

其中 $\mu$ 是预期回报率，$\sigma > 0$ 是波动率，$W_t$ 是标准布朗运动（维纳过程）。根据伊藤引理，对数收益率服从正态分布：

$$\ln\frac{S_T}{S_0} \sim N\!\left(\left(\mu - \frac{\sigma^2}{2}\right)T,\; \sigma^2 T\right)$$

</Definicao>

> "Black和Scholes（1973）推导了欧式看涨期权的价格，假设基础资产价格遵循恒定漂移和波动率的几何布朗运动，无股息且市场无摩擦。" — [OpenStax Business Statistics，第11章](https://openstax.org/details/books/introductory-business-statistics)

<Definicao titulo="Black-Scholes偏微分方程">

无套利和连续对冲复制投资组合意味着任何衍生品 $V(S,t)$ 满足抛物型偏微分方程：

$$\frac{\partial V}{\partial t} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} + rS\frac{\partial V}{\partial S} - rV = 0$$

变量替换 $x = \ln S$、$\tau = T - t$、$u = e^{r\tau}V$ 将这个偏微分方程化为**热方程**：

$$\frac{\partial u}{\partial \tau} = \frac{\sigma^2}{2}\frac{\partial^2 u}{\partial x^2}$$

</Definicao>

> "热方程 $u_t = k\,u_{xx}$ 是抛物型偏微分方程的原型。其通过与高斯核卷积的解正是当对期权收益边界条件施加约束时产生Black-Scholes公式的结果。" — [Lebl，Notes on Diffy Qs §4.3](https://www.jirka.org/diffyqs/)

<Definicao titulo="解析解——欧式看涨期权">

在边界条件 $V(S,T) = \max(S - K, 0)$ 下，偏微分方程的解为：

$$C(S,t) = S\,N(d_1) - K\,e^{-r(T-t)}\,N(d_2)$$

$$d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)(T-t)}{\sigma\sqrt{T-t}}, \quad d_2 = d_1 - \sigma\sqrt{T-t}$$

其中 $N(d) = \dfrac{1}{\sqrt{2\pi}}\displaystyle\int_{-\infty}^{d} e^{-u^2/2}\,du$ 是标准正态分布的累积分布函数（CDF）。

**解释**：$N(d_2)$ 是风险中性测度下期权行使至到期时价内的概率；$S\,N(d_1)$ 是在行使条件下接收资产的期望值，折现至 $t=0$。

</Definicao>

<Teorema titulo="看涨-看跌平价">

对于无股息资产的欧式期权，在无套利市场中：

$$C - P = S - K\,e^{-r(T-t)}$$

**证明**：构造两个投资组合，在时刻T有相同的收益。投资组合A：买入看涨期权并卖出看跌期权。投资组合B：买入资产并借款 $Ke^{-r(T-t)}$。两者都在时刻T支付 $S_T - K$。根据无套利，它们今天的价值相同。

</Teorema>

想象你想买一张**票券，享有在1个月后以今天的价格购买玩具的权利**。但你没有义务——如果玩具变便宜了，你就扔掉票券。

这张票券值多少钱？取决于三件事：
- 玩具今天的价格。
- 票券让你购买的价格。
- 价格的"神经质"程度——如果上下波动很大，票券就更值钱。

Black-Scholes是**神奇的计算**，告诉你票券值多少。两位数学家50多年前发明了这个计算，并在[**1997年赢得诺贝尔经济学奖**](https://www.nobelprize.org/prizes/economic-sciences/1997/summary/)——经济学中最重要的奖项。

<Porta nivel="10" titulo="给10岁孩子的解释">

想象Petrobras股票今天价值30美元（巴西雷亚尔）。你买了一个"权利"，可以在1个月内以32美元（巴西雷亚尔）的价格购买这只股票。如果股票升到40美元（巴西雷亚尔），你行使权利：以32美元（巴西雷亚尔）买入，以40美元（巴西雷亚尔）卖出——赚钱！如果跌到25美元（巴西雷亚尔），你干脆不行使。

这个"权利"叫做**看涨期权**（call）。但你今天应该为它支付多少？

**Black-Scholes**是回答这个问题的公式，考虑到：
- 股票的当前价格（$S = 30$）
- 执行价格（$K = 32$）
- 到期时间（$T$）
- 波动率——价格的"神经质"程度（$\sigma$）
- 利率（$r$）

该公式使用**你在中等教育中学到的一切**：函数、指数、对数、积分、概率。全部在一个方程中。

发现这一点的人在[**1997年赢得诺贝尔经济学奖**](https://www.nobelprize.org/prizes/economic-sciences/1997/summary/)。今天，世界上每个股票交易所每天使用这个公式数千次。

### 通过复制投资组合的推导

**假设：**
1. $S_t$ 遵循GBM：$dS = \mu S\,dt + \sigma S\,dW_t$。
2. 无摩擦市场、自由卖空。
3. $r$ 和 $\sigma$ 恒定。
4. 无股息。

**复制投资组合：** 多头 $\Delta = \partial C/\partial S$ 股份 + 空头1张看涨期权。价值：$\Pi = \Delta S - C$。

根据伊藤引理：

$$dC = \frac{\partial C}{\partial t}dt + \frac{\partial C}{\partial S}dS + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 C}{\partial S^2}dt$$

投资组合 $d\Pi = \Delta\,dS - dC$ 当 $\Delta = \partial C/\partial S$ 时消除 $dW_t$ 项：

$$d\Pi = -\left(\frac{\partial C}{\partial t} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 C}{\partial S^2}\right)dt$$

根据无套利：$d\Pi = r\Pi\,dt$。代入 $\Pi = \Delta S - C$：

$$\frac{\partial C}{\partial t} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 C}{\partial S^2} + rS\frac{\partial C}{\partial S} - rC = 0$$

### 通过热方程求解

变量替换 $x = \ln S + (r - \sigma^2/2)(T-t)$、$\tau = \sigma^2(T-t)/2$ 将BS化为 $u_\tau = u_{xx}$。初始条件：$u(x,0) = \max(e^x - K, 0)$。通过与高斯核卷积求解：

$$u(x,\tau) = \frac{1}{\sqrt{4\pi\tau}}\int_{-\infty}^{\infty} u(y,0)\,e^{-(x-y)^2/(4\tau)}\,dy$$

反演变量替换后，得到公式 $C = SN(d_1) - Ke^{-rT}N(d_2)$。

### 数值实现（Python）

```python
import numpy as np
from scipy.stats import norm

def bs_call(S, K, r, sigma, T):
    d1 = (np.log(S/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    d2 = d1 - sigma*np.sqrt(T)
    return S*norm.cdf(d1) - K*np.exp(-r*T)*norm.cdf(d2)

def greeks(S, K, r, sigma, T):
    d1 = (np.log(S/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    d2 = d1 - sigma*np.sqrt(T)
    phi = norm.pdf(d1)
    return {
        'delta': norm.cdf(d1),
        'gamma': phi / (S*sigma*np.sqrt(T)),
        'vega':  S*phi*np.sqrt(T),
        'theta': -(S*phi*sigma)/(2*np.sqrt(T)) - r*K*np.exp(-r*T)*norm.cdf(d2),
        'rho':   K*T*np.exp(-r*T)*norm.cdf(d2),
    }

# PETR4: S=46.60, K=47, r=14.65%, sigma=35%, T=30/365
print(bs_call(46.60, 47, 0.1465, 0.35, 30/365))  # 约 1.94美元（巴西雷亚尔）
```

### Nobel和历史

[**1997年诺贝尔经济学奖**](https://www.nobelprize.org/prizes/economic-sciences/1997/summary/)：Robert C. Merton和Myron S. Scholes，"因确定衍生品价值的新方法"。Scholes的官方讲座：[*Derivatives in a Dynamic Environment*](https://www.nobelprize.org/uploads/2018/06/scholes-lecture.pdf)。Fischer Black于1995年8月去世；Nobel委员会在引文中明确提及他。

原始论文：Black & Scholes (1973)，*The Pricing of Options and Corporate Liabilities*，J. Political Economy 81(3):637–654——被两份杂志拒绝后才发表。

### 已知的局限和后继模型

| BS假设 | 现实 | 扩展 |
|---|---|---|
| 对数正态性 | 尾部肥厚、峰度 | 跳跃（Merton 1976、Kou 2002） |
| $\sigma$ 恒定 | 波动率微笑、期限结构 | Heston (1993)、SABR (Hagan 2002) |
| 完全市场 | 摩擦、资本 | FVA、KVA、MVA (XVA框架) |
| 连续对冲 | 离散、成本 | 复制误差分析（Taleb） |

### 交易柜台实际操作什么

没人"操作Black-Scholes"——操作的是**隐含波动率**。隐含波动率曲面 $\sigma_\text{impl}(K, T)$ 是中心对象：BS被数值反演（Newton-Raphson，初值来自Brenner-Subrahmanyam $\sigma_0 \approx \sqrt{2\pi/T}\cdot C_\text{ATM}/S$），给定观察到的市场价格。

### 与第12学期（PCA和线性代数）的联系

在含$n$个资产的投资组合中，波动率是协方差矩阵 $\Sigma$。Cholesky分解 $\Sigma = LL^T$ 为蒙特卡洛生成相关布朗运动。PCA（第118课）提取主风险因子——前3-5个成分捕获>95%的方差在固定收益中。这是**风险归因**的机构基础。

### 最新进展（2025-2026）

- **粗糙波动率**（Gatheral、El Euch、Rosenbaum 2018）：$\sigma_t$ 是分数过程，$H < 1/2$ ——以更少参数重现微笑。
- **神经随机微分方程**：网络从市场数据学习波动率动态。
- **深度校准**：通过离线训练的神经网络在毫秒内校准曲面。

### 配方：给欧式看涨期权定价

1. 收集：$S$（报价）、$K$（执行价）、$r$（年化Selic）、$\sigma$（估计的隐含波动率）、$T$（天数/365）。
2. 计算 $d_1 = \dfrac{\ln(S/K)+(r+\sigma^2/2)T}{\sigma\sqrt{T}}$ 和 $d_2 = d_1 - \sigma\sqrt{T}$。
3. 从标准正态表或使用 `scipy.stats.norm.cdf` 读取 $N(d_1)$ 和 $N(d_2)$。
4. 应用：$C = SN(d_1) - Ke^{-rT}N(d_2)$。
5. 对于看跌期权：$P = C - S + Ke^{-rT}$（看涨-看跌平价）。

### B3场景——PETR4

2026年4月30日：PETR4价格46.60美元（巴西雷亚尔）。看涨期权执行价47美元（巴西雷亚尔），到期30天，估计隐含波动率35%，Selic 14.65% 年率。

$$d_1 = \frac{\ln(46{.}60/47)+(0{.}1465+0{.}0613)\cdot 0{.}0822}{0{.}35\cdot 0{.}2868} \approx 0{.}085$$

$$d_2 = 0{.}085 - 0{.}35\cdot\sqrt{0{.}0822} \approx -0{.}015$$

$$N(0{.}085)\approx 0{.}534, \quad N(-0{.}015)\approx 0{.}494$$

$$C \approx 46{.}60\cdot 0{.}534 - 47\cdot e^{-0{.}1465\cdot 0{.}0822}\cdot 0{.}494 \approx \text{1.94美元（巴西雷亚尔）}$$

与市场价格比较。如果市场收费2.50美元（巴西雷亚尔），市场隐含波动率大于35%——市场比模型定价了更多的不确定性。

### BS在实践中何时失效

- **盈利前**：隐含波动率飙升——BS假设$\sigma$恒定，但市场定价跳跃。
- **危机（2008、2020）**：真实尾部肥厚远重于对数正态。
- **流动性**：深度虚值期权有宽的买卖价差——理论价格无关。
- **美式期权**：可能提前行使——BS无解析解。使用二叉树（Cox-Ross-Rubinstein）或Crank-Nicolson。

<Exemplo titulo="计算d1和d2（应用）" numero="1">

**问题：** 对于看涨期权，$S = 100$，$K = 100$，$r = 0.05$，$\sigma = 0.20$，$T = 1$年，计算$d_1$和$d_2$。

**策略：** 直接应用公式。因为$S = K$，项$\ln(S/K) = \ln(1) = 0$。

**解决方案：**

$$d_1 = \frac{\ln(100/100)+(0.05+0.02)\cdot 1}{0.20\cdot\sqrt{1}} = \frac{0 + 0.07}{0.20} = 0.35$$

$$d_2 = 0.35 - 0.20\cdot 1 = 0.15$$

**验证：** $d_2 = d_1 - \sigma\sqrt{T} = 0.35 - 0.20 = 0.15$。正确。因为$S = K$（平价期权），对于$r > 0$预期$d_1 > 0$。

**来源。** 改编自[OpenStax — Introductory Business Statistics，第6章](https://openstax.org/details/books/introductory-business-statistics) — CC-BY 4.0。

</Exemplo>

<Exemplo titulo="通过标准正态表计算看涨期权价格（应用）" numero="2">

**问题：** 使用$d_1 = 0.35$和$d_2 = 0.15$（例题1），已知$N(0.35) \approx 0.6368$和$N(0.15) \approx 0.5596$，计算看涨期权的价格。

**策略：** 应用$C = SN(d_1) - Ke^{-rT}N(d_2)$，使用表中读取的值。

**解决方案：**

$$K e^{-rT} = 100\cdot e^{-0.05} \approx 100\cdot 0.9512 = 95.12$$

$$C = 100\cdot 0.6368 - 95.12\cdot 0.5596$$

$$C = 63.68 - 53.23 \approx 10.45$$

**验证：** 看涨期权价值10.45美元（巴西雷亚尔）对于100美元（巴西雷亚尔）的股票。直觉：平价期权波动率20%且1年期应该价值7-13%——10.45%在预期范围内。

**来源。** 改编自[OpenIntro Statistics §3.3](https://www.openintro.org/book/os/) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="看涨-看跌平价——计算看跌期权（中等）" numero="3">

**问题：** 使用例题2的数据（$C \approx 10.45$、$S = 100$、$K = 100$、$r = 0.05$、$T = 1$），计算相应欧式看跌期权的价格。

**策略：** 应用看涨-看跌平价$P = C - S + Ke^{-rT}$。

**解决方案：**

$$P = 10.45 - 100 + 95.12 = 5.57$$

**验证：** 根据对称性，相同参数的平价看跌期权应小于看涨期权，当$r > 0$时（持有股票的机会成本为$r$）。实际上，$P = 5.57 < C = 10.45$。一致。

额外测试：$C - P = 10.45 - 5.57 = 4.88 \approx S - Ke^{-rT} = 100 - 95.12 = 4.88$。平价得到确认。

**来源。** [OpenIntro Statistics §3.4 — 通过无套利论证推导平价](https://www.openintro.org/book/os/) — CC-BY-SA。

</Exemplo>

<Exemplo titulo="Delta和对冲比率（中等/高等）" numero="4">

**问题：** 一个交易柜台持有1000张看涨期权多头，$\Delta = N(d_1) = 0.6368$（例题1）。应该卖空多少股票来创建Delta中性投资组合？

**策略：** Delta中性意味着总投资组合有$\Delta_\text{total} = 0$。每张看涨期权的Delta = 0.6368；每股的Delta = 1。

**解决方案：**

投资组合：多头1000张看涨期权 + 空头$n$股。

$$\Delta_\text{portfólio} = 1000\cdot 0.6368 - n\cdot 1 = 0$$

$$n = 636.8 \approx 637 \text{ 股}$$

**验证：** 如果$S$升1美元（巴西雷亚尔），1000张看涨期权赚$1000 \times 0.6368 \times 1 = $ 636.80美元（巴西雷亚尔）。卖出的637股失去637美元（巴西雷亚尔）。净值：约-20美分——接近零（四舍五入误差）。对冲在瞬间有效；当Delta改变时必须重新平衡。

**来源。** [OpenStax — Introductory Business Statistics，第11章](https://openstax.org/details/books/introductory-business-statistics) — CC-BY 4.0。

</Exemplo>

<Exemplo titulo="120堂课的收敛——每个概念在BS中的出现（真实建模）" numero="5">

**问题：** 在公式$C = SN(d_1) - Ke^{-r(T-t)}N(d_2)$及其分量中，识别在以下地方出现的内容：(a)两个变量的函数，(b)自然对数，(c)数字$e$，(d)导数，(e)积分，(f)正态分布，(g)偏微分方程，(h)线性代数。

**策略：** 系统地将每个数学概念映射到公式中出现的分量。

**解决方案：**

(a) **两个变量的函数**（第2、51课）：$C(S,t)$ ——定义域$S > 0$、$t \in [0,T]$。

(b) **自然对数**（第7课）：$\ln(S/K)$在$d_1$中——衡量期权变为价内所需的对数收益。

(c) **数字$e$**（第7课）：$e^{-r(T-t)}$——连续折现因子；$e = \lim_{n\to\infty}(1+r/n)^n$。

(d) **导数**（第51-67课）：$\Delta = \partial C/\partial S = N(d_1)$、$\Gamma = \partial^2 C/\partial S^2$等。希腊字母是所有偏导数。

(e) **积分**（第82-87课）：$N(d) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{d} e^{-u^2/2}\,du$ ——反常积分数值计算。

(f) **正态分布**（第76-77课）：$N(d)$是标准正态$\mathcal{N}(0,1)$的CDF；通过中央极限定理的对数收益正态。

(g) **偏微分方程**（第92-95课）：公式是BS抛物型偏微分方程的解——可还原为热方程。

(h) **线性代数**（第31-35、114-118课）：在多资产投资组合中，波动率变成协方差矩阵$\Sigma$；PCA提取风险因子。

**验证：** 识别了12个学期的8个概念。其余4个（三角学、数列、解析几何、组合学）出现在派生模型中：三角在周期性隐含波动率中、生成函数在二叉树中、极坐标在风险矢量场中。

**来源。** 基于[OpenStax — Introductory Business Statistics](https://openstax.org/details/books/introductory-business-statistics)和[Notes on Diffy Qs §4.1–4.3](https://www.jirka.org/diffyqs/) — CC-BY 4.0 / CC-BY-SA的课程综合练习。

</Exemplo>
