### SVD 定理

<Definicao titulo="奇异值分解 (SVD)">

对任何 <Eq>{`A \\in \\mathbb{R}^{m \\times n}`}</Eq>，存在：

- <Eq>{`U \\in \\mathbb{R}^{m \\times m}`}</Eq> 正交矩阵（列为**左奇异向量**），
- <Eq>{`V \\in \\mathbb{R}^{n \\times n}`}</Eq> 正交矩阵（列为**右奇异向量**），
- <Eq>{`\\Sigma \\in \\mathbb{R}^{m \\times n}`}</Eq>，对角元为 <Eq>{`\\sigma_1 \\geq \\sigma_2 \\geq \\cdots \\geq \\sigma_r > 0 = \\sigma_{r+1} = \\cdots`}</Eq>，

使得 <Eq>{`A = U \\Sigma V^T`}</Eq>。整数 <Eq>{`r = \\text{rank}(A)`}</Eq>。

</Definicao>

> "Any matrix A with rank r can be written as a product $A = U \Sigma V^T$ where U is orthogonal ($m \times m$), $\Sigma$ is diagonal ($m \times n$, nonnegative entries decreasing), and V is orthogonal ($n \times n$). The diagonal entries $\sigma_1 \geq \cdots \geq \sigma_r > 0$ are the singular values of A." — [Understanding Linear Algebra, §6.3](https://understandinglinearalgebra.org/chap6.html)

<Definicao titulo="紧凑 SVD 与秩-1 展开">

**紧凑（经济）SVD** 仅保留 <Eq>{`r`}</Eq> 个非平凡列：

<Equation explicacao="展开：A 是 r 个秩-1 矩阵的加权和，权重为奇异值。" latex="A = U_r \Sigma_r V_r^T = \sum_{i=1}^r \sigma_i\, u_i v_i^T" />

每一项 <Eq>{`\\sigma_i u_i v_i^T`}</Eq> 都是**秩-1 矩阵**——一个列向量与一个行向量的外积。

</Definicao>

> "Theorem (Existence of SVD). Every real matrix A has a singular value decomposition. The singular values are the positive square roots of the nonzero eigenvalues of $A^T A$." — [A First Course in Linear Algebra, §SVD](http://linear.ups.edu/html/section-SVD.html)

### 与特征值的联系

<Definicao titulo="SVD 与矩阵 A^T A 和 A A^T">

- <Eq>{`A^T A = V (\\Sigma^T \\Sigma) V^T`}</Eq>：<Eq>{`A^T A`}</Eq> 的**特征值**为 <Eq>{`\\sigma_i^2`}</Eq>，特征向量是 <Eq>{`V`}</Eq> 的列。
- <Eq>{`A A^T = U (\\Sigma \\Sigma^T) U^T`}</Eq>：<Eq>{`A A^T`}</Eq> 的**特征值**同样为 <Eq>{`\\sigma_i^2`}</Eq>，特征向量是 <Eq>{`U`}</Eq> 的列。
- 奇异值**始终是非负实数**，即使 <Eq>{`A`}</Eq> 有复特征值。

</Definicao>

### Eckart-Young 定理

<Teorema titulo="最优秩-k 逼近 (Eckart-Young, 1936)">

<Eq>{`A`}</Eq> 的最优秩-<Eq>{`k`}</Eq> 逼近（在 Frobenius 范数和谱范数下）为：

<Equation explicacao="在前 k 个最大奇异值处截断 SVD 给出最优秩-k 逼近（最小二乘意义下）。" latex="A_k = \sum_{i=1}^k \sigma_i\, u_i v_i^T" />

误差：<Eq>{`\\|A - A_k\\|_F^2 = \\sigma_{k+1}^2 + \\cdots + \\sigma_r^2`}</Eq>，<Eq>{`\\|A - A_k\\|_2 = \\sigma_{k+1}`}</Eq>。

</Teorema>

### Moore-Penrose 伪逆

<Definicao titulo="通过 SVD 计算伪逆">

<Equation explicacao="反演 Sigma 中的正奇异值；零奇异值置零。求解 min ||Ax - b||，得最小范数解。" latex="A^+ = V \Sigma^+ U^T" />

其中 <Eq>{`\\Sigma^+`}</Eq> 通过将每个 <Eq>{`\\sigma_i > 0`}</Eq> 替换为 <Eq>{`1/\\sigma_i`}</Eq> 后转置得到。解 <Eq>{`x^* = A^+ b`}</Eq> 最小化 <Eq>{`\\|Ax - b\\|`}</Eq>，且在所有最小化子中具有最小范数 <Eq>{`\\|x\\|`}</Eq>。

</Definicao>

<Insight>

<Eq>{`A`}</Eq> 的**条件数**是 <Eq>{`\\kappa_2(A) = \\sigma_1 / \\sigma_r`}</Eq>。当 <Eq>{`\\kappa_2`}</Eq> 很大时，系统 <Eq>{`Ax = b`}</Eq> 称为病态的：<Eq>{`b`}</Eq> 中的小误差会在 <Eq>{`x`}</Eq> 中产生大误差。SVD 是诊断病态性的标准工具。

</Insight>

</Porta>

<Porta nivel="5" titulo="对 5 岁儿童">

想象你有一张**彩色狗狗照片**。照片充满了色彩点——太多了！SVD 是一个**魔法整理术**：它将照片分解成**重要性分层**。

第一层捕捉最重要的部分——狗狗的轮廓。第二层捕捉小一些的细节。依此类推。

如果你只合并最重要的前几层，仍然能认出狗狗——但使用的**内存少得多**。这就是计算机保存较小图片而不失太多质量的方式。

</Porta>

<Porta nivel="10" titulo="对 10 岁儿童">

任何矩阵都能拆成三块：<Eq>{`A = U \\Sigma V^T`}</Eq>。

- <Eq>{`V^T`}</Eq> 是输入空间的**旋转**。
- <Eq>{`\\Sigma`}</Eq> 是**缩放**——每个方向被一个数字 <Eq>{`\\sigma_i \\geq 0`}</Eq> 拉伸或压缩。
- <Eq>{`U`}</Eq> 是输出空间中的另一个**旋转**。

这些数字 <Eq>{`\\sigma_i`}</Eq>——**奇异值**——表示每个方向的重要性。最大的 <Eq>{`\\sigma_1`}</Eq> 是最重要的方向；最小的是最不重要的。

**压缩技巧**：在 <Eq>{`1000 \\times 1000`}</Eq> 像素的照片中，仅保留前 50 个最大奇异值，你存储 <Eq>{`50 \\times 1000 + 50 + 50 \\times 1000 = 100050`}</Eq> 个数而不是 1 百万——**少 10 倍**。图像仍然看起来不错。

</Porta>

<Porta nivel="15" titulo="对 15 岁青少年">

SVD 是应用线性代数中最重要的分解。它同时具有三个特性是其他分解所没有的：**普遍性**（适用于任何矩阵）、**正交性**（基 <Eq>{`U, V`}</Eq> 是标准正交的）和**唯一性**（奇异值是唯一的）。

### 几何学

任何线性映射 <Eq>{`A: \\mathbb{R}^n \\to \\mathbb{R}^m`}</Eq> 将单位球面变换成**椭球体**。椭球体的半轴长为 <Eq>{`\\sigma_1 \\geq \\cdots \\geq \\sigma_r`}</Eq>，指向方向 <Eq>{`u_1, \\ldots, u_r`}</Eq>。

- <Eq>{`V^T`}</Eq> 旋转输入空间（对齐向量 <Eq>{`v_i`}</Eq> 与坐标轴）。
- <Eq>{`\\Sigma`}</Eq> 将每个轴拉伸 <Eq>{`\\sigma_i`}</Eq>。
- <Eq>{`U`}</Eq> 将结果旋转到输出空间。

### 与对角化比较

| 方面 | 对角化 | SVD |
|---|---|---|
| 应用于 | 可对角化的方阵 | 任意矩阵 |
| 存在性 | 可能失败 | 总是存在 |
| 基 | <Eq>{`P, P^{-1}`}</Eq>（非正交） | <Eq>{`U, V`}</Eq> 正交 |
| 值 | 特征值（通常在 <Eq>{`\\mathbb{C}`}</Eq> 中） | 奇异值（<Eq>{`\\geq 0`}</Eq> 实数） |

### 直接应用：图像压缩

灰度图像是矩阵 <Eq>{`M \\in \\mathbb{R}^{m \\times n}`}</Eq>。在 <Eq>{`k`}</Eq> 项处截断 SVD：

- 存储 <Eq>{`A_k`}</Eq> 需要 <Eq>{`k(m + n + 1)`}</Eq> 个数而不是 <Eq>{`mn`}</Eq> 个。
- Frobenius 相对误差：<Eq>{`\\|A - A_k\\|_F / \\|A\\|_F = \\sqrt{\\sum_{i>k} \\sigma_i^2} / \\sqrt{\\sum_i \\sigma_i^2}`}</Eq>。

### Netflix Prize 案例 (2009)

Netflix 有评分矩阵：约 <Eq>{`10^7`}</Eq> 用户 <Eq>{`\\times 10^5`}</Eq> 部电影，稀疏。低秩逼近（SVD 变体）预测缺失评分。获胜队伍 BellKor's Pragmatic Chaos 提高了精度 10%，赢得了 100 万美元。

</Porta>

<Porta nivel="25" titulo="对工程学生">

SVD 是计算线性代数的瑞士军刀。它解决病态系统，发现隐藏结构，以最优保证压缩数据。

### 计算算法

**对于小的 <Eq>{`A`}</Eq>：**
1. 计算 <Eq>{`A^T A`}</Eq>（对称 PSD）。
2. 分解 <Eq>{`A^T A = V \\Lambda V^T`}</Eq>（特征向量）。
3. <Eq>{`\\sigma_i = \\sqrt{\\lambda_i}`}</Eq>；<Eq>{`u_i = A v_i / \\sigma_i`}</Eq> 当 <Eq>{`\\sigma_i > 0`}</Eq>。

**对于大的 <Eq>{`A`}</Eq>：** Golub-Reinsch 算法，<Eq>{`O(\\min(mn^2, m^2n))`}</Eq>。对于顶-<Eq>{`k`}</Eq>：随机 SVD (Halko-Martinsson-Tropp)，<Eq>{`O(mnk)`}</Eq> 期望。

### 按领域的应用

**计算机视觉**：Eigenfaces (Turk-Pentland 1991) — 中心化脸部矩阵的 SVD → 人脸识别基。

**机器学习**：GloVe 词嵌入 — 词共现矩阵的 SVD；白化 — <Eq>{`W = V \\Sigma^{-1}`}</Eq> 去相关特征。

**金融**：收益率曲线的 PCA — 3 个主因子（水平、斜率、曲率）捕捉约 99% 的方差 (Litterman-Scheinkman 1991)。

**数值**：数值秩 <Eq>{`r_\\epsilon = \\#\\{\\sigma_i > \\epsilon \\cdot \\sigma_1\\}`}</Eq>；通过伪逆进行稳健的最小二乘求解。

### Python 代码

```python
import numpy as np

A = np.random.randn(200, 50)
U, s, Vt = np.linalg.svd(A, full_matrices=False)

# 秩-k 逼近
k = 10
A_k = U[:, :k] @ np.diag(s[:k]) @ Vt[:k, :]
print("Frobenius 相对误差:", np.linalg.norm(A - A_k, 'fro') / np.linalg.norm(A, 'fro'))

# 伪逆和最小二乘
b = np.random.randn(200)
x_pinv = np.linalg.lstsq(A, b, rcond=None)[0]  # 内部使用 SVD
```

### 通过 SVD 的 Tikhonov 正则化

不是直接反演 <Eq>{`\\sigma_i`}</Eq>（当 <Eq>{`\\sigma_i`}</Eq> 很小时不稳定），而是使用：

<Equation explicacao="Tikhonov：收缩小奇异值，避免放大噪声。" latex="x_\lambda = \sum_{i=1}^r \frac{\sigma_i}{\sigma_i^2 + \lambda}\, (u_i^T b)\, v_i" />

对于 <Eq>{`\\lambda \\to 0`}</Eq> 恢复伪逆；对于大 <Eq>{`\\lambda`}</Eq> 收缩解。

</Porta>

<Porta nivel="40" titulo="对资深专业人士">

SVD 不仅仅是一个算法——它是线性变换的通用规范形式。每个矩阵都有 SVD；不是每个矩阵都有实特征分解。

### 历史背景

Eugenio Beltrami (1873) 和 Camille Jordan (1874) 独立地证明了方阵的 SVD。Erhard Schmidt (1907) 将其推广到积分算子（Hilbert-Schmidt 核）。对于非方矩阵的现代形式来自 Carl Eckart 和 Gale Young (1936)，他们也证明了最优逼近定理。

### 与泛函分析的联系

对于紧算子 <Eq>{`T: H_1 \\to H_2`}</Eq> 在 Hilbert 空间中，Schmidt 分解为：

<Equation explicacao="无穷维推广：紧算子分解成可数和的秩-1 算子。" latex="T = \sum_{i=1}^\infty \sigma_i\, \langle \cdot, v_i \rangle\, u_i" />

<Eq>{`T`}</Eq> 的**奇异值**形成 <Eq>{`\\ell^2`}</Eq> 中的序列。这是信号压缩、主成分分析和核谱方法背后的结构。

### 随机 SVD (Halko-Martinsson-Tropp 2011)

对于数值低秩矩阵，精确 SVD 不必要。算法：

1. 随机采样列：<Eq>{`Y = A \\Omega`}</Eq>，<Eq>{`\\Omega \\in \\mathbb{R}^{n \\times (k+p)}`}</Eq> 高斯。
2. 正交化：<Eq>{`Q, R = \\text{QR}(Y)`}</Eq>。
3. 分解投影：<Eq>{`Q^T A`}</Eq> 的 SVD（小 — <Eq>{`(k+p) \\times n`}</Eq>）。

过采样 <Eq>{`p \\approx 10`}</Eq> 时，期望误差接近 Eckart-Young 最优。可以在受限内存中实现 <Eq>{`10^6 \\times 10^6`}</Eq> 矩阵的 SVD。

### SVD 与现代机器学习

Transformers (Vaswani et al. 2017) 将注意力分解为三矩阵的乘积：<Eq>{`Q, K, V`}</Eq>。多头注意力的几何本质上是通过梯度下降学习的 SVD——"头"学习训练数据的主子空间。

低秩适应 (LoRA, 2021) — LLM 微调 — 用低秩的 <Eq>{`\\Delta W = BA`}</Eq> 扰动预训练权重 <Eq>{`W`}</Eq>，正是 SVD 将其正当化为噪声背景中的信号结构。

</Porta>

### 逐步图像压缩

给定灰度图像，矩阵 <Eq>{`A \\in \\mathbb{R}^{512 \\times 512}`}</Eq>：

1. 计算完整 SVD：<Eq>{`A = U \\Sigma V^T`}</Eq>，<Eq>{`\\sigma_1 \\geq \\cdots \\geq \\sigma_{512} \\geq 0`}</Eq>。
2. 选择 <Eq>{`k`}</Eq>：绘制 <Eq>{`\\sigma_i`}</Eq> vs <Eq>{`i`}</Eq>（碎石图）；在"肘部"或累计解释方差 <Eq>{`\\geq 95\\%`}</Eq> 处切割。
3. 存储：<Eq>{`U_{[:, :k]}`}</Eq>、<Eq>{`\\sigma_{1:k}`}</Eq>、<Eq>{`V_{[:, :k]}`}</Eq> — 共 <Eq>{`k(512 + 1 + 512)`}</Eq> 个浮点数。
4. 重建：<Eq>{`A_k = U_k \\, \\text{diag}(\\sigma_{1:k}) \\, V_k^T`}</Eq>。

以 <Eq>{`k = 50`}</Eq>：压缩比 <Eq>{`512^2 / (50 \\times 1025) \\approx 5.1\\times`}</Eq>。在视觉上与原始图像无法区分。

### 病态回归诊断

在线性回归 <Eq>{`y = X \\beta + \\varepsilon`}</Eq> 中当 <Eq>{`X`}</Eq> 病态时：

1. <Eq>{`X`}</Eq> 的 SVD：<Eq>{`X = U \\Sigma V^T`}</Eq>。
2. <Eq>{`\\kappa_2(X) = \\sigma_1 / \\sigma_r`}</Eq>。若 <Eq>{`> 30`}</Eq>，存在多重共线性。
3. 应用岭回归：<Eq>{`\\hat\\beta_\\lambda = V (\\Sigma^T \\Sigma + \\lambda I)^{-1} \\Sigma^T U^T y`}</Eq>。
4. 通过交叉验证选择 <Eq>{`\\lambda`}</Eq>。

### 实际练习：按州的 ENEM

ENEM 微数据约有 200 个每位考生的变量。州 × 变量矩阵的 SVD（26 个州 × 200 项）识别了 3-5 个"不平等轴"来结构化区域表现——由国家教育研究所 (INEP) 研究人员在每个版本发表的分析。

## 解题示例

<Exemplo titulo="简单 2×2 矩阵的 SVD" numero="1">

**问题。** 计算 <Eq>{`A = \\begin{pmatrix} 3 & 0 \\\\ 4 & 5 \\end{pmatrix}`}</Eq> 的 SVD。

**策略。** 计算 <Eq>{`A^T A`}</Eq>，分解特征向量/特征值，获得 <Eq>{`V`}</Eq> 和 <Eq>{`\\Sigma`}</Eq>，然后 <Eq>{`U`}</Eq>。

**求解。**

<Eq>{`A^T A = \\begin{pmatrix} 3 & 4 \\\\ 0 & 5 \\end{pmatrix}\\begin{pmatrix} 3 & 0 \\\\ 4 & 5 \\end{pmatrix} = \\begin{pmatrix} 25 & 20 \\\\ 20 & 25 \\end{pmatrix}`}</Eq>

特征值：<Eq>{`\\det(A^T A - \\lambda I) = (25 - \\lambda)^2 - 400 = 0`}</Eq>，所以 <Eq>{`\\lambda_1 = 45`}</Eq> 和 <Eq>{`\\lambda_2 = 5`}</Eq>。

奇异值：<Eq>{`\\sigma_1 = \\sqrt{45} = 3\\sqrt{5}`}</Eq>、<Eq>{`\\sigma_2 = \\sqrt{5}`}</Eq>。

<Eq>{`A^T A`}</Eq> 的特征向量：对于 <Eq>{`\\lambda_1 = 45`}</Eq>，解 <Eq>{`(A^T A - 45I)v = 0`}</Eq>：<Eq>{`v_1 = (1/\\sqrt{2})(1, 1)^T`}</Eq>；对于 <Eq>{`\\lambda_2 = 5`}</Eq>：<Eq>{`v_2 = (1/\\sqrt{2})(1, -1)^T`}</Eq>。

左向量：<Eq>{`u_i = Av_i / \\sigma_i`}</Eq>。

<Exemplo titulo="通过 SVD 计算矩阵的秩与子空间" numero="2">

**问题。** 通过 SVD 确定 <Eq>{`A = \\begin{pmatrix} 1 & 2 & 3 \\\\ 2 & 4 & 6 \\end{pmatrix}`}</Eq> 的秩和 4 个子空间的基。

**策略。** <Eq>{`A`}</Eq> 是 <Eq>{`2 \\times 3`}</Eq>。因为第 2 行是第 1 行的倍数，秩为 1。

**求解。**

<Eq>{`A^T A = \\begin{pmatrix} 1 & 2 \\\\ 2 & 4 \\\\ 3 & 6 \\end{pmatrix}\\begin{pmatrix} 1 & 2 & 3 \\\\ 2 & 4 & 6 \\end{pmatrix} = \\begin{pmatrix} 5 & 10 & 15 \\\\ 10 & 20 & 30 \\\\ 15 & 30 & 45 \\end{pmatrix}`}</Eq>

非零特征值：<Eq>{`\\lambda_1 = \\text{tr}(A^T A) = 70`}</Eq>（所有项平方之和，因为秩为 1）。奇异值：<Eq>{`\\sigma_1 = \\sqrt{70}`}</Eq>。

<Eq>{`v_1 = (1/\\sqrt{14})(1, 2, 3)^T`}</Eq>（<Eq>{`A`}</Eq> 行的方向）。<Eq>{`u_1 = Av_1/\\sigma_1 = (1/\\sqrt{2})(1, 2)^T`}</Eq>。

**4 个子空间：**
- <Eq>{`\\text{Row}(A) = \\text{span}\\{(1,2,3)\\}`}</Eq> — <Eq>{`V`}</Eq> 的第 1 列。
- <Eq>{`\\ker(A) = \\text{span}\\{(-2,1,0), (-3,0,1)\\}`}</Eq> — <Eq>{`V`}</Eq> 的第 2-3 列。
- <Eq>{`\\text{Col}(A) = \\text{span}\\{(1,2)\\}`}</Eq> — <Eq>{`U`}</Eq> 的第 1 列。
- <Eq>{`\\ker(A^T) = \\text{span}\\{(-2,1)\\}`}</Eq> — <Eq>{`U`}</Eq> 的第 2 列。

**验证。** 秩 = 正奇异值个数 = 1。确认：dim Row + dim ker = 1 + 2 = 3 = n。✓

**来源。** [A First Course in Linear Algebra, §SVD 和 §FS](http://linear.ups.edu/html/section-SVD.html) — Rob Beezer · GNU FDL。

</Exemplo>

<Exemplo titulo="通过 Eckart-Young 定理的最优秩-1 逼近" numero="3">

**问题。** 给定 <Eq>{`A = \\begin{pmatrix} 2 & 1 \\\\ 1 & 2 \\\\ 1 & 1 \\end{pmatrix}`}</Eq>，求最优秩-1 逼近并计算 Frobenius 误差。

**策略。** 计算 SVD 并仅保留第一项。

**求解。**

<Eq>{`A^T A = \\begin{pmatrix} 6 & 5 \\\\ 5 & 6 \\end{pmatrix}`}</Eq>。特征值：11 和 1。奇异值：<Eq>{`\\sigma_1 = \\sqrt{11}`}</Eq>、<Eq>{`\\sigma_2 = 1`}</Eq>。

<Eq>{`v_1 = (1/\\sqrt{2})(1,1)^T`}</Eq>、<Eq>{`v_2 = (1/\\sqrt{2})(1,-1)^T`}</Eq>。

<Eq>{`u_1 = Av_1/\\sqrt{11} = (1/\\sqrt{22})(3, 3, 2)^T`}</Eq>（规范化）。

最优秩-1 逼近：

<Eq>{`A_1 = \\sigma_1 u_1 v_1^T = \\sqrt{11} \\cdot \\frac{1}{\\sqrt{22}}\\begin{pmatrix}3\\\\3\\\\2\\end{pmatrix} \\cdot \\frac{1}{\\sqrt{2}}\\begin{pmatrix}1&1\\end{pmatrix} = \\frac{1}{2}\\begin{pmatrix}3&3\\\\3&3\\\\2&2\\end{pmatrix}`}</Eq>

误差：<Eq>{`\\|A - A_1\\|_F = \\sigma_2 = 1`}</Eq>。

**验证。** <Eq>{`\\|A\\|_F^2 = 4+1+1+4+1+1 = 12 = \\sigma_1^2 + \\sigma_2^2 = 11 + 1`}</Eq>。✓

**来源。** [Understanding Linear Algebra, §6.4 Exercise 6.4.3](https://understandinglinearalgebra.org/chap6.html) — David Austin · CC-BY-SA。

</Exemplo>

<Exemplo titulo="非方矩阵的伪逆" numero="4">

**问题。** 计算 <Eq>{`A = \\begin{pmatrix} 1 & 0 \\\\ 0 & 1 \\\\ 0 & 0 \\end{pmatrix}`}</Eq> 的 <Eq>{`A^+`}</Eq>，并用 <Eq>{`b = (2, 3, 1)^T`}</Eq> 解最小二乘系统 <Eq>{`\\min \\|Ax - b\\|`}</Eq>。

**策略。** <Eq>{`A`}</Eq> 有标准正交列，所以 SVD 平凡：<Eq>{`U = I_{3\\times 3}`}</Eq>（列按顺序）、<Eq>{`\\Sigma = \\begin{pmatrix} 1 & 0 \\\\ 0 & 1 \\\\ 0 & 0 \\end{pmatrix}`}</Eq>、<Eq>{`V = I_{2\\times 2}`}</Eq>。

**求解。**

<Eq>{`\\Sigma^+ = \\begin{pmatrix} 1 & 0 & 0 \\\\ 0 & 1 & 0 \\end{pmatrix}`}</Eq>，所以 <Eq>{`A^+ = V \\Sigma^+ U^T = \\begin{pmatrix} 1 & 0 & 0 \\\\ 0 & 1 & 0 \\end{pmatrix}`}</Eq>。

解：<Eq>{`x^* = A^+ b = (2, 3)^T`}</Eq>。

残差：<Eq>{`b - Ax^* = (2,3,1)^T - (2,3,0)^T = (0,0,1)^T`}</Eq>。最小误差：<Eq>{`\\|b - Ax^*\\| = 1`}</Eq>（<Eq>{`b`}</Eq> 的第三行是不可约的）。

**验证。** <Eq>{`A`}</Eq> 有秩 2。解 <Eq>{`x^* = (2,3)^T`}</Eq> 是最小范数的。<Eq>{`\\|A^+ A\\| = I_2`}</Eq>。✓

**来源。** [A First Course in Linear Algebra, §SVD Exercise SVD.C15](http://linear.ups.edu/html/section-SVD.html) — Rob Beezer · GNU FDL。

</Exemplo>

<Exemplo titulo="图像压缩：压缩比和误差" numero="5">

**问题。** 灰度图像为 <Eq>{`512 \\times 512`}</Eq> 像素。奇异值衰减如 <Eq>{`\\sigma_i = 10^4 / i`}</Eq>。计算：(a) 前 <Eq>{`k = 20`}</Eq> 个成分的累积解释方差；(b) <Eq>{`k = 20`}</Eq> 时的压缩比；(c) Frobenius 相对误差。

**策略。** 使用 Eckart-Young 定理和压缩定义的公式。

**求解。**

(a) <Eq>{`\\|A\\|_F^2 = \\sum_{i=1}^{512} \\sigma_i^2 = 10^8 \\sum_{i=1}^{512} 1/i^2 \\approx 10^8 \\cdot 1.6449 = 1.645 \\times 10^8`}</Eq>。

<Eq>{`\\sum_{i=1}^{20} \\sigma_i^2 = 10^8 \\sum_{i=1}^{20} 1/i^2 \\approx 10^8 \\cdot 1.5962`}</Eq>。

解释方差：<Eq>{`1.5962 / 1.6449 \\approx 97.0\\%`}</Eq>。

(b) <Eq>{`A_k`}</Eq> 的存储：<Eq>{`k(m + n + 1) = 20(512 + 512 + 1) = 20505`}</Eq> vs <Eq>{`512^2 = 262144`}</Eq>。比率：<Eq>{`262144 / 20505 \\approx 12.8\\times`}</Eq>。

(c) 相对误差：<Eq>{`\\sqrt{1 - 0.970} = \\sqrt{0.030} \\approx 17.3\\%`}</Eq>（在 Frobenius 中）。

**验证。** 以 <Eq>{`k = 50`}</Eq> 时解释方差会更高，误差更小。选择 <Eq>{`k = 20`}</Eq> 已捕捉 97% 并有 12.8x 压缩——对可视化来说非常好。

**来源。** [Understanding Linear Algebra, §6.4](https://understandinglinearalgebra.org/chap6.html) — David Austin · CC-BY-SA。<Eq>{`\\sigma_i`}</Eq> 衰减模型类似于 Exercise 6.4.5。

</Exemplo>
