### TFC — 第 1 部分：对积分求导

<Teorema titulo="TFC 第 1 部分（积分函数的导数）">

设 $f: [a, b] \to \mathbb{R}$ **连续**。定义**积分函数**：

$$G(x) = \int_a^x f(t)\, dt, \quad x \in [a, b].$$

则 $G$ 在 $(a, b)$ 上可导，且 $G'(x) = f(x)$。

</Teorema>

> "TFC1 指出由上限可变的积分定义的函数的导数等于被积函数在上限处的值。" — [OpenStax Calculus Vol. 1, §5.3](https://openstax.org/books/calculus-volume-1/pages/5-3-the-fundamental-theorem-of-calculus)

**TFC1 的证明。** 由导数的定义：

$$G'(x) = \lim_{h \to 0} \frac{G(x+h) - G(x)}{h} = \lim_{h \to 0} \frac{1}{h} \int_x^{x+h} f(t)\, dt.$$

由积分中值定理，存在 $c_h$ 在 $x$ 和 $x+h$ 之间，使得 $\int_x^{x+h} f(t)\, dt = f(c_h) \cdot h$。因此：

$$G'(x) = \lim_{h \to 0} f(c_h).$$

由于当 $h \to 0$ 时 $c_h \to x$，且 $f$ 连续，所以 $f(c_h) \to f(x)$。因此 $G'(x) = f(x)$。$\square$

### TFC — 第 2 部分：计算积分

<Teorema titulo="TFC 第 2 部分（求值公式）">

设 $f: [a, b] \to \mathbb{R}$ **连续**，$F$ 是 $f$ 的任意一个反导数。则：

$$\int_a^b f(x)\, dx = F(b) - F(a).$$

记号：$F(x)\big|_a^b := F(b) - F(a)$。

</Teorema>

**TFC2 的证明。** 由 TFC1，$G(x) = \int_a^x f(t)\, dt$ 满足 $G' = f$。因为 $F' = f$ 也成立，所以 $F - G$ 在 $(a, b)$ 上的导数为零，因此 $F(x) = G(x) + C$（其中 $C$ 为常数）。则：

$$F(b) - F(a) = [G(b) + C] - [G(a) + C] = G(b) - G(a) = \int_a^b f - 0 = \int_a^b f. \quad \square$$

### 莱布尼茨法则（变量极限）

<Definicao titulo="积分号下的求导">

若 $f$ 连续，$u(x)$、$v(x)$ 可导，则：

$$\frac{d}{dx} \int_{u(x)}^{v(x)} f(t)\, dt = f(v(x))\, v'(x) - f(u(x))\, u'(x).$$

（TFC1 应用链式法则的结果。）

</Definicao>

<Insight>

**为什么 TFC 是"基本"的？** 在 TFC 之前，计算 $\int_a^b f$ 需要通过黎曼和的极限——除了常函数外，任何函数的计算都很繁琐。TFC 之后，问题缩减为：**求反导数 + 两次求值**。这将微积分从分析工具转变为工程工具。

</Insight>

</Porta>

<Porta nivel="5" titulo="对 5 岁的孩子">

想象一条楼梯。每级台阶都有一定的高度。你想知道**总共上升了多少**。不需要测量每级台阶——只需看**现在你在哪里**以及**你从哪里开始**，然后计算差值。

TFC 说：要计算总累积，只需知道**到达了哪里**和**出发点在哪里**。

</Porta>

<Porta nivel="10" titulo="对 10 岁的孩子">

积分把小块加起来计算面积。导数测量变化的速度。这些看起来像完全不同的东西！

TFC 表明这些是**互逆的操作**，就像加法和减法。

**魔法公式：**要计算 $\int_a^b f$，找一个函数 $F$ 使其导数为 $f$。积分就是 $F(b) - F(a)$。

例子：$\int_0^3 x^2\, dx$。因为 $(x^3/3)' = x^2$，积分是 $3^3/3 - 0 = 9$。

没有 TFC：你必须加起无穷个矩形。有了 TFC：三次计算。这就是为什么它是微积分中最重要的定理。

</Porta>

<Porta nivel="15" titulo="对 15 岁的青少年">

TFC 有**两部分**：

**第 1 部分（TFC1）：**如果你积分一个函数再对结果求导，你会回到原函数。数学上：$\frac{d}{dx}\int_a^x f(t)\, dt = f(x)$。

**第 2 部分（TFC2）：**要计算 $\int_a^b f$，只需找一个反导数 $F$ 并计算 $F(b) - F(a)$。

**实际应用 TFC2 的步骤：**

1. 识别被积函数 $f(x)$。
2. 找 $F$ 使得 $F'(x) = f(x)$（使用反导数表）。
3. 计算 $F(b) - F(a)$。

**完整例子：**

$\int_1^4 (3x^2 + 2x)\, dx$。
- $F(x) = x^3 + x^2$。
- $F(4) - F(1) = (64 + 16) - (1 + 1) = 80 - 2 = 78$。

**验证：**对 $F(x) = x^3 + x^2$ 求导。得到 $3x^2 + 2x$。符合。

</Porta>

<Porta nivel="25" titulo="对工程学生">

TFC 是把微积分两半粘合在一起的胶水。在实践中：

### TFC1 — 对变量极限的积分求导

在 ODE 和积分方程中的常见情形：

$$\frac{d}{dx}\int_0^{x^2} \sin(t)\, dt = \sin(x^2) \cdot 2x.$$

一般规则（莱布尼茨）：若上限是 $v(x)$，下限是 $u(x)$：

$$\frac{d}{dx}\int_{u(x)}^{v(x)} f(t)\, dt = f(v(x)) v'(x) - f(u(x)) u'(x).$$

> "TFC1 是允许对积分求导的定理——在物理学中，当某个量定义为另一个量的积分时，它是基础。" — [APEX Calculus, §5.4](https://www.apexcalculus.com/)

### TFC2 — 化为代数

TFC2 把计算 $\int_a^b f$ 的问题化为代数问题：找 $F$ 使得 $F' = f$。积分技巧的整个目录（替换、分部、部分分式）**仅仅用于**解决这个代数问题。

### 误差分析

最常见的错误是忘记差值的符号：$F(b) - F(a)$，不是 $F(a) - F(b)$。计算过程中总是明确写出 $\big|_a^b$。

### TFC 在数值分析中

当 $f$ 没有初等反导数（例：$e^{-x^2}$）时，使用数值方法：
- **辛普森法则**：精度 $O(\Delta x^4)$，适合光滑函数。
- **高斯-克罗恩罗德求积**：自适应，`scipy.integrate.quad` 的标准。
- **蒙特卡罗**：在高维可行，其他方法放大不良。

</Porta>

<Porta nivel="40" titulo="对资深专业人士">

### TFC 的历史背景

牛顿大约在 1666 年在"流数法"的背景下制定了 TFC（导数是"流数"，积分是"流成"）。莱布尼茨在 1675-1676 年独立开发，使用至今仍保留的 $\int$ 和 $dx$ 记号。

著名的优先权争论（18 世纪）在一定程度上由民族主义驱动——伦敦皇家学会指控莱布尼茨剽窃；法庭由牛顿主持。现代历史记录认可平行独立发展。

### TFC 在勒贝格微积分中

在勒贝格理论中，TFC 需要更仔细的假设：

- **TFC1（勒贝格）：**若 $f \in L^1([a,b])$，则 $G(x) = \int_a^x f$ 绝对连续，且 $G' = f$ 几乎处处。
- **TFC2（勒贝格）：**若 $F$ 绝对连续，$F' = f$ 几乎处处，且 $\int_a^b f = F(b) - F(a)$。

病态例子：**康托函数**（魔鬼阶梯）连续，导数几乎处处为零，但 $F(1) - F(0) = 1 \neq 0 = \int_0^1 F'$。这是因为康托函数不是绝对连续的——违反了勒贝格 TFC2 的假设。

### TFC 在量化金融中

在 Black-Scholes 公式推导中，价格推导使用伊藤引理——TFC 的随机版本。形式上：$dF(W_t) = F'(W_t)\, dW_t + \frac{1}{2}F''(W_t)\, dt$，其中 $W_t$ 是布朗运动。额外的 $\frac{1}{2}F''$ 是布朗运动二次变分的"二阶修正"——在随机空间中与 TFC 类似。

</Porta>

<Porta nivel="pratica" titulo="实践应用 — 巴西数据">

### 车队燃料消耗

一支卡车车队的消耗速率为 $c(t) = 200 + 30t$ 升/小时（由于负载累积的线性增长）。前 8 小时的总消耗：

$$C = \int_0^8 (200 + 30t)\, dt = \left[200t + 15t^2\right]_0^8 = 1600 + 960 = 2560\text{ 升。}$$

按 R\$ 6.50/升计算：燃料总成本 = R\$ 16.640。

### 变量极限积分的导数

环境中积累的 CO2 量为 $A(x) = \int_0^x e^{-t/10}\, dt$。在时刻 $x$ 的累积速率由 TFC1 给出：

$$A'(x) = e^{-x/10}.$$

无需计算积分——TFC1 直接给出导数。

### 计算验证

```python
import sympy as sp
x = sp.Symbol('x')
F = sp.integrate(x**2 + 3*x, x)        # 反导数
result = F.subs(x, 4) - F.subs(x, 1)  # TFC2
print(result)  # => 33
```

## 已解决的例子

<Exemplo numero="1" titulo="TFC2 应用于多项式（基础）">

**问题。** 计算 $\displaystyle\int_1^3 (x^2 + 2x - 1)\, dx$。

**策略。** 通过 TFC2 求反导数：$F(x)$ 使得 $F'(x) = x^2 + 2x - 1$。然后计算 $F(3) - F(1)$。

**求解。**
$$F(x) = \frac{x^3}{3} + x^2 - x.$$

$$\int_1^3 (x^2 + 2x - 1)\, dx = F(3) - F(1) = \left(9 + 9 - 3\right) - \left(\frac{1}{3} + 1 - 1\right) = 15 - \frac{1}{3} = \frac{44}{3}.$$

**验证。** $F'(x) = x^2 + 2x - 1$。符合。

**来源。** [APEX Calculus, §5.4, 例 5.4.2](https://www.apexcalculus.com/) — CC-BY-NC。

</Exemplo>

<Exemplo numero="2" titulo="TFC2 应用于三角函数（基础）">

**问题。** 计算 $\displaystyle\int_0^{\pi/2} (\cos x + 2\sin x)\, dx$。

**策略。** 从表中查 $\cos x$ 和 $\sin x$ 的反导数；在端点求值。

**求解。**
$$F(x) = \sin x - 2\cos x.$$

$$\int_0^{\pi/2} (\cos x + 2\sin x)\, dx = F(\pi/2) - F(0) = (1 - 0) - (0 - 2) = 1 + 2 = 3.$$

**验证。** $F'(x) = \cos x + 2\sin x$。符合。

**来源。** [OpenStax Calculus Vol. 1, §5.3, 例 5.22](https://openstax.org/books/calculus-volume-1/pages/5-3-the-fundamental-theorem-of-calculus) — CC-BY-NC-SA。

</Exemplo>

<Exemplo numero="3" titulo="TFC1 对积分求导（中级）">

**问题。** 计算 $\displaystyle\frac{d}{dx}\int_1^{x^3} \cos(t^2)\, dt$。

**策略。** TFC1 结合链式法则：上限是 $v(x) = x^3$。

**求解。**
$$\frac{d}{dx}\int_1^{x^3} \cos(t^2)\, dt = \cos((x^3)^2) \cdot (x^3)' = \cos(x^6) \cdot 3x^2.$$

**验证。** 莱布尼茨一般规则：$\frac{d}{dx}\int_a^{v(x)} f(t)\, dt = f(v(x)) \cdot v'(x)$。应用 $f(t) = \cos(t^2)$、$v(x) = x^3$：$\cos(x^6) \cdot 3x^2$。符合。

**来源。** [APEX Calculus, §5.4, 例 5.4.5](https://www.apexcalculus.com/) — CC-BY-NC。

</Exemplo>

<Exemplo numero="4" titulo="莱布尼茨法则（两个极限都可变）（中级）">

**问题。** 对 $x > 0$，计算 $\displaystyle\frac{d}{dx}\int_x^{x^2} \frac{1}{t}\, dt$。

**策略。** 莱布尼茨一般规则：$f(v(x))v'(x) - f(u(x))u'(x)$，其中 $v(x) = x^2$、$u(x) = x$、$f(t) = 1/t$。

**求解。**
$$\frac{d}{dx}\int_x^{x^2} \frac{1}{t}\, dt = \frac{1}{x^2} \cdot 2x - \frac{1}{x} \cdot 1 = \frac{2}{x} - \frac{1}{x} = \frac{1}{x}.$$

**验证。** 另一种方式：$\int_x^{x^2} \frac{1}{t}\, dt = \ln(x^2) - \ln x = 2\ln x - \ln x = \ln x$。求导：$(\ln x)' = 1/x$。符合。

**来源。** [OpenStax Calculus Vol. 1, §5.3, 例 5.132](https://openstax.org/books/calculus-volume-1/pages/5-3-the-fundamental-theorem-of-calculus) — CC-BY-NC-SA。

</Exemplo>

<Exemplo numero="5" titulo="曲线与轴之间的面积（符号变化）（挑战）">

**问题。** 计算 $y = x^2 - 4$ 和 $x$ 轴在 $[-3, 3]$ 之间的总几何面积。

**策略。** 函数 $f(x) = x^2 - 4$ 在 $(-2, 2)$ 上为负，在外部为正。在零点处分割区间以正确的符号求和面积。

**求解。**
零点：$x^2 = 4 \Rightarrow x = \pm 2$。

在 $[-3, -2]$ 和 $[2, 3]$ 上：$f \geq 0$。在 $[-2, 2]$ 上：$f \leq 0$。

$$A = \int_{-3}^{-2}(x^2-4)\, dx + \left|\int_{-2}^{2}(x^2-4)\, dx\right| + \int_2^3(x^2-4)\, dx.$$

$F(x) = x^3/3 - 4x$。

- $F(-2) - F(-3) = (-8/3 + 8) - (-9 + 12) = 16/3 - 3 = 7/3$。
- $F(2) - F(-2) = (8/3 - 8) - (-8/3 + 8) = -32/3$。绝对值：$32/3$。
- $F(3) - F(2) = (9 - 12) - (8/3 - 8) = -3 + 16/3 = 7/3$。

总面积：$7/3 + 32/3 + 7/3 = 46/3$。

**验证。** 积分 $\int_{-3}^3 (x^2 - 4)\, dx = F(3) - F(-3) = (9-12) - (-9+12) = -3 - 3 = -6 \neq 46/3$。当 $f$ 改变符号时，定积分与几何面积不同。

**来源。** [Active Calculus, §4.4, 例 4.4.5](https://activecalculus.org/single/sec-4-4-FTC.html) — CC-BY-NC-SA。

</Exemplo>
