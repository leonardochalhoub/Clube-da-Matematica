### 定义和黎曼和理论依据

<Definicao titulo="两条曲线间的面积">

设 $f$ 和 $g$ 在 $[a, b]$ 上连续，且对所有 $x \in [a, b]$ 有 $f(x) \geq g(x)$。**区域** $R = \{(x, y) : a \leq x \leq b,\ g(x) \leq y \leq f(x)\}$ **的面积**为

<Equation explicacao="两条曲线间面积的基本公式——对上方减去下方进行积分。" latex="A(R) = \int_a^b [f(x) - g(x)]\, dx." />

**理论依据**：对于每个子区间内的某点 $x_i^*$，一个高度为 $[f(x_i^*) - g(x_i^*)]$、宽度为 $\Delta x$ 的矩形近似该处面积。黎曼和 $\sum_i [f(x_i^*) - g(x_i^*)]\Delta x$ 在 $n \to \infty$ 时收敛到积分。

</Definicao>

> "两条曲线 $f$ 和 $g$ 之间的区域面积可通过在区间上对差 $f - g$ 进行积分得到，前提是整个区间上 $f \geq g$。如果曲线相交，需在交点处断开区间。" — [Active Calculus §6.1](https://activecalculus.org/single/sec-6-1-area.html)

### 按 $y$ 积分

<Definicao titulo="按 y 积分的面积">

如果区域由曲线 $x = h(y)$（右方）和 $x = k(y)$（左方）所界定，其中对 $y \in [c, d]$ 有 $h(y) \geq k(y)$：

<Equation explicacao="当曲线表示为 y 的函数更自然时的面积公式。" latex="A = \int_c^d [h(y) - k(y)]\, dy." />

在以下情况中选择按 $y$ 积分：函数 $x(y)$ 比 $y(x)$ 更简洁，或区域在 $x$ 方向有多个分割但在 $y$ 方向只有一个。

</Definicao>

### 计算步骤

<Definicao titulo="计算两条曲线间面积的算法">

1. **作图**。没有草图，错误几乎是必然的。
2. **确定交点**：求解 $f(x) = g(x)$。
3. **识别每个子区间上哪条曲线在上方**（通过检验区间内一点）。
4. **在交点处分割区间**，如果上下顺序改变。
5. **在每个子区间上积分** $|f - g|$ 并求和。
6. 面积**总是正的**——如果某处 $\int(f-g)$ 为负，说明你弄反了 $f$ 和 $g$。

</Definicao>

> "计算两条曲线间区域的面积需要小心确定被积函数的符号。务必确定哪个函数在积分区间上更大。" — [APEX Calculus §7.1](https://www.apexcalculus.com/apex-calculus-v5.pdf)

<Insight>

**与微积分基本定理的联系**：$A = \int_a^b(f - g)\, dx = F(b) - G(b) - F(a) + G(a)$，其中 $F' = f$，$G' = g$。两条曲线间的面积等于 $f$ 和 $g$ 在区间上累积的差。在经济学中：边际收益曲线与边际成本曲线之间的面积 = 累积净利润。

</Insight>

<Porta nivel="5" titulo="给 5 岁孩子的解释">

想象你在两片面包中间涂满馅料——一片在上，一片在下。馅料的"厚度"沿着长度变化。

涂上去的面积就是所有厚度的总和——从一端到另一端。

积分就是把所有薄片加起来。两条曲线间的面积就是馅料的总厚度。

</Porta>

<Porta nivel="10" titulo="给 10 岁孩子的解释">

积分 $\int_a^b f$ 给出曲线 $f$ 和 $x$ 轴之间的面积。

如果你要**两条曲线之间**的面积，只需把一条从另一条减去：$\int_a^b (f - g)$，$f$ 在上方。

但有一点要注意：如果曲线**相交**，上方的曲线会改变。你需要在交点处分割区间，在每一部分分别计算。

有时候按 $y$ 积分更简单——不是竖片，而是用水平片。

</Porta>

<Porta nivel="15" titulo="给 15 岁少年的解释">

公式是 $A = \int_a^b (f - g)\, dx$，其中 $f \geq g$ 在 $[a, b]$ 上。

### 五步方案

1. **画图**。不画图的话你不知道谁在上方。
2. **找交点**：求解 $f(x) = g(x)$——这些是积分的上下限。
3. **检验顺序**：$f$ 在上，$g$ 在下。如果交换了，就分割区间。
4. **在每个子区间上积分** $f - g$。
5. **求和**各部分面积。

### 完整例子

求 $y = \sin x$ 和 $y = \cos x$ 在 $[0, \pi/2]$ 上的面积。

交点：$\sin x = \cos x \Rightarrow x = \pi/4$。

在 $[0, \pi/4]$ 上：$\cos x \geq \sin x$。在 $[\pi/4, \pi/2]$ 上：$\sin x \geq \cos x$。

$A = \int_0^{\pi/4}(\cos x - \sin x)\, dx + \int_{\pi/4}^{\pi/2}(\sin x - \cos x)\, dx$

$= [\sin x + \cos x]_0^{\pi/4} + [-\cos x - \sin x]_{\pi/4}^{\pi/2} = (\sqrt{2} - 1) + (\sqrt{2} - 1) = 2\sqrt{2} - 2$。

</Porta>

<Porta nivel="25" titulo="给工程专业学生的解释">

两条曲线间的面积出现在**经济学**、**热力学**、**统计学**和**控制论**中。

### 工程应用

**消费者剩余**：$CS = \int_0^{Q^*}[D(q) - p^*]\, dq$ ——需求曲线和均衡价格之间的面积。衡量消费者因支付价格低于愿意支付的金额而获得的收益。

**生产者剩余**：$PS = \int_0^{Q^*}[p^* - S(q)]\, dq$ ——价格和供给曲线之间的面积。

**热力学循环中的功**：在 $P$-$V$ 图中，循环的净功等于循环围成的面积。卡诺、奥托、柴油循环：都通过两条曲线间的面积计算。

**两个分布间的总变差**：$TV(f, g) = \frac{1}{2}\int|f - g|\, dx$ ——两个概率密度之间的总变差距离。

### 选择积分轴

**优先选择按 $y$ 积分**，当：
- 曲线自然表示为 $x(y)$。
- 区域在 $x$ 方向有多个分割但在 $y$ 方向只有一个（如水平抛物线）。
- 按 $y$ 的交点数更少。

### 数值方法

```python
from scipy.integrate import quad
import numpy as np

def area_entre(f, g, a, b):
    return quad(lambda x: abs(f(x) - g(x)), a, b)[0]
```

### 推广：通过二重积分和格林定理计算 $\mathbb{R}^2$ 中的面积

平面区域 $R$ 的面积为 $A(R) = \iint_R 1\, dA$。通过 Fubini 定理，这可以化为迭代积分——这激励了两条曲线间面积公式作为特例。

由格林定理：$A = \frac{1}{2}\oint_{\partial R}(x\, dy - y\, dx)$。对于参数曲线 $\gamma(t) = (x(t), y(t))$，这给出 $A = \frac{1}{2}\int_\alpha^\beta (x\dot{y} - y\dot{x})\, dt$ ——广义鞋带公式。

### 积分几何和等周问题

等周问题：在所有周长为 $L$ 的封闭曲线中，哪条包围的面积最大？答案：圆。等周不等式：$A \leq L^2/(4\pi)$。通过曲线的傅里叶分析证明（Hurwitz，1901）——傅里叶系数限制了周长与面积的关系。

### 变分法

给定边界的曲面面积是泛函 $A[\gamma] = \iint 1\, dA$。最小值为**极小曲面**（平均曲率的拉普拉斯方程）。Plateau 问题：给定一条铁丝曲线，它围成的极小曲面是什么？

### 多边形——鞋带公式

对于顶点为 $(x_1, y_1), \ldots, (x_n, y_n)$ 的多边形：

$$A = \frac{1}{2}\left\lvert\sum_{i=1}^n (x_i y_{i+1} - x_{i+1} y_i)\right\rvert.$$

（指标对模 $n$。）格林定理的直接应用——不需要积分。

</Porta>

<Porta nivel="pratica" titulo="实际应用">

**万能方案**：

1. **一定要画图**——没有草图错误是保证的。
2. 解方程 $f = g$ 找交点。
3. 识别每段的上方/下方。
4. 在每段上计算 $\int(\text{上} - \text{下})$。
5. 求和——面积为正。

### 消费者剩余——巴西数据示例

需求曲线 $D(q) = 100 - q$（单位价格，单位货币），均衡价格 $p^* = 60$，对应 $Q^* = 40$ 单位：

$$CS = \int_0^{40}[(100 - q) - 60]\, dq = \int_0^{40}(40 - q)\, dq = \left[40q - \frac{q^2}{2}\right]_0^{40} = 1600 - 800 = 800.$$

消费者在剩余中"获利"相当于 800 单位的货币。

### 累积利润

边际收益 $R'(t) = 100$ 单位货币/天，边际成本 $C'(t) = 50 + 5t$ 单位货币/天。前 $T$ 天的净利润：

$$L(T) = \int_0^T [R'(t) - C'(t)]\, dt = \int_0^T (50 - 5t)\, dt.$$

在 $t = 10$ 处过零：之后成本超过收益。$[0, 10]$ 上的面积 = 最大累积利润 = 250 单位货币。

### 常见错误

- 不画图就积分，导致顺序错误（结果为负）。
- 曲线相交时忘记分割。
- 当 $g > f$ 时计算 $\int(f - g)$ 而不用绝对值。

</Porta>

## 已解决的例子

<Exemplo titulo="经典 x² 和 x（基础）" numero="1">

**问题**。计算 $y = x$ 和 $y = x^2$ 在 $[0, 1]$ 上的面积。

**策略**。找交点，检查谁在上方，积分差。

**求解**。

交点：$x = x^2 \Rightarrow x(x-1) = 0 \Rightarrow x = 0$ 或 $x = 1$。

在 $(0, 1)$：$x > x^2$（验证：$0.5 > 0.25$）。所以 $f = x$，$g = x^2$。

$$A = \int_0^1 (x - x^2)\, dx = \left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1 = \frac{1}{2} - \frac{1}{3} = \frac{1}{6}.$$

**验证**。$1/6 \approx 0.167$。草图显示该区域大约覆盖正方形 $[0,1]^2$ 的 17%。可信。

**来源**。[Active Calculus §6.1, Activity 6.1.1](https://activecalculus.org/single/sec-6-1-area.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="曲线相交——正弦和余弦（中等）" numero="2">

**问题**。计算 $y = \sin x$ 和 $y = \cos x$ 在 $[0, \pi/2]$ 上的面积。

**策略**。曲线在 $x = \pi/4$ 相交。分开积分每段。

**求解**。

相交：$\sin x = \cos x \Rightarrow \tan x = 1 \Rightarrow x = \pi/4$。

在 $[0, \pi/4]$：$\cos x \geq \sin x$。在 $[\pi/4, \pi/2]$：$\sin x \geq \cos x$。

$A = \int_0^{\pi/4}(\cos x - \sin x)\, dx + \int_{\pi/4}^{\pi/2}(\sin x - \cos x)\, dx$。

$= [\sin x + \cos x]_0^{\pi/4} + [-\cos x - \sin x]_{\pi/4}^{\pi/2}$

$= (\sqrt{2} - 1) + ((-0 - 1) - (-\sqrt{2}/2 - \sqrt{2}/2))$

$= (\sqrt{2} - 1) + (-1 + \sqrt{2}) = 2\sqrt{2} - 2 \approx 0.83$。

**验证**。由问题对称性，两部分相等：各部分值为 $\sqrt{2} - 1$。和 $= 2(\sqrt{2} - 1)$。一致。

**来源**。[APEX Calculus §7.1, Example 7.1.3](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="按 y 积分——水平抛物线（中等）" numero="3">

**问题**。计算由 $x = y^2$ 和 $x = y + 2$ 界定的区域面积。

**策略**。曲线以 $y$ 表示更自然。在 $y$ 处找交点，积分 $h(y) - k(y)$。

**求解**。

交点：$y^2 = y + 2 \Rightarrow y^2 - y - 2 = 0 \Rightarrow (y-2)(y+1) = 0 \Rightarrow y = -1$ 或 $y = 2$。

在 $[-1, 2]$：$y + 2 \geq y^2$（在 $y = 0$ 验证：$2 \geq 0$）。所以 $h = y + 2$，$k = y^2$。

$$A = \int_{-1}^2 [(y + 2) - y^2]\, dy = \left[\frac{y^2}{2} + 2y - \frac{y^3}{3}\right]_{-1}^2.$$

在 $y = 2$：$2 + 4 - 8/3 = 6 - 8/3 = 10/3$。

在 $y = -1$：$1/2 - 2 + 1/3 = -7/6$。

$A = 10/3 - (-7/6) = 20/6 + 7/6 = 27/6 = 9/2$。

**验证**。按 $x$ 积分需要两部分（抛物线 $x = y^2$ 有两条"输出边"）——更麻烦。按 $y$ 积分更高效。

**来源**。[OpenStax Calculus Vol. 2, §2.1, Example 2.5](https://openstax.org/books/calculus-volume-2/pages/2-1-areas-between-curves) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="消费者剩余（建模）" numero="4">

**问题**。需求曲线 $D(q) = 100 - q$，均衡价格 $p^* = 60$，数量 $Q^* = 40$。计算消费者剩余。

**策略**。$CS = \int_0^{Q^*} [D(q) - p^*]\, dq$ ——需求曲线和价格水平线之间的面积。

**求解**。

$$CS = \int_0^{40} [(100 - q) - 60]\, dq = \int_0^{40}(40 - q)\, dq = \left[40q - \frac{q^2}{2}\right]_0^{40} = 1600 - 800 = 800.$$

**验证**。几何上，区域是底边 40、高 $D(0) - p^* = 40$ 的三角形。面积 = $(40 \cdot 40)/2 = 800$。吻合。

**来源**。[Active Calculus §6.1, Exercise 6.1.5](https://activecalculus.org/single/sec-6-1-area.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="含分割的面积——三次多项式（挑战）" numero="5">

**问题**。计算 $y = x^3 - 4x$ 和 $x$ 轴在 $[-2, 2]$ 上的总面积。

**策略**。识别 $x^3 - 4x$ 变号的位置；分割区间；在每部分用 $|f|$。

**求解**。

零点：$x^3 - 4x = x(x^2 - 4) = 0 \Rightarrow x = -2, 0, 2$。

在 $[-2, 0]$：$f(x) = x^3 - 4x \geq 0$（验证 $f(-1) = -1 + 4 = 3 > 0$）。

在 $[0, 2]$：$f(x) \leq 0$（验证 $f(1) = 1 - 4 = -3 < 0$）。

$A = \int_{-2}^0 (x^3 - 4x)\, dx + \int_0^2 [0 - (x^3 - 4x)]\, dx$。

第一部分：$\left[\frac{x^4}{4} - 2x^2\right]_{-2}^0 = 0 - (4 - 8) = 4$。

第二部分：$\left[-\frac{x^4}{4} + 2x^2\right]_0^2 = (-4 + 8) - 0 = 4$。

$A = 4 + 4 = 8$。

**验证**。由 $f$ 的奇对称性，两个面积相等。总计 $= 8$。
