### Cavalieri原理和切片

<Definicao titulo="用截面的体积">

设$S$为一个立体，对于每个$x \in [a, b]$，垂直于$x$轴的截面积为$A(x)$，且$A$在$[a, b]$上可积。$S$的**体积**为：

<Equation explicacao="切片法计算体积：将厚度为dx、面积为A(x)的切片连续相加。" latex="V = \int_a^b A(x)\, dx" />

**证明：**分割$a = x_0 < x_1 < \cdots < x_n = b$。每个切片$[x_{i-1}, x_i]$的体积约为$A(x_i^*) \Delta x_i$。当$\|\mathcal{P}\| \to 0$时，黎曼和收敛到积分。

</Definicao>

> "若两个立体的高度相同，且在每个高度处的截面相等，则这两个立体的体积相等。" — Cavalieri原理（17世纪），在[Active Calculus §6.2](https://activecalculus.org/single/sec-6-2-volume.html)中正式表述

### 圆盘法

<Definicao titulo="圆盘——绕x轴旋转">

设$f$在$[a, b]$上连续且非负。将$y = f(x)$下的区域绕$x$轴旋转得到的立体的体积为：

<Equation explicacao="每个截面是一个半径为f(x)的圆盘；面积=πr²。" latex="V = \pi \int_a^b [f(x)]^2\, dx" />

</Definicao>

### 垫圈法（washer）

<Definicao titulo="垫圈——两条曲线之间的区域旋转">

设$f, g$在$[a, b]$上连续，且$f(x) \geq g(x) \geq 0$。将$y = f(x)$和$y = g(x)$之间的区域绕$x$轴旋转得到的立体的体积为：

<Equation explicacao="垫圈的外半径R = f(x)，内半径r = g(x)。垫圈面积=π(R²-r²)。" latex="V = \pi \int_a^b \bigl([f(x)]^2 - [g(x)]^2\bigr)\, dx" />

</Definicao>

### 圆柱壳法

<Definicao titulo="圆柱壳——绕y轴旋转">

设$f$在$[a, b]$上连续且非负，$0 \leq a < b$。绕**y轴**旋转得到的立体的体积为：

<Equation explicacao="每条宽度为dx的竖直条形生成一个半径为x、高为f(x)、厚度为dx的圆柱壳。壳的体积=2πxf(x)dx。" latex="V = 2\pi \int_a^b x\, f(x)\, dx" />

</Definicao>

> "壳法可以看作沿着平行于旋转轴的方向积分。" — [APEX Calculus §7.3](https://www.apexcalculus.com/)

### 位移旋转轴

对于绕$y = c$旋转（而不是绕x轴）：用$f(x) \mapsto f(x) - c$（或$|f(x) - c|$）替换。对于用壳法绕$x = c$旋转：在半径的角色中用$|x - c|$替换$x$。

<Teorema titulo="Pappus定理（体积）">

若一个面积为$A$的平面区域绕不在其所在平面的外轴旋转，则生成的体积为：

<Equation explicacao="d是该区域的重心到旋转轴的距离。" latex="V = 2\pi\,\bar{d}\, A" />

其中$\bar{d}$是区域重心到旋转轴的距离。

</Teorema>

<Insight>

**圆盘作为垫圈的特例。**当$g(x) = 0$（无孔）时，垫圈公式简化为圆盘公式：$\pi(R^2 - 0^2) = \pi R^2$。三种方法都是一般原理$V = \int A(x)\,dx$的实例——只有$A(x)$的表达式不同。

</Insight>

<Porta nivel="5" titulo="给5岁孩子的解释">

想象一个橙子。你把它切成**薄片**。每片都是一个圆形的圆盘。要知道整个橙子的体积，你要**测量每片的面积**并加起来。

如果片子切得很薄——薄到极限——这个和就变成了一个积分。

这正是我们要做的：把立体切成无穷多个薄片，并加起它们的面积。结果就是体积。

</Porta>

<Porta nivel="10" titulo="给10岁孩子的解释">

**旋转体**是当你把一条曲线绕着一条轴旋转时得到的形状——就像木工车床用一块木头制成一件圆形的东西。

要计算体积，想象你把立体切成**薄片**，每片厚度为$\Delta x$。

- 每片都是一个**圆盘**，半径为$f(x)$。
- 圆盘的面积：$\pi r^2 = \pi [f(x)]^2$。
- 片的体积：面积×厚度 = $\pi [f(x)]^2 \, \Delta x$。

当$\Delta x$趋向于零，和变成积分：$V = \pi \int_a^b [f(x)]^2\, dx$。

如果区域中间有**孔**（两条曲线之间），每片都是一个**垫圈**——要减去孔的面积。

当旋转轴是竖直的，我们用**圆柱壳法**：想象像洋葱一样剥开成层。每层是一个细圆柱，你把它"展开"变成一个矩形。把所有层加起来。

</Porta>

<Porta nivel="15" titulo="给15岁青少年的解释">

### 圆盘法

将$y = f(x) \geq 0$在$x \in [a, b]$绕x轴旋转：

$$V = \pi \int_a^b [f(x)]^2\, dx$$

**快速例子：**$y = \sqrt{x}$在$[0, 4]$上绕x轴旋转。

$$V = \pi \int_0^4 x\, dx = \pi \left[\frac{x^2}{2}\right]_0^4 = \pi \cdot 8 = 8\pi \approx 25.1 \text{ 立方单位}$$

### 垫圈法

两个半径，外半径$R(x)$和内半径$r(x)$：

$$V = \pi \int_a^b \bigl([R(x)]^2 - [r(x)]^2\bigr)\, dx$$

**快速例子：**在$[0, 1]$上$y = x$和$y = x^2$之间的区域绕x轴旋转。

$R(x) = x$，$r(x) = x^2$：

$$V = \pi \int_0^1 (x^2 - x^4)\, dx = \pi \left[\frac{x^3}{3} - \frac{x^5}{5}\right]_0^1 = \pi\!\left(\frac{1}{3} - \frac{1}{5}\right) = \frac{2\pi}{15}$$

### 圆柱壳法

绕**y轴**旋转，按$x$积分：

$$V = 2\pi \int_a^b x\, f(x)\, dx$$

**快速例子：**$y = x^2$在$[0, 2]$上绕y轴旋转。

$$V = 2\pi \int_0^2 x \cdot x^2\, dx = 2\pi \int_0^2 x^3\, dx = 2\pi \cdot 4 = 8\pi$$

### 黄金法则

看**旋转轴**：
- 平行于积分轴 → **圆盘法/垫圈法**。
- 垂直于积分轴 → **壳法**。

**总是先画出区域**再建立积分。

<Porta nivel="25" titulo="给工程学生的解释">

### 一般公式

所有方法都是$V = \int_a^b A(x)\,dx$的实例。不同之处在于$A(x)$如何由几何决定：

| 方法 | $A(x)$ | 典型用法 |
|---|---|---|
| 圆盘 | $\pi [f(x)]^2$ | 绕平行轴旋转，无孔 |
| 垫圈 | $\pi([R(x)]^2 - [r(x)]^2)$ | 两条曲线间，平行轴 |
| 壳 | $2\pi x f(x)$（侧面积元） | 绕垂直轴旋转 |

### 位移轴

绕$y = c$旋转：外半径 = $f(x) - c$，内半径 = $g(x) - c$（假设$f > g > c$）。对于轴$x = c$的壳法：半径 = $|x - c|$。

### Pappus（快速验证）

$V = 2\pi \bar{d} A$。有用于验证：计算平面区域的重心$(\bar x, \bar y)$和到轴的距离。对于外半径$R$和管道$r$的圆环体：$A = \pi r^2$，$\bar d = R$ → $V = 2\pi^2 R r^2$。

### 从切片导出的形式

- **金字塔**，底面$A_0$、高$h$：$V = \int_0^h A_0(1 - y/h)^2\, dy = A_0 h/3$。
- **有方形截面的立体**：$V = \int_a^b [s(x)]^2\, dx$。
- **半径$r$的球体**：$V = \pi \int_{-r}^r (r^2 - x^2)\, dx = 4\pi r^3/3$。

### 与力学的联系

- **质量**：$m = \int \rho\, dV$（体积密度$\rho$）。
- **质心**：$\bar z = \frac{1}{m}\int z\,\rho\,dV$。
- **绕轴的转动惯量**：$I = \int r_\perp^2\,\rho\,dV$。
- **抽水功**：$W = \int_0^H \rho g A(y)(H - y)\,dy$，对于截面为$A(y)$、高度为$H$的水箱。

### 数值方法

```python
from scipy.integrate import quad
import numpy as np

def volume_disco(f, a, b):
    V, _ = quad(lambda x: np.pi * f(x)**2, a, b)
    return V

# 半径为1的球体：验证
V_esfera = volume_disco(lambda x: np.sqrt(1 - x**2), -1, 1)
# V_esfera ≈ 4.189 ≈ 4π/3 ✓
```

### 测度和抽象体积

在$\mathbb{R}^n$中，$K$的体积是Lebesgue测度$\lambda^n(K) = \int_K 1\,d\mathbf{x}$。切片是**Fubini定理**：在可测性条件下，$\int_{\mathbb{R}^n} f\,d\lambda^n = \int_{\mathbb{R}} \left(\int_{\mathbb{R}^{n-1}} f(x, y)\,d\lambda^{n-1}(y)\right) d\lambda(x)$。

### Cavalieri作为Fubini的应用

Cavalieri原理是直接的：如果$A(x) = \lambda^{n-1}(K_x)$（切片的测度）对两个立体$K$和$K'$相同，则$\lambda^n(K) = \int A(x)\,dx = \lambda^n(K')$。

### 曲线坐标

变量替换，其中雅可比式$|J|$：
- 圆柱坐标$(r, \theta, z)$：$dV = r\,dr\,d\theta\,dz$。
- 球坐标$(\rho, \phi, \theta)$：$dV = \rho^2 \sin\phi\,d\rho\,d\phi\,d\theta$。

圆柱壳法是圆柱坐标中在$r$的积分，边缘化$\theta$和$z$。

### 微分形式和方向

边界光滑的立体$\Omega$的体积可以表示为$V = \frac{1}{3}\oint_{\partial\Omega} \mathbf{r} \cdot d\mathbf{S}$（散度定理，$\mathbf{F} = \mathbf{r}/3$，$\operatorname{div}\mathbf{F} = 1$）。在多面体体积的计算中（CAD、FEM），这比体积积分更有效率。

### 广义Pappus

在微分几何中，Pappus定理对纤维化$\pi: E \to B$推广：$E$的体积是$B$上的积分，其中纤维$\pi^{-1}(b)$的体积（coarea公式）。在sub-Riemannian几何和断层扫描中的应用。

### 高维体积和Monte Carlo

对于大的$n$，$\lambda^n(B^n) = \pi^{n/2}/\Gamma(n/2 + 1) \to 0$（高维的单位球几乎是空的）。$\mathbb{R}^n$中域的体积通过Monte Carlo计算：$V \approx V_{\text{box}} \cdot (\text{内部的点})/(\text{总数})$。在量化金融中的应用（资产篮子上期权价格的积分，高维积分）。

</Porta>

<Porta nivel="pratica" titulo="实际应用——水箱、活塞和圆环体">

### 工程应用

**储液罐。**一个半径为$R$、长度为$L$的卧式圆柱形水箱到高度$h$的液体体积：
$$V(h) = L \int_{-R}^{h-R} 2\sqrt{R^2 - y^2}\, dy$$
积分变成圆扇形面积——对于卡车油罐燃料液位读数很有用。

**发动机活塞。**活塞扫过的体积（排量）为$V_{\text{cil}} = \pi R^2 \cdot \text{行程}$，通过$f(x) = R$常数的圆盘法确认。

**圆环体（轮胎、甜甜圈、内胎）。**半径为$r$的圆形截面，距轴$R$。Pappus：$V = 2\pi R \cdot \pi r^2 = 2\pi^2 R r^2$。

### 常见错误

- 在垫圈法中混淆**外**和**内**半径（减法，不是加法）。
- 当轴垂直时用圆盘法（积分在$y$，不是$x$）。
- 忘记圆柱壳中的因子$2\pi$。
- 位移轴：半径是$|f(x) - c|$，不是$f(x)$。

### 使用步骤

1. **精确绘制**2D区域——标记交点。
2. 确定**旋转轴**。
3. 选择方法：平行 → 圆盘法/垫圈法；垂直 → 壳法。
4. 用积分变量**表示半径**（或半径+高度）。
5. **积分**并用Pappus或已知公式（球体、圆锥、圆柱）验证。

### 速查公式

| 立体 | 公式 |
|---|---|
| 半径$r$的球体 | $4\pi r^3 / 3$ |
| 半径$R$、高$h$的圆锥 | $\pi R^2 h / 3$ |
| 半径$R$、高$h$的圆柱 | $\pi R^2 h$ |
| 半径$R, r$的圆环体 | $2\pi^2 R r^2$ |

## 已解例题

<Exemplo titulo="用圆盘法求球体的体积（应用）" numero="1">

**问题：**用圆盘法推导半径为$r$的球体的体积公式。

**策略：**半径为$r$的球体由半圆$y = \sqrt{r^2 - x^2}$（$x \in [-r, r]$）绕x轴旋转生成。每个截面是一个半径为$\sqrt{r^2 - x^2}$的圆盘。

**求解：**

应用圆盘公式：

$$V = \pi \int_{-r}^{r} \bigl(\sqrt{r^2 - x^2}\bigr)^2\, dx = \pi \int_{-r}^{r} (r^2 - x^2)\, dx$$

$$= \pi \left[r^2 x - \frac{x^3}{3}\right]_{-r}^{r} = \pi \left[\left(r^3 - \frac{r^3}{3}\right) - \left(-r^3 + \frac{r^3}{3}\right)\right]$$

$$= \pi \cdot 2\left(r^3 - \frac{r^3}{3}\right) = \pi \cdot 2 \cdot \frac{2r^3}{3} = \frac{4\pi r^3}{3}$$

**验证：**对于$r = 1$：$V = 4\pi/3 \approx 4.19$立方单位。经典结果得以确认。

**来源。** [OpenStax Calculus Volume 2 §2.2, Example 2.5](https://openstax.org/books/calculus-volume-2/pages/2-2-determining-volumes-by-slicing) — 许可证CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="用垫圈法——两条抛物线间的区域（中级）" numero="2">

**问题：**计算将由$y = x$和$y = x^2$所围区域（$x \in [0, 1]$）绕x轴旋转得到的立体的体积。

**策略：**两条曲线在$x = 0$和$x = 1$相交。在$[0, 1]$上，$x \geq x^2$，所以$R(x) = x$（外半径）、$r(x) = x^2$（内半径）。使用垫圈法。

**求解：**

$$V = \pi \int_0^1 \bigl([x]^2 - [x^2]^2\bigr)\, dx = \pi \int_0^1 (x^2 - x^4)\, dx$$

$$= \pi \left[\frac{x^3}{3} - \frac{x^5}{5}\right]_0^1 = \pi\!\left(\frac{1}{3} - \frac{1}{5}\right) = \pi \cdot \frac{2}{15} = \frac{2\pi}{15}$$

**验证：**体积应该小于半径为1、高为1的圆锥（$V_{\text{圆锥}} = \pi/3 \approx 1.047$）。实际上，$2\pi/15 \approx 0.419 < \pi/3$。合理——$y=x$和$y=x^2$间的区域小于完整三角形。

**来源。** [Active Calculus §6.2, Activity 6.2.2](https://activecalculus.org/single/sec-6-2-volume.html) — 许可证CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="用圆柱壳法——与垫圈法比较（高级）" numero="3">

**问题：**用圆柱壳法计算$y = x^2$和$y = x$（$[0, 1]$）间的区域绕**y轴**旋转得到的体积。将结果与用y积分的垫圈法比较。

**策略：**旋转轴是$y$（竖直），自然变量是$x$：使用壳法。每条宽度为$dx$的竖直条形生成一个半径为$x$、高为$f(x) - g(x) = x - x^2$的壳。

**求解：**

$$V = 2\pi \int_0^1 x(x - x^2)\, dx = 2\pi \int_0^1 (x^2 - x^3)\, dx$$

$$= 2\pi \left[\frac{x^3}{3} - \frac{x^4}{4}\right]_0^1 = 2\pi\!\left(\frac{1}{3} - \frac{1}{4}\right) = 2\pi \cdot \frac{1}{12} = \frac{\pi}{6}$$

**用y的垫圈法交叉验证：**用y表示的曲线：从$y = x^2$得$x = \sqrt{y}$；从$y = x$得$x = y$。外半径$R(y) = \sqrt{y}$，内半径$r(y) = y$：

$$V = \pi \int_0^1 (y - y^2)\, dy = \pi\!\left[\frac{y^2}{2} - \frac{y^3}{3}\right]_0^1 = \pi\!\left(\frac{1}{2} - \frac{1}{3}\right) = \frac{\pi}{6} \checkmark$$

**来源。** [APEX Calculus §7.3, Example 7.3.2](https://www.apexcalculus.com/) — 许可证CC-BY-NC。

</Exemplo>

<Exemplo titulo="用圆盘法求圆锥体——公式推导（证明）" numero="4">

**问题：**推导半径为$R$、高为$h$的直圆锥的公式$V = \pi R^2 h/3$。

**策略：**圆锥由直线$y = (R/h)x$（$x \in [0, h]$）绕x轴旋转生成。每个截面是一个半径为$(R/h)x$的圆盘。

**求解：**

$$V = \pi \int_0^h \left(\frac{R}{h} x\right)^2 dx = \pi \frac{R^2}{h^2} \int_0^h x^2\, dx = \pi \frac{R^2}{h^2} \cdot \frac{h^3}{3} = \frac{\pi R^2 h}{3}$$

**验证：**对于$R = h = 1$：$V = \pi/3 \approx 1.047$立方单位。Pappus定理确认：直角三角形（底$R$、高$h$）的重心距顶点$\bar{x} = h/3$。壳的体积：$2\pi \cdot (R/2) \cdot (Rh/2) = \pi R^2 h / 2 \neq \pi R^2 h/3$——这里Pappus适用于立体，不是三角形。直接用圆盘法最清楚。

**来源。** [OpenStax Calculus Volume 2 §2.2, Example 2.4](https://openstax.org/books/calculus-volume-2/pages/2-2-determining-volumes-by-slicing) — 许可证CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="抽水功——球形水箱（建模）" numero="5">

**问题：**一个半径为3 m的球形水箱装满了水（密度$\rho = 1000$ kg/m³，$g = 9.8$ m/s²）。计算将全部水抽到水箱顶部所需的功。

**策略：**把球心放在原点。顶部在$y = 3$。厚度为$dy$的在高度$y$的薄片需要提升$(3 - y)$米。高度$y$处的圆形截面半径为$\sqrt{9 - y^2}$，因此面积为$\pi(9 - y^2)$。

**求解：**

$$W = \int_{-3}^{3} \rho g \cdot \pi(9 - y^2) \cdot (3 - y)\, dy$$

$$= 1000 \cdot 9.8 \cdot \pi \int_{-3}^{3} (9 - y^2)(3 - y)\, dy$$

展开乘积：

$$(9 - y^2)(3 - y) = 27 - 9y - 3y^2 + y^3$$

$$\int_{-3}^{3} (27 - 9y - 3y^2 + y^3)\, dy = \left[27y - \frac{9y^2}{2} - y^3 + \frac{y^4}{4}\right]_{-3}^{3}$$

奇函数项（$-9y$和$y^3$）按对称性抵消。偶函数项：

$$= 2\left(27 \cdot 3 - 3^3\right) = 2(81 - 27) = 108$$

$$W = 9800\pi \cdot 108 \approx 3.33 \times 10^6 \text{ J} = 3.33 \text{ MJ}$$

**验证：**数量级：移动$\approx 113$ t的水$\approx 1.5$ m（重心距顶部）给出$113\,000 \times 9.8 \times 1.5 \approx 1.66$ MJ。预期系数2是因为实际重心（由对称性在$y = 0$，距顶部3 m）给出3.32 MJ。确认。

**来源。** [OpenStax Calculus Volume 2 §6.5, Example 6.24](https://openstax.org/books/calculus-volume-2/pages/6-5-physical-applications) — 许可证CC-BY-NC-SA。

</Exemplo>
