### 变量替换定理

<Teorema titulo="替换（变量替换）">

设 $g: [a, b] \to \mathbb{R}$ 可导且 $g'$ 连续，$f$ 在 $g$ 的像集上连续。则有：

$$\int_a^b f(g(x))\, g'(x)\, dx = \int_{g(a)}^{g(b)} f(u)\, du.$$

**不定形式**：若 $F' = f$，则 $\int f(g(x))\, g'(x)\, dx = F(g(x)) + C$。

</Teorema>

> "替换规则是积分中对应导数中链式法则的相反运算。" — [OpenStax Calculus Vol. 1, §5.5](https://openstax.org/books/calculus-volume-1/pages/5-5-substitution)

**证明。** 若 $F' = f$，根据链式法则：$(F \circ g)' = f(g(x)) \cdot g'(x)$。因此 $F \circ g$ 是 $f(g(x)) g'(x)$ 的一个反导数。根据微积分第二基本定理：

$$\int_a^b f(g(x)) g'(x)\, dx = F(g(b)) - F(g(a)) = \int_{g(a)}^{g(b)} f(u)\, du. \quad \square$$

### 机械步骤

<Definicao titulo="替换的步骤">

1. **识别** $u = g(x)$ — 通常是复合函数中的"内部"表达式。
2. **计算** $du = g'(x)\, dx$，必要时求解 $dx$。
3. **改写** 整个积分，用 $u$ 表示：被积函数和 $dx$ 都应消失。
4. **定积分**：同时替换积分上下限：$a \to g(a)$，$b \to g(b)$。
5. **计算** 关于 $u$ 的积分（应该比原来更简单）。
6. **不定形式**：用 $u = g(x)$ 代入以用 $x$ 表示结果。

</Definicao>

### 替换何时有效的迹象

被积函数应包含 $f(\text{某式})$ 乘以**该"某式"的导数**（或该导数的某个常数倍）。

模式示例：

| 被积函数 | $u$ | $du$ |
|---|---|---|
| $2x\, e^{x^2}$ | $x^2$ | $2x\, dx$ |
| $\cos x \cdot e^{\sin x}$ | $\sin x$ | $\cos x\, dx$ |
| $\frac{x}{x^2 + 1}$ | $x^2 + 1$ | $2x\, dx$（需要 $1/2$ 的调整） |
| $x^2(x^3 + 1)^5$ | $x^3 + 1$ | $3x^2\, dx$（需要 $1/3$ 的调整） |

<Insight>

**常数调整**：若 $g'(x)$ 在被积函数中乘以某个常数 $k$（但不是 $g'$ 的确切值），只需在积分内外同时乘以和除以 $k$：

$$\int x\, e^{x^2}\, dx = \frac{1}{2}\int 2x\, e^{x^2}\, dx = \frac{1}{2} e^{x^2} + C.$$

这对常数有效，但**不适用**于 $x$ 的变量或函数。

</Insight>

<Porta nivel="5" titulo="5 岁小孩的解释">

想象你要把难以计数的小块加起来。然后你发现可以把每一块换成一枚硬币，数硬币很容易。然后你把硬币换回你需要的东西。

替换就是这样：把难的形式换成容易的来计算，然后再转换回来。

</Porta>

<Porta nivel="10" titulo="10 岁孩子的解释">

还记得导数中的**链式法则**吗？$(\sin(x^2))' = \cos(x^2) \cdot 2x$。

链式法则"产生"一个乘积。替换是**反向路径**：当你看到 $\cos(x^2) \cdot 2x$ 时，你认识到它是链式法则的"孩子"并反向回到 $\sin(x^2)$。

**如何做**：把"内部的东西"叫做 $u$。例如，$u = x^2$。那么 $du = 2x\, dx$。积分 $\int \cos(x^2) \cdot 2x\, dx$ 变成 $\int \cos u\, du = \sin u + C = \sin(x^2) + C$。

替换在你**看出模式**时有效。这需要练习。

</Porta>

<Porta nivel="15" titulo="15 岁青少年的解释">

替换是最重要的积分技巧。每当链式法则在求导时产生一个乘积，替换在积分时就反向解除那个乘积。

**对 $\int 2x(x^2+1)^3\, dx$ 的逐步过程**：

1. 选择 $u = x^2 + 1$（幂次中的"内部东西"）。
2. 计算：$du = 2x\, dx$ — 完全正是剩余的部分！
3. 改写：$\int u^3\, du$。
4. 积分：$u^4/4 + C$。
5. 代回：$\frac{(x^2+1)^4}{4} + C$。

**验证**：用链式法则对结果求导：
$\left(\frac{(x^2+1)^4}{4}\right)' = \frac{4(x^2+1)^3}{4} \cdot 2x = 2x(x^2+1)^3$。验证无误。

**定积分中的替换**：

除了替换变量，也要替换积分上下限：

$$\int_0^1 2x(x^2+1)^3\, dx: \quad u(0) = 1, \quad u(1) = 2.$$

$$\int_1^2 u^3\, du = \left[\frac{u^4}{4}\right]_1^2 = 4 - \frac{1}{4} = \frac{15}{4}.$$

</Porta>

### 定积分版本的假设条件

对于有极限交换的版本，$g$ 在 $[a, b]$ 上必须**连续且可导**。不定形式不要求 $g$ 是单射，但定积分版本若 $g$ 不单调，可能需要在 $g'$ 改变符号的点处分割区间。

### 特殊替换

**根式**：$\sqrt{ax + b}$ — 取 $u = ax + b$。

**三角函数**：$\int \tan x\, dx = \int \frac{\sin x}{\cos x}\, dx$。取 $u = \cos x$，$du = -\sin x\, dx$：

$$\int \tan x\, dx = -\int \frac{du}{u} = -\ln|u| + C = -\ln|\cos x| + C = \ln|\sec x| + C.$$

**复合指数**：$\int e^{ax}\, dx = \frac{1}{a}e^{ax} + C$（常数调整：$u = ax$，$du = a\, dx$）。

> "识别应该用哪种替换的关键之一是找到'内部'函数——那个如果被求导，会产生被积函数中的乘法因子的函数。" — [APEX Calculus, §6.1](https://www.apexcalculus.com/)

### 替换何时失效

当 $g'(x)$ **不出现**在被积函数中时，替换失效 — 或者 $g'(x)$ 乘以一个不是常数的 $x$ 的函数。例如，$\int x^2 e^{x^3 + x}\, dx$ 没有简单的替换，因为 $x^3 + x$ 的导数是 $3x^2 + 1$，不是 $x^2$。

当直接替换失效时：尝试分部积分（第 85 课）。

import sympy as sp

# => (x**2 + 1)**4/4

### 实分析中的变量替换

$\mathbb{R}^n$ 上变量替换定理（用于多重积分）是：

$$\int_{\phi(\Omega)} f(y)\, dy = \int_\Omega f(\phi(x)) |\det J_\phi(x)|\, dx,$$

其中 $J_\phi$ 是 $\phi$ 的雅可比矩阵。在一维中，$|\det J_\phi| = |g'(x)|$，恢复通常的替换。在二维和三维中，雅可比行列式衡量坐标变换的"面积/体积扭曲" — 这是极坐标、柱坐标和球坐标中积分的基础。

### 概率中的替换

若 $X$ 是密度函数为 $f_X$ 的随机变量，且 $Y = g(X)$，其中 $g$ 单调可导，则 $Y$ 的密度函数为：

$$f_Y(y) = f_X(g^{-1}(y)) \cdot \left|\frac{d}{dy} g^{-1}(y)\right|.$$

这正是变量替换定理应用于密度函数。对蒙特卡洛模拟（逆变换方法）至关重要。

### 微分方程中的替换积分

**分离变量**方法 $\frac{dy}{dx} = h(x)k(y)$ 是伪装的替换：$\int \frac{dy}{k(y)} = \int h(x)\, dx$。这种技巧把微分方程化为两个独立的反导数问题。

### 三角替换（第 87 课的预告）

对于含 $\sqrt{a^2 - x^2}$、$\sqrt{a^2 + x^2}$、$\sqrt{x^2 - a^2}$ 的被积函数，使用三角替换（$x = a\sin\theta$、$a\tan\theta$、$a\sec\theta$）通过勾股恒等式消除根号。同一原理的推广。

</Porta>

<Porta nivel="pratica" titulo="实际应用 — 巴西数据">

### 递增分额的复利

投资增长率为 $r(t) = 1000 e^{0{,}06t}$ 雷亚尔每月。12 个月的累积价值：

$$V = \int_0^{12} 1000 e^{0{,}06t}\, dt.$$

替换：$u = 0{,}06t$，$du = 0{,}06\, dt$，则 $dt = du/0{,}06$。

$$V = \frac{1000}{0{,}06}\int_0^{0{,}72} e^u\, du = \frac{1000}{0{,}06}[e^{0{,}72} - 1] \approx 16.667 \times 1{,}054 \approx \text{R\$ }17.567.$$

### 衰减速度

车辆的加速度为 $a(t) = 5e^{-0{,}2t}$ m/s²。从静止开始，10 秒后的速度：

$$v(10) = \int_0^{10} 5e^{-0{,}2t}\, dt.$$

$u = -0{,}2t$，$du = -0{,}2\, dt$：

$$= \frac{5}{-0{,}2}[e^{-0{,}2t}]_0^{10} = -25(e^{-2} - 1) = 25(1 - e^{-2}) \approx 25 \times 0{,}865 \approx 21{,}6\text{ m/s}.$$

### SymPy 验证

```python
import sympy as sp
x = sp.Symbol('x')
# 替换：x*sqrt(x^2 + 1) 的积分
print(sp.integrate(x * sp.sqrt(x**2 + 1), x))
# => (x**2 + 1)**(3/2)/3
```

## 求解的例题

<Exemplo numero="1" titulo="直接替换指数（基础）">

**问题。** 计算 $\displaystyle\int 3x^2 e^{x^3}\, dx$。

**策略。** 被积函数的形式为 $f(g(x)) \cdot g'(x)$，其中 $g(x) = x^3$ 且 $g'(x) = 3x^2$。

**求解。**
$u = x^3$，$du = 3x^2\, dx$。

$$\int 3x^2 e^{x^3}\, dx = \int e^u\, du = e^u + C = e^{x^3} + C.$$

**验证。** $(e^{x^3})' = e^{x^3} \cdot 3x^2 = 3x^2 e^{x^3}$。验证无误。

**来源。** [APEX Calculus, §6.1, 例 6.1.2](https://www.apexcalculus.com/) — CC-BY-NC。

</Exemplo>

<Exemplo numero="2" titulo="常数调整（基础）">

**问题。** 计算 $\displaystyle\int x(x^2 + 5)^4\, dx$。

**策略。** $g(x) = x^2 + 5$，$g'(x) = 2x$。被积函数有 $x$（$g'$ 的一半），所以需要 $1/2$ 的调整。

**求解。**
$u = x^2 + 5$，$du = 2x\, dx$，则 $x\, dx = du/2$。

$$\int x(x^2+5)^4\, dx = \int u^4 \cdot \frac{du}{2} = \frac{1}{2} \cdot \frac{u^5}{5} + C = \frac{(x^2+5)^5}{10} + C.$$

**验证。** $\left(\frac{(x^2+5)^5}{10}\right)' = \frac{5(x^2+5)^4 \cdot 2x}{10} = x(x^2+5)^4$。验证无误。

**来源。** [APEX Calculus, §6.1, 例 6.1.4](https://www.apexcalculus.com/) — CC-BY-NC。

</Exemplo>

<Exemplo numero="3" titulo="定积分中的替换与极限变换（中等）">

**问题。** 计算 $\displaystyle\int_0^1 2x(x^2 + 1)^3\, dx$。

**策略。** $u = x^2 + 1$，$du = 2x\, dx$。交换极限：$u(0) = 1$，$u(1) = 2$。

**求解。**
$$\int_0^1 2x(x^2+1)^3\, dx = \int_1^2 u^3\, du = \left[\frac{u^4}{4}\right]_1^2 = \frac{16}{4} - \frac{1}{4} = \frac{15}{4}.$$

**验证。** 不交换极限：反导数 $(x^2+1)^4/4$。在 $x=1$ 和 $x=0$ 处求值：$2^4/4 - 1^4/4 = 4 - 1/4 = 15/4$。验证无误。

**来源。** [OpenStax Calculus Vol. 1, §5.5, 例 5.38](https://openstax.org/books/calculus-volume-1/pages/5-5-substitution) — CC-BY-NC-SA。

</Exemplo>

<Exemplo numero="4" titulo="含三角函数的替换（中等）">

**问题。** 计算 $\displaystyle\int \sin^3 x \cos x\, dx$。

**策略。** $g(x) = \sin x$，$g'(x) = \cos x$ — 在被积函数中明确出现。

**求解。**
$u = \sin x$，$du = \cos x\, dx$。

$$\int \sin^3 x \cos x\, dx = \int u^3\, du = \frac{u^4}{4} + C = \frac{\sin^4 x}{4} + C.$$

**验证。** $\left(\frac{\sin^4 x}{4}\right)' = \frac{4\sin^3 x \cos x}{4} = \sin^3 x \cos x$。验证无误。

**来源。** [OpenStax Calculus Vol. 1, §5.5, 例 5.36](https://openstax.org/books/calculus-volume-1/pages/5-5-substitution) — CC-BY-NC-SA。

</Exemplo>

<Exemplo numero="5" titulo="正切函数的积分通过替换（挑战）">

**问题。** 计算 $\displaystyle\int \tan x\, dx$。

**策略。** 写成 $\tan x = \sin x / \cos x$，然后取 $u = \cos x$。

**求解。**
$u = \cos x$，$du = -\sin x\, dx$，则 $\sin x\, dx = -du$。

$$\int \frac{\sin x}{\cos x}\, dx = \int \frac{-du}{u} = -\ln|u| + C = -\ln|\cos x| + C = \ln|\sec x| + C.$$

**验证。** $(\ln|\sec x|)' = \frac{\sec x \tan x}{\sec x} = \tan x$。验证无误。

**来源。** [APEX Calculus, §6.1, 例 6.1.8](https://www.apexcalculus.com/) — CC-BY-NC。

</Exemplo>
