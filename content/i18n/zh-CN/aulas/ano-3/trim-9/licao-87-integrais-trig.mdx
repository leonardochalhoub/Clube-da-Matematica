### 基本恒等式

<Definicao titulo="三角积分中使用的恒等式">

以下恒等式是核心工具：

- **勾股恒等式：**$\sin^2 x + \cos^2 x = 1$；$1 + \tan^2 x = \sec^2 x$；$1 + \cot^2 x = \csc^2 x$。
- **偶次幂（半角公式）：**

<Equation explicacao="将 sin² 和 cos² 化为二倍角函数——对于偶数指数是不可或缺的。" latex="\sin^2 x = \frac{1 - \cos 2x}{2}, \qquad \cos^2 x = \frac{1 + \cos 2x}{2}." />

- **积化和差：**$\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$。

</Definicao>

### 模式 $\int \sin^n x \cos^m x\, dx$

<Definicao titulo="按指数奇偶性的策略">

| 情况 | 策略 |
|---|---|
| $n$ 奇数 | 提出 $\sin x\, dx$；通过 $\sin^2 = 1 - \cos^2$ 转化 $\sin^{n-1}$；令 $u = \cos x$ |
| $m$ 奇数 | 提出 $\cos x\, dx$；通过 $\cos^2 = 1 - \sin^2$ 转化 $\cos^{m-1}$；令 $u = \sin x$ |
| 都是偶数 | 重复使用半角公式 |

对于 $\int \tan^n x \sec^m x\, dx$：

| 情况 | 策略 |
|---|---|
| $m$ 偶数 | 提出 $\sec^2 x\, dx$；通过 $\sec^2 = 1 + \tan^2$ 转化；令 $u = \tan x$ |
| $n$ 奇数 | 提出 $\sec x \tan x\, dx$；通过 $\tan^2 = \sec^2 - 1$ 转化；令 $u = \sec x$ |

</Definicao>

> "积分正弦和余弦幂次的乘积的策略取决于所涉及的指数的奇偶性。当其中一个指数为奇数时，我们'提取'一个因子并使用勾股恒等式来转化剩余的偶数次幂。" — [OpenStax Calculus Vol. 2, §3.2](https://openstax.org/books/calculus-volume-2/pages/3-2-trigonometric-integrals)

### 约化公式

<Teorema titulo="sinⁿ 的约化公式">

$$\int \sin^n x\, dx = -\frac{\sin^{n-1}x \cos x}{n} + \frac{n-1}{n}\int \sin^{n-2}x\, dx.$$

类似的公式存在于 $\cos^n$、$\tan^n$、$\sec^n$、$\csc^n$。

**证明：**分部积分，令 $u = \sin^{n-1}x$，$dv = \sin x\, dx$，加上恒等式 $\sin^2 = 1 - \cos^2$。

</Teorema>

<Insight>

**Weierstrass 替换**（通用）：$t = \tan(x/2)$ 将任何关于 $\sin x$、$\cos x$ 的有理积分转化为关于 $t$ 的有理积分。通过部分分式，一切都变成初等的——但结果可能很复杂。当其他策略失败时使用。

</Insight>

</Porta>

<Porta nivel="5" titulo="给5岁孩子讲">

你知道当你穿上幽灵服装让别人认不出你，然后脱掉吗？三角替换就是这样。

你有 $\sqrt{1 - x^2}$——很难处理。你把 $x$ 换成 $\sin\theta$——伪装！根号消失了，变成 $\cos\theta$。用 $\theta$ 计算后，脱掉伪装，回到 $x$。

</Porta>

<Porta nivel="10" titulo="给10岁孩子讲">

有一个你知道的恒等式：$\sin^2\theta + \cos^2\theta = 1$。

这意味着 $\sqrt{1 - \sin^2\theta} = \cos\theta$（假设 $\cos\theta \geq 0$）。

所以如果你有 $\sqrt{1 - x^2}$ 并令 $x = \sin\theta$，根号消失了，变成 $\cos\theta$。

在用 $\theta$ 积分后，你用一个三角形：如果 $\sin\theta = x$ 而斜边是 1，邻边就是 $\sqrt{1 - x^2}$。这给了你 $\cos\theta$、$\tan\theta$ 等用 $x$ 表示的形式——你"撤销"替换。

</Porta>

<Porta nivel="15" titulo="给15岁青少年讲">

### 正弦和余弦的幂次

**情形 1（奇数指数）：**$\int \sin^3 x\, dx$。

提出一个 $\sin x\, dx$，转化其余部分：$\sin^2 x = 1 - \cos^2 x$。

$\int (1 - \cos^2 x)\sin x\, dx$。令 $u = \cos x$：$-\int(1 - u^2)\, du = -u + u^3/3 + C = -\cos x + \cos^3 x/3 + C$。

**情形 2（偶数指数）：**$\int \sin^2 x\, dx$。

使用半角：$\int \frac{1 - \cos 2x}{2}\, dx = \frac{x}{2} - \frac{\sin 2x}{4} + C$。

### 三角替换

**例子：**$\int \sqrt{1 - x^2}\, dx$。

令 $x = \sin\theta$，$dx = \cos\theta\, d\theta$，$\sqrt{1-x^2} = \cos\theta$。

积分变成 $\int \cos^2\theta\, d\theta = \theta/2 + \sin(2\theta)/4 + C$。

回去：$\theta = \arcsin x$，$\sin(2\theta) = 2\sin\theta\cos\theta = 2x\sqrt{1-x^2}$。

结果：$\dfrac{\arcsin x}{2} + \dfrac{x\sqrt{1-x^2}}{2} + C$。

**参考三角形：**总是画一个——这是将三角函数从 $\theta$ 转换回 $x$ 的关键。

</Porta>

<Porta nivel="25" titulo="给工程专业学生讲">

### 基本积分表的心算

- $\int \sin^2 x\, dx = (x - \sin x\cos x)/2 + C$。
- $\int \cos^2 x\, dx = (x + \sin x\cos x)/2 + C$。
- $\int \tan x\, dx = -\ln\lvert\cos x\rvert + C = \ln\lvert\sec x\rvert + C$。
- $\int \cot x\, dx = \ln\lvert\sin x\rvert + C$。
- $\int \sec x\, dx = \ln\lvert\sec x + \tan x\rvert + C$。
- $\int \csc x\, dx = -\ln\lvert\csc x + \cot x\rvert + C$。
- $\int \sec^2 x\, dx = \tan x + C$；$\int \csc^2 x\, dx = -\cot x + C$。
- $\int \sec x\tan x\, dx = \sec x + C$。

### 工程联系

- **正弦波的有效值：**$V_{rms} = V_0/\sqrt{2}$——通过 $\int_0^T \sin^2(\omega t)\, dt = T/2$。
- **Cauchy 分布：**$\int_{-\infty}^\infty 1/(\pi(1+x^2))\, dx = 1$——令 $x = \tan\theta$。
- **椭圆弧长：**$\int \sqrt{1 - k^2\sin^2\theta}\, d\theta$——椭圆积分，没有闭形式。
- **Fourier 系数：**$a_n = (1/\pi)\int_{-\pi}^\pi f(x)\cos(nx)\, dx$——对于三角函数 $f$，通过恒等式直接计算。

### Euler 与复数恒等式

正弦和余弦的幂次通过 Euler 可计算：$\sin x = (e^{ix} - e^{-ix})/(2i)$，$\cos x = (e^{ix} + e^{-ix})/2$。二项式展开加上复数指数的积分，然后取实部/虚部。

</Porta>

<Porta nivel="40" titulo="给资深专业人士讲">

### Weierstrass 替换（通用）

$t = \tan(x/2)$ 将任何关于 $\sin x$ 和 $\cos x$ 的有理函数变换为关于 $t$ 的有理函数：

$$\sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2\,dt}{1+t^2}.$$

结果积分通过部分分式求解。但结果可能比直接方法更复杂——当其他策略失败或在计算机代数系统中使用。

### 椭圆积分

$\int \sqrt{1 - k^2\sin^2\theta}\, d\theta = E(k)$ 和 $\int d\theta/\sqrt{1 - k^2\sin^2\theta} = K(k)$——Legendre 椭圆积分。对于 $k \neq 0$ 不是初等的。出现在椭圆弧长、精确摆锤、引力中。

### Fourier 分析

广义 Fourier 级数的系数 $a_n, b_n$ 通过三角积分计算。$f$ 的光滑性控制 $|a_n|$、$|b_n|$ 的衰减——Fourier 分析将三角积分与近似论联系起来。

### 微分几何

弧长 $L = \int \sqrt{1 + (f')^2}\, dx$ 当 $f' = \tan\theta$ 时涉及三角替换。曲率 $\kappa = |f''|/(1 + (f')^2)^{3/2}$ 在自然坐标中计算弧长时出现。多变量中的三角替换：球面和柱面坐标是三角 Jacobian。

</Porta>

<Porta nivel="pratica" titulo="实践应用">

**三角积分的方法：**

1. 查看 $\sin$ 和 $\cos$ 的指数。
2. 有一个奇数吗？保留该因子的一个副本及其 $dx$，转化其余部分。
3. 都是偶数？使用 $\sin^2 = (1 - \cos 2x)/2$ 和 $\cos^2 = (1 + \cos 2x)/2$。
4. 根号 $\sqrt{a^2 \pm x^2}$ 或 $\sqrt{x^2 - a^2}$？应用表格中的三角替换。
5. 在三角替换后，画参考三角形回到 $x$。
6. 通过求导验证。

### 圆的面积——标准验证

$A = 4\int_0^r \sqrt{r^2 - x^2}\, dx$。令 $x = r\sin\theta$：积分变成 $4r^2\int_0^{\pi/2}\cos^2\theta\, d\theta = 4r^2\cdot\pi/4 = \pi r^2$。

### 正弦波的有效值——电路

电压 $v(t) = V_0\sin(\omega t)$ 在周期 $T = 2\pi/\omega$ 内：

$$V_{rms} = \sqrt{\frac{1}{T}\int_0^T V_0^2\sin^2(\omega t)\, dt} = V_0\sqrt{\frac{1}{2}} = \frac{V_0}{\sqrt{2}} \approx 0{.}707\, V_0.$$

### 常见错误

- 忘记 Jacobian $dx \to a\cos\theta\, d\theta$（或 $a\sec^2\theta\, d\theta$）——导致缺少因子 $a$。
- 不用三角形从 $\theta$ 回到 $x$。
- 混淆 $\sin^2 x$（幂）与 $\sin(2x)$（二倍角）。
- 在 $x = a\sec\theta$ 中，忘记 $\theta$ 的正确分支。

</Porta>

## 已解决的例子

<Exemplo titulo="正弦奇数幂（基础）" numero="1">

**问题。**计算 $\int \sin^3 x\, dx$。

**策略。**奇数指数：保留 $\sin x\, dx$，通过 $\sin^2 = 1 - \cos^2$ 转化，令 $u = \cos x$。

**解。**

$\int \sin^3 x\, dx = \int \sin^2 x \cdot \sin x\, dx = \int (1 - \cos^2 x)\sin x\, dx$。

令 $u = \cos x$，$du = -\sin x\, dx$：

$-\int (1 - u^2)\, du = -u + u^3/3 + C = -\cos x + \frac{\cos^3 x}{3} + C$。

**验证。**求导：$\sin x - \cos^2 x\sin x = \sin x(1 - \cos^2 x) = \sin^3 x$。正确。

**来源。**[APEX Calculus §6.3, Example 6.3.1](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC。

</Exemplo>

<Exemplo titulo="偶数指数——半角（基础）" numero="2">

**问题。**计算 $\int \sin^2 x \cos^2 x\, dx$。

**策略。**都是偶数：使用 $\sin x\cos x = \sin(2x)/2$ 然后半角。

**解。**

$\sin^2 x\cos^2 x = (\sin x\cos x)^2 = \frac{\sin^2(2x)}{4} = \frac{1}{4}\cdot\frac{1 - \cos 4x}{2} = \frac{1 - \cos 4x}{8}$。

$$\int \sin^2 x\cos^2 x\, dx = \frac{x}{8} - \frac{\sin 4x}{32} + C.$$

**验证。**求导：$1/8 - \cos(4x)/8 = (1 - \cos 4x)/8 = \sin^2(2x)/4 = \sin^2 x\cos^2 x$。正确。

**来源。**[OpenStax Calculus Vol. 2, §3.2, Example 3.12](https://openstax.org/books/calculus-volume-2/pages/3-2-trigonometric-integrals) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="令 x = a sin θ 对于 √(a² − x²)（中级）" numero="3">

**问题。**计算 $\int \sqrt{4 - x^2}\, dx$。

**策略。**根号 $\sqrt{a^2 - x^2}$ 其中 $a = 2$：令 $x = 2\sin\theta$。

**解。**

$dx = 2\cos\theta\, d\theta$；$\sqrt{4 - x^2} = \sqrt{4 - 4\sin^2\theta} = 2\cos\theta$（其中 $\theta \in [-\pi/2, \pi/2]$）。

$\int 2\cos\theta \cdot 2\cos\theta\, d\theta = 4\int\cos^2\theta\, d\theta = 4\cdot\frac{\theta + \sin\theta\cos\theta}{2} = 2\theta + 2\sin\theta\cos\theta + C$。

参考三角形（$\sin\theta = x/2$，斜边 2，邻边 $\sqrt{4-x^2}$）：

$\theta = \arcsin(x/2)$；$\cos\theta = \sqrt{4-x^2}/2$。

结果：$2\arcsin(x/2) + 2\cdot\frac{x}{2}\cdot\frac{\sqrt{4-x^2}}{2} + C = 2\arcsin(x/2) + \frac{x\sqrt{4-x^2}}{2} + C$。

**验证。**求导（链式法则）：$\frac{2}{\sqrt{4-x^2}} + \frac{\sqrt{4-x^2} - x^2/\sqrt{4-x^2}}{2} = \frac{2}{\sqrt{4-x^2}} + \frac{4 - 2x^2}{2\sqrt{4-x^2}} = \sqrt{4-x^2}$。正确。

**来源。**[APEX Calculus §6.4, Example 6.4.2](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC。

</Exemplo>

<Exemplo titulo="令 x = a tan θ 对于 √(a² + x²)（中级）" numero="4">

**问题。**计算 $\int \dfrac{1}{\sqrt{1 + x^2}}\, dx$。

**策略。**根号 $\sqrt{a^2 + x^2}$ 其中 $a = 1$：令 $x = \tan\theta$。

**解。**

$dx = \sec^2\theta\, d\theta$；$\sqrt{1+x^2} = \sec\theta$。

$\int \frac{\sec^2\theta}{\sec\theta}\, d\theta = \int \sec\theta\, d\theta = \ln\lvert\sec\theta + \tan\theta\rvert + C$。

三角形（$\tan\theta = x$，斜边 $\sqrt{1+x^2}$）：$\sec\theta = \sqrt{1+x^2}$，$\tan\theta = x$。

结果：$\ln\lvert x + \sqrt{1+x^2}\rvert + C$（等价于 $\text{arcsinh}(x) + C$）。

**验证。**求导 $\ln(x + \sqrt{1+x^2})$：$\frac{1 + x/\sqrt{1+x^2}}{x + \sqrt{1+x^2}} = \frac{(\sqrt{1+x^2}+x)/\sqrt{1+x^2}}{x+\sqrt{1+x^2}} = \frac{1}{\sqrt{1+x^2}}$。正确。

**来源。**[OpenStax Calculus Vol. 2, §3.3, Example 3.15](https://openstax.org/books/calculus-volume-2/pages/3-3-trigonometric-substitution) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="约化公式与应用（挑战）" numero="5">

**问题。**推导约化公式 $\int \sin^n x\, dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n-1}{n}\int\sin^{n-2}x\, dx$ 并用它计算 $\int_0^{\pi/2}\sin^4 x\, dx$。

**策略。**通过分部积分推导；对 $n = 4$ 和 $n = 2$ 应用。

**解。**

**推导：**$u = \sin^{n-1}x$，$dv = \sin x\, dx$。$du = (n-1)\sin^{n-2}x\cos x\, dx$，$v = -\cos x$。

$\int\sin^n x\, dx = -\sin^{n-1}x\cos x + (n-1)\int\cos^2 x\sin^{n-2}x\, dx$。

代入 $\cos^2 x = 1 - \sin^2 x$：

$(n-1)\int(1 - \sin^2 x)\sin^{n-2}x\, dx = (n-1)\int\sin^{n-2}x\, dx - (n-1)\int\sin^n x\, dx$。

重新整理：$n\int\sin^n x\, dx = -\sin^{n-1}x\cos x + (n-1)\int\sin^{n-2}x\, dx$。除以 $n$。

**应用：**$n = 4$：$\int\sin^4 x\, dx = -\frac{\sin^3 x\cos x}{4} + \frac{3}{4}\int\sin^2 x\, dx$。

$\int\sin^2 x\, dx = x/2 - \sin(2x)/4$。

在 $[0, \pi/2]$ 上求值：$\int_0^{\pi/2}\sin^4 x\, dx = 0 + \frac{3}{4}\left[\frac{\pi}{4} - 0\right] = \frac{3\pi}{16}$。

**验证。**Wallis 公式：$\int_0^{\pi/2}\sin^4 x\, dx = \frac{3\cdot 1}{4\cdot 2}\cdot\frac{\pi}{2} = \frac{3\pi}{16}$。确认。

**来源。**[APEX Calculus §6.3, Theorem 6.3.1](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC。

</Exemplo>
