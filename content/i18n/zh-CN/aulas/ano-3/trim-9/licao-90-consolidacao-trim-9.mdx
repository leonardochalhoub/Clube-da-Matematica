### 积分计算的概念地图

<Definicao titulo="反导数和不定积分">

设 $f : I \to \mathbb{R}$ 在区间 $I$ 上连续。如果函数 $F : I \to \mathbb{R}$ 在 $I$ 上满足 $F'(x) = f(x)$ 对所有 $x \in I$ 成立，则称 $F$ 是 $f$ 的**反导数**。

> "如果 $F$ 是 $f$ 的反导数，则所有反导数的完整族为 $F(x) + C$，其中 $C$ 是任意常数。我们写作 $\int f(x)\,dx = F(x) + C$。" — [Active Calculus §4.1, p. 215](https://activecalculus.org/single/sec-4-4-FTC.html)

**不定积分**表示这个族：$\int f(x)\,dx = F(x) + C$。

</Definicao>

<Definicao titulo="定积分与黎曼和">

对于在 $[a, b]$ 上有界的 $f$，分割 $a = x_0 < x_1 < \cdots < x_n = b$ 和样本点 $x_i^* \in [x_{i-1}, x_i]$：

$$S_n = \sum_{i=1}^n f(x_i^*)\,\Delta x_i$$

> "从 $a$ 到 $b$ 的 $f(x)$ 的定积分是黎曼和的极限，当分割的范数趋于零时，只要该极限存在且对任意样本点的选择都相同。" — [OpenStax Calculus Vol. 2 §1.2](https://openstax.org/books/calculus-volume-2/pages/1-2-the-definite-integral)

</Definicao>

<Teorema titulo="微积分基本定理（FTC1 和 FTC2）">

设 $f$ 在 $[a, b]$ 上连续。

**FTC1.** 函数 $G(x) = \displaystyle\int_a^x f(t)\,dt$ 在 $(a, b)$ 上可导且 $G'(x) = f(x)$。

**FTC2.** 如果 $F$ 是 $f$ 在 $[a, b]$ 上的任意反导数，则

$$\int_a^b f(x)\,dx = F(b) - F(a).$$

**从 FTC1 推导 FTC2。** 由于 $G'(x) = f(x) = F'(x)$，我们有 $G(x) = F(x) + C$ 对某个常数 $C$。在 $x = a$ 处求值：$G(a) = 0$ 意味着 $C = -F(a)$。因此 $G(b) = F(b) - F(a)$。

</Teorema>

### 基本反导数的快速表格

<Definicao titulo="反导数表">

| $f(x)$ | $\int f(x)\,dx$ |
|---|---|
| $x^n$ ($n \neq -1$) | $\dfrac{x^{n+1}}{n+1} + C$ |
| $x^{-1}$ | $\ln\lvert x\rvert + C$ |
| $e^x$ | $e^x + C$ |
| $\sin x$ | $-\cos x + C$ |
| $\cos x$ | $\sin x + C$ |
| $\sec^2 x$ | $\tan x + C$ |
| $\dfrac{1}{\sqrt{1-x^2}}$ | $\arcsin x + C$ |
| $\dfrac{1}{1+x^2}$ | $\arctan x + C$ |

</Definicao>

<Insight>

**为什么常数 $+C$ 很重要？** 在不定积分中，$C$ 代表一整族函数——垂直平移的曲线。在初值问题中，$C$ 由问题的数据确定。在定积分（$F(b) - F(a)$）中，常数相消，所以 $C$ 消失。理解这一点可防止"忘记 $+C$"这种在定积分中的经典错误。

</Insight>

### 规范应用

<Definicao titulo="积分求面积和体积">

**两曲线间的面积。** 如果在 $[a, b]$ 上 $f(x) \geq g(x)$：

$$A = \int_a^b [f(x) - g(x)]\,dx$$

**圆盘/圆环法求体积。** 将 $y = f(x)$ 绕 $x$ 轴旋转：

$$V = \pi \int_a^b [f(x)]^2\,dx$$

对于圆环（$f$ 和 $g$ 之间的区域，$f \geq g \geq 0$）：

$$V = \pi \int_a^b \bigl([f(x)]^2 - [g(x)]^2\bigr)\,dx$$

**圆柱壳法求体积。** 将 $y = f(x) \geq 0$ 绕 $y$ 轴旋转：

$$V = 2\pi \int_a^b x f(x)\,dx$$

> "当区域围绕与积分轴平行的轴旋转时，圆柱壳法更可取。" — [APEX Calculus §7.3, p. 359](https://www.apexcalculus.com/)

</Definicao>

想象你想知道在图画中**涂了多少油漆**。你逐行查看：这一行涂了多少？那一行呢？逐行求和所有线条。

这就是**积分**做的事：把无穷多个很小的小块加起来得到总和。而**基本定理**是一个捷径，避免了无穷求和：只需看开始和结束。

你学会了用**不同形式的油漆**（不同的函数）做这件事，并发现总是用同样的技巧。

</Porta>

<Porta nivel="10" titulo="给10岁孩子的解释">

在这个三月份，你学到了**反导数**。导数"加速了"函数；积分"减速"回到原来的速度。

但当函数复杂时有一些技巧：

- **替换法**：你用另一个更简单的变量替换这个变量，就像换衣服去海滩一样。
- **分部法**：当两种不同类型的函数相乘时，你分别处理。
- **部分分式**：把一个大分数破成更小的块。
- **三角替换**：当有奇怪的平方根时，用角度替换。

最后你学会了用所有这些来**测量面积**和**计算旋转体体积**。

### 如何应对新的积分——方法

1. **仔细观察被积函数**。
2. **使用正式门的决策树识别模式**。
3. **应用对应的技术**。
4. 如果卡住了，尝试代数操作（配方、三角恒等式）。
5. **通过求导验证**结果。

### 快速识别的例子

- $\int x e^{x^2}\,dx$：$x^2$ 的导数是 $2x$—— 令 $u = x^2$。
- $\int x e^x\,dx$：多项式 $\times$ 指数的乘积，没有链式法则——分部法。
- $\int \dfrac{1}{x^2 - 1}\,dx$：有线性因子的有理函数——部分分式。
- $\int \sin^3 x\,dx$：正弦的奇数次幂——令 $u = \cos x$。
- $\int \sqrt{1 - x^2}\,dx$：$\sqrt{a^2 - x^2}$ 型根式——三角替换 $x = \sin\theta$。

### 考试会考什么

- **不定积分**：技术 + 常数 $+C$ + 验证。
- **定积分**：FTC2 与正确的极限；如果使用替换，也要替换极限。
- **两曲线间的面积**：找到交点，确定哪条曲线"在上面"。
- **体积**：根据旋转轴选择正确的方法（圆盘 vs 圆柱壳）。

<Insight>

**当在定积分中替换时，在 $u$ 中替换极限，不要在 $x$ 中。** 经典错误：计算 $a$ 和 $b$ 处的 $u$ 值但忘记用 $u$ 重写极限。如果 $u = g(x)$，新的极限是 $g(a)$ 和 $g(b)$——你永远不需要回到 $x$。

</Insight>

### 为什么手工技术在21世纪仍然重要

工业中99%的积分由CAS（SymPy、Mathematica、MATLAB）解决。但工程师需要手工计算是因为：

1. **理智性检验**：当CAS返回意外结果时，你需要知道它是否正确。
2. **有限元弱公式化**：在推导有限元方程时，分部法显式出现。
3. **变换**：Laplace $\mathcal{L}\{f\} = \int_0^\infty f(t)e^{-st}\,dt$ 和Fourier由积分定义——理解解析结构很重要。
4. **Taylor级数与误差**：Lagrange余项公式是一个积分。

### 与下一个模块的联系

- **ODEs**：每个可分离的ODE通过对两边积分来解决。一阶线性ODE需要积分因子 + 积分。
- **Laplace变换**：是分部法和部分分式封装在一个符号中。
- **连续概率**：$\mathbb{E}[X] = \int x f(x)\,dx$、方差、分布函数——全是积分。
- **量化金融**：连续流的现值 $= \int_0^T C(t)e^{-rt}\,dt$；Black-Scholes源于高斯积分。

### 生产最佳实践

```python
import sympy as sp
x = sp.Symbol('x')

# 符号——验证你的手工答案
F = sp.integrate(x * sp.exp(x), x)
print(F)  # (x - 1)*exp(x)

# 数值——当没有闭形式时
from scipy.integrate import quad
val, err = quad(lambda t: sp.exp(-t**2), 0, 1)
```

### 你在中学没见过的积分的层级

你学到的**黎曼积分**对分段连续函数来说足够。但数学已经超越了：

- **Lebesgue（1902）**：积分函数的不连续程度更高；Dirichlet函数（$\mathbf{1}_\mathbb{Q}$）是Lebesgue可积的（值为0）但不是黎曼可积。每个黎曼可积都是Lebesgue可积，但反之不是。
- **Henstock-Kurzweil**：将黎曼和Lebesgue都推广到某些无界变差函数。
- **随机积分（Itô）**：$\int_0^T f(t)\,dW_t$，其中 $W_t$ 是布朗运动——被积函数没有有界变差；黎曼定义崩溃。

### Feynman和在积分符号下微分

> "我花了好几天试图计算一个特定的积分...标准方法都不行。然后我记起了我从一本旧微积分书学到的方法——在积分符号下微分。" — R. Feynman

技术：如果 $I(\alpha) = \int_a^b f(x, \alpha)\,dx$，则 $I'(\alpha) = \int_a^b \partial_\alpha f\,dx$（在收敛假设下）。对于像 $\int_0^\infty e^{-x^2}\cos(2\alpha x)\,dx$ 这样的积分很强大。

### Gabriel喇叭的悖论

由 $y = 1/x$、$x \in [1, \infty)$ 生成的表面绕 $x$ 轴旋转有：
- **体积**有限：$V = \pi \int_1^\infty x^{-2}\,dx = \pi$。
- **表面积**无限：$A = 2\pi \int_1^\infty \frac{1}{x}\sqrt{1 + x^{-4}}\,dx = \infty$。

哲学结论：你可以用 $\pi$ 升油漆**填满**喇叭，但无法**涂色**它——表面积无限。表面的悖论通过认识到油漆层有厚度，最小厚度最终覆盖表面来解决。

### 在金融实践中

Black-Scholes期权定价（第119课）化为高斯积分。欧洲看涨期权的价格是：

$$C = S_0 N(d_1) - K e^{-rT} N(d_2), \quad N(x) = \int_{-\infty}^x \frac{e^{-t^2/2}}{\sqrt{2\pi}}\,dt$$

Myron Scholes和Robert Merton因这个公式获得了[1997年经济学诺贝尔奖](https://www.nobelprize.org/prizes/economic-sciences/1997/summary/)。Fischer Black在颁奖前去世。你在这里学到的高斯积分是该模型的真正脊梁。

### 连续流利息计算

一家巴西公司投资一个项目，产生连续现金流 $C(t) = 50\,000 + 8\,000t$ 雷亚尔每年（$t$ 以年计），折扣率 $r = 12\%$ 每年。在 $[0, 5]$ 上的现值：

$$\text{VP} = \int_0^5 C(t)\,e^{-0{,}12t}\,dt = \int_0^5 (50\,000 + 8\,000t)\,e^{-0{,}12t}\,dt$$

通过分部法解决：$\int t e^{-rt}\,dt = -\frac{t}{r}e^{-rt} - \frac{1}{r^2}e^{-rt} + C$。

### 圆柱锥形筒的体积

一个巴西筒有横截面由 $y = \sqrt{x}$ 在 $[0, 4]$ m 上定义，绕 $y$ 轴旋转。通过圆柱壳法的体积：

$$V = 2\pi \int_0^4 x \cdot \sqrt{x}\,dx = 2\pi \int_0^4 x^{3/2}\,dx = 2\pi \left[\frac{2}{5}x^{5/2}\right]_0^4 = 2\pi \cdot \frac{2}{5} \cdot 32 = \frac{128\pi}{5} \approx 80{,}4 \text{ m}^3$$

### 常见错误——提交前的检查清单

1. 忘记在不定积分中加 $+C$。
2. 在定积分中使用替换时没有替换极限。
3. 在分部法中混淆LIATE顺序（Log、Inverse trig、Alg、Trig、Exp）。
4. 分部分式前没有在 $\deg P \geq \deg Q$ 时除 $P/Q$。
5. 从三角替换 $\theta$ 回到 $x$ 时符号错误。
6. 圆柱壳体积中忘记 $2\pi$ 因子。
7. 计算面积前没有画出区域。

## 求解的例子

<Exemplo titulo="FTC2 应用与极限替换（应用）" numero="1">

**问题：** 计算 $\displaystyle\int_0^1 2x e^{x^2}\,dx$。

**策略：** 被积函数的形式为 $f(g(x)) \cdot g'(x)，其中 $g(x) = x^2$ 和 $g'(x) = 2x$。应用替换 $u = x^2$，直接在 $u$ 中替换积分极限。

**解：**

令 $u = x^2$，则 $du = 2x\,dx$。

极限：$x = 0 \Rightarrow u = 0$；$x = 1 \Rightarrow u = 1$。

$$\int_0^1 2x e^{x^2}\,dx = \int_0^1 e^u\,du = \bigl[e^u\bigr]_0^1 = e^1 - e^0 = e - 1$$

**验证：** $2x e^{x^2}$ 的反导数是 $e^{x^2}$（求导：$(e^{x^2})' = e^{x^2} \cdot 2x$ \checkmark）。求值：$e^{1^2} - e^{0^2} = e - 1 \approx 1{,}718$。

**来源。** [Active Calculus §5.3, Activity 5.3.2](https://activecalculus.org/single/sec-5-3-substitution.html) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="迭代分部积分——xe^x（中等）" numero="2">

**问题：** 计算 $\displaystyle\int x^2 e^x\,dx$。

**策略：** 多项式与指数的乘积，它们之间没有链式法则关系。使用分部积分配合LIATE：$u = x^2$（代数）和 $dv = e^x\,dx$（指数）。需要应用分部法两次。

**解：**

**第1次应用：** $u = x^2$、$du = 2x\,dx$；$dv = e^x\,dx$、$v = e^x$。

$$\int x^2 e^x\,dx = x^2 e^x - \int 2x e^x\,dx$$

**第2次应用**（对 $\int 2x e^x\,dx$）：$u = 2x$、$du = 2\,dx$；$dv = e^x\,dx$、$v = e^x$。

$$\int 2x e^x\,dx = 2x e^x - \int 2 e^x\,dx = 2x e^x - 2e^x$$

**最终结果：**

$$\int x^2 e^x\,dx = x^2 e^x - (2x e^x - 2e^x) + C = (x^2 - 2x + 2)e^x + C$$

**验证：** $\frac{d}{dx}\bigl[(x^2 - 2x + 2)e^x\bigr] = (2x - 2)e^x + (x^2 - 2x + 2)e^x = x^2 e^x$ \checkmark。

**来源。** [APEX Calculus §8.1, Example 8.1.4](https://www.apexcalculus.com/) — CC-BY-NC。

</Exemplo>

<Exemplo titulo="部分分式——分母有两个线性因子（中等）" numero="3">

**问题：** 计算 $\displaystyle\int \frac{1}{x^2 - 1}\,dx$。

**策略：** 被积函数是有理函数，$\deg(\text{分子}) < \deg(\text{分母})$。分解分母：$x^2 - 1 = (x-1)(x+1)$。分解成部分分式。

**解：**

$$\frac{1}{(x-1)(x+1)} = \frac{A}{x-1} + \frac{B}{x+1}$$

两边乘以 $(x-1)(x+1)$：$1 = A(x+1) + B(x-1)$。

$x = 1$：$1 = 2A \Rightarrow A = 1/2$。
$x = -1$：$1 = -2B \Rightarrow B = -1/2$。

$$\int \frac{1}{x^2 - 1}\,dx = \int \frac{1/2}{x-1}\,dx + \int \frac{-1/2}{x+1}\,dx = \frac{1}{2}\ln\lvert x - 1\rvert - \frac{1}{2}\ln\lvert x + 1\rvert + C$$

$$= \frac{1}{2}\ln\left\lvert\frac{x-1}{x+1}\right\rvert + C$$

**验证：** 求导：$\frac{1}{2} \cdot \frac{(x+1) - (x-1)}{(x-1)(x+1)} = \frac{1}{2} \cdot \frac{2}{x^2-1} = \frac{1}{x^2-1}$ \checkmark。

**来源。** [OpenStax Calculus Vol. 2 §3.4, Example 3.4.1](https://openstax.org/books/calculus-volume-2/pages/3-4-partial-fractions) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="抛物线与直线间的面积（应用）" numero="4">

**问题：** 计算由 $f(x) = x^2$ 和 $g(x) = x + 2$ 围成的区域的面积。

**策略：** 找到交点（$f = g$ 的地方），确定每个子区间中哪条曲线在上面，并积分差。

**解：**

**交点：** $x^2 = x + 2 \Rightarrow x^2 - x - 2 = 0 \Rightarrow (x-2)(x+1) = 0 \Rightarrow x = -1$ 或 $x = 2$。

**哪条在上面？** 对于 $x \in (-1, 2)$：$g(0) = 2 > f(0) = 0$，所以 $g \geq f$。

$$A = \int_{-1}^2 [g(x) - f(x)]\,dx = \int_{-1}^2 (x + 2 - x^2)\,dx$$

$$= \left[\frac{x^2}{2} + 2x - \frac{x^3}{3}\right]_{-1}^2 = \left(2 + 4 - \frac{8}{3}\right) - \left(\frac{1}{2} - 2 + \frac{1}{3}\right) = \frac{10}{3} - \left(-\frac{7}{6}\right) = \frac{10}{3} + \frac{7}{6} = \frac{27}{6} = \frac{9}{2}$$

**验证：** $9/2 = 4{,}5$ 平方单位。抛物线和直线形成一个水滴形区域——对于长度为3的区间这个结果很合理。

**来源。** [Active Calculus §6.1, Activity 6.1.2](https://activecalculus.org/single/sec-6-1-area.html) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="圆柱壳法求体积（高级）" numero="5">

**问题：** 计算由 $y = \ln x$、$y = 0$ 和 $x = e$ 围成的区域绕 $y$ 轴旋转生成的立体体积。

**策略：** 该区域在 $y$ 轴右侧。绕 $y$ 轴旋转，并在 $x$ 中积分，建议使用圆柱壳法：$V = 2\pi \int_a^b x f(x)\,dx$。

**解：**

立体从 $x = 1$（因为 $\ln 1 = 0$）到 $x = e$。

$$V = 2\pi \int_1^e x \ln x\,dx$$

应用分部积分：$u = \ln x$、$dv = x\,dx$；$du = dx/x$、$v = x^2/2$。

$$\int x \ln x\,dx = \frac{x^2}{2}\ln x - \int \frac{x^2}{2} \cdot \frac{1}{x}\,dx = \frac{x^2}{2}\ln x - \frac{x^2}{4} + C$$

求值：

$$\int_1^e x \ln x\,dx = \left[\frac{x^2}{2}\ln x - \frac{x^2}{4}\right]_1^e = \left(\frac{e^2}{2} - \frac{e^2}{4}\right) - \left(0 - \frac{1}{4}\right) = \frac{e^2}{4} + \frac{1}{4} = \frac{e^2 + 1}{4}$$

$$V = 2\pi \cdot \frac{e^2 + 1}{4} = \frac{\pi(e^2 + 1)}{2} \approx \frac{\pi \cdot 8{,}389}{2} \approx 13{,}18$$

**验证：** 对于 $x \in [1, e]$，壳的半径为 $x$，高为 $\ln x$。结果具有正确的维度（单位³）。$\approx 13{,}18$ 对该区域是合理的。

**来源。** [OpenStax Calculus Vol. 2 §2.3, Example 2.3.4](https://openstax.org/books/calculus-volume-2/pages/2-3-volumes-of-revolution-cylindrical-shells) — CC-BY-NC-SA。

</Exemplo>
