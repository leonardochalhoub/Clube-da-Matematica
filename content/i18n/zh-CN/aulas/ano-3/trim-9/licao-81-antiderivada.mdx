### 反导数和不定积分

<Definicao titulo="反导数">

设 $f: I \to \mathbb{R}$ 定义在区间 $I$ 上。函数 $F: I \to \mathbb{R}$ 称为 $f$ 在 $I$ 上的**反导数**（或原函数）如果 $F'(x) = f(x)$ 对所有 $x \in I$ 成立。

$f$ 的**不定积分**是所有反导数的族，记为：

$$\int f(x)\, dx = F(x) + C, \quad C \in \mathbb{R}$$

</Definicao>

> "如果 $F$ 是函数 $f$ 在区间 $I$ 上的一个反导数，那么 $f$ 在 $I$ 上最一般的反导数是 $F(x) + C$，其中 $C$ 是任意常数。" — [OpenStax Calculus Vol. 1, §4.10](https://openstax.org/books/calculus-volume-1/pages/4-10-antiderivatives)

<Definicao titulo="为什么有常数 C？">

如果 $F' = f$，那么对任意 $C \in \mathbb{R}$，有 $(F + C)' = F' + 0 = f$。因此 $F$ 的任何竖直平移也是反导数。

**推论（平均值定理的结果）：** 在区间 $I$ 上，如果 $F$ 和 $G$ 都是 $f$ 的反导数，那么 $F - G$ 在 $I$ 上是常数。因此反导数是**相差常数意义下唯一的**。

</Definicao>

### 反导数的线性性

<Teorema titulo="不定积分的线性性">

对于在区间 $I$ 上有反导数的函数 $f$、$g$ 和实数标量 $\alpha, \beta \in \mathbb{R}$：

$$\int (\alpha f(x) + \beta g(x))\, dx = \alpha \int f(x)\, dx + \beta \int g(x)\, dx$$

</Teorema>

> "积分的求和规则和常数倍规则表明，任何函数线性组合的反导数就是反导数的线性组合。" — [APEX Calculus, §5.1](https://www.apexcalculus.com/)

<Insight>

**乘积不满足分配律：** $\int f(x) g(x)\, dx \neq \left(\int f\right)\left(\int g\right)$ 一般成立。对于乘积的积分，技巧包括分部积分（第 85 课）或替换法（第 84 课）。

</Insight>

</Porta>

<Porta nivel="5" titulo="对 5 岁孩子">

你知道**加法**和**减法**吗？减法可以撤销加法：如果你得到 3 颗糖，后来失去 3 颗，回到了原来的地方。

**导数**就像数你每分钟赚取的糖果数。**反导数**朝相反方向走：如果我告诉你你每分钟赚了多少，你就能算出你有多少糖果。

但有个问题：我不知道你是从 0 颗开始还是从 100 颗开始的。所以我们写"+ C"——C 保守了这个秘密。

</Porta>

<Porta nivel="10" titulo="对 10 岁孩子">

汽车的速度表每时刻告诉你**速度**。**反导数**做相反的事：给定速度，发现**位置**。

如果一辆车以 $v(t) = 2t$ 米每秒行驶，$t$ 秒后它在哪里？$2t$ 的反导数是 $t^2$。所以位置 $= t^2 + C$，其中 $C$ 是我们需要单独知道的初始位置。

**多项式的技巧**：$\int x^n$ 变成 $x^{n+1}/(n+1)$。指数加 1 然后除以新指数。

例子：$\int x^2\, dx = x^3/3$。$\int x^5\, dx = x^6/6$。最后总是加上 $+ C$。

</Porta>

<Porta nivel="15" titulo="对 15 岁少年">

反导数是"**撤销导数**"。如果 $f(x) = 2x$，哪个函数的导数等于 $2x$？答案：$F(x) = x^2$，因为 $(x^2)' = 2x$。

但 $F(x) = x^2 + 5$ 也工作。还有 $x^2 - 17$。任何加上的常数都可以。所以我们写：

$$\int 2x\, dx = x^2 + C$$

$C$ 是**积分常数**——承认我们不知道"起始点"。

**如何使用表：**

| 我要积分 | 规则 | 结果 |
|---|---|---|
| $x^3$ | 幂：加 1，除 | $x^4/4 + C$ |
| $\sin x$ | 表直接查 | $-\cos x + C$ |
| $e^x$ | 表直接查 | $e^x + C$ |
| $3x^2 - 4\sin x$ | 线性性 | $x^3 + 4\cos x + C$ |

**必须验证：** 对结果求导。如果得到 $f(x)$，就正确了。这个习惯在考试前发现错误。

<Insight>

基本定理（第 83 课）会告诉你反导数是计算面积和累积的关键。你现在学反导数是因为它是基本定理将使用的工具。

</Insight>

</Porta>

<Porta nivel="25" titulo="对工程学生">

反导数在**操作上**是导数的反面，但在**计算上**困难得多。有些初等函数的反导数不是初等的：

- $\int e^{-x^2}\, dx$ — 误差函数（高斯），在概率中很基础。
- $\int \sin(x^2)\, dx$ — Fresnel 函数，出现在光学和衍射中。
- $\int \frac{\sin x}{x}\, dx$ — 正弦积分 $\text{Si}(x)$，在控制理论中。

**Liouville（1835）** 刻画了哪些函数有初等反导数。Risch（1969）将这个结果转换为可判定的算法——在 Mathematica 和 SymPy 中实现。

### 积分的顺序策略

面对 $\int f\, dx$：

1. **表直接查？** 毫不犹豫地使用。
2. **线性性？** 分解成和/标量。
3. **替换** $u = g(x)$？链式法则的逆（第 84 课）。
4. **分部积分？** 乘积法则的逆（第 85 课）。
5. **部分分式**（第 86 课）如果有可因式分解的有理分母。
6. **三角恒等式**（第 87 课）如果有正弦/余弦的幂。
7. **没有初等反导数？** 泰勒级数或数值求积。

### 初值条件确定 C

在实践中（微分方程、物理、金融），$C$ 由初值条件确定。如果 $F'(t) = f(t)$ 且已知 $F(0) = F_0$，则 $C = F_0 - F(0)\big|_{C=0}$。没有初值条件，$C$ 保持符号形式。

> "找反导数的问题不仅对于计算基本定理的右侧很重要，而且对于解微分方程也很重要。" — [APEX Calculus, §5.1](https://www.apexcalculus.com/)

</Porta>

<Porta nivel="40" titulo="对资深专业人士">

反导数的结构有相当的代数和分析深度。

### Liouville 定理和 Risch 算法

**Liouville 定理**指出：如果 $f$ 是初等的且 $\int f$ 是初等的，那么 $\int f = v_0 + \sum c_i \ln v_i$，其中 $v_0, v_i$ 在相同的函数体中是初等的。Risch（1969）将这转化为**可判定算法**——给定初等函数，算法判定是否存在初等反导数，如果存在则计算它。Mathematica/Maple 中的实现是任何现代 CAS 的引擎。

### Lebesgue 积分和推广

在实分析的背景下，对于 $f \in L^1_{\text{loc}}(I)$（局部可积），$F(x) = \int_a^x f(t)\, dt$ 是**绝对连续**的且 $F' = f$ 几乎处处成立（Lebesgue）。Henstock-Kurzweil 理论（规范积分）更进一步，积分任何可导函数的导数。

### 在微分方程和信号中的角色

- **可分离微分方程**：$dy/dx = g(x) h(y)$ 简化到两个反导数。
- **Laplace 变换**：$\mathcal{L}\{f\}(s) = \int_0^\infty e^{-st} f(t)\, dt$ — 时域中的反导数。
- **PID 控制**：积分部分 $I(t) = \int_0^t e(\tau)\, d\tau$ 消除稳态误差。
- **量子**：Feynman 路径积分是路径积分——无限维空间中的函数反导数。

</Porta>

<Porta nivel="pratica" titulo="实践应用——巴西数据">

### 从加速度得到车辆位置

一辆车以 $a(t) = 3\, \text{m/s}^2$ 均加速。初速度：$v(0) = 0$。初始位置：$x(0) = 0$。

**速度：** $v(t) = \int a(t)\, dt = 3t + C_1$。从 $v(0) = 0$：$C_1 = 0$，所以 $v(t) = 3t$。

**位置：** $x(t) = \int v(t)\, dt = \int 3t\, dt = \frac{3}{2}t^2 + C_2$。从 $x(0) = 0$：$C_2 = 0$。

在 $t = 10\text{ s}$ 时的位置：$x(10) = \frac{3}{2} \cdot 100 = 150\text{ m}$。

### 投资组合增长

假设投资组合的月增长率（单位：巴西雷亚尔/月）是 $f(t) = 500 + 20t$（加速增长）。从第 0 月的 R$ 10.000（巴西雷亚尔）开始：

$$V(t) = \int (500 + 20t)\, dt = 500t + 10t^2 + C.$$

从 $V(0) = 10.000$：$C = 10.000$。12 个月后：$V(12) = 500(12) + 10(144) + 10.000 = 6.000 + 1.440 + 10.000 = \text{R\$ }17.440$。

## 已解决的例子

<Exemplo numero="1" titulo="幂规则和线性性（基础）">

**问题。** 计算 $\displaystyle\int (4x^3 - 6x + 5)\, dx$。

**策略。** 应用线性性：按幂规则 $\int x^n\, dx = x^{n+1}/(n+1) + C$ 单独积分每一项。

**求解。**
$$\int (4x^3 - 6x + 5)\, dx = 4 \cdot \frac{x^4}{4} - 6 \cdot \frac{x^2}{2} + 5x + C = x^4 - 3x^2 + 5x + C.$$

**验证。** $(x^4 - 3x^2 + 5x + C)' = 4x^3 - 6x + 5$。验证无误。

**来源。** [APEX Calculus, §5.1, 例 5.1.3](https://www.apexcalculus.com/) — CC-BY-NC。

</Exemplo>

<Exemplo numero="2" titulo="三角函数和指数（基础）">

**问题。** 计算 $\displaystyle\int (3\cos x - 2e^x + \sec^2 x)\, dx$。

**策略。** 每部分的表直接查；线性性保证我们可以求和反导数。

**求解。**
$$\int 3\cos x\, dx - 2\int e^x\, dx + \int \sec^2 x\, dx = 3\sin x - 2e^x + \tan x + C.$$

**验证。** $(3\sin x - 2e^x + \tan x + C)' = 3\cos x - 2e^x + \sec^2 x$。验证无误。

**来源。** [OpenStax Calculus Vol. 1, §4.10, 例 4.55](https://openstax.org/books/calculus-volume-1/pages/4-10-antiderivatives) — CC-BY-NC-SA。

</Exemplo>

<Exemplo numero="3" titulo="初值条件确定 C（中等）">

**问题。** 求 $F(x)$ 使得 $F'(x) = x^2 - 4x + 1$ 且 $F(2) = -3$。

**策略。** 积分得到一般族；用条件 $F(2) = -3$ 确定 $C$。

**求解。**
$$F(x) = \int (x^2 - 4x + 1)\, dx = \frac{x^3}{3} - 2x^2 + x + C.$$

初值条件：$F(2) = \frac{8}{3} - 8 + 2 + C = -3$，所以 $C = -3 - \frac{8}{3} + 6 = 3 - \frac{8}{3} = \frac{1}{3}$。

$$F(x) = \frac{x^3}{3} - 2x^2 + x + \frac{1}{3}.$$

**验证。** $F'(x) = x^2 - 4x + 1$ 且 $F(2) = \frac{8}{3} - 8 + 2 + \frac{1}{3} = 3 - 8 + 2 = -3$。验证无误。

**来源。** [OpenStax Calculus Vol. 1, §4.10, 习题 4.284](https://openstax.org/books/calculus-volume-1/pages/4-10-antiderivatives) — CC-BY-NC-SA。

</Exemplo>

<Exemplo numero="4" titulo="代数展开后再积分（中等）">

**问题。** 计算 $\displaystyle\int x(3x - 1)^2\, dx$。

**策略。** 展开平方并分配然后应用幂规则。（替换可以工作，但展开在这里更直接。）

**求解。**
$(3x-1)^2 = 9x^2 - 6x + 1$，所以 $x(3x-1)^2 = 9x^3 - 6x^2 + x$。

$$\int (9x^3 - 6x^2 + x)\, dx = \frac{9x^4}{4} - 2x^3 + \frac{x^2}{2} + C.$$

**验证。** 求导：$9x^3 - 6x^2 + x = x(9x^2 - 6x + 1) = x(3x-1)^2$。验证无误。

**来源。** [APEX Calculus, §5.1, 习题 5.1.15](https://www.apexcalculus.com/) — CC-BY-NC。

</Exemplo>

<Exemplo numero="5" titulo="在积分前重写分数（挑战）">

**问题。** 计算 $\displaystyle\int \frac{x^3 + 2x}{x}\, dx$，其中 $x > 0$。

**策略。** 在积分前逐项简化分数。$1/x$ 的积分使用表中的 $\ln|x|$ 项。

**求解。**

$$\frac{x^3 + 2x}{x} = x^2 + 2, \quad x > 0.$$

$$\int (x^2 + 2)\, dx = \frac{x^3}{3} + 2x + C.$$

**验证。** $\left(\frac{x^3}{3} + 2x\right)' = x^2 + 2 = \frac{x^3 + 2x}{x}$ 对 $x \neq 0$。验证无误。

**来源。** [Active Calculus, §4.1, 预览活动 4.1](https://activecalculus.org/single/sec-4-1-velocity-distance.html) — CC-BY-NC-SA。

</Exemplo>
