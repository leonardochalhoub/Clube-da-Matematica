### 公式推导

<Definicao titulo="分部积分法">

设 $u(x)$ 和 $v(x)$ 在 $[a, b]$ 上可导，且 $u'$ 和 $v'$ 连续。乘积求导法则告诉我们：

$$\frac{d}{dx}[u(x)v(x)] = u'(x)v(x) + u(x)v'(x).$$

两边从 $a$ 到 $b$ 积分，应用微积分基本定理：

$$[u(x)v(x)]_a^b = \int_a^b u'(x)v(x)\, dx + \int_a^b u(x)v'(x)\, dx.$$

重新整理：

$$\int_a^b u(x)v'(x)\, dx = [u(x)v(x)]_a^b - \int_a^b v(x)u'(x)\, dx.$$

用微分记号（$dv = v'(x)\, dx$，$du = u'(x)\, dx$）：

<Equation explicacao="分部积分公式——不定积分形式。" latex="\int u\, dv = uv - \int v\, du." />

</Definicao>

> "分部积分公式来自乘积的求导法则：如果 $u$ 和 $v$ 都是 $x$ 的函数，那么 $(uv)' = u'v + uv'$。两边积分并重新整理得到 $\int u\, dv = uv - \int v\, du$。" — [Active Calculus §5.4](https://activecalculus.org/single/sec-5-4-parts.html)

### LIATE 启发式规则

<Definicao titulo="选择 u 的优先级（LIATE）">

为了选择 $u$（将被求导的函数），按以下顺序优先选择：

1. **L**ogarithmic（对数函数）：$\ln x$、$\log_a x$
2. **I**nverse trigonometric（反三角函数）：$\arctan x$、$\arcsin x$、$\arccos x$
3. **A**lgebraic（代数函数）：$x^n$、多项式
4. **T**rigonometric（三角函数）：$\sin x$、$\cos x$、$\tan x$
5. **E**xponential（指数函数）：$e^x$、$a^x$

被积函数中最先出现的类别对应的函数成为 $u$。其余部分是 $dv$。

**原理：** 对数和反三角函数的导数会化简（从超越函数变为代数函数）；指数和三角函数求导后会重复出现。因此，$u$ 应该是求导时"改善"的因子。

</Definicao>

> "选择分部积分中 $u$ 的一个有用启发式方法是首字母缩略词 LIATE，代表对数函数、反三角函数、代数函数、三角函数和指数函数。" — [OpenStax Calculus Vol. 2, §3.1](https://openstax.org/books/calculus-volume-2/pages/3-1-integration-by-parts)

<Teorema titulo="技巧：回到自身的积分">

对于 $I = \int e^x \cos x\, dx$：

应用分部积分，$u = \cos x$、$dv = e^x dx$：$I = e^x \cos x + \int e^x \sin x\, dx$。

再次应用分部积分，$u = \sin x$：$I = e^x \cos x + e^x \sin x - I$。

因此 $2I = e^x(\cos x + \sin x)$，故：

<Equation explicacao="技巧使用时的结果，该积分在两次应用后重新出现。" latex="I = \frac{e^x(\sin x + \cos x)}{2} + C." />

**条件：** 当第二次应用导致原积分以相同符号重新出现时（而不是相反符号，会产生零恒等式），此技巧有效。

</Teorema>

<Insight>

**分部积分是微分的转移。** 恒等式 $\int u\, dv = uv - \int v\, du$ 将微分运算从一个因子转移到另一个。在带零边界条件的函数空间中，这使 $d/dx$ 在 $L^2$ 中反对称——这是偏微分方程弱型公式的基础。

</Insight>

想象两个朋友一起背着一个沉重的背包。一个背一段路，然后传给另一个。

分部积分就是这样：你有一个困难的计算。你"转移"其中一部分到另一边，计算变简单了。当另一边背了一段后，你可以完成计算。

<Porta nivel="10" titulo="给 10 岁孩子的解释">

还记得乘积的导数有两项吗？如果 $f = u \cdot v$，那么 $f' = u'v + uv'$。

现在想象你对两边积分：

$uv = \int u'v\, dx + \int uv'\, dx$

重新整理：$\int uv'\, dx = uv - \int u'v\, dx$。

**实际翻译：** 当你有一个乘积要积分时，你可以把它换成 $uv$ 减去**另一个积分**。如果新积分更简单，你就赢了。

**例子**：$\int x \sin x\, dx$。$x$ 是代数的（求导时化简：变成 $1$）。$\sin x$ 的原函数是 $-\cos x$。

所以 $u = x$、$dv = \sin x\, dx$。应用公式后：$-x\cos x + \int \cos x\, dx = -x\cos x + \sin x + C$。

**LIATE 技巧**：对数、反三角、代数、三角、指数中——最先出现的函数成为 $u$。

</Porta>

<Porta nivel="15" titulo="给 15 岁青少年的解释">

公式是 $\int u\, dv = uv - \int v\, du$。

**5 步秘诀：**

1. 在被积函数中识别乘积。
2. 使用 **LIATE** 选择 $u$（对数 > 反三角 > 代数 > 三角 > 指数）。
3. 其余部分是 $dv$。计算 $du = u'\, dx$ 和 $v = \int dv$。
4. 应用公式。
5. 求解 $\int v\, du$——应该更简单。

**三个基本模式：**

**1.** $\int x e^x\, dx$：$u = x$（代数），$dv = e^x dx$。结果：$xe^x - e^x + C$。

**2.** $\int \ln x\, dx$：$u = \ln x$（对数），$dv = dx$。那么 $du = dx/x$、$v = x$。结果：$x \ln x - x + C$。

**3.** $\int e^x \cos x\, dx$：应用两次——积分会回来。隔离：结果 $e^x(\sin x + \cos x)/2 + C$。

**何时不用分部积分**：如果看到 $\int x e^{x^2}\, dx$，这是替换（链式法则伪装），不是分部积分。

</Porta>

分部积分系统地解决**多项式×（指数、三角、对数、反三角）** 这一类。

### 模式表

| 积分 | $u$ | 注释 |
|---|---|---|
| $\int x^n e^{ax}\, dx$ | $x^n$ | 应用 $n$ 次；表格法加速 |
| $\int x^n \sin(ax)\, dx$ | $x^n$ | 同样 |
| $\int x^n \ln x\, dx$ | $\ln x$ | 一次应用；结果清晰 |
| $\int e^{ax}\cos(bx)\, dx$ | 任选 | 两次应用 + 隔离 $I$ |

| $\int \arcsin x\, dx$ | $\arcsin x$ | $dv = dx$；$v = x$；再替换 |

### 基本联系

- **拉普拉斯变换**：$\mathcal{L}\{t\} = \int_0^\infty t e^{-st}\, dt = 1/s^2$ ——通过分部积分计算。
- **Gamma 函数**：$\Gamma(n+1) = n \Gamma(n)$ ——通过分部积分及 $\Gamma(1) = 1$ 证明。
- **傅里叶系数**：$a_n = (1/\pi)\int_{-\pi}^\pi f(x)\cos(nx)\, dx$ ——当 $f$ 多项式时，分部积分简化。
- **$t^n$ 的拉普拉斯变换**：$n!/(s^{n+1})$ ——迭代分部积分。

### 详细表格法

对于 $\int x^3 e^x\, dx$：

| D | I | 符号 |
|---|---|---|
| $x^3$ | $e^x$ | + |
| $3x^2$ | $e^x$ | − |
| $6x$ | $e^x$ | + |
| $6$ | $e^x$ | − |
| $0$ | — | — |

结果：$x^3 e^x - 3x^2 e^x + 6x e^x - 6e^x + C = e^x(x^3 - 3x^2 + 6x - 6) + C$。

### 递推公式

通过分部积分：$\int \sin^n x\, dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n-1}{n}\int \sin^{n-2}x\, dx$。

$\cos^n$、$\sec^n$、$\csc^n$ 类似。

### 推广：格林恒等式

在 $n$ 维中，分部积分是：

$$\int_\Omega u\, \nabla \cdot \mathbf{F}\, dV = \int_{\partial\Omega} u\, \mathbf{F} \cdot \mathbf{n}\, dS - \int_\Omega \nabla u \cdot \mathbf{F}\, dV.$$

取 $\mathbf{F} = \nabla v$：第一格林恒等式 $\int u\, \Delta v = \oint u\, \partial_n v - \int \nabla u \cdot \nabla v$。

### 有限元法中的弱型公式

泊松方程 $-\Delta u = f$ 在 $\Omega$ 中，$u|_{\partial\Omega} = 0$ ——分部积分将导数转移到试探函数 $v \in H^1_0$：

$$\int_\Omega \nabla u \cdot \nabla v\, dV = \int_\Omega f v\, dV \quad \forall v \in H^1_0(\Omega).$$

没有通过分部积分的此转移，就不会有变分公式。FEniCS、Firedrake、deal.II 都符号性地实现了这一点。

### 微分算子的伴随

在 $L^2$ 中（零边界条件）：$\langle Du, v\rangle = -\langle u, Dv\rangle$ ——$D = d/dx$ 反对称。推广地，$L = \sum a_k \partial^k$ 的形式伴随是 $L^* = \sum (-1)^k \partial^k (a_k \cdot)$。分部积分证明了这一点。

### 傅里叶分析和光滑性

迭代分部积分证明：$|\hat{f}(n)| = O(n^{-k})$ 当且仅当 $f \in C^{k-1}$ 且 $f^{(k)} \in L^1$。物理空间中的光滑性与频域衰减的联系——小波和压缩理论的核心。

### 量子力学

动量算子的厄米性 $\hat{p} = -i\hbar\, \partial_x$ 要求 $\langle \psi_1 | \hat{p} \psi_2 \rangle = \langle \hat{p}\psi_1 | \psi_2 \rangle$，通过分部积分及边界条件（波函数在无穷处衰减）证明。

</Porta>

<Porta nivel="pratica" titulo="实际应用">

**完整秘诀：**

1. 被积函数有乘积吗？如果是，用分部积分。如果否，考虑替换。
2. 应用 **LIATE** 确定 $u$。
3. $du = u'\, dx$、$v = \int dv$。
4. $uv - \int v\, du$。
5. 如果 $\int v\, du$ 仍是乘积：迭代（或用表格 DI）。
6. 如果积分回来了：隔离 $I$。
7. 检查：求导结果——应该重现被积函数。

### 巴西应用

**持续增长流的现值**：年收入 $C(t) = t$ 千雷亚尔，利率 $r = 10\%$，期间 $T = 5$ 年：

$$VP = \int_0^5 t \cdot e^{-0.1 t}\, dt.$$

用分部积分：$u = t$、$dv = e^{-0.1t}\, dt$。结果：约 9.48 千雷亚尔。

**指数型随机变量的期望**：$E[X] = \int_0^\infty x \lambda e^{-\lambda x}\, dx = 1/\lambda$ ——分部积分，$u = x$。

**电路 ODE 的拉普拉斯公式**：$\mathcal{L}\{t^n\} = n!/(s^{n+1})$ ——迭代分部积分。

### 常见错误

- 忘记 $-\int v\, du$ 中的负号。
- 选择了使问题复杂化的 $u$（反 LIATE）。
- 当多项式次数 > 1 时没有迭代。
- 在不定积分中忘记 $+ C$。

## 已解决的例题

<Exemplo titulo="标准积分 xeˣ（基础）" numero="1">

**问题。** 计算 $\int x e^x\, dx$。

**策略。** LIATE：$x$ 是代数的，$e^x$ 是指数的。$u = x$（求导化简），$dv = e^x\, dx$。

**解。**

$du = dx$、$v = e^x$。

$$\int x e^x\, dx = x e^x - \int e^x\, dx = x e^x - e^x + C = e^x(x - 1) + C.$$

**验证。** 对 $e^x(x-1) + C$ 求导：乘积法则得 $e^x(x-1) + e^x = xe^x$。正确。

**来源。** [Active Calculus §5.4, Activity 5.4.2](https://activecalculus.org/single/sec-5-4-parts.html) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="ln x 的积分（技巧 dv = dx）" numero="2">

**问题。** 计算 $\int \ln x\, dx$。

**策略。** 对数独立：$u = \ln x$、$dv = dx$（非显而易见但正确的选择）。

**解。**

$du = dx/x$、$v = x$。

$$\int \ln x\, dx = x \ln x - \int x \cdot \frac{1}{x}\, dx = x \ln x - \int 1\, dx = x \ln x - x + C.$$

**验证。** 对 $x \ln x - x$ 求导：$\ln x + x \cdot (1/x) - 1 = \ln x + 1 - 1 = \ln x$。正确。

**来源。** [APEX Calculus §6.2, Example 6.2.2](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC。

</Exemplo>

<Exemplo titulo="多项式 x² 用表格 DI（中等）" numero="3">

**问题。** 用表格法计算 $\int x^2 e^x\, dx$。

**策略。** 2 次多项式×指数：DI 方法（对 $x^2$ 求导至零，对 $e^x$ 反复积分）。

**解。**

| D | I | 符号 |
|---|---|---|
| $x^2$ | $e^x$ | + |
| $2x$ | $e^x$ | − |
| $2$ | $e^x$ | + |
| $0$ | — | — |

按对角线求和，符号交替：

$$\int x^2 e^x\, dx = x^2 e^x - 2x e^x + 2e^x + C = e^x(x^2 - 2x + 2) + C.$$

**验证。** 对 $e^x(x^2 - 2x + 2)$ 求导：$e^x(x^2 - 2x + 2) + e^x(2x - 2) = e^x x^2$。正确。

**来源。** [APEX Calculus §6.2, Example 6.2.4](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC。

</Exemplo>

<Exemplo titulo="技巧：回到自身的积分（eˣ cos x）" numero="4">

**问题。** 计算 $I = \int e^x \cos x\, dx$。

**策略。** 两次分部积分——积分会重新出现。隔离 $I$。

**解。**

第 1 次应用：$u = \cos x$、$dv = e^x\, dx$、$du = -\sin x\, dx$、$v = e^x$。

$$I = e^x \cos x + \int e^x \sin x\, dx.$$

第 2 次应用：$u = \sin x$、$dv = e^x\, dx$、$du = \cos x\, dx$、$v = e^x$。

$$I = e^x \cos x + e^x \sin x - \int e^x \cos x\, dx = e^x \cos x + e^x \sin x - I.$$

因此 $2I = e^x(\cos x + \sin x)$：

$$I = \frac{e^x(\sin x + \cos x)}{2} + C.$$

**验证。** 求导：$\frac{e^x(\sin x + \cos x) + e^x(\cos x - \sin x)}{2} = \frac{2e^x \cos x}{2} = e^x \cos x$。正确。

**来源。** [OpenStax Calculus Vol. 2, §3.1, Example 3.3](https://openstax.org/books/calculus-volume-2/pages/3-1-integration-by-parts) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="定积分用分部积分（难）" numero="5">

**问题。** 计算 $\int_0^\pi x \sin x\, dx$。

**策略。** LIATE：$u = x$、$dv = \sin x\, dx$。应用分部积分并在边界处求值。

**解。**

$du = dx$、$v = -\cos x$。

$$\int_0^\pi x \sin x\, dx = [-x \cos x]_0^\pi + \int_0^\pi \cos x\, dx.$$

$[-x \cos x]_0^\pi = -\pi\cos\pi - 0 = -\pi(-1) = \pi$。

$\int_0^\pi \cos x\, dx = [\sin x]_0^\pi = 0 - 0 = 0$。

因此 $\int_0^\pi x \sin x\, dx = \pi + 0 = \pi$。

**验证。** 结果 $\pi$ 是经典的——数值验证（$\approx 3.1416$）。$x\sin x$ 在 $[0, \pi]$ 上的符号不对称性（始终为正）保证结果为正。

**来源。** [Active Calculus §5.4, Exercise 5.4.3](https://activecalculus.org/single/sec-5-4-parts.html) — CC-BY-NC-SA。

</Exemplo>
