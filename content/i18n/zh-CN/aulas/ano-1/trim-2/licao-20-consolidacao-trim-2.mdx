### 三角学——结构

<Definicao titulo="第2学期的基本恒等式">

设 <Eq>{`\\theta \\in \\mathbb{R}`}</Eq>（以弧度为单位的角）。三个中心恒等式是：

$$\sin^2\theta + \cos^2\theta = 1 \quad \text{（勾股）}$$

$$\sin(A \pm B) = \sin A \cos B \pm \cos A \sin B \quad \text{（加法）}$$

$$\sin A + \sin B = 2\sin\!\frac{A+B}{2}\cos\!\frac{A-B}{2} \quad \text{（和差化积）}$$

对于任意三角形（<Eq>{`ABC`}</Eq> 边长 <Eq>{`a, b, c`}</Eq> 分别对应角 <Eq>{`A, B, C`}</Eq>）：

$$\frac{\sin A}{a} = \frac{\sin B}{b} = \frac{\sin C}{c} \quad \text{（正弦定理）}$$

$$c^2 = a^2 + b^2 - 2ab\cos C \quad \text{（余弦定理）}$$

</Definicao>

> "和差化积将正弦的加法转化为正弦和余弦的乘积——对于简化含有多角的方程至关重要。" — [OpenStax Algebra and Trigonometry 2e, §9.4](https://openstax.org/books/algebra-and-trigonometry-2e/pages/9-4-sum-to-product-and-product-to-sum-formulas)

<Teorema titulo="正弦定理——初等证明">
在任意三角形 <Eq>{`ABC`}</Eq> 中，从顶点 <Eq>{`C`}</Eq> 向边 <Eq>{`AB`}</Eq> 作垂线 <Eq>{`h`}</Eq>。则：
- 在左侧子三角形中：<Eq>{`h = b \\sin A`}</Eq>。
- 在右侧子三角形中：<Eq>{`h = a \\sin B`}</Eq>。

等式得：<Eq>{`b \\sin A = a \\sin B`}</Eq>，因此 <Eq>{`\\dfrac{\\sin A}{a} = \\dfrac{\\sin B}{b}`}</Eq>。重复从 <Eq>{`A`}</Eq> 作垂线得到 <Eq>{`\\dfrac{\\sin C}{c}`}</Eq>。<Eq>{`\\square`}</Eq>
</Teorema>

### 数列——结构

<Definicao titulo="等差数列、等比数列和直观极限">

**等差数列（PA）：** <Eq>{`a_n = a_1 + (n-1)r`}</Eq>。前 <Eq>{`n`}</Eq> 项的和为：
$$S_n = \frac{n(a_1 + a_n)}{2}$$

**等比数列（PG）：** <Eq>{`a_n = a_1 q^{n-1}`}</Eq>。当 <Eq>{`q \\neq 1`}</Eq> 时，部分和为：
$$S_n = a_1\frac{q^n - 1}{q - 1}$$

**无穷几何级数：** 如果 <Eq>{`|q| < 1`}</Eq>，级数收敛：
$$S_\infty = \frac{a_1}{1 - q}$$

**直观极限：** 数列 <Eq>{`(a_n)`}</Eq> 的极限为 <Eq>{`L`}</Eq>，如果从某个指标开始，所有项都可以任意接近 <Eq>{`L`}</Eq>。记号：<Eq>{`\\lim_{n\\to\\infty} a_n = L`}</Eq>。

</Definicao>

> "关键思想：如果 <Eq>{`|r| < 1`}</Eq>，几何级数收敛到 <Eq>{`\\dfrac{a}{1-r}`}</Eq>。" — [OpenStax Algebra and Trigonometry 2e, §11.4](https://openstax.org/books/algebra-and-trigonometry-2e/pages/11-4-series-and-their-notations)

> "数列 <Eq>{`\\{a_n\\}`}</Eq> 收敛到 <Eq>{`L`}</Eq>，如果对于每个 <Eq>{`\\varepsilon > 0`}</Eq>，存在一个指标 <Eq>{`N`}</Eq> 使得对于所有 <Eq>{`n \\geq N`}</Eq>，<Eq>{`|a_n - L| < \\varepsilon`}</Eq>。" — [Active Calculus §8.2](https://activecalculus.org/single/sec-8-2-sequences.html)

<Porta nivel="5" titulo="给5岁小孩">

你在第2学期学了三个"游戏"：

**游戏1 —— 时钟转圈** （三角学）。想象一根时针在转。它的上下位置是**正弦**，左右位置是**余弦**。每次你问，两个位置的平方和总是1。总是！

**游戏2 —— 尺子** （等差和等比）。你按照一条规则排列一列数字。在等差数列中，规则是"每次加同样的东西"（3、7、11、15...）。在等比数列中是"每次乘以同样的东西"（2、6、18、54...）。

**游戏3 —— 去哪里了?** （极限）。如果你不断加上等比数列中越来越小的数字，和会停在某个地方。数列 <Eq>{`1, 1/2, 1/4, 1/8, \\ldots`}</Eq> 越来越接近**2**——然后就停留在那里了。

今天你同时玩三个游戏！

<Porta nivel="10" titulo="给10岁小孩">

在第2学期你学了三个大工具：

**1. 三角学** —— 正弦、余弦、单位圆。用于测量角度、计算三角形中的距离和建模波浪（声音、光、潮汐）。

**2. 数列** —— 等差和等比。等差数列每步加同样的东西（薪水每月增加固定的 200 雷亚尔）。等比数列每步乘以同样的系数（银行账户每月增加5%）。

**3. 极限** —— 一个无限继续的数列要去哪里？等比数列，公比为 <Eq>{`1/2`}</Eq>：<Eq>{`1 + 1/2 + 1/4 + 1/8 + \\ldots`}</Eq> 越来越接近2，永远不会超过。

研讨会的问题混合了三个主题：
- "一个正弦波每周期衰减——什么时候会变为零？"（三角 + 等比 + 极限）
- "一个球每次反弹损失30% —— 总距离？"（无穷等比）
- "萨尔瓦多的潮汐在什么时间达到2.5米？"（周期函数 + 三角方程）

</Porta>

<Porta nivel="15" titulo="给15岁青少年">

这是第3学期前的复习。你需要掌握的主题：

**三角学：**
- 精确值：<Eq>{`\\sin 30° = 1/2`}</Eq>、<Eq>{`\\sin 45° = \\sqrt 2/2`}</Eq>、<Eq>{`\\sin 60° = \\sqrt 3/2`}</Eq>（以及对称的余弦）。
- 勾股恒等式：<Eq>{`\\sin^2\\theta + \\cos^2\\theta = 1`}</Eq> —— 出现在每个问题中。
- 方程：<Eq>{`\\sin\\theta = k`}</Eq> 每个周期有两个解。总是归约到区间 <Eq>{`[0, 2\\pi)`}</Eq>。
- 有"角+对边+其他元素"时用正弦定理。有"三条边"或"两条边+它们之间的角"时用余弦定理。

**数列：**
- 等差：通项 <Eq>{`a_1 + (n-1)r`}</Eq>，和 <Eq>{`n(a_1 + a_n)/2`}</Eq>。
- 等比：通项 <Eq>{`a_1 q^{n-1}`}</Eq>，部分和 <Eq>{`a_1(q^n-1)/(q-1)`}</Eq>，无穷和（如果 <Eq>{`|q| < 1`}</Eq>）：<Eq>{`a_1/(1-q)`}</Eq>。
- 总是验证：在等比中，<Eq>{`|q| < 1`}</Eq> 是收敛的条件——没有它就不存在无穷和。

**直观极限：**
- <Eq>{`\\lim a_n = L`}</Eq>：项接近 <Eq>{`L`}</Eq> 但从不"停止"。
- 不动点：如果 <Eq>{`a_{n+1} = f(a_n)`}</Eq> 收敛到 <Eq>{`L`}</Eq>，则 <Eq>{`L = f(L)`}</Eq>。
- 夹挤定理：如果 <Eq>{`b_n \\leq a_n \\leq c_n`}</Eq> 且 <Eq>{`b_n, c_n \\to L`}</Eq>，则 <Eq>{`a_n \\to L`}</Eq>。

**混合问题的策略：**
1. 识别类型（三角形、波、数字列表、极限）。
2. 列出数据和未知数。
3. 选择正确的公式。
4. 通过代入验证答案。

</Porta>

### 与第2年的联系

| 第2学期 | 第2年 | 机制 |
|---|---|---|
| 三角圆 | <Eq>{`\\frac{d}{dx}\\sin x = \\cos x`}</Eq> | <Eq>{`\\sin`}</Eq> 和 <Eq>{`\\cos`}</Eq> 在零处的泰勒级数 |
| 三角方程 | <Eq>{`f'(x) = 0`}</Eq> | <Eq>{`\\sin`}</Eq> 和 <Eq>{`\\cos`}</Eq> 的临界点 |
| 无穷等比 <Eq>{`a_1/(1-q)`}</Eq> | 泰勒级数 <Eq>{`1/(1-x) = \\sum x^n`}</Eq> | 广义几何和 |
| 直观极限 | 形式极限 <Eq>{`\\varepsilon`}</Eq>-<Eq>{`\\delta`}</Eq>（第41课） | "接近"的形式化 |
| 递推的不动点 | 牛顿法、迭代 | 通过函数迭代求根 |

### 跨域应用

- **电气工程**：交流电压 = 正弦（<Eq>{`V(t) = V_0\\sin\\omega t`}</Eq>）；极点分析 = 离散时间等比。
- **金融**：复利 = 等比（<Eq>{`F = P(1+i)^n`}</Eq>）；现值 = 折扣几何级数。
- **信号处理**：傅里叶级数 = 正弦/余弦的和——JPEG、MP3、通信的基础。
- **力学**：阻尼下落 = 指数衰减包络的正弦。

### 这个模块最常见的陷阱

- **角度 vs. 弧度**：数值代码和计算器在混合时会不同。
- **条件 <Eq>{`|q| < 1`}</Eq>**：无穷几何级数只在满足时才存在。
- **有界数列 <Eq>{`\\neq`}</Eq> 收敛**：<Eq>{`(-1)^n`}</Eq> 有界但不收敛。
- **SSA 歧义**：正弦定理加两条边和对角可能给出 0、1 或 2 个三角形——总是检查判别式。
- **虚假解**：在三角方程中平方或除法时，在原方程中检查。

第2学期形成**连续+离散**的必要词汇。从这里开始程序分叉：

- **连续微积分**（第5学期+）：导数和积分推广变化率和和。
- **离散分析**（第8学期+）：组合、概率、级数。

### 结构推广

**正弦 → 傅里叶分析。** 任何周期且平方可积的函数 <Eq>{`f`}</Eq> 分解为 <Eq>{`f(x) = a_0 + \\sum_{n=1}^\\infty (a_n \\cos nx + b_n \\sin nx)`}</Eq>。这是出现在今天练习中的和差化积恒等式的直接推广。在 DSP、压缩和偏微分方程中的普遍工具。

**等比 → Z 变换。** Z 变换推广几何级数：<Eq>{`X(z) = \\sum_{n=0}^\\infty x[n]\\,z^{-n}`}</Eq> 当 <Eq>{`|z| > R`}</Eq> 时收敛（类似 <Eq>{`|q| < 1`}</Eq>）。用于数字滤波器设计（IIR、FIR）和离散控制。

**极限 → 一般拓扑。** "接近"的直观概念通过 <Eq>{`\\varepsilon`}</Eq>-<Eq>{`\\delta`}</Eq> 定义（第41课）形式化，然后推广到度量空间、巴拿赫空间和希尔伯特空间——泛函分析和有限元法的基础。

### 历史背景

正弦定理为十世纪的伊斯兰数学家（Al-Battani、Ibn Muadh）所知，在欧洲系统化之前。无穷几何级数出现在阿基米德（公元前3世纪）作为穷竭法——积分的前身。严格的极限概念仅在柯西和魏尔施特拉斯于十九世纪才出现。

### 程序中的下一步

- **第3学期**（第21-30课）：解析几何、向量、矩阵——线性代数的生成。
- **第4学期**（第31-40课）：组合和概率。
- **第2年 — 第5学期**：形式极限 <Eq>{`\\varepsilon`}</Eq>-<Eq>{`\\delta`}</Eq>（第41课）标志向严格分析的转变。

**问题。** 等差数列，<Eq>{`a_1 = 3`}</Eq> 且 <Eq>{`r = 5`}</Eq>。计算 <Eq>{`a_{20}`}</Eq> 和 <Eq>{`S_{20}`}</Eq>。

<Exemplo titulo="复数参数的三角方程" numero="2">

**问题。** 在 <Eq>{`[0, 2\\pi)`}</Eq> 中解 <Eq>{`\\sin(2x) = 1/2`}</Eq>。

**策略。** 替换 <Eq>{`u = 2x`}</Eq>，在扩展区间 <Eq>{`[0, 4\\pi)`}</Eq> 中解 <Eq>{`\\sin u = 1/2`}</Eq>，然后除以 2。

**解决。**

1. **替换 <Eq>{`u = 2x`}</Eq>。** 对于 <Eq>{`x \\in [0, 2\\pi)`}</Eq>，我们有 <Eq>{`u \\in [0, 4\\pi)`}</Eq>。
2. **解 <Eq>{`\\sin u = 1/2`}</Eq>。** 在第1象限：<Eq>{`u_0 = \\pi/6`}</Eq>。在第2象限：<Eq>{`u_1 = 5\\pi/6`}</Eq>。加上 <Eq>{`2\\pi`}</Eq>：<Eq>{`u_2 = \\pi/6 + 2\\pi = 13\\pi/6`}</Eq> 和 <Eq>{`u_3 = 5\\pi/6 + 2\\pi = 17\\pi/6`}</Eq>。
3. **回到 <Eq>{`x = u/2`}</Eq>。** <Eq>{`x = \\pi/12,\\; 5\\pi/12,\\; 13\\pi/12,\\; 17\\pi/12`}</Eq>。

**验证。** <Eq>{`\\sin(2 \\cdot \\pi/12) = \\sin(\\pi/6) = 1/2`}</Eq> ✓。<Eq>{`\\sin(2 \\cdot 13\\pi/12) = \\sin(13\\pi/6) = \\sin(\\pi/6) = 1/2`}</Eq> ✓。

**来源。** [OpenStax Algebra and Trigonometry 2e, §9.5](https://openstax.org/books/algebra-and-trigonometry-2e/pages/9-5-solving-trigonometric-equations) — CC-BY 4.0。

</Exemplo>

<Exemplo titulo="无穷等比——弹球" numero="3">

**问题。** 一个球从 10 米高处掉落，每次反弹上升到前一个高度的 70%。总距离是多少（下降和上升）？

**策略。** 分离成两个无穷等比级数——下降和上升。对每个使用 <Eq>{`S_\\infty = a_1/(1-q)`}</Eq>。

**解决。**

1. **下降。** <Eq>{`10 + 7 + 4{,}9 + \\ldots = 10/(1-0{,}7) = 10/0{,}3 \\approx 33{,}33`}</Eq> 米。
2. **上升。** <Eq>{`7 + 4{,}9 + \\ldots = 7/(1-0{,}7) = 7/0{,}3 \\approx 23{,}33`}</Eq> 米。
3. **总计。** <Eq>{`33{,}33 + 23{,}33 \\approx 56{,}67`}</Eq> 米。

**验证。** 巩固公式：总 <Eq>{`= h \\cdot (1+q)/(1-q) = 10 \\cdot 1{,}7/0{,}3 \\approx 56{,}67`}</Eq> 米。✓

**来源。** [Active Calculus §8.3](https://activecalculus.org/single/sec-8-3-geometric.html) — CC-BY-NC-SA。

</Exemplo>

<Exemplo titulo="潮汐和三角方程" numero="4">

**问题。** 萨尔瓦多的潮汐高度是 <Eq>{`h(t) = 1{,}5 + \\sin(\\pi t/6)`}</Eq>（米，<Eq>{`t`}</Eq> 小时）。（a）何时 <Eq>{`h = 1{,}5`}</Eq>？（b）何时 <Eq>{`h`}</Eq> 最大？

**策略。** （a）解 <Eq>{`\\sin(\\pi t/6) = 0`}</Eq>。（b）解 <Eq>{`\\sin(\\pi t/6) = 1`}</Eq>。

**解决。**

1. **（a）** <Eq>{`\\sin(\\pi t/6) = 0 \\Rightarrow \\pi t/6 = k\\pi \\Rightarrow t = 6k`}</Eq>。在 <Eq>{`0 \\leq t \\leq 24`}</Eq>：<Eq>{`t = 0, 6, 12, 18, 24`}</Eq> 小时。

3. **最大高度。** <Eq>{`h_{\\max} = 1{,}5 + 1 = 2{,}5`}</Eq> 米。

**验证。** 周期 <Eq>{`T = 2\\pi/(\\pi/6) = 12`}</Eq> 小时——一天两次高潮，符合现实。✓

**来源。** [Stitz–Zeager Precalculus §11.1](https://www.stitz-zeager.com/szprecalculus07042013.pdf) — CC-BY-NC-SA。

<Exemplo titulo="和差化积的三角和" numero="5">

**问题。** 在 <Eq>{`[0, 2\\pi)`}</Eq> 中解 <Eq>{`\\sin x + \\sin 2x + \\sin 3x = 0`}</Eq>。

**策略。** 分组 <Eq>{`\\sin x + \\sin 3x`}</Eq> 并应用和差化积恒等式：<Eq>{`\\sin A + \\sin B = 2\\sin\\frac{A+B}{2}\\cos\\frac{A-B}{2}`}</Eq>。

**解决。**

1. **分组。** <Eq>{`\\sin x + \\sin 3x = 2\\sin 2x \\cos x`}</Eq>（<Eq>{`A = 3x`}</Eq>、<Eq>{`B = x`}</Eq>、平均值 <Eq>{`= 2x`}</Eq>、半差 <Eq>{`= x`}</Eq>）。
2. **替换。** <Eq>{`2\\sin 2x \\cos x + \\sin 2x = \\sin 2x(2\\cos x + 1) = 0`}</Eq>。
3. **情况 1：<Eq>{`\\sin 2x = 0`}</Eq>。** <Eq>{`2x = k\\pi \\Rightarrow x = k\\pi/2`}</Eq>。在 <Eq>{`[0, 2\\pi)`}</Eq>：<Eq>{`x = 0, \\pi/2, \\pi, 3\\pi/2`}</Eq>。
4. **情况 2：<Eq>{`2\\cos x + 1 = 0`}</Eq>。** <Eq>{`\\cos x = -1/2 \\Rightarrow x = 2\\pi/3`}</Eq> 或 <Eq>{`x = 4\\pi/3`}</Eq>。
5. **解集。** <Eq>{`x \\in \\{0,\\; \\pi/2,\\; 2\\pi/3,\\; \\pi,\\; 4\\pi/3,\\; 3\\pi/2\\}`}</Eq>。

**验证。** <Eq>{`x = 2\\pi/3`}</Eq>：<Eq>{`\\sin(2\\pi/3) + \\sin(4\\pi/3) + \\sin(2\\pi) = \\frac{\\sqrt 3}{2} - \\frac{\\sqrt 3}{2} + 0 = 0`}</Eq>。✓

**来源。** [OpenStax Algebra and Trigonometry 2e, §9.4](https://openstax.org/books/algebra-and-trigonometry-2e/pages/9-4-sum-to-product-and-product-to-sum-formulas) — CC-BY 4.0。

</Exemplo>
