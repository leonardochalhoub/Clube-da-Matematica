### 核心问题

> "给定数列 $(a_n)$，当 $n \to \infty$ 时其项趋向于哪个值（如果存在的话）？"

当该值存在时，我们说数列**收敛**并写成 $\lim_{n \to \infty} a_n = L$。

<Definicao titulo="数列极限（直观版本）">

如果当 $n$ 足够大时 $a_n$ 变得**任意接近 $L$**，我们说 $\lim_{n \to \infty} a_n = L$。

严格形式化（第41课）：

$$\forall \varepsilon > 0,\ \exists N \in \mathbb{N} :\ n \geq N \Rightarrow |a_n - L| < \varepsilon$$

现在相信"接近"的概念。

</Definicao>

> "一个序列 $\{a_n\}$ 收敛到实数 $L$ 当且仅当，对于每个 $\varepsilon > 0$ 存在整数 $N$ 使得若 $n > N$，则 $|a_n - L| < \varepsilon$。" — [OpenStax Calculus Volume 2, §5.1](https://openstax.org/books/calculus-volume-2/pages/5-1-sequences)

### 著名极限

| 数列 | 极限 | 直观解释 |
|---|---|---|
| $1/n$ | $0$ | 项逐渐变小 |
| $1/n^k$ 其中 $k > 0$ | $0$ | 同上，更快 |
| $q^n$ 其中 $\|q\| < 1$ | $0$ | 等比递减（第18课） |
| $q^n$ 其中 $\|q\| > 1$ | 不存在 | 等比爆炸 |
| $(1 + 1/n)^n$ | $e \approx 2{,}71828$ | 欧拉数 |
| $\sqrt[n]{n}$ | $1$ | 通过对数 |
| $n^k / a^n$ 其中 $a > 1$ | $0$ | 指数胜过多项式 |
| $n! / n^n$ | $0$ | $n^n$ 增长快于阶乘 |

### 极限的运算

若 $\lim a_n = A$ 和 $\lim b_n = B$（均为有限）：

<Equation numero="1"
  explicacao="和的极限等于极限的和 — 在两个极限都存在且有限的所有情况下成立。"
  latex="\lim(a_n \pm b_n) = A \pm B,\quad \lim(a_n \cdot b_n) = A \cdot B,\quad \lim\frac{a_n}{b_n} = \frac{A}{B}\ (B \neq 0)" />

### 不收敛的数列

- **趋向于 $\pm\infty$**：$a_n = n$，$a_n = 2^n$。
- **无限摆动**：$a_n = (-1)^n$ — 在 $1$ 和 $-1$ 之间交替。
- **有界但无极限**：$a_n = \sin n$ — 有界但不收敛。

### 夹逼定理（Sandwich）

<Teorema titulo="夹逼定理">

如果存在数列 $(a_n), (b_n), (c_n)$ 满足

$$a_n \leq b_n \leq c_n \quad \text{对所有 } n \geq N_0,$$

且 $\lim_{n \to \infty} a_n = \lim_{n \to \infty} c_n = L$，那么 $\lim_{n \to \infty} b_n = L$。

</Teorema>

> "夹逼定理：若对所有 $n \geq N$ 有 $a_n \leq b_n \leq c_n$ 且 $\lim_{n\to\infty} a_n = \lim_{n\to\infty} c_n = L$，则 $\lim_{n\to\infty} b_n = L$。" — [Lebl, Basic Analysis I, §2.1](https://www.jirka.org/ra/)

### 单调有界准则

<Teorema titulo="单调有界数列收敛（Bolzano-Weierstrass）">

每个在 $\mathbb{R}$ 中单调且有界的数列都收敛。

**实用推论**：为了证明 $(1 + 1/n)^n$ 有极限，只需证明它单调递增且上界为 $3$（通过二项式）。极限的存在无需计算确切值就能保证。

</Teorema>

<Insight>

**为什么数列的极限和函数的极限是相同的概念？** 因为数列是函数 $f: \mathbb{N} \to \mathbb{R}$。当学习第41课中的 $\lim_{x \to \infty} f(x)$ 时，这是对定义域 $\mathbb{R}$ 的自然扩展。数列的 $\varepsilon$-$N$ 变成函数的 $\varepsilon$-$M$。每个导数 $f'(a) = \lim_{h \to 0}(f(a+h)-f(a))/h$ 都是一个数列极限。

</Insight>

<Porta nivel="5" titulo="给5岁小孩">

想象一条很长很长的走廊。走廊远处有一扇门。你迈一大步，然后一个较小的步，然后更小的步，然后几乎跳过一只小蚂蚁...

每次步子变小。但你在**接近**门。非常接近。

"门"就是**极限**。小步子是数列的项。你逐渐接近极限，但不一定触碰它。

例子：$1, 1/2, 1/3, 1/4, 1/5, \ldots$

每一步你更接近**零**。门就是零。

</Porta>

<Porta nivel="10" titulo="给10岁小孩">

数列 $1/n$ 的项为 $1, 1/2, 1/3, 1/4, 1/5, \ldots, 1/100, \ldots, 1/1\,000\,000, \ldots$

**它趋向哪里？** 趋向**零**。它永远不会恰好达到零，但能任意接近。

这个"趋向哪里"就是**极限**。我们这样写：

$$\lim_{n \to \infty} \frac{1}{n} = 0$$

读："当 $n$ 趋向无穷时，$1/n$ 的极限为零"。

**其他例子：**
- $\lim (1/2)^n = 0$ — 等比递减，每步减半。
- $\lim n = \infty$ — 只增长，无固定目标。
- $\lim (-1)^n$ 不存在 — 在 $1$ 和 $-1$ 之间跳跃，无处可去。
- $\lim (1 + 1/n)^n = e \approx 2{,}71828$ — 著名的欧拉数。

**为什么重要？** 因为极限是**所有微积分**的基础，你在接下来几年要学习。每个导数和每个积分都隐藏着极限。

</Porta>

<Porta nivel="15" titulo="给15岁青少年">

**什么是数列的极限？** 想法很简单：一个数列 $(a_n)$ 有极限 $L$ 如果项变得任意接近 $L$，对于足够大的 $n$。

$$\lim_{n \to \infty} \frac{1}{n} = 0, \quad \lim_{n \to \infty} \frac{3n+5}{n+2} = 3, \quad \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$$

**对于多项式比 $\lim P(n)/Q(n)$ 的快速技巧：**

| 若 | 则 |
|---|---|
| $\deg P = \deg Q$ | 首项系数的比 |
| $\deg P > \deg Q$ | $\pm \infty$（发散） |
| $\deg P < \deg Q$ | $0$ |

**为什么重要？** 本课程**刻意**是直观的。严格形式化（$\varepsilon$-$N$）出现在第5学期第41课。现在相信"接近"并用习题训练。

但注意：**每个导数都是极限**。当你在第5学期计算 $f'(x) = \lim_{h \to 0}(f(x+h)-f(x))/h$ 时，这就是一个数列极限 — 正好是本课的概念。

**等比准则：** $\lim q^n = 0$ 若 $|q| < 1$；$\lim q^n = +\infty$ 若 $q > 1$；若 $q \leq -1$ 则不存在。

</Porta>

<Porta nivel="25" titulo="给工程学生">

极限是**分析的关键概念**。数列收敛或发散；当收敛时，极限是唯一的（唯一性 — 习题19.33）。

### 基本定理

- **夹逼**：若 $a_n \leq b_n \leq c_n$ 且 $\lim a_n = \lim c_n = L$，则 $\lim b_n = L$。
- **单调有界收敛**：每个在 $\mathbb{R}$ 中单调有界的数列有极限（$\mathbb{R}$ 的完备性）。
- **Cauchy $\Rightarrow$ 收敛**：Cauchy数列在 $\mathbb{R}$ 中总是收敛（等价的完备性）。

### 渐近记号（计算机科学）

- $a_n = O(b_n)$：$|a_n/b_n|$ 有界 — 增长相同阶。
- $a_n = o(b_n)$：$a_n/b_n \to 0$ — $a_n$ "远小于" $b_n$。
- $a_n \sim b_n$：$a_n/b_n \to 1$ — 渐近等价。

例子：$n \ln n = o(n^2)$；$\ln n = o(n^{0.01})$；$\binom{2n}{n} \sim 4^n / \sqrt{\pi n}$（Stirling）。

### 数字 $e$

$$e = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = \sum_{k=0}^\infty \frac{1}{k!} \approx 2{,}71828\ldots$$

推广：$\lim_{n \to \infty} (1 + r/n)^n = e^r$ — 连续利率、指数衰减、ODE $\dot y = ky$ 的基础。

### 工程应用

- **LTI系统稳定性**：极点 $p$ 满足 $|p| < 1 \Leftrightarrow$ 脉冲响应 $p^n \to 0 \Leftrightarrow$ 系统稳定。
- **Newton-Raphson收敛**：迭代 $x_{n+1} = x_n - f(x_n)/f'(x_n)$ 在简单根附近**二次收敛**。
- **MCMC**（Metropolis-Hastings）：遍历链收敛到平稳分布。
- **SGD**（随机梯度下降）：适当选择 $\eta_n \to 0$ 时，参数在凸性下收敛到最小值。

### 警告：$1^\infty$ 型

$\lim (1 + 1/n)^n = e \neq 1^{\infty}$ — $1^\infty$ 型是**未定式**。不要幼稚地计算"基趋向1所以极限是 $1^{\infty} = 1$"。使用 $\lim (1 + r/n)^{nt} = e^{rt}$。

</Porta>

<Porta nivel="40" titulo="给资深专业人士">

极限是**定义** $\mathbb{R}$ 的概念。经典构造：

- **Cauchy**：$\mathbb{R}$ = 有理数Cauchy数列等价类。
- **Dedekind**：$\mathbb{R}$ = $\mathbb{Q}$ 的切割。

两者等价。选择定义**$\mathbb{Q}$ 在通常范数下的度量完备化**。完备性保证每个Cauchy数列收敛 — $\mathbb{Q}$ 没有的性质（例：逼近 $\sqrt 2$ 的有理数列是Cauchy但不收敛于 $\mathbb{Q}$）。

### 基础拓扑

收敛是**拓扑现象**：$a_n \to L$ 若 $L$ 的每个开邻域都包含某个 $N$ 之后的所有 $a_n$。在度量空间中，邻域 = 球 $B(L, \varepsilon)$。

### 推广

- **$\mathbb{R}^n$**：按分量收敛（欧几里得范数）。
- **函数空间**：逐点、一致、$L^p$ 收敛 — 通常不同。$f_n(x) = x^n$ 在 $[0,1]$：逐点收敛到不连续函数，非一致。
- **网的极限**（nets）：推广数列到偏序集（一般拓扑）。
- **范畴极限**（cones）：范畴论中统一序列极限、乘积、拉回的通用结构。

### 在ML/DL和统计中

- **大数律**：$\bar X_n \to \mu$ — Monte Carlo、batch SGD的基础。
- **中心极限定理**：$\sqrt n (\bar X_n - \mu)/\sigma \to N(0,1)$ — 置信区间的正当理由。
- **SGD收敛**：梯度在凸性和Lipschitz下衰减为 $O(1/\sqrt T)$。证明使用Lyapunov序列。
- **深层网络中的灾难遗忘**：梯度在层间几何衰减 — 方差趋向零（消失梯度问题）。

```python
import sympy as sp
n = sp.symbols('n', integer=True, positive=True)
print(sp.limit((1 + 1/n)**n, n, sp.oo))    # E
print(sp.limit((3*n + 5)/(n + 2), n, sp.oo))  # 3
print(sp.limit(n**100 / 2**n, n, sp.oo))   # 0  (exp domina)
print(sp.limit(sp.sin(n)/n, n, sp.oo))     # 0
```

<Porta nivel="pratica" titulo="实际应用 — 巴西和工程">

### 场景1：连续复利（SELIC）

如果SELIC为 $r = 10{,}75\%$ 年利率，你每年复利 $n$ 次，年增长因子为 $(1 + r/n)^n$。当 $n \to \infty$（连续复利）：

$$\lim_{n \to \infty} \left(1 + \frac{0{,}1075}{n}\right)^n = e^{0{,}1075} \approx 1{,}1134$$

对于R\$ 10.000投资，1年后：R\$ 11.134。与简单年复利比较：R\$ 11.075。差异源于欧拉的限制。

### 场景2：电容器放电（电子学）

电容器通过电阻放电遵循 $V_n = V_0 \cdot (0{,}9)^n$ 每个时间周期。因为 $|0{,}9| < 1$：

$$\lim_{n \to \infty} V_n = V_0 \cdot 0 = 0 \text{ V}$$

电容器完全放电 — 极限为零。若比值为 $q = 1{,}1 > 1$，电压会爆炸（电路不稳定）。

### 场景3：迭代算法收敛

Heron方法（巴比伦算法，公元前1世纪）求 $\sqrt c$：

$$a_1 = 1, \quad a_{n+1} = \frac{a_n + c/a_n}{2}$$

对于 $c = 5$：$a_1 = 1$，$a_2 = 3$，$a_3 = 2{,}333$，$a_4 = 2{,}2381$，$a_5 \approx 2{,}23607$ — 已有5位正确数字 $\sqrt 5 \approx 2{,}23607$。**二次收敛**：正确位数每次迭代翻倍。极限通过不动点计算：$L = (L + c/L)/2 \Rightarrow L^2 = c \Rightarrow L = \sqrt c$。

## 已解决的例子

<Exemplo titulo="1/n 的极限 — 奠基例子" numero="1">

**问题：** 求 $\lim_{n \to \infty} 1/n$。

**策略：** 数值观察序列。项无限减小 — 直观极限为 $0$。确认：给定任何目标 $\varepsilon > 0$，只需 $n > 1/\varepsilon$ 使得 $1/n < \varepsilon$。

**求解：**

1. **列出若干项。** $1,\ 1/2,\ 1/3,\ 1/4,\ \ldots,\ 1/100,\ \ldots,\ 1/10^6,\ \ldots$
2. **观察趋势。** 对任何 $\varepsilon > 0$，取 $n > 1/\varepsilon$ 使得 $1/n < \varepsilon$。
3. **结论。** $\lim_{n \to \infty} 1/n = 0$。

**验证：** $1/10^6 = 10^{-6}$，$1/10^{12} = 10^{-12}$。趋向零但从不触及。

**来源。** [Active Calculus §8.1 (Sequences)](https://activecalculus.org/single/sec-8-1-sequences.html) — CC-BY-NC-SA许可。收敛概念开篇的典范例子。

<Exemplo titulo="多项式比的极限" numero="2">

**问题：** 求 $\lim_{n \to \infty} \dfrac{3n + 5}{n + 2}$。

**策略：** 分子分母同除以 $n$（最高次幂）。这样隔离趋向零的项。

**求解：**

1. **全部除以 $n$。** $\dfrac{3n + 5}{n + 2} = \dfrac{3 + 5/n}{1 + 2/n}$。
2. **取极限。** 因为 $5/n \to 0$ 和 $2/n \to 0$：$\dfrac{3 + 0}{1 + 0} = 3$。
3. **结论。** $\lim_{n \to \infty} \dfrac{3n + 5}{n + 2} = 3$。

**验证：** $n = 1\,000$：$(3\,005)/(1\,002) \approx 2{,}999$。$n = 10^6$：$\approx 2{,}999999$。收敛到 $3$。

**技巧。** 对于 $\lim P(n)/Q(n)$ 其中 $\deg P = \deg Q$，极限是最高次系数的比。这里：$3/1 = 3$。

**来源。** [Lebl — Basic Analysis I §2.2](https://www.jirka.org/ra/) — CC-BY-SA许可。数列极限定理。

</Exemplo>

<Exemplo titulo="根的差 — 共轭技巧" numero="3">

**问题：** 求 $\lim_{n \to \infty} (\sqrt{n+1} - \sqrt{n})$。

**策略：** 未定式 $\infty - \infty$。乘以共轭 $\sqrt{n+1} + \sqrt{n}$ 来有理化。

**求解：**

1. **乘以共轭。** $\sqrt{n+1} - \sqrt{n} = \dfrac{(\sqrt{n+1} - \sqrt{n})(\sqrt{n+1} + \sqrt{n})}{\sqrt{n+1} + \sqrt{n}} = \dfrac{(n+1) - n}{\sqrt{n+1} + \sqrt{n}} = \dfrac{1}{\sqrt{n+1} + \sqrt{n}}$。
2. **分析分母。** $\sqrt{n+1} + \sqrt{n} \to +\infty$。
3. **结论。** $\lim_{n \to \infty} \dfrac{1}{\sqrt{n+1} + \sqrt{n}} = 0$。

**验证：** $n = 100$：$\sqrt{101} - 10 \approx 0{,}0499$。$n = 10\,000$：$\approx 0{,}005$。趋向零。

**来源。** [Lebl — Basic Analysis I §2.2](https://www.jirka.org/ra/) — CC-BY-SA许可。$\infty - \infty$ 型根式的标准技巧。

</Exemplo>

<Exemplo titulo="通过(1+1/n)^n得到数字e" numero="4">

**问题：** 直观证明 $\lim_{n \to \infty} (1 + 1/n)^n = e \approx 2{,}71828$。

**策略：** 计算递增 $n$ 的数值。单调有界准则保证极限存在。

**求解：**

1. **计算若干项。**

   | $n$ | $(1 + 1/n)^n$ |
   |---|---|
   | $1$ | $2$ |
   | $10$ | $2{,}5937$ |
   | $100$ | $2{,}7048$ |
   | $1\,000$ | $2{,}7169$ |
   | $10^6$ | $2{,}71828$ |

2. **观察单调性和界。** 可以证明（通过Newton二项式）数列单调递增且上界为 $3$。按单调有界定理，极限存在。

3. **确定极限。** 数值 $e \approx 2{,}71828\ldots$ 定义为该极限（等价于级数 $\sum 1/k!$）。

**验证：** SymPy：`sp.limit((1 + 1/n)**n, n, sp.oo)` 返回 `E`。

**为什么重要？** 推广：$\lim_{n \to \infty} (1 + r/n)^n = e^r$。对于速率 $r$ 的连续复利，年增长因子为 $e^r$。与利率的连接将在第5学期形式化。

**来源。** [Active Calculus §8.1](https://activecalculus.org/single/sec-8-1-sequences.html) — CC-BY-NC-SA许可。严格证明在 [Lebl §2.4](https://www.jirka.org/ra/)。

</Exemplo>

<Exemplo titulo="递推的不动点 — Heron方法" numero="5">

**问题：** 考虑 $a_1 = 1$，$a_{n+1} = (a_n + 2/a_n)/2$。它收敛到什么值？

**策略：** 若 $a_n \to L$，则 $a_{n+1} \to L$ 也成立。在递推式中取极限得到 $L$ 的代数方程（不动点方程）。

**求解：**

1. **假设极限 $L$ 存在。** $a_{n+1} \to L$（同一数列，移位1）。
2. **在递推式中取极限。** $L = (L + 2/L)/2 \Rightarrow 2L = L + 2/L \Rightarrow L = 2/L \Rightarrow L^2 = 2$。
3. **求解。** $L = \pm\sqrt{2}$。因为 $a_1 = 1 > 0$ 且递推保持正性，$L = \sqrt{2} \approx 1{,}41421$。

**数值验证：**

| $n$ | $a_n$ |
|---|---|
| $1$ | $1{,}000000$ |
| $2$ | $1{,}500000$ |
| $3$ | $1{,}416667$ |
| $4$ | $1{,}414216$ |
| $5$ | $1{,}414214$ |

**连接。** 这是 $f(x) = x^2 - 2$ 的Newton-Raphson迭代。二次收敛：正确数字每次迭代翻倍。Alexandria的Heron算法（公元前1世纪），17世纪被Newton重新发现。

**来源。** [Active Calculus §8.1](https://activecalculus.org/single/sec-8-1-sequences.html) 和 [OpenStax Calculus Volume 2 §5.1](https://openstax.org/books/calculus-volume-2/pages/5-1-sequences) — CC-BY-NC-SA许可。

</Exemplo>

<Exercicio numero="19.33" dificuldade="demonstracao"

<Exercicio numero="19.34" dificuldade="desafio"
  solucao={<>若 <Eq>{`a_n \\to L`}</Eq>，则 <Eq>{`L = \\sqrt{2 + L} \\Rightarrow L^2 = 2 + L \\Rightarrow L^2 - L - 2 = 0 \\Rightarrow (L-2)(L+1) = 0`}</Eq>。因此 <Eq>{`L = 2`}</Eq> 或 <Eq>{`L = -1`}</Eq>。因为 <Eq>{`a_1 = 1 > 0`}</Eq> 且递推保持正性，<Eq>{`L = 2`}</Eq>。数列：<Eq>{`1, \\sqrt 3, \\sqrt{2+\\sqrt 3}, \\ldots \\to 2`}</Eq>。</>}
  passos={<>
    <ol>
      <li><strong>假设极限的存在。</strong> 若 <Eq>{`a_n \\to L`}</Eq>，则 <Eq>{`a_{n+1} \\to L`}</Eq>。</li>
      <li><strong>在递推式中取极限。</strong> <Eq>{`L = \\sqrt{2 + L}`}</Eq>。</li>
      <li><strong>平方。</strong> <Eq>{`L^2 = 2 + L \\Rightarrow L^2 - L - 2 = 0`}</Eq>。</li>
      <li><strong>因式分解。</strong> <Eq>{`(L - 2)(L + 1) = 0 \\Rightarrow L = 2`}</Eq> 或 <Eq>{`L = -1`}</Eq>。</li>

    </ol>
