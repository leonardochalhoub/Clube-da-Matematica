<Porta nivel="formal" titulo="Rigorous definition">

<Definicao titulo="Function">

Let $A$ and $B$ be non-empty sets. A **function** $f$ from $A$ to $B$, denoted $f: A \to B$, is a relation that associates to each $x \in A$ a unique element $f(x) \in B$.

- $A$ is the **domain** of $f$, denoted $\operatorname{dom}(f)$.
- $B$ is the **codomain**.
- $\operatorname{Im}(f) = \{f(x) : x \in A\} \subseteq B$ is the **range**.

</Definicao>

> "A function is a relation in which each input value produces exactly one output value." — [OpenStax College Algebra 2e, §3.1](https://openstax.org/books/college-algebra-2e/pages/3-1-functions-and-function-notation)

### Classification

<Definicao titulo="Types of function">

- **Injective** (one-to-one): <Eq>{`x_1 \neq x_2 \Rightarrow f(x_1) \neq f(x_2)`}</Eq>.
- **Surjective**: <Eq>{`\operatorname{Im}(f) = B`}</Eq> (every <Eq>{`y \in B`}</Eq> has at least one <Eq>{`x`}</Eq> mapping to it).
- **Bijective**: injective AND surjective.

</Definicao>

<Porta nivel="5" titulo="For a 5-year-old">

Imagine a magic machine. You put a **number** inside. The machine thinks for a moment. And out comes another **number**.

Every time you put in the same number, the machine always gives you the same answer. Always. If the machine sometimes gives one answer, sometimes another, it is not a "function" — it is just a crazy machine.

</Porta>

<Porta nivel="10" titulo="For a 10-year-old">

A function is a **fixed relationship** between two numbers.

Example: doubling a number. If **3** goes in, **6** comes out. If **5** goes in, **10** comes out. If **8.7** goes in, **17.4** comes out. The rule is "output = input × 2".

We write this as <Eq>{`f(x) = 2x`}</Eq>. The **f** is just a name — you could call it **g**, **h**, **double**, anything. The **(x)** is where you put the number going in.

Functions appear in **EVERYTHING** in science:
- Speed of a car as a **function of time**: <Eq>{`v(t) = ?`}</Eq>
- Cost of a trip as a **function of distance**: <Eq>{`C(d) = ?`}</Eq>
- Temperature throughout the day as a **function of hour**: <Eq>{`T(h) = ?`}</Eq>

</Porta>

<Porta nivel="15" titulo="For a 15-year-old teenager">

A function <Eq>{`f`}</Eq> is a rule that associates each input to a unique output. The set of valid inputs is the **domain**, and the set of outputs that actually appear is the **range**.

Example: <Eq>{`f(x) = x^2`}</Eq>.

| <Eq>{`x`}</Eq> (input) | <Eq>{`f(x)`}</Eq> (output) |
|---:|---:|
| −2 | 4 |
| −1 | 1 |
| 0 | 0 |
| 1 | 1 |
| 2 | 4 |

Domain: <Eq>{`\mathbb{R}`}</Eq> (any real works as input). Range: <Eq>{`[0, +\infty)`}</Eq> (output is never negative).

<Porta nivel="25" titulo="For an engineering student">

A function is the most important mathematical object in all of calculus. Before you differentiate or integrate, you need absolute clarity on what a function is.

### Maximum domain

When a problem says "study <Eq>{`f(x) = \sqrt{x - 1}`}</Eq>" without specifying a domain, we adopt the **maximum natural domain**: the largest subset of <Eq>{`\mathbb{R}`}</Eq> in which the expression makes sense.

- <Eq>{`\sqrt{x-1}`}</Eq>: <Eq>{`x - 1 \geq 0 \Rightarrow x \geq 1`}</Eq>, domain = <Eq>{`[1, +\infty)`}</Eq>.
- <Eq>{`1/(x-2)`}</Eq>: <Eq>{`x \neq 2`}</Eq>, domain = <Eq>{`\mathbb{R} \setminus \{2\}`}</Eq>.
- <Eq>{`\ln(x)`}</Eq>: <Eq>{`x > 0`}</Eq>, domain = <Eq>{`(0, +\infty)`}</Eq>.

> "To find the domain of a function defined by an equation, identify all restrictions on the input variable that would make the operation undefined." — [OpenStax College Algebra 2e, §3.2](https://openstax.org/books/college-algebra-2e/pages/3-2-domain-and-range)

### Composition

<Eq>{`(f \circ g)(x) = f(g(x))`}</Eq>. **Caution**: composition is not commutative in general.

Example: <Eq>{`f(x) = x^2`}</Eq>, <Eq>{`g(x) = x + 1`}</Eq>.
- <Eq>{`(f \circ g)(x) = f(x+1) = (x+1)^2`}</Eq>
- <Eq>{`(g \circ f)(x) = g(x^2) = x^2 + 1`}</Eq>

Different!

### Why injectivity matters

A function admits an **inverse** only if it is injective. Non-injective functions must be restricted. Classic example: <Eq>{`f(x) = x^2`}</Eq> is not injective on <Eq>{`\mathbb{R}`}</Eq>, but it is injective on <Eq>{`[0, +\infty)`}</Eq>, where its inverse is <Eq>{`f^{-1}(y) = \sqrt{y}`}</Eq>.

### Functions and modeling

In engineering, a function is the object that represents a **phenomenon**:
- <Eq>{`T(t)`}</Eq>: temperature as a function of time (sensor)
- <Eq>{`V(I)`}</Eq>: voltage as a function of current (Ohm's law)
- <Eq>{`\sigma(\varepsilon)`}</Eq>: stress as a function of strain (Hooke's law)

All dimensional analysis, all calibration, all model fitting begins by understanding what the function is.

</Porta>

<Porta nivel="40" titulo="For a senior professional">

The definition of a function as a "rule that associates" is informal. The rigorous definition, à la Bourbaki, is:

> A function <Eq>{`f: A \to B`}</Eq> is a **subset** <Eq>{`f \subseteq A \times B`}</Eq> such that for each <Eq>{`x \in A`}</Eq> there exists **exactly one** <Eq>{`y \in B`}</Eq> with <Eq>{`(x, y) \in f`}</Eq>. We write <Eq>{`y = f(x)`}</Eq>.

In other words, a function IS its graph (in the sense of a set). An operational definition for Logic and Set Theory. Daily calculus does not use this formalization, but you will see it in Real Analysis (Calculus IV / University Real Analysis).

### Functions as morphisms

In Category Theory (modern language of mathematics), functions are **morphisms** between sets. Bijection is an isomorphism in the category <Eq>{`\mathbf{Set}`}</Eq>. Composition of functions is composition of morphisms.

### Functions and computation

In computer science, a function is the central concept of functional programming (Haskell, Lisp). Currying — transforming <Eq>{`f: A \times B \to C`}</Eq> into <Eq>{`f': A \to (B \to C)`}</Eq> — is routine type manipulation. A real production function might have a signature like <Eq>{`\text{User} \to \text{Order} \to \text{Promise(Receipt)}`}</Eq> — which is exactly a <Eq>{`f: A \to B \to C`}</Eq> mathematical function with side effects.

### Limitations of modeling

In real physical phenomena, "function" is an abstraction:
- **Hysteresis**: the state depends not just on the current input but on the past trajectory (plastic deformation). Not a function.
- **Quantum**: measurement is probabilistic — there is no unique deterministic value. It is a probability distribution.
- **Chaos**: small variations in initial conditions generate arbitrarily different trajectories. Deterministic in theory, unpredictable in practice.

In all these cases, the concept of a function is insufficient, and richer abstractions (maps, stochastic processes, dynamics) come into play.

</Porta>

<Porta nivel="pratica" titulo="Practice — examples with real data">

### Example 1: Taxi fare (affine model)

In São Paulo, a taxi charges:

$$T(d) = 5.50 + 3.10 \cdot d$$

where <Eq>{`T`}</Eq> is the amount in USD and <Eq>{`d`}</Eq> the distance in km.

- Domain: <Eq>{`d \geq 0 \Rightarrow [0, +\infty)`}</Eq>
- Range: <Eq>{`T \geq 5.50 \Rightarrow [5.50, +\infty)`}</Eq>
- <Eq>{`T(0) = 5.50`}</Eq> is the **base fare** (fixed boarding cost)
- <Eq>{`T(10) = 5.50 + 31 = 36.50`}</Eq>

### Example 2: BMI (Body Mass Index)

$$\text{BMI}(p, h) = \frac{p}{h^2}$$

- Function of **two variables** (weight <Eq>{`p`}</Eq> in kg, height <Eq>{`h`}</Eq> in meters).
- Physical domain: <Eq>{`p > 0`}</Eq>, <Eq>{`h > 0 \Rightarrow (0, +\infty)^2`}</Eq>.
- Range: <Eq>{`(0, +\infty)`}</Eq>.

WHO classification:
- BMI < 18.5: underweight
- 18.5 ≤ BMI < 25: normal
- 25 ≤ BMI < 30: overweight
- BMI ≥ 30: obese

### Example 3: Selic Rate (function of time, discontinuous)

The Selic is decided by the central bank in meetings every ~45 days. Between meetings, it is constant. A "step" function:

```
Selic(Jan/2025) = 13.25%
Selic(Mar/2025) = 14.25%
Selic(May/2025) = 14.75%  (held since then)
```

Domain: time (dates). Codomain: percentages. Range: discrete, values set by the central bank.

</Porta>

## Worked examples

> Five examples with increasing difficulty — from the most direct (numerical evaluation and domain reading) to real modeling (composition in a production pipeline). Each example cites the source: the original problem always comes from an open book.

<Exemplo titulo="Evaluation and direct domain (application)" numero="1">

**Problem:** For <Eq>{`f(x) = 3x^2 - 2x + 1`}</Eq>, compute <Eq>{`f(-1)`}</Eq>, <Eq>{`f(0)`}</Eq>, and <Eq>{`f(2)`}</Eq>. Determine the maximum domain.

**Strategy:** Evaluating a function at a point means replacing the variable with the given value and calculating. The maximum domain of a polynomial is all of <Eq>{`\mathbb{R}`}</Eq>, since polynomials are defined at every real number.

**Solution:**

1. <strong><Eq>{`f(-1)`}</Eq>:</strong> Substitute <Eq>{`x = -1`}</Eq>: <Eq>{`f(-1) = 3(-1)^2 - 2(-1) + 1 = 3(1) + 2 + 1 = 6`}</Eq>.
2. <strong><Eq>{`f(0)`}</Eq>:</strong> Substitute <Eq>{`x = 0`}</Eq>: <Eq>{`f(0) = 3(0)^2 - 2(0) + 1 = 0 - 0 + 1 = 1`}</Eq>.
3. <strong><Eq>{`f(2)`}</Eq>:</strong> Substitute <Eq>{`x = 2`}</Eq>: <Eq>{`f(2) = 3(2)^2 - 2(2) + 1 = 3(4) - 4 + 1 = 12 - 4 + 1 = 9`}</Eq>.
4. <strong>Domain:</strong> Since <Eq>{`f`}</Eq> is polynomial, there is no restriction. Domain = <Eq>{`\mathbb{R}`}</Eq>.

**Check:** All three values are finite. To confirm consistency, observe that <Eq>{`f(0) = 1`}</Eq> is the constant term — this always holds for any polynomial.

**Source.** [OpenStax — College Algebra 2e §3.1](https://openstax.org/books/college-algebra-2e/pages/3-1-functions-and-function-notation) — license CC-BY 4.0.

</Exemplo>

<Exemplo titulo="Maximum domain with combined restrictions (intermediate)" numero="2">

**Problem:** Determine the maximum domain of <Eq>{`f(x) = \dfrac{\sqrt{x + 2}}{x - 3}`}</Eq>.

**Strategy:** There are two simultaneous restrictions: the radicand <Eq>{`x + 2`}</Eq> must be non-negative (for the square root to exist in the reals), and the denominator <Eq>{`x - 3`}</Eq> cannot be zero. The domain is the intersection of these two conditions.

**Solution:**

1. <strong>Square root restriction:</strong> <Eq>{`x + 2 \geq 0 \Rightarrow x \geq -2`}</Eq>, or <Eq>{`x \in [-2, +\infty)`}</Eq>.
2. <strong>Denominator restriction:</strong> <Eq>{`x - 3 \neq 0 \Rightarrow x \neq 3`}</Eq>, or <Eq>{`x \in \mathbb{R} \setminus \{3\}`}</Eq>.
3. <strong>Intersection:</strong> <Eq>{`[-2, +\infty) \cap (\mathbb{R} \setminus \{3\}) = [-2, 3) \cup (3, +\infty)`}</Eq>.

**Check:**
- <Eq>{`x = -2`}</Eq>: <Eq>{`\sqrt{0}/(-5) = 0`}</Eq>. OK (included).
- <Eq>{`x = 3`}</Eq>: division by zero. Excluded. OK.
- <Eq>{`x = -3`}</Eq>: <Eq>{`\sqrt{-1}`}</Eq> does not exist in the reals. Excluded. OK.
- <Eq>{`x = 5`}</Eq>: <Eq>{`\sqrt{7}/2`}</Eq>. OK.

**Source.** [OpenStax — College Algebra 2e §3.2](https://openstax.org/books/college-algebra-2e/pages/3-2-domain-and-range) — license CC-BY 4.0.

</Exemplo>

<Exemplo titulo="Function composition (intermediate)" numero="3">

**Problem:** Let <Eq>{`f(x) = x^2 + 1`}</Eq> and <Eq>{`g(x) = 2x - 3`}</Eq>. Compute <Eq>{`(f \circ g)(x)`}</Eq> and <Eq>{`(g \circ f)(x)`}</Eq>. Show they differ at <Eq>{`x = 1`}</Eq>.

**Strategy:** Composition <Eq>{`(f \circ g)(x)`}</Eq> means "apply <Eq>{`g`}</Eq> first, then <Eq>{`f`}</Eq>". That is, <Eq>{`f(g(x))`}</Eq>. Reversing the order produces functions that are generally different — a classic warning.

**Solution:**

1. <strong><Eq>{`(f \circ g)(x) = f(g(x))`}</Eq>:</strong> substitute <Eq>{`g(x) = 2x - 3`}</Eq> in place of <Eq>{`x`}</Eq> in <Eq>{`f`}</Eq>: <Eq>{`f(2x - 3) = (2x - 3)^2 + 1 = 4x^2 - 12x + 9 + 1 = 4x^2 - 12x + 10`}</Eq>.
2. <strong><Eq>{`(g \circ f)(x) = g(f(x))`}</Eq>:</strong> substitute <Eq>{`f(x) = x^2 + 1`}</Eq> in place of <Eq>{`x`}</Eq> in <Eq>{`g`}</Eq>: <Eq>{`g(x^2 + 1) = 2(x^2 + 1) - 3 = 2x^2 + 2 - 3 = 2x^2 - 1`}</Eq>.
3. <strong>At <Eq>{`x = 1`}</Eq>:</strong>
   - <Eq>{`(f \circ g)(1) = 4 - 12 + 10 = 2`}</Eq>.
   - <Eq>{`(g \circ f)(1) = 2 - 1 = 1`}</Eq>.
   Different — composition <strong>does not commute</strong>.

**Check:** Also try <Eq>{`x = 0`}</Eq>: <Eq>{`(f \circ g)(0) = 10`}</Eq> and <Eq>{`(g \circ f)(0) = -1`}</Eq>. Different at every point except possibly at solutions of <Eq>{`4x^2 - 12x + 10 = 2x^2 - 1`}</Eq>, i.e., <Eq>{`2x^2 - 12x + 11 = 0`}</Eq>.

**Source.** [Stitz–Zeager — Precalculus §5.1](https://www.stitz-zeager.com/szprecalculus07042013.pdf) — license CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Inverse and domain restriction (advanced)" numero="4">

**Problem:** Let <Eq>{`f(x) = x^2 - 4x + 5`}</Eq> be defined on <Eq>{`\mathbb{R}`}</Eq>. Show that <Eq>{`f`}</Eq> is not injective on <Eq>{`\mathbb{R}`}</Eq>. Restrict the domain to an interval where <Eq>{`f`}</Eq> is injective and determine <Eq>{`f^{-1}`}</Eq> on that restriction.

**Strategy:** A quadratic function is not injective on <Eq>{`\mathbb{R}`}</Eq>: points symmetric about the parabola's axis have the same image. The axis of symmetry is <Eq>{`x = 2`}</Eq> (vertex). Restricting to <Eq>{`[2, +\infty)`}</Eq> makes <Eq>{`f`}</Eq> strictly increasing, hence injective; then we compute the inverse.

**Solution:**

1. <strong>Non-injectivity.</strong> Rewrite by completing the square: <Eq>{`f(x) = (x - 2)^2 + 1`}</Eq>. Then <Eq>{`f(0) = 4 + 1 = 5`}</Eq> and <Eq>{`f(4) = 4 + 1 = 5`}</Eq>. Since <Eq>{`0 \neq 4`}</Eq> but <Eq>{`f(0) = f(4)`}</Eq>, <Eq>{`f`}</Eq> is not injective.
2. <strong>Restriction:</strong> consider <Eq>{`f: [2, +\infty) \to [1, +\infty)`}</Eq>. On this restriction, <Eq>{`f`}</Eq> is increasing (the right side of the parabola), hence injective; the range is <Eq>{`[1, +\infty)`}</Eq>, hence also surjective — bijective.
3. <strong>Invert.</strong> Set <Eq>{`y = (x-2)^2 + 1 \Rightarrow (x-2)^2 = y - 1 \Rightarrow x - 2 = \pm\sqrt{y - 1}`}</Eq>. Since <Eq>{`x \geq 2`}</Eq>, we choose the positive branch: <Eq>{`x = 2 + \sqrt{y - 1}`}</Eq>. So <Eq>{`f^{-1}(y) = 2 + \sqrt{y - 1}`}</Eq>, with <Eq>{`y \geq 1`}</Eq>.

**Check:** <Eq>{`f(f^{-1}(y)) = (2 + \sqrt{y-1} - 2)^2 + 1 = (y - 1) + 1 = y`}</Eq>. ✓

**Source.** [OpenStax — College Algebra 2e §3.7](https://openstax.org/books/college-algebra-2e/pages/3-7-inverse-functions) — license CC-BY 4.0.

</Exemplo>

<Exemplo titulo="Real modeling: tiered electricity bill (real modeling)" numero="5">

**Problem:** A utility company charges electricity consumed <Eq>{`k`}</Eq> (in kWh) by tiers: up to 100 kWh pays US$0.60 per kWh; between 100 and 200 kWh pays US$0.90 for the excess; over 200 kWh pays US$1.30 for the excess. Model the total bill <Eq>{`C(k)`}</Eq> as a continuous piecewise function.

**Strategy:** Each tier adds a new "marginal price," applied only to consumption within that tier. The resulting function is affine by pieces and continuous at the boundary points (different from a step-jump charging).

**Solution:**

1. <strong>Tier 1 (up to 100 kWh):</strong> <Eq>{`C(k) = 0.60\, k`}</Eq>.
2. <strong>Tier 2 (100 to 200 kWh):</strong> the first 100 kWh cost <Eq>{`0.60 \times 100 = 60`}</Eq> dollars; the excess <Eq>{`(k - 100)`}</Eq> is charged at US$0.90: <Eq>{`C(k) = 60 + 0.90\,(k - 100) = 0.90\,k - 30`}</Eq>.
3. <strong>Tier 3 (over 200 kWh):</strong> the first 200 kWh cost <Eq>{`60 + 0.90 \times 100 = 150`}</Eq> dollars; the excess <Eq>{`(k - 200)`}</Eq> at US$1.30: <Eq>{`C(k) = 150 + 1.30\,(k - 200) = 1.30\,k - 110`}</Eq>.
4. <strong>Piecewise function:</strong> <Eq>{`C(k) = \begin{cases} 0.60\\,k & 0 \leq k \leq 100 \\\\ 0.90\\,k - 30 & 100 < k \leq 200 \\\\ 1.30\\,k - 110 & k > 200 \end{cases}`}</Eq>

**Continuity check:** at <Eq>{`k = 100`}</Eq>: tier 1 gives 60, tier 2 gives <Eq>{`90 - 30 = 60`}</Eq>. ✓ At <Eq>{`k = 200`}</Eq>: tier 2 gives <Eq>{`180 - 30 = 150`}</Eq>, tier 3 gives <Eq>{`260 - 110 = 150`}</Eq>. ✓ The function is continuous — correct model of marginal pricing.

**Source.** [Yoshiwara — Modeling, Functions, and Graphs chap. 2](https://textbooks.aimath.org/textbooks/approved-textbooks/yoshiwara/) — free license.
