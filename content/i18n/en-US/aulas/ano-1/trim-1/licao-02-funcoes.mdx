<Porta nivel="formal" titulo="Rigorous definition">

<Definicao titulo="Function">

Let $A$ and $B$ be non-empty sets. A **function** $f$ from $A$ to $B$, written $f: A \to B$, is a relation that assigns to each $x \in A$ exactly one element $f(x) \in B$.

- $A$ is the **domain** of $f$, denoted $\operatorname{dom}(f)$.
- $B$ is the **codomain**.
- $\operatorname{Im}(f) = \{f(x) : x \in A\} \subseteq B$ is the **image**.

</Definicao>

> "A function is a relation in which each input value produces exactly one output value." — [OpenStax College Algebra 2e, §3.1](https://openstax.org/books/college-algebra-2e/pages/3-1-functions-and-function-notation)

### Classification

<Definicao titulo="Types of function">

- **Injective** (one-to-one): $x_1 \neq x_2 \Rightarrow f(x_1) \neq f(x_2)$.
- **Surjective**: $\operatorname{Im}(f) = B$ (every $y \in B$ has at least one $x$ that maps to it).
- **Bijective**: injective AND surjective.

</Definicao>

<Porta nivel="5" titulo="For a 5-year-old">

Imagine a magic machine. You put a **number** in. The machine thinks for a moment. And another **number** comes out.

Every time you put in the same number, the machine always gives the same answer. Always. If the machine sometimes gives one answer and sometimes another, it is not a "function" — it is just a broken machine.

</Porta>

<Porta nivel="10" titulo="For a 10-year-old">

A function is a **fixed relationship** between two numbers.

Example: doubling a number. If you put in **3**, you get **6**. If you put in **5**, you get **10**. If you put in **8.7**, you get **17.4**. The rule is "output = input × 2".

We write this as $f(x) = 2x$. The **f** is just a name — you could call it **g**, **h**, **double**, anything. The **(x)** is the slot where you put the number that goes in.

Functions appear in **EVERYTHING** in science:
- Speed of a car as a **function of time**: $v(t) = ?$
- Cost of a trip as a **function of distance**: $C(d) = ?$
- Temperature throughout the day as a **function of the hour**: $T(h) = ?$

</Porta>

<Porta nivel="15" titulo="For a 15-year-old">

A function $f$ is a rule that assigns each input to a single output. The set of valid inputs is the **domain**, and the set of outputs that actually appear is the **image**.

Example: $f(x) = x^2$.

| $x$ (input) | $f(x)$ (output) |
|---:|---:|
| −2 | 4 |
| −1 | 1 |
| 0 | 0 |
| 1 | 1 |
| 2 | 4 |

Domain: $\mathbb{R}$ (any real number works as input). Image: $[0, +\infty)$ (the output is never negative).

**The graph** of this function is a parabola:

<Porta nivel="25" titulo="For an engineering student">

A function is the most important mathematical object in the entire calculus curriculum. Before differentiating or integrating, you need absolute clarity about what a function is.

### Maximum domain

When a problem says "study $f(x) = \sqrt{x - 1}$" without specifying a domain, we adopt the **natural maximum domain**: the largest subset of $\mathbb{R}$ on which the expression is defined.

- $\sqrt{x-1}$: $x - 1 \geq 0 \Rightarrow x \geq 1$, domain = $[1, +\infty)$.
- $1/(x-2)$: $x \neq 2$, domain = $\mathbb{R} \setminus \{2\}$.
- $\ln(x)$: $x > 0$, domain = $(0, +\infty)$.

> "To find the domain of a function defined by an equation, identify all restrictions on the input variable that would make the operation undefined." — [OpenStax College Algebra 2e, §3.2](https://openstax.org/books/college-algebra-2e/pages/3-2-domain-and-range)

### Composition

$(f \circ g)(x) = f(g(x))$. **Caution**: composition is not commutative in general.

Example: $f(x) = x^2$, $g(x) = x + 1$.
- $(f \circ g)(x) = f(x+1) = (x+1)^2$
- $(g \circ f)(x) = g(x^2) = x^2 + 1$

Different!

### Why injectivity matters

A function only admits an **inverse** if it is injective. Non-injective functions must be restricted. Classic example: $f(x) = x^2$ is not injective on $\mathbb{R}$, but it is injective on $[0, +\infty)$, where its inverse is $f^{-1}(y) = \sqrt{y}$.

### Functions and modeling

In engineering, a function is the object that represents a **phenomenon**:
- $T(t)$: temperature as a function of time (sensor)
- $V(I)$: voltage as a function of current (Ohm's law)
- $\sigma(\varepsilon)$: stress as a function of strain (Hooke's law)

Every dimensional analysis, every calibration, every model fit begins by understanding what the function is.

</Porta>

<Porta nivel="40" titulo="For a senior professional">

The definition of a function as "a rule that assigns" is informal. The rigorous definition, à la Bourbaki, is:

> A function $f: A \to B$ is a **subset** $f \subseteq A \times B$ such that for each $x \in A$ there exists **exactly one** $y \in B$ with $(x, y) \in f$. We write $y = f(x)$.

That is, a function IS its graph (in the set-theoretic sense). This is the operational definition for Logic and Set Theory. Day-to-day calculus does not use this formalization, but you will encounter it in Real Analysis (Calculus IV / undergraduate Real Analysis).

### Functions as morphisms

In Category Theory (the modern language of mathematics), functions are **morphisms** between sets. A bijection is an isomorphism in the category $\mathbf{Set}$. Function composition is morphism composition.

### Functions and computation

In computer science, the function is the central concept of functional programming (Haskell, Lisp). Currying — transforming $f: A \times B \to C$ into $f': A \to (B \to C)$ — is routine type manipulation. A "real" production function may have a signature like `User -> Order -> Promise<Receipt>` — which is exactly a mathematical $f: A \to B \to C$ with side effects.

### Modeling limitations

In real physical phenomena, "function" is an abstraction:
- **Hysteresis**: the state depends not only on the current input but on the past trajectory (plastic deformation). Not a function.
- **Quantum**: measurement is probabilistic — there is no single deterministic value. It is a probability distribution.
- **Chaos**: small variations in initial conditions produce arbitrarily different trajectories. Deterministic in theory, unpredictable in practice.

In all these cases, the concept of a function is insufficient, and richer abstractions (maps, stochastic processes, dynamics) come into play.

</Porta>

<Porta nivel="pratica" titulo="Practice — examples with real data">

### Example 1: Taxi fare (affine model)

A taxi charges:

$$T(d) = 5.50 + 3.10 \cdot d$$

where $T$ is the fare in R\$ and $d$ is the distance in km.

- Domain: $d \geq 0$ → $[0, +\infty)$
- Image: $T \geq 5.50$ → $[5.50, +\infty)$
- $T(0) = 5.50$ is the **base fare** (fixed boarding cost)
- $T(10) = 5.50 + 31 = 36.50$

### Example 2: BMI (Body Mass Index)

$$\text{BMI}(w, h) = \frac{w}{h^2}$$

- Function of **two variables** (weight $w$ in kg, height $h$ in meters).
- Physical domain: $w > 0$, $h > 0$ → $(0, +\infty)^2$.
- Image: $(0, +\infty)$.

WHO classification:
- BMI less than 18.5: underweight
- 18.5 ≤ BMI less than 25: normal
- 25 ≤ BMI less than 30: overweight
- BMI ≥ 30: obese

### Example 3: Policy interest rate (function of time, discontinuous)

The benchmark rate is set by the central bank at meetings every roughly 45 days. Between meetings it is constant. A "staircase" function:

```
Rate(Jan/2025) = 13.25%
Rate(Mar/2025) = 14.25%
Rate(May/2025) = 14.75%  (held since then)
```

Domain: time (dates). Codomain: percentages. Image: discrete, values dictated by the committee.

</Porta>

## Worked examples

> Five examples with increasing difficulty — from the most direct (numerical evaluation and domain reading) to real modeling (composition in a production pipeline). Each example cites its source: the original problem always comes from an open-licensed book.

<Exemplo titulo="Evaluation and direct domain (application)" numero="1">

**Problem:** For $f(x) = 3x^2 - 2x + 1$, compute $f(-1)$, $f(0)$, and $f(2)$. Determine the maximum domain.

**Strategy:** Evaluating a function at a point means substituting the variable with the given value and computing. The maximum domain of a polynomial is all of $\mathbb{R}$, since polynomials are defined at any real number.

**Solution:**

1.  **$f(-1)$:** Substitute $x = -1$:
    $f(-1) = 3(-1)^2 - 2(-1) + 1 = 3(1) + 2 + 1 = 6$.
2.  **$f(0)$:** Substitute $x = 0$:
    $f(0) = 3(0)^2 - 2(0) + 1 = 0 - 0 + 1 = 1$.
3.  **$f(2)$:** Substitute $x = 2$:
    $f(2) = 3(2)^2 - 2(2) + 1 = 3(4) - 4 + 1 = 12 - 4 + 1 = 9$.
4.  **Domain:** Since $f$ is a polynomial, there is no restriction. Domain = $\mathbb{R}$.

**Verification:** All three values are finite. To confirm consistency, note that $f(0) = 1$ is the constant term — this always holds for any polynomial.

**Source.** [OpenStax — College Algebra 2e §3.1](https://openstax.org/books/college-algebra-2e/pages/3-1-functions-and-function-notation) — CC-BY 4.0 license.
</Exemplo>

<Exemplo titulo="Maximum domain with combined restrictions (intermediate)" numero="2">

**Problem:** Determine the maximum domain of $f(x) = \dfrac{\sqrt{x + 2}}{x - 3}$.

**Strategy:** There are two simultaneous restrictions: the radicand $x + 2$ must be non-negative (for the square root to exist in the reals), and the denominator $x - 3$ cannot be zero. The domain is the intersection of these two conditions.

**Solution:**

1.  **Square root restriction:** $x + 2 \geq 0 \Rightarrow x \geq -2$, i.e., $x \in [-2, +\infty)$.
2.  **Denominator restriction:** $x - 3 \neq 0 \Rightarrow x \neq 3$, i.e., $x \in \mathbb{R} \setminus \{3\}$.
3.  **Intersection:** $[-2, +\infty) \cap (\mathbb{R} \setminus \{3\}) = [-2, 3) \cup (3, +\infty)$.

**Verification:**
- $x = -2$: $\sqrt{0}/(-5) = 0$. OK (included).
- $x = 3$: division by zero. Excluded. OK.
- $x = -3$: $\sqrt{-1}$ does not exist in the reals. Excluded. OK.
- $x = 5$: $\sqrt{7}/2$. OK.

**Source.** [OpenStax — College Algebra 2e §3.2](https://openstax.org/books/college-algebra-2e/pages/3-2-domain-and-range) — CC-BY 4.0 license.
</Exemplo>

<Exemplo titulo="Function composition (intermediate)" numero="3">

**Problem:** Let $f(x) = x^2 + 1$ and $g(x) = 2x - 3$. Compute $(f \circ g)(x)$ and $(g \circ f)(x)$. Show they differ at $x = 1$.

**Strategy:** Composition $(f \circ g)(x)$ means "apply $g$ first, then $f$". That is, $f(g(x))$. Swapping the order generally produces different functions — a classic warning.

**Solution:**

1.  **$(f \circ g)(x) = f(g(x))$:** substitute $g(x) = 2x - 3$ in place of $x$ in $f$:
    $f(2x - 3) = (2x - 3)^2 + 1 = 4x^2 - 12x + 9 + 1 = 4x^2 - 12x + 10$.
2.  **$(g \circ f)(x) = g(f(x))$:** substitute $f(x) = x^2 + 1$ in place of $x$ in $g$:
    $g(x^2 + 1) = 2(x^2 + 1) - 3 = 2x^2 + 2 - 3 = 2x^2 - 1$.
3.  **At $x = 1$:**
    - $(f \circ g)(1) = 4 - 12 + 10 = 2$.
    - $(g \circ f)(1) = 2 - 1 = 1$.
    Different — composition **does not commute**.

**Verification:** Try also $x = 0$: $(f \circ g)(0) = 10$ and $(g \circ f)(0) = -1$. Different at all points except possibly at solutions of $4x^2 - 12x + 10 = 2x^2 - 1$, i.e., $2x^2 - 12x + 11 = 0$.

**Source.** [Stitz–Zeager — Precalculus §5.1](https://www.stitz-zeager.com/szprecalculus07042013.pdf) — CC-BY-NC-SA license.
</Exemplo>

<Exemplo titulo="Inverse and domain restriction (advanced)" numero="4">

**Problem:** Let $f(x) = x^2 - 4x + 5$ defined on $\mathbb{R}$. Show that $f$ is not injective on $\mathbb{R}$. Restrict the domain to an interval where $f$ is injective and determine $f^{-1}$ on that restriction.

**Strategy:** A quadratic function is not injective on $\mathbb{R}$: points symmetric about the axis of the parabola have the same image. The axis of symmetry is $x = 2$ (vertex). Restricting to $[2, +\infty)$ makes $f$ strictly increasing, hence injective; then we compute the inverse.

**Solution:**

1.  **Non-injectivity.** Complete the square: $f(x) = (x - 2)^2 + 1$. Then $f(0) = 4 + 1 = 5$ and $f(4) = 4 + 1 = 5$. Since $0 \neq 4$ but $f(0) = f(4)$, $f$ is not injective.
2.  **Restriction:** consider $f: [2, +\infty) \to [1, +\infty)$. On this restriction $f$ is increasing (the right branch of the parabola), hence injective; the image is $[1, +\infty)$, hence also surjective — bijective.
3.  **Invert.** Set $y = (x-2)^2 + 1 \Rightarrow (x-2)^2 = y - 1 \Rightarrow x - 2 = \pm\sqrt{y - 1}$. Since $x \geq 2$, we choose the positive branch: $x = 2 + \sqrt{y - 1}$. Therefore $f^{-1}(y) = 2 + \sqrt{y - 1}$, with $y \geq 1$.

**Verification:** $f(f^{-1}(y)) = (2 + \sqrt{y-1} - 2)^2 + 1 = (y - 1) + 1 = y$. $\checkmark$

**Source.** [OpenStax — College Algebra 2e §3.7](https://openstax.org/books/college-algebra-2e/pages/3-7-inverse-functions) — CC-BY 4.0 license.
</Exemplo>

<Exemplo titulo="Real-world modeling: tiered electricity bill (real modeling)" numero="5">

**Problem:** A utility company charges for energy consumed $k$ (in kWh) in tiers: up to 100 kWh pay R\$ 0.60 per kWh; between 100 and 200 kWh pay R\$ 0.90 on the excess; above 200 kWh pay R\$ 1.30 on the excess. Model the total bill $C(k)$ as a continuous piecewise function.

**Strategy:** Each tier adds a new "marginal price", applied only to consumption within that tier. The resulting function is piecewise affine and continuous at the boundary points (unlike a step-charge model).

**Solution:**

1.  **Tier 1 (up to 100 kWh):** $C(k) = 0.60\, k$.
2.  **Tier 2 (100 to 200 kWh):** the first 100 kWh cost $0.60 \times 100 = 60$ reais; the excess $(k - 100)$ is charged at R\$ 0.90:
    $C(k) = 60 + 0.90\,(k - 100) = 0.90\,k - 30$.
3.  **Tier 3 (above 200 kWh):** the first 200 kWh cost $60 + 0.90 \times 100 = 150$ reais; the excess $(k - 200)$ at R\$ 1.30:
    $C(k) = 150 + 1.30\,(k - 200) = 1.30\,k - 110$.
4.  **Piecewise function:**
    $$C(k) = \begin{cases} 0.60\,k & \text{if } 0 \leq k \leq 100 \\ 0.90\,k - 30 & \text{if } 100 < k \leq 200 \\ 1.30\,k - 110 & \text{if } k > 200 \end{cases}$$

**Continuity check:** at $k = 100$: branch 1 gives 60, branch 2 gives $90 - 30 = 60$. $\checkmark$ At $k = 200$: branch 2 gives $180 - 30 = 150$, branch 3 gives $260 - 110 = 150$. $\checkmark$ The function is continuous — correct marginal billing model.

**Source.** [Yoshiwara — Modeling, Functions, and Graphs ch. 2](https://textbooks.aimath.org/textbooks/approved-textbooks/yoshiwara/) — free license.
</Exemplo>
