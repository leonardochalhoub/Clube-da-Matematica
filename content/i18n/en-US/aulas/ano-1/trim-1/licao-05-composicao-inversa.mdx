### Function composition

<Definicao titulo="Composition">

Let $f: B \to C$ and $g: A \to B$. The **composition** $f \circ g : A \to C$ is the function defined by

$$
(f \circ g)(x) = f(g(x)), \quad \forall x \in A.
$$

The domain of $f \circ g$ is the set of all $x \in \operatorname{dom}(g)$ such that $g(x) \in \operatorname{dom}(f)$:

$$
\operatorname{dom}(f \circ g) = \{x \in \operatorname{dom}(g) : g(x) \in \operatorname{dom}(f)\}.
$$

</Definicao>

> "When we combine functions so that the output of one function becomes the input of another, we create a **composition of functions**. The resulting function is called a *composite function*." — [OpenStax College Algebra 2e, §3.4](https://openstax.org/books/college-algebra-2e/pages/3-4-composition-of-functions)

<Insight>

**Order matters.** In general $f \circ g \neq g \circ f$. For $f(x) = 2x$ and $g(x) = x + 3$: $(f \circ g)(x) = 2x + 6$ and $(g \circ f)(x) = 2x + 3$. Composition is like getting dressed: putting on socks before shoes is different from shoes before socks.

</Insight>

### Inverse function

<Definicao titulo="Inverse">

$f: A \to B$ has an **inverse function** if and only if $f$ is **bijective**. In that case, the function $f^{-1}: B \to A$ is the unique function satisfying simultaneously:

$$
f^{-1}(f(x)) = x \quad \forall x \in A, \qquad f(f^{-1}(y)) = y \quad \forall y \in B.
$$

Equivalently, $f \circ f^{-1} = \operatorname{id}_B$ and $f^{-1} \circ f = \operatorname{id}_A$.

</Definicao>

> "In order for a function to have an inverse, it must be a **one-to-one** function. A function is one-to-one if each output value corresponds to exactly one input value." — [Stitz–Zeager Precalculus, §5.2](https://www.stitz-zeager.com/szprecalculus07042013.pdf)

<Definicao titulo="Algorithm for computing the inverse">

Given $y = f(x)$, to find $f^{-1}$:

1. Write $y = f(x)$.
2. Swap $x \leftrightarrow y$: write $x = f(y)$.
3. Solve for $y$ — the result is $f^{-1}(x)$.

</Definicao>

<Teorema titulo="Inverse of the composite">

If $f: B \to C$ and $g: A \to B$ are both bijective, then $f \circ g: A \to C$ is bijective and

$$(f \circ g)^{-1} = g^{-1} \circ f^{-1}.$$

**Proof (sketch).** Compute $(g^{-1} \circ f^{-1}) \circ (f \circ g)$. By associativity: $g^{-1} \circ (f^{-1} \circ f) \circ g = g^{-1} \circ \operatorname{id}_B \circ g = g^{-1} \circ g = \operatorname{id}_A$. ∎

</Teorema>

<Insight>

**Socks-and-shoes mnemonic.** To undo "put on socks then shoes," you must first **remove the shoes**, then the socks — reversed order. That is exactly $(f \circ g)^{-1} = g^{-1} \circ f^{-1}$.

</Insight>

<Porta nivel="5" titulo="For a 5-year-old">

You have **two machines**.

The first machine takes a number and **adds 1**. Put in 3, get 4. Put in 7, get 8.

The second machine takes a number and **multiplies by 2**. Put in 4, get 8. Put in 5, get 10.

If you connect the two in a row, what comes out of the first machine goes into the second. Put 3 into the first: out comes 4. Goes into the second: out comes 8. That is **composition** — two machines in a row.

And there is a machine that **undoes** things. If the machine adds 1, the undoing machine subtracts 1. You put in 8: out comes 7. The undoing machine is the **inverse**.

</Porta>

<Porta nivel="10" titulo="For a 10-year-old">

**Composition** means applying two formulas in sequence.

Example: $g(x) = x - 2$ and $f(u) = 3u + 5$. Composition $f$ after $g$:

1. Apply $g$ to $x$: gives $x - 2$.
2. Plug the result into $f$: gives $3(x - 2) + 5 = 3x - 1$.

Therefore $(f \circ g)(x) = 3x - 1$.

**Inverse** means undoing. If the formula is $f(x) = 2x + 3$, to undo it: subtract 3, then divide by 2. Result: $f^{-1}(x) = (x - 3)/2$.

**Visual trick.** On the graph, the inverse is the reflection of the original across the **diagonal line** $y = x$.

**Not every function has an inverse.** $f(x) = x^2$ does not. Why? Because $f(2) = 4$ and $f(-2) = 4$: if I only give you "4," you cannot tell whether it came from 2 or from −2. There is no way to undo it.

</Porta>

<Porta nivel="15" titulo="For a 15-year-old">

**Composition** chains two operations: the output of $g$ becomes the input of $f$.

**Watch the order:** $f \circ g$ is read "f after g," and in general $f \circ g \neq g \circ f$.

For $f(x) = 2x$ and $g(x) = x + 3$:
- $(f \circ g)(x) = f(g(x)) = f(x+3) = 2(x+3) = 2x + 6$
- $(g \circ f)(x) = g(f(x)) = g(2x) = 2x + 3$

Different!

**Domain of the composite.** When computing $f(g(x))$, $g(x)$ must land in the domain of $f$. Restrictions arise: for $f(x) = \sqrt{x}$ and $g(x) = x^2 - 4$, we need $g(x) \geq 0$, i.e., $x^2 \geq 4$, so $x \leq -2$ or $x \geq 2$.

**Algorithm for finding $f^{-1}$:** swap $x \leftrightarrow y$, solve.

Example: $f(x) = 4x - 7$.
$$y = 4x - 7 \quad \to \quad x = 4y - 7 \quad \to \quad y = \frac{x + 7}{4}$$
Therefore $f^{-1}(x) = (x + 7)/4$.

**Verification:** $f(f^{-1}(x)) = 4 \cdot \dfrac{x+7}{4} - 7 = x$. Correct!

<Insight>

**Condition for $f^{-1}$ to exist: bijection.** A function has an inverse if and only if it is injective (each output has at most one input) and surjective (each output is reached by at least one input). This can be tested graphically by the **horizontal line test**: if no horizontal line crosses the graph more than once, the function is injective.

</Insight>

</Porta>

<Porta nivel="25" titulo="For an engineering student">

Composition is the central mechanism of calculus: the **chain rule** (Trim 6) is precisely $(f \circ g)'(x) = f'(g(x)) \cdot g'(x)$. Correctly decomposing an expression into inner and outer parts is a prerequisite for differentiating accurately.

### Domain of the composite — with care

$\operatorname{dom}(f \circ g) = \{x \in \operatorname{dom}(g) : g(x) \in \operatorname{dom}(f)\}$.

For $f(x) = 1/(x-2)$ and $g(x) = 1/x$: we need $x \neq 0$ (for $g$ to be defined) and $g(x) \neq 2$, i.e., $1/x \neq 2$, i.e., $x \neq 1/2$. Therefore $\operatorname{dom}(f \circ g) = \mathbb{R} \setminus \{0, 1/2\}$.

### Inverse: bijective or restrict

$f$ has a global inverse $\iff$ $f$ is bijective. In practice:

- **Not injective?** Restrict the domain. $f(x) = x^2$ becomes injective and invertible on $[0, +\infty)$ with $f^{-1}(y) = \sqrt{y}$.
- **Not surjective?** Restrict the codomain to the image.

### Symmetric group

The bijections from a set $A$ to itself, under composition, form a **group** called $\text{Sym}(A)$ (or $S_n$ when $A$ has $n$ finite elements). The identity element is $\operatorname{id}_A$; the inverse of $f$ is $f^{-1}$. This is the fundamental structure of abstract algebra.

### Simple cryptography

A **substitution cipher** encrypts via $E: \{a,\ldots,z\} \to \{0,\ldots,25\}$ and decrypts via $D = E^{-1}$. If $E$ is not bijective, decryption is impossible. The Caesar cipher is $E(x) = (x + k) \bmod 26$ with inverse $E^{-1}(y) = (y - k) \bmod 26$.

### Notation: $f^{-1} \neq 1/f$

$f^{-1}(x)$ denotes the inverse function of $f$. It is NOT $1/f(x)$. This confusion persists well into the second year of university.

</Porta>

<Porta nivel="40" titulo="For a senior professional">

**Functional composition is the foundation of every pipeline.** In Haskell, `(f . g) x = f (g x)`. In Python, `functools.reduce(compose, [f, g, h])`. In SQL, subqueries are compositions. In sklearn, `Pipeline` is a composition of transformers. Every abstraction for "data flow" is, at its core, an algebra of compositions.

### Inverse problems and regularization

In engineering, the classical inverse problem is: **given $y$, find $x$ such that $f(x) = y$.** In computed tomography, $f$ is the Radon operator; in seismology, it is the wave propagation operator. If $f$ is not injective (underdetermined system), or if there is noise, "$f^{-1}$" is ill-posed in the Hadamard sense. The solution: **Tikhonov regularization** minimizes $\|f(x) - y\|^2 + \lambda \|x\|^2$, producing a stable pseudo-inverse. Ridge regression in ML is exactly this.

### Iterated functions and dynamics

$f^n(x) = \underbrace{f \circ f \circ \cdots \circ f}_{n}(x)$. The study of orbits $\{x, f(x), f^2(x), \ldots\}$ is the core of **dynamical systems theory**: fixed points, cycles, attractors. The Mandelbrot set is $\{c \in \mathbb{C} : f_c^n(0)\text{ does not diverge}\}$ where $f_c(z) = z^2 + c$.

**Neural networks are compositions.** An $L$-layer network is $f_\theta = f^{(L)} \circ \cdots \circ f^{(1)}$, where each $f^{(k)}(x) = \sigma(W^{(k)} x + b^{(k)})$. Training optimizes the parameters of this composition via backpropagation — which is precisely the chain rule applied recursively.

### Inverses at industrial scale

Computing $f^{-1}$ analytically is rare in production. **Newton-Raphson** is used to solve $f(x) = y$ numerically. Computing the implied volatility of Black-Scholes (lesson 119) is exactly this: given the market price of an option, numerically invert the BS formula to extract $\sigma$.

</Porta>

<Porta nivel="pratica" titulo="Practice — examples with real data">

### Celsius/Fahrenheit conversion

Directly, converting to Fahrenheit: $F(C) = \dfrac{9}{5}C + 32$.

Inverse (Fahrenheit to Celsius): swap and solve:

$$x = \frac{9}{5}y + 32 \quad\Rightarrow\quad y = \frac{5}{9}(x - 32)$$

Therefore $F^{-1}(x) = \dfrac{5}{9}(x - 32)$.

Application: 100 °F (fever in the US) $\Rightarrow$ $\dfrac{5}{9}(68) = 37.78$ °C. Normal temperature: $F^{-1}(98.6) = 37$ °C.

### Normalization pipeline (ML / data science)

In preprocessing, z-score normalization is the composition:

1. $g(x) = x - \bar{x}$ (centering)
2. $f(y) = y/\sigma$ (scaling)

Composition: $(f \circ g)(x) = (x - \bar{x})/\sigma$.

Inverse to back-transform model predictions: $(f \circ g)^{-1} = g^{-1} \circ f^{-1}$, that is, first $f^{-1}(z) = z \cdot \sigma$, then $g^{-1}(y) = y + \bar{x}$. Result: $(f \circ g)^{-1}(z) = z \cdot \sigma + \bar{x}$.

### Caesar cipher

Encodes each letter $\ell \in \{0, \ldots, 25\}$ with shift $k$:

$$E_k(\ell) = (\ell + k) \bmod 26$$

Decryption = inverse: $D_k(\ell) = (\ell - k) \bmod 26 = E_{-k}(\ell)$.

For $k = 3$: "A" (=0) $\to$ "D" (=3). Decrypt: "D" (=3) $\to$ "A" (=0). The decryption function is literally $E_k^{-1}$.

</Porta>

## Worked examples

<Exemplo titulo="Computing (f∘g)(x) — noting that order changes the result" numero="1">

**Problem:** Given $f(x) = 3x + 1$ and $g(x) = x^2$, compute $(f \circ g)(x)$ and $(g \circ f)(x)$ and compare.

**Strategy:** Apply the definition $(f \circ g)(x) = f(g(x))$ — first evaluate $g(x)$, then substitute the result into $f$. Repeat in reverse order for $(g \circ f)$.

**Solution:**

1. $(f \circ g)(x) = f(g(x)) = f(x^2) = 3x^2 + 1$.
2. $(g \circ f)(x) = g(f(x)) = g(3x + 1) = (3x + 1)^2 = 9x^2 + 6x + 1$.
3. Compare: $3x^2 + 1 \neq 9x^2 + 6x + 1$. The order changed everything.

**Verification:** At $x = 2$: $(f \circ g)(2) = 3 \cdot 4 + 1 = 13$ and $(g \circ f)(2) = 7^2 = 49$. Distinct, confirming non-commutativity.

**Source.** [OpenStax College Algebra 2e §3.4](https://openstax.org/books/college-algebra-2e/pages/3-4-composition-of-functions) — CC-BY 4.0.
</Exemplo>

<Exemplo titulo="Finding the inverse of an affine function and verifying" numero="2">

**Problem:** Determine $f^{-1}(x)$ for $f(x) = 4x - 7$. Verify that $f \circ f^{-1} = f^{-1} \circ f = \operatorname{id}$.

**Strategy:** Standard algorithm: write $y = f(x)$, swap $x \leftrightarrow y$, solve for $y$. Then validate.

**Solution:**

1. $y = 4x - 7$.
2. Swap: $x = 4y - 7$.
3. Solve: $4y = x + 7 \Rightarrow y = (x + 7)/4$.
4. Therefore $f^{-1}(x) = (x + 7)/4$.

**Verification:**
- $f(f^{-1}(x)) = 4 \cdot \dfrac{x+7}{4} - 7 = (x + 7) - 7 = x$. ✓
- $f^{-1}(f(x)) = \dfrac{(4x - 7) + 7}{4} = \dfrac{4x}{4} = x$. ✓

**Source.** [OpenStax College Algebra 2e §5.7](https://openstax.org/books/college-algebra-2e/pages/5-7-inverses-and-radical-functions) — CC-BY 4.0.
</Exemplo>

<Exemplo titulo="Domain of the composite with a square root — watch for restrictions" numero="3">

**Problem:** Let $f(x) = \sqrt{x}$ and $g(x) = x^2 - 4$. Determine $(f \circ g)(x)$ and the maximal domain.

**Strategy:** The composite exists where $g(x)$ falls in the domain of $f$, i.e., where $g(x) \geq 0$.

**Solution:**

1. $(f \circ g)(x) = f(g(x)) = \sqrt{x^2 - 4}$.
2. For it to exist: $x^2 - 4 \geq 0 \Rightarrow x^2 \geq 4 \Rightarrow |x| \geq 2$.
3. Domain: $(-\infty, -2] \cup [2, +\infty)$.

**Verification:** At $x = 3$: $g(3) = 5$; $f(5) = \sqrt{5}$. And $\sqrt{9-4} = \sqrt{5}$. ✓. At $x = 1$: $g(1) = -3 < 0$, outside the domain of $f$ — correct.

**Source.** [Stitz–Zeager Precalculus §5.1](https://www.stitz-zeager.com/szprecalculus07042013.pdf) — CC-BY-NC-SA.
</Exemplo>

<Exemplo titulo="Inverse of a quadratic function with domain restriction" numero="4">

**Problem:** $f(x) = x^2 - 4x + 7$ is not invertible on $\mathbb{R}$. Restrict the domain so it becomes invertible and determine $f^{-1}$.

**Strategy:** Complete the square to identify the vertex. Restrict to one branch (convention: right branch) and invert.

**Solution:**

1. $f(x) = (x-2)^2 + 3$. Vertex $(2, 3)$, parabola increasing for $x \geq 2$.
2. Restrict to $A = [2, +\infty)$: $f$ is strictly increasing, hence injective.
3. $y = (x-2)^2 + 3 \Rightarrow (x-2)^2 = y - 3$. Since $x \geq 2$, we have $x - 2 = \sqrt{y-3}$, so $x = 2 + \sqrt{y-3}$.
4. $f^{-1}: [3, +\infty) \to [2, +\infty)$, $f^{-1}(y) = 2 + \sqrt{y-3}$.

**Verification:** $f^{-1}(7) = 2 + \sqrt{4} = 4$. $f(4) = (4-2)^2 + 3 = 7$. ✓

**Source.** [OpenStax College Algebra 2e §5.7](https://openstax.org/books/college-algebra-2e/pages/5-7-inverses-and-radical-functions) — CC-BY 4.0.
</Exemplo>

<Exemplo titulo="Chain composition: currency conversion modeled as inverse of a composite" numero="5">

**Problem:** Conversion USD → BRL via $f(d) = 5.00 \cdot d$ (simplified rate). Conversion BRL → loyalty points via $g(r) = r/10$. (a) Model the composite function USD → points. (b) Determine the inverse points → USD. (c) How many dollars correspond to 150 points?

**Strategy:** The direct composition is $g \circ f$. The inverse is $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$ — note the reversed order.

**Solution:**

1. $(g \circ f)(d) = g(f(d)) = g(5d) = 5d/10 = d/2$.
2. $f^{-1}(r) = r/5$ and $g^{-1}(p) = 10p$.
3. $(g \circ f)^{-1}(p) = f^{-1}(g^{-1}(p)) = f^{-1}(10p) = 10p/5 = 2p$.
4. For $p = 150$: $2 \cdot 150 = 300$ dollars.

**Verification:** USD 300 $\to$ BRL 1,500 $\to$ 150 points. ✓

**Source.** [Yoshiwara — Modeling, Functions, and Graphs ch. 4](https://textbooks.aimath.org/textbooks/approved-textbooks/yoshiwara/) — free.
</Exemplo>
