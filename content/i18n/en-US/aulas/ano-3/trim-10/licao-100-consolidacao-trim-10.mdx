<Porta nivel="formal" titulo="Map of techniques and ODE decision criteria">

<Definicao titulo="ODE classification flowchart">

Given an ordinary differential equation, walk through:

1. **Order?** How many derivatives? Only <Eq>{`y'`}</Eq>: 1st order. Has <Eq>{`y''`}</Eq>: 2nd order.
2. **Linear?** Are all terms in <Eq>{`y, y', y''`}</Eq> linear (no products, no functions of <Eq>{`y`}</Eq>)?
3. **1st-order linear**: <Eq>{`y' + p(x)y = q(x)`}</Eq> → integrating factor <Eq>{`\\mu = e^{\\int p\\,dx}`}</Eq>.
4. **1st-order separable**: <Eq>{`y' = g(x)h(y)`}</Eq> → separate and integrate.
5. **2nd-order constant coeff**: <Eq>{`ay'' + by' + cy = q(x)`}</Eq> → characteristic equation + <Eq>{`y_p`}</Eq> by undetermined coefficients or variation of parameters.
6. **Non-analytic**: any form that doesn't fit above → numerical (Euler/RK4).

</Definicao>

> "The existence and uniqueness theorem says: there is exactly one solution curve through each point (x₀, y₀) where f and ∂f/∂y are continuous."
> — [Lebl, *Notes on Diffy Qs* §1.2](https://www.jirka.org/diffyqs/html/intro_section.html)

> "The idea behind the integrating factor is to write the left-hand side as an exact derivative."
> — [OpenStax *Calculus Vol. 2* §4.5](https://openstax.org/books/calculus-volume-2/pages/4-5-first-order-linear-equations)

**Techniques table for the trimester:**

| ODE | Canonical form | Technique | General solution |
|---|---|---|---|
| Separable | <Eq>{`y' = g(x)h(y)`}</Eq> | Separate and integrate | Implicit |
| Linear 1st | <Eq>{`y'+py=q`}</Eq> | <Eq>{`\\mu=e^{\\int p}`}</Eq> | <Eq>{`y = \\frac{1}{\\mu}\\int\\mu q\\,dx + C`}</Eq> |
| Malthus | <Eq>{`\\dot P = rP`}</Eq> | Separable | <Eq>{`P = P_0 e^{rt}`}</Eq> |
| Logistic | <Eq>{`\\dot P = rP(1-P/K)`}</Eq> | Separable + partial fractions | <Eq>{`P = K/(1+Ae^{-rt})`}</Eq> |
| Cooling | <Eq>{`\\dot T = -k(T-T_a)`}</Eq> | Separable | <Eq>{`T = T_a + (T_0-T_a)e^{-kt}`}</Eq> |
| 2nd homog. | <Eq>{`ay''+by'+cy=0`}</Eq> | Char. <Eq>{`a\\lambda^2+b\\lambda+c=0`}</Eq> | 3 cases |
| 2nd forced | <Eq>{`ay''+by'+cy=q`}</Eq> | <Eq>{`y_h + y_p`}</Eq> | Undetermined coeff. |
| Numerical Euler | Any | <Eq>{`y_{n+1}=y_n+hf`}</Eq> | Sequence |

<Teorema titulo="Structure of linear 2nd-order solution">

If <Eq>{`y_1, y_2`}</Eq> are linearly independent solutions of <Eq>{`ay'' + by' + cy = 0`}</Eq> and <Eq>{`y_p`}</Eq> is any particular solution of <Eq>{`ay'' + by' + cy = q(x)`}</Eq>, then every solution of the non-homogeneous equation is

<Equation latex="y = C_1 y_1 + C_2 y_2 + y_p, \quad C_1, C_2 \in \mathbb{R}." />

**Proof (sketch).** Let <Eq>{`z`}</Eq> be another solution; then <Eq>{`z - y_p`}</Eq> satisfies the homogeneous equation, hence belongs to the span of <Eq>{`y_1, y_2`}</Eq>. <Eq>{`\\square`}</Eq>

</Teorema>

<Porta nivel="5" titulo="Equations that change over time">

We learned to handle **things that change all the time**: temperature cooling down, populations growing, bridges swaying.

For each type of change there is a **different trick**. Sometimes the math separates variables into a simple account. Sometimes you need a "magic factor" that makes everything easier. And when no trick works, the computer does **step by step** until it reaches the answer.

In this lesson we put all the tricks together and pick the right one for each problem.

</Porta>

<Porta nivel="10" titulo="Eight techniques, one map">

Over trimester 10, you learned **eight ways** to handle change equations:

1. **Separable** — x and y separate: integrate each side.
2. **First-order linear** — integrating factor transforms into one side only.
3. **Malthus** — growth proportional: exponential.
4. **Logistic** — growth with capacity limit.
5. **2nd-order homogeneous** — characteristic equation gives exponentials or sines.
6. **Vibrations** — mass-spring with damping and forcing.
7. **RLC** — identical to mass-spring, but with electrons.
8. **Euler/RK4** — when there is no closed form, the computer solves step by step.

**How to choose?** Look at how many derivatives: only <Eq>{`y'`}</Eq> → first order. Has <Eq>{`y''`}</Eq> → second. If you recognize one of the canonical models (logistic, cooling, mass-spring), use that one directly.

</Porta>

<Porta nivel="15" titulo="Decision flowchart and common errors">

### Quick decision

```
ODE arrives:
├─ Only y': 1st order
│  ├─ Separate x and y? → separable, integrate
│  ├─ Form y' + p(x)y = q(x)? → integrating factor
│  └─ None? → substitution (Bernoulli, exact) or numerical
└─ Has y'': 2nd order
   ├─ Constant coeff?
   │  ├─ Homogeneous → characteristic equation
   │  └─ Forced → y_h + y_p (undetermined coeff.)
   └─ Variable coeff → Cauchy-Euler, series or numerical
```

### Classic errors of the trimester

- **Forget singular solutions in separable**: if <Eq>{`h(y_0) = 0`}</Eq>, then <Eq>{`y \\equiv y_0`}</Eq> is a singular solution. Division by <Eq>{`h(y)`}</Eq> only works away from roots.
- **Use integrating factor on non-linear ODE**: <Eq>{`y' = y^2`}</Eq> is not linear, has no integrating factor.
- **Mix up <Eq>{`\\omega_0`}</Eq> and <Eq>{`\\omega_d`}</Eq>**: natural vs. damped frequency. <Eq>{`\\omega_d = \\omega_0\\sqrt{1-\\zeta^2}`}</Eq>.
- **Large Euler step on stiff problem**: system with short time constant (RLC with large R) destabilizes explicit Euler.
- **Resonance**: when force has frequency <Eq>{`\\omega_0`}</Eq> and <Eq>{`\\zeta = 0`}</Eq>, <Eq>{`y_p`}</Eq> must include factor <Eq>{`t`}</Eq>.

### Quick check

Always substitute the solution back into the original ODE. If the result doesn't match, the solution is wrong.

</Porta>

<Porta nivel="25" titulo="Engineering map: domains and canonical ODEs">

ODEs are the **language of engineering**. Each domain has its structural models.

### Mechanics

- Translational dynamics: <Eq>{`m\\ddot x = F`}</Eq>.
- Linear vibration: <Eq>{`m\\ddot x + c\\dot x + kx = F(t)`}</Eq>. Quality factor <Eq>{`Q = 1/(2\\zeta)`}</Eq>.
- Stability: linearization around equilibrium, eigenvalues of <Eq>{`Df(x^*)`}</Eq>.

### Electricity

- RC, RL, LC, RLC: exact analogues of mass-spring.
- Transmission line: telegraph equation (PDE → ODE by separation).
- Electrical machines: Park equations (dq0 transformation).

### Chemistry and processes

- First-order kinetics: <Eq>{`\\dot c = -kc`}</Eq>.
- CSTR with exothermic reaction: mass + energy balance, coupled ODE system.
- Diffusion-reaction (1D): <Eq>{`D c'' = \\lambda c`}</Eq> (2nd-order ODE in space).

### Control

- PID controls 2nd-order plant. Closed-loop poles determine response.
- State feedback: <Eq>{`\\dot{\\mathbf x} = A\\mathbf x + B\\mathbf u`}</Eq>, <Eq>{`\\mathbf u = -K\\mathbf x`}</Eq>.
- Routh-Hurwitz criterion: stability without solving the equation.

### Professional workflow

1. **Model** from physics (balances).
2. **Nondimensionalize** — identify Bi, Re, <Eq>{`\\zeta`}</Eq>, <Eq>{`\\omega_0 T`}</Eq>.
3. **Linearize** if <Eq>{`\\Delta`}</Eq> small; analytic becomes accessible.
4. **Solve** analytically or numerically.
5. **Validate** with experiment or high-fidelity simulation.
6. **Optimize** parameters (control, sizing).

</Porta>

<Porta nivel="40" titulo="Dynamical systems, adjoints and modern frontiers">

### Geometry and flows

Every autonomous ODE <Eq>{`\\dot x = f(x)`}</Eq> defines a **flow** <Eq>{`\\phi_t`}</Eq> on a manifold. Central concepts:

- **Equilibria**: <Eq>{`f(x^*) = 0`}</Eq>. Hartman-Grobman: <Eq>{`\\phi_t`}</Eq> is locally topologically conjugate to linearization if <Eq>{`Df(x^*)`}</Eq> has no purely imaginary eigenvalue.
- **Stable/unstable manifolds**: invariant; structure the phase portrait.
- **Bifurcations**: saddle-node, Hopf, period-doubling. Parametric bifurcation diagrams.
- **Chaos**: positive Lyapunov exponents. Lorenz attractor.

### ODE adjoint

To optimize functional <Eq>{`J = \\int_0^T g(x,u)\\,dt`}</Eq> subject to <Eq>{`\\dot x = f(x,u)`}</Eq>, the gradient wrt <Eq>{`u`}</Eq> is computed via **backward adjoint equation**. Cost: one forward integration + one backward, independent of <Eq>{`u`}</Eq> dimension. Foundation of modern backpropagation in Neural ODEs (Chen et al., NeurIPS 2018).

### Modern methods

- **SINDy** (Brunton et al., 2016): identifies ODE from data via sparse regression.
- **Neural ODE**: residual network in continuous limit; trains with adjoint.
- **PINN** (Raissi et al., 2019): minimizes ODE residual + data.
- **Geometric integration**: symplectic (Störmer-Verlet) conserve energy; Lie-group preserve structure.

### Related Nobel Prize

James Peebles received the [2019 Nobel Prize in Physics](https://www.nobelprize.org/prizes/physics/2019/summary/) for theoretical contributions to physical cosmology. The Friedmann equations — governing the universe's expansion — are autonomous 1st-order ODEs for the scale factor <Eq>{`a(t)`}</Eq>.

### SDEs

Stochastic ODEs: <Eq>{`dX = f(X)\\,dt + g(X)\\,dW`}</Eq> (Itô). Finance (Black-Scholes), molecular biology (genetic noise), robust control.

</Porta>

<Porta nivel="pratica" titulo="Integrating applications with real data">

### Model selection: practical rule

Before any calculation, classify the problem on the flowchart. Examples with Brazilian context:

**Simple epidemic (COVID-19, Brazil):** <Eq>{`\\dot I = (\\beta - \\gamma)I`}</Eq> at start. Separable → exponential. When <Eq>{`S`}</Eq> drops: <Eq>{`\\dot I = (\\beta S/N - \\gamma)I`}</Eq>, SIR system, solve numerically.

**Industrial reactors (Petrobras, refinery):** Outlet temperature of a heat exchanger: <Eq>{`mc_p \\dot T = UA(T_s - T)`}</Eq> — first-order linear, integrating factor.

**Structure (Paulista building under wind):** Fundamental vibration mode: <Eq>{`m\\ddot x + c\\dot x + kx = F_0\\cos(\\omega t)`}</Eq>. Resonance matters if <Eq>{`\\omega \\approx \\omega_0`}</Eq>.

**Audio filter (amplifier, São Paulo):** Low-pass RLC, <Eq>{`f_c = \\omega_0/(2\\pi) = 1/(2\\pi\\sqrt{LC})`}</Eq>. Choose <Eq>{`L`}</Eq> and <Eq>{`C`}</Eq> for <Eq>{`f_c = 1`}</Eq> kHz.

**Pharmacokinetics (ANVISA):** Drug disappears: <Eq>{`\\dot C = -k_e C`}</Eq>. Half-life <Eq>{`t_{1/2} = \\ln 2/k_e`}</Eq>. For acetaminophen, <Eq>{`t_{1/2} \\approx 2`}</Eq> h.

### Cheat sheet of the trimester

```
Separable:  ∫ dy/h(y) = ∫ g(x) dx
Linear 1st:  μ = exp(∫ p dx), y = (1/μ)∫ μq dx + C
Logistic:  P = K / (1 + A e^{−rt})
Cooling: T = T_a + (T_0 − T_a) e^{−kt}
Char. 2nd:   a λ² + b λ + c = 0
Vibration:   ω_0 = √(k/m), ζ = c/(2√(mk))
RLC:        ω_0 = 1/√(LC), ζ = (R/2)√(C/L)
Euler:      y_{n+1} = y_n + h f(t_n, y_n)
```

## Worked examples

<Exemplo titulo="Classify and solve a 1st-order separable ODE">

**Problem.** Solve the IVP <Eq>{`y' = 2xy`}</Eq>, <Eq>{`y(0) = 3`}</Eq>.

**Strategy.** Check if separable: rewrite as <Eq>{`dy/y = 2x\\,dx`}</Eq> and integrate each side. Apply initial condition to determine the constant.

**Solution.**

<Equation latex="\frac{dy}{y} = 2x\,dx \;\Longrightarrow\; \ln|y| = x^2 + C_1 \;\Longrightarrow\; y = Ce^{x^2}." />

IC: <Eq>{`y(0) = C = 3`}</Eq>. Solution: <Eq>{`y = 3e^{x^2}`}</Eq>.

**Verification.** <Eq>{`y' = 6xe^{x^2} = 2x\\cdot 3e^{x^2} = 2xy`}</Eq>. <Eq>{`y(0) = 3`}</Eq>. Correct.

**Source.** [Lebl, *Notes on Diffy Qs* §1.3](https://www.jirka.org/diffyqs/html/separable_section.html), Exercise 1.3.2.

</Exemplo>

<Exemplo titulo="Integrating factor: first-order linear ODE with nontrivial q(x)">

**Problem.** Solve <Eq>{`y' + (2/x)y = x^2`}</Eq>.

**Strategy.** Identify <Eq>{`p(x) = 2/x`}</Eq> and compute <Eq>{`\\mu = e^{\\int 2/x\\,dx} = x^2`}</Eq>. Multiply the ODE by <Eq>{`\\mu`}</Eq> and recognize the left side as derivative of a product.

**Solution.**

<Equation latex="\frac{d}{dx}(x^2 y) = x^4 \;\Longrightarrow\; x^2 y = \frac{x^5}{5} + C \;\Longrightarrow\; y = \frac{x^3}{5} + \frac{C}{x^2}." />

**Verification.** <Eq>{`y' = 3x^2/5 - 2C/x^3`}</Eq>. Substitute: <Eq>{`y' + 2y/x = 3x^2/5 - 2C/x^3 + 2x^2/5 + 2C/x^3 = x^2`}</Eq>. Checks out.

**Source.** [OpenStax *Calculus Vol. 2* §4.5](https://openstax.org/books/calculus-volume-2/pages/4-5-first-order-linear-equations), Example 4.14.

</Exemplo>

<Exemplo titulo="Characteristic equation with complex roots and initial conditions">

**Problem.** Solve the IVP <Eq>{`y'' + 2y' + 5y = 0`}</Eq>, <Eq>{`y(0) = 1`}</Eq>, <Eq>{`y'(0) = -1`}</Eq>.

**Strategy.** Compute the characteristic equation <Eq>{`\\lambda^2 + 2\\lambda + 5 = 0`}</Eq>. Complex roots <Eq>{`\\alpha \\pm i\\beta`}</Eq> give solution with exponential and trigonometric functions. Use the ICs to determine <Eq>{`C_1, C_2`}</Eq>.

**Solution.**

<Equation latex="\lambda = \frac{-2 \pm \sqrt{4-20}}{2} = -1 \pm 2i." />

<Equation latex="y = e^{-x}(C_1\cos 2x + C_2 \sin 2x)." />

IC at <Eq>{`x=0`}</Eq>: <Eq>{`y(0) = C_1 = 1`}</Eq>.

<Equation latex="y' = -e^{-x}(C_1\cos 2x + C_2\sin 2x) + e^{-x}(-2C_1\sin 2x + 2C_2\cos 2x)." />

<Eq>{`y'(0) = -C_1 + 2C_2 = -1 + 2C_2 = -1`}</Eq>, so <Eq>{`C_2 = 0`}</Eq>.

Solution: <Eq>{`y = e^{-x}\\cos 2x`}</Eq>.

**Verification.** <Eq>{`y' = -e^{-x}\\cos 2x - 2e^{-x}\\sin 2x`}</Eq>; <Eq>{`y'' = e^{-x}\\cos 2x + 4e^{-x}\\sin 2x - 2e^{-x}\\sin 2x + ..`}</Eq> — after algebra, <Eq>{`y'' + 2y' + 5y = 0`}</Eq>. Checks out.

**Source.** [Lebl, *Notes on Diffy Qs* §2.2](https://www.jirka.org/diffyqs/html/secondlc_section.html), Example 2.2.4.

</Exemplo>

<Exemplo titulo="Logistic model with real population data">

**Problem.** City population: 50 thousand in 2000, 80 thousand in 2010. Carrying capacity estimated at 200 thousand. Logistic model <Eq>{`\\dot P = rP(1-P/K)`}</Eq>. Find <Eq>{`r`}</Eq> and forecast the population in 2030.

**Strategy.** The logistic solution is <Eq>{`P(t) = K/(1+Ae^{-rt})`}</Eq>. Use <Eq>{`P(0) = 50`}</Eq> to find <Eq>{`A`}</Eq>; use <Eq>{`P(10) = 80`}</Eq> to find <Eq>{`r`}</Eq>; calculate <Eq>{`P(30)`}</Eq>.

**Solution.** <Eq>{`K = 200`}</Eq>, <Eq>{`P(0) = 200/(1+A) = 50 \\Rightarrow A = 3`}</Eq>.

<Equation latex="P(t) = \frac{200}{1 + 3e^{-rt}}." />

<Eq>{`P(10) = 200/(1+3e^{-10r}) = 80 \\Rightarrow 1 + 3e^{-10r} = 2.5 \\Rightarrow e^{-10r} = 0.5`}</Eq>.

<Eq>{`r = \\ln 2/10 \\approx 0.0693`}</Eq> year⁻¹.

<Eq>{`P(30) = 200/(1 + 3e^{-30 \\times 0.0693}) = 200/(1 + 3 \\times 0.125) = 200/1.375 \\approx 145`}</Eq> thousand.

**Verification.** <Eq>{`P(0) = 200/4 = 50`}</Eq>. <Eq>{`P(10) = 200/(1+3/2) = 200/2.5 = 80`}</Eq>. Checks out.

**Source.** [OpenStax *Calculus Vol. 2* §4.4](https://openstax.org/books/calculus-volume-2/pages/4-4-the-logistic-equation), Example 4.11.

</Exemplo>

<Exemplo titulo="Euler method applied to Newton cooling: error vs. step">

**Problem.** Coffee at 90 °C, <Eq>{`T_a = 22`}</Eq> °C, <Eq>{`k = 0.1`}</Eq> min⁻¹. Use Euler with <Eq>{`h = 2`}</Eq> min to compute <Eq>{`T(4)`}</Eq>. Compare to exact value.

**Strategy.** ODE: <Eq>{`T' = -0.1(T - 22)`}</Eq>, <Eq>{`T(0) = 90`}</Eq>. Two Euler steps. Exact solution: <Eq>{`T(t) = 22 + 68e^{-0.1t}`}</Eq>.

**Solution.**

Step 1 (<Eq>{`t=0 \\to 2`}</Eq>): <Eq>{`f(0, 90) = -0.1(90-22) = -6.8`}</Eq>. <Eq>{`T(2) \\approx 90 + 2\\times(-6.8) = 76.4`}</Eq> °C.

Step 2 (<Eq>{`t=2 \\to 4`}</Eq>): <Eq>{`f(2, 76.4) = -0.1(76.4-22) = -5.44`}</Eq>. <Eq>{`T(4) \\approx 76.4 + 2\\times(-5.44) = 65.52`}</Eq> °C.

Exact: <Eq>{`T(4) = 22 + 68e^{-0.4} = 22 + 68\\times 0.6703 \\approx 67.6`}</Eq> °C.

Error: <Eq>{`67.6 - 65.5 = 2.1`}</Eq> °C (about 3%). With <Eq>{`h = 0.5`}</Eq> min the error drops to 0.13%.

**Verification.** Euler local error formula: <Eq>{`O(h^2) = O(4) = 0.1^2 \\times 68 \\times (e^{-0.1 \\times 0}/2) \\approx 0.34`}</Eq> °C per step, accumulating to ~0.68 °C — correct order.

**Source.** [REAMAT UFRGS, *Numerical Calculus* Ch. 8](https://www.ufrgs.br/reamat/CalculoNumerico/livro-py/main.html), Section 8.2, Example 8.3.

</Exemplo>
