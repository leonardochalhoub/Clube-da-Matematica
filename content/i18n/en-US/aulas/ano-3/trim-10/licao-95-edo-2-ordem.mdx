### General problem

<Definicao titulo="Linear homogeneous 2nd-order ODE with constant coefficients">

$$ay'' + by' + cy = 0, \quad a, b, c \in \mathbb{R},\ a \neq 0$$

**Solution space:** by the existence-uniqueness theorem, the set of solutions is a vector space of **dimension 2** — two linearly independent solutions generate the entire family.

</Definicao>

### Ansatz and characteristic equation

Substitute $y = e^{\lambda x}$: $y' = \lambda e^{\lambda x}$, $y'' = \lambda^2 e^{\lambda x}$.

$$a\lambda^2 e^{\lambda x} + b\lambda e^{\lambda x} + c e^{\lambda x} = 0 \;\Rightarrow\; a\lambda^2 + b\lambda + c = 0$$

Since $e^{\lambda x} \neq 0$, everything reduces to the quadratic algebraic equation.

<Teorema titulo="Three cases by the discriminant">

Let $\Delta = b^2 - 4ac$.

**Case 1 — $\Delta > 0$:** distinct real roots $\lambda_1 \neq \lambda_2$.
$$y = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$$

**Case 2 — $\Delta = 0$:** double root $\lambda = -b/(2a)$.
$$y = (C_1 + C_2 x)\,e^{\lambda x}$$

**Case 3 — $\Delta < 0$:** conjugate complex roots $\lambda = \alpha \pm i\beta$, where $\alpha = -b/(2a)$, $\beta = \sqrt{4ac-b^2}/(2a)$.
$$y = e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$$

</Teorema>

> "If $b^2 - 4ac > 0$, the characteristic equation has two distinct real roots $r_1, r_2$, and the general solution of [the ODE] is $y = c_1 e^{r_1 x} + c_2 e^{r_2 x}$." — [Lebl, Notes on Diffy Qs, §2.2](https://www.jirka.org/diffyqs/html/socc_section.html)

### The double root case

<Insight>

Why does the factor $x$ appear? With double root $\lambda$, $e^{\lambda x}$ is one solution, but we need another. Reduction of order shows that $x e^{\lambda x}$ is the second independent solution. Check: $(xe^{\lambda x})'' + b/a\,(xe^{\lambda x})' + c/a\,(xe^{\lambda x}) = e^{\lambda x}(a\lambda^2 + b\lambda + c)/a + e^{\lambda x}(2\lambda + b/a) = 0$ when $\Delta = 0$.

</Insight>

### Non-homogeneous equations

For $ay'' + by' + cy = q(x)$: general solution $y = y_h + y_p$.

$y_h$: solution of the homogeneous equation (two free parameters).

$y_p$: any particular solution — obtained by **undetermined coefficients** (when $q$ is a combination of polynomial, exponential, sine/cosine) or **variation of parameters** (general).

</Porta>

<Porta nivel="5" titulo="For a 5-year-old">

Imagine a swing. You push it and it oscillates. The question is: how does it move as time passes?

Mathematicians discovered that the swing's motion obeys an equation with $y''$ (how position is accelerating). With no friction: oscillates forever. With light friction: oscillates and gradually stops. With heavy friction: goes straight to rest without oscillating.

Each of these cases corresponds to one of the three types of solution to our equation.

</Porta>

<Porta nivel="10" titulo="For a 10-year-old">

In the last lesson we solved 1st-order ODEs (only $y'$). Now we have $y''$ — acceleration — too.

The trick: try $y = e^{\lambda x}$. If it works, you find $\lambda$ by solving a **quadratic equation** — the characteristic equation.

Three things can happen:
1. Two different real roots — sum of two exponentials.
2. Double root — exponential multiplied by $(C_1 + C_2 x)$.
3. Complex roots — exponential with sines and cosines (oscillation!).

Case 3 is the coolest: it appears in any system that oscillates — pendulum, spring, LC circuit.

</Porta>

<Porta nivel="15" titulo="For a 15-year-old teen">

$ay'' + by' + cy = 0$ with $a, b, c$ real constants. The general solution **always has two free parameters** $C_1$ and $C_2$ (initial conditions $y(0)$ and $y'(0)$ determine both).

### Complete algorithm

1. Write the characteristic equation: $a\lambda^2 + b\lambda + c = 0$.
2. Compute $\Delta = b^2 - 4ac$.
3. If $\Delta > 0$: $\lambda_{1,2} = (-b \pm \sqrt{\Delta})/(2a)$. Solution: $C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$.
4. If $\Delta = 0$: $\lambda = -b/(2a)$. Solution: $(C_1 + C_2 x)e^{\lambda x}$.
5. If $\Delta < 0$: $\lambda = \alpha \pm i\beta$, with $\alpha = -b/(2a)$, $\beta = \sqrt{-\Delta}/(2a)$. Solution: $e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$.

### Why use $e^{\alpha x}(\cos\beta x + \sin\beta x)$ instead of complex?

By Euler's formula: $e^{(\alpha+i\beta)x} = e^{\alpha x}(\cos\beta x + i\sin\beta x)$. Real and imaginary parts are both real solutions. A real combination of them gives the general real solution.

### Example: $y'' + 4y = 0$

$\lambda^2 + 4 = 0 \Rightarrow \lambda = \pm 2i$. Here $\alpha = 0$, $\beta = 2$.

$y = C_1\cos 2x + C_2\sin 2x$ — pure oscillation.

With $y(0) = 1$, $y'(0) = 0$: $C_1 = 1$, $C_2 = 0$. $y = \cos 2x$.

</Porta>

<Porta nivel="25" titulo="For an engineering student">

### Classification of second-order systems

Every linear system of 2nd order with constant coefficients falls into one of three regimes:

| Case | $\Delta$ | Roots | Behavior |
|---|---|---|---|
| Overdamped | $> 0$ | $\lambda_1, \lambda_2 < 0$ | Decay without oscillation |
| Critically damped | $= 0$ | $\lambda$ double, real negative | Fastest decay without oscillation |
| Underdamped | $< 0$ | $\alpha \pm i\beta$, $\alpha < 0$ | Oscillation with decay |
| Undamped | $= 0$, no dissipation | $\pm i\beta$ (purely imaginary) | Eternal oscillation |
| Unstable | any | $\text{Re}(\lambda) > 0$ | Exponential growth |

### Non-homogeneous solution — undetermined coefficients

For $q(x) = $ polynomial, exponential, sine/cosine: guess a form for $y_p$ and determine the coefficients.

| $q(x)$ | Trial form for $y_p$ (if $\lambda_p$ is not a characteristic root) |
|---|---|
| $x^n$ | $A_n x^n + \ldots + A_0$ |
| $e^{kx}$ | $Ae^{kx}$ |
| $\cos\omega x$ or $\sin\omega x$ | $A\cos\omega x + B\sin\omega x$ |
| $x^n e^{kx}$ | $(A_n x^n + \ldots + A_0)e^{kx}$ |

**Modification rule**: if $\lambda_p$ is a characteristic root of multiplicity $m$, multiply the trial form by $x^m$.

### Variation of parameters

General: $y_p = -y_1 \int \frac{y_2 q}{W}\,dx + y_2 \int \frac{y_1 q}{W}\,dx$, where $W = y_1 y_2' - y_2 y_1'$ is the Wronskian.

### Laplace transform

$a(s^2 Y - sy_0 - y_0') + b(sY - y_0) + cY = Q(s)$. Solves initial conditions directly, without separating $y_h$ and $y_p$.

</Porta>

<Porta nivel="40" titulo="For a senior professional">

### Foundation: solution space

By Picard-Lindelöf, the IVP $ay'' + by' + cy = 0$, $y(x_0) = y_0$, $y'(x_0) = y_1$ has unique global solution (for constant coefficients, on all of $\mathbb{R}$). The solution space is isomorphic to $\mathbb{R}^2$ via $(y_0, y_1) \mapsto y$.

The **Wronskian** $W[y_1, y_2](x) = y_1 y_2' - y_2 y_1'$ is constant or identically zero (Abel). $W \neq 0$ iff $\{y_1, y_2\}$ is a basis for the solution space.

### Spectral theory

For $\mathcal{L} = a\,d^2/dx^2 + b\,d/dx + c$, the eigenvalues of $-\mathcal{L}$ on the space $L^2([0,\pi])$ with Dirichlet conditions form a discrete spectrum $\{\lambda_n\}_{n \geq 1}$ — Sturm-Liouville problem. The eigenfunctions $\{\sin n\pi x\}$ form an orthonormal basis: Fourier series.

### Green and convolutions

The Green function $G(x,s)$ of $\mathcal{L}$ satisfies $\mathcal{L}G = \delta(x-s)$. The particular solution of the non-homogeneous is $y_p(x) = \int G(x,s)q(s)\,ds$. For $ay'' + by' + cy = q$:

$$G(x,s) = \frac{y_1(s) y_2(x) - y_1(x) y_2(s)}{a\,W(s)}\, H(x-s)$$

where $H$ is Heaviside (causality).

### Lyapunov stability

For $\ddot y + 2\zeta\omega_0\dot y + \omega_0^2 y = 0$: total energy $E = \frac{1}{2}\dot y^2 + \frac{1}{2}\omega_0^2 y^2$. $\dot E = -2\zeta\omega_0 \dot y^2 \leq 0$ (for $\zeta \geq 0$). Critically damped ($\zeta = 1$) is fastest without oscillation — optimal for automotive suspension.

### Nobel Prize and oscillators

The linear 2nd-order oscillator model underlies all gravitational wave detection theory: LIGO interferometers use 2nd-order resonators at 150 Hz. Kip Thorne, Barry Barish, and Rainer Weiss received the [2017 Nobel Prize in Physics](https://www.nobelprize.org/prizes/physics/2017/summary/) for the direct detection of gravitational waves — dependent on this theory.

</Porta>

<Porta nivel="pratica" titulo="Practical application">

### Pocket algorithm

For $ay'' + by' + cy = 0$:

1. $\Delta = b^2 - 4ac$.
2. If $\Delta > 0$: $\lambda = (-b \pm \sqrt{\Delta})/(2a)$ — two real. $y = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$.
3. If $\Delta = 0$: $\lambda = -b/(2a)$. $y = (C_1 + C_2 x)e^{\lambda x}$.
4. If $\Delta < 0$: $\alpha = -b/(2a)$, $\beta = \sqrt{-\Delta}/(2a)$. $y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$.

### Classical errors

- Forgetting that $\Delta < 0$ requires the **real part** in the exponential: it is $e^{\alpha x}\cos\beta x$, not $\cos\beta x$.
- With double root: remember the $x$ factor in the second solution.
- When imposing ICs: use $y'(0)$ correctly — differentiate $y$ before substituting $x = 0$.

### Model: LC electrical oscillator

LC circuit: $L\ddot q + q/C = 0$, $q(0) = Q_0$, $\dot q(0) = 0$.

$\lambda^2 + 1/(LC) = 0 \Rightarrow \lambda = \pm i/\sqrt{LC} = \pm i\omega_0$.

$q(t) = Q_0\cos(\omega_0 t)$, $i(t) = \dot q = -Q_0\omega_0\sin(\omega_0 t)$.

Resonance frequency: $\omega_0 = 1/\sqrt{LC}$ [rad/s] — basis of radio filters.

### Synthesis

| ODE | Characteristic | Solution |
|---|---|---|
| $y'' - 5y' + 6y = 0$ | $\lambda^2-5\lambda+6 = (\lambda-2)(\lambda-3) = 0$ | $C_1 e^{2x} + C_2 e^{3x}$ |
| $y'' - 4y' + 4y = 0$ | $(\lambda-2)^2 = 0$ | $(C_1+C_2 x)e^{2x}$ |
| $y'' + 4y = 0$ | $\lambda = \pm 2i$ | $C_1\cos 2x + C_2\sin 2x$ |
| $y'' + 2y' + 5y = 0$ | $\lambda = -1 \pm 2i$ | $e^{-x}(C_1\cos 2x + C_2\sin 2x)$ |

</Porta>

## Worked examples

<Exemplo titulo="Case 1 — distinct real roots" numero="1">

**Problem.** Solve $y'' - 5y' + 6y = 0$, $y(0) = 2$, $y'(0) = 3$.

**Strategy.** $\Delta = 25 - 24 = 1 > 0$: two distinct reals.

**Solution.**

Characteristic equation: $\lambda^2 - 5\lambda + 6 = (\lambda-2)(\lambda-3) = 0$.

$\lambda_1 = 2$, $\lambda_2 = 3$. General solution: $y = C_1 e^{2x} + C_2 e^{3x}$.

$y(0) = C_1 + C_2 = 2$.

$y'(0) = 2C_1 + 3C_2 = 3$.

System: $C_1 = 3$, $C_2 = -1$.

$$y = 3e^{2x} - e^{3x}$$

**Check.** $y'' - 5y' + 6y = (12-15+6\cdot 3)e^{2x} + (-9+15-6)e^{3x} = 12e^{2x} \cdot 0 + 0 = 0$. $y(0) = 3 - 1 = 2$, $y'(0) = 6 - 3 = 3$. Correct.

**Source.** [Lebl, Notes on Diffy Qs, §2.2, Example 2.2.1](https://www.jirka.org/diffyqs/html/socc_section.html) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="Case 2 — double root" numero="2">

**Problem.** Solve $y'' - 4y' + 4y = 0$, $y(0) = 1$, $y'(0) = 0$.

**Strategy.** $\Delta = 16 - 16 = 0$: double root.

**Solution.**

$\lambda^2 - 4\lambda + 4 = (\lambda-2)^2 = 0$. Double root $\lambda = 2$.

$y = (C_1 + C_2 x)e^{2x}$.

$y(0) = C_1 = 1$.

$y'(x) = C_2 e^{2x} + 2(C_1 + C_2 x)e^{2x}$.

$y'(0) = C_2 + 2C_1 = 0 \Rightarrow C_2 = -2$.

$$y = (1 - 2x)e^{2x}$$

**Check.** $y' = -2e^{2x} + 2(1-2x)e^{2x} = (2-4x-2)e^{2x} = -4xe^{2x}$. $y'' = -4e^{2x} - 8xe^{2x}$. $y''-4y'+4y = (-4-8x)e^{2x} - 4(-4x)e^{2x} + 4(1-2x)e^{2x} = (-4-8x+16x+4-8x)e^{2x} = 0$. Correct.

**Source.** [Lebl, Notes on Diffy Qs, §2.2, Example 2.2.2](https://www.jirka.org/diffyqs/html/socc_section.html) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="Case 3 — conjugate complex roots (damped oscillation)" numero="3">

**Problem.** Solve $y'' + 2y' + 5y = 0$, $y(0) = 1$, $y'(0) = 2$.

**Strategy.** $\Delta = 4 - 20 = -16 < 0$: complex. $\alpha = -1$, $\beta = 2$.

**Solution.**

$\lambda = (-2 \pm \sqrt{-16})/2 = -1 \pm 2i$.

$y = e^{-x}(C_1\cos 2x + C_2\sin 2x)$.

$y(0) = C_1 = 1$.

$y'(x) = -e^{-x}(C_1\cos 2x + C_2\sin 2x) + e^{-x}(-2C_1\sin 2x + 2C_2\cos 2x)$.

$y'(0) = -C_1 + 2C_2 = 2 \Rightarrow 2C_2 = 3 \Rightarrow C_2 = 3/2$.

$$y = e^{-x}\!\left(\cos 2x + \frac{3}{2}\sin 2x\right)$$

**Check.** The characteristic equation has roots $-1 \pm 2i$, both with real part $-1 < 0$: solution decays exponentially. $y(0) = 1$, $y'(0) = -1 + 3 = 2$. Correct.

**Source.** [Lebl, Notes on Diffy Qs, §2.2, Example 2.2.3](https://www.jirka.org/diffyqs/html/socc_section.html) — CC-BY-SA.

</Ejemplo>

<Ejemplo titulo="Non-homogeneous by undetermined coefficients" numero="4">

**Problem.** Solve $y'' - y' - 2y = e^{3x}$.

**Strategy.** $y = y_h + y_p$. For $q = e^{3x}$ and 3 is not a root of the characteristic: trial $y_p = Ae^{3x}$.

**Solution.**

$\lambda^2 - \lambda - 2 = (\lambda-2)(\lambda+1) = 0$. $y_h = C_1 e^{2x} + C_2 e^{-x}$.

Trial: $y_p = Ae^{3x}$. Substitute:

$9Ae^{3x} - 3Ae^{3x} - 2Ae^{3x} = e^{3x} \Rightarrow 4A = 1 \Rightarrow A = 1/4$.

$$y = C_1 e^{2x} + C_2 e^{-x} + \frac{1}{4}e^{3x}$$

**Check.** $y_p'' - y_p' - 2y_p = (9/4 - 3/4 - 2/4)e^{3x} = (9-3-2)/4\,e^{3x} = e^{3x}$. Correct.

**Source.** [Lebl, Notes on Diffy Qs, §2.3, Example 2.3.1](https://www.jirka.org/diffyqs/html/uc_section.html) — CC-BY-SA.

</Ejemplo>

<Ejemplo titulo="Non-homogeneous with resonance (modification rule)" numero="5">

**Problem.** Solve $y'' - 3y' + 2y = e^{2x}$.

**Strategy.** Try $y_p = Ae^{2x}$ — but $\lambda = 2$ is a characteristic root! Modification rule: multiply by $x$.

**Solution.**

$\lambda^2 - 3\lambda + 2 = (\lambda-1)(\lambda-2) = 0$. $y_h = C_1 e^x + C_2 e^{2x}$.

$\lambda = 2$ is a simple root: try $y_p = Axe^{2x}$.

$y_p' = Ae^{2x} + 2Axe^{2x}$, $y_p'' = 4Ae^{2x} + 4Axe^{2x}$.

$y_p'' - 3y_p' + 2y_p = (4A + 4Ax)e^{2x} - (3A + 6Ax)e^{2x} + 2Axe^{2x} = Ae^{2x}$.

$A = 1$. So $y_p = xe^{2x}$.

$$y = C_1 e^x + C_2 e^{2x} + xe^{2x}$$

**Check.** $y_p = xe^{2x}$: $y_p'' - 3y_p' + 2y_p = (4+4x)e^{2x} - 3(1+2x)e^{2x} + 2xe^{2x} = (4+4x-3-6x+2x)e^{2x} = e^{2x}$. Correct.

**Source.** [Lebl, Notes on Diffy Qs, §2.3, Example 2.3.2](https://www.jirka.org/diffyqs/html/uc_section.html) — CC-BY-SA.

</Ejemplo>
