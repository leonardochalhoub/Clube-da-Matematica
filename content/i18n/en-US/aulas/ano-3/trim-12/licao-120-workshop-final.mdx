### Structure of the completed program

<Definicao titulo="The four pillars of the program">

The 120-lesson program divides into four pillars:

- **Differential and Integral Calculus** (Terms 5–8): limits, derivatives, integrals, series, differential equations. Foundation: differentiation rules, Fundamental Theorem of Calculus, Taylor series, second-order linear equations.
- **Linear Algebra** (Terms 9–10): matrices, systems, determinants, vector spaces, eigenvalues, SVD. Foundation: Gaussian elimination, spectral theorem, decompositions.
- **Probability and Statistics** (Terms 10–11): distributions, Central Limit Theorem, confidence intervals, hypothesis tests, regression. Foundation: normal, chi-squared, expected value, variance.
- **Applied Modeling** (Terms 11–12): applied differential equations, quantitative finance (Black-Scholes), basic machine learning. Foundation: separable and linear ODEs, Itô's lemma, gradient descent.

</Definicao>

<Teorema titulo="Fundamental Theorem of Calculus (synthesis)">

Let $f$ be continuous on $[a, b]$ and $F$ any antiderivative of $f$. Then:

<Equation explicacao="Part 1: the function defined by accumulated integral is differentiable and its derivative is the integrand." latex="\frac{d}{dx}\int_a^x f(t)\,dt = f(x), \quad x \in [a, b]" />

<Equation explicacao="Part 2: the definite integral is computed via any antiderivative evaluated at the endpoints." latex="\int_a^b f(x)\,dx = F(b) - F(a)" />

The FTC is the bridge between the two halves of calculus — differential and integral. It appears directly in 6 of the 40 workshop problems.

</Teorema>

### What is synthesis?

Synthesis is the opposite of an isolated list of tools. Concrete example:

> *"A company sells $q$ units per day at price $p(q) = 120 - 2q$ reais. Production cost is $C(q) = 200 + 40q + q^2$. Find the quantity that maximizes profit."*

To solve:
1. **Lesson 03** (linear function) — identify revenue $R(q) = q \cdot p(q)$.
2. **Lesson 04** (quadratic) — $L(q) = R(q) - C(q)$ is quadratic.
3. **Lessons 51-52** (derivative) — solve $L'(q) = 0$.
4. **Lesson 53** (second derivative) — confirm it's a maximum.

You don't receive these steps ready-made. You **reconstruct** them from knowledge.

### Why does this matter?

- **University entrance**: ITA/IME questions require 3–4 techniques from different areas.
- **Engineering**: real problems never come labeled.
- **Data/AI**: neural networks mix linear algebra plus calculus plus statistics.

## Worked examples

<Exemplo titulo="Optimization with derivatives — profit maximization" numero="1">

**Problem:** A company has revenue $R(q) = 120q - 2q^2$ and cost $C(q) = 200 + 40q + q^2$ (in reais, $q$ units/day). Find the quantity $q^*$ that maximizes profit $L(q) = R(q) - C(q)$.

**Strategy:** Build $L(q)$, compute $L'(q)$, set to zero, verify with second derivative that it's a maximum.

**Solution:**

1. $L(q) = (120q - 2q^2) - (200 + 40q + q^2) = -3q^2 + 80q - 200$.
2. $L'(q) = -6q + 80$. Setting to zero: $q^* = 80/6 = 40/3 \approx 13.3$ units/day.
3. $L''(q) = -6 < 0$, confirming maximum.
4. $L(40/3) = -3(40/3)^2 + 80(40/3) - 200 = -\frac{4800}{9} + \frac{3200}{3} - 200 = \frac{1400}{9} \approx 155.6$ reais/day.

**Verification:** $L'(13) = -78 + 80 = 2 > 0$ and $L'(14) = -84 + 80 = -4 < 0$, confirming maximum is between $q = 13$ and $q = 14$.

**Source.** [Active Calculus §3.3, Exercise 3.3.3](https://activecalculus.org/single/sec-3-3-optimization.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Definite integral by substitution — area under curve" numero="2">

**Problem:** Calculate $\displaystyle\int_0^{\pi/2} \sin^2 x \cos^3 x \; dx$.

**Strategy:** Separate $\cos^3 x = \cos^2 x \cdot \cos x = (1 - \sin^2 x)\cos x$ and use substitution $u = \sin x$.

**Solution:**

1. Write $\cos^3 x = (1 - \sin^2 x)\cos x$.
2. Let $u = \sin x$, so $du = \cos x\,dx$. Limits: $x=0 \Rightarrow u=0$; $x=\pi/2 \Rightarrow u=1$.
3. $\displaystyle\int_0^1 u^2(1 - u^2)\,du = \int_0^1 (u^2 - u^4)\,du = \left[\frac{u^3}{3} - \frac{u^5}{5}\right]_0^1 = \frac{1}{3} - \frac{1}{5} = \frac{2}{15}$.

**Verification:** $0 < 2/15 \approx 0.133$. The integrand $\sin^2 x \cos^3 x \geq 0$ on $[0, \pi/2]$ with maximum around $x \approx 0.63$ rad where $\sin x \approx 0.59$, $\cos x \approx 0.81$; maximum value $\approx 0.21$. Area $\approx 0.21 \times 1.57/2 \approx 0.16$. Order of magnitude consistent with $2/15$.

**Source.** [Active Calculus §5.3, Exercise 5.3.5](https://activecalculus.org/single/sec-5-3-substitution.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Matrix diagonalization 2x2 — eigenvalues and eigenvectors" numero="3">

**Problem:** Diagonalize $A = \begin{pmatrix} 3 & 1 \\ 0 & 2 \end{pmatrix}$.

**Strategy:** Calculate $\det(A - \lambda I) = 0$, find eigenvalues, then eigenvectors. Build $P$ with eigenvectors as columns and verify $P^{-1}AP = D$.

**Solution:**

1. $\det(A - \lambda I) = (3-\lambda)(2-\lambda) - 0 = (3-\lambda)(2-\lambda)$. Eigenvalues: $\lambda_1 = 3$, $\lambda_2 = 2$.
2. For $\lambda_1 = 3$: $(A - 3I)\mathbf{v} = 0 \Rightarrow \begin{pmatrix}0 & 1\\ 0 & -1\end{pmatrix}\mathbf{v} = 0 \Rightarrow v_2 = 0$. Eigenvector: $\mathbf{v}_1 = (1, 0)^T$.
3. For $\lambda_2 = 2$: $(A - 2I)\mathbf{v} = 0 \Rightarrow \begin{pmatrix}1 & 1\\ 0 & 0\end{pmatrix}\mathbf{v} = 0 \Rightarrow v_1 = -v_2$. Eigenvector: $\mathbf{v}_2 = (1, -1)^T$.
4. $P = \begin{pmatrix}1 & 1 \\ 0 & -1\end{pmatrix}$, $D = \begin{pmatrix}3 & 0 \\ 0 & 2\end{pmatrix}$.

**Verification:** $AP = P \begin{pmatrix}3&0\\0&2\end{pmatrix}$. Column 1: $A(1,0)^T = (3,0)^T = 3(1,0)^T$. Column 2: $A(1,-1)^T = (2,-2)^T = 2(1,-1)^T$. Correct.

**Source.** [Linear Algebra Done Right, 4th ed., §5C Exercise 5](https://linear.axler.net/) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="2nd-order ODE — simple harmonic oscillator" numero="4">

**Problem:** Solve $y'' + 4y = 0$ with $y(0) = 1$, $y'(0) = 0$.

**Strategy:** Linear homogeneous 2nd-order equation with constant coefficients. Characteristic equation $r^2 + 4 = 0$ has complex conjugate roots.

**Solution:**

1. Characteristic equation: $r^2 + 4 = 0 \Rightarrow r = \pm 2i$.
2. General solution: $y(x) = C_1 \cos(2x) + C_2 \sin(2x)$.
3. Initial condition $y(0) = 1$: $C_1 \cdot 1 + C_2 \cdot 0 = 1 \Rightarrow C_1 = 1$.
4. $y'(x) = -2C_1 \sin(2x) + 2C_2 \cos(2x)$. Condition $y'(0) = 0$: $2C_2 = 0 \Rightarrow C_2 = 0$.
5. Solution: $y(x) = \cos(2x)$.

**Verification:** $y'' = -4\cos(2x)$. So $y'' + 4y = -4\cos(2x) + 4\cos(2x) = 0$. Initial conditions: $y(0) = 1$, $y'(0) = -2\sin(0) = 0$. Correct.

**Source.** [Notes on Diffy Qs §2.2, Exercise 2.2.1](https://www.jirka.org/diffyqs/) — CC-BY-SA.

</Exemplo>

<Exemplo titulo="Simple linear regression — coefficient estimation" numero="5">

**Problem:** With points $(1,2)$, $(2,3)$, $(3,5)$, $(4,4)$, $(5,6)$, find the regression line $\hat y = \hat\beta_0 + \hat\beta_1 x$ by least squares.

**Strategy:** Use formulas $\hat\beta_1 = \frac{\sum(x_i - \bar x)(y_i - \bar y)}{\sum(x_i - \bar x)^2}$ and $\hat\beta_0 = \bar y - \hat\beta_1 \bar x$.

**Solution:**

1. $n = 5$. $\bar x = (1+2+3+4+5)/5 = 3$. $\bar y = (2+3+5+4+6)/5 = 4$.
2. $\sum(x_i - \bar x)^2 = (-2)^2 + (-1)^2 + 0^2 + 1^2 + 2^2 = 4+1+0+1+4 = 10$.
3. $\sum(x_i - \bar x)(y_i - \bar y) = (-2)(-2)+(-1)(-1)+(0)(1)+(1)(0)+(2)(2) = 4+1+0+0+4 = 9$.
4. $\hat\beta_1 = 9/10 = 0.9$. $\hat\beta_0 = 4 - 0.9 \times 3 = 4 - 2.7 = 1.3$.
5. Line: $\hat y = 1.3 + 0.9x$.

**Verification:** For $x = 3$: $\hat y = 1.3 + 2.7 = 4.0 = \bar y$. The regression line always passes through $(\bar x, \bar y)$. Correct.

**Source.** [OpenIntro Statistics 4th ed., §8.1 Exercise 8.1](https://www.openintro.org/book/os/) — CC-BY-SA.

</Exemplo>
