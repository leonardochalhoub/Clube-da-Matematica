### Antiderivative and indefinite integral

<Definicao titulo="Antiderivative">

Let $f: I \to \mathbb{R}$ be defined on an interval $I$. A function $F: I \to \mathbb{R}$ is called an **antiderivative** (or primitive) of $f$ on $I$ if $F'(x) = f(x)$ for all $x \in I$.

The **indefinite integral** of $f$ is the family of all antiderivatives, written as:

$$\int f(x)\, dx = F(x) + C, \quad C \in \mathbb{R}$$

</Definicao>

> "If $F$ is an antiderivative of $f$ on an interval $I$, then the most general antiderivative of $f$ on $I$ is $F(x) + C$, where $C$ is an arbitrary constant." — [OpenStax Calculus Vol. 1, §4.10](https://openstax.org/books/calculus-volume-1/pages/4-10-antiderivatives)

<Definicao titulo="Why the constant C?">

If $F' = f$, then $(F + C)' = F' + 0 = f$ for any $C \in \mathbb{R}$. Thus every vertical translation of $F$ is also an antiderivative.

**Corollary (consequence of the MVT):** on an interval $I$, if $F$ and $G$ are both antiderivatives of $f$, then $F - G$ is constant on $I$. Therefore the antiderivative is unique **up to a constant**.

</Definicao>

### Linearity of antidifferentiation

<Teorema titulo="Linearity of the indefinite integral">

For functions $f$, $g$ with antiderivatives on an interval $I$, and scalars $\alpha, \beta \in \mathbb{R}$:

$$\int (\alpha f(x) + \beta g(x))\, dx = \alpha \int f(x)\, dx + \beta \int g(x)\, dx$$

</Teorema>

> "The sum rule and constant multiple rules of integration show that the antiderivative of any linear combination of functions is the linear combination of the antiderivatives." — [APEX Calculus, §5.1](https://www.apexcalculus.com/)

<Insight>

**Product does NOT distribute:** $\int f(x) g(x)\, dx \neq \left(\int f\right)\left(\int g\right)$ in general. To integrate products, the techniques are integration by parts (Lesson 85) or substitution (Lesson 84).

</Insight>

<Porta nivel="5" titulo="For a 5-year-old">

You know how to **add** and how to **subtract**? Subtraction undoes addition: if you gained 3 candies and then lost 3, you're back where you started.

**Derivative** is like counting candies you gain per minute. **Antiderivative** goes backward: if I tell you how many you gained per minute, you figure out how many you had.

But there's a catch: I don't know whether you started with 0 candies or 100. That's why we write "+ C" — the C keeps that secret.

</Porta>

<Porta nivel="10" titulo="For a 10-year-old">

The speedometer in a car tells you the **speed** at each moment. The **antiderivative** does the reverse: given speed, it finds your **position**.

If a car travels at $v(t) = 2t$ meters per second, where is it after $t$ seconds? The antiderivative of $2t$ is $t^2$. So position $= t^2 + C$, where $C$ is the starting position we need to know separately.

**Trick for polynomials**: $\int x^n$ becomes $x^{n+1}/(n+1)$. Add 1 to the exponent and divide by the new exponent.

Examples: $\int x^2\, dx = x^3/3$. $\int x^5\, dx = x^6/6$. Always add $+ C$ at the end.

</Porta>

<Porta nivel="15" titulo="For a 15-year-old teen">

Antiderivative is "**undoing differentiation**". If $f(x) = 2x$, which function has derivative equal to $2x$? Answer: $F(x) = x^2$, because $(x^2)' = 2x$.

But $F(x) = x^2 + 5$ also works. And $x^2 - 17$. Any constant added. That's why we write:

$$\int 2x\, dx = x^2 + C$$

The $C$ is the **integration constant** — it admits we don't know the "starting point".

**How to use the table:**

| I want to integrate | Rule | Result |
|---|---|---|
| $x^3$ | power: add 1, divide | $x^4/4 + C$ |
| $\sin x$ | direct from table | $-\cos x + C$ |
| $e^x$ | direct from table | $e^x + C$ |
| $3x^2 - 4\sin x$ | linearity | $x^3 + 4\cos x + C$ |

**Mandatory check:** differentiate the result. If you get $f(x)$, it's correct. This habit catches sign errors before the test.

</Insight>

<Porta nivel="25" titulo="For an engineering student">

Antidifferentiation is **operationally** the opposite of differentiation, but **computationally** much harder. There are elementary functions whose antiderivative is not elementary:

- $\int e^{-x^2}\, dx$ — the error function erf, fundamental in probability.
- $\int \sin(x^2)\, dx$ — Fresnel function, appears in optics and diffraction.
- $\int \frac{\sin x}{x}\, dx$ — sine integral $\text{Si}(x)$, in control theory.

**Liouville (1835)** characterized which functions have elementary antiderivatives. Risch (1969) converted that result into a decision algorithm — implemented in Mathematica and SymPy.

### Sequential integration strategy

When facing $\int f\, dx$:

1. **Direct from table?** Use without hesitation.
2. **Linearity?** Break into sums and scalars.
3. **Substitution** $u = g(x)$? Inverse of the chain rule (Lesson 84).
4. **By parts?** Inverse of the product rule (Lesson 85).
5. **Partial fractions** (Lesson 86) if rational with factorable denominator.
6. **Trigonometric identity** (Lesson 87) if there are powers of sine/cosine.
7. **No elementary antiderivative?** Use Taylor series or numerical quadrature.

### Initial condition determines C

In practice (ODEs, physics, finance) the $C$ is determined by an initial condition. If $F'(t) = f(t)$ and we know $F(0) = F_0$, then $C = F_0 - F(0)\big|_{C=0}$. Without an initial condition, the $C$ remains symbolic.

> "The question of finding antiderivatives is important not only for computing the right side of the Fundamental Theorem, but also for solving differential equations." — [APEX Calculus, §5.1](https://www.apexcalculus.com/)

</Porta>

<Porta nivel="40" titulo="For a senior professional">

The structure of antidifferentiation has considerable algebraic and analytic depth.

### Liouville's theorem and the Risch algorithm

**Liouville's theorem** states: if $f$ is elementary and $\int f$ is elementary, then $\int f = v_0 + \sum c_i \ln v_i$ with $v_0, v_i$ elementary in the same field of functions. Risch (1969) transformed this into a **decision algorithm** — given an elementary function, the algorithm determines whether there exists an elementary antiderivative and, if so, computes it. The implementation in Mathematica/Maple is the engine behind every modern CAS.

### Lebesgue integral and generalization

In the context of Real Analysis, for $f \in L^1_{\text{loc}}(I)$ (locally integrable), $F(x) = \int_a^x f(t)\, dt$ is **absolutely continuous** and $F' = f$ almost everywhere (Lebesgue). The Henstock-Kurzweil theory (gauge integral) extends this further, integrating derivatives of any differentiable function.

### Role in ODEs and signals

- **Separable ODEs**: $dy/dx = g(x) h(y)$ reduces to two antidifferentiations.
- **Laplace**: $\mathcal{L}\{f\}(s) = \int_0^{\infty} e^{-st} f(t)\, dt$ — antidifferentiation in the time domain.
- **PID control**: the integral part $I(t) = \int_0^t e(\tau)\, d\tau$ eliminates steady-state error.
- **Quantum**: Feynman path amplitude is a path integral — functional antidifferentiation in infinite-dimensional space.

</Porta>

<Porta nivel="pratica" titulo="Practical application — Brazilian data">

### Vehicle position from acceleration

A vehicle accelerates uniformly with $a(t) = 3\, \text{m/s}^2$. Initial velocity: $v(0) = 0$. Initial position: $x(0) = 0$.

**Velocity:** $v(t) = \int a(t)\, dt = 3t + C_1$. With $v(0) = 0$: $C_1 = 0$, so $v(t) = 3t$.

**Position:** $x(t) = \int v(t)\, dt = \int 3t\, dt = \frac{3}{2}t^2 + C_2$. With $x(0) = 0$: $C_2 = 0$.

Position at $t = 10\text{ s}$: $x(10) = \frac{3}{2} \cdot 100 = 150\text{ m}$.

### Investment portfolio growth

Suppose the monthly growth rate of a portfolio (in R\$ per month) is $f(t) = 500 + 20t$ (accelerating growth). Starting from R\$ 10,000 in month 0:

$$V(t) = \int (500 + 20t)\, dt = 500t + 10t^2 + C.$$

With $V(0) = 10,000$: $C = 10,000$. After 12 months: $V(12) = 500(12) + 10(144) + 10,000 = 6,000 + 1,440 + 10,000 = 17,440$ reais.

### Using SymPy

```python
import sympy as sp
x = sp.symbols('x')
f = 3*x**2 - 4*sp.sin(x) + sp.exp(x)
print(sp.integrate(f, x))
# => x**3 + 4*cos(x) + exp(x)
```

Use to **verify** your result, not to replace the learning process.

## Worked examples

<Exemplo numero="1" titulo="Power rule and linearity (basic)">

**Problem.** Calculate $\displaystyle\int (4x^3 - 6x + 5)\, dx$.

**Strategy.** Apply linearity: integrate each monomial separately using the power rule $\int x^n\, dx = x^{n+1}/(n+1) + C$.

**Solution.**
$$\int (4x^3 - 6x + 5)\, dx = 4 \cdot \frac{x^4}{4} - 6 \cdot \frac{x^2}{2} + 5x + C = x^4 - 3x^2 + 5x + C.$$

**Check.** $(x^4 - 3x^2 + 5x + C)' = 4x^3 - 6x + 5$ . Correct.

**Source.** [APEX Calculus, §5.1, Example 5.1.3](https://www.apexcalculus.com/) — CC-BY-NC.

</Exemplo>

<Exemplo numero="2" titulo="Trigonometric and exponential functions (basic)">

**Problem.** Calculate $\displaystyle\int (3\cos x - 2e^x + \sec^2 x)\, dx$.

**Strategy.** Direct table lookup for each term; linearity ensures we can sum the antiderivatives.

**Solution.**
$$\int 3\cos x\, dx - 2\int e^x\, dx + \int \sec^2 x\, dx = 3\sin x - 2e^x + \tan x + C.$$

**Check.** $(3\sin x - 2e^x + \tan x + C)' = 3\cos x - 2e^x + \sec^2 x$ . Correct.

**Source.** [OpenStax Calculus Vol. 1, §4.10, Example 4.55](https://openstax.org/books/calculus-volume-1/pages/4-10-antiderivatives) — CC-BY-NC-SA.

</Exemplo>

<Exemplo numero="3" titulo="Initial condition determines C (intermediate)">

**Problem.** Find $F(x)$ given that $F'(x) = x^2 - 4x + 1$ and $F(2) = -3$.

**Strategy.** Integrate to obtain the general family; use the condition $F(2) = -3$ to determine $C$.

**Solution.**
$$F(x) = \int (x^2 - 4x + 1)\, dx = \frac{x^3}{3} - 2x^2 + x + C.$$

Initial condition: $F(2) = \frac{8}{3} - 8 + 2 + C = -3$, so $C = -3 - \frac{8}{3} + 6 = 3 - \frac{8}{3} = \frac{1}{3}$.

$$F(x) = \frac{x^3}{3} - 2x^2 + x + \frac{1}{3}.$$

**Check.** $F'(x) = x^2 - 4x + 1$ and $F(2) = \frac{8}{3} - 8 + 2 + \frac{1}{3} = 3 - 8 + 2 = -3$. Correct.

**Source.** [OpenStax Calculus Vol. 1, §4.10, Exercise 4.284](https://openstax.org/books/calculus-volume-1/pages/4-10-antiderivatives) — CC-BY-NC-SA.

</Exemplo>

<Exemplo numero="4" titulo="Algebraic expansion before integrating (intermediate)">

**Problem.** Calculate $\displaystyle\int x(3x - 1)^2\, dx$.

**Strategy.** Expand the square and distribute before applying the power rule. (Substitution would work, but expansion is more direct here.)

**Solution.**
$(3x-1)^2 = 9x^2 - 6x + 1$, so $x(3x-1)^2 = 9x^3 - 6x^2 + x$.

$$\int (9x^3 - 6x^2 + x)\, dx = \frac{9x^4}{4} - 2x^3 + \frac{x^2}{2} + C.$$

**Check.** Differentiating: $9x^3 - 6x^2 + x = x(9x^2 - 6x + 1) = x(3x-1)^2$. Correct.

**Source.** [APEX Calculus, §5.1, Exercise 5.1.15](https://www.apexcalculus.com/) — CC-BY-NC.

</Exemplo>

<Exemplo numero="5" titulo="Rewriting a fraction before integrating (challenge)">

**Problem.** Calculate $\displaystyle\int \frac{x^3 + 2x}{x}\, dx$ for $x > 0$.

**Strategy.** Simplify the fraction by dividing term by term before integrating. The integral of $1/x$ uses the $\ln|x|$ entry from the table.

**Solution.**

$$\frac{x^3 + 2x}{x} = x^2 + 2, \quad x > 0.$$

$$\int (x^2 + 2)\, dx = \frac{x^3}{3} + 2x + C.$$

**Check.** $\left(\frac{x^3}{3} + 2x\right)' = x^2 + 2 = \frac{x^3 + 2x}{x}$ for $x \neq 0$. Correct.

**Source.** [Active Calculus, §4.1, Preview Activity 4.1](https://activecalculus.org/single/sec-4-1-velocity-distance.html) — CC-BY-NC-SA.

</Exemplo>
