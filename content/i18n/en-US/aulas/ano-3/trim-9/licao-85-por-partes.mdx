### Derivation of the formula

<Definicao titulo="Integration by Parts">

Let $u(x)$ and $v(x)$ be differentiable functions on $[a, b]$, with $u'$ and $v'$ continuous. The product rule states:

$$\frac{d}{dx}[u(x)v(x)] = u'(x)v(x) + u(x)v'(x).$$

Integrating both sides from $a$ to $b$ and applying the Fundamental Theorem of Calculus:

$$[u(x)v(x)]_a^b = \int_a^b u'(x)v(x)\, dx + \int_a^b u(x)v'(x)\, dx.$$

Rearranging:

$$\int_a^b u(x)v'(x)\, dx = [u(x)v(x)]_a^b - \int_a^b v(x)u'(x)\, dx.$$

In differential notation ($dv = v'(x)\, dx$, $du = u'(x)\, dx$):

<Equation explicacao="Formula for integration by parts — indefinite form." latex="\int u\, dv = uv - \int v\, du." />

</Definicao>

> "The formula for integration by parts comes from the product rule for differentiation: if $u$ and $v$ are both functions of $x$, then $(uv)' = u'v + uv'$. Integrating both sides and rearranging gives $\int u\, dv = uv - \int v\, du$." — [Active Calculus §5.4](https://activecalculus.org/single/sec-5-4-parts.html)

### LIATE heuristic

<Definicao titulo="Order of preference for u (LIATE)">

To choose $u$ (the function to be differentiated), prefer in order:

1. **L**ogarithmic: $\ln x$, $\log_a x$
2. **I**nverse trigonometric: $\arctan x$, $\arcsin x$, $\arccos x$
3. **A**lgebraic: $x^n$, polynomials
4. **T**rigonometric: $\sin x$, $\cos x$, $\tan x$
5. **E**xponential: $e^x$, $a^x$

The first category that appears in the integrand becomes $u$. The rest is $dv$.

**Logic:** logarithmic and inverse trigonometric functions have derivatives that simplify (from transcendental to algebraic); exponential and trig reproduce themselves upon differentiation. Hence $u$ should be the factor that "improves" upon differentiation.

</Definicao>

> "A useful heuristic for deciding which function to call $u$ in integration by parts is the acronym LIATE, which stands for Logarithmic, Inverse trigonometric, Algebraic, Trigonometric, and Exponential functions." — [OpenStax Calculus Vol. 2, §3.1](https://openstax.org/books/calculus-volume-2/pages/3-1-integration-by-parts)

<Teorema titulo="Trick: integral that returns to itself">

For $I = \int e^x \cos x\, dx$:

Apply parts with $u = \cos x$, $dv = e^x dx$: $I = e^x \cos x + \int e^x \sin x\, dx$.

Apply parts again with $u = \sin x$: $I = e^x \cos x + e^x \sin x - I$.

Therefore $2I = e^x(\cos x + \sin x)$, and:

<Equation explicacao="Result of the trick when the original integral reappears after two applications." latex="I = \frac{e^x(\sin x + \cos x)}{2} + C." />

**Condition:** the trick works when the second application reproduces the original integral with the same sign (not inverted, which would give a null identity).

</Teorema>

<Insight>

**Parts is derivative transfer.** The identity $\int u\, dv = uv - \int v\, du$ moves the differentiation operation from one factor to the other. In function spaces with null boundary conditions, this makes $d/dx$ antisymmetric in $L^2$ — the foundation of weak formulations in PDEs.

</Insight>

<Porta nivel="10" titulo="For a 10-year-old">

Remember that the derivative of a product has two terms? If $f = u \cdot v$, then $f' = u'v + uv'$.

Now imagine you integrate both sides:

$uv = \int u'v\, dx + \int uv'\, dx$

Rearranging: $\int uv'\, dx = uv - \int u'v\, dx$.

**Practical translation:** when you have a product to integrate, you can trade it for $uv$ minus **another integral**. If the new integral is simpler, you've won.

**Example**: $\int x \sin x\, dx$. $x$ is algebraic (simplifies upon differentiation: becomes $1$). $\sin x$ has antiderivative $-\cos x$.

So $u = x$, $dv = \sin x\, dx$. After the formula: $-x\cos x + \int \cos x\, dx = -x\cos x + \sin x + C$.

**LIATE trick**: of Log, Inv-trig, Algebraic, Trig, Exp — whichever appears first becomes $u$.

</Porta>

<Porta nivel="15" titulo="For a 15-year-old teen">

The formula is $\int u\, dv = uv - \int v\, du$.

**Recipe in 5 steps:**

1. Identify product in the integrand.
2. Use **LIATE** to choose $u$ (Log > Inv-trig > Algebraic > Trig > Exp).
3. The rest is $dv$. Compute $du = u'\, dx$ and $v = \int dv$.
4. Apply the formula.
5. Solve $\int v\, du$ — it should be simpler.

**Three fundamental patterns:**

**1.** $\int x e^x\, dx$: $u = x$ (Algebraic), $dv = e^x dx$. Result: $xe^x - e^x + C$.

**2.** $\int \ln x\, dx$: $u = \ln x$ (Log), $dv = dx$. Then $du = dx/x$, $v = x$. Result: $x \ln x - x + C$.

**3.** $\int e^x \cos x\, dx$: apply twice — the integral returns. Isolate: result $e^x(\sin x + \cos x)/2 + C$.

**When NOT to use parts**: if you see $\int x e^{x^2}\, dx$, it's substitution (chain rule in disguise), not parts.

</Porta>

<Porta nivel="25" titulo="For an engineering student">

### Fundamental connections

- **Laplace**: $\mathcal{L}\{t\} = \int_0^\infty t e^{-st}\, dt = 1/s^2$ — computed by parts.
- **Gamma function**: $\Gamma(n+1) = n \Gamma(n)$ — proved via parts + $\Gamma(1) = 1$.
- **Fourier coefficients**: $a_n = (1/\pi)\int_{-\pi}^\pi f(x)\cos(nx)\, dx$ — parts reduces when $f$ is polynomial.
- **Laplace transform of $t^n$**: $n!/(s^{n+1})$ — iterated parts.

### Detailed tabular method

For $\int x^3 e^x\, dx$:

| D | I | Sign |
|---|---|---|
| $x^3$ | $e^x$ | + |
| $3x^2$ | $e^x$ | − |
| $6x$ | $e^x$ | + |
| $6$ | $e^x$ | − |
| $0$ | — | — |

Result: $x^3 e^x - 3x^2 e^x + 6x e^x - 6e^x + C = e^x(x^3 - 3x^2 + 6x - 6) + C$.

### Reduction formulas

Via parts: $\int \sin^n x\, dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n-1}{n}\int \sin^{n-2}x\, dx$.

Same for $\cos^n$, $\sec^n$, $\csc^n$.

### Generalization: Green's identity

In dimension $n$, integration by parts is:

$$\int_\Omega u\, \nabla \cdot \mathbf{F}\, dV = \int_{\partial\Omega} u\, \mathbf{F} \cdot \mathbf{n}\, dS - \int_\Omega \nabla u \cdot \mathbf{F}\, dV.$$

For $\mathbf{F} = \nabla v$: first Green's identity $\int u\, \Delta v = \oint u\, \partial_n v - \int \nabla u \cdot \nabla v$.

### Weak formulation in FEM

The Poisson equation $-\Delta u = f$ on $\Omega$ with $u|_{\partial\Omega} = 0$ — parts moves the derivative to test function $v \in H^1_0$:

$$\int_\Omega \nabla u \cdot \nabla v\, dV = \int_\Omega f v\, dV \quad \forall v \in H^1_0(\Omega).$$

Without this transfer via parts, no variational formulation would exist. FEniCS, Firedrake, deal.II implement this symbolically.

### Adjoint of differential operator

In $L^2$ with null boundary conditions: $\langle Du, v\rangle = -\langle u, Dv\rangle$ — $D = d/dx$ is antisymmetric. More generally, the formal adjoint of $L = \sum a_k \partial^k$ is $L^* = \sum (-1)^k \partial^k (a_k \cdot)$. Parts proves this.

### Fourier analysis and smoothness

Iterated parts proves: $|\hat{f}(n)| = O(n^{-k})$ if and only if $f \in C^{k-1}$ with $f^{(k)} \in L^1$. Connection between smoothness in physical space and decay in frequency — central to wavelet theory and compression.

### Quantum mechanics

Hermiticity of momentum $\hat{p} = -i\hbar\, \partial_x$ requires $\langle \psi_1 | \hat{p} \psi_2 \rangle = \langle \hat{p}\psi_1 | \psi_2 \rangle$, proved via parts + boundary condition (wavefunction decays to zero at infinity).

</Porta>

<Porta nivel="pratica" titulo="Practical application">

**Complete recipe:**

1. Does the integrand have a product? If yes, parts. If no, consider substitution.
2. Apply **LIATE** for $u$.
3. $du = u'\, dx$, $v = \int dv$.
4. $uv - \int v\, du$.
5. If $\int v\, du$ is still a product: iterate (or use DI table).
6. If the integral returned: isolate $I$.
7. Check: differentiate the result — should reproduce the integrand.

### Brazilian applications

**Present value of growing cash flow:** income $C(t) = t$ thousand reais per year, rate $r = 10\%$, over $T = 5$ years:

$$VP = \int_0^5 t \cdot e^{-0{,}1 t}\, dt.$$

By parts: $u = t$, $dv = e^{-0{,}1t}\, dt$. Result: approximately 9.48 thousand reais.

**Expectation of exponential variable:** $E[X] = \int_0^\infty x \lambda e^{-\lambda x}\, dx = 1/\lambda$ — parts with $u = x$.

**Laplace formula for circuit ODEs:** $\mathcal{L}\{t^n\} = n!/s^{n+1}$ — iterated parts.

### Classical errors

- Forget the negative sign in $-\int v\, du$.
- Choose $u$ that complicates (anti-LIATE).
- Fail to iterate when polynomial has degree > 1.
- Forget $+ C$ in indefinite integral.

## Worked examples

<Exemplo titulo="Canonical integral xe^x (basic)" numero="1">

**Problem.** Compute $\int x e^x\, dx$.

**Strategy.** LIATE: $x$ is Algebraic, $e^x$ is Exponential. $u = x$ (simplifies upon differentiation), $dv = e^x\, dx$.

**Solution.**

$du = dx$, $v = e^x$.

$$\int x e^x\, dx = x e^x - \int e^x\, dx = x e^x - e^x + C = e^x(x - 1) + C.$$

**Verification.** Differentiate $e^x(x-1) + C$: product rule gives $e^x(x-1) + e^x = xe^x$. Correct.

**Source.** [Active Calculus §5.4, Activity 5.4.2](https://activecalculus.org/single/sec-5-4-parts.html) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Integral of ln x (trick dv = dx)" numero="2">

**Problem.** Compute $\int \ln x\, dx$.

**Strategy.** Logarithmic alone: $u = \ln x$, $dv = dx$ (non-obvious but correct choice).

**Solution.**

$du = dx/x$, $v = x$.

$$\int \ln x\, dx = x \ln x - \int x \cdot \frac{1}{x}\, dx = x \ln x - \int 1\, dx = x \ln x - x + C.$$

**Verification.** Differentiate $x \ln x - x$: $\ln x + x \cdot (1/x) - 1 = \ln x + 1 - 1 = \ln x$. Correct.

**Source.** [APEX Calculus §6.2, Example 6.2.2](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Polynomial x² with DI table (intermediate)" numero="3">

**Problem.** Compute $\int x^2 e^x\, dx$ using the tabular method.

**Strategy.** Polynomial of degree 2 × exponential: DI method (differentiate $x^2$ to zero, integrate $e^x$ repeatedly).

**Solution.**

| D | I | Sign |
|---|---|---|
| $x^2$ | $e^x$ | + |
| $2x$ | $e^x$ | − |
| $2$ | $e^x$ | + |
| $0$ | — | — |

Summing diagonal products with alternating signs:

$$\int x^2 e^x\, dx = x^2 e^x - 2x e^x + 2e^x + C = e^x(x^2 - 2x + 2) + C.$$

**Verification.** Differentiating $e^x(x^2 - 2x + 2)$: $e^x(x^2 - 2x + 2) + e^x(2x - 2) = e^x x^2$. Correct.

**Source.** [APEX Calculus §6.2, Example 6.2.4](https://www.apexcalculus.com/apex-calculus-v5.pdf) — CC-BY-NC.

</Exemplo>

<Exemplo titulo="Trick: integral that returns (e^x cos x)" numero="4">

**Problem.** Compute $I = \int e^x \cos x\, dx$.

**Strategy.** Two applications of parts — the integral will reappear. Isolate $I$.

**Solution.**

1st application: $u = \cos x$, $dv = e^x\, dx$, $du = -\sin x\, dx$, $v = e^x$.

$$I = e^x \cos x + \int e^x \sin x\, dx.$$

2nd application: $u = \sin x$, $dv = e^x\, dx$, $du = \cos x\, dx$, $v = e^x$.

$$I = e^x \cos x + e^x \sin x - \int e^x \cos x\, dx = e^x \cos x + e^x \sin x - I.$$

Therefore $2I = e^x(\cos x + \sin x)$:

$$I = \frac{e^x(\sin x + \cos x)}{2} + C.$$

**Verification.** Differentiating: $\frac{e^x(\sin x + \cos x) + e^x(\cos x - \sin x)}{2} = \frac{2e^x \cos x}{2} = e^x \cos x$. Correct.

**Source.** [OpenStax Calculus Vol. 2, §3.1, Example 3.3](https://openstax.org/books/calculus-volume-2/pages/3-1-integration-by-parts) — CC-BY-NC-SA.

</Exemplo>

<Exemplo titulo="Definite integral with parts (challenge)" numero="5">

**Problem.** Compute $\int_0^\pi x \sin x\, dx$.

**Strategy.** LIATE: $u = x$, $dv = \sin x\, dx$. Apply parts and evaluate at limits.

**Solution.**

$du = dx$, $v = -\cos x$.

$$\int_0^\pi x \sin x\, dx = [-x \cos x]_0^\pi + \int_0^\pi \cos x\, dx.$$

$[-x \cos x]_0^\pi = -\pi\cos\pi - 0 = -\pi(-1) = \pi$.

$\int_0^\pi \cos x\, dx = [\sin x]_0^\pi = 0 - 0 = 0$.

Therefore $\int_0^\pi x \sin x\, dx = \pi + 0 = \pi$.

**Verification.** The result $\pi$ is classical — confirmed numerically ($\approx 3.1416$). The asymmetry of the sign of $x\sin x$ on $[0, \pi]$ (always positive) guarantees a positive result.

**Source.** [Active Calculus §5.4, Exercise 5.4.3](https://activecalculus.org/single/sec-5-4-parts.html) — CC-BY-NC-SA.

</Exemplo>
